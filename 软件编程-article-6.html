TeamCity 2025.03 发布：Recipes、Docker 集成与 UI 全新升级

3/20/2025, 3:31:43 PM

📌 一句话摘要

TeamCity 2025.03 版本发布：UI 界面大更新，Recipes 功能重磅引入，容器化构建能力显著增强！

📝 详细摘要

TeamCity 2025.03 版本带来多项重大更新，旨在显著提升用户体验，并增强构建流程的灵活性和可扩展性。UI 方面，简化了导航，优化了设置组织方式，并改进了页面布局。引入了 Recipes（配方）功能，作为元运行器（meta-runners）的进化，支持 XML/YAML 定义，并可从 Marketplace 获取，有助于构建流程的标准化和效率提升。参数控制方面，明确区分了输入和输出参数，增强了安全性。此外，该版本还增强了 Docker 和 Podman 的集成，支持在容器中运行构建步骤，并改进了 Perforce 的合并功能，支持手动和自动代码合并，适用于需要精细化代码管理的场景。

💡 主要观点

  1. UI 大更新：导航更清晰，设置管理更高效！ 通过重新组织的设置、精简的布局和清晰的 View / Edit 模式切换，显著提升了用户体验和操作效率。
  2. Recipes 功能增强了构建步骤的复用性 Recipes（配方）作为元运行器（meta-runners）的进化，允许通过 XML 或 YAML 定义构建步骤，并支持从 JetBrains Marketplace 获取。
  3. 增强的 Docker 和 Podman 集成，通过“在 Docker 中运行 (Run in Docker)”功能和容器封装器（Container Wrapper），提供了更多容器化构建选项，简化了构建流程 新功能允许在单个容器中运行所有构建步骤，Kotlin 脚本支持容器封装器（Container Wrapper），并改进了 Docker 注册表连接。

💬 文章金句

  • Simplified navigation: The *Edit Project/Configuration* button is now a *Settings* toggle， with distinct accent colors for View and Edit modes. -> 简化导航：*编辑项目/配置* 按钮现在是一个 *设置* 开关，查看和编辑模式具有不同的强调颜色。
  • This release marks the beginning of meta-runners' evolution into recipes. -> 此版本标志着元运行器（meta-runners）向 Recipes（配方）演进的开始。
  • You can run all configuration steps in a single container using the new *Run in Docker* build feature. -> 您可以使用新的“在 Docker 中运行 (Run in Docker)”构建功能在单个容器中运行所有配置步骤。
  • The *Parameters* tab now separates input and output parameters -> “参数 (Parameters)”选项卡现在分离了输入和输出参数。
