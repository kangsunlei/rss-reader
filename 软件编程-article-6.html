谷歌最新 Gemini Agent 爆击 GPT-5.2？人类最后考试得分见分晓！网友：Altman 又该发“红色警报”了

12/12/2025, 7:07:00 AM

📌 一句话摘要

文章详细报道了谷歌发布新版 Gemini Deep Research Agent 并开放 API，与 OpenAI 发布 GPT-5.2 在同一天，“左右互搏”，揭示了二者在 AI 智能体和基础模型领域的激烈竞争，以及谷歌在长链推理、可追溯引用和智能体控制方面的创新。

📝 详细摘要

文章聚焦于谷歌与 OpenAI 在人工智能领域展开的激烈竞争。近日，谷歌发布了重新构想的 Gemini Deep Research Agent，并首次开放了嵌入式研究智能体 API，强调其在长链推理稳定性、超大规模上下文处理能力及可追溯引用方面的突破。几乎同时，OpenAI 发布了备受期待的 GPT-5.2（代号 Garlic），强化了逻辑一致性、工具调用稳定性以及智能体行为的自主性。文章深入对比了两家公司在基础模型能力和智能体平台能力上的“贴身肉搏”，指出谷歌 Deep Research Agent 基于 Gemini 3 Pro 全面重写推理链路，采用多步强化学习训练，并提供全链路引用，旨在从“报告生成工具”升级为“可执行完整研究任务的专业智能体”。同时，谷歌推出了 Interactions API，使开发者能高度控制智能体行为。文章还引用了技术社区对此次发布的讨论，特别是对谷歌新 Agent 在“人类最后的考试”（HLE）等基准测试中略优于 GPT-5.2 的关注。

💡 主要观点

  1. 谷歌发布全新 Gemini Deep Research Agent，显著提升长链推理稳定性和可追溯性。 新 Agent 基于 Gemini 3 Pro 构建，采用多步强化学习，在复杂任务中减少幻觉并确保决策一致性，同时为每个结论提供可追溯的引用来源，使其从内容生成工具升级为专业的、可审计的研究智能体。在“人类最后的考试”（HLE）等基准测试中表现出色，并在特定任务上略优于 GPT-5.2。
  2. 谷歌与 OpenAI 在同一时间段发布重磅更新，标志着行业竞争进入白热化阶段。 谷歌 Deep Research Agent 和 OpenAI GPT-5.2（Garlic）的同步发布，凸显了两大巨头在智能体未来、基础模型能力及应用生态主导权上的战略对抗。GPT-5.2 则通过强化逻辑一致性、工具调用稳定性及智能体自主性，持续推高通用 AI 能力的上限。
  3. 谷歌推出了 Interactions API，赋予开发者对智能体行为的精细化控制能力，预示未来计算范式变革。 该 API 允许开发者结构化控制智能体的行为状态、推理步骤和任务执行，将 Deep Research Agent 从产品内部能力转变为通用的智能体执行引擎。这与 OpenAI 的 Agent API、Swarm 等框架共同指向未来软件开发将以智能体为核心，谁掌握智能体框架标准，谁就掌握新一代计算范式主导权。

💬 文章金句

  • 新版 Deep Research Agent 完全基于 Gemini 3 Pro 构建，而 Gemini 3 Pro 被谷歌视为其迄今最"真实"、最可靠、最适合长链推理的旗舰模型版本。
  • 新版 Deep Research Agent 的另一个核心优势是其超大规模上下文处理能力。
  • Gemini Deep Research 在完整的"人类最后的考试"（HLE）数据集上取得了 46.4% 的领先成绩，在 DeepSearchQA 上取得了 66.1% 的成绩，在 BrowseComp 上取得了高达 59.2% 的成绩。
  • Interactions API 让开发者首次能够以结构化方式控制智能体的行为状态、推理步骤、长链任务执行、中间状态存储等。
  • 如果说基础模型决定了智能体能否思考，那么智能体平台能力则决定了智能体能否执行任务。
