📝 详细摘要

本期《React 中文周刊》#252 精心梳理了 React 及前端领域的最新进展和热门话题。重点介绍了 Storybook v10 的发布，其全面转向 ESM 并实现体积减轻 29% 的重大更新。此外，还探讨了 Godot 游戏引擎与 React Native 的创新性集成，以及 React Compiler 1.0 的实战演示，展示了自动记忆化带来的性能提升。周刊还涵盖了 React Native Community CLI 的严重安全漏洞预警、Three.js 与 React 结合的生成式艺术创作、React Native 应用程序中 AirDrop SQLite 数据库的方法，以及在 ChatGPT 中运行 Next.js 的深度实践。文章最后还汇总了 npm 认证方式更新、Node v24 LTS 发布等前端生态系统的重要快讯和多个 React 相关组件库的版本更新，为开发者提供了全面且及时的信息速览。

💡 主要观点

  1. Storybook v10 全面转向 ESM，显著提升前端组件开发效率和性能 Storybook v10 移除 CommonJS 支持，全面拥抱 ESM，使整体体积减轻 29%，并带来全新的模块自动 Mock 方式，提升了前端组件库的开发体验和运行效率。
  2. Born React Native Godot 项目实现游戏引擎与 React Native 应用的深度融合 该开源项目首次将 Godot 2D/3D 游戏引擎嵌入 React Native 应用，支持 iOS/Android 平台，并允许通过 JavaScript 直接访问 Godot API，为跨平台游戏和应用开发开辟新途径。
  3. React Compiler 1.0 搭配 TanStack Start 的实战演示展现自动记忆化优化潜力 知名 React YouTuber 通过实战演示，直观展示了 React Compiler 自动记忆化能力如何大幅提升应用性能，为开发者提供了优化 React 应用的新思路。
  4. React Native Community CLI 发现严重安全漏洞，需开发者高度关注 JFrog 安全团队披露了 React Native Community CLI 中存在的远程命令执行漏洞，开发服务器运行时可能受影响，提醒开发者及时关注修复进展以保障项目安全。
