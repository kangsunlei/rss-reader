📝 详细摘要

GitHub 宣布将 GPT-5 mini 集成到其 AI (人工智能) 驱动的代码助手 GitHub Copilot 中。本次更新旨在缩短响应时间，为开发者提供更快速、更高效的 AI (人工智能) 辅助。GPT-5 mini 将首先应用于 GitHub Copilot 企业版和 Pro+ 计划，随后逐步推广至其他版本。开发者可以在 Visual Studio Code、GitHub Copilot 聊天和 GitHub Mobile 中体验 GPT-5 mini，显著提升 Copilot 使用体验。
