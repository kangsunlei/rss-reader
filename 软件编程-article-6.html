CompactGUI：用 Windows 原生压缩功能，为程序和游戏文件夹瘦身

8/27/2026, 3:55:07 PM

📌 一句话摘要

CompactGUI 是一款利用 Windows 原生 NTFS 压缩功能的图形界面工具，能够直接压缩程序和游戏文件夹，节省硬盘空间而不影响运行，甚至可能提升加载速度。

📝 详细摘要

文章介绍了 CompactGUI 4.0，一个基于 Windows 原生 compact.exe 的图形界面工具。它允许用户直接压缩硬盘上的文件夹和文件，包括游戏和程序，从而节省存储空间。压缩后的文件可以直接运行，且不会显著增加 CPU 负载。此外，由于文件大小减小，加载时间在慢速机械硬盘上可能会有所缩短。安装和使用方法也进行了说明。

💡 主要观点

  1. 利用原生压缩功能节省空间 CompactGUI 使用 Windows 内置的 NTFS 压缩功能，允许用户直接压缩文件夹，从而节省硬盘空间，例如将 246GB 的游戏文件夹压缩至 235GB。
  2. 不影响程序运行 压缩后的文件可以直接运行，无需解压。现代 CPU 处理这些压缩文件的额外负载几乎可以忽略不计，不会影响游戏或程序的性能。
  3. 可能提升加载速度 由于文件大小减小，读取时间可能会缩短，尤其是在慢速的机械硬盘上，这可以作为一种提升加载速度的手段。
