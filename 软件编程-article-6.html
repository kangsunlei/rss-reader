Mac 也能装 SteamOS 了！开源工具 Steamac，让苹果电脑直接玩 Windows 游戏

10/8/2026, 3:22:19 PM

📌 一句话摘要

开源工具 Steamac 通过在 Mac 上运行 ARM64 版 SteamOS 虚拟机，结合 FEX 和 Proton 技术，实现了在苹果电脑上直接游玩 Windows x86 游戏的功能。

📝 详细摘要

Steamac 是一款免费开源的 Mac 工具，利用 libkrun 创建轻量级虚拟机以运行 Valve 官方为 Steam Frame 开发的 ARM64 版 SteamOS。由于 macOS 与 SteamOS 均基于 ARM64 架构，系统本身无需模拟即可高效运行。针对大量 x86 架构的 Windows 游戏，Steamac 采用 FEX 进行指令动态翻译，并借助 Proton 兼容层及 DXVK/vkd3d-proton 图形转换栈，使游戏能在 Apple Silicon GPU 上获得硬件加速。目前该项目已支持多款 DirectX 11/12 游戏（如《剑星》、《生化危机 2》），在 M4 Max 芯片上可达 60 FPS，但仍处于早期阶段，内存分配策略固定且需下载较大镜像文件。

💡 主要观点

  1. Steamac 通过虚拟化 ARM64 SteamOS 实现 Mac 原生运行 Windows 游戏的新路径 不同于传统的 CrossOver 或 Whisky 兼容层方案，Steamac 直接在 Mac 上启动一个完整的 ARM64 Linux 环境（SteamOS），利用同架构优势避免操作系统层面的模拟开销，再在内部处理游戏兼容性。
  2. FEX 与 Proton 协同解决 x86 指令集与 Windows API 的兼容性问题 FEX 负责将游戏的 x86 指令动态翻译为 ARM64 指令，Proton 提供 Windows 游戏所需的 Linux 兼容层，配合 DXVK 等图形转换技术，最终将渲染任务交给 Apple GPU 加速。
  3. 当前性能表现依赖芯片型号，M4 Max 表现优异但早期版本存在局限 测试显示 M4 Max 在 1280x800 分辨率下运行《剑星》试玩版可达约 60 FPS，而 M1 Max 仅约 18-29 FPS。项目尚处早期，默认占用一半物理内存作为虚拟机资源，可能影响多任务体验。

💬 文章金句

  • 相当于在 Mac 里装了一台 Steam 游戏机。
  • 由于 SteamOS 和苹果 M 系列芯片都采用 ARM64 架构，因此运行操作系统本身不需要模拟 x86 处理器。
  • FEX：将游戏的 x86 指令动态翻译成 ARM64 指令，让苹果芯片能够执行。
