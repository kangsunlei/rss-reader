全面掌握网络连接：Cloudflare Radar 实时 BGP 路由可见性

5/21/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare Radar 发布实时 BGP 路由可见性服务与 API，赋能网络分析。

📝 详细摘要

本文介绍了 Cloudflare Radar 全新的实时 BGP 路由查找服务，该服务通过 Web 界面可视化（桑基图）和 API 提供。它源自 RIPE RIS 和 RouteViews 的实时数据流，通过提供近乎实时、聚合的全局 BGP 数据，克服了传统路由查询工具范围受限以及聚合服务缺乏 API 的不足。该服务允许网络运营商调试网络可达性问题，评估资源全局覆盖范围，并分析路由泄露（错误地发布路由信息）和路由劫持（恶意篡改路由信息）等异常情况，并提供最新的路径信息。底层架构利用这些实时数据流（RIS Live、OpenBMP）和一个带有 Actor 模型（一种并发计算模型，用于提高系统的响应速度和可扩展性）的前缀树结构（一种用于高效存储和检索路由信息的数据结构），以实现高效的数据处理和可扩展性。该 API 使开发者能够构建自动监控和分析工具。

💡 主要观点

  1. 通过 Cloudflare Radar Web 用户界面提供实时全局 BGP 路由可见性。 网络运营商可以使用交互式桑基图和表格可视化 BGP 路径，以快速识别起源、AS 路径、RPKI 状态（资源公钥基础设施状态，用于验证路由信息的真实性），并以最小的延迟诊断路由异常。
  2. 通过 Cloudflare Radar API 提供对实时 BGP 数据的程序化访问。 使开发者和运营商能够将实时 BGP 信息集成到自定义脚本、监控系统和自动化分析工具中，以实现主动网络管理。
  3. 利用实时数据流和高效的架构实现近乎实时的更新。 该系统使用 RIS Live 和 OpenBMP 实时数据流、前缀树数据结构和一个 Actor 模型来处理和提供具有秒级延迟的 BGP 数据，比传统的基于存档的方法快得多。
