三行代码将任意 React 应用连接到 MCP 服务器

6/18/2025, 2:00:08 PM

📌 一句话摘要

介绍 `use-mcp`，一个用于轻松连接应用到 MCP 服务器的 React 库，并开源了 Cloudflare AI Playground。

📝 详细摘要

本文宣布发布 `use-mcp`，这是一个开源的 React 库，旨在简化 模型上下文协议 (MCP) 服务器客户端的开发。它强调了 `use-mcp` 如何通过抽象处理 传输协议（流式 HTTP， SSE）、认证 (OAuth 2.1) 和 会话管理 等复杂性，仅用三行代码即可将任意 React 应用连接到 MCP 服务器。该库还包含 连接状态管理、动态工具发现 和 调试 功能。此外，Cloudflare 已开源其 AI Playground，这是一个使用 `use-mcp` 和 Workers AI 构建的 聊天界面，作为一个实用示例，展示如何构建能够通过 MCP 集成外部服务的定制 AI 应用。本文将这些工具定位为对不断壮大的 MCP 生态系统 的贡献，鼓励开发者构建和连接 AI Agent。

💡 主要观点

  1. `use-mcp` 库简化了 React 中的 MCP 客户端开发。 轻松将 React 应用连接到 MCP 服务器，自动处理 传输、认证 和 会话管理 等复杂细节。
  2. 该库为可靠的连接和认证提供了强大的功能。 `use-mcp` 管理带有 退避 的 连接重试，提供 实时连接状态，并支持 OAuth 2.1 进行 安全认证流程，抽象了 手动处理。
  3. 动态工具发现 实现了与服务器功能的无缝集成。 使用 `use-mcp` 的客户端能够自动发现 MCP 服务器提供的工具，包括用于输入验证的类型安全元数据，实现无需代码修改即可适应。
  4. Cloudflare 的 AI Playground 已开源，作为实用示例和 调试 工具。 使用 `use-mcp` 和 Workers AI 构建的 playground 演示了如何构建 MCP 客户端 聊天界面，提供针对 MCP 连接 和 工具调用 的 实时调试 和 监控。
  5. Cloudflare 积极贡献 `use-mcp` 和其他工具给 开源 的 MCP 生态系统。 开源这些项目鼓励 社区参与 并 加速 模型上下文协议 及其应用的开发。

💬 文章金句

  • 仅需 3 行代码即可将任意 React 应用连接到 MCP 服务器，由库自动处理 传输、认证 和 会话管理。
  • `use-mcp` 是一个 React 库，它抽象了构建 MCP 客户端的所有复杂性。
  • 这为您提供了一个完整的 认证系统，让您可以 安全连接 到 远程 MCP 服务器，而无需 编写任何逻辑。
  • 如果 服务器添加新功能，您的应用 无需修改代码即可看到它们。
  • 我们很高兴能将 `use-mcp` 库 贡献给 MCP 生态系统，让更多开发者能够构建 远程 MCP 客户端。
