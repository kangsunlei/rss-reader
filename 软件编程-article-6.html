Vitest 4.0 发布：稳定浏览器模式和可视化回归测试就绪

12/5/2025, 2:00:00 PM

📌 一句话摘要

Vitest 4.0 引入稳定浏览器模式、内置可视化回归，并增强开发者体验。

📝 详细摘要

Vitest，这款 Vite 原生测试框架，发布了 4.0 版本，在浏览器测试和可视化回归测试方面带来了显著进展。主要功能包括稳定浏览器模式，允许测试在真实浏览器中运行，以提高准确性；集成了 toMatchScreenshot 的可视化回归测试，用于检测 UI 变化。此外，新版本还增加了 Playwright Traces 集成，通过 VSCode 扩展改进了调试功能，并优化了报告器行为。Vitest 因其开发者体验和性能而备受赞誉，但同时也注意到与旧版本 Vite 的 TypeScript 兼容性存在一个小问题。此版本包含重大更改，并提供了详细的迁移指南。

💡 主要观点

  1. Vitest 4.0 稳定了浏览器模式，提供更准确的真实浏览器测试。 从实验性转为稳定，浏览器模式支持直接在浏览器中运行测试，提供比模拟环境更可靠的结果，并需要新的提供者包（provider）。
  2. 集成的可视化回归测试，让 UI 变更检测更轻松。 新的 toMatchScreenshot 断言和 toBeInViewport 匹配器允许开发人员轻松捕获和比较 UI 组件的屏幕截图，从而简化视觉质量保证。
  3. 通过调试和性能改进，增强开发者体验。 例如 VSCode 浏览器测试调试按钮、Playwright Traces 以及持续强大的监听模式性能等功能，显著提高了开发工作流程效率。

💬 文章金句

  • Vitest 4.0 带来多项重大更新，包括浏览器模式升级为稳定版、内置可视化回归测试支持、Playwright Traces 集成以及更强大的调试功能。
  • Vitest 4.0 的一个重要新特性是稳定浏览器模式，该功能自早期版本以来一直处于实验阶段。现在，开发者可以在真实浏览器中（而非模拟环境）运行测试了。
  • 一位 Reddit 用户指出，与 Percy 或 Chromatic 等附加解决方案相比，原生集成的可视化回归测试意味着需要管理的依赖项少了一个。
  • 同一位开发者对开发者体验的改进赞不绝口，称监听模式的性能一直优于 Jest，而且现在的 Vitest 感觉像是一个更完善的测试解决方案。
