Cloudflare AI Gateway 支持 BYOK 及国内模型接入

9/27/2026, 10:39:44 AM

📌 一句话摘要

介绍 Cloudflare AI Gateway 支持 Bring Your Own Key (BYOK) 功能，可直接配置腾讯云等平台的 API Key，从而在应用中调用 Kimi K3、DeepSeek V4.1 flash 等国内模型。

📝 详细摘要

该推文分享了 Cloudflare AI Gateway 的新特性：支持 BYOK。这意味着开发者可以将其他云厂商（如腾讯云）的模型 API Key 直接配置到 Cloudflare 网关中，无需修改代码即可在自有网站或服务中调用这些模型。文中列举了支持的模型包括 Kimi K3、DeepSeek V4.1 flash 和 GLM 5.3 FlashX。引用内容提及 Vercel AI Gateway 也支持类似功能。

💡 主要观点

  1. Cloudflare AI Gateway 支持 BYOK 允许用户将外部 API Key（如腾讯云）配置到 Cloudflare 网关，实现跨平台模型调用的统一入口，简化集成流程。
  2. 支持多款主流国内模型 明确列出了 Kimi K3、DeepSeek V4.1 flash、GLM 5.3 FlashX 等模型，表明该网关对国内主流 AI 模型的兼容性良好，适合需要混合使用国内外模型的场景。
