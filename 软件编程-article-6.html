Claude、Cursor、OpenClaw 集体上手机，不摸鱼、不请假、24h 为你打工

7/12/2026, 2:15:00 AM

📌 一句话摘要

文章介绍 Claude Cowork、Cursor 和 OpenClaw 纷纷推出移动端，说明 AI 正从聊天助手转变为可在后台持续工作的代理，手机成为管理这些 AI 员工的控制台。

📝 详细摘要

文章详细描述了 Anthropic 的 Claude Cowork、Cursor 和 OpenClaw 三款 AI Agent 产品近期陆续推出移动端或网页端的情况。Claude Cowork 将任务执行环境迁移到远程云端，使得用户可以在关闭电脑后仍在手机上查看进度、接收需要人工判断的通知并继续操作；Cursor 的移动端则侧重于远程控制仍在本地运行的 Agent，提供代码差异、日志等信息并支持后续指令；OpenClaw 则采用本地网关+手机伴随节点的方式，手机主要负责对话、语音控制和设备权限调用。文章进一步分析了 AI Agent 发展的三个阶段：从单轮聊天机器人，到嵌入工作环境的执行助手，再到如今脱离具体设备、能够异步长时间运行的“数字员工”，并指出手机正成为这类代理的管理后台。文中还引用了社区讨论，指出尽管 Agent 能力在提升，但其可靠性、权限边界、可观察性和成本可预测性仍是进入生产环境的关键挑战。

💡 主要观点

  1. Claude Cowork 将任务执行迁移到远程云端，实现电脑关闭后任务仍可继续。 用户可在手机上查看任务进度、接收需要人工判断的通知，完成决策后 Agent 继续工作，手机成为管理控制台。
  2. Cursor 移动端侧重于远程控制本地运行的 Agent，提供代码差异、日志等信息并支持后续指令。 用户可以在手机上查看 Agent 执行状态、查看差异和日志，决定是否合并 Pull Request，实现异步协作。
  3. OpenClaw 采用本地网关+手机伴随节点模式，手机负责对话、语音控制和设备权限调用。 手机不承载完整 Agent，而是通过与本地 Gateway 配对实现对话和控制，保留用户对数据和基础设施的掌控。
  4. AI Agent 正经历三阶段演进：聊天机器人 → 工作环境执行助手 → 脱离设备的异步数字员工，手机成为其管理后台。 第一阶段为单轮问答；第二阶段 Agent 能读取文件、运行命令；第三阶段 Agent 能在云端或私有设备后台长时间运行，用户只需在关键节点介入。

💬 文章金句

  • 在办公桌前把任务交给 Claude，再从手机上接收已经完成的工作。
  • 这是 Cowork 的一次'重大更新'，因为 Claude 终于可以在电脑关闭后继续运行。
  • 手机不再只是 Claude 的另一个聊天窗口，而开始成为管理 Claude 工作的控制台。
  • Agent 必须能够在后台工作，而人只在关键节点出现。
