QUIC 重启难题：udpgrm 来救场

5/7/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 开源的 udpgrm，利用 eBPF 和 SO_REUSEPORT 技术，为 QUIC 等 UDP 服务提供无损重启方案，保障 UDP 服务无损重启。

📝 详细摘要

本文介绍了 Cloudflare 开源的 udpgrm，一个用于 UDP 服务器无损重启的工具，解决 UDP 服务器在重启时因状态丢失导致的连接中断问题。udpgrm 通过利用 Linux 的 SO_REUSEPORT API 和 eBPF 技术，实现了在服务器重启期间保持 UDP 连接的连续性，确保 Cloudflare 的 QUIC 服务在升级过程中保持稳定。文章详细解释了 udpgrm 的工作原理，包括如何使用 REUSEPORT 组管理多个套接字，以及如何使用 eBPF 程序进行流量分发。此外，还介绍了 udpgrm 的不同 dissector 模式，以适应不同的 UDP 协议。最后，文章提供了 udpgrm 的部署和使用方法，包括系统管理员和程序员两个角度，以及如何与 systemd 集成，确保 UDP 服务器在重启过程中不会丢失任何数据包。

💡 主要观点

  1. udpgrm 通过 SO_REUSEPORT 和 eBPF 技术实现 UDP 服务器的无损重启。 通过 SO_REUSEPORT 允许多个套接字绑定到同一 IP:端口，eBPF 程序根据连接状态将数据包路由到正确的套接字，从而实现平滑重启。
  2. udpgrm 支持 FLOW、CBPF、NOOP 和 BESPOKE 等多种 dissector 模式，灵活适应不同 UDP 协议的需求。 包括 FLOW、CBPF 和 NOOP 模式，以及更高级的 BESPOKE 模式，用于处理 QUIC 等复杂协议，确保流量的正确路由和分发。
  3. udpgrm 与 systemd 集成，简化了 UDP 服务器的部署和管理。 通过 udpgrm_activate.py 脚本和 mmdecoy 脚本，解决了 systemd 在管理 UDP 服务的生命周期和套接字创建方面的限制，实现了自动化的套接字创建和生命周期管理。

💬 文章金句

  • In particular， performing graceful restarts (also known as "zero downtime") for UDP servers has proven to be surprisingly difficult.
  • Now we have found a better method， leveraging Linux's `SO_REUSEPORT` API.

  • The adoption of QUIC and other UDP-based protocols means that gracefully restarting UDP servers is becoming an increasingly important problem.
