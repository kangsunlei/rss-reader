OpenCode 在 Zed IDE 中的配置与高效 agent 工作流

1/5/2026, 1:46:09 PM

📌 一句话摘要

作者分享了基于 Zed + OpenCode + Agent Servers 插件的 AI 编程设置，并介绍了 OpenCode Zen 提供免费模型及强大的 oh-my-opencode 多 Agent 协作方案，但也指出其消耗 token 的问题。

📝 详细摘要

推文详细介绍了独立开发者 Viking 推荐的 AI 编程设置。由于 OpenCode 最近流行，作者推荐了将其与 Zed IDE 结合的方案，通过 'Agent Servers' 插件完美集成，实现了在 IDE 中进行代码级别修改的流畅体验。作者提到 OpenCode Zen 中许多模型（如 MiniMax M2.1 和 GLM 4.7）免费且高效，适用于轻量级任务。此外，他还简要分析了 'oh-my-opencode' 这个复杂的多 Agent 协作方案，该方案包括一个主协调 Agent（Sisyphus， 使用 Claude Opus）和多个辅助 Agent（如 Oracle、Frontend UI/UX Engineer、Librarian、Explore），虽然功能强大，但作者指出其在简单需求下会消耗过多的 token。作者对 Quoted Tweet 中提到的 Cursor， Zed + OpenCode + GLM 4.7 的丝滑体验表示认同，并强调其性价比高。
