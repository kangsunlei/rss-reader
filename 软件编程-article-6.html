使用布隆过滤器加速 Vercel 全局路由的实践

9/19/2025, 1:00:00 PM

📌 一句话摘要

Vercel 通过布隆过滤器优化全局路由服务，显著降低内存占用、提升 TTFB 并加速路径查找。

📝 详细摘要

本文详细介绍了 Vercel 针对其全局路由服务性能瓶颈的工程解决方案。此前，该服务解析包含所有项目路径的大型 JSON 文件以验证请求，导致高延迟（第 99.9 百分位高达 250 毫秒），并阻塞具有大量静态路径网站的事件循环。为解决此问题，Vercel 实施了布隆过滤器，一种用于加速路径查找的概率数据结构。该方法保证无假阴性，确保返回 404 错误的安全性，而假阳性仅触发额外的存储请求。实现过程涉及协调构建和路由服务中的布隆过滤器逻辑，构建服务生成 Base64 编码的紧凑型布隆过滤器。关键优化在于直接解码 Base64 字节，避免了昂贵的字符串操作。优化后，路径查找延迟显著降低至接近于零（第 99 百分位数为 0.5 毫秒），路由服务内存使用量减少 15%，TTFB（第 75 百分位数及以上）提升 10%。

💡 主要观点

  1. 大型 JSON 路径查找文件在全球路由中造成严重瓶颈。 具有数十万静态路径的网站会生成数兆字节的 JSON 文件，导致高达 250 毫秒的解析延迟，并阻塞单线程路由服务的事件循环。
  2. 布隆过滤器有效地取代了用于路径存在检查的缓慢 JSON 解析。 Vercel 利用布隆过滤器无假阴性的特性，实现快速的“路径不存在”检查，仅在潜在匹配时回退至存储，显著提升查找速度。
  3. 巧妙的实现细节，例如直接 Base64 解码，对于性能至关重要。 通过直接将 Base64 数据视为字节数组创建布隆过滤器，避免了字符串操作，实现了近乎瞬时的过滤器实例化，仅受限于文件读取速度。
  4. 该优化在各个方面都产生了显著的性能提升。 优化后，路径查找速度提升 100-200 倍，路由服务内存使用量降低 15%，较高百分位的 TTFB 提升 10%，所有用户均受益。

💬 文章金句

  • 少数拥有数十万静态路径的网站是造成路由服务瓶颈的原因。
  • 通过用布隆过滤器替换缓慢的 JSON 解析操作，我们将路径查找延迟降低到几乎为零，并提高了每个人的性能。
  • 布隆过滤器可能会返回假阳性，但绝不会返回假阴性。对于路径查找，此属性很有价值。
  • 即使经过 Base64 编码，此布隆过滤器也比以前的 JSON 文件小 70-80%，这使得它在构建期间更快地上载，并在我们的路由服务中更快地解析。
  • 我们创建布隆过滤器的速度受文件读取的限制，这比字符串创建快几个数量级，因此我们可以几乎立即创建非常大的布隆过滤器。
