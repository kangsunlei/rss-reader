Skykeep：跨平台 iCloud 客户端，实现 Windows 本地同步

11/17/2026, 12:00:04 AM

📌 一句话摘要

Skykeep 是开源 iCloud 客户端，将备忘录、提醒事项、日历等在 Windows 和 Linux 上呈现，且支持断网查看和实时同步。

📝 详细摘要

Skykeep 是一个开源的 iCloud 客户端项目，为 Windows 和 Linux 用户提供了六个独立应用（备忘录、提醒事项、日历、通讯录、iCloud 云盘、照片）。它实现了数据的本地存储，应用启动即可查看内容，支持断网使用。iPhone 上的数据改动会实时同步至本地，支持多设备同时编辑。项目还提供「发送到 iPhone」右键菜单功能，允许直接将照片发送至相册、文档发送至文件 App，无需在手机上额外安装应用。此外，用户还可以将 iCloud 里的原图、原视频和云盘文件备份到本地硬盘。整个项目无需服务器和账号，数据仅在设备之间传输，用户可通过 Windows 微软商店直接下载安装。

💡 主要观点

  1. 本地数据存储与断网访问 数据先存在本地，应用启动即有内容，用户无需持续联网即可查看备忘录、提醒事项等信息。
  2. 实时同步与多设备协作 iPhone 上作出的修改会实时同步至 Windows 端，支持两台设备同时编辑同一内容，所有改动都被保留。
  3. 「发送到 iPhone」右键便利功能 通过右键菜单可直接将照片发送至相册、文档发送至文件 App，无需在手机端安装额外应用，大幅提升文件传输便捷性。
  4. 零服务器、隐私优先的设计 整个项目不需要服务器和账号，数据仅在设备之间点对点传输，确保用户数据隐私安全。
