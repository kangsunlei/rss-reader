GitHub 遭入侵，黑客开价 5 万美元卖源码！员工装了个 VS Code 插件，致 3800 个内部仓库被盗

5/21/2026, 6:32:00 AM

📌 一句话摘要

GitHub 因员工安装恶意 VS Code 插件导致约 3800 个内部仓库被窃，黑客组织 TeamPCP 开价 5 万美元出售这些包含 Copilot 等核心项目源码的数据。

📝 详细摘要

本文报道了一起针对 GitHub 的供应链安全攻击事件。攻击者通过向 VS Code 官方插件市场投毒，诱使一名 GitHub 员工安装了恶意扩展，从而控制了该员工的开发设备，并窃取了约 3800 个内部代码仓库。黑客组织 TeamPCP 在暗网公开叫卖这些数据，起售价 5 万美元，声称数据包含 GitHub Copilot、Enterprise Server 等核心项目源码。文章分析了 VS Code 插件生态的安全隐患，指出插件拥有读取本地文件、执行终端命令、访问 Git 凭据等高权限，而开发者对官方市场的盲目信任是攻击得手的关键。文章还回顾了近年来多起 VS Code 恶意插件事件，强调 AI 编程助手类插件正成为新的高危攻击入口，并揭示了从恶意插件到开发者电脑再到企业核心资产的完整攻击链。

💡 主要观点

  1. GitHub 因员工安装恶意 VS Code 插件导致约 3800 个内部仓库被窃。 攻击者通过投毒 VS Code 扩展控制了员工设备，进而访问了包含 Copilot、Enterprise Server 等核心项目的内部代码仓库，黑客组织 TeamPCP 开价 5 万美元出售这些数据。
  2. VS Code 插件拥有极高权限，是供应链攻击的理想入口。 恶意插件可以读取本地文件、扫描目录、获取环境变量、调用终端命令、访问 Git 凭据等，而开发者对官方插件市场的盲目信任使得这类攻击极易得手。
  3. AI 编程助手类插件正成为新的高危攻击入口。 随着 AI Coding 工具爆发，伪装成 AI 编程助手的恶意插件已多次出现，累计安装量达数百万次，可将开发者设备数据上传至海外服务器。
  4. 攻击链清晰：恶意插件 → 开发者电脑 → 内部仓库 → 企业核心资产。 攻击者无需正面突破公司服务器，只需攻陷一名开发者，即可通过其开发机连接内部系统，窃取核心资产。

💬 文章金句

  • 攻击者甚至不需要正面突破公司服务器，他们只需要'攻陷开发者'。
  • 过去几年里，开发者圈子里一直有个默认共识：'从官方插件市场下载工具，至少是安全的。'——但现在，这个共识正在被一次次打破。
  • 开发者如今最常使用的 AI Coding、自动补全、代码生成类插件，正在成为新的高危攻击入口。
