Wassette：微软基于 Rust 构建的 Wasm 与 MCP 之间的桥梁

8/24/2025, 2:15:00 AM

📌 一句话摘要

微软 Wassette 项目基于 Rust 和 WebAssembly，利用模型上下文协议（MCP）赋能 AI 智能体自主发现并安全执行外部工具，提升其能力和安全性。

📝 详细摘要

文章详细介绍了微软 Azure Core Upstream 团队发布的 Wassette，一个基于 Rust 的运行时。该项目创新性地利用了 Wasmtime WebAssembly 运行时和模型上下文协议（MCP），旨在彻底改变 AI 智能体获取和执行新功能的方式。Wassette 充当 WebAssembly 组件与 MCP 之间的桥梁，使得 AI 智能体能够自主从开放容器倡议（OCI）注册表下载、审查并安全地执行所需的工具，从而突破了传统智能体受限于预配置工具集的限制。文章强调了 Rust 在提供安全高性能运行时基础方面的优势，WebAssembly 在提供可移植沙箱执行环境中的作用，以及 MCP 作为 AI 智能体工具集成标准协议的重要性。Wassette 通过能力驱动的安全模型，确保了即使是潜在恶意工具也能在严格隔离的环境中运行，保障了系统安全。未来，Wassette 将致力于实现智能体的自主工具发现功能，进一步提升 AI 系统的自我改进能力。

💡 主要观点

  1. Wassette 作为 Wasm 与 MCP 的桥梁，使 AI 智能体具备自主工具获取与执行能力。 通过将 WebAssembly 组件转换为 MCP 兼容工具，Wassette 允许 AI 智能体根据任务需求，从 OCI 注册表动态下载并安全执行新功能，突破了预设工具集的限制，实现了“补给式”能力扩展。
  2. Rust、WebAssembly 和 MCP 的结合为 AI 智能体提供了高性能、高安全性的运行时环境。 Rust 提供内存安全和零成本抽象，WebAssembly 提供可移植的沙箱执行环境和工作负载隔离，MCP 提供标准化的接口，共同确保 AI 智能体在安全隔离的环境下高效运行。
  3. Wassette 采用能力驱动的安全模型，确保 AI 智能体工具执行的安全性。 Wasmtime 运行时默认拒绝系统资源访问，并通过用户明确授权机制，即使是潜在恶意组件也无法未经许可访问系统资源，极大限制了潜在风险，实现了浏览器级的安全隔离。

💬 文章金句

  • Wassette 建立在经过实战考验的基于 Rust 的 WasmtimeWebAssembly （Wasm）运行时之上，并利用模型上下文协议（MCP），使 AI 智能体能够自主下载、审查和安全地执行工具，同时保持浏览器级的安全隔离。
  • 我们可以把这看作是教导智能体如何进行补给：认识到需要什么，并弄清楚如何得到它。
  • Rust 提供了安全、高性能的运行时基础。WebAssembly 提供了可移植的沙箱执行环境。MCP 提供了标准化的接口，使 AI 智能体可以普遍访问工具。
  • 组件提供了与现代浏览器引擎相当的工作负载隔离，这是通过默认拒绝功能系统实现的。
  • 我们相信，如果一个智能体缺少完成任务所需的工具，它应该能够自主地找到这些工具并加载它们。
