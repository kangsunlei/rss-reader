📝 详细摘要

文章按主题分块介绍了本周 GitHub Trending 排名靠前的开源项目：首先推荐李博杰开源的《深入理解 AI Agent：设计原理与工程实践》电子书，覆盖 Agent 基础、上下文工程、记忆、编码 Agent 等十章并提供 92 个可运行实验；其次介绍 LingBot-Map，一个基于 Geometric Context Transformer 的前馈式 3D 基础模型，能够从连续图像实时重建三维场景，支持长序列推理；随后推荐 croc，一个基于 PAKE 的跨平台文件传输工具，使用一句话口令即可完成端到端加密传输；接着展示 UI Skills 项目，提供一套可供编码 Agent 调用的 UI 规范 Skills，涵盖基础布局、可访问性、运动性能等细则；随后介绍 Kimi Code、Pi Web、jcode 等终端 AI Agent 及其增强工具，强调它们在代码编辑、会话管理、多模型协作方面的特性；最后列出了一批值得关注的其他项目，如技能合集、模型网关、代码知识图谱、设计 Skill 等。整体内容以项目简介、星数增长和使用方式为主，信息密度较高，但缺乏深度技术分析和独立评测。

💡 主要观点

  1. 《深入理解 AI Agent》电子书提供系统学习路径，配有 92 个可运行实验。 本书围绕 Agent = LLM + 上下文 + 工具的公式展开，涵盖基础理论、上下文工程、记忆系统、编码 Agent、多模态交互等十章内容，并提供多语言版本和在线阅读，适合作为 Agent 学习的主线教材。
  2. LingBot-Map 实现从视频流实时重建三维场景，支持长序列推理。 该项目提出 Geometric Context Transformer 和分页 KV Cache，在 518×378 分辨率下可达约 20 FPS，能够处理超过 1 万帧的视频，适用于机器人建模、自动驾驶和数字孪生等场景。
  3. croc 通过一句话口令实现跨平台端到端加密文件传输。 发送端执行 `croc send` 生成短语，接收端输入同一短语即可完成传输；支持断点续传、IPv6 自动回退以及通过 Tor 等代理工作，无需配置端口转发。
  4. UI Skills 提供可供编码 Agent 调用的 UI 规范集合，解决 AI 生成界面的常见问题。 包括 baseline-ui（间距、排版、组件、动画、布局）、fixing-accessibility、fixing-motion-performance 等子项目，以及从现有代码提取 DESIGN.md 的工具，给出如图标按钮需 aria-label、交互反馈不超过 200ms 等具体规则。
  5. Kimi Code、Pi Web、jcode 等终端 AI Agent 提供代码编辑、会话管理和多模型协作能力。 Kimi Code 能读取修改代码、执行 Shell 命令、搜索网页并自主调整计划；Pi Web 为 pi coding agent 提供本地浏览器工作台，支持会话分叉和 Git Worktree；jcode 采用 Rust 实现，强调多会话、性能和记忆图谱，首帧延迟约 14ms。
