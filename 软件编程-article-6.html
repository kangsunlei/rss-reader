Cap'n Web：适用于浏览器和 Web 服务器的一种创新型 RPC 系统

9/22/2025, 2:00:01 PM

📌 一句话摘要

Cap'n Web 是一款新的开源 TypeScript RPC 系统，适用于 Web 浏览器和服务器，具有对象能力模型、无模式、JSON 序列化以及通过高效 Promise 流水线等实现的特性。

📝 详细摘要

本文介绍了 Cap'n Web，这是一个**开源**、**轻量级**（经过 minify+gzip 压缩后小于 10 kB）的 RPC 协议，它是在纯 TypeScript 中实现的，专为现代 Web 技术栈而设计。作为 Cap'n Proto 的精神继承者，它强调对象能力模型，支持双向调用、通过引用传递函数和对象，以及基于能力的安全性模式，简化了复杂的分布式编程，并通过对象能力模型增强了安全性。与 Cap'n Proto 不同，它是无模式的，使用人类可读的 JSON 序列化，并与 TypeScript 无缝集成，以实现端到端的类型检查。主要功能包括 Promise 流水线，它通过将依赖的 RPC 调用链接到单个网络往返中来解决网络延迟问题，以及用于一次性调用序列的 HTTP 批量模式。本文将 Cap'n Web 定位为传统 REST 和 GraphQL 的强大替代品，特别是对于交互式 Web 应用和微服务，它通过使用标准 JavaScript API 自然地对复杂交互进行建模。它强调了一种创新的「记录-回放」机制，用于服务器端 `array.map` 操作，进一步减少了列表处理的网络开销，并且与所有主流浏览器、Cloudflare Workers 和 Node.js 兼容。

💡 主要观点

  1. Cap'n Web 的对象能力 RPC 模型支持强大、安全且原生 JavaScript 的分布式 API 设计。 此模型允许双向调用、通过引用传递函数和对象，以及基于能力的安全机制。它通过让开发人员设计与常规 JavaScript API 非常相似的 RPC 接口来简化复杂的分布式交互，从而增强了表达性和安全性。
  2. Promise 流水线通过将依赖的调用链接到单个往返中来显著优化网络延迟。 允许开发人员在 Promise 上链接依赖的 RPC 调用而无需等待，从而在单个网络往返中发送一系列操作，从而减少复杂、多步骤操作的显著延迟。
  3. Cap'n Web 提供了一种 JavaScript 原生的 GraphQL 替代方案，用于解决数据获取瀑布和复杂的变更。 它解决了类似于 GraphQL 的“瀑布”问题，但在原生 JavaScript 中，为 mutation 提供了卓越的可组合性，并引入了一种新颖的服务器端 `array.map`，用于高效的列表处理，而无需新的语言。

💬 文章金句

  • Cap'n Web 比几乎所有其他 RPC 系统都更具表现力，因为它实现了**对象能力 RPC 模型**。
  • 简而言之，Cap'n Web 允许您像设计常规 JavaScript API 一样设计 RPC 接口，同时仍然承认并补偿网络延迟。
  • 客户端不可能「伪造」会话对象。获得它的唯一方法是调用 authenticate()，并使其成功返回。
  • Cap'n Web 解决了瀑布问题，*而无需*引入新的语言或生态系统。它只是 JavaScript。
  • 用于表示 map 函数「指令」的「DSL」*只是 RPC 协议本身*。
