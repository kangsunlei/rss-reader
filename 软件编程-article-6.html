电缆中断、风暴与 DNS：2025 年第四季度互联网中断回顾

1/26/2026, 2:00:00 PM

📌 一句话摘要

Cloudflare Radar 的 2025 年第四季度报告分析了由政府关停、海底电缆中断、极端天气以及超大规模云平台技术故障导致的全球互联网中断事件。

📝 详细摘要

这份来自 Cloudflare Radar 的技术报告总结了 2025 年第四季度互联网停机的多种原因。主要中断事件包括坦桑尼亚选举期间由政府主导的大规模关停；影响海地、巴基斯坦和喀麦隆的多起国际光缆中断；以及飓风 Melissa 在牙买加、气旋 Senyar 在斯里兰卡和印度尼西亚造成的重大基础设施损坏。报告还详细记录了技术故障，包括意大利和以色列的 DNS 解析问题，以及 AWS (us-east-1) 和 Microsoft Azure (Front Door) 等主要云服务商的运营事故。此外，报告还对 Cloudflare 自身发生的涉及数据库权限和请求体解析逻辑的两起事件进行了透明的事后分析，强调了“Fail Small”的韧性策略。

💡 主要观点

  1. 物理基础设施仍是全球连接的关键脆弱点。 2025 年第四季度的多起事件（如 PEACE 和 WACS 电缆中断）表明，单条国际光纤链路的损坏可能导致整个地区的网络近乎完全瘫痪。
  2. DNS 故障的影响与全网连接中断类似。 Fastweb 和 Cellcom 的事件表明，即使物理链路处于活动状态，DNS 解析问题也会阻止用户访问网页，实际上导致流量下降 70-80%。
  3. 超大规模云停机对更广泛的互联网生态系统具有级联效应。 AWS us-east-1 和 Azure Front Door 的问题不仅影响了直接客户，还影响了依赖这些源站的 Cloudflare 等第三方服务，导致全球范围内的错误率上升和延迟增加。
  4. 极端天气事件导致数字基础设施的恢复周期延长。 虽然在飓风 Melissa 等风暴过后电力可以迅速恢复，但物理电信基础设施的损坏通常需要数周或数月才能完全修复并恢复到基准流量。

💬 文章金句

  • 虽然电力可能在几天内基本恢复，但物理基础设施的损坏需要更长的时间来处理。
  • 虽然这不是由连接失败引起的互联网停机，但 DNS 解析问题对互联网流量的影响非常相似。
  • 这些异常是通过观察到我们网络中预期的流量模式发生重大偏离而检测到的。
  • 第四季度观察到的中断事件强调了实时数据在维持全球连接方面的重要性。
