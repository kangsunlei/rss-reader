📌 一句话摘要

本文介绍了 Open Design，一个 GitHub 上开源的 Claude Design 替代品，它通过连接本地 Coding Agent 实现一句话生成可交付的 HTML 页面、PPT 等设计成品。

📝 详细摘要

文章介绍了开源项目 Open Design，它作为 Anthropic 的 Claude Design 的开源替代品，在 GitHub 上已获得近 2 万 Star。该项目不自带 AI 模型，而是作为一个中间层，将用户电脑上已有的 Coding Agent（如 Claude Code、Cursor 等）转变为设计引擎。用户输入一句话需求后，系统会通过一个表单确认设计参数，然后 Agent 在本地创建项目目录、读取模板、编写 CSS 和 HTML，最终在沙盒 iframe 中渲染出完整的单文件 HTML。文章详细阐述了其架构（Next.js 前端 + Node daemon 后端）、核心流程（提示词工程、文件系统操作）、以及特色功能，包括 71 套品牌设计系统、19 个可组合 Skill、反 AI 味的提示词工程（如五维自评审和 slop 黑名单）。最后提供了简单的部署命令和运行方式。

💡 主要观点

  1. Open Design 是 Claude Design 的开源替代品，通过连接本地 Coding Agent 实现 AI 驱动设计。 项目不自带 AI 模型，而是作为中间层，将用户已有的 Coding Agent（如 Claude Code、Cursor）接入设计工作流，实现一句话生成可交付的设计成品。
  2. 项目通过提示词工程和本地文件系统操作，确保生成高质量、无 AI 味的设计。 通过初始化表单、五维自评审和 slop 黑名单等机制，防止生成低质量或模式化的设计，并直接在本地文件系统上操作，生成真实的 HTML、CSS 文件。
  3. 内置 71 套品牌设计系统和 19 个 Skill，提供开箱即用的设计能力。 用户可直接选用 Apple、Stripe 等品牌的设计系统，或选择网页原型、Dashboard 等不同 Skill，快速切换设计风格和输出类型。

💬 文章金句

  • 输入一句话，直接出设计成品，不是草图，不是线框图，是能交付的 HTML 页面、PPT、移动端原型。
  • 可以看成是把你手上最强的 Coding Agent 接进设计工作流的中间层。
  • 输出不是截图，不是草图，是完整的单文件 HTML，可以直接导出为 HTML、PDF、PPTX、ZIP。
