FedCM：一种新的身份认证标准，或将改变我们在网络上的登录方式

9/13/2025, 2:16:00 AM

📌 一句话摘要

文章详细介绍了 FedCM 这一新的浏览器 API，旨在通过提供安全、保护隐私的联合登录标准，改变未来网络身份认证方式。

📝 详细摘要

本文深入探讨了联邦凭证管理（FedCM）API，这是一个由 W3C 推动的新 Web 标准，旨在为联合登录提供一个原生、保护隐私且无障碍的解决方案。文章首先阐述了 FedCM 的提出背景，主要是为了应对第三方 Cookie 的淘汰以及现有联合登录机制（如 OAuth/OIDC 和 SAML）在隐私和用户体验上的不足。随后，详细介绍了 FedCM 的工作原理、与传统重定向流程的对比，并通过图示清晰展现了首次和二次登录的用户体验。文章还全面分析了 FedCM 在主流浏览器（Chrome、Edge、Safari、Firefox 等）和身份提供商（Google、Shopify 等）中的支持现状。更重要的是，它提供了依赖方（RP）和身份提供商（IDP）的详细实现指南，包括代码示例和所需的 HTTP API 端点。最后，文章评估了 FedCM 对开发者、IDP 和最终用户的影响，强调了其在隐私、安全和用户体验方面的优势，同时也指出了当前面临的浏览器覆盖率、替代方案和品牌控制等挑战。

💡 主要观点

  1. FedCM 作为浏览器原生 API，旨在解决第三方 Cookie 淘汰后的联合登录隐私与体验问题。 通过引入浏览器原生支持，FedCM 为用户提供了更一致、安全且保护隐私的登录体验，减少了对易被追踪的第三方 Cookie 的依赖，并改善了传统重定向流程的弊端。
  2. 文章详细阐述了 FedCM 在依赖方(RP)和身份提供商(IDP)的实现细节和流程。 提供了 RP 调用 API 进行登录和断开连接的代码示例，以及 IDP 需要实现的`.well-known`文件和一系列 HTTP API 端点（如`accounts_endpoint`、`id_assertion_endpoint`等），具有很强的实践指导意义。
  3. FedCM 对开发者、IDP 和最终用户都有深远影响，但仍面临兼容性与控制权挑战。 它简化了开发者集成联合登录的复杂度，提升了 IDP 的服务能力，并改善了用户登录体验，但目前浏览器支持不完全，开发者需维护回退方案，且品牌化和 UX 控制有所限制。

💬 文章金句

  • FedCM 是一种新的浏览器 API，用于实现安全、无障碍、保护隐私的联合登录。
  • FedCM 最初的动机是为联合登录提供更好的基础，并得到浏览器的支持。与一般用途的 Web 原语（如重定向、iframe 和第三方 cookie）不同，部分原因是这些原语也被广告商用来在网络上追踪用户，开发者可以使用原生 API。
  • 保护用户隐私和通过浏览器提供更好的用户体验的目标导致了 FedCM 项目。
  • 使用 FedCM 是一个简单的实现任务：调用原生浏览器 API。当使用时，FedCM 允许用户在不离开网络应用的情况下在 IDP 上进行认证，使用一种原生的、安全的、注重隐私的方法。
  • FedCM 至关重要。这个提议的标准已经在大多数桌面流量上得到了支持，并且正在积极开发中，工作组中有三十个组织参与。
