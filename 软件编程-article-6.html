PhoneBox：旧安卓手机变身电脑副屏与快捷键控制面板

11/18/2026, 1:30:05 PM

📌 一句话摘要

PhoneBox 让旧安卓手机成为无需 Root 的桌面副屏和触控面板，支持 121 个组件和 30 套模板，实时显示 Claude/Codex 额度，提升开发效率。

📝 详细摘要

PhoneBox 是一款将旧安卓手机（Android 7+）转化为电脑桌面副屏和触控面板的项目，无需 Root 或账号。用户可在浏览器中拖拽编辑，拥有 121 个小组件和 30 套模板，可展示 CPU、显卡、内存、网速、音乐、天气等信息。支持 USB 或 Wi-Fi 连接，跨平台（Windows、macOS、Linux）。还能作为快捷键面板，一键启动应用、发组合键、调音量。特别适合显示 Claude Code 和 Codex 的额度及重置时间。

💡 主要观点

  1. 旧设备资源再利用 将闲置的旧安卓手机转化为功能性副屏，降低硬件投入成本。
  2. 无需 Root 的高便利性 支持 Android 7 以上版本，且无需 Root 或登录账号，降低使用门槛。
  3. 可视化组件丰富 提供 121 个组件和 30 套模板，支持自定义布局，实时展示系统监控和 AI 服务额度信息。
  4. 多平台跨设备控制 通过 USB 或 Wi-Fi 连接支持 Windows、macOS 和 Linux，支持作为快捷键面板提升操作效率。

💬 文章金句

  • PhoneBox 能把旧安卓手机变成电脑的桌面副屏和触控面板，Android 7 以上就行，不用 Root，也无需账号。
  • Claude、Codex 的额度和重置时间直接显示在手机上，Claude Code 弹出权限确认时，在手机上点允许或拒绝就行。
