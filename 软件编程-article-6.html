美团 LongCat Interaction 团队发布大模型交互系统技术报告 WOWService

11/21/2025, 12:00:00 AM

📌 一句话摘要

美团 LongCat 团队发布 WOWService 大模型交互系统，通过数据知识双驱动、自我优化训练、四阶段训练和多 Agent 协同，实现本地生活服务智能化升级，显著提升效率和用户体验。

📝 详细摘要

美团 LongCat 团队针对大模型在本地生活服务领域面临的通用能力适配难、服务可靠性与个性化兼顾难、数据成本高、缺乏业务适配框架等“三重困境”，发布了「WOWService 大模型交互系统技术报告」。该系统融合了数据与知识双驱动、自我优化训练（SRT）、四阶段多层次训练流水线（CPT、SFT、DPO、RL）以及多 Agent 协同四大核心技术框架。WOWService 在实际业务中已应用于美团智能客服及数十个内部场景，通过人机协同标注和模型自我批判强化，仅用 10%的标注数据即可达到传统方案效果，并在 11 项关键指标上全面超越 Base 模型，显著提升了用户满意度和运营效率，为本地生活服务的智能化升级提供了高效解决方案。

💡 主要观点

  1. WOWService 通过数据与知识双驱动，有效解决大模型在本地生活领域的适配难题。 系统结合结构化业务知识与大规模真实交互数据，通过强化学习等技术，使模型在复杂业务场景下能准确遵循业务规则，提升服务质量与合规性。
  2. 自我优化训练（SRT）机制显著降低了模型训练成本和周期，并实现模型持续进化。 SRT 通过自动筛选线上高质量服务日志作为正样本，并对负样本进行归因分析和重写，形成数据闭环，仅用 10%标注数据即可达传统效果。
  3. 四阶段多层次训练流水线（CPT、SFT、DPO、RL）实现模型能力的持续进化与闭环优化。 该体系通过持续预训练夯实通用与领域能力，监督微调适配业务风格，偏好优化强化用户需求响应，最终借助强化学习提升复杂场景推理能力和业务表现。
  4. 多 Agent 协同机制提升了复杂场景下系统的业务适应性与服务合规性。 主智能体负责全局控制，动态调用专用子智能体处理特定任务，结合“Handoff”模式，构建灵活、可扩展的智能交互服务体系。

💬 文章金句

  • 在本地生活服务领域，大模型技术落地正遭遇 '三重困境'：通用能力与领域需求难以适配，复杂场景下服务可靠性与个性化无法兼顾，高昂的数据成本与漫长的训练周期进一步增加了开发难度。
  • 仅需 10%的小模型标注数据即可达到传统方案相当的效果，有效降低了训练成本和周期。
  • WOWService 系统通过持续优化和创新，不仅显著提升了用户满意度和业务运营效率，还在 11 项关键指标上全面超越了 Base 模型，充分展现了其在实际业务场景中的卓越优势。
  • 为持续提升智能交互系统在复杂、多变业务场景下的适应能力与服务质量，WOWService 在高质量数据与知识基础上，构建了涵盖持续预训练（CPT）、有监督微调（SFT）、直接偏好优化（DPO）和强化学习（RL）的四阶段多层次训练流水线。
  • 多 Agent 架构采用层次化设计，主智能体负责全局对话控制与决策，根据实时上下文动态调用各类专用子智能体，并将其输出整合进最终响应。
