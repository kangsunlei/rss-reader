Shopee OnePiece：业内首个融合上下文工程、隐式推理和多目标训练策略的生成式搜推建模框架

9/27/2025, 2:15:00 AM

📌 一句话摘要

Shopee OnePiece 是业内首个融合上下文工程、隐式推理和多目标训练策略的生成式搜推建模框架，显著提升了电商场景下的推荐效果。

📝 详细摘要

文章深入探讨了生成式推荐（GR）在工业界落地面临的挑战，指出当前方法在替换传统 DLRM 时，在上下文工程、隐式推理和多目标训练策略方面存在不足，难以充分发挥大语言模型（LLM）的通用建模能力。为解决这些问题，Shopee Search 团队联合人大高瓴学院提出了 OnePiece 框架。该框架包含三大核心贡献：一是为序列化推荐设计了专属的上下文工程，通过“锚点物品序列”和“场景描述符”等精心构造的 context，引导模型捕捉细粒度的预测意图；二是提出了 Block-wise Latent Reasoning，使模型能在 ID 序列上进行“深度思考”，并通过并行处理多个 token，显著提升推理过程的“信息带宽”；三是为隐式推理定制了渐进式训练策略，通过多步骤监督信号引导模型进行由浅入深的思考，使其无缝适应多目标排序系统并引导差异化思考。离线和在线实验结果表明，OnePiece 在 Shopee 主搜场景中取得了显著的 GMV/user 和广告收入增长，并在召回和排序任务上实现了个性化与相关性的平衡，证明了其强大的外推能力和工业级应用潜力。

💡 主要观点

  1. 上下文工程框架弥补了生成式推荐模型在意图捕捉上的不足 通过引入锚点物品序列（PA）和场景描述符（SD），模型能根据精心设计的上下文，更准确地捕捉用户细粒度的预测意图，提升推荐相关性。
  2. Block-wise 隐式推理提升了模型在 ID 序列上的思考能力和信息带宽 模型在潜在表示空间直接进行多步推理，而非文本解码，同时通过多 token 并行处理，显著增加了推理过程的信息流通量，解决了 ID 序列推理的难题。
  3. 渐进式多目标训练策略优化了隐式推理过程与多任务系统适应性 为隐式推理量身定制的训练策略，在不同推理步骤叠加渐进式监督信号，有效引导模型进行差异化思考，使其无缝适应复杂的多目标排序系统。

💬 文章金句

  • 如果要让搜推广建模追平 GPT4o 级别的能力，生成式推荐的技术地图还缺少几个重要拼图：上下文工程、推理和有效的训练策略。
  • OnePiece 范式是业内首个融合了上下文工程、隐式推理和多目标训练策略的生成式搜推建模框架，旨在将缺失的拼图补全。
  • 隐式推理在模型做 next token 计算的时候不做 decoding，而是直接把它原模原样拿下来，填到 next token 的位置上，如此往复循环几步，再进行解码操作。
  • OnePiece 在覆盖了文本召回曝光的 60%+ 商品的同时，覆盖了个性化导向召回（如 SwingI2I）的 70%+。
  • OnePiece 1.0 让我们看到了，"提示词优化"可能会成为搜推广技术栈下的一个全新方向。
