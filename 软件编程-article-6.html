Ant Design Pro v6.0.0 发布

5/3/2026, 5:47:00 AM

📌 一句话摘要

Ant Design Pro v6.0.0 正式发布，全面拥抱 React 19、antd 6、Turbopack 构建引擎和 Tailwind CSS 等最新技术栈，并清理了大量历史包袱。

📝 详细摘要

本文是 Ant Design Pro v6.0.0 的官方发布公告。文章详细介绍了 v6 版本的核心更新，包括全面升级至 React 19 和 antd 6，采用基于 Turbopack 的 utoopack 构建引擎使生产构建提速约 42%，以及用 Tailwind CSS、antd-style 和 CSS Modules 全面替代 Less 的样式体系重构。此外，v6 还引入了基于 Ant Design X 的 AI 助手页面、用 Biome 替代 ESLint + Prettier、用 React Query 替代 useRequest 等工具链现代化举措，并提供了 Cheatsheet 速查文档和详细的升级指南。文章指出，这是一次大版本升级，推荐新建项目并逐步迁移业务代码。

💡 主要观点

  1. 全面升级至 React 19 和 antd 6，拥抱最新前端生态。 v6 基于 React 19 和 antd 6 构建，开箱即用并发特性、Server Components 和 CSS 变量主题等新能力，使项目保持技术前沿。
  2. 构建工具从 webpack 切换至 utoopack (Turbopack)，生产构建提速约 42%。 采用基于 Rust 的 Turbopack 构建引擎，显著提升冷启动、HMR 和生产构建速度，实测生产构建耗时从 15.5s 降至 9.0s。
  3. 样式体系从 Less 全面迁移至 Tailwind CSS + antd-style + CSS Modules。 放弃维护活跃度下降的 Less，采用原子化 CSS、CSS-in-JS 和 CSS Modules 的组合方案，提升开发体验和主题切换性能。
  4. 工具链现代化：Biome 替代 ESLint/Prettier，React Query 替代 useRequest。 使用 Biome 统一 lint 和 format，速度提升 10 倍以上；React Query 提供更强大的缓存、去重和乐观更新能力，满足中后台常见需求。

💬 文章金句

  • v6 做了两件事：全面拥抱最新技术栈，以及清理历史包袱。
  • 生产构建提速约 42%，日常开发中冷启动和 HMR 提升更为明显。
  • v6 是一次大版本升级，涉及框架和依赖的全面更新，推荐新建 v6 项目，逐步迁移业务代码。
