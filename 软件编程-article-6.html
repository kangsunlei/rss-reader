ReScript 12.0 发布：引入全新构建系统

12/31/2025, 9:00:00 AM

📌 一句话摘要

ReScript 12.0 正式发布，为这一编译至 JavaScript 的强类型语言带来了现代化的构建系统、改进的语法、运算符一致性以及其他提升开发体验的功能。

📝 详细摘要

ReScript 12.0 已发布，这是该强类型编译语言的一次重大更新。此版本完成了多年来对编译器工具链现代化的努力，重点关注开发体验、语法改进和性能提升。核心特性包括：完全重写的构建系统，具备智能依赖追踪和更快的增量构建能力；增强了 int、float 和 bigint 类型之间的运算符一致性；引入了支持模式匹配的字典字面量，以便更简洁地处理 JSON 数据。其他显著更新包括嵌套记录类型、用于更好集成现代打包工具（如 ESBuild 和 SWC）的 JSX 保留模式，以及正则表达式字面量。该版本还拥有模块化运行时和平台特定二进制文件，大幅缩减了安装体积。尽管文章提到社区讨论有限，但它将 ReScript 定位为 TypeScript 的强力且类型完备的替代方案，强调其极快的编译速度和 OCaml 血统，特别适用于 React 开发。

💡 主要观点

  1. ReScript 12.0 显著实现了编译器工具链和开发体验的现代化。 此版本凝聚了多年的开发成果，引入了全新的构建系统、改进的语法和性能增强，旨在使 ReScript 更加稳健且对开发者友好。
  2. ReScript 12 的新构建系统提供了更快、更智能的增量构建。 它具备精确的依赖追踪功能，避免了不必要的重新编译，专为比前代更高效地处理大型项目和 Monorepo 而设计。
  3. ReScript 12 通过统一运算符和字典字面量增强了语言特性。 算术运算符现在可以在不同的数字类型中一致工作，支持模式匹配的字典字面量简化了 JSON 数据的处理，减少了样板代码。
  4. ReScript 将自己定位为类型完备且高性能的 TypeScript 替代方案。 源自 OCaml 的血统，ReScript 提供了完备的类型系统，且编译速度比 TypeScript 快得多，这对大型 React 代码库尤为有利。

💬 文章金句

  • ReScript 12.0 引入了多项重大功能，包括完全重写的构建系统、改进的运算符、支持模式匹配的字典字面量、嵌套记录类型、JSX 保留模式以及正则表达式字面量。
  • 这解决了随着项目规模扩大和 Monorepo 普及而显现的局限性，因为之前的构建系统主要针对单包项目。
  • TS 仍然保留了 JavaScript 的所有糟粕，且在设计上是不完备的。ReScript 是用 OCaml 编写的，所以你将获得市面上最快的编译器之一。不再需要为生产环境构建等待 5 分钟。
  • ReScript 的类型系统是完备的，保证永远不会出错，而 TypeScript 的类型系统进行的是启发式猜测，有时在运行时可能会出错。
