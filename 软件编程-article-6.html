使用 Cloudflare Realtime 和 RealtimeKit，让你的应用真正实现互动

4/9/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 推出 Cloudflare Realtime 和 RealtimeKit，通过简化的软件开发工具包 (SDK) 和与 Hugging Face 的合作，助力开发者高效构建实时音视频与人工智能应用。

📝 详细摘要

Cloudflare 推出了 Cloudflare Realtime 和 RealtimeKit，旨在降低实时音视频与人工智能应用开发的技术门槛。RealtimeKit 包括用于移动端（iOS、安卓、React Native、Flutter）和 Web 平台的软件开发工具包 (SDK)，以及服务器端服务，如录制、协调和转录。Cloudflare 通过收购 Dyte (一家实时音视频技术公司) 加速了 RealtimeKit 的开发，简化了 WebRTC 的复杂性。Cloudflare 还宣布了选择性转发单元 (SFU) 和 NAT 穿透中继 (TURN) 服务的全面可用性，并与 Hugging Face 合作，为 FastRTC 用户提供免费访问 Cloudflare 的 TURN 服务器产品的权限。RealtimeKit 旨在帮助开发者快速构建视频会议、直播、实时同步和人工智能语音集成等应用。

💡 主要观点

  1. RealtimeKit 简化了实时音频和视频应用的开发过程。 通过提供跨平台软件开发工具包 (SDK) 和服务器端服务，RealtimeKit 降低了 WebRTC 复杂性，助力开发者专注于用户体验创新。
  2. Cloudflare 的选择性转发单元 (SFU) 和 NAT 穿透中继 (TURN) 服务提供可扩展的实时通信基础设施。 选择性转发单元 (SFU) 支持同步广播 (simulcast)，NAT 穿透中继 (TURN) 服务提供高级分析，帮助开发者构建可扩展且可靠的 WebRTC 应用。
  3. 与 Hugging Face 的合作，为人工智能开发者提供了开箱即用的实时通信能力。 FastRTC 用户可以免费使用 Cloudflare 的 TURN 服务器产品，使他们能够专注于构建语音界面、视频管道和多模态应用。

💬 文章金句

  • RealtimeKit：助您轻松构建实时应用，摆脱 WebRTC 困扰。
  • 选择性转发单元 (SFU) 和 NAT 穿透中继 (TURN) 服务现已正式发布。
  • 借助 RealtimeKit，开发者现在可以在数小时内实现复杂的实时体验。
