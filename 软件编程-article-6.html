Windows 再曝 0Day 漏洞，可完整绕过微软 RoguePlanet 补丁

8/13/2026, 10:00:00 AM

📌 一句话摘要

安全研究员 Chaotic Eclipse 披露新的 Windows 0Day 漏洞 ShieldBreak，可完整绕过微软对 RoguePlanet（CVE-2026-50656）的补丁，在 Windows 11 25H2 和 Server 2025 上成功率达 100%。

📝 详细摘要

文章报道安全研究员 Chaotic Eclipse 发布的新 Windows 0Day 漏洞 ShieldBreak 的 PoC，可绕过微软对 RoguePlanet（CVE-2026-50656，CVSS 7.8）的补丁。RoguePlanet 是 Defender 恶意软件保护引擎（mpengine.dll）的竞态条件漏洞，可实现本地权限提升至 SYSTEM 权限。ShieldBreak 在 Windows 11 25H2 和 Server 2025 上测试成功率 100%，Windows 10 同样受影响但当前 PoC 不支持。此外，文章回顾了 Chaotic Eclipse 此前披露的 YellowKey、GreenPlasma 等 0Day 漏洞，以及微软对其公开披露的批评，强调协同漏洞披露的重要性。7 月初微软已发布 RoguePlanet 补丁，但 ShieldBreak 证明补丁可被绕过，再次引发对 Windows 安全修复有效性的关注。

💡 主要观点

  1. ShieldBreak 可完整绕过 RoguePlanet 补丁 Chaotic Eclipse 发布的 PoC 证明微软对 CVE-2026-50656 的补丁存在绕过可能，在 Windows 11 25H2 和 Server 2025 上成功率 100%，Windows 10 同样受影响但 PoC 暂不支持。
  2. RoguePlanet 是 Defender 引擎的竞态条件漏洞 CVE-2026-50656 影响 mpengine.dll，可实现本地权限提升至 SYSTEM，攻击者需先获得系统访问权限后利用该漏洞进一步提权。
  3. 微软批评 Chaotic Eclipse 的公开披露行为 微软表示其未获事先通知，公开披露使客户面临风险，强调协同漏洞披露（CVD）的行业标准，并称已通过赏金计划与研究人员合作。
  4. Chaotic Eclipse 近期连续披露多个 Windows 0Day 除 ShieldBreak 外，还披露了 YellowKey（绕过 BitLocker）、GreenPlasma（权限提升）等漏洞，以及 LegacyHive（目标为用户配置文件服务的权限提升漏洞）。

💬 文章金句

  • 微软未能正确修补 RoguePlanet 漏洞 CVE-2026-50656，该 PoC 展示了对该补丁的完整绕过。
  • 最近几周，多个 0Day 漏洞被公开披露。这些漏洞的详细信息在发布前并未与微软共享，这些披露使我们的客户面临不必要的风险。
  • 这种合作关系使我们能够在概念验证代码落入恶意行为者手中之前，为先受影响的服务进行更新。
