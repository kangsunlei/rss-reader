GitHub Copilot CLI 正式支持智能体客户端协议 (ACP)

1/28/2026, 3:06:52 PM

📌 一句话摘要

GitHub 宣布 Copilot CLI 已支持智能体客户端协议 (ACP)，实现了 AI 智能体与客户端之间的结构化通信，可广泛应用于 IDE 集成及多智能体系统等场景。

📝 详细摘要

GitHub 官方发布了 Copilot CLI 的重大更新：新增对智能体客户端协议 (ACP) 的支持。该推文详细列举了这一协议带来的核心能力，包括初始化连接、发现智能体功能、创建隔离会话、发送多模态提示词（文本、图像及上下文资源）以及接收流式更新。这一基础性升级将助力开发者重新构思 IDE 集成、CI/CD 流水线、自定义前端和多智能体系统的构建方式。更多技术细节已在 GitHub 官方博客中公开。
