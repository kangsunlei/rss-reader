ReSharper 现已推出 Microsoft Visual Studio Code 版本：公开预览现已开放 | .NET 工具博客

5/19/2025, 11:10:42 AM

📌 一句话摘要

JetBrains 发布了 ReSharper 扩展的公开预览版，该扩展适用于 Microsoft Visual Studio Code。此扩展将 .NET 生产力功能引入 VS Code 环境。

📝 详细摘要

本文宣布 ReSharper for Visual Studio Code 的公开预览版，它将之前仅在完整 Visual Studio 中提供的著名 .NET 生产力功能进行了扩展。该扩展提供了核心 ReSharper 功能，例如实时代码分析、智能代码补全、用于轻松导航的 R# 解决方案资源管理器、安全的重命名重构以及一致的代码格式化。此预览版可免费使用，并计划在预览期结束后包含在 dotUltimate 订阅和免费的非商业层级中。开始使用包括安装扩展和禁用不兼容的 Microsoft C# 扩展和 C# 开发工具包扩展。通过在线帮助、社区论坛和产品内置功能提供支持和反馈渠道。本文还简要提到了 JetBrains AI 助手 for VS Code 的同步预览发布。

💡 主要观点

  1. ReSharper 现在可以作为 Visual Studio Code 的公开预览版扩展使用。 这扩展了数百万开发者信任的成熟 .NET 生产力功能。该功能现已应用于流行的轻量级 VS Code 编辑器，从而大大提高了其可访问性。
  2. 该扩展提供了核心 ReSharper 功能，可在 VS Code 中增强生产力。 主要功能包括：实时代码分析（可检测错误和代码异味）、智能代码补全、通过 R# 解决方案资源管理器实现便捷的项目导航，以及安全重构工具（如重命名）。
  3. 公开预览版是免费的，未来的可用性与 dotUltimate 订阅和免费的非商业层级相关联。 用户可以在预览阶段免费全面评估此扩展，并了解未来使用所需的许可模式。
  4. 兼容性问题需要禁用 Microsoft 的 C# 扩展和 C# 开发工具包扩展。 为了确保 ReSharper 顺利运行，用户必须禁用 Microsoft 的相关扩展，这是成功安装和使用的关键步骤。

💬 文章金句

  • ReSharper 现在可以作为 Visual Studio Code 的扩展使用。
  • 现在，您可以在 VS Code 的简化界面中，体验数百万开发者信赖的强大代码分析、*Rename* 重构和直观的 *Solution Explorer* 等功能。
  • ReSharper for Visual Studio Code 目前作为公开预览版提供。
  • 预览结束后，ReSharper for VS Code 将作为 dotUltimate 订阅的一部分提供。
  • ReSharper for Visual Studio Code 不兼容 Microsoft C# 扩展和 C# 开发工具包扩展。
