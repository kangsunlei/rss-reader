立即体验 | Android 16 QPR2 Beta 2 开放测试

10/15/2025, 9:51:00 AM

📌 一句话摘要

Android 16 QPR2 Beta 2 达成平台稳定性，带来开发者验证、短信 OTP 保护、自定义图标、高效垃圾回收和次要 SDK 版本等关键更新。

📝 详细摘要

文章宣布 Android 16 QPR2 Beta 2 版本已达成平台稳定性，API 接口和应用行为已最终确定，鼓励开发者利用最新平台创新。此次更新包含多项重要特性：引入**开发者验证**机制，要求应用在特定地区由经过验证的开发者注册才能安装，以增强用户安全，并提供相关 API 和 ADB 命令供开发者测试；**短信 OTP 保护**将延迟大多数应用接收包含 SMS Retriever 哈希的短信，以防 OTP 劫持，同时豁免特定系统应用；**自定义应用图标形状**功能允许用户选择应用图标样式；Android 运行时 (ART) 集成**分代并发标记-压缩垃圾回收器**，旨在降低 CPU 使用、减少卡顿并提升电池效率；**Health Connect** 新增原生步数追踪和扩展运动数据记录功能；此外，Android 首次推出**次要 SDK 版本**，允许更频繁地发布新平台 API，加速创新，同时最大限度减少应用兼容性问题。文章最后提供了获取 Beta 2 版本和提交反馈的指南。

💡 主要观点

  1. 引入开发者验证机制，显著提升 Android 应用生态系统的安全性 新的验证要求旨在防止恶意软件和欺诈行为，确保只有经过验证的开发者才能分发应用，同时提供测试工具方便开发者适配。
  2. 推出次要 SDK 版本，加速 Android 平台 API 的迭代与创新 此举突破了年度大版本更新的限制，使 Google 能更频繁地发布新 API，同时降低了对应用兼容性的影响，提高开发灵活性。
  3. 优化 ART 垃圾回收机制，改善应用性能和用户体验 集成分代并发标记-压缩垃圾回收器，通过更高效的内存管理，降低 CPU 消耗，减少应用卡顿，并提升设备的电池续航能力。

💬 文章金句

  • Android 16 QPR2 最新发布的 Beta 2 版本现已达成平台稳定性！这意味着 API 接口已锁定，面向应用的行为也已最终确定，因此您可以将其整合到自己的应用中，并利用我们最新的平台创新功能。
  • 从 2026 年 9 月开始，在特定地区，Android 将要求应用由经过验证的开发者注册，才可以安装在经过认证的 Android 设备上，通过 Android 调试桥 (ADB) 安装的应用除外。
  • Android 运行时 (ART) 会在 Android 16 QPR2 中集成一个分代并发标记-压缩 (CMC) 垃圾回收器，它会将回收工作的重心放在新分配的对象上，因为这些对象更有可能是垃圾。
  • QPR2 是首个采用次要 SDK 版本的 Android 版本，使我们能够突破年度单次更新的限制，通过新平台 API 实现更快速的创新。
