Tailscale SSH 存在未修补漏洞，被入侵设备可获取其他服务器 root 权限

10/26/2026, 10:05:00 AM

📌 一句话摘要

Tailscale SSH 存在高危未修补漏洞，允许攻击者通过被攻陷的设备获取网络内其他服务器的 root 权限，利用路径包括端口转发、套接字替换和竞态条件绕过，具备蠕虫级传播能力。

📝 详细摘要

本周安全研究员 Erica Windisch 揭示了 Tailscale SSH 的严重安全漏洞，只要网络中有一台设备被攻陷，攻击者即可借此获取其他可访问服务器的 root 权限。漏洞利用依赖于开启端口转发的 Tailscale SSH 配置，攻击路径包括直接访问 root 套接字、替换套接字以及绕过文件访问检查。该漏洞具备蠕虫级传播能力，可在短时间内扩散至全网设备。Tailscale 尚未发布修复，建议用户关闭端口转发、收紧访问规则并启用密钥过期功能。

💡 主要观点

  1. 漏洞利用前提与传播机制 攻击需要 Tailscale SSH 开启端口转发且攻击者已控制一台设备。利用路径包括访问 root 套接字、替换套接字和绕过文件检查，具备蠕虫级传播能力，可在短时间内扩散至全网设备。
  2. 官方回应与防护建议 Tailscale 已收到报告并正在排查，但尚未发布修复。建议用户关闭端口转发、收紧访问规则为单源目配对、开启密钥过期功能，并删除指向 Unix 套接字的 serve 转发规则。
  3. 报告中的其他风险 报告还披露了 11 个其他安全问题，包括应用连接器漏洞（可访问云元数据服务）和 headscale 相关问题。这些漏洞尚未被其他研究人员复现，Tailscale 尚未确认具体技术结论。

💬 文章金句

  • Tailscale SSH 存在未修补高危漏洞。
  • 这类攻击需要满足两个前提：一是 Tailscale SSH 开启了端口转发配置，二是攻击者已经控制了网络内一台设备，且该设备根据网络访问规则有权限连接目标服务器。
  • 正因如此，这类攻击不需要窃取密码或密钥。攻击者只需要先在一台设备上建立立足点，可通过利用漏洞 Web 应用、投毒软件包、钓鱼攻击或窃取登录凭证等常规途径实现，Tailscale 本身不会为攻击者提供初始立足点。
  • Windisch 将漏洞的整体影响定义为"可蠕虫化传播"。在实验室环境中，一台被攻陷的设备可以向访问规则允许的所有设备扩散，不需要密码、不需要窃取密钥、也不需要用户交互，每一步扩散耗时不到 1 秒。
  • 报告原文描述为："这种网状网络结构能将一个普通的初始立足点，以机器速度转化为对全网络设备的特权访问。"
