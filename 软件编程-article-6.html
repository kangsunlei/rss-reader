带爪子的机器人

2/5/2026, 3:30:07 PM

📌 一句话摘要

DHH 使用 OpenClaw 探索了 AI 智能体的未来，证明了现代 LLM 无需专门的 API 或协议，即可导航电子邮件和 SaaS 平台等以人为中心的数字界面。

📝 详细摘要

本文记录了对 OpenClaw 的一次实操实验，这是一个提供持久执行和长期记忆的 AI 智能体框架。作者 David Heinemeier Hansson (DHH) 测试了一个假设：先进的 AI 智能体不再需要 API 或模型上下文协议 (MCP) 等专门的“机器适配”即可有效运作。通过让名为 Kef 的智能体仅使用标准 Web 界面独立注册电子邮箱账号和协作平台 Fizzy，他证明了高端模型 Claude 4.5 和 Kimi K2.5 可以成功导航为人类设计的数字世界。他得出结论，虽然专门的协议目前对提高效率很有用，但长期趋势倾向于通过人类功能入口与环境交互的智能体，这使得专门的机器对机器协议可能变得过时。

💡 主要观点

  1. 持久执行将 AI 从响应式的提示词工具转变为主动的个人助手。 通过赋予 AI 自己的机器和持久运行环境，它可以独立监控通知并执行长期任务，而无需等待用户输入。
  2. 现代 LLM 越来越能够导航以人为中心的数字界面，而无需专门的 API。 实验表明，模型可以通过直接与 UI 交互来处理复杂的工作流，例如注册电子邮件和 SaaS 工具，就像人类一样。
  3. 像 MCP 这样专门的智能体协议可能只是 AI 演进过程中的临时拐杖。 虽然 API 和协议目前降低了延迟和 Token 成本，但“计算机使用”能力的快速提升表明，智能体最终将完全依赖人类功能入口。
  4. 安全隔离是进行自主智能体实验的前提。 作者强调在隔离的虚拟机（如 Proxmox）中运行智能体，以防止赋予 AI 持久访问个人数据和登录权限所带来的风险。

💬 文章金句

  • 模型不再局限于提示-响应循环，而是能够持续检查自己的电子邮件、Basecamp 通知以及你授予访问权限的任何其他内容。
  • 我没有安装任何技能、任何 MCP，也没有给它任何 API 的访问权限。零机器适配。
  • 如果我要滑向冰球将要到达的位置，那将是一个智能体像自动驾驶汽车一样，不需要特殊设备……就能与环境交互的世界。
  • 人类功能入口将绰绰有余。
  • LLM 是助手，而不是自主可靠的程序员。我是资深开发人员；LLM 的存在是为了加速我的工作，而不是取代我的判断。
