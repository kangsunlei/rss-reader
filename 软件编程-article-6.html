5/18/2025, 1:04:00 AM

📌 一句话摘要

文章介绍了一个基于 Vue 3 和 CSS Houdini 构建的像素风组件库，解决了现有方案的渲染问题。

📝 详细摘要

文章作者出于对像素 UI 的喜爱，注意到现有 CSS 框架 NES.css 在不同浏览器和缩放下存在的渲染间隙问题。为此，作者决定使用 Vue 3、TypeScript、UnoCSS 并结合 CSS Houdini 的 Paint Worklet 技术，从头构建一套像素风组件库——pixel-ui。文章详细介绍了技术选型及理由，特别是利用 Paint Worklet 实现像素边框的原理，克服了 `box-shadow` 的限制。此外，还介绍了内置的像素字体、GIF 动画组件以及自动生成 API 文档的插件等特色功能。文章提供了快速上手指南、效果预览图以及项目规划，并呼吁社区参与，共同完善这个开源项目。

💡 主要观点

  1. 现有像素风 CSS 框架在缩放和跨浏览器渲染上存在缺陷。 基于 `box-shadow` 实现的像素效果在不同环境下可能因浮点偏移导致渲染间隙，影响视觉一致性。
  2. 使用 CSS Houdini 的 Paint Worklet 可实现精确的像素边框渲染。 通过自定义 Paint Worklet，可以在 Canvas 上以物理像素网格为基础绘制边框，避免了传统 CSS 属性的渲染问题。
  3. 该组件库采用现代前端技术栈构建并具备多项实用功能。 结合 Vue 3、TypeScript、UnoCSS，并提供内置组件、像素字体、GIF 动画支持及文档自动化工具，提高了开发效率和体验。
