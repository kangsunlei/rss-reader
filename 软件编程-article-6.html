BellSoft 推出 Java 加固镜像

12/8/2025, 9:00:00 AM

📌 一句话摘要

BellSoft 发布了新的“加固镜像”产品，旨在通过 Java 运行时优化、操作系统强化和主动 CVE 修复，显著提升容器安全，降低 Java 企业软件供应链中的漏洞。

📝 详细摘要

BellSoft 在 KubeCon 2025 上推出了“加固镜像”方案，旨在解决企业软件供应链中日益增长的容器安全漏洞问题。该方案结合了 Java 运行时优化、操作系统强化和主动 CVE 修复，声称可将已知漏洞减少 95%，并降低 30% 的资源消耗。文章指出，目前 Java 服务中近半数存在已知已被利用的漏洞。新的加固镜像通过移除非必要组件和包管理器，实现镜像的最小化和配置锁定，从而提高安全性并提供 SBOM。它基于 BellSoft 自研的轻量级 Alpaquita Linux，并包含了优化的 Liberica JDK Lite，声称可减少 30% 的内存和磁盘空间占用。BellSoft 强调其作为顶级 OpenJDK 贡献者的专业优势，在优化 Java 运行时层面的能力优于竞品。该产品提供免费社区版和付费标准版、高级版，以满足不同需求。

💡 主要观点

  1. BellSoft 的“加固镜像”产品通过全面策略提高了容器安全性。 该方案整合了 Java 运行时优化、操作系统强化和高效的 CVE 修复，能够显著减少已知漏洞，旨在应对不断升级的企业软件供应链安全挑战。
  2. 该方案在安全性和资源效率方面实现了双重提升。 通过精简镜像和优化 JDK，BellSoft 加固镜像不仅能将漏洞减少 95%，还能降低 30% 的 RAM 和磁盘空间使用，提升运行效率。
  3. BellSoft 通过其 OpenJDK 专业技术，提供比竞品更优化的 Java 运行时安全方案。 BellSoft 凭借其作为顶级 OpenJDK 贡献者的背景，不仅专注于操作系统层面强化，更深层次地优化 Java 运行时，以提供针对 Java 工作负载的独特且高效的安全解决方案。

💬 文章金句

  • BellSoft 加固镜像顺应了市场对安全、高性能容器解决方案日益增长的需求，并与我们提供最全面、最可靠的 Java 体验这一承诺相符。
  • 通过结合专业的 Java 运行时优化、主动的 CVE 修复以及轻量、灵活的基础，我们的加固镜像为企业提供了一个安全、可审计的平台，能够减少漏洞、提高性能并简化迁移。
  • BellSoft 将其解决方案定位为 Java 企业的更灵活选择，特别是利用其作为顶级 OpenJDK 贡献者的专业知识，除了在操作系统层面进行强化，还更深入地优化运行时层。
