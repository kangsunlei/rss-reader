HTML 优先，框架次之：JavaScript 终于成长起来了吗？

9/28/2025, 11:17:00 AM

📌 一句话摘要

文章探讨了现代 Web 开发从“JavaScript 优先”转向“HTML 优先”的趋势，认为这是 JavaScript 成熟的标志。

📝 详细摘要

文章深入探讨了现代 Web 开发中“HTML 优先，框架次之”的新兴趋势，认为这是 JavaScript 成熟的标志。长期以来，Web 开发过度依赖 JavaScript 框架构建单页应用（SPA），导致了性能问题、复杂性增加以及可访问性下降。文章指出，像 Astro、HTMX、Enhance 和 MarkoJS 等新工具正引领开发者回归语义化 HTML 作为基础，仅在必要时才使用 JavaScript 进行渐进增强。这种转变不仅提升了网站的加载速度、可访问性、弹性和可扩展性，也降低了新开发者的入门门槛。作者强调，未来前端将是分层而非堆叠的，框架作为增强而非基础，鼓励开发者重新学习并利用原生浏览器功能，以实现更高效、更以用户为中心的 Web 体验。

💡 主要观点

  1. 过度依赖 JavaScript 框架导致 Web 应用性能下降、复杂性增加及可访问性问题 单页应用模式使得 HTML 和 CSS 被 JS 生成和操作，导致页面空白、爬虫无法访问等问题，增加了开发和运维的复杂度。
  2. 以 Astro、HTMX 为代表的“HTML 优先”工具兴起，推动 Web 开发回归基础，关注速度和可访问性 这些工具从语义化 HTML 开始构建，按需引入 JavaScript 进行增强，而非默认使用框架，实现了性能和开发效率的提升。
  3. JavaScript 的角色正在成熟，从“渲染一切”转向“在重要时提供增强”，框架作为辅助而非基础 SSR 和边缘计算的回归，以及 React Server Components 等新模式，都表明 JS 正在与原生浏览器功能协同，构建更弹性、高效的 Web。

💬 文章金句

  • JavaScript 不再只是一种脚本语言，而是成了整个前端的基础------以至于 HTML 和 CSS 常常由 JavaScript 生成、由 JavaScript 操作，甚至被 JavaScript 抽象所取代。
  • 像 Astro、HTMX、Enhance 和 MarkoJS 这样的新工具及其开发哲学正在颠覆传统的前端范式。
  • JavaScript 不会因此消失，相反，它正在逐步进化。它的角色正在从'随时随地渲染一切'转变为'在重要的时候提供增强'。
  • 默认思维模式正在发生转变，即鼓励开发者优先使用原生浏览器功能：HTML 用于内容，CSS 用于样式，JavaScript 用于交互（仅在必要时）。
  • 前端的未来不是回归到纯 HTML，而将是一个以 HTML 为基础的分层方法。你仍然可以使用 React、Svelte 或 Vue，但是作为增强，而不是作为基础。
