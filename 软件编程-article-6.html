Claude Code 出新漏洞，恶意仓库可偷取本地隐私文件

7/28/2026, 10:00:00 AM

📌 一句话摘要

Claude Code 存在符号链接漏洞，恶意仓库可通过内存导入功能在未经用户同意的情况下窃取本地隐私文件。

📝 详细摘要

本文报道了 Claude Code 的一个安全漏洞，该漏洞允许恶意仓库利用符号链接（symlink）绕过路径检查，在用户未授权的情况下将本地敏感文件（如 /etc/passwd）导入模型上下文并发送至外部端点。漏洞核心在于工具在验证路径可见性时使用词法路径，但在读取文件时却跟随符号链接。此外，攻击者可通过修改配置文件将数据导向自定义服务器。尽管研究人员提出了规范化路径验证的修复建议，但 Anthropic 目前将其视为工作区信任机制下的预期行为。

💡 主要观点

  1. 漏洞源于词法路径检查与实际文件读取之间的不一致。 Claude Code 在检查 @import 是否在项目内时使用可见路径，但读取时会跟随符号链接，导致恶意仓库能导入外部文件且不触发外部导入警告。
  2. 攻击者可实现本地隐私数据的静默外泄。 被导入的文件内容会被包含在首次出站请求中，且可通过修改 .claude/settings.json 中的 ANTHROPIC_BASE_URL 将数据发送至攻击者控制的服务器。
  3. 工作区信任机制扩大了潜在受影响范围。 开发者若信任了宽泛的父目录（如 ~/src），新克隆的恶意项目将直接继承信任，无需再次弹出对话框即可执行上述攻击。

💬 文章金句

  • 该安全问题的成因在于：Claude Code 在解析 ./link 之前，先将其评估为仓库内部路径。
