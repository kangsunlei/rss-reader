Cloudflare MCP 与 wrangler 的区别及实操体验

9/21/2026, 1:59:29 PM

📌 一句话摘要

作者对比 Cloudflare MCP 与 wrangler，认为 MCP 覆盖整份 Cloudflare API 而非仅开发部署流程，并分享用 MCP 操作 DNS、查日志的体验。

📝 详细摘要

针对朋友提问「MCP 和直接用 wrangler 有什么区别」，作者给出判断：MCP 服务更全，面对的是整份 Cloudflare API，而不只是 Wrangler 暴露的那一层，几乎覆盖所有操作；wrangler 仍偏向开发部署那几个流程。作者以自身经历佐证，昨天用 MCP 操作了 DNS，还查了出错的 observability logs，认为通过 MCP agent 能用自然语言操作整个 CF 账号。

💡 主要观点

  1. Cloudflare MCP 的覆盖面大于 wrangler MCP 面对的是整份 Cloudflare API，几乎覆盖所有操作；wrangler 则偏向开发部署那几个流程，二者定位不同而非替代关系。
  2. MCP 让自然语言操作整个 Cloudflare 账号成为可能 作者以自己用 MCP 操作 DNS、查询出错的 observability logs 为例，说明通过 MCP agent 可以用自然语言完成账号级操作。

💬 文章金句

  • mcp 服务更全 面对的是整份 Cloudflare API 不只是 Wrangler 暴露的那一层
  • 通过 MCP agent 能用自然语言操作整个 CF 账号，还是很香的。
