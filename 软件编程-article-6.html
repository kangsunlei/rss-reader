微软刚开源了 1 个神器：录一遍操作，自动学习内化成 Skill。

8/8/2026, 6:36:00 AM

📌 一句话摘要

本文介绍微软开源的桌面端工具 Skill Recorder：通过录制一次真实电脑操作，由 GitHub Copilot 分析提取意图与步骤，自动生成可复用的 Agent Skill 或定时 Automation。

📝 详细摘要

文章从传统编写 Skill 的痛点切入——需要反复试跑、补充规则与示例——类比「手把手演示教新同事最有效」，引出微软新开源的桌面工具 Skill Recorder。该工具可录制屏幕操作与可选语音讲解，经 GitHub Copilot 分析后提取任务意图和有序步骤，经人工检查后生成 Skill（SKILL.md）或 Automation（定时或条件触发的流程）。文章梳理了四步链路：Record、Control、Analyze、Create，并说明人工检查环节的重要性——屏幕录像中混有等待、切错窗口等无关动作，需要清理。安装方面目前支持 macOS 与 Windows 11，需要屏幕录制权限与 GitHub Copilot 登录。作者也提示项目很新，复杂任务泛化能力仍需真实场景检验。

💡 主要观点

  1. 传统 Skill 编写依赖反复试跑迭代，效率较低。 文章指出先列步骤再让 Agent 试跑、根据问题补充规则的流程需要多次修改，与直接演示教学相比更耗成本。
  2. Skill Recorder 将演示操作转化为可复用流程。 它记录屏幕操作与语音讲解，由 Copilot 提取意图和有序步骤，经人工检查后生成 Skill 或 Automation。
  3. 人工检查环节是保证流程质量的关键。 录制内容包含等待、切错窗口等无关动作，Agent 生成的流程需要人工清理和确认后才可靠。
  4. 工具仍处于早期阶段，复杂任务泛化待验证。 作者指出项目版本较新，在真实场景下能否稳定处理复杂任务仍是未知数。

💬 文章金句

  • 先把工作做一遍，再把写流程这件事交给 Agent。
  • 屏幕录像里会混入等待、切错窗口、临时返回等无关动作，最终留下的流程需要比原始操作更干净。
  • 写 Skill，本质上是在把你一套熟练的工作流程翻译给 AI。
