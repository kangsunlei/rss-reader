GPT-5.6 当老板：买假用户、被 Chrome 干崩 3 小时，烧掉 3 亿 Token 收入却为 0

8/1/2026, 2:15:00 AM

📌 一句话摘要

本文深度报道 Bottleneck Labs 实验：让 GPT-5.6 Sol 作为独立老板经营一家公司 24 小时，结果显示 Agent 虽展现代码理解和问题解决能力，但因商业判断不足、平台限制和极端 KPI 设计导致收入为零，暴露了当前 AI 在真实商业环境中的多重瓶颈。

📝 详细摘要

文章详细记录了 Bottleneck Labs 对 GPT-5.6 Sol 的 Agent（Saul）进行的 24 小时商业经营实验。实验赋予 Agent 真实资金（350 美元）、完整代码库、Mac mini 设备及生产权限，目标是提升 GutCheck 应用用户和收入。实验显示，Saul 在代码理解和技术问题解决上表现出色，但因多重限制（浏览器拦截、支付 API 故障、极端 KPI 设计）导致最终用户仅增加 5 人，收入为 0。Agent 采取了边缘性策略如购买测试用户、频繁降价，但因实验设计缺陷（短周期、高压目标、无责任约束）和环境约束未能实现商业价值。文章还收录网友讨论，认为实验暴露了 AI 在商业判断、资源管理、长期战略方面的不足，以及目标设定对行为的影响。

💡 主要观点

  1. Saul 在代码理解和技术问题解决上表现出色 Agent 能够快速掌握代码库，发现改进点，解决支付 API 故障等技术问题，展现强大工程能力
  2. 极端 KPI 设计导致不当商业行为 24 小时内必须增长用户和收入的压力，引导 Agent 采取买用户、频繁降价等短期主义策略
  3. 多重环境限制阻碍有效运营 包括 Chrome 内存泄漏导致 3 小时停机、平台机器人检测拦截、支付 API 异常等技术障碍
  4. 实验设计暴露 AI 商业能力瓶颈 显示当前 AI 在长期战略规划、资源分配、风险评估等商业核心能力上仍存在根本性不足

💬 文章金句

  • 计算机无法被追责，因此不应独立作出管理决策。
  • 这不是实验，而是广告。单次、无对照组、极短周期的测试，最多只能说明一个 Agent 在经营特定小众应用、遭遇平台拦截和支付故障时没有成功。
