Uno 平台 6.0 及 Uno 平台 Studio 发布：性能与工具大幅提升

5/17/2025, 12:00:00 AM

📌 一句话摘要

Uno 平台 6.0：加速 .NET 跨平台开发，赋能开发者！

📝 详细摘要

Uno 平台 6.0 和 Uno 平台 Studio 已经发布，为跨平台 .NET 开发框架带来了显著的性能改进和开发者工具增强。主要亮点包括一个新的统一的基于 Skia 的渲染引擎，以在各个平台上实现更好的性能和一致性，以及正式发布热设计 (Hot Design)，一个运行时可视化 UI 编辑器。报告的性能指标包括高达 75 % 的更小占用空间，60 % 更快的启动速度，30 % 更少的内存，以及 45 倍更快的执行速度。此版本还引入了新的跨平台组件，如 MediaPlayerElement 和 WebView2，以及例如 IL 裁剪和 XAML 裁剪等优化，以减少应用大小并加快构建时间。该平台仍然是开源的，而 Studio 提供了商业增强支持。

💡 主要观点

  1. 新的 Skia 引擎统一了所有平台上的高性能渲染。 统一的 Skia 渲染引擎在各平台提供一致的硬件加速 UI 渲染，显著提升性能。
  2. 热设计 (Hot Design) 支持运行时实时可视化 UI 编辑。 热设计 (Hot Design) 功能允许开发者暂停正在运行的应用，以可视化方式编辑 UI，并在无需重启的情况下恢复，从而显著简化 UI 开发工作流程。
  3. 优化显著减少了应用大小并改善了构建时间。 Win32 的 IL 裁剪、XAML / 资源裁剪以及新的 Win32 后端有助于大幅减少空白应用大小，并提高 AOT 编译速度。

💬 文章金句

  • Uno 平台 6.0 是迄今为止最佳、最快的 Uno 平台，现在配备了一个新的统一渲染引擎，该引擎极大地改善了应用启动时间，并在 UI 渲染方面实现了超高性能。
  • 热设计 (Hot Design) 允许开发者暂停正在运行的应用程序，以可视化方式编辑 UI，并在无需重启的情况下恢复会话。
  • 该渲染引擎还将应用程序占用空间减少高达 75 %，启动速度提高 60 %，降低内存使用率 30 %，并将执行速度提高高达 45 倍。
  • Windows 后端现在支持 Win32 实现而不是 WPF，从而可以进行完整的 IL 裁剪，并将独立应用的大小减少 100 MB。
  • 通过分离 UI 和非 UI 功能，开发人员现在可以构建仅依赖于运行时功能的库，而无需包含 UI 依赖项，从而简化了跨平台目标定位并减少了包开销。
