DiffusionGemma: 文本生成速度提升 4 倍

6/22/2026, 9:30:00 AM

📌 一句话摘要

谷歌发布实验性文本扩散模型 DiffusionGemma，可在本地 GPU 上实现最高 4 倍的文本生成速度提升，同时开源 260 亿参数混合专家模型权重。

📝 详细摘要

文章宣布谷歌正式推出 DiffusionGemma，一款基于 Apache 2.0 许可的开源实验性文本扩散模型。该模型拥有 260 亿参数（MoE 架构，推理时仅激活 3.8B），通过并行生成 256 个 Token 的方式突破传统自回归模型的顺序生成瓶颈，在单张 H100 上可达 1000+ Token/秒。文章详细解释了其工作原理：从随机占位符画布开始，经多次迭代精炼最终输出文本。与自回归模型的关键区别在于硬件利用方式——扩散模型将计算密集型任务打包，更适配本地单用户场景，而自回归模型在高并发云端优势更明显。文章明确了 DiffusionGemma 的实验性状态，指出其在输出质量上低于标准 Gemma 4，适合行内编辑、代码填充、数独求解等非线性任务，并提供了微调教程与多种部署工具（MLX、vLLM、Hugging Face Transformers 等）。整体上是一篇清晰、克制的模型发布与技术原理介绍。

💡 主要观点

  1. DiffusionGemma 通过并行生成 256 个 Token 实现 4 倍速度提升。 不同于自回归模型逐个 Token 顺序生成，该模型一次生成完整文本块，充分发挥硬件计算能力，在单 GPU 上达到极高吞吐量。
  2. 模型为 26B MoE，推理仅激活 3.8B 参数，可量化至 18GB 显存。 通过激活少量参数与量化技术，模型能够在消费级 GPU（如 RTX 5090）上高效运行，降低本地部署门槛。
  3. 双向注意力与自纠错机制在非线性任务中优势明显。 每个 Token 可关注所有其他 Token，配合迭代精炼过程，使其在代码填充、行内编辑、数学图谱等需全局上下文的任务上表现优于自回归模型。
  4. 作为实验性模型，质量低于标准 Gemma 4，适用场景需权衡。 谷歌明确建议对最高质量要求的生产应用仍使用自回归 Gemma 4，DiffusionGemma 更适合速度优先、可接受一定质量损失的场景。

💬 文章金句

  • DiffusionGemma 扭转了这种低效局面。它不再按顺序逐词进行预测，而是同时生成包含 256 个 Token 的完整段落。
  • 将模型推理过程从单一的、顺序操作的‘打字机’模式，升级为能同时印制整块文本的‘大型印刷机’模式。
