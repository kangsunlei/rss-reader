Amazon Bedrock AgentCore 添加 A2A 协议，支持可互操作的多代理工作流程

11/28/2025, 12:45:00 PM

📌 一句话摘要

Amazon Bedrock AgentCore 现在支持代理间（A2A）协议，实现基于不同框架的 AI 代理之间的互操作通信和工作流程编排。

📝 详细摘要

Amazon Bedrock AgentCore Runtime 现在支持代理间（A2A）协议，这是一项重大增强，可实现基于 OpenAI、LangGraph 和 Claude Agents SDK 等不同框架构建的 AI 代理之间的互操作通信和协调。该协议为代理共享上下文、推理和能力提供了一种标准化的、可验证的格式，直接解决了多代理系统互操作性的关键挑战。 至关重要的是，A2A 的重点在于代理间的通信，这与处理代理和工具交互的模型上下文协议 (MCP) 有所不同。它的设计促进了松散耦合和模块化，允许代理的独立开发和部署。关键的架构特性包括通过标准化的“代理信息卡 (Agent Cards)”实现的动态代理发现和强大的编排能力，从而实现自适应的任务路由。通信使用基于 HTTP/S 的 JSON-RPC 2.0 同步或异步进行。文章还强调了 Unit42 识别出的潜在“会话劫持 (Session Smuggling)”漏洞，强调了安全实施的必要性。这一进步大大简化了复杂 AI 代理系统的协作开发和部署。

💡 主要观点

  1. A2A 协议实现了跨各种 AI 代理框架的无缝互操作性。 通过提供通用的通信标准，A2A 允许使用不同的软件开发工具包 (SDK)（OpenAI、LangGraph 等）构建的代理共享上下文和能力，从而促进复杂的多代理工作流程。
  2. A2A 解决的是代理间的协调问题，而非代理与工具的连接。 与侧重于代理访问资源的 MCP 不同，A2A 专门解决的是多个代理协作和通信的挑战，这对于强大的多代理部署至关重要。
  3. 该协议促进了代理系统的模块化、动态发现和强大的编排。 代理作为独立的单元运行，通过代理信息卡 (Agent Cards) 声明功能，并且可以动态发现和编排，从而增强系统的弹性和适应性。

💬 文章金句

  • 该协议允许使用 Strands Agents、OpenAI Agents SDK、LangGraph、Google ADK 或 Claude Agents SDK 开发的代理“以通用、可验证的格式共享上下文、能力和推理”。
  • 虽然 MCP 将单个代理连接到其工具和数据源，但 A2A 使多个代理能够相互协调。
  • A2A 协议实现了松散耦合和模块化，允许每个代理作为独立单元运行。
  • 代理通过标准化模式声明其功能，从而创建可用功能和专业化的注册表。
  • A2A 协议的有状态行为使代理能够记住最近的交互并保持连贯的对话。会话走私攻击利用此属性将恶意指令注入到对话中...
