挖到 15 个宝藏插件，网友把 DeepSeek Harness 玩出了花。

8/21/2026, 5:17:00 AM

📌 一句话摘要

本文盘点 DeepSeek Harness 生态中的 15 个开源插件，覆盖桌面客户端、界面增强、视觉识别、浏览器控制、多 Agent 协作与记忆管理等场景。

📝 详细摘要

文章以清单形式介绍 DeepSeek Harness（DSH）社区生态中的 15 个开源项目。内容分为多个场景：两个桌面客户端降低小白上手门槛；dsh-web-ui-all 提供任务看板、Git 记录、移动端远程等界面全家桶；DSH Better Sidebar 补充文件浏览、终端和子 Agent 状态面板；dsh-TUI 为终端用户提供类似 Claude Code 的界面；DSH Vision Toolkit 和 ModLens 让纯文本模型具备读图能力；dsh-browser 可接管当前 Chrome 标签页并保留登录态，敏感输入需授权。文章还介绍了多款皮肤插件（深海女仆、QQ2006、同花顺风格、Excel 风格、表情包替换），以及多 Agent 组队插件 dsh-agent-teams 和记忆类工具 OpenViking、Hindsight。每个项目均附开源地址和简要使用说明，适合按需选用。

💡 主要观点

  1. DSH 生态已形成覆盖多场景的插件体系。 从桌面客户端、网页增强、终端界面到视觉理解、浏览器控制和多 Agent 协作，插件已能解决多数日常使用痛点。
  2. 桌面客户端显著降低小白上手门槛。 将 Web 界面、本地服务和插件市场打包成 Windows/macOS 应用，用户无需接触 Node.js 与命令行。
  3. 皮肤类插件主要改变外观与聊天气氛，不影响模型能力。 社区最活跃的方向是换肤与表情包，属于体验层定制，对功能提升有限。
  4. 视觉与记忆类插件拓展了 DSH 的实用边界。 通过图片问答、元素定位和长期记忆，弥补纯文本模型在视觉任务与跨会话上下文上的不足。
