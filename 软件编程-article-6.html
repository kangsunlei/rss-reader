Harness：Claude Code 多 Agent 协作插件，自动生成团队架构

6/2/2026, 7:30:12 AM

📌 一句话摘要

Harness 是一个 Claude Code 插件，能根据项目描述自动生成多 Agent 团队架构，内置 6 种协作模式和 100 套现成模板。

📝 详细摘要

该推文介绍了一个名为 Harness 的开源工具，它是一个 Claude Code 插件，旨在解决单个 Agent 在复杂项目中能力有限的问题。用户只需一句话描述项目，Harness 就能自动生成一整套 Agent 团队架构，包括 Agent 定义文件和技能文件。它内置了流水线、并行处理、专家池等 6 种团队协作模式，并能自动选择最合适的方案。整个流程从领域分析到验证测试分六步自动完成，官方还提供了 100 套现成模板，覆盖深度研究、网站开发等场景，可直接放入项目的 .claude 目录使用。
