CasOS：自带控制面的容器云平台——不用先搭一个 Kubernetes 集群

6/19/2026, 8:03:55 AM

📌 一句话摘要

CasOS 是一个内嵌 Kubernetes 控制面的容器云平台，无需预先搭建完整的 K8s 集群即可运行，旨在降低部署和管理 Kubernetes 工作负载的门槛。

📝 详细摘要

本文介绍了开源项目 CasOS，一个运行在 Kubernetes 之上的「云操作系统」。其核心创新在于将 API Server、Controller Manager、Scheduler 等控制面组件内嵌到服务本身，并支持使用 MySQL 替代 etcd 作为状态存储，从而免去了传统搭建 K8s 集群的复杂流程（如安装 etcd、配置 TLS、部署网络插件等）。用户只需配置一个数据库连接，即可在几分钟内拉起一个完整的 Kubernetes 环境。文章详细列举了 CasOS 的功能，包括工作负载管理（Deployment、StatefulSet、CronJob）、存储与网络配置、运维体验（Pod 日志、浏览器终端、文件浏览器）、权限管理（ClusterRoleBinding、RoleBinding）、安全加固（准入策略、镜像扫描）以及证书自动化（Let's Encrypt）。技术栈为 Go 后端、React 前端，支持 Linux、macOS 和 Windows 三端运行。

💡 主要观点

  1. CasOS 通过内嵌控制面组件，解决了 K8s 部署门槛过高的问题。 传统搭建 K8s 集群需要独立部署 etcd、API Server、Controller Manager 等组件，并处理复杂的证书和网络配置。CasOS 将这些组件内嵌，并用 MySQL 替代 etcd，大幅简化了部署流程。
  2. 它提供了一套完整的 Web UI 来管理 Kubernetes 工作负载生命周期。 从创建 Deployment、StatefulSet 到配置 Service、Ingress，再到查看 Pod 日志、进入容器终端，所有操作都可在 Web 界面完成，无需使用 kubectl 命令行。
  3. 内置了安全加固功能，包括准入策略、授权策略和镜像扫描。 通过 webhook 拦截危险操作，控制用户权限，并集成 Trivy 进行镜像漏洞扫描，在部署前即可发现安全风险。

💬 文章金句

  • CasOS 想解决的就是这个问题：把 API Server、Controller Manager、Scheduler 这些控制面组件内嵌进服务本身，部署的时候不用再单独去拉起一套 Kubernetes 控制面、不用再为了状态存储单独运维一套 etcd。
  • 结果就是：配一个数据库连接，几分钟内就能拉起一个完整可用的 Kubernetes 环境，而不是几个小时。
