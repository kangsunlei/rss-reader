📌 一句话摘要

文章详细盘点了 Chrome 在 2025 年发布的 22 个 CSS 和 UI 新特性，旨在帮助开发者构建更具动态性和交互性的网页。

📝 详细摘要

文章深入介绍了 Chrome DevRel 团队发布的 22 个 CSS 和 UI 新特性，涵盖了可定制组件、下一代交互和优化的人体工程学三大模块。在可定制组件方面，Invoker Commands、Dialog Light Dismiss、popover="hint"、可定制的下拉菜单、::scroll-marker/button()、scroll-target-group、Anchored container queries 和 Interest invokers 等特性大大简化了前端开发。在下一代交互方面，Scroll-state queries、Tree counting functions、scrollIntoView() container、Nested View Transition Groups 和 DOM State-Preserving Move (moveBefore)等功能提升了网页的动态性和流畅性。而优化的人体工程学则通过 Advanced attr() function、ToggleEvent.source、text-box features、shape() function、if() statements、Custom Functions、Expanded range syntax、Stretch sizing keyword 和 corner-shape 等新特性，使 CSS 开发更加直观高效。这些新特性旨在减少 JavaScript 依赖，提升开发效率，创造更丰富的用户体验。

💡 主要观点

  1. 2025 年 Chrome 推出 22 个 CSS 和 UI 新特性，聚焦可定制组件、下一代交互和人体工程学优化。 这些新特性旨在减少对 JavaScript 的依赖，通过原生 CSS 能力实现更复杂的 UI 组件和交互效果，提升开发效率和性能。
  2. 可定制组件模块带来声明式浮层、可定制下拉菜单等，简化复杂 UI 的实现。 Invoker Commands、可定制 select 元素等特性使得开发者无需 JS 即可实现模态框、下拉菜单等交互，降低了开发复杂度并提升了可访问性。
  3. 下一代交互模块增强了滚动动画、视图转换和 DOM 操作功能，提升用户体验流畅性。 Scroll-state queries、Nested View Transition Groups 和 moveBefore 等功能为实现平滑的滚动效果、页面切换动画和无状态丢失的 DOM 操作提供了原生支持，提高了 Web 应用的动态性能。
  4. 优化的人体工程学特性使 CSS 编写更具逻辑性和表达力。 Advanced attr()、if()语句、Custom Functions、shape()等创新功能提升了 CSS 的灵活性和可维护性，让开发者能更直观地“雕刻”网页，并解决垂直对齐等长期存在的布局挑战。

💬 文章金句

  • 本年度的工作坊热火朝天，解决了诸如下拉菜单样式等存在了数十年的难题，并带来了原生锚点定位和轮播图滚动 API 等核心模块。
  • 这些功能帮助你以 CSS 的自然状态工作，使你的工作流程更加直观。
  • 全新的 Invoker Commands 允许按钮对其他元素执行操作，而无需 JavaScript。
  • Element.scrollIntoView 的 container 选项允许你仅滚动最近的祖先滚动容器，避免过度滚动。
  • CSS 中的 if() 函数允许你根据条件测试为属性设置不同的值，类似于 JavaScript 中的三元运算符。
