为智能体推出 Markdown

2/12/2026, 2:03:12 PM

📌 一句话摘要

Cloudflare 推出了 “Markdown for Agents”，这项功能利用 HTTP 内容协商在边缘侧自动将 HTML 转换为 Markdown，从而将 AI Token 使用量降低高达 80%。

📝 详细摘要

文章探讨了从以人为中心的网页浏览向 AI 驱动的发现模式的转变，在这种模式下，智能体和爬虫难以处理非结构化的 HTML。Cloudflare 全新的 “Markdown for Agents” 功能利用标准的 HTTP 内容协商（Accept 请求头）直接向 AI 系统提供 Markdown。通过在边缘侧转换内容，Cloudflare 显著降低了 Token 消耗（以本文为例，Token 数量减少了 80%），同时提供了更清晰的语义结构。该系统包含诸如 “x-markdown-tokens” 之类的元数据头，用于上下文窗口管理，并集成了 “Content Signals Policy” 以定义 AI 训练和搜索的数据使用权限。

💡 主要观点

  1. 与传统的 HTML 相比，Markdown 是 AI 智能体更优的内容格式。 HTML 是为人类视觉呈现而设计的，包含大量的 “噪声”，如 div 包装器和脚本。Markdown 提供了语义化且 Token 效率高的结构，能够降低成本并提高模型的推理准确性。
  2. Cloudflare 通过标准 HTTP 请求头实现实时的 HTML 到 Markdown 转换。 通过使用 “Accept: text/markdown” 请求头，AI 智能体可以直接请求结构化数据。Cloudflare 的边缘网络会即时进行转换，开发者无需再构建自定义的抓取和转换流水线。
  3. Token 效率是采用智能体专用内容格式的主要驱动力。 作者展示了将一篇标准的博客文章从 HTML 转换为 Markdown 后，Token 减少了 80%。这种效率使得智能体能够在有限的上下文窗口内以更低的成本处理更多信息。
  4. Content Signals Policy 为管理 AI 数据使用权提供了框架。 该功能集成了相关请求头，用于标记内容是否可用于 AI 训练、搜索或输入。这使得发布者能够在将智能体视为一等公民的同时，保持对其知识产权使用方式的控制。

💬 文章金句

  • 向 AI 提供原始 HTML 就像是按字付费去阅读包装袋，而不是阅读里面的信件。
  • 你正在阅读的这篇博文在 HTML 格式下占用 16，180 个 Token，转换为 Markdown 后仅占用 3，150 个 Token。这意味着 Token 使用量减少了 80%。
  • Markdown 已迅速成为智能体和整个 AI 系统的通用语言。
  • 现在不仅要考虑人类访客或传统的 SEO 优化经验，更要开始将智能体视为一等公民。
  • 我们的网络将在可能的情况下，自动且高效地即时将 HTML 转换为 Markdown。
