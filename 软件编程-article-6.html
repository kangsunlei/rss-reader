洞察中国开发者生态：JetBrains 2025 年开发者生态系统调查关键趋势 | 研究博客

📌 一句话摘要

这份 JetBrains 报告揭示了中国开发者生态的关键趋势，显示 Java 的主导地位、小程序的高采用率、低代码的强劲参与度以及对本土 LLM 的偏好，这些特点使其与全球开发者模式区分开来。

📝 详细摘要

这篇 JetBrains 研究博客文章基于 2025 年开发者生态系统调查，深入探讨了中国开发者生态。它强调了几个使中国区别于全球平均水平的关键趋势，包括 Java 因互联网和移动应用增长而持续主导、小程序开发的广泛采用，以及在上市公司工作的开发者比例更高。文章还指出中国开发者对低代码/无代码平台的参与度更高，尤其是在网站和应用构建方面。最后，文章探讨了中国独特的 LLM 格局，本土替代方案和特定工具（如 Cursor）比 ChatGPT 和 GitHub Copilot 等全球领导者更受欢迎，反映了对本土或自托管解决方案的偏好。

💡 主要观点

  1. 与全球趋势相比，Java 在中国开发者生态中的主导地位显著更强。 Java 是 58.17% 中国开发者的主要语言，这得益于其在大规模互联网、电子商务、金融科技和社交媒体领域的根深蒂固地位，以及其在 Android 开发中的历史作用。
  2. 小程序开发在中国的普及程度远高于全球开发者社区。 30.27% 的中国开发者参与小程序开发，利用 uni-app 和微信原生等平台，这些平台深度融入中国的日常生活并促进各种服务。
  3. 中国开发者对低代码/无代码平台的参与度更高，超越了典型的业务流程自动化范畴。 中国开发者更倾向于构建应用程序（17% 对比全球 10%），并且特别使用低代码/无代码来构建网站和应用程序（30% 对比全球 17%），这表明了一种更广泛、以生产力为导向的文化。
  4. 中国的 LLM 生态系统显示出对本土或特定替代工具的明显偏好，而非全球市场领导者。 GitHub Copilot 不太受欢迎，像 ChatGPT 和 Claude 这样的全球 LLM 代表性较低；相反，Cursor、DeepSeek 和通义灵码的使用率很高，凸显了独特的采用模式。

💬 文章金句

  • 虽然 Java 在全球范围内仍然是一种流行的开发语言，但它在中国的开发者中使用频率远高于大多数其他地区。
  • Java 在中国市场的主导地位从根本上是由其互联网行业的爆炸性增长以及由此形成的既定技术栈所驱动的。
  • 在中国，39% 的开发者从事 B2B 业务，28% 从事 B2C 业务，而全球范围内这一比例分别为 58% 和 35%。这表明中国市场更侧重于面向消费者，开发者更常为最终用户产品和服务做出贡献。
  • 与全球平均水平相比，中国开发者表现出更积极地参与低代码/无代码平台的趋势。
  • 像 ChatGPT 和 Claude 这样的全球领导者在中国的代表性也远低于其他地区。相反，本土替代方案，如 DeepSeek 和通义灵码，扮演着重要角色，反映出对本土或自托管解决方案的强烈偏好。
