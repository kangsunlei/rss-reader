NVIDIA cuVS 助力 Faiss：GPU 索引性能飞跃

5/8/2025, 4:25:58 PM

📌 一句话摘要

Meta 和 NVIDIA 合作显著加速了 Faiss 的 GPU 向量搜索，cuVS 功不可没。

📝 详细摘要

Meta 与 NVIDIA 合作将 NVIDIA cuVS 集成到 Faiss v1.10 中，旨在加速 GPU 上的向量搜索。相较于经典 GPU 加速方案，NVIDIA cuVS 在 IVF 索引构建速度上提升高达 4.7 倍，搜索延迟降低高达 8.1 倍；对于图索引，CAGRA 的构建速度比 CPU HNSW 快 12.3 倍，搜索延迟降低高达 4.7 倍。基准测试采用 Deep1B 数据集的子集，并使用 OpenAI text-embedding-ada-002 模型在 NVIDIA H100 GPU 上生成嵌入向量，与 Intel Xeon Platinum 8480CL 系统对比，结果表明索引构建和搜索效率均有显著提升。

💡 主要观点

  1. NVIDIA cuVS 显著加速了 Faiss 中 GPU 索引的构建。 通过集成 NVIDIA cuVS，Faiss 在 IVF 和图索引的构建时间上实现了显著加速，速度最高提高了 12.3 倍，从而提高了处理大规模向量数据的效率。
  2. cuVS 降低了 Faiss 中 GPU 索引的搜索延迟。 NVIDIA cuVS 的集成不仅加速了索引构建，还显著降低了搜索延迟，最高降低了 8.1 倍，极大地提升了实时搜索能力。
  3. Faiss 1.10.0 集成了 NVIDIA cuVS 算法，提供了灵活的切换选项。 Faiss 1.10.0 允许用户通过新的 conda 包在经典 Faiss GPU 实现和 NVIDIA cuVS 算法之间切换，方便用户根据实际需求选择最合适的索引方案。

💬 文章金句

  • Meta 和 NVIDIA 合作，通过将 NVIDIA cuVS 集成到 Meta 的开源相似性搜索库 Faiss v1.10 中，加速了 GPU 上的向量搜索。
  • 对于倒排文件 (IVF) 索引，NVIDIA cuVS 的性能优于经典 GPU 加速 IVF 构建时间，高达 4.7 倍；搜索延迟降低了高达 8.1 倍。
  • 对于图索引，CAGRA 的构建速度比 CPU HNSW 快 12.3 倍；搜索延迟降低了高达 4.7 倍。
