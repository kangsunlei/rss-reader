HeroUI React v3.1.0 支持中文文档

5/26/2026, 4:53:55 AM

📌 一句话摘要

HeroUI React v3.1.0 版本发布，新增中文 React 文档和本地化演示，并带来多项无障碍和 UI 改进。

📝 详细摘要

这是一条关于 HeroUI React v3.1.0 版本发布的推文。发布者 Ding 转发了 HeroUI 官方的版本公告，并评论「竟然支持中文了！」，重点突出了该版本新增的中文 React 文档和本地化演示这一亮点。该版本还包含可访问的软前景色令牌、共享滚动条工具、链接悬停/按下状态、更好的 RTL 支持以及 useTheme SSR、Toast、Fieldset 等组件修复。对于中文开发者社区来说，这是一个重要的本地化里程碑。
