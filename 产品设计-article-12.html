CSS Studio 发布：支持 AI Agent 联动的浏览器原生设计工具

4/7/2026, 3:00:18 PM

📌 一句话摘要

CSS Studio 是一款运行在浏览器内的本地设计工具，支持与 AI Agent 协作生成代码，且采用买断制模式。

📝 详细摘要

CSS Studio 正式发布，这是一款集成在浏览器中的设计工具。其核心特性包括：1. 运行在用户站点本地，无需订阅，一次性付费；2. 能够与现有的 AI Agent 联动，直接编写和修改 CSS 代码；3. 强调隐私与本地化。该工具为开发者和设计师提供了一种更直接的「在浏览器中设计并生成代码」的工作流。
