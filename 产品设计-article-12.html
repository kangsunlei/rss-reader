从算力、推理、成本看 AI 接下来的几年

12/4/2025, 11:45:00 PM

📌 一句话摘要

文章从算力、推理和成本角度深度剖析 AI 未来发展，强调缩放定律仍在但受成本约束，推理能力驱动增长飞轮，以及算力电力成为 AI 竞争核心。

📝 详细摘要

本文基于一位海外科技投资人的观点，深入探讨了 AI 未来发展的三个核心趋势。首先，作者指出缩放定律依然有效，AI 技术并未触及天花板，只是在产品化过程中受到成本和产品形态的制约，正从“炫技阶段”转向“算账阶段”。其次，文章强调推理能力（reasoning）的提升为大模型带来了真正的“增长飞轮”，通过模型自我生成高质量数据再训练，形成“用户→数据→产品变好→更多用户”的闭环。最后，文章指出成本、算力和电力已成为决定 AI 胜负的底层变量，尤其强调“有效协同算力”（coherent FLOPs）和电力效率（每瓦产出 Token 数）的重要性，并对应用层产品开发者提出在设计时需关注模型完成任务所需的 Token 数而非单纯 API 调用单价的建议。

💡 主要观点

  1. 缩放定律依然有效，但 AI 发展受成本与产品形态制约 模型性能仍随算力、规模、数据提升，但产品设计开始平衡性能与成本，AI 正从技术炫耀转向商业实用阶段。
  2. 推理能力为大模型构建了真正的“增长飞轮” 模型具备多步思考和自我修正能力，能生成高质量训练数据，形成“使用→数据→优化→更多使用”的闭环，增强护城河。
  3. 成本、算力和电力成为决定 AI 胜负的关键底层变量 在 AI 时代，有效协同算力（coherent FLOPs）和电力效率（每瓦 Token 产出）比单纯 GPU 数量更重要，是构建基础设施护城河的基础。
  4. 应用层产品开发应关注任务所需 Token 而非 API 单价 开发者需深入理解模型在特定任务上的 Token 消耗，以实现更高效、更具成本效益的 AI 产品设计和应用。

💬 文章金句

  • 体验变平缓，不等于技术停滞；AI 现在更像是在从「炫技阶段」进入「算账阶段」。
  • 模型推理 → 产生结构化的高质量数据 → 喂回模型 → 模型推理更好 → 吸引更多用户 → 产生更多数据......
  • 这是他职业生涯里第一次，成本如此关键。
  • 比显卡数量更重要的，是显卡之间能不能好好协同。
  • 在电力受限的世界里，决策公式会变得非常简单粗暴：每 1 瓦电，我能产出多少有效 Token？
