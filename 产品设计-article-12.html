与 Claude 对话：你能进行内容审计吗？

3/11/2026, 1:00:41 PM

📌 一句话摘要

Teresa Torres 演示了如何利用 Claude Code (CLI) 通过交叉引用书籍章节与博客 SEO 表现来进行复杂的内容审计，从而识别战略性增长机会。

📝 详细摘要

本文介绍了新系列“与 Claude 对话”，重点关注 Claude Code 在产品管理和内容策略中的实际应用。作者 Teresa Torres 分享了一个使用该 AI CLI 工具为其网站 Product Talk 进行全面内容审计的案例研究。通过向 Claude 提供其著作《Continuous Discovery Habits》的本地 Markdown 文件和博客存档，她让 AI 能够识别出显著的 SEO 差距。该过程揭示了一些高流量关键词，虽然她的书中有深入探讨，但博客却未能获得排名，例如“结果 vs 产出”和“产品路线图”。文章强调，AI 输出的质量在很大程度上取决于提供结构化的本地上下文，而不是依赖通用的 Web 端提示词。

💡 主要观点

  1. 相比标准的 Web 界面，Claude Code (CLI) 提供了更卓越的上下文管理。 通过使用命令行工具，作者可以将本地 Markdown 文件的整个目录提供给 Claude，使 AI 能够同时深入分析她的书籍和博客。
  2. AI 可以有效弥合深度知识产权与 SEO 表现之间的差距。 审计识别出了“木马”机会——即作者在书中以独特视角涵盖的高流量通用术语，但在博客上尚未进行优化，这为受众增长提供了清晰的路线图。
  3. 结构化交互和澄清性问题对于高质量的 AI 交付成果至关重要。 审计的成功依赖于 Claude 在执行任务前针对范围、地理位置和成功指标提出澄清性问题的能力，从而确保最终分析具有可操作性。

💬 文章金句

  • 如果你只是打开 Claude.ai 并要求它对你的网站进行内容审计，它的表现不会太好。
  • 最大的差距在于 CDH 涵盖的广泛主题，但目前缺乏针对性的内容。
  • 以 Teresa 特有的产品发现视角来撰写这些高搜索量的主题。
  • 我太专注于如何帮助人们设置 Claude Code，以至于忘了分享为什么要这么做。
