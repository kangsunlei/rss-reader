马斯克彻底把 X 平台给开源了，但是我却复刻不出来

5/17/2026, 2:06:00 AM

📌 一句话摘要

本文深入分析了马斯克将 X 平台推荐算法开源的具体内容、技术架构、未开源部分以及背后的商业与监管博弈，指出虽然代码架构完整，但缺少核心数据与生产级模型，无法真正复刻 X。

📝 详细摘要

文章围绕马斯克将 X 平台推荐算法开源这一事件展开。首先介绍了开源的具体内容，包括基于 Grok 的 Transformer 推荐系统，其核心由负责网内内容的 Thunder 和网外内容的 Phoenix Retrieval 两个候选来源，以及一个统一的排序模型 Phoenix Scorer 组成。文章详细解释了该模型如何预测用户行为（点赞、转发等）并加权排序。其次，文章明确指出开源并非完全透明，缺失了生产级模型权重、训练数据、广告竞价策略和部分内容理解管道（Grox）等核心机密。最后，文章分析了马斯克开源的深层动机：一方面是为了兑现承诺、重建用户信任，另一方面更是为了对抗欧洲日益严格的监管审查，将开源作为一种主动防御策略。文章还讨论了开源带来的代价，如暴露技术弱点、让竞争对手学习等。

💡 主要观点

  1. X 平台开源了基于 Grok 的 Transformer 推荐系统核心架构。 系统由 Thunder（网内内容）和 Phoenix Retrieval（网外内容）两个候选来源，以及一个预测用户行为概率并加权排序的 Phoenix Scorer 模型组成，设计思路清晰。
  2. 开源并非完全透明，核心数据与生产级模型仍被保留。 GitHub 上仅包含一个迷你版模型用于教学演示，而生产级模型规模、海量用户行为训练数据、广告竞价策略等商业机密均未公开，导致无法真正复刻 X 的推荐效果。
  3. 马斯克开源的主要动机是应对欧洲监管压力并重建用户信任。 面对欧盟和法国的算法调查，主动开源代码可以宣称透明，以此对抗监管审查，同时向用户和广告主证明算法公正性，是一种进攻性的防御策略。

💬 文章金句

  • 我们知道这个算法很笨，需要大幅改进，但至少你可以看到我们实时且透明地努力让它变得更好。没有其他社交媒体公司这样做。
  • 开源是开源了，但并不是完全开源。
  • 你虽然可以根据 GitHub 开源的这些东西去造一个类似 X 的社交平台，但你造不出一个和 X 一样好用的推荐系统。
  • 进攻才是最好的防守。
  • 马斯克在 2023 年开源 Twitter 算法时说过一句话：'我们希望 X 成为互联网上最透明的系统，并让它像最著名、最成功的开源项目 Linux 一样强大。'
