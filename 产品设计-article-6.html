Anthropic 优化 30 多个生物模型，蛋白质设计成本最高降 98%

9/19/2026, 6:24:01 AM

📌 一句话摘要

Anthropic 让 Claude 在不到四周内优化 30 多个生物研究开源模型，平均提速约 4 倍，并把蛋白设计流程的算力成本从约 1 万美元压到约 150 美元。

📝 详细摘要

Anthropic 公布 Claude 在生物分子建模上的一组新结果：不到四周，Claude 优化了 30 多个用于生物研究的开源深度学习模型，覆盖蛋白结构预测、蛋白设计、Protein Language Model 和基因组学。在允许极小精度损失时平均提速约 4 倍，要求输出完全一致时平均仍接近 2 倍。Claude 开发了 FlashPairformer 自定义 kernel 加速 triangle attention 与 triangle multiplication，并逐模型优化推理路径；还开发低显存 Big mode，让超过 1 万 Token 的生物分子系统可在单个 NVIDIA GPU 节点上推理，超过 7 万 Token 的系统也能完成推理，但预测结构发生坍缩，说明降低的是资源门槛而非预测能力。在 de novo protein binder 设计流程中，条件从约 1.6 万词 Prompt、sub-agent、每靶点约 1 万美元算力，压缩到单个 Claude 模型、一张 H200、约 1100 词 Prompt，16 个靶点的 ipSAE 表现与此前大致相当，GPU 与 Token 合计约 150 美元。优化代码已开源。

💡 主要观点

  1. Claude 直接参与底层 kernel 优化，而非只调用现成模型 Anthropic 让 Claude 开发出 FlashPairformer 自定义 kernel，专门加速 AlphaFold3、OpenFold3、Boltz-2 等模型大量使用的 triangle attention 和 triangle multiplication，相较 NVIDIA cuEquivariance 在 triangle attention 上平均快 2.7—2.9 倍，triangle multiplication 上快 1.7—3.2 倍。
  2. 优化在提速的同时基本保住了预测精度 允许极小数值精度变化时，十多个结构预测模型平均提速约 4 倍；要求输出完全一致时平均仍约 1.6 倍。Fast mode 与默认设置在 DockQ 大于 0.23 的界面数据上统计无显著差异，下游任务未观察到性能下降。
  3. 低显存 Big mode 把大型分子系统的推理门槛降到单节点 Big mode 可在单个 NVIDIA GPU 节点上准确预测超过 1 万 Token 的系统，并让超过 7 万 Token 的系统完成推理；但 3.1 万至 7 万 Token 的病毒衣壳等系统预测结构发生坍缩，证明的是资源门槛下降，而非模型具备可靠预测能力。
  4. 蛋白设计流程的算力成本下降约两个数量级 此前每个靶点最多消耗约 1 万美元算力、约 2500 个 H100 GPU 小时，且依赖约 1.6 万词 Prompt 和 sub-agent；此次压缩到单个 Claude 模型、一张 H200、24 小时、约 1100 词 Prompt，16 个靶点的 ipSAE 中位数与最高值与此前大致相当，GPU 与 Token 合计约 150 美元。
  5. 150 美元只是计算设计成本，不等于完整研发成本 该数字仅覆盖 Claude 调用优化后模型完成计算设计时的 GPU 与 Token 支出，不包括后续湿实验验证环节，也不代表一套蛋白从设计到验证的全流程成本。

💬 文章金句

  • 在允许极小精度损失的情况下，这批模型平均提速约 4 倍；如果要求输出结果完全一致，平均也能实现接近 2 倍的加速。
  • 因此，这部分结果证明的是推理资源门槛已经下降，而不是结构预测模型已经具备了对 7 万 Token 生物系统的可靠预测能力。
  • 这里的 150 美元并不是一套蛋白从设计到湿实验验证的完整成本，也不包括后续实验环节。
  • 这一次，它开始直接参与这些专业模型的 kernel、推理代码和显存使用优化，再调用优化后的模型完成蛋白设计。
