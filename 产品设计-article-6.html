让 AI 帮你操作手机，这个 GitHub 开源项目支持安卓和 iPhone。

9/26/2026, 6:46:31 AM

📌 一句话摘要

Mobile MCP 是一个让 AI Agent 通过无障碍服务和图像识别操作安卓/iOS 真机及模拟器的开源项目，支持 Claude Code 等客户端，适用于自动化测试和页面检查。

📝 详细摘要

本文介绍了 GitHub 上近 7K Star 的开源项目 Mobile MCP，该项目允许 AI Agent 直接控制移动设备（安卓和 iOS，含真机与模拟器）。其核心机制是优先利用系统提供的无障碍信息来定位 UI 元素，若信息不足则结合截图和视觉模型分析坐标进行操作。文章详细列出了从环境准备（Node.js、Android SDK/Xcode）、设备连接调试到在 Claude Code 或 Cursor 中配置 MCP 服务的完整步骤，并提供了验证连接的指令示例。该工具主要面向独立开发者，用于自动化执行如页面布局检查、按钮点击验证等重复性测试任务，减少人工介入。

💡 主要观点

  1. Mobile MCP 实现了 AI 对移动设备的跨平台控制能力 支持安卓和 iOS 的真机及模拟器，Agent 可读取屏幕内容、点击、滑动和输入文字，填补了通用 LLM 与移动端交互的空白。
  2. 采用“无障碍服务 + 视觉兜底”的双模态交互策略 优先使用 App 暴露的无障碍信息（文本、位置）进行精准控制，效率高且稳定；当控件难以识别时，回退到截图配合视觉模型分析坐标，适应不同 App 的界面结构。
  3. 提供标准化的 MCP 集成方案，降低接入门槛 兼容 Claude Code、Cursor 等主流支持 MCP 协议的客户端，通过简单的 npx 命令或 JSON 配置即可启动服务，无需复杂的原生代码开发。
  4. 核心价值在于提升独立开发者的测试效率 特别适用于前端修改后的自动化回归测试，如检查按钮位置、页面跳转逻辑等，将原本需要人工操作的 UI 验证流程转化为自然语言指令驱动的自动执行。

💬 文章金句

  • 很多独立开发者，用它做页面检查。
  • 优先利用系统提供的无障碍信息。
  • 如果信息不完整或控件难以识别，可以获取截图，让具备图像理解能力的 AI 分析画面，再通过坐标操作。
