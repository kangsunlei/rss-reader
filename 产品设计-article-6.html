Codex 开始“反杀”Claude Code 了吗？

8/23/2026, 11:45:00 PM

📌 一句话摘要

OpenAI Codex 的周活跃用户数突破 2000 万，增速是 Claude Code 的 4 倍，显示出在 AI 编程领域的快速崛起，但 Anthropic 的整体收入仍领先，竞争格局尚未完全逆转。

📝 详细摘要

本文分析了 OpenAI Codex 和 Anthropic Claude Code 在 AI 编程市场的竞争态势。Codex 的周活跃用户数从 500 万迅速增长到 2000 万，而 Claude Code 的增长则显著放缓，年化收入增长率仅为 5.2%。尽管 Codex 在用户数上实现了快速追赶，但 Anthropic 的整体年化收入仍超过 OpenAI，且 Claude Code 在企业客户中的粘性较强。文章指出，未来的竞争将取决于底层模型的性能和企业业务的转化效率。

💡 主要观点

  1. Codex 快速增长，Claude Code 增速放缓 OpenAI Codex 的周活跃用户数在短短几个月内从 500 万翻倍至 2000 万，而 Claude Code 的年化收入增长率已降至 5.2%，显示出两者的市场动能发生了显著变化。
  2. Anthropic 仍保持收入领先 尽管 Codex 在用户数上追赶，但 Anthropic 的整体年化收入（约 650 亿美元）仍远高于 OpenAI（约 400 亿美元），且 Claude Code 在企业客户中具有较高的粘性，难以轻易被替代。
  3. 未来竞争取决于模型和企业转化 最终的胜负将取决于底层模型的性能（如即将发布的 Astra 和 Fable 5.1）以及各自在企业市场的转化效率。OpenAI 需要将大量用户转化为高价值企业客户，才能真正挑战 Anthropic 的地位。

💬 文章金句

  • Codex 本周已经突破 2000 万活跃用户。此前 CNBC 获得的 OpenAI 内部数据也显示，公司 AI 编程与工作类 Agent 产品已经达到约 2000 万周活。
  • 截至 8 月 10 日，Claude Code 过去四周的增长率已经降至 5.2%；而 OpenAI Codex 同期增长 20.8%，接近前者的 4 倍。
  • Anthropic 的年化收入运行率已经突破 650 亿美元，OpenAI 最新披露的年化收入水平则超过 400 亿美元。按 650 亿美元和 400 亿美元的下限计算，Anthropic 目前的年化收入水平至少领先约六成。
