免费技能制作卡通短片：不用 AI 视频生成器

11/8/2026, 2:36:00 AM

📌 一句话摘要

介绍了一个免费技能，能通过拆解 20 部参考短片的 1200 帧，由 Claude Code 生成带 2D 角色和 3D 世界的 55-70 秒竖屏短片

📝 详细摘要

作者开发了一个免费技能，拆解 20 部参考短片的 1200 帧作为风格资料，用户只需提供主题即可由 Claude Code 自动写脚本、规划分镜并渲染出 55-70 秒的竖屏短片。技能支持 2D 角色配彩色 3D 世界、手绘小镇、滑行镜头，并附带音乐音效。安装方式为复制仓库到~/.claude/skills/目录，然后指示 Claude Code 执行。

💡 主要观点

  1. 免除 AI 视频生成器依赖 通过拆解参考片段的 1200 帧作为风格库，结合 Claude Code 自动生成脚本和分镜，制作竖屏短片无需第三方 AI 视频工具。
  2. 自动化内容制作流程 从主题输入到脚本生成再到渲染完成，全程由 Claude Code 驱动，输出 2D 角色配 3D 世界视觉效果，提升自媒体创作效率。
