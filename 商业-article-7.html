深度｜当 AI 学会跳过中间商，OpenAI 对 DoorDash 的广告帝国产生威胁

3/23/2025, 5:10:53 AM

📌 一句话摘要

OpenAI 的 AI Agent 可能威胁 DoorDash 的广告中介地位，但也可能为其带来新的流量入口。

📝 详细摘要

文章探讨了 OpenAI 的 AI Agent 对 DoorDash 等消费端应用生态的潜在冲击。AI Agent 能够自动化在线购物等任务，可能绕过传统应用，使 AI 公司成为中介，从而影响这些平台的广告收入。DoorDash 等公司担心 AI Agent 减少用户对其网站的访问，从而降低广告价值。零售商可以通过构建自己的代理，如提供推荐或产品信息，与 AI Agent 互动，或利用 ChatGPT 等 AI 工具增加流量。尽管 AI Agent 目前存在速度慢和性能不佳等局限性，但其兴起已促使企业思考如何调整广告和产品发现策略，以适应这一新的技术趋势。文章还提到了 ChatGPT 对零售商网站流量的影响，与 AI Agent 形成对比。

💡 主要观点

  1. AI Agent 可能绕过传统 App，通过减少用户访问和降低广告展示机会及点击率，对广告收入构成威胁 AI Agent 能够自动化消费端任务，减少用户对特定 App 的依赖，从而降低其广告价值，对依赖广告收入的平台产生冲击。
  2. 零售商可通过自建 Agent 或利用 AI 工具应对冲击 零售商可以构建自己的 Agent 与 AI Agent 互动，提供推荐或额外的产品信息，或利用 ChatGPT 等 AI 工具增加流量，以适应 AI Agent 带来的变化。
  3. 沃尔玛等零售商考虑建立自己的 Agent，与 AI Agent 互动，从而更好地理解客户需求并提供产品信息 沃尔玛美国业务的首席技术官哈里 · 瓦苏德夫表示，零售商应对网络代理威胁的一种方法是建立自己的代理与它们互动，提供推荐或额外的产品信息。
  4. AI Agent 目前存在局限性，未来发展仍需观察 AI Agent 在速度和性能上仍有不足，其发展和应用前景尚不明朗，对消费端应用生态的影响程度仍需进一步观察。

💬 文章金句

  • 如果只有 AI 机器人而不是人访问 DoorDash 网站，那对 DoorDash 的业务来说并不太好
  • 公司有可能阻止 Operator 访问他们的网站。例如，Reddit 已经这样做了。
  • 这项技术 '只能是补充和辅助性的'，并且 DoorDash 并不担心它对公司广告业务的影响。
  • AI agent 和沃尔玛的理论代理将 '建立对客户需求的共同理解'
