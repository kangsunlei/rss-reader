Kimi K3：很强，很贵，很爱给你炫技

7/17/2026, 2:14:00 PM

📌 一句话摘要

本文评测 Kimi K3 模型，展示其在长程 Agent 与代码生成上的强大能力，同时指出其炫技倾向、高昂定价与高部署门槛，认为 K3 虽强但普通用户可能用不起。

📝 详细摘要

文章介绍月之暗面发布的 Kimi K3（2.8 万亿参数，MoE 架构，896 专家），并基于官方信息与作者自测试进行评测。测试涵盖从零生成 Three.js 死星战壕、浏览器策略游戏、需求理解（含 18 条矛盾需求）和代码 Bug 修复，K3 表现优秀但存在推理时间过长（任务小时级）、UI 模板化、爱炫技等问题。文章指出 K3 的 API 定价大幅提高（输出 100 元/百万 tokens），进入 Frontier 模型区间，标志月之暗面从低价竞争转向高端定价；开源权重计划发布但需 64+加速器部署，实际可及性有限。最终认为 K3 更强、更贵、更爱炫技，对行业的影响需从生产力角度重新评估。

💡 主要观点

  1. K3 在长程 Agent 与代码生成上表现出色，但存在炫技倾向与耗时过长问题。 从零生成游戏和复杂需求实现能力强，但运行时间数小时，且 UI 风格模板化，美观优先于效率。
  2. K3 定价大幅提高，不再走低价路线，进入 Frontier 模型定价区间，可能缩小用户基础。 输出价格 100 元/百万 tokens，是前代 K2.7 Code 四倍，实际使用成本高，对普通开发者不友好。
  3. K3 开源权重部署门槛极高，实际可及性有限。 官方建议 64+加速器 supernode 环境，权重开放后绝大多数机构无法有效运行，开源象征性大于实用性。
  4. K3 能发现需求矛盾并服从最终决策，体现一定的判断力但在复杂场景未验证。 在含 18 条矛盾需求的任务中，K3 合并出 7 个问题，最终服从拍板，管理面板显示分开标注，折中方案。

💬 文章金句

  • 普通人可能快用不起最强开源模型了。
  • K3 确实很会 Build。
  • 更强，更贵也更爱炫技的 K3 给整个中国模型行业带来的更关键的影响。
