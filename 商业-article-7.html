实测 Manus 和 Lovart，谁才是 Agent 新王？

5/19/2025, 10:15:00 AM

📌 一句话摘要

对比评测设计领域垂直 Agent Lovart 和通用 Agent Manus 的图像生成能力，论证垂直 Agent 在专业场景中的优势。

📝 详细摘要

文章对近期备受关注的 AI Agent 产品 Lovart 和 Manus 进行了实测对比，重点关注其图像生成及创意设计能力。指出 Lovart 作为垂直设计 Agent，其优势在于内置完整的设计工作流和对设计逻辑的理解，能像“接单”一样完成从需求到交付的全流程任务，体现出“魂”的价值。而 Manus 作为通用型 Agent，虽然调度能力强，但在专业设计场景下更像“调模型+拼素材”，缺乏行业专业流程结构，是“壳”大“魂”轻的代表。文章通过多个创意案例对比了两者的美学理解、概念化表达和信息组织能力，并强调了垂直 Agent 扎根具体场景、内化行业经验的重要性，认为 Lovart 指出了 Agent 落地的正确方向。

💡 主要观点

  1. 垂直 Agent Lovart 具备完整的专业工作流和深层设计逻辑。 与通用 Agent 不同，Lovart 集成创意流程，从理解需求到生成成品，更像一个具备行业经验的设计师，而非简单的模型调用器。
  2. 通用 Agent Manus 在专业垂直场景下表现为“样样通，样样松”。 尽管 Manus 调度能力强，能完成多项任务，但在需要专业知识和流程的创意设计领域，其能力主要体现在调模型和拼素材，缺乏深度和结构。
  3. Agent 的核心价值在于内化行业经验和专业流程结构。 真正可用的 Agent 需要扎根特定场景，理解并执行该领域的复杂任务链条，而非仅依赖于大模型的通用能力或插件调度。

💬 文章金句

  • 感觉 Agent 赛道现在不是卷概念，而是像在打群架。
  • Lovart 是在执行一个内部清晰的设计逻辑，而 Manus 是在调模型 + 拼素材。
  • 它需要的更像是一个 creative director 写给设计团队的 brief：说清楚风格、题材、构图逻辑，甚至语气和情绪。
  • 不是生成图像，而是在做设计。
  • 扎进一个场景，吃透这个行业的工作节奏、拆清楚任务链条，把流程、语境和专业经验都写进系统里。
