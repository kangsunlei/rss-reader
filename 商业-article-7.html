Evolvent AI 胡梦康：Agent 可能会被模型吃掉，但帮助 Agent 进化不会

8/17/2026, 10:15:00 AM

📌 一句话摘要

本文通过对 Evolvent AI 创始人胡梦康的专访，阐述了 Self‑Evolving Agent、RSI 以及 Evolution‑as‑a‑Service 的核心思想，并探讨了 Agent 数据基础设施的价值与未来模型格局。

📝 详细摘要

文章记录了 Founder Park 与 Evolvent AI 创始人胡梦康的对话，梳理了他从 NLP、具身智能到 Agent 的研究路径，解释了为何选择聚焦 Self‑Evolving Agent 与 RSI（Recursive Self‑Improvement），并提出了「Evolution as a Service」的愿景——把 Agent 自我进化所需的数据、环境、训练与评估标准化为服务。胡梦康认为，虽然通用 Agent 能力可能被基础模型厂商吸收，但真正的壁垒在于能够发现并提供前沿模型尚未解决的 capability gap，即「谁能帮 Agent 更快地进化，谁就占住了生态位」。文中还详细描述了 Agent 数据的三要素（Environment、Task、Verifier）、长程任务的真实性、动态环境的重要性，以及如何通过独立的 evaluation 防止 reward hacking。最后讨论了创业心得、团队构成以及对未来模型与应用公司关系的看法，强调 Agent 将成为能够自闭环、自盈利的经济主体。

💡 主要观点

  1. Self‑Evolving Agent 的核心是让模型在真实任务中与环境交互、获得反馈并持续学习。 通过规模化构建任务环境，让 Agent 在实际任务中滚动迭代，积累经验并提升能力，最终目标是打造能够自我进化的 AI Scientist 系统。
  2. Evolution as a Service 旨在标准化 Agent 全生命周期所需的数据、环境、训练与评估基础设施。 服务对象包括基座模型厂商与应用层公司，提供可直接运行的环境与任务，使 Agent 能够自发现能力缺口、生成数据、训练模型并通过独立评估验证真实提升。
  3. 通用 Agent 能力很可能被基础模型厂商内化，但真正的壁垒在于发现并提供前沿模型尚未解决的 capability gap。 基础模型会把通用能力（Tool Use、Browser Use 等）内化进模型，而专属环境、真实业务数据以及动态验证器等仍需外部基础设施供应，这决定了谁能在 Agent 生态中占据关键位置。

💬 文章金句

  • 谁能帮 Agent 更快地进化，谁就占住了生态位。
  • LLM 是缸中之脑，Agent 才是未来。
  • 如果你的 Agent 可以自进化，那其实不需要一个非常复杂的 Agent Framework 和 Learning Loop，它可能非常简单，自己把自己需要的能力补全。
  • 未来每家应用公司都可能拥有自己的模型。
  • 我们希望服务的是整个进化周期。客户给我们的不是「帮我标多少条数据」，是一个 Model、一个真实的业务任务分布，以及一个它希望提升的目标。
