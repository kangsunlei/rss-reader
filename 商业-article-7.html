📝 详细摘要

本文详细阐述了为 Code Agent 设计的**一份系统提示（System Prompt）**，旨在规范其在处理 Git 仓库时的行为。核心指令包括：在任务完成后或终止前等待所有终端命令完成；在修改文件后必须使用 Git 提交，确保工作区干净；禁止创建新分支和修改现有提交。文章重点介绍了 AGENTS.md 文件的作用及其规范，指出这些文件可在文件系统中任何位置出现，为 Agent 提供项目特定的指导信息（如编码规范、测试方法、PR 消息格式）。AGENTS.md 指令的作用域为其所在目录树，深层嵌套文件具有更高优先级，但用户直接指令优先级最高。此外，系统提示强制 Agent 在输出中引用所查阅的文件路径和终端输出，并规定了详细的引用格式，以确保结果的可追溯性和准确性。这些规范共同构建了一个严谨、可控的 AI Agent 自动化编程及协作框架。

💡 主要观点

  1. Code Agent 必须遵守严格的 Git 操作流程 Agent 被要求在 Git 仓库中进行提交、处理冲突、确保工作区干净，且不能创建分支或修改历史提交，这保证了自动化操作的可控性和安全性。
  2. 通过 AGENTS.md 文件实现项目特定规范的传递 AGENTS.md 文件允许项目维护者在不同目录下定义针对 Agent 的行为、代码风格、测试等特定指令，提高了 Agent 适应不同项目环境的能力。
  3. 指令优先级清晰界定，确保 Agent 行为符合预期 用户直接指令优先级最高，AGENTS.md 文件优先级随嵌套深度增加，避免了指令冲突时的不确定性，保证了行为逻辑的一致性。
  4. 强制引用机制提升 Agent 输出的可追溯性和可信度 Agent 必须引用其输出中涉及的文件路径和终端命令结果，这使得用户可以追溯信息的来源，验证结果的准确性。

💬 文章金句

  • Wait for all terminal commands to be completed (or terminate them) before finishing.
  • You must leave your worktree in a clean state.
  • For every file you touch in the final patch， you must obey instructions in any [AGENTS.md](http://AGENTS.md) file whose scope includes that file.
  • More-deeply-nested [AGENTS.md](http://AGENTS.md) files take precedence in the case of conflicting instructions.
  • If the [AGENTS.md](http://AGENTS.md) includes programmatic checks to verify your work， you MUST run all of them and make a best effort to validate that the checks pass AFTER all code changes have been made.
  • If you browsed files or used terminal commands， you must add citations to the final response (not the body of the PR message) where relevant.
