开源和闭源模型的差距在拉大：这是 DeepSeek 论文揭示的残酷真相

12/7/2025, 1:56:00 AM

📌 一句话摘要

文章基于 DeepSeek 论文揭示开源与闭源大模型性能差距正在扩大，并分析其结构性原因及 DeepSeek 通过技术创新应对挑战的策略。

📝 详细摘要

文章深入解读了 DeepSeek V3.2 技术报告，指出当前开源大模型与闭源模型之间的性能差距非但没有缩小，反而因闭源模型更快的进步速度而扩大。论文通过 MMLU-Pro、GPQA Diamond、HLE 等基准测试数据证实了这一趋势。文章进一步分析了导致差距拉大的三个结构性问题：开源模型普遍采用低效的传统注意力机制、后训练阶段资源投入严重不足，以及 AI Agent 能力滞后。面对这些挑战，DeepSeek V3.2 通过引入 DSA 稀疏注意力机制优化架构、大幅提升后训练预算（超过预训练成本 10%），以及系统化任务合成流程强化 Agent 能力，成功在特定领域缩小了与闭源模型的差距，为开源 AI 探索出一条通过技术创新而非单纯资源堆砌的生存之道。

💡 主要观点

  1. 开源与闭源大模型性能差距正在扩大，尤其在复杂任务上 DeepSeek 论文通过多项基准测试数据，明确指出闭源模型如 GPT-5 和 Gemini 3.0 Pro 的性能提升速度显著快于开源模型，导致两者差距日益拉大。
  2. 差距拉大源于架构、资源投入和 Agent 能力滞后等结构性问题 开源模型在长序列处理中普遍依赖低效的传统注意力机制，后训练资源投入不足，以及在复杂交互、工具调用等 Agent 能力上存在明显滞后。
  3. DeepSeek 通过 DSA、超常规后训练和 Agent 任务合成进行应对 DeepSeek V3.2 引入 DSA 稀疏注意力机制提升长序列效率，将后训练预算提升至预训练成本的 10% 以上，并系统合成 Agent 任务，有效提升了模型能力。
  4. 开源 AI 的未来在于技术路线创新而非资源硬碰硬 DeepSeek 的实践证明，通过高效架构和科学的后训练方法，开源模型可以在有限资源下实现接近顶尖闭源模型的效果，找到独特的生存发展路径。

💬 文章金句

  • 闭源专有模型的性能提升速度显著更快。结果是，两者的差距非但没有缩小，反而在扩大，闭源系统在复杂任务上展现出越来越强的优势。
  • 开源模型普遍依赖传统的 vanilla attention 机制，这种机制在处理长序列时效率极低。
  • 后训练是让模型从'会说话'变成'会思考'的关键环节，需要通过强化学习让模型学会推理、工具使用和遵循复杂指令。
  • DeepSeek V3.2 成为 Agent 场景中极具成本效益的选择，显著缩小了开源与前沿闭源模型之间的性能差距。
  • 开源 AI 唯一的生存之道：不是硬碰硬拼资源，而是拼技术路线的创新。
