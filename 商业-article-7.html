50 个员工，估值 471 亿元

8/21/2026, 9:27:00 AM

📌 一句话摘要

Stripe 以 70 亿美元估值收购全球最大大模型聚合平台 OpenRouter，这家仅 50 人团队的公司凭借聚合碎片化 API 的商业模式实现爆发式增长，中国大模型贡献超 60%流量成为关键支撑。

📝 详细摘要

文章报道 Stripe 收购 OpenRouter 的交易细节与行业背景。OpenRouter 成立于 2023 年，由 OpenSea 联合创始人 Alex Atallah 创立，商业模式为聚合全球 400+大模型 API，用户通过统一接口调用，平台收取 5.5%服务费。公司 2024 年 10 月年化推理支出仅 1000 万美元，2026 年 3 月已达 10 亿美元，增长曲线陡峭。中国模型在 2026 年 2 月起集体霸榜，MiniMax、小米 MiMo、阿里 Qwen、腾讯混元、月之暗面 Kimi、DeepSeek 相继登顶，目前中国模型 Token 消耗占比超 60%，主要用户来自美国开发者。VC 投资回报丰厚，B 轮估值 13 亿美元，3 个月后以 70 亿美元被收购。Stripe 收购动机在于布局 AI Agent 时代的支付基础设施，防范传统电商被智能体商务颠覆。文章同时指出 OpenRouter 排名参考价值有限，OpenAI 年化收入已超 400 亿美元，OpenRouter 平台总收入仅为其零头。

💡 主要观点

  1. OpenRouter 以聚合器模式成为 AI 基础设施关键节点。 大模型 API 格式、计费、限流策略高度碎片化，OpenRouter 提供统一接口降低集成成本，在模型赛道越卷时生意越好，且几乎无需重资产投入。
  2. 中国模型通过 OpenRouter 实现大规模出海。 2026 年 2 月起中国模型集体霸榜，Token 消耗占比从不足 2%飙升至超 60%，用户 47%来自美国，OpenRouter 成为中国大模型出海的关键支点。
  3. Stripe 收购旨在布局 AI Agent 时代的支付基础设施。 Stripe 担忧 AI Agent 驱动的智能体商务颠覆传统支付场景，通过收购 OpenRouter 获取模型调用结算能力，与自身支付基础设施形成协同。
  4. 70 亿美元估值隐含极高增长预期，化学反应待验证。 按 7 月 1.4 亿美元年化收入计算，P/S 倍数超 50 倍，Stripe 与 OpenRouter 在 AI 基础设施与支付基础设施之间的协同效应尚需时间检验。

💬 文章金句

  • 大模型赛道越卷，OpenRouter 的生意就越好。而且这个生意还几乎不需要本钱投入。
  • 如果没有中国模型的崛起，OpenRouter 今天恐怕很难有 70 亿美元的估值。
  • OpenAI 的年化收入据说已经突破了 400 亿美元，而 OpenRouter 平台所有模型的 API 收入加起来不过 10 亿美元，只是 OpenAI 一家的零头而已。
