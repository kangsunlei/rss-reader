AI 营销大师课：从入门到精通只需 60 分钟

2/9/2026, 7:30:07 PM

📌 一句话摘要

本大师课介绍了“Vibe Marketing”，这是一种利用 Claude Code、MCP 工具和自定义 AI 技能，实现从调研到程序化视频制作的整个营销漏斗自动化的工作流。

📝 详细摘要

被称为“The Boring Marketer”的 James Dickerson 展示了一套完整的 AI 驱动营销工作流，该工作流呼应了“Vibe Coding”运动。通过利用 Claude Code 和模型上下文协议（MCP），他展示了如何将专业的营销框架直接集成到开发者的终端中。该过程涉及使用 Perplexity 和 Playwright 进行深度市场调研，应用“Skills”（预定义的专家指令）进行定位和直接响应文案创作，并利用 Remotion 进行程序化视频广告生成。这种方法让非技术和技术创始人都能在短短一小时内构建高转化率的落地页、引流产品（Lead Magnets）和多平台广告活动，强调数据驱动的调研而非平庸的 AI 生成内容。

💡 主要观点

  1. 通过“Vibe Marketing”将营销视为开发环境的延伸。 通过使用 Claude Code 等工具，开发者可以在编写代码的同一个终端中构建营销资产，从而实现利用 AI 智能体从产品构建到用户获取的无缝衔接。
  2. 利用 MCP 工具进行深度调研，防止产生低质量的“AI 垃圾内容”。 通过 MCP 集成 Perplexity 和 Playwright，使 AI 能够获取实时市场数据和竞争对手洞察，确保生成的营销文案和策略基于实际的市场空白，而非平庸的幻觉。
  3. 将专业营销框架转化为可复用的“AI Skills”，以保持质量的一致性。 通过将 Eugene Schwartz 的文案创作方法或特定的定位视角编码为“Skills”，用户可以引导 LLM 产出具有专业审美和高转化潜力的高级品牌资产。
  4. 利用 Remotion 等程序化工具，以近乎零成本的代价扩大创意生产规模。 使用 Claude Code 通过 Remotion 编辑和生成视频，可以瞬间为不同平台（Meta、YouTube）创建数百个广告变体，将营销过程转变为高频测试机器。
  5. 采用“Orchestrator”技能来识别并填补营销漏斗中的空白。 Orchestrator 智能体会分析现有资产（如落地页和定位），以建议缺失的组件（如引流产品或邮件序列），为不确定下一步营销动作的创始人提供战略路线图。

💬 文章金句

  • 你可以在构建产品的同一个地方进行营销，利用 Skills、MCP 和智能体进行协作。
  • 人们跳过了枯燥的调研环节……这就是‘AI 垃圾内容’的来源。他们只是输入一个提示词并得到一个结果，然后纳闷为什么没效果。
  • Vibe marketing 就是利用 AI 智能体为你的 Vibe-coded 产品获取用户。
  • 在家庭服务行业，第一个响应的人通常能赢得 35% 的工作。AI 可以在几分钟内响应线索，而无需增加人手。
  • 你可以成为一台‘测试机器’，在一次对话中生成 20 个不同的落地页和 20 个广告。
