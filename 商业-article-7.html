DeepSeek 的 Harness，有一套新世界观｜Hao 好聊趋势

📌 一句话摘要

本文深度解读 DeepSeek Harness 的「一切皆插件」架构设计，结合时空可组合性理论与 RHI 领域最新研究，分析其作为 AI 自进化温床的技术逻辑与潜在价值。

📝 详细摘要

文章围绕 DeepSeek 发布的 Harness 项目展开，指出其核心创新在于将传统 Harness 中不可动的底层组件（Session、System Prompt、Tools、Agent、Agent Loop 等）全部拆分为插件，由 Cordis Runtime 统一管理依赖与生命周期。配套论文提出时空可组合性（Spatiotemporal Composability）理论，通过可回退效应与反应式共效应解决插件独立拆卸与依赖协调问题。文章进一步梳理 RHI（递归式 Harness 自我改进）领域的三个核心困境：进化什么、怎么进化、怎么递归，并引用 Meta-Harness、AHE、HarnessCompass、Harness-R1 等最新研究，指出通用 Harness 假设正被证伪，原语复用与组合泛化才是可行路径。作者认为 DSH 的真正价值在于为 Reward Assignment 提供结构化的干预边界，使 Agentic RL 的信用分配成为可能，从而为 AI 自进化奠定基础。

💡 主要观点

  1. DeepSeek Harness 将底层核心组件全部插件化，突破传统 Harness 的静态架构。 与 Claude Code、Codex 等开箱即用型 Harness 不同，DSH 把 Session、System Prompt、Tools、Agent、Agent Loop 等原本不可动的组件也拆为插件，由 Cordis Runtime 统一管理依赖、生命周期与撤销机制。
  2. 时空可组合性是 DSH 插件系统的理论基础。 时间可组合性通过可回退效应（revertible effects）保证插件卸载后环境恢复原状；空间可组合性通过反应式共效应（reactive coeffects）显式表达组件依赖，使 Runtime 能动态协调依赖变化。
  3. RHI 领域面临三个未解困境：进化什么、怎么进化、怎么递归。 进化什么：Harness 边界模糊，Prompt、工具、记忆、Middleware 性质不同却混在同一搜索空间；怎么进化：通用 Harness 假设被证伪，泛化能力有限；怎么递归：多数方案中优化器本身并未学习改进。
  4. Harness 应被视为组合泛化器，而非静态工具箱。 MIT CSAIL 研究指出 Harness 的核心价值是将 OOD 任务转换为 LID 局部调用，通过组合已有能力应对新任务。这为 RHI 提供了新视角：沉淀可复用原语，学习动态组合策略。
  5. DSH 的真正底牌是为 Agentic RL 的 Reward Assignment 提供结构化干预边界。 GRPO 等组相对方法在 Agentic RL 中因环境状态分叉而失效。DSH 的可回退效应与显式依赖让每次干预的影响范围可追踪，使信用分配从粗粒度终局 Reward 细化到具体组件干预。

💬 文章金句

  • DeepSeek 端出的这道看似繁琐的新菜，从一开始，就不是做给现在的开发者吃的，而是为明天的 AI 准备的进化温床。
  • 当基础模型的智力增长开始不可避免地遭遇边际效应，这种基于底层原语的组合泛化与自我进化，或许才是通向 AGI 下一阶段的真正钥匙。
  • Harness 并不是一个单纯包在模型外面的工具箱，它更像外部世界和神经网络之间的一层程序。
