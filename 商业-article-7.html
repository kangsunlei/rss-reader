DeepSeek APP 突然更新账单，网友：要收费了？

11/28/2026, 5:04:34 AM

📌 一句话摘要

DeepSeek 在聊天界面新增 Token 账单显示，按 API 空闲时段价格计费且仍免费，暗示算力紧张下的商业化探索与新模型发布预期。

📝 详细摘要

文章报道 DeepSeek 网页和 App 端悄悄上线对话级 Token 账单功能，显示输入输出 Token 用量、缓存命中情况及按 API 空闲时段定价计算的费用（如百万输入 Token 缓存命中 0.02 元），但聊天仍免费。结合近期因算力不足限额、OpenRouter 调用量激增至 59.2 万亿 Token 等背景，分析此举或为商业化铺垫，同时网页版限额消失引发 V5 或 V4.1 Pro 新模型发布猜测。

💡 主要观点

  1. DeepSeek 在消费端聊天界面引入 Token 级账单显示 网页和 App 端新增硬币图标，点开可查看本轮对话的输入/输出 Token 用量、缓存命中率、单价及金额，并显示上下文占用进度，使算力成本对用户透明化。
  2. 账单定价直接对齐 DeepSeek-V4.1-Flash API 空闲时段价格 百万 Token 输入缓存命中 0.02 元、未命中 1 元、输出 4 元，高峰时段翻倍，将原本仅面向开发者的按量计费规则原封不动搬入普通用户聊天框。
  3. 近期因算力不足实施限额，调用量却持续暴涨 11 月 16 日因算力不足限制免费额度、压缩输入上限、切断长对话；同期 OpenRouter 上 DeepSeek-V4.1-Flash 单周调用量从 33.6 万亿 Token 环比增 801%增至 59.2 万亿 Token，稳居榜首。
  4. 账单上线被视为商业化试水，网页版限额消失引发新模型猜测 用户推测免费额度用完后将转为充值制；同日网页版限额悄悄取消，市场猜测 V5 或 V4.1 Pro 训练告一段落释放算力，新模型发布在即。

💬 文章金句

  • 算力不足。
  • 每百万 Token 输入（缓存命中）仅需 0.02 元、输入（缓存未命中）需 1 元，输出则需 4 元。
  • DeepSeek-V4.1-Flash-1017 在 OpenRouter 上的单周调用量就已达到 33.6 万亿 Token，环比暴涨 801%。
  • 今天网页版的限额似乎悄无声息地消失了。
