1 人公司，扛 5 个人的活，还要管 50 个 Agents ？| S10E18

6/26/2026, 9:30:00 AM

📌 一句话摘要

两位非技术背景的实践者对谈，深度解析 AI 时代个人创业如何借助 Agent 将内容生产与产品开发效率提升数倍，并探讨了「一人公司」的现实困境与协作模式。

📝 详细摘要

本期圆桌讨论聚焦 AI 时代下「一人公司 (OPC)」的创业新模式。嘉宾余一和归藏作为非技术背景的实践者，分享了如何借助 AI Agent 实现超级个体的蜕变：余一打造数字分身，利用 AI 工作台将自媒体视频制作从 2 小时降至 20 分钟，一年内从 2000 粉增长至近 20 万；归藏则作为独立开发者，其 PPT Skill 在 GitHub 收获超 2 万 Star。讨论深入对比了双方对 Agent 定位的分歧——余一视其为可成长的合伙人，归藏则坚持工具与可控性优先。此外，现场还重点拆解了 OPC 的最大痛点并非产品开发，而是获客、复购与信任链的建立；同时指出了当业务涉及合规、财务等复杂流程时，单人模式的局限性与畏难情绪，并展望了小团队 + AI Agent 的新型组织架构。

💡 主要观点

  1. AI 大幅降低了非技术人员的创业门槛，让「吃自己的狗粮」成为可能。 余一分享通过 Web Coding 和 AI 工作台，技术小白也能搭建完整业务流，将过去需要研发团队的资源内化为个人能力，先解决自身需求再推向市场。
  2. 对 Agent 的定位分歧导致了完全不同的协作模式：工具 vs 合伙人。 归藏要求 Agent 具备高确定性，可控制交付质量，视其为高效工具；余一则赋予 Agent 决策自主权，允许其犯错积累经验，追求成为独立的数字分身。
  3. AI 时代的创业瓶颈从生产环节转移到了分发、获客与建立信任。 当代码和内容的壁垒因 AI 变低后，真正的壁垒成了渠道、用户口碑和信任关系。嘉宾认为应通过公开构建和自媒体展示来让客户看见并建立信任。
  4. 一人公司终究还是会遇到天花板，非核心琐事的处理是最大的隐形阻碍。 虽然 AI 能处理复杂逻辑，但在合规、财务、线下供应链等人类参与度高的环节，个人极易产生畏难情绪。3-10 人的小团队配合各自 Agent 的协作模式被认为是更好的归宿。

💬 文章金句

  • AI 能做这些琐碎事情以后，我们创造力还是比较重要的……创造力其实来自于我们坐那儿闲的没事干那种发呆的时间。
  • AI 太快了……如果你有一个很明确的分界线……我怕你一直在探索，你也不知道自己在打磨什么，就在原地以更快的速度在那边拉磨。
  • 从股权和并购投资的角度而言的话，它是天然的希望你这件事情具有持续性、扩张性，还有稳定性和安全性的……这个跟 OBC 的形式是天然的相反的。
