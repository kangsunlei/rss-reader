MiniMax-M1 登场，MiniMax 再次证明自己是一家模型驱动的 AI 公司

6/17/2025, 12:39:00 PM

📌 一句话摘要

MiniMax 推出文本推理模型 MiniMax-M1，凭借 MoE、混合注意力和 CISPO 算法创新，在长上下文和智能体能力上表现全球领先，同时优化了训练效率。

📝 详细摘要

文章详细介绍了 MiniMax 最新发布的自研文本推理模型 MiniMax-M1。该模型基于 MoE 和混合注意力（Lightning Attention）等创新架构，并提出了新的强化学习算法 CISPO。M1 原生支持百万 Token 上下文输入和目前所有模型中最长的 80k Token 输出，在长上下文理解（如 OpenAI-MRCR， LongBench-v2）和智能体工具使用（如 TAU-Bench）等评测基准上表现领先，尤其在 Agentic Tool Use 方面被认为是市面最强的模型。文章指出，这些底层技术创新显著提升了训练效率，降低了成本，例如在生成 10 万 Token 时计算量仅为 Deepseek R1 的 25%。M1 的发布基于公司此前在 MoE 和线性注意力上的探索，再次证明 MiniMax 在模型驱动方向上的强劲研发实力。模型同时宣布开源。

💡 主要观点

  1. MiniMax-M1 在长上下文和智能体工具使用能力上表现全球领先 模型原生支持百万 token 上下文和 80k 输出，在多项基准测试中表现优异，尤其在 Agentic Tool Use 方面是目前市面最强，达到金字塔尖水平。
  2. M1 在底层架构和算法上实现双线创新，显著提升效率并降低成本 采用混合注意力 Lightning Attention 替代传统机制，克服 Transformer 局限；提出强化学习算法 CISPO 解决混合架构下的 RL 难题，大幅提高了训练效率并降低成本（如计算量仅为 Deepseek R1 的 25%）。
  3. M1 的发布是 MiniMax 技术路线的延续与验证，巩固其模型驱动地位 M1 基于 MiniMax 此前在 MoE 和 Linear Attention（MiniMax-Text-01）上的探索，是其架构创新的进一步 Scale up，验证了非共识技术路线的可行性，再次证明 MiniMax 作为一家模型驱动 AI 公司的实力。

💬 文章金句

  • 作为推理模型，MiniMax-M1 在长上下文理解能力上，是目前包括所有闭源和开源模型在内，能力全球前二的模型，且在训练和推理成本上极高的性价比。
  • 从评测基准 TAU-Bench (airline) 中的表现来看，目前 M1 已经是市面上在 Agentic Tool Use 方面能力最强的模型。
  • M1 是目前唯一一个用线性注意力机制「大改」传统 Transformer 架构，从而大规模实现混合注意力的 MoE 推理模型；在算法层面，M1 提出了新的强化学习算法 CISPO。
  • 在生成长度为 10 万 Token 时，M1 的计算量仅为 Deepseek R1 的 25%，而整个 M1 的完整强化学习训练能在 512 张 H800 GPU 上仅用 3 周完成。
  • M1 的出现，背后是一条 MiniMax 从传统的稠密模型与 Transformer 架构，转向 MoE 与线性注意力机制的草蛇灰线。
  • 正是因为这些屡次探入模型底层架构「非共识」地带所带来的技术创新，一直在印证 MiniMax 终究是一家「模型驱动」的 AI 公司。
