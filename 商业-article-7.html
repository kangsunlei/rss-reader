全世界消耗 Token 最多的人

4/13/2026, 1:30:00 PM

📌 一句话摘要

本文讲述了 25 岁韩国青年 Sigrid Jin 如何通过一年消耗 250 亿 Token 的极端实践，成为 AI 代理（Agent）领域的顶级专家，并在 Claude Code 源代码泄露事件后，利用其积累的直觉和 AI Harness 技术，快速重写出功能相似的免费替代品 Claw Code 的故事。

📝 详细摘要

文章以人物特写的形式，深度报道了韩国青年 Sigrid Jin 在 AI 时代的独特成长路径。他并非科班出身，但通过自学和大量实践，一年内在 Claude Code 上消耗了 250 亿 Token（约合 125 万人民币），成为 Anthropic 公司的顶级用户。这巨额消耗的背后，是他对 AI 代理（Agent）和 AI Harness（AI 调度系统）的深入研究与实践。文章的核心事件是 2026 年 3 月 Claude Code 源代码泄露后，Sigrid Jin 凭借对 Claude Code 的深刻理解和其推广的 AI 工作流工具 oh-my-codex，在数小时内指挥多个 AI 代理协同工作，以“净室重写”的方式复现了其核心逻辑，推出了免费的 Claw Code 项目并迅速爆火。故事不仅展现了个人的技术狂热与创新，更隐喻了在 AI 时代，极致的资源消耗（Token）可以转化为深刻的技术直觉和打破行业门槛的能力。

💡 主要观点

  1. 极致的 Token 消耗是 AI 时代获取深度技术直觉的新路径。 Sigrid Jin 通过一年烧掉 250 亿 Token 的“暴力”实践，获得了对 Claude Code 和 AI 代理工作流的深刻理解，这种直觉让他在代码泄露事件中能快速进行净室重写。
  2. AI Harness（AI 调度系统）是让 AI 代理实现自动化、规模化协作的关键基建。 文章将 AI Harness 比喻为“工地总调度”，它通过制定规则和流程，让不同的 AI 工具像流水线一样配合，实现无人值守的持续运行，这是 Sigrid Jin 及其团队的核心研究方向。
  3. 顶级的技术消费不是为了炫富，而是为了降低门槛和创造普惠价值。 Sigrid Jin 消耗巨资研究 Claude Code，最终目的却是创造出功能相似但免费的 Claw Code。这体现了其技术哲学：用资源投入打破技术壁垒，将成果返还给社区。
  4. 非典型的技术成长路径在 AI 时代更具可能性。 主人公 Sigrid Jin 背景多元（语言人文、辩论、军事财务），非科班出身，靠训练营和自学进入开发领域，并迅速成为社区领袖，这挑战了传统的工程师成长叙事。

💬 文章金句

  • 一年烧掉 250 亿个 Token，有位 25 岁的韩国小伙子，成了全世界最能烧的人。
  • “这是用 250 亿个 Token 换来的直觉。”Sigrid Jin 后来这样评价。
  • 在 AI 时代，最顶级的 Token 消费，从来不是为了证明你有钱，而是为了把门槛踩得稀巴烂。
  • 从这个角度看，Sigrid Jin 这 250 亿个 Token，烧的不是钱，是一张通往新世界的门票。
  • 他决定，不看泄露的代码，只用 AI Harness 从零重写一个。
