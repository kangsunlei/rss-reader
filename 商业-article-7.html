终于！CUDA 官宣：添加原生 Python 支持，开发者狂喜

4/7/2025, 10:27:06 AM

📌 一句话摘要

NVIDIA CUDA 在 GTC 2025 上正式支持原生 Python，降低了 CUDA 的使用门槛。

📝 详细摘要

文章报道了 NVIDIA CUDA 开始原生支持 Python 的重要进展。CUDA 作为高性能并行计算平台，此前主要支持 C/C++。为了降低 CUDA 使用门槛，加速 AI 开发效率，扩大 CUDA 的用户群体，NVIDIA 在 GTC 2025 大会上宣布 CUDA 工具链将全面支持 Python 编程。开发者现在可以直接使用 Python 编写算法，并在 NVIDIA GPU 上高效执行，无需手动调用底层内核或依赖 C++ 接口封装。NVIDIA 还推出了 CuTile 这一更贴近 Python 开发者“数组思维”的编程模型，以及一系列 Python 友好的工具和库，包括 CUDA Core、cuPyNumeric、NVMath Python 等，使得 Python 开发者能够更自然、高效地利用 CUDA 进行 GPU 加速计算。

💡 主要观点

  1. CUDA 未来将支持更多语言，成为通用平台。 除了 Python，CUDA 还将支持 Rust、Julia 等语言，降低使用门槛，吸引更多开发者加入 CUDA 生态。
  2. CUDA 原生支持 Python，降低了 GPU 加速计算的门槛。 Python 开发者无需学习 C/C++，即可利用 CUDA 在 GPU 上高效运行算法，方便 AI 工程师和科研人员使用。
  3. NVIDIA 提供了一系列 Python 友好的工具和库。 包括 CUDA Core、cuPyNumeric、NVMath Python 和 CuTile 编程模型，简化 Python 开发者的 GPU 编程体验。

💬 文章金句

  • CUDA，英伟达深耕多年的并行计算平台和编程模型框架，正式加入了对 Python 的原生支持！
  • 我们一直在努力让加速计算与 Python 深度融合，使其成为 CUDA 技术栈中的'一等公民'。
  • 这不仅仅是把原来的 C 语言翻译成 Python，而是要让 Python 保持本色，让 Python 开发者也感到自然。
  • 相比线程，tile 更贴近 Python 语言的哲学；它足够高效，性能也不输 C++。
  • CUDA 不再设置'语言门槛'，正在从'专业工具'向'通用平台'演化，未来不再只有系统级程序员才能玩转 CUDA。
