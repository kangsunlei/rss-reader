从 0 到 1 拆解 FreeWheel ChatBI：大模型如何重塑视频广告智能数据分析新生态

6/28/2025, 2:15:44 AM

📌 一句话摘要

FreeWheel ChatBI 系统专注于视频广告数据分析，利用大模型技术实现智能查询与决策支持，重塑企业数据分析新生态

📝 详细摘要

本文详细介绍了 FreeWheel 开发的 ChatBI 系统 Insights Chatbot，该系统通过大语言模型(LLM)技术重塑视频广告数据分析流程。系统核心功能包括数据查询与可视化、交互式数据分析、仪表盘导航、知识问答和智能追问等，已在公司内部帮助业务人员提升 90%的数据分析效率。技术实践上重点解决了 LLM 理解业务问题、智能选表、Text2SQL 生成、数据分析算法等关键挑战，采用 Prompt+RAG 方法增强业务理解，融合多种检索技术实现 95%以上的选表准确率。系统基于 LangGraph 搭建 Agentic 框架，结合 Workflow 和 Agent 模式灵活应对不同分析需求，并通过用户反馈闭环机制持续优化系统表现。

💡 主要观点

  1. Prompt+RAG 方法有效提升 LLM 业务理解能力 通过业务概述作为 System Prompt，结合向量数据库存储业务术语，动态检索增强 LLM 对特定业务问题的理解准确性
  2. 多检索技术融合实现 95%选表准确率 结合向量检索、TF-IDF、GraphRAG 等多种方法召回候选字段和表，再经过业务约束过滤和 LLM 决策，大幅提升选表精度
  3. Workflow 与 Agent 模式互补满足分析需求 预定义 Workflow 处理常见问题，Agent 动态调度工具应对长尾需求，灵活覆盖各类数据分析场景
  4. LangGraph 构建的 Agentic 框架提升系统交互能力 通过 Router 节点实现意图识别和功能路由，支持多轮对话和用户反馈闭环，持续优化系统表现
  5. 多模型协同保障数据安全与性能平衡 结合公有云大模型与私有化部署小模型，在保证推理能力的同时实现数据脱敏处理，确保企业数据安全

💬 文章金句

  • ChatBI 突破了传统 BI 的限制，它通过对话实现数据分析，让'人人都是数据分析师'成为可能
  • 通过融合 Workflow（预定义常见问题的分析流程）与 Agent（动态调度工具处理长尾需求）的模式，灵活满足各类分析需求
  • 智能选表：鉴于字段繁多，选表的难点聚焦于事实表，通过标注 400 余个选表示例，系统在事实表选择上的准确率基本达到 95%以上
  • 如果说智能数据查询是 ChatBI 的基础，解决了'能问'的问题，那智能数据分析则是 ChatBI 的升华，帮助用户从数据中发现业务异常、寻找根因，获取洞察
  • 我们引入用户反馈学习，构建闭环优化流程，以不断提升系统准确率与用户满意度
  • 随着 LLM 能力演进与系统持续优化，我们相信 ChatBI 将真正融入日常业务流程，帮助用户节省 90%的重复性工作，让数据的价值最大化
