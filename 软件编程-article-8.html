📌 一句话摘要

WhisperLiveKit 是一个开源的超低延迟、自托管实时语音转文字工具，集成说话人分离、多语言翻译及多种后端（Whisper、Voxtral、FunASR、Qwen3‑ASR、Canary 等），支持本地部署、Docker 及 API 调用。

📝 详细摘要

文章介绍了 WhisperLiveKit 的核心功能与使用方法。它不仅提供基于 Whisper 的实时转写，还内置说话人分离（基于 Sortformer 或 Diart）、实时翻译以及多种后端选择，能够在跨语言会议中边说边出译文。文中详细说明了项目架构、后端支持（如 Voxtral‑MLX、FunASR/SenseVoiceSmall、Qwen3‑ASR 流式及因果模式、Canary 后端），并给出了快速开始的安装命令、API 兼容性（OpenAI、Deepgram 兼容）、从网页捕获音频的扩展以及 Docker 部署指南（包括 GPU/CPU 构建、Compose 配置）。通过丰富的代码示例和参数说明，帮助读者快速搭建属于自己的低延迟语音转文字服务。

💡 主要观点

  1. WhisperLiveKit 提供超低延迟的本地部署实时语音转文字流水线。 项目不仅包装 Whisper，还整合了近年的同步语音识别研究，实现边说话边出字，支持 VAD 降低空闲开销，适用于会议记录、播客转稿等场景。
  2. 内置说话人分离与实时翻译，支持跨语言会议边说边出译文。 基于 Sortformer 或 Diart 进行说话人区分，输出直接是分角色稿；通过后端接入实时翻译功能，可在多语言场景中同步生成目标语言字幕。
  3. 多种后端可选，涵盖 Whisper、Voxtral、FunASR、Qwen3‑ASR、Canary 等，并提供因果模式以降低计算量。 文章分别介绍了各后端的安装方式、运行参数及特点，例如 Voxtral 支持自动语言检测、Qwen3‑ASR 提供因果‑KV 编码器以实现有界内存与恒定每块计算量，满足不同硬件与延迟需求。
  4. 提供完整的部署指南，包括 Docker、GPU 加速及生产环境的 Nginx 配置。 读者可通过简单的 docker build/run 命令快速启动服务，亦可使用 docker compose 缓存模型与令牌，并附带生产级的反向代理与 HTTPS 建议，便于实际项目落地。
