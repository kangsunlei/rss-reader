vitest --changed：仅跑变更文件的测试命令

11/18/2026, 12:13:27 PM

📌 一句话摘要

作者介绍了 vitest 提供的--changed 参数，仅运行受影响的测试文件，极大提升 CI 测试速度。

📝 详细摘要

作者分享了 vitest 的--changed 命令用法，该命令会让 Git 返回变更文件列表，再找出导入这些文件的测试文件，仅运行相关测试。相配合引用的实践经验，提出了智能分片、按 diff 跑测试、工具替换等加速 CI 的技巧。

💡 主要观点

  1. vitest --changed 基于 Git 变更文件筛选测试 通过 Git 获取变更文件，再依据 import graph 定位受影响的测试文件，大幅缩短不必要的测试运行时间。
  2. 引用的 CI 经验包含智能分片与工具替换 结合历史耗时分片、仅跑受影响测试、tsc 改 bun check、oxlint 替代 lint 等多项提升构建与测试效率的技巧。

💬 文章金句

  • 它只会跑 changed files 相关的 tests，内部原理是 Vitest 会让 Git 给出变更文件列表，然后找出 import 了这些文件 的测试文件
