黑客劫持 AI 渗透测试 Agent，植入后门窃取 API 密钥

10/28/2026, 10:00:00 AM

📌 一句话摘要

攻击者利用暴露的 Cairn 面板，向 AI 渗透测试 Agent 注入恶意任务，成功植入 SSH 后门、下载远程访问木马，并窃取本地存储的 API 密钥，暴露了 Agentic AI 系统在权限管理和网络隔离方面的安全漏洞。

📝 详细摘要

本文报道了针对 AI 渗透测试工具 Cairn 的自动化攻击活动。攻击者通过访问未加固的 Cairn 面板，向 Agent 发送恶意指令，包括添加未授权 SSH 密钥、下载 Poseidon 植入体，以及搜索并窃取敏感 API 密钥。调查显示，该攻击活动涉及两个独立集群，均利用了 Agent 对面板指令的无条件执行特性，揭示了暴露 AI 工具的严重安全风险。

💡 主要观点

  1. 攻击者利用暴露的 Cairn 面板，向 AI Agent 注入恶意任务，包括植入 SSH 后门和下载远程访问木马。 Cairn 面板允许用户查看和启动任务，但未对访问权限进行严格限制。攻击者利用这一漏洞，向 Agent 发送指令，添加未知公钥到 SSH 配置文件，并执行下载并运行恶意二进制文件的脚本，从而获得对目标系统的持久访问权限。
  2. 攻击活动涉及两个独立集群，分别专注于持久化访问和凭证窃取。 调查识别出两个不同的攻击模式：一个集群（AIA0009）专注于建立持久化连接和投放恶意软件，另一个集群（AIA0010）专注于探测内部服务和窃取存储在系统中的 API 密钥。这两个集群分别利用了 Agent 的不同能力，共同构成了对 AI 工具的全面威胁。
  3. 该攻击暴露了 Agentic AI 系统在权限管理和网络隔离方面的安全漏洞。 Cairn Agent 对面板指令的无条件执行，以及对本地文件系统的读取权限，使得攻击者可以轻松窃取敏感数据。这一事件强调了在部署 AI 工具时，必须严格限制其权限边界，并确保管理界面不被直接暴露在公共网络中。

💬 文章金句

  • 只要能访问该面板，任何人都可以查看项目、启动新任务、停止或删除正在运行的任务。这种高权限控制特性，使得未做安全防护的面板对攻击者具备极高利用价值。
  • 该脚本会下载一个 Linux 二进制文件，校验其 SHA256 哈希值后在后台启动。NorForge 确认该二进制文件为 Poseidon 植入体，这是一款基于 Go 语言开发的远程访问木马，通常通过开源红队框架 Mythic 进行管理。
