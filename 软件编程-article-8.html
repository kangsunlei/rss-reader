Google 披露 Citrix 0Day 攻击，黑客植入 Web Shell 攻入企业内网

10/1/2026, 10:00:00 AM

📌 一句话摘要

Google 披露 Citrix NetScaler 两个高危 0Day 漏洞，攻击者利用内存溢出和输入验证漏洞注入 Web Shell 渗透企业内网。

📝 详细摘要

Google 报告 Citrix NetScaler（ADC 与 Gateway）存在两个 0Day 漏洞（CVE-2023-3516 和 CVE-2023-35190），CVSS 评分高达 9.5。攻击者利用这些漏洞绕过认证获取 root 权限，并部署名为 WHIPSHOT 和 SLAPSHOT 的恶意工具进行内网侦察和横向移动。官方已发布修复补丁，建议安全团队尽快更新并进行排查。

💡 主要观点

  1. 曝出两个高危 0Day 漏洞 漏洞包括 CVE-2023-3516（内存溢出）和 CVE-2023-35190（输入验证不当），CVSS 评分达 9.5。
  2. 攻击可获取 root 权限并持久化 攻击者通过漏洞绕过身份验证后获得 root 权限，并为 /bin/sh 设置 setuid 权限以确保低权限进程也能以高权限执行。
  3. 部署专用恶意工具链 攻击者利用了 WHIPSHOT（利用 Base64 隐藏在 HTTP Header）和 SLAPSHOT（Python 隧道程序）用于内网侦察、流量转发和横向移动。
  4. 边缘设备安全风险巨大 NetScaler 等边缘设备通常缺乏端点检测覆盖，但拥有敏感内网的直接访问权限，成为攻击的首选目标。

💬 文章金句

  • 攻击者利用这些漏洞绕过认证、获取 root 权限，并植入隐蔽 Web Shell。
  • 这类设备通常缺乏端点检测能力覆盖，却拥有敏感内网环境的直接访问权限。
  • 为了长期保留 root 访问权限，攻击者还会为 /bin/sh 设置 setuid 权限。
