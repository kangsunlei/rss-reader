WhatsApp 部署基于 Rust 的媒体解析器，为 30 亿台设备拦截恶意软件

2/12/2026, 10:24:00 AM

📌 一句话摘要

WhatsApp 已成功将其核心媒体解析库从 C++ 迁移到 Rust，覆盖 30 亿台设备，旨在消除内存安全漏洞。

📝 详细摘要

WhatsApp 工程团队完成了一项大规模迁移，将其 “wamedia” 库中 16 万行遗留的 C++ 代码替换为 9 万行内存安全的 Rust 代码。此次转型源于媒体类恶意软件的长期威胁，例如 2015 年的 Stagefright 漏洞。通过在包括 Android、iOS 和 Web 平台在内的数十亿台设备上部署该 Rust 解析器，WhatsApp 实现了迄今为止全球最大规模的客户端 Rust 部署之一，在显著缩减代码库规模的同时，有效消除了主要的内存相关安全漏洞。

💡 主要观点

  1. WhatsApp 将 16 万行 C++ 代码替换为 9 万行 Rust 代码。 此次重写在提供原生内存安全性的同时，显著降低了代码库的复杂性，展示了 Rust 在用更少代码处理复杂系统方面的高效性。
  2. 此次迁移的目标是消除内存安全漏洞。 通过弃用 C++，WhatsApp 降低了缓冲区溢出和悬空指针等风险，这些风险在历史上曾被隐藏在 MP4 等媒体文件中的恶意软件所利用。
  3. 这是全球最大规模的客户端 Rust 部署之一。 该库部署在包括移动端、桌面端和可穿戴设备在内的超过 30 亿台设备上，证明了 Rust 在大规模生产环境中的成熟度。
  4. 此举是对 Stagefright 遗留问题的战略性回应。 借鉴以往操作系统级的漏洞教训，WhatsApp 构建了自己的防御层，以便在不可信的媒体数据与敏感系统组件交互之前，对其进行安全的解析。

💬 文章金句

  • WhatsApp 工程团队使用 Rust 重写了其媒体处理库，将代码库从 16 万行 C++ 缩减至 9 万行，同时增加了内存安全保护。
  • 该库运行在数十亿台设备上……使其成为迄今为止最大规模的客户端 Rust 代码部署之一。
  • 公司意识到这些代码正在处理来自潜在敌对源的不可信数据，这使其成为进行内存安全重写的必然目标。
