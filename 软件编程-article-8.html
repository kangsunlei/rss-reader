自制了个桌面小摆件:一条神龙实时显示 Claude Code 的额度和状态

7/5/2026, 11:19:17 AM

📌 一句话摘要

作者为解决每次查询 Claude Code 额度的麻烦，自制了一个基于 ESP32 的桌面摆件，通过 Go 桥接程序获取额度数据，并用神龙动画实时显示状态。

📝 详细摘要

文章介绍了一个开源的桌面摆件项目，用于实时显示 Claude Code 的剩余额度和状态。作者因每次需手动敲命令或翻网页查看额度而感到不便，于是用 ESP32-S3 开发板、2.8 寸触摸屏和 LovyanGFX 固件制作了一个神龙主题的显示设备。摆件通过 USB 串口连接 PC 上的 Go 桥接程序，该程序读取 Claude 的登录 token 并从 API 获取额度数据，同时通过蓝牙协议获取会话状态。神龙会根据连接、空闲、运行任务或权限等待等状态变化表情，还显示 5 小时和 7 天窗口的额度和倒计时。项目完全开源，附有 GitHub 仓库链接和实物图片。

💡 主要观点

  1. 制作了一个神龙主题桌面摆件，实时显示 Claude Code 额度和状态。 通过神龙表情和龙珠动画直观呈现空闲、运行、等待权限等状态，解决了频繁查询额度的痛点。
  2. 方案包括 PC 端 Go 桥接程序与硬件固件两部分。 Go 程序读取 Claude 订阅 token，调用 /api/oauth/usage 获取额度并通过 USB 串口推送；硬件基于 ESP32-S3 和 2.8 寸 LCD，使用 PlatformIO + Arduino + LovyanGFX 开发。
  3. 会话状态通过 Claude 桌面端的蓝牙 Hardware Buddy 协议获取。 使用 Nordic UART 服务和配对加密通信，实时获取运行中和等待的会话数量。
