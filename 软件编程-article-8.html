Cloudflare 与 Coinbase 合作成立 x402 基金会，推动 x402 交易

9/23/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 和 Coinbase 启动 x402 基金会，旨在标准化机器对机器支付。此举通过 x402 协议，并集成 Cloudflare 的软件开发工具包，同时提出延迟支付方案。

📝 详细摘要

本文宣布 Cloudflare 和 Coinbase 建立战略合作伙伴关系，成立 x402 基金会，旨在推广和标准化用于机器对机器交易的 x402 协议。传统 Web 支付主要面向人机交互，缺乏对机器间交易的支持，x402 协议的出现填补了这一空白。x402 作为一个开放协议，使自动化客户端和服务器能够通过 HTTP 直接交换价值，而无需传统账户或订阅。文章详细介绍了核心 x402 交易流程，展示了如何通过编程访问数字资源，并为 AI 代理解锁新的货币化模型，例如按浏览器渲染会话付费或按实时数据馈送付费。Cloudflare 进一步提出了一种创新的 x402 延迟支付方案，专门为需要延迟结算或汇总计费的代理支付量身定制，例如 Cloudflare 的“按爬网付费”服务。该方案允许将意图的加密证明与金融结算分离，同时支持传统支付渠道和稳定币。文章重点介绍了 Cloudflare 的实际集成，包括在代理 SDK 和模型上下文协议 (MCP) 中对 x402 的支持。同时，Cloudflare 还为开发者提供了一个交互式 Playground，方便他们体验 x402 服务。

💡 主要观点

  1. x402 协议为机器对机器支付建立了一个开放标准，从而实现了数字服务之间的直接价值交换。 该协议解决了自动化交易的需求，允许客户端和服务器以编程方式协商资源支付，从而超越传统以人机交互为主的 Web 支付系统。
  2. Cloudflare 引入了一种 x402 延迟支付方案，为代理和自动化交易提供灵活的结算选项。 这种新方案支持延迟和汇总支付，将加密承诺与金融结算分离，尤其适用于 Web 爬虫和订阅模式等用例。
  3. Cloudflare 的代理 SDK 和 MCP 集成提供了即时工具，供开发人员实施支持 x402 的服务和应用程序。 开发者可以利用这些软件开发工具包和交互式 Playground 构建并测试相关应用，实现数字资源货币化，促进 AI 代理交互。

💬 文章金句

  • x402 为开发者提供了一个清晰、开放的协议，支持网站和自动化代理在全球范围内进行支付协商。
  • 实现了能够解析 x402 协议的客户端与服务器之间无需账户、订阅或 API 密钥即可完成交易。
  • 为了解决这些类型的支付场景，我们正在为 x402 协议提出一种新的延迟支付方案。
  • 这创建了一个灵活的框架，可以在其中立即建立加密信任，而金融结算可以使用传统的支付渠道或稳定币。
  • 运行代码是将开放约定从理论转化为真正有用的东西，并最终转化为公认的标准。
