NadMesh 僵尸网络利用 Shodan 劫持暴露的 AI 与 MCP 基础设施

7/19/2026, 10:00:00 AM

📌 一句话摘要

NadMesh 僵尸网络利用 Shodan API 自动化侦察暴露的 AI 服务，通过超过 20 种漏洞利用向量感染基础设施，并窃取高价值的 AI 凭证与模型令牌。

📝 详细摘要

文章详细分析了 NadMesh 僵尸网络的技术细节，该网络自 2026 年 7 月初以来利用 Shodan API 自动化侦察暴露的 AI 服务（如 ComfyUI、Ollama、n8n），将获取的 IP 注入扫描队列。它采用 5 阶段工业化攻击链，包括集中控制、多态二进制构建和主动投递，针对 Kubernetes、Docker API、Redis 和遗留系统等超过 20 个向量。恶意软件窃取 AWS 密钥、Kubernetes 令牌和 AI 模型令牌，并使用 Garble 混淆和蜜罐规避来逃避检测。

💡 主要观点

  1. 利用 Shodan API 优先扫描暴露的 AI 服务。 ai_harvest.py 脚本定位 ComfyUI、Ollama 等特定端口，将 IP 注入扫描队列，避免在无效地址空间上浪费带宽。
  2. 采用 5 阶段工业化攻击链与 Web 管理面板。 包含情报收集、集中控制、任务供给、二进制构建与投递，具备转化漏斗分析等企业级功能，远超传统恶意代码特征。
  3. 窃取高价值 AI 凭证与内部工具配置。 提取 AWS 密钥、Bedrock 凭证、Kubernetes 令牌及本地 AI 模型令牌，威胁情报价值高于被攻陷的计算资源本身。

💬 文章金句

  • NadMesh 将自主扫描、超过 20 种独特漏洞利用向量以及基于 Shodan 的情报收集整合成一个闭环系统，其运营者称之为'n4d mesh 控制器'。
  • 一旦发现暴露的服务，恶意软件会自动将获取的 IP 地址以最高优先级注入其扫描队列。
  • 所有恢复的数据都被传回一个中央仪表盘，该仪表盘跟踪汇总的证书数量、活跃的 MCP 漏洞以及可逃逸的 Docker 主机------对于运营者而言，这些威胁情报比被攻陷的计算资源本身更具价值。
