Home Assistant + Grafana：打造你的专属太阳能监控看板

4/17/2025, 2:10:50 PM

📌 一句话摘要

本文指导如何利用 Home Assistant、InfluxDB 和 Grafana 搭建安全、公开的太阳能监控仪表盘。

📝 详细摘要

本文提供详细的分步教程，指导安装配置 InfluxDB（包括数据库和用户创建），以及配置 Home Assistant 向 InfluxDB 发送数据。随后介绍 Grafana 的安装配置及其与 InfluxDB 数据源的连接。本文包含 Grafana 仪表板 JSON 文件，用于快速设置。强调安全措施，通过创建新管理员并移除默认账户，保障 Grafana 实例安全。用户据此可轻松监控并公开展示太阳能发电及消耗数据。

💡 主要观点

  1. 使用 InfluxDB 存储由 Home Assistant 收集的太阳能数据，用于长期监控和分析。 InfluxDB 是一个时间序列数据库，非常适合存储和查询时间序列数据，有效地管理来自太阳能逆变器的连续数据流。
  2. 使用 Grafana 可视化来自 InfluxDB 的数据，以创建一个直观的太阳能监控仪表板。 Grafana 提供了各种图表和面板选项，用于自定义仪表板以清晰地显示太阳能系统指标。
  3. 实施安全措施以保护 Grafana 实例免受未经授权的访问。 适当的安全配置，例如创建新的管理员用户和禁用默认帐户，对于防止未经授权的访问和潜在漏洞至关重要。
  4. 使用 Cloudflare Tunnel 启用对仪表板的远程公共访问，以便轻松共享。 Cloudflare Tunnel 提供了一种安全的方式，可以将本地服务暴露给公共互联网，而无需复杂的端口转发和防火墙配置。
