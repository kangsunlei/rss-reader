MongoDB Atlas 和 Cloud Manager 导航系统全新升级

4/8/2025, 2:12:57 PM

📌 一句话摘要

MongoDB Atlas 和 Cloud Manager 更新导航，通过更高效地访问服务和工具，改善工作流程并提升用户体验。

📝 详细摘要

MongoDB Atlas 和 Cloud Manager 经历了一次重要的用户体验更新，重新设计了导航以简化工作流程，使用户能够更直观地访问常用服务并更高效地完成任务。新的导航设计在 Atlas 和 Cloud Manager 平台之间提供了一致的体验，包括：更清晰的资源上下文、一个集中的实用工具中心（包括告警、账单、帮助和身份管理），以及简化的左侧导航。此更新基于用户反馈，旨在简化工作流程。Atlas 更新现已上线，Cloud Manager 更新将于 2025 年 5 月 12 日当周开始。

💡 主要观点

  1. 以新工作流程为中心的架构通过引导开发人员完成深入的工作流程，从而保持开发人员的“沉浸式体验”。 新的导航优先考虑平台服务，根据用户的工作流程突出显示它们，使开发人员可以更轻松地专注于当前任务最相关的工具，从而更有效地工作并更快地创新。
  2. 简化的左侧导航现在分为四个类别：数据库、数据、服务和安全。 这些类别充当不同的容器，将 Atlas 的功能分组以反映开发人员需要在 Atlas 中执行的任务。这种新结构使导航 Atlas 更加容易，帮助开发人员更快地找到合适的工具。
  3. 顶部导航栏中的资源导航器确保开发人员始终知道他们正在处理哪个资源。 资源导航器清晰地显示了用户在 Cloud Manager 中正在处理的资源，无论是项目还是组织。用户可以更简单地在资源之间切换，并且随着用户更深入地浏览 Atlas，上下文清晰度也得到了提高。

💬 文章金句

  • 新架构简洁直观。它通过引导开发人员完成深入的工作流程，从而保持开发人员的“沉浸式体验”。
  • 新的导航设计在 Atlas 和 Cloud Manager 平台之间提供了一致的体验。
  • 告警、账单、帮助和身份管理 (IAM，Identity and Access Management) 等基本实用工具集中在右上角的一个位置。
