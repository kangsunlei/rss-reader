谷歌 Apigee 添加了内置的 LLM 治理 Model Armor

7/29/2025, 7:01:00 AM

📌 一句话摘要

谷歌云推出 Model Armor，将原生大语言模型（LLM）治理框架集成到 Apigee API 管理平台，旨在增强 LLM 应用的安全性与可控性。

📝 详细摘要

文章详细介绍了谷歌云新推出的 Model Armor 公开预览版，这是一个直接集成到 Apigee API 管理平台的 LLM 治理框架。Model Armor 通过在 Apigee 代理层运行，利用声明性策略实现提示验证、输出过滤和 token 级控制，有效应对提示注入、越狱尝试和个人身份信息（PII）暴露等 LLM 特有风险。它支持多 LLM 提供商（如 Vertex AI、OpenAI、Anthropic）并与 Google Kubernetes Engine (GKE) 和 Security Command Center 集成，提供集中式治理、监控和预警。该框架旨在简化企业对 LLM 流量的安全管理，使其能像对待传统 API 一样严格，无需修改下游系统。

💡 主要观点

  1. Model Armor 将 LLM 治理原生集成到 Apigee API 管理平台 通过在 API 代理层直接执行 LLM 特定策略，简化了企业对 LLM 流量的安全管理，无需额外中间件或修改后端系统。
  2. 有效应对 LLM 特定安全风险，如提示注入和敏感数据暴露 Model Armor 提供即开即用的策略执行，可在请求和响应层面检测并阻止越狱、注入攻击和 PII 泄露，提升 LLM 应用的安全性。
  3. 支持多 LLM 提供商并与谷歌云安全生态深度集成 兼容多种主流 LLM，并与 GKE 和 Security Command Center 协同工作，实现集中化策略部署、监控和违规行为预警，增强了异构架构下的可控性。

💬 文章金句

  • Model Armor，它引入了针对 LLM 特定策略的即开即用执行，例如提示验证、输出过滤和 API 层的 token 级控制。
  • 有了 Model Armor，企业可以像对待传统 API 一样严格地对 LLM 流量进行同样的治理。
  • Model Armor 支持多个 LLM 提供商，包括 Vertex AI（Gemini、Meta Llama）、OpenAI、Anthropic 和自托管模型，允许在异构架构中进行集中治理。
  • 虽然其他 API 网关也提供了通用流量控制，但它们通常需要自定义中间件来实现模型级安全。Model Armor 旨在通过在 Apigee 中提供原生的 LLM 特定策略执行来消除这种复杂性。
