📌 一句话摘要

本文介绍开源项目 claude-obsidian，它结合 Claude Code 与 Obsidian，让 AI 自动整理笔记、建立知识图谱、检测矛盾，实现具备知识复利的第二大脑。

📝 详细摘要

文章以 Karpathy 的「LLM Wiki」理念为引，详细推荐开源项目 claude-obsidian。该项目能自动将网页、PDF、代码、视频笔记等转化为 Markdown 知识图谱，支持自动实体/概念/来源页创建、双向链接、矛盾检测、会话记忆和 8 类健康检查。作者给出了两种安装方式，并演示了日常使用流程（丢资料、提问、健康检查、可视化、跨项目复用），强调其本地、纯文本、无锁定的特点。文章最后附有项目地址、作者博客及 Karpathy 原始 gist 链接。

💡 主要观点

  1. claude-obsidian 将 Claude Code 与 Obsidian 深度融合，实现 AI 驱动的自动化知识管理。 项目遵循 Karpathy「LLM Wiki」理念：把资料丢进去，模型自动阅读、抽概念、建链接，形成互联的知识网络，回答时引用整理过的笔记而非训练数据。
  2. 核心功能涵盖自动整理、矛盾检测、会话记忆和健康检查，显著降低知识库维护成本。 自动创建实体页/概念页/来源页及双向引用；检测冲突论点并标注来源；每次会话结束更新 hot.md 保持上下文；lint 命令列出孤儿笔记、死链、过期信息等 8 类问题。
  3. 安装与使用门槛低，支持两种安装方式，并提供完整的开箱即用体验。 可通过 git clone 或 Claude Code plugin 安装，setup 脚本自动配置 Obsidian 图形视图和 CSS；日常通过 /wiki 命令初始化结构，之后用自然语言交互。
