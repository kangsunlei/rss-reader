Phoenix.new 发布远程 Agent 驱动的 Elixir 开发环境

6/22/2025, 12:00:00 AM

📌 一句话摘要

Phoenix.new 提供由全栈 AI Agent 驱动的浏览器原生的远程 Elixir 开发环境。

📝 详细摘要

本文介绍了 Phoenix.new，这是 Chris McCord 推出的一个新平台，它为 Elixir 应用提供基于云的临时开发环境，这些环境完全由 AI Agent 控制。它在 Fly.io 基础设施上启动临时的、隔离的虚拟机，提供一个完整的开发系统，包括 Shell 访问、浏览器预览和 GitHub 集成。一个关键特性是 Agent 能够利用 Phoenix 的实时功能（如 LiveView），允许它们在浏览器会话中与应用进行交互。Agent 可以执行广泛的任务，包括代码修改、依赖管理、测试、数据库交互以及生成全栈功能。虽然平台解决了潜在的厂商锁定问题，但其设计旨在与标准的 Phoenix 应用兼容。它被认为是迈向云原生、AI 辅助开发的重要一步。

💡 主要观点

  1. 提供远程、Agent 驱动的 Elixir 开发环境。 LLM Agent 对在临时虚拟机中运行的真实 Phoenix 应用拥有全栈控制权，可以在云端实现自动化编码、测试和迭代。
  2. 由 Phoenix 的创建者 Chris McCord 开发。 该平台由 Phoenix 框架的创建者构建，表明与生态系统有深入的集成和理解。
  3. 深度集成 Phoenix 的实时功能。 Agent 可以启动浏览器会话，并以程序化方式与 LiveView 组件交互，在开发过程中提供实时验证和反馈。
  4. Agent 能够进行全面的全栈开发。 Agent 可以执行从代码变更和依赖管理到数据库探索和生成完整功能（包括 WebSockets 和 Presence）的任务。

💬 文章金句

  • Chris McCord 发布了 Phoenix.new，这是一个浏览器原生的 Agent 平台，让大型语言模型能够对 Elixir 开发环境进行全栈控制。
  • Phoenix.new 允许用户直接在浏览器中启动 Elixir 项目。
  • 当 Agent 添加一个前端组件时，它不仅仅是检查编译是否成功——它会启动一个浏览器会话，加载应用，并以程序化方式与其交互。
  • 随着对 Elixir 之外的多种语言和框架的支持不断增强，Phoenix.new 有望成为云原生、AI 辅助开发的一个强大入口点。
