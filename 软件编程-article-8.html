如何一眼定位 SQL 的代码来源：一款 SQL 染色标记的简易 MyBatis 插件

3/24/2025, 12:47:58 PM

📌 一句话摘要

本文介绍了一款基于 MyBatis 插件的 SQL 染色方案，旨在解决 SQL 代码来源定位困难的问题，通过在 SQL 语句中添加注释标记，实现快速定位。

📝 详细摘要

本文针对后端研发和运维在日常工作中遇到的线上 SQL 定位排查难题，提出了一种基于 MyBatis 插件的 SQL 染色解决方案。该方案通过在 SQL 语句中添加包含 statementId 和 PFinderId 等信息的注释，实现对 SQL 语句的标记，从而能够快速定位 SQL 代码的来源，无需修改业务代码和 SQL 语句，**降低问题排查时间，提高开发效率**。该插件对 SQL 执行的性能影响很小，同时还支持自定义信息的染色，例如客户端的执行线程 id 等。文章详细介绍了该插件的实现原理、使用方法和效果，并提供了常见问题的解答，旨在为面临类似问题的开发者提供实践经验和参考。

💡 主要观点

  1. SQL 染色标记通过 MyBatis 插件实现业务零侵入 通过 MyBatis Plugin 机制对 SQL 进行染色增强，无需修改业务代码和 SQL，实现 SQL 的无感增强和自动染色，降低了维护成本。
  2. 使用 SQL statement id 唯一标识 SQL 采用 mapper namespace + SQL id 作为 SQL statement 的 id，可以唯一确定程序中的 SQL 在 mapper 文件中的位置，方便追溯调用来源和业务场景。
  3. SQL 注释方式的染色增强不影响 SQL 执行和指纹 将附加信息作为 SQL 注释，对 SQL 进行拼接改写，不影响 SQL 的执行正确性，也不会改写 SQL 指纹，有助于慢 SQL 排查和死锁日志分析。
