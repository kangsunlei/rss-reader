📝 详细摘要

本期 JavaScript 中文周刊第 190 期汇总了近期 JS 生态的关键进展和实用资源。热点包括基于 Rust 的高性能打包工具 Rolldown 正式支持 Vite，TC39 工作组推进 Array.fromAsync 等多个提案进入第 4 阶段，以及 Google WebStatus.dev 平台的重大更新。此外，还涵盖了 React Native、SQLite-JS 等领域的快讯。文章和视频部分推荐了 JavaScript 开发者学习 Go 语言的指南、`document.currentScript` API 的使用技巧、Svelte Summit 大会视频、使用可选链优化代码、React 服务器组件导入机制等。代码与工具方面，介绍了在 Node.js 中集成 PHP 的 php-node 项目，Storybook 9 在测试方面的重大更新，以及自动化浏览器操作的命令行工具 Beachpatrol。文末列举了 Babel 8 Beta、ESLint v9.28.0 等多个重要项目的版本发布信息。

💡 主要观点

  1. Rolldown-Vite 发布，为 Vite 带来 Rust 高性能打包能力 基于 Rust 的 Rolldown 打包工具现已支持 Vite，旨在大幅提升构建速度，提供现有打包工具的直接替代方案。
  2. TC39 会议推进多项提案进入第 4 阶段 Array.fromAsync、Error.isError 和显式资源管理等重要 JavaScript 语言提案已接近最终标准，影响未来 JS 开发。
  3. Storybook 9 发布，重点加强 UI 组件测试能力 流行的 UI 组件开发和测试工具迎来重大更新，Storybook Test 提供交互、视觉和可访问性测试，并支持监视模式。
  4. Babel 8 Beta 版本发布，主要破坏性变更已完成 JavaScript 编译器 Babel 经过两年开发，其主要升级内容已在 Beta 版本中完成，预示正式版临近。

💬 文章金句

  • Rolldown 是一个基于 Rust 的高性能 JavaScript 打包工具，旨在为同样高性能的 Vite 构建工具提供支持，现在这个目标已经实现。
  • Array.fromAsync、Error.isError 和显式资源管理等提案都进入了第 4 阶段，此外还有其他进展。
  • 这个用于开发和测试前端 UI 组件的流行工具在**测试方面** 迎来重大更新。
  • 我们计划在 Babel 8 中包含的所有破坏性变更都已完成。
