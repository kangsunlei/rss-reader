📝 详细摘要

文章介绍了智谱新发布的 AutoGLM 沉思模型，该模型是首个集深度研究能力和网页操作能力于一体的 Agent，不仅具备深度研究能力还能实际操作，能自主完成任务甚至赚钱。通过模拟人类思考方式，AutoGLM 沉思能够进行多轮“灵魂拷问”，自主搜索信息、筛选条件，最终确定最佳行动方案。智谱还开源了推理模型 GLM-Z1-Air，其推理速度是 R1 的 8 倍，价格仅为 1/30。智谱 CEO 张鹏提出 Agent 也存在 Scaling Law，并通过 WebRL 算法框架提升 Agent 性能。AutoGLM 系列模型在智能体基准评测 AgentBench 上取得了 SOTA 成绩，AutoGLM 的动手能力全面领先。智谱将继续专注于 Agentic GLM 的研发，并预计 2025 年将是 Agent 应用元年。

💡 主要观点

  1. AutoGLM 沉思模型具备深度研究和操作能力 该模型能够模拟人类思考，自主完成复杂任务，并通过实际案例证明其在智能体领域的应用潜力。
  2. 智谱提出 Agent 也存在 Scaling Law 通过扩展训练时的 inference compute，Agent 展现出更强的性能，并通过 WebRL 算法框架提升 Agent 性能。
  3. AutoGLM 系列模型在 AgentBench 上取得 SOTA 成绩 表明其在 GUI 智能体领域具有领先地位，特别是在 Phone Use 和 Browser Use 基准上超越了其他模型。
  4. AutoGLM 沉思背后的模型是全新推出的 Agent 大脑——沉思模型 该模型通过强化学习，让模型学会自我批评、反思、甚至沉思，并通过更长的深度思考时间换取更优的效果。
