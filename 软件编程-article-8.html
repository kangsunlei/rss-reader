JetBrains .NET 工具更新预告 | .NET 工具博客

7/25/2025, 1:02:34 PM

📌 一句话摘要

JetBrains 宣布将于 2025.2 和 2025.3 版本中对其 .NET 工具进行更新，精简功能并移除低使用率特性，此举基于用户反馈和使用数据。

📝 详细摘要

本文详细介绍了 JetBrains 计划于 2025.2 和 2025.3 版本中发布的 .NET 工具的重大更新。 这些调整基于广泛的用户反馈和使用数据分析，旨在简化产品，并将开发工作重点放在核心功能上，以期为现代 .NET 开发者提供最大价值。 2025.2 版本的主要变更包括简化独立的 dotCover，提供现代化的命令行运行器和简化的配置，同时停止支持不常用的过滤选项和过时的应用类型。 值得注意的是，Rider 2025.2 将停止对 Mono 和 Unity 项目的代码覆盖率支持，在 Unity 迁移到 CoreCLR 后，可能会恢复对 Unity 的支持。 此外，Visual Studio 的 TeamCity 扩展也将停止使用。 对于 2025.3 版本，Rider 中的动态程序分析 (DPA) 将不再是一个单独的工具，而是集成到 *监控* 工具中，该工具在 dotUltimate 商业许可下可用。 JetBrains 强调其致力于协助用户完成这些过渡，并邀请进一步的反馈，以塑造 dotUltimate 套件的未来路线图。

💡 主要观点

  1. JetBrains 正在通过整合和移除基于用户数据的低使用率功能来精简 .NET 工具。 这一战略决策旨在提高关键领域的性能和稳定性，确保将开发资源导向为大多数用户提供最重要价值的功能。
  2. Rider 中对 Mono / Unity 代码覆盖率和 Visual Studio 的 TeamCity 扩展等特定功能的支持将被移除。 由于使用率低和维护成本高，删除这些功能使 JetBrains 能够减少技术债务并更有效地分配资源，但这可能会影响特定的用户工作流程。
  3. 动态程序分析 (DPA) 将在 dotUltimate 商业许可下集成到 Rider 的监控工具中。 这种集成旨在在 Rider 中提供更统一和强大的性能分析体验，整合工具并将许可与更广泛的 dotUltimate 套件对齐。

💬 文章金句

  • 我们相信这些改变将使我们能够为每个人构建更好的工具。
  • 分析结果表明：虽然多年来我们构建了许多强大的功能，但有些功能未得到充分利用，而另一些功能则具有我们尚未完全实现的巨大潜力。
  • 这些更改显著减少了开销，并使我们的团队能够专注于对现代 .NET 开发工作流程最重要的核心覆盖场景。
  • 我们计划在 Unity 迁移到 CoreCLR 后（预计在 Unity 7 LTS 之后）恢复对 Unity 项目的覆盖率分析。
  • 这些更改将帮助我们释放大量的开发能力，并将其导向对我们的用户最重要的改进。
