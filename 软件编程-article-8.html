Docker Desktop 4.42 发布，带来原生 IPv6、集成的 MCP 工具包以及 AI 模型打包功能

7/15/2025, 8:46:00 AM

📌 一句话摘要

Docker Desktop 4.42 增强了网络灵活性、AI 工作流集成和模型分发功能，但发布初期在 macOS 上存在显著稳定性问题。

📝 详细摘要

Docker 公司发布了 Docker Desktop 4.42 版本，此版本重点增强了网络灵活性、AI 工作流集成和模型分发能力。新版本原生支持 IPv6，允许用户灵活配置网络模式，并集成了模型、客户端、协议（MCP）工具包，简化了对 GitHub、MongoDB 等多种 MCP 服务器的管理，同时提供了新的 Docker MCP CLI 命令以支持自动化工作流。在 AI 工作流方面，Model Runner 扩展了对高通 Windows 设备的支持，并引入了 `docker model package CLI` 命令，使开发者能将 GGUF 格式的 AI 模型打包成符合 OCI 标准的镜像，便于安全分发到 Docker Hub 或私有注册表。然而，文章也详细指出了该版本发布初期在 macOS 用户中报告的显著稳定性问题，包括容器无响应、网络错误和启动失败等，这些问题一度严重影响了用户体验。文章结尾提及 Docker 团队已基本解决这些错误，旨在恢复用户信心。

💡 主要观点

  1. Docker Desktop 4.42 提升了网络灵活性和 AI 工作流集成。 新版本新增原生 IPv6 支持增强了网络适应性，同时集成 MCP 工具包和 AI 模型打包功能，简化了开发者的 AI 应用构建与分发。
  2. MCP 工具包集成简化了服务器管理和 DevOps 自动化。 用户无需额外安装即可管理多种服务器，并通过新的 CLI 命令实现自动化工作流，结合 AI 助手 Gordon 提升了交互效率。
  3. AI 助手 Gordon 与 MCP 集成，提升了 DevOps 交互效率和故障排除能力。 Docker 的 AI 助手 Gordon 直接与 MCP 集成，允许开发者使用自然语言或命令驱动的提示与服务交互，简化了 DevOps 设置和基础设施故障排除。
  4. 新版本提供了将 AI 模型打包为 OCI 镜像的能力，便于分发和管理。 开发者可将 GGUF 格式的 AI 模型打包成可重复使用的 OCI 镜像，实现模型在不同环境间的安全分发和可移植性。
  5. Docker Desktop 4.42 在 macOS 上初期面临显著稳定性问题。 许多 macOS 用户报告了容器无响应、网络错误和无法启动等问题，影响了用户体验，虽然后续声称已解决，但值得关注。

💬 文章金句

  • 该版本增强了网络灵活性、AI 工作流集成和模型分发功能。
  • 原生 IPv6 支持现在允许用户在双栈、仅 IPv4 或仅 IPv6 模式之间进行选择，并具有智能 DNS 解析。
  • 开发人员现在可以使用新的 docker model package CLI 命令将 GGUF 格式的 AI 模型 打包成 符合 OCI 的镜像，以安全分发到 Docker Hub 或私有注册表。
  • 自 Docker Desktop 4.42 发布以来，许多 macOS 用户报告称其稳定性显著下降。
  • 这些错误似乎已经由 Docker 团队基本解决了，因此大多数新用户应该能够充分利用此次更新带来的好处，而无需面对许多此类难题。
