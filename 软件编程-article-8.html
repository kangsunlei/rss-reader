BugHunter：基于 Claude 及免费 AI 服务的漏洞赏金工具包

6/15/2026, 10:00:00 AM

📌 一句话摘要

本文介绍开源漏洞赏金工具包 BugHunter，其基于 Claude 并扩展支持免费 AI 服务，可自动化完成从子域名枚举到报告提交的全流程漏洞挖掘。

📝 详细摘要

文章详细介绍了由安全研究员 Shuvon Md Shariar Shanaz 开发的开源工具 BugHunter。该工具最初基于 Anthropic 的 Claude Code，现已升级为独立 CLI 工具，支持 Ollama、Groq、DeepSeek 等免费或低成本 AI 服务提供商，降低了独立研究者的使用门槛。文章阐述了其核心工作流，包括攻击面测绘、多类型漏洞测试、7 问题验证门确认和报告生成等命令。工具整合了约 35 种扫描工具，并具备跨会话记忆持久化、断点续传等高级功能。此外，BugHunter 还支持 Web3 智能合约审计和代币审计，覆盖重入攻击、闪电贷攻击等 10 类漏洞。文章最后介绍了其模块化 AI Agent 架构，以及作为 Claude Code 插件或独立 CLI 工具的多种部署方式。

💡 主要观点

  1. BugHunter 是一个全流程自动化的开源漏洞赏金工具包。 该工具覆盖从子域名枚举、存活主机发现到漏洞测试、验证和报告生成的所有阶段，仅需一条终端命令即可完成，显著提升了漏洞挖掘效率。
  2. 工具已扩展支持免费 AI 服务，降低了使用门槛。 除了 Claude，BugHunter 现已支持 Ollama（本地离线）、Groq（免费云服务）和 DeepSeek（低成本）等选项，使更多独立研究者能够使用 AI 辅助进行安全测试。
  3. 7 问题验证门机制用于过滤低价值发现。 在执行 validate 命令时，该机制通过一系列问题对发现进行确认，有效过滤重复或无效报告，避免研究人员浪费精力提交低质量漏洞。
  4. 工具具备跨会话记忆和断点续传功能。 BugHunter 将发现结果记录到 JSONL 存储系统中，使得在一个目标上发现的模式可用于新目标，并支持通过 bughunter pickup 命令恢复中断的扫描。
  5. BugHunter 提供专门的 Web3 安全审计能力。 工具包含智能合约审计模式，覆盖重入攻击、闪电贷攻击等 10 类漏洞，以及代币审计模块，用于扫描跑路指标、蜜罐检测等 Web3 项目风险。

💬 文章金句

  • AI 驱动全流程漏洞赏金，7 重验证精准猎杀 Web2/Web3 漏洞。
  • 该工具包支持多种部署方式：可作为 Claude Code 插件、独立 CLI 工具，或集成到 OpenCode、Pi Agent 和 Codex 等其他 Agent 框架中，是目前 GitHub 上功能最为全面的 AI 辅助漏洞赏金自动化开源解决方案之一。
