Google 发布 LMEval：一款开源跨平台 LLM 评测工具

5/31/2025, 12:00:00 AM

📌 一句话摘要

Google 发布 LMEval，一款用于跨平台评估大型语言模型（LLM）的开源工具。

📝 详细摘要

Google 推出了 LMEval，这是一个开源框架，旨在以准确、多模态和便捷的方式评估来自不同服务提供商的大型语言模型（LLM）。 随着 AI 模型快速发展，我们需要对模型进行快速可靠的评估，以确定其是否适用于特定应用。LMEval 应运而生。 其主要功能包括通过 LiteLLM 实现的跨平台兼容性、提高效率的增量评估、对文本、图像和代码的评估支持，以及加密的结果存储。 文章提供了一个 Python 代码示例，演示了如何设置和运行基准测试。 LMEval 已经被用于创建基准测试，例如用于安全性的 Phare LLM 基准测试，并与 Harbor Bench 和 EleutherAI 的 LM 评估工具等替代方案进行了比较。

💡 主要观点

  1. LMEval 能够使用统一 API 接口进行跨平台 LLM 评测。 通过与 LiteLLM 集成，LMEval 可以使用单一基准定义来评估来自不同服务提供商（OpenAI、Google、Azure 等）的模型，即使各家 LLM 服务的 API 存在差异。
  2. 该工具支持高效的增量基准测试执行。 智能引擎确保只有在模型、提示或问题发生变化时才运行必要的评估，从而提高频繁测试的速度。
  3. LMEval 支持多模态评估和安全的数据存储。 它可以评估文本、图像和代码的理解能力。评估数据和结果会被加密，以保护隐私并防止被搜索引擎抓取和收录。
  4. LMEval 包含一个可视化仪表盘，用于分析评估结果。 LMEvalboard 提供了一个用户界面，用于查看整体性能、分析单个模型以及直观地比较多个模型。

💬 文章金句

  • LMEval 旨在帮助 AI 研究人员和开发者比较不同大型语言模型（LLM）的性能。
  • LMEval 诞生的原因之一是新模型正被快速推出。
  • 为了支持多种 LLM 服务，至关重要的是，评估基准可以定义一次并在多个模型中重复使用，即使它们的 API 存在差异。
