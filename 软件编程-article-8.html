Cloudflare 开发者平台全面升级：更快、更强、更易用！

9/25/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 开发者平台迎来重大升级，Workers、AI 搜索、Containers 和 R2 性能与能力全面提升。

📝 详细摘要

本文详细介绍了 Cloudflare 开发者平台的最新增强，重点在于提高性能、扩展功能和简化开发者体验。主要更新包括显著增强 Cloudflare Workers 的 Node.js 兼容性，从而支持更多 Node.js API 和软件包的无缝运行。AI 搜索服务（原 AutoRAG）现已支持 OpenAI、Anthropic 等多模型，应用场景不再局限于 LLM 应用检索。远程绑定现已正式发布，支持本地开发直接连接生产环境资源。Cloudflare Containers 提供更大的实例类型和更高的并发限制，而 Workers Builds 现已正式发布，拥有更大的磁盘空间和 CPU 算力。R2 推出低频访问存储类别，以更经济的方式存储不常访问的数据，且免收出站流量费。媒体转换服务支持按需视频处理，浏览器渲染服务通过 Playwright 和 Stagehand 获得增强。这些新服务进一步拓展了平台能力。此外，Cloudflare 邮件服务和数据平台等新的构建模块，以及 UI 改进，旨在提供更加一致和强大的开发者环境。

💡 主要观点

  1. Cloudflare Workers 获得了显著的 Node.js 兼容性和增强的本地开发能力。 扩展了对 `node:fs`、`node:https` 等 Node.js API 和软件包的支持，并正式发布远程绑定，简化了生产环境资源的迁移与本地测试。
  2. AI 和数据服务通过多提供商支持和新的处理工具得到了显著扩展。 AI 搜索集成 OpenAI、Anthropic 等模型，媒体转换和 Cloudflare 数据平台为内容处理和分布式 SQL 查询提供强大支持。
  3. Containers、R2 和 Workers Builds 等平台基础设施服务获得了重大的性能和可扩展性升级。 Containers 和 Workers Builds 资源限制提升，R2 低频访问降低存储成本，浏览器渲染能力增强，助力开发者构建和扩展更复杂的应用。

💬 文章金句

  • 当您在 Cloudflare 上构建时，我们认为为您完成繁重的工作是我们的职责。
  • AI 搜索不再局限于 LLM 应用检索，而是提供快速、灵活的内容索引，赋能各类 AI 应用。
  • 通过这些更改，无论您来自何处，Workers 都将变得更加强大且更易于采用。
  • Playwright 支持正式发布，并同步至最新 v1.55 版本，为客户构建可靠、可扩展的应用提供生产级保障。
  • 与 R2 的所有服务一样，**免收出站流量费**，无需为数据传输支付额外带宽费用。
