📌 一句话摘要

小红书 hi lab 团队开源了中等规模 MoE 文本大模型 dots.llm1 及其预训练和指令微调检查点，性能媲美 Qwen2.5-72B。

📝 详细摘要

文章详细介绍了小红书 hi lab 团队首次开源的文本大模型 dots.llm1。这是一个参数总量 142B、激活参数 14B 的 MoE 模型。通过精心设计的数据处理流程，dots.llm1 在 11.2T 高质量数据上训练后，在综合指标上与 Qwen2.5-72B 模型持平。文章重点阐述了其预训练数据处理、训练效率优化（特别是 AlltoAll overlap 和 Grouped GEMM 改进）以及 MoE 模型设计与两阶段 Post-train 策略。hi lab 团队开源了 Base 模型、Instruct 模型及多个中间检查点，为社区提供了宝贵的研究资源。模型的开源地址已提供在 Hugging Face 和 GitHub 上。

💡 主要观点

  1. dots.llm1 是一个高性能中等规模 MoE 文本大模型 总参数 142B、激活参数 14B，在高质量数据和训练优化下，性能达到与大型模型 Qwen2.5-72B 相当的水平，实现了效率与效果的平衡。
  2. 开源了包含中间检查点在内的多个模型版本 除 Instruct 和 Base 模型外，还开源了预训练阶段不同 token 量的检查点，这为研究模型的学习动态和进行持续训练提供了独特资源。
  3. 精心设计的数据处理流程提升了模型训练效率和性能 结合 URL 过滤、规则处理、模型判别等方法，构建高质量预训练数据集，减少了所需训练 token 量，提高了模型效果。
  4. 通过多种优化技术提升了 MoE 模型的训练效率 采用了 interleaved 1F1B with A2A overlap 和优化的 Grouped GEMM 实现，有效降低了通信开销，提升了大规模 MoE 模型的训练速度。

💬 文章金句

  • dots.llm1 是一个大规模的 Mixture of Experts (MoE)语言模型，在总共 1420 亿参数中激活 140 亿参数
  • 为促进大模型社区的研究工作，hi lab 团队开源了 Pretrain 阶段每经过 1T token 的中间训练检查点和 Instruct 模型，为研究大语言模型的学习动态提供了宝贵的基础。
  • dots.llm1 在仅训练 11.2T token 的前提下，综合指标打平 Qwen2.5 72B 模型，大大减少了算力消耗。
  • 开源一系列 pretrain base 模型，包括预训练过程中每经过 1T tokens 后所保存的 checkpoint——是目前开源中间 checkpoint 模型中，首个参数超过千亿的大模型
