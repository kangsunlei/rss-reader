📌 一句话摘要

本文报道 Google 工程师 Justin Poehnelt 开发爆款 gws CLI 工具后遭解雇，硅谷公司竞相邀请，并分析事件背后大公司创新与文化矛盾：AI Agent 对商业模式的颠覆威胁。

📝 详细摘要

文章详细介绍了 Google DevRel 工程师 Justin Poehnelt 用 Rust 开发 gws（Google Workspace CLI）工具，该工具在 GitHub 获得 2.9 万 Star 并登顶 Hacker News。工具动态调用 Google API，面向 Agent 原生设计，内置 40 多个 Skills。在项目爆火后，Justin 被 Google 解雇，理由是其仓库使用 Google Logo 过于「官方」。讽刺的是，解雇两天后 Google 在 Cloud Next 2026 上宣布官方 Workspace CLI 路线图。Justin 认为真正原因是 AI Agent 对 Workspace 商业模式的威胁。事件曝光后，OpenClaw 创始人、OpenRouter CEO、Vercel CEO 等公开邀请他加入。文章还提到 Google Cloud AI 总监 Addy Osmani 也在同期离开 Google，引发联想。

💡 主要观点

  1. 员工开发官方未推出的工具并爆火，反而因知识产权和品牌合规问题被解雇。 该事件凸显大公司内部创新与合规流程的冲突，尤其是当员工产品接近公司商业化方向时的处理方式。
  2. 表面原因是品牌违规，深层原因是 AI Agent 对 Workspace 商业模式的颠覆威胁。 Justin 认为管理层真正害怕的是 AI Agent 让用户无需传统 Web 界面即可操作 Workspace，从而威胁现有订阅收入。
  3. 事件引发硅谷公司「抢人」，形成鲜明对比。 Vercel、OpenRouter 等公司公开邀请，显示行业对创新执行力的高度渴求和开放文化。

💬 文章金句

  • 我认为，Workspace 部门以及部分管理层、部分项目真正害怕的是被颠覆。但他们害怕的并不是我的 CLI，而是 AI Agent 将会给 Workspace 带来的变化。
  • Google 因为他开发了 Google Workspace CLI 而开除了他。幸运的是，Google 开除不了我。
