📝 详细摘要

Mole 1.32， the popular open-source Mac cleaning utility boasting 44.3K stars， has been released. This update prioritizes performance optimization， featuring faster scanning with parallel cache discovery. Notable enhancements include improved cleanup for macOS system files and emulators (PCSX2， RPCS3)， more accurate disk capacity reporting， and a seamless installation experience. The developer is actively seeking community suggestions for further cleanup targets.
