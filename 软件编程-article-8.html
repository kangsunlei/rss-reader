代码模式：一种更优的 MCP 使用方法

9/26/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 推出代码模式，利用 LLM 编写 TypeScript 代码与 MCP 工具交互，显著提升了智能代理的性能和效率。

📝 详细摘要

本文介绍了 Cloudflare 的创新方法“代码模式”，旨在增强大型语言模型 (LLM) 通过模型上下文协议 (MCP) 与外部工具交互的方式。该方法解决了传统“函数调用”的局限性，即 LLM 在工具交互方面受限于合成训练数据。Cloudflare 的解决方案是将 MCP 工具转换为 TypeScript API，然后指示 LLM *编写代码*来调用这些 API。这充分利用了 LLM 卓越的代码生成能力，这些能力是在大量真实代码的基础上训练出来的。“代码模式”使代理能够处理更多、更复杂的工具，并更有效地链接多个调用，从而减少令牌浪费。该技术实现的底层是 Cloudflare 的轻量级 V8 隔离区，用于安全、沙箱化的代码执行，并由新的 Worker Loader API 促进动态隔离区配置。这种架构还通过防止基于绑定的资源访问泄露 API 密钥来增强安全性。

💡 主要观点

  1. LLM 擅长代码编写，显著提升工具交互。 通过让 LLM 编写 TypeScript 代码来调用 MCP 工具，“代码模式”利用了它们强大的代码生成能力，克服了基于合成数据的直接工具调用的局限性。
  2. 该方法提高了复杂代理工作流程和链式调用的效率。 生成代码允许 LLM 直接链接多个工具调用，绕过中间 LLM 处理，并减少多步骤任务的令牌浪费。
  3. Cloudflare 的 V8 隔离区提供了一个安全、高性能的执行环境。 该解决方案利用 Cloudflare Workers 中轻量级、可一次性使用的 V8 隔离区，用于快速安全地执行 LLM 生成的代码，与容器相比具有更高的效率。
  4. 通过 MCP 和基于绑定的访问，保持了统一性和安全性。 MCP 标准化了 API 发现，而 Workers 的绑定提供了安全、无 API 密钥的工具访问，防止密钥泄露并简化了授权。

💬 文章金句

  • 简而言之，LLM 更擅长编写代码来调用 MCP，而不是直接调用 MCP。
  • 让 LLM 通过工具调用执行任务，就像让莎士比亚临时抱佛脚学了一个月中文，然后用中文写剧本一样。这很难发挥出他的最佳水平。
  • MCP 提供了一种连接和了解 API 的统一方式。
  • 隔离区比容器轻得多。一个隔离区可以在几毫秒内启动，仅使用几兆字节的内存。
  • 绑定的另一个好处是它们隐藏了 API 密钥。绑定本身提供了对 MCP 服务器的已授权客户端界面。
