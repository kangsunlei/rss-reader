GitHub Copilot 现已支持 GPT-5 公开预览，多款 IDEs (集成开发环境) 可用

8/19/2025, 3:55:05 PM

📌 一句话摘要

GitHub 宣布 GPT-5 现已在 GitHub Copilot 中面向多个 IDEs (集成开发环境) 推出公开预览版，大幅提升 AI 编码辅助能力。

📝 详细摘要

GitHub 发布推文，宣布对 GitHub Copilot 进行重大升级，集成了 OpenAI 的 GPT-5 模型。这项先进的 AI 功能现已进入公开预览阶段，可在各种集成开发环境 (IDEs) 中使用，包括 Visual Studio、JetBrains IDEs、Xcode 和 Eclipse，正如链接的更新日志所示。本次集成旨在为开发者提供更强大的代码生成、代码补全和辅助功能，标志着 AI 驱动的软件开发工具取得了显著进步。
