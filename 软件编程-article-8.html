重磅！淘天联合爱橙开源强化学习训练框架 ROLL，高效支持十亿到千亿参数大模型训练

6/25/2025, 4:54:00 AM

📌 一句话摘要

淘天与爱橙开源了面向大规模语言模型的高效强化学习训练框架 ROLL，支持十亿至千亿参数模型。

📝 详细摘要

本文介绍了淘天集团与爱橙科技联合开源的强化学习训练框架 ROLL，旨在解决大规模语言模型（LLM）后训练阶段强化学习（RL）面临的效率、可扩展性和易用性挑战。ROLL 框架采用单控制器与并行工作器架构，引入优化策略和数据传输模块，提供 Rollout 调度器进行样本生命周期管理，并支持多任务、智能体强化学习、多种 RL 算法及主流训推引擎。框架具备弹性资源调度与分布式并行能力，支持从单机到千卡集群，通过 AutoDeviceMapping 实现资源优化分配。实验结果表明，ROLL 在不同任务和模型上显著提升了 LLM 性能和训练效率，并展现了良好的稳健性和实用性。项目已在 GitHub 开源，并持续迭代。

💡 主要观点

  1. ROLL 框架专为大规模 LLM 强化学习训练设计 框架旨在解决现有 RL 系统在大模型训练中的效率、可扩展性和易用性痛点，支持十亿到千亿参数模型的高效稳定训练。
  2. 采用创新架构和调度机制提升训练效率 通过单控制器与并行工作器、优化的数据传输、Rollout 调度器和 AutoDeviceMapping 等，实现了灵活模块化、高效调度和资源优化。
  3. 具备多任务、智能体 RL 支持及广泛兼容性 内置丰富 RL 任务和 Agentic RL 支持，兼容 vLLM、DeepSpeed 等主流引擎，提供灵活配置，满足多样化应用和研究需求。

💬 文章金句

  • ROLL 以用户体验为核心设计理念，专为「高效・可扩展・易用」而打造，彻底打通从小模型到 600B+ 超大模型的 RL 训练落地路径。
  • ROLL 在诸如人类偏好对齐、复杂推理和多轮自主交互场景等关键领域显著提升了大语言模型的性能，同时具备超高的训练效率。
  • ROLL 是一款面向用户友好设计的强化学习框架。具体来说，ROLL 从一开始就考虑了三类用户诉求，即：技术先驱者、产品开发者和算法研究者。
  • 基于 Ray 的多角色分布式架构，灵活资源分配，训练无缝支持 MegatronCore 5D （DP / TP / PP / CP / EP）并行高效利用异构硬件，从单机到千卡集群均能轻松运行。
  • 样本级 Rollout 生命周期调度机制，支持异步奖励计算、动态采样、按样本裁剪与 EarlyStopping，显著提升训练效率与资源利用率。
