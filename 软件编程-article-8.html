EffectCraft：基于 Rust 开发的开源 After Effects 替代品

10/8/2026, 1:30:13 PM

📌 一句话摘要

EffectCraft 是一款用 Rust 编写的开源动效软件，复刻 AE 界面与功能，内置 MCP 服务以支持 AI Agent 自动化关键帧与渲染。

📝 详细摘要

EffectCraft 旨在解决轻量级动效需求下购买 Adobe After Effects 订阅的高成本问题。它使用 Rust 从头编写，高度还原 AE 的面板布局、快捷键及核心功能（如图层、关键帧、3D 摄像机等），并包含 306 种特效，覆盖 AE 绝大多数自带特效。其独特之处在于不依赖 FFmpeg 即可实现多种格式导出，并原生支持 Lottie 导入导出。此外，它集成了 MCP 协议，允许 Claude Code 等 AI 助手直接调用菜单操作，实现自动打关键帧和渲染，体现了“AI 驱动的传统软件现代化”思路。

💡 主要观点

  1. 高性能与自主可控的技术栈 采用 Rust 语言重写核心引擎，摆脱了对 FFmpeg 的依赖，自行实现编码器，提升了软件的稳定性和跨平台兼容性（macOS/Windows/Linux）。
  2. 低迁移成本的设计哲学 严格遵循 After Effects 的用户习惯（面板、快捷键、逻辑），使得熟悉 AE 的专业人士可以无缝切换，降低了学习曲线。
  3. 面向未来的 AI 集成能力 通过暴露 MCP 接口，使 AI Agent 能够像人类一样操作软件（设置关键帧、触发渲染），为自动化视频生产提供了新的基础设施可能。

💬 文章金句

  • 每个菜单操作都能被 Agent 调用，自带 MCP 服务，让 Claude Code 帮忙打关键帧、渲染成片也行。
