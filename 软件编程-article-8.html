📝 详细摘要

文章报道了 DeepSeek-V4 模型的发布，强调其拥有 100 万 token 的超长上下文，并在 Agent 能力、世界知识和推理性能上取得重大突破。文章核心介绍了 DeepSeek-V4 采用的混合注意力机制（Hybrid Attention），包括 CSA（稀疏压缩注意力）和 HCA（超级压缩注意力）两部分，该架构通过 token 维度压缩大幅降低了长文本场景中的注意力计算成本，使百万 token 上下文成为可能。文章还引用了官方评测数据，显示 V4 在 Agent 编码、世界知识等任务上已接近或超越部分顶级闭源模型。作者表示将在未来三个月内对架构细节进行深入分析，并鼓励读者直接体验或查阅原版技术论文。

💡 主要观点

  1. DeepSeek-V4 拥有 100 万 token 的超长上下文，并在多项评测中表现优异。 模型在 Agent 编码、世界知识、数学和竞赛代码等任务上，性能已接近或超越部分顶级闭源模型，如 Sonnet 4.5 和 Gemini-Pro-3.1。
  2. 混合注意力机制是 V4 实现超长上下文的关键架构创新。 该机制由 CSA（稀疏压缩注意力）和 HCA（超级压缩注意力）组成，通过压缩 KV 缓存来降低计算成本，使百万 token 上下文在实践中成为可能。
  3. 文章是对官方发布信息的初步解读，缺乏深度技术分析。 作者主要引用了官方数据和架构图，并承诺未来三个月内进行深入分析，当前内容以信息转述和趋势判断为主。
