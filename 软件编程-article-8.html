社区推荐重排技术：双阶段框架的实践与演进｜得物技术

📌 一句话摘要

本文深入探讨了得物社区推荐重排架构从启发式规则向生成式模型演进的实践，重点介绍了双阶段框架、自回归与非自回归模型优化及高性能推理方案。

📝 详细摘要

文章系统性地介绍了得物技术在推荐系统重排阶段的演进历程。针对精排 Pointwise 建模在多样性和上下文建模上的局限，得物采用了“生成-评估（G-E）”双阶段协同框架。文中详细对比了非自回归模型（高并发、低延迟）与自回归模型（高精度、强依赖建模）的优劣，并分享了通过 MTP（多 Token 预测）结构突破自回归推理瓶颈的实战经验。此外，文章还涵盖了 GPU 推理加速、KV Cache 复用等工程优化手段，并前瞻性地提出了基于强化学习（DPO/PPO）的端到端序列生成下一代架构，旨在实现从“候选筛选”到“序列创造”的跨越。

💡 主要观点

  1. 重排阶段需从 Pointwise 转向 Listwise 建模以优化全局收益。 精排独立打分忽略了项间交互和多样性，重排通过建模序列整体价值，解决位置偏差和内容同质化问题。
  2. 采用 G-E 双阶段框架平衡了搜索效率与评估精度。 生成阶段（G）负责快速筛选高质量候选排列，评估阶段（E）进行精细化打分，有效缓解了质量与延迟的矛盾。
  3. 引入 MTP 结构显著提升了自回归重排模型的推理效率。 通过单步多 Token 联合预测，减少了自回归过程中的前向传播次数，使高复杂度模型能满足线上毫秒级响应要求。
  4. 工程与模型双重优化保障了端到端生成的性能落地。 通过 GPU 独立部署、TensorRT 量化、KV Cache 复用及 GQA 等技术，解决了 CPU 推理延迟高、资源竞争等瓶颈。
  5. 未来重排将迈向基于强化学习的端到端序列生成架构。 规划引入 DPO/PPO 微调机制，将重排目标从局部筛选升级为直接创造符合全局业务目标的序列，突破现有范式上限。

💬 文章金句

  • 重排作为最终决策环节，承担着将精排输出的有限候选集转化为最优序列的关键职责。
  • 生成式模型逐渐成为重排主流范式，主要分为两类：自回归生成模型、非自回归生成模型。
  • 自回归生成模型在传统基础上增加 MTP 结构，突破生成式重排模型推理瓶颈。
  • 将重排从‘候选筛选’升级为‘序列创造’，直接以全局业务目标为优化目标。
  • 通过序列级优化，在同等延迟下实现质量与多样性双提升。
