“10 周的工作量，AI 只用 4 天！”Anthropic 发布会全程实录：你引以为傲的复杂工程，在模型眼里只是个玩具

5/13/2026, 9:50:00 AM

📌 一句话摘要

本文是 Anthropic 最新「Code w/ Claude」开发者大会的全程实录，核心展示了 Claude 平台三大新能力（多智能体协同、目标导向、模型造梦）以及 Claude Code 桌面版与异步开发流，标志着软件工程正从同步编码向 AI 驱动的异步开发范式转移。

📝 详细摘要

文章详细记录了 Anthropic 举办的「Code w/ Claude」开发者大会 Keynote 内容。Anthropic 首席产品官 Ami Vora 开场指出，AI 模型能力呈指数级增长，但企业开发模式仍停留在线性阶段，开发者使命是弥合这一鸿沟。研究产品负责人 Dianne Penn 介绍了模型层的持续进化，强调「任务视界」是衡量模型智商的核心维度，并透露了更高阶判断力、更深上下文窗口、多智能体协同等未来目标。Claude 平台团队 Angela Jiang 和 Katelyn Lesse 现场演示了三大新特性：多智能体协同（组建智能体舰队）、目标导向（精确定义成功标准并自动迭代）、模型造梦（智能体自主学习并沉淀经验）。Claude Code 团队 Cat Wu 和 Boris Cherny 发布了桌面版、代码审查器、远程控制、自动修复、Routines 例程和 Claude Security 等新功能，展示了从「给 Claude 写提示词」到「让 Claude 给 Claude Code 写提示词」的范式转变。文章还引用了 Stripe（10 周工作量 4 天完成）、Shopify、Mercado Libre 等企业的实际案例。

💡 主要观点

  1. AI 模型能力呈指数级增长，但企业开发模式仍停留在线性阶段。 Anthropic 认为模型能力爆发速度远超企业应用速度，开发者的核心使命是弥合这一鸿沟，将模型能力转化为普通人解决问题的利器。
  2. Claude 平台推出三大新特性：多智能体协同、目标导向、模型造梦。 多智能体协同允许组建智能体舰队分工协作；目标导向通过阅卷智能体自动评估迭代结果；模型造梦让智能体在空闲时回顾会话、自主学习并沉淀经验到记忆库。
  3. Claude Code 推动从同步编码向异步开发流范式转移。 新功能包括桌面版、Routines 例程（高阶提示词，自动监听事件并唤醒 Claude）、CI 自动修复、代码审查器等，开发者工作从「盯着写代码」变为「配置自动化流程后验收成果」。
  4. 模型升级带来商业机会爆发，企业应锚定未来能力而非当前版本。 Dianne Penn 建议开发者「为下一个版本的 Claude 做设计」，建立自动化评估体系和原型系统，以便在模型能力跃升时第一时间捕获新机会。

💬 文章金句

  • AI 模型的能力正在呈'指数级'增长，但大多数企业的开发模式仍停留在'线性'阶段。
  • Stripe 的团队有 5 万行 Scala 代码必须转写成 Java，他们最初估算需要 10 周，结果用了 Claude，只花了 4 天就全部搞定。
  • 模型层是今天大家将听到的所有创新的底座。这是最核心的共识。
  • 默认的操作不再是'我要去给 Claude Code 写提示词'，而是'我要让 Claude 去给 Claude Code 写提示词'。
  • 我们坚信，未来的趋势是，海量的代码将以'异步'的方式被生产出来。
