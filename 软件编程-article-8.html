Cursor 入门：MCP 开发调用和项目实战

6/3/2025, 12:31:00 AM

📌 一句话摘要

深度探讨了 AI 编程工具 Cursor 结合 MCP 协议进行项目开发的能力与技巧，并分享了实战经验。

📝 详细摘要

文章详细介绍了 Model Context Protocol (MCP) 协议作为连接 AI 模型与数据源/工具的标准化方式，阐述了其架构、组件及通信机制。接着，文章聚焦于 AI 编程工具 Cursor，介绍了其 Docs 和 Rules 等核心功能。文章主体通过两个实战案例展示了 Cursor 在开发中的应用：首先，利用 Cursor 快速构建一个简单的天气查询 MCP Server；其次，尝试开发一个更复杂的黄金价格预测项目。通过实战，作者分析了 Cursor 在项目开发中的显著优点，如强大的上下文感知和命令执行能力，同时也指出了长会话处理和复杂代码 debug 方面的不足。最后，作者基于实战经验，提炼出一系列提高 Cursor 使用效率的技巧，强调了清晰需求、技术方案先行、工具 활용以及版本控制的重要性。

💡 主要观点

  1. MCP 协议标准化了 AI 模型访问数据和工具的方式 MCP 提供开放标准，使 AI 应用能安全便捷地连接并操作本地及远程数据，为 AI 工具提供了"连接万物"的基础接口。
  2. Cursor 结合 Docs 和 Rules 等功能，提升 AI 辅助开发效率 Cursor 作为 AI-native IDE，通过索引文档、定义规则等方式增强 AI 理解项目上下文的能力，进而提高代码生成和问题解决的效率。
  3. AI 编程工具需要使用者具备基础开发能力 虽然 Cursor 功能强大，但在处理复杂项目、联调或调试时，用户仍需理解代码和系统，辅助 AI 定位和解决问题。
  4. 有效使用 AI 开发工具需掌握核心技巧 包括清晰描述需求、优先设计技术方案、充分利用文档和规则、添加日志以及使用 Git 进行版本管理，以引导 AI 并控制开发过程。

💬 文章金句

  • 之前对 AI Coding 的认知还停留在 tab 补全、自动生成单元测试上，没想到现在已经发展到直接能开发项目了，某种意义上做到了"有嘴就行"。
  • MCP provides a standardized way to connect AI models to different data sources and tools。
  • Cursor 相对于常规 IDE 的 Chat 面板，可以直接阅读整个项目文件、浏览网页、读取图片、运行命令，这几个功能十分好用。
  • 一些极小的代码 bug 不容易发现。
  • 简单几天 cursor 体验下来，感觉网传的零基础小白上手开发 app 上线或许多少有点夸大其词，稍微复杂点的项目...还是需要使用者具备一定的开发基础的（常用的 node、python、linux、git 命令）。
