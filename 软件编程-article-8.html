苹果 Containerization 提供了面向 macOS 的原生 Linux 容器支持

6/17/2025, 10:51:00 AM

📌 一句话摘要

苹果发布 Containerization 框架，为 macOS 带来基于轻量级虚拟机的原生 Linux 容器支持。

📝 详细摘要

文章介绍了苹果在 WWDC 2025 上发布的 Containerization 框架和 Container CLI 工具。这个新框架允许开发者在 macOS 上以轻量级虚拟机的方式运行 Linux 容器，无需依赖 Docker 等第三方工具。其独特之处在于每个容器运行在独立的轻量级 VM 中，相比传统共享 VM 模式，提供了增强的安全性、专用资源分配（独立 IP、CPU/内存）和隐私设计。框架使用 Swift 编写，包含自定义初始化系统 vminitd，并通过静态 Linux SDK 和 musl 实现跨平台编译。文章还提及通过优化 Linux 内核、EXT4 块设备和 Apple Silicon 实现亚秒级启动。Containerization 已作为开源项目发布，并提供了类似 Docker 的命令行工具。文章最后对比了 Containerization 与其他容器工具（如 Podman， containerd）的不同之处，强调其基于轻量级 VM 的创新方法。

💡 主要观点

  1. 苹果 Containerization 提供 macOS 原生 Linux 容器支持 开发者无需第三方工具，即可在 Mac 上直接运行 Linux 容器，简化开发环境配置和管理。
  2. 采用轻量级虚拟机实现容器隔离 每个容器运行在独立的 VM 中，提高了安全性、资源隔离性和隐私性，是与传统容器技术的关键区别。
  3. 基于 Swift 构建核心组件并已开源 框架使用 Swift 开发，并开放源代码，便于社区参与、审计和构建定制化解决方案。

💬 文章金句

  • 这是开发者在 macOS 上运行 Linux 容器方式的重大转变，因为这一新的开源容器化框架消除了对 Docker 等第三方工具的需求。
  • 传统的容器化解决方案会在单个大型虚拟机中运行多个容器，与之不同，苹果的方法是在轻量级虚拟机中运行每个 Linux 容器。
  • 增强安全性：每个容器都能获得与完整虚拟机相同的隔离级别，这显著减少了攻击面。
  • 尽管每个容器都在自己的虚拟机中运行，但苹果声称通过多项优化实现了亚秒级的启动时间。
  • 苹果已经在 GitHub 上将 Containerization 框架和 container CLI 工具作为开源项目发布。
