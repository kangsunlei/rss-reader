局中局！给 Agent 装上 OpenViking，它们竟然学会了“记仇”和“伪装”？

4/22/2026, 10:03:00 AM

📌 一句话摘要

本文介绍了字节跳动开源的 OpenViking 上下文管理框架及其配套的 VikingBot，通过一个多智能体狼人杀 Demo 生动展示了如何为 Agent 提供长期、可追溯的集体记忆，使其能够跨局学习、形成策略并模拟复杂的社会行为。

📝 详细摘要

文章深入探讨了多智能体协作中的一个核心挑战：缺乏长期、可追溯的集体记忆。字节跳动技术团队开源的 OpenViking 框架旨在解决此问题，为集体智能提供统一的上下文管理底座。文章通过一个精心设计的 6 个 VikingBot 参与的狼人杀 Demo，详细展示了 OpenViking 如何工作：Agent 能够将每局的发言、投票和思考过程沉淀为记忆，记住其他 Agent 的行为模式（如撒谎、带节奏），并在后续对局中利用这些记忆进行更复杂的推理、伪装和策略调整，最终实现胜率的显著提升。文章不仅描述了生动的博弈场景，还系统性地介绍了 OpenViking 的技术架构，包括其三层记忆结构（L0/L1/L2）、基于 ReAct 的智能记忆抽取、增量更新机制、语义化文件命名以及多租户支持。同时，文章也介绍了深度集成 OpenViking 的 VikingBot，其核心能力、灵活的部署模式（共享/渠道隔离/会话隔离）以及详细的安装和配置指南。

💡 主要观点

  1. OpenViking 为多智能体系统提供了长期、可追溯的集体记忆底座。 它通过统一的 `viking://` 目录协议和三层记忆结构（摘要/总结/完整内容），结构化地存储和管理 Agent 与用户的交互历史、行为模式和策略经验，解决了多 Agent 协作中“记忆缺失”和“经验无法沉淀”的核心痛点。
  2. 基于记忆的跨局学习能显著提升智能体的博弈能力和策略复杂度。 狼人杀 Demo 证明，携带 OpenViking 记忆的 VikingBot 能够学会“记仇”（识别撒谎者）、“伪装”（利用历史行为隐藏身份）和“结盟”（识别可靠伙伴），其胜率随着对局数增加而明显上升，展现了从经验中迭代进化的能力。
  3. VikingBot 是深度集成 OpenViking 的 Agent 实现，具备高可扩展性和灵活部署能力。 VikingBot 内置了 OpenViking 的专用工具，支持多渠道接入，并通过网关架构与 AgentLoop 解耦。它提供共享、渠道隔离、会话隔离三种工作空间模式，能适应从个人助手到企业级多租户的各种复杂场景。
  4. OpenViking 采用了多项优化技术以实现记忆的高效管理与检索。 包括引入 ReAct 进行智能记忆抽取、基于 Patch 的增量更新以减少 LLM 调用、语义化文件命名以提升可解释性，以及渐进式检索机制（先摘要后完整内容），在提升准确率的同时大幅降低了 Token 消耗。

💬 文章金句

  • 缺少能够长期协同进化的记忆，协作起来像在经历‘初恋 50 次’，它们记不住‘谁在过去做了什么’，无法沉淀共同经验，更难在复杂博弈中形成‘记仇’、‘结盟’或‘深度伪装’等高阶群体行为。
  • 结果表明：VikingBot 能够有效将群聊中的发言、投票与思考过程沉淀下来，记住 A 曾经撒过的谎、B 带过的节奏、C 救过的场，让‘记忆’成为跨局推理与博弈的底座。
  • OpenViking 的上下文存储遵从统一的 viking:// 目录协议，意味着 VikingBot 可以像操作本地文件系统一样，对上下文做 ls、tree、read、find/search。
  • 记忆不只记‘用户说了什么’，更重要的是记‘怎么解决问题’。
  • 无论是 VikingBot 还是 OpenViking 插件，都让 Agent 的准确率提升了近 3 倍。VikingBot 在保证极高准确率的同时，将 Token 消耗降低为 OpenViking 插件的二分之一。
