GitHub 推出 AgentHQ，Copilot 生态再扩容

11/13/2025, 2:40:00 AM

📌 一句话摘要

GitHub 在年度活动上发布 AgentHQ，该功能允许开发者直接在 GitHub 环境中创建和部署 AI 智能体，进一步扩展了 Copilot 生态系统，实现全流程自动化开发。

📝 详细摘要

GitHub 在其年度开发者盛会 Universe 2025 活动上推出了 AgentHQ，这是一项允许开发者直接在 GitHub 开发环境内创建和部署 AI 智能体的新功能。AgentHQ 旨在将 AI 自动化扩展到整个代码仓库，区别于 Copilot 主要的编辑器内代码补全，它能处理问题分类、文档编写、测试与部署等编码流程中的多个环节。开发者可利用 GitHub API 和运行时环境构建智能体，这些智能体在隔离环境中运行，并与 GitHub Actions 集成，支持将传统 CI/CD 任务与 AI 驱动的推理相结合。AgentHQ 的推出标志着 GitHub 进军代理式开发新赛道，并使开发过程更具对话感和上下文感知能力。文章还提及了 Copilot Workflows 的新功能、CodeQL 驱动的代码审查以及 VS Code Plan Mode 的正式发布等相关更新。

💡 主要观点

  1. AgentHQ 将 AI 自动化从代码补全扩展至整个开发流程 与 Copilot 专注于编辑器内代码生成不同，AgentHQ 允许智能体监控仓库事件、响应拉取请求并执行代码审查，覆盖从问题分类到部署的完整开发生命周期。
  2. 开发者可利用 GitHub 环境构建和部署定制化 AI 智能体 AgentHQ 提供 GitHub API 和运行时环境，使开发者能够创建可访问仓库数据、操作拉取请求的智能体，并在隔离且受控的环境中安全运行。
  3. AgentHQ 与 GitHub Actions 集成，赋能 AI 驱动的自动化管道 通过结合传统 CI/CD 任务与 AI 驱动的推理，AgentHQ 能够实现智能化的代码审查、自动化改进建议和重复性维护任务，提升开发效率和质量。

💬 文章金句

  • 智能体被设计成可定制、面向特定任务的 AI 助手，可处理编码流程中的多个环节，从问题分类、文档编写到测试与部署。
  • AgentHQ 还与 GitHub Actions 集成，支持将传统 CI/CD 任务与 AI 驱动的推理相结合，打造自动化管道。
  • AgentHQ 的推出让 GitHub 站上了代理式开发的新赛道，与 Anthropic 的 Claude Skills 和 Cursor 的多智能体界面同台竞技。
  • GitHub 表示，这项新功能是其更大计划的一部分，旨在让开发过程更具对话感和上下文感知能力。
