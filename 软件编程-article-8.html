使用 BigQuery ML 解决 Zeotap 的相似人群问题

11/15/2025, 12:00:00 AM

📌 一句话摘要

Zeotap 利用 BigQuery ML 和向量搜索构建可扩展的相似人群模型，通过巧妙的点积方法克服了原生 Jaccard 相似度对低基数（类别较少）特征的限制。

📝 详细摘要

本文详细介绍了客户智能平台 Zeotap 如何利用 Google Cloud 的 BigQuery ML 和向量搜索为数字营销人员创建有效的相似人群。它通过结合 Zeotap 的多重图算法和高质量数据资产，解决了稀疏的第一方数据问题。核心技术重点是为低 cardinality（类别较少）的类别特征实现 Jaccard 相似度，而 BigQuery 向量搜索本身并不原生支持 Jaccard 相似度。作者解释了他们如何巧妙地使用 BigQuery 的点积（一种向量运算）和曼哈顿范数（一种计算向量长度的方法）函数推导出 Jaccard 距离。该解决方案涉及通过独热/多热编码生成向量嵌入，构建高效的向量索引（IVF/TREE_AH），并采用诸如“稀疏特征”预过滤和批量处理之类的高级策略。这些技术使 Zeotap 能够高效且经济高效地处理海量数据集（数百万用户），完全在 BigQuery 生态系统中交付可扩展的相似人群模型，而无需专门的向量数据库。这种实用的方法允许使用单个 SQL 脚本创建定制的相似人群模型，从而显著增强客户分群和个性化。

💡 主要观点

  1. Zeotap 有效地利用 BigQuery ML 和向量搜索来生成可扩展的相似人群。 通过完全在 BigQuery 生态系统中构建解决方案，Zeotap 实现了经济高效且高性能的客户分群，将复杂的最近邻问题转换为更简单的内连接，而无需专门的向量数据库。
  2. Jaccard 相似度对于低基数特征至关重要，它可以通过点积和曼哈顿范数在 BigQuery 向量搜索中实现。 尽管 BigQuery 的原生向量搜索缺少 Jaccard 距离，但 Zeotap 通过根据点积（一种向量运算）和曼哈顿范数（一种计算向量长度的方法）重新制定 Jaccard 距离，从而设计了一个巧妙的解决方案，使其可用于用户配置文件数据集。
  3. 诸如稀疏特征预过滤和批量处理之类的高级策略对于扩展大型数据集中的向量搜索至关重要。 为了克服大规模相似人群搜索的计算复杂性，Zeotap 采用预过滤来减少搜索空间，并采用批量处理来查询用户，从而显著提高了效率并降低了资源负载。

💬 文章金句

  • 相似人群是由机器学习算法识别的一群新的潜在客户，他们与现有的高价值客户群具有相似的特征和行为。
  • Jaccard 相似度之所以出色，是因为它很简单，并且很容易解释许多其他复杂的距离度量和相似度指标，而这些指标仅衡量嵌入空间中的距离——这实际上是奥卡姆剃刀（一种解决问题的原则，选择最简单的方案）。
  • 但是，我们可以将二进制向量的选择表示为 Jaccard 距离（1 - Jaccard 相似度）：Jd(A，B) = 1 - |A∩B|/|A∪B| = (|A∪B| - |A∩B|)/|A∪B|
  • 一个简单但非常有效的策略是**避免搜索普遍存在的用户特征。**
  • 借助 BigQuery ML 和向量产品，以及其强大的无服务器架构，我们能够发布满足各个客户领域和需求的定制相似人群模型。
