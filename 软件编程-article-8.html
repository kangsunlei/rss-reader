开源！快手提出面向长上下文推理的序列压缩注意力机制 KSA！

5/14/2026, 3:45:00 AM

📌 一句话摘要

快手推荐模型团队提出 Kwai Summary Attention (KSA)，通过 Summary Token 实现序列级 KV Cache 压缩，在 8 倍压缩比下显著提升长上下文推理效率，并在 RULER-128K 等长序列任务上超越 Full Attention 基线。

📝 详细摘要

本文由快手推荐模型团队撰写，系统介绍了他们提出的 Kwai Summary Attention (KSA) 机制。KSA 的核心思路是在序列层面按 chunk 插入可学习的 Summary Token，将每个 chunk 的语义压缩为一个表征，从而将 KV Cache 与序列长度的线性增长斜率从 1 降至 1/k（默认 k=8）。文章详细阐述了 Summary Token 压缩、Sliding Chunk Attention (SCA) 的设计原理，以及 KSA 与 GQA、MLA 等现有 KV 压缩技术的正交组合能力。在系统实现上，KSA 采用连续 KV Cache 布局，将 cache 组织为三段物理相邻的 buffer，大幅提升解码吞吐。实验部分展示了在 From Scratch（1.9B 参数、400B tokens）和 Qwen3-4B-Base CPT（85B tokens）两种训练范式下的完整评测结果：在 RULER-128K 长序列检索任务中，Hybrid KSA 分别超越 Full Attention 16.60 分和 5.81 分；在通用能力评测中，Hybrid KSA 是所有 Hybrid 方案中与 Full Attention 差距最小的，且在 MATH、GSM8K 等数学推理任务上表现突出。文章还讨论了推荐系统思想与大模型预训练技术交汇的趋势。

💡 主要观点

  1. KSA 通过 Summary Token 实现序列级 KV Cache 压缩，将增长斜率从 1 降至 1/k。 将输入序列按 chunk 切分，每个 chunk 末尾插入可学习的 Summary Token 负责压缩该 chunk 语义，Text Token 通过近处原文和远处 Summary 访问上下文，实现 8 倍压缩比下保留完整长距离回溯能力。
  2. Sliding Chunk Attention (SCA) 解决了 SWA 与 Summary Token 组合时的信息丢失问题。 将滑动粒度从 token 级提升至 chunk 级，保证每个历史 chunk 要么整体可见原文，要么整体通过 Summary 访问，不存在中间态，实现前序信息的完整覆盖。
  3. KSA 与 GQA、MLA 等现有 KV 压缩技术正交，压缩率可直接相乘。 GQA 压缩 Head 数，MLA 压缩 Embedding 维度，KSA 压缩 Token 数，三者独立，组合使用时 KSA+GQA 可将 KV Cache 压至 MHA 的 0.78%，KSA+MLA 压至 0.22%。
  4. Hybrid KSA 在长序列检索和数学推理任务上均超越 Full Attention 基线。 在 RULER-128K 上 Hybrid KSA 超越 Full Attention 16.60 分（From Scratch）和 5.81 分（CPT）；在 MATH 上高出 13.54 分，GSM8K 上高出 10.85 分，表明 Summary 机制对长链路依赖任务提供更好的归纳偏置。

💬 文章金句

  • KSA 的核心并非追求最小 KV Cache，而是在保持 cache 与序列长度线性关系的前提下，引入一个语义级压缩比 k，将增长斜率从 1 降为 1/k。
  • GQA、MLA 做的是每个 token 的 KV 体积的压缩，KSA 做的是参与计算的 token 数量的压缩，三者压缩维度正交，可以叠加使用，压缩率可观。
  • Hybrid-KSA 是所有 Hybrid 方案中与 Full Attention 能力差距最小的，甚至略高于 Full，并在 MBPP (62.20)、HumanEval (62.50) 等结构化生成任务上领跑。
  • 许多在推荐场景中已被反复验证的问题，正在 LLM 体系中被重新定义与解决。
