静态 IP：更安全的连接 - Vercel

10/2/2025, 1:00:00 PM

📌 一句话摘要

Vercel 为 Pro 和企业版团队引入静态 IP，旨在实现与需要 IP 白名单的外部服务的安全连接。

📝 详细摘要

Vercel 宣布即日起 Pro 和企业版客户可以使用静态 IP。此功能确保源自 Vercel 构建和函数的流量通过一致的、共享的静态 IP 地址路由。对于需要连接到外部服务或数据库，并强制执行 IP 白名单以确保安全的组织来说，此功能至关重要。用户可以通过项目或团队设置中的“连接性 (Connectivity)”部分轻松启用静态 IP。静态 IP 与 Vercel 现有的安全计算解决方案协同工作。安全计算为有更严格隔离要求的用户提供完全专用的 VPC 模型。推出静态 IP 是 Vercel 战略的一部分，旨在让更多企业级功能易于访问，并支持用户自助服务。

💡 主要观点

  1. Vercel 为需要 IP 白名单的 Pro 和企业版团队提供静态 IP，增强安全性。 此功能为 Vercel 构建和函数提供一致的出站 IP 地址，从而能够安全连接到基于 IP 地址限制访问的外部服务。
  2. 静态 IP 增强了 Vercel 部署的安全性和合规性。 通过支持 IP 白名单，Vercel 帮助用户遵守安全策略，并无缝集成敏感的第三方系统和数据库。
  3. 此功能是 Vercel 自助服务企业功能的战略举措。 此举使 Pro 和企业版用户能够在其 Vercel 平台内更直接地控制其基础设施的网络和安全设置。
