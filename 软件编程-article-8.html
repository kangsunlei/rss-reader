攻击者正利用 FortiSandbox 三大漏洞发起攻击，未认证即可获取 root 权限

6/17/2026, 11:00:00 AM

📌 一句话摘要

本文报道 Fortinet FortiSandbox 三个关键漏洞正被积极利用，攻击者可在未认证状态下通过单个 HTTP 请求获取 root 权限，并提供了技术细节、受影响版本与入侵指标。

📝 详细摘要

文章基于 Defused 安全团队的实时遥测数据，报道 Fortinet FortiSandbox 平台三个关键漏洞（CVE-2026-39813、CVE-2026-39808、CVE-2026-25089）正被攻击者积极利用。其中 CVE-2026-39813 为路径遍历漏洞，允许未认证攻击者绕过认证访问敏感数据；CVE-2026-39808 和 CVE-2026-25089 为操作系统命令注入漏洞，可导致以 root 权限执行任意命令。文章指出这三个漏洞均可通过向 /jsonrpc/ API 端点发送特制 POST 请求触发，无需任何前置认证。文章还列出了受影响版本范围、入侵指标（IOC）以及遭入侵后可能被用于横向移动或恶意文件标记的风险。内容编译自 Cybersecurity News 的英文报道。

💡 主要观点

  1. FortiSandbox 三个漏洞无需认证即可利用，攻击者可通过单个 HTTP 请求获取 root 权限。 CVE-2026-39813（路径遍历）、CVE-2026-39808 和 CVE-2026-25089（命令注入）均可通过向 /jsonrpc/ API 发送特制 POST 请求触发，无需任何前置认证，风险极高。
  2. CVE-2026-39813 此前无公开利用记录，本次为首次公开案例。 该漏洞允许攻击者通过注入路径遍历序列绕过认证，访问配置备份、序列号等敏感数据，本次观测到的攻击集群属首次公开。
  3. 遭入侵的 FortiSandbox 可能被用作横向移动跳板或恶意文件标记工具。 攻击者可能利用被控设备将恶意文件标记为安全，从而欺骗依赖 FortiSandbox 的其他 Fortinet 产品，或在企业网络内部横向移动。
