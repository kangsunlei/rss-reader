Docker Desktop 4.44 发布

8/14/2025, 1:16:37 PM

📌 一句话摘要

Docker Desktop 4.44 增强了 AI 模型调试功能，通过新的 MCP 客户端和 Kubernetes CLI 简化了集成，并提升了在 macOS 和 WSL2 上的性能。

📝 详细摘要

Docker Desktop 4.44 专注于提供增强的可靠性、更严格的 AI 建模控制以及更简化的工具集成。 主要功能包括对 Docker Model Runner 的重大改进，为调试提供可检查的 AI 推理工作流程，并提供实时资源检查以防止系统变慢，尤其是在并发模型执行时。 Docker MCP 工具包现在支持 Goose 和 Gemini CLI，只需单击一下即可设置超过 140 个 MCP 服务器，从而简化了智能代理的开发。 新的 `docker desktop kubernetes` CLI 命令简化了本地 Kubernetes 集群管理。 此外，该版本在 macOS 上默认为 Apple Virtualization 技术，以获得卓越的性能，并包括对 WSL2 环境的重大稳定性和性能增强，例如减少内存消耗和更智能的 CPU 节流。 此更新旨在通过上述方式，为 AI 和 Kubernetes 用户提供更高效、可靠和集成的开发体验。

💡 主要观点

  1. 增强的 Docker Model Runner 改进了 AI 调试和资源管理。 新的检查器允许详细检查 AI 推理请求和响应，而实时资源检查可防止系统冻结，从而能够自信地并发执行多个 AI 模型。
  2. 新的 MCP 客户端和 Kubernetes CLI 集成简化了开发人员的工作流程。 通过 MCP 工具包，可以一键设置 Goose 和 Gemini CLI，连接到各种服务器。 集成的 Kubernetes 命令简化了本地集群管理，从而减少了上下文切换。
  3. 平台升级显著提高了 macOS 和 Windows 上的性能和稳定性。 macOS 上的默认 Apple Virtualization 技术提高了启动速度和内存使用效率，而 WSL2 增强功能减少了冻结情况，并提高了响应速度，尤其是在图形密集型工作负载方面。

💬 文章金句

  • 此功能为 AI 工作流程带来了透明度和调试能力，并为那些尝试使用基于 AI / LLM（大型语言模型）的应用程序的用户提供了重要的可用性升级。
  • 通过一键集成，开发人员可以减少配置基础架构的时间，而将更多时间用于构建智能的、目标驱动的代理。
  • 通过将集群管理引入 CLI，Docker 减少了心智负担，并加快了工作流程，特别是对于在部署到托管集群之前在本地进行原型设计的团队。
  • 在 macOS 上，Apple Virtualization 现在是默认的虚拟化后端，可提供卓越的性能。
  • 目标是减少意外情况，增强可观测性，并加快迭代速度。
