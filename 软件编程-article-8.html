专为 Claude Code 而生的终端，开源了！

6/5/2026, 9:05:00 AM

📌 一句话摘要

cmux 是一款专为 AI Agent 编程工具（如 Claude Code、Codex）设计的原生 macOS 终端，通过侧边栏信息聚合、智能通知系统和内置浏览器，解决多 Agent 并行工作时的进度追踪与上下文切换痛点。

📝 详细摘要

文章介绍了开源终端工具 cmux，它专为 AI Agent 编程场景设计。作者从自身痛点出发——同时运行多个 Claude Code 和 Codex 会话时，原生终端标签页混乱、通知无上下文、排查问题效率低——引出了 cmux 的核心设计。cmux 的核心功能包括：信息密度极高的侧边栏（显示 Git 分支、PR 状态、工作目录、监听端口和最新通知）、智能通知系统（Agent 等待输入时窗口亮起蓝色光环并高亮标签页）、内置浏览器（供 Agent 抓取页面快照并执行操作）、以及 Claude Code Teams 模式（多 Agent 并排运行）。此外，它还支持 SSH 远程工作区、CLI 和 socket API 脚本化控制。文章指出 cmux 基于 Ghostty 二次开发，目前仅支持 macOS，可通过 Homebrew 或 .dmg 安装。

💡 主要观点

  1. cmux 通过侧边栏聚合多 Agent 会话的关键信息，解决信息分散问题。 侧边栏以垂直标签页形式，直接展示每个工作区的 Git 分支、PR 状态、工作目录、监听端口和最新通知文本，让用户一眼掌握所有会话状态，无需逐个切换窗口查看。
  2. 智能通知系统通过视觉高亮，精准定位需要人工介入的 Agent。 当 Agent 执行任务卡住等待输入时，对应窗口会亮起蓝色光环，侧边栏标签页同步高亮，并支持快捷键快速跳转到未读通知，大幅减少排查时间。
  3. 内置浏览器使 Agent 能直接与本地开发服务器交互，简化调试流程。 Agent 可抓取页面的无障碍树快照、获取元素引用、执行点击和表单填写等操作，省去在终端和浏览器之间来回切换的麻烦。
  4. cmux 支持 SSH 远程工作区和脚本化控制，覆盖更广泛的使用场景。 远程工作区可通过网络路由访问本地浏览器窗格，拖拽图片自动通过 scp 上传；所有操作均可通过 CLI 和 socket API 控制，便于集成到自定义工作流中。
