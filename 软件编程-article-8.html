【早说】从 JS 框架之争看 AI Agent 的未来演进

6/30/2026, 1:00:00 AM

📌 一句话摘要

本文通过回顾 JS 框架之争中 React 因极简主义取胜并被 Next.js 补齐的历程，类比预测 AI 智能体领域也将出现类似的「meta 编排层」。

📝 详细摘要

文章以 JavaScript 框架战争（jQuery → AngularJS → React → Next.js）为引线，剖析 React 因刻意极简而战胜全能型框架 Angular 的深层原因：没有团队能洞悉所有开发方式，专注核心才能做到最好。随后，Next.js 作为首个 meta 框架补齐了 React 在性能、SEO 等方面的短板。作者将这一模式映射到当下 AI 智能体领域，指出 Claude Code 等全能型智能体如同当年的 Angular，而 Codex 等专注型智能体更像 React。最终，极简的智能体将胜出，并催生一个位于智能体之上的新层级——meta 编排层，它负责跨仓库调度、持久化记忆、多智能体协调等运营支撑能力，不触碰模型本身。作者还介绍了自己开源的方案 Polygraph 作为实际例子。

💡 主要观点

  1. React 因极简主义赢得了框架战争，不足由 meta 框架 Next.js 补齐。 React 只做渲染引擎，不包揽应用层，因此能专注做好核心；Next.js 在之上提供路由、SSR 等能力，补齐了 React 的短板。
  2. AI 智能体领域将重演相似历史，专注核心的极简智能体将胜出。 像 React 一样，专注做模型编排或核心代码生成的智能体比什么都做的全能型智能体更容易成功，因为构建方无法了解所有组织的需求。
  3. 需要「meta 编排层」来补齐智能体的运营支撑能力。 该层位于智能体之上，提供跨仓库调度、持久化记忆、多智能体协调等功能，不干预模型本身，如同 Next.js 包裹 React。

💬 文章金句

  • 做得最少的框架，反而赢了。
  • 最终胜出的智能体会是专精而克制的，一个新的层级将在它们之上生长起来。
  • 以为一个团队能洞悉整个行业的软件开发全流程，那是一种幻觉。
