📝 详细摘要

文章围绕 DeepSeek-V4-Flash 的 API 公测展开，首先对比模型性能（Terminal-Bench 82.7 分超 V4-Pro），强调其低价策略（输入 1 元/百万 token）。主体部分分步骤讲解接入 Codex 和 Claude Code 的两种方法：1. 官方一键脚本配置（支持 Responses API，无需协议转换）；2. 手动修改配置文件。补充了通过 CC Switch 工具实现 Claude Code 的模型切换，以及为 DeepSeek 增加视觉能力的 Vision Skill 安装方法。文章以实战教程为主，附赠免费开源教程链接。

💡 主要观点

  1. DeepSeek-V4-Flash 性能突破与性价比优势 模型在 Terminal-Bench 测试中得分 82.7（超 V4-Pro 72.1），输入成本仅 1 元/百万 token，输出 2 元/百万 token，强调低价策略降低使用门槛。
  2. Codex 接入的官方脚本与手动配置方法 提供两种配置方式：1. 官方脚本自动化配置（支持 Responses API）；2. 手动编辑 models.json 和 config.toml 文件，详细说明路径与参数设置。
  3. Claude Code 的模型切换与视觉扩展方案 通过开源工具 CC Switch 实现 Claude Code 的模型切换，支持 DeepSeek-V4-Flash；补充视觉能力扩展方法，结合通义千问等多模态模型解决 DeepSeek 无图像理解问题。
