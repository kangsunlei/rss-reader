Python Worker 服务再升级：Wasm 快照与原生 uv 工具加持

12/24/2025, 10:00:00 AM

📌 一句话摘要

Cloudflare 通过由 WebAssembly 驱动的内存快照显著增强了其 Python Worker 服务，实现了近乎即时的冷启动，并通过 uv 工具扩展了包兼容性，将 Python 定位为边缘计算的核心支持语言。

📝 详细摘要

Cloudflare 在其 Python Worker 服务方面取得了重大进展，解决了长期存在的冷启动缓慢和包兼容性受限等问题。其核心创新在于利用 WebAssembly (Wasm) 和内存快照，从而实现近乎即时的启动时间。通过在部署时执行一次顶层作用域并捕获 Wasm 线性内存快照，Cloudflare 可以快速恢复 Worker 服务，将 FastAPI 和 Pydantic 等重型包的冷启动时间从 10 秒大幅缩短至约 1 秒。这种方法还绕过了 ASLR（地址空间布局随机化）的复杂性，而 ASLR 通常会使本地内存快照的实现变得复杂且不安全。此外，Cloudflare 通过支持任何 Pyodide 兼容库（包括带有 C 扩展模块的库）扩展了包兼容性，并引入了 `pywrangler` —— 一个与 `uv` 集成的命令行工具 —— 以简化依赖管理。这些更新将 Python 集成到 Cloudflare 的高级功能中，例如 FastAPI 集成、智能代理 AI 和工作流以及持久对象，使 Python 成为边缘、生产级 AI 和数据科学应用的高性能且可行的选择。

💡 主要观点

  1. Wasm 驱动的内存快照大幅缩短了 Python Worker 服务的冷启动时间。 Cloudflare 利用 WebAssembly 和内存快照几乎即时地初始化 Python Worker 服务，绕过了完全重新初始化，解决了 Python 固有的冷启动延迟问题。
  2. 扩展的包兼容性使得 Python Worker 服务能够接入更广泛的生态系统。 通过支持 Pyodide 兼容库（包括带有 C 扩展模块的库），Cloudflare 使开发人员能够在其无服务器环境中使用以前无法使用的各种 Python 包（例如 NumPy、Pandas）。
  3. `uv` 集成工具简化了 Python Worker 服务的依赖管理和部署。 引入 `pywrangler` 和 `uv` 简化了 Python 依赖项的边缘部署管理和打包，提供了更友好的开发人员体验和更快的开发周期。
  4. Python 集成 Cloudflare 高级功能，支持复杂的边缘应用。 Python Worker 服务现在与 FastAPI、智能代理 AI 和工作流以及持久对象集成，显著扩展了 Python 在边缘直接构建复杂、有状态和 AI 驱动应用程序的能力。
  5. Cloudflare 将 Python 定位为边缘计算（尤其是 AI/数据科学）的核心支持语言。 通过消除性能障碍并提供强大的工具，Cloudflare 提升了 Python 与 JavaScript 并列的地位，以高性能的无服务器平台面向不断增长的 AI 和数据科学社区。
