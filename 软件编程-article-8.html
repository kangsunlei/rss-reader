yovoice：本地开源配音工具与 Claude Code Agent Skill

9/26/2026, 1:30:03 PM

📌 一句话摘要

介绍开源本地配音工具 yovoice，支持声音克隆与情绪控制，并附带 Claude Code Agent Skill 实现自动化配音。

📝 详细摘要

针对短视频和有声书制作中配音成本高、隐私泄露及操作繁琐的痛点，介绍了开源工具 yovoice。该工具支持 macOS 和 Windows，提供 IndexTTS、VoxCPM2、OmniVoice、Qwen3-TTS 等多种模型，具备本地运行、声音克隆及情绪控制能力。此外，项目附带了 Claude Code Agent Skill，允许开发者通过代码直接生成配音文件，极大提升了批量内容生产的效率。

💡 主要观点

  1. 本地化解决配音隐私与成本问题 yovoice 将文字转语音、声音克隆等核心功能部署在本地，避免了在线服务按字数收费及数据上传服务器的风险，且支持硬件加速。
  2. 多模型支持与灵活的声音设计 集成 Qwen3-TTS 等主流模型，既支持基于参考音频的克隆，也支持通过自然语言描述直接生成特定腔调的声音。
  3. Claude Code Agent Skill 提升工作流效率 通过配套的 Agent Skill，开发者可直接利用 Claude Code 处理音频任务，无需切换桌面应用，特别适合需要批量生成口播内容的场景。
