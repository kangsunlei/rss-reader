MacBook 触控板“张口说话”，还能来段 Rap！开发者极限整活，开源便狂揽 1.9k Star

📌 一句话摘要

开发者 Cody Collier 开源了名为 NO SPEAKER 的项目，通过控制 MacBook 触控板的触觉驱动装置绕过内置扬声器直接发声，引发极客圈广泛关注。

📝 详细摘要

开发者 Cody Collier 在 GitHub 上开源了名为 NO SPEAKER 的项目，展示了如何让 MacBook 触控板「兼职」当扬声器。该项目不依赖任何外部音频设备或拆解硬件，而是通过 macOS 私有框架（MultitouchSupport）调用触觉马达，利用线性预测从语音中提取关键共振峰，转换为正弦波信号驱动玻璃面板高频振动，从而实现朗读文字甚至播放 Rap 的效果。项目上线后迅速获得大量 Star，展现了极客探索硬件边界的趣味性，同时也引发了关于音质限制、私有 API 兼容性以及硬件寿命的讨论。

💡 主要观点

  1. 利用触觉马达驱动玻璃面板发声 通过控制 MacBook 的 Force Touch 触控板以最高每秒约 4000 次的频率振动，直接带动周围空气发声，无需依赖内置扬声器或额外音频设备。
  2. 基于共振峰特征将文字转为振动信号 项目通过 macOS 自带语音功能生成原始音频，每隔 10 毫秒提取两个主要共振峰及音高响度，转换为触控板可执行的振动信号，从而实现文字朗读。
  3. 调用 macOS 私有框架实现精细控制 项目绕过了苹果公开 API 的限制，直接调用内部的 MultitouchSupport 私有框架，从而能够连续改变频率和强度，但这也带来了系统更新可能导致失效的风险。

💬 文章金句

  • 即使将 MacBook 内置扬声器静音，触控板依然能发出声音。
  • NO SPEAKER 并没有打算取代 MacBook 的扬声器，也没有解决什么迫切的实际需求。
  • 它更像是一次对硬件边界的探索：一块原本只负责触觉反馈的玻璃，在开发者手里竟然也能承担声音输出的任务。
