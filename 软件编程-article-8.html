第一个全职 AI CEO 来了！29 岁前编程神童正让 AI 替他管理千人公司

5/3/2026, 2:31:00 AM

📌 一句话摘要

29 岁 Brex 创始人 Pedro Franceschi 通过自建 OpenClaw 系统，用 AI Agent 自动化 CEO 日常管理决策，并分享了从编程神童到金融科技创业者的成长历程。

📝 详细摘要

本文编译自播客访谈，讲述了 Brex 创始人 Pedro Franceschi 的传奇经历：8 岁自学编程，12 岁越狱 iPhone，14 岁赚取 30 万美元，后创立巴西版 Stripe 和金融科技公司 Brex（以 51.5 亿美元出售给 Capital One）。文章核心亮点在于 Pedro 正在用自研的 OpenClaw 系统构建 AI CEO 工作流，通过信号摄取管道、自动化任务解析和 Agent 间对抗式监控，实现用 AI 处理日常管理决策。他还提出了「用另一个 LLM 监控 Agent」的 Crab Trap 方案，并分享了关于 AI Agent 部署安全、虚拟员工管理以及未来财务决策自动化的深度思考。

💡 主要观点

  1. Pedro Franceschi 正在用自研 OpenClaw 系统实现 AI 驱动的 CEO 工作流。 系统通过信号摄取管道扫描邮件、Slack 等数据源，以人和项目为核心对象筛选信息，自动生成摘要和待办事项，并利用 autoresolver 模块自动推进任务执行。
  2. 用另一个 LLM 监控 Agent 是确保 AI 安全运行的有效方案。 Crab Trap 系统通过 HTTP 代理拦截 Agent 流量，由另一个 LLM 审查所有请求是否合规，形成对抗式监督结构，解决 Agent 部署中的安全问题。
  3. AI 时代真正的竞争壁垒在于定义公司独特气质（Ethos）的判断力。 当技术卓越成为标配，如何为 AI 注入公司特有的价值观和筛选标准，以及识别那些纯粹热爱创造的人才，才是人类决策的核心价值所在。
  4. 未来财务决策将因 AI 实现质的飞跃，但人类仍需为 Agent 行为负责。 AI 可聚合信息辅助决策，但关键判断仍需人类把关。Agent 也需要像员工一样有经理监督，建立反馈和问责机制。

💬 文章金句

  • 当你有一个像 OpenClaw 这样的 agent 在运行时，最好的监控方式不是让人类盯着，而是让另一个 LLM 来盯着。
  • 如果把非核心的杂事都交给模型，剩下的这些需要极高洞察力的问题，才是人们真正应该投入精力的地方。
  • 好奇心、精力、投入当然都很重要。但对我来说，这一切最终都来自一种非常强烈的创作驱动，而不是传统意义上的'工作'心态。
  • 我们塑造了工具，尔后工具又反过来塑造了我们。
  • 你无法简单论证'招一个从小自学代码的人'和'招一个在 OpenAI 或 Anthropic 做研究的机器学习博士'哪个更好，这完全取决于你想构建什么样的公司。
