💡 主要观点

  1. Remix 3 RC 摆脱 React 依赖，走向独立全栈框架 Remix 已完成从 React 框架到独立全栈框架的重写，官网定位改为「单一包」满足现代 Web 应用全部需求。正式版计划 10 月 2 日发布，当前已可上手开发，标志着其技术路线与 React 生态正式解耦。
  2. pnpm 12 用 Rust 重写但保持命令与 lockfile 兼容 v12 底层从 JavaScript 迁移至 Rust 实现，v11 的几乎全部命令、参数和 lockfile 格式直接迁移，仅有寥寥几处变动。npm latest tag 仍指向 v11，需执行 pnpm self-update next-12 才能升级。
  3. htmx 4.0 首次大版本发布，从 XMLHttpRequest 迁移至 Fetch API 作为「反 SPA」库两年来首个大版本，核心变化是请求层从 XHR 切到 Fetch API；属性继承改为默认关闭、事件标准化并重命名，新增 morphing swaps 与特性。
  4. Zod 4.5 通过方法记忆化将单 schema 内存占用降低 9 倍 深度文章详解方法记忆化优化机制，朴素 z.string()的堆内存占用从 7.5KB 压缩至 784 字节，是 TypeScript 优先 schema 校验库的重大性能发布。
  5. Lovable 以 85 万行规模从 Next.js 平稳迁移至 TanStack Start 通过反向代理并行运行新旧两套栈，两端共享同一代码目录，完成大规模 Monolith 迁移，为同类项目提供了可参考的工程实践路径。
