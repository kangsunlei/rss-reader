微软开源 GitHub Copilot Chat 扩展

6/1/2025, 12:00:00 AM

📌 一句话摘要

微软计划开源 GitHub Copilot Chat 扩展，并将核心人工智能集成到 VS Code 中，使其成为 AI 原生编辑器。

📝 详细摘要

在 Build 2025 大会上，微软宣布计划在 MIT 许可证下开源 GitHub Copilot Chat 扩展的代码，并将其核心人工智能功能重构到 VS Code 的主代码库中。此举的原因在于，随着 LLM（大型语言模型）的进步，专有提示词的价值逐渐降低。同时，此举也解决了扩展开发者要求更紧密地集成到 VS Code 核心中的需求（此前，他们难以使用稳定 API 实现深度集成）。此外，微软还希望通过稳定核心 API 广泛提供核心人工智能功能，从而挑战那些仅在功能上竞争的 VS Code 衍生版本。该计划旨在提高数据收集的透明度，并加强社区驱动的安全性。开发者对此反应普遍积极，他们看好集成本地 AI 模型的前景及其对编辑器竞争格局的影响。这将推动 VS Code 默认演变为“AI 原生编辑器”。

💡 主要观点

  1. 微软将开源 Copilot Chat，并将人工智能功能集成到 VS Code 核心中。 该战略举措通过开放源代码，将核心人工智能功能集成至主编辑器，旨在实现更紧密的集成，并促进社区的广泛参与。
  2. LLM 的进步降低了专有提示词的竞争优势。 随着 LLM 的可访问性和透明度提高（例如 Anthropic 发布提示词），保持特定提示策略的私密性的价值降低。
  3. 开源和核心集成解决了开发者的请求，并挑战了编辑器衍生版本。 此举允许扩展开发者使用稳定的 API 进行深度集成，并削弱了 Cursor 等 VS Code 衍生版本的基于功能的竞争策略。

💬 文章金句

  • 在 Build 2025 大会上，微软宣布计划在未来几个月内，在 MIT 许可证下开源 GitHub Copilot Chat 扩展背后的代码，并将核心人工智能功能直接重构到 VS Code 的主代码库中。
  • 该计划使 VS Code 不仅支持人工智能扩展，而且默认演变为“AI 原生编辑器”。
  • Reddit 和 Hacker News 等平台上的开发者普遍对开源表示赞赏。
  • 通过将 Copilot Chat 扩展以 MIT 许可证开源，并将其核心功能集成到 VS Code 核心中，微软可能会大大削弱那些软件开发资源有限的衍生版本，使其难以仅凭功能与庞大的扩展开发者社区竞争。
