今天，Chrome 应用商店将彻底移除所有 Manifest V2 扩展，趁现在如何备份？

8/31/2026, 1:00:14 PM

📌 一句话摘要

本文介绍了 Chrome 应用商店即将移除所有 Manifest V2 扩展的背景，并提供了详细的备份和恢复指南，包括批量备份整个扩展文件夹和单个扩展的打包方法，以帮助用户在扩展被移除前保存重要功能。

📝 详细摘要

随着 Chrome 138 的发布，谷歌将彻底从应用商店中移除所有基于 Manifest V2 的扩展程序。为了防止数据丢失，用户可以备份扩展文件夹或打包单个扩展进行恢复。文章详细说明了在 Windows 和 macOS 上找到扩展存储位置的步骤，以及如何通过加载未打包的扩展来恢复功能。

💡 主要观点

  1. Manifest V2 扩展即将被移除 根据谷歌的计划，2026 年 8 月 31 日后，所有基于 Manifest V2 的扩展将从 Chrome 应用商店中消失，且无法重新安装。
  2. 备份方法：批量与单个 用户可以通过复制整个 'Extensions' 文件夹来批量备份，或者通过打包特定 ID 的文件夹来备份单个扩展。恢复时，只需将文件覆盖到原位置或加载未打包的扩展即可。
  3. 恢复注意事项 恢复的扩展可能会显示一个特殊标记，表示其为本地加载而非商店下载。此外，备份时应确保 Chrome 已完全退出，以避免数据损坏。

💬 文章金句

  • 注意：安装在 Chrome 138 或更早版本上的 Manifest V2 扩展程序将保留安装状态，但无法接收任何更新，并且从 Chrome 中移除后无法从 Chrome 应用商店重新安装。
  • 如果想连扩展设置、数据库等数据也尽可能保存下来，建议直接备份整个 %LOCALAPPDATA%\Google\Chrome\User Data\Default\。
