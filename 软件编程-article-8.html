构建无服务器、后量子加密的 Matrix 家用服务器

1/27/2026, 2:00:00 PM

📌 一句话摘要

Cloudflare 展示了一个基于 Workers 构建的无服务器 Matrix 家用服务器概念验证，提供后量子安全、零闲置成本和全球边缘性能。

📝 详细摘要

本文详细介绍了将 Matrix 家用服务器从传统的有状态单体架构迁移到使用 Cloudflare Workers 的无服务器架构的技术细节。通过将 PostgreSQL、Redis 和文件系统等传统组件映射到 Cloudflare 的 D1、KV、R2 和 Durable Objects，团队消除了服务器管理的运维“税”。核心亮点包括在传输层实现后量子加密（X25519MLKEM768）、使用 Durable Objects 进行强一致性状态解析，以及采用 Sliding Sync 优化移动端性能。最终实现了一个高度安全、免维护且成本随实际使用量缩放的家用服务器。

💡 主要观点

  1. 无服务器原语可以替代复杂协议的传统有状态基础设施。 通过将 SQL 映射到 D1，Redis 映射到 KV，互斥锁映射到 Durable Objects，开发者可以在无需管理 VPS、负载均衡器或数据库的情况下运行像 Matrix 这样的有状态应用。
  2. 传输层默认集成后量子加密。 该实现利用了 Cloudflare 的混合 X25519MLKEM768 密钥协商，无需手动配置即可保护数据免受未来量子计算机的威胁。
  3. Durable Objects 解决了基于边缘的状态解析的一致性挑战。 虽然 D1 处理通用数据，但 Durable Objects 提供了单线程、强一致性的存储，这对于声明一次性加密密钥等原子操作至关重要。
  4. 无服务器模式显著降低了运维成本和延迟。 闲置时成本缩减至零，全球分布确保消息处理发生在离用户最近的边缘位置，将延迟降低至 20-50ms。

💬 文章金句

  • Workers 提供了拥有数据的主权，而无需承担拥有基础设施的负担。
  • 我们剥离了操作系统、数据库管理和网络配置，只留下应用逻辑和数据本身。
  • 传统的家用服务器无论是否有人使用都要花钱。Workers 的定价是基于请求的，所以你在使用时付费，但当大家都在睡觉时，成本会降至接近零。
  • 随着 Cloudflare PQC 部署的扩展，安全态势也会随之提升——我们无需采取任何行动。
  • Matrix 是一个需要投入时间和金钱来喂养的有状态、沉重的猛兽……我们想看看是否能完全消除这种负担。
