“Windows 该淘汰了！”Rails 之父 DHH 开炮：微软上万工程师干不过一个人带着 AI 干活

11/23/2026, 9:34:00 AM

📌 一句话摘要

DHH 在播客中阐述 AI Agent 正在重塑软件行业竞争格局，主张通过 Omarchy Linux 发行版实现桌面端用户规模超过 macOS，同时强调开源模型与前沿实验室的平衡发展至关重要。

📝 详细摘要

本文基于 DHH（Ruby on Rails 之父）在播客中的专访，深入探讨了 AI Agent 时代来临对软件行业的颠覆性影响。DHH 指出，macOS 和 Windows 已不适合 Agent 时代，而 Omarchy Linux 发行版恰好具备 Agent 最擅长处理的终端、配置文件等特性。他分享了通过 AI Agent 开发 Omarchy 项目的实践经验，包括如何用数十万行代码加速开发。文章还讨论了 AI 正在降低软件开发成本，可能让小团队复刻 Adobe Lightroom 等专业软件，甚至消灭部分传统应用。DHH 强调开源模型与前沿实验室的平衡发展，警示闭源垄断的风险。他计划于 3 年内让 Linux 用户规模超过 macOS（约 1.8 亿），并预测 AI 将在软件开发领域实现超级智能。

💡 主要观点

  1. macOS 和 Windows 不适合 Agent 时代，Omarchy Linux 是天然的 Agent 原生操作系统 Linux 过去让人头疼的终端、配置文件和复杂错误信息，恰恰是 Agent 最擅长处理的特性。相比之下，Apple 正在增加 macOS 与 Agent 协作的难度，甚至警告用户不要让 Claude 访问文件。
  2. AI Agent 正在重塑软件行业竞争规则，降低开发成本 AI 正在让软件开发成本快速下降，过去只有微软、Adobe 等巨头才能建立的产品和生态，小团队如今有机会重新创造。Agent 可以直接完成用户原本需要通过应用才能完成的工作。
  3. Omarchy 通过 AI Agent 实现从虚拟试错到真机 Skill 固化的闭环 整个操作系统都有 Agent 参与开发，DHH 没有亲手写过代码，但通过 Agent 生成了几十万行代码。用户可以灵活修改操作系统功能，实现从 30 分钟到几十秒的 97 倍速度提升。
  4. 开源模型与前沿实验室需要平衡发展，避免双寡头垄断 DHH 虽欣赏 Opus 等闭源模型，但强调 AI 行业不能变成两家实验室瓜分市场的双寡头格局。开源和开放权重至关重要，能够让行业保持公平竞争。
  5. 计划 3 年内让 Linux 桌面用户规模超过 macOS 全球 macOS 用户约 1.8 亿，Linux 完全有机会超过这个数字。DHH 通过 Quattro 版本全面投入 Agent 开发，用 Agent 构建产品，再把 Agent 交给所有用户手中。
