CF 发布 EmDash CMS：基于 Astro 的现代内容管理系统

11/8/2026, 1:44:20 PM

📌 一句话摘要

介绍 Cloudflare 推出的 EmDash CMS 系统，它基于 Astro 构建，拥有 WordPress 风格的后台和 MCP CLI 工具。

📝 详细摘要

作者分享 Cloudflare 发布的 EmDash CMS，有人尝试吗。提到早在前个月就发布 1.0 版，基于 Astro 的 CMS，拥有 WordPress 风格的管理后台，内置 MCP CLI，方便 Agent 使用，同时兼容 Cloudflare 全家桶环境。界面清爽美观，基于 Cloudflare 的 Kumo UI 组件库。适合需要搭建 CMS 的开发者尝试。

💡 主要观点

  1. EmDash 是基于 Astro 构建的 CMS 使用 Astro 框架搭建，具有较好的性能和开发体验，适合现代化 Web 项目。
  2. 具备 WordPress 风格的管理后台 让使用者有熟悉的内容管理体验，降低学习成本。
  3. 内置 MCP CLI，兼容 Cloudflare 全家桶 便于 Agent 集成使用，支持 Cloudflare 的全部生态环境，提升开发效率。
