谷歌 DeepMind 发布 Gemini 2.5 计算机使用模型，赋能 UI 控制 AI 代理

10/9/2025, 5:45:00 PM

📌 一句话摘要

谷歌 DeepMind 的 Gemini 2.5 计算机使用模型通过感知屏幕上下文并执行操作，使 AI 代理能够直接控制图形用户界面。

📝 详细摘要

谷歌 DeepMind 推出了 Gemini 2.5 计算机使用模型，它是 Gemini 2.5 Pro 系统的一个专门变体，旨在使 AI 代理能够直接与图形用户界面交互。该模型使开发人员能够创建 AI 代理，这些代理可以点击、键入、滚动和操作网页，甚至潜在的移动应用上的交互元素。该系统通过迭代循环运行。开发人员提供环境截图、任务描述和历史操作记录，模型返回结构化的函数调用，由客户端执行这些调用，实现 UI 操作。早期评估表明，该模型在界面控制基准测试中表现出色，在 Online-Mind2Web 上实现了约 70%的准确率，并且响应时间优于其他系统。但是，一位高级数据科学顾问对该模型是否已准备好投入生产表示担忧，理由是当前实现可能存在速度瓶颈，并且可能被标准的 API 调用所取代。DeepMind 强调集成强大的安全防护措施，包括每个步骤的安全评估和敏感操作的用户确认要求，以降低与 UI 控制 AI 代理相关的风险。该模型目前通过谷歌 AI Studio 和 Vertex AI 中的 Gemini API 提供预览。

💡 主要观点

  1. Gemini 2.5 计算机使用模型使 AI 代理能够直接与图形用户界面进行交互。 这种专用模型使 AI 能够感知屏幕上的上下文并执行诸如单击、键入和滚动之类的操作，从而显著提高 Web 和移动环境的自主智能体能力。
  2. 该模型通过迭代循环运行，将视觉输入转换为结构化的 UI 操作以供执行。 开发人员将屏幕截图和任务馈送到模型，该模型会生成可执行的操作，从而可以与 Web 和移动环境进行动态和自适应的交互，并重复执行直到任务完成。
  3. 尽管基准测试性能强劲，但实际的生产部署面临着速度和替代集成方法等挑战。 尽管该模型具有创新性，但专家反馈表明，当前实现可能存在速度瓶颈，对于某些任务，直接 API 调用或应用集成可能更为高效。
  4. 集成了强大的安全措施，以防止恶意使用并确保 AI 代理的安全可靠部署。 DeepMind 已通过每个步骤的操作评估和敏感操作的用户确认要求来优先考虑安全性，从而解决了 UI 控制 AI 的关键问题。

💬 文章金句

  • 新模型使开发人员能够构建可以单击、键入、滚动和操作网页上的交互元素的代理。
  • 实际上，该模型通过 Gemini API 公开的新 *computer_use* 工具在一个循环中运行。
  • 这种类型的解决方案很有前途，但我认为它尚未准备好投入生产。当前的实现非常慢，并且通常可以用标准的 API 调用或直接的应用程序集成来代替。
  • Gemini 2.5 计算机使用模型集成了针对 Web 环境中恶意提示、不安全操作和诈骗的保护措施。
