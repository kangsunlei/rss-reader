Agent 是雷声大雨点小？5 位创始人吐真言：“内争外患”还被错配、基模威胁也挺狠

12/11/2025, 4:31:00 AM

📌 一句话摘要

本文深入探讨了 AI Agent 领域的发展现状、挑战与机遇，剖析了通用与垂直 Agent 的路线之争，并指出在基模冲击下，Agent 仍有巨大商业价值，但需精准定位。

📝 详细摘要

文章围绕 AI Agent “雷声大雨点小”的质疑展开，通过采访多位行业创始人与技术负责人，揭示了 Agent 市场现状。核心问题在于场景选择与 Agent 能力的错配，而非技术性能瓶颈。文章详细讨论了通用 Agent 面临的成本高、落地难、价值定位模糊等问题，以及垂直 Agent 在特定领域的深度优势。同时，文章分析了基础大模型崛起对 Agent 赛道的冲击，以及科技巨头对 Agent 通信标准主导权的争夺。尽管面临泡沫与挑战，但文章强调 Agent 在金融、电信、能源等领域仍蕴含巨大商业潜力，并认为 Agent 市场最终将走向通用与垂直协同发展的动态平衡，而非非此即彼的淘汰赛。

💡 主要观点

  1. AI Agent 市场面临的质疑核心是场景与能力错配，而非技术性能瓶颈。 通用 Agent 被误用于垂域简单场景或低价值通用场景，导致其核心价值难以体现，使用者体验不佳，而非 Agent 本身技术不足。
  2. 通用与垂直 Agent 路线之争最终将走向协同发展，而非替代。 通用 Agent 将承担通用任务处理，垂直 Agent 深耕领域深度决策，两者互补。垂直 Agent 凭借行业资源和场景壁垒，长期价值不可替代。
  3. 基模能力的快速提升对 Agent 市场构成冲击，但拥有独特数据和专业深度的垂直 Agent 仍有生存空间。 通用大模型迭代速度快，冲击了纯粹依赖基模能力的 Agent，但如医疗等拥有独特、难以获取数据的垂直领域 Agent，因其高精度和专业性具有不可替代的价值。
  4. Agent 领域虽有泡沫，但已展现出显著的商业价值。 虽然存在倒闭项目，但 Agent 初创公司融资额和营收增长强劲，尤其在编程、IT、知识管理等领域已实现盈利，未来在金融、电信、能源等领域潜力巨大。

💬 文章金句

  • “核心在于场景选择与 Agent 能力的错配，而非技术本身的性能瓶颈。”
  • “不管是通用 Agent 还是垂直 Agent，受限于基础大模型的发展水平、技术成熟度，以及解决方案与实际需求的匹配度等因素，现阶段确实存在一些明显缺点，也很容易被大家感知到，但这并不会成为阻碍行业发展的根本原因。”
  • “博弈”在升级，终局不会是二选一。
  • “只要能解决问题，就是很有价值的产品。”
  • “即便模型未来去做类似事情，大概率也会采用类似 Agent 的运作方式。”
