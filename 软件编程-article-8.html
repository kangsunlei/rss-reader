试试你显卡一秒的计算量，用 CPU 单核需要算多久

6/9/2026, 4:05:14 AM

📌 一句话摘要

本文介绍了一个基于 GPU 并行加密与 CPU 单核解密的时间锁算法，通过调整并发数可实现几秒加密对应一天解密的效果，并提供了在线演示。

📝 详细摘要

文章介绍了一个利用 GPU 与 CPU 算力差异实现的时间锁算法。作者基于此前讨论过的仅含 3 个运算操作的解密函数，更新了加密方案。通过 GPU 并行加密，可以在高端显卡上实现几秒的加密时间对应 CPU 单核一天的解密时间，比例可达万级。文章提供了在线演示页面，用户可调整并发数与 Cost 参数来测试 GPU 加密性能，加密完成后可生成解密链接，用于测试 CPU 单核的解密速度。作者指出 CPU 单核性能差距不大，因此解密时间相对公平，这也是该锁的设计意义。

💡 主要观点

  1. 利用 GPU 并行加密与 CPU 单核解密的速度差实现时间锁。 算法核心是利用 GPU 大规模并行计算能力快速完成加密，而解密过程依赖 CPU 单核串行执行，两者算力差异可达万倍，从而实现几秒加密对应一天解密的效果。
  2. 在线演示允许用户自定义并发数与 Cost 参数。 演示页面默认 8192 并发，高端显卡可调高；Cost 参数控制加密复杂度，调高后可更充分测试 GPU 性能。
  3. CPU 单核性能差距小，解密时间相对公平。 与 GPU 不同，CPU 单核频率上限接近（约 6GHz），不同设备间的解密时间差异不大，保证了时间锁的公平性。

💬 文章金句

  • GPU 并行加密时间 / CPU 单核解密时间的比例更大，在高端显卡上可达到万级，几秒钟的加密可生成一天的解密。
  • CPU 单核性能不像 GPU 那样有巨大差距，即使顶配也只有 6GHz 左右，因此解密的时间差距相对公平，这也是这个锁的意义。
