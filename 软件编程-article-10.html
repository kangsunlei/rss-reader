PerryTS：基于 LLVM 的原生 TypeScript 编译器

4/21/2026, 12:34:14 PM

📌 一句话摘要

PerryTS 是一个能将 TypeScript 直接编译为原生二进制文件且支持原生 UI 控件的开源库，无需 Node.js 或 Electron 运行时。

📝 详细摘要

推文介绍了一个名为 PerryTS 的新兴开源项目。该工具的核心特性在于脱离了传统的 JavaScript 运行时（如 Node.js）和 WebView（如 Electron），利用 SWC 和 LLVM 技术栈将 TypeScript 代码直接编译为真正的原生二进制文件，并支持原生 UI 控件。虽然目前官网展示的作品多为 Demo 级别，但其技术路径为高性能跨平台桌面应用开发提供了新的想象空间。
