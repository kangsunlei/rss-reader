快手发布 SeamlessFlow 框架：完全解耦 Trainer 与 Agent，时空复用实现无空泡的工业级 RL 训练！

8/21/2025, 11:30:00 AM

📌 一句话摘要

快手发布 SeamlessFlow 框架，通过解耦 Trainer 与 Agent 及标签驱动的时空复用，实现工业级 RL 训练吞吐量翻倍。

📝 详细摘要

快手 Kwaipilot 团队推出 SeamlessFlow 强化学习训练框架，旨在解决大模型 RL 训练中 Trainer 与 Agent 强耦合以及算力利用率与系统稳定性之间的矛盾。该框架通过引入独立数据平面（Trajectory Manager 和 Rollout Manager）彻底解耦训练逻辑与智能体，实现对 Agent 无感知的模型更新和轨迹管理。其次，创新性地提出标签驱动的资源调度范式，通过“时空复用 pipeline”统一训推共卡与训推分离模式，有效消除流水线空泡，大幅提升 GPU 利用率。实际测试显示，SeamlessFlow 使端到端吞吐量提升 100%，训练时间减少 62%，并在实际软件工程任务中显著提升大模型性能，展现了卓越的工业级应用价值。

💡 主要观点

  1. 数据平面彻底解耦 Trainer 与 Agent，提升系统灵活性 Trajectory Manager 透明捕获 token 级 I/O，Rollout Manager 无感协调模型更新，使训练与智能体实现独立，降低维护成本，提升开发效率。
  2. 标签驱动调度与时空复用，消除 Pipeline Bubble 通过为资源赋予能力标签，动态调度训练与推理任务，将机器闲置时间压缩至零，大幅提升异构集群算力利用率。
  3. 工业级验证显示显著性能提升与实际应用价值 相比主流框架，吞吐量提升 100%，训练时间减少 62%，并在软件工程任务中显著提升 Qwen 模型性能，验证了其在复杂场景下的有效性。

💬 文章金句

  • SeamlessFlow 的第一个关键创新是引入了独立的数据平面层，彻底解耦了 RL 训练和智能体实现。
  • SeamlessFlow 的第二个创新是提出了标签驱动的资源调度范式。这个设计的精妙之处在于，它没有在 Colocated 和 Disaggregated 之间做非此即彼的选择，而是将两者统一在了统一的抽象框架下。
  • 在实际测试中，SeamlessFlow 的端到端 token 吞吐量相比基线提升 100%，整体训练时间减少 62%。
  • SeamlessFlow 的时空复用 pipeline，将 off-polcy 数据的落后程度控制在了 1 步以内，在实现无空泡的同时，尽可能减小了其对 RL 算法侧的负面影响。
  • SeamlessFlow 的发布标志着工业级 RL 训练进入了一个新阶段。它不再是在现有架构间做取舍，而是从实际算法需求触发，通过以更高观点对 Infra 中各架构进行抽象，实现了新的架构方案，打破了长期存在的效率与稳定性矛盾。
