FerretDB 云：MongoDB Atlas 的开源替代品？

9/6/2025, 12:17:00 PM

📌 一句话摘要

FerretDB 云作为托管的、开源的、MongoDB 兼容的数据库服务推出，构建于 DocumentDB 和 PostgreSQL 之上。它旨在替代 MongoDB Atlas，并挑战 MongoDB 的 SSPL。

📝 详细摘要

FerretDB 宣布推出 FerretDB 云，这是一种托管数据库服务，它使用 PostgreSQL 上的开源 DocumentDB 层提供 MongoDB 兼容性。它旨在成为 MongoDB Atlas 的跨云替代方案，目前已在 AWS 上提供。FerretDB 采用 Apache 2.0 许可，允许开发人员利用现有的 MongoDB 驱动程序和工具，从而简化 MongoDB 工作负载的迁移，同时确保数据存储在 PostgreSQL 中，以确保可靠性，并长期摆脱供应商锁定。该服务提供有竞争力的功能，如高达 64 TB 的存储、加密和企业级 SLA，并且值得注意的是，它开箱即用地提供向量搜索。文章重点介绍了 FerretDB 和 MongoDB 之间关于开源许可的激烈讨论，FerretDB 提倡反对 MongoDB 的服务器端公共许可证 (SSPL)，以促进市场竞争，并防止单一供应商决定价格。

💡 主要观点

  1. FerretDB 云提供了一种托管的、开源的 MongoDB Atlas 替代方案。 它构建于 PostgreSQL 和 DocumentDB 之上，在 Apache 2.0 许可下提供 MongoDB 兼容性，解决了对 MongoDB 的 SSPL 的担忧，让开发者免受供应商锁定的束缚。
  2. 新服务简化数据库管理，并保持与 MongoDB 工具的兼容。 开发人员可以利用现有的 MongoDB 驱动程序和工具，而 FerretDB 云负责处理基础设施、补丁和扩展，从而简化运营并增强开发人员体验。
  3. FerretDB 积极挑战数据库市场的封闭许可模式。 该项目直接反对 MongoDB 的 SSPL，提倡真正的开放竞争，以防止单一供应商控制定价和市场动态。

💬 文章金句

  • 有了 FerretDB 云，这种体验变得更加简单。您不再需要自己管理基础设施、打补丁或者扩展 PostgreSQL，现在可以在几分钟内配置和运行 FerretDB。您的应用程序仍然像与 MongoDB 通信一样连接，但您的数据存储在使用开源 DocumentDB 扩展的 PostgreSQL 中，从而为您提供可靠性和长期自由。
  • FerretDB 云提供的功能集与本地 FerretDB 实例完全相同。例如，MongoDB 中的向量搜索仅在 Atlas 上可用，而 FerretDB 云和本地 FerretDB 都可以直接提供此功能。
  • SSPL 影响巨大——如果只有少数云服务商有权以服务形式提供软件，市场竞争将不复存在，最终形成单一厂商通过许可控制价格的局面。MongoDB 就是一个例子。
  • Ferret 试图以开源为幌子，但实际上是借兼容之名行模仿、盗窃和挪用之实。
