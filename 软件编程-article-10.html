Visual Studio Copilot：更智能的默认模型与更多选择

6/25/2025, 11:24:03 PM

📌 一句话摘要

Visual Studio 的 Copilot 升级 GPT-4.1，扩展模型选择，并提供使用情况追踪，提升开发效率。

📝 详细摘要

本文宣布了 Visual Studio 中 GitHub Copilot 体验的重大更新。主要改进包括将 GPT-4.1 设置为新的默认模型，相比之前的 4o 模型，响应更快，建议质量更高。开发人员现在可以访问更广泛的模型，包括各种 Claude Sonnet 和 Opus 版本、OpenAI o3 mini 和 Gemini 模型（Flash 和 Pro），并在会话中保持选择。此次更新还引入了一个 “Copilot 消耗面板”，用于轻松监控使用情况，这与 GitHub 新的消耗计费模式密切相关。此面板允许用户跟踪高级请求，并提供管理其计划的链接，从而确保 IDE 中 AI 使用成本的透明可控。

💡 主要观点

  1. GPT-4. 1 成为 Visual Studio 中 Copilot 的新默认模型。 提供更快的响应和更高质量的建议，提升编码效率。
  2. 现在可以使用更广泛的尖端 AI 模型选择。 开发人员可以在 Visual Studio 中灵活选择 Claude Sonnet 4、Opus 4、Gemini 2. 5 Pro 等模型，并保持选择偏好。
  3. 新的 “Copilot 消耗面板” 提供透明的 AI 使用情况追踪。 开发人员可以在 Visual Studio 中监控高级请求使用情况，清晰掌握用量，这与 GitHub 的新消耗计费模式密切相关。

💬 文章金句

  • Visual Studio 中的 Copilot 现在使用 **GPT-4. 1** 作为默认模型（之前为 4o）。在我们的测试中，它提供了明显更好的性能，包括更快的响应、更高质量的建议和更高的整体效率。
  • 现在，您可以访问范围更广的模型：Claude Sonnet 4、Claude Opus 4、Claude Sonnet 3. 5、Claude 3. 7（非思考型和思考型）、OpenAI o3 mini、Gemini 2. 0 Flash、Gemini 2. 5 Pro
  • 我们添加了一个新的 **Copilot 消耗面板**，以帮助您监控使用情况。
