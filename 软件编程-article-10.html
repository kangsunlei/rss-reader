📌 一句话摘要

本期 Node 中文周刊汇总了 aube 包管理器、TypeScript 7.0 Beta、.NET Native AOT 编写 Node 原生插件等多项技术热点与工具更新。

📝 详细摘要

本文是 Node 中文周刊第 223 期，精选了近期 Node.js 生态中的多个重要动态。头条是 mise 作者推出的新包管理器 aube，主打极致性能和安全默认。TypeScript 7.0 Beta 发布，其 Go 重写的编译器号称快 10 倍。微软展示了如何使用 .NET Native AOT 编写 Node.js 原生插件。此外还介绍了 Optique 1.0 类型安全 CLI 解析器、DocMD 文档站点生成器、新版 RocksDB 绑定等工具，以及 Bun v1.3.13 的更新和多个生态项目的版本发布。

💡 主要观点

  1. aube 是 mise 作者推出的新 Node.js 包管理器，主打高性能和安全默认。 作为又一个包管理器，aube 的卖点在于极致性能和开箱即用的兼容性，同时默认启用安全策略，为开发者提供更高效、更安全的依赖管理体验。
  2. TypeScript 7.0 Beta 发布，Go 重写的编译器速度提升约 10 倍。 这是首个用 Go 重写的原生 TypeScript 编译器 Beta 版本，性能提升显著。同时，TS 6.0 作为过渡版本仍很重要，因为 7.0 共享了 6.0 的默认配置变更。
  3. .NET Native AOT 技术可用于编写 Node.js 原生插件。 开发者现在可以使用 C# 等 .NET 语言编写 Node 原生插件，通过 Native AOT 编译为共享库并暴露 N-API 入口点，为 Node.js 生态引入 .NET 生态的能力。
