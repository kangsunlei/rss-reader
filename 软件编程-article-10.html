用了 Rust，谷歌实测：Android 上内存漏洞率比 C/C++低 1000 倍！

11/14/2025, 8:21:00 AM

📌 一句话摘要

谷歌实测数据显示，在 Android 系统开发中引入 Rust 语言后，内存安全漏洞率比 C/C++降低了 1000 倍，同时显著提升了开发效率和代码稳定性。

📝 详细摘要

本文详细分析了谷歌在 Android 系统开发中引入 Rust 语言的实践成果。根据谷歌发布的 2025 年最新数据，Android 中的内存安全漏洞首次降至所有漏洞的 20%以下。研究表明，Rust 代码的内存安全漏洞密度比 C/C++代码低 1000 倍。此外，Rust 还带来了显著的开发效率提升，包括代码变更回滚率降低 4 倍，代码审核时间减少 25%。文章深入探讨了谷歌在 Android 系统、内核、固件及自有应用中扩大 Rust 应用范围的计划，并分享了如何通过 Scudo 加固分配器和加强 unsafe Rust 培训来进一步提升安全性的经验。谷歌强调，Rust 使其能够在“快速”与“安全”之间找到平衡，实现更高效、更安全的系统开发。

💡 主要观点

  1. Rust 显著降低了 Android 系统的内存安全漏洞密度 谷歌实测数据显示，Rust 在 Android 上的内存安全漏洞密度比 C/C++低 1000 倍，使内存安全漏洞占比首次降至 20%以下，大幅提升了系统安全性。
  2. Rust 提升了软件开发效率和代码稳定性 采用 Rust 后，代码变更回滚率降低了 4 倍，代码审核所需时间减少 25%，这意味着更少的返工和更快的交付，提高了整体开发吞吐量和质量。
  3. 谷歌正积极将 Rust 应用扩展到更多关键领域 基于 Rust 在 Android 系统中的成功经验，谷歌计划将其推广到 Linux 内核、固件以及多款自有安全敏感应用中，以进一步提升整体安全性。
  4. 多层防御体系与培训是保障 Rust 安全性的重要补充 通过 Scudo 加固分配器及时发现潜在漏洞，并加强对 unsafe Rust 代码的培训，确保开发者能安全有效地使用 Rust 的底层控制能力。

💬 文章金句

  • 与 Android 现有的 C/C++ 代码相比，Rust 带来的内存安全漏洞密度降低了 1000 倍。
  • Rust 相关变更的回滚率降低了 4 倍，代码审核所需时间也减少了 25%。
  • 开发一款操作系统离不开像 C、C++ 和 Rust 这些系统级编程语言所提供的底层控制与可预测性。
  • Google 称，以往想降低内存安全风险，只能依靠静态分析、运行时防御、沙箱隔离、快速补丁等方式，每种方式都要付出性能或开发效率的代价。但 Rust 带来了另一种路线：最安全的路径，同时也是最高效的路径。
  • 提升开发者对 unsafe Rust 的理解，将进一步提高 Android 和整个开源生态的代码质量。
