装好 OpenClaw，首件要干的必须是这件事！（第 5 讲，干货收藏）

3/8/2026, 7:42:00 AM

📌 一句话摘要

本文针对 AI Agent 工具 OpenClaw 运行中的安全风险，提出了包含修改确认、自动备份、审计、回滚等在内的六大安全规范，旨在通过 Prompt 约束确保 Agent 行为可控。

📝 详细摘要

文章作者分享了在使用 OpenClaw 过程中的安全治理经验。针对 AI Agent 可能存在的自主安装未知插件、误删配置或泄露敏感信息等风险，作者构建了一套基于 SAFETY.md 的安全框架。该框架涵盖了六个核心维度：建立高/中/低危行为的分级确认机制、触发式自动备份、详细的变更审计日志、异常情况下的回滚流程、敏感数据脱敏存储以及 Skill 安装的白名单审核。通过将这些规范集成到 Agent 的核心配置文件中，实现了对 AI 行为的有效约束和可追溯性，并展示了 Agent 在规范约束下的实际运行效果。

💡 主要观点

  1. 建立基于风险等级的行为确认机制，平衡效率与安全。 将 Agent 行为分为高、中、低危三个等级，规定高危必须人工确认，中危需告知，低危可直接执行，确保关键操作在人类掌控中。
  2. 通过 Prompt 强制执行自动备份与回滚机制。 在 Agent 修改关键配置前触发备份，并预设回滚指令模版，防止因 AI 错误操作导致系统失控、飞书失联或配置丢失。
  3. 实施变更记录审计与检查点机制，确保操作透明。 详细记录 Agent 的每一次文件修改和变更日志，并通过检查点机制防止记录遗漏，为后续的安全审计提供完整证据链。
