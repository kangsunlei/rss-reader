Vibe Coding 了两年，分享一下我对于 Vibe 的感想。

6/20/2026, 9:41:43 AM

📌 一句话摘要

本文以亲身经历吐槽 Vibe Coding 圈子的乱象，分享从入门到反思的两年实践，并区分了不同层级的 AI 编程使用者。

📝 详细摘要

作者是一名刚参加完高考的学生，从高二开始接触 Vibe Coding，经历了从盲目使用 AI、乱提需求、买课、到用 AI 污染开源仓库的「神人」阶段。文章以自嘲口吻描述了 Vibe Coding 圈子的众生相：真正用 AI 工作的人没空分享、学生被糟糕的大学教育逼得自学、以及那些炫耀 Token 消耗量却解决不了实际问题的「神人」。最后，作者将 Vibe Coding 使用者分为三类：原教旨全程 AI 派、将 AI 作为辅助工具的赛博义体派、以及轻度使用者，并指出前者的能力上限极高、下限也极低。

💡 主要观点

  1. Vibe Coding 圈子存在严重的噪音与神人现象。 真正高效使用 AI 的开发者忙于工作，很少发声；而大量炫耀 Token 消耗、卖课、污染开源仓库的「神人」占据了舆论，导致外界对 Vibe Coding 产生负面印象。
  2. Vibe Coding 使用者可分为三个层级。 原教旨派全程依赖 AI，上限极高但下限极低；赛博义体派自己写架构与关键代码，AI 只负责填空，效率与可控性最佳；轻度使用者仅用 AI 做 MVP 验证或改错，影响有限。
  3. 国内大学计算机教育滞后，倒逼学生自学 AI 编程。 作者举例某高校网安专业的人工智能课作业，老师连「MCP Server」是什么都不懂，反映出教学内容与实际脱节，学生不得不通过 Vibe Coding 等途径自学。

💬 文章金句

  • 真正需要这玩意儿提高工作效率的人 Vibe 完都去忙着干活了，谁有闲工夫在朋友圈和论坛上蹿下跳的。
  • 原教旨 Vibe 的人已经相当于机械飞升了……上限极高的前提是成为掌管提示词工程的神、同时用 Harness Prompt 把 AI 调成星怒；下限就是那种说不清自己需求的人。
