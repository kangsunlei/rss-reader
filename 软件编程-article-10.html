微软又开源了一款 Skill 神器

8/10/2026, 9:05:00 AM

📌 一句话摘要

本文介绍微软开源的 Skill Recorder 工具，通过录屏与 AI 分析将用户操作转化为可复用的 Agent 技能（Skill）或自动化流程。

📝 详细摘要

文章介绍了微软最新开源的桌面工具 Skill Recorder。该工具旨在降低为 AI Agent 编写操作手册（Skill）的门槛，用户通过录屏并口述操作过程，由 AI 分析并将其转化为结构化的意图与步骤。与传统 RPA 记录坐标不同，Skill Recorder 侧重于语义理解，将操作泛化为 Agent 原生工具调用。文中详细说明了其本地化处理的隐私机制、安装方式以及与 Claude Code 等同类功能的对比，强调了通过「演示」而非「编写」来沉淀 AI 技能的趋势。

💡 主要观点

  1. 通过录屏降低 AI 技能（Skill）的创建门槛。 改变了以往需要手动编写详细操作手册的繁琐过程，用户只需演示一遍任务，AI 即可自动生成可复用的执行步骤。
  2. 实现从「坐标记录」到「语义泛化」的跨越。 区别于传统 RPA 依赖界面元素位置，该工具将操作转化为 Agent 原生工具（如 CLI、web_fetch），使单一操作能泛化为一类能力。
  3. 采用本地化处理以保障隐私安全。 录制、存储、画面提取及 Whisper 语音转写均在本地完成，仅在点击分析时将必要时间线和文本发送至云端 AI。

💬 文章金句

  • RPA 记的是鼠标点哪里、按钮在哪个位置，界面一改工作流就废。而 Skill Recorder 是先理解我们想完成什么，再把操作换成 Agent 原生工具。
  • 现在的模型已然足够强大，但要让它成为我们日常工作生活的干活利器，还得靠 Skill 沉淀。
