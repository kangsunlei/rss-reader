Void IDE： Cursor 的开源替代品，发布 Beta 版本

6/21/2025, 12:00:00 AM

📌 一句话摘要

Void IDE： 一款基于 VS Code 的新型开源、注重隐私的 AI 代码编辑器，发布 Beta 版本。

📝 详细摘要

Void IDE 是一款新型开源 AI 代码编辑器，基于 Visual Studio Code 分支而来，现已发布 Beta 版本。该项目获得 Y Combinator 支持，定位为 Cursor 和 GitHub Copilot 等专有 AI 编码工具的免费、注重隐私的替代品，旨在解决用户对数据隐私和订阅费用的担忧。Void IDE 支持各种 LLM ，包括通过 Ollama 进行本地托管和直接 API 调用，让开发者能够掌控代码数据。它提供标准的 AI 编码功能，如行内编辑、聊天和代码生成，以及代码库上下文和 Prompt 编辑等高级功能。由于源自 VS Code ，用户可以轻松迁移设置。该版本的发布引起了开发者社区的广泛关注，引发了关于开源替代品和 VS Code 分支激增的讨论。

💡 主要观点

  1. Void IDE 是一款开源、注重隐私的 AI 代码编辑器。 它作为 Cursor 和 Copilot 等闭源工具的免费替代品，优先考虑用户对代码数据的控制，并支持灵活的 AI 模型集成。
  2. 它解决了专有工具的隐私和成本问题。 通过允许本地处理或直接 API 调用，它避免通过第三方后端发送敏感代码，从而降低嵌入反演攻击等隐私风险。
  3. 基于 VS Code ，它简化了开发者的采用过程。 作为 VS Code 的分支，用户可以轻松迁移现有主题、快捷键绑定和设置，降低切换编辑器的障碍。
