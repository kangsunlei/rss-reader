被迫裁员 75%、只剩 6 个月续命！Tailwind 创始人崩溃自白：全球爆火的 CSS 框架，竟养不起 8 个人

1/8/2026, 9:37:00 AM

📌 一句话摘要

Tailwind CSS 创始人 Adam Wathan 公开表示公司面临严重财务危机，被迫裁员 75%，并指出 AI 对其商业模式冲击巨大，导致流行开源项目难以维系团队生存。

📝 详细摘要

文章报道了前端 CSS 框架 Tailwind 的创始人 Adam Wathan 发布的裁员公告和自白。尽管 Tailwind CSS 社区流行度极高，但其商业公司 Tailwind Labs 却面临严重的生存危机，已经裁员 75% 的工程团队，创始人表示公司仅剩 6 个月的运营资金。Adam Wathan 归因于两个主要原因：替代性的开源方案增多，以及大模型（AI）生成 UI 的能力日益增强，导致购买其付费组件和文档访问量的急剧下降。文章回顾了此前社区开发者提交 PR 提议为 AI 优化文档被拒的争议，并引用了 Adam Wathan 沉重回应的细节，揭示了开源项目在流行度与商业化可持续性之间的矛盾与困境。AI 在带来挑战的同时，也正在成为公司维持运营的工具。

💡 主要观点

  1. Tailwind Labs 公司面临严峻生存危机，被迫裁员 75% 且仅剩 6 个月运营资金。 尽管 Tailwind CSS 框架广受欢迎，但其商业运营公司 Tailwind Labs 因收入持续下降，近期裁掉了大部分工程团队，创始人坦承财务状况恶化至仅能支持半年。
  2. AI 和开源替代方案是导致 Tailwind 商业模式受冲击的主要原因。 CEO Adam Wathan 指出，付费产品的开源竞争加剧，以及 AI 生成 UI 的进步，直接导致其文档访问量和付费产品销售额大跌，进而影响公司营收。
  3. 开源项目的流行度与商业可持续性之间存在巨大矛盾。 文章揭示了一个普遍现象：一个技术项目即便在全球范围内极其流行和被广泛依赖，也可能因为无法找到有效的商业模式来支撑运营，而面临生存困境。
  4. 面对商业困境，团队规模进行“结构性改变”，裁员工程师以求自救。 Adam Wathan 强调裁员并非象征性，而是将 4 名工程师团队缩减至 1 人，以在资金耗尽前，确保留任员工能获得体面薪资，并呼吁自己将回归更直接的个人贡献者角色。
  5. AI 在给商业带来挑战的同时，也成为公司维持运营的工具。 Adam Wathan 认为 AI 既是导致当前困境的重要原因，但在现有团队人手极少的情况下，AI 也被用于处理 GitHub Issue 分类和服务器故障诊断等任务，成为提高效率的救命绳。

💬 文章金句

  • “做生意真的很难。比写代码难多了。”
  • “我们只剩六个月时间了。如果情况完全没有改变，大约六个月后，我们将无法再履行支付工资的义务。
  • “我们目前最大的挑战，一方面是那些可以替代我们过去收费产品的开源方案，另一方面是越来越多的人直接用 AI 生成 UI，而不是购买我们出售的组件。”
  • “我亲手打造了一个统治世界、无处不在且超级流行的 CSS 框架，却搞不清楚怎么让它赚到足够养活八个人的钱——八个人啊，这根本就不算什么规模。”
  • “讽刺的是，目前业务的成功程度竟然与开源项目的受欢迎程度呈反比，这太难了。”
