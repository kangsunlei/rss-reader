Docker 桌面版 4.41：Docker 模型运行环境新增 Windows 支持，集成 Docker Compose 与测试容器，并登陆 Microsoft 应用商店

4/29/2025, 1:20:29 PM

📌 一句话摘要

Docker 桌面版 4.41 为 Docker 模型运行环境带来 Windows 平台支持（含 NVIDIA GPU 加速）、增强的模型管理界面、与 Docker Compose 和测试容器的新集成，并正式上架 Microsoft 应用商店。

📝 详细摘要

Docker 桌面版 4.41 带来了专注于 AI 开发和开发者体验的重大更新。本次发布将 Docker 模型运行环境扩展至 Windows 平台（支持 NVIDIA GPU），并新增专用的模型管理界面。与 Docker Compose 和测试容器的新集成实现了 AI 与传统微服务的统一工作流。Visual Studio Code 的 Docker DX 扩展提供了包含代码检查和漏洞扫描的增强开发工具。其他重要更新包括：macOS 上弃用 QEMU 虚拟化、通过 Microsoft 应用商店提供自动更新、新增 ACH 转账支付选项。这些改进旨在简化跨平台的基于容器的 AI 开发。

💡 主要观点

  1. Docker 模型运行环境现支持 Windows 平台（含 NVIDIA GPU 加速） 这一增强功能让 Windows 开发者能够利用 GPU 加速进行 AI 模型开发，扩展了 Docker 在 AI 工作流中的能力，使 Windows 开发团队能更便捷地使用该功能。
  2. Docker 桌面版新增模型管理界面 新增的'模型'专区提供了与容器、卷和镜像并列的模型浏览、运行和管理可视化工具，为 AI 模型管理提供更直观的界面。
  3. 与 Docker Compose 和测试容器的集成 这些集成使开发者能够在统一工作流中管理 AI 模型和传统微服务，并将 AI 模型纳入自动化测试场景，简化端到端开发流程。
  4. Visual Studio Code 的 Docker DX 扩展 这个新扩展提供了全面的开发工具，包括对 Dockerfile 和 Compose 文件的代码检查、漏洞扫描和最佳实践建议，帮助开发者及早发现问题并遵循最佳实践。
  5. macOS 上弃用 QEMU 虚拟化 向 Apple 虚拟化框架的过渡将提升 Apple Silicon 上的性能和稳定性，但使用 QEMU 的开发者需要在 2025 年 7 月前迁移其设置。
  6. Docker 桌面版现已上架 Microsoft 应用商店 Microsoft 应用商店分发简化了 Windows 用户的安装和更新流程，同时通过原生 Intune 移动设备管理(MDM)集成为企业 IT 团队提供更好的部署管理选项。

💬 文章金句

  • 通过将模型视为优先对象(first-class artifacts)，开发者可以使用他们已熟悉的 Docker 容器工具来进行版本控制、分发和部署
  • Docker DX 扩展通过丰富的编辑功能、代码检查特性和内置漏洞扫描来优化您的容器开发工作流
  • 这一新分发渠道为 Windows 用户提供了增强的安装和更新体验，同时简化了 IT 管理员的部署管理
  • 随着 ACH 转账支付选项的引入，客户可以选择最适合其业务的支付方式
  • 这些更新都是为了帮助您使用既熟悉又信赖的工具更高效地工作
