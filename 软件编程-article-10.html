又一个 Agent 神器爆火！

7/6/2026, 9:15:00 AM

📌 一句话摘要

本文介绍 Tutti 这款多 Agent 协作开源工具，通过共享上下文和工作空间，实现不同 Agent 之间的无缝切换与任务协同，并以开发世界杯赛事实时追踪应用为例展示完整工作流。

📝 详细摘要

文章先引出多 Agent 工具切换时上下文丢失的痛点，然后介绍 Tutti：一个类似操作系统的多 Agent 实时共享工作空间，支持接入 Claude Code、Codex 等 Agent，并通过 @ 引用共享上下文、任务和文件。作者以一个「2026 世界杯赛事实时追踪」应用从零开发为例，展示了在 Tutti 中通过 Claude Code 梳理需求、在产品原型设计应用输出设计稿、再交由 Codex 接手作图和改项目的完整链路，全程无需重复背景。最后指出 Tutti 补充了 AI 工具链中容易被忽略的环境层，让 Agent 在同一项目状态与上下文中连续工作。

💡 主要观点

  1. Tutti 的核心价值是解决多 Agent 切换时的上下文丢失问题。 通过共享工作空间和 @ 引用机制，Agent 之间可以自动获取对方的历史会话、文件改动和应用产出，省去人工重复交接。
  2. Tutti 内置了产品原型设计、AI 文档等应用，可实现端到端开发协作。 用户可以在同一空间中完成需求分析、原型设计、代码开发和图像生成，各环节产出可被 Agent 直接引用。
  3. Tutti 支持使用用户已有的 AI 订阅，无需额外付费。 接入 Claude Code、Codex 等 Agent 时，沿用用户已有的 API 额度，降低了使用门槛。
