用 Agent Plan 解锁 AI 导演体验：通过 CUA 搭 Blender 白模指导武侠视频生成

10/8/2026, 11:02:00 AM

📌 一句话摘要

文章演示了利用火山引擎 Agent Plan 中的 CUA（Computer Use Agent）自动操作 Blender 生成武侠视频白模预演，再结合 Seedance 模型生成最终成片的完整工作流。

📝 详细摘要

针对 AI 视频生成中动作与镜头难以精确控制的痛点，本文提出了一种「先导演后拍摄」的解决方案：使用 Agent Plan 专属 Harness——CUA（Computer Use Agent）自动操控云桌面中的 Blender，根据提示词构建包含人物动作、运镜轨迹和分镜时序的三维白模预演视频。随后，将这段白模视频作为运动参考，配合生成的角色/场景参考图，输入给字节 SOTA 级生视频模型 Seedance，从而生成符合严格时空约束的最终写实武侠短片。文章详细拆解了从环境配置、Blender 建模指令、TOS 上传到最终 Prompt 构造的全流程，并展示了 AFP 用量消耗统计，强调该流程适用于对动作和镜头时序有高要求的科幻、都市等题材。

💡 主要观点

  1. 通过 CUA 操作 Blender 生成白模预演，解决 AI 视频动作与镜头不可控问题 传统文生视频模型在复杂动作（如武术招式）和特定运镜（如 360 度环绕）上往往表现不稳定。引入 CUA 让 Agent 直接操控专业三维软件 Blender，以立方体等简化几何体快速搭建出精确的动作轨迹、空间关系和镜头时序，形成可控的「导演脚本」。
  2. 采用「白模视频 + 参考图」的多模态输入策略提升成片质量 最终视频生成阶段，不仅提供角色和场景的高清参考图以保持视觉一致性，更关键的是将 Blender 渲染出的白模视频作为运动参考喂给 Seedance 模型。这种结构化的时空约束能确保生成画面严格遵循预设的分镜节奏和人物交互逻辑。
  3. Agent Plan 套餐整合了从创意到成片的完整工具链与统一计量 火山引擎 Agent Plan 提供了开箱即用的 CUA 环境、主流编程工具兼容接口以及统一的 AFP（Agent Fuel Points）燃料值计量体系。用户无需单独购买或配置复杂的本地 Blender 环境和 API Key，即可串联建模、动画、渲染和视频生成全流程。

💬 文章金句

  • 用 AI 直接生成一段带动作和运镜的视频，最容易卡住的地方是：动作和镜头对不上你想要的效果。
  • 思路其实很像真正的导演拍片：先把人物关键动作、运镜轨迹定下来，Blender 白模则提供了这样的三维空间。
  • 这套 「白模预演 → 参考帧 → 生视频」的流程并不局限于武侠短片。科幻机甲追逐、都市动作戏、古风场景调度等对动作和镜头时序有要求的内容，都可以沿用同样的思路
