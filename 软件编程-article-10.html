The popular disk cleanup tool Mole releases version 1.15， bringing significant performance improvements， enhanced security， and a smoother user experience.

📝 详细摘要

Mole is a developer tool capable of reclaiming tens of gigabytes of disk space in a single cleanup. In less than 80 days， it has rapidly grown to over 20，000 GitHub Stars. This v1.15 release primarily focuses on performance， security， and overall polish. The new version boasts up to 10x faster startup speeds， thanks to optimized Homebrew detection and smarter application scan caching. Disk scanning is now more reliable， automatically skipping slow network volumes. Security has been enhanced by restricting `chown` operations to the user's home directory and disabling risky LaunchServices rebuilds on macOS Sonoma and Sequoia. Additionally， the update introduces pnpm cache cleanup， configurable project cleanup depth， improved terminal output and spinner stability， and broader coverage for protected applications. The test suite has also been significantly expanded to validate performance， permission safety， and uninstall reliability. This release contains no breaking changes， aiming to deliver a faster， safer， and smoother Mole experience.
