📌 一句话摘要

本文介绍了如何使用 Java 和 SpringBoot 搭建 MCP 服务，并结合大模型与 ERP 系统集成，实现数据交互。

📝 详细摘要

本文详细介绍了如何使用 Java 和 SpringBoot 搭建一个基于 MCP 协议的服务端，并通过 SSE 和 HTTP 协议与客户端进行通信，简化 LLM 应用与外部数据源的集成。文章首先介绍了 MCP 协议的基本概念和架构设计，然后逐步讲解了如何使用 SpringBoot 搭建 SSE 服务，以及如何处理客户端发送的初始化、工具列表和工具调用等请求。此外，文章还介绍了如何使用注解和反射机制来自动注册工具方法，简化开发过程。通过 MCP 协议，可以实现诸如语音助手控制 ERP 系统等智能化人机交互。最后，文章展望了 MCP 协议在智能助手等领域的应用前景，并指出了权限控制等需要进一步解决的问题。

💡 主要观点

  1. MCP 协议简化了 LLM 应用与外部数据源的集成 MCP 协议定义了一套标准化的数据通信方式，使得 LLM 应用可以方便地与各种外部数据源和工具进行交互，实现更丰富的功能。
  2. 通过 SSE 和 HTTP 协议实现 MCP 服务端与客户端的通信 服务端通过 SSE 协议向客户端推送消息，并通过 HTTP 协议接收客户端的请求，这种方式可以实现双向通信，满足 MCP 协议的需求。
  3. 使用注解和反射机制可以简化 MCP 工具方法的注册 通过自定义注解 @McpMethod 和反射机制，可以自动扫描和注册 MCP 工具方法，避免了手动配置的繁琐，提高了开发效率。
  4. MCP 协议可以实现人机交互的智能化 通过 MCP 协议，可以将 LLM 应用与语音助手等工具集成，实现通过语音指令控制 ERP 系统等功能，提升用户体验。

  • 我们通过上述的方式完成了一个的 **「MCP」** 服务， 并且也可以为我们的一些其他系统进行扩展，用大模型来改造这些系统的使用方式，美滋滋。
