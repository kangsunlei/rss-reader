又一个神级 Skill，开源了！

7/7/2026, 9:05:00 AM

📌 一句话摘要

本文介绍开源的 AI Agent 浏览器工具 BrowserAct，通过 stealth 浏览器、三层反爬体系和人机协作机制帮 Agent 突破真实网页限制，并允许用户用自然语言将网页任务封装为可复用的 Skill。

📝 详细摘要

文章从实际使用体验出发，详细介绍 BrowserAct 的六大亮点：stealth-extract 提取公众号等复杂页面、三层反爬体系（环境指纹、自动验证码、人工远程接力）、基于状态索引的动态交互模式（省 token 且适应页面变化）、Skill Forge 让小白也能通过自然语言封装网页任务为可复用技能、与 Playwright 的差异定位，以及成本与隐私设计。文章配有大量实测截图和安装命令，帮助读者快速上手。

💡 主要观点

  1. BrowserAct 通过 stealth 浏览器和三层反爬体系，让 Agent 能真正进入微信、小红书等真实网页。 环境层提供指纹伪装与人机检测绕过；执行层自动 solve-captcha；人机协作层遇到扫码等敏感操作触发远程接力，不硬闯。
  2. Skill Forge 允许用户用自然语言将网页任务封装为可复用的 Skill，降低重复劳动。 用户仅需描述目标网站与字段需求，Agent 自动探索并生成 Skill 包，后续可直接调用，无需每次重新摸网页。
  3. BrowserAct 采用“先看页面再行动”的动态交互模式，比传统脚本更稳定。 每一步操作前先获取当前页面元素编号，页面变化后重新获取，避免使用过期选择器导致失败，同时节省 token。
  4. 工具在成本隐私方面有清晰设计：基础功能免费，敏感操作留确认门，本地 profile 默认不上传。 只有动态代理和多浏览器实例收费；登录、支付等操作触发 remote-assist，确保用户知情与控制。

💬 文章金句

  • 真正省下来的不是一次点击，而是下一百次重复摸网页的成本。
  • Agent 落地的瓶颈，从来不只是模型。模型已经很会想了。问题是，它经常进不去真实系统，或者进去之后不知道怎么稳定地往下走。
  • 把“必须人帮一下”的步骤纳入工作流，任务不会死在这里。
