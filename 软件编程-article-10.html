小红书 dots infra 开源 BigMac : 突破多模态大模型训练的帕累托前沿

7/22/2026, 10:06:00 AM

📌 一句话摘要

小红书 dots infra 团队开源 BigMac，一种打破计算效率与显存占用帕累托前沿的多模态大模型流水并行训练范式。

📝 详细摘要

文章详细介绍了 BigMac，一种针对多模态大模型（MLLM）训练的流水并行新范式。BigMac 的核心思路是保留 LLM pipeline 作为稳定主干，只在依赖满足且不打断 LLM 执行顺序的位置嵌入编码器和生成器计算，形成“依赖安全的嵌套流水线”。文章对比了计算高效（显存爆炸）和显存高效（气泡严重）两种现有方案，指出 BigMac 同时实现了高计算效率和有界显存。在工程实现层面，BigMac 解耦了全局调度与运行时执行，提供对模型开发者透明的接口以及 schedule-aware 工具链（profiler、simulator、可视化）。实验表明，在理解型和生成型多模态训练负载上，BigMac 训练速度较基线提升 1.08～1.9 倍，且显存使用保持稳定。文章最后附有开源地址、论文引用和团队招聘信息。

💡 主要观点

  1. BigMac 通过“依赖安全的嵌套流水线”打破计算与显存的帕累托前沿。 以 LLM pipeline 为时间线主干，在不打乱 LLM 执行顺序的前提下嵌入编码器和生成器计算，既保持了 LLM 流水线的计算效率，又及时释放了模态模块的激活显存。
  2. 相比计算高效方案，BigMac 避免了显存随 global batch size 线性增长；相比显存高效方案，消除了跨模块 pipeline 气泡。 在理解型负载上，BigMac 训练速度较计算高效基线 Optimus 提升 1.08～1.1 倍，较显存高效基线 Megatron-DistTrain 提升 1.6～1.9 倍，且显存使用稳定。
  3. BigMac 提供了解耦的 Scheduler/Executor 结构、对模型开发者透明的接口以及 schedule-aware 工具链。 全局调度可见、可检查，模型代码无需感知 PP 细节，profiler/simulator 工具链支持性能瓶颈诊断与并行策略快速迭代。
  4. 在多模态生成负载（含 20B 参数生成器）上，BigMac 优势更为明显。 计算高效方案在所有测试 batch size 下 OOM，而 BigMac 通过及时运行生成器 backward 并释放激活显存，保持了稳定训练且加速比达到 1.5～1.9 倍。

💬 文章金句

  • BigMac 的核心是打破这个前沿。
  • BigMac 不是在显存和 bubble 之间做交换，也不是用 bubble 换显存。
