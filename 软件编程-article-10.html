Brevo 遭供应链攻击，超 10 万网站被植入恶意代码

9/20/2026, 10:00:00 AM

📌 一句话摘要

Brevo 遭两次入侵，攻击者利用被盗 Cloudflare 密钥通过 CDN 边缘节点注入恶意代码，影响超 10 万网站，但源站文件未被修改，暴露了供应链攻击的隐蔽危害。

📝 详细摘要

本文报道了云营销平台 Brevo 遭受的供应链攻击事件。攻击者首次通过 SAML SSO 漏洞获取账号权限，二次则利用硬编码的 Cloudflare API 密钥部署恶意 Worker，篡改边缘节点脚本，向 Brevo 官网及超过 10 万个客户网站植入恶意代码。恶意代码包含伪装成 WordPress 插件的恶意程序和 clickfix 欺骗页面，针对已登录管理员并隐藏自身。攻击全程在 CDN 边缘进行，源站文件保持干净，常规检测无法发现。Brevo 已清除恶意内容，但未说明两次入侵是否关联。文章还为受影响网站提供了检查建议，并指出封禁攻击者使用的合法域名可能影响正常客户功能。

💡 主要观点

  1. 攻击者两次入侵 Brevo，第二次利用硬编码的 Cloudflare API 密钥部署恶意 Worker。 首次入侵通过 SAML SSO 漏洞获取 138 个账号，二次入侵则使用被盗的长期 Cloudflare 密钥，在边缘节点篡改响应并注入恶意代码，影响范围远超第一次。
  2. 恶意代码包含恶意 WordPress 插件和 clickfix 遮罩层，针对已登录管理员和普通用户。 恶意插件可自动安装并隐藏自身，通过 must-use 目录持久化；clickfix 页面诱骗用户运行恶意命令。攻击者无需逐个入侵站点，即可通过 Brevo 的可信基础设施触达海量网站。
  3. 攻击全程隐藏在 CDN 边缘，源站文件未被修改，常规检测无法发现。 恶意 Worker 在边缘节点篡改响应并移除安全头，源站始终保持干净。这凸显了供应链攻击的隐蔽性和危害，也说明仅靠源站完整性检查不足以防御。
  4. Brevo 已清除恶意内容，但未回应两次入侵是否关联；文章为受影响网站提供了具体检查建议。 文章指出封禁攻击者使用的合法域名 sendibt1.com 可能影响正常客户功能，体现了攻击者对信任基础设施的滥用。管理员应检查日志、对比文件列表并轮换密码。

💬 文章金句

  • 攻击者窃取了一枚硬编码在应用源代码中、拥有账户完整权限的长期 Cloudflare API 密钥。
  • 恶意 WordPress 插件：当站点管理员访问自身网站时会自动安装
  • 攻击全程隐藏在 CDN 边缘
  • 讽刺的是，sendibt1.com 看似是很多人会第一时间封禁的域名，但实际上封禁它会带来问题
