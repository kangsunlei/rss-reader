Claude Code 官方 VS Code 扩展遭篡改，植入持久化 SSH 后门

10/31/2026, 10:00:00 AM

📌 一句话摘要

研究人员发现 Cursor 市场上的 Claude Code 官方扩展遭篡改，攻击者通过植入恶意代码实现了持久化 SSH 后门并收集主机信息。

📝 详细摘要

网络安全人员披露，Cursor 市场分发的 Anthropic 官方 Claude Code 扩展（版本 2.1.31）遭到入侵。攻击者在保留原有代码的基础上插入了 66 行恶意代码，通过向用户的 ~/.ssh/authorized_keys 文件添加攻击者控制的公钥来实现持久化 SSH 后门。虽然在 macOS 和 Windows 上因缺乏管理员权限未成功开启 SSH 服务，但恶意扩展仍能安装持久化机制并收集包括公网 IP、操作系统版本、Git 邮箱及敏感环境变量名在内的信息。

💡 主要观点

  1. Cursor 市场遭遇供应链攻击 攻击者入侵了 Cursor 市场分发的 Anthropic 官方 Claude Code 扩展，影响范围可能达五千用户。
  2. 植入持久化 SSH 后门 恶意代码向用户的 ~/.ssh/authorized_keys 文件添加攻击者的 SSH 公钥，并标记为 'svc-telemetry' 以规避检查。
  3. 跨平台持久化机制尝试 恶意扩展尝试通过计划任务、crontab 或 LaunchAgent 等机制在不同平台建立反向隧道并维持。
  4. 敏感主机信息侦察 恶意代码会收集公网 IP、主机名、Git 全局邮箱以及最多 40 个包含 KEY、TOKEN 等敏感关键词的环境变量名。

💬 文章金句

  • 攻击者在保留原有代码的基础上，额外插入了 66 行恶意加载代码，使正常扩展具备后门安装能力。
  • 向用户的 ~/.ssh/authorized_keys 文件添加攻击者控制的 SSH 公钥，该密钥被标记为 'svc-telemetry'，伪装成无害的遥测组件。
  • 在大多数 macOS 和 Windows 主机上，恶意扩展并未获得该权限。
