Papermorph Skill 让 Claude Code 将 PDF 课本生成互动网页课

11/5/2026, 2:30:04 PM

📌 一句话摘要

Papermorph 是 Claude Code 的 Skill 模块，输入 PDF 课本即可生成带旁白的互动网页课、纸偶动画、竖屏短片等多种形式。

💡 主要观点

  1. 多模态内容转化 将 PDF 课本转化为带旁白的互动网页课、纸偶动画、纪录片、竖屏短片等多种形式输出
  2. 动态化教学元素 公式、图形随讲解步进变化，章节内置小测验和练习，提升学习互动性
  3. 儿童友好设计 动画设计“小马过河”等绘本，支持错题友好反馈，适合儿童参与式学习
  4. 轻量化交付形式 产出为静态网页，无需服务器，章节可导出带字幕的 1080p 视频，免费语音旁白可选付费配音

💬 文章金句

  • Papermorph 这个 Skill 给了个更直观的办法，用大白话问它某台机器怎么工作，它会做出一个能拆开看的 3D 模拟器。
  • 做出来的都是静态网页，不用服务器和数据库，每一章也能导出成带字幕的 1080p 视频。
  • 旁白可以用免费语音，想要角色配音才需要接付费服务。
