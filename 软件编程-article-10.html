📝 详细摘要

文章介绍 DeepSeek Harness 的开源桌面客户端 DSH Desktop。DeepSeek Harness 是 DeepSeek 开源的智能体框架，核心理念为 Everything is a Plugin，已收获 10 万+ Star。DSH Desktop 由社区开发，采用 MIT 协议，把 Harness 封装成 macOS/Windows 桌面应用，免去命令行操作。文章重点介绍三大亮点：Preset 广场可挑选现成的插件组合；内置 DeepSeek、OpenAI、Anthropic、Gemini 等多模型服务商，也支持 OpenRouter；Agent 设置可导出为 .dshpreset 文件分享，且分享包不含 API Key。最后给出官网下载与源码运行的上手指引，并提示网上下载的 Agent 设置需确认来源安全。

💡 主要观点

  1. DSH Desktop 把 DeepSeek Harness 封装成桌面应用，免去命令行操作。 双击图标即可启动，后台自动完成环境准备，支持 macOS 和 Windows，保留项目管理、Agent 与插件能力。
  2. Preset 广场让用户可按需挑选插件组合，快速定制专业 Agent。 基于 Everything is a Plugin 理念，多插件组合构成 Preset，通用 Agent 加 Preset 即可变成面向垂直场景的专业 Agent。
  3. 模型服务商可灵活选择，支持主流闭源模型与 OpenRouter。 内置 DeepSeek、OpenAI、Anthropic、Gemini、xAI、Kimi 等，接入 OpenRouter 后自动列出可用模型，无需手工填写 ID。
  4. Agent 可导出为 .dshpreset 文件分享，但需注意插件权限风险。 分享包不含 API Key 与对话记录，但插件可能拥有运行命令或读取文件权限，因此网上下载的设置必须先确认来源。

💬 文章金句

  • 通用 Agent + Preset = 专业 Agent。
