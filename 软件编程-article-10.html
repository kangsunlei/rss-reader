📌 一句话摘要

JetBrains 回答关于 Kotlin 多平台工具、性能与未来规划的关键问题。

📝 详细摘要

这篇来自 Kotlin 博客的文章解答了 KotlinConf 2025 中关于 Kotlin 多平台 (KMP) 的热门问题。内容涵盖 IntelliJ IDEA 和 Android Studio 中 KMP 工具的现状与未来改进，包括增强的 Swift 和跨语言功能。JetBrains 团队讨论了在提高桌面目标原生编译速度方面所做的持续努力，并鼓励用户向 YouTrack 提交错误报告以协助改进。文章重点关注 KMP 的发展，特别是即将推出的 Compose 多平台 Web Beta 版，以及通过 Kotlin/JS `@JsExport` 和 Kotlin/Native Swift 导出等方式改进业务逻辑共享，和在 Web 平台支持功能（如与 HTML 元素的互操作性）方面的进展。此外，文章还详细介绍了通过将语义节点映射到 DOM 元素，为 Web 上的 Compose 多平台实现基本可访问性和潜在 SEO (搜索引擎优化) 支持的计划。最后，文章确认 Navigation 3 的构建充分考虑了 KMP，并将支持多平台开发。

💡 主要观点

  1. JetBrains IDE 提供并计划增强 Swift 和跨语言的 KMP 工具支持。 IntelliJ IDEA 和 Android Studio 的 KMP 插件已支持 Swift/Kotlin 的基本功能，如导航，未来将进一步增强。
  2. 正在努力提高 KMP 桌面目标的原生编译速度。 Kotlin 团队正在调查原生构建性能问题，并鼓励用户向 YouTrack 报告具体问题。
  3. KMP 的未来包括 Compose 多平台 Web Beta 版和改进的业务逻辑共享。 主要发展重点是将 Compose 多平台扩展到 Web，增强 Kotlin/JS 和 Kotlin/Native 的导出功能，并提高整体平台成熟度。
  4. 计划为 Compose 多平台 Web 提供可访问性和潜在的 SEO。 将通过把 Compose 的语义节点映射到 DOM 元素来实现基本的可访问性支持，这也有助于 SEO (搜索引擎优化)。
  5. Navigation 3 专为多平台支持而设计，将支持多平台。 Navigation 库的下一个主要版本正在开发中，充分考虑了 KMP 兼容性，确认了多平台可用性。

💬 文章金句

  • IntelliJ IDEA 和 Android Studio 的 KMP 插件已经支持 Swift 和跨语言 Kotlin/Swift 功能，例如导航，我们计划添加更多！
  • 我们目前正在研究原生构建性能。首先，请查看我们关于提高原生编译速度的建议。
  • 我们正在推动 Kotlin Multiplatform 成为一个完整和成熟的解决方案！
  • 我们计划在今年晚些时候通过将 Compose 语义节点映射到 DOM 元素来实现基本的可访问性支持。
  • Navigation 3 的构建考虑了 Kotlin Multiplatform。所以，答案是肯定的，Navigation 3 将支持多平台。
