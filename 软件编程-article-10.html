iOS 开发者现在可以通过 Web 提供免佣金支付 - Vercel

5/1/2025, 1:00:00 PM

📌 一句话摘要

联邦法院裁决允许 iOS 开发者引导用户至外部支付，免佣金，降成本，优体验，惠及开发者和用户。

📝 详细摘要

文章讨论了 Epic Games 诉 Apple 案的联邦法院裁决，该裁决允许 iOS 开发者引导用户到外部支付页面，无需支付佣金，减少了苹果对其应用生态的限制。此前，苹果对应用内购买收取 30% 的佣金（“苹果税 (Apple Tax)”），并通过 StoreKit 外部购买链接 API 对外部支付收取 27% 的佣金，从而限制了开发者的选择和用户的体验。新裁决取消了这些限制，允许开发者在应用内提供直接链接到外部支付页面的动态链接，并免除相关佣金。这为开发者提供了更大的灵活性和机遇，可以优化支付体验、提供更优惠的价格，并与用户建立直接关系。文章还介绍了 Vercel 发布的 Web 支付入门套件，该套件集成了 Stripe Checkout，旨在帮助开发者快速构建安全、可扩展的 Web 支付流程。

💡 主要观点

  1. 法院裁决允许 iOS 应用内引导用户到外部支付，无需支付佣金 开发者现在可以在应用中提供直接链接到外部支付页面的动态链接，从而拥有更大的灵活性。
  2. Web 成为提供卓越用户体验的移动商务平台 由于 App Store 的限制减少，开发者可以利用 Web 来构建快速、安全和可定制的结账流程，为用户提供更好的支付体验。
  3. Vercel 提供 Web 支付入门套件，帮助开发者快速开始 该套件旨在帮助开发者构建针对转化率、性能和开发者控制进行优化的结账流程，并支持 Apple Pay。

💬 文章金句

  • 这项裁决并没有推倒围墙花园，而是打开了一扇门。现在，开发者们可以走出去了。
  • 昨天的裁决结束了这种情况。它确认开发者可以引导用户访问外部支付页面，苹果不能对这些交易征税或阻碍。
  • 如果没有 App Store 的限制，原生开发者可以拥抱 Web 来构建快速、安全和可定制的结账流程。
