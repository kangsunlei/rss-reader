📌 一句话摘要

本文介绍了 AI 原生终端 Warp 的开源情况，详细阐述了其 Block 块状交互、AI Agent 集成、GPU 加速 UI 等核心特性，并提供了下载和源码构建方式。

📝 详细摘要

文章报道了 AI 终端 Warp 在 GitHub 上开源的消息，该项目已获得超过 5 万 Star。Warp 是一个用 Rust 从头开发的 AI 原生终端，定位为智能体开发环境。文章详细介绍了 Warp 与传统终端的核心区别：采用 Block 块状交互模型，将每条命令及其输出组织为独立块，支持搜索、过滤和分享；内置 AI Agent，可直接调用 Claude Code、Codex 等外部 CLI Agent，并新增对 Kimi、Qwen 等开源模型的支持；支持交互式代码审查，无需切换 IDE；自研 GPU 加速 UI 框架 WarpUI，渲染速度快，输入延迟低。文章还提供了下载安装和从源码构建两种使用方式。

💡 主要观点

  1. Warp 是一个用 Rust 开发的 AI 原生终端，已开源并获超 5 万 Star。 该项目定位为智能体开发环境，由 OpenAI 赞助，被 TIME 评为 2025 年最佳发明之一，支持 macOS、Linux、Windows 三大平台。
  2. Warp 采用 Block 块状交互模型，替代传统终端的滚动输出。 每条命令和输出被组织为独立块，附带元数据，支持搜索、过滤和分享，解决了传统终端输出混杂、难以定位的问题。
  3. Warp 是 AI 原生设计，内置 AI Agent 和交互式代码审查功能。 可直接调用 Claude Code、Codex 等外部 CLI Agent，支持在终端内逐行审查 AI 生成的代码并一键修改，无需切换 IDE。
  4. Warp 自研了 GPU 加速的 UI 框架 WarpUI，渲染性能优异。 完全用 Rust 编写，代码库包含 60 多个 crate，渲染速度快，输入延迟低，且 WarpUI 部分采用 MIT 协议开放使用。

💬 文章金句

  • Warp 的核心思路很直接：把终端重新做一遍。
  • 传统终端就是命令输入、输出、滚动、继续输入的死循环。
  • Warp 没用 Electron，也没用 Qt，而是完全用 Rust 从零写了一套 GPU 加速的 UI 框架，叫 WarpUI。
  • 把 Agent 的工作完成度从 80% 推到 100%，这一步不用再切窗口了。
