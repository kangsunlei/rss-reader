BellSoft 发布 Java 加固镜像

12/14/2025, 2:16:00 AM

📌 一句话摘要

BellSoft 发布了新的 Java 加固容器镜像，通过优化 Java 运行时、操作系统加固和主动 CVE 修复，旨在减少企业软件供应链中的漏洞并提升性能。

📝 详细摘要

文章介绍了 BellSoft 在 KubeCon 2025 大会上发布的新产品“加固镜像”，该方案结合了 Java 运行时优化、操作系统加固和主动 CVE 修复，旨在解决企业软件供应链日益严重的漏洞危机。官方称，该方案可将已知漏洞减少 95%，并降低资源消耗 30%。BellSoft 的解决方案基于其轻量级 Alpaquita Linux 发行版，通过移除包管理器和非必要组件、锁定配置来达到最小化和不可变性，同时提供详细的 SBOM。BellSoft 将此方案定位为在 Distroless 的极简和标准镜像易用性之间取得平衡的灵活替代方案，并提供免费社区版、标准版和高级版。

💡 主要观点

  1. BellSoft 推出加固镜像以解决容器安全和软件供应链漏洞问题。 新的容器镜像产品将 Java 运行时优化、操作系统加固和 CVE 修复结合，旨在大幅减少已知漏洞并优化资源使用，应对当前企业软件供应链的安全挑战。
  2. 加固镜像通过技术手段实现高安全性与性能。 基于 BellSoft 自研的 Alpaquita Linux，镜像移除了不必要组件，锁定了配置，提供了软件物料清单（SBOM），并承诺更快的关键 CVE 修复速度，有效提升容器的安全性与运行效率。
  3. BellSoft 的解决方案在市场竞争中寻求平衡与差异化。 它在极简的 Distroless 和功能全面的标准镜像之间提供了一个折中方案，更灵活地满足 Java 团队需求，并与 Chainguard、Docker 等竞争对手形成差异。

💬 文章金句

  • 在 KubeCon 2025 大会上，BellSoft 发布新的"加固镜像"产品，将 Java 运行时优化、操作系统加固与主动 CVE 修复合而为一。
  • 这种一体化方案可将已知漏洞减少 95%，还将资源消耗最多压低 30%。
  • 加固镜像是 BellSoft 对市场安全、高性能容器解决方案日益增长需求的回应，也是兑现了我们交付最完整、可靠 Java 体验的承诺。
