Qoder 1.0 正式发布！从 AI IDE 迈向智能体自主开发工作台

5/15/2026, 6:22:00 AM

📌 一句话摘要

阿里发布 Qoder 1.0，从 AI IDE 升级为智能体自主开发工作台，引入独立 Quest 视窗、跨项目多任务并行、团队级知识引擎和自定义专家团，实现从需求定义到交付的全流程自动化。

📝 详细摘要

阿里正式发布 Qoder 1.0，将其从 AI IDE 升级为智能体自主开发工作台。核心升级包括：Quest 独立视窗成为 Agent-first 开发台，集成任务管理、状态追踪和产物审查；支持跨项目、跨代码库的多任务并行，通过统一面板实时追踪全局进展；整合记忆、Repo Wiki 和知识卡片为统一的团队级知识引擎，实测显示代码保留率提升 11%、Token 消耗降低 40%、对话轮次减少 33%；专家团模式引入 Quest 视窗，并新增自定义专家能力，开发者可打造专属 Agent 团队。底层通过 Agent Harness 的系统性重构，将聊天对话升级为结构化任务运行时，将分散的上下文供给收敛为贯穿运行时的知识工程。Qoder 自 2025 年 8 月上线以来已服务全球超过 500 万用户。

💡 主要观点

  1. Qoder 1.0 从 AI IDE 升级为智能体自主开发工作台。 用户只需定义需求，Agent 团队即可自主完成执行、验证和交付全流程，实现从辅助编程到自主开发的范式转变。
  2. Quest 独立视窗成为 Agent-first 开发台的核心入口。 集成任务管理、状态追踪、产物审查和知识调用，开发者可在任务委派与协同编程之间自由切换，上下文无缝衔接。
  3. 团队级知识引擎是 1.0 版本的关键创新。 整合记忆、Repo Wiki 和知识卡片，实现团队知识共享，Agent 持续调用知识，代码保留率提升 11%，Token 消耗降低 40%。
  4. 支持自定义专家团队，打造专属 Agent 流水线。 开发者可创建由规划、调研、编码、审查、测试等专家组成的 Agent 团队，并配置领域知识和外部工具接口。

💬 文章金句

  • 全面接管代码生成、验证和交付流程
  • Quest 从 IDE 内的一个模式升级为独立视窗，集成任务管理、状态追踪、产物审查和知识调用等能力，成为面向 Agent-first 工作范式的开发工作台。
  • 这是全球首次实现团队知识共享机制。
  • 实测数据显示，知识引擎上线后，代码保留率提升 11%，输入 Token 消耗降低 40%，对话轮次减少 33%。
  • 模型提供智能，Harness 决定这份智能能否转化为可用交付。
