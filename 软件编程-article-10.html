📝 详细摘要

Mole 1.29 is a significant update to the open-source Mac cleaning tool， adding a '--dry-run' flag for safe command execution and enabling JSON output for seamless integration into automation pipelines. The release also optimizes Xcode DeviceSupport cleanup and improves sudo handling within Automator and Shortcuts， providing developers and power users with a reliable， scriptable solution to reclaim disk space.
