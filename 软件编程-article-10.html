Node.js 官方发布新工具，助力稳定 TypeScript 支持！

6/12/2025, 1:25:00 AM

📌 一句话摘要

Node.js 发布 Amaro 1.0 工具，以类型剥离方式提升对 TypeScript 的原生支持。

📝 详细摘要

文章介绍了 Node.js 官方发布 Amaro 1.0，这是一个基于 Rust/WebAssembly 的 TypeScript “类型剥除加载器”。它解决了 Node.js 长期以来原生支持 TS 不足、依赖第三方工具、启动慢、调试复杂的问题。文章详细回顾了 Node.js 从 2024 年起逐步增强 TS 支持的时间线，并解释了 Amaro 的高速性能、双模式支持（strip-types/transform-types）及依赖剥除等关键功能。最后，文章将 Node.js + Amaro 的类型剥离方式与 Bun 和 Deno 的内置完整 TS 编译支持进行了对比分析，指出了各自的优劣和适用场景。总的来说，Amaro 是 Node.js 生态整合 TS 的重要一步，预示着未来更统一高效的开发体验。

💡 主要观点

  1. Node.js 官方发布 Amaro 1.0，提供原生的 TypeScript 运行支持 Amaro 是官方推出的类型剥离加载器，允许开发者直接运行 `.ts` 文件，不再强依赖第三方工具，简化了开发流程。
  2. Amaro 采用基于 Rust 和 WebAssembly 的高效实现 基于 SWC 引擎，Amaro 运行速度快，资源占用低，提供了高性能的 TypeScript 运行体验。
  3. Node.js 的类型剥离方式与 Bun/Deno 的完整编译不同 Node.js 只移除类型注释，不执行完整类型检查；而 Bun/Deno 提供内置的完整 TS 编译和类型检查能力。
  4. 官方支持逐步完善，未来 `.js` 和 `.ts` 开发界限模糊 Node.js 对 TS 的原生支持是渐进式的，Amaro 的发布是关键里程碑，预示着未来开发体验将更加统一高效。

💬 文章金句

  • 6 月 10 日，Node.js 官方发布了 Amaro 1.0，这是 Node.js 官方的 TypeScript "类型剥除加载器"，可以让开发者直接在 Node.js 中运行 .ts 文件，不需要先转成 .js。
  • Amaro 是用 Rust 写的，并通过 WebAssembly 在 Node.js 中运行的 **类型剥除加载器**。
  • Node.js 选择"类型剥离"这种方式，是为了保留现有生态的兼容性，代价更小；Bun 和 Deno 是从底层支持 TS，功能更全。
  • Amaro 让"直接用 Node 跑 TS"变得可行。未来开发时，.js 和 .ts 的区别会越来越小，开发方式会更加统一、高效，也更安全。
