使用 marimo 探索您的 Cloudflare Python 笔记本数据

7/16/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 与 marimo 合作，提供集成了身份验证和灵活部署选项的响应式 Python 笔记本体验，方便用户探索 Cloudflare 数据。

📝 详细摘要

本文宣布 Cloudflare 与开源响应式 Python 笔记本 marimo 建立战略合作伙伴关系，旨在提升 Cloudflare 开发者的数据探索和管理效率。marimo 的核心功能解决了传统笔记本在协作、可重复性和部署方面的局限性：响应式执行模型、Git 友好的存储和 WebAssembly 支持，以实现高效的浏览器端执行。该集成引入了通过 PKCE 协议集成的 Cloudflare 身份验证，简化了 API 访问，并为 R2、Workers AI 和 D1 等 Cloudflare 服务提供了开源笔记本示例。此外，本文详细介绍了 marimo 笔记本如何部署在 Cloudflare 容器上，以实现可扩展的、长时间运行的数据工作流，或通过 Workers 静态资源共享。文章提供了与 Cloudflare API 交互的设置说明和代码示例，强调易用性和安全的数据访问，标志着 Cloudflare 和 marimo 将在大规模数据分析领域进行更深入的合作。

💡 主要观点

  1. marimo：解决传统笔记本局限的响应式 Python 笔记本 其响应式执行模型确保了单元格之间的一致性，防止错误，并允许将笔记本部署为独立的数据应用程序，从而显著提高了可重复性和可共享性。
  2. Cloudflare 和 marimo 深度集成：内置身份验证，并提供 R2、Workers AI 和 D1 等服务示例 通过 PKCE 直接 Cloudflare 帐户登录简化了 API 访问，并为 R2、Workers AI 和 D1 提供的示例加速了 Cloudflare 生态系统内的数据探索。
  3. marimo 笔记本可以轻松地在 Cloudflare 的基础设施上部署和扩展。 对 WebAssembly 的支持支持通过 Workers 进行经济高效的浏览器端共享，而 Cloudflare 容器为长时间运行的、计算密集型的数据工作流提供了一个强大的平台。

💬 文章金句

  • marimo 重新构想了笔记本的体验，同时考虑到了这些挑战。它是一个开源的响应式 Python 笔记本，旨在实现可重现、易于在 Git 中跟踪、可作为独立脚本执行和可部署。
  • marimo 与传统笔记本区分开来的核心功能是其响应式执行模型，该模型由单元格上静态推断的数据流图提供支持。
  • Cloudflare 身份验证已集成至 marimo 笔记本 —— 直接从笔记本登录 Cloudflare 帐户，无需创建 API 令牌即可使用 Cloudflare API
  • 由于 marimo 笔记本存储为 Python，因此它们享有软件的所有优势：使用 Git 进行版本控制，作为脚本或管道执行，使用 pytest 进行测试，使用 uv 内联包需求，并将符号从您的笔记本导入到其他 Python 模块中。
  • 如果您的笔记本需要身份验证，您可以分层使用 Cloudflare Access 以实现安全、经过身份验证的访问。
