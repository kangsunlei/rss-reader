在 Vercel 上支持 MCP (模型上下文协议， Model Context Protocol) 服务器 - Vercel

5/7/2025, 1:00:00 PM

📌 一句话摘要

Vercel 通过支持 MCP 服务器和客户端，并提供相关工具和模板，简化了 AI 模型集成流程。

📝 详细摘要

Vercel 现在支持部署 MCP (模型上下文协议， Model Context Protocol) 服务器和客户端，通过提供的服务器模板和 `@vercel/mcp-adapter` 包简化 AI 模型集成。MCP 被视为 AI 任务的定制工具包，与传统的 REST API 不同，它可能在幕后使用多个 API 和业务逻辑。MCP 现在支持 HTTP 和 OAuth 协议。Vercel 的 AI SDK 提供了内置支持，用于将 Node.js 或 Next.js 应用程序连接到 MCP 服务器。Vercel 上的流动计算 (Fluid compute) 因其在 AI 推理工作负载中具有成本效益而备受关注。

💡 主要观点

  1. MCP 作为一个为 AI 任务量身定制的工具包，简化了 AI 模型集成。 MCP 与传统 REST API 不同，它封装了多个 API 和业务逻辑，为 AI 提供定制工具，简化 AI 任务的构建和集成。
  2. Vercel 的 MCP 适配器支持 SSE 和 HTTP 传输，增强了灵活性。 `@vercel/mcp-adapter` 包支持 SSE 和无状态 HTTP 传输。开发人员可以根据客户端需求选择合适的传输方法，从而提高 MCP 服务器的灵活性和兼容性。
  3. Vercel 的 AI SDK 提供了对 MCP 服务器的内置支持。 Vercel 的 AI SDK 简化了将 Node.js 或 Next.js 应用程序连接到 MCP 服务器的过程，从而简化了 Vercel 生态系统中的 AI 集成。
  4. 流动计算显著降低了 AI 推理成本。 流动计算为 AI 推理和代理工作负载提供了一个更具成本效益的平台，与传统的 Serverless 方法相比，有望节省 90% 以上的成本。

💬 文章金句

  • MCP (模型上下文协议) 是一种为 AI 模型构建集成的方式。
  • 与其将 MCP 视为 REST API，不如将其视为一个定制的工具包，可以帮助 AI 实现特定任务。
  • 流动计算使您能够拥有完整的 Node.js 或 Python 兼容性，同时拥有一个更具成本效益和高性能的 AI 推理和代理工作负载平台。
