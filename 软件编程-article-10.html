Manus 数月憋大招， 100 个 Agent 并发只为选双鞋？肖弘放话：第一阶段就得先做超贵的 AI！

8/9/2025, 2:16:00 AM

📌 一句话摘要

Manus 推出“Wide Research”功能，采用百个 AI Agent 并发处理任务，挑战传统深度研究模式，并强调 AI 产品初期高成本的商业策略。

📝 详细摘要

文章详细介绍了中国 AI 初创公司 Manus 推出的“Wide Research”新功能。该功能通过同时部署 100 多个通用 AI Agent 来并行处理大规模任务，旨在突破传统单一 Agent 深度研究的局限，提升研究和创意探索的效率。文章对比了 Manus 与 OpenAI 等竞争对手的“深度研究”路径，并指出 Wide Research 的独特架构在于其通用 Agent 的灵活协作能力，而非预设角色。同时，文章也指出了该功能在性能基准、协作细节和成本效益方面缺乏具体证据。此外，文章提及 Manus 近期将业务撤出中国市场，原因在于其使用的大模型（OpenAI、Claude）等不支持在中国地区运营。最后，文章探讨了公司 CEO 肖弘关于“超贵 AI”的商业哲学。整体而言，该功能是 AI Agent 领域的一次大胆尝试，但其长期影响和有效性仍有待观察。

💡 主要观点

  1. Manus 推出“Wide Research”功能，实现百个 AI Agent 并发处理任务。 该功能通过同时部署 100 多个通用 AI Agent，以并行方式处理大规模研究或创意任务，显著提升了处理速度和产出多样性，与传统单一 Agent 模式形成差异。
  2. “Wide Research”采用通用 Agent 架构，提升任务处理灵活性。 不同于传统多 Agent 系统中的角色预设 Agent，Wide Research 中的每个子 Agent 都是功能完备的 Manus 实例，可独立承担任何任务，实现灵活可扩展的任务处理。
  3. 文章对“Wide Research”的实际效益和技术细节提出质疑。 尽管功能创新，但文章指出 Manus 未提供性能基准、对比数据或技术解释，缺乏证据证明其比单个高性能 Agent 更高效，且未详述 Agent 协作和结果整合机制。
  4. Manus CEO 提出“超贵 AI”的商业策略，适应 AI 高边际成本阶段。 公司创始人肖弘认为 AI 初期产品应“超贵”以拓展人类能力边界，并通过盈利逐步降低成本，这解释了 Manus 产品高昂定价的商业逻辑。

💬 文章金句

  • Wide Research 非依赖单个 AI Agent 进行深度分析，而是可同时部署 100 多个 AI Agent，处理单个任务或一系列相关子任务。
  • Wide Research 的关键不仅仅在于拥有更多的智能体，而是它们如何协作。不同于那些角色预设的传统多 Agent 系统，Wide Research 中的每个子 Agent 都是功能完备、特性齐全的 Manus 实例。
  • 尽管 Manus 宣称 Wide Research 是 Agent 并行技术的突破，却未提供直接证据，证明生成数十或数百个子 Agent 比让单个高性能 Agent 按顺序处理任务更高效。
  • AI 在开始时更像边际成本很高的原子生意，然后 (也许会) 逐步转变成为边际成本更低或者接近于零的比特生意。和这个匹配的做法是：制造超贵但是拓展人类能力边界的 AI 产品。
