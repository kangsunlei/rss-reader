通过自动化僵尸网络防护、密码套件选择和 URL 扫描器更新，增强安全性和简化控制

3/17/2025, 1:00:00 PM

📌 一句话摘要

Cloudflare 发布安全更新，包括自动化僵尸网络防护、密码套件选择和增强的 URL 扫描器，旨在提升用户安全性和控制力，并减少管理负担。

📝 详细摘要

Cloudflare 发布了一系列新功能，旨在提高客户，特别是企业客户可用的安全工具。其中包括：改进的自动化安全级别，通过集成僵尸网络数据和其他请求速率信号，自动保护客户免受已知的恶意僵尸网络流量的侵害；密码套件选择，允许用户通过 Cloudflare 仪表板更好地控制加密设置；以及改进的 URL 扫描器，包括批量扫描、相似性搜索、位置选择器和威胁情报等新功能。这些更新旨在为用户提供更强大的在线安全管理能力，从主动威胁检测到对加密设置的细粒度控制。

💡 主要观点

  1. 自动化安全级别通过集成僵尸网络数据，增强了默认防护能力，降低了误报率 新安全系统整合了实时 DDoS 评分、流量阈值及僵尸网络追踪系统，从而减少误报，提高防护准确性，且无需人工配置。
  2. 密码套件选择功能使用户可以根据安全或合规性需求自定义加密设置 Cloudflare 仪表板现在提供密码套件选择，包括安全建议、合规性预设和自定义选择，以满足不同的安全和兼容性需求。
  3. URL 扫描器的新版本通过批量扫描和地理位置扫描，提升了威胁检测效率 企业客户现在可以通过批量扫描 URL、从特定地理位置进行扫描，并利用 IOC 搜索，更有效地识别和应对网络钓鱼及恶意软件威胁。
  4. Cloudflare 利用其作为反向代理的独特优势，提升整体网络安全水平 Cloudflare 作为全球领先的反向代理服务提供商，能够从独特的网络位置监测和分析大量的网络流量，从而更有效地识别和应对各种网络安全威胁。
