提升 Visual Studio Chat 的代码理解能力

8/14/2025, 12:00:59 PM

📌 一句话摘要

Visual Studio Copilot 集成了远程语义搜索，结合关键词搜索与 AI 驱动的上下文理解，为开发者提供更精确、基于意图的代码搜索结果，从而提升开发效率。

📝 详细摘要

本文宣布 Visual Studio Copilot 的代码搜索能力得到显著升级，引入了远程语义搜索。此前，Visual Studio Copilot 依赖于 BM25 算法进行关键词搜索，但该方法缺乏上下文理解，容易错过相关代码。新的语义搜索利用先进的向量嵌入，使系统能够掌握搜索查询和代码片段背后的含义和意图，匹配概念而非精确的词语。集成的语义搜索支持自然语言查询，从而提供更准确的结果。本文通过 Roslyn 仓库的并排比较展示了改进的精确度，表明语义搜索能够产生更少但更相关的结果。此功能适用于托管在 Azure DevOps 和 GitHub 仓库中已建立索引的解决方案，旨在节省时间，减少开发者在浏览复杂或不熟悉的代码库时的挫败感，从而显著提高生产力。

💡 主要观点

  1. 语义搜索通过理解含义和意图，显著提高了代码搜索的准确性。 与错过同义词的传统关键词搜索 (BM25) 不同，语义搜索使用向量嵌入来掌握上下文相似性，从而提供更相关的结果，更准确地匹配开发者的意图。
  2. 将语义搜索集成到 Visual Studio Copilot 中可提高开发者生产力。 通过支持自然语言查询和提供精确的代码上下文，开发者可以快速浏览复杂的代码库，从而节省大量时间并减少开发过程中的挫败感。
  3. 此高级搜索功能可用于 Azure DevOps 和 GitHub 仓库。 远程索引允许语义搜索在广泛使用的代码托管平台上运行，从而使广泛的开发者和项目可以使用此强大功能。

💬 文章金句

  • 通过将传统关键词搜索 (BM25) 的强大功能与前沿 AI 模型的深度上下文理解相结合，嵌入到 Visual Studio Copilot 代码搜索体验中。
  • 借助高级向量嵌入，语义搜索将查询和代码转化为高维空间中的向量进行匹配，从而理解其含义，而不仅仅是匹配精确的词语。
  • 使用语义搜索，结果可能会更少，但它们会更准确。搜索引擎能够理解 “删除非同步修饰符” 和 “删除 Async 修饰符” 具有相同的含义，即使措辞不同，也证明了其对代码含义的更深入理解。
  • 远程语义搜索到 Visual Studio Copilot 标志着 Copilot 在理解开发者代码库方面向前迈出了一大步。
