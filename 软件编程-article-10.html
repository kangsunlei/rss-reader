黑客用 DeepSeek 驱动 AI Agent 窃取 16834 份系统权限和凭证

9/18/2026, 10:00:00 AM

📌 一句话摘要

网络犯罪组织利用 DeepSeek 驱动的 AI Agent 自动化扫描并窃取系统凭证，凸显了配置错误在自动化攻击下的严重风险。

📝 详细摘要

文章报道了网络犯罪组织 BlackHatSect0r 使用 DeepSeek 模型驱动的 AI Agent 自动化窃取凭证的事件。该组织通过 Hermes Agent 接入 DeepSeek，移除安全设置，利用 DXSCAN 工具扫描暴露的云存储、.env 文件等配置错误，已窃取 16834 份凭证，涉及数据库、API 密钥等多种类型。攻击还关联数据盗窃、勒索和诈骗活动。文章强调自动化攻击放大了常规配置缺陷的危害，并为企业提供防御建议，如审计云权限、轮换密钥和排查攻击指标。

💡 主要观点

  1. BlackHatSect0r 组织使用 DeepSeek 驱动的 AI Agent 自动化执行网络攻击。 该组织通过 Hermes Agent 接入 DeepSeek 模型，移除安全设置，利用 DXSCAN 工具扫描暴露的凭证，并已窃取 16834 份凭证。
  2. 攻击主要利用公开的云存储和配置错误。 攻击未利用新漏洞，而是基于暴露的.env 文件、云密钥、弱口令等，如加密货币交易所因 JWT 弱口令导致泄露。
  3. 凭证窃取规模大，且涉及其他犯罪活动。 凭证库包含多种类型，部分用于钓鱼邮件；组织还涉嫌数据盗窃、勒索和针对老年群体的诈骗。
  4. 防御方需强化配置排查和安全意识。 企业应审计云权限、轮换密钥，并排查攻击指标如 SOUL.md 文件；同时需培训员工防范钓鱼电话等新型攻击。

💬 文章金句

  • 研究发现，网络犯罪组织 BlackHatSect0r（关联别名 DXQRTXX）运营着一套自动化网络犯罪作业体系。
  • 该组织使用接入 DeepSeek 模型的 AI Agent 扫描公开泄露的密钥、验证窃取到的访问权限，再将结果回传至自研控制平台。
  • 攻击者获得的所有有效访问权限，均来自公开可读的云存储桶、暴露在公网的.env 或 Git 文件、默认签名密钥，或是硬编码在浏览器端代码中的密钥。
