GitHub 数据显示 AI 工具正在创造“便利循环”，重塑开发者的语言选择

3/5/2026, 10:22:00 AM

📌 一句话摘要

GitHub 2025 年 Octoverse 数据显示，AI 编程助手正在推动一种“便利循环”，通过偏好 TypeScript 可预测且类型安全的结构，使其成为最常用的语言。

📝 详细摘要

本文分析了 GitHub 2025 年 Octoverse 报告，强调了一个历史性的转变：TypeScript 在月度贡献者数量上超越了 Python 和 JavaScript，成为排名第一的语言。这一高达 66% 的同比增长归功于 AI 编程助手创造的“便利循环”。由于 TypeScript 的静态类型为大语言模型（LLM）提供了更清晰的上下文和更高的可预测性，AI 工具在处理该语言时表现更好，减少了开发者的阻力。这种易用性鼓励了更多人采用，进而产生了更多高质量的训练数据，进一步提升了 AI 在该语言上的熟练度，并从根本上改变了开发者选择技术栈的方式。

💡 主要观点

  1. AI 助手正通过“便利循环”影响编程语言的选择。 当 AI 工具让某种特定语言的编写变得毫无阻力时，开发者会更频繁地采用它，从而形成一个增加使用量并提供更好模型训练数据的反馈循环。
  2. TypeScript 已超越 Python 和 JavaScript，成为 GitHub 上最受欢迎的语言。 凭借 66% 的巨大同比增长，截至 2025 年 8 月，TypeScript 的月度贡献者已达到 263.6 万，标志着十多年来最显著的排名变动。
  3. 静态类型与 LLM 之间的技术协同效应提升了 AI 的效率。 与动态语言相比，TypeScript 显式的类型定义为 AI 模型提供了更优的上下文，从而在开发过程中实现更准确的代码生成并减少幻觉。

💬 文章金句

  • AI 编程助手不仅在改变开发者编写代码的速度。更重要的是，这些助手正在影响开发者最初选择哪种语言。
  • 当 AI 让一项技术变得毫无阻力时，开发者就会蜂拥而至。这会产生更多的训练数据，从而让 AI 在该技术上表现得更好。
  • TypeScript 凭借 66% 的巨大同比增长成为 GitHub 最常用的语言，这不仅仅是因为框架默认设置的原因。
  • 这是十多年来最大的编程语言排名大洗牌。
