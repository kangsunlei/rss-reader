教你从零“手搓”一个大模型，别再只会调用 API 了

12/24/2025, 9:36:00 AM

📌 一句话摘要

通过从零开始“手搓”一个小型 LLM，文章详细拆解了大模型从分词到 Transformer 架构和训练推理的底层技术原理，旨在帮助开发者深入理解大模型工作机制，而非仅停留在 API 调用层面。

📝 详细摘要

本文以“手搓”小型 LLM 的形式，深入浅出地讲解了大模型的核心构建原理和实现细节。它从编码（Tokenizer）入手，解释了字符级、词级和子词级 Tokenzier 的原理与优缺点，重点介绍了 BPE 算法，解决了人机语言转换的第一步。接着，文章详细阐述了 LLM 模型的核心组成部分，包括 Embedding、Attention 机制（从朴素 Attention 到多头 Attention），并通过生动的例子和代码片段展示了其工作流。Masking 和 Dropout 等防止模型“作弊”和过拟合的机制也被提及。最后，文章结合 Transformer Block 的堆叠，构成完整的 LLM 模型，并讨论了预训练、SFT 训练方式以及温度和 Top-k 采样等推理策略，帮助读者从宏观到微观全面理解大模型的构建与运行。文章用生动的比喻和简化了数学的讲解方式，使非专业背景的技术人员也能有效吸收。

💡 主要观点

  1. Tokenizer 是 LLM 理解语言的关键，子词级 BPE 算法有效平衡了词汇表规模与 OOV 问题。 文章详细介绍了 Tokenizer 的分类及其优缺点，强调 BPE 算法作为主流子词级分词技术，能够将自然语言有效转换为模型可处理的数字序列，是 LLM 性能的基础。
  2. Embedding 将离散 Token 转换为高维向量，并结合位置嵌入，赋予模型理解语义和语序的能力。 通过 Embedding 层，将无语义的 Token ID 转化为包含语义信息的高维向量，并引入 Positional Embedding 解决 Transformer 的“脸盲”问题，使模型能够理解词语间的关系和语序。
  3. Attention 机制通过计算 Token 间关联度实现信息融合，是 Transformer 捕获长距离依赖的核心。 借由向量点积和 Softmax 归一化，Attention 机制量化了 Token 间的“关系好”程度，并通过加权求和融合信息，多头 Attention 则从不同维度并行捕捉语义，全面提升模型对上下文的理解。
  4. Transformer Block 通过堆叠多层注意力与前馈网络，形成 LLM 强大的学习和推理能力。 Transformer Block 是 LLM 的基本单元，结合 LayerNorm、Residual Connection 等技术，确保了深层网络训练的稳定性和效率，使其能够高效处理复杂语言任务。
  5. 预训练聚焦文本续写，SFT（监督微调）通过特定数据格式将模型塑造成对话助手。 预训练让模型掌握了语言的统计规律，而 SFT 环节则通过构建对话模板和有选择地计算损失，有效地引导模型从“文本续写机”转变为能理解并回答用户问题的“对话助手”。

💬 文章金句

  • 当你亲手写出 Attention 层的矩阵乘法，亲眼看到模型从输出乱码到学会说话，你会发现：大模型，其实也没那么可怕。
  • 所有 LLM 的输入都依赖 Tokenizer 的预处理结果。如果分词策略不合理，如拆分后丢失语义或 Token 粒度过细，会直接影响模型对文本的理解能力。
  • 一个设计优良的 Tokenizer 是提升 LLM 性能的基础前提。
  • 我们希望当前的文字可以**注意到** 其他的文字。
  • 在它眼里，你输入的问题可能只是某本小说或新闻的开头，它并不知道这代表一次'对话'的开始。它只是在尽职尽责地根据概率，顺着你的话继续往下编故事，而不是在回答你的问题。
