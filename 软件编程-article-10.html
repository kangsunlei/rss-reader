GitHub 开启 Issues 语义搜索公测

2/20/2026, 9:11:38 PM

📌 一句话摘要

GitHub 推出了 Issues 语义搜索公测版，实现了超越精确关键词匹配的意图识别搜索。

📝 详细摘要

GitHub 正在对 GitHub Issues 开启语义搜索公测。与传统的关键词搜索不同，这项由 AI 驱动的功能可以理解用户的真实意图，即使术语不完全一致也能成功找到结果。此次更新旨在显著提升信息的可发现性和工作流效率，尤其能帮助需要管理海量 Issue 的开发者。
