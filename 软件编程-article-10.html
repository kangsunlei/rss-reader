zg 正式开源：本地检索，不止于关键词

8/31/2026, 10:40:00 AM

📌 一句话摘要

zg (zvec-grep) 是一款开源的本地优先检索基础设施，通过结合语义检索、BM25 和 ripgrep，为人类和 AI Agent 提供从模糊意图发现到精确验证的全流程本地内容检索能力。

📝 详细摘要

zg 旨在解决本地内容检索中仅依赖关键词匹配（如 rg）容易遗漏语义相关内容，而纯语义检索缺乏精确性的痛点。它提供了一套集成语义检索、BM25 混合检索与 rg 精确匹配的工具链，支持代码、文档及结构化数据的提取与索引。zg 采用本地优先设计，内置端侧 Embedding 模型与嵌入式索引，确保数据隐私。通过 MCP 协议，zg 能无缝集成至 Cursor、Claude Code 等 AI Agent 中，实测证明其能显著减少 Agent 的工具调用次数和 Token 消耗，同时提升任务完成质量。

💡 主要观点

  1. 构建从模糊探索到精确验证的全流程检索链路 通过提供语义检索（意图发现）、BM25（相关性收敛）和 rg（精确验证）三种能力，减少 Agent 在检索过程中猜测关键词的轮次，提高定位效率。
  2. 针对 AI Agent 的上下文效率进行深度优化 通过 RRF 多路结果融合、按代码符号/文档章节组织信息单元以及紧凑的结果预览，减少无关文本进入上下文，从而降低 Token 消耗并缩短响应时间。
  3. 坚持本地优先的隐私与性能架构 内置 16M 级轻量化端侧模型（如 potion-code-16m-v2）实现本地 Embedding，无需 GPU 即可快速索引大规模仓库，确保敏感代码无需上传云端。
  4. 通过 MCP 协议实现 Agent 的即插即用 支持自动发现并配置 Codex、Claude Code、Cursor 等主流 Agent 客户端，使 Agent 能直接调用 zg 的检索能力而无需复杂集成。

💬 文章金句

  • 本地内容检索需要在保留 rg 精确、快速和穷尽能力的基础上，进一步具备语义发现、相关性排序与上下文组织能力
  • zg 的核心设计目标是 让分散在本地文件中的信息能够被高效发现和准确定位
  • 在 SWE-QA-Bench 中，zg 在将工具调用减少超过一半、输入 Token 减少近一半 的同时，评审得分提升了 1.50 分
  • 文件扫描、内容提取、本地 Embedding、索引与检索均在设备内完成，完整流程无需上传内容或依赖外部服务
