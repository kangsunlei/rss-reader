📌 一句话摘要

作者分享了如何利用 Vue3 和 ECharts 等技术栈，从零构建一个旅游主题数据可视化大屏，并附带源码。

📝 详细摘要

文章详细记录了作者使用 Vue3、TypeScript、Vite、ECharts 等主流前端技术栈开发一个旅游主题数据可视化大屏的实践过程。文中重点介绍了如何从 DataV 平台获取 GeoJSON 地图数据，并巧妙地利用 ECharts 通过多图层堆叠和位移配置，实现了平面地图的立体视觉效果。此外，文章还分享了通过 CSS 引入自定义电子屏风格数字字体以及使用`vue3-odometer`库实现数字翻牌轮播效果的具体方法。作者提供了完整的项目源码和在线预览地址，为希望学习大屏开发和数据可视化的前端开发者提供了实用的项目模板和实现思路。

💡 主要观点

  1. 利用 ECharts 通过图层堆叠实现二维地图的立体视觉效果 文章详细讲解了如何从 DataV 获取 GeoJSON 数据，并注册到 ECharts，再通过叠加多个 geo 图层并设置不同的位移，巧妙地实现了平面地图的立体感，提升了视觉表现力。
  2. 介绍了大屏数字显示和轮播效果的具体实现方案 分享了通过 CSS 的`@font-face`引入自定义电子屏风格字体的方法，并利用`vue3-odometer`库轻松实现了数字翻牌的动态轮播效果，增强了界面的互动性和专业感。
  3. 提供了一个基于主流前端技术栈的大屏项目实践案例 整个项目基于 Vue3、TypeScript、Vite 等成熟技术栈，结合 ECharts 进行数据可视化，为前端开发者提供了一个完整的、可复用的项目模板和实现思路。

💬 文章金句

  • 在刷了半小时 pdd 之后我买了张 ui 图，并根据这个 ui 做了一个大屏。
  • 因为这个项目的地图，基本没有交互，就纯纯的数据展示。使用 echarts 来做的 效果会比，cesium 那些更好。
  • 通过叠加多个图层，并且每个图层的 layoutCenter 都不同 最终就可以实现这种看起来很立体的二维地图
  • 这个大屏虽然只有一个页面，但是做的时候，相关的图表配置调整还是挺多的。
  • 后续打算开发一个 mini 版的后台管理，用来管理大屏数据，并且这个后台管理的接口用 node 开发，用来当作 node 后端的练习。
