Claude Code 零提示精准拆解复杂钓鱼邮件攻击链

1/10/2026, 1:24:18 AM

📌 一句话摘要

Vercel CEO 演示了 Claude Code 如何在没有任何提示的情况下，完美诊断出一封来自被入侵的 Betterment 账户的复杂钓鱼邮件，并准确推断出了攻击方式。

📝 详细摘要

这条推文展示了一个复杂钓鱼攻击的真实案例。Betterment 的电子邮件通知系统遭入侵，被用于发送“比特币 & 以太坊赠品”骗局。作者，Vercel 的 CEO，认为垃圾邮件过滤器需要借助 AI 来应对此类威胁，因为该邮件竟通过了标准的 DKIM/SPF/DMARC 认证。随后，他通过向 Claude Code 提供原始邮件源代码（不加任何上下文）来展示其能力。Claude Code 不仅正确将其识别为骗局并警告不要发送加密货币，还提供了一个可靠的技术推断：攻击很可能源于 Betterment 的电子邮件营销账户（使用 Braze/Sparkpost 基础设施）被入侵，或是拥有其营销工具访问权限的第三方所为。这充分展示了 AI 在网络安全分析中的实际应用价值。
