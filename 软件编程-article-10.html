GitHub 暂停 Copilot 的 GPT-5.3-Codex 推行计划

2/10/2026, 1:57:58 AM

📌 一句话摘要

GitHub 暂时停止了新模型 GPT-5.3-Codex 的部署，以优先保障平台的稳定性。

📝 详细摘要

GitHub 宣布暂停为 GitHub Copilot 推行 GPT-5.3-Codex 模型，理由是需要专注于平台稳定性。在此之前（如引用推文所述），该模型因在智能体（Agentic）编程任务中性能提升 25% 以及更强的推理能力而备受期待。此次暂停表明，尽管该模型在技术上实现了重大飞跃，但确保稳定的服务交付仍是该开发者平台的首要任务。
