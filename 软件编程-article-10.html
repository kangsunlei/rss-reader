Swiggy 发布 Hermes V3：从 Text-to-SQL 演进为对话式 AI

1/2/2026, 3:00:00 PM

📌 一句话摘要

Swiggy 的 Hermes V3 利用 GenAI 将 Text-to-SQL 转型为对话式 AI 助手，显著提升了 SQL 生成准确率，支持多轮交互并提供透明的查询解释。

📝 详细摘要

Swiggy 推出了由 GenAI 驱动的 Text-to-SQL 助手 Hermes V3，标志着其早期版本的重大演进。最初，Hermes 在处理派生指标和对话上下文方面面临局限，促使工程团队利用少样本学习（Few-shot Learning）、元数据检索和结构化 LLM 工作流对其进行了重构。Hermes V3 现在整合了基于向量的提示词检索系统，通过将 Snowflake 中执行的历史 SQL 转换为自然语言解释，并利用向量相似度获取少样本示例，将 SQL 生成准确率从 54% 大幅提升至 93%。它还具备用于多轮交互的对话记忆功能，以及一个使用 ReAct 风格推理循环来拆解复杂问题的编排智能体。一项关键增强是引入了解释层，用于澄清查询假设并分配置信度分数，从而增强非技术用户的信任。该系统与 Swiggy 的安全和合规基础设施紧密集成，支持基于角色的访问控制（RBAC）和审计日志。Hermes V3 的架构采用了多种开源和云原生技术，包括向量数据库、用于编排的 LangChain 以及可观测性框架。

💡 主要观点

  1. Hermes V3 利用向量检索和大上下文 LLM 显著增强了 Text-to-SQL 的准确性和对话能力。 通过将历史 SQL 查询转换为自然语言解释，并利用向量相似度进行少样本示例检索，Hermes V3 将 SQL 生成准确率从 54% 提升至 93%，并支持复杂的、多轮对话。
  2. 具备 ReAct 风格推理循环的编排智能体负责管理复杂查询的拆解。 系统采用智能体流程将复杂的用户问题分解为离散任务，确保生成准确 SQL 查询的过程结构化且可重复。
  3. Hermes V3 引入了解释层，以提升 AI 生成洞察的透明度和信任度。 该功能澄清了生成 SQL 背后的假设并提供置信度分数，使非技术用户能够理解查询的形成过程，增加他们对系统输出结果的信任。
  4. 该系统与企业安全和数据治理策略进行了深度集成。 Hermes V3 通过基于角色的访问控制、SSO、临时回复和审计日志，严格遵守安全和合规标准，确保对敏感数据的安全访问。

💬 文章金句

  • Hermes 现在接入了一个经过筛选的历史查询及其提示词数据库，利用向量相似度进行检索，并能记住对话上下文，在实现自然的多轮交互的同时，将 SQL 生成准确率从 54% 提升到了 93%。
