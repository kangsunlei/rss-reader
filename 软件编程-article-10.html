CVE-2025-57752：Next.js 图像优化缓存投毒漏洞

8/29/2025, 1:00:00 PM

📌 一句话摘要

Next.js 图像优化中存在一个缓存投毒漏洞 (CVE-2025-57752)，允许未经授权访问敏感图像，造成严重安全风险。Vercel 已在 v15.4.5 和 v14.2.31 版本中修复此漏洞，请尽快升级。

📝 详细摘要

本文详细介绍了 CVE-2025-57752 漏洞。该漏洞为严重的缓存投毒漏洞，影响 Next.js 图像优化 v15.4.5 和 v14.2.31 之前的版本。当 API 路由返回基于请求头的图像内容，并且这些图像由 Next.js 图像优化处理时，就会出现此问题。优化的图像可能在未将这些敏感标头合并到缓存键中的情况下被缓存，这可能导致未经授权的用户访问其不应访问的图像内容，或者通过 CDN 或内部缓存泄露用户数据。此漏洞不需要用户交互或提升的权限，只需要先前的授权请求来填充缓存。解决方案包括阻止请求头转发到代理的图像接口端点，从而确保需要授权数据的图像无法被缓存。强烈建议用户立即升级到 Next.js v15.4.5 或 v14.2.31。本文感谢 'reddounsf' 的负责任披露，并提供了 GitHub Advisory 和修复 PR 的参考。

💡 主要观点

  1. Next.js 图像优化容易受到通过敏感 API 路由进行的缓存投毒攻击。 利用此漏洞，攻击者可以在不考虑授权标头的情况下缓存优化的图像，从而可能导致未经授权的访问和受保护内容的跨用户泄漏。
  2. 该漏洞允许未经授权披露用户特定或受保护的图像内容。 通过 API 路由提供并由 Next.js 优化的敏感图像可能被不正确地缓存，然后提供给未经授权的用户，从而损害数据隐私。
  3. 该修复程序阻止请求头转发到图像接口端点。 此修复方案能够确保需要授权数据的图像无法被缓存，从而有效地减轻了敏感内容的缓存投毒风险。

💬 文章金句

  • 已经解决了一个影响 **Next.js 图像优化** 的漏洞。它影响了 **v15.4.5** 和 **v14.2.31** 之前的版本，并且涉及一个缓存投毒问题，该问题导致来自 API 路由的敏感图像响应被缓存并随后提供给未经授权的用户。
  • 当 API 路由用于返回基于标头而变化的图像内容，并且这些图像通过 Next.js 图像优化传递时，优化的图像可能会在不包括这些请求标头作为缓存键的一部分的情况下被缓存。
  • 这可能导致：用户特定或受保护的图像内容的**未经授权的披露**；通过 CDN 或内部缓存有条件的内容的**跨用户泄漏**。
  • 该问题通过确保请求标头不转发到代理到图像接口端点的请求来解决。 这确保了图像接口端点不能用于提供需要授权数据因此无法缓存的图像。
