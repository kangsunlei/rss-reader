开源模型赢了 Token 流量，Anthropic 赚走了大部分钱

7/11/2026, 3:37:00 AM

📌 一句话摘要

文章通过数据和案例分析解释了为何开源模型在 Token 使用量上领先，而前沿模型厂商仍保持主要收入来源。

📝 详细摘要

文章引用 Decagon CEO Jesse Zhang 的观点，指出尽管开源模型在 Token 消耗量上占优（如 DeepSeek 在 Vercel AI Gateway 占比超三分之一），但前沿模型如 Anthropic 的 Opus 4.8 仍占据平台大部分支出，原因在于企业在应用早期阶段愿意为通用智能支付溢价，待场景成熟后再迁移至成本更低的开源模型。文中还引用了 Dario Amodei 关于“开放权重”与真正开源的区别，以及模型成本、延迟和微调需求的讨论，并指出 Nvidia Nemotron 等新模型可能进一步格局。整体呈现出一种双层模型经济：前沿模型主导应用发现，开源模型主导生产部署。

💡 主要观点

  1. 开源模型在 Token 使用量上领先，但前沿模型仍占据主要支出。 文中引用 Vercel AI Gateway 和 OpenRouter 数据显示，DeepSeek V4 Flash 处理的 Token 量远高于 Opus 4.8，但由于后者单 Token 成本约为前者的 23 倍，其在平台上的支出份额仍然超过半数。
  2. 企业在应用生命周期早期倾向使用昂贵的前沿模型进行场景验证。 当应用场景尚不明确时，企业愿意为通用智能支付溢价，以获得最强模型的能力；待场景成熟后，再转向成本更低、可定制的开源模型进行生产部署。
  3. 开源模型的选择根源在于定制化需求而非纯成本考量。 作者指出，企业采用开源模型主要是因为前沿模型无法按需微调且不具备完全控制权，而开放权重模型则允许在特定任务上进行深度微调以降低延迟、提升性能。

💬 文章金句

  • 即使模型公开，你也看不到它的内部运行机制，因此业内通常把这类模型称为「开放权重」，而不是「开源」。
  • 开源从来不等于免费。模型体量如此庞大，企业仍然需要花钱在云端运行推理，也需要专业团队进行部署和优化，确保模型能够足够快速、稳定地运行。
  • 前沿模型和开源模型之间并不是竞争对手，开源模型的成功也并非建立在前沿模型实验室失去市场的基础上。相反，它们更像是同一个生命周期中的两个阶段：企业先使用昂贵的前沿模型验证某个应用场景是否成立，等到场景逐渐成熟，再将其迁移到成本更低的开源模型上。
  • 按照这一价格差距推算，尽管 Opus 4.8 的 Token 使用量明显低于 V4 Flash，但它很可能仍然占据了平台大部分模型支出。
  • 当一个应用场景已经充分成熟，企业已经了解输入数据的分布、模型需要表现出的行为，以及必须防范的失败模式时，权衡就会发生逆转。此时，通用智能反而成了额外负担。企业真正需要的是体量最小、速度最快，并且经过专门微调、能够把特定任务做到极致的模型。
