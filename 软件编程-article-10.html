Node.js — Node v24.0.0 (Current)

5/6/2025, 2:31:35 PM

📌 一句话摘要

Node.js v24.0.0 正式发布，包含 V8 13.6 版本升级、npm 11 更新以及多项重要 API 改进。

📝 详细摘要

Node.js v24.0.0 包含以下重要更新：V8 JavaScript 引擎升级至 13.6 版本，新增 Float16Array 和 RegExp.escape 等特性；npm 更新至 11 版本，带来性能提升和安全增强。关键 API 变更包括：AsyncLocalStorage 默认采用 AsyncContextFrame 实现以提升性能；URLPattern 现已成为全局 API。权限系统(Permission Model)已稳定，启动参数从 --experimental-permission 调整为 --permission。测试运行器(test runner)现在会自动等待子测试完成。Windows 平台构建工具链变更为 ClangCL（已移除 MSVC 支持）。此版本还包含 Undici 7 HTTP 客户端的改进，并移除了 url.parse() 和 tls.createSecurePair 等已弃用的 API。

💡 主要观点

  1. V8 升级至 13.6 版本 新增 Float16Array 和 RegExp.escape 等 JavaScript 特性，提升性能和功能支持
  2. npm 更新至 11 版本 性能优化、安全增强以及更好的现代 JavaScript 包兼容性
  3. AsyncLocalStorage 默认使用 AsyncContextFrame 采用更高效的异步上下文跟踪实现，提升性能和 API 健壮性
  4. URLPattern 成为全局 API 无需显式引入(import)即可全局访问，提供强大的 URL 模式匹配功能
  5. Windows 构建工具链变更 构建工具从 MSVC 迁移至 ClangCL，用于 Windows 平台的 Node.js 编译
  6. 测试运行器(test runner)改进 自动等待子测试完成，使测试编写更加直观便捷
