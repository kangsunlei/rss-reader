“人类的带宽太低、算力也低”，agent 可以替人去工作丨 100 个 AI 创业者

4/13/2026, 12:45:00 PM

📌 一句话摘要

本文是对 AI 创业公司 Floatboat 创始人谭少卿的深度访谈，探讨了其以桌面客户端为切入点、聚焦人机交互设计、并最终构建 agent 协同办公网络的独特创业理念与实践。

📝 详细摘要

文章是《晚点 AI》「100 个 AI 创业者」系列的一篇，深度访谈了 Floatboat 创始人谭少卿。Floatboat 是一款独特的 AI 生产力工具，其核心是集成了文件管理器、浏览器和 AI 对话框的桌面客户端，旨在通过感知用户的完整工作环境来释放 AI 的潜力。谭少卿认为，在 AI 智能已足够强大的当下，人机交互设计是决定产品成败的关键，并提出了「产品设计决定用户需求」的观点。文章详细阐述了他的非共识理念，包括对「记忆」的分层处理、对 agent 自主性的谨慎态度，以及将文件管理和浏览器标签作为上下文管理核心的交互逻辑。谭少卿的最终愿景是构建一个 agent 原生的协同办公网络，甚至 agentOS，将人从有限的劳动时间中解放出来。

💡 主要观点

  1. AI 时代的产品创新关键在于人机交互设计，而非单纯追求模型智能。 谭少卿认为，当前 AI 智能已足够强大，但用户通过对话框与 AI 交互的「带宽」太低。Floatboat 通过集成文件管理器和浏览器，将用户的隐性工作环境（文件、操作行为）作为上下文，无需复杂 prompt，从而释放了被压抑的 AI 使用需求。
  2. 「产品设计决定用户需求」，直观的交互能释放被压抑的需求。 他以 OpenClaw 的 skills 功能使用率低为例，指出不是用户没需求，而是调用方式（需记忆名称、打字）门槛太高。Floatboat 通过推荐和拖拽等直观交互，让用户自然使用 Combo Skills，验证了好的设计能创造需求。
  3. Agent 的终极价值在于构建高带宽的协同网络，将人从劳动时间中解放。 谭少卿的愿景不止于工具，而是构建一个 agent 协同办公网络。他认为 agent 间通信带宽远高于人类，未来 agent 可以基于主人的上下文「出去干活」，在无需主人实时介入的情况下协同完成任务，实现真正的生产力解放。
  4. 对「记忆」和「自主性」持审慎态度，主张分层与学习而非全盘自动化。 他反对笼统的「记忆」概念，认为应将其结构化（如 Combo Skills）并分层控制。同时，他对 OpenCaw 的「心跳机制」持保留意见，认为真正的自主性应是 agent 学习用户行为后主动洞察重复性工作，而非预设规则的定时执行。

💬 文章金句

  • 不是没需求，是你的产品没有把需求释放出来。
  • 人类的带宽太低、算力也低。你面对这些庞杂的信息和生产力的时候，怎么处理、怎么协同？这本质上就是人机交互的问题。
  • Agent 跟人不一样，人跟人之间的沟通带宽太小了......但是 agent 与 agent 之间带宽是极大的。
  • 小老虎看起来跟小猫咪没什么区别，但几个月后就不一样了。老虎不是猫。
  • 你只有自己先做，并且要做大，之后人家才愿意去接入，去兼容。
