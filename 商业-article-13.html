一文读懂微软 Build 2026 开发者大会：“Agent 优先”时代到来，一口气发七款自研模型

6/3/2026, 1:11:00 AM

📌 一句话摘要

微软 Build 2026 大会发布七款自研 MAI 模型、Scout 智能体、MXC 系统级安全沙箱及 Project Solara 等产品，宣告「Agent 优先」战略全面落地。

📝 详细摘要

本文对微软 Build 2026 开发者大会的核心发布进行了全面梳理。文章从 CEO 纳德拉的「Agent 优先」战略愿景切入，详细介绍了七大板块：七款从零训练的自研 MAI 模型（含旗舰推理模型 MAI-Thinking-1、编程模型 MAI-Code-1-Flash 等）、以 Scout 和 GitHub Copilot 桌面应用为代表的智能体生态、内置在 Windows 中的系统级安全沙箱 MXC、Edge 浏览器的本地 AI 能力升级、Microsoft IQ 与 Rayfin 等开发者工具与云服务、Surface RTX Spark Dev Box 等新硬件，以及基于 Android 的 Agent 原生平台 Project Solara。文章还提及了量子芯片 Majorana 2 的进展与 Microsoft Discovery 平台的发布。报道结构清晰，信息密度高，完整呈现了微软从模型到硬件、从系统到治理的全栈 AI 布局。

💡 主要观点

  1. 微软发布七款自研 MAI 模型，强调「零蒸馏」与从零训练。 旗舰推理模型 MAI-Thinking-1 在软件工程测试中与顶级模型持平；编程模型 MAI-Code-1-Flash 专为 GitHub Copilot 优化；所有模型共享统一基础设施，并首次允许开发者调整权重。
  2. Scout 是核心智能体产品，可在 Teams 中像人类同事一样工作。 Scout 能浏览消息、日历和邮件，自动完成任务、重新安排冲突会议并起草回复，通过微软 Frontier 计划提供，需 GitHub Copilot 订阅。
  3. MXC 是内置在 Windows 中的系统级安全沙箱，解决 Agent 自主性带来的安全风险。 MXC 提供从进程隔离到云实例的「可组合沙箱频谱」，将 Agent 执行与用户桌面、剪贴板等分离，每个 Agent 绑定身份以实现可审计、可治理。
  4. Microsoft IQ 将四个上下文源合并为 Agent 的共享知识基础。 Work IQ、Foundry IQ、Fabric IQ 和 Web IQ 分别捕获组织运作、知识库、实时业务数据和全球上下文，使 Agent 成为了解公司运转的虚拟员工。
  5. Project Solara 是基于 Android 的 Agent 原生平台，旨在让设备运行 AI Agent 而非应用。 首批概念设备包括桌面中心和可穿戴工牌，微软不自行生产，而是提供参考设计供硬件制造商转化为行业特定产品。

💬 文章金句

  • 你正在构建自己的模型：在你的环境中，用你的数据训练，由你控制。你的机构知识会成为模型的一部分，并且只属于你。
  • 你的公司本质上就是雇佣了你的助理。拥有私人助理的全部意义在于，当你不在工作时，他们还在工作。
  • 界限正在崩塌。你不一定需要传统的应用模式。你不需要传统的方式来开发体验。
