零基础速通 DeepSeek Harness，带你玩转赛博乐高

8/21/2026, 2:00:00 AM

📌 一句话摘要

本文详细介绍了 DeepSeek Harness 的安装（通过 npx、WorkBuddy、Codec）、基本对话、Skill 安装、插件使用及卸载全流程，帮助零基础用户快速上手。

📝 详细摘要

文章从零基础出发，逐步讲解 DeepSeek Harness 的安装方式：官方源码安装、Node.js 快速体验（npx @deepseek-ai/dsh web）、以及通过 WorkBuddy 或 Codex 一键部署。接着演示了首次对话的设置（选择工作区、模型与推理等级）、如何安装 Skill（以 ppt-master 为例）、利用插件市场自定义 UI（如更换背景、添加功能），并展示了多模态功能的现状（Harness 已支持图文输入，但当前 DeepSeek-V4-Pro 模型尚不支持多模态）。最后说明了卸载方法（关闭进程、删除文件夹或使用系统卸载），并指出未来使用 AI 工具只需明确需求，交给 Agent 处理。全文配有大量截图和操作步骤，适合想要快速体验 DeepSeek Harness 的开发者和 AI 爱好者。

💡 主要观点

  1. DeepSeek Harness 支持多种安装途径，包括源码编译、npx 快速体验以及 WorkBuddy/Codec 一键部署。 文章详细对比了三种方式的操作步骤和适用人群，指出对于不熟悉命令行的用户，使用 WorkBuddy 或 Codex 可大幅降低安装门槛。
  2. 首次对话需要指定工作区、选择模型与推理等级，Harness 会将任务分解为可追踪的子任务并提供决策提示。 通过设置工作区和模型参数，用户可以让 Harness 自动规划任务流程，并在需要人工审批或决策时弹出通知，提升交互的可控性。
  3. 插件系统是 Harness 的核心亮点，支持通过对话框或命令行安装 UI、功能及记忆类插件，实现界面定制和能力扩展。 文章展示了如何安装皮肤插件（如滑动变祖器）、记忆插件以及自定义代码审查插件，说明插件机制使得 Harness 能够像“赛博乐高”般自由组装功能。
  4. 当前 DeepSeek-V4-Pro 模型尚不支持多模态，尽管 Harness 已完成图文输入管线的打通，实际使用图片时会报错。 文章指出 Harness 0820 更新已将图像输入送至模型适配层，但因底层模型不接受图像导致多模态功能受限，提醒用户在尝试图像相关任务时需注意模型能力。
  5. 卸载过程简单：关闭进程删除本地文件夹或使用系统卸载，可选删除 ~/.dsh 目录清理配置和凭据。 无论是通过 npx 临时运行还是源码克隆的方式，文章都给出了对应的清理步骤，确保用户能够彻底移除 Harness 及其残留数据。

💬 文章金句

  • 以前安装一个开源项目，第一步是学会敲命令；现在第一步可以是把 GitHub 链接丢给另一个 Agent。
  • DeepSeek Harness 自己还没有做到点击即用，但 Codex、WorkBuddy 这类本地电脑 Agent，已经把它最劝退普通用户的命令行门槛直接抹掉了
  • 万物皆插件，插件几乎是 DeepSeek Harness 最大的亮点
