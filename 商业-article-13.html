📌 一句话摘要

OpenAI 平台工程负责人揭示其战略转向：从单一模型 AGI 到多专业模型平台，强调 API、微调、上下文工程及 Agent Builder 的价值，并分享定价哲学。

📝 详细摘要

文章通过对 OpenAI 平台工程负责人 Sherwin Wu 的深度访谈，揭示了 OpenAI 从追求“最强模型”转向构建“最强平台”的战略演变。核心观点包括：OpenAI 内部认知已转变，单一大一统 AGI 模型路线已破灭，未来将是大量专业化模型和多模型组合的生态；API 和 ChatGPT 并行发展，模型具有强“粘性”难以被抽象；强化微调（RFT）是企业利用数据提升模型性能的关键；提示词工程已演变为上下文工程，工具调用和 RAG 变得更重要；Agent 被视为核心智能的不同接口，Agent Builder 针对流程化、强约束任务提供解决方案；定价策略以按使用量计费为主，并认为开源不会侵蚀 API 业务。访谈内容对理解 OpenAI 的未来方向和 AI 行业趋势具有重要参考价值。

💡 主要观点

  1. OpenAI 战略重心从“最强模型”转向“最强平台”。 OpenAI 内部认知已转变，未来将是大量专业化模型族、微调体系及可控 Agent 并存，通过 API 和 ChatGPT 广泛分发智能，构建最强平台生态。
  2. 单一大一统 AGI 模型路线破灭，多模型组合是未来趋势。 行业认知在短时间内巨变，模型无法被“去中介化”且具有强粘性，市场会演化出大量专业模型，OpenAI 正通过投资定制化和微调 API 来促进生态增长。
  3. 提示词工程演变为“上下文工程”，聚焦工具调用和数据获取。 随着模型指令遵循能力增强，关键在于为模型提供正确工具、数据，引导其主动推理和工具调用，而非传统意义上的简单 Prompting。
  4. Agent Builder 是针对流程化、强约束任务的低代码解决方案。 针对客服、市场等高度流程化、SOP 驱动的行业，Agent Builder 通过节点和强约束确保 Agent 按既定路径执行，满足现实世界对确定性和监管的需求。
  5. 开源模型不会取代 API 业务，模型粘性与推理难度是核心壁垒。 开源模型与 API 服务面向不同用户群，且大规模、高性能的模型推理是极难的工程问题，OpenAI 在训练和推理上的紧密反馈循环难以复制，确保 API 业务的持续价值。

💬 文章金句

  • OpenAI 正在从'做一个最强模型'，转向'做一个最强平台'。
  • 现在越来越清楚的是，会有大量专门化模型的生长空间，而且还会出现很多不同类型的模型。
  • 模型不是那种'你换了我也无所谓'的东西。
  • 所有产品线------Sora、Codex、API、ChatGPT------都是同一核心智能的不同接口、不同部署方式。
  • 在需要强确定性、强流程执行、强监管的任务中，如何让 agent '按轨道走'。
