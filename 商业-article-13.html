又一个收购：AI 时代的 GitHub 为啥值 129 亿美元

8/28/2026, 7:46:00 AM

📌 一句话摘要

NVIDIA 拟以 129 亿美元收购 Hugging Face，因其作为 AI 模型发现、协作与部署的开放入口，具有战略价值，可连接分散开发者生态与通用算力需求，支撑 NVIDIA 在 AI 基础设施中的长期竞争力。

📝 详细摘要

本文分析了 NVIDIA 计划收购 Hugging Face 的背景与动机，指出 Hugging Face 作为 AI 模型的 GitHub，承载了模型权重、数据集、评测和演示应用，并连接了 API 与部署工具。尽管年收入仅 1.5 亿美元，但其在开放模型生态中的入口地位，以及与 NVIDIA 算力需求的潜在协同，使其估值高达 129 亿美元。同时，文章也探讨了收购可能带来的中立性风险，并与 GitHub 被微软收购的先例进行了对比。

💡 主要观点

  1. Hugging Face 是 AI 模型的发现与协作入口 Hugging Face 平台汇集了大量开源模型、数据集和演示应用，并提供版本管理、讨论区和推理接口，成为开发者寻找和使用 AI 模型的主要渠道。
  2. NVIDIA 需要分散的生态来支撑算力需求 随着 OpenAI 等巨头开始自研芯片，NVIDIA 需要依赖一个开放、分散的模型生态来维持对通用 GPU 的需求，而 Hugging Face 正是连接这些分散开发者的关键节点。
  3. 收购价格反映了战略价值而非单纯财务指标 尽管 Hugging Face 的年收入仅 1.5 亿美元，但 129 亿美元的估值反映了其在 AI 开放生态中的战略地位，以及其在模型从发现到部署全流程中的控制力。
  4. 中立性是潜在风险 Hugging Face 的价值部分来自其对所有硬件和云平台的开放性。被 NVIDIA 收购后，如何保持这种中立性，避免其他厂商转投竞争平台，将是交易后的关键挑战。

💬 文章金句

  • Hugging Face 真正昂贵的地方，在于掌握了模型从'被发现'到'被部署'的入口。
