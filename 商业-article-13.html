4600 万围观！Claude 两周搓出「Manus」火到宕机：0 行代码是人写，创业公司集体破防

1/19/2026, 8:37:55 AM

📌 一句话摘要

Claude 推出桌面 AI 助手 "Cowork"，0 行代码由人类编写，能直接操作本地文件，引发行业震动并预示 AI Agent 进入本地设备新趋势。

📝 详细摘要

文章介绍了 Anthropic 公司推出的桌面 AI 助手 Claude Cowork，该产品在发布后引发广泛关注，甚至导致服务器一度宕机。Cowork 是一款能够直接操作本地文件的 AI 助手，它将 Claude Code 的核心功能以更友好的桌面应用形式呈现，降低了普通用户使用 AI 进行文件管理和任务自动化的门槛。文章通过多个案例展示了 Cowork 在文件整理、内容创作及复杂任务自动化方面的强大能力，同时强调了其"0 代码是人写，全由 AI 生成"的开发模式。针对桌面 AI 助手的安全顾虑，文章也提及了 Claude Cowork 采用文件系统沙盒技术，以 VZVirtualMachine 和自定义 Linux 根文件系统隔离运行，增加了安全边界。文章认为，Claude Cowork 的出现预示着 AI Agent 正从云端走向本地设备，开启了 AI 交互的新范式，对整个行业产生了深远影响。

💡 主要观点

  1. Claude Cowork 是一个由 AI 生成代码开发的桌面 AI 助手，能直接操作本地文件。 Anthropic 工程师 Boris Cherny 证实 Cowork 的全部代码均由 AI 编写，其核心功能是让 AI 在获得授权后，能够直接读取、编辑和创建本地指定文件夹内的文件，实现文件管理和自动化任务。
  2. Cowork 降低了 AI Agent 的使用门槛，将命令行工具的用户体验转向可视化界面。 它将 Claude Code 命令行工具的功能以无技术门槛的桌面应用形式呈现，让更多普通用户能够方便地利用 AI 处理本地任务，解决"CLI 工具再强大，普通用户根本碰不到"的问题。
  3. Cowork 展现了强大的任务自动化能力，能处理复杂工作流并提升办公效率。 用户案例显示，Cowork 可以完成文件分类、重命名、自动内容生成与分发（找论文、写帖子、生成图片）、制作报告、构建应用等多种复杂任务，被赞为“第一个真正好用的智能办公软件”。
  4. 桌面 AI Agent 面临安全挑战，但 Cowork 通过沙盒技术增强了安全性。 文章讨论了桌面 Agent 可能导致的系统崩溃或数据盗窃风险，并指出 Cowork 运行在文件系统沙盒中，利用 macOS 的 VZVirtualMachine 和自定义 Linux 根文件系统隔离任务，提升了用户数据和系统的安全性。

💬 文章金句

  • 当有人问「这个 Cowork 有多少代码是 AI 写的」时，Claude Code 的工程师 Boris Cherny 只回了三个字：「All of it」。
  • 本来以为只是一个小升级，做了一个有用户交互页面的 Claude Code 而已。但 Claude 自己可能都没有想到，这条视频竟然会有 4600 万的浏览。
  • 这一次，真的是好评如潮。不光是对 Claude Cowork 这个概念，它要做的事情，觉得兴奋；一些实测了 Cowork 的网友，也表示它实际做出来的效果，同样出色，还毫不吝啬地说，这是第一个真正好用的智能办公软件。
  • 如果说过去一年是 Agent 元年，我们看到各式各样的 Agent 产品，都是在浏览器里面运行，无论是 Manus、Kimi K2 还是 MiniMax，都是需要我们上传文件到网页，然后才能进行处理。今年的节奏似乎直接来到本地设备的 Agent 构建，从年底沸沸扬扬的手机助手，到前几天刚刚发布的千问 App，能直接购物导航......Agent 的作用，仿佛从一个独立的网站里面跳出来，开始要真正进入我们实际使用的设备上。
