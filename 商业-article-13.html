DeepSeek 降价背后：Token 生意在重新洗牌

5/8/2026, 10:55:00 AM

📌 一句话摘要

本文从产业经济学视角系统分析 Token 市场的定价逻辑、市场结构、商业模式演化及未来趋势，揭示 DeepSeek 降价与 OpenAI 涨价并存背后的深层商业逻辑。

📝 详细摘要

本文是《Token 经济学》系列第八期，由上海交通大学教授史占中撰写。文章以 DeepSeek V4 大幅降价与 OpenAI GPT-5.5 涨价这一矛盾现象为切入点，从货币理论、市场结构、商业模式与公共政策等维度系统审视 Token 经济。核心内容包括：当前 Token 市场呈现「分层式寡头垄断」结构，高端市场由 OpenAI、Anthropic、Google 等寡头主导，中低端市场则被开源模型和众多云服务商占据；Token 定价逻辑从成本导向转向价值导向，输出 Token 价格远高于输入 Token；定价模式正经历「三浪叠加」演化——从按量计费到结果导向定价，再到可能的金融化衍生品市场；Token 价格的地区差异正在扩大，中国厂商凭借能源成本、算法创新和政策支持形成结构性价格洼地，驱动全球算力再平衡。文章还探讨了商业模式从「卖 Token」向「卖结果」的转变、未来 Token 交易所的可能性、竞争格局的「电信式」演化以及碳排放外部性定价等前沿议题。

💡 主要观点

  1. Token 市场呈现「分层式寡头垄断」结构，高端与中低端市场并存。 OpenAI、Anthropic、Google 等构成高端寡头，定价以价值锚定为主；中低端市场被开源模型和云服务商占据，呈现垄断竞争特征。开源模型构成价格天花板，低切换成本约束溢价空间。
  2. Token 定价模式正经历从按量计费到结果导向定价的「三浪叠加」演化。 第一浪按量计费与订阅并行，第二浪结果导向定价（按任务完成计费）将在 2-3 年内崛起，第三浪 Token 金融化（期货、衍生品）可能在 3-5 年内出现雏形，最终形成混合定价体系。
  3. Token 价格的地区差异正在扩大，中国厂商形成结构性价格洼地。 中国厂商凭借能源成本优势、出口管制倒逼的算法创新（MoE、量化压缩）以及产业政策支持，将推理成本压缩至美国同行的几十分之一，驱动 API 跨境套利和全球算力再平衡。
  4. 商业模式正从「卖 Token」向「卖结果」转变，但两种模式将长期共存。 用户真正付费的对象正从模型调用转向任务完成，但「结果」的定义和风险承担转移是核心难题。最可能的演化路径是 Token 作为底层计费协议，结果作为上层商业包装。

💬 文章金句

  • Token 的「真实成本」可能连公司自身也难以精确核算。训练成本、推理成本、研发人员分摊、数据采购、安全对齐成本......这些项目难以精确归因到单个 Token 上。
  • 用户切换 AI 提供商的成本极低，往往只需要修改几行 API 代码，这迫使即使是寡头也不敢过度定价。
  • Token 不会消失，它将退居幕后成为 AI 产业链的底层计量标准，而用户看到的将是「任务完成」「订阅套餐」「服务包」等上层定价形态。
  • Token 经济学的剧本还在第一幕。技术在降价，开源在倒逼，监管在追赶，地缘在切割——每一股力量都在逐步去重塑这张定价表背后的权力结构。
  • 理解 Token 的定价、市场结构与未来趋势，本质上是在理解一种新型生产要素如何被嵌入到人类社会既有的经济、政治和文化秩序之中。
