刚刚，OpenAI 正式发布 o3-pro！奥特曼激动更新博客：温和的奇点

6/11/2025, 3:26:00 AM

📌 一句话摘要

OpenAI 发布新模型 o3-pro，性能超越 o3，CEO Sam Altman 同步发表“温和的奇点”博客。

📝 详细摘要

文章报道了 OpenAI 最新推理模型 o3-pro 的正式发布，该模型已面向 Pro 和 Team 订阅用户开放。根据 OpenAI 公布的专家评估和学术基准测试，o3-pro 在科学、教育、编程和数据分析等领域相对于前代 o3 展现出显著性能提升，特别在数理和编程任务上表现突出，评论者也对其清晰度、指令遵从性等给予更高评价。文章也提供了部分早期用户的实测反馈，结果褒贬不一，有用户对其编程和问题解决能力赞赏，也有用户表示失望。同时，文章引用了 OpenAI CEO Sam Altman 题为“温和的奇点”的博客，其中 Altman 认为人类正迈向数字超级智能，这将极大地加速科学进步和生产力提升，带来物质丰裕，但也强调了技术安全、广泛普及使用权以及社会适应的重要性。API 定价方面，o3-pro 价格较高（每百万输入 token 20 美元 / 输出 80 美元），但 o3 价格大幅下调（每百万输入 token 2 美元 / 输出 8 美元），仅为 o3-pro 的十分之一。

💡 主要观点

  1. OpenAI 发布 o3-pro 模型，多方面性能优于 o3。 新模型在专家评估中获得更高评价，并在数理、科学、编程等学术基准上表现出色，尤其在推理能力、清晰度和指令遵从性上有明显提升。
  2. o3-pro 已对 Pro/Team 用户开放，API 定价较高但 o3 大幅降价。 付费订阅用户可通过 ChatGPT 和 API 使用新模型。虽然 o3-pro 的 API 成本较高，但 OpenAI 同时将 o3 的价格降低了 90%，为用户提供更经济的选择。
  3. Sam Altman 博客探讨“温和的奇点”与 AI 未来影响。 Altman 预言数字超级智能即将到来，认为这将加速科学进步，带来巨大的生产力和物质丰裕，但也强调解决技术和社会安全问题、普及使用权以及社会快速适应新变化的重要性。
  4. 早期用户对 o3-pro 实测反馈不尽相同。 部分用户对其在编程和复杂问题解决上的能力表示赞赏，认为其性能有显著提升，但也有用户表示实际体验未能达到预期或感觉提升不明显。
