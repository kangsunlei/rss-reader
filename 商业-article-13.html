Codex 大踏步进击，入驻浏览器，它新增的能力得有这么多…

5/10/2026, 4:25:00 AM

📌 一句话摘要

OpenAI 为 Codex 推出 Chrome 扩展，使其能直接操作浏览器、协调多代理并行测试复杂网页交互，并集成 DevTools 调试能力，将 AI 编程助手扩展为浏览器原生工作平台。

📝 详细摘要

文章介绍了 OpenAI 在 5 月 7 日发布的 Codex for Chrome 扩展。与开源扩展不同，Codex 不仅能测试代码，还能实际操作浏览器，协调多个子代理并行测试多人协作网页应用。文章通过一个多人在线画图游戏的测试案例，展示了 Codex 创建房间、协调代理、检查结果的完整流程。扩展的核心能力包括：直接操作已登录的网页服务、多标签页后台并行处理、集成 DevTools 接口进行前端调试、跨标签页汇聚上下文。Codex 会自动判断使用 API 插件、Chrome 扩展或内置浏览器三种通道中的最优方式。文章指出，Codex 周活跃用户已超 400 万，比年初增长 8 倍，并提到 OpenAI 未来可能将 Codex、ChatGPT 和自研浏览器 Atlas 合并。最后给出了安装路径和安全风险提示。

💡 主要观点

  1. Codex for Chrome 扩展实现了浏览器原生操作能力，区别于 Computer Use 的截图推理方式。 扩展直接获取 Chrome 的完整能力，包括已登录 session、多标签页上下文和 DevTools 接口，比 Computer Use 的截图+坐标方式更高效精准。
  2. 多代理并行测试复杂网页交互是核心价值场景。 文章通过多人画图游戏测试案例，展示了 Codex 协调 4 个子代理在各自标签页中同步操作的能力，解决了人工测试多人协作应用时的痛点。
  3. Codex 自动选择最优通道访问网络资源。 系统会根据任务类型自动判断使用 API 插件、Chrome 扩展或内置浏览器三种通道，用户也可通过 @Chrome 指令强制指定。
  4. Codex 周活跃用户超 400 万，增长迅速。 比年初增长 8 倍，收入快速增长，可能威胁 Anthropic 地位，对国内厂商有启示作用。

💬 文章金句

  • 大厂做的扩展和开源扩展，确实不是一个东西。Codex for Chrome 不只是测试代码成果，还能实际操作浏览器，协调多个代理并行测试复杂的网页交互场景。
  • 既然工作都在浏览器里，那就让 Codex 原生地待在浏览器里吧。
  • Codex 未来面向的是所有日常工作泡在浏览器里的人。运营同学用来操作后台、产品经理用来看数据看板、市场同学用来批量收集竞品信息，这个野心不可谓不大呀。
  • 既然 Codex 能操作你已登录的网页，就意味着它能接触到你在那些服务里的数据。这是能力来源，也是风险边界，自己做好平衡。
