wxa-runner: Run WeChat Mini Programs Directly in Chrome Browser

11/6/2026, 1:40:00 AM

📌 一句话摘要

An open-source project wxa-runner allows developers to run and debug WeChat mini programs in Chrome DevTools without needing the WeChat Developer Tools.

📝 详细摘要

The tweet introduces wxa-runner， an open-source tool that enables running WeChat mini programs， uni-app， and Taro projects directly in Chrome with full DevTools debugging support， hot reload， Playwright test automation， and simulated login capabilities. It provides installation via npx and includes technical details for developers.

💡 主要观点

  1. Direct Browser-based Mini Program Execution wxa-runner eliminates the need for WeChat Developer Tools by allowing mini programs to run directly in Chrome， streamlining the development workflow for developers.
  2. Cross-framework Compatibility Supports native WeChat mini programs， uni-app， and Taro frameworks， making it versatile for developers using different development stacks.
  3. Integrated Testing and Debugging Enables Playwright automated testing and Chrome DevTools debugging with hot reload， including simulated login， request interception， and static export features for broader use.
