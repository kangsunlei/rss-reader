怎么做 IP 这件事，大家都在学迪士尼，但还没人真正学会

6/29/2026, 11:39:00 AM

📌 一句话摘要

本文深度编译 Acquired 播客对迪士尼 IP 商业模型的万字拆解，系统揭示其飞轮逻辑、历史教训与不可复制的护城河，并指出任天堂是唯一成功复刻的公司。

📝 详细摘要

文章基于 Acquired 播客近四小时的深度内容，系统拆解迪士尼如何从一部动画短片成长为全球最强 IP 公司。核心论点包括：动画角色因不老、不涨薪、永远工作而具备结构性优势；迪士尼成功的关键在于同时满足四件事：100% IP 所有权、动画媒介、低频高质的稀缺性纪律、长期稳定的所有权结构。文章详述了从失去幸运兔奥斯华到建立米老鼠品牌、从《白雪公主》的豪赌到迪士尼乐园的诞生、从二战时期的品牌保护到金库重映策略的发现等关键历史节点。同时指出，没有新 IP 持续注入，飞轮会退化，1984 年差点成为地产公司。最后分析只有任天堂做了类似的事，并给出对 IP 创业者的四个拷问。

💡 主要观点

  1. 迪士尼成功的起点是 100%拥有 IP 所有权，这一教训源自 1928 年失去幸运兔奥斯华的惨痛经历。 失去奥斯华让迪士尼意识到，发行渠道和团队都可被替代，唯有 IP 所有权是根本。此后所有决策都围绕此信条，包括最终用一位体育主播换回奥斯华版权。
  2. IP 商业模式不是设计出来的，是跟着市场信号跑出来的飞轮逐步长成。 米老鼠俱乐部、周边授权、漫画条等节点都是偶然发现并快速跟进的，并非 Walt 事先规划。飞轮是保持开放、在核心产品基础上快速响应市场的结果。
  3. 主力媒介必须保持稀缺，次级媒介可以铺天盖地，两者互相强化不消耗。 电影作为主力媒介需低频高质（如每 6-8 年重映一次），而周边、漫画等次级媒介可大量铺开。Disney+打破这一平衡导致漫威和星战疲劳。
  4. 动画角色具有永久性的结构优势，真人 IP 无法比拟。 米老鼠永远不老、不涨薪、无档期纠纷，可无限复利。真人 IP 受演员年龄、薪酬绑架，无法实现同等商业周期。
  5. 飞轮不是永动机，没有新 IP 持续注入会退化为地产公司。 Walt 去世后近 20 年无新爆款，电影利润降至乐园的 1%，直到收购皮克斯、漫威等才重启引擎。IP 体系需持续投资和维护。

💬 文章金句

  • 动画角色永远不会老，永远不会死，永远不需要涨薪，永远可以工作，永远活在当下。
  • 稀缺性不是自动存在的，是需要被管理的。主力媒介一旦丧失稀缺感，飞轮的增强机制就会反转成消耗机制。
  • IP 不会折旧，只要你管理好它的出现频率，它可以被反复货币化。
  • 飞轮的前提是有一个受众真正爱上的核心 IP。
  • All-in 是飞轮公司的宿命，不是选择，你不可能在质量上打折。
