weread-book-exporter: Open-Source Tool to Export WeChat Reading Books

11/8/2026, 12:33:00 AM

📌 一句话摘要

An open-source project that exports all books from WeChat Reading to PDF， EPUB， or Markdown formats while preserving original content and structure.

📝 详细摘要

The weread-book-exporter project allows users to export any book they have reading permission for in WeChat Reading to local formats including PDF， EPUB， and Markdown. It preserves the original table of contents， heading levels， and high-resolution images， fixing pagination and alignment issues common in web versions. The exported Markdown can be directly imported into Obsidian or Notion knowledge bases.

💡 主要观点

  1. Multi-Format Export Supports PDF， EPUB， and Markdown formats for flexible use cases
  2. Content Preservation Maintains original table of contents， heading levels， and high-resolution illustrations
  3. Quality Improvement Fixes common web version issues like pagination loss and paragraph misalignment
  4. Knowledge Base Integration Exported Markdown files can be directly imported into Obsidian and Notion
