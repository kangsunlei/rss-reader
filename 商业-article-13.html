人是最慢的节点，还怎么管 AI Agent？｜AI 跃迁者调研

📌 一句话摘要

本文深度访谈 Multica 创始人张佳圆，揭示了一个 4 人团队如何通过 Agent 协作平台实现组织效率革命，并探讨了人在 AI 时代的新角色与思考边界。

📝 详细摘要

本文是腾讯研究院「AI 跃迁者调研」系列的第四期，深度访谈了开源 Agent 协作平台 Multica 的创始人张佳圆。文章核心围绕一个 4 人团队如何通过自建的 Agent 编排平台，实现组织效率的指数级提升。张佳圆详细阐述了 Multica 的产品定位（模型中立的协作层）、核心设计原则（Agent 三类角色、最多两层架构）、以及团队的真实工作流（周一规划、每日 6 点 demo、其余时间交给 Agent）。文章深入探讨了「人是最慢的节点」这一核心洞察，分析了组织架构从多人协作到「一人端到端」的变革，并提出了「Agent idle 率」作为衡量组织 AI Native 程度的关键指标。同时，访谈也坦诚地讨论了信任问题、思考退化等代价与未解张力，以及创始人对于增长、壁垒和保持独立思考的深刻反思。

💡 主要观点

  1. 组织效率的瓶颈已从 AI 转向人，人的注意力带宽成为最大摩擦。 Agent 可以并行处理数十上百个任务，但人的注意力有限，同时处理 3-5 件事就已困难，这导致整个组织的产出效率受限于人的处理速度。
  2. Agent 协作架构应遵循「三类角色、最多两层」原则，避免模仿人类低效的多层级组织。 所有 Agent 协作可归结为 Orchestrator（协调者）、Worker（执行者）、Validator（验证者）三类角色。人类组织因信息聚合需要多层，但 Agent 无此限制，超过两层的架构是对人类组织的拙劣模仿。
  3. 组织变革的核心是去掉人与 Agent 之间的中间传递层，实现「一人端到端」负责。 传统多人协作中，信息从人传递到人再给 Agent 会产生巨大损耗。直接由最终负责人与 Agent 沟通，从 PRD 到研发到测试验收由同一人负责，可大幅提升效率。
  4. 「Agent idle 率」是衡量组织 AI Native 程度的关键指标，应持续降低 Agent 闲置时间。 大部分人的 Agent 每天满载运行仅 2-3 小时，闲置 20 小时。降低 Agent 闲置率意味着更多产出，是组织需要持续优化的方向。
  5. 在 AI 时代，人的独立思考能力被低估，需要刻意保护。 AI 输出的是基于统计的「P50」中位数结果，缺乏独特视角。过度依赖 AI 会导致思考退化，创始人应刻意留出时间进行独立思考和决策，如写 journal、先思考再与 AI 讨论。

💬 文章金句

  • 整个组织的产出效率瓶颈，其实现在已经是人了，而非 AI 或者 Agent。
  • 建太多层级，是对人类这种低效组织的一个拙劣模仿。
  • 即使你快速做一个错误的决策，要比你缓慢地做一个正确的决策来得更好，因为你做了错误的决策总是可以去修整它，但你犹豫不决的话，就会导致整个组织因为你这一块而 block 在这里。
  • 人的思考在 AI 时代是被低估的。AI 给你吐出来的东西可能是一个 P50 的东西，就是中位数。
  • 你只要活得足够久，可能是你一个很大的壁垒了。
