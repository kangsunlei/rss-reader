百度搭子重新定义 Agent「托付半径」

7/10/2026, 9:41:00 AM

📌 一句话摘要

百度搭子通过个人版、企业版与搭子联盟三轮更新，构建从个人到行业的「托付半径」，用实际办公案例证明 Agent 交付能力已成为核心赛点。

📝 详细摘要

本文围绕百度搭子在 AI DAY 的发布，深入评测产品更新并提炼「托付半径」概念。个人版升级智能路由、全端记忆与 Browser Use，实际演示了混乱 Excel 表格的智能清洗、优质教学 PPT 的自动生成以及自媒体创作套件的全流程支持；企业版则通过积分技能共享、知识库沉淀和四层安全体系，解决组织对 AI 的不信任问题；搭子联盟借助行业合作伙伴补齐垂直领域 know-how。文章最后对比了 Codex 等竞品，指出 Agent 下半场的胜负手是稳定交付 90%以上的工作，而人类的核心价值将转向判断力。

💡 主要观点

  1. 「托付半径」是衡量 Agent 价值的核心尺度。 文章提出用户愿意把多少工作彻底交给 Agent，决定了产品的上限；百度搭子的三个版本分别对应个人、公司和行业三层信任半径。
  2. 个人版依靠记忆、智能路由与直接浏览器交互降低交付成本。 全端记忆让习惯跨设备延续，智能路由优化任务耗时，Browser Use 从 VNC 模式转为直接操作，显著提升日常办公的效率与可用性。
  3. 企业版解决的核心矛盾是「能用但不敢用」。 通过技能/知识库共享、四层安全体系与全程审计，将一次性提效转化为组织复利，让企业愿意按信任制度而不是感觉来使用 AI。
  4. Agent 赛点在于交付，而非参数与跑分。 文章引用百度 DAA（日活智能体数）概念，强调 Agent 的价值在于每天真正交付了多少结果，并指出人类保留判断力、执行批量外包是未来工作常态。

💬 文章金句

  • 判断力才是这个时代最后的手艺活，把判断之外的一切都托付给 AI。
  • Agent 的赛点是交付，边界是人。
  • 把活尽管交给硅基生物，把人，留下来。
