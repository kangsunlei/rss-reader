聊透 Agent，它是「同事」还是「工具」，创业机会和价值究竟是什么？

6/13/2025, 8:03:00 AM

📌 一句话摘要

专家访谈深入剖析 Agent 真问题与真机会，探讨技术路径、商业模式和未来趋势。

📝 详细摘要

文章通过对拾象科技创始人李广密和 AI Research Lead 钟凯祺的访谈，深入探讨了 Agent 作为继大模型之后的下一个科技风口。指出 Agent 从演示走向实用的门槛在于底层基础设施的构建，而非单纯的模型能力，特别是可控运行环境、记忆系统和上下文感知等。文章提出了从 Copilot 平滑演进到 Agent 的务实路径，并以 Cursor 为例进行分析。重点阐述了 Coding 环境因其数据可验证性和数据飞轮潜力，被视为通往 AGI 的关键试炼场和高价值领域。探讨了评估好 Agent 的标准（任务完成率、成本效率、用户粘性）和 AI Native 的产品理念（同时服务人和 AI）。同时分析了 Agent 商业模式从基于成本向基于价值转变的趋势以及自下而上的 ToB 增长方式。最后展望了人与 Agent 的新型协作关系、Agent 基础设施的关键机会（如虚拟机、浏览器、记忆、工具）以及未来 AI 技术（多模态、自主学习、记忆、新交互）的发展方向和巨头在 Agent 领域的策略分化。

💡 主要观点

  1. Agent 是继大模型后重要风口，核心挑战在于底层基础设施而非模型本身。 Agent 从工具走向智能体，其大规模落地和实用化需要可控环境、记忆系统、上下文感知等基础设施的突破性进展。
  2. 从 Copilot 到 Agent 是务实演进路径，可积累用户数据并逐步实现自动化。 通过从辅助型 Copilot 入手，收集用户反馈和数据，逐步提升 AI 能力和用户心智占领，平滑过渡到更自动化的 Agent 形态。
  3. Coding 因其可验证数据和数据飞轮潜力，是通往 AGI 的关键试炼场。 代码环境结构化且结果易验证，非常适合 AI 进行多轮强化学习和能力迭代，是锻炼 AI 核心能力的重要领域，具有巨大价值潜力。
  4. 好的 Agent 需构建数据飞轮环境、具备上下文感知，并实现 AI Native 双向服务。 通过构建可验证奖励环境（RLVR），增强记忆与上下文连接能力，设计能服务人类和 AI 的双向产品机制，提升 Agent 能力与用户粘性。
  5. Agent 商业模式正从成本向价值转变，ToB 领域自下而上增长模式兴起。 除了传统按成本或 SaaS 收费，按动作、工作流、结果甚至按 Agent 本身付费等新模式出现，更体现 Agent 带来的效率和价值，同时产品开始从 C 端或特定人群自下而上进入企业。

💬 文章金句

  • Agent 由此成为继大模型之后，全球科技圈最快形成共识的第二个风口。
  • 大模型将不再只是工具，而是要成为可以自我调度的智能体。
  • Agent 的真正门槛，或许并不在模型能力，而在其赖以生存的底层设施。
  • AGI 有可能最先在 Coding（编码）环境下实现，因为这个环境最简单，它能锻炼 AI 的核心能力。
  • 我感觉 GPT-4o 开始有记忆的那一刻，我才真正对 ChatGPT 这款应用产生了粘性。
