AI 巨头的「Token 补贴大战」，快打完了吗？

6/21/2026, 4:00:00 AM

📌 一句话摘要

本文从 Token 补贴战切入，分析 AI 巨头烧钱竞争的底层逻辑，并论证 AI Token 因缺乏锁定效应，终局更可能走向「水电煤」式基础设施而非赢家通吃。

📝 详细摘要

文章以「AI 订阅用户实际享受的 Token 价值是订阅费的数十倍」这一反常识现象为引，系统拆解了当前 AI 巨头间的 Token 补贴大战。作者首先引用 SemiAnalysis 的数据，展示 OpenAI 和 Anthropic 订阅计划中惊人的补贴倍数，并指出越贵的套餐补贴越高，本质是「逆向定价」——用亏损锁定重度用户。随后，文章对比了互联网时代的补贴战（滴滴、美团），指出关键差异：AI Token 几乎没有锁定效应，API 标准化使得切换成本极低，补贴无法建立壁垒。文章引入 Google Ventures 创始人 Bill Maris 的观点，揭示谷歌凭借每年超 3000 亿美元的广告利润，有能力将 Token 价格再砍 80%，而依赖融资的 OpenAI 和 Anthropic 在上市后将面临财务报表压力，难以跟进。最后，文章探讨了两种终局剧本：「互联网服务」式的先补贴后垄断，以及「水电煤」式的基础设施化。作者倾向于后者，认为 AI 的竞争是一场没有赢家的消耗赛，最终 Token 将像电力一样成为无人独占的基础设施，对用户而言则是长期享受低价的好消息。

💡 主要观点

  1. 当前 AI 订阅价格是深度补贴后的结果，补贴倍数可达订阅费的数十倍。 SemiAnalysis 数据表明，越贵的套餐补贴越高，这是 AI 公司用亏损锁定重度用户和开发者的策略。
  2. AI Token 缺乏锁定效应，补贴无法建立用户壁垒。 API 标准化使得用户切换模型成本极低，与打车、外卖等依赖网络效应的互联网服务有本质区别，补贴停止后用户可瞬间流失。
  3. 谷歌凭借广告利润拥有不对称的补贴能力，可随时将 Token 价格再降 80%。 Bill Maris 指出，谷歌的广告印钞机使其在价格战中拥有结构性优势，而依赖融资的 OpenAI 和 Anthropic 在上市后将难以应对。
  4. AI 的终局更可能是「水电煤」式基础设施，而非赢家通吃。 由于缺乏锁定效应和产品差异化，竞争将把价格压向成本线，AI Token 最终会成为标准化基础资源，无人能独占暴利。

💬 文章金句

  • Token 就是 token，无论谁家生产的，都是同一种东西。
  • 补贴不是在「建立壁垒」，更像在「维持心跳」——只要有人出价更低，用户就跑了。
  • 当一种技术足够重要、足够通用、足够标准化，它就不再属于任何一家公司。它属于基础设施。
