The Information：硅谷投资人都在看华人 Agent 公司

7/9/2025, 1:25:00 PM

📌 一句话摘要

硅谷投资人与 OpenAI 正密切关注由华人创业者创办的 AI Agent 公司及其产品进展。

📝 详细摘要

文章报道了硅谷投资界和 OpenAI 对华人 AI Agent 创业公司的关注。这些公司如 Manus、Genspark、Lovart 等，致力于通过 AI Agent 自动化各类任务，从数据分析、PPT 制作到日程管理和创意设计。文章详细介绍了 Genspark 的 Super Agent 在商业化上的快速进展，以及 Lovart 在创意设计领域的创新应用。同时指出，这些公司利用 Anthropic 和 OpenAI 等主流 AI 模型，并为避免潜在风险，选择在新加坡等地设立总部，以期打造全球性产品。文章揭示了生成式 AI 从科学研究转向工程落地的趋势，以及华人团队在此领域的优势。

💡 主要观点

  1. 华人 AI Agent 公司正成为硅谷投资和 OpenAI 的焦点。 Manus、Genspark、Lovart 等华人创业公司凭借其 AI Agent 产品在自动化、创意设计等领域取得显著进展，吸引了顶级投资机构和 AI 巨头的关注。
  2. 华人 Agent 产品在商业化和用户增长上展现出巨大潜力。 Genspark 的 Super Agent 在短时间内实现高额 ARR 和大量付费用户，Lovart 的内测版也迅速积累了大量注册用户，显示出市场对 Agent 产品的强劲需求。
  3. 华人创业者通过全球化布局规避风险并拓展市场。 为避免地缘政治和监管风险，这些 AI Agent 公司选择在新加坡等地设立总部，旨在打造具有全球竞争力的产品，实现业务的国际化发展。

💬 文章金句

  • Generative AI 正在从前沿科学转向工程落地------这正是华人的优势所在。
  • 我们有机会运营一款全球性的产品。
  • 在 Super Agent 发布后的 45 天内，其年度经常性收入（ARR）达到了 3600 万美元。
  • 上周，OpenAI 发表了一篇关于 Genspark 的博文，提到该公司使用了 OpenAI 的 GPT-4.1 和实时语音模型。
  • Manus 的总部已于五月迁至新加坡。
