Token，杀死了 AI 应用

7/31/2026, 1:30:00 PM

📌 一句话摘要

本文深挖 AI 视频应用创业公司的 token 采购困局，揭示以转售 token 为核心的商业模式如何陷入毛亏率陷阱，并探讨后训练模型、硬件订阅与 FDE 等出路。

📝 详细摘要

文章以 OiiOii 等 AI 视频生成公司斥资采购火山引擎 Seedance 2.0 官方 API 为切入，剖析 AI 应用行业被 token 经济绑定后的结构性困境。作者提出毛亏率概念：AI 应用公司高价采购顶级模型 token，转售与订阅定价却低于成本，LibTV 甚至赔本转卖 API Key 以堆高 ARR。与传统 SaaS 边际成本随规模摊薄不同，AI 应用用户越多、调用越狠，亏损越大，毛利被模型厂商的后置结算系统牵着走。为救毛利，产品被迫设计成 token 控制器，通过套餐陷阱、模型降级、时长限制等方式抑制消耗，反而损害用户体验。文章还分析了腾讯 WorkBuddy 等巨头不惧 token 消耗的降维竞争，并给出后训练垂直模型、软硬结合订阅、FDE 结果付费等逃出 token 陷阱的方向。

💡 主要观点

  1. 顶级模型 token 正卡住 AI 应用公司的咽喉。 OiiOii 需将约 40% 账面现金用于采购 Seedance 2.0 API 年框，token 价格与并发数、人脸库等权益绑定，直接决定产品能否顺畅运行。
  2. 转售 token 是一场毛亏率生意。 LibTV 以低于采购价反向补贴转卖 API Key 换取收入和 ARR，用户满额使用时边际毛利率可达负百分之十几甚至更高，低价策略反而吸引重度用户，形成逆向选择。
  3. AI 应用与传统 SaaS 的成本结构本质不同。 传统软件边际成本随规模摊薄，AI 应用每次调用都产生真实 token 成本，用户越多、用得越狠亏得越多，毛利被模型厂商后置结算系统牵着走。
  4. 产品设计被 token 控制扭曲。 为救毛利，应用通过套餐陷阱、模型降级、时长限制、参数隐藏等方式抑制用户消耗，产品从围绕体验设计退化为围绕少消耗设计。
  5. 出路在于换一种卖法。 后训练垂直模型、硬件加高毛利订阅、FDE 按成果付费等模式，正在替代单纯转卖 token 的脆弱生意；token 只是入场券而非护城河。

💬 文章金句

  • token 买到的只是入场券，而不是护城河。
  • 工具属性的产品，不存在忠诚度。
  • SaaS 是用户越多越便宜，AI 应用反过来，用户越多你越亏。
  • 真正向 token 而生的公司，并非烧更多 token 的公司，而是能把 token 换了一种卖法的公司。
