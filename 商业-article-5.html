扣子空间一手实测：字节的第一个 Agent，比 Manus 如何？

4/19/2025, 5:01:00 AM

📌 一句话摘要

实测字节跳动通用 Agent 平台扣子空间，展示其任务表现并分析技术特点。

📝 详细摘要

文章实测了字节跳动新推出的通用 Agent 平台“扣子空间”，该平台提供通用实习生和领域专家两种 Agent。评测显示，扣子在制定旅行攻略和穿搭推荐等任务上表现良好，但在专家助手任务中出现 Bug，如 Python 脚本调用失败、API 权限异常等。文章分析了扣子空间的技术特点，包括探索和规划两种模式、MCP 扩展支持，以及与火山引擎 OS Agent 解决方案的协同，体现了字节在 Agent 领域的整体布局。Agent 需要具备深度思考能力和明确的标准，这将是行业发展趋势。

💡 主要观点

  1. 扣子空间在旅行攻略和穿搭推荐等任务上表现良好 扣子空间能够根据用户需求，生成包含行程安排、预算参考和旅行提示的旅行攻略，以及根据天气推荐穿搭并制作相关图片。
  2. 扣子空间支持 MCP 扩展，展现了其在未来 AI 生态中的潜力 通过接入 MCP 扩展，扣子空间可以集成更多插件，实现更丰富的功能，例如语音合成，进一步扩展 AI Agent 的能力边界。
  3. 字节跳动通过快速发布豆包 · 深度思考模型和扣子空间，展现了其在 Agent 赛道的快速迭代能力 字节在 Agent 赛道再次展现了速度与执行力，通过发布豆包 · 深度思考模型、推出 OS Agent 解决方案和内测扣子空间，字节跳动正在快速推进 Agent 产品的落地。

💬 文章金句

  • 字节迈出了走向 Agent 时代的第一步，但距离完美好用，显然也还有很长一段距离。
  • MCP 被认为是未来 AI 生态的「标准 USB 接口」。
  • Agent 是 AI 为各行各业带来变革的必经之路，需具备深度思考模型支持的反思和规划能力，才能完成专业度高、耗时长的复杂任务。
