火山引擎想做 Token“熔炉”

6/21/2025, 12:28:00 PM

📌 一句话摘要

火山引擎通过聚焦 Token 消耗和激进策略争夺 AI 云市场，其模式与传统云厂商不同并面临质疑。

📝 详细摘要

文章深度分析了火山引擎在当前大模型爆发背景下的市场竞争策略。指出火山引擎作为后起之秀，面对传统云厂商在 IaaS/PaaS 层的优势壁垒，采取了区别于它们的激进打法，尤其强调将 Token 消耗量作为核心业务和衡量指标，转而聚焦 MaaS 和 Agent 层。通过巨额投入和流量扶持打造豆包 App 作为 C 端门面，并进行大规模人才挖角，试图在 AI 云市场实现弯道超车。文章引用了内部数据和外部报告支持其论述，但也对单纯以 Token 量衡量价值的有效性、团队效率和策略的长期持续性提出了质疑。整体展现了当前国内 AI 云市场竞争的激烈态势以及各厂商不同的应对策略。

💡 主要观点

  1. 火山引擎将 Token 消耗量作为核心业务指标推动全员聚焦 区别于传统云厂商的营收或 IaaS 份额，火山引擎自上而下以 Token 调用量衡量产品和销售绩效，旨在快速抢占大模型调用市场份额。
  2. 豆包 App 作为火山引擎 C 端门面，通过巨额投入快速拉升用户量和 Token 消耗 得益于字节系流量和营销投放，豆包 App 用户规模快速增长，成为 AI 应用顶流，是火山引擎实现 Token 消耗目标的关键产品。
  3. 火山引擎采取激进的人才挖角策略，快速组建 AI 技术团队 通过高薪从竞争对手和明星创业公司大量吸纳 AI 人才，快速壮大研发力量，为大模型和 AI 业务发展奠定基础。
  4. 聚焦 MaaS 和 Agent 层是火山引擎避开传统 IaaS/PaaS 壁垒的差异化策略 面对阿里云等在底层 IaaS/PaaS 的优势，火山引擎选择直接在模型服务层和应用层发力，寻求新的竞争突破口。
  5. 文章对单纯以 Token 衡量价值的有效性及策略持续性提出质疑 Token 消耗量不等于商业价值，企业更关注解决实际问题。火山引擎高投入、不计 ROI 的策略能否持续并带来盈利仍是未知数。

💬 文章金句

  • 火山引擎目前是表现最激进、不计较投入的云厂商。
  • 火山引擎正在自上而下推动"Token"文化，"谭待（火山引擎总裁）的逻辑很简单，销售身上都背上指标，今年卖多少产品，卖的这些产品能消耗多少数量的 Token"。
  • 据 IDC 统计，在不包含内部产品条件下，去年国内大模型调用总量中，火山引擎占比 46.4%，相当于百度与阿里之和。
  • 在大模型智能成本越来越低的背景下，企业要么选择开源模型自主构建，要么对价格已经脱敏。比起看 Token 调用和价格，他们更想要的是解决问题。
  • 豆包应用团队的人员配置在大厂是常态，可跟 DeepSeek 一比，似乎略显"冗余"。
