GitButler：深度集成 AI 与 Agent 的下一代 Git 客户端

2/8/2026, 7:26:45 AM

📌 一句话摘要

GitButler 是一款深度结合 AI 的 Git 客户端，内置 Claude Code 界面并支持多智能体并行工作及 MCP 协议。

📝 详细摘要

推文介绍了一款名为 GitButler 的新型 Git 客户端。其核心特色在于与 AI 的深度融合：内置了 Claude Code 的图形界面，允许用户在「Agents」标签页中运行多个智能体。每个智能体可对应不同的分支进行并行开发。此外，它还支持 MCP（Model Context Protocol）接口，能够与 Cursor、Claude 等其他 Agent 工具无缝集成，旨在重塑开发者的版本控制工作流。
