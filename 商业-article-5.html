OpenAI 全新 Agent Builder 与 ChatKit：功能强大，令人惊艳

10/8/2025, 6:21:05 PM

📌 一句话摘要

本文探讨 OpenAI 的新 Agent Builder、ChatKit 和 Widgets，展示它们如何简化构建和部署用于客户支持和线索挖掘的自定义多智能体 AI 工作流程。

📝 详细摘要

Amir 和 Greg Isenberg 深入剖析了 OpenAI 的最新创新：Agent Builder、ChatKit 和 Widgets。核心重点是 Agent Builder 的可视化界面，它显著降低了创建复杂多智能体工作流程的门槛，能够协调 AI 智能体执行诸如用户咨询分类、提供支持或捕获销售线索等任务。这通过连接逻辑节点、工具调用和向量存储上下文来实现，无需大量编码。ChatKit，作为一款全新的 SDK，有助于将这些 Agent Builder 工作流程集成到网站中，使非技术团队能够部署和管理复杂的聊天机器人。Widgets 在聊天界面中提供动态 UI 组件。讨论重点介绍了一个多智能体系统的实际演示，该系统将用户分类为现有客户或新线索，并将他们引导至支持智能体（使用知识库）或销售智能体（收集潜在客户信息）。文章强调了这些工具的成本效益、定制化以及对开发人员依赖性的降低，并将它们定位为 AI 发展的重要里程碑，使高级功能不仅限于工程师，更能为更广泛的受众所用。

💡 主要观点

  1. OpenAI 的 Agent Builder 通过可视化界面简化了多智能体工作流程的创建，显著降低了技术门槛。 Agent Builder 允许用户使用拖放界面设计复杂的多智能体协同流程，集成工具、逻辑节点和向量存储，无需深入的编码知识，从而使非技术用户也能使用高级 AI 功能。
  2. ChatKit 和 Widgets 支持将 Agent Builder 工作流程无缝集成到具有动态 UI 的网站中，从而减少对开发人员的依赖。 ChatKit 提供了一个 SDK，用于将自定义 AI 智能体工作流程部署到前端应用程序，而 Widgets 在聊天界面中提供动态 UI 组件，从而使非技术团队能够独立管理和更新网站聊天机器人。
  3. 新工具使非技术团队能够构建、部署和管理用于特定业务需求的自定义 AI 智能体，例如客户支持和线索挖掘。 通过普及多智能体系统开发，这些工具允许产品经理、客户支持和销售团队创建量身定制的 AI 解决方案，从而提高效率，并减少对工程资源的依赖以进行部署和迭代。
