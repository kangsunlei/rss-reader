当所有 AI 都在理解世界，这家公司在理解你

6/25/2026, 12:49:00 PM

📌 一句话摘要

本文通过创始人访谈，介绍 Clipto.AI 以端侧多模态模型构建个人记忆层（Memory Layer）的理念与产品，认为 AI 需要理解用户个人数据才能走向真正的 Personal AI。

📝 详细摘要

文章专访 Clipto.AI 创始人康洪文，阐述了他在 AI 记忆层方向的产品愿景。Clipto 是一款跑在本地的多模态搜索工具，能对视频、音频、图片、文档进行感知理解与结构化组织，让用户通过自然语言查询个人数据。康洪文认为，当前 AI 过度关注世界模型却缺失用户模型，Agent 的普及需要独立于 Intelligence Layer 的 Memory Layer 作为基础设施。文章回顾了创始人从微软亚洲研究院、卡内基梅隆大学到智影（后被腾讯收购）的二十年经历，说明其从视频理解、视频生成到记忆组织的技术主线。文章还讨论了本地与云端协同的 AI 架构趋势，以及 Memory Layer 在隐私、成本与连续上下文方面的优势。总体而言，文章对 Memory Layer 概念进行了较完整的介绍与论证，但缺少技术细节与对潜在问题的深度剖析。

💡 主要观点

  1. AI 缺失 Memory Layer，导致无法理解用户个人上下文。 当前大模型拥有互联网知识，但用户数据散落在本地设备中，AI 无法持续构建个人模型，Agent 因此无法真正理解用户。
  2. Clipto 通过本地端侧多模态模型构建个人记忆层。 系统在设备端完成视频、音频、图片、文档的感知与结构化解析，用户可用自然语言搜索或提问，所有处理不出设备，保障隐私与低成本。
  3. 未来 AI 架构将分为 Intelligence Layer 与 Memory Layer。 云端大模型负责世界知识（Intelligence Layer），本地记忆系统负责个人上下文（Memory Layer），两者协同构成 Personal AI 的基础设施。
  4. 创始人二十年技术主线从理解内容、生成内容演进到组织内容。 康洪文先后在微软亚洲研究院、卡内基梅隆大学研究视频理解，创办智影实现视频生成，如今押注 Memory Layer，对应 AI 技术演进的三阶段。

💬 文章金句

  • 过去十年，AI 一直在构建世界模型，但缺少用户模型。
  • 如果没有长期记忆，再聪明的 Agent 也无法真正理解用户。
  • Agent 负责执行任务，Memory Layer 负责管理用户记忆，所有 Agent 都能够基于这套统一记忆系统理解用户。
