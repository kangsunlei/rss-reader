晚点独家丨智谱 API 用户数近 700 万，新启用超 5 万块国产算力芯片

8/10/2026, 2:19:00 PM

📌 一句话摘要

智谱 API 用户近 700 万，ARR 增长 15 倍，已启用超 5 万块国产算力芯片，并通过算法优化提升推理效率，编程场景带动业务快速增长。

📝 详细摘要

晚点独家报道称，智谱 API 用户近 700 万（较七月初增约 200 万），其中企业客户 2.3 万家；ZCode 上线 1 月突破百万用户。今年以来 ARR 增长 15 倍，受编程场景及前沿模型拉动。智谱已启用超 5 万块国产算力芯片，并通过 KV 缓存分拆、ZCube 架构及高速 API（400 token/s）等手段，使长程任务推理吞吐最高提升 132%，集群吞吐提升 15%，交换机与光模块需求降三分之一。Coding Plan 价格从 20 元/月涨至 118 元/月，API 毛利率在自有算力设施上可达 50%-60%。文中还讨论了独立模型公司的算力窗口期及大厂在算力与人力上的优势。

💡 主要观点

  1. 用户与收入快速增长 API 用户近 700 万，较七月初增长约 200 万；ARR 增长 15 倍，受编程场景需求及前沿模型拉动。
  2. 国产算力芯片大规模启用 已启用超 5 万块国产算力芯片以缓解推理需求，为模型服务提供硬件基础。
  3. 推理效率技术优化 通过 KV 缓存分拆、ZCube 推理网络及高速 API（400 token/s），长程任务推理吞吐最高提升 132%，集群吞吐提升 15%，交换机与光模块需求降低三分之一。
  4. 商业模式与毛利率提升 Coding Plan 价格从 20 元/月涨至 118 元/月，API 毛利率在自有算力设施上可达 50%-60%，显示卖 token 的盈利空间。

💬 文章金句

  • 智谱 MaaS 开放平台注册用户（即 API 用户）近 700 万，相比七月初增长约 200 万
  • 今年以来，智谱 ARR 增长 15 倍
  • 有超过 5 万块国产算力芯片已经启用
  • 通过分拆 KV 缓存，智谱和中科加禾的研究成果可以将单个推理服务吞吐随长程任务增长而最高提升达 132%。
  • 智谱 API 毛利率在理想状况下，于自有算力设施上运转时可达 50% 到 60%。
