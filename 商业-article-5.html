速递｜AWS 百亿豪赌或遭反噬：Anthropic API 争夺战，与谷歌云的反向收割

4/22/2025, 3:16:59 AM

📌 一句话摘要

由于 Bedrock 服务在容量和功能上存在限制，AWS 在 Anthropic 上的百亿投资或面临挑战，或将导致市场份额和声誉的损失。

📝 详细摘要

文章指出，亚马逊对其投资的 AI 初创公司 Anthropic 的依赖可能带来问题。AWS 通过其 Bedrock 服务向客户提供 Anthropic 的 AI 模型，但由于 Bedrock 在 API 使用量限制和功能（如提示缓存功能）上的不足，许多客户由于无法获得最优条款和最新功能，选择直接使用 Anthropic 的 API，甚至转向谷歌云的 Vertex 服务，以获得更灵活和高效的 AI 服务。文章还提到，AWS 内部对 Bedrock 的容量问题表示担忧，并采取了一些措施来解决这些问题，例如将 Bedrock 业务划归 EC2 负责人管辖。尽管如此，AWS 在云计算领域的地位仍然稳固，但 Bedrock 的问题可能会影响其在 AI 领域的竞争力。同时，文章也提及了微软 Azure 和 OpenAI、谷歌云和 Gemini 也面临着类似的问题。

💡 主要观点

  1. AWS Bedrock 服务在容量和功能上存在短板，影响客户体验 Bedrock API 的使用限制和功能滞后，导致客户难以充分利用 Anthropic 的 AI 模型，影响了 AWS 在 AI 领域的竞争力。
  2. 客户转向 Anthropic 自有 API 或谷歌云 Vertex，对 AWS 构成潜在威胁 由于 Bedrock 的限制，部分客户选择直接使用 Anthropic 的 API 或转向谷歌云的 Vertex 服务，这可能导致 AWS 失去潜在的大客户和收入。
  3. AWS 将 Bedrock 业务划归 EC2 负责人管辖，体现了对该问题的重视 AWS 通过调整管理层结构，将 Bedrock 业务置于其核心云服务器业务负责人之下，表明 AWS 正在积极寻求解决方案。
  4. AWS 采取措施解决 Bedrock 问题，但效果有待观察 AWS 提供 Provisioned Throughput 服务，以解决容量问题，但这些措施的效果仍需进一步验证。

💬 文章金句

  • AWS 高层将 Bedrock 的容量问题称为“灾难性事故”
  • 我知道我们希望获得最优条款，并且需要最新的功能，而这些最新功能会优先出现在 Anthropic 上
  • AWS 在 Bedrock 中采用速率限制，以确保所有客户能“公平获取”热门 AI 模型资源，并在其云服务器业务 EC2 等服务中“保护技术安全与连续性”
