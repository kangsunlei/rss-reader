Databricks 身份安全升级：无密码、更智能、更安全

5/21/2025, 9:55:51 AM

📌 一句话摘要

Databricks 通过引入无密码选项、托管 MFA、增强 PAT 控制、统一登录和自动配置等一系列新功能，提升身份安全水平。

📝 详细摘要

Databricks 正在通过几项新的身份和访问控制功能增强其数据智能平台安全性，朝着无密码、情境感知的未来发展。主要公告包括 Databricks 托管的多因素身份验证 (MFA) 的正式发布。此前，Databricks 已经弃用了托管密码。通过自动 90 天不活动撤销和新的个人访问令牌 (PAT) 的 2 年最大生命周期，以及管理员的访问令牌报告，加强了程序化访问安全性。统一登录简化了单点登录 (SSO) 管理，只需从单个帐户级别配置即可应用于所有工作区。此外，自动身份管理在 Azure Databricks 上以公开预览版推出。它通过与 Microsoft Entra ID 的原生集成，实现无缝用户预配置。这些更新旨在简化安全管理，增强保护，并符合不断发展的行业标准。

💡 主要观点

  1. Databricks 托管的 MFA 正式发布，为无密码安全未来提供支持。 随着托管密码的弃用，Databricks 托管的 MFA 的正式发布为没有 IdP 托管的 SSO 的用户提供了一种内置的、更强大的身份验证方法。
  2. 新的 PAT 控制提高了自动化访问的安全性。 自动不活动撤销（90 天）和新 PAT 的最大生命周期（2 年）显著降低了风险。这些措施针对的是长期存在且可能被泄露的 API 令牌，这些令牌常用于自动化。
  3. 统一登录简化了跨工作区的 SSO 管理。 在帐户级别集中 SSO 配置减少了管理开销，确保了一致的安全策略，并简化了跨多个 Databricks 工作区的访问。
  4. 自动身份管理支持实时、无缝的用户预配置。 通过与 Microsoft Entra ID 的原生集成，可以自动执行用户和组同步，从而简化访问管理，并轻松共享 AI/BI 仪表板等资源。

💬 文章金句

  • 身份安全的未来是无密码、情境感知和无摩擦的。
  • 随着越来越多的客户依靠 Databricks 来普及数据和 AI 访问，保护自动化访问比以往任何时候都重要。
  • 统一登录立即将单点登录 (SSO) 带到您帐户中的所有 Databricks 工作区。
  • SSO 仍然是集中身份管理的最佳实践。
  • 自动身份管理通过与 Entra ID 中的用户、组和服务主体进行原生集成，实现安全、实时的访问管理。它无需连接器应用程序或手动同步。
