MockMvcTester：Spring 控制器测试的利器

4/22/2025, 1:22:39 PM

📌 一句话摘要

Spring 框架 6.2 引入的 MockMvcTester，使用 AssertJ 风格的断言，更便捷地测试 Spring 控制器。

📝 详细摘要

本文详细介绍了 Spring 框架 6.2 中引入的 `MockMvcTester`。它构建于 `MockMvc` 之上，并提供 AssertJ 支持，能够更流畅、更高效地测试 Spring 控制器。本文演示了在多种常见场景下使用 `MockMvcTester`，例如 REST API、Thymeleaf 视图等，包括测试 REST API JSON 响应、异常处理、Thymeleaf 视图渲染、URL 重定向、flash 属性和模型验证错误。此外，还介绍了如何在 `@WebMvcTest` 和 `@SpringBootTest` 环境中配置 `MockMvcTester`，以及如何从现有 `MockMvc` 实例创建 `MockMvcTester` 实例。总而言之，`MockMvcTester` 通过其流畅的 API 和全面的断言，显著提高了 Spring 控制器测试的效率和可读性。它采用 AssertJ 提供的断言方式。

💡 主要观点

  1. `MockMvcTester` 提供了更简洁的 API，简化了 Spring 控制器的测试。 与传统的 `MockMvc` 相比，`MockMvcTester` 通过链式调用和更具表现力的断言，提高了测试代码的可读性和可维护性。
  2. `MockMvcTester` 支持各种测试场景，包括 REST API 和 Thymeleaf 视图。 `MockMvcTester` 提供了相应的 API 和断言，用于测试 REST API JSON 响应和异常处理，以及测试 Thymeleaf 视图渲染和模型数据。
  3. `MockMvcTester` 可以通过 `@WebMvcTest` 和 `@SpringBootTest` 轻松配置和使用。 在 Spring Boot 项目中，可以通过简单的注解配置自动配置 `MockMvcTester`，或者从现有的 `MockMvc` 实例创建。

💬 文章金句

  • 相比于手动查找 `get()`、`post()`、`status()` 等静态导入，使用 `MockMvcTester` 提供的流畅 API 更加便捷。
  • 正如您在本文中看到的，`MockMvcTester` 帮助您使用流畅的 API 编写测试，并提供许多自定义断言来更清晰地验证测试结果。
  • 如果您使用的是 Spring Boot 3.4.0 或更高版本，则可以开始使用 `MockMvcTester` 来编写更易读的测试代码，使用流畅的 API。
