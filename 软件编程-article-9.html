Claude Code 新增支持通过 流式 HTTP 连接 远程 MCP 服务器

6/22/2025, 12:00:00 AM

📌 一句话摘要

Claude Code 新增支持通过 流式 HTTP 连接 远程 MCP 服务器，从而大幅简化了与外部 开发者工具 的集成。

📝 详细摘要

Anthropic 的 Claude Code 现在支持使用 流式 HTTP 连接到 远程 模型上下文协议 (MCP) 服务器。这一增强消除了 开发者 设置 本地服务器 的需求，使得与 安全服务、项目管理系统 和 知识库 等外部工具的集成大幅简化，且维护开销更低。文章强调了使用 Sentry MCP 服务器在 Claude Code 内进行问题跟踪和修复等示例，并详细介绍了使用 OAuth 2.0 通过 HTTP/SSE 进行身份验证的过程。尽管 Reddit 上的一些观点淡化了其重要性，但也有人（如 Robert Matsukoa）强调了它通过消除 基础设施成本 而改变 AI 工具集成经济性的潜力，但也指出，更容易集成所带来的上下文使用量的增加可能导致更高的 AI 使用成本。文章最后指出了可用的 MCP 服务器列表。

💡 主要观点

  1. Claude Code 现在通过 流式 HTTP 支持 远程 MCP 服务器。 这项新功能允许在不设置 本地服务器 的情况下与外部工具集成，从而简化了 开发者 工作流 并降低了 维护开销。
  2. 远程 MCP 集成比 本地设置 更容易、维护开销更低。 开发者 只需添加 供应商 的 URL 即可连接，将 服务器管理、更新、扩展 和 可用性 等职责分担给 供应商。
  3. 此功能可为特定 工作流 实现更深度的 上下文集成。 MCP 在需要从 不同系统 进行关联的场景中表现出色，例如 多仓库调试 或 遗留系统分析，提供了重要的价值。
  4. 使用 MCP 服务器可能因上下文更大而增加成本。 虽然 远程 MCP 降低了 基础设施成本，但更容易集成所带来的从外部源拉取更多上下文的操作可能会增加 AI 使用成本，需要仔细考虑具体的 用例。

💬 文章金句

  • Anthropic 最近在 Claude Code 中引入了对连接 远程 MCP 服务器 的支持，允许 开发者 无需手动设置 本地服务器 即可集成外部工具和资源。
  • 远程 MCP 服务器 提供了一种比 本地服务器 维护开销更低的替代方案：只需将 供应商 的 URL 添加到 Claude Code 中即可，无需手动设置。
  • 远程服务器消除了以前本地 MCP 部署所需的 基础设施成本。
  • MCP 的优势体现在需要深度 上下文集成 的场景中：多仓库调试 会话、需要历史上下文的 遗留系统分析，或同时结合 多个数据源 的 工作流。
