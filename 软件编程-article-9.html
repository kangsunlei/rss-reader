基于 Rust 的 Vite 直接替代品发布，早期采用者报告构建速度提升 10 倍

6/9/2025, 12:00:00 AM

📌 一句话摘要

一个基于 Rust 的 Vite 直接替代品 `rolldown-vite` 显示构建速度最高可提升 16 倍，同时显著减少内存消耗。

📝 详细摘要

尤雨溪宣布了 `rolldown-vite` 的技术预览版，这是一个用 Rust 编写的 Vite 打包器替代品。像 GitLab 和 Excalidraw 这样的早期采用者报告称，构建时间（快 3 到 16 倍）和内存消耗（有人报告内存使用减少到原来的 1/100）都有显著改进。虽然仍在预览阶段，但它的目标是与当前的 Vite 实现初始功能对等，以便在现有代码库上进行测试。一个主要挑战是确保与广泛的 Vite 插件生态系统的兼容性，这需要插件作者进行调整。这一发展是用 Rust 重写 JavaScript 工具链以获得性能提升的日益增长趋势的一部分，与 Biome 和 TypeScript 编译器转向 Rust 等项目一致。未来计划包括一个完整打包模式，并扩展 Rust 在 Vite 内部机制中的作用。

💡 主要观点

  1. `rolldown-vite`，一个基于 Rust 的 Vite 替代品，现已提供技术预览版。 用 Rust 编写的 `rolldown-vite` 旨在替换 Vite 中的核心打包逻辑，以实现显著的性能改进。
  2. 早期测试显示构建速度最高提升 16 倍，并大幅减少内存使用。 像 GitLab 和 Excalidraw 这样的公司报告了显著改进，展示了大幅节省开发者时间与资源的潜力。
  3. 确保插件兼容性是更广泛采用的关键挑战。 虽然一些 Rollup/Vite 插件可能有效，但其中许多需要更新或进行结构性调整，才能充分利用新的 Rust 核心。
  4. 这反映了为提升性能而用 Rust 重写 JavaScript 工具的趋势。 这一举措与其他项目（如 Biome 和 TypeScript 编译器移植到 Rust）一致，旨在克服 JavaScript 执行限制。

💬 文章金句

  • 早期采用者（例如 Excalidraw、GitLab）报告构建速度快 3-16 倍，并显著降低内存使用。
  • GitLab 将构建时间从 2.5 分钟缩短到仅 40 秒，并将内存使用量减少到原来的 1/100。
  • 考虑到大约 100 个项目... 我们谈论的是每年节省 500 小时，将近 21 天。
  • 插件和生态系统兼容性需要持续的工作。
  • 过去常说一切都将用 JS 编写。但现在看来，Rust 已经取代了这个说法。
