Java 近期资讯：OpenJDK JEP、Azul Payara、WildFly、LangChain4j、OpenXava 和 Google ADK

📌 一句话摘要

本文汇总了近期 Java 生态的多项重要更新，涵盖 OpenJDK JEP 进展、Azul Payara 品牌重塑、WildFly 新工具、LangChain4j 及 Google ADK 版本发布等。

📝 详细摘要

这是一篇 Java 技术资讯综述文章，由 InfoQ 翻译自英文原文。内容覆盖了 OpenJDK 多个 JEP 的最新状态，包括将 G1 设为默认 GC、默认启用紧凑对象头、Vector API 第 12 轮孵化以及 PEM 编码特性定稿。此外，还报道了 Azul 收购 Payara 后的品牌更新、Micronaut 和 WildFly 的版本发布、LangChain4j 1.15.0 的新特性（如 Docling 集成和参数默认值）、OpenXava 7.7.2 的改进，以及 Google ADK 1.3.0 的新功能。文章以信息聚合为主，为 Java 开发者提供了快速了解生态动态的窗口。

💡 主要观点

  1. OpenJDK 多个 JEP 进入新阶段，JDK 27 特性趋于稳定。 JEP 523（默认 G1 GC）、JEP 534（默认紧凑对象头）和 JEP 537（Vector API 第 12 轮孵化）均进入 Proposed to Target 状态，标志着 JDK 27 在垃圾回收、内存布局和向量计算方面的关键进展。
  2. Azul 完成对 Payara 的品牌整合，推出 Azul Payara Community。 收购五个月后，Payara Platform Community 正式更名为 Azul Payara Community，并发布 2026 年 5 月版，包含多项缺陷修复和 Jakarta EE 11 支持更新。
  3. LangChain4j 和 Google ADK 等 Java AI 工具持续迭代。 LangChain4j 1.15.0 集成 Docling 文档解析器并新增参数默认值属性；Google ADK 1.3.0 新增 Apigee API 支持和 Skill 加载接口，降低了 Java 开发者构建 AI 应用的门槛。

💬 文章金句
