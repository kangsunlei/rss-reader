微软突发“封杀令”！全面禁止 Cursor 使用 C、C++、C# 扩展，开发者被迫回退版本

4/12/2025, 7:08:12 AM

📌 一句话摘要

微软限制 VS Code 扩展在非官方版本使用，开发者社区担忧其重拾 “拥抱、扩展、消灭” 策略，并积极寻求应对。

📝 详细摘要

文章报道了微软对其 VS Code 的 C/C++ 和 C# 扩展实施的新限制，禁止在非微软的编辑器（如 Cursor）中使用，导致开发者需要回退版本或寻找替代方案。此举源于微软在扩展的**许可证条款**中添加了限制，引发了开发者社区对微软可能采取 “拥抱、扩展、消灭” 策略的担忧，即先兼容开放标准，然后通过专有功能扩展，最终排挤竞争对手。文章还提到 Cursor 作为 VS Code 的竞争产品，其社区发布了即时修复程序，并积极寻求长期解决方案。开发者社区对此反应强烈，有人建议检查扩展的许可证或使用开源替代品，以避免受到类似限制。文章最后指出，微软的这一举动提醒开发者，对工具和平台的控制权意味着对规则的控制权，未来充满了不确定性。

💡 主要观点

  1. 微软限制 VS Code 扩展在非官方版本的使用，引发开发者社区担忧。 微软修改了 C/C++ 和 C# 扩展的许可协议，禁止在非微软的编辑器如 Cursor 中使用，开发者被迫寻找替代方案。
  2. 此举被开发者视为微软可能重拾 “拥抱、扩展、消灭” 策略的信号，威胁开源生态。 开发者担心微软通过控制 VS Code 及其扩展，排挤竞争对手，维护其在软件开发工具生态中的主导地位。
  3. 开发者建议检查扩展许可证或使用开源替代品，以应对微软的限制。 为了避免受到微软许可协议的限制，开发者应关注扩展的许可证条款，或者选择使用 Open VSX 等开源市场上的替代品。
