React 中文周刊 #230 - Mantine 8.0 发布：新增 20+ 组件与图表功能

5/10/2025, 12:33:00 PM

📌 一句话摘要

React 中文周刊 #230 详细介绍了 Mantine 8.0 发布(新增 20+ 组件及图表功能)、React Server Components 指南、Relay v19 兼容 React 19 等多项重要更新

📝 详细摘要

本期 React 中文周刊重点报道了 Mantine 8.0 版本的发布，该版本新增了 20 多个组件(包括 GitHub 风格的 Heatmap、Tree 等)并集成了 Recharts 图表功能。同时提供了写给 Astro 开发者的 React Server Components 指南，帮助开发者理解这一新技术。此外还介绍了 Relay v19 发布并兼容 React 19、react-sounds 音效库、mono-jsx 服务端 JSX 运行时等多个 React 相关工具的更新。周刊还包含了 JavaScript 生态圈的重要消息，如 Redis 8.0 重新开源、Node v24.0.0 发布等，并预告了 React Conf 2025 的举办信息。

💡 主要观点

  1. Mantine 8.0 新增 20+ 组件并集成 Recharts Mantine 8.0 版本通过集成 Recharts 增强了图表功能，新增了 GitHub 风格的 Heatmap、Tree 和 SemiCircleProgress 等组件，为 React 开发者提供了更丰富的 UI 组件选择
  2. Astro 开发者指南帮助理解 React Server Components 文章通过比较 Astro 的'孤岛'架构与 RSC 的相似之处，提供了从 Astro 入手理解 React Server Components 的指南，降低了这一新技术的入门门槛
  3. Relay v19 兼容 React 19 Facebook 的声明式 React/GraphQL 框架 Relay 更新至 v19 版本，保持与最新 React 19 的兼容性，为复杂应用提供更好的数据获取方案
  4. react-sounds 为 React 应用添加音效 react-sounds 库提供了精心设计的音效解决方案，使开发者能够轻松为网页应用添加恰到好处的音效体验
  5. Redis 8.0 重新开源 Redis 从 8.0 版本开始重新采用开源许可，这对依赖 Redis 的 React 全栈开发者是个重要消息

💬 文章金句

  • Mantine 是最受欢迎的 React 组件库之一，这绝非偶然：它功能齐全、现代化，而且界面美观
  • Astro 的'孤岛'架构与 React Server Components 在思维模型上有着惊人的相似之处
  • Relay 很有趣，它来自 Facebook 但不是 React 团队开发的，最初是为 Facebook 应用程序中的 React Native 部分创建的
  • 在网页中添加音效可能听起来像是一场噩梦，但这个项目做得相当出色，提供了精心设计的示例，音效恰到好处
  • 如果你因为 2024 年的许可证争议而避免使用 Redis，那么好消息来了：Redis 从 8.0 版本开始重新开源
