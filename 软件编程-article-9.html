Cloudflare 全新发布：Arroyo 和 Pipelines 流式接入方案

4/10/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 发布 Pipelines 的 open beta 版本，并通过收购 Arroyo 增强其实时数据处理能力，致力于构建全面的数据平台。

📝 详细摘要

Cloudflare 推出了 Pipelines 的 open beta 版本，旨在解决传统数据处理在配置、运维和响应速度上的复杂性和延迟性，可以将大量结构化的实时数据以高吞吐量、低延迟的方式加载到 R2 对象存储服务中，无需管理底层基础设施。同时，Cloudflare 还宣布收购了 Arroyo，这是一个云原生分布式流处理引擎，旨在实现数据的实时转换和处理。结合新发布的 R2 Data Catalog，Cloudflare 正在构建一个数据平台，支持全球范围内的数据接入、大规模存储、计算，以及边缘计算和数据主权。未来，Cloudflare 计划支持更多数据源和目标，并与 R2 Data Catalog 集成。

💡 主要观点

  1. Pipelines 提供高吞吐量和可扩展性，支持流式数据接入。 Pipelines 可以处理高达每秒 10 万条记录的接入量，并利用 Durable Objects 实现水平分片和数据持久化，适用于大规模数据场景。
  2. Arroyo 的集成将为 Pipelines 带来强大的流处理能力 Arroyo 提供基于 SQL 的流处理 API，支持实时数据转换、聚合和分析，简化了流数据管道的构建和管理。
  3. Cloudflare 正通过 Pipelines、Arroyo 和 R2 Data Catalog 构建一个支持边缘计算和数据主权的实时数据平台 结合 Pipelines、Arroyo 和 R2 Data Catalog，Cloudflare 旨在提供全球范围内的数据接入、存储和计算服务，支持边缘计算和数据主权。

💬 文章金句

  • Pipelines allows you to ingest high volumes of structured， real-time data， and load it into our object storage service， R2.
  • 翻译：Pipelines 允许您接入大量结构化的实时数据，并将其加载到我们的对象存储服务 R2 中。
  • We've acquired Arroyo， a cloud-native， distributed stream processing engine， to make that happen.
  • 翻译：我们收购了云原生分布式流处理引擎 Arroyo，以实现这一目标。
  • Cloudflare， uniquely， allows us to push these systems all the way to the edge， enabling a new paradigm of local stream processing that will be key for a future of data sovereignty and AI.
  • 翻译：Cloudflare 独一无二的优势在于，它允许我们将这些系统推送到边缘，从而实现本地流处理的新模式，这将是未来数据主权和 AI 的关键。
