NVIDIA 发布 AI、机器人和自动驾驶领域的开放模型、数据集与工具

1/10/2026, 12:45:00 PM

📌 一句话摘要

NVIDIA 发布了一套涵盖 AI、机器人和自动驾驶领域的全面开放模型、数据集和工具，显著扩展其开源贡献以加速 AI 开发与研究

📝 详细摘要

NVIDIA 宣布大幅扩展其开放 AI 生态系统，发布了一套涵盖语言、智能体系统、机器人、自动驾驶和生物医学研究的开放模型、数据集与开发工具。关键更新包括：为智能体 AI 扩展 Nemotron 模型系列，新增语音识别、检索增强生成（RAG）和安全组件，同时提供开放数据集和训练代码；在机器人与物理 AI 领域，推出用于感知、推理和合成数据生成的 Cosmos 世界基础模型，以及用于人形机器人控制的 Isaac GR00T N1.6；重要亮点是 NVIDIA Alpamayo，这是一个专为基于推理的自动驾驶设计的新开放模型系列，辅以 AlpaSim 开源仿真框架和大规模驾驶数据集；此外，还发布了用于医疗保健和生命科学的新 Clara 模型，专注于蛋白质设计、药物设计、安全性预测和 RNA 结构建模。所有发布资源均通过 GitHub 和 Hugging Face 以开放许可提供，许多还打包为 NIM 微服务以供部署

💡 主要观点

  1. NVIDIA 正在通过跨多个 AI 领域的新模型、数据集和工具扩展其开放生态系统 本次发布涵盖智能体 AI（Nemotron）、机器人（Cosmos、Isaac GR00T）、自动驾驶（Alpamayo、AlpaSim）和医疗保健（Clara），展示了 NVIDIA 通过开源贡献促进 AI 创新的承诺
  2. 发布内容针对实际应用和现实挑战，通过专业化模型家族实现 从低延迟语音识别和多模态文档搜索到人形机器人控制和基于推理的自动驾驶，这些工具旨在解决各行业的具体复杂问题
  3. NVIDIA 通过 GitHub 和 Hugging Face 等成熟平台强调开放访问 在流行平台上以开放许可提供这些资源，降低了开发者和研究人员的入门门槛，促进了更广泛的采用和协作开发
  4. 以 Alpamayo 为代表的自动驾驶工作是多年开发的成果，涉及广泛测试和行业合作 Alpamayo 的开发涉及重要的道路测试、大规模仿真以及与梅赛德斯-奔驰等汽车行业领导者的合作伙伴关系，表明了对关键 AI 应用的成熟且经过充分验证的方法

💬 文章金句

  • NVIDIA 发布了一套涵盖语言、智能体系统、机器人、自动驾驶和生物医学研究的开放模型、数据集和开发工具
  • Nemotron RAG 引入了嵌入和重排序视觉语言模型，旨在用于多模态文档搜索和检索流程
  • NVIDIA 推出了新的 Cosmos 世界基础模型，支持现实环境中的感知、推理和合成数据生成
  • 公告的一个组成部分是 NVIDIA Alpamayo，这是一个用于基于推理的自动驾驶的新开放模型系列
  • 所有模型和数据集均以开放许可发布，可通过 GitHub 和 Hugging Face 访问
