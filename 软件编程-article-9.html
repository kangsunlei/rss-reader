地下论坛售卖黑客 AI 工具，多采用被盗 Key 和开源模型越狱

10/16/2026, 10:00:00 AM

📌 一句话摘要

Bitsight 追踪 16 个地下论坛发现，AI 相关讨论半年增长 45%，黑客工具 MONST3R-AI 盗用 OpenAI、Anthropic、Google 的 API 密钥驱动自动化扫描，开放权重模型因可自行部署而受黑产青睐。

📝 详细摘要

文章基于 Bitsight 威胁情报团队 2026 年 2 月至 8 月对 16 个地下论坛数千条帖子的追踪，梳理了网络犯罪生态向 AI 迁移的趋势。核心发现包括：一款名为 MONST3R-AI 的自主渗透工具以「自主渗透测试平台」名义出售，卖家不托管模型，而是让买家填入窃取的 OpenAI、Anthropic、Google API 密钥，从而绕过模型服务商的滥用检测，并把调用费用转嫁给密钥真实持有者；卖家自称已扫描 199 台主机、发现 1072 个安全问题，但数据无法独立验证。开放权重模型（GLM、DeepSeek）讨论热度上升，因其可下载自部署、无需请求审核、成本更低（CloseRouter 报价 GLM 每百万输入词元 0.053 美元，官方 API 为 1.12 美元），部分论坛还按「服从恶意请求」难易度给模型排名，并出现移除安全对齐的 abliteration 操作。同期 AI 相关讨论增长 45%，勒索软件下降 49%，钓鱼下降 8.5%，WormGPT、FraudGPT 等犯罪聊天机器人讨论下降 8.7%。文章还列举了 FakeGit 攻击（约 7600 个恶意 GitHub 仓库，超 800 个伪装成 AI 技能或 MCP 服务器）、AI 智能体调用 IDA Pro 自动挖掘缓冲区溢出、浏览器自动化智能体入侵企业 Notion 账号等实战案例，并给出密钥排查、MCP 插件核验、本地智能体权限收敛、建立人工登录行为基线等防御建议。

💡 主要观点

  1. 被盗 AI API 密钥正成为黑客自动化攻击的「免费算力」，成本被转嫁给密钥持有者 MONST3R-AI 不托管模型，买家填入窃取的 OpenAI、Anthropic、Google 密钥即可驱动自动化扫描，既绕开模型服务商的安全防护与滥用检测，又把全部调用费用记在被盗密钥账户上。卖家自称扫描 199 台主机、发现 1072 个安全问题，但数据来自其自身控制面板，Bitsight 无法独立验证。
  2. 开放权重模型因可自部署、免审核、低成本而成为黑产首选 GLM、DeepSeek 等模型可直接下载部署到租用服务器，不存在因违规请求被封号的问题；部分中俄文论坛按模型「服从恶意请求」的难易度排名，并出现移除安全对齐的 abliteration 操作。CloseRouter 宣称 GLM 每百万输入词元仅 0.053 美元，而官方 API 同等规模为 1.12 美元。
  3. 地下论坛话题结构发生迁移：AI 升温，勒索软件与钓鱼降温 统计周期内 AI 相关讨论增长 45%，勒索软件下降 49%，钓鱼下降 8.5%，WormGPT、FraudGPT 等犯罪聊天机器人下降 8.7%。勒索软件降温部分源于执法打击，部分源于团伙转向更私密的加密通信渠道。
  4. AI 供应链与智能体权限成为新的攻击面 FakeGit 活动通过约 7600 个恶意 GitHub 仓库传播 SmartLoader，其中超 800 个伪装成 AI 技能或 MCP 服务器（含仿冒的 Docker MCP Gateway），试图混入公开 AI 工具注册表；另有攻击者演示让 AI 智能体调用 IDA Pro 自动寻找缓冲区溢出并编写利用方案，以及用浏览器自动化智能体入侵企业 Notion 账号。
  5. 防御重点应从模型能力转向密钥、插件与行为基线的治理 文章建议：将 AI 密钥泄露与云凭证泄露同等处置并排查公网暴露；逐一核验 MCP 服务器与智能体插件的来源和代码；本地代码智能体不应默认拥有敏感目录与系统命令权限，高风险操作需人工审批；针对 Notion、Slack、GitHub 建立人工登录行为基线，利用无头浏览器智能体在访问频率、操作间隔上的异常特征识别自动化攻击。

💬 文章金句

  • 买家只需将盗取的密钥填入工具，就能利用这些密钥驱动自动化扫描，而产生的全部调用费用最终由密钥的真实持有者承担。
  • 这类模型可以直接下载并部署到租用的服务器上运行，不需要经过模型服务商的请求审核，也不存在因违规请求被封禁账号的问题。
  • 随着类似工具不断出现，被盗 AI API 密钥可能进一步成为黑客驱动自动化扫描和攻击工具的"免费算力"。
  • 通过无头浏览器运行的 AI 智能体，其访问频率、操作间隔和行为模式通常与真人操作存在明显差异，这些异常特征可以作为识别自动化攻击活动的辅助信号。
