JavaScript 中文周刊 #208 - Bun v1.3 全栈 JavaScript 运行时重大更新

📌 一句话摘要

本期 JavaScript 中文周刊汇总了 Bun v1.3、Vite+、Node.js v25 等 JavaScript 生态的最新技术更新、工具发布及精选文章，为开发者提供全面速览。

📝 详细摘要

本期 JavaScript 中文周刊#208 全面汇总了前端与后端 JavaScript 生态的最新技术动态和重要发布。主要内容包括 Bun v1.3 升级为全栈 JavaScript 运行时，集成了开发服务器、热重载及数据库客户端；Evan You 发布基于 Vite 的全新工具链 Vite+ / VitePlus；Node.js v25.0.0 上线并内置 Web Storage 支持与多项性能优化。此外，周刊还精选了提升 Web JavaScript 可信度的 WAICT 项目、SolidJS 关于 Signals 的深度演讲、多篇性能优化、开发工具使用及框架重构等技术文章和视频。同时，推荐了 DOMPurify、python-node、jsonriver 等新工具，并分享了 React Compiler 1.0、Firefox 144、PostgreSQL 18 等重要资讯及多个库的版本发布，内容丰富且时效性强。

💡 主要观点

  1. Bun v1.3 发布，成为集全栈能力于一身的 JavaScript 高性能运行时 新版本集成了全栈开发服务器、热重载、内置数据库客户端和独立可执行文件打包功能，大幅提升了 JavaScript 全栈开发的效率与便利性。
  2. Vite+ / VitePlus 全新工具链发布，旨在提供更强大统一的开发体验 Evan You 推出基于 Vite 的商业化工具链，面向个人、开源项目和小企业免费，旨在解决传统 Vite 在某些场景下的局限性，提供更全面的前端开发解决方案。
  3. Node.js v25.0.0 上线，内置 Web Storage 支持并带来多项性能优化 最新版本引入了 Web Storage 支持、JSON.stringify 性能显著提升、权限模型改进以及 WebAssembly 和 JIT 优化，进一步增强了 Node.js 的功能和执行效率。
  4. WAICT 项目致力于提升 Web 上 JavaScript 代码的可信度与安全性 由 W3C 支持的 WAICT 项目，目标是确保浏览器执行的 JavaScript 代码未被篡改，为 Web 应用提供类似 App Store 的安全保障，增强用户信任。
  5. React Compiler 1.0 正式版发布，实现 React 代码自动 Memo 优化 该编译器能够自动分析 React 代码并智能应用 memoization 优化，显著提升应用性能，同时大大简化了开发者手动进行性能优化的工作量。

💬 文章金句

  • Bun 1.3 刚推出没多久，这绝对是这周 JavaScript 圈里最热的消息！
  • Bun v1.3 升级后，既可以作为 Node.js 的无缝替代品，还具备了一大波新特性，成为名副其实的'全栈运行时'。
  • Node 最新的前沿版本来了！这次内置开启了 Web Storage、JSON.stringify 性能显著提升，权限模型引入了新的 --allow-net 选项，还直接支持 Uint8Array 的 base64/hex 转换，WebAssembly 和 JIT 也都有优化升级。
  • 这篇文章介绍了由 W3C 支持的 WAICT（Web Application Integrity， Consistency， and Transparency）项目，目标是让网页像 App Store 一样安全，保证浏览器执行的代码真的没被篡改。
  • React 团队刚刚发布 React Compiler 1.0 正式版，它能自动分析你的 React 代码自动加上 memo 优化，用起来超省心。
