Plannotator：Agent 生成计划与代码的网页批注工具

9/12/2026, 7:30:02 AM

📌 一句话摘要

Plannotator 提供网页界面让用户划线批注 Agent 生成的计划和代码，支持多种编码 Agent，全部数据本地存储。

📝 详细摘要

Plannotator 是一个网页工具，用于审查和修改 AI 代理生成的计划与代码。用户可以在网页上打开 Agent 生成的计划，进行段落划线、写批注，点击后将意见整体发回给 Agent 进行修改；代码改动则以左右对照形式展示，支持逐行评论并直接给出建议代码，能够拉取 GitHub 或 GitLab 的 PR 进来评审。工具已适配 Claude Code、Codex、Copilot CLI、Gemini CLI、OpenCode 等 9 个编码 Agent，提供自动识别已安装 Agent 的安装脚本并完成配置。Agent 生成的 HTML 页面也能直接渲染并在页面上批注，评论时可随时询问 AI 或让它先进行一轮审查再把评论贴到改动上。所有计划、改动、批注均存储在本地，不收集使用数据。适合希望将审计过程从终端迁移到可视化界面的开发者。

💡 主要观点

  1. 统一可视化审查界面 将 Agent 生成的计划和代码改动以网页形式呈现，支持划线批注和逐行评论，提升人机协作效率。
  2. 本地化隐私与多 Agent 适配 所有数据仅存储本地，不上传；内置脚本自动识别并配置多种主流编码 Agent，降低使用门槛。
