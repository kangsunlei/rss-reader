Application Insights 代码优化：自动识别 .NET 性能瓶颈

9/17/2025, 12:00:00 PM

📌 一句话摘要

微软增强了用于 .NET 的 Application Insights 代码优化，能够自动识别并推荐修复生产应用中的 CPU、内存和线程瓶颈。新功能还集成了 GitHub Copilot。

📝 详细摘要

这篇 InfoQ 文章宣布了 Microsoft 在 Azure Application Insights 中对代码优化功能的重大增强，目标是 .NET 开发人员。该服务由 AI 驱动，利用 .NET Profiler 自动检测性能瓶颈，包括 CPU、内存和线程问题，直接在生产环境中，并提供可操作的代码级建议来解决这些问题。主要新功能包括检测线程阻塞问题，直接从概览页面分配 GitHub Copilot 任务以简化修复，以及对 OpenTelemetry 收集器的预览支持，增强了遥测的灵活性。.NET Profiler 由采样触发，或者当 CPU / 内存使用率超过 80% 的阈值时触发，具有可配置的参数和最小的用户影响。开发人员可以查看跨资源的整合建议，并利用带有 GitHub Copilot 的 Visual Studio / VS Code 扩展来生成修复或创建问题。虽然分析器引入了 5 - 15% 的 CPU / 内存开销，但跟踪数据存储是免费的，为期 15 天。该功能支持各种 Azure 服务，Web 应用性能分析至少需要基础层（Basic Tier）。

💡 主要观点

  1. 增强的代码优化自动识别并提供 .NET 性能瓶颈的代码级修复。 这种基于 AI 的服务主动检测生产应用中的 CPU、内存和线程问题，提供精确的建议以提高应用程序的可靠性和性能，减少手动诊断工作。
  2. 与 GitHub Copilot 的集成简化了已识别性能问题的修复过程。 开发人员可以直接通过 VS / VS Code 扩展分配任务或生成代码修复，从而加速瓶颈的解决并提高开发人员的生产力。
  3. 对 OpenTelemetry 收集器的预览支持在遥测收集方面提供了更大的灵活性和标准化。 这允许开发人员利用广泛采用的开放标准实现可观测性，减少供应商锁定，并简化与其他监控工具和平台的集成。

💬 文章金句

  • 此功能是 Azure Monitor 产品的一部分，现在与 Application Insights 中的 .NET Profiler 结合使用，可自动检测生产应用中的 CPU、内存和线程问题，并提供代码级别的建议来修复它们。
  • 代码优化是一种基于 AI 的服务，运行在 Azure Application Insights 上，它使用 Application Insights Profiler for .NET 收集的遥测数据来分析运行时行为，找到细化到各个方法的性能瓶颈，并提供可操作的建议。
  • 代码优化中的增强功能包括检测阻止线程的问题、从概览页面直接分配 GitHub Copilot 任务以及预览支持 OpenTelemetry 收集器而不是 Application Insights 自有收集器。
  • 在检查代码问题时，他们可以使用 Visual Studio 或 VS Code 扩展（与 GitHub Copilot 集成）来建议甚至生成修复，或者创建分配给 Copilot 代理的 GitHub 问题。
  • 对于许多 Azure 服务来说，启用 .NET Profiler 相对简单。
