Python、R 双雄崛起，MATLAB 正在退场？TIOBE 5 月榜单发布！

5/11/2026, 9:08:00 AM

📌 一句话摘要

TIOBE 2026 年 5 月榜单显示，统计编程语言市场正经历深度整合，Python 与 R 双雄崛起，MATLAB、SAS 等老牌工具集体退场。

📝 详细摘要

文章基于 TIOBE 2026 年 5 月最新榜单，分析了编程语言市场，特别是统计编程语言领域的重大变化。核心趋势是统计语言市场正经历一场深度整合，生态快速向 Python 和 R 两大阵营集中。Python 凭借在 AI、大模型和数据工程领域的统治地位，已彻底主导工业界；R 则凭借在学术科研、生物统计和医学研究中的不可替代性，守住了学术阵地，本月排名回升至第 8 位。与此同时，MATLAB 逼近 Top 20 边缘，SAS 接近跌出 Top 30，SPSS 已跌出 Top 100，Stata 排名降至第 124 位，这些老牌工具正在被边缘化。文章还提及了其他值得关注的变化，如 Java 26 的发布使其重获增长动力并超越 C++，以及系统编程新秀 Zig 首次逼近 Top 30。此外，文章预测概率编程语言 Stan 下月可能首次进入榜单，反映了 AI 与统计学融合的趋势。

💡 主要观点

  1. 统计编程语言市场正经历深度整合，Python 与 R 双雄争霸。 Python 凭借在 AI 和工业界的统治地位，R 凭借在学术科研领域的不可替代性，成为仅存的两大核心生态，MATLAB、SAS、SPSS 等老牌工具集体退场。
  2. Python 主导工业界，R 坚守学术界，形成清晰分工。 Python 在 AI、大模型、数据工程领域成为默认语言，而 R 在流行病学、生物统计、高级统计建模等学术领域仍具优势，两者形成了工业化与学术研究的互补格局。
  3. Java 26 发布重获增长动力，Zig 首次逼近 Top 30。 Java 凭借新版本发布超越 C++，系统编程新秀 Zig 因其兼顾底层性能与易用性的特性，吸引了大量开发者关注。

💬 文章金句

  • 统计编程语言市场正在发生一场深度整合。
  • Python 负责工业化与 AI；R 则主导学术研究与统计分析。
  • 技术优势并不一定能快速转化为生态优势。
