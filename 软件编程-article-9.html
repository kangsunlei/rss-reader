Docker Desktop 4.43 版本发布

7/3/2025, 8:01:43 AM

📌 一句话摘要

Docker Desktop 4.43 推出增强版模型运行器、全新设计的 MCP 工具市场（含安全功能）、MCP 服务器提交支持、智能 AI 代理 Gordon 5.0，以及用于 Kubernetes 转换的 Compose 桥接功能。

📝 详细摘要

Docker Desktop 4.43 带来重大更新，优化了 AI 模型管理和 MCP 工具集成流程。模型运行器新增完善的模型管理功能，扩展 OpenAI API 兼容性，并提供细粒度的运行时控制。全新设计的 MCP 工具市场通过加密签名、软件物料清单(SBOM)和溯源认证强化安全性，同时支持 Docker 官方和社区贡献的镜像。MCP 工具包新增 OAuth 认证支持，并优化了与 VS Code 和 GitHub 的集成体验。Docker 的 AI 代理 Gordon 现支持多线程并行对话，性能提升达 5 倍。新增的 Compose 桥接功能可通过单条命令将本地 Compose 文件转换为 Kubernetes 配置，大幅简化部署流程。

💡 主要观点

  1. 增强版模型运行器：改进管理功能与 OpenAI API 兼容性 新增模型检查和管理命令，优化动态代理行为的 API 支持。
  2. 全新 MCP 工具市场：安全特性与社区支持 通过加密签名、SBOM 和溯源认证，简化 MCP 服务器的发现和使用流程，现支持 Docker 官方和社区贡献的镜像。
  3. MCP 工具包：OAuth 认证与无缝集成 集成 GitHub 安全认证，优化 VS Code 工作流体验。
  4. AI 代理 Gordon 5.0：多线程对话支持 性能提升 5 倍，支持多对话并行处理且保持独立上下文。
  5. Compose 桥接：便捷的 Kubernetes 转换方案 通过单条命令实现 Compose 到 Kubernetes 的配置转换，简化部署并使开发与生产环境保持一致。

💬 文章金句

  • 模型运行器现提供增强的模型管理功能，扩展的 OpenAI API 兼容性，以及精细的运行时行为控制。
  • MCP 工具市场已收录 100 余个经过验证的容器化工具，均配备加密签名、SBOM 和溯源认证。
  • Gordon 的多线程能力与 MCP 工具协同工作，可显著提升开发效率。
  • Compose 桥接提供智能预设和自定义选项，实现 Compose 应用向 Kubernetes 的灵活迁移。
  • Docker Desktop 4.43 为 AI 与云原生应用开发者提供实用更新，包含安全性和生产力方面的增强特性。
