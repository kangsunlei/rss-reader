程序员正在失去软件选择权！RedMonk 联合创始人：Agent 正在成为新的“Kingmakers ”，开发者可能从决策者退成建议者

10/12/2026, 9:50:00 AM

📌 一句话摘要

RedMonk 创始人 Stephen O'Grady 认为，AI Agent 的崛起正让开发者的角色从代码编写执行者转变为系统架构决策者，技术选择权正向 Agent 转移。

📝 详细摘要

本文通过对 RedMonk 创始人 Stephen O'Grady 的访谈，探讨了 AI Agent 如何重塑软件工程范式。过去开源和云服务让开发者绕过采购获得了技术选择权，而现在 Coding Agent 的出现让模型在语言、框架、甚至 UI 细节上开始自主决策。作者指出，开发者的核心竞争力不再是编写代码，而是定义系统约束、设计任务边界并验收 Agent 的结果。未来的开发者可能从“程序员”演变为调度多个 Agent 的“皇帝（皇帝）。

💡 主要观点

  1. 技术选择权的两次转移 第一次是开源和云服务让开发者绕过企业采购直接决定了技术栈；第二次是 AI Agent 开始在执行任务时自主选型框架和依赖。
  2. 开发者的角色定位重塑 开发者正在从“亲手施工的人”变为“决定系统如何构建的人”，其工作重心转向设计约束、比较方案和验收 Agent 的交付。
  3. Agent 带来的安全与维护挑战 Agent 可能会引入团队不愿维护的技术或违反版权的资源，因此技术选型规则必须通过依赖白名单、静态检查和 CI 门禁来强制执行。
  4. 软件产品的未来分类趋势 未来软件将分为三类：主要供人类使用的、主要供 Agent 调用的以及两者兼顾的，后者的增长速度将最快。

💬 文章金句

  • 开发者正在从亲手施工的人，变成决定系统怎么建的人。
  • 新的'造王者'可能不再是开发者，而是 Agent。
  • 真正的分界线是开发者还在设计约束、比较方案和验收结果，还是只剩下一个'同意修改'的按钮。
  • 乐观地看，开发者不只是'王'而会成为调度一组 Agent 的'皇帝'。
