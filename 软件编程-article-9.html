📝 详细摘要

为了防止恶意用户通过修改对话上下文来诱导模型泄露加密的推理记录，Anthropic 更新了 API 策略。现在，如果开发者尝试在新的请求中引用旧的推理记录，但同时改变了之前的聊天记录、系统提示或工具配置，系统将检测到不一致并报错。这一举措旨在保护模型的知识产权，并确保推理记录只能在原始的对话环境中被合法访问。

💡 主要观点

  1. 新 API 规则旨在防止推理记录的非法泄露。 通过强制要求上下文一致性，Anthropic 阻止了攻击者利用改写的对话来骗取模型输出加密的推理数据，从而保护了模型的知识产权。
  2. 开发者需要注意上下文管理，以免触发 API 限制。 使用自动摘要或修改历史消息的应用程序可能会意外违反这一规则，导致推理记录丢失或请求失败。开发者应确保在利用旧推理时，对话环境保持不变。
