为应用商店集成提供商新增检查工具 API 支持 - Vercel

4/30/2025, 1:00:00 PM

📌 一句话摘要

Vercel 应用商店集成提供商通过使用检查工具 API 在部署后进行自定义测试，并在仪表板中展示结果，以增强其应用功能。

📝 详细摘要

Vercel 应用商店的集成提供商现在可以利用检查工具 API 在部署后定义和运行自定义测试和断言。测试结果会直接显示在 Vercel 仪表板中。这有助于开发者更快地发现实际问题，例如 API 可用性、运行时错误、响应时间阈值和网页指标。构建集成时，应提供最小或零配置的解决方案。检查工具 API 提升了 Vercel 应用商店集成的质量和用户体验。

💡 主要观点

  1. 检查工具 API 为 Vercel 应用商店集成提供商提供更深层次的功能 通过自定义测试和断言，集成提供商可以在部署后直接在 Vercel 仪表板中显示可操作的结果，帮助开发者及早发现问题。
  2. 提供零配置解决方案简化开发者体验 为了简化开发者体验，集成应提供易于使用的检查，并直接在 Vercel 仪表板中显示清晰、可操作的结果。
