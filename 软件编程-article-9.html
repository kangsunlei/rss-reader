Telegram Desktop 曝 HTML 导出漏洞，隐藏 JS 可窃取聊天消息

9/15/2026, 10:00:00 AM

📌 一句话摘要

Telegram Desktop 的 HTML 导出功能存在转义缺陷，攻击者可通过隐藏 JavaScript 注入窃取聊天内容，已在 4.15.1–6.9.3 版本中被发现并在 7.0.1 版本修复。

📝 详细摘要

Telegram Desktop 的 HTML 导出功能在 4.15.1 至 6.9.3 版本中存在转义缺陷，攻击者可在机器人发送的消息中植入隐藏 JavaScript。用户将聊天导出为 HTML 并在浏览器中打开时，脚本会自动执行，读取聊天中的发送者、时间戳、聊天名称、成员数量等信息，并将数据上传至攻击者服务器。脚本还能篡改页面显示，伪造验证表单。该漏洞可通过转发传播，机器人不必加入目标聊天，转发后仍携带恶意脚本，导致群成员导出时仍受影响。补丁已在 6.9.4 beta 与 7.0.1 版本发布，修复缺失的转义逻辑，但旧版本生成的导出文件仍可能携带恶意脚本。Telegram 官方未给出 CVE 编号，也未在补丁说明中提及该漏洞，用户需自行更新至 7.0.1+ 并重导出旧文件或在禁用 JavaScript 的浏览器中打开。

💡 主要观点

  1. 通过未转义的内联键盘按钮文本，攻击者可在 Telegram Desktop HTML 导出文件中注入隐藏 JavaScript，窃取聊天内容。 机器人可植入 script 标签，用户导出 HTML 后脚本自动执行，读取聊天信息并上传。
  2. 该漏洞可通过转发传播，机器人消息不需加入目标聊天，转发后仍携带恶意脚本，导致群成员导出时仍受影响。 转发保留按钮，攻击范围扩大。
  3. 受影响版本 4.15.1 至 6.9.3，补丁已在 6.9.4 beta 与 7.0.1 版本发布，修复缺失的转义逻辑。 代码行自 2024 年 3 月起存在，补丁提交 6/30，发布 7/3、7/14。
  4. 目前无 CVE 编号，Telegram 官方未发布正式补丁说明，用户需自行更新并重导出旧文件或禁用 JS。 官方未给出 CVE，建议更新至 7.0.1+，重导出旧文件或在禁用 JS 的浏览器打开。

💬 文章金句

  • Telegram Desktop 导出功能存在转义缺陷，机器人发送的消息可在聊天内容中植入隐藏 JavaScript，若用户将聊天导出为 HTML 文件，就会携带该恶意脚本。
  • 脚本运行无需任何额外 Click，它可以读取文件内的所有消息内容，涵盖发送者名称、时间戳、聊天名称、聊天类型、成员数量以及本地文件路径等信息，并将全部数据上传到攻击者控制的服务器。
  • 该脚本还可以篡改页面显示内容。研究人员在演示中，用脚本将整个导出页面替换为伪造的 Telegram“验证”表单。
  • 研究人员发现，发起攻击的机器人不需要加入目标聊天。如果机器人发送的消息仅附带网页链接按钮，消息被转发时会完整保留这些按钮，因此任何群成员将该机器人消息转发到群组时，都会同步携带恶意脚本。
  • Telegram 在 7 月就推送了修复补丁，但客户端更新不会修改此前用旧版本生成的导出文件，因此旧的 HTML 导出文件仍可能携带恶意脚本。
