2025 年 Linux 内核十大技术创新｜年终盘点

2/16/2026, 3:30:00 AM

📌 一句话摘要

资深内核专家宋宝华深度解析 2025 年 Linux 内核在内存管理、调度优化、网络零拷贝及设备内存管理等领域的十大核心技术突破。

📝 详细摘要

本文由知名 Linux 内核开发者宋宝华撰写，系统性地回顾了 2025 年 Linux 内核最具代表性的十项技术创新。文章深入探讨了通过 Sheaves 和 Barns 机制优化 slab 分配性能、sched_ext 对 cgroup 子调度器的层次化支持、以及解决优先级翻转的代理执行（Proxy Execution）机制。此外，还详细分析了旨在提升 swap 性能的 swap table 结构、TCP 与 io_uring 的零拷贝技术演进、基于 rseq 的时间片扩展、multi-kernel 并行运行方案以及用于 GPU 等加速器内存管理的 dmem cgroup。这些创新集中体现了内核在高性能计算、多租户隔离和硬件直通领域的最新演进方向。

💡 主要观点

  1. Slab 引入 Sheaves 和 Barns 机制以优化 per-CPU 缓存。 借鉴 buddy 系统的 pcp 机制，通过本地 Sheaves 减少锁竞争，Barns 作为全局池平衡内存，显著提升了 slab 对象分配与释放的并发性能。
  2. sched_ext 增加 cgroup 子调度器支持，实现层次化调度。 允许在 cgroup 层级绑定不同的 BPF 调度器，使系统能根据数据库、虚拟机或游戏等不同业务负载定制化调度策略，满足多租户混部需求。
  3. 代理执行（Proxy Execution）机制有效缓解优先级翻转问题。 通过分离调度与执行上下文，允许高优先级任务将时间片“捐赠”给持有锁的低优先级任务，从而加速锁释放，改善系统响应和用户体验。
  4. Swap Table 替代 Xarray 显著提升匿名页交换性能。 针对 swap 空间固定且有限的特点，采用类似数组的简单结构替代复杂的树形 xarray，将查询复杂度降至 O(1) 并增强了 CPU 缓存局部性。
  5. 零拷贝技术在 TCP 和 io_uring 领域取得重大硬件直通进展。 支持设备内存（DMABUF）直接通过网络收发，减少了 host buffer 拷贝开销，特别适用于分布式 AI 训练和高性能远程存储场景。

💬 文章金句

  • 代理执行的逻辑是，在调度层面把调度上下文和执行上下文分开。
  • swap table 的检索过程是相对于 xarray 而言是更快的，相对于 xarray 原先的 O(logN)，现在可认为是 O(1)。
  • io_uring 提供了一种‘混合旁路’机制：在保持与 Linux 内核体系紧密集成的同时，实现了显著的性能提升。
  • multi-kernel 与容器、hypervisor 都有本质不同，它在同一台机器上并行运行多个 Linux kernel，每个 kernel 独占一部分硬件。
  • 当内核看到了用户态设置了 rseq::slice_ctrl::request =1，它可能选择不立即把线程换下 CPU，而是批准一次时间片扩展。
