让 AI 真正懂数据：猫超 Matra 项目中的 AI 知识库建设之路

12/16/2025, 12:30:00 AM

📌 一句话摘要

本文详细介绍了猫超（天猫超市）Matra 项目在 AI 知识库建设上的实践与经验，旨在通过构建结构化的知识体系，赋能 Data Agent 实现智能取数与分析，解决数据研发效率低下和业务场景需求痛点。

📝 详细摘要

文章深入探讨了猫超 Matra 项目如何构建 AI 知识库，以应对大规模数据资产带来的管理挑战和业务一线“人找数”的痛点。从初期数据治理问题出发，引出 Data Agent 作为智能化解决方案，强调高可靠知识库的核心作用。设计上，文章阐述了不重构数据模型、知识库可拓展性和质量优先的维护策略，并详细构建了指标、实体、属性、表、字段等五类知识。在实践中，经历了从钉钉文档到产品化平台的知识构建过程，解决了传统维护方式的有效性、保鲜性和高成本问题。技术上，引入 GraphRAG 技术构建知识图谱提升召回准确率，并基于 ReAct 和 Plan&Execute 框架设计 Agent，实现了从自然语言到 SQL 的智能转换。通过资产查询、智能问数和开发提效等应用案例，展示了 Matra 项目的显著成效和能力边界，并展望了未来在准确性提升、知识持续保鲜和能力边界拓展上的规划。

💡 主要观点

  1. 大规模数据资产治理挑战推动 AI 知识库建设需求。 猫超数据资产规模庞大但存在规范不一、冷资产多、逻辑口径散落等问题，导致数据研发效率低下，急需通过 AI 知识库进行业务知识的统一管理和赋能。
  2. AI 知识库通过结构化知识体系赋能 Data Agent 实现智能取数与分析。 构建包含指标、实体、属性、表、字段的知识库，结合 LLM 和 Data Agent，旨在让 AI 理解业务问题，自动生成并执行 SQL，实现从“人找数”到“AI 取数、分析”的转变。
  3. 知识库维护从静态文档向半自动化产品化平台演进，显著提升效率和准确性。 通过产品化平台，实现知识的自动解析、关联和校验，解决了手动维护知识库的有效性差、保鲜性低和维护成本高等痛点，保证了知识库的长期可用性。
  4. GraphRAG 结合 Agent 框架有效提升 NL2SQL 的准确性和复杂任务处理能力。 引入知识图谱精确刻画数据关系、提升召回准确性，并结合 ReAct 和 Plan&Execute 框架，使 Agent 能够进行多步推理、任务拆解和异常处理，增强了 SQL 生成和复杂任务执行的稳定性。

💬 文章金句

  • 没有高质量的知识库，AI 难以准确理解语义、正确生成逻辑、稳定交付结果。
  • 构建一套面向 AI 的、可理解、可检索、可推理的 AI-知识库体系，已成为推动数据研发提效、赋能智能取数的核基础设施。
  • 平台秉承着在保障知识准确的情况下，实现知识间尽量独立但强关联，且极大减少了研发人工操作，仅需要确认，实现了知识库的半自动化，有效解决了手工维护知识库中遇到的三种问题。
  • 我们采用 GraphRAG 技术，通过构建结构化的知识图谱，全面表达和推理数据表与字段之间的关联关系，从而显著提高召回结果的准确性。
