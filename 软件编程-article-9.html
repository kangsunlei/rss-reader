Gödel Rescheduler：适用于云原生系统的全局最优重调度框架

📌 一句话摘要

字节跳动开源的 Gödel Rescheduler 是一个全局最优重调度框架，通过图算法优化云原生系统资源分配和任务摆放。

📝 详细摘要

文章详细介绍了字节跳动研发的云原生全局最优重调度框架 Gödel Rescheduler。针对传统重调度触发单一、稳定性差、不推荐节点等核心挑战，Gödel Rescheduler 提出了全新的解决方案，由 Policy Manager 和 Movement Manager 两大核心组件构成。Policy Manager 负责策略配置、条件检测和算法执行，支持多种灵活的触发方式，并通过插件机制接入 Detector 和 Algorithm Provider，实现策略冲突和稳定性校验。Movement Manager 则负责决策执行和排序，利用有向图强连通分量分解对任务迁移进行排序和分批处理，确保不违反 PDB 限制，并将结果同步给 Gödel Scheduler。文章还分享了 Gödel Rescheduler 在字节跳动内部合并部署、负载均衡、碎片整理和拓扑域容灾等四大场景的应用实践及显著效果。最后展望了未来的优化方向，并宣布项目已开源。

💡 主要观点

  1. 传统重调度方案存在灵活性差、稳定性难保、不推荐节点等核心问题 周期性触发单一，多策略易冲突，且仅杀死实例而非智能重排，导致集群效率与稳定性受损。
  2. Gödel Rescheduler 通过 Policy Manager 和 Movement Manager 实现全局最优重调度 Policy Manager 负责策略控制和算法，Movement Manager 负责决策执行和排序，两者协同优化任务摆放。
  3. Movement Manager 采用图算法对迁移进行排序和分批处理 基于有向图强连通分量分解，确保任务迁移遵循 PDB 等约束，优化并发执行效率。
  4. 项目在字节跳动内部四大核心场景取得显著优化效果 在合并部署、负载均衡、碎片整理、拓扑域容灾等方面，有效提升了通信效率、资源利用率和系统可靠性。
