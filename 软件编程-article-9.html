Grafana 安全发布：CVE-2025-3260、CVE-2025-2703、CVE-2025-3454 的中高危安全漏洞修复

6/13/2025, 4:45:19 AM

📌 一句话摘要

Grafana 发布安全更新，修复了多个高危和中危安全漏洞，包括权限绕过和跨站脚本（XSS）攻击。

📝 详细摘要

Grafana 发布了针对多个版本的安全补丁，修复了三个主要安全漏洞。其中包括一个高危漏洞 CVE-2025-3260，该漏洞允许 Viewer 和 Editor 角色绕过仪表盘权限，查看或编辑所有仪表盘。中危漏洞 CVE-2025-2703 是 XY 图表插件中的 DOM 型跨站脚本（DOM XSS）漏洞，允许攻击者通过编辑图表面板执行任意 JavaScript 代码。另一个中危漏洞 CVE-2025-3454 存在于数据源代理应用程序编程接口（API）中，允许通过在 URL 中添加额外斜杠绕过授权检查，影响 Prometheus 和 Alertmanager 等数据源。Grafana 建议用户升级到受影响的安全版本（11.6.0， 11.5.3， 11.4.3， 11.3.5， 11.2.8 和 10.4.17），并提供了临时的缓解措施。

💡 主要观点

  1. Grafana 11.6.x 存在权限绕过漏洞，允许未授权用户访问和修改仪表盘。 CVE-2025-3260 允许 Viewer 查看所有仪表盘，Editor 编辑和删除所有仪表盘，该漏洞同样影响开启匿名认证的配置。
  2. XY 图表插件存在 DOM 型跨站脚本（DOM XSS）漏洞，攻击者可执行任意 JavaScript 代码。 CVE-2025-2703 允许具有 Editor 权限的用户通过编辑 XY 图表面板注入 XSS payload，执行恶意脚本。
  3. 数据源代理应用程序编程接口（API）存在授权绕过漏洞，攻击者可未经授权访问数据。 CVE-2025-3454 允许用户通过在 URL 中添加斜杠绕过授权检查，影响 Prometheus 和 Alertmanager 等数据源。

💬 文章金句

  • Grafana 11.6.x 在新功能开发过程中引入了一个安全漏洞，该漏洞允许 Viewer 和 Editor 绕过仪表盘的特定权限。
  • 外部安全研究人员报告称，Grafana 内置 XY 图表插件存在 DOM 型跨站脚本（DOM XSS）漏洞。
  • 该漏洞在审查外部贡献者的 pull request 时被发现，它影响 Grafana 的数据源代理应用程序编程接口（API），允许通过在 URL 路径中添加额外的斜杠绕过授权检查。
