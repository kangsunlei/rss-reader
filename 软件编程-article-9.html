为了保住 Windows 的霸权，微软花 2000 万买下一个字母

7/12/2026, 12:00:00 AM

📌 一句话摘要

本文澄清了微软为域名拼写错误支付 2000 万美元的网络谣言，并详细讲述了微软为保住 Windows 商标，真的花费 2000 万美元买下 Linux 变体系统 Lindows 名称的真实商业与法律故事。

📝 详细摘要

文章首先辟谣了流传甚广的「微软因 Hotmail 域名拼写错误多付 2000 万美元」的故事，指出其缺乏事实依据。随后引出真正的历史事件：2001 年，一家公司推出了旨在兼容 Windows 应用的 Linux 发行版 Lindows，并成功将预装该系统的电脑摆上沃尔玛货架。微软以商标侵权为由提起诉讼，但 Lindows 团队以「Windows（窗口）」是 GUI 通用术语而非微软专属商标为由成功抗辩，法官驳回了微软的禁令。为避免在后续诉讼中败诉并导致 Windows 商标沦为通用词，微软最终在 2004 年以 2000 万美元买下了 Lindows 商标及域名，并将其永久雪藏。Lindows 公司则更名为 Linspire 继续运营。文章以轻松的商业史叙事，揭示了科技巨头为维护品牌霸权不惜重金的经典案例。

💡 主要观点

  1. 微软因 Hotmail 域名拼写错误多付 2000 万美元是网络谣言。 作者指出该故事缺乏事实依据，实际交易为全股票对价，且大公司法务不可能犯如此低级的错误。
  2. Lindows 是一个旨在通过 Wine 兼容 Windows 应用的 Linux 发行版。 其目标是让用户既能使用 Linux，又能运行熟悉的 Windows 软件，但因技术限制，兼容性远不如预期。
  3. Lindows 在商标诉讼中以「Windows 是通用术语」成功反击微软。 法官认同了 GUI 的「窗口」概念早于微软产品，驳回了微软的禁令，使微软面临失去 Windows 商标独占权的空前危机。
  4. 微软为规避商标沦为通用词的风险，以 2000 万美元买下 Lindows 商标并雪藏。 面对败诉可能，微软选择用重金快速了结官司，买下对手品牌后彻底弃用，以维护 Windows 的品牌霸权。
