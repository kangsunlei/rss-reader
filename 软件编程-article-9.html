DeepMind 提出 CaMeL：防御 LLM 提示注入新方案

4/26/2025, 12:00:00 AM

📌 一句话摘要

DeepMind 的 CaMeL 采用传统安全原则防御 LLM 提示注入，并在 AgentDojo 测试中表现出色。

📝 详细摘要

文章介绍了 DeepMind 提出的 CaMeL，一种用于防御 LLM 提示注入攻击的机制。CaMeL 通过分析查询中的控制和数据流来阻止恶意输入，借鉴了传统安全原则。它使用自定义 Python 解释器跟踪数据来源，并基于 Dual LLM 架构，通过特权 LLM 生成 Python 程序的受限子集来管理数据流，确保操作符合权限限制。该方案在 AgentDojo 基准测试中表现出较好的防御效果，但依赖用户定义安全策略，并存在用户疲劳的风险。Simon Willison 认为该方法不依赖更多 AI 来解决 AI 问题是其亮点。

💡 主要观点

  1. CaMeL 采用传统软件安全原则防御提示注入 CaMeL 不依赖 AI 检测，而是借鉴控制流完整性、访问控制等传统方法，提高了防御的可解释性和可靠性。
  2. Dual LLM 架构是 CaMeL 的基础 通过隔离不受信任的数据和特权操作，降低了恶意输入直接影响核心系统的风险，是防御提示注入的关键。
  3. CaMeL 依赖用户定义安全策略，但也提供了灵活的安全配置选项 依赖用户定义安全策略，增加了配置复杂性，同时用户疲劳可能导致安全策略失效，需要进一步优化，但也提供了灵活的安全配置选项。

💬 文章金句

  • CaMeL associates， to every value， some metadata (commonly called capabilities in the software security literature) to restrict data and control flows， giving the possibility to express what can and cannot be done with each individual value by using fine-grained security policies.
  • AI techniques use probabilities: you can train a model on a collection of previous prompt injection examples and get to a 99% score in detecting new ones... and that's useless， because in application security 99% is a failing grade.
