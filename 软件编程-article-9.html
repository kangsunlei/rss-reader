Cursor 入门：MCP 开发调用和项目实战

6/5/2025, 12:30:00 AM

📌 一句话摘要

深度解析 Cursor AI 编码工具，结合 MCP 协议进行实战开发，并分享实践经验与技巧。

📝 详细摘要

文章详细介绍了新兴 AI 编码工具 Cursor 及其核心功能 Docs、Rules 和 Agent Chat，并引入模型上下文协议（MCP）的概念、架构和工作流程。通过一个基于 TypeScript 开发 MCP 天气服务的实战案例，展示了如何利用 Cursor 辅助开发，包括环境初始化、代码生成、依赖管理和构建。接着，文章分享了构建一个更复杂黄金价格预测项目的经验，指出 AI 辅助开发在 API 调试和前后端联调方面的局限性，强调开发者基础的重要性。最后，总结了使用 Cursor 的优缺点，并提供了一系列实用的使用技巧，旨在帮助技术人员更高效地利用 AI 工具提升开发效率。

💡 主要观点

  1. MCP 提供 AI 应用连接数据源和工具的标准化协议 Model Context Protocol（MCP）定义了一种开放标准，使 AI 模型能安全访问和操作本地及远程数据，是 AI 应用连接外部能力的接口。
  2. Cursor 通过 Docs、Rules、Agent Chat 等功能增强开发体验 Cursor 集成文档索引（Docs）、自定义规则（Rules）和强大的 Agent Chat，可以直接阅读项目、浏览网页、运行命令，显著提升 AI 辅助编码效率。
  3. 结合 Cursor 与 MCP 可实现 AI 驱动的工具调用开发 文章通过构建天气 MCP Server 的例子，演示了如何利用 Cursor 快速搭建和测试符合 MCP 标准的工具服务，供其他 AI Host 调用。
  4. AI 编码工具仍需开发者具备扎实基础和调试能力 尽管 AI 工具能提高效率，但在 API 调试、前后端联调和复杂逻辑 bug 定位上仍需人工干预，开发者基础至关重要。
  5. 高效利用 Cursor 需掌握技巧，如充分描述需求、利用 Docs/Rules 和版本控制 通过清晰定义产品功能、预先规划技术方案、活用上下文工具和 Git，可以最大化 Cursor 的价值，避免返工和提升协作效率。

💬 文章金句

  • 之前对 AI Coding 的认知还停留在 tab 补全、自动生成单元测试上，没想到现在已经发展到直接能开发项目了，某种意义上做到了"有嘴就行"。
  • MCP provides a standardized way to connect AI models to different data sources and tools。
  • 最后看下 MCP 的基本工作流程：工具描述与上下文注入 -> 选择工具 -> MCP Client 发起工具调用 -> MCP Server 执行工具 -> 结果返回与模型整合。
  • 这两天试玩了 Cusor，直呼"真香"。
  • 除了 MCP、Docs、Rules 这些工具，cursor 相对于常规 IDE 的 Chat 面板，可以直接阅读整个项目文件、浏览网页、读取图片、运行命令，这几个功能十分好用。
