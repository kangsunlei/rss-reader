编程常用的 MCP Server，用自然语言写代码

6/3/2025, 12:30:00 AM

📌 一句话摘要

文章详细介绍并实践了多种 MCP Server，展示了如何利用自然语言驱动编程开发任务。

📝 详细摘要

文章深入探讨了 Model Context Protocol (MCP) 在编程开发领域的应用。作者首先概述了 MCP 的热度及潜力，认为其能实现自然语言控制开发环境和工具。随后，文章详细介绍了如何在**Cursor、Trae**等支持 MCP 的编辑器中配置和使用不同的 MCP Server，包括 filesystem（文件系统操作）、fetch（网页内容获取）、github（GitHub 信息查询）、git（Git 命令执行）、postgres（数据库查询）、puppeteer（浏览器自动化）以及 magic（智能 UI 生成）和 browser-tools（浏览器调试）。通过具体的配置步骤和测试截图，作者展示了利用 LLM+MCP 实现自然语言代码生成、文件操作、版本控制、数据库交互、网页自动化调试等功能的可行性。文章指出 MCP 尚处于早期阶段，但已具备实用性，并展望了其未来的发展趋势。

💡 主要观点

  1. MCP 协议使 LLM 能通过 Server 与外部工具交互 Model Context Protocol 允许大语言模型连接并调用各种外部服务和工具（如文件系统、Git 仓库、数据库等），从而扩展 AI 的能力边界，实现更多复杂的实际操作，不再局限于文本生成。
  2. 多种 MCP Server 已支持常见的开发任务 针对文件系统（filesystem）、Git（github， git）、数据库（postgres）、网页操作（fetch， puppeteer， browser-tools）等不同编程场景，已有成熟的 MCP Server 可用，开发者可以配置使用，通过自然语言高效执行传统上需要代码或命令行的操作，例如文件读写、代码提交、数据查询、网页自动化等。
  3. 集成开发环境正在拥抱 MCP 实现自然语言编程 Cursor、Trae 等前沿编辑器和 IDE 已开始集成 MCP 功能，为开发者提供了在熟悉环境中通过与 AI 对话完成开发任务的能力，极大地改变了传统的编程交互模式，是自然语言编程落地的关键一步。
