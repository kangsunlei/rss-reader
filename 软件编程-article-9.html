介绍 AI Runtime：Databricks 上用于模型训练与微调的可扩展、无服务器 NVIDIA GPU

3/19/2026, 6:00:03 PM

📌 一句话摘要

Databricks 推出“AI Runtime”，这是一种用于模型训练和微调的无服务器、按需 GPU 基础设施，旨在通过将计算与现有的数据治理和可观测性工具集成，来简化 MLOps 生命周期。

📝 详细摘要

本文宣布了 Databricks AI Runtime (AIR) 的公开预览版，这是一种旨在降低深度学习 GPU 基础设施管理复杂性的平台解决方案。通过提供对 NVIDIA A10 和 H100 GPU 的无服务器、按需访问，AIR 允许开发人员跳过手动集群配置和设置。该运行时深度集成于 Databricks 生态系统中，利用 Lakeflow 进行编排，MLflow 进行可观测性管理，以及 Unity Catalog 进行治理。它还包括预配置的环境（带有优化的库，如 PyTorch、CUDA）以及像 Genie Code 这样的智能体辅助调试工具，旨在加速从交互式 Notebook 开发到生产级分布式训练的过渡。

💡 主要观点

  1. 解决深度学习中的基础设施瓶颈。 文章指出，GPU 基础设施的采购、配置和调试是主要的阻碍因素，分散了研究人员对核心建模工作的注意力。
  2. 无服务器、按需 GPU 配置。 AIR 允许用户直接将 A10 和 H100 GPU 挂载到 Notebook 上，而无需管理集群，从而实现按需付费并消除闲置时间成本。
  3. 用于端到端 MLOps 的生态系统集成。 通过与 Lakeflow、MLflow 和 Unity Catalog 集成，该运行时确保 GPU 工作负载能够受益于现有的数据流水线、治理和实验跟踪。
  4. 优化的环境管理。 该运行时预装了 PyTorch 和 CUDA 等关键依赖项，并支持分布式训练框架，减少了环境设置和依赖地狱（dependency hell）所花费的时间。

💬 文章金句

  • 深度学习研究人员更倾向于专注于建模，而不是排查基础设施故障。
  • 只需点击 2-3 次即可配置您的 Notebook，并快速挂载到无服务器 A10 和 H100 GPU 上开始训练——无需集群。
  • AI Runtime 针对整个深度学习生命周期进行了优化，旨在为您节省时间。
  • 通过我们的 Lakeflow 集成，客户可以将模型训练和微调与上游数据流水线及下游生产系统保持紧密同步。
