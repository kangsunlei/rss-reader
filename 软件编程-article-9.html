用于在 Cloudflare Workers 上构建安全混合云应用的全球虚拟私有云

4/11/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 推出 Workers VPC，旨在简化混合云应用的构建并提供安全的混合云连接。

📝 详细摘要

Cloudflare 发布了 Workers VPC 的预览版，旨在克服传统 VPC 在混合云应用开发中的局限性。Workers VPC 允许将 Cloudflare 上的应用资源分组到隔离的环境中，并使用 Workers VPC Private Links 私有连接连接到公共或私有云中的传统 VPC，从而简化了开发人员构建混合云应用的过程。这使得 Cloudflare 资源和私有网络中的资源可以互相访问，如同位于同一 VPC 中。Workers VPC 利用 Cloudflare 的网络和路由功能来降低出站费用并优化应用性能。该功能计划于 2025 年晚些时候发布。在此处表达兴趣并注册（英文）[https://www.cloudflare.com/workers-virtual-private-cloud-signup]。

💡 主要观点

  1. Workers VPC 通过创新的隔离环境增强安全性，确保应用间的流量安全。 Workers VPC 允许将 Cloudflare 资源分组到隔离的环境中，确保只有 VPC 内的资源才能相互访问，从而保护应用到应用之间的流量。
  2. Workers VPC Private Links 私有连接简化了混合云连接。 通过 Workers VPC Private Links 私有连接，Cloudflare 资源可以访问外部云中的私有资源，如同位于同一 VPC 中，而无需遍历公共互联网。
  3. Workers VPC 降低了出站费用并优化了性能。 Workers VPC 利用 Cloudflare 的网络和路由功能，支持 Cloudflare 网络互联，以降低带宽成本并通过智能放置优化应用性能。

💬 文章金句

  • 虚拟私有云旨在保障您的安心和安全，但其巧妙的设计也为在 Workers 上构建应用带来了极高的挑战。
  • 我们希望为您提供一个非常简单的解决方案，以解锁对外部云资源的访问，并以一种随着您使用 Workers 实现更多工作负载的现代化而扩展的方式。
  • Workers VPC 解锁了大量当前锁定在外部云中的工作负载，而无需您将这些私有资源暴露给公共互联网即可在 Workers 上构建。
