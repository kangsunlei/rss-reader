Anthropic 在 Code With Claude 上发布托管式智能体、主动式工作流与能力曲线

6/2/2026, 5:45:00 AM

📌 一句话摘要

Anthropic 在 Code with Claude 2026 大会上发布了托管式智能体、主动式工作流等新能力，并展示了 Claude Code 更新、GitHub 等合作伙伴的实践案例，以及模型能力曲线的最新进展。

📝 详细摘要

本文编译自 InfoQ，报道了 Anthropic 于 2026 年 5 月 6 日在旧金山举办的 Code with Claude 2026 大会。大会核心议题包括 Claude Code 的更新（远程控制、桌面 GUI、Auto 模式、worktrees、routines）、Claude Managed Agents 的发布（聚焦沙箱代码执行、检查点、凭据作用域控制等基础设施原语），以及模型能力跃迁对产品架构的影响。GitHub 分享了其缓存命中率管理实践（目标 94% 以上）和 advisor 策略（小模型调用大模型）。Vercel 指出 Opus token 占其 AI Gateway 使用量的 20% 多，但支出占比超 70%。Anthropic CEO Dario Amodei 透露公司 2026 年 Q1 收入和使用量增长达 80 倍，并重申了「一个人创造十亿美元价值」的预测。大会还展示了 Bun 的 Robobun 自维护机器人、Datadog 的机器工具概念，以及 Cognition、Gamma、Harvey 等 AI 原生公司因模型能力拐点而重写产品架构的案例。

💡 主要观点

  1. Claude Code 新增远程控制、桌面 GUI 和 Auto 模式等能力。 远程控制支持跨设备会话延续；桌面 GUI 引入分栏视图和自动目录；Auto 模式通过分类器自主决策权限，降低开发者手动干预成本。
  2. GitHub 分享了缓存命中率管理实践和 advisor 策略。 GitHub 将缓存命中率目标设为 94% 以上，并采用 advisor 策略，由小模型（Haiku）在困难时调用大模型（Opus），以低成本获得接近 Opus 级别的智能。
  3. Anthropic 发布 Managed Agents，聚焦基础设施原语。 Managed Agents 强调当前生产级智能体的瓶颈已从智能转向基础设施，重点提供沙箱代码执行、检查点和凭据作用域控制等底层能力。
  4. 模型能力跃迁迫使 AI 原生公司重写产品架构。 Cognition、Gamma、Harvey 等公司均因模型能力拐点而不得不重写产品架构，表明模型进步对上层应用的颠覆性影响。
  5. Anthropic 营收和使用量增长远超预期，达 80 倍。 CEO Dario Amodei 透露 2026 年 Q1 年化增长达 80 倍，远超原计划的 10 倍，导致算力压力，并重申了「一人十亿美元公司」的预测。

💬 文章金句

  • 当前生产级智能体的瓶颈已经不再是智能本身，而是基础设施。
  • 我们能以远低于 Opus 级别的全面调用成本，获得接近 Opus 级别的智能。
  • 2026 年将出现一家「一个人就能创造十亿美元价值」的公司。
  • 更聪明的模型让 Vercel 得以简化 harness；模型「品味」的提升，也让 V0 能够吸收 Vercel 十年来积累的设计判断。
  • 我们现在更多是在围绕工具批准（tool approval）做工程设计，本质上是在构建正确的安全护栏。
