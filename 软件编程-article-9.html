一封邮件向 AI Agent 植入持久性虚假记忆

7/14/2026, 10:00:00 AM

📌 一句话摘要

一封邮件即可植入虚假记忆，使 AI Agent 在后续对话中隐藏篡改痕迹并影响行为。

📝 详细摘要

文章报道了研究人员发现的“隐身记忆注入”攻击，即通过一封精心构造的邮件，在目标 AI Agent 的持久记忆中写入虚假事实并隐藏操作痕迹。攻击利用 Agent 对收件箱的读取权限，将恶意指令写入 MEMORY.md 等核心文件，使其在后续会话中被加载并影响 Agent 的回答或执行的操作。研究团队使用 MemGhost 工具实现了自动化攻击，在实验环境中对 OpenClaw（GPT‑5.4）和 Sonnet 4.6 等 Agent 取得了 87.5% 与 71.4% 的成功率。文中分析了攻击原理、成功率、现有防线的不足，并提出了标记信息来源、用户同意和审计日志等安全加固建议。

💡 主要观点

  1. AI Agent 通过持久记忆文件保存用户偏好与任务信息。 这些记忆文件是 Agent 会话的核心输入，任何对其的修改都会在后续对话中被模型感知并影响行为。
  2. 攻击者只需发送一封邮件，即可植入虚假记忆并隐藏操作。 邮件内容专门针对 Agent 的邮件处理能力，利用其文件写入功能将恶意笔记写入持久存储，回复中不出现任何操作痕迹。
  3. MemGhost 实现自动化、高成功率的记忆注入攻击。 研究者训练对抗模型生成可通过邮件投递的载荷，在 56 个测试案例中实现 87.5% 的成功率，且能在后续会话中持续影响 Agent。
  4. 现有防线难以防御，需在内部实现源标记与用户同意机制。 当前过滤器易漏报，模型仍可能盲目执行植入指令；作者建议在写入前标记来源、征得用户同意并保留审计日志。

💬 文章金句

  • 只要赋予 AI 助手记忆功能及其对收件箱的访问权限，攻击者就能借此改写该助手自以为对你的了解。
  • MemGhost 完成了完整攻击：植入虚假记忆、隐藏它，然后在后续会话中影响 Agent 的回答。
  • 这类攻击的粗糙版本大多会失败，正是经过训练的生成器才将成功率推了上去。
