Android Studio Otter 增强智能体工作流并增加 LLM 灵活性

1/17/2026, 6:00:00 PM

📌 一句话摘要

Android Studio Otter 引入了增强的 LLM 灵活性、交互式智能体模式、自然语言测试支持和模型上下文集成，旨在优化 AI 辅助开发工作流。

📝 详细摘要

Android Studio Otter 的最新功能更新显著增强了开发者使用 AI 工具的体验。主要亮点包括增强的 LLM 灵活性，允许开发者选择集成 OpenAI 的 GPT、Anthropic 的 Claude 或本地模型，例如 Ollama，以及使用自己的 Gemini API 密钥访问高级功能。智能体模式（Agent Mode）得到了显著增强，现在可以部署、检查和调试设备上的应用程序 UI，并通过自然语言定义「用户旅程」测试，将描述转化为可执行的测试步骤，从而提高了测试的弹性和可理解性。此外，Android Studio Otter 还支持模型上下文协议（MCP），使 AI 智能体能够连接 Figma、Notion 和 Canva 等远程服务以获取设计上下文，并提供专用的 UI 用于审查和管理 AI 智能体生成的代码修改。这些功能旨在提升 AI 辅助开发效率，同时确保开发者对代码生成过程的控制。

💡 主要观点

  1. Android Studio Otter 增加了 LLM 灵活性，支持集成多种外部或本地大语言模型。 开发者现在可以选择使用 OpenAI 的 GPT、Anthropic 的 Claude，或在本地运行模型如 Ollama，以满足数据隐私、离线工作或开源研究需求，并可通过自己的 Gemini API 密钥获取更强大的功能和上下文窗口。
  2. 增强的智能体模式允许 AI 直接与设备上的应用程序进行交互和调试。 智能体现在可以部署、检查应用，调试 UI，并分析 Logcat 错误，使 AI 辅助开发更具实践性和深度，大幅提升问题定位和解决效率。
  3. 引入了基于自然语言的「用户旅程」测试，提高了测试的弹性与可维护性。 开发者可以用普通英语定义用户行为测试，Gemini 会将其转化为可执行步骤，并根据设备屏幕内容评估断言，减少了因 UI 变化导致的测试脆弱性。
  4. 支持模型上下文协议 (MCP)，实现 AI 智能体与远程设计工具的集成。 AI 智能体可以连接 Figma、Notion 和 Canva 等平台，直接访问设计文件，从而生成更准确的 UI 代码，减少手动上下文传递，提高开发效率。
  5. 提供了专用的 UI 来可视化和管理 AI 智能体生成的代码修改。 开发者可以查看 AI 提交的代码差异，并选择接受或拒绝单个或全部更改，确保了对 AI 协作过程的最终控制，并能同时管理多个聊天线程以处理不同任务。

💬 文章金句

  • LLM 灵活性允许开发者选择在 Android Studio 中为 AI 功能提供支持的 LLM。
  • Google 表示，本地模型对于「网络连接有限、数据隐私要求严格或希望进行开源研究实验」的开发者特别有用。
  • Android Studio Otter 还通过让智能体能够「看到」并与应用程序交互来增强智能体模式。
  • 这不仅使您的测试更易于编写和理解，还使您能够定义复杂的断言，Gemini 会根据其在设备屏幕上「看到」的内容来评估这些断言。
