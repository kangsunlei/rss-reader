简化部署：几秒钟启动 Workers 应用程序

4/8/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 推出“部署到 Cloudflare”按钮，开发者和开源项目维护者可从 Git 仓库一键部署 Workers 应用程序。

📝 详细摘要

Cloudflare 推出了“部署到 Cloudflare”按钮，可添加到 GitHub 和 GitLab 等 Git 仓库中包含 Workers 应用程序的 README 文件中。该按钮能自动创建 Git 仓库，配置 Workers KV 命名空间、D1 数据库和 R2 存储桶等必要资源，并为 CI/CD 设置 Workers Builds，还能为每个拉取请求添加预览 URL，从而显著简化部署流程。Fiberplane、MCP 服务器和 AI 代理等示例展示了该按钮在不同应用场景下的强大功能。此功能旨在降低设置和部署开源 Workers 应用程序的复杂性，鼓励更多开发者共享、自定义和贡献这些项目。

💡 主要观点

  1. “部署到 Cloudflare”按钮简化了部署过程。 它自动化了仓库创建、资源配置和 CI/CD 设置，减少了手动配置。
  2. 自托管 Workers 应用程序变得前所未有的轻松。 该按钮消除了与传统云提供商相关的繁琐设置、运营开销和隐藏成本。
  3. 鼓励共享和贡献开源 Workers 项目。 通过简化部署，该按钮降低了开发人员使用和贡献开源项目的门槛。

💬 文章金句

  • 现在，您的项目可以在一蹴而就——这意味着更多的吸引力、更多的反馈和更多的贡献。
  • 通过使用“部署到 Cloudflare”按钮使您的开源仓库可访问，您可以允许其他开发人员部署他们自己的应用程序实例，而无需深入的基础架构专业知识。
  • 每次向新创建的仓库中的生产分支推送新内容时，都会自动构建和部署，这得益于 [++Workers Builds++](https://developers.cloudflare.com/workers/ci-cd/builds/)。
