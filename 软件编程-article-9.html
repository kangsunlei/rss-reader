偷藏 3 个月，Anthropic 删除识别“中国 AI”的隐藏代码，官方回应：这只是一次实验，我们早想删了

7/2/2026, 7:24:00 AM

📌 一句话摘要

Anthropic 在 Claude Code 中隐藏了一套检测中国时区、域名及 AI 实验室的代码，用于识别模型蒸馏行为，被开发者发现后引发隐私与信任争议，官方回应称已计划移除。

📝 详细摘要

本文报道了 Anthropic 在 Claude Code 中隐藏近三个月的检测代码事件。该代码通过检测系统时区、代理域名及 AI 实验室关联，以不同 Unicode 字符编码状态。被 Reddit 开发者逆向发现后，Anthropic 工程师承认这是一项防止模型蒸馏的实验，并称已在最新版本中移除。文章梳理了技术细节、官方回应及开发者社区的质疑，指出此举虽技术层面已解决，但用户信任的修复才是核心问题。

💡 主要观点

  1. Anthropic 在 Claude Code 中隐藏检测代码长达三个月。 代码通过检查 Base URL、系统时区（Asia/Shanghai 等）和域名列表，识别中国 AI 实验室及转售商，并将结果以不同 Unicode 引号字符编码到 System Prompt 中。
  2. Anthropic 官方回应称该代码是一项实验，旨在防止模型蒸馏与未授权转售。 负责工程师表示实验始于 3 月，团队已部署更强缓解措施，并于 7 月 1 日版本中回滚该功能，但未解释为何此前不公开披露。
  3. 开发者社区质疑此举破坏了工具信任，根本问题在于透明度的缺失。 由于代码被混淆且未在更新日志中说明，外界怀疑若非被曝光，该机制可能会长期运行。Claude Code 拥有高系统权限，这种隐蔽行为引发了对隐私和安全的担忧。

💬 文章金句

  • 对于 Anthropic 而言，删除隐藏代码或许并不困难。但如何重新赢得开发者的信任，恐怕才是这场风波真正留下来的问题。
