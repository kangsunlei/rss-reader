📝 详细摘要

在实际项目中，我发现 Prompt 写不好通常不是因为太短，而是因为「模糊」，模型无法理解期望的格式、风格或受众。本文详细讲解了如何通过明确角色、定义任务、提供上下文、约束格式和使用示例来构建有效的 Prompt。此外，还探讨了 Prompt 压缩技术，以优化长上下文场景下的成本和延迟。

💡 主要观点

  1. 五要素构建基础 一个有效的 Prompt 必须包含角色设定、任务描述、背景信息、输出格式和示例。这些要素共同帮助模型理解上下文，并生成符合预期的结果。
  2. 进阶技巧提升质量 使用 CoT 触发词可以引导模型进行更深入的推理，而 XML 标签包裹则有助于明确区分不同的输入部分，提高模型的理解精度。
  3. 迭代与压缩优化 Prompt 工程是一个持续优化的过程，需要通过测试集验证效果。此外，对于长 Prompt，可以利用压缩技术（如 LLMLingua）来减少 token 消耗，从而降低成本和延迟。
