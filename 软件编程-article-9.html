reinstall：操作系统自己重装？这个开源项目有点神奇

10/13/2026, 1:22:33 PM

📌 一句话摘要

一个无需 U 盘或启动盘，通过在现有系统运行命令即可实现 Windows 与 Linux 互相重装的开源脚本。

📝 详细摘要

本文介绍了一个名为 reinstall 的开源工具，它允许用户在现有操作系统状态下通过简单的命令行命令自动完成系统重装。该工具支持 Windows、Linux 以及飞牛 OS 等多种发行版的互相转化，并提供了网页实时查看日志、DD 镜像恢复以及 Live OS 环境启动等实用功能，非常适合需要维护 VPS 或云服务器的开发者。

💡 主要观点

  1. 核心功能：无介重装 无需物理 U 盘或制作 启动盘，直接在现有系统内运行脚本即可触发重装流程，极大降低了服务器维护的门槛。
  2. 跨平台转换支持 支持 Windows 与 Linux 系统（如 Ubuntu， Debian， CentOS 等）之间的互相转化安装，满足了多环境切换的需求。
  3. 可视化进度监控 脚本在重装期间会开启一个 Web 服务，用户可以通过浏览器实时查看安装日志和进度，解决了远程操作断连后无法反馈的问题。
  4. 灵活的参数配置 支持自定义 SSH 密钥登录、内网穿透（frpc）、禁用云内核（防止黑屏）以及安装前验证（hold 模式）等进阶功能。

💬 文章金句

  • 不需要 U 盘，不需要制作启动盘，**只需要在现有系统中运行一条命令**，就能自动完成重装
  • 甚至可以在 Windows 与 Linux 系统之间互相转化安装
  • 通过网页可以实时查看到安装日志、进度
