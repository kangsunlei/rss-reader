📌 一句话摘要

WebStorm 2025.2 路线图详细规划了 IDE 的增强功能，包括更完善的 Bun 支持、TypeScript 性能优化和最新的 CSS 特性。

📝 详细摘要

本文概述了 JetBrains WebStorm 2025.2 版本（计划于 7 月发布）的主要功能。重要的更新包括增强对 Bun JavaScript 运行时和软件包管理器的支持，提供自动项目检测和上下文感知操作，从而提高灵活性。我们还将通过持续开发基于服务的类型引擎，有针对性地提升性能，尤其是在 React 和 Angular 等大型项目和复杂框架中，实现更快的类型推断和代码补全。路线图还重点介绍了 CSS 支持的进展，增加了对现代 CSS 语法的识别，例如 `@layer`、`:has()` 和新的颜色格式。同时，修复了 CSS-in-JS 语言注入中 CSS 变量无法正确解析的问题，从而提供更简洁的样式支持。此外，我们还在进行准备工作，使 WebStorm 与即将到来的 Go 语言重写的 TypeScript 编译器保持一致。欢迎大家体验 WebStorm 的 EAP 版本，抢先了解最新功能！

💡 主要观点

  1. 增强的 Bun 支持简化了项目设置和执行流程。 WebStorm 2025.2 将自动检测 Bun 项目并添加上下文操作，在 Node.js 之外，为软件包管理和文件运行提供更大的灵活性。
  2. 基于服务的类型引擎显著提升 TypeScript 性能。 我们正在努力在 React 和 Angular 等大型框架中实现更快的类型推断和代码补全，从而解决已知的性能瓶颈，改善开发者体验。
  3. 增强了现代 CSS 功能和 CSS-in-JS 变量的处理能力。 增加了对新 CSS 功能的验证和补全支持，并修复了 styled-components 等 CSS-in-JS 语言注入中 CSS 变量无法正确解析的关键问题。
  4. 为 Go 语言重写的 TypeScript 编译器做好了准备。 WebStorm 正在为即将到来的 Go 语言重写的 TypeScript 编译器做准备，以便充分利用其潜在的性能改进。

💬 文章金句

  • 请注意，这些计划可能会有所调整。
  • 这些改进是我们致力于提供即用型替代运行时和软件包管理器的重要组成部分，旨在帮助您更灵活地选择最适合的工具组合。
  • 在过去的几个版本中，我们一直在构建一个全新的基于服务的类型引擎，从底层改进 WebStorm 理解和处理 TypeScript 类型的方式。
  • CSS 发展迅速，我们希望确保 WebStorm 与时俱进，使您能够充分利用最新的语法和样式功能，并获得强大的代码辅助功能。
  • 虽然这项使用原生代码重写的计划仍处于早期阶段，但我们已经在 WebStorm 内部采取措施，为未来的发展做好准备。
