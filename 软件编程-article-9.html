Node 中文周刊 #247 - Node.js 26 正式进入 LTS，Node2Shell 漏洞修复

10/30/2026, 11:20:00 PM

📌 一句话摘要

本期周刊涵盖了 Node.js 26 成为 LTS 版本、修复 Node2Shell 远程代码执行漏洞、讨论了 JS 运行时单一化风险以及多个开源工具更新。

📝 详细摘要

本期 JavaScript 中文周刊 #247 重点介绍了 Node.js 26“Lithium”正式成为 Active LTS 分支，支持到 2029 年 4 月；十月安全发布修复 10 个 CVE，其中内置 Brotli 解码器的 Node2Shell 可导致远程代码执行；RedMonk 分析师讨论 JavaScript 运行时单一化的风险；Reylo 借 TypeScript 7.1 内容映射器实现 .sql 文件的类型化导入；OpenTelemetry JS 3.0 与 Dependency Cruiser 18.7 发布。

💡 主要观点

  1. Node.js 26「Lithium」正式成为 Active LTS 分支 Node.js 26.13.0 把 Node 26 提升为长期支持版本，更新将持续到 2029 年 4 月，成为生产环境应当瞄准的新分支。Node 24 已转入维护期。
  2. 十月安全发布修复了 Brotli 漏洞 Node.js 修复了 26.12.1、24.22.1 与 22.23.4 三个版本，其中内置 Brotli 解码器缺陷被称 Node2Shell，恶意压缩数据可能导致远程代码执行。
  3. JavaScript 运行时单一化 随着 Deno、Cloudflare 运行时逐步退出，服务端格局可能收窄为 Node、Bun 与 Workers。Node 的主导地位值得担忧。
  4. Reylo：把 .sql 文件导入，并获得完整的类型推导 由 Zod 作者开发，直接用纯 .sql 文件编写查询，参数类型能从 SQL 中推导，依赖 TypeScript 7.1 内容映射器。
  5. GitHub Actions 工作流锁文件正式可用 在用户的工作流中可以锁定依赖的版本。
