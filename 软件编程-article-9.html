Numbus：为 AI 与人类同写文档的现代化方案

11/3/2026, 2:10:50 PM

📌 一句话摘要

介绍 Numbus 文档框架，基于 Astro 构建，支持人类和 AI Agent 双格式输出，具备技能调用及 MCP 服务等高级功能

📝 详细摘要

作者分享了 CF 的 Numbus 文档站点框架，基于 Astro，专为人类和 AI Agent 同时编写文档而设计。支持 MDX 语法，自动生成 HTML 和 MD 两种格式，且能自动创建 llms.txt 和 llms-full.txt。更强大的功能包括：skills（让文档站添加可被 Agent 调用的技能），websearch mcp（让 Agent 搜索文档），远程 MCP server（可暴露为 MCP 服务）。作者认为这是一个现代化的 AI 文档写作解决方案。

💡 主要观点

  1. Numbus 支持双模式文档生成 通过 MDX 编写，能同时生成人类可读的 HTML 页面和 AI Agent 可解析的 Markdown 格式，实现人机协同文档管理
  2. 具备高级功能提升 AI 交互能力 包含 skills 调用、websearch MCP 搜索及远程 MCP Server 等特性，使文档不仅是静态内容，更能成为可交互的 AI 工具
