JavaScript 中文周刊 #240 - VoidZero 加盟 Cloudflare，Angular v22 正式发布

6/11/2026, 9:10:00 AM

📌 一句话摘要

本期 JavaScript 中文周刊汇总了 VoidZero 加盟 Cloudflare、Angular v22 发布、Safari 27 beta 等重大新闻，以及多篇关于现代工程价值观、Deno 与 Bun 生态的深度文章和实用工具。

📝 详细摘要

本期周刊以「VoidZero 加盟 Cloudflare」为头条，详细报道了尤雨溪创立的公司（Vite、Vitest、Rolldown、Oxc 的母公司）正式加入 Cloudflare，并附带 100 万美元 Vite 生态基金的消息。同时，Angular v22 正式发布，将 Signal Forms、Angular Aria 与异步响应式三大特性升级为稳定版。快讯部分涵盖 Safari 27 beta 的 ESM 加载器重写、Electron 43 beta 的性能提升、React Compiler Rust 移植版可测试等。文章推荐部分精选了 Jest 作者关于 AI 时代工程价值观的思考、对 Deno 保持自身优势的呼吁、以及 RedMonk 分析师以 Bun 为样本探讨 AI 与开源可持续性的深度文章。工具与代码部分介绍了 Geometric.js、Micromodal.js、PDFSlick 4.0 等实用库。最后还汇总了 TanStack Table v9 Beta、Node-RED v5.0 等多个版本发布信息。

💡 主要观点

  1. VoidZero 加盟 Cloudflare 是 JavaScript 工具链领域的年度大事件。 尤雨溪创立的 VoidZero（Vite、Vitest、Rolldown、Oxc 母公司）正式加入 Cloudflare，所有项目保持 MIT 许可，团队继续掌舵，并附带 100 万美元 Vite 生态基金，对前端生态影响深远。
  2. Angular v22 将三大核心特性升级为稳定版。 Signal Forms、Angular Aria 与异步响应式三大特性正式可用于生产，路由器新增原生浏览器 Navigation API 的实验性支持，标志着 Angular 框架的重要演进。
  3. AI 正在重塑现代工程价值观。 Jest 作者认为，随着 AI 代理编写更多代码，ownership、品味、严格而快速的反馈循环等价值观被推到更核心的位置，而非传统的手写代码能力。
  4. Deno 社区对兼容性路线存在分歧。 有爱好者认为，追逐 Node.js/npm 兼容性正在让 Deno 失去其零配置、贴合 Web 标准、单文件全包的独特体验优势，呼吁保持初心。
  5. Bun 成为观察 AI 编写核心基础设施可持续性的风向标。 RedMonk 分析师指出，Bun 代码中 AI 生成比例越来越高，这使其成为检验 AI 能否可持续地编写和维护核心基础设施的典型案例。
