通过可重用提示文件提升你的 Copilot（副驾驶）协作

9/2/2025, 12:00:42 PM

📌 一句话摘要

Visual Studio 引入了 GitHub Copilot 的可重用提示文件，显著提高了提示工程效率，并极大地促进了团队协作。

📝 详细摘要

本文宣布并解释了 Visual Studio 的新功能：GitHub Copilot 的可重用提示文件。它旨在解决创建有效人工智能提示的常见挑战，允许开发者通过编写、保存和直接在 Visual Studio 中使用 `.github/prompts/[title].prompt.md` 文件来运行自定义提示。这项创新确保了优化的提示始终触手可及，无需再搜索过去的通信记录或笔记。该功能不仅加快了个人工作流程，还促进了无缝的团队协作，因为这些提示文件在代码仓库中共享，从而在整个项目中提升结果一致性，并加速解决方案的发现。本文提供了最大化这些文件实用价值的技巧，包括利用 `awesome-copilot` 这样的社区资源，按主题组织提示，以及定期改进并在团队内共享有效的提示。

💡 主要观点

  1. 可重用提示文件简化了 Visual Studio 中 Copilot 的交互。 开发者可以直接在集成开发环境 (IDE) 中保存并快速访问精心制作的提示，从而消除重复并加速 AI 辅助编码流程。
  2. 该功能显著增强了团队协作和提示一致性。 在代码仓库中共享的提示文件确保所有团队成员使用一致且有效的提示，从而提高代码质量并加速项目理解。
  3. 提供了实用技巧来最大化可重用提示的实用性。 本文提供了关于组织、改进和共享提示的可操作建议，包括利用 `awesome-copilot` 这样的社区资源。

💬 文章金句

  • 可重用提示文件允许你在 Visual Studio 内部编写、保存和运行提示。
  • 这意味着你最好的提示始终触手可及——无需再在旧文件、电子邮件或笔记中搜索。
  • 这些文件在代码仓库中共享，确保项目结果的一致性，并方便团队成员使用。
  • 每个人都可以从经过测试的有效提示中受益，这些提示可以加速理解和解决方案的发现。
  • 定期审查和改进你最常用的提示，以确保其有效性和相关性。
