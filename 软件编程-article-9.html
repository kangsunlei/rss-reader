Claude 水印被破解，暴涨 15000+ Star！

8/20/2026, 9:41:00 AM

📌 一句话摘要

文章介绍 Anthropic 为 Claude 模型加入肉眼不可见的水印，以及 GitHub 上开源去水印工具 watermarks-remover 的原理与使用方式，并指出该项目一周获 1.5 万星。

📝 详细摘要

文章首先说明 Anthropic 在 2026 年 8 月 2 日后发布的 Claude 模型中加入了肉眼不可见的水印，以符合欧盟监管要求。随后介绍了 GitHub 上刚刚获得 15000+ Star 的开源项目 watermarks-remover，该工具提供 Agent 技能和 Python 服务两种使用方式，能够去除 Claude、Gemini、OpenAI 等多家 AI 厂商在文本及 PNG、PDF、DOCX、MP4 等二十多种文件格式中的水印。文章详细描述了该工具的三层去水印方案：第一层清除零宽空格等不可见字符；第二层通过改写文本来打散统计采样水印；第三层剥除文件中的 C2PA 来源信息和 EXIF 元数据。同时强调该工具仅依赖 Python 标准库，无需第三方包，且仅限于授权内容使用。最后作者对加水印与去水印的技术双面性进行了简短评论，并给出了项目的 GitHub 地址。

💡 主要观点

  1. Claude 模型在 2026 年 8 月 2 日起生成的文本中加入肉眼不可见的水印。 这是 Anthropic 为符合欧盟 AI 内容标识监管而采取的措施，水印对全球用户生效，肉眼无法直接察觉。
  2. 开源项目 watermarks-remover 能够去除多家 AI 厂商在文本和文件中的水印。 该项目提供 Agent 技能和 Python 服务两种使用方式，支持 Claude、Gemini、OpenAI 等模型，兼容 PNG、PDF、DOCX、MP4 等二十多种文件格式。
  3. 工具采用三层方案分别处理不可见字符、统计采样水印和文件元数据。 第一层直接删除零宽空格等字符；第二层通过改写文本来降低统计水印；第三层剥除图片、PDF 等文件中的 C2PA 和 EXIF 信息。
  4. watermarks-remover 仅依赖 Python 标准库，使用简便且不调用厂商 API。 无需第三方包，可通过一条命令启动本地 HTTP 服务；默认仅处理授权内容，避免滥用。

💬 文章金句

  • 使用 Claude 的朋友，需要注意了，现在模型生成的每一段文字里，可能都塞了其他东西。
  • 它叫 watermarks-remover 。
  • 另外项目的核心实现，只用到 Python 标准库，没有依赖任何第三方包。
  • 另外作者特意强调，工具只用于自己拥有内容和获得授权的稿件，提前声明正确的用法。
