Vercel v0 API 正式发布：支持 MCP、流式响应和自动部署

8/23/2026, 2:00:00 AM

📌 一句话摘要

Vercel 推出 v0 API，让开发者通过编程方式访问其 AI 应用构建智能体，支持流式响应、MCP 集成和自动部署，将应用构建过程自动化。

📝 详细摘要

Vercel 的 v0 API 允许开发者以编程方式与 AI 应用构建智能体交互，通过发送提示词生成和修改应用程序文件。API 支持流式响应，公开智能体操作，并允许基于现有仓库或文件创建应用程序。开发者可以关联 Vercel 项目进行部署，并利用 MCP 或 AI SDK 集成外部工具。该 API 旨在自动化应用开发工作流，与交互式构建工具形成对比。

💡 主要观点

  1. 编程方式访问 AI 构建智能体 v0 API 允许开发者通过 HTTP 请求与 AI 智能体交互，而不是使用图形界面。这使得应用构建过程可以被自动化和集成到现有工作流中。
  2. 支持流式响应和 MCP 集成 API 提供流式传输，实时显示智能体操作，并支持 Model Context Protocol (MCP) 集成，允许连接外部数据源和工具，增强智能体的能力。
  3. 自动化部署和预览 开发者可以通过 API 直接将生成的应用程序部署到 Vercel，并获取预览 URL。这实现了从概念到部署的无缝自动化，无需手动干预。

💬 文章金句

  • 这是迈向全程可编程应用开发工作流的重要一步。
  • 你的智能体需要一个应用程序。它将提示词连同你的设计系统一起发送给 v0 API，随后会收到一个预览 URL：应用程序已在 Vercel Sandbox 中实时运行。
