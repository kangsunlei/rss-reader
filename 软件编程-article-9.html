OpenAI 的 GPT-5 发布：成本更具竞争力，面临严格审查

8/11/2025, 12:46:00 PM

📌 一句话摘要

OpenAI 发布 GPT-5，新功能和更低定价引人关注，但数据可视化方式和用户反馈引发争议。

📝 详细摘要

OpenAI 于 2025 年 8 月 7 日向 ChatGPT 用户通过 API 发布了 GPT-5，引入了“思考”路由器、新的模型大小和面向生产的定价，尤其值得关注的是，其输入成本约为 GPT-4o 的一半。该模型拥有 400K token 的上下文窗口，并在 MLE-Bench 和 SWE-Lancer 等基准测试中提高了性能，尤其是在代码密集型任务中。尽管取得了这些进步，OpenAI 在演示文稿中使用的条形图，在视觉上存在误导，因此受到了批评。该公司已将其 API 整合为 Responses API，从而简化了智能代理应用程序的开发，并可通过单个请求直接访问图像生成、代码解释器、文件搜索和模型上下文协议 (MCP) 服务器。GPT-5 还声称显著降低了幻觉率。然而，Reddit 上的用户反应波动较大，有报告称感知到的语气发生了变化，速率限制也更加严格，并且旧模型被暂时移除，最终 OpenAI 恢复了 GPT-4o 作为选项。

💡 主要观点

  1. GPT-5 引入了高级功能，如“思考”路由器和扩展的上下文窗口。 新的路由器允许模型为复杂的任务进行更深入地分析，结合 400K token 的上下文窗口，增强了模型在生产用例中的推理和理解能力。
  2. OpenAI 的 API 围绕 Responses API 整合，简化了多模态和工具使用应用程序。 Responses API 成为智能代理应用程序的主要接口，通过单个请求实现多模态提示、内置工具和远程模型上下文协议 (MCP) 服务器的无缝集成。
  3. 尽管有性能声明，GPT-5 的发布遇到了数据可视化问题和用户反馈褒贬不一。 OpenAI 的基准图表在视觉上具有误导性，Reddit 上的用户反馈表明对语气和速率限制的变化感到失望，促使恢复 GPT-4o 作为选项。
  4. GPT-5 显著降低了幻觉率，并提高了事实基准测试的可靠性。 针对 LongFact 和 FActScore 等数据集，GPT-5 模型，尤其是“gpt-5-thinking”，表现出显著较低的事实错误，从而提高了模型的可信度。

💬 文章金句

  • 通过立即向所有人开放 GPT-5，OpenAI 锁定了巨大的网络效应。新用户涌入，现有用户大规模升级，ChatGPT 的市场竞争力增强。
  • GPT-5 的定价为每百万输入 token 1.25 美元，每百万输出 token 10 美元，约为 GPT-4o 输入成本的一半。
  • GPT-5 模型显示出比 OpenAI o3 和之前的基线显著更低的幻觉率，gpt-5-thinking 在三个基准测试的浏览开启和浏览关闭设置中产生的事实错误减少了五倍以上。
  • 在许多方面都取得了良好的进展，但仍然只是行业参与者之一，并未实现巨大飞跃。 关于其在现实世界中的表现，还有诸多问题尚待验证，并且显然还未达到通用人工智能的水平。
