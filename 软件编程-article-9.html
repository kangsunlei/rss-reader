GitHub 备受争议的 AI 训练政策变更

3/27/2026, 8:31:30 PM

📌 一句话摘要

Gergely Orosz 批评 GitHub 在政策变更上缺乏透明度，该变更似乎允许对私有仓库进行 AI 训练，即便是对于付费的商业版和企业版用户也是如此。

📝 详细摘要

作者强调了对 GitHub 最近政策变更的重大担忧。他指出，GitHub 未能明确说明这些变更是否影响商业版或企业版用户，但已有报告显示这些用户确实受到了影响。这条推文强烈批评了 GitHub 处理用户数据隐私的方式。
