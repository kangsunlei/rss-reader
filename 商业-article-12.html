Kimi Work 不是中国版 Codex

6/8/2026, 7:29:00 AM

📌 一句话摘要

本文深度评测 Kimi Work，指出它不是中国版 Codex，而是一款面向知识工作者的通用本地 Agent，通过 WebBridge、Agent 集群和 Skill 技能体系，将 AI Agent 能力从编程泛化到办公场景，开启 Vibe Working 时代。

📝 详细摘要

文章围绕 Kimi Work 的产品定位、核心能力与使用体验展开。作者首先澄清 Kimi Work 并非中国版 Codex，其目标用户是知识工作者而非程序员，产品形态是用户熟悉的对话框+侧边栏，而非终端命令行。核心能力包括：WebBridge 让 AI 像人一样操作浏览器（登录、点击、读取页面），Agent 集群最多可并行调用 300 个子 Agent 拆解任务，以及内置的 Skill 技能广场和同花顺、世界银行等专业数据库。作者通过实际测试（取关马斯克、生成 PPT、分析招股书）验证了产品能力，并透露该产品由 Kimi 工程师使用 Kimi Code 等工具在一周内开发完成，92%的代码由 AI 生成。最后讨论了安全机制（任务限定在指定文件夹）和工作范式变化。

💡 主要观点

  1. Kimi Work 定位为面向知识工作者的通用本地 Agent，而非中国版 Codex。 产品面向文档处理、表格、PPT 等办公场景，用户界面是对话框+侧边栏，无需终端和命令行，降低了非编程用户的使用门槛。
  2. WebBridge 让 AI 像人一样操作浏览器，突破传统 API 调用限制。 通过模拟人类登录、点击、读取页面，WebBridge 可以访问需要登录或反爬限制的网站，无需付费 API，作者用取关马斯克等操作验证了其可用性。
  3. Agent 集群实现任务并行执行，显著提升效率。 最多可调用 300 个子 Agent 并行工作，作者测试 300 页招股书 PPT 制作，单 Agent 需 43 分钟，集群仅 21 分钟，体现了多 Agent 并行范式的优势。
  4. 该产品由 AI 开发，92%代码由 AI 生成，体现 AI 再造 AI 理念。 Kimi 工程师使用 Kimi Code 等工具一周内完成开发，背后 K2.6 模型支持 13 小时连续编码、300 个子 Agent 并行协作和 4000 余次自主工具调用。

💬 文章金句

  • Vibe Working 有可能是接下来比 Vibe Coding 更火的词。
  • 过去是 Vibe Coding，接下来更多人将进入 Vibe Working(氛围办公)。
  • 用一套 Agent 产品，打造了另一个 Agent 产品，相当于'AI 再造 AI'概念具象化了。
