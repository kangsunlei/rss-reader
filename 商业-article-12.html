“价格打骨折”，Claude Haiku 5.5 把小模型卷到一分钱时代

10/7/2026, 11:44:00 PM

📌 一句话摘要

Anthropic 发布 Claude Haiku 5.5，通过大幅降价至 GPT-6 Luna 水平并显著提升编程与电脑操作能力，将小模型竞争从单纯的价格战推向性能与成本平衡的新阶段。

📝 详细摘要

文章报道了 Anthropic 最新发布的轻量级模型 Claude Haiku 5.5。该模型在价格上极具竞争力，输入每百万 token 仅 0.1 美元，输出 0.5 美元，较上一代降价 90%，并与 OpenAI 的 GPT-6 Luna 持平。除了低价，Haiku 5.5 重点补齐了此前在编程（Terminal-Bench 得分从 0 提升至 39.2%）、电脑操作（OSWorld 得分大幅提升）和知识工作方面的短板，支持可调模式和 100 万 token 上下文。尽管在事实知识和部分自动化基准测试中仍落后于竞品，且存在因安全策略导致的过度拒绝问题，但其实际表现已获开发者认可。此外，Anthropic 还下调了 Sonnet 模型的缓存价格，并为订阅用户提供 API 积分返还。文章分析认为，此举标志着小模型赛道进入“又便宜又好用”的竞争阶段，虽然面临中国厂商更低价格的挑战，但 Haiku 5.5 凭借均衡的性能和生态整合能力，旨在成为智能体工作流中的高效执行单元。

💡 主要观点

  1. Haiku 5.5 通过激进降价和性能补强，重新定义小模型价值标准 新模型价格降至上一代的十分之一，与 GPT-6 Luna 持平，同时在编程、电脑操作等关键短板上有显著突破（如 Terminal-Bench 得分从 0 升至 39.2%），表明小模型不再只是“凑合用”，而是具备处理复杂任务的能力。
  2. 实际应用场景验证了其作为智能体组件的潜力 独立开发者和企业客户反馈显示，Haiku 5.5 在生成 SVG 图形、Bug 分类、项目搭建等任务中延迟降低、速度提升，适合大规模运行的分析工作和子智能体任务，证明了其在真实工作流中的可用性。
  3. Anthropic 通过全线调价和积分政策巩固生态优势 除了 Haiku 降价，Sonnet 缓存读取价格减半，预计使智能体任务成本降低 20%；同时向 Max/Team 订阅用户返还等额 API 积分，降低了开发者使用 API 的门槛，增强了用户粘性。
  4. 小模型竞争加剧，但仍需应对来自开源和中国厂商的价格压力 虽然 Haiku 5.5 追平了 Luna 的价格，但 Qwen3.7 Flash 等中国模型价格更低，GLM-5.3 Flash 在某些基准测试中得分略高。Haiku 5.5 更多是被动应战，其长期成功取决于能否在稳定性和可靠性上建立壁垒。

💬 文章金句

  • 小模型竞速赛，左起依次为 OpenAI CEO 奥特曼、谷歌 CEO 皮查伊、Anthropic CEO 阿莫迪。图片经由 AI 处理
  • 距离上一代 Haiku 发布快一年，Anthropic 终于更新了这条最小号的产品线。
  • 最引人注意的是价格：输入每百万 token 仅 0.1 美元，输出 0.5 美元，直接降至上一代 Haiku 4.5 的十分之一，也与 OpenAI 上个月发布的 GPT-6 Luna 持平。
  • 小模型的战争，从比谁更便宜，进入了比谁又便宜又好用的阶段。
  • 对开发者来说，真正的考验，是 Haiku 5.5 能不能稳定、可靠地完成那些目标明确、边界清晰的任务，并且经得起反复调用。
