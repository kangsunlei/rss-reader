Claude Code Co-work 令人震撼

1/13/2026, 9:38:13 AM

📌 一句话摘要

Wes Roth 报道了包括 Anthropic 的 Co-work 发布、Google 面向智能体购物的通用商务协议、OpenAI 传闻中的硬件、苹果与 Google 的 Gemini 合作以及即将发布的 DeepSeek V4 在内的重大 AI 新闻。

📝 详细摘要

Wes Roth 的这段视频快速概述了 AI 领域的重大发展。主要亮点包括 Anthropic 推出的 Co-work，这是 Claude Code 的用户友好版本，旨在让非技术用户也能使用强大的自动化功能。视频深入探讨了 Google 为「智能体购物时代」创建「通用商务协议」的雄心，假设 AI 智能体将成为人类与互联网之间的新中介。进一步的爆料包括 OpenAI 的「Sweet Pea」和「Gumdrop」硬件项目的泄露细节、苹果与 Google Gemini 合作的战略意义，以及预计将发布的开源 DeepSeek V4 模型，据传该模型将在编码能力上超越当前基准。Roth 强调了 AI 从技术工具向普及化、易用性工具的转型，以及随之而来的挑战和机遇。

💡 主要观点

  1. Anthropic 的 Co-work 通过用户友好界面将 Claude Code 的能力扩展到非技术用户 Co-work 是专为 Max 订阅者提供的 macOS 独家研究预览版，允许 Claude 访问和操作文件夹、从各种输入生成内容，并与众多外部连接器交互，无需深厚的技术知识
  2. Google 正在积极开发「通用商务协议」（UCP）以促进 AI 智能体驱动的购物 UCP 是与主要零售商合作构建的，旨在使 AI 模式和独立 AI 智能体能够研究、比较并最终直接进行购买，可能集成微支付以支持智能体间交易
  3. OpenAI 据传正在开发消费级硬件设备，代号为「Sweet Pea」和「Gumdrop」，计划于 2026 年发布 这些设备可能包括类似 AirPods 的音频设备和集成 AI 的笔形录音器，标志着 OpenAI 向实体产品的推进，生产目标高达 5000 万台
  4. 苹果与 Google 已达成合作，苹果的下一代基础 AI 模型将利用 Google 的 Gemini 这一战略联盟标志着权力动态的转变，苹果通过集成 Google 的先进 AI 来增强 Siri 和其他功能，可能创建一个在 AI 领域占主导地位的生态系统
  5. 开源模型，尤其是 DeepSeek V4，正成为对抗企业 AI 主导地位的关键制衡力量 据传 DeepSeek V4 将显著提升编程能力，挑战专有模型，并可能培育更具竞争力和去中心化的 AI 格局

💬 文章金句

  • Claude Code 正在进化，它升级了，我们之前看到的甚至还不是它的最终形态。Anthropic 正式推出了 Co-work，你可以将其视为「面向大众的 Claude Code」。
  • OpenAI 的新设备可能类似于 AirPods。这些是你可以随身携带并塞入耳朵的 AI 设备。
  • 有趣的是，当被问及是否使用 Claude Code 来更新 Claude Code 本身时，Boris 确认了这一点。这意味着他对 Claude Code 的所有贡献和新功能都是由 Claude Code 编写的。
  • Google 已经非常明确地表示，他们希望将广告插入到这个 AI 模式中。
  • 最强大的开源 AI 力量仍然来自中国。DeepSeek 正引领这一潮流。
