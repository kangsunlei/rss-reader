龙芯、海光暴涨，中美 CPU 集体走牛背后有一个新逻辑

1/22/2026, 10:34:00 AM

📌 一句话摘要

文章分析了 2026 年 CPU 价格暴涨背后的逻辑：除产能受限外，AI 智能体（Agentic AI）对“域外 CPU”通用算力的海量需求成为核心增长引擎。

📝 详细摘要

本文深度剖析了 2026 年初全球 CPU 市场价格异动及资本市场走牛的深层原因。文章指出，继存储芯片之后，CPU 成为“算力税”的第二波承担者。供给侧方面，先进制程产能被高毛利 GPU 瓜分，且封装瓶颈导致出货周期大幅延长。需求侧方面，AI 智能体（Agentic AI）的兴起重塑了市场格局。智能体在执行任务时，除了大模型推理，还涉及大量的决策编排、网页搜索、代码执行等通用计算任务，这些任务主要由“域外 CPU”承担，且占据了任务总延迟的 80%-90%。随着智能体数量和复杂度的指数级增长，通用 CPU 市场迎来了巨大的增量空间，这也为龙芯、海光等国产 CPU 提供了新的发展机遇。

💡 主要观点

  1. CPU 价格上涨受供给侧产能分配和封装瓶颈的双重挤压。 代工厂优先保障高毛利 GPU 产能，挤压了 CPU 配额，同时 CoWoS 等先进封装产能超载导致 CPU 出货周期延长至 24 周以上。
  2. AI 智能体创造了对“域外 CPU”的大规模结构性需求。 智能体运行中，数据库检索、代码执行等非推理任务占据总延迟的 80%~90%，这些任务高度依赖通用 CPU 而非 GPU。
  3. 智能体经济的繁荣将带动通用 CPU 市场进入长效增长期。 预测到 2030 年活跃 Agent 数量和任务执行数将呈指数级增长，这种确定性需求正重塑 CPU 作为 AI 基础设施的核心地位。

💬 文章金句

  • 这一极端的价格压力迅速从上游传导至终端……一场覆盖全行业的“算力税”已经拉开序幕。
  • 整个智能体工作负载中，AI 计算任务只是一部分，还有很大部分是通用计算。
  • 在典型的 Agent 工作负载中，运行在 CPU 上的任务处理占据了任务总 Latency 的 80～90%。
  • 按照任务总延迟来计算，域外 CPU 的需求增加不比 GPU/AI 芯片少。
  • 这是新的增长逻辑，也就会在资本市场带来新的增长故事。
