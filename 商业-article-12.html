为了让大家用好 nano banana，谷歌发布了一份官方提示词教程

9/3/2025, 11:37:00 AM

📌 一句话摘要

谷歌官方发布了基于 Gemini 2.5 Flash Image 的多套 Prompt 模板，旨在帮助用户快速生成写实、插画、文本、商业、留白及漫画等高质量图像。

📝 详细摘要

文章详细介绍了谷歌为 Gemini 2.5 Flash Image（代号“nano banana”）模型提供的官方 Prompt 模板，旨在降低用户生成高质量图像的门槛。这些模板覆盖了写实摄影、插图与贴纸、文本渲染、商业摄影、极简主义与留白设计以及漫画等多类场景。每个模板都提供了详细的英文 Prompt 示例及其大意，并附带了使用 Python 调用 API 生成图像的代码片段，极大地增强了文章的实用性和可操作性。文章强调，用户无需深入理解原理，只需套用模板并像讲故事一样描述场景，即可有效利用模型能力，实现高效高质量的图像生成。

💡 主要观点

  1. 谷歌官方 Prompt 模板覆盖多种图像生成场景 提供了写实摄影、插图、文本渲染、商业摄影、留白设计和漫画共 6 种模板，满足不同创作需求，提升生成效率和质量。
  2. 强调像讲故事一样写场景是 Prompt 核心 通过详细描述场景、主体、光线、风格等元素，能够更精准地引导 AI 模型，生成符合预期的图像效果。
  3. 文章提供可直接运行的 Python 代码示例 每个模板都附带了使用 Google GenAI API 的 Python 调用代码，极大方便了开发者和用户进行实践和测试。
  4. Gemini 2.5 Flash 在文本渲染方面表现突出 模型在处理图像中的文字内容时展现出卓越能力，通过清晰的字体和设计描述即可产出高质量含文本图片。
