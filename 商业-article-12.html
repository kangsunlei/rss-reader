测试 Reachy Mini —— Hugging Face 推出的树莓派驱动机器人

2/13/2026, 9:00:00 AM

📌 一句话摘要

Jeff Geerling 对 Reachy Mini 机器人进行了评估，将其高质量的开源硬件与目前碎片化的软件生态系统以及云端 AI 带来的重大隐私担忧进行了对比。

📝 详细摘要

本文提供了对 Reachy Mini 的上手评测，这是一款由 Pollen Robotics 和 Hugging Face 开发的树莓派驱动机器人。作者 Jeff Geerling 记录了组装过程、硬件质量和软件体验，特别是测试了其“智能体”能力。虽然硬件因其坚固的 ABS 结构和开源特性（允许通过树莓派 CM4 进行本地控制）而受到称赞，但软件体验揭示了营销承诺与当前现实之间的巨大差距。Geerling 强调了技术障碍，如 IPv6 DNS 问题以及不同 Linux 发行版上不一致的应用表现。文章重点关注了对话式 AI 的隐私影响；作者注意到孩子们会迅速将机器人拟人化，并对默认连接到 OpenAI 的云端连接表示担忧。最终，这款机器人被定位为一款面向技术人员的有前途的教育工具，而非“即插即用”的消费级家电。

💡 主要观点

  1. AI 机器人现状目前尚未达到营销宣传中所谓“极其简单”的水平。 尽管高调的演示暗示了无缝的智能体行为，但实际的用户体验包含重大的技术摩擦，包括网络 Bug、未记录的 API 特性，以及为了避免云端依赖而对大量本地算力的需求。
  2. AI 与人类交互中的拟人化带来了直接且重大的隐私风险。 作者观察到孩子们很快就会将机器人视为有意识的生物，从而导致他们分享敏感的个人数据。这凸显了“默认开放”云端集成的危险，这些集成在未经明确同意的情况下将音频和视觉数据发送到第三方服务器。
  3. 开源硬件为注重隐私的用户和开发者提供了关键的安全保障。 由于 Reachy Mini 基于树莓派构建并具有开放 API，用户可以刷入自己的操作系统并将数据保留在本地。这种灵活性对于将设备从依赖云端的小工具转变为安全的教育平台至关重要。
  4. 本地运行 AI 智能体的真实成本对大多数爱好者来说仍然高得望而却步。 虽然机器人套件 449 美元的价格相对实惠，但在不依赖外部 API 的情况下在本地运行复杂的 AI 模型需要巨大的 GPU 算力，这可能会使系统总成本增加近十倍。
  5. Reachy Mini 更像是一款优秀的教育工具，而非成熟的消费级产品。 该套件的价值在于构建、编码和调试复杂机器人系统的学习过程。它最适合了解 Linux 和机器人技术的用户，而不是那些寻求开箱即用 AI 助手的用户。

💬 文章金句

  • 意图并非取代人类互动，而是为了激发学习。
  • 我解释了他们应该像对待陌生人一样对待机器人和对话式 AI，不要那么毫无保留。
  • 这是一个为学习而构建的机器人，它不是一个插上电源就能立即获得 AI 智能体带来的即时满足感的家电。
  • 最终结果（基本上是一个可以表达情感的智能音箱）不值 449 美元，但学习体验以及完全掌控它的能力可能值这个价。
  • 我确实对这个小机器人 API 和 Web UI 的“默认开放”性质感到担忧，尤其是像对话应用这样在没有任何形式同意的情况下立即连接到 OpenAI 服务器的行为。
