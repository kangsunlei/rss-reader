CycBox: 跨平台物联网调试工具，支持串口、TCP、UDP、MQTT、Modbus、远程调试、Lua 脚本、高精度时钟

6/3/2026, 3:03:42 AM

📌 一句话摘要

CycBox 是一款基于 Flutter + Rust 的跨平台物联网调试工具，以 1 毫秒级高精度定时、Lua 脚本应答和 MCP AI 助手为核心亮点，覆盖串口、TCP、UDP、MQTT、Modbus 等多种协议。

📝 详细摘要

本文是作者在 V2EX 分享创造板块发布的产品介绍帖，详细介绍了自研跨平台物联网调试工具 CycBox。文章从开发初衷（实现串口高频发送与自动应答）切入，阐述了其 Flutter + Rust 的技术架构，并重点突出了三大核心能力：1 毫秒分辨率（±0.5ms）的高精度定时与每秒超 1000 次的数据收发、内嵌 Lua 脚本引擎实现毫秒级消息应答与数据桥接、以及基于 MCP 协议的 AI 助手（可根据 PDF 数据手册或源码自动生成配置与脚本）。功能清单覆盖串口/蓝牙串口、TCP、UDP、WebSocket、P2P 加密连接、MQTT（内置 Broker）、Modbus RTU/TCP（Master 与 Slave）、多种数据帧格式（AT、COBS、SLIP、JSON 自定义）、远程调试（基于 iroh 加密连接）、数据解析与实时曲线图/FFT，并支持 Windows、Linux、Android 及 headless 边缘节点部署。文末附有 GitHub 仓库、Windows 商店链接及 6 个 B 站视频教程。

💡 主要观点

  1. 核心创新在于 1 毫秒级高精度定时与 Lua 脚本驱动的自动应答。 ±0.5ms 的延时精度和每秒超 1000 次的数据收发能力，配合 Lua 脚本引擎，使工具能实现基于设备响应的毫秒级自动应答，解决了传统串口调试工具在高频交互场景下的痛点。
  2. MCP AI 助手降低了物联网调试的配置门槛。 用户可上传 PDF 数据手册、文档或 MCU 源码，AI 自动生成连接参数、消息模板和 Lua 脚本，将原本需要大量人工查阅手册和编写脚本的工作自动化。
  3. 功能覆盖全面，从协议到部署形成闭环。 支持串口、TCP、UDP、MQTT、Modbus 等主流协议，内置 Broker 和多种数据帧格式，并支持远程调试与 headless 边缘节点部署，覆盖了从开发调试到现场运维的全链路需求。

💬 文章金句

  • 软件最大的特点是支持 1 毫秒分辨率的延时，精度为 ±0.5 毫秒，可以基于循环发送功能实现每秒超过 1000 次的数据收发。
  • MCP 与 AI 助手，可以根据用户提供的 PDF 设备数据手册，文档，或者 MCU 下位机源码，配置连接参数，生成消息发送模板以及编写 Lua 调试脚本。
