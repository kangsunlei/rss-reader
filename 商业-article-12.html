AI 会议黑马驾到？Claude 和 Figma 也来卷|Product Hunt 精选 52

5/25/2026, 12:00:00 PM

📌 一句话摘要

本文精选了 Product Hunt 月榜中 10 款 AI 新产品，涵盖建站、会议笔记、内容创作、Agent 可靠性、硬件键盘等多个领域，并介绍了 Claude Code Routines 和 Figma for Agents 等重磅更新。

📝 详细摘要

文章是「随机小分队」出品的 Product Hunt 月榜精选，本期共介绍 10 款产品。头名 Brila 通过分析 Google Maps 评论为线下商家自动生成网站；Fathom 3.0 推出无机器人会议记录模式；ProdShort 将日常会议自动转化为短视频；Velo 提供 AI 演示视频制作与数字分身功能；Plurai 通过训练小模型实现低成本的 AI Agent 可靠性评估；Dune 是一款上下文感知的 Mac 三键实体键盘；NovaVoice 定位为桌面端语音操作系统；Clera 是 AI 人才招聘平台；Figma for Agents 通过 MCP 协议让 AI 直接操作 Figma 画布；Claude Code Routines 则提供了托管式的定时开发任务自动化。文章以产品介绍为主，信息密度高，但缺乏深度分析和独立观点。

💡 主要观点

  1. Product Hunt 月榜反映了当前 AI 产品创新的主要方向。 本期榜单覆盖了 AI 建站、会议效率、内容创作、Agent 可靠性、硬件交互和招聘等多个领域，展示了 AI 应用正在从通用工具向垂直场景深度渗透的趋势。
  2. Claude Code Routines 和 Figma for Agents 是本期最重磅的更新。 Claude Code Routines 提供了托管式的定时任务自动化，降低了开发者维护基础设施的负担；Figma for Agents 通过 MCP 协议让 AI 直接操作设计系统，解决了 AI 生成设计稿与团队规范脱节的核心痛点。
  3. AI 产品的核心价值在于解决特定场景的真实痛点。 从 Brila 的评论驱动建站到 Plurai 的低成本 Agent 评估，这些产品都针对明确的用户痛点提供了可落地的解决方案，而非追求通用性。

💬 文章金句

  • Brila 主要面向餐厅、美容院、诊所、健身房等有一定 Google Maps 评论积累的本地服务型商家。
  • Fathom 3.0 最具特色的是新推出的'无机器人捕获'模式，用户可按需选择纯转录、音频或视频录制方式，兼顾隐私与灵活性。
  • Plurai 的核心理念是'vibe-training'——用户只需用自然语言描述 Agent 应该做什么、不应该做什么，平台即可自动生成合成训练数据。
  • Figma for Agents 通过 MCP 工具，首次赋予 AI Agent 直接在 Figma 画布上写入的能力。
  • Claude Code Routines 是 Claude 最新推出的新功能，专为 PR 审查、Backlog 整理、部署验证、告警分诊等重复性开发工作流设计。
