OpenAI 发布 o3、o4-mini：首批使用图片思考的推理模型，会自主使用工具、评测继续刷榜

4/17/2025, 12:00:00 AM

📌 一句话摘要

OpenAI 发布具备图像思考和自主工具使用能力的新型推理模型 o3 和 o4-mini，性能显著提升。

📝 详细摘要

OpenAI 发布了两款新型 AI 推理模型：o3 和 o4-mini。o3 被认为是 OpenAI 最强大的推理模型，在数学、编程、推理、科学和视觉理解等方面均表现出色。o4-mini 则是一款更小巧、快速的模型，在价格、速度和性能之间实现了平衡。这两款模型都是 OpenAI 首批具备“图像思维”能力的模型，能将图像直接融入推理过程，并能自主使用 ChatGPT 工具，如网络浏览、代码执行和图像处理。o3 和 o4-mini 在多个基准测试中创下新纪录，效率也超越前代产品，同时验证了强化学习 scaling law。此外，OpenAI 还推出了 Codex CLI，一个可从终端运行的轻量级编码代理，旨在最大化模型的推理能力。本次发布是 GPT-5 发布前的最后独立模型，具有里程碑意义。

💡 主要观点

  1. o3 和 o4-mini 具备图像思考能力，提升了视觉推理能力。 这两款模型能够分析图像，并在推理过程中调整画面，从而更好地理解和处理视觉信息，例如分析图表或从有缺陷的照片中提取洞见。
  2. 模型能够自主使用工具，提高问题解决效率。 o3 和 o4-mini 可以访问 ChatGPT 工具，并根据问题自主选择和使用工具，例如搜索网络、编写代码和生成图表，从而快速生成详细的答案。
  3. 强化学习的 scaling law 在 o3 的开发中得到验证。 通过增加训练计算量和推理时的思考量，o3 的性能得到显著提升，验证了模型性能会随着思考时间的增加而持续进步的趋势。
  4. Codex CLI：终端推理工具 Codex CLI 是一个可以从终端运行的轻量级编码代理，旨在最大化 o3 和 o4-mini 等模型的推理能力，并即将支持 GPT-4.1 等更多 API 模型。

💬 文章金句

  • o3 和 o4-mini 可能是 ChatGPT 在 GPT-5 之前的最后独立 AI 推理模型。
  • o3 和 o4-mini 是其首批能够「用图像思考」的模型。
  • 通过重新探索扩展路径------这次是在强化学习领域------将训练计算量和推理时的思考量都提升了一个数量级，但依然能看到明显的性能提升，这验证了模型性能会随着思考时间的增加而持续进步。
