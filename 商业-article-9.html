Kora 产品负责人：如果 Agent 负责中间 80% 的工作，人还剩什么价值？丨 Every

📌 一句话摘要

本文通过「AI 三明治」模型，阐述了在 AI Agent 时代，人类的核心价值在于定义问题和打磨作品的两端，中间执行层可放心交给 AI。

📝 详细摘要

本文基于对 Kora 产品负责人 Kieran 播客内容的整理，深入探讨了在 AI Agent 能力日益增强的背景下，人类应如何重新定位自身价值。文章核心提出了「AI 三明治」模型：人类是两端的面包，负责开始阶段的定义问题、头脑风暴和结束阶段的打磨作品、提升质感；AI 是中间的馅料，负责执行、测试等中间环节。文章还介绍了 Compound Engineering 框架，强调通过系统性地沉淀经验让 Agent 持续进化。作者认为，人类的核心竞争力在于切换框架、做出判断、注入品味，这些是 Agent 难以替代的。最终建议是找到自己的「艺术时刻」，将精力集中在能带来独特价值的环节。

💡 主要观点

  1. AI Agent 时代，人类的价值在于「AI 三明治」的两端。 人类应在开始阶段定义问题、设定边界，在结束阶段打磨细节、注入品味，中间的执行层可放心交给 AI。
  2. Compound Engineering 的核心是系统性地沉淀经验。 通过 Planning、Work、Review、Compound 四步流程，将踩坑经验存入知识库，让 Agent 在下一次做得更好，避免重复错误。
  3. 人类的核心竞争力在于切换框架和做出判断。 Agent 可以执行具体方案，但选择哪个视角来解决问题、判断什么是值得解决的问题，需要人类基于对行业和用户的理解来完成。
  4. 工程师的角色正在向「产品工程师」转变。 工程师需要更关注产品而非仅关注代码，工作方式更接近管理者，在开始和结尾介入，而非全程盯着每一行代码。

💬 文章金句

  • AI 是三明治中间的馅料，人类是两端的面包。中间可以自动化，但开始和结尾需要人类的判断和品味。
  • 如果你在 review 过程中学到了什么，把这些知识存回系统，agent 下次就不会再犯同样的错误——这才是 Compound Engineering 最强大的部分。
  • 自动化测试说一切正常，但人类点进去看看，会觉得这里有点别扭，再调一下——这个时刻是让产品从能用变成好用的关键。
  • 如果你想让自己的作品有个性、有质感，就不能完全自动化一切。
  • 找到你的独特角度，然后用 agent 去放大这个角度，而不是让 agent 替你做所有事。
