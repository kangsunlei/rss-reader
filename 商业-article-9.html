使用 Gemini Code Assist Standard 和 Enterprise 编写代码

10/15/2026, 2:33:45 AM

📌 一句话摘要

本文介绍了如何在 VS Code 和 IntelliJ 中使用 Gemini Code Assist 进行代码生成、补全和转换，包括通过提示、注释、智能操作以及远程仓库上下文来提高开发效率。

📝 详细摘要

Gemini Code Assist 是一款 AI 赋能的协作工具，支持在 VS Code 和 IntelliJ 中进行代码编写。用户可以通过自然语言提示生成代码、获取行内补全、使用智能操作，并利用远程仓库上下文来获得更相关的建议。本文详细介绍了这些功能的具体操作步骤和注意事项。

💡 主要观点

  1. 代码生成与转换 用户可以通过在代码文件中添加注释或使用快速选择菜单中的 /generate 命令来提示 Gemini Code Assist 生成代码。生成的代码会显示在差异视图中，用户可以选择接受或拒绝这些更改。
  2. 代码补全与后续编辑预测 Gemini Code Assist 提供实时的行内代码补全，帮助用户快速编写函数。此外，后续编辑预测功能允许用户查看并接受对整个文件中的代码建议，而不仅仅是当前光标位置。
  3. 智能操作与上下文利用 用户可以通过选择代码块并点击智能操作图标来执行特定任务，例如生成单元测试。此外，通过将远程仓库作为上下文，Gemini Code Assist 可以提供更准确、更相关的代码建议。

💬 文章金句

  • Gemini Code Assist 会根据提示在差异视图中生成代码。
  • 若要接受 Gemini Code Assist 给出的代码建议，请按 Tab 键。否则，若要忽略建议，请按 Esc 键或继续编写代码。
  • 通过将远程仓库用作重点关注的上下文来源，您可以从 Gemini Code Assist 获得更准确、更相关的建议，这有助于您更快、更高效地编写代码。
