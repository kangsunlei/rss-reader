115. 对 OpenAI 姚顺雨 3 小时访谈：6 年 Agent 研究、人与系统、吞噬的边界、既单极又多元的世界

9/11/2025, 10:03:20 AM

📌 一句话摘要

OpenAI 研究员姚顺雨深入探讨 AI Agent 的六载研究，强调语言模型在泛化、推理中的核心作用，并展望人机交互、智能体生态的未来。

📝 详细摘要

本期播客特邀 OpenAI 研究员姚顺雨，围绕 AI 智能体（Agent）的构建、创新及对未来社会的深远影响展开深度对话。姚顺雨回顾了其从理论计算机科学转向语言智能体研究的历程，强调语言作为实现泛化最本质工具的重要性。访谈深入阐释了 Agent 的定义、其从符号主义到深度强化学习再到大语言模型驱动的三波演进，并指出当前 Agent 研究已进入“下半场”，核心挑战从模型和方法转向如何定义有价值的任务和环境。他着重强调了语言模型强大的推理能力是 Agent 实现泛化的关键，并探讨了提升 Agent 能力所需的长期记忆、内生奖励系统以及多智能体协作。此外，播客还讨论了代码环境作为实现通用人工智能（AGI）的重要场域，以及 AI 模型能力溢出背景下创业公司通过创新交互方式获取机遇的策略。最后，嘉宾展望了未来 AI Agent 生态的多元化发展，平衡安全与价值创造，并分享了对人与 AI 关系、机器意识及未来投资策略的独到见解。

💡 主要观点

  1. 语言模型是构建通用智能体（Agent）的核心，其推理能力是实现泛化的关键。 语言模型提供的强先验知识赋予 Agent 推理能力，使其能像人类一样在新环境中快速适应和解决问题，而非仅依赖特定任务的训练。
  2. Agent 研究已进入“下半场”，重点从模型和方法转向任务和环境的定义与设计。 随着通用方法的成熟，AI 研究的瓶颈在于如何设计有挑战性、有真实价值的任务，并构建清晰、基于结果而非过程的奖励机制。
  3. 交互方式创新是创业公司在 AI 模型能力溢出背景下的最大机遇。 面对 Super App 带来的路径依赖，创业公司应探索不同于传统或现有大厂的交互方式，结合模型能力创造独特价值，而非简单模仿。
  4. 代码环境是实现通用人工智能（AGI）的重要场域，为 Agent 提供了自然的闭环反馈机制。 代码作为 AI 与数字世界交互的“手”，提供可验证的执行结果反馈，有助于 Agent 学习和适应复杂多变的任务场景。
  5. 未来 AI Agent 的发展需要突破长期记忆和内生奖励系统，构建多元智能生态。 Agent 需具备自我探索和学习能力，理解复杂语境与内在激励，以实现更高智能与经济价值创造，并形成中心化与去中心化并存的生态。

  • 我觉得就是首先你要找一个足够有挑战的任务，然后这个任务能够做出有本质的新的方法。
