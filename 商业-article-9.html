Deno 就 Oracle 侵权 'JavaScript' 商标一案提起诉讼，主张其为通用名称，案件进入发现阶段。

📝 详细摘要

Deno 针对 Oracle 关于 'JavaScript' 商标的诉讼案件进入发现阶段。Deno 主张 'JavaScript' 是一个通用名称，而非 Oracle 的品牌。文章详细介绍了案件的背景、Deno 的立场以及接下来的法律程序。Deno 强调，如果成功撤销该商标，'JavaScript' 将不再受商标限制，成为自由使用的编程语言。此外，文章还提到了社区对 'JavaScript' 可能改名为 'WebScript' 或 'ECMAScript' 的讨论，包括改名可能带来的招聘和市场影响。

💡 主要观点

  1. Deno 主张 'JavaScript' 是通用名称，不应被 Oracle 商标化 Deno 认为 'JavaScript' 用于描述一种编程语言，而非品牌，它是世界上最流行的编程语言之一，不应由 Oracle 独占。
  2. 案件进入发现阶段，Deno 期待 Oracle 的回应 Oracle 必须在 8 月 7 日前对 Deno 的撤销请求做出回应，Deno 期待看到 Oracle 如何反驳关于商标通用性和放弃的主张。
  3. 社区讨论 'JavaScript' 可能改名为 'WebScript' 或 'ECMAScript' 有人提议将 'JavaScript' 更名为 'WebScript' 以避免商标问题，但也有人担心这会引起混淆或不被广泛接受，特别是在招聘和市场推广方面。

💬 文章金句

  • Deno 强调，大家都知道 JavaScript 并不是甲骨文的产品，截至目前，有 19，550 人支持这一观点（在 javascript.tm 网站上）。
  • 如果 Deno 赢得了这一撤销请求，或者甲骨文做出正确的决定，放弃该商标，那么 JavaScript 将会自由，不再有商标符号（™），也不再有许可的担忧。
  • 有人提议将 JavaScript 更名为'WebScript'，因为这个名字更符合 Web 技术栈，并且没有商标问题。
