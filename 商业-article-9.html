📌 一句话摘要

推文介绍了一款通过 MCP 协议连接 Framer 与 AI Agent 的第三方插件，支持通过对话分析和修改设计稿。

📝 详细摘要

作者分享了一个 Framer 的第三方 MCP (Model Context Protocol) 插件，该插件实现了 Framer 与 coding agent 的深度连接。它能够分析项目的全局信息，并允许用户通过 AI 指令（“靠嘴”）直接修改设计稿内容。作者认为这极大提升了设计效率，解决了 Framer 与 AI 协作的场景痛点，并对官方尚未提供此类功能感到意外。
