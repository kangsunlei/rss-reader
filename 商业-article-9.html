ChatGPT 与 Codex 负责人：面向普通人的 Agent 已经来了丨 SV Girl

5/25/2026, 12:58:00 PM

📌 一句话摘要

OpenAI 产品负责人 Tibo 在访谈中详细阐述了 Agent 技术已成熟到可供普通人使用，并提供了从资料整理、权限设置到工作流部署的具体行动指南。

📝 详细摘要

本文是对 OpenAI 负责 ChatGPT、Codex 和 API 的产品负责人 Tibo 访谈的深度总结。Tibo 认为，Agent 技术已经跨越了需要技术背景的门槛，未来半年内将深刻改变所有知识工作者的工作方式。文章核心围绕「普通人如何开始使用 Agent」展开，拆解为五个关键步骤：准备个人资料库（如过往样稿和项目文件）、理解权限与安全边界（如自动审核机制）、明确人类责任（不能将理解外包）、从低风险工作流起步（如邮件整理、每日简报），以及认识到 Vibe Coding 的局限（原型可行，规模化仍需工程判断）。Tibo 还预测，随着 Agent 能操作电脑和浏览器，软件需求将爆发，工程师的角色将从编码转向系统设计与架构判断。文章最后强调，Prompt 红利将退潮，未来 AI 的使用将更接近自然对话，而人的核心能力在于清晰表达真实处境、目标和判断。

💡 主要观点

  1. Agent 技术已成熟，普通人无需技术背景即可使用。 Tibo 指出，Agent 已能在长时间内保持可靠，并能接入 Gmail、日历、文档等常用工具，门槛已从配置调试降至应用层，每个人都能从中获益。
  2. 部署 Agent 应从准备个人资料库和低风险任务开始。 建议从过往样稿和项目文件入手，让 Agent 了解你的语气和背景。先从每日简报、邮件整理、市场研究等低风险、有明确输入输出的任务开始，逐步扩大权限。
  3. 人类仍需为 Agent 的行为负责，不能将理解外包。 Tibo 强调，AI 可以辅助完成报税、写代码等任务，但最终承担结果的是人。代码出错不能归咎于 Agent，评审问题也不能推卸责任，人类必须保留最终判断权。
  4. Vibe Coding 适合验证想法，但规模化仍需工程判断。 非技术人员可以用 AI 快速做出原型，但扩展到服务几十万用户时，架构、可维护性和可靠性问题仍需专业工程师介入。未来 6-9 个月 AI 在代码维护性上会有进步，但完全无需技术背景仍很遥远。
  5. 软件需求将因 Agent 而爆发，工程师角色将发生转变。 当每个人都能将想法转化为软件形态，基础设施和应用数量会爆炸。工程师的工作重心将从编码转向系统理解、架构判断、调试和业务沟通，只懂写代码的工程师将面临风险。

💬 文章金句

  • 每个人都会在电脑上拥有一个小小的个人助理，让你做到三个月、六个月前做不到的事。
  • 今天你必须主动提示、创造性地提问；未来，不会再这样。
  • 人类依然要负责，不能把理解外包出去。
  • 如果谈知识工作者的生产力，语气样本是一个好文件；我不建议解释你的语气，我建议直接放过往样稿。
  • 未来，它会更像从朋友那里得到好建议，或者像我们现在这样自然对话。
