The Era of Agent：拾象 AGI 投资洞察

5/8/2026, 12:03:00 PM

📌 一句话摘要

本文是拾象投研团队对 2026 年 AGI 领域的深度投资洞察，核心观点是 Coding Agent 已成为科技史上增速最快的新物种，并推动 AI Labs 进入战略与组织文化竞争的新阶段。

📝 详细摘要

本文是拾象投研团队发布的 2026 年 AGI 投资洞察报告。报告指出，以 Coding Agent 为代表的新物种正以史无前例的速度增长，预计 2026 年 AI Coding 创造的 ARR 将突破 1000 亿美元。文章深入分析了 Anthropic、OpenAI、Google 三家头部 AI Labs 的战略选择与组织文化差异，认为在模型训练没有 secret sauce 的当下，组织和战略文化才是竞争的关键。报告还提出了「Agent-native」的新投资框架，认为市场坐标系应从 To B/To C 转向 To Human/To Agent，并探讨了 Agent 作为独立经济主体的趋势。此外，文章还覆盖了机器人数据 Scaling、World Model 技术路线、以及 Neo Labs 等前沿趋势。

💡 主要观点

  1. Coding Agent 是科技史上增速最快的新物种，预计 2026 年 AI Coding ARR 将突破 1000 亿美元。 Coding Agent 的爆发式增长标志着 AI 从 Chat 模式向 Agent 模式的跃迁，其重要性堪比信息流推荐中的「抖音」级别机会，是当前所有头部 AI Labs 的共识和重注方向。
  2. 模型训练没有 secret sauce，组织和战略文化才是 AI Labs 竞争的核心壁垒。 Anthropic 在 Coding 上的领先并非源于技术秘密，而是其从 Day 1 就坚持的「数据决定一切」的组织基因和战略聚焦。相比之下，OpenAI 和 Google 因战略误判而暂时落后。
  3. Agent 正成为数字世界新的消费者与生产者，投资框架需转向「Agent-native」。 市场正在为 Agent 重构基础设施（如 Stripe 提供支付、Cloudflare 允许 Agent 开户），Agent 已开始以独立身份发起交易和消耗资源。投资判断需从 To B/To C 的旧地图转向 To Human/To Agent 的新标尺。

💬 文章金句

  • AI 第一次开始系统性地加速 AI 自己，这是进入 2026 年最重要的结构性变化。
  • 在全新范式出现之前，模型训练没有 secret sauce，组织和战略文化才是。
  • Anthropic 是一家 AGI-native 的公司，内部员工几乎全员信奉 AGI 会实现。
  • Agent 自身也在成为数字世界新的消费者与生产者。
  • 要做好 Coding，真正的难度不在技术 know-how 层面，而在组织与战略层面。
