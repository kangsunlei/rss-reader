Andrej Karpathy YC 孵化器万字洞察：软件 3.0 时代创业机会，钢铁侠战衣是人与 agent 协作终极形态

6/24/2025, 1:40:00 AM

📌 一句话摘要

Andrej Karpathy 分享软件从 1.0 到 3.0 的演进，强调大模型重塑开发范式和 Agent 时代的创业机会。

📝 详细摘要

文章基于 Andrej Karpathy 在 YC AI Startup School 的演讲，系统梳理了软件范式从手写代码（1.0）、训练模型（2.0）到自然语言编程（3.0）的演变。他将大型语言模型比作新型操作系统或公共基础设施，分析了其特性与局限性。文章重点探讨了 AI Agent 时代的产品设计方向，提出“部分自治型应用”、“自主性滑块”和“人类在环”的关键概念，并以 Cursor、Perplexity 等产品为例。Karpathy 强调自然语言编程（vibe coding）将降低开发门槛，人人都是程序员成为可能。最后，他展望了为 Agent 设计软件系统和 Web 交互接口的必要性，认为人机协作的“钢铁侠战衣”是未来产品的终极形态。

💡 主要观点

  1. 软件开发正经历从 1.0 到 3.0 的范式巨变 软件从手写代码（1.0）到训练权重（2.0），再到使用自然语言 prompt 编程 LLM（3.0），大幅降低了编程门槛，颠覆了传统开发模式。
  2. 大模型像新型操作系统，具有独特心理机制 LLM 集计算、内存、调度于一体，但表现出“数字雨人”与“糊涂虫”并存的特性，且记忆短暂，需要人工管理其上下文。
  3. “部分自治型应用”是 Agent 时代核心机会 未来产品应设计 GUI、自主性滑块和人类在环机制，平衡 AI 效率与可控性，实现人机高效协作，而非追求全自主 AI。
  4. 自然语言编程将催生“人人都是程序员”的时代 Vibe coding 等自然语言交互方式让不懂代码的人也能进行软件创作，极大地释放了大众的创造力和开发者潜力。
  5. 未来的软件系统和 Web 需适配 AI Agent 需要建立面向 Agent 的标准化接口和数据结构（如 llm.txt），降低 Agent 交互成本，使其成为数字世界的第一类信息公民。

💬 文章金句

  • 他指出，软件正在进入一个快速重写与结构重构的时代，而这场变革的核心动力正是大型语言模型的兴起。
  • 因此可以将三代软件的演进总结为： * 软件 1.0：用代码编程计算机； * 软件 2.0：用权重参数"编程"神经网络； * 软件 3.0：用英文 prompt 编程语言模型。
  • 最合适的类比对象是"操作系统"。语言模型并非像电、水那样的静态商品，而是一个日益复杂、具备平台属性的技术栈。
  • 最令人着迷的，是大型语言模型颠覆了技术扩散的历史路径。
  • 理想产品应是人机共驾的"智能战衣"，而非全自主的"AI 机器人"。
