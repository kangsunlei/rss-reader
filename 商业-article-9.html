ChatGPT 将迎来史上最大改版，“AI 只用来聊天的时代结束了”

6/7/2026, 11:17:00 AM

📌 一句话摘要

OpenAI 计划将编程工具 Codex 整体并入 ChatGPT，将其重塑为能编写代码、管理日程、操控软件的超级应用，标志着 AI 从聊天工具向智能体平台的战略转型。

📝 详细摘要

文章基于《金融时报》独家消息，报道 OpenAI 正对 ChatGPT 进行自 2022 年推出以来最大规模改版，核心是将增长最快的编程工具 Codex 并入 ChatGPT，并接入外部合作伙伴应用。文章从战略意图、技术基础、竞争压力、商业逻辑四个层面展开：OpenAI 高管认为 AI 的未来在于替用户执行任务的智能体，而非简单对话；底层模型 GPT-5.5 的升级使 Codex 能独立执行复杂多步骤任务；Anthropic 的 Claude Code 在编程能力上曾领先 OpenAI，直接促使 OpenAI 火速组建 Codex 团队并调整组织架构；IPO 在即，OpenAI 需要将 Codex 推向 9 亿消费级用户以撬动付费意愿。文章还提及 Codex 桌面应用推出后用户基数两个月增长六倍、周活跃用户突破 500 万等数据，以及 OpenAI 搁置 Sora 等消费者业务、集中资源投向企业客户的具体取舍。

💡 主要观点

  1. ChatGPT 将从聊天工具转型为超级应用，核心是整合编程工具 Codex。 OpenAI 计划将 Codex 整体并入 ChatGPT，并接入外部合作伙伴应用，使其能编写代码、管理日程、操控软件，成为替用户执行任务的智能体平台。
  2. 底层模型 GPT-5.5 的升级是 Codex 能力跃升的关键推动力。 GPT-5.5 在处理长期、多步骤任务时明显优于前代，不再需要频繁人工指导，使 Codex 在拿到清晰指令后能独立执行，开发者信任度随之提升。
  3. Anthropic 的 Claude Code 领先是 OpenAI 加速整合的直接诱因。 2024 年秋季 Anthropic 编程能力已领先 OpenAI，2025 年 2 月发布 Claude Code 预览版后，OpenAI 火速组建 Codex 团队并调整组织架构，将 ChatGPT、Codex 和 API 团队合并。
  4. IPO 在即，OpenAI 需要将 Codex 推向 9 亿消费级用户以撬动付费意愿。 Codex 用户多为付费订阅用户，变现效率高。OpenAI 搁置 Sora 等消费者业务，集中资源投向企业客户，目标是上市前将收入数据做得更扎实。
  5. 直接编写代码比模拟人类操作浏览器更高效，Codex 被提升为通用智能体核心。 OpenAI 曾推出 Operator 尝试让 AI 模拟人类在浏览器中操作，但效率太低。高管层认为直接编写代码才是更有效的方式，这与 Anthropic 从 Claude Code 走向 Claude Cowork 的路径一致。

💬 文章金句

  • AI 仅用于聊天的时代已经结束了。
  • 有了能帮你在电脑上做任何事情的智能体，接下来的目标是把这套能力推给每一个人。
  • 到了 GPT-5.5，Codex 的优势已经大到不容忽视。
  • 直接编写代码，才是 AI 在电脑上完成诸如构建复杂电子表格等任务的更有效方式。
  • 习惯了免费的「闲扯」、聊天的数亿消费者，最终是否愿意为了一个能替自己干活、帮自己赚工资的数字智能体掏钱？
