Vibe Coding 产品最大的错觉，是以为自己真的有护城河

11/25/2025, 12:36:00 PM

📌 一句话摘要

Base44 创始人 Maor Shlomo 深度剖析 AI 产品“护城河”的错觉，强调垂直整合、大厂威胁、软件液态化趋势及 AI 创业的增长与投资策略。

📝 详细摘要

文章通过对 Base44 创始人 Maor Shlomo 的访谈，深入探讨了 AI 产品，特别是 Vibe Coding 工具的"护城河"问题。Shlomo 指出，Vibe Coding 工具极易被复制，真正的壁垒在于构建功能完备、能处理复杂业务场景的"垂直整合"平台，实现"最后一公里"的交付。他认为，AI 初创公司的技术护城河几乎不存在，真正的威胁来自拥有全栈资源的大型科技公司，如 Google。文章还预测未来软件将"液态化"，Vibe Coding 将吞噬传统 SaaS 市场，定制化和数据私有化将成为趋势。在投资方面，Shlomo 建议 AI 创业公司应专注于增长和抢占市场，利润率会随小模型和开源模型的普及而改善；同时，应投资"不性感"的传统行业和垂直整合的业务，而非纯 Agent 公司，因为这些功能容易被模型厂商商品化。访谈还分享了 Base44 被 Wix 收购的背后思考，强调了通过合作加速成功的策略。

💡 主要观点

  1. Vibe Coding 工具易复制，真正的护城河在于“垂直整合”的平台能力 构建一个能处理复杂业务、提供深层集成和基础设施的“迷你云”平台，帮助用户“走完最后一公里”，才是难以复制的壁垒。
  2. AI 初创公司的技术护城河薄弱，大厂是真正的威胁 模型提供商和拥有全栈资源（如算力、数据、云服务）的巨头（如 Google）一旦下场，能够迅速复制并吞噬市场，对中间平台构成巨大挑战。
  3. 未来软件将“液态化”，Vibe Coding 会吞噬传统 SaaS 市场 软件将变得更具定制性，用户能通过 Vibe Coding 生成完全符合自身需求、无功能臃肿的版本，掌握代码和数据所有权，淘汰传统“一刀切”的 SaaS 模式。
  4. AI 创业核心任务是增长和抢占市场，利润率问题会随小模型普及改善 在模型价格持续下降的背景下，通过智能路由选择更便宜的小模型和开源模型，能大幅改善利润率，当前重点在于获取更多用户和市场份额。
  5. 投资应聚焦“不性感”的传统行业和垂直整合业务，而非纯 Agent 公司 纯 Agent 功能容易被模型厂商商品化，而深入金融、餐饮、医疗等传统行业，构建端到端的 AI 业务，才能形成真正的壁垒和价值。

💬 文章金句

  • 现在前沿的 AI 创业公司最大的错觉是什么？以为自己真的有护城河。
  • 我认为做一个 Vibe Coding 工具相对容易，但是打造一个能构建「真实商业软件」的平台，功能完备、且能扛得住复杂业务场景，非常非常难。
  • 技术护城河几乎不存在，真正的威胁来自大厂。
  • 未来软件都会变得「液态化」，Vibe Coding 会吞掉传统 SaaS 软件。
  • 你需要在那些很难被复制的地方下大注。
