Codex 不限时了，我先删掉了一堆 Skills｜附 GPT-5.6 官方指南

7/13/2026, 9:12:00 AM

📌 一句话摘要

OpenAI 与 Anthropic 取消 Codex 使用额度限制，GPT-5.6 更强但 Token 消耗激增，官方指南提示先明确结果、设定边界并提供验收标准，以高效、低风险地使用新模型。

📝 详细摘要

文章报道 Codex 取消 Plus、Business、Pro 用户每 5 小时限制后，GPT-5.6 的使用出现 Token 消耗异常高的问题。通过真实案例和用户反馈，作者说明新模型在更强能力下需要更谨慎的提示词设计：先描述期望的结果，只提供对交付必要的背景，明确边界并加入验证步骤，避免冗长步骤导致的 Token 浪费。官方指南强调简洁聚焦结果、控制背景信息、设定可验证的输出标准，帮助用户在不超额度的前提下发挥模型潜力。

💡 主要观点

  1. GPT-5.6 的推理能力提升导致 Token 消耗显著增加，使用 Skills 会进一步膨胀上下文。 GPT-5.6 在复杂任务（如 3D 网页生成）中可持续数小时运行，导致 Token 消耗远超预期；Superpower、Agent 等外部 Skills 在模型内部被调用后会额外占用上下文，使思考时间变长、Token 消耗异常高。
  2. 官方指南建议先描述结果，只提供对交付必要的关键背景信息。 指南明确要求先写明要得到的最终输出，随后补充对结果产生影响的背景，避免冗长的步骤说明；提示词应聚焦于最终成果，必要时加入验证标准，以显著降低模型的思考时间和 Token 消耗。
  3. 提示词的边界与验收规则是防止模型跑偏的关键。 通过限定可使用的数据源、预算、时间等约束，并在提示词末尾加入明确的验证要求（如检查行动项负责人、核对数据一致性），能够显著提升任务的可靠性和效率，防止模型越界或错误发送未审阅的内容。
