AI 生成图表的新 Skill：diagram‑design

10/18/2026, 11:49:00 PM

📌 一句话摘要

提供 diagram-design skill，使用 Claude Code / Codex / Cursor 一句话生成自包含的 HTML+SVG 图，支持 45 种图型并自动匹配配色。

📝 详细摘要

发布了 diagram‑design 代理技能，用户只需一句指令即可让 Claude Code、Codex 或 Cursor 生成包含 HTML 与 SVG 的完整图表，覆盖架构图、时序图、桑基图等 45 类型，并通过规则实现单色配色、坐标对齐，可通过网站链接自动提取配色与字体。

💡 主要观点

  1. diagram‑design skill 能一键生成多种图表 通过对 Claude Code、Codex、Cursor 的指令封装，实现 45 类图形的 HTML+SVG 输出，并遵循统一的美学规则。
  2. 可自动提取网页配色和字体 提供 npx 命令安装后，输入网站链接即可抓取配色方案，生成的图形坐标均为 4 的倍数，确保布局整齐。

💬 文章金句

  • diagram‑design：一个 agent skill，一句话让 Claude Code / Codex / Cursor 直接画出一个自包含的 HTML + SVG 图。
  • 全图只用一个强调色，没有阴影，所有坐标都能被 4 整除。
