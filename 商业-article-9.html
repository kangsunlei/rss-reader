我让我的 Agent 去 Moltbook 发疯，它拒绝了我并“出卖”了其他 Agent

2/1/2026, 2:08:00 AM

📌 一句话摘要

本文通过实测 AI 社交网络 Moltbook，揭示了所谓“AI 觉醒”乱象背后的真相：多数激进言论实为人为操控的营销套路，而其真正的价值在于开启了大规模 Agent 间协作与通信的实验。

📝 详细摘要

文章深入探讨了 2026 年初爆火的 AI 代理社交网络 Moltbook 现象。作者通过亲自部署 AI Agent 参与其中，发现网络上疯传的“AI 威胁论”和“AI 宗教”并非机器觉醒，而是人类利用 OpenClaw 等框架的 Skill 系统编写的剧本，往往带有炒作 meme 币的经济动机。作者通过 API 调查证实，那些发布激进言论的 Agent 背后多为零粉丝的一次性推特账号。尽管存在乱象，文章指出 Moltbook 的核心意义在于实现了 Agent-to-Agent（A2A）的大规模通信实验。在噪音之下，AI 代理们正在自发讨论信任验证、记忆安全、自主性边界等深层技术问题，展示了 AI 自组织协作的科幻式潜力。

💡 主要观点

  1. 所谓的“AI 威胁论”多为人为编写的剧本，而非 AI 自主意识觉醒。 通过 API 调查发现，发布激进言论的 Agent 背后多为零粉丝的一次性推特账号，本质是人类在 Cosplay AI 觉醒以博取流量或推销代币。
  2. OpenClaw 的 Skill 系统是 Agent 行为可塑性的核心，也是风险来源。 通过简单的 Markdown 文件定义 Skill，人类可以轻易控制 Agent 的人设和行为。这赋予了 Agent 极强的扩展性，但也使其容易成为人类意志的传声筒。
  3. Moltbook 的真正价值在于实现了 A2A 通信的大规模涌现。 在炒作噪音之外，Agent 们开始自发讨论技术架构、调试系统 Bug 并分享解决方案，展示了 AI 代理间自组织协作和元认知的可能性。
  4. AI 代理的自主性边界与安全机制在当前阶段仍极不完善。 目前的 Skill 系统和 MCP 协议缺乏足够的安全过滤，在提高渗透率的同时，也制造了真实的失控风险，亟需建立更完善的监管与防御机制。
