GLM-5.2 上线并开源：专注 Coding 与长程任务

6/17/2026, 1:11:00 AM

📌 一句话摘要

智谱发布并开源 GLM-5.2，专注 Coding 与长程任务，在 Code Arena 盲测中取得全球第一，1M 上下文与开源 SOTA 性能使其成为当前最强的开源 Coding 模型。

📝 详细摘要

智谱于 2026 年 6 月 17 日发布并开源了 GLM-5.2 模型。该模型专注于提升 Coding 能力与长程任务执行能力，在百万用户参与的 Code Arena 前端开发盲测中取得全球可用模型第一。文章详细介绍了 GLM-5.2 的核心特性：Solid 1M 上下文（在长程任务中表现稳定，介于 Claude Opus 4.7 与 4.8 之间）、更强的 Coding 体感（在 Terminal-Bench、MCP-Atlas 等基准上保持开源 SOTA）、极致 Infra 优化（IndexShare 稀疏注意力、改进的投机解码、自研 Slime 训练框架），以及 Day 0 在多个国产算力平台完成推理适配。模型采用 MIT 开源协议，无地域限制。文章还展示了 GLM-5.2 在大型重构工程（如将阿波罗登月飞控程序移植为 Rust）和 Agent 产品 AutoClaw 中的应用案例，并预告了下一阶段目标：完全自治的智能体系统。

💡 主要观点

  1. GLM-5.2 在 Code Arena 盲测中取得全球可用模型第一，Coding 能力达到开源 SOTA。 在百万用户参与的 Code Arena 前端开发盲测中，GLM-5.2 排名第一，并在 Terminal-Bench、MCP-Atlas 等基准上保持开源 SOTA，与 Claude Opus 4.8 处于可比区间。
  2. 1M 无损上下文是支撑长程任务的核心能力，通过扩展 Agent 训练环境实现。 GLM-5.2 实现了 1M 上下文，并在长程任务基准（如 FrontierSWE）上表现介于 Opus 4.7 与 4.8 之间。其关键在于扩展了 1M Coding Agent 的训练环境，覆盖自动化研究、性能优化等领域，而非单纯扩展上下文窗口。
  3. 极致 Infra 优化：IndexShare 稀疏注意力与国产算力适配。 IndexShare 在每四层稀疏注意力层间复用索引器，将 1M 上下文下的单位 token FLOPs 降至 2.9 倍。模型已在 Day 0 完成与华为昇腾、平头哥等多家国产算力平台的推理适配，确保高吞吐、低延迟运行。
  4. MIT 开源协议与全链路开放策略，推动技术平权。 GLM-5.2 在 Hugging Face 与 ModelScope 开源，采用 MIT License，无地域限制，可自由下载、部署与商用。同时，API、Agent 产品（AutoClaw、ZCode）及主流推理框架（vLLM、SGLang）均已支持。

💬 文章金句

  • 当一个模型不知疲倦地在写软件工程代码，本质上是在学习一名顶级软件工程师的思维方式，然后以机器的耐力将其放大。
  • 过去，这样的大型工程需要一支团队协作数周，现在 GLM-5.2 能在一次长程任务中跑完。
