LangChain 和 LangGraph 智能体框架达到 v1.0 里程碑

10/22/2025, 3:28:47 PM

📌 一句话摘要

LangChain 和 LangGraph 达到 v1.0 里程碑，引入简化的 LangChain，利用中间件加速智能体开发过程，以及用于持久、高度可控的 AI 智能体的可用于生产环境的 LangGraph...

📝 详细摘要

本文宣布了 LangChain 和 LangGraph 的 v1.0 版本发布，这是构建 AI 智能体的两个关键开源框架。LangChain 1.0 专注于通过新的 `create_agent` 抽象来简化智能体创建，从而能够使用任何模型提供商进行快速开发。它引入了“中间件”，用于在智能体循环中进行细粒度控制和自定义，以及用于与模型提供商无关的模型输出的标准化内容块。软件包的功能范围也得到了简化，将旧版功能移动到 `langchain-classic`。LangGraph 1.0 是一个较低级别的框架，专为生产级、长期运行的智能体而设计，提供持久状态、内置持久性和人机协作模式等功能。文章强调，LangChain 智能体基于 LangGraph 构建，确保了可组合性和灵活性，方便开发者从使用高级特性过渡到自定义工作流程。重新设计的文档站点统一了 Python 和 JavaScript 的资源。

💡 主要观点

  1. LangChain 1.0 通过 `create_agent` 和中间件简化了 AI 智能体开发，从而能够更快地实现，并提供更强的自定义能力。 新的 `create_agent` 抽象简化了智能体构建，而中间件为开发人员提供了对智能体执行流程的细粒度控制，使其能够适应各种用例。
  2. LangGraph 1.0 提供了一个强大的、较低级别的框架，用于构建生产就绪、持久且高度可控的 AI 智能体系统。 持久状态、内置持久性和人机协作模式等关键功能解决了生产环境中可靠且长期运行的智能体应用程序的关键需求。
  3. 这些框架被设计为可以无缝组合，使开发人员可以根据需求的变化从高级 LangChain 过渡到细粒度的 LangGraph 控制。 这种架构协同作用确保了开发人员不会被锁定在一种方法中，从而提供了灵活性，可以在同一生态系统中利用 LangChain 的快速原型设计和 LangGraph 的高级自定义。

💬 文章金句

  • LangGraph 1.0 通过强大的基于图的执行模型解决了这些差距，并为可靠的智能体系统提供了生产就绪的功能。
