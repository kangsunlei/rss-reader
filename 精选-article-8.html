Nemotron 3 Super 发布：用于智能体推理的开源混合 Mamba-Transformer MoE 模型

3/11/2026, 3:18:39 AM

📌 一句话摘要

NVIDIA 推出 Nemotron 3 Super，这是一款拥有 120B 参数的混合 Mamba-Transformer MoE 模型，具备 1M 上下文窗口和创新的 Latent MoE 架构，专为智能体推理而优化。

📝 详细摘要

Nemotron 3 Super 是一款总参数量为 120B（激活参数 12B）的模型，旨在解决多智能体系统中的“思考税”和“上下文爆炸”问题。它采用了独特的混合骨干网络，结合了用于提升序列效率的 Mamba-2 层和用于精确召回的 Transformer 注意力机制。核心创新包括 Latent MoE（潜空间混合专家），它通过压缩 Token 使得在相同计算成本下可调用 4 倍数量的专家；以及多 Token 预测 (MTP)，用于增强推理和投机采样。值得注意的是，该模型采用 NVFP4 原生预训练，针对 NVIDIA Blackwell 进行了优化。NVIDIA 已将该模型作为完全开源资源发布，包括权重、25 万亿 Token 的预训练数据以及完整的训练配方。

💡 主要观点

  1. 混合 Mamba-Transformer 骨干网络平衡了序列效率与精确的关联召回。 通过交替使用具有线性时间复杂度的 Mamba-2 层和具有高保真检索能力的 Transformer 注意力机制，该模型在维持实用的 1M Token 上下文窗口的同时，不会丢失寻找特定事实的能力。
  2. Latent MoE 架构在不增加计算开销的情况下实现了更细粒度的专家专业化。 在路由之前将 Token 嵌入投影到压缩的潜空间中，使模型能够以相同的成本咨询 4 倍数量的专家，从而为 Python 语法或 SQL 逻辑等多样化任务提供专门的专家支持。
  3. 多 Token 预测 (MTP) 提高了逻辑连贯性，并通过内置的投机解码加速了推理。 训练模型同时预测多个未来的 Token，迫使其内化长程依赖关系，从而带来更好的思维链推理能力，并在结构化生成任务中实现高达 3 倍的加速。
  4. 原生 NVFP4 预训练在保持高精度的同时，针对下一代硬件优化了模型。 与训练后量化不同，原生 4 位浮点训练确保模型从一开始就在算术限制内保持稳定，显著降低了显存需求，并加快了在 NVIDIA Blackwell 上的推理速度。
  5. 完全开放的生态系统为开发者提供了定制所需的权重、数据集和配方。 NVIDIA 发布了 25 万亿 Token 的预训练数据和 4000 万个训练后样本，允许研究人员复现训练流程，或针对特定领域的智能体应用调整混合架构。

💬 文章金句

  • 多智能体系统生成的 Token 数量是标准对话的 15 倍……这种“上下文爆炸”会导致目标漂移，即智能体逐渐失去对齐。
  • Latent MoE 使模型能够以运行一个专家的相同计算成本咨询 4 倍数量的专家。
  • 预测多个未来的 Token 迫使模型内化更长程的结构和逻辑依赖关系。
  • Super 从第一次梯度更新开始就以降低的精度进行原生训练，这意味着模型学会了在 4 位算术限制下保持准确。
  • Nemotron 3 Super 在完整测试套件 [PinchBench] 中得分为 85.6%，使其成为同类产品中表现最好的开源模型。
