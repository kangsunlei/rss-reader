什么时候 Agent 能自己写 skill？

3/30/2026, 2:03:00 PM

📌 一句话摘要

本文深度综述了 AI Agent 技能（Skill）从手动打磨向自主发现、封装组合及持续进化的演进历程，并系统梳理了 2025-2026 年间学术界与工业界在 Agent 技能生命周期管理上的核心突破。

📝 详细摘要

文章探讨了 AI Agent 领域的核心瓶颈：如何让 Agent 自主获取并优化专业技能。作者回顾了从 1999 年强化学习理论到 2023 年 Voyager 开启「技能即代码」时代的跨越，重点分析了 2025 年 Anthropic 发布 Agent Skills 标准后的技术爆发。内容涵盖了技能发现的三种路径（好奇心、失败、需求驱动）、技能组合的挑战（嵌套崩溃与模型能力瓶颈）、以及技能进化的前沿方案（如 EvolveR 的闭环自进化）。最后指出，Agent 技能正从学术兴趣转向工程化落地，成为一种可复用、可传承的知识基础设施。

💡 主要观点

  1. 技能形态的转变是 Agent 进化的关键拐点。 技能从不可解释的神经网络权重矩阵转向可读、可编辑、可迁移的代码（如 JavaScript 函数），使得知识的积累、检验与传播成为可能。
  2. 技能发现已形成好奇心、失败和需求驱动三条成熟路径。 EXIF 通过环境探索发现技能，EvoSkill 通过分析失败原因定向修复，CASCADE 则在处理专业任务时按需自主学习工具用法。
  3. 技能组合是当前 Agent 走向复杂的工程瓶颈。 单步原子技能已相对成熟，但多层层级嵌套会导致错误率指数级累积，弱模型在组合时容易因边界条件失控而崩溃。
  4. 技能进化正在实现从「外挂经验库」到「模型策略升级」的闭环。 通过对比分析（AutoRefine）或自蒸馏结合强化学习（EvolveR），Agent 不仅能优化外部技能文件，还能进化模型本身的推理策略。

💬 文章金句

  • Agent 不是变聪明了才学会 skill，而是 skill 变得可读了，才能被积累、检验、传播。
  • 发现原子级 skill 不是瓶驳，组合才是。
  • 零件都好使，装到一起就崩了。
  • 进化的过程本身就包含管理，淘汰劣质经验、合并冗余经验、持续校准评分，这些不是进化之外的维护工作，而是进化机制的一部分。
