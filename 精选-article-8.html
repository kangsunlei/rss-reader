Katelyn Lesse – Anthropic：为 AI 代理优化 Claude API

12/4/2025, 8:15:01 PM

📌 一句话摘要

Anthropic 详细介绍了 Claude 的 API 如何演进，通过利用模型能力、管理上下文，并为 AI 代理提供基础设施，从而帮助开发者构建强大的 AI 代理系统。

📝 详细摘要

Anthropic 的 Claude 开发者平台团队负责人 Katelyn Lesse 概述了他们的策略，旨在演进 Claude 的 API 以支持强大的 AI 代理开发。她提出了三个核心支柱：首先，通过例如用于控制推理时间的“思考预算”和可靠的自定义工具使用等功能，最大化 Claude 的固有能力；其次，使用模型上下文协议 (MCP) 、客户端内存工具和上下文编辑来优化上下文窗口管理，确保 Claude 在正确的时间访问最相关的信息；第三，为自主代理操作提供基础设施。该基础设施包括一个安全的沙盒化代码执行环境，Claude 可以在其中编写和运行代码，以及“代理技能 (Agent Skills)”，即特定领域的脚本和指令文件夹，使 Claude 能够更独立和有效地运行。这个平台演进旨在使开发者能够构建高性能和复杂的代理系统，例如他们内部的 Claude 代码产品。

💡 主要观点

  1. Anthropic 正在通过“思考预算”和工具使用等 API 功能来增强 Claude 的核心能力。 通过公开允许开发者控制 Claude 的推理时间并集成自定义工具的功能，Anthropic 使代理能够更有效地处理复杂问题并可靠地与外部系统交互。
  2. 有效的上下文窗口管理对于最大化 Claude 在代理系统中的性能至关重要。 诸如模型上下文协议 (MCP) 、客户端内存和上下文编辑等工具可确保 Claude 的有限上下文窗口仅包含最相关的信息，从而显著提高响应质量和效率。
  3. 通过安全的代码执行和代理技能 (Agent Skills) 为 Claude 提供“一台计算机”，可以赋能更自主和有能力的代理。 Anthropic 的基础设施允许 Claude 在沙盒环境中编写和运行代码，并利用特定领域的“代理技能 (Agent Skills)”（脚本、指令、资源），将其转变为一个非常有能力和自我操作的代理。
