今夜，语音模型第一次超越人类！OpenAI 再现 Her 时刻，95 后华人研究员坐镇

8/29/2025, 12:00:00 AM

📌 一句话摘要

OpenAI 发布了生产级实时语音 API 和先进的 gpt-realtime 语音到语音模型，显著提升了语音智能体的音质、理解力和功能调用能力。

📝 详细摘要

OpenAI 最新发布了 Realtime API 和 gpt-realtime 语音到语音模型，旨在彻底改变 AI 语音交互。Realtime API 简化了语音智能体的构建，支持图像输入、远程 MCP 服务器集成及 SIP 电话功能，实现了语音的直接处理，大幅降低延迟。gpt-realtime 模型在音质上达到近乎真人的水平，具备细腻情感表达和多语种切换能力。同时，其智能与理解力显著提升，能精准捕捉非语言线索，并在 Big Bench Audio 和 MultiChallenge 等评测中表现优异。模型对指令的遵循和函数调用能力也大幅增强，支持异步函数调用，为开发者构建复杂、高效的语音应用提供了强大工具。文章还提到了两位华人研究员在 OpenAI 的贡献，展现了团队的技术实力。

💡 主要观点

  1. Realtime API 简化语音智能体构建，实现低延迟、高品质的生产级应用 通过单一模型和接口直接处理语音，支持图像输入和 SIP 电话，大幅提升开发效率和用户体验，使语音智能体更易于落地和扩展。
  2. gpt-realtime 模型在音质、理解力和指令遵循方面达到新高度，接近真人水平 模型能捕捉非语言线索，无缝切换语言，精准遵循复杂指令，并生成具有情感和语速的自然语音，极大提升了用户交互的沉浸感和满意度。
  3. gpt-realtime 的函数调用能力显著增强，支持异步调用，提升智能体实用性 模型能更准确、及时地调用外部工具，即使长时间函数调用也能保持对话流畅，使其在生产环境中处理复杂任务时更具操作性和效率。
