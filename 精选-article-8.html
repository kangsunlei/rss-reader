Qwen4-Max 首发上线千问 AI 平台，API 服务、Token Plan 同步开放

11/16/2026, 3:24:00 AM

📌 一句话摘要

阿里巴巴发布全新一代基座大模型 Qwen4-Max，采用稀疏注意力 MoE 架构，支持百万上下文，在编程、智能体等能力上显著提升性能，同时推出 API 服务与 Token 计费方案。

📝 详细摘要

阿里巴巴正式发布 Qwen4-Max 大模型，首次上线千问 AI 平台。该模型基于稀疏注意力（QSA）的全新 MoE 架构，总参数 2.4T，具备原生视觉和长程任务能力，支持百万级上下文。相较上一代 Qwen3.8-Max，Qwen4-Max 在 Terminal-Bench 4.0 专业编程评测中，平均 Token 用量从 289K 降至 151K，减少近 50%，得分从 37.9 提升至 48.5，提升近 28%；同时单任务平均费用降低 58%。模型面向汽车制造、游戏开发、金融投研、科学研究等领域深度优化。在实际场景中，Qwen4-Max 实现了汽车产线规划、零件设计与加工验证，单件工艺编程人工投入由 475 分钟降至 26 分钟，减少约 95%；在材料和药物发现中，模型完成了从分子设计到实验验证的闭环，最终获得经实验验证的新型冷却液分子。

💡 主要观点

  1. Qwen4-Max 采用稀疏注意力 MoE 架构，支持百万上下文 模型总参数 2.4T，具备原生视觉和长程任务稳定交付能力，为复杂任务提供强大支撑。
  2. 在编程能力上显著提升，Token 用量降 50%，得分提升 28% 在 Terminal-Bench 4.0 评测中，平均 Token 用量从 289K 降至 151K，得分从 37.9 分提升至 48.5 分，同时单任务费用降低 58%。
  3. 在实际生产场景中实现了汽车制造和药物发现的闭环工作流 汽车产线规划人工投入减少 95%，材料发现完成从分子设计到实验验证的 48 小时闭环，最终获得经验证的新型冷却液。
  4. 推出千问 AI 平台及 API 服务与 Token 计费方案 开发者可通过 API 调用 Qwen4-Max，国内每百万 Tokens 输入 10 元，输出 30 元，隐式缓存命中仅 0.5 元。

💬 文章金句

  • 在 Terminal-Bench 4.0 专业编程评测中，同为 Xhigh 思考档位，Qwen4-Max 的每次尝试平均 Token 用量从 289K 降至 151K，减少近 50%，评测得分提升近 28%。
