Claude Code 现已支持自动代码审查，检测安全漏洞

8/6/2025, 4:44:22 PM

Anthropic 宣布 Claude Code 新增自动代码安全漏洞审查功能，集成了临时命令和 GitHub Actions，实现持续安全检查。

Anthropic 为 Claude Code 推出一项新功能，支持自动安全漏洞审查，使开发者能够在代码部署前发现潜在的安全问题。该功能包括用于按需检查的 `/security-review` 斜杠命令，以及用于自动审查每个 Pull Request (PR) 的 GitHub Actions 集成，从而简化开发流程中的安全评估环节。
