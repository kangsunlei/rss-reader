采纳率从 7.9%到 54%：快手智能 Code Review 的三阶进化

3/9/2026, 4:34:00 AM

📌 一句话摘要

本文详述了快手智能代码审查系统从纯 LLM 启发式到知识引擎驱动，再到 Agentic 自主决策的三代架构演进，将 CR 采纳率从 7.9% 提升至 54%。

📝 详细摘要

快手技术团队针对传统人工 Code Review (CR) 效率低、标准不一及 AI 评审早期“幻觉”严重、采纳率低（不足 10%）等痛点，构建了智能 CR 系统。该系统经历了三个阶段：1.0 阶段依赖纯 LLM 启发式评审，因上下文缺失和知识匮乏导致误报高；2.0 阶段引入“上下文智能构造引擎”与“1，100+ 条确定性规则”，通过 Map-Reduce 处理长上下文及三层价值过滤体系，显著提升了评审的可信度；3.0 阶段演进为 Agentic 自主决策架构，利用元数据驱动的 Agent 底座和智能规划层，实现标准场景高效处理与复杂场景深度推理的双路并行。目前，该系统已覆盖快手 74% 的 MR，显著缩短了评审周期，并实现了研发知识的系统化沉淀与自进化。

💡 主要观点

  1. 从纯 LLM 驱动转向“知识引擎+规则确定性”的融合架构。 早期纯模型评审因缺乏上下文和领域知识导致采纳率极低。2.0 架构通过 AST 解析、跨文件依赖推断和确定性规则库，为 LLM 划定评审范围，解决了 AI 幻觉和低价值建议问题。
  2. 构建多层次上下文智能构造引擎与 Map-Reduce 长上下文处理机制。 通过语言识别、方法体扩展及逻辑切分，突破 Git Diff 的片段限制，确保模型能理解代码变更的全貌，并解决大 MR 导致模型注意力分散或超出窗口的问题。
  3. 建立三层价值评估过滤体系与 RAG 增强的 BadCase 拦截机制。 通过基础噪声过滤、准确性校验和价值密度评估筛选“金句”；同时利用向量库存储历史误判案例，触发 LLM 自检，实现对同类幻觉误报的主动防御。
  4. 演进至 Agentic 自主决策模式，平衡评审的“确定性”与“创造性”。 3.0 架构引入智能规划层，根据 MR 复杂度自动路由：简单场景走高效确定性链路，复杂场景由 Agent 自主规划上下文获取并进行跨边界、业务意图层面的深度推理。
  5. 通过研发知识自进化闭环，实现隐性经验的显性化沉淀。 将故障回溯、最佳实践和历史人工评审知识转化为 1，200+ 条可执行规则，并结合开发者反馈数据驱动系统持续迭代，实现“越用越准”。

💬 文章金句

  • 让 AI 能力从‘私人助理’升级为‘团队协作者’。
  • 工具不仅要‘可用’，更要成为开发者‘可信赖’的智能伙伴。
  • 通过‘知识工程’提升大模型准确性，让智能评审真正落地为可信赖的生产力工具。
  • 该快则快、该深则深，构建自主规划 + 双路并行 + Agentic 智能体的确定性与创造性融合框架。
  • 智能 CR 的目标不止于发现代码层面的问题，未来还将致力于成为一名‘架构顾问’。
