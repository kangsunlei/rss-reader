开源崛起、降价 80%，大模型真的还能赚到钱吗？

8/1/2026, 12:08:00 AM

📌 一句话摘要

本文分析大模型 API 价格下降 80%的背后逻辑，结合摩根士丹利报告与国内创业团队的盈利模型对比，探讨开源模型与闭源模型的竞争策略，以及大模型商业化的盈利变量与未来趋势。

📝 详细摘要

文章从 OpenAI GPT-5.6 Luna API 价格下调 80%入手，结合摩根士丹利关于 1GW 数据中心盈利模型与国内创业团队 8 卡 B300 节点盈利计算的对比，分析大模型商业化中的四个关键变量（有效吞吐量、商业利用率、Token 净价、设备折旧年限）。文中指出开源模型（如 Kimi K3）通过权重开放扩大供给，但官方 API 仍有优化系统与服务保障优势；闭源模型则通过能力领先与服务质量维持溢价。同时，OpenAI 的频繁额度重置被解读为用户留存与市场测试策略。文章认为大模型价格战已演变为技术降本、运营效率与客户价值捕获的综合竞争，未来利润分配将倾向于同时控制算力成本与客户支付意愿的企业。

💡 主要观点

  1. 大模型 API 价格大幅下降反映了技术成本下降与市场竞争加剧。 OpenAI 将 Luna API 价格下调 80%，Kimi K3 开放权重推动市场供给扩大，表明大模型行业进入价格竞争阶段，但价格并非唯一竞争维度。
  2. 盈利模型差异反映了大模型商业化的复杂性。 摩根士丹利的 1GW 数据中心模型与国内 8 卡节点盈利计算存在四倍回报率差异，源于吞吐量、利用率、价格和折旧年限等变量的不同假设，说明商业模式需动态调整关键参数。
  3. 开源与闭源模型形成差异化竞争策略。 开源模型通过权重开放获得生态影响力（如 Kimi K3 允许部署与商业化但限制大规模 API 业务），闭源模型则依赖能力领先与服务质量维持溢价（如 OpenAI 的优化系统与稳定性）。
  4. 用户额度管理是 OpenAI 的市场策略组成部分。 频繁重置额度既是补偿技术问题的措施，也是用户留存、定价实验与产品优化的工具，通过增量算力激励用户深度嵌入。

💬 文章金句

  • Token 会越来越便宜，但大模型已经脱离讲故事的时代，开始接受收入、现金流和投资回报的检验。
  • 模型、算力与客户入口越完整，越有机会把技术降本转化为投资回报。
