腾讯开源 BrowserSkill：让 Agent 借用你已登录的真实浏览器

9/16/2026, 1:02:33 PM

📌 一句话摘要

腾讯开源 CLI + 浏览器扩展组合 BrowserSkill，让任何能跑 shell 的 Agent 借用用户已登录的真实浏览器标签页干活，通过四层架构、会话模型与权限收敛的安全设计，在不打断用户的前提下完成自动化。

📝 详细摘要

作者系统拆解了腾讯开源的 BrowserSkill。它针对现有 Agent 浏览器自动化（Playwright、headless Chrome、browser-use）开的是「另一个浏览器」、没有登录态与 Cookie 的痛点，改为借用用户日常浏览器：登录态复用、独立 Agent Window 互不干扰、框架无关（能跑 shell 即可，Cursor/Claude Code/Codex 等）、遇到验证码或支付确认可请求人工接管。架构为 Agent → bsk CLI → daemon → 浏览器扩展 → Agent Window 四层，Agent 永不直接碰浏览器；核心抽象是会话（不透明 ID + 专属窗口 + ref-store + 借用表），同会话串行、跨会话并行。安全上做权限收敛：写操作限于 Agent Window、借用需用户确认、开关以浏览器设置为权威来源、文件传输三方分权、凭证零提取、30 天审计日志。SKILL.md 把防御性纪律写进说明书，评测框架强调「诚实验证」，约 3 个月迭代到 0.3.0。

💡 主要观点

  1. BrowserSkill 用「借用真实浏览器」替代「另开一个浏览器」 现有方案开的是无登录态、无 Cookie 的独立浏览器，需单独配测试账号；BrowserSkill 直接操作用户已登录的真实 profile，并在独立可见的 Agent Window 中运行，不打断用户正常使用。
  2. 四层架构与会话模型把 Agent 与浏览器彻底隔离 Agent → bsk CLI → daemon → 扩展 → Agent Window，Agent 永不直接碰浏览器；会话是核心抽象，同会话操作串行以保证引用安全，不同会话并行，结束需显式 session stop。
  3. 安全模型对「Agent 拿真实身份上网」逐步收敛权限 写操作限于 Agent Window、借用需用户确认、自动化开关以浏览器设置为权威来源以防 Agent 自我提权、文件传输三方分权、凭证零提取、effect_state 未知时禁止盲目重试，另有 30 天审计日志。
  4. 0.3.0 远程模式支持云端 Agent 操控本地登录态 Agent 跑在服务器上，通过一次性配对链接加可续期/吊销的设备凭证，经 TLS 认证的 WSS 连回本地浏览器，这在云端 Agent 操控本地登录态场景中属稀缺能力。

💬 文章金句

  • Agent 永远不直接碰浏览器。
  • 把"Agent 拿着你的真实身份上网"这件事的每一步都做了权限收敛
  • 缺少适配器证据记为 unverified，绝不静默算通过。
