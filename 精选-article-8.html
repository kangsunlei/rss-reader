漏洞百出的夏季：聚焦约翰·雷贝格的提示注入研究

8/15/2025, 10:44:44 PM

📌 一句话摘要

约翰·雷贝格的“AI 漏洞月”揭示了主流 AI 工具中普遍存在的严重 Prompt 注入漏洞。

📝 详细摘要

本文报道了独立 AI 研究员约翰·雷贝格发起的“AI 漏洞月”倡议，他每天发布关于各种易受提示注入攻击的 AI 工具的报告。该研究涵盖多个平台，如 ChatGPT、Codex、Anthropic MCPs、Cursor、Amp、Devin、OpenHands、Claude Code、GitHub Copilot 和 Google Jules 等，揭示了这些漏洞在发现三年后仍然普遍且危险。作者总结了约翰的每一项发现，阐述了各种攻击向量，包括通过 Markdown 图像或 DNS 请求进行数据泄露，通过诱骗代理修改自身配置（例如，VS Code `settings.json`）来执行任意命令，以及权限提升。这些漏洞中观察到的常见模式包括 Prompt 注入作为初始攻击向量，各种数据泄露方法（例如，Web 请求、自定义 DNS 服务器），以及编码代理中任意命令执行的问题性质。本文介绍了约翰提出的“AI 杀伤链”概念，描述了 Prompt 注入如何导致“混淆代理”问题，进而实现自动工具调用。一个值得关注的问题是，尽管进行了负责任的披露，但许多已报告的漏洞尚未被供应商修复，通常是因为修补它们会严重影响工具的实用性。作者重申，某些系统可能天生不安全，但行业仍在明知风险的情况下构建它们。

💡 主要观点

  1. Prompt 注入漏洞在许多领先的 AI 工具中令人震惊地普遍存在且危险。 约翰每天披露关于 ChatGPT、Devin、Copilot 等的漏洞，表明这些基本的安全漏洞仍然存在，从而能够进行各种恶意活动，如数据盗窃和未经授权的命令执行。
  2. 常见的攻击模式包括数据泄露、任意命令执行和权限提升。 攻击者利用 Markdown 图像渲染、Web 请求功能或修改配置文件等功能来窃取敏感数据或执行恶意代码，通常通过欺骗 AI。
  3. “AI 杀伤链”突出了 Prompt 注入导致自动、未经确认的工具调用的关键风险。 这条链条中，一个混淆代理 AI 智能体自动触发危险操作，构成了严重的威胁，特别是当供应商未能实施强大的人工确认或安全配置时。
  4. 许多已报告的 AI 漏洞仍未被供应商修复，引发了重大的安全问题。 尽管进行了负责任的披露，但大量关键的 Prompt 注入问题仍未得到解决，通常是由于对工具实用性的影响，这表明某些 AI 系统是“设计上不安全的”。

💬 文章金句

  • 这是一个既令人称奇又令人担忧的演示，展示了这些漏洞在首次开始讨论它们近三年后仍然是多么普遍和危险。
  • 如果你可以*完全避免不受信任的指令*，你就不需要担心这个问题……但我不认为考虑到人们喜欢使用 LLM 驱动工具的方式，这完全是现实的。
  • 约翰创造了术语**AI 杀伤链**来描述一种特别有害的模式：Prompt 注入导致[混淆代理]，然后启用自动工具调用。
  • 其中一些问题得到了修复，但令人担忧的是，问题报告给了供应商，但供应商在 90 或 120 天内没有修复。
  • 在我们找到一个强大的解决方案之前，可能存在*根本不应该构建的系统*。看起来我们还是构建了它们！
