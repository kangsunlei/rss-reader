Qwen3.6-27B：无需 MoE 路由，旗舰级编程能力

4/22/2026, 1:02:00 PM

📌 一句话摘要

通义实验室发布 Qwen3.6-27B，以 270 亿稠密参数在编程基准上全面超越前代 397B MoE 旗舰模型，并原生支持多模态与长上下文。

📝 详细摘要

通义实验室于 2026 年 4 月 22 日开源发布 Qwen3.6-27B 模型。该模型采用 270 亿稠密参数架构，无需 MoE 路由，显著降低了部署门槛。其核心亮点在于编程能力的突破：在 SWE-bench Verified（77.2）、SWE-bench Pro（53.5）、Terminal-Bench 2.0（59.3）和 SkillsBench（48.2）等关键基准上全面超越前代 397B MoE 旗舰模型 Qwen3.5-397B-A17B。此外，模型原生支持多模态，可处理图像、视频与文本，具备视觉推理、文档理解和视觉问答能力。在推理任务 GPQA Diamond 上达到 87.8 分，展现出与超大参数模型相当的深度思考能力。模型已开源权重，并计划集成至阿里云百炼 API 及主流编程助手如 OpenClaw、Claude Code 和 Qwen Code。

💡 主要观点

  1. Qwen3.6-27B 以 270 亿稠密参数实现编程能力全面超越前代 397B MoE 旗舰。 在 SWE-bench Verified、Terminal-Bench 2.0 等多个核心编程基准上，该模型均取得领先分数，证明了稠密架构在小参数规模下的巨大潜力。
  2. 模型原生支持多模态与长上下文，可处理图文推理等复杂任务。 Qwen3.6-27B 支持视觉语言思考与非思考模式，能够完成视觉推理、文档理解和视觉问答，扩展了应用场景。
  3. 模型已开源并计划集成主流编程助手，降低开发者使用门槛。 权重已在 Hugging Face 和 ModelScope 开源，未来将支持阿里云百炼 API，并兼容 OpenClaw、Claude Code 等工具。
