GPT-5：主要特性、定价和模型卡

8/7/2025, 5:36:12 PM

📌 一句话摘要

对 OpenAI 的 GPT-5 模型系列的深入评测，涵盖其主要特性、极具竞争力的定价，以及来自其系统卡中关于安全性、可靠性等方面的关键见解……

📝 详细摘要

本文基于两周的预览体验，对 OpenAI 新 GPT-5 模型系列进行了全面介绍。作者详细介绍了 GPT-5 的核心特性，包括其在 ChatGPT 中的混合性质和具有可调节推理级别的更简单的 API 变体（常规、迷你、纳米）。重点介绍了诸如大 token 限制（输入 272，000 token，输出 128，000 token）和多模态输入能力等关键规格。文章重点关注 GPT-5 的积极定价策略，这使得它在与其他领先模型（如 Claude 和 Gemini ）的竞争中具有优势。文章还附有详细的比较表。来自 GPT-5 系统卡的见解揭示了在减少幻觉、增强指令遵循和最小化谄媚方面的重大改进，以及为细微的安全响应引入的 ‘safe-completions （安全完成）’。文章还批判性地考察了持续存在的提示注入挑战，尽管 GPT-5 显示出比前代产品更好的抵抗力。最后，它探讨了 API 功能，如 “思维轨迹” 和 “reasoning_effort” 选项，最后以 SVG 生成基准等实际示例作为总结。

💡 主要观点

  1. GPT-5 在各种任务中表现出很高的能力和可靠性，使其成为一个强大的默认选择。 作者的经验表明，GPT-5 很少出错，而且经常令人印象深刻，这表明与之前的模型相比，其在一般性能和稳定性方面有了显著的飞跃。
  2. OpenAI 对 GPT-5 模型采用了极具竞争力的定价策略。 GPT-5 的定价明显低于其前代产品和竞争对手，旨在提高采用率，并使开发人员能够以更经济高效的方式使用先进的 AI 功能。
  3. 在减少幻觉、谄媚以及提升 safe-completions 安全性方面取得了显著进展。 该系统卡揭示了 OpenAI 专注于改进模型行为，以提高可信度和安全性，从二元拒绝转向更细致、更有帮助但更安全的输出。
  4. 尽管有所改进，但提示注入仍然是 AI 应用程序中一个尚未解决的关键安全挑战。 即使 GPT-5 表现出更好的抵抗力，但高攻击成功率表明，开发人员必须继续在其应用程序中实施强大的防御措施，以防止提示注入。

💬 文章金句

  • 它仍然是一个 LLM ——它与我们以前拥有的东西没有显著的区别——但它很少出错，而且通常感觉很称职，或者偶尔在我想用模型做的那些事情上令人印象深刻。
  • GPT-5 是一个统一的系统，它有一个智能快速的模型来回答大多数问题，一个更深入的推理模型来解决更困难的问题，以及一个实时路由器，可以根据对话类型、复杂性、工具需求和明确的意图快速决定使用哪个模型。
  • 该定价与其他提供商相比具有极强的竞争力。
  • 我们在减少幻觉、改进指令遵循和最小化谄媚方面取得了重大进展，并提升了 GPT-5 在 ChatGPT 最常见的三种用途（写作、编码和健康）中的性能。
  • 但这也是一个强烈的信号，表明提示注入仍然是一个尚未解决的问题！
