Claude Code 创始人再次公开：团队的 10 个使用技巧！

2/3/2026, 2:58:00 PM

📌 一句话摘要

Claude Code 创始人 Boris Cherny 分享了团队内部提升 AI 编程效率的 10 个进阶技巧，涵盖并行工作流、规则固化及子智能体应用。

📝 详细摘要

本文由 Claude Code 创始人 Boris Cherny 总结并分享了其团队内部使用该工具的 10 个核心技巧。文章强调了 AI 辅助编程不应仅停留在简单的对话层面，而应通过工程化手段提升效率。核心建议包括：利用 git worktree 实现多任务并行处理；在复杂任务中坚持“计划先行”并引入 Review 机制；通过持续迭代 CLAUDE.md 文件来固化项目规范；封装自定义 Skill 以处理技术债和上下文聚合；以及利用 Subagents 增加算力投入和任务卸载。这些技巧旨在帮助开发者构建更高效、更自动化的 AI 协作工作流。

💡 主要观点

  1. 利用 git worktree 实现多会话并行处理，显著提升开发吞吐量。 通过开启 3-5 个独立的 git worktree 并运行独立的 Claude 会话，开发者可以同时处理多个任务，并利用 Shell 别名实现不同任务间的快速切换。
  2. 将 CLAUDE.md 视为项目的“长期记忆”和规则库，进行持续迭代。 每次纠正 Claude 的错误后，应要求其将规则更新至 CLAUDE.md。这种持续的反馈循环能显著降低 AI 的重复错误率，使其更契合项目规范。
  3. 在复杂任务中坚持“计划先行”模式，并引入角色化审查机制。 在编写代码前先打磨详尽的计划，甚至启动第二个 Claude 实例以 Staff Engineer 的身份进行 Review，确保代码实现能够“一步到位”。
  4. 通过 Subagents（子智能体）实现算力扩展与任务卸载。 在请求中添加指令调用子智能体，可以投入更多算力解决复杂问题，同时保持主智能体的上下文窗口整洁，避免信息过载导致的性能下降。

💬 文章金句

  • 使用 Claude Code 并没有所谓的唯一正解——毕竟每个人的配置环境都各不相同。
  • 把精力集中在打磨计划上，这样 Claude 在实现代码时就能一步到位（1-shot）。
  • 要在 CLAUDE.md 上多下功夫……保持迭代，直到你能感觉到 Claude 的错误率显著下降为止。
  • 在任何请求后加上 'use subagents'，如果你希望 Claude 投入更多算力来解决某个问题。
  • 我个人而言，我已经有 6 个多月没亲手写过一行 SQL 了。
