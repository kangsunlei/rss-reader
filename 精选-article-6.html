上限让人尝鲜，可靠让人常用：千问蒋冠军谈 Personal Agent

11/5/2026, 6:04:00 AM

📌 一句话摘要

千问蒋冠军阐述 Personal Agent 从尝鲜到常用的关键路径：模型、记忆、生态缺一不可，以稳定性为核心，通过后训练、Skill 约束和用户确认机制提升可靠性。

📝 详细摘要

本文对话聚焦千问 Personal Agent 的实践路径，探讨如何让智能体从「上限」体验走进千家万户。蒋冠军指出，做好 Agent 需要三大支柱：模型能力、记忆与上下文、生态工具。他解释称，模型已能思考并调用工具，记忆按因果关系存储而非简单堆积，后训练对齐真实用户需求。系统通过 Skill 约束和用户确认机制兜底，确保涉及交易和隐私的操作安全可靠。文章还提到，当前仍有局限：生态不通的行业难以对接，模糊的长期目标（如「六个月升职」）尚未实现，完整旅行规划等复杂任务仍需用户引导。

💡 主要观点

  1. Personal Agent 的核心要素是模型、记忆和生态三样齐。 模型提供思考与执行能力，记忆按因果关系存储上下文，生态工具则决定任务可落地范围。缺一不可，缺生态则导致下限不稳，缺记忆则无法持续对话。
  2. 稳定性比上限更重要，用户需要可靠的单点功能。 产品要从「让人尝鲜」转为「常用」，必须保证单个任务（如抢券、订票）成功率高。千问通过后训练、Skill 约束和用户确认机制兜底，确保涉及交易和隐私的操作安全可靠。
  3. 后训练要对齐真实用户，而非榜单。 模型智商虽高，但用户表达差异大。千问围绕三十多个行业做意图透视，聚合八千多个基础能力，后训练和强化学习重点保证这些能力的稳定性，避免因表达差异导致任务失败。
  4. 生态不通的场景只能「承认做不到」。 部分行业和产品拒绝第三方调用，MCP、API 无法接入。即便有 CUA、mobile use 也需用户授权且不够简洁。这类场景只能直接说明不可实现，生态通达是 Agent 可落地的前提。
  5. 模糊的长期目标（如升职）目前做不到。 明确目标（如马拉松时间）可跟踪，但「六个月升职」等模糊目标涉及周报、项目方案等关联，因内在关系弱且难以量化，当前 Agent 只能处理具体环节，无法完整追踪。
