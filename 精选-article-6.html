如何使用 ChatGPT 应用 SDK：使用应用 SDK 构建披萨应用

10/15/2025, 6:32:52 PM

📌 一句话摘要

本指南通过披萨应用示例，演示如何使用 OpenAI 的应用 SDK 和模型上下文协议 (MCP) 构建交互式 ChatGPT 应用。

📝 详细摘要

本文介绍了 OpenAI 的 ChatGPT 应用，它由新的应用 SDK 和模型上下文协议 (MCP) 驱动，可在 ChatGPT 对话中实现交互式 UI。本文为开发者提供了一个全面的逐步教程，指导如何使用官方披萨应用示例构建 ChatGPT 应用。指南涵盖了设置开发环境、运行本地应用服务器、使用 ngrok 公开暴露应用，以及披萨应用的 Node.js 代码的详细演练，解释了组件、工具、资源等核心概念。此外，它还指导如何在 ChatGPT 中启用开发者模式并连接自定义应用。文章最后提出了一些扩展应用功能的实际挑战，强调了 SDK 在将对话式 AI 与各种应用中的交互式用户界面融合方面的潜力。

💡 主要观点

  1. ChatGPT 应用通过应用 SDK 和 MCP 在对话中启用自定义交互式 UI。 这些新的应用类似于插件，允许开发者直接在 ChatGPT 内部渲染动态元素，例如地图、轮播图或视频，由后端 MCP 服务器驱动。
  2. 构建应用涉及设置本地服务器、公开暴露应用，以及配置 ChatGPT 开发者模式。 本教程提供了清晰的指令，用于克隆示例、运行 Node.js 服务器、使用 ngrok 进行公共访问，以及在 ChatGPT 的开发者设置中连接应用。
  3. ChatGPT 应用的核心组件是组件，它们被映射到工具和资源。 组件定义了 UI 元素，而工具代表 ChatGPT 的可调用操作，资源则为渲染这些交互式组件提供 HTML / JS 标记。

💬 文章金句

  • OpenAI 最近推出了 ChatGPT 应用，由新的应用 SDK 和模型上下文协议 (MCP) 驱动。
  • 将这些应用视为 ChatGPT 的插件：你可以在对话中自然地调用它们。它们可以在 ChatGPT 内部渲染自定义交互式 UI（地图、轮播图、视频等）。
  • 组件是应用的核心。每一个都代表 ChatGPT 可以显示的一块 UI。
  • SDK 使以全新的强大方式融合对话与交互式 UI 成为可能。
