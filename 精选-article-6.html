兄弟！你真的懂 Skill 吗？

3/17/2026, 12:46:00 AM

📌 一句话摘要

本文深度拆解了 Anthropic 的 Skill 框架源码与 16 个官方技能，揭示了其通过“Markdown 注入 + 沙箱执行”取代传统 Function Calling 的核心机制。

📝 详细摘要

文章对 Anthropic 开源的 Skill 框架进行了全方位的技术剖析。作者通过对 2000 多行核心源码的解读，梳理出从 SKILL.md 声明到 LLM 执行的 7 步完整链路。核心观点认为，Anthropic 并没有采用传统的 Function Calling 注册大量 API，而是通过 `skill_run` 工具在隔离沙箱中执行脚本，配合三层信息注入模型（概览、主体、详细文档）来优化 Token 消耗。文章归纳了五种 Skill 执行模式：纯 Prompt 注入型、脚本执行型、库调用型、参考文档渐进加载型以及复杂的编排型。这种设计哲学强调“教 AI 知识”优于“给 AI 接口”，充分利用了 LLM 的代码生成与逻辑推理能力，为开发者构建高效、灵活的 Agent 系统提供了极具价值的工程参考。

💡 主要观点

  1. Anthropic 的 Skill 系统核心逻辑是“教 AI 知识”而非单纯“注册 API”。 官方 16 个技能均未通过 Tools 声明注册函数，而是利用 SKILL.md 文本注入 system prompt，引导 LLM 自主编写或调用沙箱脚本。
  2. skill_run 工具通过隔离沙箱和增量哈希设计，实现了生产级的安全与性能平衡。 该工具创建隔离工作空间并自动注入环境变量，利用文件哈希避免重复拷贝，通过只读保护防止脚本篡改技能源码，确保执行环境安全高效。
  3. 采用三层信息注入模型（L0-L2）极大地优化了长对话中的 Token 经济性。 系统根据 LLM 的需求，从轻量概览到详细文档渐进式加载内容，相比一次性塞入所有文档，可节省约 40%-50% 的 Token 消耗。
  4. 总结出的五种 Skill 模式为不同复杂度的 AI 任务提供了标准化的实现路径。 从简单的纯 Prompt 约束到复杂的多 Agent 编排流水线，这五种模式覆盖了从前端设计到自动化测试、复杂项目管理的各种应用场景。

💬 文章金句

  • 与其给 AI 注册新函数，不如教它怎么写代码。
  • Skill 的执行力 = SKILL.md body 质量 × (Agent 基础工具 + skill_run 沙箱能力)
  • Anthropic 显然想通了一件事：function calling 是给确定性操作设计的，而大多数 Skill 面对的是不确定性任务。
  • SKILL.md 本质上就是一种极其高效的知识传递方式：用最少的 Token，把最关键的领域知识注入到 LLM 的上下文中。
  • LLM 最强的能力不是调 API，而是理解自然语言指令后自主解决问题。
