把记忆塞进 KV Cache，Agent 反而变笨了？KV 驻留内存，到底靠什么在干活！

10/28/2026, 4:00:00 PM

📌 一句话摘要

通过 12 次受控消融实验拆解 Agent KV Cache 驻留内存的机制，发现鲜活编码而非驻留本身是关键，账本类内容 stale 驻留会触发任务框塌缩，检索注入必须采用行级窄窗方案，最终给出「活跃对象 KV 鲜活驻留 + 账本外部存储窄窗注入」的分裂架构配方。

📝 详细摘要

文章基于 Qwen2.5-7B-Instruct 开展 12 次单变量消融实验（screening-level），系统拆解「把记忆塞进 KV Cache」在 Agent 长程任务中时好时坏的机制。核心发现五点：1）有效成分是每轮对目标/指令的鲜活重编码（买到位置可达性），而非驻留或重锚定动作本身；2）同一 44 行账本内容，prompt 侧每轮重发无恙，KV stale 驻留却在相位切换处触发任务框塌缩（鹦鹉学舌、源混淆、编造），且跨 GPU 型号呈临界性；3）塌缩的必要条件是 stake-chain 的 KV 驻留，切掉即消失；4）检索注入整链涌现（KV gating 或 prompt flash）均失败，仅 hit±1 行级窄窗注入能修好深历史检索且零编造，开销仅 0.315×；5）二阶决策总量打平但剖面互补：KV 擅长冲突优先级与近场补救，prompt 擅长深历史与源引用。最终给出分裂架构：当前目标/挂起目标/指令走 KV 辅区每轮鲜活编码，账本类对象仅外部追加、按需 hit±1 瞬态注入。实验为单模型、合成脚本、greedy 单轨迹，结论为筛查级方向性证据，非总体估计。

💡 主要观点

  1. Fresh encoding（每轮鲜活重编码）是 KV 驻留内存的有效成分，而非驻留本身或重锚定动作 实验 E6 裁决：目标每轮鲜活编码进 KV 辅区（F 臂）自由回忆 20/20，stale 驻留（G 臂）仅 8/20，sham 等长重锚定非目标内容（S 臂）仅 1/20。机制上买到的是位置可达性——把驻留区拉回查询附近；固定 stale 驻留仅改目标区与查询距离，自由回忆即从 20/20 翻到 8/20，而任务抽取几乎不受伤。
  2. Residency form 决定同一内容命运：Ledger 类内容 stale 驻留 KV 会触发任务框塌缩，且跨硬件呈临界性 E7 同一 44 行账本、同一管理策略，prompt 侧执行（P）五个行为门全满分、strict median 41；KV 侧执行（K）五个行为门全挂、strict median 26，塌缩集中在第 31 轮相位切换：任务框丢失、源混淆、编造。跨 GPU 复现：4080S 塌、4090 不塌、5090 又塌，bf16 数值路径细节决定落哪侧。工程含义：不要把 ledger 类内容以 stale 方式钉进 KV。
  3. Stake-chain 的 KV residency 是塌缩的必要条件，消融链钉死因果 E9-D 去除式诊断：切掉 stake chain 的 KV 驻留 → 塌缩消失（strict 回到 41/41）；不页入 read-back → 塌缩依旧；stake 不进 KV 仅提问轮 flash 进 prompt → 不塌但进度题能力归零。同一张表四种命运：stale KV 驻留→塌；不进 KV→行为满分；提问轮整链 flash→不塌但用不上；prompt 每轮鲜活→处处满分。
  4. 检索注入有分布约束：整链涌现（KV gating 或 prompt flash）均失败，仅行级窄窗（hit±1）成功 E8 Call-level KV gating：进度题 6/20（对照 17/20、prompt 20/20），模型面对「四十多行突然冒出」的结构突变。E9-D 提问轮 prompt flash：不塌但 j4c 0/4，闪现是分布外打断。E11 行级窄窗：命中行 ±1 瞬态注入 user message，深历史紧急查找 5/5、源引用 5/5、编造从 10/10 降为 0，开销约 143 tokens/run（0.315× baseline）。注入必须渐进、窄窗才能留在分布内。
  5. 二阶决策总量打平但剖面互补，分裂架构实现六类全满分零编造 E10 六类决策事件主分 Kf 15/20 vs P 15/20 打平：深历史/源引用 prompt 胜（5/5 vs 0/5 并编造）；冲突优先级/近场补救 KV 胜（5/5 vs 0/5）。E11 加上行级检索后，KV recipe 六类全 5/5、零编造。理想形态：KV 的干净目标信号 + 近场锐度，配上可咨询的窄窗账本。

💬 文章金句

  • Presence ≠ use。驻留保住了可用性，却不保住自发使用。
  • 有效成分是对目标内容的每轮新鲜编码，不是「重锚定这个动作本身」。
  • 同一内容，形态可以决定命运，塌缩还可能跨硬件临界。
  • 整链涌现本身就是突变事件；注入必须渐进、窄窗，才能留在分布内。
  • 最终 recipe：分裂，而不是铁板一块——KV 驻留区放 active 对象且每轮 fresh encode，检索层放 ledger 类且 hit±1 瞬态注入。
