我上了一堂关于 Claude Co-work 和 Claude Code 的私教课

1/23/2026, 3:00:34 PM

📌 一句话摘要

Anthropic 创始人 Boris 演示了 Claude Co-work 和 Claude Code，展示了智能体 AI 如何通过用户友好的界面实现文件管理、浏览器任务和复杂软件工程的自动化。

📝 详细摘要

本文深入采访了 Claude Code 的创作者 Boris，探讨了 Anthropic 在智能体 AI 领域的最新进展：Claude Co-work 和 Claude Code。与传统的聊天机器人不同，这些工具旨在“采取行动”——直接与本地文件系统交互，通过 Computer Use 控制网络浏览器，并执行复杂的流程，如收据处理以及跨 Gmail 和 Slack 的自动化沟通。Boris 解释了从基于终端的技术工具向基于 GUI 的桌面应用程序的转变，强调了 AI 安全特性，如删除保护和沙箱环境。他还分享了先进的生产力策略，例如并行运行多个 AI 智能体、利用模型上下文协议（MCP），以及维护共享的“Claude.md”文件，为 AI 行为构建团队范围的知识库。

💡 主要观点

  1. 智能体 AI 的定义在于其采取行动的能力，而不仅仅是生成文本。 Boris 强调，Claude Co-work 超越了聊天，它利用工具与本地操作系统交互并控制浏览器，以执行数据录入和电子邮件自动化等现实任务。
  2. 安全性和保障性通过沙箱化和人工确认环节得以集成。 Anthropic 采用虚拟机执行任务，并设有“删除保护”等功能，以确保 AI 智能体在没有用户明确授权的情况下不会执行破坏性操作。
  3. “Claude.md”文件充当引导 AI 行为的协作知识库。 通过在 Git 仓库中的共享 Markdown 文件中记录错误和首选解决方案，团队可以防止 AI 重复错误，并确保整个组织的输出一致性。
  4. 并行化 AI 智能体是实现巨大生产力提升的关键。 Boris 描述了一种工作流，他同时管理 5-10 个并行的 Claude 任务，扮演监督者而非程序员的角色，这通过“AI 军团”有效地扩展了人力产出。

💬 文章金句

  • 聊天机器人和智能体之间的区别在于，智能体可以采取行动。它不仅仅是文本；它可以使用你电脑上的工具。
  • 在过去的两个月里，我 100% 的代码都是由 Claude Code 编写的；我自己一行代码都没写过。
  • 如果你能精通 Claude Co-work，你将能够超越这个星球上 99% 的人。
  • 原则是：任何问题都不应该发生第二次。你只需将其写入 Claude.md，它就会成为你团队的共享知识。
  • 我是高级开发人员；LLM 是为了加速我的工作，而不是取代我的判断。
