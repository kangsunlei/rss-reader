分享 10 个你可能不知道的 Claude Code 隐藏命令。

3/20/2026, 2:09:00 AM

📌 一句话摘要

本文详细介绍了 Anthropic 官方命令行工具 Claude Code 的 10 个实用隐藏命令与快捷键，旨在提升开发者的 AI 辅助编程效率与交互体验。

📝 详细摘要

文章针对 Claude Code 这一高效 AI 编程 Agent，整理并分享了作者在深度使用中发现的 10 个核心隐藏功能。重点介绍了用于非干扰并行提问的 `/btw`、实现代码与对话分类回退的 `/rewind`、自动规划与执行模型切换的 `/model opusplan`，以及代码审查工具 `/simplify`。此外，还涵盖了远程控制、定时任务、会话分叉及导出等进阶用法，并补充了截图粘贴、换行等实用快捷键。作者强调了 AI 工具迭代极快，建议开发者通过这些技巧优化工作流，避免上下文污染并提升推理质量。

💡 主要观点

  1. 使用 /btw 命令在任务执行过程中进行非干扰式提问。 该命令允许用户在 Agent 工作时插入问题，且对话不会被计入历史上下文，有效避免了长会话中的上下文污染，同时利用缓存节省 Token。
  2. 通过 /rewind 实现代码与对话的精细化回退管理。 不同于简单的撤销，该功能支持只回退代码、只回退对话或两者同时回退，非常适合在尝试新方案失败时保留讨论思路而仅重置代码状态。
  3. 利用 /model opusplan 模式平衡推理能力与使用成本。 该隐藏模式会自动调用 Opus 模型进行复杂的架构规划，再切换至 Sonnet 模型执行具体编码，既保证了逻辑深度又优化了 Pro 用户的额度消耗。
  4. 调用 /simplify 技能进行多维度的自动化代码审查。 该命令会启动三个并行 Agent，分别从代码复用、质量和运行效率三个角度进行审查，比传统的 review 命令更能发现 AI 生成代码中的微妙冗余。
  5. 借助 /remote-control 实现跨设备的远程编程控制。 通过生成同步 URL，开发者可以在手机上远程操作电脑端的 Claude Code，代码依然在本地运行，兼顾了移动办公的灵活性与本地环境的安全性。

💬 文章金句

  • 这就是所谓的上下文污染，用 Claude Code 时间长的人应该都被坑过。
  • 规划需要深度思考，需要理解整个项目的架构和各种依赖关系，这种事情 Opus 确实比 Sonnet 强很多。
  • 你可以理解成，一个是后悔药，一个是平行宇宙（指 rewind 与 branch 的区别）。
  • AI 加持之下，产品的进化速度，太快了。
  • AI 写的代码经常会有一些微妙的冗余，/simplify 相当于找了三个同事帮你同时 review。
