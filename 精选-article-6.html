DeepSeek Harness 开发者预览版：一切皆插件

8/13/2026, 12:57:00 PM

📌 一句话摘要

DeepSeek Harness 发布 v0.1 开发者预览版，采用「一切皆插件」的开放架构，旨在构建可灵活重组的 Agent 基础设施并同步开源。

📝 详细摘要

DeepSeek Harness 团队推出了其开发者预览版 v0.1，并以 MIT 协议开源。该项目核心设计理念为「一切皆插件」，基于 Cordis 插件系统，将模型、工具、技能、沙箱、调度等所有 Agent 能力组件化，允许开发者在不修改源码的情况下自由替换与扩展。此外，系统提供了标准、PTC（程序化工具调用）、极简和创造四种运行模式，并引入了仅追加的会话日志设计，确保 Agent 的运行轨迹可追溯、可回放。

💡 主要观点

  1. 核心架构采用「一切皆插件」设计。 基于 Cordis 元框架，将 Agent 的所有能力（如存储、调度、UI 等）解耦为独立插件，实现高度的可组合性与灵活性。
  2. 提供四种差异化的运行模式。 针对不同场景提供标准模式、PTC 模式（代码驱动工具调用）、极简模式（基准测试）及创造模式（运行时试验）。
  3. 建立全链路可追溯的运行轨迹。 通过 append-only 会话日志记录所有输入输出与调度细节，支持轨迹的恢复、分叉与回放。

💬 文章金句

  • 所有 Agent 能力均由插件组合而成，可自由替换、灵活重组。
  • 开发者无需改动 DeepSeek Harness 的源码本身，就能以插件的方式独立选择、替换或扩展其中的任一能力。
