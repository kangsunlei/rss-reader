张阔：用真实商业任务检验 AI 系统

10/8/2026, 11:00:00 PM

📌 一句话摘要

阿里国际站总裁张阔复盘 AI 电商 Agent 半年进展：通用榜单近满分，但无人干预下真实任务通过率仅约 61%，模型、工程框架与上下文缺一不可，按任务路由模型才能把成本降到商家日常用得起。

📝 详细摘要

本期硅谷 101 再次访谈阿里国际站总裁张阔，距离其发布 Accio Work 约半年。张阔的核心观察是：模型在通用榜单上不断逼近满分，但商家在真实经营中的体感提升并不成比例。团队从阿里国际站的百万级真实经营与问答数据中整理出 107 个电商任务并开源，覆盖采购比价、船期预订、交易纠纷判断等七大类，分为 L1-L4 难度；在最前沿模型、无人干预条件下，任务通过率约为 61%。他把 Agent 能力概括为 model × harness × context，强调三者缺一不可，垂直产品的优势来自二十多年积累的交易、供应商与行业上下文。成本方面，XWork 通过帕累托最优路由，把简单任务交给小尺寸或高性价比模型、复杂任务交给前沿模型，并以集约采购和工程/上下文优化，使跑完 107 个任务的成本约为 Codex 与 Claude Code 的三分之一（约 3.69 美元 vs 9 美元以上）。节目还讨论中美 SaaS 与电商生态差异、AI 对 SaaS 的削弱与融合、多 Agent 建议冲突时以经营目标为准，以及采购下单、产品品味、预算分配等最终判断仍应留给人。这是一次有具体数据和实践框架、但立场偏向厂商的访谈。

💡 主要观点

  1. 通用榜单接近满分，不等于真实业务中可用；107 个真实电商任务在无人干预下通过率约 61%。 张阔团队用阿里国际站真实经营和问答数据构建 107 个任务 benchmark 并开源，覆盖七大类、L1-L4 难度。最前沿模型全自动完成全部任务的比例仅 61% 多，说明 math/coding/通用 agent 评测与电商垂直任务完成度相关性有限，也解释了为什么模型升级没有同步变成商家体感。
  2. Agent 能力等于 model × harness × context，任一项为零则整体为零。 张阔认为垂直 Agent 不能只等模型升级，必须同时做模型后训练、推理服务、工程框架与上下文管理。垂直产品的护城河来自二十多年积累的交易、供应商沟通、行业属性与平台趋势数据；这些上下文决定 AI 能否理解企业到底在优化利润、份额还是速度。
  3. 成本决定 AI 能否成为日常工具，帕累托最优路由把简单任务交给便宜模型。 XWork 按任务难度路由到不同模型：L3 以下用高性价比或小尺寸模型，复杂任务用 frontier 模型，并以集约采购、harness 与 context 优化压低成本。跑完 107 个任务，XWork 约 3.69 美元，Codex 与 Claude Code 均在 9 美元以上，约为其三分之一。商家固定用最贵模型解决所有问题是常见误区。
  4. AI 接手重复性经营工作，但最终商业判断仍应留给人。 多平台经营报表、商品发布、客户经营分析与风险预警等重复工作适合 AI；而采购下单、产品品味、市场判断、预算分配以及多 Agent 建议冲突时的取舍，需要老板基于整体经营目标决定。AI 可以让生意更灵活，但不能替代对“这盘生意到底要什么”的判断。
  5. AI 不会简单杀死 SaaS，而是要求垂直软件与 Agent 互相集成；中美电商与 SaaS 生态差异明显。 美国 SaaS 更垂直，电商有独立站生态；中国平台更整合，商家习惯多平台经营。SaaS 掌握企业工作流与经营上下文，AI 需要这些上下文才能真正落地，因此更可能是互相集成。AI 产品第一天就是全球化的，但工具、平台与区域上下文仍需适配。

💬 文章金句

  • 事实上可能现在最 frontier 的模型在我们这个办事下面能够通过率就是 61%多一点点。他要想要达到及格水平，现在都有点费劲。
  • 我们说 agent 有一个公式，就是 agent 等于 model 乘以 harness 乘以 context。
  • 因为现在商家测我们的一个感受是必须是一个用得起的 AI 才是一个有价值的 AI
  • 但是从我们整体的感觉上来讲，就是大家没有把本质的水位，每一个发布的模型的时候拉的那么大。
  • 但是最终这个商业判断还是人去做。
