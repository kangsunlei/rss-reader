ChatGPT 再进化：o1 支持调 Python 分析数据，网友：进化成 Copilot 了

3/14/2025, 6:53:49 AM

📌 一句话摘要

ChatGPT 的 o1 和 o3-mini 模型集成 Python，显著提升了数据分析和可视化能力，使其成为更强大的数据分析工具。

📝 详细摘要

文章介绍了 ChatGPT 的 o1 和 o3-mini 模型新增的 Python 数据分析功能。通过对飞机航班记录的分析，展示了 o1 在数据处理、时区转换和复杂计算方面的强大能力和准确性。同时，文章还测试了各模型的数据可视化能力，对比了 o1、GPT-4o 和 Claude 在生成折线图方面的表现。结果显示，o1 和 GPT-4o 能够生成准确的图表，但 o1 的图表在可读性方面略有不足，Claude 虽然生成了交互式网页，但在时区转换上出现了错误。此外，OpenAI 还将 Mac 客户端的 Work with Apps 功能开放给所有用户，进一步提升了用户体验，方便用户在不同应用之间共享数据。

💡 主要观点

  1. ChatGPT o1 模型通过 Python 集成，显著提升了数据分析能力，成为更强大的数据分析工具。 o1 模型能够处理复杂的数据分析任务，包括数据提取、时区转换和统计计算，为用户提供准确的结果。例如，在分析航班记录时，o1 能够准确计算航班延误，并进行时区转换。
  2. 不同 AI 模型在数据分析和可视化方面各有优劣，o1 在数据准确性方面表现出色。 GPT-4o 在输出格式上更胜一筹，Claude 在可视化方面更具创新性，但存在准确性问题，o1 在准确性方面表现出色，保证了数据分析结果的可靠性。
  3. Work with Apps 功能提升了 ChatGPT 的易用性，简化了用户工作流程。 该功能允许用户直接从其他应用程序导入数据，无需手动复制粘贴，简化了编程等任务的工作流程，提升了用户体验。

💬 文章金句

  • o1 已经从一个助理，进化成全能的数据分析 Copilot 了。
  • 最终，这四个问题，o1 在调用了 Python 之后全都分析对了。
  • Claude 这边则是闹出了一些乌龙，一开始表示自己无法打开上传的文件（可能是文件名包含中文的缘故），反复自动重试多次后，竟然自己编了一套答案出来。
