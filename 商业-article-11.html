马斯克 SpaceX 与 Cursor 达成 600 亿美元「可选收购」协议

4/22/2026, 12:37:35 PM

📌 一句话摘要

马斯克旗下的 SpaceX 与 AI 编程工具 Cursor 达成 600 亿美元可选收购协议，反映了 Coding Agent 领域的激烈竞争。

📝 详细摘要

推文报道了马斯克旗下的 SpaceX 与知名 AI 编程工具 Cursor 达成的重大财务协议。作者分析了 Cursor 在硅谷「御三家」重兵布局 Coding Agent 领域的竞争压力下，作为非基座模型公司的处境。文中指出 Cursor 虽然工程能力强，但在基座模型上受限（如使用 Kimi K2.5），被马斯克或 Meta 等大厂收购可能是其最佳结局。该协议估值从 25 亿飙升至 600 亿，仅用时 15 个月。
