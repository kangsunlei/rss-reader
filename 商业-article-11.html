将产品管理与设计融入 AI 驱动的 Git 工作流

3/15/2026, 3:38:11 PM

📌 一句话摘要

Garry Tan 主张将产品规格和设计文件视为 Git 仓库中的代码，并利用 Claude Code 等 AI 工具进行开发。

📝 详细摘要

基于“Markdown 即代码”的理念，Garry Tan 提出产品管理 (PM) 和设计产物应以 Markdown 和图像文件的形式存储在 Git 仓库中。他建议将这些内容与项目计划和 QA 测试用例一起，通过 Claude Code 进行开发。这种方法旨在使规范和 AI 指令的演进与实际代码库同步，通过为产品文档提供更好的版本控制和 CI 验证，有望将交付速度提升一倍。
