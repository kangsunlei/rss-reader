Token 消耗量成为社群门槛可能走向泡沫

6/23/2026, 8:45:57 AM

📌 一句话摘要

池建强评论 AI 社群中开始以 token 日消耗量作为门槛的现象，认为这如同 GitHub star 一样可能变成泡沫和贴标签。

📝 详细摘要

池建强引用群友观点，指出部分 AI 社群已开始要求成员 token 日消耗量过亿才能加入，并对比此前 GitHub star 的泡沫化趋势。他认为人类总在发明各种标签，这种以消耗量论资排辈的现象很可能走向泡沫。
