复盘 Personal Agent 集体诞生背后：和蔡伟聊 AI 产品史、需求真伪、入口与未来想象

11/18/2026, 3:08:54 AM

📌 一句话摘要

蚂蚁灵光负责人蔡伟复盘 Personal Agent 集体爆发：模型长程任务完成率从三四成跃至六七成、跨过阈值后，主动性成为新产品形态的核心，成败取决于智能、供给、安全可信三要素。

📝 详细摘要

本期张小珺访谈蚂蚁灵光负责人蔡伟（David）。他曾在硅谷与谷歌做计算机视觉研发十年，2019 年回国创业与投资，2024 年加入蚂蚁参与 AI 战略。他把大模型之后的产品分为三代：ChatGPT 式问答解决信息获取，Claude Code / Manus 式任务拆解与工具调用解决固定流程的软件工作，Personal Agent（PA）则以主动性为核心，在合适时机提供关键信息并代为执行；三者分别对应信息、软件、服务业，在中国大致是千亿、万亿、十万亿级的市场空间。灵光 2025 年 3 月立项，7 月内测，11 月上线快速研究、闪应用与多模态感知三大能力，2026 年春节后启动 PA 研发，10—11 月才推出可公测版本。他给出 PA 成败的三要素：智能（长程任务拆解、工具调用、个性化记忆）、供给（支付宝、钉钉等生态与连接器）、安全可信（授权与支付控制），并坦承蚂蚁强在供给与合规，弱在纯 C 端产品的打造与推广经验。产品上他强调「主轴与灵魂」，主动性不能作为问答框架上的附加功能；边界感靠信息分层（内环、中环、外环）加冷启动后的数据飞轮。他还比较了 Instinct 证明 PA 可脱离 APP、Muse 的边界感与推送质量更优，并区分 PA 与 O2O：前者是模型带来的供给侧重构，后者是场景侧变化；另谈到大厂与创业公司的分工、补贴战、算力成本与终局推演。转录仅覆盖访谈前段，结尾截断。

💡 主要观点

  1. PA 是模型能力跨过阈值后解锁的新产品形态，主动性是核心差异，不能当作问答框架上的附加功能。 蔡伟称模型在长程任务上的完成率从三四成跃升到六七成，跨过了可用阈值；ChatGPT 解决信息获取，Claude Code / Manus 解决任务拆解与工具调用，PA 则要主动在合适时机给信息、代办事项。但他强调产品要有主轴与灵魂：ChatGPT 的主轴是问答且立得很稳，把「盯事情」做成功能与做成主轴，整体表达完全不同。
  2. PA 成败取决于智能、供给、安全可信三要素，蚂蚁强在供给与合规，弱在纯 C 端的运营补课。 供给上依托支付宝既有合作网络与中心化团队降低对接成本，安全上继承金融业务的授权、隐私与支付控制体系；但每个服务的接口与体验都不一样，模型通用能力不等于场景丝滑，关键场景仍需产品与技术联合调优。短板是从零建立市场认知与推广路径，团队在纯 ToC 产品的打磨上经验不足。
  3. 主动性的真正难点是边界感，靠信息分层与冷启动后的数据飞轮，而非一条通用提示词。 同一趟日本行，机票、酒店、请假、日程冲突是内环，天气与新景点是中环，泛相关内容是外环；Muse 的推送少而精，形成「稀缺—期待—点击」正循环，而高频低质的早报夜报会被当成营销短信，用户关闭通知甚至卸载。每个人边界不同，冷启动时尺度难把握，先立克制的产品主张再按真实反馈调参。
  4. PA 与 O2O 的本质区别是供给侧而非场景侧变化，O2O 的线上化恰好为 Agent 铺路。 O2O 把线下服务搬到线上形成入口，供给的丰富度与线上化程度决定 Agent 的能力上限；智能供给重构既生成全新供给（即时生成的回答），也把散落服务重组为连贯体验。商业机会本质来自供需短暂失衡，模型释放的是供给侧潜力，而移动互联网更多是定位等场景侧解锁。
  5. 竞争壁垒随阶段变化：短期看智能，中长期看供给与安全；补贴战是商业决策，不等于产品与技术领先。 基础模型能力趋同后，生态与个性化记忆更关键。国内充分竞争下补贴可能出现，甚至不排除在春晚节点以红包或服务体验形式出现，但留存与 LTV 才决定胜负；算力成本可借离线任务错峰调度与基础设施降价缓解。他也判断 chatbot 长期会接走部分搜索，但搜索引擎公司的算法、人才、数据积累与用户习惯迁移都需要过程。

💬 文章金句

  • 总结归纳就三点，我认为第一点就是智能，第二点是供给，然后第三点是安全可信。
  • 它其实就是一个产品要有自己的灵魂跟主轴，它和功能其实并不是完全一回事儿。
  • 我觉得 instinct 的给人带来了一个非常大的不一样的一个启示，是一个 PA 不一定要以 APP 的形式去存在。
  • 信息本身其实是应该分层分级的。
  • 所以我认为整个 o to o 这波其实给 PA 创造了非常好的一个条件。
