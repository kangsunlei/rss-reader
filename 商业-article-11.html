作者用 C++ 和 Windows API 复刻 Photoshop，开发了一款轻量级、免安装的图像编辑器 Fedit，并分享了开发过程中的挑战和收获。

📝 详细摘要

文章讲述了作者在大学期间，为了解决漫画阅读器使用不便的问题，进而尝试用 C++ 和 Windows API 复刻 Photoshop 的故事。他开发了一款名为 Fedit 的图像编辑器，具备免安装、资源占用低等特点，UI 设计尽可能还原 Photoshop 的经典界面，包含自由浮动窗口、图层管理等功能。文章分享了开发过程中遇到的 UI 设计难题，以及通过开发 Fedit 获得的 C++ 开发经验，最终凭借此项目获得了一份 C++ 工作。Fedit 的成功不仅是技术上的突破，也为作者的职业生涯奠定了基础。

💡 主要观点

  1. 用 C++ 和 Windows API 可以实现强大的图像处理功能 作者通过 Fedit 项目证明了 C++ 在图像处理领域的潜力，展示了其在 UI 设计和功能实现方面的灵活性。
  2. UI 设计是图像编辑器开发中的关键挑战 复刻 Photoshop 的 UI 界面，特别是可自由吸附 / 分离的工具面板、颜色选择器等，需要深入理解 Windows API 和 GDI+。
  3. 实际项目经验是提升编程技能的有效途径 通过 Fedit 项目的开发，作者不仅巩固了 C++ 知识，还积累了解决实际问题的经验，为后续职业发展奠定了基础。
  4. 坚持个人项目，并将其开源，可以为职业发展带来意想不到的机会 作者的 Fedit 项目不仅获得了正面评价，还为他带来了 C++ 工作机会，证明了个人项目的价值。

💬 文章金句

  • 我希望 Fedit 的操作流程尽可能接近 Photoshop，但有些功能实在是很难实现
  • 我花费了大量时间在 MSDN 和 Stack Overflow 上查找解决方案，但这并没有太大帮助，因为大多数问题都非常特殊且具体，我还是得靠自己去分析和调试。
  • 最终，这些原则让 Fedit 具备了以下特性：免安装，开箱即用；可以在权限受限的系统上运行，甚至可以直接从 U 盘启动；资源占用极低。
