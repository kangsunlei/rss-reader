晚点独家丨字节讨论训超 5 万亿参数模型，张一鸣：不蒸馏、别被 Coding 这种短期热点影响

8/6/2026, 12:43:00 PM

📌 一句话摘要

本文独家报道字节跳动正在讨论训练超 5 万亿参数模型，并披露张一鸣在 Seed 全员会上反对蒸馏、主张追求智能上限、不被 Coding 短期热点牵制的战略判断。

📝 详细摘要

《晚点 LatePost》独家报道，字节跳动 Seed 团队正在讨论训练参数规模超 5 万亿的新模型，超过阿里 Qwen 3.8-Max（2.4 万亿）和月之暗面 K3（2.8 万亿），为国内已知最大，但计划仍处早期。文章披露张一鸣与 Seed 负责人吴永辉召开全员会：张一鸣安抚团队焦虑，明确可接受短期落后，以追求智能上限为目标；认可 Coding 为关键方向但提醒不应被短期热点牵着走；表扬 Seedance 的差异化路线；明确反对蒸馏，认为蒸馏只能复制 Claude，难以真正超越。文章还梳理了 Seed 过去半年表现：多模态（Seedance/Seedream）领先并支撑火山引擎商业化，但语言模型 Seed 2.0 市场反响有限；豆包 token 消耗增长低于预期，智谱与月之暗面靠 Coding 能力扩大 ARR；字节已引入 DeepSeek 研究员郭达雅补课 Coding，并推动取消赛马、收拢资源。文章认为字节正试图用「大力出奇迹」与 Seedance 式极致预训练的方法，在语言模型上弯道超车，但也指出超大参数语言模型在系统工程、数据与跨部门协作上面临更大挑战。

💡 主要观点

  1. 字节正讨论训练超 5 万亿参数模型，意图弯道超车。 该规模超过阿里 Qwen 3.8-Max 和月之暗面 K3，为国内已知最大，但计划仍处早期，不保证最终发布。
  2. 张一鸣明确反对蒸馏，认为无法真正超越。 蒸馏短期改善表现但本质是复制 Claude 能力，只能逼近对手，字节宁可短期落后也要从底层构建 AGI 壁垒。
  3. 张一鸣提醒不被 Coding 短期热点牵制。 认可编程是当前关键方向并整合火山引擎、飞书、豆包资源，但强调编程之外有更大机会，应追求智能上限。
  4. Seed 多模态领先但语言模型落后，商业化承压。 Seedance/Seedream 贡献豆包过半 token 消耗，但语言模型 Seed 2.0 反响有限，二季度多模态增速放缓，豆包 token 消耗低于目标。
  5. 字节以「大力出奇迹」方式押注 AI，并推动组织变革。 沿袭多项目并行与极致投入风格，将 Coding 资源统一划归郭达雅，同时取消赛马、明确分工，试图复刻 Seedance 的成功路径。
