机器人刷一段「短视频」，就能学会新技能？自变量 HOST 技术「神器」来了

8/3/2026, 9:01:00 AM

📌 一句话摘要

机器人只需观看一段约 29 秒的人类演示短视频，即可通过 HOST 框架实现零样本技能获取，无需额外数据采集或模型微调。

📝 详细摘要

文章介绍了自变量机器人提出的 HOST（Human-to-robot One-Shot Skill AcquisiTion）框架，该框架让机器人只需观看一次人类演示的短视频即可学会新技能，免去传统模仿学习中大量遥操作数据采集和模型微调的步骤。文章详细说明了 HOST 的核心机制：通过将视频画面与机器人动作映射到同一向量空间并使用动态时间规整算法对齐进度，以及采用双专家 MoT 架构分离视觉理解与动作生成，从而避免直接模仿人类动作带来的身体差异问题。实验表明，在 50 项全新任务中平均成功率达 62%，相比最快的监督微调基线，示范数据量降至五十分之一，学习时间缩短约 507 倍；且因未更新模型参数，旧任务保留率高，抗遗忘能力强，对光照、物体替换、场景变化等干扰具有一定鲁棒性。文章还指出该框架已开源，涵盖论文、GitHub 和 Hugging Face 链接，有助于推动具身智能技术的普及和开发者生态建设。

💡 主要观点

  1. HOST 实现一次性视频演示即可学习新技能，无需额外数据采集或模型微调。 机器人只需观看一次约 29 秒的人类演示视频，就能在推理过程中完成技能获取，全程不更新模型参数，也不需要采集遥操作数据。
  2. 相比传统监督微调，示范数据量降至 1/50，学习时间缩短约 500 倍。 文章对比表明，HOST 所需的演示次数仅为传统方法的 2%，技能获取时间相比最快的 SFT 基线缩短约 507 倍。
  3. 通过向量空间映射和动态时间规整算法实现人机动作时间差的自动对齐，显著降低进度误差。 HOST 将视频画面与机器人动作投射到同一向量空间，使用 DTW 算法自动对齐进度，使进度误差从 0.079 降至 0.006，降低一个数量级。
  4. 采用双专家 MoT 架构，分离视觉理解与动作生成，避免直接模仿人类动作带来的身体差异问题。 视觉大脑负责理解视频进度并预测未来场景，动作大脑将视觉目标转化为机器人动作，从而绕过对人类动作细节的精确模仿。
  5. 未更新模型参数使旧任务保留率高，抗灾难性遗忘，且对光照、物体替换、场景变化等干扰具有一定鲁棒性。 实验显示，HOST 在旧任务上的保留率比最好的微调基线高出 59 个百分点；在光照、物体替换、场景变化和人为移动物品等干扰下，成功率仍保持在 53%以上。

💬 文章金句

  • 机器人只要看一段 29 秒的人类演示短视频，就能当场上手干活，期间甚至完全不需要更新模型参数，也不必专门采集几十条机器人遥操作数据。
  • 相比监督微调的方案，HOST 需要的示范数量降至五十分之一，技能获取时间较最快的 SFT 基线缩短约 507 倍。
  • 于是 HOST 的研究团队想了个绝招：不看时间，看进度。他们把视频画面和机器人的动作，映射到同一个叫「向量空间」里，然后用动态时间规整算法自动对齐。
  • 但 HOST 因为全程没改模型的脑回路（参数），旧任务表现基本没受影响，比最好的微调基线高出了整整 59 个百分点！
  • 开源能够让更多研究机构和开发者参与其中。
