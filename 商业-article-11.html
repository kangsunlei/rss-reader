智谱悄悄上架天猫：Token 越来越便宜，为什么 AI 公司反而开始限量了

9/5/2026, 10:10:00 AM

📌 一句话摘要

智谱在 Token 单价下降的背景下限量并上天猫卖额度，揭示 AI 行业正从「卖模型」转向「卖调用/卖订阅」的商业模式演进，核心矛盾在于成本下降但用量激增形成的「杰文斯悖论」效应。

📝 详细摘要

本文以智谱入驻天猫售卖 Token 套餐为切入点，分析 AI 行业正在发生的商业模式变化。文章指出，尽管智谱等单位 Token 推理成本较年初下降 80%，但调用量增长超过 40 倍，导致行业普遍出现算力压力和限量策略——Kimi 暂停新用户订阅、阿里云调整 Coding Plan、腾讯云提价 460%。智谱上半年 MaaS/API 收入占比从 15.2%跃升至 86.5%，本地化部署收入占比从 84.8%骤降至 13.5%，完成商业模式换挡。作者引用杰文斯悖论解释这一现象：Token 越便宜，用户越敢让 AI 做更复杂的任务，消耗反而更快增长。文章提出 AI 商业化四阶段路径：卖模型→卖调用→卖订阅→卖端到端任务结果，并预测未来趋势是基础 Token 越来越便宜，但高级智能的价格可能上升，计费方式将从「每百万 Token 多少钱」转向「完成一个任务多少钱」。

💡 主要观点

  1. Token 单价下降与用量激增并存，形成 AI 行业的「杰文斯悖论」效应 智谱单位 Token 推理成本较年初下降 80%，但调用量增长超 40 倍；Kimi 因算力压力暂停新用户订阅，阿里云调整 Coding Plan，腾讯云 HY2.0 Instruct 输入价格涨幅超 460%。根本原因在于 Agent 模式替代 Chatbot 模式：一个复杂任务可能消耗几十万至数百万 Token，用户越用越多而非越少。
  2. 智谱完成从「卖模型」到「卖调用/卖订阅」的商业模式切换 2026 年上半年 MaaS/API 收入 8.25 亿元，占比从去年的 15.2%跃升至 86.5%，本地化部署收入占比从 84.8%降至 13.5%。API 平均售价提升约 101%，毛利率提升至 24.6%，实现成本下降、收入增长、用量激增的「不可能三角」。
  3. AI 商业化存在四阶段演进路径：卖模型→卖调用→卖订阅→卖端到端任务结果 早期模型能力有限，平台靠低价或免费吸引用户；当模型能完成代码生成、工具调用、持续执行等复杂任务后，用户购买的不再是「一个模型」而是「完成任务的能力」。计费逻辑从「每百万 Token 多少钱」转向「完成一个任务多少钱」。
  4. 基础 Token 会越来越便宜，但高级智能的使用成本未必下降 类比云计算：服务器成本下降不意味着企业云支出减少，因为用得更多了。AI 趋势类似——模型能力跃迁推动用户把更复杂的任务交给 AI，Token 消耗形成增长飞轮。智谱半年报称「模型每完成一次能力跃迁，客户购买的东西就向结果靠近一步」。

💬 文章金句

  • Token 越便宜，大家越敢让 AI 干更多事情；AI 越聪明，大家又越愿意把更复杂的事情交给它。
  • 单 Token 价格下降≠AI 使用成本下降。因为模型越强，大家让它做的事情越复杂。
  • 模型每完成一次能力跃迁，客户购买的东西就向结果靠近一步，本公司的收入结构随之改写一次。
  • 相较收入增速，收入构成的切换更值得关注。
