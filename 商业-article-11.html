对话阶跃 AI：做桌面 Agent，要比 Claude Cowork 往前一步

1/19/2026, 9:59:00 AM

📌 一句话摘要

阶跃 AI 产品负责人钟经纬分享桌面 Agent 产品背后的思考与尝试，强调比 Claude Cowork 更激进的本地化、主动式探索，并聚焦办公场景下的文件处理和信息获取。

📝 详细摘要

本文深度访谈了阶跃 AI 桌面伙伴产品负责人钟经纬，探讨了 Agent 产品的选择策略、发展方向及实践经验。文章指出，尽管 Claude Cowork 取得了成功，但阶跃 AI 选择在桌面端 Agent 上进行更激进的探索，如“全局记忆”和“悬浮窗”交互。产品团队认为 AI Agent 仍处于早期阶段，其核心挑战在于提升 Agent 能力（更稳、更快、成本更低）和提高用户渗透率（让用户认识到并学会使用 Agent）。阶跃 AI 桌面伙伴聚焦于办公场景下的文件处理和信息获取，并通过“妙计”功能简化操作、降低门槛，并探索 Agent 的主动服务能力。同时，文章也强调了模型本身的重要性与产品化、场景教育、经验沉淀、用户反馈等周边因素的结合，以及“对话形式解决任务成本最低”的理念。

💡 主要观点

  1. 阶跃 AI 桌面伙伴在桌面端 Agent 的探索上比 Claude Cowork 更进取。 阶跃 AI 推出了“全局记忆”和“悬浮窗”等功能，寻求在上下文可能性和用户体验上进行更激进的探索，并优先选择本地客户端以激发用户更大的场景想象空间和多元用户场景探索。
  2. Agent 产品的核心挑战是能力提升和用户渗透率。 关键在于让 Agent 做得更多、更稳、更快、成本更低，并通过 Skill 等方式提升能力；同时，解决用户认知不足、不清楚 Agent 能做什么的问题，提升产品渗透率。
  3. 阶跃 AI 桌面伙伴优先聚焦于办公场景下的文件处理和信息获取。 选择电脑端是因为其能深度集成浏览器和本地工具、安全获取用户资产，且办公场景任务复杂、手动成本高，用户对 Agent 的容忍度更高，可更好地体现其智能。
  4. “妙计”功能是提升 Agent 渗透率和用户教育的关键。 “妙计”通过简化操作、降低门槛、沉淀脚本资产，并作为 playbook 帮助用户建立对 Agent 能力的认知。未来将探索 Agent 的自主学习能力，即自行创建和复用“妙计”。
  5. Agent 最重要的发展方向是提供“主动服务”能力。 最终目标是 Agent 能主动识别用户需求并提供服务，解决用户“知道能用”和“知道哪里能用”的认知鸿沟。当前探索分为从核心能力切入和开放给用户设定规则两种方式，但隐私安全是重要考量。
  6. 模型本身依然重要，但产品化、场景教育等周边因素重要性也在提升。 强模型自带流量和能力突破仍在发生，但 Agent 产品落地更需要个人数据接入、场景教育、经验沉淀以及工具细节设计和用户反馈等环节的结合以实现共同进化。

💬 文章金句

  • 在现有的 Web、App 和数据库之上，叠加一层「Agent 加工层」。这一层由以用户为中心的 Agent 们组成，它们的目标不是复刻服务商既有的流程，而是围绕用户需求，构建「新结果」和「新状态」。
  • 办公场景不一样，任务往往复杂、链路长、手动成本高，即便成功率只有七成，用户也愿意反复尝试。而且办公也能更好的体现 Agent 的智能。
  • 我个人的一种理解是：在现有的 Web、App 和数据库之上，叠加一层「Agent 加工层」。这一层由以用户为中心的 Agent 们组成，它们的目标不是复刻服务商既有的流程，而是围绕用户需求，构建「新结果」和「新状态」。
  • 能力有了，但触达和引导没跟上。「主动」是解决这个问题的方法之一。
  • 对话中调用，成本最低。你只需说出任务目标，agent 自动生成或匹配「妙计」，这比去应用商店找工具、下载、再学习使用要顺畅得多。
