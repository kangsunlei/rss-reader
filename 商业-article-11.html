掌管 Codex 额度的「赛博义父」，到底什么来头

7/16/2026, 6:00:00 AM

📌 一句话摘要

本文通过追踪 Tibo（Thibault Sottiaux）的个人经历与 Codex 额度频繁重置现象，揭示了这位被开发者称为「赛博义父」的 OpenAI 核心产品负责人背后的技术背景与产品理念。

📝 详细摘要

文章详细梳理了 Tibo 的成长经历——从比利时神童式早期编程、鲁汶大学学习、在 Google DeepMind 参与 AlphaGo 等项目，到因不满内部官僚而加入 OpenAI。在 OpenAI 中，他最初负责内部工具，随后主导了 Codex 的早期形态，并在 2025 年将其公开发布。文章重点描述了 Tibo 在 X（Twitter）上频繁发布「重置 Codex 额度」的推文，这一行为被开发者们戏称为「赛博义父」，并解释了其背后的产品逻辑：通过频繁重置来应对用户爆炸式增长、平衡算力限制，以及将 Codex 与 ChatGPT、开发者 API 合并为统一的超级应用。文中还提到 Tibo 会利用 Codex 完成日常工作，如生成邮件摘要、制作面包店地图等，展示了他亲身使用自己产品的理念。整篇文章兼具人物传记、产品史和技术文化观察，兼具信息密度与有趣的叙事。

💡 主要观点

  1. Tibo 从 DeepMind 跳槽 OpenAI，因不满内部官僚而追求快速迭代。 他在 DeepMind 见识到强大模型却未及时对外发布，这促使他加入 OpenAI 以追求更快的产品落地与用户反馈。
  2. Codex 额度频繁重置背后是用户爆发式增长与算力限制的博弈。 文章引用 Tibo 自身的推文及 OpenAI 内部算力预测，说明重置是应对用户数快速增长的临时调节手段。
  3. Tibo 亲身使用 Codex 完成日常工作，体现「吃自己的狗粮」理念。 他利用 Codex 生成邮件摘要、制作面包店地图等，展示了产品在真实工作流中的实用价值。
  4. Codex 正在向通用本地 Agent 方向演进，并将与 ChatGPT、API 合并为超级应用。 OpenAI 内部重组将 ChatGPT、Codex 和开发者 API 整合，Tibo 负责统一执行，旨在构建面向十亿用户的统一入口。
  5. 「赛博义父」的网络形象实际上是产品体验的一部分，为抽象 AI 系统提供了可感知的人脸。 作者指出，Tibo 在社交媒体上的互动让看不见的 AI 系统拥有了可沟通的「面孔」，增强了用户的信任感与参与感。
