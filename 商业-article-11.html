微软大会拉来 Altman、马斯克，纳德拉的 AI Agent 野心藏不住了

5/20/2025, 10:26:00 AM

📌 一句话摘要

微软 Build 2025 大会全面聚焦 AI Agent，推出跨平台开发工具和愿景，构建开放智能体网络。

📝 详细摘要

文章报道了微软在 Build 2025 大会上将 AI 战略全面转向 AI Agent，并由 CEO 纳德拉提出构建“开放智能体网络”（Open Agentic Web）的愿景。大会引人关注的是 Sam Altman 和伊隆・马斯克都通过连线参会，尽管坊间有微软与 OpenAI 存在分歧的传言，但这反而凸显了微软寻求更开放模型生态的背景，并官宣引入 xAI 的 Grok 模型。大会发布了多项支持 AI Agent 开发和应用的新能力，包括增强 GitHub Copilot 的 Agent 功能、推出 Windows AI Foundry 和 Azure AI Foundry Agent Service，并重点支持 MCP、NLWeb 等开放协议，以及 Entra Agent ID 等安全机制，旨在降低开发者创建、管理和部署 AI Agent 的门槛。微软还深化了 AI Agent 在 Microsoft 365（如 Copilot Tuning、多智能体编排）和特定领域（如科研领域的 Discovery）的应用。尽管 Agent 化带来了平台变革潜力，但也对隐私、就业等社会层面带来潜在影响。

💡 主要观点

  1. 微软将 AI 战略核心转向 AI Agent，并描绘 Open Agentic Web 蓝图。 这标志着微软 AI 布局从 Copilot 助手向更自主、能处理复杂任务的智能体演进，旨在打造下一代互联网应用生态，并在大会上提出了构建“开放智能体网络”的愿景。
  2. 推出跨平台开发者工具和开放标准赋能 Agent 构建与部署。 通过 Azure AI Foundry、Windows AI Foundry 等平台及增强的开发工具，降低开发者创建、管理和部署 AI Agent 的门槛。特别是对 MCP 和 NLWeb 等开放协议的支持，体现了构建开放生态的努力。
  3. 在核心产品中深度集成 AI Agent 能力以提升效率。 GitHub Copilot、Microsoft 365 Copilot 等产品智能化升级，支持用户定制（如 Copilot Tuning）和编排多 Agent 完成复杂工作流，提高个人和企业生产力。
  4. 引入多元模型支持并加强 Agent 生态安全与管理。 大会宣布引入 xAI 的 Grok 模型，扩大模型生态选择。同时，推出 Entra Agent ID 等身份管理系统，为 Agent 提供专属身份和权限控制，确保安全性并促进有序发展。

💬 文章金句

  • 微软的 AI 叙事，今年全面走向 AI Agent。
  • 让更多的应用程序由智能体驱动，打造一个「Open Agentic Web（开放智能体网络）」。
  • 微软正在提供对模型上下文协议（MCP）的全面支持，微软和 GitHub 方面已经加入了 MCP 相关委员会，以帮助推进 MCP 的大规模采用。
  • 微软正在推出一个名为 NLWeb 的开放项目，称其「在智能体网络中可以发挥与 HTML 类似的作用」。
  • 我们从几个垂直集成堆栈的应用程序，发展成为一个能够支持这个开放可扩展智能体网络的平台。
