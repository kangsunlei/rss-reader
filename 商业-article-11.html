专访 GMI Cloud 创始人 Alex Yeh：算力即未来，不做 AI 时代的旁观者

4/14/2025, 9:29:19 PM

📌 一句话摘要

GMI Cloud 创始人 Alex Yeh 分享 AI Infra 创业经验，强调算力基础设施的重要性，并将 GMI Cloud 定位为 AI 领域的 “Shopify”， 致力于解决 AI 推理成本高昂的问题，提供灵活、自主可控的云服务。

📝 详细摘要

GMI Cloud 创始人 Alex Yeh 在采访中分享了其在 AI Infra 领域的创业历程与思考。他强调了算力在 AI 时代的重要性，并将 GMI Cloud 定位为 AI 领域的 “Shopify”，旨在为 AI 创新者提供灵活、自主可控的云服务环境， 解决 AI 推理成本高昂的问题。文章详细介绍了 GMI Cloud 在 AI 推理引擎方面的技术创新，包括自扩容 (Auto Scaling)、全球扩容 (Global Scaling) 和热切换 (Hotswap) 等特性，以及如何通过 PD 分离、EP 等技术优化降低 Token 成本。此外，Alex 还分享了对通用 Agent 发展趋势的看法，认为短期内垂直领域的 Agent 应用更有机会落地。面对与大型云厂商的竞争，GMI Cloud 致力于成为全栈式的 AI 云服务公司，加速 AI 应用落地，支持 AI 产业的创新与发展。

💡 主要观点

  1. AI 推理引擎需具备自扩容 (Auto Scaling)、全球扩容 (Global Scaling) 和热切换 (Hotswap) 能力 这些特性保证了 AI 应用在推理阶段的可靠性和可扩展性，降低了因机器宕机对客户的影响，提升了用户体验。
  2. B 端创业需找到锚定客户，并拼命迭代产品方案 通过与客户的持续沟通，了解其需求和反馈，不断打磨产品，实现客户的所想所需，是 B 端创业成功的关键。
  3. 通用 Agent 的爆发时机未到，垂直场景更有机会落地 模型与物理世界的交互能力、算力成本和数据整合是制约通用 Agent 发展的主要因素，而特定领域的 Agent 应用已取得突破。
  4. 云厂商需通过技术创新降低 Token 成本，提升性价比 在保证性能的前提下，通过 PD 分离、EP 等技术降低 Token 成本，同时考虑本土化需求，为客户提供更具竞争力的 AI 云服务。
  5. GMI Cloud 定位为 AI 领域的 “Shopify”， 旨在为 AI 创新者提供灵活、自主可控的云服务环境 GMI Cloud 致力于将 Environment 归还给客户，在产品设计上给客户留足了选择的空间， 提供了 GPU Instance、Cluster Engine、Inference Engine 三层服务， 允许用户彼此独立购买，也可以一起购买。

💬 文章金句

  • 对于 AI 创业而言，你不可能一开始就能预测到它具体的未来形态，也不知道具体会在何时迎来爆发。但你必须有一个保持十年的 TrueNorth。它就如同航空母舰一样，不可动摇。
  • 我们想把 Envrionment 归还给客户。
  • 我们是 "Shopify of AI"
  • 只把成本砍到最低，但稳定性不能保证也是没有意义的。又或者说你虽然在美国最便宜，但客户需要在亚洲地区实施业务，本土化的 '性价比' 才是客户最看重的。
  • 我觉得这是一个超级酷的事情，我想要做一个隐形的 GPU 云网络，当一个隐形的 support 的角色，去支持那些创业团队或企业内的创新者去实现自己心中的 AI 产品。
