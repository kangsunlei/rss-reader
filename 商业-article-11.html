OpenAI 硬件负责人的闭门分享，向我们揭示了为什么硬件「终点」仍是智能手机

4/28/2026, 11:47:00 AM

📌 一句话摘要

本文基于 OpenAI 硬件负责人 Richard Ho 的闭门分享，深入分析了 OpenAI 自研芯片、操作系统及智能手机的底层逻辑，指出其核心目标是从模型公司转型为全栈系统公司，以 agent 为中心重新定义计算范式。

📝 详细摘要

文章以 OpenAI 硬件负责人 Richard Ho 在斯坦福的闭门分享为核心线索，结合 OpenAI 即将推出智能手机的传闻，系统阐述了 OpenAI 的硬件战略。文章指出，OpenAI 做手机并非跨界，而是其从模型公司向基础设施公司、再向设备公司转型的自然结果。Richard Ho 强调，GPU 并非为 Transformer 和 agent 等 AI 负载设计，OpenAI 必须自研芯片和系统以突破算力、能耗和延迟瓶颈。文章对比了 Rabbit R1、Meta Ray-Ban 和阿里千问眼镜等 AI 硬件路径，认为 OpenAI 是唯一一家试图从芯片、基础设施、操作系统到设备进行全栈重构的公司。最终结论是，未来的竞争将在系统层展开，计算范式正从 app 为中心转向 agent 为中心，这将重新定义一切。

💡 主要观点

  1. OpenAI 做手机是其从模型公司向全栈系统公司转型的必然结果。 文章认为，OpenAI 做手机并非跨界，而是其自研芯片、操作系统和基础设施战略的自然延伸，目的是在 agent 时代掌握从底层芯片到终端设备的完整控制权。
  2. 当前 GPU 架构并非为 AI 负载设计，自研芯片是突破瓶颈的关键。 Richard Ho 指出，GPU 是为通用并行计算设计的，面对 Transformer、agent 和长上下文推理等 AI 负载，效率低下。OpenAI 必须自研芯片，为未来 6-9 个月的模型演进进行定制化设计。
  3. 现有手机操作系统（iOS/Android）不是为 agent 设计的，需要被重写。 Agent 需要持续存在、跨任务协同和系统级权限，这与当前 app-based、session-based 的交互范式冲突。OpenAI 需要自研操作系统来释放 agent 的全部潜力。
  4. 未来的 AI 竞争将从模型层转向系统层。 Richard Ho 认为，真正的护城河在于系统级的优化能力，即在相同功耗下提供更多计算、更低延迟。这需要从芯片、网络、能源到设备进行端到端的整合。

💬 文章金句

  • 你必须为模型将要去的方向设计硬件，而不是为今天的模型。
  • 真正的限制不再只是模型，而是算力、能耗、成本、延迟，是整个系统。
  • 手机不是为 agent 设计的。
  • （模型公司）不再是在芯片层赢，而是在系统层赢。
  • 未来不是 cloud-only，也不是 edge-only，而是两者结合。
