“4.1 淘汰 4.5 ！”OpenAI 发布升级版 GPT-4.1 全家福：推理、编程性能升级

5/15/2025, 3:18:00 AM

📌 一句话摘要

OpenAI 发布 GPT-4.1 系列模型，提升编程和指令执行能力，提供不同规模和价格选项，并集成到 ChatGPT。

📝 详细摘要

文章报道了 OpenAI 正式推出 GPT-4.1、GPT-4.1 mini 和 GPT-4.1 nano 三款新模型。核心亮点是 GPT-4.1 在编程和指令执行方面相比前代（包括 GPT-4o 和研究预览版 GPT-4.5）有显著提升，特别是在软件工程基准测试中表现出色。文章详细介绍了各模型的特点：GPT-4.1 mini 将成为 ChatGPT 免费用户的默认模型，而 GPT-4.1 nano 则主打低延迟和成本效益。同时，文章提供了 API 定价信息，并提及 GPT-4.1 支持高达 100 万 token 的上下文窗口。最后，文章指出 OpenAI 已将原先仅限 API 使用的 GPT-4.1 系列集成到 ChatGPT 平台，并提及了模型安全评估和透明度方面的讨论。

💡 主要观点

  1. GPT-4.1 系列模型在编程和指令执行方面性能显著提升。 新的 GPT-4.1 在 SWE-bench 和 MultiChallenge 等基准测试中超越了 GPT-4o 和 GPT-4.5，特别优化了工程师使用 ChatGPT 时的效率。
  2. OpenAI 推出了不同规模和性能的新模型以满足多样化需求。 GPT-4.1 mini 作为免费默认模型，GPT-4.1 nano 提供高速低成本特性，与 GPT-4.1 共同服务于不同场景和用户群。
  3. 新模型已集成到 ChatGPT 平台，提升用户可访问性。 用户现在可以通过 ChatGPT 界面选择和使用 GPT-4.1 系列模型，方便日常使用，响应了用户仅限 API 的不满。
  4. GPT-4.1 支持超长上下文窗口，扩展了企业级应用场景。 100 万 token 的上下文窗口使 GPT-4.1 API 适用于处理大型文档或代码库，如多文档审阅和财务分析。

💬 文章金句

  • GPT-4.1 模型将帮助软件工程师在使用 ChatGPT 编写或调试代码时获得更高效的支持。
  • 在 SWE-bench Verified 软件工程基准测试中，GPT-4.1 得分 55%，较 GPT-4o 的 33%提升了 22%。较 GPT-4.5 的 38%提升了 17%，可以说是"4.1 完胜和淘汰了 4.5"。
  • 对于对低延迟要求较高的任务，GPT-4.1 nano 是 OpenAI 目前速度最快、成本最低的模型。
  • 我们原计划只在 API 中提供该模型，但大家都希望能在 ChatGPT 中使用它。祝大家编码愉快！
