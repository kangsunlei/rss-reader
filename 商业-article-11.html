独家对话 OpenAI 姚顺雨：生成新世界的系统

9/11/2025, 9:55:00 AM

📌 一句话摘要

OpenAI 研究员姚顺雨深度解析 AI Agent 的发展历程、核心能力与未来方向，强调语言在实现通用智能体中的关键作用及交互方式的创新潜力。

📝 详细摘要

文章独家对话 OpenAI 研究员姚顺雨，深入探讨 AI Agent（智能体）的演进历程与未来趋势。姚顺雨从个人经历出发，阐述了其从计算机视觉转向语言模型，并最终专注于 Language Agent 研究的非共识路径。他强调语言作为实现泛化通用系统最本质的工具，并指出 GPT 模型在开放行为空间决策上的优势远超 BERT。文章详细梳理了 Agent 从符号主义 AI 到深度强化学习，再到大语言模型驱动的 Agent 的三波发展浪潮，并提出当前 Agent 研究的核心在于任务和环境的定义，而非模型方法本身。他认为，代码是 AI 最重要的“affordance”，与人的手类似，是 Agent 实现通用能力的基石。访谈还讨论了 OpenAI 模型能力分级（L1-L5）的内在逻辑，并指出 Agent 发展的两大关键方向：自我奖励机制（Intrinsic Reward）和多智能体协作（Multi-Agent），对应着个体创新者（Innovator）和组织者（Organizer）的未来形态。姚顺雨深入探讨了“泛化”的本质，认为语言模型通过推理能力实现了跨任务的泛化。最后，他预测创业公司在设计超越现有模式的新颖交互方式上存在巨大机会，并对 Agent 的长期记忆和内生奖励机制的突破表示乐观。

💡 主要观点

  1. 语言是实现通用人工智能和泛化智能体最本质的工具，其推理能力是关键。 姚顺雨强调语言作为人类发明的通用工具，其独特的泛化能力使得基于语言模型构建的 Agent 能够进行跨任务推理和适应新环境，这是传统 AI 难以达到的。
  2. AI Agent 发展的核心瓶颈已从模型方法转向定义好的任务与环境。 随着大语言模型提供通用方法，当前重点在于如何设计具有挑战性、基于结果且白盒规则化的任务和环境，以驱动 Agent 实现有价值的真实世界应用。
  3. 创业公司在设计超越现有模式的新颖交互方式上存在巨大机会。 姚顺雨指出，目前的想象力仍受限于传统交互方式，未来 Agent 将催生“Super App”等超越现有模式的交互，这为创业者提供了颠覆性创新的空间。
  4. 长期记忆和内生奖励机制是 Agent 迈向创新者和组织者的关键能力。 具备长期记忆能支持 Agent 进行复杂、长期的任务，而内生奖励机制则能驱动 Agent 在缺乏外部反馈时进行自我探索和创造，这对应着 AI 向更高级智能形态演进。

💬 文章金句

  • 创业公司最大的机会是：能够设计不同的 interface（交互方式）。
  • 语言是人为了实现泛化而发明出来的工具，这一点比其他东西更本质。
  • Code 有点像人的手。它某种程度上，是 AI 最重要的 affordance（环境给予行动者的可能性）。
  • 我一直有这个非共识：我想要去做 Agent。
  • 也许，这个世界在变得越来越单极的同时，也在变得越来越多元。
