本周 AI 项目推荐：Link、Agentic Wallets、Token Pay——Token 支付底座长啥样

6/28/2026, 3:47:00 AM

📌 一句话摘要

本文梳理了 Stripe、Coinbase、Skyfire、支付宝等公司在 AI Agent 支付领域的近期实践，指出 Token 正从充值会员费转变为 Agent 间流通的一般等价物，并分析了各方案的进展与局限。

📝 详细摘要

文章围绕 AI Agent 支付基础设施这一新兴主题，介绍了四条主要路线：Stripe 用 SPT 和 MPP 构建 Agent 经济基础设施，允许 Agent 在用户授权下自主完成支付，但尚未覆盖真正的 A2A 交易；Coinbase 推出 Agentic Wallets 和基于 HTTP 402 的 x402 微支付协议，让 Agent 自主持有和支出资金，但面临非加密场景落地难题；Skyfire 通过 KYAPay 协议给 Agent 发放加密身份凭证，解决准入和结账问题，但依赖生态采纳；支付宝 Token Pay 面向 MaaS，提供随用随充、企业分发和灵活计费方案，但账单可控性仍是挑战。文章指出这些方案虽路径不同，但都在回答同一个问题：当 Agent 成为互联网新行动者时，需要什么样的身份、钱包和风控系统。当前 Token Economy 处于混乱生长阶段，最终胜负取决于谁先跑出足够多的非币圈场景。

💡 主要观点

  1. Token 正从 Agent 充值会员费转变为 Agent 间流通的一般等价物。 文章提出核心视角：Agent 的使用、雇佣、交易都用 Token 来锚定，Token 不再只是给 Agent 充值的费用，而是变成 A to A 的流通货币，围绕它会产生新的支付基础设施和经济范式。
  2. Stripe 的 SPT 和 MPP 是目前最接近 Agent 经济基础设施的方案，但仍停留在人类授权下的消费。 Stripe 通过 Shared Payment Tokens 限制支付条件和 Machine Payments Protocol 让 Agent 直接与商家交易，但 Agent 不能自主赚钱和雇佣其他 Agent，真正 A2A 闭环未完成。
  3. Coinbase 的 x402 协议试图用一次 HTTP 请求完成微支付，但非加密场景接受度存疑。 x402 让 Agent 在访问 API 时直接完成稳定币支付，无需注册和签约，但稳定币支付尚未被主流互联网服务采用，标准之争（AP2 vs x402）结局未定。
  4. Skyfire 解决 Agent 的“身份准入”问题，但需生态广泛承认。 Skyfire 的 KYAPay 将身份、授权和支付压缩进同一 Token，解决 Agent 像爬虫一样无身份的问题，但协议价值取决于被多少网站、API 和支付网络认可。
  5. 支付宝 Token Pay 面向 MaaS，但账单控制和计费灵活性比支付方式更重要。 Token Pay 提供随用随充、企业分发和灵活计费，但 Agent 自行充值可能导致账单不可控，一套灵活的计量计费规则是更关键的问题。

💬 文章金句

  • Token 不再是给 Agent 充值的会员费，而是变成 A to A 的流通货币。
  • 不是给 Token 找支付方式，而是给 Agent 找经济身份。
  • 现在 Agent 在互联网上一个最大的问题是像个'黑户'，它访问网站像爬虫。
