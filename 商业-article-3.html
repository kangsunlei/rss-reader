Windows 跑在智能手表上，开发者“魔改”震惊网友：这次是真 Windows on Arm

4/2/2025, 10:27:13 AM

📌 一句话摘要

开发者 Gustave Monce 成功将 Windows 移植到 Google Pixel Watch 3 智能手表上，展示了在 Arm 设备上运行 Windows 的可能性。

📝 详细摘要

本文介绍了开发者 Gustave Monce 将 Windows 操作系统移植到 Google Pixel Watch 3 智能手表上的过程。Monce 是一位热衷于在非传统设备上运行 Windows 的极客，他曾成功在旧手机和双屏手机上运行 Windows 11。这次，他选择智能手表作为新的挑战目标，通过分析 Pixel Watch 3 的硬件和启动方式，利用 UEFI 启动系统，并解决了一系列技术难题。 他创新性地精简 Windows PE 系统，并利用 A/B 分区机制解决了存储空间限制问题，最终成功在智能手表上启动了 Windows PE 简化版，验证了在智能手表上运行 Windows 的可行性。这一项目展示了 Windows on Arm 的潜力，并引发了网友的关注和讨论。

💡 主要观点

  1. UEFI 启动系统是 Windows 移植到智能手表的关键 Pixel Watch 3 采用 UEFI 启动，与 PC 启动方式相似，为运行 Windows 提供了可能性，降低了移植难度。
  2. 解决存储空间限制需要精简系统和利用 A/B 分区机制 由于手表存储空间有限，开发者通过精简 Windows PE 系统，并利用 A/B 分区机制，将启动文件写入未使用的分区，解决了存储问题。
  3. 开发者需要具备解决系统兼容性问题的能力 面对 Google 推送的 Android 15 更新导致 UEFI 启动文件无法通过验证的问题，开发者需要修改内核头文件才能解决兼容性问题。
