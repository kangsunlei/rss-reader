算力成本是 AI 全面落地的关键瓶颈

10/8/2026, 2:28:29 AM

📌 一句话摘要

认为 AI 渗透仍处早期，核心制约因素是 Token 价格过高；预测当算力便宜到像电力一样不被关注时，才是 AI 真正普及的标志。

📝 详细摘要

作者指出当前 AI 在各行业的应用尚属早期，即便是程序员群体也未完全依赖 AI。根本原因在于算力成本高昂，Token 价格相比传统能源（电力）过于昂贵。作者类比电力发展史，提出 AI 成熟的标志是用户不再关心 API Token 价格。最后引导读者进行思想实验：假设拥有无限低成本算力，会如何改变工作方式，以此反思当下。

💡 主要观点

  1. 成本决定 AI 普及速度 目前个人和中小企业因 Token 费用高昂而限制使用，只有当边际成本趋近于零（类似电力），大规模融合才可能发生。
  2. 未来导向的思维实验 通过构想“无限低成本算力”下的应用场景，可以帮助个体和企业提前布局，识别那些受限于当前成本但具备巨大潜力的业务模式。

💬 文章金句

  • 如果 token 是 AI 时代的新的能源， 那么它和电力这样的能源相比价格实在太贵了。
  • 未来 AI 发展的重要的标志应该是 AI 算力价格低到人们不用太关心 API token 的价格
