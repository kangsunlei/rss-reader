iPadOS 26 可能用来办公，但用 iPadOS 26 办公有点不可能

6/24/2025, 12:07:07 PM

📌 一句话摘要

评估 iPadOS 26 新特性对办公生产力的影响，分析其触控与键鼠交互下的 UI 矛盾。

📝 详细摘要

文章深入分析了 iPadOS 26 在 WWDC25 上发布的多任务窗口和文件管理新功能。虽然这些更新借鉴了 macOS，旨在提升 iPad 的生产力，但作者指出，新的窗口交互存在别扭之处，且移除了曾经便于快速查询或消息回复的 Slide Over 功能带来不便。更核心的问题在于，iPadOS 为兼顾触控和键鼠两种操作方式，导致 UI 元素偏大，影响了信息密度和在传统办公软件（如 Excel）中的操作效率。文章认为 iPad 在创意等触控优先领域已具备生产力，但在传统键鼠驱动场景仍受限，并提出应将焦点从“iPad 有无生产力”转移到“用 iPad 能创造什么”。

💡 主要观点

  1. iPadOS 26 引入 macOS 式窗口与文件管理 新的多窗口机制和增强的文件 app 功能，如分栏显示和预览 app，使 iPad 在基础操作上更接近传统电脑，提升了部分便利性。
  2. 新交互设计在触控与键鼠间存在矛盾 窗口“甩出”操作、Exposé手势与 macOS 习惯冲突，同时支持两种输入方式导致 UI 妥协，影响信息密度和效率。
  3. 传统办公场景（如 Excel）效率受 UI 设计制约 为适配触控，iPadOS 的界面控件偏大，在处理复杂表格等键鼠密集操作时，效率远低于为键鼠优化的 macOS。
  4. iPad 的生产力优势体现在触控和创意领域 文章强调 iPad 在绘画、设计等依赖 Apple Pencil 和触控的创意工作流程中已成功开辟了自己的生产场景。
  5. 应关注用 iPad 创造价值而非是否有生产力 结论引导读者停止争论 iPad 是否是“真电脑”，转而思考其在特定应用场景中独特的价值和创造潜力。

💬 文章金句

  • 毕竟现在的 iPad 使用着和 Mac 几乎一模一样的 SoC，iPad 作为平板电脑和真电脑之间的差距，几乎就只剩下 iPadOS 了。
  • 这真的是一个非常奇怪且别扭的功能。
  • 这归根结底还是因为 iPad 需要同时满足手指和键鼠两种不同的交互方式，导致必然会有一部分显示上的浪费。
  • 因此，也许是时候停止追问「iPad 有没有生产力」这个问题了。相比之下，人们更该问的是：我可以用 iPad 创造出什么？
