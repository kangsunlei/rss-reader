巨头的新战场：AI 编程 IDE（暨 字节 Trae 调用 MCP 教程）

4/22/2025, 7:08:03 AM

📌 一句话摘要

文章解析 AI 编程 IDE 成为巨头新战场的原因，并以字节 Trae 调用 MCP 为例，展示其巨大潜力。

📝 详细摘要

文章分析了 OpenAI 收购 Windsurf 和字节跳动整合 MarsCode 为 Trae 的背后原因，**核心在于** MCP 协议的出现，它是 AI IDE 成为巨头必争之地的关键。文章详细介绍了 MCP 的概念，即 AI 与外部应用之间的适配层，并以 Trae 为例，演示了如何通过 MCP 调用外部应用（如 Puppeteer）来扩展 AI 的功能。此外，文章还简要介绍了 Trae 的新版本中增强的上下文功能，包括添加文档集和使用网上信息作为上下文，从而为 AI 提供实时联网能力。最后，文章总结认为，有了 MCP 调用和联网能力，AI IDE 将成为一个无所不能的 AI 控制台。

💡 主要观点

  1. MCP 协议是 AI IDE 扩展外部能力的关键 MCP 作为 AI 与外部应用之间的适配层，使得 AI 可以通过统一的格式接入各种外部应用，无需了解其接入细节，极大地扩展了 AI 的功能。
  2. Trae 通过 MCP 调用实现了对外部应用的控制 Trae 通过内置的 MCP 市场和手动配置，可以轻松添加各种 MCP 服务器，如 Puppeteer，从而使 AI 具备了控制浏览器的能力。
  3. 上下文功能增强了 AI 的理解和推理能力 Trae 通过提供额外的代码、文件、目录、文档和网上信息作为上下文，帮助 AI 模型更好地理解和完成任务，尤其是联网能力让 AI 可以获取实时信息。

💬 文章金句

  • 有了 MCP 以后，AI IDE 可以扩展外部能力，从而无所不能，这让它成为巨头的必争之地。
  • MCP 可以理解成一个 AI 与外部应用之间的适配层。
  • 我认为，在 AI IDE 里面调用 MCP 服务器，将成为近期软件业的热点，值得大家重点关注。
