不再吃老本的高达新游戏，终于像个“大作”了

9/11/2026, 2:24:00 PM

📌 一句话摘要

万代南梦宫新作《高达 异轨征途》以原创世界观和「狩猎巨型怪物」玩法取代情怀路线，试玩显示其动作底子扎实、规格换代，是高达 IP 为扩展新受众而主动「离经叛道」的一次尝试。

📝 详细摘要

本文基于作者受邀在上海试玩《高达 异轨征途》的体验，分析这款高达新作的定位与设计逻辑。文章指出，该作几乎剥离了系列情怀要素：全新世界观、非传统造型的主角机「螺旋高达」，敌人也由人类内部斗争改为外星怪兽「启示」，因而被部分老粉质疑「不算高达」。试玩显示，其战斗核心是围绕巨型 Boss 的部位破坏与「以小博大」，制作人富山勇也此前曾负责《噬神者 3》，「高达怪猎」的定位顺理成章。文章进一步分析，传统高达游戏中迎战巨型 MS 的体验并不舒适，而四足着地的「野兽」型 Boss 更利于观察动作与攻击部位。在机甲手感上，游戏保留三维移动、气槽管理与自由改装，并通过推进器细节与速度变化建立操纵感。最后，文章将新作放回高达 50 周年的商业语境：高达 IP 销售额已超 2500 亿日元，但游戏长期是模型与动画的附庸，扩展新客群成为必然选择，而「离经叛道」本就是高达系列延续生命力的方式。

💡 主要观点

  1. 《异轨征途》主动剥离高达情怀要素，转向原创世界观与「狩猎巨型怪物」玩法，以扩展新受众 新作世界观全新，主角机造型偏离传统高达，敌人从人类内部斗争改为外星怪兽「启示」，因此自公布起就收到「不承认这是高达」的回应。制作人采访印证，这是为了降低新人入坑门槛、用成熟玩法吸引新用户。
  2. 战斗核心是围绕巨型 Boss 的部位破坏与「以小博大」，制作人履历让「高达怪猎」的定位顺理成章 试玩两关的重头戏都是击败大型 Boss，部位破坏伴随慢动作、音效与大量扣血的正反馈，鼓励玩家围绕「拆部位」做文章。制作人富山勇也此前负责《噬神者 3》，同样是「巨型荒神＋部位破坏」的动作游戏。
  3. 传统高达游戏中迎战巨型 MS 的体验并不舒适，四足着地的「野兽」型 Boss 更利于动作观察与部位攻击 超大型 MS 继承高挑机设、站姿挺直，玩家在地面只能攻击腿部，纵向机动有限，攻击手臂头部时体验别扭。而趴伏姿态的 Boss 绝大多数部位可从地面攻击，横向剪影也更易判断出招，「德雷克」即采用此思路。
  4. 游戏通过三维移动、气槽管理与自由改装建立机甲操纵感，动态操控弥补了静态造型的争议 游戏保留日式机器人题材常见的喷射槽、推进飞行与闪避，并支持头部、躯干、四肢等零件改装。试玩中三台预设配装手感差异明显，如「吉尔达」空中闪避更轻盈并自动发射追踪光弹。作者认为高速自由的操作反馈足以让人忽略造型上的不符预期。
  5. 高达 IP 商业价值巨大但游戏长期是模型与动画的附庸，扩展客群成为新作诞生的必然背景 按万代南梦宫财报口径，高达系列集团销售额已超 2500 亿日元，官方将「进一步扩大粉丝群体」列为目标。但多数高达单机游戏商业上依附于模型与动画，素质难匹配 IP 地位，因此需要一款规格对得起 IP 的单机作品。

💬 文章金句

  • 如非必要，勿增 AI。
  • 真正决定游戏好不好玩的，依然是人对「什么样的自由会带给玩家乐趣」的理解。
  • 玩家是不需要被纠正的。
  • 它就只是游戏，游戏核心还是创造一种令人沉浸的体验，加入 AI 的目标应该是增强这种体验。
