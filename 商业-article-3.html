大厂的 Agent 竞争有了哪些新趋势｜窄播 Weekly

6/7/2026, 3:48:00 PM

📌 一句话摘要

本文梳理大厂 Agent 竞争的最新趋势，指出竞争焦点正从 Coding Agent 向通用生产力场景泛化，并围绕产品整合、生态建设与上下文积累四条主线展开。

📝 详细摘要

文章以《窄播 Weekly》第 93 期形式，总结近期大厂 Agent 产品动态（微软 Scout、OpenAI Codex 整合、微信 Agent、千问第三方 Skill 等），提炼出四条竞争主线：1）生产力场景成为焦点，Agent 被定位为「同事」；2）内部产品整合加速，Chatbot 与 Agent 走向融合，原有互联网服务以 Skill 形式接入；3）第三方生态建设提上日程，千问、微信、OpenAI 均开放插件或 Agent 平台；4）上下文积累成为关键，既涉及用户端多源信息对齐，也涉及开发端模型与产品团队的协同。文章认为，这些趋势最终指向 Coding Agent 向通用场景的系统级泛化。

💡 主要观点

  1. Agent 竞争焦点从 Coding Agent 向通用生产力场景泛化。 微软 Scout、OpenAI Codex 升级、豆包专业版等产品均瞄准办公、数据分析、设计等非开发场景，知识工作者增速已超开发者。
  2. 大厂加速内部产品整合，Chatbot 与 Agent 走向融合。 OpenAI 整合 ChatGPT 和 Codex，将对话入口升级为 Agent 协同界面；字节、美团、腾讯等将原有互联网服务以 Skill 形式接入 AI 产品。
  3. 第三方 Agent/Skill 生态建设成为下一阶段关键。 千问向第三方开放 Agent 运营，微信接入美团并与手机厂商建立 Agent to Agent 连接，OpenAI 推出 Agent 插件并计划开放第三方部署。
  4. 上下文积累成为 Agent 体验的核心瓶颈。 姚顺雨指出模型需要足够好的输入，用户端需积累多源上下文，开发端需建立模型与产品团队的协同反馈机制，这既是技术问题也是组织问题。

💬 文章金句

  • Coding Agent 成为一种执行任务的通用方案，并与 Chatbot 走向融合。
  • 过去很多传统应用的功能，要转换成可被智能体调用的能力，才能够把过去多年积累下来的价值进一步释放出来。
  • 模型越来越擅长把复杂输入变成输出，但前提是它能拿到足够好的输入。
