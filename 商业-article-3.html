顶级 Vibe Coding 应用评测：Cursor、Claude Code、Lovable 等

11/3/2025, 7:32:52 PM

📌 一句话摘要

本文对顶级 Vibe Coding 应用（如 Cursor、Claude Code 和 Lovable）进行了排名，为技术和非技术开发者在工具选择、信任和心态方面提供了见解。

📝 详细摘要

本文是 Greg Isenberg 和 Mickey 之间对话的实录，评估并排名了各种 Vibe Coding 应用程序，包括 Cursor、Claude Code、Lovable、v0、Bolt、Windsurf 和专注于移动端的平台，如 Rork 和 VibeCode App。他们根据工具对技术开发者和非技术构建者的适用性进行分类，强调了对底层团队和工具生态系统（社区、集成）的信任的重要性。主要见解包括 Cursor 强大的社区和代理能力，Claude Code 最近的性能下降，以及 v0 由于 Vercel 集成和可重用组件而对非技术用户具有优势。讨论还强调了移动 Vibe Coding 应用程序的新兴趋势，并为非技术构建者提供了关键建议：培养坚韧的心态，理解使用 AI 构建高质量软件仍然需要时间、计划和坚持。

💡 主要观点

  1. 在选择 AI 编码工具时，对开发团队的信任和强大的生态系统是至关重要的因素。 用户将时间和精力投入到工具中；一个稳定的团队和一个强大的社区（如 Cursor 的社区）提供必要的支持、文档和长期的可靠性。
  2. 不同的 AI 编码工具适用于不同的用户群体：技术开发者与非技术构建者。 像 Cursor 和 Claude Code 这样的工具适用于熟悉技术概念的开发者，而像 v0 和 Lovable 这样的平台旨在为非技术用户抽象复杂性。
  3. 非技术用户必须培养坚韧的心态，认识到使用 AI 构建软件需要时间和坚持。 尽管有 AI 辅助，软件开发仍然很复杂。用户应该预期迭代、失败和规划的需要，而不是即时、完美的解决方案。

  • Cursor 的代理，它建立在 Claude Code 之上，赋予了它读取、编写、编辑的所有这些能力，可能实际上使它比 Claude Code 本身更好，对吧？
  • 你的第一个版本失败了。你使用了 Lovable，它崩溃了。好吧，那又怎样？你换一个工具，然后重试，对吧？我认为心态需要转变为理解软件是困难的。
  • 很多人，如果他们进行了五次提示而没有构建出任何东西，他们就会感到沮丧。恕我直言，是什么让你认为你可以构建一个功能齐全的软件，人们会使用它、关心它，甚至会为之付费？
