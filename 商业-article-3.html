#540.AI Agent 的达尔文时刻：技术重构、多模型博弈与未来软件三分天下

5/17/2026, 8:34:31 PM

📌 一句话摘要

Tasklet 创始人 Andrew Lee 深度分享 AI Agent 平台六个月全栈重写、上下文管理革命、从单一模型信徒到多模型中立平台的战略转型，并预言未来仅三类软件公司能存活。

📝 详细摘要

本期播客克隆自《Cognitive Revolution》，对话 Tasklet 创始人兼 CEO Andrew Lee。Andrew 坦诚分享了其 AI Agent 平台在过去六个月的彻底重构：从工作流自动化转向通用 Agent，并将整个技术栈包括上下文管理、Computer Use 和集成架构全部推倒重来。核心技术创新在于用文件系统取代长聊天记录，通过分桶压缩和缓存感知策略控制成本。Andrew 还首次袒露了从几乎 all-in Anthropic 到果断拥抱多模型平台的心路历程，直面与模型供应商（Anthropic）之间既合作又竞争的微妙关系，并揭示了其 80% 流失用户流向 Claude Max 的残酷现实。他由此提出作为中立仲裁者的「Harness 机甲」理念，帮助企业押注所有模型。最后，Andrew 抛出一个惊人预测：未来仅存三类软件公司——横向通用平台、Headless API 公司、以及直接售卖结果的解决方案公司。节目还涵盖了对模型性格差异、共享大脑计划、企业级信任基础设施（回滚、审核）等前沿话题的探讨。

💡 主要观点

  1. 将聊天历史存入文件系统，而非直接喂给 LLM，是控制成本并支持无限扩展的关键 Tasklet 将历史状态移入文件系统，发送给 LLM 的只是提示。通过按时间分桶的智能压缩和缓存感知策略，实现了对长周期 Agent 任务（如一年内运行万次）的支持，且不会导致成本崩溃。
  2. 从单一模型押注转向多模型中立平台，是企业级客户的必然选择 面对 Anthropic 通过补贴 Max 订阅导致的用户流失，Andrew 将 Tasklet 定位为中立平台，为企业打包所有主流模型（Anthropic、OpenAI、Google、DeepSeek），并作为中立仲裁者优化模型选择，降低供应链风险。
  3. Harness 的角色应从约束模型的缰绳，转变为增强其能力的机甲 随着模型能力趋同，Harness 的核心价值不再仅是控制，而是提供存储、计算、API 连接和与企业级管控（审计、权限、成本控制）的结合，释放 Agent 的真实潜力。
  4. 未来仅存三类软件公司：横向通用平台、Headless API 公司和解决方案公司 Andrew 认为 AI Agent 将替代大量传统 SaaS，最终市场格局将由覆盖全场景的通用 Agent 平台、提供 API 的商业服务商（如 Stripe），以及直接售卖自动化结果的解决方案公司主导。

💬 文章金句

  • 过去六个月里，基本上每一行代码可能都被动过了，我们大多数基础假设都被推翻了。
  • 我们真正需要的是一个保存你历史的文件系统，然后实际发送给 LLM 的只是提示。
  • 押我们，等于押注所有人。我们会给你提供 Anthropic 的模型、OpenAI 的模型、Google 的模型......我们是纯粹的中立方。
  • 我倾向于认为大家其实都在构建同样的东西。......Harness 更像是给它穿上机甲，让它能在真实世界里真正去做事。
  • 我们想做的，就是成为那个取代知识工作者所有 SaaS 产品的 AI Agent 平台。
