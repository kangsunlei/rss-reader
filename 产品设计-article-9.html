Cloudflare 形象因账单问题骤变：从大善人到背刺者

10/14/2026, 4:07:54 AM

📌 一句话摘要

用户对 Cloudflare 的好感迅速消失，因其在 D1、Email Send 和 RealtimeKit 服务上造成的财务和时间损失，认为其 billing 系统与 support 严重落后于 AWS。

📝 详细摘要

这条推文描述了 Cloudflare 的声誉逆转，从被赞誉为‘大善人’，到由于不透明的账单和糟糕的客户支持而被称为‘背刺者’。作者列举了在 D1 数据库、Email Send、RealtimeKit 等具体服务上的多次失败经历，认为 Cloudflare 的技术能力尽管可以，但其商业模式和支持服务无法与其他主流提供商如 AWS 相比。

💡 主要观点

  1. Cloudflare D1 迁移失败 用户尝试使用 Cloudflare D1 的数据库服务，但由于未知的失败原因，最终不得不切换到 Supabase，导致了时间和资源上的损失。
  2. Email Send 服务不可靠 Cloudflare 的电子邮件发送服务存在严重问题，迫使用户回退到基于 AWS 的解决方案，表明该服务在生产环境中不稳定。
  3. RealtimeKit 导致代码重写 使用 RealtimeKit 时，项目遇到了无法解决的问题，最终需要重写代码并放弃该服务，浪费了一个月的开发时间。这反映出 Cloudflare 在实时通信领域的服务成熟度不够。

💬 文章金句

  • 被 Cloudflare D1 背刺过，最后迁移到了 @supabase
  • 被 Cloudflare Email Send 背刺过，最后回退到了 AWS SES
  • 被 Cloudflare RealtimeKit 背刺过，最后重新了产品代码，扯皮浪费了一个月时间
