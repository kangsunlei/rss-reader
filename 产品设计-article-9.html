Apodex 1.1 发布：面向复杂专业工作的 Agent，开源框架与本地模型

8/25/2026, 1:06:19 AM

📌 一句话摘要

Apodex AI 发布 Apodex 1.1 版本，专为科学研究、金融分析等复杂专业工作设计，并同步开源 Agent 框架 FrontierAgent 与本地可运行的 mini 模型。

📝 详细摘要

Ding 转发并评论 Apodex AI 官方发布的 Apodex 1.1：该模型家族定位复杂专业工作（科研、金融分析、深度搜索），具备异步 Agent 团队协作能力，可并行拆解任务并持续整合发现。亮点在于同步开源：FrontierAgent 本地可部署的研究工作台（含异步 Agent 团队）、Apodex 1.1 mini 开放权重模型供本地运行，以及在线工作台与 API 平台。附带发布会配图一张。
