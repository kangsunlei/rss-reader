字节内测 ADrive 智能网盘，对飙腾讯网盘

9/21/2026, 9:04:01 AM

📌 一句话摘要

字节内测面向企业的 ADrive 智能网盘，主打人与 AI Agent 共用存储与协作空间，与腾讯网盘、百度网盘形成 AI 办公基础设施的新一轮竞争。

📝 详细摘要

文章报道字节正在内测面向企业的 ADrive 智能网盘，定位为 Agentic AI 网盘，让用户与 AI Agent 共用同一套文件存储与协作空间。豆包、TRAE、Aime 等字节系 Agent 以及 Codex、DeepSeek 等外部 Agent 生成的文件都可沉淀其中，支持团队复用与被 Agent 引用，并支持本地同步盘挂载、文档润色翻译、格式转换、图片编辑、知识库问答、企业/团队/个人三级空间与自然语言检索、以图搜图。文章同时梳理腾讯网盘与百度网盘的同类动作：腾讯网盘为 WorkBuddy 提供存储并已上线官网，可连接腾讯文档、CodeBuddy、IMA、元宝、腾讯会议等应用，通过 CLI、MCP 供 Agent 调用；百度则把百度网盘直接放进 AI 办公 Agent 库库 AI。作者认为网盘正从「存资料、看资料」的云空间，转变为知识资产沉淀、共享协作、多应用连接与 Agent 调用的基础设施，需要从 Agent 视角重构产品。

💡 主要观点

  1. 字节 ADrive 的核心定位是让用户与 AI Agent 共用同一套文件存储与协作空间 ADrive 面向企业用户，豆包、豆包工作、TRAE、Aime 等字节系 Agent 以及 Codex、DeepSeek 等外部 Agent 生成的文件都可存储其中，文档与产物可被团队复用和被 Agent 引用，实现人和 Agent 在同一工作空间办公。
  2. ADrive 在存储之外叠加了智能处理与检索能力 产品集成 AI 智能助手，支持文档润色、改写扩写、翻译、总结归纳，PDF 转 Word、图片转 Word 等格式转换，图片加水印、尺寸调整、美化、OCR，并可将存储文档作为知识库进行推理问答；检索支持自然语言一句话搜索与以图搜图，管理上提供企业、团队、个人三级空间与容量配额。
  3. 腾讯网盘与百度网盘采取了相似的 AI 化路径，卖点高度重合 腾讯网盘此前为 WorkBuddy 提供存储，已上线官网准备独立推出，可连接腾讯文档、CodeBuddy、IMA、元宝、腾讯会议等应用，聚合上下文并形成长期记忆资产，通过 CLI、MCP 供 Agent 调用；百度则把百度网盘直接放进 AI 办公 Agent 库库 AI，实现文件双向流转。作者指出字节 ADrive 的宣传图与腾讯网盘如出一辙。
  4. 网盘的产品逻辑正在被 Agent 重构 传统网盘主要解决跨设备存取资料，而在 AI Agent 作为数字员工加入工作流后，文档的来源、使用、检索识别与共享协作都需要 Agent 参与，网盘中的资料需要随时被 Agent 作为上下文调用，才能从「躺着吃灰」变成真正的资产。

💬 文章金句

  • 链接你的 AI 应用，让文件与产物持续可用。
  • 实现人和 Agent 在同一个工作空间办公。
  • 字节 ADrive 的卖点，和腾讯网盘，一模一样。
  • 也正是有 Agent 的加入，网盘中的数据资料，才不止于躺在那里吃灰，会被彻底激活。
  • AI 智能网盘，将作为 AI 办公 Agent 产品的重要基础设施。
