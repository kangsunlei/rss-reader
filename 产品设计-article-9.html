GPT 是思考模型，Jev 是行动模型

9/24/2026, 1:46:47 AM

📌 一句话摘要

Jev 是 OpenAI 前研究员 Diogo 团队研发的「行动模型」，只输出是/否加置信度，用自然语言的模糊 if 语句把大模型的理解力与代码的确定性结合，速度与成本远优于大语言模型。

📝 详细摘要

文章从应用与机会角度解读 Jev 模型。作者指出，GPT、Claude、DeepSeek 等大语言模型的核心逻辑是「写作文」，需要长篇思考再输出小作文；而 Jev 只做判断，输入任意自然语言，输出固定结构的是/否与置信度，耗时 0.114 秒对比 GPT 的 8.566 秒，且更便宜。作者认为「判断」与「快」相加就是「行动」，因此 GPT 是思考模型，Jev 是行动模型。文章进一步指出 Jev 的关键价值在于让智能具备代码层面的确定性：它兼具大模型的理解能力与 if else 的确定性结构，解决了大模型做意图判断时慢、贵、不稳定的三大问题，理论上代码库中所有意图判断都能用 Jev 重做。作者也回应了「没门槛」的质疑，认为 Jev 的价值不在模型能力，而在于想到了「自然语言模糊 if 语句」这个方向，其产品哲学源自《思考，快与慢》。

💡 主要观点

  1. GPT 是思考模型，Jev 是行动模型 大语言模型的核心逻辑是词语接龙式的「写作文」，需要长篇思考再输出；Jev 只做判断，输入任意自然语言，输出是/否加置信度，0.114 秒对比 GPT 的 8.566 秒，且更便宜。作者把「判断」与「快」相加，得出「行动」这一结论。
  2. 判断决策是广义的，Jev 的潜力在具身智能 作者认为世界上大部分动作都是判断：打游戏时何时开枪、白领拍板项目、叠毛衣先折哪只袖子，都是无数细碎判断的集合。电脑操作只是 AI 最容易验证的方向，走路、叠毛衣、洗碗等连续决策判断才是 Jev 更大的潜力所在。
  3. Jev 让智能有了代码层面的确定性 软件时代的 if else 只能处理客观条件，无法理解语义；大模型虽能做意图判断，但存在慢、贵、不稳定三个问题，Prompt 是软约束，输出 JSON 容易漏片段。Jev 输入端可理解自然语言，输出端只给固定结构，兼具理解力与确定性，对代码衔接友好。
  4. 理论上代码库中所有意图判断都能用 Jev 重做 作者以自己做的「根据小红书文案自动从图库挑图」工具为例，以前用大模型理解匹配，现在可换成 Jev 逐条判断是/否合格或选置信度最高者。Jev 输入 $0.042、输出免费，能极大提升智能水平并扩展场景边界。
  5. Jev 的最大价值是可能性，而非模型能力 面对「用 Qwen 微调两小时就能做出类似能力」「GPT 后训练一调就能覆盖」的质疑，作者认为 Jev 被传播不是因为能力多强，而是带来了别出心裁的方向，如同年初 OpenClaw 掀起的 Agent 范式。官方定位是「能理解自然语言的模糊 if 语句或前沿智能函数调用」。

💬 文章金句

  • GPT 是思考模型，Jev 是行动模型。
  • 在分工合作中，人类的价值体现在「判断力」。
  • 让「智能」，有了代码层面的「确定性」。
  • 一个能够理解自然语言的"模糊 if 语句"或"前沿智能函数调用"。
  • 面向人的 AI 被训练为取悦和辅助人，而模型能够为程序提供可靠决策，才有可能真正实现自动化。
