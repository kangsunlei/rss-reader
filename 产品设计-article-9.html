Framer 发布会：内置 Agent 与外部 API 接入，定价昂贵

6/17/2026, 9:04:01 AM

📌 一句话摘要

Framer 发布会新增内置 Agent 和外部 Agent 接入功能，但第三方 API 定价昂贵，作者认为这是非大模型公司的唯一出路。

📝 详细摘要

作者评论了昨晚的 Framer 发布会，认为没有太多惊喜。主要更新是加入了内置的 Agent 功能，并支持接入外部 Agent。作者指出，第三方产品通过 API 接入的定价非常昂贵，并认为这可能是非大模型公司未来唯一的解决方案。推文附带了 Framer 外部 Agent 的官方页面链接和一张相关图片。
