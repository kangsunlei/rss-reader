OpenAI 会杀死 Manus 们吗？

7/24/2025, 11:46:00 PM

📌 一句话摘要

文章深度剖析 OpenAI 发布 ChatGPT Agent 后，与初创公司在 AI Agent 技术路线上的竞争，揭示行业格局变化及潜在风险。

📝 详细摘要

本文深度剖析了 OpenAI 发布 ChatGPT Agent 后，AI 产品领域所面临的“接口博弈”局面，揭示了 OpenAI 通过整合语义层与能力层，对 AI Agent 初创公司（如 Manus）形成的结构性冲击。文章详细对比了 OpenAI 基于端到端训练的专用模型与初创公司依赖上下文工程和应用优化的不同技术路线。通过具体案例，阐述了双方在任务完成度、响应速度和结果呈现上的优劣。此外，文章还深入探讨了 AI Agent 的快速发展对就业、个人隐私和安全可能带来的深远影响，以及 OpenAI 在安全防护和商业化方面的策略。整体呈现了 AI Agent 领域的技术路线之争、市场动态及未来挑战。

💡 主要观点

  1. OpenAI 通过端到端训练的专用模型，旨在提升 AI Agent 的底层核心能力。 ChatGPT Agent 作为统一模型，能够进行任务规划、跨工具调用和文档生成，并在学术测试中表现出超越现有模型的强大底层能力，体现了巨头在基础技术上的优势。
  2. 初创公司通过上下文工程和应用优化，在用户体验和任务完成度上寻求差异化。 Manus 等公司虽依赖外部大模型，但通过提示工程、KV 缓存等工程创新，在响应速度、成本控制及生成结果美观度上表现更佳，满足用户对产品体验的需求。
  3. AI Agent 的广泛应用将深刻影响就业和个人隐私，需关注其潜在风险。 Agent 具备从思考到行动的完整能力，可能加速工作替代，同时对用户隐私数据构成潜在威胁，引发行业对安全和伦理的担忧。

💬 文章金句

  • 你以为 AI 产品是在做体验，其实是在"接口博弈"。
  • AI 时代的创业者们面临着比任何历史时期都更快速的技术迭代，一次底层模型更新往往就能毁掉一个垂直领域的创新产品。
  • 大模型会吃掉 90%的 Agent。
  • 如果模型进步是上涨的潮水，我们希望 Manus 成为那条船，而不是固定在海床上的柱子。
  • Agent 代表着 AI 系统能力的新高度，它可以用自己的计算机完成一些令人惊叹且复杂的任务。
