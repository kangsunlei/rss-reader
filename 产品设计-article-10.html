📌 一句话摘要

本文介绍了蚂蚁 “百宝箱” 支持 MCP 后，AI Agent 可以调用支付宝接口发起**模拟**支付，探索了 AI 智能体在商业闭环能力方面的潜力。

📝 详细摘要

文章主要介绍了蚂蚁智能体开发平台 “百宝箱” 在接入 MCP 后，AI Agent 具备了调用支付宝接口，创建订单、生成付款码等发起**模拟**交易的能力。作者通过实际体验，展示了 AI Agent 如何通过一个简单的 prompt，就能生成付款链接并完成扣款（沙盒环境）。虽然目前只是一个模拟器，但作者认为这是 AI 智能体 “参与世界” 的开始，是其能够参与实际的商业活动，而不仅仅是信息处理的关键一步。文章还探讨了 AI 在资金流方面的应用，并设想了未来 Agent 作为小型项目经理，拥有预算感和操作能力的应用场景。

💡 主要观点

  1. 蚂蚁 MCP 模拟 AI Agent 发起交易的能力 通过 MCP，AI Agent 可以调用支付宝接口，实现创建订单、生成付款码等操作，从而模拟完成支付链路，向商业闭环迈进。
  2. 资金流对 AI Agent 至关重要 与信息流不同，资金流涉及真实的承诺兑现。接入支付是 AI Agent 参与真实世界，并为行为负责的重要一步。
  3. AI Agent 未来或将在商业活动中扮演更重要的角色 Agent 可以拥有目标感、预算感和操作能力，完成诸如 PPT 模板购买、内容套用等任务，实现更复杂的自动化流程。

💬 文章金句

  • 收钱，是智能体的成年礼，是他 "参与世界" 的开始
  • 第一笔钱，为的不是为了支付，而是接入一个世界的权限
  • 它不再只是 "懂你在说什么"，而开始 "能为这句话付出代价"
