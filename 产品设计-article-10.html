为什么中美头部 Agent，不约而同走向开放？

9/18/2026, 8:05:50 AM

📌 一句话摘要

中美头部 Agent 公司 OpenAI、Anthropic 和腾讯不约而同开放底座，以应对 Context 分散与平台化竞争，Agent 正从 coding 走向通用平台。

📝 详细摘要

文章深度拆解了 OpenAI、Anthropic 和腾讯三家头部 Agent 公司开放底座的逻辑与路径。指出 Agent 竞争白热化之际，开放成为共同选择，因为 Agent 从 coding 走向办公和通用平台，企业竞争越来越多地落到 Context 上，而上下文散落各方，开放是整合能力的必要手段。三家公司各有侧重：OpenAI 和 Anthropic 沿模型能力外溢路径，将 Harness 沉淀为可复用基础设施；腾讯则强调整机开放，通过 WorkBuddy 连接软件、数据和硬件，构建网络效应。文章还引用问卷调查数据，讨论用户黏性基础——模型能力 vs 任务入口，并展望未来竞争取决于用户固定什么。

💡 主要观点

  1. Agent 竞争从 coding 走向办公和通用平台，企业竞争落到 Context 上。 Agent 最早用于写代码，但已扩展到办公场景，如文档、表格和 PPT。办公世界上下文更厚，涉及企业数据、业务规则和权限，模型与 Harness 能力趋近时，竞争关键变为 Context 整合能力。
  2. 开放是解决 Context 分散问题的必要手段，而非单纯姿态。 上下文散落在企业内部、软件公司、数据商等各方，单一公司无法全部补齐。通过开放底座，允许行业伙伴接入能力，形成网络，如 WorkBuddy 连接腾讯文档、企业微信等，实现能力互补。
  3. 三家公司开放路径不同：OpenAI 和 Anthropic 侧重模型能力外溢，腾讯强调整机开放。 OpenAI 和 Anthropic 将 Harness 沉淀为 SDK 或托管服务，沿模型优势向外传导；腾讯则开放完整 Agent 整机，包括执行底座、账号、记忆和多端流转，以应对中国市场数据分散的格局，构建飞轮效应。
  4. 用户黏性基于不同基础，未来竞争取决于用户固定什么。 Codex 和 Claude Code 黏性来自模型与专业工作流结合；WorkBuddy 则吸引非产研用户，部分用户习惯固定 Agent 更换底层模型。竞争关键在于用户是固定最强模型还是任务入口。

💬 文章金句

  • 模型负责想，Harness 负责让事情继续往前走。
  • 开放由此不再只是一个姿态，而成了解决问题的办法。
  • WorkBuddy 更像是开放了一套'Agent 整机'：既有执行底座，也有账号、记忆和多端流转。
  • 用户究竟会在哪里留下来。
  • 如果用户固定的是最强模型，产品、Harness 和开发生态就会围绕模型聚集。
