20 万字不到 1 分钱，梁文锋把 token 价格打骨折了

4/28/2026, 11:46:00 PM

📌 一句话摘要

DeepSeek 连续两天大幅下调 API 缓存命中价格，将百万 tokens 成本降至 2 分 5 厘，并深度绑定华为昇腾生态，意图以低价策略重构 AI 基础设施定价权，同时为国产算力替代铺路。

📝 详细摘要

本文深入分析了 DeepSeek 在 2026 年 4 月底连续两天大幅降价的战略意图与行业影响。文章指出，DeepSeek 将 API 缓存命中价格降至全球新低（V4-Pro 低至 0.025 元/百万 tokens），此举并非简单的价格战，而是旨在通过低价策略将 AI 定位为基础设施，重塑市场对合理价格的预期。文章进一步剖析了不同玩家的处境：大厂（如阿里云）因依赖生态和云服务盈利而不受影响；中间层模型厂商（如智谱、月之暗面）则面临巨大压力。更关键的是，DeepSeek 已深度适配华为昇腾 950 集群，利用国产芯片在推理场景下的性价比优势（成本比英伟达方案低 60%-70%），为国产算力替代提供了真实案例。最后，文章探讨了 DeepSeek 的商业化路径，认为低价 API 只是入口，真正的价值在于通过开源建立生态，并转向企业私有化部署、云厂商合作等更高价值的服务。

💡 主要观点

  1. DeepSeek 将 API 缓存命中价格降至全球新低，意图重塑 AI 定价体系。 通过连续降价，DeepSeek 将百万 tokens 成本降至 0.025 元，使长文本、知识库等场景成本下降 90% 以上。此举旨在将 AI 定位为基础设施，改变市场对合理价格的预期，迫使竞争对手跟进或解释其高价的合理性。
  2. 降价策略对不同玩家影响各异，大厂无感，中间层承压。 阿里、腾讯等大厂依靠云服务和生态盈利，API 仅为引流工具，不受影响。而智谱、月之暗面等中间层模型厂商，因缺乏生态护城河，在 DeepSeek 的低价冲击下，面临跟价则利润受损、不跟则客户流失的两难困境。
  3. DeepSeek 深度绑定华为昇腾生态，为国产算力替代提供真实案例。 DeepSeek 已适配华为昇腾 950 集群，利用国产芯片在推理场景下的性价比优势（成本比英伟达方案低 60%-70%）。这不仅是技术适配，更是一个头部模型将流量和需求带入国产算力生态的标志性事件，有望激活整个国产芯片产业链。
  4. 低价 API 是入口，企业私有化部署和生态才是 DeepSeek 真正的商业化方向。 文章认为，DeepSeek 不能长期依赖低价 API 作为收入来源。其真正的商业化路径是：先用价格打穿市场，再用开源建立开发者生态，最终通过企业私有化部署、模型调优、安全运维等增值服务来承接价值，成为 AI 开发的默认底座。

💬 文章金句

  • 梁文锋不是在打价格战，他是在重新定义'AI 基础设施'的定价权。
  • DeepSeek 这次降的，不只是 token 的单价。它是把'长文本、长代码、长知识库'这些原本最烧钱的 AI 应用场景，全都打入了价格的谷底。
  • DeepSeek 降价的本质是他们找到了对应的客户。
  • DeepSeek 的价值在于，它不是一家边缘模型厂商做适配，而是一个头部模型亲自把流量和需求带进国产算力生态。
  • 低价可以是入口，却不应该成为终点。
