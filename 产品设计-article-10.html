Figma 更新，关 UI 设计师什么事？

5/14/2025, 2:35:00 PM

📌 一句话摘要

分析了 Figma 2025 年更新的五个新功能及其对 UI 设计师有限的实用价值

📝 详细摘要

文章详细介绍了 Figma 2025 年更新的五个新功能：自动布局网格 Grid、网页设计工具 Sites、品牌资产管理工具 Buzz、矢量绘图工具 Draw 和 AI 生成工具 Make。作者逐一分析了每个功能的特点、应用场景和价值，指出这些更新更多是 Figma 为维持估值而进行的跨界尝试，而非对 UI 设计工作流程的实质性改变。特别强调这些功能在国内设计环境中的适用性有限，UI 设计师应更关注项目和作品集，而非过度依赖工具更新。

💡 主要观点

  1. Figma 更新是资本驱动而非用户需求驱动 作者指出这些跨界更新主要是为了维持公司估值，而非真正解决 UI 设计师的实际需求
  2. Figma Grid 功能应用场景有限 Grid 功能仅适用于 Bento 型组件布局，且需要设计师熟悉组件设计，对复杂组件不适用
  3. Sites 功能在国内市场适用性低 Sites 功能仅适用于静态页面，且因服务器在国外而不够稳定，加上付费门槛高，国内使用价值有限
  4. Buzz 功能更接近傻瓜式出图工具 Buzz 功能简陋，主要吸引非设计从业者使用模板出图，无法满足国内复杂运营设计需求
  5. Draw 和 Make 功能不应被过度期待 Draw 受限于矢量绘图特性，Make 只能生成小样，都无法直接产出符合国内设计需求的成果

💬 文章金句

  • Figma 这次的更新，不再只是围绕界面设计的功能做完善，而是进行各种跨界的拓展。说好听点是功能更丰富更多元，说难听点就是为了维持估值要编造新的故事了。
  • UI 本身能做的功能就很少，类似动效这些经过市场验证毫无商业价值和潜力的模块，更是不会被重视
  • 作为 UI 设计师本身不用纠结于这次更新带来了什么巨大的改变，还是对我们有什么重大的影响，只是 Figma 基于资本考量做出的一种战略性的尝试。
  • 少关注点软件，多关注点项目和作品集输出。
