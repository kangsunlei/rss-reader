Agent 赛马结束，超级工作台上位

7/23/2026, 12:42:00 AM

📌 一句话摘要

文章分析腾讯、阿里、字节近期将分散的 AI Agent 收敛到超级工作台的举措，指出这是从野蛮生长到统一入口的产品共识，并预见 Agent 将成为底层能力而非可见产品。

📝 详细摘要

文章回顾了过去半年各大厂在 Agent 领域的密集布局，指出技术壁垒被开源工具抹平后，算力成本和分散产品线导致投入产出比下降。随后详细描述了腾讯将 QClaw 并入 WorkBuddy、阿里将三款 Agent 整合为“千问办公”、字节将 TRAE SOLO 改名为 TRAE Work 的具体动作，并指出这不是偶然的组织调整，而是 Agent 时代第一次真正的产品共识：从人人做一个的野蛮生长到超级工作台统一所有 Agent。文章进一步分析了这一共识背后的市场转向——程序员不再是最大市场，所有上班的人才是真正的大市场；解释了超级工作台如何通过 Skills 接口重构企业软件层次，使界面消失、后端服务成为核心；最后梳理了 Agent 的三阶段演进（产品→入口→能力），认为当前行业正从第一阶段快速滑向第二、第三阶段，Agent 终将像电力、网络一样成为无人提及却不可或缺的底层设施。

💡 主要观点

  1. 大厂开始收敛分散的 Agent，转向统一的超级工作台入口。 腾讯、阿里、字节几乎同时将各自的 Agent 产品并入 WorkBuddy、千问办公、TRAE Work，这不是偶然的组织调整，而是基于算力成本和市场确定性的产品共识。
  2. AI 的真正大市场从程序员转向所有上班的人。 虽然编程场景率先成熟，但通用办公场景覆盖数十亿职场人，其 Token 消耗和市场体量远超代码场景，因而超级工作台的价值在于服务全员工作流。
  3. Agent 正从可见产品演变为底层能力，未来将像电力和网络一样无人提及却不可或缺。 文章梳理了 Agent 三阶段演进：产品→入口→能力，指出当入口重构完成后，Agent 将通过 Skills 接口无处不在，成为企业软件的底层调度中心，界面将逐渐消失。

💬 文章金句

  • 从"人人做一个"的野蛮生长，到"超级工作台"统一所有 Agent。
  • Agent 正在经历浏览器和超级 App 之后，互联网历史上又一次能力下沉。
  • 真正成熟的底层技术，最后都会失去自己的名字。
