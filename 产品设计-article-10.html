📝 详细摘要

OpenAI 在 DevDay 上发布了 25 项新功能，包括 Dots 个人 Agent、ChatGPT Space 协作空间、GPT-6.1 Sol 模型、Ultrafast 高速档和 Decisions API。Dots 是一种持续在线的个人 Agent，能处理各种任务并与用户协作。ChatGPT Space 是一个协作空间，允许用户和 Agent 共同工作。GPT-6.1 Sol 模型在智能和成本上接近 GPT-6 Astra，但价格仅为其五分之一。Ultrafast 高速档提供更快的响应速度，每秒最高 300 个 token。Decisions API 允许模型在零点几秒内作出选择。此外，OpenAI 还发布了 Codex Harness 开源、Codex Security Cloud 云端安全扫描、Agents API 电脑操作等功能。

💡 主要观点

  1. OpenAI 发布了 25 项新功能，包括 Dots 个人 Agent、ChatGPT Space 协作空间、GPT-6.1 Sol 模型、Ultrafast 高速档和 Decisions API 这些新功能显著提升了 AI 工具的智能、速度和协作能力，为用户提供更强大的 AI 解决方案。
  2. Dots 是一种持续在线的个人 Agent，能处理各种任务并与用户协作 Dots 能够处理用户的日常任务，如订机票、订餐、装修等，并能够与用户进行协作，提供更高效的服务。
  3. ChatGPT Space 是一个协作空间，允许用户和 Agent 共同工作 ChatGPT Space 提供了一个协作环境，用户和 Agent 可以共同工作，提高工作效率和协作能力。
  4. GPT-6.1 Sol 模型在智能和成本上接近 GPT-6 Astra，但价格仅为其五分之一 GPT-6.1 Sol 模型提供了更高的智能和更低的成本，使其成为日常使用的理想选择。
  5. Ultrafast 高速档提供更快的响应速度，每秒最高 300 个 token Ultrafast 高速档显著提升了 AI 工具的响应速度，为用户提供更快的服务。
  6. Decisions API 允许模型在零点几秒内作出选择 Decisions API 提供了更快的决策能力，使 AI 工具能够更快地作出选择和响应。
