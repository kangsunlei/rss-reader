如何提升 UI 设计师的专业审美

4/17/2025, 12:00:00 AM

📌 一句话摘要

本文阐述了 UI 设计师如何通过分层认知和实践迭代提升专业审美，强调审美提升是一个持续迭代的过程。

📝 详细摘要

本文旨在解决 UI 设计师审美能力不足，无法进行有效设计判断和提升的问题，提出了审美提升的三个层次：基本归类、设计解构和辩证认识。同时，文章提供了三个实践方法：收集筛选（基础）、理论学习（支撑）和成果分析（升华）。强调案例收集重在筛选而非数量，理论学习需结合实践，成果分析要结合实际应用场景。文章旨在帮助 UI 设计师建立更深层次的审美观，从而做出更成熟的项目。

💡 主要观点

  1. 审美提升需经历三个层次 从直觉判断到专业分析，再到价值解读，逐步提升对设计的理解深度，避免审美停留在表面。
  2. 案例筛选是提升审美的关键 通过大量案例对比和筛选，建立自己的审美标准，并不断提高标准，才能有效提升审美能力。
  3. 设计成果分析需结合应用场景 不能只关注设计本身，要分析设计在实际应用中的效果和价值，从而更全面地评价设计。

💬 文章金句

  • 专业审美在前期可以分为三个层次：基本归类、设计解构、辩证认识
  • 真正具备辩证认识的设计师，是不会把设计好坏判断标准交给其他人的。
  • 一定要记得你们收集的这个画板是用来提升审美的不是当灵感库的，不要想着把这些案例留着过年，它们收集下来对你最大的作用就是 '牺牲' 自己成为你审美路上的垫脚石
  • 审美先于实践
  • 提升这部分的能力，最简单的做法其实就是做全面的竞品分析，分析的角度越多越完整，那么越能挖掘设计和其它领域的联系。
