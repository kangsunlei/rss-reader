黑鲸之后，OpenAI 开放 Harness，争夺“Agent 运行时”

8/22/2026, 12:58:00 AM

📌 一句话摘要

本文分析 OpenAI 开放 Codex Harness 与 DeepSeek 开源 DSH 之间的竞争，探讨 Agent 运行时成为新一轮模型公司间竞争的战场。

📝 详细摘要

文章围绕 Agent 时代“运行时”竞争展开分析。OpenAI 通过开放 Codex Harness，使开发者能将 Codex 的会话管理、上下文处理、工具调用等能力集成至企业内部系统，实现从编程 Agent 向企业级执行系统的延伸。同时，DeepSeek 在 OpenAI 公开 Codex Harness 后五天内开源了 DeepSeek Harness（DSH），采用“一切皆插件”的架构，允许开发者自由替换模型、工具、沙箱等底层组件。文章还介绍了国内其他模型公司如月之暗面的 Kimi Code 和智谱的 ZCode 在 Agent 执行系统上的布局。分析认为，Harness 的开放程度直接影响开发者的使用成本与改造难度，而模型公司开放 Harness 的根本动因在于获取训练数据、优化模型能力以及掌握用户入口。最终，Agent 运行时将成为模型公司间的新战场。

💡 主要观点

  1. OpenAI 开放 Codex Harness，使开发者可将 Agent 能力集成至企业系统。 Codex Harness 负责管理会话状态、上下文、工具调用、沙箱和人工审批，开发者可通过 codex exec、SDK 或 app-server 接入企业已有系统。
  2. DeepSeek 开源 DSH，采用‘一切皆插件’架构，允许自由替换底层组件。 DSH 将模型、工具、技能、会话、沙箱、存储、Agent Loop、调度和 UI 都定义为插件，开发者可根据 Cordis 机制灵活组合，降低与上游分叉成本。
  3. 模型公司开放 Harness 的核心动因在于获取训练数据与掌握用户入口。 通过 Harness，模型公司能观察任务失败点、工具调用卡滞、上下文策略等信息，优化模型能力；同时可控制计费方式，向 API Token 之外延伸。
  4. 国内模型公司也纷纷布局 Agent 执行系统。 月之暗面推出 Kimi Code，智谱发布 ZCode，二者在开放程度上与 DSH 存在差异，反映出国内厂商在 Agent 运行时竞争中的战略选择。

💬 文章金句

  • Agent 时代，“运行时”和入口竞争同样重要。
  • Harness 很难形成一套长期稳定的最优方案。
  • 模型公司在这方面拥有天然优势。
