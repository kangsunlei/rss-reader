阶跃 Step 3.5 Flash ：春节 AI 混战杀出的黑马，正在 Agent 时代弯道超车

2/3/2026, 6:28:28 PM

📌 一句话摘要

阶跃星辰发布 Step 3.5 Flash 模型，通过稀疏 MoE 架构与 SWA 技术，在保持极高性能的同时实现极致推理速度，旨在定义 Agent 时代的高效底座。

📝 详细摘要

文章深入探讨了阶跃星辰最新发布的 Step 3.5 Flash 模型。该模型采用 1960 亿参数的稀疏 MoE 架构（每个 token 仅激活约 110 亿参数），通过滑动窗口注意力（SWA）和投机采样技术，将推理速度提升至最高 350 tokens/s。文章指出，Agent 时代对模型的需求已从单纯的对话流畅度转向任务交付效率，Step 3.5 Flash 在数学推理（AIME/IMO）和代码能力（SWE-bench）上表现卓越，且支持在 128GB 内存的 MacBook 上本地运行 256K 超长上下文，展示了“以巧见大”的技术路线，标志着 AI 能力正从云端昂贵集群向个人终端普及。

💡 主要观点

  1. Agent 时代需要从 Chatbot 的“堆参数”逻辑转向“高效率”逻辑。 传统的 Scaling Law 在 Agent 场景下效率较低，新一代模型应关注任务交付速度和长上下文处理能力，而非单纯追求参数规模的堆砌。
  2. Step 3.5 Flash 采用稀疏 MoE 架构，实现了低激活参数下的高性能。 通过 1960 亿总参数但仅激活 110 亿参数的设计，模型在大幅降低算力开销的同时，保持了足以应对复杂推理任务的智能水平。
  3. 速度在 Agent 场景中是核心生产力，而非单纯的体验优化。 用户在 Agent 任务中更关注结果交付而非生成过程，极高的推理速度（如 350 tokens/s）能显著提升自动化任务的闭环效率。
  4. 模型在数学和代码等高难度推理任务中展现出“解题家”特质。 凭借极致的后训练优化，模型在 AIME 和 SWE-bench 等权威榜单中表现优异，证明其具备真正的逻辑拆解与自我纠错能力。
  5. 支持本地化部署和超长上下文处理，降低了高性能 Agent 的使用门槛。 模型支持在 128GB 内存的 MacBook 上流畅运行 256K 上下文，标志着顶级 AI 能力正从云端集群走向个人终端设备。

💬 文章金句

  • Agent 时代已经来了，这是共识。而怎么做一个好用的 Agent 模型？Agent 时代需要 Agentic 的模型。
  • 在 Agent 时代，速度不再是体验，而是生产力本身，直接决定了任务交付的效率。
  • 过去的模型像是个‘背题家’，靠死记硬背海量数据来蒙混过关；而 Step 3.5 Flash 是个真正的‘解题家’。
  • 最强的大脑，不应该只活在昂贵的 H100 集群里，它应该活在你的电脑里，甚至未来的手机里。
  • 在算力并不是无限的现实世界里，谁能用更精巧的架构、更少的资源解决更复杂的问题，谁才是真正的赢家。
