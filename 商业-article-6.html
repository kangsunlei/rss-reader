📌 一句话摘要

OpenAI 发布 o3 和 o4-mini，o3 首次实现图像融入思维链，开启视觉推理新纪元，并在多项基准测试中创下记录。

📝 详细摘要

OpenAI 发布了最新的推理模型 o3 和 o4-mini。o3 作为最强推理模型，侧重于复杂推理，在编程、数学、科学和视觉感知领域创下新纪录，并首次支持图像直接融入思维链，开启了融合视觉与文本推理的全新问题解决方式。配合 Python 数据分析、网络搜索和图像生成等工具，o3 能够应对更复杂的任务。o4-mini 则优化了快速、低成本推理，侧重于快速响应，在非 STEM 和数据科学任务中表现出色。两款模型在多个测试中全面超越前代，且指令遵循和响应质量都显著提升。OpenAI 还推出了轻量级终端编码 Agent —— Codex CLI，支持多模态输入，可以辅助用户完成终端编码任务。OpenAI 计划在未来几个月发布一个出色的开放模型，并积极开发 Agents SDK 中的线程支持，以改善对话历史和记忆，未来模型（GPT-5）预计将进一步整合这些优势。

💡 主要观点

  1. o3 首次支持图像直接融入思维链，在推理能力和多模态处理上表现出色。 o3 能够更长时间思考复杂问题，并结合 Python 数据分析、网络搜索和图像生成等工具，应对更复杂的任务。
  2. o4-mini 优化了快速、低成本推理，在非 STEM 和数据科学任务中表现出色。 o4-mini 在 AIME 2024 和 2025 数学测试中准确率分别为 92.7% 和 93.4%，效率高，更适合需要快速响应的场景。
  3. OpenAI 推出了轻量级终端编码 Agent —— Codex CLI，支持多模态输入。 基于 o3 和 o4-mini 的推理能力，Codex CLI 支持多模态输入，已在 GitHub 开源，并启动 100 万美元计划支持相关项目。
