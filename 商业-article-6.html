Agent、机器人与制药，谁先被 Astra 改写？

10/19/2026, 11:00:00 PM

📌 一句话摘要

三位一线研究者复盘 GPT-6 Astra 在 Agent、机器人与 AI 制药中的实测：机器人能力出现定性跃迁但仍需快慢系统分层，AI 制药卡在真实实验验证与数据，C 端 Agent 受身份、成本与平台封锁制约。

📝 详细摘要

本期《硅谷 101》在 GPT-6 Astra 发布约三周后，请来破壳机器人创始人许华哲、Pokee.ai 创始人朱哲清、华盛顿大学助理教授王晟，分别从机器人、Agent 与 AI for Science 三个方向复盘实测。机器人部分，Astra 展现出跨本体适应、通过反思迭代改进动作、以及把真实环境快速转成仿真的能力，在多个机器人 benchmark 上取得突破；但它推理慢、COT 对简单任务冗余、缺乏直觉物理与灵巧操作，叠衣、双臂和旋转抓取仍弱。嘉宾因此判断需要快慢系统分层：本地 10B 以下小模型负责实时控制，云端大模型负责规划与反思。Agent 部分，Computer Use 因第三方 API 不开放而重新受关注；Meta Muse 等 C 端产品沿用 Manus 的浏览器路径，云端虚拟机 IP 易被商家屏蔽，软硬件结合与本地身份验证可能是破局点。成本上，每用户每周一亿 token 约合 100 美元，叠加虚拟机与高模型价格，免费 token 模式难以持续。AI 制药部分，Astra 的长程任务与 Computer Use 能操作生物医学老旧软件，但生物医学知识 benchmark 未见提升，安全拒答更严；模型在分子预测上表现好，实验设计仍是明显短板，真实实验验证周期长、高质量语料稀缺，实验闭环与真实世界接口成为关键。节目最后讨论人类科学家转向定义问题与把关。

💡 主要观点

  1. Astra 给机器人带来的是定性跃迁，但主要价值在高层规划与跨本体泛化，而非端到端实时控制。 嘉宾实测中，Astra 能根据本体运动速度、桌面高度调整动作，并通过多轮反思把插花、画金门大桥等任务做得更好，还能把真实环境快速转成仿真；在 Robot Dojo 等 benchmark 上取得第一。但它的长 COT 让简单任务也耗时，叠衣、双臂、旋转抓取等灵巧任务仍弱，且缺乏对水会洒、玻璃会碎这类直觉物理的理解。
  2. 机器人落地需要快慢系统分层：本地小模型管实时控制，云端大模型管规划与反思。 嘉宾认为本地模型 10B 以下较舒适，十几 B 到几十 B 需升级芯片；高动态任务必须在本地，准静态任务可接受几百毫秒网络延迟。筷子夹小球时，自研模型能连续试错、速度快，Astra 则每一步都要分析原因，容易慢并陷入僵局；行业因此走向大模型规划加小模型实时控制的混合架构。
  3. C 端 Agent 的商业化卡在身份验证、平台封锁与 token 和虚拟机成本，软硬件结合可能是破局点。 Meta Muse 与 Manus 都走浏览器操作路径，但云端虚拟机 IP 容易被 Amazon 等商家屏蔽，商家还担心多个 agent 刷流量、比价。若 agent 运行在用户自有硬件上，商家能确认它代表真实用户，就更愿开放 access；一亿 token 免费额度约合 100 美元每周，叠加云端 CPU 与高模型价格，完全免费 token 的模式难以持续。
  4. AI 制药的瓶颈不是分子生成，而是可执行实验方案、真实实验验证与高质量数据。 Astra 的 Computer Use 能操作生物医学里多年未更新的老旧软件，长程任务可跑 8 到 24 小时，但提升主要来自通用编程与规划，生物医学知识 benchmark 并未提升，安全拒答还更严。模型能预测蛋白质活性，却难以给出在什么温度、用什么分子、如何适配实验室资源的可执行方案；真实实验周期长，高质量语料少，湿实验闭环与面向 AI 的实验接口成为关键。
  5. 模型能力曲线与行业落地周期存在巨大分差，前沿 lab 最烧 token 的方向是 AI for Science。 OpenAI 解纳维-斯托克斯方程时，agent 发了约 270 万条消息、消耗约 1300 亿输出 token，按零售价约 2200 万美元；这类投入对普通用户感知不强，传统企业甚至仍困在 Copilot 里。小模型在白领工作流上追赶明显，但现有生物医学 benchmark 更像数据科学竞赛，可能让模型追错方向；人类科学家的角色正转向定义问题、设计评估与最终把关。

💬 文章金句

  • 我们现在方向我们都叫它叫 human use AI 怎么样控制真实实验中的一些实验员，一些 technician 去做实验。
  • 所以我们真正在意的问题都是不能被 benchmark 衡量的，都是没有答案的。
  • 如果说这个硬件本身属于这个用户，他就可以直接确认说这个 agent 就是这个用户，是一个代表行为，那我就会愿意把这个 access 开给你。
  • 我们可能未来需要看到一个完全免费 token，根本不是一个限制的这么一个产品才行。
  • 我觉得从 robotics 角度，extra 是一个飞跃式的。
