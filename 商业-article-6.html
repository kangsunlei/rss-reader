📌 一句话摘要

本文是一份详尽的实操指南，教用户如何通过 Claude Code 结合国产大模型 API 和 Skills 插件系统，在本地免费打造功能强大的 AI Agent。

📝 详细摘要

文章深入探讨了 2026 年本地 AI Agent 的爆发趋势，重点介绍了 Anthropic 推出的 Claude Code 及其核心生态 Skills。作者指出，虽然 Cowork 等产品门槛较高，但本质上都源于 Claude Code。文章详细解释了 Skills 的概念——即一种可移植的、将通用 Agent 转变为专用工具的文件夹目录（包含指令、脚本和资源）。随后，文章提供了“保姆级”教程，指导用户从安装 Node.js 和 Git 开始，到配置智谱、MiniMax 等国产大模型 API，最后展示了如何利用 Skills 实现视频下载、PDF 处理、视频生成和 Canva 设计等复杂本地任务。文章还特别强调了使用 Plan Mode（计划模式）来规避 AI 误删文件的风险。

💡 主要观点

  1. Skills 是将通用 Agent 转化为专用 Agent 的核心机制。 Skills 本质上是一个包含 SKILL.md、指令和脚本的文件夹目录，它像应用市场一样封装了特定任务的工作流，使 AI 能像拥有“快捷键”一样处理复杂需求。
  2. Claude Code 是实现本地 Agent 的高性价比“脚手架”。 相比每月 200 美元的 Cowork 订阅，Claude Code 提供了类似的本地文件处理能力，且支持通过修改 settings.json 接入低成本的国产大模型 API。
  3. Plan Mode 是开发者在使用本地 Agent 时的重要安全防线。 在计划模式下，AI 处于只读状态，仅提供执行方案而不实际修改文件，有效防止了 AI 因误解指令而删除重要本地数据的风险。

💬 文章金句

  • Skills 更多的是像一个应用市场，它能把不同需求的应用都整理为一个单独的技能。
  • 有了 Claude Code，等于有了一个 200 美元订阅才能用的 Cowork，和 20 美元订阅才能用的 Skills。
  • 任何可以被总结出一套工作流的任务，我们都可以让 Skills 来处理。
