2 个月，20 亿美元估值、硅谷 7500 万美元投资，Manus 给中国 AI 创业者指了条什么路？

6/1/2025, 4:05:00 AM

📌 一句话摘要

文章分析了 AI 初创公司 Manus 如何在国内外评价两极分化下，凭借工程化能力和增量思维获得海外巨头重视和高额投资，并探讨其对中国 AI 创业的启示。

📝 详细摘要

文章深入分析了中国 AI 初创公司 Manus 在国内受到质疑（如“没有自己的大模型”）但在海外却获得谷歌、微软、OpenAI 等巨头高度认可和 7500 万美元投资的现象。作者认为，Manus 虽然没有基础模型，但其基于大模型 API 的应用层创新和强大的工程化能力，为拥有模型的巨头提供了消耗 token 和扩展生态的“增量游戏”机会。文章借鉴量子物理中的“量子隧穿效应”和“势垒改变”，解释了 Manus 如何凭借先发优势和聚焦策略，在尚未成熟的通用 Agent 领域实现市场突破，获得了包括传闻中接近 1 亿美元 ARR 的巨大先发红利。作者还 reframed 了对 Agent 产品“套壳”的质疑，强调其作为复杂工程系统而非简单外壳的价值。最后，文章提出通用 Agent 的下一步关键在于聚焦并优化高频用户场景，通过不断交付超越预期的体验来建立用户壁垒，并鼓励中国创业者以更开放的“增量思维”和“凡人勇气”拥抱全球 AI 生态机遇。

💡 主要观点

  1. Manus 在国内被质疑却获海外巨头高度认可和投资 即使没有自研大模型，Manus 凭借其 Agent 产品获得海外巨头重视和高额融资，体现了其作为应用层创新对模型生态的价值。
  2. Manus 的“无模型”策略对大模型巨头是增量机会 Manus 通过调用顶级模型 API，消耗 token、创造应用场景，帮助巨头扩大生态价值，是“增量游戏”而非“存量博弈”。
  3. 量子隧穿效应解释创业公司突破行业壁垒的路径 即使资源能量有限，创业公司也能通过高效锐利、工程化投入等方式，“隧穿”技术势垒，获得市场先发红利。
  4. AI Agent 的“套壳”本质是复杂的系统工程挑战 将大模型比作 CPU，Agent 开发是构建类似操作系统和管理系统的工程，解决大量周边问题，具有重要价值。
  5. 通用 Agent 成功在于聚焦高频场景和优化交付 优先解决用户 80%高频需求的 80%，通过不断优化交付体验卷入用户，建立用户心智，形成比技术更坚固的壁垒。

💬 文章金句

  • 嘿，这家伙没模型，居然也能做出这样的东西！让我的模型又多了一个 token 消耗出口啊。
  • 即使能量不足，它仍有一定概率「隧穿」过去，就像凭空出现在山的另一边一样。
  • 覆盖半数核心场景即可触发「通用感」了。
  • 对于通用 AI 产品，只要有资源，唯一正确的策略，就是在前面提到的「需求收敛模型」上，用不断的创新成果和更好的交付，形成对用户的卷入，只有用户是壁垒，是不断增值的资产。
  • 你可以说每一台苹果手机都是 CPU 的套壳，但这个壳也可以是复杂精致的产品工程。
