📌 一句话摘要

对谈斯坦福黄柯鑫，深入探讨 AI Scientist 概念、Biomni 项目及 AI 在生物医药领域的巨大潜力。

📝 详细摘要

本文是一篇对斯坦福大学黄柯鑫（Biomni 项目第一作者）的访谈。文章首先定义了 AI Scientist 为模拟人类科学家的 Agent 系统，旨在自动化科学研究循环。接着分析了现有通用 Agent 在生物医药领域面临的环境缺失和专家知识鸿沟等挑战。详细介绍了 Biomni 项目如何通过构建一个集成海量专业工具、数据库和软件的环境来解决这些问题，并展示了其在湿实验设计和干数据分析中的应用价值，显著提升了效率。最后，文章展望了 AI for Science 领域的未来发展方向，包括环境建设、强化学习应用以及潜在的千亿级市场机会，强调 AI Agent 将根本性改变科研范式，实现人类难以做到的大规模搜索和数据整合。

💡 主要观点

  1. AI Scientist 是模拟人类科学家的 Agent 系统，自动化科研循环并推动发现。 通过自动化“假设-实验-观察”循环，AI Scientist 旨在提升科研效率，并最终实现自主发现，改变科学研究范式。
  2. 通用 Agent 难胜任 AI Scientist 因缺乏环境与专家 Know-how。 生物医药领域的海量分散工具、数据库、软件和未被记录的专家隐性知识是通用 Agent 难以逾越的障碍。
  3. Biomni 的核心贡献是为生物医学 Agent 构建了集成化开放环境。 Biomni 整合数百种专业资源，提供 Agent 执行科研任务所需的基础设施，解决了环境缺失的关键问题。
  4. AI for Science 领域蕴藏巨大商业潜力，可能出现 Cursor 级别机会。 AI Agent 能规模化、智能化地执行科研任务，特别是在数据搜索和整合方面，将带来千亿级别的市场机会。

💬 文章金句

  • AI scientist 实际上就是模拟人类科学家，本质是 agentic system，能够自主提出假设、设计实验并循环修正；
  • 我认为最后一公里的核心问题是缺少一个合适的环境。
  • Biomni 的核心是构建一个环境，让 AI agent 能够执行大量的研究任务。
  • 我认为 AI for Science 会出现像 Cursor 或 Devin 这样的机会，会带来千亿级别的机会。
