Manus 背后的重要 Infra，E2B 如何给 AI Agents 配备“专属电脑”？

5/9/2025, 12:30:00 PM

📌 一句话摘要

作为 Manus 背后的关键 Infra，E2B 为 AI Agent 提供安全沙盒环境，支持代码执行和电脑操作，目标是成为 AI 时代的 AWS。

📝 详细摘要

文章详细介绍了 E2B 这一新兴基础设施如何为 AI Agent 提供安全、隔离的沙盒环境，支持代码执行和电脑操作。E2B 最初是一个代码解释器，随着 AI Agent 的发展，其沙盒月创建量一年内从 4 万增长到 1500 万，增长了 375 倍，逐渐转型为更通用的运行时环境。文章探讨了 E2B 的技术理念、产品定位、使用场景（特别是 computer use 场景）以及面临的挑战，并分享了 CEO 对未来 AI Agent 发展的看法。E2B 从训练阶段就介入 AI Agent 生命周期，愿景是成为 AI Agent 时代的 AWS，提供从开发到部署的完整生命周期支持。

💡 主要观点

  1. E2B 沙盒月创建量一年内增长 375 倍 从 4 万增长到 1500 万的爆炸式增长，证明了市场对 AI Agent 安全执行环境的强烈需求
  2. E2B 为 AI Agent 提供安全、隔离的沙盒环境 基于 microVM 技术，支持代码执行、浏览器操作和系统工具调用，解决了 Agent 执行环境的安全性和隔离性问题
  3. 从代码解释器转型为通用运行时环境 随着 AI Agent 应用场景扩展，E2B 发展为支持数据分析、应用生成、模型训练等多场景的运行时环境
  4. 目标是成为 AI Agent 时代的 AWS 提供从开发到部署的完整基础设施支持，包括 GPU 支持和应用托管能力，愿景是成为自动化 infra 平台
  5. computer use 是 AI Agent 的下一个重要场景 E2B 已推出 Desktop Sandbox 和 open-computer-use 项目，探索 Agent 控制电脑的可行方案

💬 文章金句

  • E2B 本质上是一个可以快速启动（~150 毫秒）的 microVM，它的底层类似于 AWS Firecracker 这个代表性的 MicroVM
  • Vasek 希望 E2B 能成为 AI agent 时代的 AWS，成为一个自动化的 infra 平台
  • 代码就像是一种通用语言，可以作为连接一切的粘合剂
  • 真正赢得开发者的方法是提供的体验好到让开发者几乎不需要思考自己在用一个工具——就像是大脑的延伸一样
  • James 认为现在只能靠视觉是因为大多数应用根本不提供友好的结构化入口
