杨斌：To B/To C 已经过时，“To A”的新时代来了

7/16/2026, 9:10:00 AM

📌 一句话摘要

清华大学杨斌教授提出「To A」概念，认为面向 AI/Agent 的商业范式正在崛起，将重塑传统 To B/To C 的底层逻辑，企业需要主动遗忘旧经验以拥抱新场域。

📝 详细摘要

本文由清华大学杨斌教授撰写，提出「To A」这一新概念，旨在为 AI 时代商业新场域提供观察框架。文章指出，随着 AI Agent 成为需求表达、筛选和决策的主体，传统 To B/To C 二元框架已不足以描述未来商业。作者分析了 To A 的核心特征：Human not in the loop、Agent 间交互、对接口开放与数据标准的重视，以及资源稀缺性从注意力转向算力与可信数据。文章强调，企业需要「unlearn」旧经验，重构商业模式与价值创造逻辑，以碳硅共生为基本假设，拥抱 AI 次方变革。

💡 主要观点

  1. To A 代表面向 AI/Agent 的新商业范式，将独立于 To B/To C 并可能超越其规模。 随着 AI Agent 自主完成采购、投资、消费决策，企业需要服务非人类的需求主体，这不再是 To B 或 To C 的延伸，而是全新的市场场域。
  2. Human not in the loop 是 To A 最重要的商业逻辑之一。 传统商业流程受限于人类注意力、时间和认知能力，而 Agent 化后，商业活动可摆脱 Human in the loop 的瓶颈，实现更高效的闭环。
  3. To A 要求企业从界面友好转向接口开放、数据标准、响应稳定。 Agent 不关心页面精美，只关心 API 是否开放、数据是否结构化、服务是否可靠，产品设计逻辑需根本转变。
  4. 进入 To A 时代最大的障碍是认知鸿沟，需要主动遗忘 To B/To C 的默认做法。 传统成功经验如广告、订阅、流量思维在 To A 中可能失效，企业需以第一性原理重新设计模式，实现战略扬弃。

💬 文章金句

  • To B、To C，我们驾轻就熟；To A ，才刚刚开始。
  • unlearn，对赢过互联网时代的'大厂'、大神尤为关键。
  • To A 的第一步，是 unlearn to B 和 to C 时代默认的做法。
