万字探讨 Agent 发展真方向：模型即产品，Agent 的未来要靠模型而不是 Workflow

3/21/2025, 11:54:14 AM

📌 一句话摘要

Agent 的未来在于模型和强化学习，而非工作流。

📝 详细摘要

文章批判了当前基于预设工作流的 Agent 模式，指出其在处理复杂任务时存在局限性。文章强调，Agent 的未来发展方向在于模型本身，通过强化学习与推理结合，使 Agent 具备自主规划和决策能力，实现“模型即产品”。文章以 OpenAI 的 DeepResearch 和 Anthropic 的 Claude Sonnet 3.7 为例，阐述了模型自主性的重要性。此外，文章还展望了 Agent 在网络工程、金融等领域的应用前景，并解读了“苦涩教训”在 Agent 设计中的应用， 强调 Agent 需要自主学习和探索，而不是人为设定知识。文章还指出，缺乏具备“行动性”的数据是当前 Agent 发展面临的挑战之一。

💡 主要观点

  1. 模型即产品是 Agent 发展的未来方向 通用模型扩展遇到瓶颈，定向训练效果超预期，推理成本极速下降，都推动 AI 模型本身成为未来产品。
  2. 强化学习 + 推理是构建真正 Agent 的成功之路，通过模拟搜索环境和草稿式推理，实现自主决策和规划。 通过强化学习训练 LLM 智能体，使其具备自主搜索、规划和行动能力，摆脱对预定义提示的依赖。
  3. 市场低估了强化学习的潜力 资本市场对强化学习的巨大潜力未能准确评估和体现，导致模型训练公司融资困难，阻碍了技术创新。

💬 文章金句

  • AI 模型本身，就是未来的产品。
  • 未来真正的突破，必须是直接从模型层面入手，重新设计 AI 系统。
  • 一个真正的智能体，就是在每个具体场景中，都能自动完成用户心里想做却没明确说出来的事情。
  • 人们必须学会苦涩的教训：人为地去预设我们思考的方式，长期来看并不奏效。
  • 就像 OpenAI 和 Anthropic 一样，我们将计划直接公开说明：DeepSeek 的使命并不是仅仅打造单个产品，而是提供一种基础设施层面的能力......我们会首先投入研究和训练，将其作为我们的核心竞争力。
