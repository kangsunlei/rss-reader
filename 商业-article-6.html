前剪映负责人创业融资近亿，给 AI Coding 们补审美

8/25/2026, 1:30:00 PM

📌 一句话摘要

前剪映负责人创业融资近亿，推出 AI 产品原型设计工作台 OJO，试图把审美工程化，让普通用户参与设计流程。

📝 详细摘要

文章介绍了前剪映中国负责人 Kiki 张琪智创办的 AI 产品原型设计工作台 OJO，该产品已获顺为资本和联想创投近亿元人民币首轮融资。OJO 通过 Agent Team、Agent、Skill 三层架构，先帮助用户澄清需求、定义产品方向，再进行结构、视觉和交互设计，最后交给 Coding Agent 实现代码。文章指出，随着 AI 让代码实现变得容易，判断和审美成为新的稀缺能力；OJO 试图将设计师的专业判断拆解成可执行的 Skill 库，使普通用户也能参与完整的设计工作流。文中引用了 Kiki 对剪映经验的迁移、对设计与实现顺序的颠覆、以及团队在 Skill 匹配和模型调度方面的思考，展示了 AI 在设计领域的探索与挑战。

💡 主要观点

  1. OJO 将设计流程拆解为需求澄清、产品定义、结构视觉交互设计，最后交给 Coding Agent 实现。 通过 Agent Team 确定方向、Agent 推进任务、Skill 提供专业约束，形成完整的设计链路，使普通用户能够参与专业判断环节。
  2. 实现门槛下降后，判断和审美成为新的稀缺能力，OJO 试图把审美品味工程化。 文章指出，AI 让代码生成变快，瓶颈从"能不能做出来"转向"做出来之后是否好用、好看并形成辨识度"，因而需要将设计判断封装为可调用的 Skill。
  3. OJO 的三层架构（Agent Team、Agent、Skill）旨在将通用模型能力约束到专业设计领域。 Agent Team 决定任务方向，Agent 调用模型与资源执行具体工作，Skill 提供如字体、版式等细则，使设计过程可被系统化匹配与执行。
  4. Kiki 将剪映的经验迁移到 OJO，强调先理解用户再定义产品，这与她在剪映时期的产品方法一致。 她通过"先极小、再极大、再极小"的路径从具体场景推演大变化，认为专业创作能力的拆解与封装是降低门槛的核心。
  5. 团队正在积累任务 × Agent Team × Skill 的匹配关系，期望未来用户只需说出目的，系统自动安排合适的 Agent 与 Skill。 通过熟练用户的选择和好案例积累数据，逐步将选择权交给系统，使 Agent、Multi-Agent 和 Skill 退到产品背后，降低学习成本。

💬 文章金句

  • 实现变容易后，判断开始稀缺。
  • 把专业创作能力拆开、封装，再交给普通用户。
  • 当实现门槛下降，判断会成为新的缺口。
  • OJO 认为，根源在于对 Design 的定位上。
  • Skill 则为具体环节加入更细的专业规则，这也是将审美品味工程化的最直接体现。
