AI 时代，一种新经济正在长出来｜智联网·价值篇

6/9/2026, 9:00:00 AM

📌 一句话摘要

本文系统论述了以 Agent 为行为主体的「智联网」时代，商业模式将从注意力经济转向效果经济，并分析了 Token 消耗、节约分成、专家数字分身调用等新模式的探索与挑战。

📝 详细摘要

本文是腾讯研究院「智联网」系列的第二篇，聚焦 AI Agent 时代商业模式的代际更替。文章首先指出，当 Agent 替用户执行任务时，以 DAU 和注意力为核心的移动互联网商业模式（广告、订阅、佣金）将失去根基，因为 Agent 不会被广告打动，也不需要在页面上停留。作者系统对比了移动互联网与智联网在行为主体、价值储存器、付款决策等方面的结构性差异，并指出入口之争将从 App 图标转向意图接住者。在商业模式探索部分，文章详细分析了当前主流的「订阅+消耗」模式、Token 按量调用定价、节约分成（如 Sierra 的按解决工单计费）、专家数字分身调用付费等新方向，并指出按结果付费需要跨过「说不清、算不清、守不住、认不准」四道门槛。文章最后提出，智联网经济的完整雏形需要三大支柱：用户主 Agent、Agent 任务市场和 Agent 支付基础设施，并预告了下一期关于 Agent 信任机制的讨论。

💡 主要观点

  1. 智联网时代，商业模式的核心将从注意力经济转向效果经济。 当 Agent 作为执行者，广告失去了曝光基础，订阅面临按量计费的挑战，按结果付费（如节约分成、按解决工单计费）成为新方向，价值链路发生根本性换基。
  2. Token 按量调用是当前最成熟的 Agent 经济基础定价模式。 文章以 Claude、GPT 等模型为例，分析了 Token 定价的差异与多模型路由策略，指出 Token 效能（效率与质量）将成为效果经济时代的全要素生产率。
  3. 按结果付费需要跨过「说不清、算不清、守不住、认不准」四道门槛。 任务定义、验收标准、基线漂移和第三方验证是落地难点，文章借鉴了电力行业 EMC（合同能源管理）三十年的经验，为 AI 节约分成提供了合同范式参考。
  4. Agent 支付基础设施是智联网经济运转的微循环系统。 Agent 交易具有小额高频特征，需要极低单价可结算、免确认自动扣款、跨服务即时清算等新能力，Stripe 的 Agent Payment API 是早期探索。
  5. 智联网经济的完整雏形需要用户主 Agent、Agent 任务市场和 Agent 支付基础设施三大支柱。 用户主 Agent 是意图统一入口，任务市场催生竞价与评测平台，支付基础设施让交易发生，三者咬合形成完整的 Agent 经济系统。

💬 文章金句

  • 屏幕时代终结。或许未来我们可以给日活换成了一个新概念：任务完成率 TCR（Task Completion Rate）。
  • 当 Agent 替用户去办事，注意力不再停留在页面上，这就会让广告失去了曝光基础。
  • 服务的客户不再是人，而是人的 Agent。
  • Token 效能将成为效果经济时代的全要素生产率。
