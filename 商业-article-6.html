千问大更新，把 Agent 装进了电脑和手机

8/7/2026, 2:32:00 AM

📌 一句话摘要

本文基于独家体验，实测千问大更新后的 Agent 能力，覆盖定时任务、办公助理、文件整理与多端协同等功能，展示 AI 从聊天助手走向个人电脑和手机的落地效果。

📝 详细摘要

文章是 APPSO 对千问大更新的独家体验评测。更新上线了思考研究、定时任务、办公助理、智能体广场和语音通话等功能，并支持 Qwen3.8-Max 等旗舰模型。作者用多个真实场景实测新功能：定时抓取 AI 热点并同步到网页、自动整理桌面与夸克网盘、连接钉钉/飞书/Notion 等第三方服务；让 AI 独立完成八年级数学备课，自动拆解出教案、PPT、分层练习和互动网页等十多项任务并交付可编辑文件；还尝试扫描整理手写菜谱、下载五年国考职位表筛选可报岗位、对多家科技公司财报做深度研究并生成多种格式报告。文中也如实记录能力边界，如创建原生透视表受限时改用合并数据加筛选的替代方案。整体印证 Agent 正从概念走向普通人的电脑和手机。

💡 主要观点

  1. 千问将 Agent 能力落地到电脑和手机端，支持定时任务与多端协同。 用户可设定固定时间让 AI 自动抓取资讯并整理成简报，云端任务可在手机和电脑间同步、远程管理。
  2. 办公助理能自主拆解复杂目标并调用多种工具交付成果。 输入备课需求后自动拆出十多项任务，按指定模板和 Logo 输出可编辑教案、PPT、互动网页等文件。
  3. Agent 能读取文件语义而非仅做表面分类。 识别泛黄手写菜谱中的油渍、透字与方言写法，完成去重、索引和菜谱档案制作，体现多模态与语义理解能力。
  4. Agent 能力仍受限于已有工具与技能的边界。 创建 Excel 原生透视表失败后采用合并数据表加下拉筛选的替代方案，说明复杂任务仍需工具链持续完善。

💬 文章金句

  • Agent 不再是一个概念，它开始变成了对话框里的一个按钮、手机上的一条推送、桌面上的一个文件夹。
  • 当 AI 助手真的能替你干活的时候，你会发现自己已经很难再回到什么都要亲力亲为的状态了。
