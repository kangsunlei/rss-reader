JetBrains IDE 新 UI 预览 | JetBrains Platform Blog

6/19/2025, 10:11:27 AM

📌 一句话摘要

JetBrains 在 2025.2 EAP 中发布 One Island 和 Many Islands 两款实验性 UI 主题，并征集用户反馈。

📝 详细摘要

JetBrains 推出了两款新的 UI 风格：One Island 和 Many Islands，可在其 IDE 的 2025.2 抢先体验计划（EAP）中进行测试。本次更新侧重于视觉改进，功能保持不变。其目标是使 IDE 外观更现代化，优化之前 UI 更新的各个方面（例如编辑器 / 工具窗口分离和更醒目的导航），并使设计语言与 Toolbox 和 Fleet 等其他 JetBrains 产品保持一致。JetBrains 正在通过一项调查积极征求用户反馈，以帮助决定哪种新风格最终将成为默认风格。同时，他们也在积极解决已知问题，并鼓励用户报告其他问题。

💡 主要观点

  1. 最新的 EAP 中提供了两款新的实验性 UI 风格，可供测试。 JetBrains 在 2025.2 EAP 中引入了 One Island 和 Many Islands 主题，允许用户预览和测试潜在的未来默认 UI。
  2. 此次视觉更新旨在使 IDE 外观更现代化，并优化现有设计元素。 新主题旨在根据过去的用户反馈，将 UI 更新到当前的设计趋势，并优化窗口分离和导航等区域。
  3. JetBrains 正在积极收集用户反馈，以确定下一个默认主题。 鼓励用户尝试新风格并完成调查，这将直接影响哪个主题会被选为新标准。

💬 文章金句

  • 在 JetBrains IDE 的最新 2025.2 EAP 中，您可以找到两种新的 UI 风格：One Island 和 Many Islands，每种风格都提供深色模式和浅色模式。
  • 最终，这些风格之一将成为新的默认风格 —— 您的反馈将帮助我们决定选择哪一种。
  • 本次更新仅为视觉上的调整 —— 所有功能保持不变。
  • 我们希望 UI 界面保持新鲜和现代感，紧跟设计潮流。
  • 我们邀请您体验新风格并分享您的想法。
