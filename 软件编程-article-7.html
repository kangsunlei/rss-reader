从代码生成到自主决策：打造一个 Coding 驱动的“自我编程”Agent

12/22/2025, 9:48:00 AM

📌 一句话摘要

文章详细介绍了大淘宝技术团队如何构建一个“自我编程”的 Coding 驱动型 Agent，通过将代码作为核心指令，结合多模型、分层记忆和高效 Prompt 工程，实现 DevOps 场景下的复杂任务自主决策与执行。

📝 详细摘要

本文详细介绍了大淘宝技术团队构建“自我编程”Coding 驱动型 Agent 的实践。该 Agent 通过让大模型生成并执行 Python 代码，替代了传统的 JSON 工具调用，显著增强了 Agent 的自主决策能力和复杂任务处理灵活性。文章详细阐述了 Agent 的系统设计，包括基于 ReAct 架构的优化、混合模型策略、分层记忆系统（感知、短期、长期记忆）以及模块化的 Prompt 工程。技术实现亮点在于通过 Py4j 实现 Java 与 Python 双向调用，并设计了高效的代码执行引擎和工具包体系。最终目标是打造一个能胜任 DevOps 场景的“1.5 线”AI 助手，具备自我评估、多 Agent 协作和持续学习能力，有效提升了任务的成功率和响应速度。

💡 主要观点

  1. 核心创新：以“代码即指令”取代传统 JSON 工具调用，显著提升 Agent 灵活性。 通过让 LLM 生成并执行 Python 代码来控制 Agent 行为，改变了传统 Agent 基于 JSON 组装调用的局限性，实现了分支、循环等复杂逻辑，增强了 Agent 的自主性和对复杂任务的处理能力。
  2. Agent 系统采用 ReAct 架构优化，并基于 Spring Boot 构建后端，支持多模型混合部署等特性。 系统在 ReAct 模式基础上进行深度优化，利用 Spring AI 生态接入多种 LLM 模型，并根据任务类型选择最优模型，确保了不同场景下的高效和高质量处理。
  3. 设计了分层记忆系统（感知、短期、长期记忆）以提高 Agent 的上下文连贯性和学习能力。 区分感知记忆、短期记忆和长期记忆，有效解决了传统 Agent 上下文窗口限制、记忆组织缺失和知识更新困难等问题，使其能从历史交互中学习并支持复杂推理。
  4. Prompt 工程采用配置化、模块化设计，结合 FIM 格式进行代码续写，提高代码生成效率和质量。 通过结构化的 Segment 机制和 FIM（Fill-in-the-Middle）代码生成格式，使 LLM 能精准地在代码前缀和后缀之间续写核心逻辑，保证了生成代码的逻辑连贯性和正确性。
  5. 通过 Py4j 实现 Java 与 Python 双向调用，构建高效的代码执行引擎和工具包体系。 Py4j 作为 Python 和 Java 的桥梁，使得 Python 代码可以灵活调用 Java 工具包，同时保证了执行引擎的异步、监控和安全，是“代码即指令”实现的关键一环。

💬 文章金句

  • 既然 LLM 可以写出高质量的代码，为什么不能让它更进一步，编写并运行代码来控制 Agent 自身的行为呢？
  • 其核心创新在于用"代码即指令"替代传统 JSON 工具调用，显著提升灵活性与执行能力，目标是打造能胜任 DevOps 场景的"1.5 线"AI 助手，具备自我评估、多 Agent 协作和持续学习能力。
  • FIM 技术的核心优势：上下文感知，精准填充，逻辑连贯。
  • 记忆系统是构建真正智能 Agent 的关键组件。
  • Toolkit Bridge 是整个 Python 和 Java 沟通的桥梁，可以说是这套架构中最关键的一环。它解决了"Python 怎么调用 Java 工具包"这个核心问题。
