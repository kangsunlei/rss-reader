Jefferies 利用 Databricks 和智能体分析实现大规模股票研究现代化

3/2/2026, 4:28:48 PM

📌 一句话摘要

Jefferies 利用 Databricks AI/BI Genie 和基于 LangGraph 的多智能体架构，为股票分析师提供了一个对话式、受治理且多源的数据智能平台。

📝 详细摘要

本文详细介绍了全球投资银行 Jefferies 如何通过构建 Jefferies Data Intelligence (JDI) 来实现其股票研究业务的现代化。面对从海量数据集中综合 3，500 家公司信号的挑战，Jefferies 告别了传统的基于 SQL 的自服务模式和缓慢的“保姆式”工程支持。新系统使用 Databricks AI/BI Genie 作为推理引擎，并采用基于 LangGraph 构建的多智能体架构，将自然语言问题转化为复杂的数据查询。该工作流包含负责规划、执行和综合的专门智能体，允许分析师在保持 Databricks Unity Catalog 严格数据治理的同时，跨内部数据和外部 API（如 FRED 和 BLS）验证研究结果。

💡 主要观点

  1. 从手动数据转换转向面向分析师的智能体自然语言界面。 Jefferies 通过使用 AI/BI Genie 消除了将基本市场问题转化为 SQL 连接的摩擦，允许分析师在无需技术背景的情况下使用领域特定语言查询数据。
  2. 使用 LangGraph 实现多智能体架构以处理复杂的研究任务。 该系统采用结构化工作流，由规划智能体分解问题，执行智能体并行检索数据，综合智能体将结果汇总为连贯的投资信号。
  3. 跨数据集验证是高确信度投资建议的核心价值。 智能体工作流能够对来自不同来源（如客流量、应用下载量和宏观指标）的信号进行三角验证，从而在几分钟内验证或反驳投资假设。
  4. 通过 Databricks Unity Catalog 实现默认治理集成。 通过将 AI 体验锚定在 Unity Catalog 中，Jefferies 确保自动执行行级和列级安全权限，在无需自定义授权逻辑的情况下保持合规性。

💬 文章金句

  • 股票研究是一场关于广度和确信度的博弈。
  • 分析师不会根据表和连接来构建问题，他们会询问有关基本面、宏观经济、行业趋势、比较定位、催化剂、风险等方面的问题。
  • 其力量在于汇集多个独立的数据集来验证一个论点。这并非冗余——它是在增加确信度。这就是游戏规则。
  • 了解如何与数据交互的语法将变得越来越不重要，更多的重点将放在验证或反驳基于数据拼图的假设上。
