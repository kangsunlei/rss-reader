TC39 推九项 JavaScript 提案，包括 Array.fromAsync、Error.isError 和 using

📌 一句话摘要

TC39 推九项 JavaScript 提案，其中 Array.fromAsync、Error.isError 和 using 已达 Stage 4，成为标准的一部分。

📝 详细摘要

本文报道了 Ecma 技术委员会 39 (TC39) 在 ECMAScript (JavaScript) 标准方面取得的最新进展。TC39 是负责该标准演进的技术委员会。九项提案通过了阶段流程，其中三个关键特性达到了 Stage 4，这意味着它们现在是标准的一部分：`Array.fromAsync` 简化了从异步可迭代对象创建数组的过程；`Error.isError()` 提供了一种可靠的跨域方法来检查错误实例；`using` 实现了显式资源管理，便于进行一致性清理。文章简要提及了其他提案，例如 Import Attributes 推进到 Stage 3，并提到了 TC39 的阶段流程。

💡 主要观点

  1. Array.fromAsync 简化了异步可迭代数据的处理。 这种新方法允许直接从生成器或流等异步数据源创建数组，替代了手动 `for await...of` 循环，使代码更简洁。
  2. Error.isError 提供了一种可靠的方式来识别不同 JavaScript 域中的 Error 对象。 与 `instanceof Error` 不同，后者在处理跨域错误实例（例如来自 iframes）时可能失败，`Error.isError()` 提供了一种健壮的检查。
  3. 使用 `using` 的显式资源管理为资源清理提供了统一方式。 此特性提供了一种一致的语法，用于管理需要显式释放的资源（如文件、网络连接），防止资源泄漏，并与 `try...finally` 块相比简化了代码。
