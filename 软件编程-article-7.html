DeepSeek 正式官宣摇人，夯！

6/30/2026, 1:37:40 AM

📌 一句话摘要

DeepSeek 首次大规模公开招聘，计划将所有部门扩大至少一倍，所有岗位接受实习，但不招销售、市场和公关岗位，同时新成立 Agent Harness 团队加速大模型产品化。

📝 详细摘要

文章围绕 DeepSeek 的官方招聘公告展开，从招聘规模、岗位特点、招人标准三个维度进行解读。公告显示 DeepSeek 计划将现有团队规模扩大至少一倍，放出 7 大类 33 个岗位，所有岗位均接受实习生，体现了「看能力而不是看经验」的人才观。文章还分析了 DeepSeek 不设立销售、市场和公关岗位的原因，指出其战略重心全部押在研发和产品上。此外，作者系统梳理了 DeepSeek 的招人标准：价值观筛选（长期主义、极致专注、开源精神）、无限热爱、以及反经验主义的用人哲学（无 KPI、自下而上分工）。最后重点介绍了新成立的 Agent Harness 团队及其负责人崔添翼，该团队致力于构建连接大模型与智能体产品的工程化平台。

💡 主要观点

  1. DeepSeek 首次大规模招聘，计划将所有部门规模扩大至少一倍。 公告明确表示会努力将所有部门的规模扩大至少一倍，并一次性放出 33 个具体岗位，涵盖算法、开发、数据、测试、运维以及 HR、法务等职能岗，规模空前。
  2. 所有岗位接受实习，体现「看能力而不是看经验」的人才观。 CEO 梁文锋曾表示，有经验的人会照搬旧法，没经验的人会认真思考，因此招人看重基础能力、创造性和热爱，而非过往经验。这一理念直接促成了实习生计划。
  3. 不招销售、市场和公关岗位，专注研发和产品。 与多数 AI 公司不同，DeepSeek 不设市场部和公关部，重心全部押在底层模型研究和工程化上，体现了其低调务实的战略风格。
  4. 新成立 Agent Harness 团队，加速大模型产品化。 该团队由量化专家崔添翼领导，核心公式为「Model + Harness = Agent」，旨在构建模型之外的所有工程配套，将大模型能力转化为可落地的 Agent 产品。
  5. 招人标准强调的是价值观、热爱与反经验主义。 DeepSeek 内部没有 KPI 和固定任务，鼓励自下而上的创新，允许试错，用「创造者和冒险家」的标准筛选人才。

💬 文章金句

  • 看能力而不是看经验。
  • 创新需要尽可能少的干预和管理，让每个人有自由发挥的空间和试错机会。
