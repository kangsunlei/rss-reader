GitHub Copilot 与 Figma 通过 MCP 实现双向集成

3/10/2026, 5:15:39 PM

📌 一句话摘要

GitHub 宣布推出双向 Figma MCP 服务端，允许 Copilot 用户同步设计上下文至代码，并将 UI 更改推送回 Figma。

📝 详细摘要

GitHub 发布了针对开发者与设计师工作流的重大更新，推出了双向 Figma MCP（Model Context Protocol，模型上下文协议）服务端。这一集成让 VS Code 中的 GitHub Copilot 用户能够将实时设计上下文直接引入编码环境，反之，也能将编写好的 UI 组件推送回 Figma 画布。通过闭合设计与生产之间的环路，该工具旨在减少协作摩擦并保持开发者的心流状态。
