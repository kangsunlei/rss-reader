Sora 等领先人工智能产品基于 Next.js App Router 构建

10/2/2025, 1:48:42 PM

📌 一句话摘要

Guillermo Rauch 强调 OpenAI 的 Sora 以及 Claude 和 Grok 等著名人工智能平台均采用 Next.js App Router 作为其 Web 界面。

📝 详细摘要

Vercel (Next.js 背后的公司) 的 CEO Guillermo Rauch 在推文中指出了一个重要趋势：包括 OpenAI 最新发布的 Sora 在内的主要人工智能产品，正在使用 Next.js App Router 构建。他列出了 Claude、Grok、Lovable、v0 和 Cursor AI 等其他著名人工智能项目，它们都使用 Next.js 来实现其 Web 应用。这展示了 Next.js 在人工智能领域中，对于高要求、备受瞩目的项目的稳健性和适用性。
