📌 一句话摘要

Smartsheet 通过实施 Lambda 预配置并发和 Graviton 架构，成功降低延迟并优化成本，为企业 Serverless 架构优化提供了可行的实践方案。

📝 详细摘要

本文介绍了 Smartsheet 如何通过优化其 Serverless 架构，在高并发和低延迟的挑战下，降低延迟和优化成本，提升用户体验。Smartsheet 通过采用 Lambda 预配置并发来减少冷启动延迟，并使用自动扩展来匹配流量模式。此外，他们还将 CPU 架构从 x86_64 切换到 arm64 Graviton，进一步优化了成本。这些优化措施使得 Smartsheet 的 P95 延迟降低了 83%，并在函数 GB-second 成本上节省了 20%。文章还总结了一些最佳实践，如微调 Lambda 函数、使用 Graviton2 架构和使用预配置并发等。

💡 主要观点

  1. 预配置并发结合自动扩展显著降低了 Lambda 函数的冷启动延迟。 通过预先配置和保持 warm 的执行环境，并根据流量自动调整，减少了请求等待执行环境初始化带来的延迟，提高了用户体验。
  2. 自动扩展预配置并发可以优化成本效率。 根据流量模式动态调整预配置并发的数量，避免了在非高峰时段资源的浪费，提高了资源的利用率。
  3. 迁移到 Graviton 架构可以降低 Lambda 函数的成本。 通过将 Lambda 函数的 CPU 架构切换到 arm64 Graviton，可以节省 Lambda 函数的 GB-second 成本，提高成本效率。

💬 文章金句

  • 为了在降低成本的同时减少客户请求延迟，我们的工程团队利用 Lambda 预配置并发与自动扩展和 Graviton，这使得 P95 延迟降低了 83%，同时在我们继续扩展平台及其限制时提供高质量的服务。
  • 对于实施交互式 API 的函数，自动扩展阈值为 60% 利用率，以提前预配置执行环境，保持极低的延迟，并使函数更能抵抗流量激增。
  • 通过切换到 Graviton 架构，Smartsheet 在函数 GB-second 成本上节省了 20%。
