Grafana 告警：更快速、可扩展的告警管理

8/5/2025, 2:03:19 PM

📌 一句话摘要

Grafana 告警推出全新告警规则列表页面。新页面提供更佳性能、更清晰的 UI 和视图，增强告警管理的可扩展性和用户体验。

📝 详细摘要

本文宣布推出 Grafana 告警的新告警规则列表页面，这是一次彻底的重新设计，旨在解决大规模告警部署管理中存在的性能瓶颈、清晰度及易用性问题。此次重构引入了两种不同的视图：用于理解告警结构的“分组视图”和用于快速搜索和过滤所有规则的“列表视图”。主要改进包括更简洁、更集中的 UI，仅显示关键细节，并通过新的分页 API 实现了显著的性能提升。本文还深入探讨了实施过程中面临的技术挑战，例如使用混合分层方法来协调数据一致性（配置 API (Config API)）与速度（状态 API (State API)），以及通过“指纹”哈希生成稳定的规则标识符。此外，文章还阐述了如何通过后端分页来管理前端过滤。这些新功能正在向 Grafana 云用户推出，并将通过功能开关在 Grafana 12.1 中向 Grafana OSS 和企业版用户提供。该团队的下一个重点是改善主动告警的分类体验。

💡 主要观点

  1. 新的告警规则页面提供不同的“分组”和“列表”视图，以提高清晰度和可搜索性。 “分组视图”有助于理解告警结构，而“列表视图”可以快速过滤所有规则，满足不同用户在告警结构理解和规则搜索方面的需求，从而提高工作效率。
  2. 通过新的分页 API 和混合数据获取方法，显著提升了大规模规则下的加载和搜索性能。 将快速、最终一致的状态 API (State API) 与强一致的配置 API (Config API) 相结合，即使有数千条规则，也能确保快速加载，同时保持数据的准确性。
  3. UI 经过精简和简化，专注于核心告警管理任务。 通过仅显示基本细节并简化操作，新的界面减少了干扰，使用户可以更轻松地一目了然地评估和管理告警。

💬 文章金句

  • 有效的告警是任何可观测性策略的支柱。
  • 这不仅仅是一个小更新；这是一个彻底的、从头开始的重新设计。
  • 我们的主要目标是为所有类型的用户创造一种专注、直观和快速的体验。
  • 新的列表页面首先使用快速的分页 Prometheus 状态 API (Prometheus State API) 来获取规则组的整体结构。然后，为了确保您始终看到最新的信息，UI 使用配置 API 在该分页结构之上，使用最新的、强一致的规则数据来丰富此视图。
