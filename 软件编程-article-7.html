朝鲜黑客将开发者工具转化为恶意软件投递渠道，攻击全球近百机构

6/16/2026, 10:00:00 AM

📌 一句话摘要

本文综合多份安全报告，系统梳理了朝鲜黑客组织利用 VS Code 扩展、恶意 npm 包、GitHub 仓库等开发者工具作为投毒渠道，针对全球近百机构发起加密货币窃取攻击的技术手法与演进趋势。

📝 详细摘要

文章以 Proofpoint 披露的 UNK_DeadDrop 行动为核心，详细分析了朝鲜黑客组织 Contagious Interview 如何通过伪装成技术测试或职位招聘的钓鱼邮件，诱导开发者克隆恶意 GitHub 仓库并在 VS Code 中打开，利用 `runOn: folderOpen` 技术自动触发恶意代码执行。文章进一步扩展至近期十余起关联攻击活动，涵盖恶意 VS Code 扩展、npm 供应链投毒、Git 钩子滥用、Cython 编译规避、AI 辅助开发载荷等手法，并引用多家安全厂商（Proofpoint、Trend Micro、Yeeth Security、Expel 等）的报告数据，呈现了攻击者从社交平台定向钓鱼向大规模工业化投毒演进的趋势。文章最后引用 Expel 的分析，指出朝鲜因制裁导致的经济困境使其有强烈动机持续此类攻击。

💡 主要观点

  1. 朝鲜黑客利用 VS Code 的 `runOn: folderOpen` 机制实现零交互代码执行。 攻击者将恶意代码嵌入 VS Code 项目配置，受害者克隆仓库并在编辑器中打开时，恶意脚本自动执行，无需用户额外操作，大幅降低了攻击门槛。
  2. 攻击已从社交平台定向钓鱼转向大规模邮件投毒，呈现工业化趋势。 UNK_DeadDrop 行动在六周内发送 250 多封邮件，目标覆盖近 100 家机构的个人，超过 75% 位于美国，表明攻击者正在规模化扩展其开发者定向攻击行动。
  3. 攻击链覆盖多平台，最终目标均为窃取加密货币钱包凭证。 Linux/macOS 使用 shell 脚本部署 Overlord 框架，Windows 使用 VBScript 安装恶意 VS Code 扩展，最终均通过 HTTP POST 将窃取的浏览器扩展和桌面钱包数据外传。
  4. 供应链攻击手段持续演进，包括恶意 npm 包、Git 钩子、Cython 编译等。 攻击者不断更新载荷形式，如将 InvisibleFerret 从 Python 脚本迁移至 Cython 编译的 .pyd/.so 文件以规避检测，并利用遭入侵的 Packagist 包针对 PHP 开发者。
  5. 受控机器可被武器化为下游感染媒介，形成蠕虫式传播链。 Trend Micro 指出，攻击者不仅感染单个开发者，还利用受控机器篡改其仓库提交记录，将代码贡献转化为针对下游开发者的感染源。

💬 文章金句

  • UNK_DeadDrop 活动表明朝鲜针对开发者的金融窃取行动日趋成熟，从社交媒体平台虚假面试转向大规模招聘主题钓鱼邮件分发恶意仓库链接，显示攻击者正在工业化扩展行动规模。
  • 虽然经济动机的网络犯罪对大多数国家缺乏吸引力（因制裁导致的损失远超收益），但朝鲜情况特殊。该国已承受严厉制裁，几乎无法施加更多威慑，而对其严重受限的经济活动而言，收益却相当可观。
