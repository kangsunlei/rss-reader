Azure AI 搜索发布智能代理检索，赋能更卓越的对话式 AI

5/31/2025, 12:00:00 AM

📌 一句话摘要

Azure AI 搜索引入智能代理检索，旨在提升对话式 AI 的准确性。

📝 详细摘要

微软已发布 Azure AI 搜索中智能代理检索的公开预览版。这是一种查询引擎，旨在通过规划和执行复杂的检索策略，优化对话式 AI 的响应效果。该系统利用对话历史和 Azure OpenAI，将查询分解为跨多种数据类型的并行子查询。据称，相比传统 RAG，答案相关性提升高达 40%。它通过全新的 API 和 SDK 包提供，并构建于现有的 Azure AI 搜索索引之上。该过程涉及 LLM 分析、动态策略规划、并行子查询执行和语义重排序。此功能旨在为复杂企业场景中的智能代理提供更精细的知识检索能力，目前已在特定区域推出，并采用按需付费的定价模式。智能代理 RAG 通过引入动态推理、智能工具选择和迭代优化，弥补了传统静态工作流程的不足。

💡 主要观点

  1. 智能代理检索显著提升了对话式 AI 答案的相关性。 通过自主规划和执行多步骤检索策略，这项 Azure AI 搜索的新功能，相比传统 RAG，能将复杂查询的答案准确率提升高达 40%。
  2. 该系统采用 AI 代理实现动态查询规划和执行。 该系统利用对话历史和 Azure OpenAI，将复杂问题分解为子查询，并通过并行执行这些子查询来获取更相关的信息，并动态调整搜索策略。
  3. 相比传统 RAG，它能更好地支持复杂的企业用例。 智能代理 RAG 的动态推理和迭代优化能力，使其成为不断演进的业务需求、合规工作流程以及多源数据环境的理想之选。
  4. 技术实现依赖于新的 API / SDK 组件和现有的 Azure 基础设施。 智能代理检索可通过 2025-05-01-preview REST API 和 SDK 中的全新知识代理对象进行访问，并与 Azure AI 搜索索引、专用代理资源以及用于编排的 Azure OpenAI 集成。

💬 文章金句

  • 微软发布了 Azure AI 搜索中的智能代理检索公开预览版，这是一种能够自主规划和执行复杂问题检索策略的查询引擎。
  • 据该公司称，与传统 RAG 相比，该技术可将对话式 AI 中的答案相关性提高多达 40%。
  • Agentic RAG (ARAG) 通过引入动态推理、智能工具选择和迭代优化来填补这一空白。
