📌 一句话摘要

阿里全面禁用 Anthropic 全家桶，源于逆向发现 Claude Code 包含隐藏代码检查中国用户并打标记，官方称为实验但信任已破裂。

📝 详细摘要

文章确认阿里即将全面禁用 Anthropic 全线产品（包括 Claude Code），理由是一名海外开发者逆向 Claude Code 二进制时发现了一段加密混淆的隐藏代码：它会检测系统时区是否为中国，并比对 API 请求是否命中一份含 100 多个中国域名的黑名单。若命中，则在系统提示词中通过替换 Unicode 字符（如撇号换同形字符、日期横杠换斜杠）来标记用户，且模型被指令不得告知用户。代码被公开后，Claude Code 团队承认是几个月前的实验，并称新版已移除。作者通过朋友证实了该禁令，并评论闭源产品的信任危机与开源模式的可验证价值。

💡 主要观点

  1. 阿里因 Claude Code 隐藏代码事件全面禁用 Anthropic 全家桶。 逆向发现 Claude Code 含中国时区检查及域名黑名单，自动标记用户，官方承认是实验但已撤回，阿里据此要求全员卸载 Anthropic 产品，替换为国产 AI 工具。
  2. 隐藏代码通过 Unicode 同形字符打标记，且指令不许告知用户，严重破坏信任。 标记藏于标点符号的替换中，肉眼不可见，代码经加密混淆，官方未主动公开直至逆向曝光，导致用户对其安全性产生根本性质疑。
  3. 对比闭源的隐藏风险，开源模型的透明性成为信任基础。 被黑名单的国产 AI 公司多数开源模型权重，代码公开可验证，无法藏匿类似后门，凸显开源赋予用户自主可控的安全价值。
