Microsoft Foundry 代理服务：通过长期记忆预览简化状态管理

12/30/2025, 10:16:00 AM

📌 一句话摘要

Microsoft 的 Foundry 代理服务现已推出长期记忆功能的公开预览，使代理能够存储、检索和管理会话上下文，从而实现更个性化、更具洞察力的交互。

📝 详细摘要

Microsoft 宣布其 Foundry 代理服务中的记忆功能将开放公开预览，提供一个直接与代理服务集成的全托管长期记忆存储。这项新功能允许开发者在不同的会话、设备和工作流程中持久存储和管理关键的会话上下文，例如聊天摘要、用户偏好和重要信息。该记忆系统分三个不同的阶段运行：首先，提取阶段识别并捕获重要的用户交互细节（例如用户偏好、近期活动）；其次，整合阶段合并已提取的记忆，以消除冗余并解决冲突信息，从而保持准确性；最后，检索阶段使用混合搜索技术有效召回相关记忆，从而促进更自然、更明智的代理对话。开发者可以通过 Foundry 门户启用此功能，该门户会自动配置记忆存储，也可以使用 SDK 或 API 以编程方式进行交互。

💡 主要观点

  1. Microsoft 的 Foundry 代理服务引入了用于持久化上下文管理的长期记忆功能。 这项新功能允许 AI 代理保留和利用用户偏好和聊天摘要等信息，跨不同会话、设备和工作流程，增强连续性和个性化。
  2. 记忆系统通过提取、整合和检索阶段运行。 首先从交互中提取关键信息，然后合并并解决冗余或冲突的记忆，最后，利用混合搜索技术高效检索相关记忆，以支持更明智的对话。
  3. 开发者可以通过 Foundry 门户、SDK 或 API 轻松集成和管理记忆。 该功能设计易于采用，既提供自动配置的门户启用方式，也提供定制化使用的编程访问方式。

💬 文章金句

  • 我们的记忆系统地从对话历史中提取用户档案信息和聊天摘要。
  • 记忆作为项存储在托管记忆存储中，并分三个阶段运行。
  • 冲突信息（例如新的过敏症状）将得到解决以确保准确性。
  • 代理使用混合搜索技术快速查找相关记忆，确保对话自然且具洞察力，并可在对话开始时检索到核心用户信息。
