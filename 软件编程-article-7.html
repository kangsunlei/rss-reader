📌 一句话摘要

JetBrains 详细介绍了 Kotlin 在 Web 开发领域的最新进展和未来规划，重点包括 Kotlin Multiplatform 的双重 Web 目标（Kotlin/JS 和 Kotlin/Wasm）、Compose Multiplatform 升级至 Beta 版本（性能提升 3 倍）以及对旧版浏览器的兼容性支持。

📝 详细摘要

本文系统阐述了 JetBrains 通过 Kotlin Multiplatform (KMP) 提升 Web 开发能力的最新成果。文章详细说明了双重 Web 技术方案：Kotlin/JS 适用于与原生 UI 共享业务逻辑（提供更优的 JavaScript 互操作性），而 Kotlin/Wasm 则能实现完整的 UI 共享（性能提升达 3 倍）。即将推出的重要改进包括：增强的 IDE 工具链（调试功能、项目向导）、Kotlin/Wasm 和 Compose Multiplatform 进入 Beta 版本阶段，以及创新的兼容模式——在现代浏览器中自动使用 Wasm，同时为旧版浏览器提供 JavaScript 回退方案。技术路线图还涵盖了未来发展方向，如 Wasm 多线程支持、模块化编译、现代 JavaScript 工具链集成，以及自动生成 TypeScript 到 Kotlin 的包装器。

💡 主要观点

  1. Web 开发的双重技术方案 Kotlin/JS 擅长与原生 JavaScript UI 共享业务逻辑（适合渐进式采用），而 Kotlin/Wasm 通过 Compose Multiplatform 实现完整 UI 共享，性能提升达 3 倍——开发者可根据项目架构需求灵活选择。
  2. IDE 与工具链优化 IntelliJ/Android Studio 中新增的调试功能、项目向导和测试运行器显著提升了 Web 开发的体验，减少配置工作并加快开发迭代速度。
  3. 具备兼容性回退的生产级 Wasm 随着 WasmGC 获得所有主流浏览器支持，Kotlin/Wasm 已达到 Beta 版本阶段，并配备智能兼容模式——自动为旧版浏览器提供 JavaScript 版本，有效解决实际部署问题。
  4. 面向未来的 JavaScript 互操作性 @JsExport 注解即将稳定化，配合自动生成的 TypeScript 到 Kotlin 包装器，将大幅简化 JavaScript 库的使用，降低企业级应用的集成难度。
  5. 高性能技术路线图 规划中的 Wasm 多线程支持和模块化编译将为计算密集型 Web 应用带来接近原生的性能表现，同时与 esbuild/Vite 等现代打包工具的集成将优化构建流程。

💬 文章金句

  • 基准测试表明，WebAssembly 在 UI 共享场景下的性能表现显著更优（提升近 3 倍）。
  • 对于不支持新特性的浏览器，系统会自动运行 JavaScript 版本，避免出现空白页面并确保功能可用。
  • 我们的目标是让 Web 平台的多线程开发变得与 JVM 平台同样简单，使高性能 Web 应用的开发达到新的水平。
  • 系统将自动生成可直接使用的 Kotlin 声明，完整描述 [NPM] 库的可用 API 接口。
  • 该方案与近期引入的增量编译技术相辅相成，仅需重新编译发生变更的 Kotlin 模块。
