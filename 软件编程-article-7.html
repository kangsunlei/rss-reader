淘天⾃营质量技术 AI 智能体的实践和思考

5/19/2025, 9:23:00 AM

📌 一句话摘要

介绍淘天如何构建 AI 智能体，通过流程编排与 RAG 解决自营业务质量保障痛点。

📝 详细摘要

面对电商自营业务链路复杂、场景繁多带来的质量保障痛点，淘天自营质量技术团队构建了基于 AI 大模型的智能体。文章详细阐述了该智能体如何利用流程任务编排引擎与 RAG 架构，实现工具调度、数据查找、链路诊断、知识答疑等核心能力，有效提升质量保障效率。通过结构化工具知识库和动态数据查找相结合，提升了 Agent 的稳定性和准确性。文章介绍了各 Agent 的具体设计与优势，并展示了在商品数据、供应商信息、订单特征、链路日志诊断等场景的应用效果。总结了智能体的初步成果（服务人数、使用次数），并展望了未来在能力完善、方案沉淀、生态共建及复杂场景攻坚等方向的发展。

💡 主要观点

  1. 复杂的电商自营质量保障面临诸多技术痛点 业务链路长、场景差异大、工具平台分散等问题，导致技术人员日常工作效率低下，异常排查耗时，急需提效手段。
  2. 构建基于流程编排引擎+RAG 的 AI 智能体解决痛点 结合静态知识库与动态流程任务，AI 智能体能理解用户意图，智能调度工具、查找动态数据、诊断系统问题，提升工作效率。
  3. 工具调度 Agent 通过 RAG+重构 function_call 提高稳定性 不同于直接依赖大模型 function-call，通过结构化工具知识库和流程任务编排，确保 Agent 能稳定、准确地执行工具调用和提供使用说明，减少幻觉。
  4. 动态数据查找 Agent 支持从多数据源获取实时信息 该 Agent 能根据用户需求，配置化调用接口或查询数据源（如 ODPS），获取动态数据并由大模型进行总结回答，解决动态数据查找难题。
  5. 链路诊断 Agent 整合 Tracing 和日志平台进行智能分析 结合阿拉丁、鹰眼等链路追踪和日志查询平台数据，智能体能根据用户问题分析异常链路和日志，帮助技术人员快速定位和诊断问题。
