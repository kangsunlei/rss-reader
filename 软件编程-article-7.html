高精度启发式规则提升机器人管理能力

3/19/2025, 1:00:00 PM

📌 一句话摘要

Cloudflare 将机器人管理启发式规则迁移到更灵活的规则集引擎，显著提高了机器人检测的准确性，并增强了客户的控制力。

📝 详细摘要

Cloudflare 通过将机器人管理启发式规则从 Lua 引擎迁移到规则集引擎，解决了旧引擎在规则复杂性和部署效率上的限制。新引擎使用 YAML 语法，支持更灵活和精确的规则编写，显著提高了机器人检测的准确性，降低了误报率，并提升了规则部署速度。此外，Cloudflare 还为机器人管理企业客户提供了机器人检测 ID，增强了对机器人流量的可见性，并支持在防火墙规则中使用这些 ID 进行更精细的控制。新增的账户接管检测 ID 可以帮助客户识别可疑的登录活动，从而更好地保护应用程序。

💡 主要观点

  1. 迁移到规则集引擎提高了规则的灵活性、准确性和部署效率 新引擎支持更复杂的规则编写，能够更精确地识别恶意流量，同时减少对正常用户的误判，降低误报率，并提升规则部署速度。
  2. 机器人检测 ID 增强了客户对机器人流量的可见性 客户可以在分析、日志和防火墙事件中查看机器人检测 ID，从而更好地理解机器人流量的来源和行为。
  3. 新增的账户接管检测 ID 可以帮助识别可疑登录活动 通过监控登录尝试和失败的异常增加，可以帮助客户识别潜在的暴力破解和使用泄露的凭据进行批量登录尝试（撞库攻击）。

💬 文章金句

  • 我们使用的每个启发式规则都包含唯一的机器人检测 ID。
  • 在 Cloudflare 规则集引擎上编写启发式规则使我们的工程师和分析师能够以易于理解的 YAML 语法编写新规则。
  • 在将启发式规则的定义缩小到仅在滥用网络来源时才标记 Golang TLS 指纹后，该规则现在的误报率为 0.0001%（百万分之一）。
