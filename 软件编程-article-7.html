📝 详细摘要

该推文分享了一个重要的 SQL 性能优化技巧，尤其针对大数据集的分页操作。作者指出，当`OFFSET`值非常大时，传统的`LIMIT + OFFSET`分页方式性能会显著下降。正确的做法是采用游标式分页（Cursor-based Pagination），通过限制查询范围到某个有序字段（如时间点或唯一 ID）之前，可以快速定位数据并减少扫描量，从而大幅提升性能。推文还引用了原帖，并提到 GitHub 的分页机制也采用了类似的方法，作者表示自己已重新绘制图表解释逻辑和实践，并征求反馈，体现了对技术细节的深入探讨和分享精神。
