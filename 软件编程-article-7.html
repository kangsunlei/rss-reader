刚刚，尤雨溪发布 Vue 新版本，无虚拟 DOM 版 Vue 来了！

7/12/2025, 10:26:00 AM

📌 一句话摘要

尤雨溪发布 Vue 3.6.0-alpha.1，引入无虚拟 DOM 的 Vapor Mode，旨在大幅提升前端应用运行时性能，同时保留 Vue 开发体验。

📝 详细摘要

文章详细介绍了 Vue 3.6.0-alpha.1 版本中引入的 Vapor Mode，这是 Vue 生态的一个重要里程碑。Vapor Mode 是一种全新的单文件组件编译模式，通过去除虚拟 DOM 的运行时开销，直接生成高效的指令式渲染代码，从而显著提升性能并减小包体积。它采用了移植自 alien-signals 的全新响应式核心，实现了更快的更新速度，并已在基准测试中与 SolidJS、Svelte 5 表现相当。文章还提供了 Vapor Mode 的启用方式（纯 Vapor 应用或混合使用）和适用场景（局部引入或新项目尝鲜），并列举了当前不支持的功能。尤雨溪强调 Vapor Mode 是 Vue 的“双运行时架构”进化，而非替代，它在保留 Vue 开发风格的同时，将性能推向了新高度。

💡 主要观点

  1. Vapor Mode 通过去除虚拟 DOM 显著提升 Vue 应用运行时性能。 Vapor Mode 编译时生成高效指令式渲染代码，消除虚拟 DOM 的 diff/patch 开销，实现更轻巧的运行时和更快的更新，尤其在大规模组件渲染中表现优异。
  2. Vue 将迈入“VDOM + Vapor”双运行时架构时代。 Vapor Mode 并非取代现有虚拟 DOM，而是作为一种可选的、性能更优的编译模式，为开发者提供更多选择，满足不同场景下的性能需求。
  3. Vapor Mode 在提升性能的同时保留了 Vue 的开发体验。 开发者仍可沿用熟悉的
