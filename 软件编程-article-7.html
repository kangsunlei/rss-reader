爱奇艺大数据异构计算实践

5/15/2025, 4:01:00 AM

📌 一句话摘要

爱奇艺大数据通过引入公有云 AMD/ARM 异构机器及改造 YARN 调度，大幅提升计算性价比与资源利用率。

📝 详细摘要

文章详细介绍了爱奇艺大数据团队在降本增效背景下，如何成功引入公有云 AMD 和 ARM 等高性价比异构计算机型。核心挑战在于 ARM 架构与现有大数据生态（Hadoop、Flink 等）及业务代码的兼容性适配，以及如何在包含 x86 和 ARM 节点的异构集群中实现高效调度。团队建立了标准化的机器选型流程，包括准入门槛、标准化性能测试和生产负载量化评估。针对 ARM 适配，文章阐述了组件升级、业务 Jar 任务扫描改造及强制准入机制。在异构调度方面，基于 YARN 节点属性和 Placement Constraint，改造了 Spark、Flink 等计算引擎实现定向调度，并针对 YARN 默认调度的不足，自研了自定义均衡调度策略，优先分配高性能节点。实践结果表明，该方案大幅提升了单机性价比，ARM 节点在超分环境下 CPU 利用率更高，Spark/Flink 作业速度提升显著。未来计划构建混合云分级计算资源池并优化跨云数据传输。

💡 主要观点

  1. 建立标准化的异构机器选型流程是引入新硬件的前提。 通过设定准入门槛、进行标准化性能测试和生产负载评估，能够科学量化不同机型的性价比和适用性，降低引入风险，提高决策效率。
  2. ARM 等新架构引入需要对大数据生态和业务代码进行全面兼容性适配。 从 Hadoop 等基础组件到 Spark/Flink Connector 及业务 Jar 任务，都需要检测和改造，才能保证任务在新架构上稳定、正确运行。
  3. 基于 YARN 节点属性和自定义策略可实现高效异构计算调度。 利用 YARN Placement Constraint 实现任务定向调度，并结合单机使用率排序的均衡策略，能充分利用异构节点资源，解决默认调度的不均衡问题。

💬 文章金句

  • 为了进一步降本，我们从 2024 年开始引入公有云 AMD、ARM 等高性价比计算机型，加快机型迭代、提升单机计算密度，进而实现单机性价比大幅提升。
  • 由于 AMD 和 Intel 都采用 x86 架构，不需要特别的适配，而 ARM 的 CPU 架构和指令集与 x86 不同，需要适配改造，并支持异构计算调度。
  • 为应对不同机型性能评估的长期性问题，我们构建了统一的可观测性系统。
  • 我们引入 YARN 节点属性 （YARN Node Attribute）调度功能...来实现指哪打哪的定向调度功能。
  • 因为 ARM 架构特点，在超分的环境下，CPU 利用率稳定安全水位可以达到 90%，相较于 x86（一般在 70% 以下）大幅提升计算密度，同时 Spark 和 Flink 作业速度提升 30% 以上，单机性价比大幅提升。
