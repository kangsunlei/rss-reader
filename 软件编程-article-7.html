Cursor 遭遇供应链投毒，恶意 Claude Code 扩展波及 5000 名用户

11/15/2026, 10:00:00 AM

📌 一句话摘要

Cursor 确认 10 月安全事件源于 Fireworks AI 密钥泄露，导致恶意 Claude Code 扩展在市场缓存中植入后门，潜在影响约 5000 名用户。

📝 详细摘要

FreeBuf 报道 Cursor 10 月安全事件追溯至 Fireworks AI 访问密钥泄露，攻击者利用该密钥窃取凭证并在 VS Code 扩展市场缓存中上传带后门的 Claude Code 扩展（Windows 与 macOS 版本 2.1.312/313），潜在波及约 5000 名用户，代码在加载时自动执行、收集主机信息并尝试建立 SSH 隧道，通过 macOS LaunchAgent 或 Windows 计划任务实现持久化，但多数设备因权限不足未实现远程登录。Cursor 已切断对 Fireworks 的访问权限、轮换凭证、重新部署基础设施，事件自 11 月 1 日后基本受控，建议用户删除扩展并检查端点痕迹、隔离设备、清除持久化机制、轮换所有凭证并评估是否需要重建环境。

💡 主要观点

  1. Cursor 确认 10 月安全事件源于 Fireworks AI 密钥泄露，导致恶意 Claude Code 扩展在市场缓存中植入后门，潜在影响约 5000 名用户。 攻击者利用泄露的访问密钥窃取凭证，在 VS Code 扩展市场缓存中上传带后门的 Claude Code 扩展，代码加载时自动执行，收集主机信息并尝试建立 SSH 隧道，通过 macOS LaunchAgent 或 Windows 计划任务实现持久化。
  2. 潜在波及约 5000 名用户，主要影响 Windows 与 macOS 平台的 Claude Code 2.1.312 与 2.1.313 版本。 根据 Cursor 更新，在约 11 小时的时间窗口内，最多有 5000 名请求特定缓存版本的用户可能收到恶意构建包，但实际受影响设备数量不明。
  3. Cursor 已切断对 Fireworks 的访问权限、轮换所有内部凭证、重新部署生产基础设施并加强密钥扫描。 为遏制风险，Cursor 将推理流量切走 Fireworks 平台，撤销其访问权限，轮换凭证，扩大密钥扫描范围，并在 11 月 1 日后止观察到攻击者活动，事件已基本受控。
  4. 建议用户删除恶意扩展、检查端点痕迹、隔离受影响设备、清除持久化机制并轮换所有可访问凭证。 Cursor 明确指出仅删除扩展可能残留 SSH 密钥与启动脚本，用户需检查端点痕迹、隔离设备、清除持久化机制，并在可信设备上轮换所有凭证，必要时重建环境。
