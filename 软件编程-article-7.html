Azure 基础设施安全：从芯片到系统的全面防护

8/25/2025, 4:14:12 PM

📌 一句话摘要

Azure 采用“芯片到系统”的纵深防御安全方法，整合定制硬件、机密计算和开源举措，以保护云基础设施，旨在为客户提供更高级别的安全保障。

📝 详细摘要

本文详细介绍了 Microsoft Azure 全面的“芯片到系统”安全策略，该策略由安全未来计划驱动。文章重点介绍了关键创新，如 Azure Boost（隔离了虚拟机的控制平面和数据平面）和 Azure 集成 HSM（一种定制安全芯片，可在服务器内提供 FIPS 140-3 级别 3 密钥保护）。机密计算着重通过基于硬件的可信执行环境 (TEE) 保护使用中的数据，为各种应用程序需求提供一系列安全保证。Caliptra 的应用进一步提升了硬件安全透明度，它是由行业合作伙伴合作开发的开源芯片信任根，并具备后量子弹性密码学能力。此外，OCP SAFE 框架促进了系统安全审查，代码透明服务 (CTS)（一种基于 SCITT 标准的不可篡改的账本技术）确保了整个硬件和固件供应链中可验证的完整性和可审计性。这些举措旨在为 Azure 的云和 AI 基础设施提供强大且多层面的安全保障，确保从基础硬件到客户工作负载的信任和完整性。

💡 主要观点

  1. Azure 采用从芯片到服务的纵深防御策略。 这种多层方法整合了定制硬件（如 Azure Boost、集成 HSM）、机密计算和软件服务，旨在全面保护从物理硬件到客户工作负载的整个云堆栈。
  2. 机密计算通过基于硬件的 TEE 保护使用中的数据。 它提供了一系列安全保证，从“直接迁移”现有应用程序到深度集成的机密应用程序，从而保护敏感工作负载，使其免受虚拟机监控程序和其他系统软件的攻击。
  3. 开源举措和透明度增强了硬件安全性和供应链完整性。 通过 Caliptra（具有后量子密码学的开源芯片信任根）和 OCP SAFE（系统安全审查）等协作，可以建立跨硬件和固件供应链的可验证信任和完整性。

💬 文章金句

  • 在 Microsoft，安全设计始于我们计算堆栈的基础——芯片级别——并延伸到云的每一层。
  • Azure 正在重新定义从数据中心到边缘的工作负载安全。
  • 机密计算利用基于硬件的可信执行环境 (TEE) 保护工作负载（例如虚拟机），使其免受其他系统软件（包括虚拟机监控程序）的侵害。
  • Caliptra 是一个完全开源的芯片信任根，由 Microsoft、AMD、Google 和 NVIDIA 合作开发。
  • 代码透明服务 (CTS) 是一种不可篡改的账本技术，旨在满足供应链完整性、透明度和信任 (SCITT) 的标准。
