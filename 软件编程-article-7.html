GitHub Copilot SDK 正式发布

1/22/2026, 3:02:17 PM

📌 一句话摘要

GitHub 发布 Copilot SDK，开放了其 CLI 工具背后的核心执行循环访问权限。

📝 详细摘要

GitHub 宣布推出 GitHub Copilot SDK，允许开发者通过程序化方式调用 GitHub Copilot CLI 背后的生产级执行循环。该 SDK 旨在简化 AI 开发流程，开发者只需几行代码，即可在自己的应用中集成多模型会话、自定义工具定义、模型上下文协议 (MCP) 集成、GitHub 认证以及智能体技能等核心功能。此次发布为构建复杂的 AI 原生应用提供了更底层的支持。
