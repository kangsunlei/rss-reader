Apache Doris + Iceberg 超大规模湖仓一体实践

3/28/2025, 11:30:25 AM

📌 一句话摘要

天翼云利用 Apache Doris 和 Iceberg 构建湖仓一体方案，在多个数据分析场景中提升性能并降低成本。

📝 详细摘要

文章介绍了天翼云基于 Apache Doris 和 Apache Iceberg 构建的湖仓一体方案。该方案通过 Doris 作为数据湖分析处理引擎和实时分析引擎，解决了传统架构中数据孤岛、性能不足和灵活性差的问题。文章详细阐述了该方案在多个数据分析场景，包括实时报表、湖仓融合、日志分析等方面的实践应用，并重点介绍了天翼云与 Doris 社区的合作，在查询性能和 Iceberg 生态对接方面共建完成的大量工作，显著提升了 Doris 在湖仓融合场景下的实践能力。最后，展望了未来在存算分离、业务落地、国产化和社区共建等方面的规划。

💡 主要观点

  1. Doris 与 Iceberg 的湖仓一体方案具备灵活性、高性能和低成本优势。 Doris 可以直接访问 Iceberg 表数据，加速查询，同时支持数据写回，结合数据缓存和物化视图等技术，提升湖上数据分析性能。
  2. Doris 在实时报表和多维分析场景中能显著提升查询效率。 通过替代传统架构中的 Impala + Redis 和 PG 组件，Doris 实现了秒级快速检索，统一多技术栈，简化架构，提升性能。
  3. 引入 Doris 替代 ELK 架构，能有效降低日志存储成本并提升查询效率。 Doris 在日志存储分析场景中，实现了写入吞吐提升 5 倍、存储成本降低 80%、百亿级日志检索秒级响应、查询效率提升 3 倍的显著收益。
  4. Doris 在国产化 MPPDB 应用中表现出色，通过与鲲鹏 ARM 芯片联合共建，提升了编译和运行效率，增强了数据安全性。 天翼云与 Doris 社区、鲲鹏 ARM 芯片联合共建，结合毕昇编译器，提升 Doris 编译效率，优化 Bitshuffle，提升运行效率，并实施安全加固措施。

💬 文章金句

  • 天翼云基于 Apache Doris 成功落地项目已超 20 个，整体集群规模超 50 套，部署节点超 3000 个，存储容量超 15PB。
  • 为此，天翼云全新架构基于 Apache Doris 和 Apache Iceberg 实现湖仓一体方案，构建了一个兼具灵活性、高性能和低成本的数据平台。
  • 优化后，相关类型查询的 IO 请求量从几百 GB 降至几百 MB，有效缓解了网络带宽压力，并提升了整体查询性能。
