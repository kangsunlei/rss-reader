神秘新模型“Ox Alpha”突袭 OpenRouter，性能超过 Fable 5？全网盲猜智谱或小米

8/23/2026, 2:00:00 AM

📌 一句话摘要

OpenRouter 匿名发布代号 'Ox Alpha' 的神秘模型，拥有 100 万 Token 上下文，支持文本、图像、视频输入，并免费开放一周供开发者测试。社区猜测其可能来自小米、腾讯、Google 或智谱，但目前无确凿证据，模型身份仍未揭晓。

📝 详细摘要

OpenRouter 推出一款代号为 'Ox Alpha' 的匿名模型，该模型拥有 100 万 Token 上下文窗口，支持文本、图像和视频输入，并具备工具调用与结构化输出能力。模型上线后迅速引发社区热议，猜测其可能来自小米（MiMo V3）、腾讯（HY 4）、Google（Gemini）或智谱（GLM-5.3）。尽管有初步测试显示其在某些任务中表现优于 Fable 5，但由于缺乏官方确认和详细基准数据，模型的真实身份和性能上限仍不确定。OpenRouter 宣布该模型将免费开放一周，供开发者进行大规模压力测试。

💡 主要观点

  1. OpenRouter 匿名发布 'Ox Alpha' 模型，拥有 100 万 Token 上下文，支持多模态输入和工具调用。 该模型被描述为面向高效编程、长时间 Agent 任务和生产环境，具备超大上下文窗口（>100 万 Token）和最大 13 万 Token 输出。它支持文本、图像、视频输入，并能进行工具调用和 JSON 结构化输出，但暂不支持严格的 JSON Schema 约束。
  2. 社区猜测 'Ox Alpha' 可能来自小米、腾讯、Google 或智谱，但无确凿证据。 由于模型匿名，社区基于发布时间、功能特征和历史先例进行了多种猜测。例如，小米曾以 'Hunter Alpha' 匿名测试 MiMo-V2-Pro；腾讯可能在测试 HY 4；Google 拥有类似上下文的 Gemini 模型；智谱则被怀疑因分词器匹配而可能是 GLM-5.3。然而，这些均为推测，模型真实身份尚未揭晓。
  3. 模型免费开放一周，供开发者进行大规模压力测试。 OpenRouter 宣布 'Ox Alpha' 将免费开放一周，提供宽松的速率限制和接近无限的使用额度（每天 100T Token）。这不仅让开发者可以免费试用，也为模型提供方提供了大规模真人测试的机会，以收集真实环境下的性能反馈。

💬 文章金句

  • The model is currently free， with input and output prices set to zero.
  • OpenCode announced that Ox Alpha will be available for free on their platform for one week， with relaxed rate limits and nearly unlimited usage quotas.
  • For a model with a 1 million token context window and video input support， a completely free API is quite rare.
