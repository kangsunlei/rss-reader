Pake v3.7.2 Released: Performance Optimization and Enhanced Reliability

12/31/2025, 11:55:00 PM

📌 一句话摘要

The open-source project Pake released v3.7.2， enhancing the performance， correctness， and build reliability for converting web pages into desktop applications.

📝 详细摘要

Pake v3.7.2 introduces multiple improvements in performance， correctness， and build reliability for its open-source tool， which enables developers to convert any webpage into a desktop application with a single command. Through Rust release-profile optimizations and LTO， binaries are smaller and run faster. Media handling has been enhanced to ensure that images and videos from CDNs are correctly previewed within the app instead of being treated as downloads. Build efficiency is also improved due to local icon reuse and a switch from axios to native fetch. Error handling has been improved with safer Rust patterns and clearer macOS messages. Additionally， Linux packaging is more consistent across DEB， RPM， and AppImage formats， and the test suite has been expanded， alongside dependency upgrades including Tauri v2.9.5.
