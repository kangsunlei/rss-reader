📌 一句话摘要

Vite 将集成基于 Rust 的打包工具 Rolldown 替代 esbuild 和 Rollup，大幅提升性能并统一构建，Vue 3.6 也将捆绑使用。

📝 详细摘要

文章报道了前端构建工具 Vite 的一个重要更新：计划用基于 Rust 编写的新打包工具 Rolldown 替换其目前使用的 esbuild 和 Rollup。当前 Vite 依赖 esbuild 进行依赖预打包，Rollup 进行生产打包，作者指出这种双工具模式导致开发生产环境不一致和部分性能浪费。Rolldown 被描述为 Rollup 的 Rust 升级版，专注于速度、兼容性和高级优化特性（如 HMR 和模块联邦）。集成 Rolldown 的核心目标是统一构建流程、提升性能。文章提供了通过安装 rolldown-vite 包（临时方案）来体验这一变化的方法，并列举了集成后 Rolldown 将负责的多个构建环节。文章最后强调了尤雨溪已宣布 Vue 3.6 将直接捆绑 Rolldown，认为这一整合是前端构建领域的里程碑。

💡 主要观点

  1. Vite 计划用基于 Rust 的打包工具 Rolldown 替代 esbuild 和 Rollup。 当前 Vite 依赖 esbuild 预打包和 Rollup 生产打包，存在开发/生产环境不一致和部分性能浪费问题。Rolldown 的引入旨在解决这些问题，统一构建流程。
  2. Rolldown 及生态工具将接管 Vite 构建流程中的多个关键环节。 集成后，Rolldown 将负责构建打包、优化、CommonJS 支持和打包配置；语法降级、JS/CSS 压缩等任务将由 Oxc 和 Lightning CSS 等基于 Rust 的工具处理，全面替换 esbuild 的相应功能。
  3. 这一变革将带来统一的构建体验、显著的性能提升和新特性支持。 基于 Rust 的 Rolldown 速度远超 JavaScript 工具，实现开发和生产环境的统一，并支持高级分块、内置 HMR、模块联邦等特性，提升开发效率和应用性能。
  4. Vue 3.6 将直接捆绑并依赖 Rolldown。 这一重要变化不仅影响 Vite 本身用户，也将直接集成到主流框架 Vue 中，进一步推广 Rolldown 的应用，使其成为前端构建生态的重要组成部分。

💬 文章金句

  • 这玩意儿可是用 Rust 写的，性能强得不行，未来要把现在 Vite 里用的 esbuild 和 Rollup 都给替了。
  • 开发环境和生产环境用的两套工具，有时候就不一致，bug 难找得很。
  • Rolldown ，就是用 Rust 写的现代化 JavaScript 打包工具，堪称 Rollup 的升级版。
  • 就三个字：统一、性能、特性。
  • 并且 尤雨溪 也宣布了 Vue3.6 将直接和 Rolldown 捆绑在一起了
