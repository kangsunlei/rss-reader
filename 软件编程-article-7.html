推荐 7 个本周火火火的 GitHub 项目，尤其是第一个。

5/10/2026, 2:33:00 AM

📌 一句话摘要

本文精选了本周 7 个热门 GitHub 项目，涵盖 AI 编程路由、极简 Coding Agent、大模型教程、Agent 记忆系统、3D 编辑器、手绘风格图生成和短视频自动生成等方向。

📝 详细摘要

文章以项目推荐形式，介绍了 7 个近期在 GitHub 上热度较高的开源项目。第一个项目 9router 是一个 AI 编程路由工具，聚合 40 多个 AI 提供商和 100 多个模型，支持自动故障转移和 Token 节省，旨在降低 AI 编程工具的使用成本。第二个项目 jcode 是一个用 Rust 编写的极简 Coding Agent 外壳，性能远超 Claude Code，支持 Swarm 多 Agent 协作和语义记忆。第三个项目是上海交通大学出品的《动手学大模型》系列教程，覆盖从微调部署到 Agent 安全的完整路径。第四个项目 agentmemory 为 AI Coding Agent 提供持久化记忆系统，采用四层记忆架构和混合检索。第五个项目 SuperSplat 是一个浏览器端的 3D Gaussian Splatting 编辑器。第六个项目 ian-handdrawn-ppt 是一个能生成手绘风格技术解释图的 Skill。第七个项目 Pixelle-Video 是阿里团队开源的自动短视频生成引擎。文章对每个项目进行了简要介绍和功能亮点说明。

💡 主要观点

  1. 9router 聚合多 AI 提供商，实现低成本 AI 编程。 通过路由 40+ 提供商和 100+ 模型，支持自动故障转移和 Token 压缩，有效降低 API 使用成本，是 AI 编程圈的白嫖神器。
  2. jcode 用 Rust 实现极高性能的 Coding Agent 外壳。 自研终端渲染引擎和 Mermaid 图表渲染库，内存占用和首次渲染时间远低于 Claude Code，并支持 Swarm 多 Agent 协作和语义记忆系统。
  3. 上海交大《动手学大模型》教程覆盖大模型开发全流程。 包含 11 个章节，从提示学习、微调部署到 Agent 安全，提供 PPT、文档和可运行 Notebook，适合动手实践。
  4. agentmemory 为 AI Agent 提供四层持久化记忆系统。 模仿人脑记忆架构，采用混合检索（BM25+向量+知识图谱），实现跨会话记忆，前 5 条结果召回率达 95.2%。
  5. SuperSplat 是浏览器端的 3DGS 编辑器，零门槛可用。 基于 WebGL/WebGPU 渲染，支持查看、裁剪、合并和优化 3D Gaussian Splatting 数据，无需安装。

💬 文章金句

  • 9router 的思路很直接：把 40 多个 AI 提供商、100 多个模型统一接到你的 AI Coding 工具后面。
  • jcode 是一个用 Rust 写的 Coding Agent 外壳，主打极致性能。
  • dive-into-llms 是上海交通大学出的《动手学大模型》系列编程实践教程。
  • agentmemory 是一个专门给 AI Coding Agent 做的持久化记忆系统。
  • SuperSplat 是 PlayCanvas 团队做的浏览器端 3DGS 编辑器。
