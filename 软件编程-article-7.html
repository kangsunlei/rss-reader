黑客利用 Codex 与 DeepSeek 发起攻击，全球 440 台 PaperCut 服务器遭入侵

10/17/2026, 10:00:00 AM

📌 一句话摘要

黑客利用 Codex 与 DeepSeek 等 AI Agent 自动化开发并迭代 PaperCut 漏洞利用代码，已入侵全球 48 国 395 家机构的至少 440 台服务器，并借此渗透内网。

📝 详细摘要

GreyNoise 与 Hunt.io 的联合调查披露了一起大规模自动化攻击事件：攻击者借助 OpenAI Codex 编码 Agent、DeepSeek 模型及常见安全工具，对暴露在公网的 PaperCut NG/MF 打印管理服务器发起批量攻击，至少 440 台服务器被入侵，涉及 48 个国家的 395 家机构。攻击者组合利用 CVE-2026-81578 与 CVE-2026-82078 两个漏洞实现远程代码执行，并准备了适配不同版本与网络环境的多个利用变种，还保留了一条 XML-RPC 备用攻击路径。攻击者意外暴露的工作目录显示，其向编码 Agent 下达了持续测试、失败后调整方案、并行处理任务的指令，整个攻击呈自动化迭代特征。获得初始访问后，攻击者部署注册表与凭证收集工具、创建反向 SOCKS 隧道，向企业内网与域控渗透。文章最后给出修补版本、限制管理接口公网访问、排查异常迹象与 IoC 等防御建议，并提示不同机构统计口径存在差异。

💡 主要观点

  1. AI Agent 将漏洞利用的开发与迭代周期压缩到小时级 攻击者用 Codex 编码 Agent 与 DeepSeek 模型自动开发、测试并优化利用代码，从自建实验室测试到接触首个真实系统不到 4 小时，大规模攻击启动后 26 秒即攻陷 11 家机构。但研究人员强调，成功入侵的关键仍是目标系统存在漏洞或防护薄弱。
  2. 两个 PaperCut 漏洞组合形成完整攻击链，且存在难以靠打补丁消除的备用路径 CVE-2026-81578 允许未授权请求修改系统设置，CVE-2026-82078 涉及不安全的类加载机制，二者组合可实现远程代码执行。此外还有一条独立的 XML-RPC 攻击路径，只要 API 暴露且访问控制薄弱，仅修补原始漏洞仍无法保障安全。
  3. 攻击并未止步于打印服务器，而是以此为跳板向域控和内网横向渗透 暴露的文件显示攻击者部署了收集 Windows 注册表与服务凭证的工具、可创建反向 SOCKS 隧道的脚本，并自动化打包被控系统信息。Hunt.io 恢复的数据中，侦察池含 1005 台主机，45 个目标存在可用反向 SOCKS 访问，涉及 46 个活动目录域。
  4. 不同机构的入侵统计口径差异明显，需谨慎解读数字 GreyNoise 报告的 440 个被攻陷实例与 Hunt.io 的 1005 台侦察主机并不重合，前者是确认入侵，后者包含版本检测判定可能存在的漏洞系统。文章明确提示这一差异，避免读者误读规模。
  5. 防御重点在于补丁之外的入侵排查与攻击面收敛 除升级至 26.0.5、25.0.13、24.1.10 等安全维护版本外，应限制管理接口公网访问、对 XML-RPC API 做访问控制或启用强认证与白名单，并排查 user-lookup.* 设置被改、custom/web/ 下未知文件、异常子进程、chisel 隧道与 cron 持久化等迹象。

💬 文章金句

  • 研究人员指出，AI Agent 显著加快了攻击流程，但成功入侵的关键仍在于目标系统存在漏洞或防护薄弱。
  • 这条备用路径的风险极高：仅修补原始漏洞无法保障系统安全，只要 API 仍暴露在外、认证机制或网络访问限制薄弱，系统依然存在被入侵的可能。
  • 补丁只能阻止攻击者继续利用已知漏洞，无法判断攻击者是否已经入侵系统。
  • 这些记录既展示了攻击者如何将初始访问转化为长期网络立足点，也说明不同机构统计的入侵数量来自不同数据集，统计口径存在明显差异。
