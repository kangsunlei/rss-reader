GitHub 面临生存之战！多位员工曝内部乱象：独立文化要没了，封杀 Claude Code 才能“活”

5/24/2026, 2:15:00 AM

📌 一句话摘要

本文综合外媒报道，揭示了 GitHub 在微软内部正面临生存危机，包括频繁宕机、安全漏洞、员工士气低落、独立文化被削弱，以及来自 Cursor 和 Claude Code 等 AI 编码工具的激烈竞争。

📝 详细摘要

文章基于多家外媒报道和多位现任及前任员工采访，系统梳理了 GitHub 当前面临的严峻挑战。在技术层面，GitHub 近期遭遇多次重大宕机，2025 年服务可用率跌破 90%，并出现严重 RCE 漏洞和因员工安装被投毒 VS Code 扩展导致内部代码库被入侵的安全事件。在组织层面，前 CEO 离职后，微软未任命新 CEO，而是将 GitHub 领导团队并入 CoreAI 团队，此举被视为其独立地位下降的标志，导致内部士气低落和人才流失。在竞争层面，GitHub 正面临 Cursor、Claude Code 等 AI 编码工具的强力挑战，这些工具正在改变开发者的工作方式，削弱了将代码上传至 GitHub 的必要性。文章还提到，微软内部曾大规模推广 Claude Code，后因统一工具链和成本压力而要求团队切换回 GitHub Copilot CLI，这进一步凸显了 GitHub 在微软内部的尴尬处境。文章认为，GitHub 需要尽快打出“翻身”一击，否则其战略价值与资源优先级可能面临重新评估。

💡 主要观点

  1. GitHub 正面临严重的技术可靠性危机，服务可用率大幅下滑。 2025 年 GitHub 服务可用率跌破 90%，4 月甚至低于 85%，频繁的宕机和容量规划失误严重影响了开发者体验和平台信誉。
  2. 安全事件频发，从 RCE 漏洞到内部代码库被入侵，暴露出安全治理短板。 Wiz 发现严重 RCE 漏洞，且 88% 的企业服务器实例未及时修复；一名员工安装被投毒的 VS Code 扩展导致约 4000 个内部仓库被攻陷，安全形势严峻。
  3. 组织层面陷入领导真空和文化危机，独立地位被削弱。 前 CEO 离职后微软未任命新 CEO，GitHub 被并入 CoreAI 团队，被视为地位下降；员工士气受挫，人才持续流失，加剧了运维和创新压力。
  4. 外部竞争加剧，AI 编码工具正在重塑开发者工作流，威胁 GitHub 核心地位。 Cursor 和 Claude Code 等产品改变了写代码和协作的方式，降低了开发者对 GitHub 仓库的依赖，微软内部对 Claude Code 的推广与限制也反映了这一竞争态势。

💬 文章金句

  • 在微软内部，如今的 GitHub 正在遭遇一场生存级别的危机。
  • GitHub 的可用性出现明显下滑...其服务在 2025 年的可用率已跌破 90%，且整体趋势持续下滑，4 月的可用率更是已低于 85%。
  • 许多员工甚至认为，GitHub 在微软体系下的定位变得模糊，原本引以为傲的独立文化遭到削弱，内部士气受到影响。
  • 这些产品正在改变开发者写代码、调试与协作的方式，也削弱了把代码持续上传到 GitHub 仓库的必要性。
  • 目前来看，留给 GitHub 的时间和空间都在收缩，GitHub 需要尽快打出'翻身'一击。否则，其战略价值与资源优先级都可能面临重新评估。
