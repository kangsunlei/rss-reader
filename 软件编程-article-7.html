Rspress 2.0：AI 原生文档、更快的启动速度与重构的主题

3/8/2026, 12:00:00 PM

📌 一句话摘要

Rspress 2.0 作为一款 AI 原生静态站点生成器发布，其特点包括重构的主题、通过懒编译实现的显著构建性能提升，以及为 AI 智能体专门优化的 Markdown 输出。

📝 详细摘要

Rspress 2.0 标志着这款基于 Rspack 的文档工具迎来了重大演进，重点关注三个核心支柱：开发者体验、性能和 AI 准备就绪。此次更新引入了高度灵活的基于 BEM 的主题系统，并切换到 Shiki 进行构建时语法高亮。通过懒编译和持久化缓存，性能得到了大幅提升，冷启动速度快至 50ms。值得注意的是，全新的 SSG-MD 功能使文档站点能够生成高质量的 Markdown 和 llms.txt 文件，专门针对 AI 智能体进行了优化，使 Rspress 成为 LLM 时代具有前瞻性的工具。

💡 主要观点

  1. 通过 SSG-MD 功能引入 AI 原生渲染，以实现更好的 LLM 集成。 与传统的 HTML 转 Markdown 不同，Rspress 2.0 通过 React 虚拟 DOM 渲染内容，以生成高质量的 Markdown 和 llms.txt 文件，使文档更易于被 AI 智能体和 LLM 消费。
  2. 通过懒编译和持久化缓存策略实现显著的构建性能优化。 通过在开发过程中仅在请求时编译页面，并利用持久化缓存进行后续构建，Rspress 将冷启动时间缩短至 50ms，并将构建速度提升了高达 60%。
  3. 重构的主题系统，为开发者提供四个不同层级的定制和控制。 新主题采用基于 BEM 的方法与特定 CSS 框架解耦，允许开发者在简单的 CSS 变量调整、组件重导出或完整的组件 Eject 之间进行选择，以获得最大的灵活性。
  4. 通过采用 Shiki 并回归 JavaScript 版 MDX 解析器实现工具链的战略转变。 转向 Shiki 确保了与 VS Code 一致的高亮效果，同时牺牲了 Rust 版 MDX 解析器的原始速度，以换取 JavaScript 版本提供的更好的生态系统兼容性和插件支持。

💬 文章金句

  • Rspress 2.0：AI 原生文档、更快的启动速度与重构的主题。
  • SSG-MD 通过 React 虚拟 DOM 渲染内容，生成适合 AI 智能体的高质量 Markdown。
  • 通过懒编译，页面仅在开发期间访问时才进行编译，将冷启动时间从几秒缩短至低至 50 毫秒。
  • BEM 方法是一个深思熟虑的选择，旨在与任何特定的 CSS 框架解耦，允许团队自由使用 Tailwind、Less 或 Sass。
  • Rspress 的核心差异化在于其基于 Rspack 的构建速度及其 AI 原生特性。
