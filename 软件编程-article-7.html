Android XR SDK 最新动态: 开发者预览版 4 现已推出

6/5/2026, 9:30:00 AM

📌 一句话摘要

Android XR SDK 开发者预览版 4 发布，引入音频眼镜与显示眼镜的新命名、增强体验 API、沉浸式 3D 模型支持及 Geospatial API 预览，核心库即将进入 Beta 版。

📝 详细摘要

本文是 Google 官方博客，宣布 Android XR SDK 开发者预览版 4 的正式推出。文章首先介绍了设备命名调整：AI 眼镜更名为音频眼镜，显示 AI 眼镜更名为显示眼镜。核心更新分为两大方向：一是为音频眼镜和显示眼镜打造的增强体验，包括 Jetpack Projected 库的设备可用性 API 和 ProjectedTestRule，以及 Jetpack Compose Glimmer 库新增的 Google Sans Flex 字体、Stacks 和 Title Chips 组件。二是为 XR 头戴式设备和有线 XR 眼镜打造的沉浸式体验，涉及 XR Runtime、Jetpack SceneCore 和 ARCore for Jetpack XR 即将进入 Beta 版，并移除了旧版 Guava 和 RxJava3。具体新增功能包括 SceneCore 中的 glTF 模型节点操作和自定义网格、Compose for XR 的原生 glTF 支持，以及 ARCore for Jetpack XR 中适用于有线 XR 眼镜的 Geospatial API 预览版。文章还提及了 Android XR Developer Catalyst 计划，为开发者提供预发布硬件。最后，文章介绍了对虚幻引擎、Godot 的官方支持以及新的 Unity 开发工具。

💡 主要观点

  1. Android XR SDK 预览版 4 聚焦跨设备统一开发体验。 通过统一头戴式设备、有线 XR 眼镜和智能眼镜的 API，并引入更清晰的设备命名（音频眼镜、显示眼镜），降低开发者在不同形态设备上的适配成本。
  2. 增强体验库新增设备可用性 API 和测试工具。 Jetpack Projected 库的 Device Availability API 将设备佩戴状态映射为标准 Lifecycle State，简化应用行为调整；ProjectedTestRule 则简化了单元测试的搭建。
  3. 沉浸式体验核心库即将进入 Beta 版，并采用 Kotlin 优先架构。 XR Runtime、SceneCore 和 ARCore for Jetpack XR 将进入 Beta，同时移除旧版 Guava 和 RxJava3，转向现代化 Kotlin 架构，提升开发效率。
  4. 新增 glTF 模型节点操作、自定义网格和原生 glTF 支持。 SceneCore 的 GltfModelNode 允许修改 3D 模型节点属性并运行动画；CustomMesh 支持动态构建几何体；Compose for XR 的 SpatialGltfModel 提供原生 glTF 渲染能力。
  5. Geospatial API 预览版将 AR 与地理位置深度结合。 ARCore for Jetpack XR 的 Geospatial API 可在 87 个国家/地区实现高精度位置锚定，结合 Gemini Live API 可构建上下文感知的 AI 导览等体验。

💬 文章金句
