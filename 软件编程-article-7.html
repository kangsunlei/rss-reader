OpenAI 高管教网友用 Claude 跑 GPT-5.6 Sol，开发者照做却被封号，CC 之父火速下场回应后还想挖角却遭拒

8/10/2026, 9:27:00 AM

📌 一句话摘要

OpenAI 高管发教程教开发者在 Claude Code 中运行 GPT-5.6 Sol，开发者照做后 Anthropic 账号被封，两家公司高管隔空交锋并围绕跨模型兼容与账号安全机制展开争论。

📝 详细摘要

文章完整梳理了一场由跨模型调用引发的账号封禁争议。OpenAI Codex 负责人 Tibo 在 X 上发布教程，指导用户通过第三方配置在 Anthropic Claude Code CLI 中调用 GPT-5.6 Sol；开发者 Alex Getman 按步骤操作后，Anthropic 账号被系统自动暂停。Anthropic Claude Code 负责人 Boris Cherny 回应称，封号并非因为用户使用其他模型，而是账号安全分类器误触发，并已解决该问题。事件发酵中，Cherny 公开挖角 Tibo 被拒，Tibo 强调 harness 选择自由，并宣布为 ChatGPT Work 和 Codex 用户重置额度，Sam Altman 后续转发支持。文章最后指出，该事件折射出 AI 编程工具在跨模型兼容、平台开放性与安全风控之间的行业矛盾。

💡 主要观点

  1. OpenAI 高管公开教用户在 Claude Code 中调用 GPT-5.6 Sol，开发者照做后账号被封。 Tibo 发布配置教程后，开发者 Alex Getman 按步骤操作，Anthropic 账号随即被系统暂停，引发争议。
  2. Anthropic 回应封号并非因使用竞品模型，而是安全分类器误触发。 Claude Code 负责人 Boris Cherny 表示不会因用户在开发环境中使用其他模型而封禁账号，并已解决误封问题。
  3. 挖角插曲与额度重置成为事件转折，双方在开放性问题上立场各异。 Cherny 邀请 Tibo 加入 Anthropic 被拒，Tibo 强调 harness 选择自由，并为 OpenAI 用户重置额度，Sam Altman 转发支持。
  4. 事件折射出 AI 编程工具跨模型兼容与平台开放、安全风控之间的行业矛盾。 开发者希望自由组合不同厂商的模型，平台则需在开放性、安全风险和商业利益之间寻找平衡，这将成为 AI 企业共同面对的问题。

💬 文章金句

  • 我们不会因为用户在自己的开发环境中使用其他模型而封禁账号。几乎可以确定，是另一个账号分类器触发了限制。我正在调查此事，感谢你的反馈。
  • 我很想帮忙，但我并不在 Anthropic 工作。如果 Anthropic 仅仅因为用户在他们的开发环境中接入了其他模型，就封禁账号，这确实令人感到不解。
  • 很高兴事情已经解决，一切都恢复正常了。Harness 的选择的自由非常重要，我们应该让用户自己决定哪个模型最适合他们。
