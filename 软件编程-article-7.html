Gemini Live API 在 Vertex AI 上普遍可用

12/13/2025, 12:00:00 AM

📌 一句话摘要

谷歌 宣布 在 Vertex AI 上 正式推出 Gemini Live API，该 API 由 支持原生音频的 Gemini 2.5 Flash 模型 提供支持，旨在实现实时多模态对话式 AI 智能体。

📝 详细摘要

本文宣布 Gemini Live API 在 Vertex AI 上 正式推出，该 API 利用 支持原生音频的 Gemini 2.5 Flash 模型。通过 集成 语音、视觉 和 文本，该 API 为多模态对话式 AI 设定了 新标准，能够提供 流畅、仿人 且 高度 情境化的 低延迟 交互。它 支持 实时功能，例如 在 句子中途 处理 打断、理解 听觉线索 以及 解释 复杂的 视觉数据。文章 强调了 其 企业就绪性、在 Vertex AI 上 通过 全球基础设施 和 数据驻留功能 实现的 稳定部署。来自 Shopify、UWM、SightCall、Napster、Lumeris、Newo 和 11Sight 等公司 的 多个 案例研究 展示了 其在 增强 客户体验 和 提高 各行业 运营效率 方面的 实际影响。

💡 主要观点

  1. 由 支持原生音频的 Gemini 2.5 Flash 模型 提供支持的 Gemini Live API，现已在 Vertex AI 上 普遍可用。 此次 发布 标志着 在 使 先进的 实时 多模态 AI 适用于 企业应用 方面 迈出了 重要一步，实现了 语音、视觉 和 文本的 无缝集成。
  2. Gemini Live API 为 仿人 对话式 AI 交互 设定了 新标准。 它 允许 AI 智能体 理解 意图、语气 和 上下文，处理 打断，并 结合 视觉数据 提供 即时 情境 帮助，模仿 自然的 仿人 对话。
  3. Vertex AI 为 部署 Gemini Live API 提供 企业级 安全性、稳定性 和 全球基础设施。 其 强大的 平台 确保 任务关键型 智能体 以 一致的 低延迟 性能 运行，并 符合 数据驻留 和 合规标准，这 对于 业务应用 至关重要。
  4. 领先 公司 已在 利用 Gemini Live API 彻底改变 其在 各个行业 的 客户体验 和 运营。 来自 Shopify、UWM、SightCall、Napster、Lumeris、Newo 和 11Sight 的 示例 说明了 该 API 如何 用于 构建 智能助手，以 解决 问题、提高 效率 并 促进 创意 协作，展示了 其 广泛的 适用性 和 影响力。

  • Gemini Live API 是 原生 多模态的，旨在 处理 人类对话的 即时 复杂性：它 可以在 句子中途 处理 打断 而不 受影响，确保 自然的 轮替。
