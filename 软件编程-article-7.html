Agentic 时代的技术地图：AICon 2026 上海站全日程正式发布

6/2/2026, 5:45:00 AM

📌 一句话摘要

AICon 2026 上海站全日程发布，以 Agentic 操作系统为核心命题，聚焦 Agent 工程化落地与研发组织 AI 重塑两大主题，汇集阿里、腾讯、蚂蚁等头部公司技术实践。

📝 详细摘要

本文是 AICon 2026 上海站大会的全日程发布公告。大会以「构建可信赖、可规模化、可商业化的 Agentic 操作系统」为核心命题，于 6 月 26-27 日在上海举办。文章详细介绍了大会的四场主题演讲，分别由复旦大学邱锡鹏（MOSS 多模态模型）、阿里云张献涛（云原生到 Agent Native）、蚂蚁集团周俊（百灵 v2.6 模型与工作流智能）、清华大学翟季冬（Token 服务全链路优化）四位重量级嘉宾主讲。大会内容主体围绕两大命题展开：一是 Agent 如何真正用起来，涵盖工程化、记忆与运行时基础设施、安全与可信治理三个专题；二是研发组织如何被 AI 重塑，包括企业级研发体系重构和 AI 开发生产力重构两个专题。此外还设置了 AI 原生数据工程、世界模型与多模态智能、大模型推理优化、金融领域大模型落地、企业智算架构、移动端开发与端侧智能等专题，以及 Google Cloud 硬核动手实验室。

💡 主要观点

  1. Agent 工程化的核心挑战不在模型层，而在执行层。 阿里云服务数千家企业客户的实践表明，超过 70% 的 Agent 工程挑战来自执行层，Serverless 的无状态假设正被 Agent 的有状态本质所挑战。
  2. 大会聚焦两大核心命题：Agent 真正用起来，以及研发组织被 AI 重塑。 超过一半的专题演讲围绕这两个命题展开，前者涵盖工程化、记忆与安全治理，后者关注从个人提效到组织级研发体系重构的系统性变革。
  3. 多模态模型、推理优化和端侧智能是技术前沿方向。 MOSS 多模态模型、腾讯混元世界模型、京东 xLLM 投机推理、华为 Omni Cache 等议题代表了模型能力和推理效率的前沿突破。
  4. 金融领域是大模型落地最严苛的场景之一。 大会专门设置了金融领域大模型落地实践专题，涵盖反欺诈、信贷全链路变革、保险风控等头部机构的真实工程经验。

💬 文章金句

  • 当 AI 不再只是工具，组织本身开始被重塑。
  • 超过 70% 的 Agent 工程挑战不在模型层，而在执行层。
  • Serverless 十年的无状态假设，正在被 Agent 的有状态本质所挑战。
  • 大模型如何从「会回答」走向「能执行」——从 Agent 能力、推理效率到 Async RL 训练范式，一套完整的工作流智能构建路径。
