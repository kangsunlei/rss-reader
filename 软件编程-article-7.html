📌 一句话摘要

本文详细介绍了为 Claude Code 构建持久化记忆与自我学习系统的完整设计，通过 Hook 机制、模式提炼和向量检索，实现跨会话的行为习惯学习与知识复用。

📝 详细摘要

文章来自得物技术团队，记录了一套为 Claude Code 打造的「自我进化与记忆系统」的完整实现。系统由行为观测层（Observation Engine）、模式提炼层（Instinct Engine）和记忆注入层（Memory Engine）三个子系统构成，形成从工具调用捕获、行为模式分析到跨会话知识注入的自学习闭环。 行为观测层通过 Claude Code 原生 Hook 机制（PreToolUse/PostToolUse/Stop）100% 捕获每次工具调用，写入 JSONL 观测流，并设计了数据分片与生命周期管理防止膨胀。模式提炼层在会话结束时自动运行，通过统计模式检测（5 种硬编码模式）和 AI 语义分析（调用 Claude 模型）两条并行路径提炼行为模式，生成原子化的 Instinct 规则，并基于 Jaccard 相似度的 Union-Find 算法进行语义去重，按 domain 聚合后写入规则文件。记忆注入层则处理知识性记忆，使用本地 nomic-embed-text 模型进行向量化，通过 SessionStart Hook 在会话启动时自动检索 Top-5 相关记忆并注入系统提示。 文章还提供了量化收益：上下文冷启动时间从 10 分钟降至 30 秒，Token 消耗降低约 78%，错误重复率下降 80%，并指出记忆系统的价值随时间呈指数增长。整体设计理念强调原子性优先、隐私边界（观测数据仅存本地）、置信度演化和 Hook 优先于 Skill 的确定性触发。

💡 主要观点

  1. 系统通过 Hook 机制实现 100% 确定性触发，替代了依赖模型主动调用的 Skill 方案。 早期版本使用 Skill 触发学习，触发率不稳定。v2 改用 Claude Code 原生 Hook 机制（PreToolUse/PostToolUse/Stop），在工具调用生命周期中强制捕获数据，确保数据采集的完整性和可靠性。
  2. 模式提炼采用统计检测与 AI 语义分析双路径互补。 统计路径通过 5 种硬编码模式快速识别高频工具调用序列，语义路径调用 Claude 模型分析观测摘要，捕获统计方法无法识别的深层行为规律，两者结合兼顾了速度与深度。
  3. 记忆系统使用本地 Embedding 模型进行向量检索，兼顾语义理解与隐私保护。 选用本地运行的 nomic-embed-text 模型配合 qdrant 向量库，避免将包含项目路径、函数名等敏感信息的记忆内容上传到第三方服务，在 M 系列芯片上推理速度约 10ms/条。
  4. 系统带来可量化的效率提升：冷启动时间降至 30 秒，Token 消耗降低 78%，错误重复率下降 80%。 SessionStart Hook 自动注入项目记忆和高置信度规则，使模型首条响应即体现上下文感知；精确召回 Top-5 记忆而非全量粘贴，大幅节省 input token；Instinct 系统记住历史错误模式，有效避免同类问题重复发生。

💬 文章金句

  • 每次打开 Claude Code 开始新对话，它都是一张白纸。昨天你花了 10 分钟解释的项目架构、你反复纠正的代码风格偏好、你建立的特殊开发规范——全部归零。
  • Hook 优先于 Skill：确定性触发是数据质量的保障。放弃依赖模型主动调用的 Skill 触发，改用系统级 Hook 确保 100% 采集率。
  • 记忆系统的价值随时间指数增长，而非线性增长。
