AgentTeams 加速开源迭代，新版本新增 Dashboard

10/20/2026, 8:12:00 AM

📌 一句话摘要

AgentTeams 1.2.5 发布，配套 Dashboard v1.3.1 新增统一资源管理、项目任务两级看板、Skill 热加载与远程同步、运行时升级及编码 CLI 集成等工程化能力。

📝 详细摘要

阿里巴巴中间件团队发布 AgentTeams 1.2.5 版本，配合独立发版的 Dashboard v1.3.1，重点强化多智能体团队的工程化管控能力。更新涵盖五大维度：统一用户权限、Worker/Manager、团队、Skill、MCP 及模型路由的资源管理；提供项目与任务两级看板，支持依赖拓扑、阻塞点定位、暂停恢复与完成检查；Skill 管理引入远程 Nacos 注册表同步、热加载与 ZIP 导出，提升能力复用；运行时完成 CoPaw 到 QwenPaw 升级，引入 DeepSeek Harness 实验性 Worker，新增 LLM 参数调优、原地升级回滚等可靠性优化；新增 Coding CLI 扩展，支持 Qwen Code、OpenCode、Qoder 等编码工具的安装授权、执行记录审计与环境变量配置。文章以发布说明形式呈现，面向开发者展示开源项目的最新工程进展。

💡 主要观点

  1. AgentTeams 1.2.5 正式发布，配套 Dashboard v1.3.1 提供统一管控入口 版本更新围绕 Dashboard 这一统一入口展开，集中管理用户权限、Agent 实例、团队关系、技能工具模型资源，解决多 Agent 协作中的资源碎片化问题。
  2. 新增项目与任务两级看板，支持依赖追踪、进度可视化与人工干预 项目视图展示整体进度与任务依赖拓扑，任务视图记录负责人、执行要求、状态变更历史与产物，支持暂停恢复、重新委派通知，便于人工介入与追溯。
  3. 统一 Skill 管理支持远程注册表同步、热加载与 ZIP 导出，提升能力复用效率 技能目录覆盖内置、共享、团队及插件技能，接入 Nacos Skill Registry 实现远程同步；QwenPaw 支持热加载无需重启，ZIP 下载便于导出复用，权限体系保障分发安全。
  4. 运行时完成从 CoPaw 到 QwenPaw 升级，引入 DeepSeek Harness 实验性 Worker，强化可靠性与模型参数调优 QwenPaw 2.2.1 带来重试并发控制、流式响应超时调优、原地升级回滚、兼容性检查等能力；减少重复同步与配置重载，修复 Manager 重启恢复、MCP 注册、Matrix 空转等问题。
  5. 新增编码 CLI 管理与执行记录审计，支持主流编码工具集成 Dashboard 提供 Qwen Code、OpenCode、Qoder 的安装检查、授权配置、执行参数管理，新增只读执行详情页可查看关联任务、结果日志及被阻止记录，配合环境变量编辑与网关身份探测完善工程化闭环。

💬 文章金句

  • AgentTeams 1.2.5 已正式发布，默认搭配独立发版的 Dashboard v1.3.1，新增编码 CLI 管理、执行记录查看与 LLM 参数调优等功能。
  • 项目组织完整目标与任务关系，任务记录具体工作的执行信息。
  • QwenPaw Manager 和 Worker 已支持技能热加载，技能更新后无需重启运行时。
  • 1.2.5 已交付 Coding CLI 扩展，支持 Qwen Code、OpenCode 和 Qoder 等编码工具。
