编程能力提高 50%！GLM-5.3 满分通过了 GPT-5.6 给的 Coding 测试

8/15/2026, 2:15:00 AM

📌 一句话摘要

智谱发布 GLM-5.3，通过 GPT-5.6 设计的 Coding 测试满分，编程能力提升约 50%，同时安全漏洞发现能力显著增强，在真实开源项目中发现 2436 个漏洞。

📝 详细摘要

北京时间 8 月 14 日，智谱发布 GLM-5.3 模型。该模型基于 GLM-5.2 的长程强化学习技术栈，扩大训练规模并投入更多计算资源。智谱让 GPT-5.6 设计了包含五项任务的 Coding 测试，GLM-5.3 在 ZCode 中 13 分钟内满分通过，GPT-5.6 给出 A- 评价。性能提升主要来自后训练，内部 Code Bench 显示编程能力提高约 50%。技术架构方面，引入了 IndexShare、SAO 和 slime 框架，支持长程 Agent 任务训练，同时优化了 token 消耗效率。安全能力是本次亮点，CyberGym 测试达 84.5%，ExploitBench 达 54.4%，在真实开源项目中发现 2436 个漏洞，其中 1097 个高危及以上。模型将于约两周后完成安全评估并公开权重。

💡 主要观点

  1. GLM-5.3 通过 GPT-5.6 设计的 Coding 测试满分，获 A- 评价。 测试包含推理强度、算法代码生成、仓库缺陷修复、多轮工具调用和安全审计五项，GLM-5.3 在 13 分钟内完成，GPT-5.6 肯定其受约束工程执行能力，但指出任务复杂度低于真实大型工程。
  2. 编程能力提升约 50% 来自后训练而非基础模型升级。 智谱在 GLM-5.2 技术栈基础上扩大训练规模，引入更接近真实工程的长程任务环境，让模型从写代码转向独立承担完整工程工作。
  3. 安全能力超预期，在真实开源项目中发现 2436 个漏洞。 CyberGym 达 84.5%，ExploitBench 达 54.4%。漏洞覆盖系统内核、浏览器引擎、Web 应用等，平均存在 26.6 年，其中 1097 个高危及以上。
  4. 开源后训练框架 slime，支持长程强化学习训练。 slime 整合 Megatron 训练与 SGLang Rollout，优化了 Router 调度与负载均衡，长程 Coding RL 端到端训练吞吐提升超 2.3 倍。

💬 文章金句

  • 这次测试说明 GLM-5.3 在 ZCode 中的受约束工程执行能力很强，可评为 A-。
  • 但不能仅凭这次 100 分就认定它在大型系统工程或真实安全任务中达到前沿闭源模型水平。
  • 模型不仅更擅长定位单个漏洞，也开始能够跨越漏洞利用的多个阶段进行推理，并形成相对完整的攻击利用链。
