有人花 3 天做了个开源工具，一句话生成各种场景的 HTML。

5/19/2026, 7:19:00 AM

📌 一句话摘要

本文介绍了一个名为 html-anything 的开源工具，它能利用本地 AI Agent 根据用户输入的一句话内容，自动生成适用于多种场景的精美 HTML 文件。

📝 详细摘要

文章围绕「HTML is the new markdown」这一观点展开，介绍了一个名为 html-anything 的开源项目。该项目由 Open Design 团队在 3 天内开发完成，旨在将 AI 生成 HTML 的理念落地为实用工具。其核心功能是让用户通过粘贴内容、选择模板并按下快捷键，即可利用本地已安装的 Coding Agent（如 Claude Code、Cursor 等）自动生成设计精美的 HTML 文件。文章重点介绍了该工具的三大亮点：内置 75 套覆盖 9 种输出格式的模板、零额外 API Key 成本直接复用现有 Agent 会话、以及一键导出到微信公众号、X、小红书等平台且无需二次排版。最后，文章提供了简单的安装和使用步骤。

💡 主要观点

  1. html-anything 是一个利用本地 AI Agent 生成 HTML 的开源工具。 该工具基于「HTML is the new markdown」的理念，让用户无需手写代码，通过粘贴内容和选择模板，即可让 AI 自动生成适用于多种场景的精美 HTML 文件。
  2. 工具内置 75 套模板，覆盖 9 种输出格式。 模板涵盖杂志文章、PPT、海报、小红书卡片、网页原型等多种格式，每种格式下还有多种风格可选，极大地降低了从内容到最终交付物的门槛。
  3. 零额外成本，直接复用用户已有的 Coding Agent。 html-anything 不自行构建 Agent，而是自动检测并复用用户电脑上已安装的 Claude Code、Cursor 等工具，无需额外配置 API Key，边际成本为零。
  4. 一键导出到多个平台，无需二次排版。 工具支持直接导出到微信公众号、X、小红书等平台，并自动处理 CSS 内联、图片渲染、公式转换等格式问题，极大提升了内容发布效率。

💬 文章金句

  • HTML is the new markdown。
  • Markdown 是草稿，HTML 才是给人看的最终形态。
  • 过去不选 HTML 是因为手写太麻烦，但在 Agent 时代，你不应该再手写 HTML 了，让 AI 来。
