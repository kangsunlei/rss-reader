MadeYouReset：快速重置缓解措施已防御的 HTTP/2 漏洞

8/14/2025, 3:03:07 PM

📌 一句话摘要

MadeYouReset 是一个新披露的 HTTP/2 DoS 漏洞。它利用恶意构造的帧进行流重置，但现有的快速重置缓解措施在很大程度上可以防御它。

📝 详细摘要

本文详细介绍了 MadeYouReset (CVE-2025-8671)，这是特拉维夫大学研究人员发现的一种新的 HTTP/2 拒绝服务攻击漏洞。该漏洞在概念上类似于快速重置攻击 (CVE-2023-44487)，利用了 HTTP/2 流重置机制。虽然快速重置直接发出重置，但 MadeYouReset 通过发送专门制作的恶意构造帧来诱骗服务器重置流，从而导致资源耗尽。幸运的是，由于许多主要的 HTTP/2 实现已经受到 2023 年为应对快速重置而实施的缓解措施的保护，因此影响有限。Cloudflare 确认其系统不易受到这些先前缓解措施的影响。文章还建议 Cloudflare 的开源 Pingora 框架的用户将其 `h2` Rust 包更新到 0.4.11 或更高版本，以修补潜在的易受攻击性。

💡 主要观点

  1. MadeYouReset 是一种新的 HTTP/2 DoS 漏洞，它利用恶意构造的帧来触发流重置。 这种攻击方法不同于直接流重置，它迫使服务器花费资源来启动然后立即丢弃操作，从而可能导致资源耗尽和服务不可用。
  2. 针对先前快速重置攻击的主动缓解措施可有效防御 MadeYouReset。 2023 年为应对快速重置而实施的措施已无意中为此新漏洞提供了实质性保护，从而大大限制了其广泛破坏的潜力。
  3. Cloudflare 的基础设施受到保护，Pingora 用户可以通过更新其 `h2` 库进行修补。 Cloudflare 现有的 DDoS 缓解措施可确保提供保护，同时建议开源 Pingora 框架的用户更新其 `h2` Rust 包，以解决潜在的易受攻击性。

💬 文章金句

  • 如果您使用 Cloudflare 进行 HTTP DDoS 缓解，那么您已经受到 MadeYouReset 的保护。
  • MadeYouReset 和快速重置是两个概念上相似的 HTTP/2 协议攻击，它们利用了 HTTP/2 规范中的一项基本功能：流重置。
  • MadeYouReset 和快速重置之间的区别在于，客户端不是直接发出流重置，而是通过发送专门制作的恶意构造帧来诱骗服务器重置流。
  • 在当今已广泛使用的大多数主要 HTTP/2 实现中，为应对 2023 年的快速重置而采取的主动措施也为 MadeYouReset 提供了实质性保护，从而限制了其潜在影响并防止了类似的破坏性事件。
  • Pingora 的用户可以使用 cargo update 命令（Rust 的包管理工具）来更新其 h2 Rust 包版本，从而修补其应用程序。
