💡 主要观点

  1. 字节跳动通过 Memory Graph 降低 OOM 崩溃率 文章介绍了字节跳动如何利用内存快照技术构建 Memory Graph，该技术能够还原对象引用关系，帮助识别异常内存来源并辅助归因，从而在三个月内将头条和抖音的 OOM 崩溃率降低超过 50%。
  2. 滴滴的 HDFS 滚动升级实践 滴滴分享了将大规模生产集群中的 HDFS 从 2.7 版本滚动升级到 3.2 的经验，重点讨论了版本兼容、服务连续性、升级顺序、风险控制和异常回退等关键问题。
  3. 快手对 Android 内存分配器的优化 快手深入分析了 jemalloc 内存分配器的组织结构和碎片管理机制，并介绍了 Google 为 Android 平台进行的定制优化，旨在降低内存占用和碎片率。
  4. 美团外卖的微前端实践 美团介绍了如何使用基于 React 的微前端架构来治理 PC、H5 和 KA 三端的工程膨胀问题，通过将系统拆分为独立子工程，实现了更快的构建时间和更好的可维护性。
  5. 网易云音乐的 iOS 14 小组件实战 文章详细讲解了 iOS 14 WidgetKit 小组件的实现，包括 Timeline 数据刷新、SwiftUI 界面构建、App Groups 数据共享、Intents 个性化配置，以及 URL Scheme 跳转等内容。
