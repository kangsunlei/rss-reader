我在 GitHub 上搜罗了 6 个高质量数据集，看看哪些会用到。

10/31/2026, 12:21:00 AM

📌 一句话摘要

本文介绍了六个在 GitHub 上开源的高质量数据集，包括唐宋诗词、3D 资产、雅思英语单词、健身动作、国家城市地理信息，以及物理模拟数据，这些资源可以用于开发教育、娱乐、仿真等领域的应用程序。

📝 详细摘要

文章详细列举了六个具有广泛应用前景的开源数据集。第一个是包含三十多万首唐宋诗词的文本库，适合用于开发诗词学习或游戏应用。第二个和第三个是 3D 资产数据集，分别由 NVIDIA 和 Scenario 3D 提供，用于机器人仿真和游戏开发。第四个是雅思英语单词数据集，配有丰富的音频和图像资源，用于语言学习。第五个是国家城市地理信息数据库，提供全球地址数据。最后一个是 15TB 的物理模拟数据，用于研究流体、声波等物理现象。这些数据集均可通过 GitHub 或 Hugging Face 获取，并提供了具体的下载链接。

💡 主要观点

  1. 唐宋诗词数据集 包含约 5.5 万首唐诗、26 万首宋诗和 2.1 万首宋词，以及古典文集，适合用于开发诗词日历、飞花令游戏或诗人作品集分析。
  2. 3D 资产数据集 由 NVIDIA 和 Scenario 3D 提供，包含物理仿真模型和 AI 生成的 3D 对象，用于机器人训练、工业仿真和虚拟场景构建。
  3. 雅思英语单词数据集 包含 7298 个单词的文本、图像和音频资源，支持多种语言，用于开发单词记忆和语言学习应用程序。
  4. 健身动作数据集 包含 1324 个健身动作的 GIF 演示和详细说明，支持多语言，用于创建健身指导或训练记录应用。
  5. 国家城市地理信息数据库 提供 250 个国家及 15 万个城市的层级数据，包括经纬度和时区信息，用于开发地址表单、城市查询或旅行地图。
  6. 物理模拟数据 包含 15TB 的流体、声波、生物和超新星爆炸模拟数据，用于可视化物理过程和训练机器学习模型。

💬 文章金句

  • 想做一个飞花令小游戏，可以从诗句里筛选指定的字。想做诗人的作品集，可以按作者归类。每天挑一首诗，配上日期和自己设计的页面，也能做成诗词日历。
  • 做机器人训练场景时，可以从里面挑选物件，省去一部分自己建模的工作。
  • 注册页面里常见的"先选国家，再选省州，最后选城市"，就需要这样的层级关系。
  • 把连续几个时刻的数值画出来，可以观察一个物理过程怎样变化。把它们交给机器学习模型训练，则可以研究如何根据已有状态预测后续演变。
