微软 Azure Cobalt 200 ARM 芯片：AI 驱动，性能提升 50%

11/28/2025, 10:00:00 AM

📌 一句话摘要

Azure Cobalt 200：微软云服务定制 ARM 芯片，AI 数字孪生设计，性能提升 50%

📝 详细摘要

微软在其年度 Ignite 大会上发布了 Azure Cobalt 200 ARM 芯片，标志着其定制硅产品的重大进步。作为 Cobalt 100 处理器的继任者，它承诺为各种 Azure 工作负载（包括数据库、Web 服务器、存储缓存、网络事务和数据分析）带来 50% 的性能提升。Cobalt 200 的开发过程是高度数据驱动的，利用了从 CPU 微架构到服务器设计的“数字孪生”模拟。微软利用 AI 和 Azure 计算，模拟了 140 个基准测试在 2，800 种片上系统 (SoC) 和系统设计参数组合下的性能和功耗。总共评估了超过 350，000 个配置候选方案。这种广泛的模拟能够快速迭代以实现最佳设计点，从而产生一个高效节能的平台。Cobalt 200 SoC 基于 ARM 的 Neoverse 计算子系统 V3 构建，具有 132 个活动核心。每个核心配备 3MB 的 L2 缓存和 192MB 的 L3 系统缓存，并与 Azure 最新的安全性、网络和存储技术集成。之前的 Cobalt 100 虚拟机已经被 Databricks 和 Snowflake 等公司广泛采用。

💡 主要观点

  1. Azure Cobalt 200 ARM 芯片：AI 驱动，云工作负载性能提升 50% 这种显著的性能提升直接使 Azure 客户受益，提高了各种应用程序（从数据库到数据分析）的效率，并可能降低运营成本。
  2. 微软采用了一种数据驱动的设计方法，使用 AI 和数字孪生模拟进行芯片开发。 这种创新的方法能够快速和广泛地优化 片上系统 (SoC) 和系统参数，从而产生一个高度节能和高性能的平台，专为 Azure 的特定需求量身定制。
  3. Cobalt 200 SoC 基于 ARM 的 Neoverse V3 构建，具有 132 个核心和大量的缓存。 先进的架构、高核心数和大量 L2/L3 缓存，对于在 Azure 云环境中高效处理高要求的企业工作负载至关重要，确保卓越性能。

💬 文章金句

  • Cobalt 200，它提供了 50% 的性能提升，并与最新的微软安全、网络和存储技术集成。
