Cloudflare 年度回顾：AI 机器人积极抓取，后量子加密达 50%，Go 份额翻倍

12/31/2025, 7:38:00 AM

📌 一句话摘要

Cloudflare 的 2025 雷达年度回顾显示，互联网流量增长 19%，Googlebot 在 AI 机器人抓取中占据主导，后量子加密显著普及，且基于 Go 语言的 API 客户端份额几乎翻倍。

📝 详细摘要

Cloudflare 的 2025 雷达年度回顾报告基于其广泛的基础设施数据，揭示了关键的互联网趋势。全球互联网流量增长了 19%，其中 Googlebot 被确定为最活跃的抓取工具，负责超过 28% 的已验证机器人流量，用于搜索索引和 AI 训练。值得注意的是，Anthropic 和 OpenAI 等 AI 平台展现出极高的抓取-推荐比，表明内容被消费但却没有同等比例的流量回流到源站点。报告还显示，所有人类生成的网络流量中有一半现在使用后量子加密，其采用率同比几乎翻倍，这加强了对“先收集，后解密”攻击的防御能力。此外，基于 Go 语言的客户端份额几乎翻倍，占自动化 API 请求的 20%。本次回顾还提到了持续的互联网中断（通常是由于计划性关闭或内乱造成），以及不断升级的超大量 DDoS 攻击，这些问题共同凸显了互联网的脆弱性及其日益增长的机器人活动。

💡 主要观点

  1. AI 机器人，特别是 Googlebot，正在积极抓取互联网以进行索引和 AI 训练。 Googlebot 在 Cloudflare 的机器人流量中占据主导地位，这表明搜索和 AI 公司正在大量获取数据，导致抓取-推荐比失衡，即 AI 平台消费内容却未带来相应比例的回流流量。
  2. 后量子加密在 2025 年显著加速普及，达到人类网络流量的 50%。 PQC 使用量的快速增长反映了在保护互联网通信免受未来量子计算威胁方面取得的关键进展，有效化解了“先收集，后解密”攻击。
  3. 基于 Go 语言的客户端在自动化 API 请求中的份额几乎翻倍。 Go 客户端目前占自动化 API 请求的 20%，表明开发者在 API 开发领域对 Go 的偏好和生态系统实力日益增强，在这个特定领域超越了 Python 和 Node.js 等其他流行语言。
  4. 互联网持续面临中断和不断升级、创纪录的 DDoS 攻击的挑战。 中断通常源于非技术因素（如学术考试关闭或内乱）；同时，日益频繁和大规模的 DDoS 攻击也凸显了互联网固有的脆弱性，以及对强大安全基础设施的需求。

💬 文章金句

  • Googlebot 在 2025 年再次负责 Cloudflare 最大的请求流量，因为它为搜索索引和 AI 训练抓取了数百万个 Cloudflare 客户网站。
  • AI 平台正在积极抓取内容，却没有相应比例地将流量引回源站点，抓取-推荐比相较 2024 年有所增加。
  • 一半的人类生成网络流量现在使用后量子加密，以防御“先收集，后解密”攻击，这比年初的 29% 几乎翻了一番。
  • 20% 的自动化 API 请求是由基于 Go 语言的客户端发出的，这比 2024 年 Go 语言的 12% 份额有了显著增长。
