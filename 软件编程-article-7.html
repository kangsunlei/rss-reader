Windows Forms 独立进程设计器中显式程序集引用的工具箱支持

4/17/2025, 2:45:27 PM

📌 一句话摘要

Visual Studio 17.14 Preview 3 引入了对 .NET Framework 项目中显式程序集引用的工具箱支持，有助于简化现有应用程序的开发。

📝 详细摘要

Visual Studio 17.14 Preview 3 增强了 Windows Forms 独立进程设计器，为 .NET Framework 项目提供了对显式程序集引用的工具箱支持。显式程序集引用是指直接在项目中引用的独立程序集，通常代表现有的 .NET Framework 组件，包括不易升级的 32 位组件。此功能通过自动扫描和提取控件信息，使这些组件在工具箱中可用，从而解决了在现代 64 位开发环境中使用这些组件的挑战。虽然简化了现有控件的使用，但由于显式程序集引用的限制，本文建议使用结构良好的 NuGet 包以获得最佳设计时体验。此功能目前适用于 .NET Framework 项目，并计划扩展到 .NET 项目。

💡 主要观点

  1. 工具箱现在支持显式程序集引用。 现在可以直接从工具箱中使用显式程序集引用中的控件。
  2. 此功能简化了现有控件的使用。 它通过允许开发人员在现代设计器中使用他们的现有控件，显著降低了迁移和维护的难度。
  3. 仍然建议使用 NuGet 包以获得最佳体验。 对于高级设计时功能，仍然建议使用与新的可扩展性模型对齐的结构良好的 NuGet 包。
  4. 显式程序集引用具有设计时限制。 显式程序集引用仅作为运行时组件处理，这限制了其高级设计时功能。

💬 文章金句

  • 显式程序集引用是直接在您的项目中引用的独立程序集。它们不是通过 NuGet 包、项目引用或全局程序集缓存 (GAC) 引入的。
  • 我们目前正在专门为 .NET Framework 项目推出此功能，但我们计划在未来的 Visual Studio 版本中将此支持扩展到 .NET 项目。
  • 虽然我们很高兴提供此功能，但我们继续强调，为了获得最丰富和最可预测的设计时体验，推荐的路径仍然是通过与新的可扩展性模型对齐的结构良好的 NuGet 包。
