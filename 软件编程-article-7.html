Splunk Enterprise 曝高危漏洞，CVSS 评分 9.8

6/11/2026, 10:00:00 AM

📌 一句话摘要

Splunk Enterprise 被披露多个高危漏洞，其中 CVE-2026-20253 允许未授权文件操作，CVSS 评分高达 9.8，需紧急修复。

📝 详细摘要

本文报道了 Splunk Enterprise 近期披露的多个高危安全漏洞。文章重点介绍了四个漏洞：CVE-2026-20253（CVSS 9.8）允许攻击者在 PostgreSQL 辅助服务端点上进行未经验证的任意文件创建和截断操作；CVE-2026-20251（CVSS 8.8）允许低权限用户通过 Splunk Secure Gateway 应用实现远程代码执行；以及两个中等严重程度的漏洞，分别涉及存储型 XSS（CVSS 7.1）和 SSRF（CVSS 7.6）。文章最后给出了升级至特定版本或采取临时缓解措施的修复建议。

💡 主要观点

  1. Splunk Enterprise 曝出多个高危漏洞，最严重的 CVE-2026-20253 允许未授权文件操作。 该漏洞 CVSS 评分 9.8，攻击者无需凭证即可在 PostgreSQL 辅助服务端点上创建或截断文件，可能导致数据库破坏或恶意文件植入。
  2. 另一个高危漏洞 CVE-2026-20251 允许低权限用户实现远程代码执行。 该漏洞源于 Splunk Secure Gateway 应用对 KV Store 数据的不安全反序列化，攻击者可利用特制 JSON 输入重建任意 Python 对象。
  3. 官方建议升级至特定版本，无法升级时可采取临时缓解措施。 修复版本包括 10.4.0、10.2.4 等；临时措施可关闭 Splunk Web 或禁用 Splunk Secure Gateway 应用。
