Grafana 安全发布：针对 CVE-2025-4123 和 CVE-2025-3580 的高危和中危安全修复

6/30/2025, 3:06:01 PM

📌 一句话摘要

新的 Grafana 补丁修复了高危 XSS 漏洞和中危用户删除漏洞。

📝 详细摘要

本文宣布发布 Grafana 12.0 和所有当前受支持版本的安全补丁，解决了两个漏洞：CVE-2025-4123（高危 XSS）和 CVE-2025-3580（中危用户删除）。XSS 漏洞允许攻击者重定向用户，并可能接管账户，值得注意的是，该漏洞不需要编辑器权限。用户删除问题可能允许组织管理员删除服务器管理员，从而导致 Grafana 实例无法管理。强烈建议用户立即将 Grafana 实例升级到最新的补丁版本。Grafana Cloud 和在云服务提供商处托管的 Grafana 用户已受到保护。

💡 主要观点

  1. 最新 Grafana 补丁解决了两个安全漏洞。 高危 XSS (CVE-2025-4123) 和中危用户删除问题 (CVE-2025-3580) 需要立即在 Grafana 中进行修补。
  2. 高危 XSS 漏洞 (CVE-2025-4123) 可能导致账户接管。 这种高危 XSS 不需要编辑器权限，并且可以通过重定向和恶意 JavaScript 执行来影响用户。
  3. 中危用户删除问题 (CVE-2025-3580) 存在 Grafana 实例无法管理的风险。 如果服务器管理员是组织管理员管理的组织的唯一成员，或者服务器管理员不属于任何组织，则组织管理员可能会删除服务器管理员。
  4. 强烈建议升级 Grafana 实例。 通过升级到已修补的版本来应用最新的安全补丁是缓解这两种漏洞的最有效方法。
  5. Grafana Cloud 和托管云实例已经安全。 Grafana Cloud 等托管 Grafana 服务以及主要云服务提供商提供的服务已经收到了必要的补丁。

💬 文章金句

  • 今天，我们发布了 Grafana 12.0 和所有当前受支持版本的补丁。
  • 一种高危跨站脚本 (XSS) 漏洞，允许攻击者将用户重定向到恶意网站。
  • 成功利用此漏洞可能导致会话劫持或完全账户接管。
  • 如果由于此漏洞而删除了唯一的服务器管理员账户，则 Grafana 实例变得无法管理。
  • 要完全解决 CVE-2025-4123，请升级您的 Grafana 实例。
