📌 一句话摘要

Maya 通过集中式 AWS API 网关平台，有效解决了 API 管理难题。

📝 详细摘要

本文介绍了菲律宾金融科技公司 Maya 如何利用构建在 Amazon API Gateway 上的统一 API 网关平台，克服分散式 API 管理的挑战。最初，由于缺乏标准化、安全状况维护不足以及跨多个独立网关的操作可见性较差，面临诸多挑战。该解决方案将 API 集中在专用的 AWS 账户中，利用 CloudFront、WAF、Shield 和 Lambda 授权器等服务增强安全性，并使用 Transit Gateway 实现服务集成。通过 OpenAPI 规范和 Terraform IaC 流水线来强制执行标准化。使用 CloudWatch、Dynatrace 和 Splunk 实现全面的可观测性。这种集中式方法增强了开发团队的能力，同时确保了一致性、安全性和可见性。最后，总结了该平台的未来路线图，包括与开发者门户的集成、模块化设计、自带授权器、集中式模式验证和 API 货币化。

💡 主要观点

  1. 集中 API 网关解决了碎片化挑战。 将多个独立网关整合到一个平台中，可以提高标准化程度，简化安全措施的实施，并实现统一的可观测性。
  2. 基础设施即代码（IaC）确保一致性和可审计性。 在 CI/CD 流水线中使用 Terraform 和 OpenAPI 规范可自动执行 API 部署，防止配置漂移并加强安全状况。
  3. 多层安全方法保护 API。 结合 CloudFront、WAF 和 Shield 进行边界防御，并使用 Lambda 授权器进行细粒度访问控制，从而保护 API 免受各种威胁。
  4. 集成监控提供端到端可见性。 利用 CloudWatch、Dynatrace 和 Splunk 提供对 API 性能、日志和安全事件的全面洞察，以进行主动管理。

💬 文章金句

  • 在 Maya，不同的团队构建 API 以将其服务公开给商家。随着应用程序数量的增长，管理 API 的开销也随之增加。
  • 这使应用程序团队能够专注于功能开发，同时将管理工作转移至 API 平台。
  • 为了应对这些挑战，Maya 实施了一个 API 平台，代号为 Unified API Gateway。
  • 这种方法有助于确保全面防御外部威胁，并实施严格的访问控制策略。
  • API 网关与 Lambda 授权器集成，用于身份验证和授权。该自定义函数基于身份、角色和范围等多个因素实施细粒度的访问控制。
