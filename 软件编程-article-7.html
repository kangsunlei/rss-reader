基于 DeepSeek 和多智能体的根因定位系统实践

11/20/2025, 11:15:00 PM

📌 一句话摘要

顺丰科技基于 DeepSeek 大模型和多智能体技术，构建了面向复杂场景的智能运维根因定位系统，显著提升故障诊断与修复效率。

📝 详细摘要

本文详细介绍了顺丰科技在 AIOps 与 RCA（根因定位）领域的实践，展示了如何从 DevOps 演进到 AIOps，并着重解决了 RCA 面临的多模态数据融合、因果推断复杂性等技术难点。文章核心阐述了基于“架构师 Agent+多领域专属 Agent”的多智能体协同运维体系，该体系在根因定位、策略推荐和动态阈值等场景中发挥关键作用。系统架构包括多源数据融合、多智能体诊断、运维知识库建设和 AIOps 工具落地。此外，文章还深入探讨了 DeepSeek 等大模型在多告警收敛、日志分析、根因溯源和时序数据分析中的优化与应用，并通过提示词工程、知识库集成及多智能体协同，将根因定位有效性提升了 36%以上，准确率目标达 90%。最后，文章总结了该系统在提升运维效率、保障业务连续性、优化资源配置和积累经验知识方面的落地价值与技术挑战。

💡 主要观点

  1. AIOps 与 RCA 技术正从被动响应转向主动预测，但面临多模态数据融合与因果推断等挑战 运维技术从自动化 DevOps 发展到智能 AIOps，RCA 需整合异构数据、处理复杂依赖关系，并保障数据质量与工程化落地，以实现主动预测与故障自愈。
  2. 顺丰构建了“架构师 Agent+多领域专属 Agent”的多智能体协同平台，实现复杂根因分析 通过架构师 Agent 协调与决策，结合告警分析、APM 链路等专属 Agent 的独立分析能力，有效应对多告警场景下的根因定位和策略推荐。
  3. DeepSeek 等大模型在 RCA 中优化多告警收敛、日志分析与根因溯源，显著提升定位准确率 私有化部署 DeepSeek 大模型，通过提示词工程和知识库集成，结合多智能体协同，将根因定位有效性提升超 36%，目标准确率达 90%。

💬 文章金句

  • AIOps 阶段（智能运维新范式）：基于大数据分析与机器学习，实现异常检测、根因定位和故障自愈，将运维从被动响应转向主动预测，显著降低平均修复时间（MTTR）与业务中断风险。
  • 解决 RCA 技术难点的关键：1）运维数据整合；2）多智能体协同；3）大模型推理与知识沉淀。
  • 在多智能体系统的协同机制中，采用“架构师 Agent 为核心+多领域专属 Agent 分工协作”的模式。
  • 目前使用私有化部署 Deepseek-V3 685B 大模型，优化提示词后根因定位有效性提升 36% 以上，推荐准确率提升 50% 以上。
  • 多智能体协同方案的效果显著优于单智能体方案，且大幅超越基于复杂规则的算法方案，其核心目标是将根因定位准确率提升至 90%。
