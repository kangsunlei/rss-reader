Anthropic 发布 Claude CoWork

1/20/2026, 3:41:00 PM

📌 一句话摘要

Anthropic 推出了 Claude CoWork，这是一款基于 macOS 的 AI 智能体，由可互操作的 Agent Skills 开放标准驱动，用于自主文件管理和文档处理。

📝 详细摘要

Anthropic 发布了 Claude CoWork，这是一款旨在自动化本地 macOS 目录中多步工作流的 AI 智能体。该工具通过文件夹权限模型运行，并利用 Apple 的虚拟化框架进行隔离，能够自主读取、写入和组织文件。其技术亮点在于使用子智能体协作进行并行任务执行，并以 “Agent Skills” 为基础——这是一个用于模块化 AI 能力的开放标准。该标准允许对办公格式（XLSX、PDF 等）进行专门处理，并已获得 Microsoft、OpenAI 等行业的广泛采用。尽管功能强大，但早期报告显示其资源消耗较高且在文件处理方面存在潜在风险，因此需要谨慎部署并进行备份。

💡 主要观点

  1. Claude CoWork 将 AI 从聊天界面转向自主的本地文件系统执行。 通过授予目录级权限，用户允许智能体直接在硬件上执行复杂的多步操作，如数据提取和文件整理。
  2. “Agent Skills” 开放标准促进了跨平台 AI 工具的互操作性。 模块化的 YAML/Markdown 格式允许开发者创建可跨 Claude、VS Code、GitHub Copilot 和 OpenAI Codex 运行的能力，防止供应商锁定。
  3. 子智能体协作实现了复杂技术任务的并行处理。 该架构生成多个并发的 Claude 实例来处理独立的子任务，显著减少了大规模文档处理的执行时间。
  4. 安全和资源管理是本地 AI 智能体的关键考量因素。 该工具在虚拟机中运行以实现隔离，但高 Token 消耗（标准消息的 50-100 倍）以及误删文件的风险需要严格监管。

💬 文章金句

  • Claude CoWork 在测试过程中意外消耗了 11GB 的文件。用户在授予目录访问权限之前，应执行适当的备份程序。
  • 该工具主要由 Claude Code 本身在约 1.5 周内构建完成，展示了 AI 的代码生成能力。
  • 你创建的技能不会被锁定在 Claude 中——相同的技能格式适用于所有采用该标准的 AI 平台和工具。
  • 系统采用渐进式披露，仅在相关时加载技能指令，从而管理上下文窗口的利用率。
