💡 主要观点

  1. Midjourney 成立医疗子公司，推出 60 秒全身超声扫描仪，目标 2031 年全球部署 5 万台。 该技术通过 50 万个微小元件实现快速全身 3D 成像，声称可避免 30% 死亡和 50% 医疗费用。但放射科医生指出，超声无法成像肺部、骨骼和含气肠道，并非真正「全身」，且当前分辨率远未达到医学实用标准，相关声明脱离现实。
  2. 瑞士联邦议会投票解除新核电站建设禁令，但需全民公投最终决定。 议会同时讨论了养老金融资、南方共同市场自贸协定、周日营业扩张及婚姻税改等议题。HN 社区围绕核废料管理、安全性及技术可行性展开了激烈辩论。
  3. 安全研究者发现约一万个 GitHub 仓库通过伪装 README 中的压缩包链接分发木马恶意软件。 这些仓库克隆合法项目，频繁修改 README 以绕过检测。HN 评论指出，此类攻击针对自动化代理，并讨论了密码管理、硬件密钥及开发环境隔离等安全实践。
  4. 微软新 Outlook 因基于 WebView2 导致通知响应延迟 10 秒，内存占用是经典版的 4-5 倍。 该架构问题导致点击通知后需重新唤醒浏览器层，效率远低于本地缓存的原生应用。微软已推迟强制迁移计划至 2027 年 3 月。
  5. 本地模型 Qwen 并非云端模型的降级替代，而是针对隐私、成本和控制场景的专用工具。 文章作者指出，本地模型在分布式系统编码上表现不如云模型，且量化后易产生幻觉，无法无人监督使用。HN 社区进一步讨论了不同模型的提示技巧差异。
