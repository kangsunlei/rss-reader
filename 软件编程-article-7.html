Browserbase Skills：一句话让 AI 完成浏览器自动化任务

5/1/2026, 7:30:04 AM

📌 一句话摘要

GitHub 上开源项目 Browserbase Skills 让用户通过自然语言指令即可让 AI 执行网页数据抓取、评论总结和 UI 自动化测试等浏览器任务。

📝 详细摘要

该推文介绍了一个名为 Browserbase Skills 的 GitHub 开源项目，它是一套浏览器自动化技能包。用户只需输入一句话指令，AI 就能自动完成特定网站的抓取、评论总结或 UI 自动化测试。项目内置了反爬虫绕过、验证码自动识别和本地 Cookie 同步功能，可处理复杂登录状态。安装方式非常便捷，在 Claude Code 中输入一条指令即可完成，无需额外配置。对于日常使用 Claude Code 开发且经常需要与浏览器打交道的开发者来说，这是一个实用的工具。
