B 站基础安全在 AI 溯源方向的探索实践

11/7/2025, 4:02:00 AM

📌 一句话摘要

B 站基础安全团队通过引入 AI Agent 和 MCP 协议，实现了安全告警的智能研判与自动化溯源，显著提升了安全运营效率。

📝 详细摘要

文章详细介绍了哔哩哔哩基础安全团队在 AI 赋能安全溯源方向的探索与实践。背景部分阐述了安全事件告警运营从人工到 SOAR 的演变，以及 AI 技术（大模型知识库、告警解读、研判）在提升效率方面的优势。特别强调了 Claude 的 MCP 协议作为 AI 与工具交互标准，使得 AI Agent 成为连接 AI 与真实数据的关键桥梁。技术方案部分，文章阐述了将内部 HIDS、蜜罐、CMDB、EDR、日志平台等安全产品的 API 接口转化为 AI 可调用的 MCP 工具集，构建了“安全产品告警 -> 流式处理 -> AI 研判降噪 -> 机器人推送 -> 运营响应 -> AI 辅助溯源”的流程架构。实践案例展示了 AI Agent 在蜜罐、HIDS 和 EDR 告警溯源中的具体应用，能够自动关联多源数据，定位攻击者和行为。最终，文章指出 AI 已将告警降噪率提升至 93.33%，大幅提高了运营效率，并展望了未来安全产品将开放基于 MCP 的工具集，实现更智能化的协同安全运营。

💡 主要观点

  1. AI Agent 结合 MCP 协议是实现企业安全告警自动化溯源的核心。 通过 MCP 协议将内部安全产品能力转化为 AI 可调用的工具集，赋能 AI Agent 进行多源数据关联分析和复杂业务闭环，是提升安全运营智能化的关键。
  2. 将多样化的安全产品 API 接口统一为 AI 可调用的 MCP 工具集。 文章展示了 HIDS、蜜罐、CMDB、EDR 等多种安全产品的 API 如何标准化为 AI Agent 的工具集，使其能够查询、关联内部资产和告警数据，实现更全面的溯源。
  3. AI 在 B 站实践中显著提升了安全告警降噪率和溯源效率。 实际案例表明，AI 辅助研判将人工处理的告警量大幅减少，降噪率高达 93.33%，并能自动完成事件追踪、行为分析及责任主体定位，有效提升运营效率。
  4. 构建“人机协同+自动化溯源”的告警处理架构。 通过将 AI 研判、机器人推送与人工响应相结合，实现了告警处理流程的智能化升级，既保留了人工灵活性，又充分发挥了 AI 的自动化能力。

💬 文章金句

  • 借助 AI 的能力来提升安全事件告警的处理效率，已经成为各大企业探索与实践的重要方向。
  • 基于 MCP 的 AI Agent 已经演变为连接 AI 与真实数据的关键桥梁。
  • 大模型不仅仅是对话聊天，答疑助手，而是一个具备领域全面，专业性极强的智能体，通过增加记忆能力，管理上下文能力，自动解析意图、调用合适的工具集，便可完成复杂的业务闭环。
  • AI 已经不再只是辅助告警分析的“锦上添花”，而是逐步演变为推动告警运营自动化与溯源智能化的核心引擎。
  • 安全部门能够在更短的时间、更低的成本、更高的准确性下完成告警处置与溯源，为企业抵御日益复杂的安全威胁提供坚实保障。
