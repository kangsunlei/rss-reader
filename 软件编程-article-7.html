Cloudflare Workers Node.js 兼容性改进一周年

9/25/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 通过原生实现 Node.js 标准库关键子集，显著增强了 Workers 的兼容性，促进了 npm 生态的广泛应用。

📝 详细摘要

在过去一年中，Cloudflare 显著提高了其 Workers 平台对 Node.js 的兼容性，使开发者能够无缝部署现有的 npm 模块和框架，如 Express。这项战略举措包括使用 TypeScript 和 C++ 原生实现 Node.js 标准库的关键子集（例如，`node:http`、`node:fs`、`node:crypto`、`node:process`、`node:zlib`）。这种从 polyfill 的转变显著提升了性能并减少了内存使用。本文解释了在分布式 serverless 环境中实现 Node.js 依赖底层操作系统的传统功能（如文件系统和进程管理）所面临的挑战，详细介绍了如何通过新的基于内存的虚拟文件系统支持 `node:fs`，以及网络模块（`node:http`、`node:net`、`node:tls`）如何利用现有的 Workers API。文章还重点介绍了用于加密功能的 `ncrypto` 项目，提供了通过兼容性标志启用这些功能的明确说明，并概述了在保持 Workers 向后兼容性的同时，处理 Node.js 已停止维护 API 的策略。

💡 主要观点

  1. Cloudflare Workers 现在原生支持 Node.js 标准库 API 的关键子集。 与之前基于 polyfill 的方法相比，这种使用 TypeScript 和 C++ 的原生实现显著提高了性能并减少了内存使用，从而实现了流行的 npm 模块的无缝集成。
  2. Node.js 的传统文件系统和网络概念已应用于 serverless Workers 环境。 `node:fs` 模块通过创新的基于内存的虚拟文件系统提供支持，解决了分布式系统中持久存储的挑战。 同样，`node:http`、`node:net` 和 `node:tls` 利用现有的 Workers API（如 Sockets 和 Fetch），使 Express 等框架能够在 serverless 模型中运行。
  3. 开发人员可以通过具有精细控制的 `nodejs_compat` 标志启用 Node.js 兼容性功能。 `nodejs_compat` 标志简化了启用过程，它是一个总括性的标志，并提供单独功能控制选项，以及管理 Node.js 生命周期结束 API 的能力，从而确保向后兼容性。
