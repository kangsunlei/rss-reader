Cloudflare 雷达推出新的区域互联网流量和证书透明度分析功能

9/26/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 雷达推出新的区域互联网流量分析功能和全面的证书透明度数据，增强对互联网健康和安全性的深入了解。

📝 详细摘要

Cloudflare 雷达引入了两项重大增强功能：区域互联网流量分析和详细的证书透明度 (CT) 数据。区域流量分析提供了互联网趋势的本地化视图，支持在国家/地区内的更细粒度级别进行分析，包括字节、请求、设备类型和机器人/人类流量份额等指标，并利用地理名称数据进行精确的地理信息划分。这允许通过雷达界面、数据探索器和 API 对特定区域和自治系统内的流量模式进行精细探索。新的 CT 功能是 Merkle Town 的演进，提供了对 TLS 证书颁发的深入分析，涵盖了数量、特征（如公钥、签名算法、验证级别和持续时间）、证书颁发机构 (CA) 所有者的颁发趋势（例如，Let's Encrypt 的重要作用）和 CT 日志分布。这两项功能对于增强互联网信任、安全监控和研究至关重要。所有底层数据都可通过雷达 API 访问，这加强了 Cloudflare 对全面互联网可见性的承诺。

💡 主要观点

  1. Cloudflare 雷达现在提供精细的区域互联网流量分析。 这允许用户分析国家/地区内的更细粒度流量趋势，包括设备和机器人/人类流量比例，从而更本地化地了解互联网使用模式和区域事件的影响。
  2. 增强的证书透明度 (CT) 数据已集成到 Cloudflare 雷达中。 新的 CT 仪表板提供了对 TLS 证书颁发、特征以及跨 CA 和日志的分布的深入分析，这对于互联网信任、安全监控和研究至关重要。
  3. 这两项功能都可通过 Cloudflare 雷达的用户界面 (UI)、数据探索器和 API 访问。 这确保了各种技术受众的广泛效用，从而可以进行定制分析、集成到其他系统中，并为开发人员和研究人员提供全面的数据访问。

💬 文章金句

  • 区域流量分析让用户能够以更本地化的视角查看雷达上显示的流量趋势。
  • 借助这项新功能，您将能够以更本地的级别查看流量趋势，包括字节和请求，以及桌面/移动设备和机器人/人类流量份额的细分。
  • 事实证明，证书透明度 (CT) 在其他方面也具有非常宝贵的价值，因为它提供了互联网上使用的所有网站证书的公开访问列表。
  • Cloudflare 雷达上的证书透明度是 Merkle Town 的下一个演进，它提供了与雷达上已有的安全和域信息的集成，以及更多交互方式来探索和分析 CT 数据。
  • 目前，大多数 (92%) 已颁发证书的有效期在 47 到 100 天之间。更短的证书有效期通过限制证书泄露时的暴露来提高安全性。
