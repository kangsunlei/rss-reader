Grafana 高危安全更新：图像渲染插件与合成监控代理中 CVE-2025-5959、CVE-2025-6554、CVE-2025-6191 和 CVE-2025-6192 漏洞修复

7/2/2025, 2:36:55 PM

📌 一句话摘要

Grafana 发布图像渲染插件 (3.12.9) 和合成监控代理 (0.38.3) 的关键安全更新，修复四个 Chromium 高危漏洞（可导致远程代码执行）。

📝 详细摘要

Grafana Labs 发布紧急安全更新，修复 Chromium 中四个高危漏洞（CVE-2025-5959、CVE-2025-6554、CVE-2025-6191 和 CVE-2025-6192），这些漏洞影响 Grafana Image Renderer 插件（需升级至 3.12.9）和 Synthetic Monitoring Agent（需升级至 0.38.3），攻击者可利用这些漏洞实施远程代码执行。本公告提供了详细升级指南（含容器部署命令），并确认 Grafana Cloud（包括 Azure 托管的 Grafana 服务）已完成安全更新。公告同时披露了完整的漏洞响应时间线，并特别致谢漏洞奖励计划贡献者 Alex Chapman。建议使用受影响版本的用户立即执行升级操作。

💡 主要观点

  1. Chromium 高危漏洞影响 Grafana 核心组件 Chromium 中的四个高危漏洞（CVE-2025-5959、CVE-2025-6554、CVE-2025-6191、CVE-2025-6192）可能导致 Grafana Image Renderer 插件和 Synthetic Monitoring Agent 被远程代码执行，根据 CVSS 3.1 漏洞评分体系评定为最高危等级。
  2. 受影响版本需紧急升级 用户需立即升级至 Image Renderer 3.12.9 和 Synthetic Monitoring Agent 0.38.3 版本以消除安全风险，公告包含详细的升级操作指引。
  3. 漏洞奖励计划助力安全研究 安全研究员 Alex Chapman 通过 Grafana 漏洞奖励计划报告漏洞利用链，体现了协调披露机制的价值。
  4. 云端服务已完成安全加固 Grafana Cloud（含 Azure 托管的 Grafana 服务）已完成安全更新，云服务提供商确认当前服务已处于安全状态。

💬 文章金句

  • 建议使用 Grafana Image Renderer 插件或本地部署 Synthetic Monitoring Agent 的用户立即升级系统。
  • 根据 CVSS 3.1 漏洞评分体系评估，这些漏洞对 Grafana 运行环境构成最高危威胁。
  • 若您当前运行的是 Grafana Image Renderer 版本低于 3.12.9 或 Synthetic Monitoring Agent 版本低于 0.38.3，请立即执行升级操作。
  • 特别致谢 Alex Chapman 通过我方漏洞奖励计划报告 CVE-2025-959 的原始攻击向量。
