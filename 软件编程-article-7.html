Octogent：解决 Claude Code 多会话协同混乱的开源工具

5/2/2026, 10:00:07 AM

📌 一句话摘要

Octogent 是一个开源项目，通过为每个任务创建独立上下文空间，让 Claude Code 能派生并协调多个子 Agent 并行工作，解决多会话管理混乱问题。

📝 详细摘要

该推文介绍了一个名为 Octogent 的开源工具，专门解决使用 Claude Code 开发时多个终端窗口管理混乱的问题。Octogent 的核心功能包括：为每个任务创建独立的上下文空间，使用 Markdown 文件管理任务列表和笔记，支持一个 Claude Code 派生并协调多个子 Agent 并行工作。其亮点在于 Agent 之间可以互相通信，汇报进度和传递阻塞信息；每个任务的上下文保存在文件中，不会因对话丢失而中断；同时提供本地 Web 界面，直观展示每个 Agent 的运行状态。对于经常使用 Claude Code 处理多个复杂任务的开发者来说，这是一个实用的效率工具。
