Qwen-Audio-3.0 系列语音模型正式上线千问 AI 平台

8/17/2026, 7:56:00 AM

📌 一句话摘要

阿里巴巴自研的 Qwen-Audio-3.0 系列语音模型（ASR/TTS/Realtime）在千问 AI 平台上线，三项赛道均获全球第一，开发者可通过 API 或 Token Plan 订阅使用。

📝 详细摘要

阿里云发布 Qwen-Audio-3.0 系列语音模型，包含语音识别（ASR）、语音合成（TTS）和实时交互（Realtime）三个子模型。该系列在 Artificial Analysis 7 月语音排行榜上囊括三项全球第一，支持复杂语境识别、多语种多方言合成、端到端对话及工具调用。模型已应用于千问 App、千问办公、Qoder 等产品。文章同时推广千问 AI 平台的 Token Plan 订阅服务，给出个人版与团队版的定价与折扣力度。

💡 主要观点

  1. Qwen-Audio-3.0 系列在三项语音赛道均获全球第一。 在 Artificial Analysis 7 月语音排行榜上，ASR、RealTime、TTS 三个赛道均排名第一，是该领域首个实现大满贯的模型。
  2. 三个子模型分别覆盖语音识别、合成与实时对话。 ASR 支持复杂语境与专业领域识别；TTS 支持多语种多方言及情绪语气控制；Realtime 实现端到端理解、边听边说与工具调用。
  3. 模型已在阿里巴巴自有产品中应用。 已部署于千问 App、千问办公、Qoder 等产品，形成实际生态验证。
  4. 平台提供 API 与 Token Plan 两种接入方式。 开发者可通过 API 调用模型能力，或订阅 Token Plan 获取额度，个人版 Lite/Standard/Pro 分别对应不同用量与价格。

💬 文章金句

  • Qwen-Audio-3.0-ASR 将语音转为文字，支持复杂语境和专业领域识别
  • Qwen-Audio-3.0-Realtime 支持端到端语音理解与对话，可边听边说、随时打断追问，并支持工具调用
  • 在全球权威 AI 评测平台 Artificial Analysis 今年 7 月的语音排行榜上，该模型斩获语音识别（ASR）、实时交互（RealTime）和语音合成（TTS）三个赛道的全球第一，拿下'大满贯'
