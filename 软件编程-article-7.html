sweety-handdraw-video：AI 一键生成手绘配音视频

11/8/2026, 2:30:10 PM

📌 一句话摘要

sweety-handdraw-video 是一个 AI 工具，能将文字内容自动生成边画边讲的手绘配音视频，支持 21 种画风，内置 Claude Code 和 Codex 调用。

📝 详细摘要

sweety-handdraw-video 是一个 AI 技能工具，可将主题或文章内容转化为边画边讲的有声视频。Agent 负责编写口播、设计分镜、生成插画，本地工具完成线条描绘、上色，汉字按标准笔顺生成。支持 21 种画风和 6 款手臂选择。生成流程包括先生成口播，再按时长分配画面时长。成片无需使用图生视频模型，保留素材、声音、时间戳，可灵活修改字幕。支持 Claude Code 和 Codex 调用。示例作品《那条死于愤怒的蛇》49 秒，展示从情节到情绪放大的完整流程。

💡 主要观点

  1. 全自动化手绘视频生成 从内容到成片全流程自动化，降低配音视频制作难度。
  2. 本地化工具链实现 所有绘画操作在本地完成，保障隐私安全，避免依赖云端视频生成模型。
  3. 可编辑的中间产物 保留声音、素材、时间戳，修改字幕无需重新生成图像，提高协作效率。

💬 文章金句

  • 先生成口播，再按每段话的时长算出每幅画能画几秒、最多几笔，画面跟着声音走。
  • 成片不用图生视频模型，素材、声音、时间戳都留着，改一句字幕不用重新生图，这点我很喜欢。
  • 作者的样片《那条死于愤怒的蛇》49 秒，从蛇和锯子的冲突讲到愤怒怎么放大伤害。
