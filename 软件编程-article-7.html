Java 近期新闻：Jakarta EE 11 Web Profile、GlassFish、TornadoVM、Micronaut

4/19/2025, 2:16:00 AM

📌 一句话摘要

Java 生态近期迎来 Jakarta EE 11 Web Profile 发布、GlassFish、TornadoVM 和 Micronaut 等重要更新，提升开发效率和应用性能。

📝 详细摘要

本文汇总了 Java 生态系统近期的重要更新。Jakarta EE 11 Web Profile 正式发布，GlassFish 8.0.0 发布了包含 Jakarta EE 11 新功能的里程碑版本，为企业级 Java 开发提供更强大的支持。TornadoVM 1.1.0 版本增强了对混合精度计算的支持，并引入了新的设备内存区域映射功能，提升 Java 在异构计算领域的应用潜力。Micronaut Framework 4.8.0 改进了 Micronaut SourceGen 模块，并激活了依赖注入跟踪能力，帮助开发者更好地理解和调试 Micronaut 应用。Quarkus 和 JHipster 也发布了包含错误修复和依赖升级的维护版本，进一步提升了 Java 开发的稳定性和效率。

💡 主要观点

  1. Jakarta EE 11 Web Profile 的发布是重要里程碑，简化企业级应用开发 Jakarta EE 11 Web Profile 的发布，标志着 Jakarta EE 规范的进一步完善， Jakarta EE 11 包含了 Contexts and Dependency Injection (CDI 4.1)、JSON Processing (JSON-P 2.1) 和 RESTful Web Services (JAX-RS 3.1) 等关键规范的更新，为企业级 Java 开发提供了更强大的支持，并简化了开发流程。
  2. TornadoVM 1.1.0 增强了异构计算能力，提升 Java 应用性能 TornadoVM 1.1.0 通过支持矩阵操作的混合精度计算和新的设备内存区域映射功能，使得 Java 应用能够更好地利用 GPU 等硬件加速器，从而提升在异构计算领域的应用潜力，加速 AI 和大数据处理。
  3. Micronaut Framework 4.8.0 提升了开发体验，方便问题追踪 Micronaut Framework 4.8.0 通过改进 SourceGen 模块和激活依赖注入跟踪能力，帮助开发者更好地理解和调试 Micronaut 应用， 从而能够快速定位和解决依赖注入相关的问题，提升开发效率。
  4. Quarkus 和 JHipster 的更新，增强了 Java 开发的稳定性和安全性 Quarkus 通过修复解析器错误和 TLS 配置问题，增强了 GraphQL 和 TLS 功能的稳定性和可靠性。JHipster 则通过依赖升级和安全漏洞修复，提升了应用的整体安全性和性能。

💬 文章金句

  • Jakarta EE 11 Web Profile 已发布！
  • Micronaut Framework 4.8.0，包含 Micronaut Core 4.8.9，对 Micronaut SourceGen 模块进行了改进
  • TornadoVM 1.1.0 发布，包含了错误修复和一些改进，例如：支持矩阵操作的混合精度 FP16 到 FP32 的计算
  • 修复了使用 Spring Boot 和 Hazelcast 登录 JHipster 应用时抛出的 ClassCastException
