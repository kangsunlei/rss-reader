Apache Paimon C++ ：从阿里数据湖走向开源社区

9/9/2026, 10:18:00 AM

📌 一句话摘要

Apache Paimon C++ 0.3.0 正式发布，源自阿里内部数据湖需求，提供基于 Arrow 的原生 C++ SDK，兼容多种引擎并实现显著性能提升，开启社区化发展。

📝 详细摘要

Apache Paimon C++ v0.3.0 是该项目在 Apache 基金会下的首个正式版本，起源于阿里内部数据湖对高效、无 JVM 依赖的表格存储需求。项目在两年生产验证后，已在阿里数 EB 数据上稳定运行，并在 2025 年开源后吸引蚂蚁、字节、云器等团队共建。Paimon C++ 通过 Arrow C Data Interface 实现列式 Batch 交换，提供插件化的 FileFormat、FileSystem、MemoryPool、Executor 等可定制组件，既保留各引擎已有的性能优化，又提供完整的 Paimon 表语义（Snapshot、Manifest、Merge‑on‑Read、Deletion Vector 等）兼容 Java 实现。文章还展示了多项性能优化，如分层 Spill Merge、并行预取、异步批转换和 Count 短路，并给出 Native Spark、StarRocks 等真实工作负载的 1.5‑3.7 倍加速数据。随后介绍了对 AI 与多模态检索的支持，统一管理结构化、文本、向量和二进制数据，推动“一份数据入湖，全部数据可检索”。最后呼吁社区共同推进功能演进与 AI 场景落地。

💡 主要观点

  1. Apache Paimon C++ 0.3.0 正式发布，标志着该项目从阿里内部走向 Apache 社区。 该版本是首个在 Apache 基金会下的 C++ 实现，源自阿里数据湖对高效、无 JVM 依赖的表格存储需求，已在生产环境支撑数 EB 数据。
  2. 设计为原生 C++ SDK，基于 Arrow 批式数据交换并支持深度插件化。 通过 Arrow C Data Interface 实现列式 Batch 传输，插件化的 FileFormat、FileSystem、MemoryPool、Executor 等组件让不同引擎能够复用已有优化，同时保持灵活可定制。
  3. 完整实现 Paimon 表语义并保持与 Java 实现的兼容。 SDK 支持 Snapshot、Manifest、Merge‑on‑Read、Deletion Vector、Compaction 等关键特性，确保 C++ 引擎能够在不丢失功能的前提下读取和写入 Paimon 表。
  4. 多项系统级性能优化带来显著加速。 分层 Spill Merge、并行文件预取、异步 Batch 转换、Count 短路等技术在 Native Spark、StarRocks 等真实工作负载中实现 1.5‑3.7 倍查询提速。
  5. 扩展至 AI 与多模态检索，统一管理结构化、文本、向量和二进制数据。 在 Data Evolution 表模式下，Paimon C++ 支持全局 Row ID、向量相似度、全文检索等能力，使“一份数据入湖，全部数据可检索”成为可能。
