保护免受 'React2Shell' 攻击的资源 - Vercel

12/5/2025, 1:00:00 PM

📌 一句话摘要

Vercel 详细说明了关键的 'React2Shell' (CVE-2025-55182) 漏洞，建议立即更新 Next.js 和 React 服务组件。

📝 详细摘要

此 Vercel 安全公告解决了影响 Next.js 应用程序（15.0.0 到 16.0.6 版本）和使用 React 服务组件的其他框架的关键 'React2Shell' 漏洞 (CVE-2025-55182)。它确认了公开的概念验证漏洞利用和活跃的威胁参与者探测。Vercel 已经实施了多层防御，包括 Web 应用防火墙 (WAF) 规则和阻止易受攻击的 Next.js 版本的新部署。文章强烈建议立即升级到已修补的 Next.js 版本，这是唯一的完整修复方法。WAF 仅提供部分保护。它为 Next.js 提供了详细的补丁表，为其他框架提供了指导，并回答了有关漏洞检测、利用迹象、可用保护措施和安全测试实践的常见问题。Vercel 还强调了与 HackerOne 合作进行负责任的披露，提供丰厚的漏洞赏金。

💡 主要观点

  1. 立即修补是 'React2Shell' 漏洞的唯一完整修复方法。 虽然 Vercel 的 WAF 提供了关键的防御层，但文章明确指出，升级到已修补的 Next.js 或 React 服务组件版本是完全修复 CVE 漏洞的唯一方法。
  2. Vercel 已经实施了强大的、多层纵深防御方法来保护用户。 这包括主动的 WAF 规则，与主要的 CDN/WAF 提供商共享缓解措施，以及阻止易受攻击的 Next.js 应用程序的新部署，体现了全面的平台级安全防护。
  3. 提供了清晰可操作的跨框架漏洞检测和缓解步骤。 文章提供了用于检查 Next.js 版本的具体说明、详细的补丁表、针对其他 React 服务组件框架的指南，并通过常见问题解答解决了常见的用户问题。

💬 文章金句

  • 强烈建议升级到已修补的版本，这是唯一完整的修复方法。
  • 所有通过 Next.js 或任何其他框架使用 React 服务组件的用户都应立即更新。
  • Vercel 采取了纵深防御方法，以确保客户和更广泛的社区受到保护。
  • WAF 规则是一层防御，但永远无法保证 100% 的覆盖率。
  • 我们建议不要在生产环境中使用公开可用的漏洞利用。
