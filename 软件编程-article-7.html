📝 详细摘要

本期 JavaScript 中文周刊精选了**本周**多篇技术文章和工具更新，**快速概览了**前端和 Node.js 生态的**最新动态**。热点部分深度观察了 2025 年 React 发展和社区讨论，介绍了 Rust 构建的极速 Linter 工具 Oxlint v1.0 的发布及其性能优势，以及 pnpm v10.12 实验性全局虚拟存储如何优化包管理效率。文章和视频部分探讨了代码检查、早期 JS 代码回顾、Node.js 原生热模块重载思路、JSON 方法局限性、ESLint 插件、JS 避坑点及 Angular 20 更新。工具部分展示了 npmgraph、Jest 30、Orange ORM 等实用库和工具。此外，还包含了 Safari 新特性、安全漏洞、Node.js EOL 提醒、TypeScript Go 重写进展等生态圈动态。周刊内容丰富，覆盖面广，是了解 JS 生态一周进展的良好资源。

💡 主要观点

  1. Mark Erikson 深入分析了 2025 年 React 的发展现状和社区讨论焦点。 作为 Redux 维护者，他的视角有助于开发者理解 React 新特性背后的原因，澄清误解，把握未来方向，具有重要的参考价值。
  2. 基于 Rust 的 Oxlint v1.0 正式发布，提供了远超 ESLint 的代码检查速度。 极致的性能提升可以显著加快大型项目的代码检查流程，提高开发效率，且兼容大量 ESLint 规则，易于迁移采用。
  3. pnpm v10.12 引入实验性全局虚拟存储，进一步优化依赖管理效率。 通过软链接共享依赖包，减少重复安装和存储空间占用，特别适用于多项目开发环境，提升工作流效率。
  4. npmgraph 工具提供了直观的 npm 依赖关系可视化能力。 用户可以轻松查看包之间的依赖结构，帮助理解项目复杂度、识别潜在冲突或冗余依赖，辅助项目维护。
  5. TypeScript 编译器正在用 Go 重写，旨在提升编译速度和利用并发优势。 这一底层优化将显著提升 TypeScript 项目的构建和开发体验，是值得关注的生态重大进展。

  • React 依然是 JavaScript 生态里最重要的依赖之一，但最近各种新特性和创新也引发了不少关于未来方向的讨论。

  • pnpm 一直以速度和高效著称，远超 npm。这次 v10.12 更进一步，带来了"全局虚拟存储"...
