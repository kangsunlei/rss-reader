TypeScript 换芯成功！

12/8/2025, 8:05:00 AM

📌 一句话摘要

TypeScript 官方发布了 Go 语言重构的原生预览版编译器和语言服务，大幅提升了编译和类型检查速度，并优化了编辑器体验。

📝 详细摘要

文章介绍了 TypeScript 官方近期发布的重磅更新：将编译器和语言服务完全使用 Go 语言重构。这意味着 TypeScript 将从基于 JavaScript 运行的编译器升级为原生编译器，显著提升了编译和类型检查的速度，官方数据显示可达 8-10 倍。新版本支持“冷启动 + 全量构建”的快速编译，对大型项目尤为有利。文章还提供了安装和体验原生预览版的简单教程，并指出 VS Code 扩展也同步支持。此外，原生版语言服务完善了自动补全、跳转定义等编辑器功能，使其趋于成熟。作者建议对于追求效率且项目体量不小的开发者，可以立即尝试升级，并提供了不同项目类型（中小项目、大型项目、特殊构建需求项目）的升级建议及注意事项。

💡 主要观点

  1. TypeScript 编译器和语言服务已使用 Go 语言重构为原生版本。 这是一次从“脚本语言编译器”到“原生编译器”的跨代升级，不再依赖 JS 运行时，显著提升了执行效率和体验。
  2. 原生版 TypeScript 大幅提升了编译和类型检查速度，相比旧版快 8-10 倍。 即便在“冷启动 + 全量构建”模式下，也能实现显著加速，尤其对大型项目而言，开发效率将有质的飞跃。
  3. 原生版 TypeScript 语言服务完善了编辑器内功能，已足够日常开发使用。 编辑器体验如自动补全、跳转定义等功能已得到支持，解决了此前原生版本功能不完善的问题，提高了开发者的使用意愿。
  4. 建议追求效率且项目非“年代久远”的开发者积极尝试原生版本。 对于中小或大型项目，原生版在编译速度和编辑器体验上均有显著优势；但需注意对老环境和部分旧 API 的兼容性问题。

💬 文章金句

  • 现在原生预览版已经可以拿来试用了。
  • 官方给出的数据非常直观 —— 同样的项目，用新版命令行编译器跑起来比旧版快 8-10 倍。
  • 团队坦言，这些曾经是不少人犹豫要不要尝试原生版本的原因 —— '编辑器功能不完善 = 体验不完整'。现在，这些缺口已经补齐，原生版对日常开发来说已经足够成熟了。
  • 总的来说，只要你的项目不是那种'年代久远、层层兼容、动一下就会塌'的老环境，现在试试原生版本真的很划算。
