Agoda 在 CI/CD 流程中使用 ChatGPT 优化 SQL 存储过程

10/3/2025, 1:40:00 PM

📌 一句话摘要

Agoda 成功将 ChatGPT 集成到 CI/CD 流程中，以自动化 SQL 存储过程的优化，从而显著减少人工工作量并加快合并请求的审批速度。

📝 详细摘要

Agoda 率先在其 CI/CD 流程中使用 ChatGPT 来优化 SQL 存储过程。此举旨在减轻数据库开发者的负担，并加快合并请求 (MR) 的审批时间。低效的 SQL 代码通常源于低效连接、过度查询嵌套或缺少索引等问题，这些问题会严重影响性能、成本和可扩展性。此前，数据库开发者需要花费大量时间分析与 SP 变更相关的性能测试失败。现在，通过引入自动化步骤，系统将 SQL 代码、表结构、索引和性能报告提供给 ChatGPT，然后 ChatGPT 会建议优化的 SP 版本和索引修改。这种 LLM 辅助方法可以对性能测试进行并列比较，使开发人员能够做出更明智的决策。该举措已成功减少人工审查时间，并提高了开发工作流程效率。Agoda 目前正在努力进行进一步的增强，包括对 LLM 修改后的 SP 进行自动逻辑验证，使优化功能可以在 CI/CD 流程之外访问，优化 GPT prompt，并将该方法应用于高 CPU 生产 SP，以降低基础设施成本。

💡 主要观点

  1. Agoda 将 ChatGPT 集成到 CI/CD 中，以自动化 SQL 存储过程的优化。 这种创新方法利用 LLM 分析 SQL 代码、表模式和性能报告，生成优化的存储过程和索引建议，从而简化开发工作流程。
  2. LLM 辅助流程显著减少了人工工作量，并加快了 MR 审批速度。 通过自动分析性能不佳的 SP，Agoda 发现此前花费在这些任务上的 320 人天大幅减少，从而提高了开发人员的效率，并将 MR 审批时间从 4.1 小时缩短。
  3. 未来的工作重点是扩大可访问性，并改进 LLM 建议。 Agoda 计划将优化工具扩展到 CI/CD 之外，并改进 prompt 工程以优化 GPT 的建议。此外，他们还将应用此方法来优化高 CPU 生产 SP，从而降低基础设施成本。

💬 文章金句

  • 为了减少人工工作量并加速 SP 调整，我们将 GPT 集成到我们的开发工作流程中。我们的目标是减少人工审查时间，加快 MR 审批速度，并让开发人员可以使用自助服务工具进行性能调整。
  • 该团队创建了一个自动化步骤，该步骤通过将存储过程的 SQL 代码、表结构和索引以及性能测试报告提供给 LLM，从而使用 ChatGPT 生成 SP 优化建议。
  • 尽管在利用 ChatGPT 方面取得了初步成功，但开发人员仍在努力改进以解决一些限制。其中一项改进是自动逻辑验证，旨在确保即使 LLM 建议了大量更改，经过大量修改的 SP 也能保持相同的逻辑。
