Vercel 确认 #react2shell POC 可用，并已采取应对措施

12/4/2025, 10:01:33 PM

📌 一句话摘要

Vercel CEO 确认 #react2shell 概念验证存在，其 Web Application Firewall 正在阻止利用，并敦促用户升级 React 和框架。

📝 详细摘要

Vercel CEO Guillermo Rauch 确认 #react2shell 概念验证正在传播。他保证 Vercel 的 Web Application Firewall (WAF) 正在有效阻止该漏洞的特定变体。然而，他也指出恶意行为者正试图利用此漏洞，因此开发者应优先升级 React 及相关框架，以降低风险。
