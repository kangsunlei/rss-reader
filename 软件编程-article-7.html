Tutti VM：让多个 AI Agent 实时共享工作区的协作工具

8/25/2026, 10:00:00 AM

📌 一句话摘要

Tutti VM 将人与 AI Agent（如 Claude Code、Codex）拉入云端持久化房间，实时共享项目文件、代码、环境及服务状态，支持跨 Agent 额度借用，无需部署即可协作。

📝 详细摘要

GitHubDaily 介绍了一款名为 Tutti VM 的工具，解决多个 AI Agent（Claude Code、Codex）协作时的额度冲突和环境不同步问题。Tutti VM 把人和 Agent 放进一个云端房间，房间内是一个持久化共享工作区，始终保持最新状态。房间中的项目文件、代码、环境依赖和运行的服务对所有成员实时可见；例如两人同时修改同一网页，双方都能即时看到变化且无代码冲突。无需额外部署，房间内运行的网站服务可直接在浏览器中访问查看。当个人 Agent 额度用尽时，可借用房间成员共享的 Agent 额度继续工作，且使用的是 Agent 能力而非直接账号，登录状态仍停留在各自本机，避免账号封禁风险。工具提供开箱即用安装包，适合团队或朋友多人协作使用 AI 编程助手。
