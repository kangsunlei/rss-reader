React 内联 Markdown 编辑器：所见即所编，语法标记智能显示

7/18/2026, 11:25:00 AM

📌 一句话摘要

一个基于 CodeMirror 6 的 React Markdown 编辑器，编辑时文档显示为渲染效果，语法标记仅出现在光标所在行。

📝 详细摘要

该推文介绍了一个 React Markdown 编辑器组件，基于 CodeMirror 6 实现，核心创新在于编辑器将文档显示为接近渲染后的样式（所见即所编），同时语法标记（如粗体、标题等）仅在当前光标所在行显示，其余行隐藏标记，提供沉浸式编辑体验。
