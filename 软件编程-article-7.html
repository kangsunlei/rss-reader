React Router 和 Remix 漏洞防护 - Vercel

4/26/2025, 1:00:00 PM

📌 一句话摘要

Vercel 修复 React Router 高危漏洞，保护用户免受缓存投毒和 XSS 攻击。

📝 详细摘要

安全研究人员发现了 React Router 中的两个高危漏洞，CVE 编号分别为 CVE-2025-43864 和 CVE-2025-43865，这些漏洞可能导致缓存投毒和存储型跨站脚本 (XSS) 攻击。 Vercel 积极分析了这些漏洞对其平台的影响，并部署了 Vercel 防火墙的缓解措施，有效保护了其客户。该漏洞影响了使用 `Cache-Control` 标头的 v7.0.0 到 v7.5.1 之间的 React Router 版本。Vercel 的缓解措施包括剥离 `X-React-Router-Spa-Mode` 和 `X-React-Router-Prerender-Data` 标头。Vercel 还清除了 CDN 缓存，并建议用户更新到 React Router 7.5.2 并清除 Cloudflare 等其他缓存。该漏洞由 zhero 披露。

💡 主要观点

  1. React Router 存在高危漏洞可导致缓存投毒和 XSS CVE-2025-43864 和 CVE-2025-43865 允许攻击者通过修改请求头来修改响应，从而导致缓存投毒。 这些漏洞还会导致服务拒绝 (DoS) 和存储型跨站脚本 (XSS) 等问题。
  2. Vercel 通过防火墙缓解措施主动保护客户 Vercel 通过从 Vercel 防火墙中的请求中删除 `X-React-Router-Spa-Mode` 和 `X-React-Router-Prerender-Data` 标头来防御攻击。
  3. 建议更新 React Router 和清除其他缓存 建议更新到 React Router 7.5.2 并重新部署，并清除包括 Cloudflare 在内的其他缓存。

💬 文章金句

  • CVE-2025-43864 and CVE-2025-43865 enable an external party to modify the response using certain request headers， which can lead to cache poisoning Denial of Service (DoS).
  • Vercel customers using React Router between v7.0.0 and v7.5.1 were impacted before our Firewall mitigation
  • We have deployed mitigations for attacks by stripping the `X-React-Router-Spa-Mode` and `X-React-Router-Prerender-Data` headers from the request in the Vercel Firewall.
