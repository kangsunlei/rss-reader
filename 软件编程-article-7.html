Anthropic 发布 Claude Code Security 预览版

2/21/2026, 12:07:34 AM

📌 一句话摘要

Anthropic 推出 AI 代码安全扫描工具，在内部测试中发现 500 多个潜伏多年的漏洞。

📝 详细摘要

Anthropic 推出了 Claude Code Security 的研究预览版。该功能利用 AI 扫描代码库以识别安全漏洞，并为人工审核提供针对性的软件补丁建议。在 Anthropic 的内部项目中，该工具成功识别了 500 多个此前未被发现的安全问题，其中部分代码已存在数十年。这标志着 AI 在自动化安全审计和遗留代码维护方面迈出了重要一步。
