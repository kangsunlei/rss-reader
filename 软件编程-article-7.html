关于大模型与软件开发的一些思考

8/28/2025, 2:10:00 PM

📌 一句话摘要

Martin Fowler 分享了关于大型语言模型（LLMs）对软件开发影响的见解，批评了相关使用情况调查，指出了人工智能经济泡沫现象，并着重强调了安全风险，尤其是在智能代理浏览器扩展应用中。

📝 详细摘要

Martin Fowler 对大型语言模型（LLMs）在软件开发领域的现状和未来影响进行了一系列反思。他质疑了早期关于 LLM 影响评估调查的有效性，认为这些调查通常未能充分考虑除基本代码自动完成之外的各种使用模式，可能导致误导性结论。虽然他对编程的长期未来表示不确定，但他提倡开发者积极尝试 LLMs，并密切观察有效的工作流程。Fowler 坚定地认为，当前的人工智能领域存在经济泡沫，注定会破裂，但同时也将产生具有持久价值的成果。他以一种颇具争议的视角看待 LLM 的生成偏差问题，认为它们是一种基本“特性”而非缺陷，并建议采用重复查询等策略来管理其不确定性。Fowler 还思考了 LLMs 在软件工程中引入不确定性的作用，使其与其他工程学科更加相似。最后，他着重强调了由于 LLMs 导致软件系统受攻击面显著增加所带来的严重安全问题，特别是在智能代理浏览器扩展的背景下，他赞同 Simon Willison 的观点，即此类代理本质上存在缺陷且不安全。

💡 主要观点

  1. 当前关于 LLM 在软件开发中使用情况的调查通常存在缺陷且具有误导性。 许多调查忽略了简单代码自动完成之外的各种 LLM 工作流程，导致对开发者如何真正利用 LLM 价值的理解不够深入，可能误导未来的应用策略。
  2. 大模型时代编程的未来充满不确定性，需要不断试验。 对编程领域的未来发展做出明确预测为时尚早。相反，开发者应该积极尝试 LLMs 并分享经验，以共同探索其最佳应用方式。
  3. 当前的人工智能市场是一个经济泡沫，与过去的技术繁荣时期类似。 虽然预计人工智能经济泡沫将会破裂，导致许多公司倒闭，但它也将创造巨大的持久价值，就像互联网泡沫时代一样，一些公司在普遍崩溃中依然蓬勃发展。
  4. LLM 的生成偏差是一种基本特性，而非错误，需要采取适应性使用策略。 鉴于 LLMs 固有的不确定性（即每次运行结果可能不同），用户应多次查询，尤其是在需要精确答案时，并比较结果，以便更好地利用其可变性并提高可靠性。
  5. LLMs 显著增加了软件系统的受攻击面，特别是智能代理浏览器。 “致命三要素”（私有数据访问、不受信任的内容、数据渗漏）使得智能代理浏览器扩展存在致命缺陷，通过复杂且隐蔽的指令造成严重的安全漏洞。

💬 文章金句

  • 我担心的是，忽略使用 LLM 的不同工作流程的调查，会产生将人们引入歧途的数据。
  • 而且，我认为任何说自己知道未来会怎样的人都是在瞎扯。我们仍在摸索如何使用 LLMs，并且在对如何高效利用它们有一个清晰的认识之前，还需要一段时间，特别是当它们取得显著改进时。
  • 所有重大的技术进步都伴随着经济泡沫，从运河、铁路到互联网，无一例外。我们几乎可以 100% 确定这个泡沫会破裂，导致大量投资付诸东流。
  • 我的前同事 Rebecca Parsons 长期以来一直认为，生成偏差不是 LLM 的 Bug，而是一种特性。事实上，它们就是 *这个* 特性。LLM 所做的只是生成内容，只不过我们发现其中一些是有用的。
  • Willison 认为，智能代理浏览器扩展的 *整个概念* 存在根本性缺陷，无法安全构建。
