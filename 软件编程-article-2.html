Rainman Translate Book：基于 Claude Code 的整本书籍翻译工具

3/21/2026, 1:30:15 PM

📌 一句话摘要

开源工具 Rainman Translate Book 支持 PDF/DOCX/EPUB 格式整本书籍翻译，通过 8 个并行子智能体解决长文本截断问题。

📝 详细摘要

该推文推荐了一个名为 Rainman Translate Book 的开源翻译工具，专门解决整本书籍翻译的痛点。工具基于 Claude Code 构建，使用 Calibre 和 Pandoc 处理格式转换，核心机制是将书籍拆分为小块并由 8 个并行子智能体同时翻译，每个智能体独立上下文窗口避免内容截断。工具支持断点续传，翻译完成后自动生成 HTML/DOCX/EPUB/PDF 四种格式，支持中文、英文、日文、韩文等多种语言互译。适合需要翻译外文书籍或文档的用户使用。
