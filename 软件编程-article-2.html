Vercel 首席执行官 Guillermo Rauch 宣布与 Astral 合作，将 `uv` 设置为 Vercel 上 Python 项目的默认工具，构建速度最高可提升 65%。

📝 详细摘要

Vercel 首席执行官 Guillermo Rauch 宣布与 Astral 合作，将他们先进的 Python 工具集成到 Vercel 平台。集成后，Vercel 将默认使用 Astral 开发的高性能工具 `uv` 作为 Python 项目的默认工具。预计此更改将显著缩短构建时间，Python 构建速度最高可提升 65%，并增强与各种依赖文件格式的兼容性，从而简化 Vercel 上 Python 开发者的开发和部署过程。
