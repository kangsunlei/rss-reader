微软开源的 Skill 进化神器，GitHub 上斩获 5000 多 Star 了。

6/12/2026, 9:39:00 AM

📌 一句话摘要

微软开源 SkillOpt，将训练神经网络的方法论（梯度、学习率、验证集）系统化地应用于 AI Agent 技能文档的自动优化，在 52 个评测单元上全面领先。

📝 详细摘要

本文介绍微软研究院开源的 SkillOpt 项目，其核心思想是将 AI Agent 的 Skill.md 文件视为可训练参数，借鉴神经网络训练流程（权重→Skill.md、梯度→轨迹反思、学习率→编辑幅度、验证集→评分门控、epoch→多轮迭代）来系统化优化技能文档。文章详细拆解了 ReflACT 六阶段管线：Rollout（执行任务收集轨迹）、反思分析（分析错误与成功原因）、生成补丁（小步编辑）、合并、排序筛选、验证门控（严格优于当前版本才接受）。实验覆盖 6 个 benchmark、7 个目标模型、3 种执行方式共 52 个评测单元，SkillOpt 全部最佳或并列最佳，在 GPT-5.5 上平均提升 19-24 分，最高达 39 分。优化后的技能文档可跨模型、跨场景迁移，部署时仅需一个 300-2000 token 的 Markdown 文件作为系统指令，推理成本为零。文章还提供了安装、配置、训练、评估及 WebUI 监控的完整使用指南。

💡 主要观点

  1. SkillOpt 将神经网络训练方法论系统化应用于 AI Agent 技能文档优化。 通过建立权重→Skill.md、梯度→轨迹反思、学习率→编辑幅度、验证集→评分门控、epoch→多轮迭代的对应关系，使技能优化从手工调参变为有纪律的自动化流程。
  2. ReflACT 六阶段管线确保每次修改都有据可查且严格验证。 从 Rollout 收集轨迹、反思分析、生成补丁、合并、排序筛选到验证门控，每一步都确保候选版本在验证集上严格优于当前版本才被接受，避免盲目修改。
  3. 52 个评测单元全部最佳，最高提升 39 分。 覆盖 SearchQA、ALFWorld、DocVQA、数学推理、电子表格、OfficeQA 等多样化任务，在 GPT-5.5 上平均提升 19-24 分，全面超越 TextGrad、GEPA 等现有方法及人类专家手写技能。
  4. 优化后的技能文档可跨模型迁移，部署成本为零。 在 Codex 上优化的技能可直接用于 Claude Code CLI，跨 benchmark 也有泛化性。最终产物仅 300-2000 token 的 Markdown 文件，作为系统指令即可部署，无需额外模型调用。

💬 文章金句

  • 把 Skill 的 md 文件当作神经网络里的可训练参数，然后用训练神经网络的那套纪律去优化它。
  • 你花了好几轮 epoch 训练出来的东西，部署的时候就是一个小小的 Markdown 文件。
  • 候选 skill 文档不会直接生效，必须先在验证集上跑一轮评分，只有得分严格优于当前 skill 文档，才会被接受。
