VoidZero 发布 Oxfmt Alpha：基于 Rust 的卓越性能与 Prettier 兼容性

1/23/2026, 4:00:00 PM

📌 一句话摘要

VoidZero 推出了 Oxfmt 的 Alpha 版本，这是一款基于 Rust 的代码格式化工具，其速度比 Prettier 快 30 倍，同时保持了 95% 的输出兼容性。

📝 详细摘要

VoidZero 宣布发布 Oxfmt 的 Alpha 版本，这是一款基于 Rust 编写的 Oxc 编译器栈构建的高性能 JavaScript 和 TypeScript 格式化工具。作为 Prettier 的无缝替代方案，它通过优化架构瓶颈，实现了比 Prettier 快 30 倍、比 Biome 快 3 倍的格式化速度。该工具旨在通过与 Oxlint 集成来简化开发工作流，从而减少配置开销。虽然目前处于 Alpha 阶段并拥有 95% 的 Prettier 兼容性，但其路线图已规划支持 Vue 和 Svelte 等框架、内置导入排序以及增强的插件功能。

💡 主要观点

  1. Oxfmt 相比现有格式化工具提供了极大的性能提升。 基准测试显示其速度比 Prettier 快 30 倍，比 Biome 快 3 倍，非常适合格式化时间成为瓶颈的大型代码库和 CI/CD 流水线。
  2. 与 Prettier 的高兼容性确保了低摩擦的迁移路径。 凭借 95% 的输出兼容性以及对标准 .prettierrc 选项的支持，开发者可以在几乎不改变现有代码风格的情况下切换到 Oxfmt。
  3. Oxc 工具链旨在统一 Lint 和格式化以减少开销。 通过同时提供 Oxlint 和 Oxfmt，VoidZero 消除了为防止不同工具之间规则冲突而进行的复杂配置需求。

💬 文章金句

  • Oxfmt 通过将基于 Rust 的工具性能优势与 Prettier 格式化风格的熟悉感相结合，解决了 JavaScript 生态系统中的一项挑战。
  • 团队的目标是减少配置开销，并消除禁用工具间重叠规则的需求。
