BigQuery 集成 Apache Spark 无服务器服务正式发布

6/11/2025, 12:00:00 AM

📌 一句话摘要

谷歌云推出与 BigQuery 深度集成的无服务器 Apache Spark，以简化数据处理。

📝 详细摘要

谷歌云宣布无服务器 Apache Spark 全面可用，现已深度集成到 BigQuery 统一数据平台中。此服务（前身为 Dataproc Serverless ）通过提供按需处理来解决管理 Spark 集群的复杂性，显著降低了总拥有成本 ( TCO ) 和基础设施开销。主要优势包括通过 Lightning Engine 实现高达 3.6 倍的性能提升，对 BigQuery 、 GCS 、 Spanner 以及 Iceberg / Delta Lake 等开放格式数据的无缝数据访问，全面的 OSS 兼容性，以及由 Gemini 提供支持的代码生成和故障排除协助，进一步提高了效率。该集成在 BigQuery Studio 中提供了统一开发者体验，使用 BigLake 元数据存储和 BigQuery Storage Read API ，可在单一数据副本上并行运行 SQL 和 Spark 代码。还包括增强安全性、作业隔离和监控等企业级功能。文章重点介绍了如何通过代码示例轻松入门。

💡 主要观点

  1. 无服务器 Spark 现已全面可用并集成到 BigQuery 中。 此集成提供了统一平台体验，允许用户直接在熟悉的 BigQuery 环境中使用 Spark 处理，从而简化工作流程。
  2. 该服务显著降低了总拥有成本 ( TCO ) 并消除了集群管理开销。 用户仅支付作业运行时长费用，避免了与空闲集群和手动基础设施维护相关的成本，从而可能实现成本节省。
  3. 通过 Lightning Engine 和优化连接器提供增强性能。 Lightning Engine 提供向量化执行和优化 I / O ，从而在各种数据源上实现更快的查询性能，提高处理效率。
  4. BigLake 元数据存储实现了统一数据访问和互操作性。 Spark 和 BigQuery 可以在相同的数据副本上操作，无论是托管格式还是开放格式，从而简化数据治理和访问控制。
  5. Gemini 集成为编码和故障排除提供 AI 协助。 开发者通过 BigQuery Studio 环境中由 Gemini 提供支持的 PySpark 代码生成和故障排除建议，提高了效率。
