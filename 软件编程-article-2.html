NVIDIA Run:ai 模型流式传输器：加速云存储上的 LLM 推理

12/5/2025, 12:00:00 AM

📌 一句话摘要

NVIDIA Run:ai 模型流式传输器现已支持 Google 云存储。通过流式传输模型权重，显著减少 GKE 上 LLM 推理的冷启动时间，提升可扩展性和效率。

📝 详细摘要

本文详细介绍了 NVIDIA Run:ai 模型流式传输器与 Google 云存储的全新原生集成，旨在解决 Google Kubernetes Engine (GKE) 上大型语言模型 (LLM) 推理的关键“冷启动”问题。随着 LLM 规模的增长，将模型加载到 GPU 内存所需的时间已成为主要瓶颈，导致 GPU 资源闲置并延误服务扩展。该工具通过将模型张量并发地流式传输到 GPU 内存来解决此问题，从而将加载时间从数分钟缩短至数秒。对于多 GPU 设置，其分布式流式传输功能使用 NVIDIA NVLink 有效地协调跨 GPU 的加载。该集成方案具有简单易用、性能卓越和安全性增强等特点，使 vLLM 用户只需一个命令行标志即可激活它，并利用 GKE 的工作负载身份来简化凭据管理。此外，将模型串流器与 Anywhere Cache 云存储相结合，可提供额外的服务器端加速，从而创建一个性能卓越的模型加载系统。此次合作旨在促进 GKE 上更快、更具弹性和更灵活的 MLOps 流程管线。

💡 主要观点

  1. NVIDIA Run:ai 模型流式传输器显著减少了 GKE 上的 LLM 冷启动时间。 通过将模型权重直接流式传输至 GPU 内存，而非完全下载，该方案可将模型加载时间从数分钟缩短至数秒，这对于大型语言模型的高效推理和自动缩放至关重要。
  2. 该流式传输器通过分布式流式传输和 NVLink 增强了多 GPU 性能。 该方案优化了跨多个 GPU 的协同加载，允许每个进程获取部分权重，并通过高带宽 NVLink 共享，从而提升大型模型并行部署的性能。
  3. 与 Google 云存储和 vLLM 的集成简化了部署并提高了安全性。 原生云存储支持、简化的 vLLM 标志以及 GKE 工作负载身份简化了部署配置，并通过移除手动密钥管理增强了安全性。

💬 文章金句

  • 加载模型的每一分钟，都是 GPU 闲置的一分钟，是您的服务延迟扩展以满足需求的一分钟，也是用户请求等待响应的一分钟。
  • 通过将模型流式传输到 GPU 内存中，模型流式传输器能够显著缩短启动过程中最耗时的部分。
  • 对于 vLLM 等流行的推理服务器用户，启用流式传输器非常简单，只需向 vLLM 命令行添加一个标志：`--load-format=runai_streamer`
  • 在 GKE 上运行时，模型流式传输器可以自动使用集群的工作负载身份。这意味着您不再需要手动管理和挂载服务帐户密钥，从而简化部署配置并增强安全性。
  • Anywhere Cache 服务器端加速与 NVIDIA Run:ai 模型流式传输器的客户端加速协同工作，共同创建了一个易于管理且性能极高的模型加载系统。
