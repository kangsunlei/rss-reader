Vercel 为 AI Agent 开启自主基础设施采购功能

3/2/2026, 7:25:13 PM

📌 一句话摘要

Vercel CEO Guillermo Rauch 宣布，AI Agent 现在可以通过 Vercel CLI 自主发现并集成第三方服务。

📝 详细摘要

这条推文重点介绍了 Vercel 在支持 AI Agent 方面的重大进展。除了编写和部署代码，Agent 现在还被赋予了“采购”能力——即通过 Vercel CLI 自主发现并安装 Marketplace 集成。Guillermo Rauch 提出了“自主基础设施”的概念，为 Agent 利用现有的第三方服务提供了一条标准化路径，避免了从零开始重复开发，从而显著提升了 Agent 工作流的效率。
