Cloudflare 推出零数据出口费用数据平台

11/1/2025, 10:57:00 AM

📌 一句话摘要

Cloudflare 全新数据平台提供零数据出口费用和诸如 Apache Iceberg 等开放标准的托管式分析数据服务。

📝 详细摘要

Cloudflare 现已启动数据平台的公开测试版。这是一个托管解决方案，旨在帮助用户轻松摄取、存储和查询分析数据表。该平台集成了 Cloudflare Pipelines，用于事件收集和 SQL 处理；R2 数据目录，用于 Apache Iceberg 元数据管理和维护；以及 R2 SQL，一个分布式无服务器查询引擎，用于处理 Petabyte 级别的数据集。其主要目标是简化传统数据基础设施，并降低其运营成本，因为传统数据基础设施通常既昂贵又复杂。Cloudflare 的一个关键优势是其“零数据出口费用”政策。这从根本上改变了数据仓库的经济模式，Cloudflare 旨在挑战主要云提供商在数据传输成本方面的优势，大规模运营每年可能节省数百万美元。该平台利用了对 Arroyo 流处理引擎的收购，最初支持无状态 SQL 转换，未来计划支持有状态处理能力，例如聚合和增量更新的物化视图。与 Logpush (日志推送服务) 的集成以及通过 Workers (无服务器函数) 的用户自定义函数也计划在 2026 年初推出。此产品对现有的 Cloudflare 用户极具吸引力，因为它充分利用了 Cloudflare 的性能和安全功能。在公开测试版期间，核心平台组件不收费，但存储和查询操作会产生标准的 R2 费用。

💡 主要观点

  1. Cloudflare 数据平台提供了一种使用开放标准的托管式分析数据解决方案。 该平台集成了 Pipelines、R2 数据目录和 R2 SQL，从而简化了数据摄取、存储和查询流程，同时降低了分析工作负载的运营复杂性和成本。
  2. 该平台的零数据出口费用从根本上改变了数据仓库的经济模式。 通过消除数据传输成本，Cloudflare 直接挑战了现有的云提供商，为 Petabyte 级别的运营提供了显著的成本节约，并提高了可负担性。
  3. Cloudflare 旨在通过无服务器、基于使用量的模式来实现分析数据基础设施的民主化。 在收购 Arroyo 的基础上，该平台将 Cloudflare 的无服务器开发者平台理念扩展到数据领域，使每个人都能访问和负担得起强大的分析功能。
