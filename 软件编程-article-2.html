GitHub Copilot 集成 GPT-5.3-Codex，大幅提升编程性能

2/9/2026, 6:25:05 PM

📌 一句话摘要

GitHub 宣布 OpenAI 的 GPT-5.3-Codex 已在 GitHub Copilot 中正式发布，该版本在性能上有了显著提升，并增强了智能体任务的推理能力。

📝 详细摘要

GitHub 已正式向 GitHub Copilot 用户推送 GPT-5.3-Codex。与前代版本（GPT-5.2-Codex）相比，本次更新在智能体编程任务上带来了 25% 的性能提升，并在编程和智能体基准测试中创下新纪录。该模型在复杂的开发者工作流中展现出卓越的推理与执行能力，目前用户可通过 VS Code 和 Copilot CLI 进行访问。
