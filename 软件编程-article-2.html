AGENTS.md：AI 编码智能体的新兴开放标准

8/27/2025, 8:40:00 PM

📌 一句话摘要

AGENTS.md 是一种新兴的开放标准，它是一种基于 Markdown 的约定，旨在为 AI 编码智能体提供结构化的、机器可读的指令。它补充了传统的 README 文件，并简化人与机器的协作。

📝 详细摘要

本文详细介绍了 AGENTS.md 的出现。它是一种开放且直接的、基于 Markdown 的约定，旨在为 AI 编码智能体提供结构化的、机器可读的软件开发指令。AGENTS.md 定位为面向人类的文档（如 README.md）的补充，隔离了特定于智能体的指导，例如设置命令、测试工作流程和编码风格偏好，从而减少 README 文件中的冗余，并为 AI 工具提供清晰的路径。目前，已有超过 20，000 个 GitHub 存储库采用了 AGENTS.md。其灵活性支持具有嵌套文件的大型单体仓库，确保为子项目量身定制指导。虽然 AGENTS.md 旨在减少人机协作中的摩擦，并被认为与基础的 README.md 具有相似的地位，但开发人员指出，它并不能消除对人工监督的需求，尤其是在业务逻辑和架构决策方面。对于分离面向人和面向智能体的文档，目前还存在一些疑虑。

💡 主要观点

  1. AGENTS.md 是一种开放的、基于 Markdown 的标准，用于为 AI 编码智能体提供结构化指令。 它通过为 AI 工具提供机器可读的上下文来补充 README.md，涵盖了特定的开发指令（如设置和风格），从而减少了面向人类的文档中的干扰。
  2. 该格式专为跨各种 AI 辅助开发工具的可移植性而设计，并支持复杂的项目结构。 其基于 Markdown 的方法确保了可访问性和集成到现有项目结构中，允许嵌套文件为智能体提供细粒度的、软件包级别的指导。
  3. 虽然旨在简化人机协作，但 AGENTS.md 并不能取代在复杂领域中进行人工监督的必要性。 开发人员强调，人工输入对于理解业务逻辑、项目目标和架构偏好仍然至关重要，这突出了对人的理解的持续需求。

💬 文章金句

  • AGENTS.md，一种直接且开放的格式，旨在帮助 AI 编码智能体进行软件开发。
  • 通过隔离这些信息，项目可以减少其 README 中的干扰，同时为智能体提供清晰的行动路径。
  • 我认为，对于诸如业务逻辑之类的问题，AI 仍然需要特殊的指导。如果没有人为告知，AI 永远无法确切地知道开发者正在构建什么、为什么要构建，以及项目的最终目标是什么。
  • 通过标准化项目与 AI 助手通信的方式，AGENTS.md 旨在减少人机协作中的摩擦。
