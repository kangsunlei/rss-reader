Vercel Fluid vs. Cloudflare Workers：性能与技术差异

10/4/2025, 4:13:45 PM

📌 一句话摘要

Guillermo Rauch 详细介绍了 Vercel 迁移出 Cloudflare Workers 的技术原因，并强调了 Vercel Fluid 的卓越性能、开放运行时以及到云服务的低延迟。

📝 详细摘要

Vercel 首席执行官 Guillermo Rauch 提供了 Vercel Fluid 和 Cloudflare Workers 之间的详细技术比较，声称 Fluid 在服务器渲染方面的速度是 Cloudflare Workers 的 1.2 倍到 5 倍。他解释说，Vercel 试图使用 Workers，但由于 CPU (中央处理器) 性能差、容量低、延迟不规则、单一供应商运行时（不是真正的 Node.js）以及到其他云服务的高延迟（10 毫秒到 100 毫秒）等问题而迁移。相比之下，Fluid 提供基于 CPU (中央处理器) 的定价、高效的并发、可定制的函数大小、像 Node.js 和 Python 这样的完整开放运行时以及到云服务的 1 毫秒延迟。他还参考了 @theo 进行的基准测试。
