Node.js 迈向稳定的 TypeScript 支持：Amaro 1.0 发布

9/7/2025, 2:15:00 AM

📌 一句话摘要

Node.js 团队发布 Amaro 1.0，正式迈向稳定的 TypeScript 原生支持，解决了长期以来对第三方工具的依赖。

📝 详细摘要

文章报道了 Node.js 团队发布 Amaro v1.0.0，这是 Node.js 实现稳定 TypeScript 原生支持的关键一步。Amaro 是 Node 官方提供的类型剥离加载器，基于 SWC TypeScript 解析器的 WebAssembly 移植。长期以来，Node.js 开发者不得不依赖第三方工具（如 `ts-node`、`tsx`）或使用 Deno 等替代运行时来处理 TypeScript。Amaro 的发布，尤其是其作为全局加载器处理 `node_modules` 中 TypeScript 文件的能力，显著优于现有的实验性支持。文章还提到 Amaro 支持 `strip-types` 和 `transform-types` 两种模式。社区对此普遍持积极但谨慎的态度，部分开发者已成功在生产环境中使用，并认为原生支持将取代对外部工具的需求。Amaro 遵循 MIT 许可，并支持 TypeScript 5.8。

💡 主要观点

  1. Node.js 官方加载器 Amaro 1.0 发布，实现稳定的 TypeScript 原生支持 Amaro 作为 Node 官方的类型剥离加载器，解决了 Node.js 长期缺乏原生 TS 支持的问题，标志着官方对 TS 生态的深度整合，降低了开发复杂度。
  2. Amaro 具备全局加载能力并支持多种类型转换模式 Amaro 能够作为全局加载器处理 `node_modules` 中的 TS 文件，并提供 `strip-types` 和 `transform-types` 两种模式，满足不同场景下的类型处理需求，提升开发灵活性。
  3. 社区对 Amaro 普遍持积极态度，认可其替代第三方工具的潜力 开发者普遍认为 Amaro 的原生支持能有效替代现有的第三方 TS 工具链，简化项目配置和部署，尽管对生产可用性仍存在一些谨慎的讨论。

💬 文章金句

  • Node.js 团队 最近发布了 Amaro v1.0.0，向稳定支持 TypeScript 迈出了重要一步。
  • Amaro 是 Node 官方提供的类型剥离加载器，也是官方.ts 加载的重要基础。
  • Amaro 的一个关键特性是能够作为全局加载器在 node_modules 中处理 TypeScript 文件，这是它比 Node.js 当前的实验性支持有显著优势的一个地方。
  • 如果你能使用 Node 的原生类型剥离，那么肯定就不需要那些包了[tsx/ts-node]。
