代理面板：在 GitHub 上的任何位置使用 Copilot 编码代理执行任务

8/19/2025, 7:53:14 PM

📌 一句话摘要

GitHub 推出代理面板，使开发人员能够从 GitHub.com 上的任何位置将编码任务交给 Copilot 编码代理，并无缝跟踪进度。

📝 详细摘要

GitHub 引入了新的“代理面板”。它是一个 GitHub.com 上的轻量级覆盖层，旨在帮助开发人员在不中断工作流程的情况下，从任何页面快速将编码任务交给 Copilot 编码代理。此功能通过允许异步、自主的任务分配和实时进度跟踪来简化开发人员的生产力。Copilot 编码代理充当自主团队成员，接受自然语言提示以生成草稿拉取请求、运行测试并在后台准备更改。该面板有助于分配后台任务、监控实时状态以及直接访问生成的拉取请求。本文还确认了 Copilot 编码代理在多个平台（包括 VS Code 和 GitHub Mobile ）上的可用性，以及所有付费 Copilot 订阅者对其的更广泛访问。利用 GitHub Actions 进行执行和模型上下文协议 (MCP) 进行安全数据访问，该系统确保开发人员通过详细的日志和基于 PR 的批准来保持控制。

💡 主要观点

  1. 新的代理面板允许开发人员从任何 GitHub 页面委派 Copilot 编码代理任务。 这个轻量级的代理面板，让你可以更方便地分配后台编码任务和监控进度，不用离开当前的工作页面，效率更高。
  2. Copilot 编码代理充当自主的对等方，从自然语言提示生成草稿拉取请求。 它在云中异步运行，处理诸如代码起草、测试和代码检查等任务，使开发人员能够卸载例行工作并专注于更高级别的问题。
  3. 该代理的功能通过多平台集成和安全协议访问得到扩展。 它可在 GitHub.com、VS Code 和其他集成开发环境中使用，并利用 MCP 进行安全存储库数据访问，从而为 AI 驱动的开发提供了一个通用且受控的环境。

💬 文章金句

  • 今天，我们将在 GitHub 上推出一种新的代理体验 --- 代理面板 --- 让您可以通过简单的提示从 github.com 上的任何页面快速将任务交给 Copilot ，并在不中断流程的情况下跟踪 Copilot 的进度。
  • 代理面板今天在 github.com 的每个页面上都可用，它是 GitHub 上代理工作流程的任务控制中心。
  • Copilot 编码代理让您可以移交编码任务 --- 通过 GitHub.com、GitHub Mobile、VS Code 或任何支持 MCP 的工具 --- 并在完成后获得草稿拉取请求。
  • 其安全的、由 GitHub Actions 提供支持的环境可以自动运行构建、测试和代码检查工具，而无需询问每个步骤。您可以通过详细的日志和基于拉取请求的批准来保持控制，并且可以通过在评论中提及 @copilot 来提供反馈。
