微软 Edge 0-Click 利用链串联 5 个漏洞，实现代码执行并逃逸沙箱

10/30/2026, 10:00:00 AM

📌 一句话摘要

研究人员披露了一条全新的微软 Edge 漏洞利用链，该链组合 5 个逻辑缺陷与两项 Windows 原生功能，无需内存破坏即可突破浏览器沙箱，在外部执行代码。

📝 详细摘要

安全研究员 Orange Tsai 发布了一项重要研究，揭示了微软 Edge 浏览器中存在的一条复杂漏洞利用链。该链通过串联条件访问导航缺陷、跨站脚本、CORS 泄露、路径遍历和协议处理漏洞，实现了从恶意网页到系统代码执行的完整攻击路径。这一发现强调了浏览器安全审计中对模块间交互的重视，并提醒用户及时更新以防范此类攻击。

💡 主要观点

  1. Edge 导航模块的逻辑缺陷导致通用跨站脚本 Edge 的条件访问导航处理模块未能将请求与原始标签页绑定，导致 JavaScript 在错误的安全上下文中执行，形成通用跨站脚本（UXSS），打破了网站间的隔离边界。
  2. 多重漏洞组合实现自动化攻击 利用链结合了硬编码的弹窗例外、跨窗口流程绕过、CORS 泄露和协议处理缺陷，实现了无需用户额外点击即可触发的自动化攻击，尽管仍需用户加载恶意内容。
  3. 突破沙箱利用 Windows 原生功能 通过修改 Edge 配置文件和利用 Windows 的 telnet 处理程序，攻击者成功将执行从浏览器沙箱扩展到外部系统，实现了完整的代码执行。

💬 文章金句

  • 该模块存在一个关键缺陷：没有将导航请求与原始标签页绑定。Chromium 内核会直接调用当前活动标签页处理请求，导致原本仅应在特定上下文运行的 JavaScript 可以在其他网站上执行，形成通用跨站脚本（UXSS），打破了不同网站之间原本的隔离边界。
  • 该利用链还需要获取已登录的 Edge 配置文件及其对应的邮箱地址。在测试环境中，当用户访问微软网站时，微软的 OneAuth 功能会调用已有的微软账户自动创建并登录配置文件。
  • 研究者借助路径遍历与空字节处理缺陷，首先突破了路径限制，可以将文件写入指定临时文件夹之外的位置。同时他还绕过了系统强制的 JSON 文件扩展名校验，实现任意文件写入。
