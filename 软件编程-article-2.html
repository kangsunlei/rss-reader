Python 常用 Pillow 图像库曝出严重漏洞，构造文件可触发代码执行

10/24/2026, 10:00:00 AM

📌 一句话摘要

Pillow 图像处理库的 EPS 文件处理逻辑存在严重漏洞，攻击者可通过构造恶意文件名触发 Ghostscript 命令执行，影响范围覆盖 2.6.0 至 12.3.0 版本，建议立即升级至 13.0.0 或采取隔离措施。

📝 详细摘要

文章详细报道了 Python 图像处理库 Pillow 的重大安全漏洞。该漏洞由 Pillow 在处理 EPS 格式图像时，将未经校验的文件名直接传递给 Ghostscript 引起，攻击者可利用此漏洞执行任意操作系统命令。此外，新版本还修复了多个高危漏洞，包括 JPEG 解码溢出和 TIFF 内存保存问题。由于 Pillow 的广泛应用，该漏洞对众多 Python 项目构成严重威胁，建议用户尽快升级至 13.0.0 版本。

💡 主要观点

  1. Pillow 的 EPS 处理逻辑存在严重漏洞，攻击者可通过构造文件名触发命令执行。 Pillow 在打开 EPS 文件时，将文件名直接传递给 Ghostscript，而未进行合法性校验。攻击者可以构造特殊的文件名，使其被 Ghostscript 识别为执行指令，从而触发任意代码执行。该漏洞影响范围从 2.6.0 到 12.3.0 版本。
  2. 新版本 13.0.0 修复了多个高危漏洞，包括 JPEG 解码和 TIFF 保存问题。 除了 EPS 漏洞外，13.0.0 还修复了两个严重级别的 JPEG 解码漏洞和一个 TIFF 内存保存漏洞。这些漏洞分别涉及 FlashPix 格式的 JPEG 攻击、JPEG 缩略图生成时的缓冲区溢出，以及 TIFF 文件在内存中的保存问题，均可能导致程序崩溃或代码执行。
  3. 建议用户立即升级至 13.0.0 版本，并采取隔离措施以防范攻击。 由于 Pillow 的广泛使用，该漏洞对许多 Python 项目构成威胁。用户应尽快升级到 13.0.0 版本，并确保重新构建所有依赖该库的容器和包。如果无法立即升级，应采取隔离措施，例如禁止安装 gs 程序或严格限制可处理的文件类型，以防止漏洞被利用。

💬 文章金句

  • 公告指出：'漏洞由文件名触发，与 PostScript 文档内的任何内容无关'。这意味着攻击者只要给完全无害的 EPS 文件设置恶意文件名，就能触发漏洞造成危害。
  • 该漏洞只有在主机安装了 gs 程序时才会触发——gs 是 Pillow 打开 EPS 文件的必需依赖。漏洞影响范围覆盖 Pillow 2.6.0 到 12.3.0 的所有版本。
  • Pillow 维护方认为，攻击者需要完全控制文件名才能利用漏洞，因此将其评为中危。但 GitHub 分配的 CVE 记录给该漏洞打出 9.2 分（满分 10 分），评级为严重，两者的判定前提一致。
