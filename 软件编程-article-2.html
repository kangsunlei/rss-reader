.NET Aspire 9.5 发布：全新 CLI 更新命令、AI 仪表盘可视化器及扩展集成

9/27/2025, 9:30:00 AM

📌 一句话摘要

.NET Aspire 9.5 引入全新 CLI 更新命令、用于大语言模型遥测的 AI 仪表盘可视化器，并扩展了分布式应用开发集成。

📝 详细摘要

微软发布了 .NET Aspire 9.5，这是一个支持 .NET 8、.NET 9 和 .NET 10 发布候选版本 1 的小幅更新。主要亮点是 `aspire update` 命令的预览版，旨在自动执行项目升级并感知渠道。此版本还引入了对单文件应用容器 (`apphost.cs`) 的实验性支持，以及多项工具增强，包括对 `aspire exec` 和 VS Code 中 SSH 远程端口转发的改进。在可观测性方面，Aspire 仪表盘现在配备生成式 AI 可视化器，用于检查以大语言模型为中心的遥测数据，以及多资源控制台日志、自定义资源图标和改进的跟踪过滤。此外，Aspire 9.5 显著扩展了集成能力，为 OpenAI 端点、GitHub 模型和 Azure AI Foundry 的类型化目录、开发隧道、YARP 静态文件服务、Azure Kusto 以及增强的 Redis 和 RabbitMQ 支持提供原生支持。应用模型和发布方面的改进，例如资源生命周期事件 API 和统一的 Azure 部署管道也包含在内，同时还需注意一些重大更改。社区反馈积极，特别是对更新命令和以 AI 为中心的仪表盘功能。

💡 主要观点

  1. 全新 `aspire update` 命令简化了项目维护和升级流程。 这个预览版 CLI 命令可以自动扫描、验证并安全更新应用，显著减少手动工作，提高 Aspire 项目的维护效率。
  2. Aspire 仪表盘现在包含用于大语言模型遥测的生成式 AI 可视化器。 此功能通过允许开发者整理和检查以大语言模型为中心的遥测数据，并与不断发展的 OpenTelemetry 标准保持一致，为开发者提供增强的 AI 驱动应用可观测性。
  3. 扩展的集成增强了 Aspire 与各种云和 AI 服务的功能。 对 OpenAI、Azure AI Foundry、开发隧道和 Azure Kusto 的原生支持，以及改进的 Redis/RabbitMQ 集成，简化了利用各种外部服务的复杂分布式应用开发。

💬 文章金句

  • Aspire 9.5 的核心新增功能之一是新的 *aspire update* 命令的预览版。
  • 此功能允许开发者整理和检查以大语言模型为中心的大语言模型遥测数据，并支持不断发展的 OpenTelemetry 约定。
  • 这些新增功能延续了 Aspire 对提供更清晰的分布式应用行为洞察的关注。
  • Aspire 9.5 现在包括对 OpenAI 端点、GitHub 模型和 Azure AI Foundry 的类型化目录以及开发隧道集成的原生支持，以简化本地服务的公开。
