📝 详细摘要

Kaku v0.5 (Codename Yohaku) marks a major update for this macOS terminal emulator， specifically tailored for AI-assisted development. This release focuses on accelerating the developer's 'inner loop'—the cycle of executing commands， fixing errors， and navigating files. Key features include AI Shell fixes that suggest and apply corrections for failed commands， deep integration with the yazi file manager， and sophisticated editor-style text manipulation. Additionally， it introduces a diagnostic 'Kaku Doctor' tool and performance optimizations like Lua bytecode caching for near-instant startup.
