Vercel CLI 新增 `api` 命令，助力 AI 智能体深度集成

1/27/2026, 6:01:27 PM

📌 一句话摘要

Vercel 在其 CLI 中推出了全新的 `api` 命令，使 AI 智能体能够安全地直接访问 Vercel 平台，无需额外安装 MCP。

📝 详细摘要

Vercel CEO Guillermo Rauch 宣布在 Vercel CLI 中引入 `api` 命令。该功能专为 Claude Code 等 AI 智能体设计，提供直接的终端 API 访问能力。其核心优势在于无需安装额外的 MCP（模型上下文协议），并能直接复用现有 CLI 的安全与身份验证配置。这一更新标志着 Vercel 在 AI 驱动开发工作流集成方面迈出了重要一步，开发者只需运行 `npx vercel@latest api` 即可快速上手。
