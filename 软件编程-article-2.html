Claude Code 与阶跃星辰 Flash 社媒爬取实测对比

2/22/2026, 4:04:45 PM

📌 一句话摘要

通过实测对比 Claude Code 和阶跃星辰 Flash，验证了国产 Flash 模型在长程任务中的高性价比与稳定性。

📝 详细摘要

作者针对社媒数据爬取任务，对比了 Claude Code 和国产模型阶跃星辰（StepFun）Flash 的表现。实测显示，Claude Code 质量最优但耗时约 3.5 分钟；阶跃星辰 Flash 虽然在指令遵循上略有偏差（找了 15 条而非 20 条），但数据准确、图表丰富，且处理 200 万 Token 仅需 0.2 美元。作者高度评价了国产模型在 Toolcall 稳定性和性价比方面的表现，认为其非常适合国内 AI 用户。
