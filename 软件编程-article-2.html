Databricks 数据共享与协作功能更新

3/27/2025, 4:00:00 PM

📌 一句话摘要

Databricks 通过 Delta Sharing、Clean Rooms 等功能，安全地促进跨平台数据共享与协同。

📝 详细摘要

Databricks 发布了一系列数据共享和协同的新功能与合作，旨在降低成本并提升效率。Delta Sharing 引入了跨平台视图共享、使用 OIDC 令牌的安全开放共享、Lakehouse Federation Sharing 等功能，提高了数据共享的灵活性和安全性。Clean Rooms 已全面上市，支持跨云联合共享和 HIPAA 合规。通过与 SAP 的合作，Delta Sharing 实现了 SAP Business Data Cloud 和 Databricks 之间的双向数据共享。这些更新旨在简化跨平台数据协同，同时加强安全协议，减少数据移动和 ETL 过程。

💡 主要观点

  1. Delta Sharing 通过多种新特性，简化了跨平台数据协同。 跨平台视图共享允许在不同环境中无缝共享视图，Lakehouse Federation Sharing 支持直接共享非 Databricks 数据，减少数据移动和 ETL 过程。
  2. Delta Sharing 通过多种新特性，增强了数据共享的安全性。 OIDC 令牌联邦提高了开放共享的安全性，Serverless Egress Control 确保 serverless 环境的安全。
  3. Databricks Clean Rooms 的全面上市，为企业在保护隐私的前提下进行数据协同提供了便利。 Clean Rooms 支持跨云联合共享和 HIPAA 合规，适用于广告、欺诈检测等多种场景，并已得到 Mastercard 等公司的应用。
  4. 与 SAP 的合作使得 SAP 数据能够安全地与 Databricks 集成，用于高级分析和 AI。 Delta Sharing 在 SAP Business Data Cloud 和 Databricks 之间实现了无缝数据交换，降低了数据不一致的风险，并最大化了 SAP 投资的价值。
  5. Serverless Egress Control 确保接收者的 serverless 环境安全。 Serverless Egress Controls 确保接收者的 serverless 环境保持安全，并与开放互联网隔离。该功能只允许接收者访问与 Delta Shares 关联的授权存储位置，从而增强安全性并降低未经授权的数据访问风险。

💬 文章金句

  • Databricks 助力企业安全地在团队、伙伴和平台间共享数据、AI 模型和分析，避免数据重复和厂商锁定。
  • Delta Sharing 为多云生态系统提供简化的跨平台数据协同，同时执行严格的安全协议。
  • Delta Sharing 在 SAP Business Data Cloud 和 Databricks 之间提供无缝、安全的数据交换——无论使用 SAP Databricks 还是客户现有的 Databricks 工作区。
