paper2code：输入 arXiv 链接即可生成带引用的论文代码实现

4/26/2026, 1:30:05 PM

📌 一句话摘要

GitHub 开源项目 paper2code 通过输入 arXiv 链接，自动生成带有详细引用标注的完整代码实现，解决论文复现痛点。

📝 详细摘要

该推文介绍了一个名为 paper2code 的开源项目，旨在解决算法工程师和科研人员在复现论文时遇到的常见痛点。用户只需输入一个 arXiv 链接，该项目就能自动输出完整的代码实现，并且每一行关键代码都会在注释中明确标注对应的论文章节和公式序号，清晰区分了原作者意图和 AI 生成部分。此外，该项目还可作为技能安装到 Claude Code 等 Agent 工具中使用，通过命令行即可快速本地部署。对于经常需要与前沿论文打交道的技术从业者来说，这是一个非常实用的工具。
