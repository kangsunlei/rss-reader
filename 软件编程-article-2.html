Sure：开源多账户记账，AI 助手+ Docker 部署

11/15/2026, 12:00:03 AM

📌 一句话摘要

Sure 是一个开源个人记账应用，支持多账户整合、AI 收支分类，并可自行部署在 Docker 服务器上，保障隐私安全。

📝 详细摘要

面对每月账户分散记账的痛点，Sure 提供了统一的面板查看现金流、净资产和支出去向。前身为 Maybe Finance，开源后由社区维护。具备 AI 助手功能，能分析交易并自动归类。支持 Docker 部署，浏览器和 Mac 桌面均可用，手机端查看余额。为注重隐私的个人用户提供便捷的理财管理方案。

💡 主要观点

  1. 多账户整合 统一显示银行卡、信用卡、投资账户的收支和余额，避免了逐个 App 查询的繁琐。提供现金流、净资产和支出去向的综合面板，便于快速掌握财务状况。
  2. AI 辅助分类 内置 AI 助手，可自动识别交易中的商家和类别。用户只需对话式提问，即可获取账户总结、支出趋势等分析数据。这一自动化功能显著提高了记账效率和数据利用率。
  3. 隐私与可扩展性 支持 Docker 部署，这意味着用户可自行托管在个人服务器，完全控制数据，不必担心第三方泄露。同时，开放 API 接口方便与外部服务（如 Claude）集成，扩展了应用的实用性。

💬 文章金句

  • 里面带一个 AI 助手，接上自己的大模型后，可以直接问它账户、收支、净资产方面的问题，后台还会自动给每笔交易归类、识别商家。
  • 用 Docker 部署在自己的服务器上，账目数据都留在自己手里。
