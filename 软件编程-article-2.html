老板让背景位置智能展示：字多居中，字少右下

📌 一句话摘要

文章介绍了如何实现背景图根据内容高度智能调整位置的需求（字少时居中、字多时靠下），并提供了 CSS+JS 和 CSS 容器查询两种技术实现方案。

📝 详细摘要

文章针对背景图片根据内容高度动态调整位置的需求，提出了两种前端实现方案。首先回顾了 CSS 背景属性基础，然后详细介绍了基于 JavaScript 判断内容高度并动态切换 CSS 类的方式。接着，引入了更现代的 CSS 容器查询（Container Query）特性，解释了其原理、用法及与媒体查询的区别，并给出了基于容器查询的实现代码。文章对比了两种方法的优劣，并提供了容器查询的浏览器兼容性信息。整体内容实用，为解决特定前端布局问题提供了清晰的思路和代码示例。

💡 主要观点

  1. 根据容器内容高度动态调整背景位置是一项常见前端需求 解决了在不同内容量下背景图片展示不协调的问题，提升用户体验和页面美观度，例如满足字多时居中、字少时靠下的具体设计要求。
  2. 可通过 CSS+JS 或 CSS 容器查询实现动态背景定位 JS 方法灵活但代码繁琐，需要手动判断和切换类；容器查询提供更原生、组件化的 CSS 解决方案，通过@container 规则根据容器尺寸自动应用样式，简化响应式布局。
  3. CSS 容器查询基于父容器尺寸响应式调整样式 相比媒体查询基于视口尺寸，容器查询粒度更细，根据容器而非视口变化，更适合组件化开发和构建独立的、响应式模块。
  4. CSS 容器查询目前浏览器兼容性良好，但仍需注意目标用户群体的支持情况 主流现代浏览器（Chrome， Edge， Safari， Firefox 等）均已支持容器查询，但在考虑使用时仍需根据项目需求和用户浏览器分布评估其可行性，对于不支持的浏览器可能需要备用方案或 Polyfill。

💬 文章金句

  • 当标题内容较少时，背景图要靠右居中展示，并根据区域上下裁剪，从中间部分开始显示
  • 当标题内容较多时，背景图要靠右底部对齐展示
  • 简单理解就是：内容少，图居中裁；内容多，图靠下贴边。
  • 其实上述的效果无非就是通过两个类名控制，内容高度低于图片时，用一个类名控制图片样式；内容高度高于图片时，用另一个类名控制图片样式。
  • Container Query（容器查询）是 CSS 中的一项现代特性，它允许根据 "父容器的尺寸" 而不是 "视口尺寸" 来响应式地改变样式。
  • 容器查询虽然好用，但也要注意兼容性
