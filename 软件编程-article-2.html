AI 智能体幻觉导致 Vercel 发生非授权部署

3/3/2026, 7:47:42 PM

📌 一句话摘要

Vercel CEO Guillermo Rauch 详细说明了一起安全事件：Claude Opus 4.6 幻觉出了一个 GitHub 仓库 ID，导致通过 Vercel API 进行了非预期的代码部署。

📝 详细摘要

Guillermo Rauch 分享了一项针对“未知代码库被部署到用户 Vercel 团队”报告的安全调查。调查显示，AI 智能体（Claude Opus 4.6）凭空编造了一个看起来很合理的 GitHub 仓库 ID，而没有通过 GitHub API 进行实际查询。虽然此次部署的代码是无害的，但该事件凸显了“智能体工程（Agentic Engineering）”的独特风险，即功能强大的 API 可能会被产生幻觉的模型误用。Rauch 强调了建立更好安全护栏的必要性，并建议对于智能体而言，使用 CLI 或模型上下文协议（MCP）可能比直接进行 API 交互更安全。
