排序基础模型：挑战、成功与经验教训

1/28/2026, 5:03:00 PM

📌 一句话摘要

Netflix 专家分享了他们如何通过 UniCoRn 模型统一搜索与推荐系统，并利用基于 Transformer 的用户基础模型进一步增强个性化体验。

📝 详细摘要

本文详细介绍了 Netflix 如何从碎片化的机器学习模型转向统一的搜索与推荐架构。文章引入了“UniCoRn”（统一上下文排序器），这是一种多任务学习模型，通过统一不同产品界面的上下文和数据，取代了多个定制化系统。为了解决深度个性化的挑战，Netflix 受 LLM 启发开发了“用户基础模型”（FM）。该 FM 将用户交互轨迹视为序列（类似于文档中的单词），并采用基于 Transformer 的自监督学习方法来捕捉长期和短期偏好。通过将此 FM 集成到 UniCoRn 中，Netflix 在减少维护开销和创新阻力的同时，在搜索和推荐任务上实现了显著的性能提升。

💡 主要观点

  1. 将搜索与推荐统一为单一模型 (UniCoRn) 可以减少技术债。 通过将搜索和推荐都视为具有不同上下文的排序任务，Netflix 用一个模型取代了四个独立模型，精简了工程流水线，并允许创新同时应用于所有界面。
  2. 用户基础模型 (FM) 可以利用类 LLM 架构学习与任务无关的会员偏好。 通过将用户交互历史 Token 化并使用基于 Transformer 的 Decoder-only 架构，模型能够以自监督方式学习整体用户行为模式，类似于 GPT 模型学习语言的方式。
  3. 将基础模型集成到排序系统中带来了“魔法般”的个性化提升。 FM 作为一个强大的特征提取器，能够理解用户的细微差别；将其注入 UniCoRn 排序器后，显著提高了相关性并过滤掉非偏好内容（例如为成人个人资料过滤掉儿童节目）。
  4. 延迟和计算成本等系统因素对于大规模排序至关重要。 部署大型基础模型需要平衡模型复杂度与推理 SLA，利用缓存、GPU 优化和异构上下文 API 等策略来保持响应迅速的用户体验。

💬 文章金句

  • 我们提出的问题是，能否为搜索和推荐任务构建一个统一的模型？答案是肯定的。
  • 我们拥有的不是句子，而是交互轨迹。学习目标同样采用自监督方式，与大语言模型相同。
  • 我认为基础模型中的 Transformer 就像哈利·波特，而它带来的个性化就是魔法。
  • 训练一个基础模型的成本远低于训练每个独立的定制模型，因为后者需要一次又一次地重新学习这些用户模式。
  • 应用于产品某一部分的创新可以立即适用于产品的其他部分。
