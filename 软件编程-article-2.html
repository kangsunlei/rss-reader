10/16/2026, 1:25:40 AM

📌 一句话摘要

作者称赞 ChatGPT Chrome 扩展的网页总结功能，但质疑其是否不再支持第三方 API 或本地 Codex 调用。

📝 详细摘要

作者分享了 ChatGPT Chrome 浏览器扩展更新后的正面体验，认为网页总结等功能极强。同时提出疑问：目前似乎只能登录 OpenAI 官方账号，无法调用本地 Codex，猜测其可能像 Claude 一样停止支持第三方 API。

💡 主要观点

  1. ChatGPT 官方扩展功能增强 网页总结等功能将 ChatGPT 能力直接集成到浏览器中，用户体验极佳。
  2. 第三方 API 支持可能被削弱 无法调用本地 Codex，可能暗示官方在收拢生态，限制第三方 API 的接入。

💬 文章金句
