lcu：将 ChatGPT 桌面版操作能力集成至 Claude Code 等 Agent

10/9/2026, 12:00:05 AM

📌 一句话摘要

开源项目 lcu 将 ChatGPT 桌面版的自动化操作能力剥离并开放给 Claude Code 等其它 Agent 调用，实现了跨环境的电脑控制能力。

📝 详细摘要

开源项目 lcu 通过调用 ChatGPT 桌面版底层的操作接口，使 Claude Code、Codex 等其他 Agent 能够获取读取窗口、模拟点击、截图及操作 Chrome 网页等能力。该项目在权限控制上进行了细化设计，支持单次授权及永久授权，并通过 Touch ID 验证保障核心配置安全。

💡 主要观点

  1. 核心功能复用 lcu 将 ChatGPT 桌面版自带的电脑操作能力提取出来，赋能给 Claude Code 等其他开发工具，避免了为使用该功能而在不同 Agent 间切换。
  2. 细粒度的安全权限管理 项目通过对话式授权机制，配合 Touch ID 强制校验，防止 Agent 随意篡改授权列表或操作高危应用（如终端）。
