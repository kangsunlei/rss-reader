Jetpack Compose 增强滚动 、惰性列表 等功能

8/14/2025, 6:00:00 PM

📌 一句话摘要

最新的 Jetpack Compose 版本引入了用于阴影 、2D 滚动 、改进的惰性列表性能和增强的开发者工具的新 API 。

📝 详细摘要

本文重点介绍了 Jetpack Compose 2025 年 8 月发布的关键更新 ，重点关注增强 UI 渲染 、性能和开发者体验的功能 。它引入了 `Modifier.dropShadow()` 和 `Modifier.innerShadow()` ，以实现更灵活的阴影效果 ，超越了基于层级的阴影 。引入了 `onVisibilityChanged` 和 `onFirstVisible` 等可见性修饰符 ，以更好地跟踪 UI 元素可见性 ，实现动态内容控制 。讨论了惰性组件的性能增强 ，重点介绍了用于优化惰性列表和网格预取的 `LazyLayoutCacheWindow` 。`Scrollable2D` 修饰符是一项重要补充 ，它允许对复杂 UI (如电子表格) 进行二维滚动 ，并改进了与 Android Views 的滚动互操作性 。此外 ，该版本还引入了一个可选 API ，用于提供更丰富的崩溃日志 ，从而提供更有用的调试信息 。最后 ，一个新的运行时注解库公开了编译器和静态代码分析注解 (如 `@RememberInComposition` 和 `@FrequentlyChangingValue`) ，以指导开发者编写性能更高且更准确的 Compose 代码 。

💡 主要观点

  1. 新的阴影修饰符提供了增强的 UI 渲染能力 。 `Modifier.dropShadow()` 和 `Modifier.innerShadow()` 提供了对视觉阴影效果更精细的控制 ，使开发者能够创建比传统阴影更丰富 、更复杂的用户界面 。
  2. 惰性组件和滚动方面的显著性能和控制改进 。 `LazyLayoutCacheWindow` 优化了惰性列表和网格的预取 ，而 `Scrollable2D` 修饰符实现了复杂的多方向滚动 ，提升了数据密集型应用的用户体验 。
  3. 更好的开发者工具 ，用于调试和代码质量 。 更丰富的崩溃日志包含可组合项名称 ，简化了错误识别 。新的运行时注解通过标记潜在问题 ，指导开发者编写更高效 、更准确的 Compose 代码 。

💬 文章金句

  • 两个新的修饰符 `Modifier.dropShadow()` 和 `Modifier.innerShadow()` 能够渲染盒阴影效果 ，无论是在可组合项 (例如图像或矩形) 的下方还是上方 。
  • 由于新的 `LazyLayoutCacheWindow` ，惰性列表和网格现在都提供了更好的预取性能 ，它允许开发者指定要预取的项目数量 。
  • 对于实现更复杂的滚动体验 (如电子表格或图像查看器) 的应用程序来说 ，一个重要的新功能是新的 Scrollable2D 修饰符 ，它可以在两个维度上实现滚动和快速滑动 ，并扩展了现有的 `Scrollable` 修饰符 ，后者仅在一个方向上起作用 。
  • 在工具方面 ，新的 Jetpack Compose 版本引入了一个可选择启用的 API ，用于提供更丰富的崩溃日志 ，其中将包括可组合项名称和崩溃位置 。
  • 谷歌推出了一个新的运行时注解库 ，用于公开编译器和静态代码分析注解 ，让非 Compose 类和函数也能使用这些注解 ，而无需依赖 Compose 运行时 。
