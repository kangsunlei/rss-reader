Grafana 安全更新：CVE-2025-3415 中等严重性安全漏洞发布

6/13/2025, 9:25:16 PM

📌 一句话摘要

Grafana 发布安全补丁，修复 CVE-2025-3415 中等严重性漏洞，该漏洞暴露了告警功能中的钉钉联系人信息。

📝 详细摘要

Grafana 实验室发布了安全补丁（版本 12.0.1、11.6.2、11.5.5、11.4.5、11.3.7、11.2.10 和 10.4.19），以修复 CVE-2025-3415 漏洞。该中等严重性漏洞由于配置疏忽，向仅具有查看者权限的 Grafana 用户明文暴露了已配置的钉钉告警集成 URL，此问题通过漏洞赏金计划发现。文章详细介绍了漏洞影响（CVSS 3.0 评分 4.3）、受影响版本（<=12.0.1）以及修复方案（升级到补丁版本或移除配置/撤销 API 密钥），同时包括事件响应流程的时间表，并提供安全问题报告和安全公告获取方式。

💡 主要观点

  1. CVE-2025-3415 中等严重性漏洞影响 Grafana 告警功能。 该安全缺陷以明文形式向具有查看者权限的用户暴露了钉钉联系人 URL，可能导致集成安全性降低。
  2. 多个 Grafana 版本均已发布补丁以修复此漏洞。 强烈建议用户将 Grafana 实例升级到指定补丁版本，以应用必要的安全修复。
  3. 为无法立即升级的用户提供了备选缓解措施。 如果无法立即升级，移除钉钉配置或撤销相关 API 密钥可以暂时缓解风险。

💬 文章金句

  • 这些补丁版本包含 CVE-2025-3415 的修复程序，该漏洞为中等严重级别，暴露了 Grafana 告警功能中的钉钉联系人信息。
  • 在 Grafana 告警功能中，配置的钉钉联系人信息可能以明文形式暴露给具有查看者权限的 Grafana 用户。
  • 要彻底修复 CVE-2025-3415，请升级您的 Grafana 实例。
