GitHub 推迟自托管 Actions 计费政策调整，降低托管运行器价格

12/17/2025, 7:24:16 PM

📌 一句话摘要

GitHub 已推迟针对自托管 GitHub Actions 的有争议计费政策调整，以重新评估其策略，同时确认降低托管运行器价格。

📝 详细摘要

为回应社区反馈，GitHub 宣布了一项关于 GitHub Actions 的重大政策逆转。公司正在推迟此前宣布的自托管运行器计费政策调整，以重新审视其方案并更有效地与社区互动。同时，公司重申托管运行器价格将从 2026 年 1 月 1 日起最高降低 39%。GitHub 承认维护 Actions 控制平面涉及的实际成本，以及他们为改进自托管运行器所做的投资，以使其能在客户环境（特别是复杂的企业场景）中大规模运行。尽管有这些背景，GitHub 也承认在规划此次具体变更时，未能充分吸纳社区的意见。他们旨在通过改进沟通和根据开发者输入更新路线图来重建信任，并将持续交付 GitHub Actions 及整个平台的服务。
