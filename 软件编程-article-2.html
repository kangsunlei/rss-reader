abtop：为 AI 编程助手打造的终端监控面板

4/22/2026, 1:30:11 PM

📌 一句话摘要

abtop 是一款开源的终端监控工具，可实时查看 Claude Code 等 AI 编程助手的 Token 消耗、上下文占比及限流状态。

📝 详细摘要

推文介绍了一款名为 abtop 的开源工具，专门解决开发者在使用 Claude Code 或 Codex CLI 等 AI 编程助手时，难以跨会话监控资源消耗的问题。该工具在终端提供直观面板，展示 Token 用量、上下文占比和速率限制。其核心优势在于纯本地读取进程状态，无需 API 密钥，保障隐私安全，并支持在 tmux 环境下快速跳转会话，极大提升了多任务 AI 开发的效率。
