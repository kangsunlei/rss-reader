phonedriver：让 Claude Code 等 Agent 能操作手机

11/16/2026, 12:18:48 AM

📌 一句话摘要

phonedriver 为 Claude Code、Codex、Cursor 等 AI Agent 提供手机操作能力，支持安卓/iOS 真机与模拟器，显著降低 Token 消耗且保留人工确认机制。

📝 详细摘要

phonedriver 解决了 Claude Code 等 Agent 无法直接操作手机的痛点。它为模型配备一台可操作的手机（真机或模拟器），通过将每一屏转化为带编号的文字清单，模型按编号点击，结果只报告界面变更，大幅降低 Token 消耗（mobile-mcp 方案约高出 6.9 倍）。演示中 Claude Code 能自主完成披萨下单流程至支付环节，随后主动要求人工确认。作者用 9 个手机任务对比测试，验证了其轻量化方案。适合 App 开发者让 AI 自动走一次新用户首次使用流程发现 Bug。

💡 主要观点

  1. Agent 可直接操作手机 提供安卓和 iPhone 真机及模拟器支持，配合 Claude Code、Codex、Cursor 等 Agent 实现自动化点击、填表操作。
  2. Token 消耗显著降低 采用分屏文字清单编号方式，仅报告界面变更，实测比 mobile-mcp 低 6.9 倍。
  3. 关怀式支付安全机制 在支付环节自动暂停并请求人工确认，降低财产风险，体现对关键操作的审慎设计。

💬 文章金句

  • phonedriver 就是给 Agent 配了一台手机，Claude Code、Codex、Cursor 这些都能直接操作安卓手机和 iPhone，模拟器和真机都行。
  • 作者拿 9 个手机任务做了对比，同样的活，mobile-mcp 用掉的 token 是它的 6.9 倍。
  • 碰到付款先停下来问人，这点我觉得很关键，不然真不敢让它碰自己的手机。
