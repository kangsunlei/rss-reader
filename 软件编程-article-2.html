Cloudflare D1 数据库新增全局只读复制功能

5/3/2025, 12:00:00 AM

📌 一句话摘要

Cloudflare D1 数据库发布全局只读复制 Beta 版，降低读取延迟，提高吞吐量，并保证数据一致性。

📝 详细摘要

Cloudflare 在 2025 开发者周上发布了 Serverless SQL 数据库 D1 的全局只读复制 Beta 版。通过在每个区域自动配置副本，应用程序可以更快地服务于读取查询，同时在请求中保持强大的顺序一致性。D1 通过会话 API 实现请求路由和数据一致性管理，确保会话内查询的顺序一致性。此功能满足了社区的期待，并解决了部分用户关注的问题。

💡 主要观点

  1. 全局只读复制提升读取性能 全局只读复制通过自动配置区域副本，降低读取延迟并提高吞吐量。
  2. 会话 API 保证顺序一致性 D1 的只读复制是异步的，但通过会话 API 可以确保来自同一客户端的请求的顺序一致性。
  3. 通过 `withSession` 方法实现灵活的会话管理 通过 `withSession` 方法和不同的路由选项（如 `first-unconstrained` 首次无约束路由， `first-primary` 首次主节点路由），实现灵活的会话管理和数据一致性控制。

💬 文章金句

  • D1 的只读复制功能构建于数据库会话的概念之上。
  • 会话机制确保会话中所有查询的顺序一致性，无论其被路由到哪个数据库副本。
  • D1 运行于 Cloudflare 的全球网络之上，无法保证来自同一客户端的请求每次都被路由到同一副本。
