AgentDraw：可能是第一个能让 agent 帮你生成稳定好看可编辑的各种配图的开源工具

7/4/2026, 2:18:13 PM

📌 一句话摘要

AgentDraw 是一个开源工具，让 AI agent 通过 SVG 生成可编辑、好看的各类配图，并提供设计语言与校验机制提升输出稳定性。

📝 详细摘要

文章介绍了 AgentDraw，一个让 AI agent（如 cc/codex）生成稳定好看且可编辑图表的开源工具。作者指出现有 agent 生图方案要么输出难以编辑（直接生成 HTML 或图片），要么生成的 draw.io 类似图形不稳定且丑陋。AgentDraw 通过两核心思路解决这些问题：一是采用结构化的“设计语言”对间距、颜色、交互等进行约束，把抽象的设计风格转化为可执行的规则，从而减少 agent 的随机抽卡；二是让 agent 直接生成 SVG，再将 SVG 渲染为画板数据，既保证输出稳定又便于后续编辑。工具内置 44 种设计主题，支持流程图、架构图、产品路线图等多种图表，生成后可在浏览器中自由拖拽调整文字、方框、连线及布局，并导出为 SVG 或 PNG 用于文章、文档、PPT 等场景。此外，AgentDraw 还提供校验、测试与评估机制，让 agent 能自动判断输出是否符合质量要求并进行优化。文章最后给出 GitHub 地址并鼓励读者尝试安装使用。

💡 主要观点

  1. 现有 agent 生图方案要么难以编辑，要么输出不稳定且丑陋。 直接让 agent 生成 HTML 或图片虽然效果好，但无法在画板上拖拽修改；让 agent 生成 draw.io 类图形图形图则线条混乱、美感差，导致使用体验 poor。
  2. AgentDraw 通过设计语言约束和 SVG 首先的方式提高输出稳定性和可编辑性。 设计语言把间距、颜色、交互等可结构化的设计因素转化为规则，减少 agent 的随机抽卡；让 agent 生成 SVG 再渲染为画板数据，既能利用 agent 对 SVG 的熟悉，又保证输出可直接在浏览器中编辑。
  3. 内置 44 种设计主题，支持多种图表类型，生成后可在浏览器中自由编辑并导出 SVG/PNG。 主题涵盖正式商务、技术架构、复古手册、深色故障分析、活泼产品等风格，用户无需懂设计即可得到统一好看的图；生成的画板支持文字、方框、连线、布局的手动调整，满足文档、PPT、项目汇报等场景需求。
  4. 提供校验、测试与评估机制，让 agent 能自动判断输出质量并进行优化。 当 agent 的输出不符合预设要求时，系统会给出反馈，agent 可基于此进行自动改进，避免陷入无效的反复生成循环，提升整体生成效率和质量。

💬 文章金句

  • 让 agent 直接生图或者直接做 html ，输出很好，但很难编辑（让你拖拽加个元素就加不动）
  • 让 agent 直接去生成 draw.io 类似工具的图，输出非常不稳定，而且很丑，连线不知道连哪去了
  • 这次是真的想把 Agent 生图这件事做好，不是搞个噱头
  • 设计语言 [...] 只要我们能把这些能结构化的，可解释的东西能约束清楚，我们就能尽量减少 agent 抽卡的次数
  • svg first [...] 让 agent 去画 svg ，再渲染画板数据就可以保证输出的稳定同时，也能得到好的编辑效果。
  • 如果设计不是一个可测试与评估的事情，那么设计本身就没法被约束和被优化。agentDraw 提供了一套校验的能力，让 agent 知道自己的输出是否符合要求，是否能达到一定的质量。
