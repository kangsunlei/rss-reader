Compose 多平台 1.8.0 发布：iOS 版 Compose 多平台已稳定并达到生产就绪状态 | Kotlin 官方博客

5/6/2025, 4:41:20 PM

📌 一句话摘要

Compose 多平台 1.8.0 为 iOS 带来了稳定且生产就绪的 UI 框架，通过 Kotlin 多平台实现 Android 与 iOS 间高效的代码共享。

📝 详细摘要

本文宣布 Compose 多平台 1.8.0 正式发布，标志着 iOS 版 Compose 进入稳定版本并具备生产就绪性能（应用体积仅增加 9MB）。文章重点介绍了与 Jetpack Compose 的功能对等性、类型安全的路由导航、无障碍支持以及达到原生 SwiftUI 级别的性能（96%的团队报告无性能问题）。该版本包含增强的 SwiftUI/UIKit 互操作、热重载等开发工具，并展示了平台间共享 96%代码的实际应用案例。文章还提到了 Web 开发方面的进展，包括改进的导航和资源预加载 API。

💡 主要观点

  1. Compose 多平台 1.8.0 带来稳定的 iOS 支持 该版本标志着 Kotlin 多平台在 iOS 开发中达到生产就绪状态，支持跨平台 UI 代码共享，相比原生应用体积仅增加 9MB。
  2. 实现与 Jetpack Compose 的功能对等性 包含类型安全的路由导航、无障碍支持和资源管理功能，与 Android 的 Jetpack Compose 相当，96%的团队报告无性能问题。
  3. 增强与原生 iOS 框架的互操作 改进的 SwiftUI/UIKit 互操作允许逐步采用并将 Compose 与原生视图混合使用，实际应用案例展示平台间共享 96%代码。
  4. 开发工具提升生产力 热重载和即将推出的 IDE 插件改善了开发体验，Compose 预览功能即将支持通用代码。
  5. 不断增长的生态系统支持 官方 Kotlin 多平台库目录(klibs.io)和采用多平台能力的 Jetpack 库为生产应用提供了坚实基础。

💬 文章金句

  • 通过此次更新，Kotlin 多平台成为移动开发的完整解决方案，可在不牺牲应用质量或失去平台特定能力控制权的情况下，实现业务逻辑和 UI 的灵活代码共享。
  • iOS 版 Compose 多平台现已包含构建真实应用精美 UI 所需的一切功能。
  • 所有主要 API 现已正式稳定，提供强有力的兼容性承诺，未来预计只有极少数不兼容变更。
  • 根据我们最新的调查，超过 96%在 iOS 上使用 Compose 多平台的团队报告没有重大性能问题。
  • Compose 热重载功能现已可用。它允许您修改 UI 代码并立即查看结果，无需重启应用或丢失当前状态。
