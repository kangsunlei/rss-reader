Postman 不经许可安装 AI 插件并绕过用户授权

11/4/2026, 2:01:19 AM

📌 一句话摘要

作者指责 Postman 在未获用户授权的情况下自动安装 Codex 与 Claude Code 插件，并设置自动信任的 hook 机制，同时安装 CLI 并配置 MCP。

💡 主要观点

  1. Postman 自动安装 AI 插件而不获用户许可 这种行为侵犯用户隐私与控制权，属于严重的安全与伦理问题，可能导致恶意行为的扩展。
  2. 自动启用 trusted hook 绕过用户同意 hook 机制若可被隐蔽设为 trusted，可能赋予 AI Agent 在 API 任务中自动调用能力，形成潜在的权限滥用风险。
  3. 同步安装 Postman CLI 并配置 MCP 进一步扩大了自动化与集成的边界，也暗示出于完整生态系统控制的潜在动机。

💬 文章金句

  • Postman 在未经用户许可的情况下安装 Codex 和 Claude Code 的插件
  • 还绕过用户自动将这个 hook 的状态改成 trusted
  • 这软件太恶心了 从一个插件发展到越来越恶心
