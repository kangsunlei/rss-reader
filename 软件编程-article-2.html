Vercel 推出 x402-mcp：为 MCP 工具带来开放协议支付

9/12/2025, 1:00:00 PM

📌 一句话摘要

Vercel 引入了 `x402-mcp`，它是开放的 x402 协议的集成，支持在 HTTP 请求中直接为访问外部服务的 AI 代理进行程序化、免账户支付。

📝 详细摘要

本文介绍了 Vercel 的一项新集成 `x402-mcp`，用于开放的 x402 协议，旨在解决 AI 代理与付费外部服务交互的程序化支付挑战。传统上，由于需要手动设置、密钥管理以及为每个 API 单独计费，AI 代理面临诸多限制。x402 协议通过将支付请求直接嵌入到 HTTP 中，并利用 402 Payment Required 状态代码来实现无需事先注册账户即可进行支付，从而解决了这个问题。Vercel 的 `x402-mcp` 专门将此功能与模型上下文协议 (MCP) 服务器和 Vercel AI SDK 集成，从而简化了开发人员的流程。本文提供了清晰的代码示例，用于保护 API 路由并在 MCP 中定义付费工具，演示了客户端如何轻松包装 fetch 请求来处理付款。x402 协议在标准 HTTP 交换上运行，支持各种支付网络，但当前的实现通常使用 Base 区块链上的 USDC 来实现快速、免账户的交易。提供了一个入门模板，展示了与 Next.js、AI SDK、AI Elements 和 AI Gateway 的集成，使其对于希望在其 AI 应用程序中实施程序化支付的开发人员来说非常实用。

💡 主要观点

  1. x402 协议支持 AI 代理直接通过 HTTP 请求进行程序化、免账户支付。 通过利用 HTTP 402 状态代码，x402 允许 API 动态请求支付，从而无需预注册、密钥管理和单独计费，这对于自主 AI 代理至关重要。
  2. Vercel 的 `x402-mcp` 将 x402 与 Vercel AI SDK 和模型上下文协议 (MCP) 服务器集成。 此集成简化了开发人员定义付费 API 路由和 MCP 工具的流程，从而允许 AI 代理授权和进行支付，作为其与外部服务的标准交互流程的一部分。
  3. 该协议是开放的，与支付网络无关，目前支持 Base 区块链上的快速、一次性支付。 x402 的开放性确保了灵活性，支持各种货币和方案，包括非加密选项，而其当前在 Base 区块链上的实现提供了高效、免账户的交易。

💬 文章金句

  • AI 代理在处理复杂任务的能力不断提升，但当需要访问付费外部服务时，仍然面临一个长期存在的限制。
  • x402 是一个开放协议，通过将支付直接添加到 HTTP 请求中来解决此问题。它使用 402 Payment Required 状态代码，以允许任何 API 端点请求付款，而无需事先设置帐户。
  • 我们构建了 `x402-mcp`，以将 x402 支付与模型上下文协议 (MCP) 服务器和 Vercel AI SDK 集成。
  • 与特定于供应商的支付 API 不同，x402 被设计为开放的 Web 协议。它不与任何集中式支付提供商绑定，并且可以支持不同的支付网络或方案。
  • 目前，大多数实现都采用 Base 区块链上的 USDC 进行精确的单次结算，从而实现快速且免账户的交易。
