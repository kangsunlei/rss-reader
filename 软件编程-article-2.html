开启 MPS 2025.1 早期访问计划 | MPS 博客

3/31/2025, 5:08:48 PM

📌 一句话摘要

MPS 2025.1 EAP 版本发布，主要在项目视图性能提升、支持创建无 generator 语言、增强事务属性单元格以及支持构建语言作为生成目标等方面进行了功能扩展。

📝 详细摘要

JetBrains 发布 MPS 2025.1 早期访问计划 (EAP) 版本。此版本主要关注于优化用户体验和扩展语言生成能力。项目视图的导航性能得到显著提升，允许创建不带 generator 的语言项目，增强了事务属性单元格的功能，并支持将构建语言作为生成目标。此外，该版本还修复了大量 bug，提高了系统的稳定性和可靠性。鼓励用户下载并试用新版本，提供反馈。

💡 主要观点

  1. 构建语言作为生成目标扩展了语言生成能力 现在可以将构建语言作为生成目标，为用户扩展 MPS 中的构建语言或创建替代方案提供了可能性。
  2. 项目视图性能优化显著提升了导航效率 通过修复 MPS-38299 和 MPS-37938，大幅提高了在逻辑项目视图中的导航速度，优化了用户体验。
  3. 支持创建无 generator 语言简化了项目创建流程 新建项目向导允许创建不包含 generator 的语言，避免了手动删除 generator 的步骤，简化了项目初始化流程。

💬 文章金句

  • Today we're starting the EAP for MPS 2025.1. The first EAP build is now ready for you to download and try!
  • The *New Project wizard* now allows users to create a language without an empty generator.
  • Based on a request from one of our customers， we smoothed the build language so that it can now be used as a target for generation.
