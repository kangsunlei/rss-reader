Pogocache：具有低延迟和多种网络协议的开源缓存软件

8/31/2025, 10:20:00 AM

📌 一句话摘要

Pogocache，一种新的基于 C 的开源缓存软件，通过支持多种网络协议和提供嵌入式集成来实现低延迟和高 CPU 效率，将其定位为一款高性能的缓存解决方案。

📝 详细摘要

本文介绍了 Pogocache，这是一款由 Tile38 的创建者 Josh Baker 最近发布的 AGPLv3 许可的开源缓存软件。Pogocache 用 C 语言编写，优先考虑低延迟和 CPU 效率，声称与 Memcache、Valkey/Redis、Dragonfly 和 Garnet 等已建立的缓存解决方案相比，具有更高的吞吐量和响应时间。一个关键特性是它支持多种网络协议 —— Memcache、Valkey/Redis、HTTP 和 PostgreSQL —— 允许与各种客户端库和系统工具无缝集成，而无需管理多个端口。Pogocache 可以作为服务器运行，也可以直接嵌入到应用程序中，嵌入时提供每秒超过 1 亿次的操作。它的设计包含一个具有高扇出（例如，4096 个分片）的分片哈希表，灵感来自作者的 `shardmap` 项目，并优化了线程处理。常见的用例包括会话存储、数据库查询缓存、实时数据馈送和 API 加速。虽然 Hacker News 上最初的社区反馈大多是积极的，但有些人希望了解更多设计细节，并希望对性能声明进行独立验证。该项目的路线图包括特定领域的集成和企业工具，1.1 版本已经增加了自动过期密钥清理功能。

💡 主要观点

  1. Pogocache 提供卓越的性能，具有极低的延迟和高 CPU 效率。 该软件针对低资源竞争和良好的内存局部性进行了优化，声称在响应时间和跨多个内核的可扩展性方面优于 Memcache、Redis 等。
  2. 它支持多种流行的网络协议，并且可以直接嵌入到应用程序中以实现最大速度。 通过模拟 Memcache、Redis、HTTP 和 PostgreSQL API，它简化了集成。嵌入 `pogocache.c` 文件绕过了网络开销，实现了每秒超过 1 亿次的操作。
  3. Pogocache 具有分片哈希表设计，并具有雄心勃勃的未来增强功能路线图。 它的核心设计使用具有许多独立分片的分片哈希表，灵感来自 `shardmap`。该路线图包括特定领域的集成和企业级功能，如分布式路由。

💬 文章金句

  • Pogocache 比 Memcache、Valkey、Redis、Dragonfly 和 Garnet 更快。它具有每个请求的最低延迟，提供最快的响应时间。
  • 无需将 Pogocache 作为基于服务器的程序运行，可以将独立的 pogocache.c 文件编译到现有软件中，绕过网络并以编程方式直接访问缓存。运行嵌入式提供原始速度，每秒超过 1 亿次操作。
  • 除了性能之外，Pogocache 最有趣的地方在于它提供的服务器接口：它模拟了 Redis 和 Memcached 的 API，提供了一个简单的 HTTP API，并允许您通过 PostgreSQL 网络协议与它通信！
  • 虽然最初的发布和性能声明无疑令人兴奋，但 Pogocache 的真正考验还在后面。这些基准测试在各种生产工作负载下，在严格的独立审查下将如何保持？
