📝 详细摘要

文章报道了一款名为《牛来》（Ox Alpha，代号 stealth/ox-alpha）的匿名大模型突然在 OpenRouter 和 OpenCode 上线的消息。该模型疑似国产，可能是智谱未发布的 GLM-5.x 系列多模态升级版。其主要特性包括百万级上下文窗口、最大 13 万 token 输出、图片与视频输入支持，并专为高效 Coding、长时间 Agent 任务及生产力场景打造。社区实测显示，其在 DeepSWE 编码基准上取得了 80% 的通过率，远超同批的 Claude Fable 5（65%）、Grok 4.6（62%）及 GPT-5.6-sol（52%）。文章提及该模型目前可在 OpenRouter 免费调用，OpenCode Zen 免费计划中也已上线，免费窗口约一周，官方表示零数据保留。文章末邀请读者猜测该模型所属公司并分享使用体验。

💡 主要观点

  1. 神秘模型 Ox Alpha 突然在 OpenRouter 和 OpenCode 上线。 该模型代号为 stealth/ox-alpha，命名寓意为“牛来”，疑似国产匿名模型，可能是智谱未发布的 GLM-5.x 系列多模态升级版。
  2. Ox Alpha 拥有强大的多模态与长上下文能力。 支持百万上下文窗口、最大 13 万 token 输出，并可处理图片与视频输入，专为高效 Coding、长时间 Agent 任务及生产力场景设计。
  3. 社区实测其编码能力位于第一梯队。 在 DeepSWE 编码基准上取得 80% 通过率，显著高于同批的 Claude Fable 5、Grok 4.6 和 GPT-5.6-sol。
  4. 目前 Ox Alpha 可免费使用，窗口期约一周。 可在 OpenRouter 免费调用，OpenCode Zen 免费计划中也已上线，官方表示零数据保留，但提醒用户注意敏感信息。

💬 文章金句

  • 这款神秘模型很大概率是国产的，因为之前智谱、小米、美团、蚂蚁百灵，都有「先发布匿名模型再公布」的案例。
  • 牛来模型的能力也很牛，一百万上下文窗口、最大输出 13 万 token，不仅支持读取图片，甚至还支持视频输入。
  • 社区实测方面，在 DeepSWE 编码基准的小样本测试中，Ox Alpha 拿到了 80% 的通过率，同批题目 Claude Fable 5 是 65%、Grok 4.6 是 62%、GPT-5.6-sol 是 52%。
  • 目前社区证据指向智谱。独立研究者 Ben Davis 表示他 99% 确信 Ox Alpha 属于 GLM-5.x 系列，理由是视频编码器的 token 消耗模式与 GLM-5V-Turbo 完全一致、Tokenizer 指纹也与 GLM-5.3 吻合。
