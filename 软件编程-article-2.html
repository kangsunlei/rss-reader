CVE-2025-49826 - Vercel

7/3/2025, 1:00:00 PM

📌 一句话摘要

Vercel 修复了 Next.js 15.1.0-15.1.8 版本中的缓存污染漏洞 (CVE-2025-49826)，该漏洞可能导致 HTTP 204 响应被缓存从而引发拒绝服务攻击 (DoS)，但使用 Vercel 托管服务的客户不受影响。

📝 详细摘要

Vercel 已修复 Next.js 15.1.0 至 15.1.8 版本中的安全漏洞 (CVE-2025-49826)，对 Vercel 托管客户无影响。该漏洞涉及缓存污染问题，静态页面的 HTTP 204 响应可能被缓存并返回给所有访问该页面的用户，导致拒绝服务 (DoS)。漏洞利用需要特定攻击条件：使用受影响 Next.js 版本、在 ISR 模式下配置了缓存重新验证的路由（通过 `next start` 或独立模式运行）、以及配置了缓存 HTTP 204 响应的 CDN。修复方案移除了导致 HTTP 204 响应的有问题的代码路径，并通过不再依赖共享响应对象来填充 Next.js 响应缓存，从而消除了竞态条件。安全研究人员 Allam Rachid 和 Allam Yasser 因通过合规渠道披露漏洞而获得致谢。

💡 主要观点

  1. Next.js HTTP 204 响应缓存漏洞可能导致拒绝服务 Next.js 15.1.0-15.1.8 版本中的漏洞允许 HTTP 204 响应被错误缓存并返回给所有访问受影响静态页面的用户，导致系统进入拒绝服务 (DoS) 状态。
  2. 漏洞利用需要特定攻击条件 漏洞利用需要：受影响的 Next.js 版本、ISR 模式下配置缓存重新验证（通过 `next start` 或独立模式）、以及 CDN 缓存 HTTP 204 响应——展示了精确的攻击面。
  3. 全面修复同时解决了根本原因和竞态条件 解决方案包括消除 HTTP 204 响应代码路径和移除共享响应对象依赖，显示了对缓存机制的深入技术理解。
  4. 对 Vercel 托管客户无影响 该漏洞仅影响非 Vercel 托管配置，凸显了平台安全优势。
  5. 致谢通过合规渠道披露漏洞的研究人员 安全研究人员 Allam Rachid 和 Allam Yasser 得到了适当认可，展示了良好的安全实践透明度。

💬 文章金句

  • Next.js 中的一个漏洞已被修复。该漏洞影响版本 `>=15.1.0 <15.1.8`，涉及导致拒绝服务 (DoS) 的缓存污染问题。
  • 此问题不影响使用 Vercel 托管的客户。
  • 在特定条件下，该问题可能允许静态页面的 HTTP 204 响应被缓存，导致所有尝试访问该页面的用户均会收到 HTTP 204 响应。
  • 该问题通过移除可能导致 HTTP 204 响应的有问题的代码路径得到解决。
  • 此外，我们通过不再依赖共享响应对象来填充 Next.js 响应缓存，消除了可能导致此缓存污染的竞态条件。
