Vercel Fluid 计算推出活跃 CPU 定价

6/25/2025, 1:00:00 PM

📌 一句话摘要

Vercel 为 Fluid 计算推出了活跃 CPU 定价，仅根据代码的活跃 CPU 使用时间收费。

📝 详细摘要

Vercel 宣布其 Fluid 计算平台将采用活跃 CPU 定价，该平台专为 AI 推理等 I/O 密集型工作负载设计。文章解释了从传统服务器到无服务器再到 Fluid 计算的演变过程，强调了 Fluid 如何通过跨并发请求共享资源来优化资源。新的定价模型提高了效率，除了预置内存和调用次数外，还会专门为代码活跃使用 CPU 的时间计费。这一转变旨在使成本更紧密地与实际工作负载的计算消耗保持一致，而非仅仅基于函数生命周期，这可能为 Vercel Functions 和 Sandbox 的用户带来显著的成本节约。

💡 主要观点

  1. Fluid 计算通过跨并发请求共享资源，高效处理现代 I/O 密集型工作负载。 Fluid 计算通过跨调用编排计算，克服了无服务器的局限性，例如冷启动和资源利用不足，从而为 AI 推理和类似任务实现了更好的资源复用。
  2. 新的活跃 CPU 定价仅对代码的活跃 CPU 使用时间计费。 这种创新的定价模型区分了函数驻留在内存中和活跃使用 CPU 的时间，显著降低了工作负载在等待外部资源时的空闲期成本。
  3. 该定价模型结合了活跃 CPU、预置内存和调用次数，实现了细粒度计费。 通过将成本分解为这些组成部分，Vercel 旨在创建一个透明的模型，直接反映现代应用程序生命周期中不同部分消耗的资源。

💬 文章金句

  • 这些工作负载是长时间运行的、不可预测的，并以新的方式使用云资源。
  • Fluid 计算突破了传统的一对一无服务器模型。Fluid 计算并非为每次调用启动一个单独的实例，而是智能地跨调用编排计算资源。
  • 活跃 CPU 定价解决了这个问题。这是一种新的定价模型，仅根据您的代码活跃使用 CPU 的时间进行收费。
  • 这使得定价与实际使用量保持一致。计算成本与实际工作量成正比，而非仅仅与函数活跃的时间成正比。
