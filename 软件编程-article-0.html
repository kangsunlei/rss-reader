Visual Studio 代理模式现开放预览

5/13/2025, 5:26:51 PM

📌 一句话摘要

Visual Studio 推出代理模式预览版，通过集成 MCP 服务器实现 AI 驱动的自主循环编码任务。

📝 详细摘要

本文宣布 Visual Studio 17.14 中代理模式(Agent Mode)的公测版发布。该模式显著增强 GitHub Copilot 功能，使其能自主规划代码编辑、通过 MCP 服务器调取工具，并以持续迭代方式完成任务。代理模式可自动识别相关上下文、推荐终端命令、执行构建/测试，并通过模型上下文协议(Model Context Protocol， MCP)服务器扩展工具支持范围。文章详细说明了如何启用代理模式，列举了其可执行的复杂任务案例，并提供了使用自定义设置优化体验的技巧。特别强调了与 MCP 服务器的集成这一关键创新，实现了与云环境、数据库和版本控制平台的无缝交互。同时宣布 Visual Studio 将采用每月更新机制，确保开发者能持续获取 Copilot 的最新功能。

💡 主要观点

  1. 代理模式支持自主循环完成任务 与标准 Copilot 功能不同，代理模式会循环处理任务直至完成，自主执行代码编辑、工具调取和验证，并具备自修正能力。
  2. MCP 服务器显著扩展代理模式能力 模型上下文协议(MCP)服务器提供了对额外工具和数据源的标准化访问，无需定制开发即可实现与云环境、数据库和版本控制平台的无缝对接。
  3. 自定义设置和上下文提升代理模式准确性 通过自定义设置提供编码标准和团队偏好的详细上下文，可大幅提升代理模式在团队协作环境中的输出质量。
  4. 每月更新确保持续功能优化 Copilot 的月度更新机制确保开发者能持续获取 Visual Studio 中最新的 AI 驱动开发功能。

💬 文章金句

  • Visual Studio 的代理模式允许使用自然语言定义任务，Copilot 将自主规划、修改代码库、启用工具并通过循环执行解决问题。
  • 代理模式的突出特点是能评估代码修改结果，并通过多次循环执行解决中间过程问题。
  • MCP 让 AI 应用无需为每个数据源单独开发连接器，即可对接各类数据和工具。
  • 为 Copilot 提供充分的上下文信息（包括编码标准、团队偏好和常用库等）是获得更精准响应的关键。
