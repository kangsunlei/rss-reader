专为 Agent 而生的终端神器，开源了！

6/23/2026, 11:05:00 AM

📌 一句话摘要

本文介绍专为 AI Agent 设计的开源终端复用工具 rmux，支持多 Agent 协调、代码驱动终端及跨平台安装，兼容 tmux 命令。

📝 详细摘要

文章从 tmux 在 Agent 场景下的不足出发，引出用 Rust 从头构建的终端复用工具 rmux。其核心特点包括：支持多 Agent 协调（如 Claude Code 指挥 Codex、Gemini CLI）、提供命令行/Rust SDK/浏览器共享三种对等入口、兼容 90 多条 tmux 命令及配置文件。作者将其与 Playwright 类比，强调 rmux 可像 API 一样驱动终端。此外还介绍了跨平台安装方式（brew、apt、cargo 等）和 Web Share 功能。文章最后指出 rmux 虽刚开源可能有 Bug，但代表了终端自动化的新方向。

💡 主要观点

  1. rmux 专为 AI Agent 的终端自动化场景设计。 相比传统 tmux，rmux 提供程序化接口（命令行/SDK/浏览器），让 Agent 可以像操作 API 一样精确控制终端，实现多 Agent 协调任务编排。
  2. rmux 兼容 tmux 命令和配置，迁移成本极低。 支持 90 多条 tmux 命令，可直接沿用 tmux.conf 配置文件和常见插件脚本，原有用户可无缝切换。
  3. 三种对等入口让终端控制更灵活。 命令行、Rust SDK、浏览器共享三种方式均可驱动同一个守护进程，实现本地执行与远程共享分离，类似 Playwright 控制浏览器的思路。
  4. 跨平台支持且安装简单。 原生支持 Windows、macOS 和 Linux，一行 curl 或通过 brew/apt/cargo 即可安装，无需 WSL。
