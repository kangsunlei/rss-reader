美团正式发布 CatPaw：全场景 AI Agent，从个人提效到企业智能化

7/28/2026, 2:02:04 PM

📌 一句话摘要

美团发布基于 LongCat 2.0 的全场景 AI Agent 平台 CatPaw，支持跨端协作、本地生活场景深度集成及企业级 Agent 托管。

📝 详细摘要

美团技术团队宣布基于其开源的 LongCat 2.0 大模型（1.6T 参数，平均激活约 48B，动态范围 33B‑56B，支持 1M 超长上下文）推出全场景 AI Agent 平台 CatPaw。该平台提供移动端 App、PC 客户端和云端三种形态，实现全时段多端协作；深度融合美团在本地生活领域的行业知识，提供即装即用的专家与技能，覆盖门店评价、文案生成、营销物料设计、活动策划、经营数据分析等场景。CatPaw 支持一键安装 AI 专家、跨会话长期记忆、多 Agent 自主协同以及企业级 Managed Agents，具备沙箱隔离、凭证集中托管、按需弹性伸缩和全链路可观测等安全与运维能力。目前已在美团内部覆盖 9 万员工、搭建 3 万 Agent，并在多个真实业务场景中完成验证，面向企业提供数字员工、扫码即用及按需定制的 AI 助手服务。

💡 主要观点

  1. CatPaw 基于 LongCat 2.0 大模型，提供 1.6T 参数、平均激活约 48B、支持 1M 超长上下文的强大基础模型。 该模型是在五万张国产算力卡上完成全流程训练与推理的万亿参数模型，为后续 Agent 能力提供坚实基础。
  2. 平台提供移动端 App、PC 客户端和云端三种形态，实现全时段多端协作和 7×24 小时不间断运行。 移动端支持随时发起任务与查看进度，PC 端专注深度执行，云端确保任务在本地设备离线时仍可继续。
  3. 深度融合美团本地生活领域知识，内置即装即用的专家与技能，覆盖门店评价、文案生成、营销物料设计、活动策划、经营数据分析等场景。 通过将行业经验封装为可直接调用的技能，使 AI Agent 能够快速理解并协助本地生活业务的具体操作。
  4. 支持多 Agent 自主协同和企业级 Managed Agents，提供沙箱隔离、凭证集中托管、按需弹性伸缩和全链路可观测的安全运维能力。 用户只需描述目标，系统自动拆解任务并调度多个具备专属工具的 Agent 并发执行，结果自动汇总；企业可通过托管平台快速构建、部署和管理专属数字员工。

💬 文章金句

  • 大模型 1.6T，平均激活约 48B，动态范围 33B 到 56B，原生支持 1M 超长上下文。
  • 提供独立的移动端 App 与 PC 客户端，双端任务实时同步、无缝协作。
  • 只需明确最终目标，Agent 便会自主规划步骤并在授权范围内深度执行：读取文件、操作浏览器、运行终端命令，直接交付 Excel、可视化报告或代码等可用成果。
  • Agent 运行环境严格隔离，租户间数据互不可见。凭证集中托管，确保 Agent 全程零接触敏感资产。
  • 猫爪将持续深入行业场景，让 AI Agent 真正成为驱动经营增长的数字化伙伴。
