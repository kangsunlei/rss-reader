用 bagidea-office 将 Claude Code Agent 变成桌面壁纸像素小人

7/15/2026, 12:00:05 AM

📌 一句话摘要

介绍一个开源工具 bagidea-office，可将 Claude Code Agent 可视化为桌面壁纸上的像素小人，支持多模型切换和语音，提升任务管理直观性。

📝 详细摘要

推文作者分享使用 bagidea-office 开源项目的体验：将 Claude Code 后台 Agent 转化为 Windows 桌面壁纸中的像素小人，小人能自主走向工位、触发安检、开会讨论、提交方案供审批，还支持灵活的模型切换（Claude、DeepSeek、Qwen、GLM、OpenAI 等十几种）和语音功能，只需一行命令安装。
