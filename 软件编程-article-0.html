📝 详细摘要

本课程由经验丰富的数学教授 Ed Pratowski 主讲，通过 Python 编程实践，系统讲解大学微积分的核心概念。课程从极限的基础概念开始，逐步深入到导数规则、斜率解释以及金融建模和抛物运动等实际应用。同时，课程还涵盖了重要的定理，如罗尔定理和中值定理，以及积分微积分的主题，如黎曼和、微积分基本定理和使用旋转体计算体积。此外，还将学习如何应用 SymPy 等符号数学库进行绘图和计算。通过编写导数代码、绘制图形和以编程方式计算积分，加深对数学的理解，并获得数学编程的实践技能，这对于数据科学、工程和技术职业来说是宝贵的财富。本课程适合对微积分和 Python 编程有一定基础，并希望结合两者解决实际问题的学习者。

💡 主要观点

  1. 通过 Python 编程实践，加深对微积分概念的理解 通过编写代码实现微积分中的各种概念，例如导数、积分等，可以更直观地理解其数学原理和应用。
  2. 将微积分应用于实际问题，例如金融建模和抛物运动 通过实际案例，展示微积分在解决现实世界问题中的应用，帮助学习者更好地理解微积分的价值。
  3. 使用 SymPy 等符号数学库，简化微积分计算和绘图 SymPy 等库可以帮助学习者更方便地进行微积分计算和绘图，从而更专注于理解微积分的概念和应用。
