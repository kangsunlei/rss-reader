GitHub Copilot 为 Claude Opus 4.6 推出快速模式

2/7/2026, 10:13:58 PM

📌 一句话摘要

GitHub Copilot Pro+ 用户现在可以在研究预览中体验 Anthropic Claude Opus 4.6 的“快速模式”，其 Token 生成速度提升了 2.5 倍。

📝 详细摘要

GitHub 在 GitHub Copilot Pro+ 中推出了 Anthropic Claude Opus 4.6 的“快速模式”研究预览版。此次更新旨在提供 2.5 倍的 Token 生成速度，同时保持模型原有的尖端智能水平。该功能目前处于实验阶段，用户可以在 VS Code 或 Copilot CLI 中进行测试。在 2 月 16 日之前，高级请求将提供促销定价，方便开发者体验高性能的 AI 编程辅助。
