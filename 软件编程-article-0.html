让 Al Agent 看懂所有文档：将任何文档转换为统一的 Markdown 格式

8/18/2026, 4:44:13 PM

📌 一句话摘要

Firecrawl 开源 PDF Inspector 和 AnyDoc，通过结构化分析和统一输出，把各种文档转换为 AI 友好的 Markdown 格式。

📝 详细摘要

Firecrawl 最近开源了两个项目：PDF Inspector 和 AnyDoc。PDF Inspector 是一个用 Rust 编写的 PDF 分析库，它会先判断 PDF 内部结构——对含真实文字层的页面直接解析，对扫描件、图片 PDF 或混合 PDF 采用本地 PP-OCRv6 模型进行 OCR，从而降低不必要的计算成本。AnyDoc 能处理 PDF、Word、Excel、PPT、EPUB、CSV 等多种格式，并将它们的表格、标题、脚注、链接等元素统一为一致的 Markdown 结构，支持粗体、斜体、删除线、代码块、列表等。两个项目均为纯本地工具，无需调用外部 API，适合需要频繁让 AI 处理各类文档的场景，能够提高处理效率、准确性并降低成本。

💡 主要观点

  1. PDF Inspector 先分析 PDF 内部结构，再根据内容类型选择直接解析或 OCR。 对包含真实文字层的页面直接解析；对扫描文档、图片 PDF 或混合 PDF 的图片部分使用本地 PP-OCRv6 模型进行 OCR，这样可以避免对纯文本页面进行不必要的 OCR，降低计算成本。
  2. AnyDoc 提供多格式文档的统一 Markdown 输出。 它能处理 PDF、Word、Excel、PPT、EPUB、CSV 等格式，并将表格、标题、脚注、链接等元素统一格式，确保粗体、斜体、删除线、代码块、列表等在不同来源的文档中保持一致的 Markdown 结构。
  3. 纯本地、无需 API 的特点让 AI Agent 处理文档更高效、更准确且更省钱。 因为项目完全在本地运行，不依赖外部服务，开发者可以直接集成到 AI 工作流中，快速把各类文档转为 LLM 可读的 Markdown，从而提升处理速度和准确性，同时避免第三方 API 费用。

💬 文章金句

  • 只要你经常需要让 AI 来处理各类文档，先用它来处理一遍，可以更高效、更准确，以及更省钱。
  • PDF Inspector 是一个 Rust 编写的 PDF 分析库。它不会直接把所有 PDF 扔给 OCR，而是先分析 PDF 内部结构。
