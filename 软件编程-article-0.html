[分享] 把 iPhone 的 AI 边缘流光效果带到了 Mac 上

6/18/2026, 4:35:16 PM

📌 一句话摘要

一个将 iPhone Apple Intelligence 边缘流光效果复刻到 Mac 上的小工具，通过 Agent Hooks 在 AI 思考时触发屏幕边缘动画。

📝 详细摘要

本文作者分享了一个名为 EdgeGlow 的 macOS 小工具，其核心功能是将 iPhone 上 Apple Intelligence 工作时屏幕边缘的虹彩流光效果带到 Mac 上。当 Claude Code 等 AI 工具思考时，屏幕边缘会显示旋转的渐变流光，完成后淡出。文章详细介绍了技术实现（纯 Swift + SwiftUI，使用 CAShapeLayer 和 CIGaussianBlur）、特性（5 种颜色主题、双模式动画、多显示器支持、低资源占用）、配置方式（通过 Agent Hooks）以及安全考虑（仅绑定本地地址）。项目以 MIT 协议开源。

💡 主要观点

  1. EdgeGlow 通过 Agent Hooks 监听 AI 工具状态，触发屏幕边缘动画。 工具利用 Claude Code 等 AI 工具的 Agent Hooks 机制，在 AI 开始思考时发送 HTTP 请求到本地服务器，触发屏幕边缘流光动画，完成后淡出。
  2. 技术实现轻量高效，纯 Swift + SwiftUI，无第三方依赖。 使用 CAShapeLayer 和 CIGaussianBlur 实现霓虹灯效果，Timer 驱动动画，NWListener 搭建本地 HTTP 服务器，资源占用极低（~0% CPU， ~50MB 内存）。
  3. 安全设计周到，HTTP 服务仅绑定本地地址。 服务仅监听 127.0.0.1，仅接受 GET 请求，无 CORS 头，不收集任何数据，确保不会被外部或网页 JS 滥用。

💬 文章金句

  • 纯 Swift + SwiftUI ，无第三方依赖
  • HTTP 服务仅绑定 127.0.0.1（`acceptLocalOnly`）
