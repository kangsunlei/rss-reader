工程师又替 AI 背锅？Cursor 限制多设备登陆引众怒，竞对趁机下场抢用户！

4/20/2025, 8:11:00 AM

📌 一句话摘要

Cursor 因 AI 客服乌龙事件导致用户流失，Augment Code 借机宣传其更强大的 AI 编码助手。

📝 详细摘要

AI 编码工具 Cursor 因限制多设备登录引发用户不满，AI 客服的错误回复加剧了用户流失。Augment Code 借机宣传其 AI 编码助手，该 AI 智能体具备强大的上下文处理能力，能够有效处理大型代码库，并提供实时同步的代码变更。Augment Code 成立于 2022 年，已累计融资 2.7 亿美元，体现了其巨大的市场潜力。

💡 主要观点

  1. Cursor 多设备登录限制及 AI 客服乌龙导致用户大量流失 Cursor 限制多设备登录，加上客服 AI 的错误回复，导致用户体验急剧下降，引发社区抗议和大量退订，损害了用户信任。
  2. Augment Code 借机推广其 AI 编码助手，并超越 GitHub Copilot Augment Code 通过宣传其在 SWE-bench 基准测试中超越 GitHub Copilot 的 AI 智能体技术，吸引了因 Cursor 事件而流失的用户，展示了其技术实力。
  3. Augment Agent 具备理解海量代码库上下文和实时同步代码变更的能力 Augment Agent 拥有可容纳 20 万 token 的上下文窗口，能够处理包含数百万行代码的大型系统，并实时同步代码变更，提升开发效率。
  4. AI 将在软件开发领域扮演更积极主动的角色 AI 不仅能辅助编码，还能深入评估代码质量并提出改进意见，从而提升软件项目的安全性、可靠性和易用性。

💬 文章金句

  • 我发现 Cursor 作为 IDE 的价值越来越低。它曾经一度领先，但似乎迷失了方向，陷入了困境。
  • 他们索取的太多，要求的太多，而给予的太少。我们的核心功能每天都在被剥夺。
  • AI 编码无疑是一个热门领域，但大多数探索都集中在所谓「从 0 到 1」或者叫「氛围编程」方面------即从头开始生成一款软件。但我们的目标是解决软件工程学科中的另一个常见难题，即维护大型复杂系统。
  • 某种程度上讲，选择 Cursor 的客户相当于退出了微软生态系统。他们无法使用微软提供的、用于访问其环境的所有标准 VS Code 插件。而我们则保持则与 VS Code 以及微软生态系统的 100% 兼容性。
  • 我们最终能够利用 AI 实现真正令人兴奋的目标，包括 AI 将深入评估代码库质量、提出代码库改进意见，生成有助于软件项目更加安全、强大、易用且健壮的宝贵建议。
