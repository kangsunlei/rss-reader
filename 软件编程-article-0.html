Iceberg v3：统一生态系统的新篇章

6/2/2025, 7:40:00 PM

📌 一句话摘要

Iceberg v3 引入删除向量和行血缘等高级功能，显著提升数据处理效率及生态系统的协同能力。

📝 详细摘要

Apache Iceberg v3 近期已获批准，为表格格式带来重要进展，包括引入新的删除向量、行血缘，并支持半结构化数据和地理空间类型。这些功能旨在解决 v2 版本中行级删除效率低下和增量处理复杂等问题。删除向量通过优化存储，并要求每个文件仅使用单个向量，从而提升读取性能。行血缘利用行 ID 和序列号简化增量工作流，有效跟踪提交中的变更。其重要优势在于，这些功能实现了 Delta Lake、Apache Parquet 和 Apache Spark 等技术之间的无缝互操作能力，使用户无需重写现有数据或删除文件即可充分利用 v3 的各项功能。这些改进共同致力于统一数据湖生态系统，并提高 ETL、数据摄取和查询的效率。

💡 主要观点

  1. Iceberg v3 通过新的删除向量格式提升行级删除性能。 删除向量优化了已删除行的存储和跟踪方式，与 v2 相比，显著降低了读取放大，进而加速了 ETL 和数据摄取流程。
  2. 行血缘通过跟踪提交中的行变更来简化增量处理。 行血缘利用行 ID 和序列号，使引擎能够高效识别并处理变更行，从而以更低成本实现下游更新，如物化视图。
  3. Iceberg v3 功能可促进主要数据湖技术之间的互操作性。 新功能和格式在 Delta Lake、Parquet 和 Spark 中保持一致，确保用户无需重写数据或删除文件，即可在 Delta Lake、Parquet 和 Spark 中无缝衔接。

💬 文章金句

  • Iceberg v3 包括重大改进，例如删除向量、行血缘以及用于半结构化数据和地理空间用例的新类型。
  • 这种新格式避免了 Parquet 文件与内存中删除操作表示之间的转换。
  • 借助行血缘，引擎可以通过匹配跨提交的行版本来查找行级更改。
  • 当与物化视图等增量处理对象结合使用时，行 ID 信息尤其有用。
