我开发了 skills 管理工具， skills++

6/14/2026, 5:27:57 PM

📌 一句话摘要

本文介绍了一款名为 skills++ 的桌面工具，用于聚合、管理和一键安装多种 AI 编程工具的 skill 文件，解决多工具间 skill 管理碎片化的问题。

📝 详细摘要

文章作者因 Claude Code、Codex 等 AI 编程工具各自拥有独立的 skill 目录，导致安装和管理不便，于是开发了 skills++ 桌面应用。该工具从 skills.sh、LobeHub 等多个来源聚合 skills，能自动识别本机安装的 AI 工具（如 Codex、Claude、Cursor 等 10+ 种），并提供一键安装、卸载、重装功能。它支持 git 克隆、文件拷贝、解压、软链接四种安装策略，并默认自动选择最合适的方式。文章展示了工具的多张截图，并说明了技术栈为 Tauri 2.x + React 19 + TypeScript + Tailwind CSS v4 + SQLite。

💡 主要观点

  1. skills++ 解决了多 AI 编程工具间 skill 管理碎片化的问题。 不同 AI 工具（如 Claude Code、Codex）各有独立的 skill 目录，用户需重复安装或手动管理。该工具通过统一聚合和自动识别，实现一键管理。
  2. 工具支持多种安装策略并自动选择最优方案。 提供 git 克隆、文件拷贝、解压、软链接四种方式，默认自动选择最合适的，用户也可手动指定，兼顾了灵活性与易用性。
  3. 技术栈成熟，界面功能完整。 采用 Tauri 2.x + React 19 + TypeScript 构建，支持浅色/深色主题、搜索筛选、版本检测等功能，表明项目已具备一定的完成度。

💬 文章金句

  • 它从 skills sh 、LobeHub 等地方聚合 skills ，自动识别你本机装了哪些 AI 工具，然后就能一键安装/卸载/重装 skills 。
