GPT-4o 代码补全模型在 VS Code Copilot 公开预览

3/23/2025, 12:00:00 AM

📌 一句话摘要

GitHub Copilot 推出基于 GPT-4o 的代码补全模型，显著提升 VS Code 代码建议的准确性和效率，未来还将支持 JetBrains IDEs。

📝 详细摘要

GitHub Copilot 推出了基于 GPT-4o 的代码补全模型，该模型在超过 275，000 个高质量公共代码仓库上进行了训练，支持 30 多种编程语言。与之前的版本相比，GPT-4o Copilot 模型能够提供更准确、更符合上下文的代码建议，从而提高开发者的生产力。Copilot Business 和 Enterprise 用户需要先启用“预览功能”才能使用该模型。用户可以在 VS Code 和 JetBrains IDEs 中轻松选择 GPT-4o 模型。此外，GitHub Copilot 还推出了 Next Edit Suggestions 功能，可以预测和建议代码中的逻辑修改。鼓励用户提供反馈以持续改进 GPT-4o 模型。

💡 主要观点

  1. GPT-4o Copilot 模型通过大量高质量代码训练，显著提升代码建议的准确性和上下文相关性。 GPT-4o 模型基于超过 275，000 个公共代码仓库进行训练，支持 30 多种编程语言，能够提供更精确和符合上下文的代码建议。
  2. Copilot 仍然有待改进的地方：缺少 Prompt caching 和 local model。 根据 Johan Sanneblad 的观点，Copilot 缺少用于提升性能的 Prompt caching 和用于代码合并的 local model 这两个主要功能。
  3. Next Edit Suggestions 功能可以预测和建议代码中的逻辑修改，简化编辑流程。 该功能可以识别整个文件中的潜在修改，提供插入、删除和替换建议，帮助开发者节省大量时间。
  4. 用户反馈对于改进 GPT-4o Copilot 模型至关重要。 开发者可以通过分享使用体验，帮助改进模型的性能和可用性，从而使所有 Copilot 用户受益。

💬 文章金句

  • GitHub Copilot is quickly catching up to Cursor IDE which is already packed with custom models.
  • From what I can see there are just two main features missing in Copilot: Prompt caching for performance and a local model for code merging.
  • We finally have a good code completion model with good support for C++， C# and Java.
