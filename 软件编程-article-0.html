Node.js：停止使用 EOL 版本，立即升级！

6/15/2025, 12:00:00 PM

📌 一句话摘要

警告：Node.js 18 EOL 存在严重安全风险！建议立即升级到 Node.js 22。

📝 详细摘要

这篇 Node.js 官方博客文章强调了使用生命周期结束 (EOL) 的 Node.js 版本所带来的严重安全风险，特别关注 Node.js 18 及更早版本。文章解释说，这些版本不再收到安全补丁，使应用程序面临已知的安全漏洞风险。下载统计显示，仍有约 30% 的社区用户在使用这些不受支持的版本。文章强烈建议直接升级到 Node.js 22，跳过 Node.js 20，因为 Node.js 22 具有更长的支持窗口（截止到 2027 年 4 月）、更好的性能和新功能，有助于减少频繁升级带来的负担。对于无法立即升级的组织，HeroDevs 提供的 Never-Ending Support 等商业支持选项可以作为临时解决方案，但升级到积极支持的版本仍应是首要目标。

💡 主要观点

  1. Node.js 18 及更早版本已达到 EOL，存在重大安全风险。 不受支持的 Node.js 版本不再收到安全补丁，这使应用程序面临已知漏洞利用的风险。近期发布的咨询报告已经证实了这一点。
  2. 开发者应直接升级到 Node.js 22，跳过 20。 Node.js 22 提供更长的 LTS 窗口（截止到 2027 年 4 月），包含最新的功能和性能提升，并有助于避免更频繁的升级周期。
  3. 数百万次的下载量表明大量应用仍面临 EOL 版本的安全威胁！ 尽管存在风险，但大量 Node.js 社区用户仍在使用不受支持的版本，这突显了潜在的广泛安全问题。
  4. 对于需要时间进行升级的组织，可以获得商业支持。 HeroDevs 等供应商为 EOL 版本提供临时的 Never-Ending Support，在组织计划迁移到 Node.js 22 时提供安全补丁和帮助。

💬 文章金句

  • Node.js 18 及所有更早版本都已达到生命周期结束 (EOL)。它们现在完全不受支持，意味着它们不会收到任何更新，包括安全补丁。
  • 当发生安全发布时，EOL 版本总是会受到影响，这意味着 Node.js 18 及所有更早版本都存在相同的漏洞，但永远不会收到补丁。
  • 根据下载统计数据，Node.js v18 仍然每月有大约 5000 万次下载，而遗留版本（v16 及更低版本）继续每月有数千万次下载。
  • 虽然 Node.js 20 目前是维护 LTS 版本，但 Node.js 22 是更明智的升级目标。
  • Node.js 22 提供最长的支持窗口、最佳性能和最大的确保未来适用性。
