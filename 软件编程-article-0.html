如何请求更改 CVE 记录

4/9/2025, 8:02:44 PM

📌 一句话摘要

本指南为开发者和安全研究人员提供有效请求更改 CVE 记录的方法，以提高软件安全信息的准确性。

📝 详细摘要

本文为安全研究人员和开发者提供详细指南，指导他们如何向 CVE 授权机构 (CNA) 请求更改或更新 CVE 记录。文章强调了 CVE ID 的重要性，以及发现软件漏洞时及时更新信息的重要性。文章提供了逐步指导，说明如何识别特定 CVE ID 对应的 CNA，包括如何在 cve.org 和 nvd.nist.gov 上查找 CNA 信息。文章还解释了如何通过 CVE.org 合作伙伴列表查找 CNA 联系信息，并强调在沟通中包含关键信息，例如 CVE ID、建议的更改、理由和支持证据。最后，文章讨论了如何处理 CNA 不响应或出现争议的情况，并介绍 CVE 计划的争议解决机制。该指南旨在帮助安全专业人员维护和提高软件安全信息的准确性和可用性。

💡 主要观点

  1. 通过 cve.org 和 nvd.nist.gov 识别负责维护特定 CVE ID 的 CNA，以请求修改。 CNA 负责其发布的 CVE 记录；因此，修改请求应直接发送给相关的 CNA。
  2. 在向 CNA 传达更改请求时，给出明确的理由和相关证据。 清晰的理由和公开可用的参考链接有效地支持修改请求，并帮助社区理解风险。
  3. 通过 CVE 争议处理流程升级未解决的争议。 如果与 CNA 无法达成协议，可根据 CVE 官方政策将争议升级至更高级别的机构。

💬 文章金句

  • CVE ID 是一个广泛使用的软件漏洞跟踪系统。
  • CNA 负责在首次发布后更新 CVE 记录，因此任何请求都应直接发送给他们。
  • 清晰的披露决策和漏洞细节有助于开发者和安全社区理解风险，并做出明智的缓解决策。
