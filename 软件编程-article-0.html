在团队之间迁移 Marketplace 资源 - Vercel

4/1/2026, 12:32:02 AM

📌 一句话摘要

Vercel 现在支持直接通过仪表板在团队之间迁移数据库等 Marketplace 资源，无需使用 API，从而简化了项目迁移流程。

📝 详细摘要

Vercel 推出了一项新功能，允许用户直接通过 Vercel 仪表板在团队之间迁移 Marketplace 资源。此更新取消了以往必须使用 API 才能完成此类任务的要求，极大地简化了团队重组或项目移交过程中的资源管理。该功能目前支持从 Prisma、Neon 和 Supabase 等提供商处迁移数据库，前提是目标团队已安装相应的集成。相关团队的所有者和成员均可发起此类迁移。

💡 主要观点

  1. 基于仪表板的直接资源迁移。 用户现在可以使用 Vercel UI 在团队之间移动 Marketplace 资源，无需手动调用 API，简化了管理工作流程。
  2. 目标团队的前提条件。 为了成功完成迁移，目标团队必须在其环境中安装相关的集成（例如 Supabase 或 Neon）。
  3. 广泛的迁移角色权限。 源团队和目标团队的所有者及成员均可使用此功能，从而在项目迁移过程中实现灵活协作。

💬 文章金句

  • 现在，您可以直接从 Vercel 仪表板在团队之间迁移 Marketplace 资源，而无需依赖 API。
  • 这简化了团队或项目变更期间的资源管理。
  • 在接收资源之前，目标团队必须安装相应的集成。
