中国大模型跻身全球 AI 第一梯队，开源改写中西方竞争规则！

6/25/2026, 11:15:00 AM

📌 一句话摘要

本文报道第 21 届开源中国峰会，汇集陆首群、华为、小米、中兴等专家演讲，展现中国大模型与开源 AI 生态的最新进展，认为中国已跻身全球第一梯队。

📝 详细摘要

文章为第 21 届开源中国·开源世界高峰论坛首日议程的完整记录。陆首群开场指出中国开源 AI 正走降本增效的性价比路线，区别于西方闭源重资产。AAIF 执行总监 Mazin Gilbert 强调开放标准对 Agent 生态的关键作用。小米张晨分享了 MiMo 模型通过 Hybrid SWA 等优化实现 1M 上下文与极低推理成本的技术细节。华为叶琪提出开源蜂群智能范式。中兴孟伟分析 Co-Sight 与 OpenClaw 的融合。GitHub、宇树、智元、瀚高、RWKV、银河麒麟、腾讯云、海光等多家企业也分别就具身智能、Agent 安全、数据库开源、国产算力等议题展开讨论。整体展现了中国开源从消费方转向供给方、从国内走向全球的趋势。

💡 主要观点

  1. 中国开源 AI 走降本增效路线，与西方闭源重资产形成对比。 陆首群指出美西方高投资、高成本、堆算力，而中国以开源为底座，低投资、低成本、节省电力，以有限资源获取更高效率，推动行业从拼参数转向差异化竞争。
  2. Agent AI 成为热点，开放标准与生态协作是关键。 AAIF（智能体人工智能基金会）成立，推动 MCP、A2A 等协议发展，旨在为 Agent 提供中立、开放的开源基础；多家厂商展示 Agent 在金融、能源、电信等行业的落地路径。
  3. 小米 MiMo 模型通过工程优化实现 1M 上下文与极致推理效率。 MiMo-V2-Pro 采用 Hybrid SWA 混合注意力机制，基于开源 SGLang 深度优化，推理成本已降至与 DeepSeek 同处国内最低梯队，破解了长上下文带来的计算与显存瓶颈。
  4. 具身智能面临仿真到真机的鸿沟，需要大规模真机测评平台。 Dexmal 发起的 RoboChallenge 提供首个全球规模真机测评场，目前叠碗等简单任务已被打穿，但柔性物体和长程操作仍是难题，具身大模型的'ChatGPT 时刻'尚未到来。
  5. 中国开源正从生态消费方转向供给方，加速全球化。 COPU 提出'一体两翼'战略：国内场景锤炼技术，向西参与欧美规则治理，向东赋能一带一路国家；与沙特签署 MOU 并举办首届中沙开源峰会，推动技术标准输出。

💬 文章金句

  • 开发者的红利正从'会写代码'转移到'会调度、会判断、会提问'。
  • 开源大模型将带动大量中小模型形成'模型集群'，把整个行业从拼参数、拼算力的同质竞争，引向各有所长的差异化竞赛。
  • 开源，无论如何都必须实现商业化的伟大胜利。
