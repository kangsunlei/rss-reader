Claude Code 动态工作流：数百个并行子智能体处理大型任务

5/28/2026, 11:14:39 PM

📌 一句话摘要

Claude Code 推出动态工作流功能，可在单次会话内启动数百个并行子智能体，专门处理全代码库漏洞排查、大规模迁移等复杂任务。

📝 详细摘要

该推文详细解读了 Claude Code 的「动态工作流」新功能。该功能允许 Claude 在单次会话中动态生成编排脚本，同时启动数十甚至数百个并行子智能体，每个子智能体独立完成一部分工作，最后由主流程汇总结果。最适合全代码库漏洞排查、大规模代码迁移和独立交叉验证等场景。新增的「ultracode」模式可让 Claude 自动判断何时启动工作流。目前以研究预览形式上线，支持 CLI、桌面版、VS Code 扩展及主要云 AI 服务。官方案例显示，Bun 团队用该功能在 11 天内将大部分代码从 Zig 迁移到 Rust，测试通过率达 99.8%。
