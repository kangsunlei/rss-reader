Visual Studio 17.14 Preview 3：GitHub Copilot 功能更新（现已推出）

4/16/2025, 6:24:10 PM

📌 一句话摘要

Visual Studio 17.14 Preview 3 引入 GitHub Copilot 的引导式入门、模型访问和代码映射等新功能，旨在提升 AI 辅助开发体验。

📝 详细摘要

Visual Studio 17.14 Preview 3 版本发布，带来了 GitHub Copilot 的多项更新，旨在简化开发流程，提高开发效率。新增引导式入门，帮助新手快速上手 Copilot。改进了模型访问，可以直接在 Visual Studio 中启用 Claude 3.7 等最新模型。代码映射功能也得到了升级，Copilot 可以更准确地插入代码建议。此外，Next Edit Suggestions 可以根据之前的更改提供上下文相关的代码编辑建议，Adaptive Paste 能够自动调整代码风格、格式，进行代码翻译，并具备代码补全能力，自动调整粘贴到 Visual Studio 中的代码，以适应现有代码的上下文，减少手动修改。

💡 主要观点

  1. 引导式入门：助力新手快速掌握 GitHub Copilot。 五步引导，用户即可免费体验 Copilot，掌握 AI 代码补全、Copilot Chat 等功能，并学会如何利用上下文提升效率。
  2. 改进了模型访问，方便开发者使用最新的 AI 模型。 无需调整设置，用户可以直接通过 Visual Studio 从 github.com 启用任何可用的模型。
  3. Adaptive Paste：自动调整粘贴代码，优化上下文适应性。 此功能可自动修复错误、调整代码格式、翻译代码语言及补全代码。

💬 文章金句

  • Visual Studio 中的 GitHub Copilot 体验持续更新，以提供 AI 辅助开发的最新进展。
  • 前往 GitHub Copilot 徽章下拉菜单，选择 GitHub Copilot Walkthrough。
  • Adaptive Paste 简化了代码集成。
