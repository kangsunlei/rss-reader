AI/BI 四月功能更新概览

4/21/2025, 5:02:26 PM

📌 一句话摘要

Databricks AI/BI 四月更新聚焦 Genie 与仪表板的功能增强，包括用户界面改进、文件上传、计算维度和 Git 集成，旨在提升数据分析效率和协作能力。

📝 详细摘要

Databricks AI/BI 在四月份迎来了一系列更新，旨在提升数据分析的效率和协作能力。Genie 用户界面得到了改进，更简洁，操作空间更大。Genie 新增了文件上传功能，解决了数据集成复杂性的问题，允许用户直接上传 Excel 和 CSV 文件进行分析，并与 Unity Catalog 中的现有数据进行混合分析。AI/BI 仪表板现在可以作为 Jobs 中的一个任务运行，解决了数据更新和报告分发效率的问题，方便用户在数据管道刷新后自动刷新仪表板并发送 PDF 快照。此外，仪表板还增加了计算维度功能，解决了数据建模灵活性不足的问题，允许用户在仪表板内创建新的维度字段。最后，AI/BI 仪表板现在支持 Git 文件夹集成，方便用户进行版本控制和协作。

💡 主要观点

  1. Genie 文件上传功能简化了外部数据与 Unity Catalog 数据整合流程，加速数据洞察。 用户无需复杂的数据导入流程，即可将 Excel 和 CSV 文件上传到 Genie 中，与 Unity Catalog 中的现有数据进行混合分析，加速从外部数据中获取洞察。
  2. 仪表板任务功能实现了数据管道与仪表板更新的自动化连接，提升了数据报告的效率和及时性。 用户可以将仪表板刷新设置为 Jobs 中的一个任务，在数据管道完成后自动刷新仪表板，并通过邮件发送 PDF 快照，实现数据报告的自动化分发。
  3. 计算维度功能增强了仪表板的灵活性和定制性 用户无需修改底层数据集，即可在仪表板内创建新的维度字段，使用 SQL 表达式实现更灵活的数据分组和分类，满足定制化的数据分析需求。

💬 文章金句

  • AI/BI 允许用户在整个组织内轻松地探索、分析和分享见解，而无需管理许可证、数据提取或构建非官方的数据仓库。
  • 新的布局为指令和数据选项卡提供了更多的屏幕空间，从而可以更轻松地在 Genie 对话中优化您的指令。
  • 计算维度允许作者直接在仪表板中创建新的维度字段，而无需修改底层数据集。
