IBM 和 NASA 训练了首个太阳物理学基础模型

8/31/2025, 6:00:00 PM

📌 一句话摘要

IBM 和 NASA 开发了 Surya，首个用于太阳物理学的 AI 基础模型，用于预测太阳活动并减轻其影响，表现出优于专业模型的性能。

📝 详细摘要

IBM 和 NASA 合作开发了 Surya，一个拥有 3.66 亿 参数的 AI 基础模型，旨在预测关键的太阳活动，如耀斑、太阳风和太阳爆发的前兆。这些事件对宇航员的安全以及地面基础设施（如通信和电力网络）构成重大风险。Surya 在 NASA 太阳动力学观测台 (SDO) 提供的九年高分辨率图像上进行了训练，使其能够学习跨越各种尺度和时间动态的全面太阳表征。Surya 的一个关键创新在于它脱离了传统的、狭隘的任务特定模型，为太阳物理学提供了一种更通用的方法。尽管 Surya 具有通用设计，但在太阳区域分割和耀斑/太阳风预测等任务中，其性能优于现有的专业模型。在架构上，它采用了一个带有频谱门控块的 2D Transformer 用于噪声抑制和特征增强，以及长短时注意力块来捕获多尺度依赖。研究人员认为，Surya 发展了物理感知表征，使其无需额外训练即可预测太阳动态。该模型在 Hugging Face 和 GitHub 上公开提供。

💡 主要观点

  1. Surya 是首个用于太阳物理学的 AI 基础模型，提供通用的太阳活动预测。 与之前的任务特定模型不同，Surya 从 NASA SDO 的大量数据中学习通用的太阳表征，使其能够适应各种预测任务，并且性能优于专业模型。
  2. Surya 的架构集成了先进的组件，可实现稳健的、具有物理感知能力的太阳动力学理解。 它使用 2D Transformer、用于降噪的频谱门控和长短时注意力块来捕获细粒度和长程时间依赖性，从而实现更准确、更具通用性的预测。
  3. 该模型在 Hugging Face 和 GitHub 上的开放可用性促进了更广泛的科学研究和应用开发。 Surya 的可访问性有助于科学界采用和进一步开发该模型，从而加速空间天气预测和相关领域的进步。

💬 文章金句

  • Surya 是 IBM 和 NASA 创建的一个拥有 3.66 亿 参数的模型，用于预测太阳活动，包括耀斑事件、太阳风和太阳爆发的前兆，这些事件可能会严重影响太空中宇航员的安全以及通信、电力分配等地面系统。
  • 目前太阳物理学研究中的机器学习应用通常依赖于任务特定的数据和从头开始训练的模型，这可能效率低下、容易过度拟合，并且受到标记数据稀缺的限制，特别是对于罕见事件 Ahmadzadeh et al. (2019)，这些事件通常是最有趣的。
  • 尽管不是任务特定的，但 Surya 的性能优于现有的专业模型，包括用于太阳区域分割的 U-Net、用于太阳耀斑预测的 AlexNet 以及用于太阳风速度预测的 AlexNet 和 ResNet50。
  • 研究人员坚持认为，Surya 能够开发在一定程度上具有物理感知能力的表征，而不仅仅是记忆过去的模式。
  • Surya 在 Hugging Face 和 GitHub 上可用。
