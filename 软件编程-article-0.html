Lydie：支持 Markdown 文件夹编辑的写作应用

11/18/2026, 4:15:27 AM

📌 一句话摘要

Lydie 是一款写作应用，支持直接打开 Markdown 文件夹编写，也可连接自托管的在线工作区。

📝 详细摘要

推文介绍了 Lydie 这一写作应用的核心功能：用户可以直接打开装有 Markdown 文件的文件夹进行写作，或将其连接到自托管的在线工作区使用。该应用聚焦于知识整理与写作效率，适合需要本地文件管理的写作者。

💡 主要观点

  1. 本地文件系统直接集成降低使用门槛 用户无需额外导入导出 Markdown 文件，即可在应用内完成编辑，提升工作流连续性。
  2. 自托管的在线工作区支持私有化部署 用户可自行部署服务端，确保数据安全隐私，符合对自托管工具的需求。
