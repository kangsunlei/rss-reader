DeepSeek R1 现已在 Vertex AI 模型花园中面向所有用户开放

7/17/2025, 12:00:00 AM

📌 一句话摘要

Google Cloud 宣布 DeepSeek R1 在 Vertex AI 模型花园中以托管式模型即服务 (MaaS) 形式提供，旨在简化企业的大模型部署和管理流程。

📝 详细摘要

Google Cloud 通过集成 DeepSeek R1 作为完全托管的模型即服务 (MaaS) 产品，扩展了其 Vertex AI 模型花园。此举旨在帮助企业更灵活地构建 AI 应用，同时体现 Google 对开放 AI 生态系统的支持。MaaS 产品提供无服务器 API，解决了部署大模型带来的运营和财务挑战，例如对大量 GPU 基础设施的需求。这使客户可以绕过基础设施管理复杂性，直接专注于应用程序开发。本文提供了关于如何通过 Vertex AI UI 和 API (使用 REST 和 OpenAI Python 客户端库) 启用 DeepSeek R1 并与之交互的实用分步指南，并附有代码示例。该服务是一个安全的企业级平台，内置数据隐私和合规性功能，并提供灵活的按需付费定价模式。

💡 主要观点

  1. DeepSeek R1 现在作为 Vertex AI 上的托管服务提供，简化了大模型部署。 MaaS 产品减轻了配置和管理 GPU 基础设施的负担，使开发人员可以专注于 AI 应用的构建。
  2. Vertex AI MaaS 提供了一个安全的企业级平台，具有灵活的 AI 模型消费定价。 用户受益于内置的数据隐私和合规性，以及随需求扩展的按需付费模式，这使得企业更容易访问和管理强大的 AI。
  3. 该服务提供通过 UI 和标准 API (REST， OpenAI Python 客户端) 的直接集成方式。 提供了分步说明和代码示例，使开发人员能够快速启用 DeepSeek R1 并将其集成到他们的应用程序中。

💬 文章金句

  • DeepSeek R1 通过我们的模型即服务 (MaaS) 产品向所有人开放。
  • 部署和管理当今的大模型面临运营和财务挑战。
  • Vertex AI 的 MaaS 产品旨在消除这种复杂性。
  • 通过将这些模型作为完全托管的无服务器 API 提供，我们消除了客户配置或管理底层基础设施的需求。
  • 您可以使用 REST API 或 OpenAI Python API 客户端库将 DeepSeek R1 集成到您的应用程序中。
