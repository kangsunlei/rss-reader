📌 一句话摘要

ThreeUI 将付费版 50 个 Three.js+React 3D 交互组件完整开源为社区版，含 164 个变体，实时预览可调参数，MIT 协议可商用，适合落地页/官网快速落地。

📝 详细摘要

推文介绍 ThreeUI 社区版开源：原为付费产品，现将 50 个 Three.js 结合 React 的交互式 3D 组件全部开源，算上变体共 164 个可浏览效果。官网每个组件实时渲染，旁侧参数控件可拖拽调整，源码标签页直达。免费版未删减变体与控件，仅 Pro/Beta 组件保留。npm 安装支持按需引入单组件，MIT 协议可商用。适用于作品集、产品官网等需 3D 质感场景，省去从头写 Three.js 调 Shader 的时间。附 GitHub 链接与预览图。
