SAP Databricks 在 AWS 平台正式发布

4/30/2025, 8:36:42 PM

📌 一句话摘要

SAP Databricks 现已在 AWS 平台全面可用，通过 Delta Sharing 技术直接在 SAP 业务数据云中实现人工智能与数据分析功能。

📝 详细摘要

本文宣布 SAP Databricks 在 AWS 平台正式发布，该版本是 Databricks 的完全托管式服务，原生集成于 SAP 业务数据云。90% 的《财富》500 强企业使用 SAP 管理关键业务数据，此解决方案有效解决了企业采用传统人工智能与数据分析方法时面临的挑战，例如因数据复制导致的系统复杂性和成本上升问题。SAP Databricks 通过支持在 SAP 业务数据云中完成端到端的人工智能、机器学习与数据分析流程，无需使用独立平台或进行物理数据复制，从而大幅简化了操作流程。该集成采用 Delta Sharing 技术实现安全的双向数据访问，使数据团队能够运用 Databricks Notebooks 和 AI 驱动的 Databricks Assistant 等工具，将 SAP 数据与外部数据源进行整合。该方案支持使用 Mosaic AI 构建特定领域的人工智能/机器学习模型，并能无缝衔接下游 SAP 应用程序，无需建立冗余的数据管道。

💡 主要观点

  1. 消除数据复制需求 SAP Databricks 支持跨系统进行端到端人工智能与数据分析而无需物理数据复制，显著降低了系统复杂度与运营成本，同时缓解了数据治理难题。
  2. Delta Sharing 实现安全数据融合 通过 Delta Sharing 的原生集成技术提供安全双向数据访问能力，实现 SAP 数据与外部数据源的融合，为分析和人工智能模型训练提供更丰富的数据支持。
  3. 完整 AI/ML 生命周期支持 提供 Databricks Notebooks、Assistant 和 Mosaic AI 等工具链，完整支持从数据准备、模型开发到特定领域解决方案部署的全生命周期工作流。
  4. 无缝衔接 SAP 应用程序 支持团队在 Databricks 中完成分析后，直接将结果应用于下游 SAP 应用程序，无需额外数据迁移或构建传输管道。

💬 文章金句

  • SAP Databricks 是 Databricks 的完全托管版本，以服务形式原生集成于 SAP 业务数据云中。
  • 客户现可直接在 SAP 业务数据云中运行端到端的人工智能、机器学习与数据分析流程，无需使用独立平台或进行物理数据复制。
  • SAP Databricks 通过 Delta Sharing 技术原生集成到 SAP 业务数据云，实现安全的双向数据访问，无需在系统间物理复制数据。
  • 数据团队可将 SAP 数据与其他应用程序、数据库及对象存储系统的数据进行整合。
  • 团队可在 SAP Databricks 中执行人工智能与分析任务，并顺畅使用下游 SAP 应用程序（如规划工具），无需构建冗余数据管道。
