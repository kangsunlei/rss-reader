“我把所有模型都换成了 DeepSeek V4”：月账单降 90%，效果还更好

4/25/2026, 7:30:00 AM

📌 一句话摘要

本文深入对比了 DeepSeek V4 与 GPT-5.5、Claude Opus 4.7 在定价、性能和技术架构上的差异，通过实测案例和成本分析，论证了 DeepSeek V4 以极低价格提供接近前沿水平性能的颠覆性优势。

📝 详细摘要

文章以 2026 年 4 月 OpenAI 发布 GPT-5.5 并大幅涨价为引子，对比了仅一天后开源的 DeepSeek V4 系列模型。核心论点是 DeepSeek V4 凭借 MIT 开源协议、百万 token 上下文窗口和仅为 GPT-5.5 十分之一的价格，正在重塑 AI 模型市场的竞争格局。文章详细对比了 DeepSeek-V4-Pro 与 GPT-5.5、Claude Opus 4.7 的 API 定价，指出在标准定价下，DeepSeek-V4-Pro 的成本仅为前者的七分之一到六分之一，而更轻量的 V4-Flash 版本成本甚至不到前者的 2%。技术层面，文章介绍了 V4 在长上下文场景下的关键优化，如压缩稀疏注意力和流形约束超连接，使得 KV cache 减少 90%。通过卡丁车游戏开发、Apple 风格天气界面生成等实测案例，以及科技博主 Sean Donahoe 和 Simon Willison 的迁移体验，文章展示了 DeepSeek V4 在编码、审美和日常任务上的实际表现，结论是其在性价比上具有压倒性优势，但在最前沿的推理基准上仍与顶尖模型有 3 到 6 个月的差距。

💡 主要观点

  1. DeepSeek V4 以极低价格提供了接近前沿水平的性能，颠覆了 AI 模型市场的定价逻辑。 DeepSeek-V4-Pro 的 API 成本约为 GPT-5.5 的七分之一、Claude Opus 4.7 的六分之一，而 V4-Flash 版本成本甚至不到前两者的 2%，实现了数量级的价格优势。
  2. DeepSeek V4 在长上下文场景下实现了显著的技术优化。 通过压缩稀疏注意力和流形约束超连接等创新，V4 在百万 token 上下文场景下的 KV cache 减少 90%，单 token 推理 FLOPs 仅为 V3.2 的 27%。
  3. 实测表明，DeepSeek V4 在编码和日常任务上表现优异，但在最前沿推理基准上仍有差距。 卡丁车游戏和天气界面等实测案例显示 V4 能输出高质量代码，但官方承认在标准推理基准上仍略逊于 GPT-5.4 和 Gemini-3.1-Pro，差距约 3 到 6 个月。
