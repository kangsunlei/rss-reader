报告：LLM 在事件管理中尚不能取代 SRE

9/27/2025, 10:00:00 PM

📌 一句话摘要

报告显示，LLM 作为辅助工具有前景，但尚不能自主进行复杂事件的根本原因分析，取代 SRE 。

📝 详细摘要

本文总结了两项研究（一项来自 ClickHouse ，另一项来自 Tomasz Szandała ）的发现，评估大型语言模型（LLM ）在站点可靠性工程（SRE ）中的应用，特别是事件根本原因分析（RCA ）。ClickHouse 的研究测试了诸如 Claude Sonnet 4 、OpenAI GPT - o3 、GPT - 4.1 、Gemini 2.5 Pro 和 GPT - 5 等模型，基于真实可观测性数据，结论是 LLM 在缺乏人工指导的情况下，无法实现自主 RCA 。这些模型在处理复杂问题时经常遇到困难，产生幻觉或局限于单一推理路径。成本和调查时间也差异很大。然而，LLM 擅长起草 RCA 报告。Szandała 的研究评估了 GPT - 4o 、Gemini - 1.5 和 Mistral - small 在混沌工程场景中的表现，发现与人类 SRE （62 % ）相比，LLM 在零样本设置中表现出适度的成功（44 - 58 % 的准确率）。至关重要的是，提示工程显著提高了 LLM 的性能（60 - 74 % 的准确率），但仍落后于人类 SRE （超过 80 % ）。两项研究均表明，LLM 在日志总结、报告起草和计划制定等方面作为辅助工具有显著价值，但战略决策和复杂问题解决仍需人工干预。

💡 主要观点

  1. LLM 尚不能在事件管理中实现完全自主的根本原因分析。 多项研究表明，即使是像 GPT - 5 这样先进的 LLM ，在没有人为干预的情况下，也很难持续识别复杂生产问题的根本原因，经常产生幻觉或固执于不正确的推理。
  2. LLM 作为 SRE 辅助工具，能有效提升特定任务效率。 LLM 擅长总结嘈杂的日志、起草事后分析报告、提出调查计划和审查数据，从而使 SRE 能够专注于更复杂的问题解决和战略决策。
  3. 提示工程是提升 LLM 在 SRE 任务中表现的关键。 结构化的提示技术可以显著提高 LLM 在根本原因分析中的准确性，这表明人类用户如何与这些 AI 模型互动和指导它们非常重要。

💬 文章金句

  • “自主 RCA 尚未实现，”作者解释说。“在我们的评估中，利用 LLM 更快、更低成本地定位生产问题的期望并未实现，甚至 GPT - 5 也没有胜过其他模型。”
  • “这反映了一种常见的模式：模型倾向于固守单一推理路径，缺乏对其他可能性的探索。”
  • “随后，模型开始构建一个缺乏证据的虚构原因，并试图证明其合理性。”
  • “那么 LLM 现在可以取代 SRE 吗？不能。与快速可观测性技术栈结合使用时，能否缩短事件处理时间并改进文档质量？”
  • “未来的方向是更完善的上下文信息和更强大的工具，并由工程师主导。”
