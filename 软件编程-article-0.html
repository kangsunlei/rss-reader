EDOT (OpenTelemetry 的 Elastic 发行版) GA 发布，LLM 可观测性

4/15/2025, 6:43:20 PM

📌 一句话摘要

Elastic Observability 9.0/8.18 发布，主要更新包括 EDOT 正式发布和 LLM 可观测性功能。

📝 详细摘要

Elastic Observability 9.0/8.18 版本发布，主要更新包括：EDOT（OpenTelemetry 的 Elastic 发行版）正式发布，为 SRE 和开发者提供稳定的 OpenTelemetry 生态系统；LLM 可观测性功能正式发布，提供针对 Azure OpenAI、AWS Bedrock 和 Google Vertex AI 等主流 LLM 平台的端到端洞察，并支持 EDOT language SDKs 中的 GenAI 工具集成能力和 Amazon Bedrock Guardrails（安全护栏）；Logstash 事件写入速度提升 5 倍；Elastic Agent 支持 AWS EKS；Discover 功能增强，整合日志探索功能并移除 Logs Explorer 和 Logs Stream。

💡 主要观点

  1. EDOT 正式发布，提供稳定可靠的 OpenTelemetry 生态。 EDOT 的所有组件都已正式发布，为生产环境提供企业级支持，同时保持 OpenTelemetry 原生规范，增强了关联性和分析能力。
  2. LLM 可观测性功能 GA，支持主流 LLM 平台，并提供 GenAI 工具集成能力和 Amazon Bedrock Guardrails（安全护栏）支持。 为 AI 应用开发者提供端到端的洞察，以管理和优化 LLM 应用的性能、成本、安全性和可靠性，支持 Azure OpenAI、AWS Bedrock 和 Google Vertex AI 等。
  3. Elastic Agent 支持 AWS EKS，简化部署和集成。 Elastic Agent 容器现在可以作为 EKS 附加组件使用，方便用户轻松部署 Elastic Agent 容器并无缝集成到他们的 EKS 集群中。
  4. Discover 功能增强，整合日志探索功能，提升数据分析体验。 Discover 整合了日志探索功能，移除了 Logs Explorer 和 Logs Stream，提供更强大的数据分析能力。

💬 文章金句

  • All EDOT components are now GA， providing SREs and developers with a stable OpenTelemetry (OTel) ecosystem for production use.
  • LLM observability is now generally available， providing SREs and developers of AI-based apps the end-to-end insights they need to manage and optimize large language model (LLM) applications for performance， cost， safety， and reliability.
  • With this enhancement to Elastic's APM， you can now observe generative AI applications using our Python， Node.js， and Java EDOT SDKs.
  • With the enhancement of Elastic's Amazon Bedrock integration with support for [Amazon Bedrock Guardrails](https://www.elastic.co/observability-labs/blog/llm-observability-amazon-bedrock-guardrails)， you can monitor key aspects of safety and reliability controlled by configurable safeguards.
