CVE-2025-29927

3/22/2025, 5:00:00 PM

📌 一句话摘要

Next.js 发布 15.2.3 版本以修复 CVE-2025-29927 安全漏洞，该漏洞影响使用 Middleware 的自托管 Next.js 应用，可能导致安全检查被绕过。

📝 详细摘要

Next.js 发布了 15.2.3 版本，以解决 CVE-2025-29927 安全漏洞。该漏洞是由于 `x-middleware-subrequest` 标头处理不当，影响使用 `next start` 和 `output: 'standalone'` 的自托管 Next.js 部署，允许恶意请求绕过 Middleware 中的关键检查，如身份验证。建议立即更新到 15.2.3 或 14.2.25 版本。对于无法升级的用户，建议阻止包含 `x-middleware-subrequest` 标头的外部请求。Vercel 和 Netlify 上托管的应用程序以及静态导出的应用程序不受影响。Next.js 团队正在发布 v12 和 v13 的向后移植补丁，并将更新此帖子。

💡 主要观点

  1. CVE-2025-29927 允许绕过 Middleware 检查 攻击者可以跳过 Middleware 执行，绕过授权 Cookie 验证等关键安全检查，从而导致未授权访问。
  2. 自托管 Next.js 应用受影响 使用 `next start` 和 `output: 'standalone'` 的自托管应用需要立即更新。
  3. 缓解措施包括升级或阻止特定标头 升级到 15.2.3 或 14.2.25 是首选方案，否则阻止包含 `x-middleware-subrequest` 标头的请求。
  4. Next.js 团队正在发布 v12 和 v13 的向后移植补丁 为使用旧版本 Next.js 的用户提供安全支持。

💬 文章金句

  • 我们建议所有使用 `next start` 和 `output: 'standalone'` 的自托管 Next.js 部署立即更新。（We recommend that all self-hosted Next.js deployments using `next start` and `output: 'standalone'` should [update](https://nextjs.org/docs/app/building-your-application/upgrading) immediately.）
  • Next.js 使用一个内部标头 `x-middleware-subrequest` 来防止递归请求触发无限循环。（Next.js uses an internal header `x-middleware-subrequest` to prevent recursive requests from triggering infinite loops.）
  • 如果无法修复到安全版本，建议阻止包含 `x-middleware-subrequest` 标头的外部用户请求到达您的 Next.js 应用程序。（If patching to a safe version is infeasible， it is recommended that you prevent external user requests which contain the `x-middleware-subrequest` header from reaching your Next.js application.）
