介绍一个名为 Codex2API 的开源项目，它提供 OpenAI 风格接口，用于反向代理 Codex 并管理账号池与调度。

📝 详细摘要

该推文推荐了 Codex2API 项目，这是一个基于 Go + Gin + React/Vite 构建的 Codex 反向代理与管理后台。它对外提供兼容 OpenAI 的 chat/completions、responses、images 等接口，对内通过 Refresh Token 维护账号池和 Access Token 生命周期。调度系统支持按健康层级动态分配并发，具备 429 冷却、401 封禁及自动恢复机制，调度分实时加减。支持 PostgreSQL + Redis 或 SQLite + 内存缓存两种模式，可通过 Docker 一键部署。管理后台包含 Dashboard、账号管理、使用统计、调度看板和系统设置等功能。
