BigQuery 新增生成式 AI 函数，助力更优数据分析

1/27/2026, 12:00:00 AM

📌 一句话摘要

Google Cloud 通过 AI.GENERATE 和 AI.SIMILARITY 等全新 SQL 函数，将 Gemini 和 Vertex AI 模型直接集成到 BigQuery 中，实现了无缝的非结构化数据分析。

📝 详细摘要

本文介绍了 BigQuery 中全新生成式 AI 函数的正式发布（GA）及预览版。通过将 Gemini 和 Vertex AI 模型直接集成到 BigQuery SQL 中，Google 允许用户在不离开数据仓库环境的情况下执行复杂的 AI 任务，如文本生成、摘要提取和语义相似度计算。关键更新包括：使用终端用户凭据（EUC）简化的权限设置、支持多模态输入和结构化输出的 AI.GENERATE 函数，以及用于简化语义搜索的 AI.SIMILARITY 函数。这些功能旨在利用熟悉的 SQL 语法，弥合海量非结构化数据（图像、音频、视频）与结构化分析洞察之间的鸿沟。

💡 主要观点

  1. BigQuery 现在支持通过标准 SQL 函数直接调用 AI 模型。 AI.GENERATE 和 AI.EMBED 等函数允许开发人员直接在 SELECT 语句中对文本、图像和视频进行推理，减少了对复杂数据流水线的需求。
  2. 原生支持从非结构化数据生成结构化输出。 通过在 AI.GENERATE 中使用 output_schema 参数，用户可以强制 LLM 以可解析的格式返回数据，并直接映射到 BigQuery 的列中。
  3. 通过终端用户凭据（EUC）简化的身份验证降低了配置摩擦。 EUC 允许使用用户的个人 IAM 身份对 Vertex AI 请求进行身份验证，从而消除了交互式查询中对独立服务账号配置的需求。
  4. AI.SIMILARITY 无需预计算嵌入即可实现快速语义搜索。 该函数在一个步骤中同时处理嵌入生成和余弦相似度计算，非常适合在中小型数据集上进行原型设计和交互式分析。

💬 文章金句

  • 为了帮助您以最小的摩擦释放这些数据的潜力，我们将 Gemini 和其他 Vertex AI 模型直接集成到了 BigQuery 中。
  • 这些函数是完全可组合的，可以放置在标准 SQL 函数出现的任何位置：SELECT 语句、WHERE 子句和 ORDER BY 子句中。
  • AI.SIMILARITY 通过理解查询背后的底层概念，超越了简单的子字符串搜索。
  • 通过指定所需的 output_schema，将您的非结构化数据转换为结构化洞察。
