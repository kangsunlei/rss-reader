Next.js 15.4

7/14/2025, 8:00:00 PM

📌 一句话摘要

Next.js 15.4 提升了性能和稳定性。Turbopack 实现了 100% 集成测试兼容性，同时提供 Next.js 16 计划中的主要功能的早期预览。

📝 详细摘要

本文宣布发布 Next.js 15.4，重点介绍了性能和稳定性的重大进展，特别是 Turbopack。一个重要的里程碑是 Turbopack 实现了生产环境构建 (`next build --turbopack`) 的 100% 集成测试兼容性，现在为 vercel.com 提供支持，意味着 Turbopack 已经可以大规模使用了。该帖子还提供了 Next.js 16 的早期预览，详细介绍了即将推出的功能，例如用于简化缓存的统一 `cacheComponents` (缓存组件) 标志、用于更快导航的优化前端路由、用于调试的增强开发者工具以及将 Node.js 中间件提升到稳定状态。鼓励开发者升级到 15.4，并通过 canary 版本和配置标志体验 Next.js 16 的实验性功能。

💡 主要观点

  1. Turbopack 实现了生产环境构建的 100% 集成测试兼容性。 这标志着 Turbopack 稳定性的关键一步，验证了它在生产环境中的可靠性，并展示了 Next.js 应用程序的显著性能改进。
  2. Next.js 16 将通过 `cacheComponents` 引入统一缓存，并优化前端路由。 这些功能旨在简化性能优化策略并提高导航速度，从而在 Next.js 应用程序中提供更灵敏、更高效的用户体验。
  3. 开发人员可以通过实验性标志预览 Next.js 16 功能。 这允许早期采用者测试和提供有关即将推出的功能（如浏览器日志转发和新的缓存行为）的反馈，从而塑造框架的未来发展。

💬 文章金句

  • `next build --turbopack` 现在通过了所有 8298 个生产环境构建的整合测试，现在为 `vercel.com` 提供支持。
  • Cache Components (beta)：它将实验性缓存功能（动态输入/输出、`use cache` (使用缓存) 和局部预渲染）整合到一个统一的 `cacheComponents` 标志中。这简化了性能优化策略。
  • Optimized Client-Side Routing：通过更智能的预取、改进的缓存失效策略和减少的带宽使用来增强 App Router 导航。这能够实现更快、更灵敏的导航。
