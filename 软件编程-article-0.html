Blaizzy 推出 Nativ：将 mlx-vlm 打包成原生 SwiftUI 应用

7/22/2026, 1:20:44 AM

📌 一句话摘要

该项目把 mlx-vlm 推理服务器封装为原生 macOS 应用，提供 OpenAI/Anthropic 兼容 API，可作为 Claude Code 等工具的本地后端。

📝 详细摘要

Geek(@geekbb) 分享了 Apple MLX 生态中最具影响力的开源开发者 Blaizzy 最新作品 Nativ。该项目将 mlx-vlm 服务器包装成一个原生 SwiftUI 应用，内置聊天、模型管理、API 服务和性能监控，全部打包在一个 DMG 安装包中。应用暴露出 OpenAI 和 Anthropic 兼容的 API 端点，可直接供 Claude Code、Codex 等工具作为本地后端使用。推文附带项目 GitHub 链接和应用截图，展示了其功能界面。
