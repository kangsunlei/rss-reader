现已推出：适用于谷歌云的 Rust SDK

9/10/2025, 12:00:00 AM

📌 一句话摘要

谷歌云正式发布其 Rust SDK，为开发者提供一种受支持、内存安全且地道的途径，将 Rust 与超过 140 个谷歌云应用程序接口集成。

📝 详细摘要

本文宣布正式发布适用于谷歌云的 Rust SDK。此前，由于缺乏官方支持，非官方解决方案在维护、安全性和功能方面存在局限性。该 SDK 为 Rust 开发者提供了一种强大、地道且受支持的途径，用于与超过 140 个谷歌云应用程序接口进行交互，包括 Vertex AI、云密钥管理服务和身份与访问管理等服务。主要功能包括全面的应用程序接口覆盖、对各种凭据（应用程序默认凭据、OAuth2、API 密钥、服务账号以及即将推出的工作负载身份联合）的内置身份验证支持，以及包含代码示例的广泛文档。该 SDK 旨在简化高性能后端服务、安全数据处理管道、实时分析和内部工具的开发，邀请社区提供反馈和贡献，以不断改进。

💡 主要观点

  1. 官方 Rust SDK 解决了非官方解决方案的局限性，提供受支持且地道的集成。 新的 SDK 为 Rust 开发者提供了一种一致、安全且完全集成的方式来使用谷歌云，解决了之前非官方 SDK 中存在的维护、安全性和缺少功能的问题。
  2. 全面的应用程序接口覆盖和强大的身份验证简化了跨各种谷歌云服务的开发。 通过访问 140+ 个应用程序接口（包括 Vertex AI、KMS、IAM）以及对各种身份验证方法的内置支持，该 SDK 简化了复杂、安全和高性能应用程序的开发。
  3. 在 crates.io 和 GitHub 上的可用性，加上广泛的文档，有助于快速采用和社区参与。 通过标准 Rust 包存储库和开源平台轻松访问该 SDK，以及专门的指南和示例，降低了入门门槛，并鼓励开发者贡献和反馈。

💬 文章金句

  • 我们很高兴地宣布推出适用于谷歌云的官方 Rust SDK，为您提供一种受支持且地道的途径，在 140+ 个谷歌云应用程序接口中使用 Rust——无需包装器，无需任何变通方案。
  • 该 SDK 的构建与我们其他官方谷歌云客户端库一样，致力于一致性、安全性和平台集成。
  • 谷歌云 Rust SDK 包含许多功能，可简化您的开发：140+ 个应用程序接口、内置身份验证、有用的文档和代码示例。
  • 我们欢迎您的反馈和贡献，因为我们正在积极改进 Rust SDK。
