Context Mode：将 AI 编程上下文压缩 98% 的开源工具

5/1/2026, 12:00:09 AM

📌 一句话摘要

开源项目 Context Mode 通过沙盒化数据处理和本地会话管理，将 AI 编程工具的上下文占用压缩 98%，支持 14 个主流平台。

📝 详细摘要

该推文介绍了一个名为 Context Mode 的开源项目，旨在解决 AI 编程工具中上下文窗口溢出的痛点。其核心思路是将原始数据保留在沙盒中，仅将处理后的结果送入上下文窗口，据称可将 315 KB 的原始输出压缩至 5.4 KB，节省 98% 的空间。项目还使用本地数据库记录会话状态，支持对话压缩后的无缝恢复。Context Mode 兼容 Claude Code、Cursor、Gemini CLI、VS Code Copilot 等 14 个主流 AI 编程工具，内置 11 种语言运行时，并提供知识库索引和智能搜索功能，所有数据均在本地处理，无需联网上传。
