ASP.NET Core 10 Preview 2 优化 Blazor 导航，更新 OpenAPI

3/30/2025, 12:00:00 AM

📌 一句话摘要

ASP.NET Core 10 Preview 2 显著改进 Blazor 导航体验，增强 OpenAPI 功能，并优化开发者工具。

📝 详细摘要

ASP.NET Core 10 Preview 2 引入了对 Blazor 导航、OpenAPI 文档生成和开发者工具的改进。具体来说，Blazor 导航系统已更新，以避免在使用 `NavigateTo`（Blazor 中用于页面导航的函数）进行同页面导航时强制滚动到页面顶部。`NavLink` 组件也得到了改进；现在，当使用 `NavLinkMatch.All`（NavLink 组件的匹配模式）进行匹配时，默认情况下它会忽略查询字符串和片段。Blazor 项目模板的重新连接 UI 进行了结构更新，新的 `ReconnectModal` 组件将 CSS 和 JavaScript 分开，以实现更严格的内容安全策略（CSP）合规性。API 开发者获得了对将 XML 源代码注释传播到 OpenAPI 文档中的内置支持。Preview 2 还包含一些提升开发体验的细节改进，例如 `QuickGrid` 的 `CloseColumnOptionsAsync` 方法，在表单绑定中将空字符串视为空值（针对可空类型），以及 Aspire 仪表板的新身份验证指标。请注意，最小 API 终结点现在必须使用命名方法而不是 lambda 函数来利用 OpenAPI 文档。

💡 主要观点

  1. 更新后的 Blazor 导航消除了同页面导航期间的滚动问题。 对 `NavigateTo` 和 `NavLink` 的更改简化了同页面导航，并通过 `AppContext` 开关（用于控制应用程序上下文的设置）提供向后兼容性。
  2. OpenAPI 现在支持 XML 注释，从而方便了 API 文档的生成。 将 XML 注释传播到 OpenAPI 文档中的内置支持简化了文档创建，但需要为最小 API 终结点使用命名方法。
  3. 提升开发体验的改进简化了开发。 诸如 `QuickGrid` 的 `CloseColumnOptionsAsync`、将空字符串视为空值以及新的身份验证指标等小改进，提高了开发人员的生产力。

💬 文章金句

  • Preview 2 中最相关的更改是改进了 Blazor 中的导航系统，以消除不良用户体验问题。
  • API 开发者获得了对将 XML 源代码注释传播到 OpenAPI 文档中的内置支持。
  • Preview 2 还引入了一些提升开发体验的细节改进
