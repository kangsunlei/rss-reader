TOON：通过减少令牌消耗优化 LLM 成本

11/23/2025, 2:49:00 AM

📌 一句话摘要

TOON (面向令牌的对象表示法) 是一种新型的、感知模式的 JSON 替代方案，旨在显著减少 LLM 提示中的令牌消耗，从而潜在地节省成本并实现类似的准确性。

📝 详细摘要

本文介绍了面向令牌的对象表示法 (TOON)，这是一种新发布的数据格式，旨在通过减少令牌使用量，优化 LLM 提示效率，相较于 JSON 有显著提升。TOON 被描述为 JSON 数据模型的紧凑、人类可读的编码，它结合了 YAML 用于嵌套对象和 CSV 用于统一数组的元素。基准测试表明，在某些情况下，TOON 可以减少 40-55% 的令牌消耗，从而可能降低 LLM 推理成本。本文提供了具体的示例，比较了相同数据的 JSON 和 TOON 格式，说明了令牌节省的情况。它还解决了准确性的问题，引用了测试表明 TOON 在 GPT 5 Nano 上实现了 99.4% 的准确率，同时使用了减少 46% 的令牌，这归因于显式的长度和字段列表。虽然对于结构化数据来说很有效，但文章指出 JSON 或 YAML 可能更适合非统一或深度嵌套的对象。TOON 是一个开源项目，提供规范、文档、在线试验场以及在 MIT 许可证下发布的 TypeScript/JavaScript 参考实现，使其易于开发人员探索和进行基准测试。

💡 主要观点

  1. TOON 显著降低 LLM 提示的令牌消耗，优于 JSON。 TOON 结合 YAML 和 CSV 结构，在基准测试中实现了 40-55% 的令牌减少，从而直接降低 LLM 推理成本。
  2. TOON 在减少令牌的同时保持高准确率，消除了对数据完整性的疑虑。 测试显示，即使使用更少的令牌，TOON 在 GPT 5 Nano 上仍然达到了 99.4% 的准确率，这说明显式的模式信息有助于 LLM 的理解。
  3. TOON 效率受数据形态影响，实施需谨慎评估。 虽然对于统一数据来说很强大，但 JSON 或 YAML 可能对于非统一或深度嵌套的结构更有效，强调了上下文感知格式选择的必要性。

💬 文章金句
