📝 详细摘要

谷歌云 Next '25 大会重点展示了人工智能技术对公共部门的赋能。主要发布包括：谷歌分布式云允许客户在本地部署 Gemini 模型；AgentSpace 与 Chrome 企业版集成，提升员工生产力并获得 FedRAMP High 授权；Vertex AI 平台支持 Gemini 2.5 和全套生成媒体模型，并获得 FedRAMP High 授权；推出谷歌统一安全，利用人工智能统一安全产品；谷歌 Workspace 为美国联邦政府机构提供高达 71% 的折扣。此外，谷歌云与多家机构合作，推动人工智能在公共部门的应用。

💡 主要观点

  1. 谷歌分布式云让公共部门客户在本地部署 Gemini 模型。(Google Distributed Cloud lets public sector customers deploy Gemini models on-premise.) GDC 提供了最高级别的安全性和合规性，使公共部门机构能够灵活地访问最新的谷歌人工智能创新。
  2. AgentSpace 与 Chrome 企业版集成，提升员工生产力。(AgentSpace integrates with Chrome Enterprise， boosting employee productivity.) 员工可以直接从 Chrome 的搜索框中搜索和访问所有企业资源，简化工作流程，提高生产力。
  3. 谷歌统一安全通过人工智能赋能更强大的安全防护。(Google Unified Security empowers stronger security with AI.) 该解决方案整合了 Google 的安全产品和 Mandiant 的专业知识，提供统一的视图，并改进复杂基础设施中的威胁检测。
