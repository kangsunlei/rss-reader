KPMG 如何使用 Delta Sharing 来访问和审计上百亿笔交易

9/19/2025, 7:10:00 PM

📌 一句话摘要

KPMG 利用 Databricks Delta Sharing 安全地审计了上百亿笔交易，从而提升了大规模财务报告的效率和质量。

📝 详细摘要

本文详细介绍了 KPMG 如何利用 Databricks 的 Delta Sharing 来解决大规模财务审计中的重大挑战，特别是在紧张的期限内访问和分析上百亿行的交易数据。由于之前的 AWS PostgreSQL 设置存在数据量限制、数据传输缓慢、查询性能不足以及资源瓶颈等问题，KPMG 寻求一种可扩展且安全的解决方案。Delta Sharing 是一种开放的数据共享协议，提供了一种强大的替代方案，可以实现安全、高效和跨平台的数据交换，而无需数据重复。其关键优势包括：能够处理 PB 级数据；降低存储和计算成本；灵活地与 PySpark、SQL 和 BI 等工具集成；以及 Delta Tables 的“时间旅行”功能。该方案通过以下方式实现：基于 JSON 配置的安全数据共享；与 Unity Catalog 集成以实现集中治理；计划的数据刷新；以及从 PostgreSQL 到 Spark SQL/PySpark 的查询优化。这些措施显著提高了整体审计效率和质量。

💡 主要观点

  1. Delta Sharing 实现了安全、跨平台的数据交换，避免了数据重复。 这种开放协议通过提供对不同云环境（AWS 到 Azure）中 PB 级数据的合规访问，而无需昂贵且耗时的数据复制，从而直接解决了关键的审计挑战。
  2. 利用 Delta Sharing 显著提高了审计效率、可扩展性和数据质量。 它通过处理海量数据集、减少运营开销，并允许审计师使用时间旅行等功能更快、更可靠地执行全量交易分析，从而克服了 PostgreSQL 的限制。
  3. 与 Unity Catalog 的集成确保了对共享数据的强大数据治理和访问控制。 Unity Catalog 提供了一个集中式平台，用于管理权限和应用治理策略，这对于敏感的财务审计环境中的合规性和安全性至关重要。

💬 文章金句

  • 为了大规模地提供有意义的见解，分析不仅必须是稳健的，而且还必须是高效的——平衡成本、时间和质量，以在紧张的时间内实现最佳结果。
  • Delta Sharing 是一种开放的数据共享协议，通过实现 KPMG 和被审计实体之间安全高效的跨平台数据交换而无需重复，从而提供了理想的解决方案。
  • Delta Sharing 旨在处理 PB 级数据，消除了 PostgreSQL 的性能限制。
  • Unity Catalog 提供了一个统一的平台，用于管理权限、应用治理策略，并保持对数据访问者的完全可见性。
