Opus 4.6 Fast Mode 现已登陆 Vercel AI Gateway

4/8/2026, 12:32:03 AM

📌 一句话摘要

Vercel AI Gateway 现已支持 Claude Opus 4.6 Fast Mode，为高端高频工作流提供 2.5 倍的输出速度，价格为标准版的 6 倍。

📝 详细摘要

Vercel 宣布将 Claude Opus 4.6 Fast Mode 集成至其 AI Gateway。这一高级实验性功能在保持模型智能水平不变的前提下，输出 token 的速度提升了 2.5 倍。它专为对低延迟有严格要求的“人在回路”（human-in-the-loop）工作流和大规模编码任务而设计。此次更新包括对 Vercel AI SDK 和 Claude Code 的支持，并提供了一个用于测试的 Playground。不过，这种性能提升伴随着显著的成本增加，其定价为标准 Opus 费率的 6 倍。

💡 主要观点

  1. Claude Opus 4.6 Fast Mode 可实现 2.5 倍的 token 生成速度。 这一实验性功能旨在解决对延迟敏感的任务，如实时编码辅助和复杂规划，且不会牺牲模型的推理能力。
  2. 与 Vercel AI SDK 和 Claude Code 无缝集成。 开发者只需在提供商选项中传递简单的 `speed: 'fast'` 参数，或更新 CLI 工具的 `settings.json` 文件，即可启用该高速模式。
  3. 卓越性能伴随 6 倍的价格溢价。 Fast Mode 的定价远高于标准费率（输入/输出每百万 token 分别为 30 美元/150 美元），定位为实现高价值生产力提升的专业工具。

💬 文章金句

  • Fast mode 是一种高级高速选项，在保持相同模型智能水平的同时，提供 2.5 倍的输出 token 速度。
  • 无需切换上下文即可运行大型编码任务，无需长时间等待即可获得规划结果。
  • Fast mode 的定价是标准 Opus 费率的 6 倍。
