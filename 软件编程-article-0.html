h5i Radio – 利用 Git，让 Claude 和 Codex 进行实时对话

6/4/2026, 10:27:28 PM

📌 一句话摘要

h5i Radio 是一个开源工具，利用 Git 仓库作为中介，让 Claude、Codex 等 AI Agent 能像开发者协作代码一样进行实时消息交换和协同工作。

📝 详细摘要

本文介绍了一个名为 h5i 的开源工具及其核心功能 h5i Radio。该工具将 AI Agent 的任务、消息、记忆和协作信息存储到 Git 仓库中，使得多个 Agent 可以共享上下文、协同工作。文章重点解释了 Agent Radio 的原理：它将 Git 仓库当作一个聊天群，每条消息以 JSON 格式存放在 Git 的特殊位置（refs/h5i/msg）中。Agent 通过写入消息、执行 git push 和 git pull 来实现消息的发送与接收，整个过程无需消息服务器、数据库或 WebSocket。文章还提供了安装命令、使用示例（如让 Claude 和 Codex 共同设计下一代深度学习框架）以及监控对话（h5i msg watch）和发布总结到 GitHub PR（h5i share pr post）等附加功能。

💡 主要观点

  1. h5i Radio 利用 Git 仓库作为 AI Agent 之间的消息中介。 通过将消息以 JSON 格式存储在 Git 的 refs/h5i/msg 中，并利用 git push/pull 进行同步，实现了去中心化的 Agent 通信，无需传统消息服务器。
  2. 该工具实现了多个 AI Agent 的上下文共享与协同工作。 h5i 将 Agent 的任务、消息和记忆都存入 Git，使得不同 Agent（如 Claude 和 Codex）能像开发者协作代码一样共享上下文，共同完成复杂任务。
  3. h5i Radio 提供监控和发布功能，增强协作透明度。 用户可通过 h5i msg watch 实时监控 Agent 对话，或通过 h5i share pr post 将对话总结发布到 GitHub Pull Request 中，便于团队协作与审查。

💬 文章金句

  • h5i 是一个开源工具，它把 AI Agent 的任务、消息、记忆和协作信息存储到 Git 中，让多个 Agent 能像开发者协作代码一样共享上下文、协同工作。
  • 整个过程不需要消息服务器、数据库或 WebSocket，Git 本身就承担了消息同步的工作。
