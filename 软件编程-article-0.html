📌 一句话摘要

介绍个人投资者开源的 claude-trading-skills 项目，将盘面分析、仓位计算、交易日记、复盘等拆解为可调节的 Claude Code Skill，并通过纪律关卡防止情绪化交易。

📝 详细摘要

本推文分享了 claude-trading-skills 项目，这是一位个人投资者开源的 Claude Code Skill 集合。该项目将看大盘、算仓位、写交易日记、复盘等投资实践拆解为独立 Skill 模块。推文特别强调了一个「纪律关卡」机制：未制定交易计划、仓位超标或在亏损后想要报复性加仓时，系统会拦截交易并记入日记。项目支持每天花约 15 分钟浏览市场状态、每周复盘持仓、每笔平仓留下记录，月底回顾规则效果。基本流程无需付费行情接口，即可使用公开 CSV、K 线截图和本地文件运行。项目不代替用户做出买卖决定，而是管理决定过程。作者建议持有 ETF 和分红股且容易管不住手的投资者可借此立规管情绪。

💡 主要观点

  1. 模块化拆解交易流程 将盘面分析、仓位计算、交易日记、复盘等投资环节拆分为独立的 Claude Code Skill，降低认知负荷，提升操作可执行性。
  2. 纪律关卡强制交易规范 在未制定计划、仓位超标或想进行报复性加仓时自动拦截交易行为，迫使投资者反思并记录，有效约束情绪化决策。
  3. 数据来源轻量可行 无需订阅付费行情接口，直接使用公开 CSV、K 线截图和本地文件即可运行，降低使用门槛。
