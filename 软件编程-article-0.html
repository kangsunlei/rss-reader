通过自动 Prompt 优化，以 90 倍成本优势构建顶尖企业智能体

9/24/2025, 9:25:00 PM

📌 一句话摘要

Databricks 展示了 GEPA 等自动提示优化技术如何显著提升企业 AI 智能体的信息抽取性能，使开源模型性能超越竞争对手。

📝 详细摘要

Databricks 在本文中介绍了一种强大的技术：自动 Prompt 优化。该技术旨在提高大型语言模型（LLM）在企业 AI 智能体中的性能和成本效益，尤其是在信息抽取（IE）任务中。文章强调了大规模 IE 的挑战，并提出了“IE Bench”，这是一个反映真实世界企业复杂性的全新综合评估套件。核心创新是 GEPA（基于语言反射的引导式进化提示优化），这是一种由 Databricks 和加州大学伯克利分校开发的新型提示优化技术。实证结果表明，经过 GEPA 优化的开源模型，如`gpt-oss-120b`，在准确性方面超越了领先的专有模型，如 Claude Opus 4.1，提升约 3%，同时服务成本降低高达 90 倍。该方法同样显著提高了专有前沿模型的性能，提升幅度达 6-7%。此外，文章还表明，与传统的监督微调（SFT）相比，自动 Prompt 优化提供了卓越的性价比，并且这些方法可以结合使用以获得更大收益。生命周期成本分析显示，对于大规模部署，一次性优化成本可以快速摊销，使得经过 GEPA 优化的`gpt-oss-120b`成为一种极具成本效益的企业 AI 解决方案。这些强大的功能现已集成于 Databricks Agent Bricks 平台，助力企业构建更高效的 AI 智能体。

💡 主要观点

  1. 自动 Prompt 优化使开源 LLM 能够在实现顶尖性能的同时，显著降低成本。 经过 GEPA 优化的`gpt-oss-120b`优于 Claude Opus 4.1 约 3%，并且服务成本降低 90 倍，使得先进 AI 技术更易于获取，并显著提升成本效益。
  2. 与监督微调（SFT）相比，Prompt 优化提供了卓越的性价比。 它提供与 SFT 相当或更优的性能，但服务成本降低 20%，并且结合使用这两种技术可以进一步提高性能，同时保持效率。
  3. 生命周期成本分析证实，自动 Prompt 优化为大规模企业部署带来可观的长期节省。 一次性优化成本可以快速摊销，从而为经过 GEPA 优化的开源模型带来大幅降低的生命周期成本，这对于生产环境至关重要。

💬 文章金句

  • 经过 GEPA 优化的 gpt-oss-120b 超过了最先进的专有模型 Claude Sonnet 4 和 Claude Opus 4.1 约 3%，而服务成本分别降低了约 20 倍和 90 倍。
  • 自动 Prompt 优化提供的性能与监督微调（SFT）相当或更优，同时将服务成本降低了 20%。
  • Prompt 优化提供了一种不同的方法，利用结构化搜索，在反馈信号的指导下自动改进 Prompt。
  • 生命周期成本分析表明，当大规模提供服务时（例如，10 万个请求），一次性优化开销可以快速摊销，并且收益远远超过成本。
  • Prompt 优化重塑了企业 AI 系统的质量-成本帕累托前沿，在提升性能的同时，显著提高了效率。
