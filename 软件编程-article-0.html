📝 详细摘要

推文介绍了 Holeberry，这是一款专为 macOS 设计的 Pi-hole 管理客户端。它将 Pi-hole 的核心操作（如查看状态、临时停用、放行域名、更新规则）集成到系统菜单栏中，消除了频繁访问 Web 后台的需要，提升了管理便捷性。

  1. 交互体验优化 通过菜单栏常驻的方式，简化了 Pi-hole 这种通常依赖 Web UI 的服务的日常高频操作路径。
