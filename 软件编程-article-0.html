使用 Hugging Face 和 Databricks 构建 GenAI 应用实践

3/26/2025, 6:10:00 PM

📌 一句话摘要

本文介绍如何利用 Hugging Face 模型、Unity Catalog、Model Serving 和 Databricks Apps，端到端地构建和部署生成式 AI 应用。

📝 详细摘要

本文详细介绍如何使用 Hugging Face 模型、Unity Catalog、Model Serving 和 Databricks Apps 构建和部署生成式 AI (GenAI) 应用，并提供详细步骤。文章首先概述了 Databricks Apps，然后通过一个图像转换的生成式 AI 应用示例，逐步讲解了将图像加载到 Unity Catalog 管理的存储卷中、使用 MLflow 在 Unity Catalog 中注册 Hugging Face 模型、使用 Model Serving 部署模型，以及开发 Databricks App 并嵌入模型的过程。文章旨在帮助读者无需高级 Web 应用开发经验，也能将复杂 AI 模型转化为实用的业务应用。

💡 主要观点

  1. 利用 Unity Catalog 管理数据，为 Hugging Face 模型提供数据支持 通过将图像等非表格数据存储在 Unity Catalog 管理的存储卷中，可以集中进行数据治理和控制，确保数据安全。
  2. 通过 MLflow 进行模型注册和版本控制 通过 MLflow pyfunc 封装 Hugging Face 模型，可以方便地将其注册到 Unity Catalog 中，并进行版本管理。
  3. 使用 Model Serving 部署模型，并通过 Databricks Apps 构建用户界面 Databricks Model Serving 提供托管服务，支持将机器学习模型部署为 REST API，实现实时预测。

💬 文章金句

  • With Databricks Apps， developers can build and launch data and AI applications faster， more securely， and with seamless integration into the Databricks Data Intelligence Platform.
  • In this guide， we'll show you how to leverage the power of GenAI and Unity Catalog to build and deploy custom AI applications that can transform your business.
  • Model Serving in Databricks is a fully managed service that allows you to deploy machine learning models as REST APIs.
