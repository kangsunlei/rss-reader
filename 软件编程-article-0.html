Agent Loop 深度调研：把决定权交给模型的一次换代，为什么发生在现在😄

7/3/2026, 12:38:05 AM

📌 一句话摘要

本文从控制权移交视角梳理 LLM 应用的三代范式演变，解释 Agent loop 为何在 2024-2026 年爆发。

📝 详细摘要

文章提出 Agent loop 的核心变化是把「下一步做什么」的判定权从开发者的代码交到模型手里。沿这条控制权移交线，梳理了三代范式：Prompt 时代（全部由开发者写死）→ RAG/框架时代（部分路由由模型决定）→ Agent loop 时代（模型自主规划与结束）。并分析为什么这种结构 2022 年就已存在，却直到近两年才爆发：模型单步准确率跨过可用阈值、MCP 等标准化工具接口降低了集成成本、编码场景率先完成商业验证。文章视角独特，提炼出「上一代主角降级为新范式组件」的规律。

💡 主要观点

  1. Agent loop 改的是控制权：从开发者代码交给模型。 LLM 应用六年来第一次把「下一步做什么、什么时候算完成」的判定权从开发者代码交到模型手里，这是代际变化的本质。
  2. 三代范式遵循「上一代主角降级为新范式组件」的规律。 Prompt 时代是手工编排，RAG/框架时代引入检索和模板，Agent loop 时代模型自主规划，前代技术成为新范式的基础设施。
  3. Agent loop 在 2024-2026 年爆发有三个推动因素。 模型单步准确率过阈值、MCP 标准化工具接口、编码场景先完成商业验证，三者共同促使 Agent loop 从实验室走向生产。
