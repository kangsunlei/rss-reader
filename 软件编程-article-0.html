Node 中文周刊 #238 - Node.js 26.7 发布

📌 一句话摘要

Node 中文周刊 #238 汇总了 Node.js 26.7 与 LTS 发布、Shai-Hulud 蠕虫事件、vlt 1.0、anydoc 工具及调试技巧等生态动态。

📝 详细摘要

本期周刊首先介绍了 Node.js 26.7.0（Current）及 v24.19.0 LTS 的更新内容，包括测试覆盖率增强、FFI 与 SQLite 修复以及 Perfetto 跟踪支持。随后报告了名为 Shai-Hulud 的凭据窃取蠕虫利用伪造的 keyv 6.0 发布进行传播，影响 keyv 及 400+ 个 npm 包，并提醒 npm v12、pnpm 与 vlt 默认阻止安装脚本可防御此类攻击。接着重点推出了 vlt 1.0，该工具提供类 CSS 选择器的依赖图查询功能及托管私有注册表。随后介绍了 anydoc 库，能够将 Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV、PDF 等 14 种文档格式转换为 Markdown，并提供浏览器内演示。此外，还包含了一则调试卡住 Node.js 进程的技巧、Express 安全更新、net.BlockList 性能提升、Web Worker API 移植提案以及多个工具库的版本发布（如 ioredis v6.0、MicroDiff v1.6、Devalue v5.9 等）。整体以链接与简短描述的形式呈现，旨在让开发者快速捕获近期 Node.js 生态的重要更新。

💡 主要观点

  1. Node.js 26.7.0 与 v24.19.0 LTS 发布，带来测试覆盖率增强、FFI/SQLite 修复及 Perfetto 跟踪支持。 新版本通过 --test-coverage-include-all 让未被测试触及的文件也参与覆盖率报告；修复了 FFI 与 SQLite 导致的崩溃；Perfetto 跟踪需自定义构建才能使用。
  2. Shai-Hulud 蠕虫卷土重来，利用伪造的 keyv 6.0 发布传播，影响 keyv 及 400+ 个 npm 包。 该蠕虫依赖安装脚本运行进行凭据窃取；npm v12、pnpm 与 vlt 默认阻止安装脚本，可有效防御此类攻击。
  3. vlt 1.0 发布，提供类 CSS 选择器的依赖图查询及托管私有注册表服务。 vlt query 支持 60 多种类 CSS 选择器（其中一半与安全相关），帮助开发者审计依赖；同时提供托管的私有包注册表，提升私有包管理体验。
  4. anydoc 库可将 14 种文档格式转换为 Markdown，提供 Node.js 与 WASM 绑定及浏览器演示。 支持 Word、PowerPoint、Excel、OpenDocument、RTF、EPUB、CSV、PDF 等格式转换；示例显示处理 1600 页 PDF 仅需约 2 秒，适合文档迁移与内容统一。
  5. 调试卡住 Node.js 进程的技巧：捕获永不退让的事件循环阻塞器。 文章介绍了一种通过特定工具或方法定位导致事件循环被长时间占用的代码，帮助开发者快速定位并解决线程卡死问题。
