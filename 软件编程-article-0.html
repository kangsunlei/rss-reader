DeepLethe 开源 Utopia：带时间线的企业知识图谱工具

9/7/2026, 12:00:13 AM

📌 一句话摘要

DeepLethe 开源的 Utopia 是一款带时间线的企业知识图谱工具，支持多格式文档上传、多源同步，可追溯事实来源与版本，支持多模型和内网部署。

📝 详细摘要

传统企业知识库仅存储当前状态，难以追溯历史决策的依据与变更口径。DeepLethe 开源的 Utopia 定位为企业世界模型，本质是带时间线的知识图谱，每条事实会记录生效时间与来源文件，修改错误时不覆盖旧版本，同时留存事实真实时间线与系统认知时间线。它支持 10 余种格式文档上传，可定时同步网页、RSS、GitHub、Jira、Notion 等多源数据，问答结果带引用可跳转原文；重复实体支持分步合并且每一步可撤销，冲突事实会标注后由人工选择处理方式；还可关联 PostgreSQL、MySQL 等数据库进行联合查询，仅需 Rust 程序加 Postgres 即可部署，支持 DeepSeek、Qwen、Ollama 等模型，可整套部署在内网。项目 README 开头专门声明不愿被称为开源版 Palantir，项目 GitHub 仓库已公开。

💡 主要观点

  1. Utopia 核心是带时间线的知识图谱，解决企业知识库无法追溯历史决策的问题 每条事实记录生效时间与来源文件，修改错误时不覆盖旧版本，同时留存事实真实时间线与系统认知时间线
  2. 支持多源数据接入与关联查询 支持 10 余种格式文档上传，可定时同步网页、RSS、GitHub、Jira、Notion 等源，还可关联 PostgreSQL、MySQL 等数据库，问答结果带引用可跳转原文
  3. 部署灵活且支持多模型适配 仅需 Rust 程序加 Postgres 即可运行，支持 DeepSeek、Qwen、Ollama 等模型，可整套部署在内网
  4. 实体与冲突处理人性化 重复实体分三步合并且每一步可撤销，冲突事实会标注后由人工选择处理方式

💬 文章金句

  • 公司里的知识库只记「现在是什么」，去年那个决定当时依据哪份材料、后来怎么改的口径，翻不出来。
  • 改错不覆盖，旧版本关掉、新版本接上，图谱同时留两条线:这件事在现实里何时为真，系统又是何时才知道的。
