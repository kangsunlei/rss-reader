Zed 编辑器通过 ACP 协议一站式管理所有 Code Agent

5/2/2026, 12:04:04 AM

📌 一句话摘要

Zed 编辑器原生支持通过 ACP 协议集成多种 AI 编程助手，提供比 VS Code/Cursor 加插件更统一的 Code Agent 管理体验。

📝 详细摘要

这条推文介绍了 Zed 编辑器的一个实用功能：它原生支持通过 ACP 协议直接集成 Claude Code、Codex、Gemini、OpenCode、Cursor CLI 以及 Pi Agent 等主流 AI 编程助手，甚至支持国产的 Kimi CLI 和 Qoder CLI。作者认为，这种原生集成的体验优于 VS Code 或 Cursor 通过插件实现的方式，并且 Zed 还支持导入其他代码工具的历史会话，实现了一站式管理所有 Code Agent 的能力。
