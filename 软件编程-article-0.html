一人组建一支 Agent 军团，狂揽 11.9 万 Star!

6/30/2026, 10:45:00 AM

📌 一句话摘要

本文介绍开源项目 The Agency，它提供 232 个覆盖开发、设计、产品等部门的 AI Agent 角色定义，并配有桌面客户端，帮助用户按需组建 AI 团队。

📝 详细摘要

文章介绍了开源项目 The Agency，该项目由作者在 Reddit 上发起，基于社区需求构建了 232 个 AI Agent 角色，分为 16 个部门，涵盖开发（前端、后端、架构师等）、运营（增长黑客、内容创作等）、设计（UI/品牌/视觉设计师）、产品（产品经理、需求排期等）、测试（功能/性能/接口测试等）等常见岗位。每个 Agent 并非简单的提示词，而是包含完整的角色定义、工作流和交付质量指标。项目配套有桌面客户端 Agency Agents，支持 Windows/macOS/Linux，用户可按需选取并安装 Agent，兼容 Claude Code、Codex、Cursor 等主流 AI 编程工具。文章认为该项目的价值在于将专业的经验沉淀为可复用的 Agent 定义，降低跨领域学习成本，让个人能像管理团队一样编排 AI 角色。

💡 主要观点

  1. The Agency 项目提供了 232 个覆盖多角色的 AI Agent 定义。 这些 Agent 分为开发、设计、运营、产品、测试等 16 个部门，每个角色包含完整的语气、工作流、交付标准和衡量指标。
  2. 项目配套桌面客户端，支持按需选择和安装 Agent。 用户通过桌面应用可按需安装所需 Agent，避免全部加载导致的上下文溢出，兼容 Claude Code、Codex、Cursor 等主流 AI 编程工具。
  3. 项目的核心价值在于将专业经验沉淀为可复用的 AI 角色定义。 作者将过去藏在专业人士脑子里的经验，变成可直接使用和自定义修改的 Agent 文件，降低跨领域学习和项目搭建的门槛。

💬 文章金句

  • 一个人的能力总是有限的，不可能每个领域都懂，如果去学习又极其消耗时间。现在缺哪一块知识，就直接安装对应 Agent，这样一个人也能是一个团队。
  • 说实话，The Agency 最有意思的地方，其实并不是拥有 232 个 Agent 角色。而是作者把过去一个个藏在专业人士脑子里的经验，变成了人人都能直接拿来用，还能照着改的东西。
