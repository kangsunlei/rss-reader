📝 详细摘要

这条推文是一个重要的后续，详细阐述了前一条推文中确定的第三个技术问题：云连接性较差。Rauch 解释说，当无服务器函数与外部云服务交互时，例如数据库（Supabase、PlanetScale、Neon）或 API (Stripe)，Vercel Fluid 相对于 Cloudflare Workers 等边缘平台的云内延迟优势会更加明显。他认为，将核心应用程序逻辑定位在“边缘”不仅在运行时方面是一个错误，而且在计算位置方面也是一个错误，这主要是由于累积的 I/O (输入/输出) 瀑布和 CPU (中央处理器) 性能限制。
