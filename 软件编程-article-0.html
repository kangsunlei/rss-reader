为什么说多模态是推荐系统破局的关键？来自饿了么一线的实战复盘

11/11/2025, 12:31:00 AM

📌 一句话摘要

饿了么团队通过三阶段训练和双塔模型，成功构建并实战多模态推荐系统，有效提升了本地生活场景下的推荐效果。

📝 详细摘要

文章深入探讨了推荐系统从传统 ID 特征向多模态智能推荐的演进，并详细复盘了饿了么首页店铺推荐场景下多模态推荐系统的设计与实现。作者首先回顾了传统推荐算法的局限性（如冷启动和语义信息缺失），随后梳理了多模态推荐领域的技术发展，包括 AlignRec、SimTier、MAKE、QARM 等代表性工作，并分析了它们在多模态表征对齐和稠密/稀疏特征融合上的不同策略。文章进一步介绍了文本表征（Encoder-only 与 Decoder-only）和视觉表征（CNN 与 Transformer）的核心方法，以及图文多模态表征的协同与联合范式（CLIP、ALBEF、VLM2Vec、GME）。在此基础上，文章重点阐述了饿了么团队在首页店铺推荐场景下的多模态推荐实践，包括基于搜索行为的商户表征建模和三阶段训练策略：第一阶段是领域适配预训练，构建商品级、商户级和混合级图文对齐；第二阶段是行为驱动微调，通过 Query-Image、Query-Text、Query-Fusion 多路对齐用户偏好；第三阶段是利用 SimTier 和 MAKE 技术融合多模态与传统 ID 特征。文章还分享了建模、视觉压缩和文本特征提取等方面的编码实践经验。最终，该方案在离线评估中显著提升了 Recall@k 和 AUC 指标，验证了多模态推荐在本地生活场景的巨大潜力。

💡 主要观点

  1. 多模态推荐是解决传统推荐系统冷启动和语义理解不足的关键。 通过引入图像、文本等多模态内容信息，能有效弥补 ID 特征的局限性，提升推荐的精准度和用户体验，尤其对新物料和长尾内容价值显著。
  2. 多模态表征对齐与特征融合是核心技术挑战，业界已形成多种解决方案。 不同的技术路线在对齐策略（基于 ID 交互、语义交互、联合训练）和融合方案（量化编码、相似度分桶、特征聚合）上各有侧重，以平衡语义纯粹性与行为适配性。
  3. 饿了么采用三阶段训练策略构建多模态推荐系统，适配本地生活场景。 包括领域适配预训练、行为驱动微调和多模态与 ID 特征融合，确保模型能从多粒度、多维度有效学习和利用商户和商品的多模态信息。
  4. 双塔式 EVL-sep 模型在饿了么场景下效果显著，超越大型通用模型。 尽管使用较低维度的表征向量，但通过精细设计的双塔架构和多路对齐训练策略，在跨模态检索和用户偏好匹配方面表现出色，尤其在混合意图查询场景下优势明显。
  5. 有效的编码实践和 SimTier+MAKE 特征融合优化是高性能推荐系统的关键。 灵活初始化、视觉压缩层优化、文本特征提取与 T5 融合架构，以及 SimTier+MAKE 技术，共同确保了多模态信息与传统 ID 特征的有效整合和系统的高效运行。

💬 文章金句

  • 推荐系统开始从单纯依赖用户行为 ID 特征转向充分利用商品图像、文本描述等丰富内容信息的新范式。
  • 多模态特征的引入主要解决了传统推荐系统的三大痛点：长尾 item 和长尾用户的行为序列数据不足问题、新 item 和新用户的冷启动问题、跨场景的推荐特征迁移问题。
  • 业界在多模态推荐的两大核心挑战上形成了不同的技术路线：一是多模态表征对齐策略，二是如何有效融合稠密语义特征与稀疏 ID 特征。
  • 双塔式模型在跨模态检索任务上达到 90.8% 的整体召回率，显著优于 SOTA 通用模型 GME-qwen2-vl-7b（3584 维）的 66.5%。
  • 经过第三阶段特征融合优化的联合训练，为推荐系统离线 AUC 指标带来显著提升：全量商户 CTCVR AUC +0.19%，CTR AUC +0.17%。
