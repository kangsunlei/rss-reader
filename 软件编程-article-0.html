吴恩达评 Agent 现状：MCP 尚处“蛮荒”，单 Agent 跑通已是“奇迹”，A2A 协作堪称“双重奇迹”

5/31/2025, 2:42:00 AM

📌 一句话摘要

吴恩达与 Harrison Chase 对话，探讨 AI Agent 构建挑战、工具体系、MCP 及未来趋势，强调评估与技术能力重要性。

📝 详细摘要

文章总结了吴恩达与 LangChain 创始人 Harrison Chase 关于 AI Agent 现状及未来构建的深度对话。他们提出将“Agent”视为一个“Agenticness”光谱，并指出当前主要机会集中在简单线性业务流程的自动化。构建 Agentic 系统的核心挑战在于任务分解、流程编排及评估机制的搭建，尤其强调系统性评估对快速定位问题的关键作用。文中类比 AI 工具为“乐高积木”，强调熟练组合多样化工具的重要性，并指出 RAG 等技术的最佳实践正随 LLM 进化而改变。对话中认为 MCP 是填补市场空白的重要一步，有望标准化工具、API、数据源集成，但尚处早期；Agent 间通信则更早期。他们还讨论了语音交互作为一种新的交互方式，其独特优势在于降低用户输入门槛，但也对系统实时性（延迟）提出了更高要求。此外，他们强调 AI 辅助编程能显著提升开发者效率，同时呼吁学习基础编程仍旧重要。最后，吴恩达分享了 AI 创业成功的关键因素：速度和技术能力。

💡 主要观点

  1. AI Agent 应视为“Agenticness”光谱，关注其自主性程度而非严格定义 与其纠结系统是否符合严格的 Agent 定义，不如将“代理性”视为一个光谱，关注其自主性强弱，这有助于社区更快进入实操阶段并专注于构建。
  2. 高效 Agent 构建依赖任务拆解、流程编排与系统性评估 从复杂任务中分解微步骤、设计工作流结构，并建立端到端和步骤级的评估机制是关键，能快速定位问题和提升效率，避免走弯路。
  3. AI 工具多样化如“乐高积木”，熟练组合能力决定构建复杂系统效率 当前 AI 工具丰富多样，开发者需要熟悉并高效组合不同的工具和组件来解决特定问题。有经验的团队能凭借丰富的“积木”储备和组合能力更快找到最优解。
  4. MCP 和 Agent 间通信尚早期，但 MCP 标准有潜力连接工具与数据源 MCP 有望标准化工具、API 和数据源的集成，减少 n×m 的连接工作量，但目前实现和身份验证等仍待成熟。Agent 间通信则挑战更大，跨团队协作尤为困难。
  5. 语音交互是 AI 应用层的重要方向，降低门槛但对延迟要求高 语音作为交互方式可以降低用户“自我审查”和输入门槛，更容易获取信息。但语音系统对实时性要求极高，需应对延迟挑战，可通过预回应、背景音等技巧优化用户体验。
  6. AI 辅助编程显著提升开发者效率，但基础编程技能仍不可或缺 AI 编码助手极大地提高了编程效率，已成为不可或缺的工具。然而，理解底层原理、错误信息仍需编程基础，学习编程对于清晰指令计算机和有效调试至关重要。
  7. AI 创业成功的关键预测因素是速度和技术能力 吴恩达的 AI Fund 经验表明，创业公司能否快速执行和团队深厚的技术理解力（尤其是在快速演进的 AI 领域）是决定成败的首要因素。

💬 文章金句

  • 与其花那么多时间争论这个是不是 Agent，不如我们整个社区换个方式思考：把“Agenticness（代理性）”看作一个光谱------有些系统代理性强，有些弱。
  • 一个很重要但常被忽略的点是：要搭建一个正确的 Eval（评估）体系，不只是评估整个系统的效果，还要能追踪每一步骤，这样你才能快速定位“是哪一步坏了”，“是哪个 Prompt 没有发挥作用”。
  • 你拥有的积木越丰富，组装成复杂结构的能力就越强。
  • 如果说 MCP 还早期，那 Agent 间通信就更早期了。
  • 如果你回顾过去几十年的编程发展历史，每一次编程门槛降低，都会让更多人开始学习编程。
