Vercel 插件支持 OpenAI Codex 和 Codex CLI - Vercel

3/27/2026, 12:02:04 AM

📌 一句话摘要

Vercel 的编程智能体插件现已集成 OpenAI Codex 和 Codex CLI，提供实时代码验证和专业智能体支持。

📝 详细摘要

Vercel 宣布其 Vercel 插件已扩展对 OpenAI Codex 和 Codex CLI 的支持。此次更新使开发团队能够利用超过 39 种平台特定技能和 3 个专为简化工作流程而设计的智能体。主要功能包括实时代码验证，以及通过 Codex 插件市场无缝集成到现有的开发环境中，旨在协助团队优化部署和开发周期。

💡 主要观点

  1. 与 OpenAI Codex 和 Codex CLI 集成。 开发者现在可以直接在 Codex 工具中使用 Vercel 插件，以提升编码工作流程和部署速度。
  2. 访问专业智能体和平台技能。 该插件提供了 3 个专业智能体和 39 种平台技能，以协助完成各种开发任务和平台特定的优化。
  3. 实时代码验证。 此次集成包含在开发过程中对代码质量和正确性提供即时反馈的功能，从而减少部署错误。

💬 文章金句

  • Vercel 插件现已支持 OpenAI Codex 和 Codex CLI。
  • 通过该插件，团队可以访问超过 39 种平台技能、3 个专业智能体以及实时代码验证功能，以辅助开发工作流程。
  • 从 Codex 插件市场中安装它。
