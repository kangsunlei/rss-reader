Chrome 151 彻底终结旧版扩展：uBlock Origin 时代落幕

6/13/2026, 7:21:14 PM

📌 一句话摘要

Chrome Canary 151 版本彻底终结 Manifest V2 扩展支持，标志 uBlock Origin 等经典扩展在 Chrome 中正式落幕，但经过六年过渡，多数主流扩展已完成 MV3 迁移，普通用户影响有限。

📝 详细摘要

文章报道了 Chrome Canary 151 版本彻底移除 Manifest V2 扩展支持的消息，意味着 uBlock Origin 等经典扩展无法再通过命令行参数启用。作者实测确认正式版 149 仍可启用，Beta 版 150 已失效。文章梳理了受影响的主要扩展（uBlock Origin、AdGuard、Tampermonkey 等），回顾了 Google 从 2020 年起推动 MV3 的六年过渡历程，并指出多数主流扩展已完成 MV3 迁移（如 uBlock Origin Lite、Tampermonkey 5.x）。文章还讨论了 Edge 和 Firefox 的现状，认为 Firefox 难以因此获得大量新用户，而普通用户可能根本感受不到这次变化。

💡 主要观点

  1. Chrome 151 彻底终结 Manifest V2 扩展支持。 实测确认 Canary 151 无法通过命令行参数启用旧版扩展，正式版 149 仍可，Beta 150 已失效，标志六年过渡期结束。
  2. 多数主流扩展已完成 MV3 迁移，普通用户影响有限。 uBlock Origin Lite、AdGuard MV3、Tampermonkey 5.x 等均已适配 MV3，除少数坚持旧技术的项目外，用户几乎无感知。
  3. Firefox 难以因 Chrome 弃用 MV2 而获得大量新用户。 Firefox 已沦为小众浏览器，且用户使用浏览器的场景本身在减少，加上已有 MV3 替代品，迁移动力不足。

💬 文章金句

  • Chrome 用户没有离开 Chrome，开发者自然也不会离开 Chrome。
  • 经过六年的过渡期，大部分主流扩展都已经推出了 Manifest V3 版本。
