Vercel 通过 Markdown 渲染为 AI 智能体优化网页内容

1/29/2026, 7:22:49 PM

📌 一句话摘要

Vercel CEO Guillermo Rauch 宣布为智能体提供自动 Markdown 渲染功能，将页面大小从 500 kb 缩减至 2 kb，显著提升效率。

📝 详细摘要

Guillermo Rauch 探讨了“智能体网页”（Agent Web）的概念，即 AI 智能体主要以 Markdown 而非沉重的 HTML 形式消费内容。他透露，Vercel 已为其更新日志和文档实现了面向智能体的自动 Markdown 渲染，使数据负载量大幅减少了 99%（从 500 kb 降至 2 kb）。他还提供了一个实用的 curl 命令，方便开发者通过 'accept: text/markdown' 请求头来测试这种内容协商机制。
