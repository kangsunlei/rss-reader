Agent 时代的 HTTP 来了？谷歌 A2A 开源协议打破企业间 Agent 壁垒，OpenAI 系缺席标准之战

4/12/2025, 7:08:12 AM

📌 一句话摘要

谷歌开源 A2A 协议旨在打破企业间 Agent 壁垒，实现 AI 智能体的互操作性，构建企业级智能系统，但 OpenAI 系公司缺席或影响其广泛应用。

📝 详细摘要

谷歌推出了 Agent2Agent (A2A) 协议，旨在解决不同 AI 智能体之间无法有效协作的问题，实现不同平台和生态中 AI 智能体之间的安全和标准化协作，从而打破智能体之间的壁垒。A2A 协议是开源的，并与多家公司共同开发，目标是实现跨平台、多模态的协同工作，使智能体能够彼此通信、发现对方能力、协商任务分配，并协作完成复杂的企业级流程。该协议依赖于关键能力，例如“能力发现：智能体可以通过 Agent Card 展示能力，以便客户端智能体选择最佳远程智能体”。A2A 协议采用社区驱动的开发模式，并与 Anthropic 的 MCP 协议互补。尽管 OpenAI 系公司缺席，谷歌仍然欢迎其他致力于智能体互操作性协议的联盟合作。

💡 主要观点

  1. A2A 协议旨在实现跨平台 AI 智能体的互操作性。 该协议允许不同平台和生态中的 AI 智能体进行安全、标准化的协作，促进智能体之间的通信、能力发现和任务分配。
  2. A2A 协议依赖于能力发现、任务管理、协作和用户体验协商等关键能力。 这些能力确保智能体可以展示自身能力、管理任务生命周期、进行上下文回复和协商用户体验，从而实现有效的协同工作。
  3. A2A 协议与 MCP 协议互补，共同构建智能体生态系统。 A2A 聚焦于智能体之间的通信，而 MCP 则有助于连接工具和资源，二者共同促进更完善的智能体生态系统的发展。
  4. A2A 协议的开源和社区驱动模式，旨在促进更广泛的采用和持续发展。 通过开放源代码和接受社区贡献，A2A 协议能够更快地适应新的使用场景和应用需求，从而实现更广泛的采用。

💬 文章金句

  • Agent2Agent 协议旨在实现不同平台和生态中的 AI 智能体之间的安全、标准化协作，无论它们基于何种框架或由哪家公司构建。
  • 我们认为 MCP 和 A2A 是互补的功能，我们看待 Agent2Agent 的方式是将其置于更高的抽象层，以使应用程序和智能体能够相互通信。
  • 所有这些协议都将持续演进，特别是在 AI 发展速度如此之快的背景下，我们将不断发现新的使用场景和应用需求，这也将推动协议持续发展。
