📌 一句话摘要

Arnis 是一个 GitHub 开源项目，可将 OpenStreetMap 上的真实地理数据（地球、月球、火星）转换为《我的世界》中的方块世界，用户可下载桌面端软件，框选区域生成可游玩的地图。

📝 详细摘要

Arnis 读取开放地图 OpenStreetMap 记录的道路、建筑和地形信息，结合高程数据，将真实世界转换为 Minecraft 风格的方块世界，支持地球、月球和火星等行星。该项目已获得约 1.7 万星，提供 Windows/macOS/Linux 桌面端客户端，生成的世界可用于 Java 版和基岩版。生成效果取决于源地图数据的详细程度，数据丰富的地区（如标志性景点）效果更佳，数据不足的区域则可能出现细节缺失。用户通过下载发布页版本、启动软件、框选区域和生成世界即可获得可游玩的地图。项目还扩展到月球和火星地形，使用 NASA 的月表和 MOLA 高程数据，并按比例缩放方块尺寸和材质以反映表面特征。

💡 主要观点

  1. Arnis 可将 OpenStreetMap 上的真实地理数据（地球、月球、火星）转换为《我的世界》中的方块世界。 该项目读取 OpenStreetMap 记录的道路、建筑轮廓等信息，结合高程数据，按规则生成游戏内的方块地形，支持多种行星。
  2. Arnis 开源项目在 GitHub 上获得约 1.7 万星，提供 Windows、macOS 和 Linux 桌面端客户端。 高星数表明社区认可，其跨平台支持方便用户下载并生成适用于 Java 版和基岩版的 Minecraft 世界。
  3. 生成效果与源地图数据的详细程度密切相关，数据丰富的地区（如标志性景点）效果更好。 OpenStreetMap 的信息完整度影响复刻的精度，数据不足的区域（如部分中国地区）可能出现细节缺失。
  4. 用户通过下载发布页版本、启动软件、框选区域和生成世界即可获得可游玩的地图。 操作流程包括四步：下载、打开软件、矩形选区和等待生成，最后可在 Minecraft 中打开生成的世界进行探索。
  5. 项目还扩展到月球和火星地形，使用 NASA 的月表和 MOLA 高程数据，并按比例缩放方块尺寸和材质。 月球方块水平代表 200 米，垂直放大 4 倍；火星方块水平代表 500 米，材质区分沙尘、岩壁、冰雪等表面特征。
