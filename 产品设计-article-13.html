坏了！卖 Token 的核心机密被老马学到了

7/11/2026, 2:00:00 AM

📌 一句话摘要

本文分析 Grok 4.5 的定价策略，指出马斯克借鉴了中国模型厂的「性价比」打法，并延伸讨论 AI 行业从「谁更聪明」转向「谁能干活、谁占入口、谁收钱」的竞争逻辑变迁。

📝 详细摘要

文章围绕 SpaceXAI 发布 Grok 4.5 展开，核心论点是中国模型厂（DeepSeek、智谱、MiniMax 等）最早践行的「性价比」定价策略正在被硅谷主流采纳。作者拆解了三个递进层次：其一，Grok 4.5 以每百万 token 输入 2 美元、输出 6 美元的定价切入 coding agent 市场，比 Opus 4.8 max 节省 4.2 倍 token，这是「入口」而非「低端」；其二，同日 OpenAI 审计 SWE-Bench Pro 暴露 benchmark 失信问题，将竞争焦点推向真实工作流验证；其三，IDE 正在成为新的「收银台」，Cursor、Claude Code、Codex 等工具将模型调用打包为可计费的开发账单。作者认为，评测权、入口权、计费权正在合流为同一战场，AI 的竞争本质已从「智能涌现」转向「经济可验证的任务完成能力」。

💡 主要观点

  1. 性价比是中国模型厂的核心机密，Grok 4.5 将其包装成硅谷叙事。 DeepSeek、阿里、百度等厂商以低价切入市场，核心逻辑是 coding agent 进入 IDE 后每次调用都叠加成本，低 token 消耗是真实入口。Grok 4.5 借鉴了这套语言，但用 SpaceXAI 的品牌叙事重新包装。
  2. OpenAI 审计 SWE-Bench Pro 暴露 benchmark 失信，将竞争推向真实工作流。 OpenAI 发现新评测集约 30% 任务有问题，不再建议将其作为可靠标准。这客观上把「真实任务 + 价格验证」推到台前，企业采购逻辑从「榜单第几」转向「跑完真实任务花了多少钱」。
  3. IDE 正在成为新的收银台，计费权从 API 移向开发入口。 Cursor 将 agent 请求、模型调用、团队用量打包为账单中心；Codex 数据显示并发 agents 使用率快速上升。模型厂的竞争从 API 定价权延伸到 IDE 默认模型位和工作流集成权。
  4. 评测权、入口权、计费权正在合流为同一战场。 当 benchmark 不再可信，企业信任从榜单转向真实验证；谁占住 IDE 入口、谁定义「能干活」的标准、谁收走每次任务调用的钱，三者正在合流。竞争本质已从「谁更聪明」变为「谁能经济地完成任务」。

💬 文章金句

  • 便宜不是低端，是入口，是真的让普通人能用起来的可能性。
  • 旧 benchmark 信不过了，企业不会因此停止采购 agent。它们会换一种问法：别告诉我你榜单第几，先让我看一个真实任务，跑完到底花了多少钱。
  • 评测权、入口权、计费权，正在变成同一个战场。
