全新 Figma 工作流：代码与设计的双向同步

3/25/2026, 3:01:44 PM

📌 一句话摘要

实操演示 Figma 全新 MCP 服务器与 Claude Code 的集成，实现代码自动生成 Figma 设计稿及设计变更回写代码的双向闭环工作流。

📝 详细摘要

本视频介绍了 Figma 最新发布的 MCP（模型上下文协议）服务器功能，结合 Claude Code 实现了 Web 代码与 Figma 设计文件之间的双向同步。演示的完整工作流分两个方向：第一，在 Claude Code 中安装配置 Figma MCP 服务器后，通过 AI 提示词从线上 Web 项目自动提取 CSS 设计 Token，并在 Figma 中以 Auto Layout 和变量绑定的方式 1:1 还原页面布局；第二，在 Figma 中完成设计调整（修改背景色、新建 Token、去除边框）后，将 Figma 框架链接提供给 Claude Code，由 AI 读取设计变更并自动更新代码库。演示者指出，由于 LLM 的非确定性，有时需要二次提示才能完美还原，但整体工作流验证了代码与设计双向联动的可行性。视频最后包含相关付费课程的推广内容。

💡 主要观点

  1. Figma 新 MCP 服务器让 Claude Code 能将网页代码自动转换为 Figma 设计稿。 在 Claude Code 中安装 Figma MCP 服务器后，可通过 AI 指令提取网页 CSS 设计 Token，并在 Figma 文件中自动创建匹配的变量和 Auto Layout 框架，完整还原现有设计系统。
  2. 设计 Token 和变量从全局 CSS 中自动提取并绑定，保持设计系统一致性。 工作流要求 AI 从全局 CSS 重新绑定 Token、创建对应 Figma 变量，并为所有框架启用自动布局，生成的 Figma 文件继承既有设计系统，避免硬编码数值。
  3. 双向同步让 Figma 中的设计改动能直接回写至代码库。 在 Figma 完成调色、新建 Token 等操作后，将框架链接提供给 Claude Code，AI 可读取设计变更并更新设计系统和代码，实现真正的设计-开发闭环。
  4. 工作流可用但存在非确定性，复杂修改可能需要二次提示才能精准还原。 受 LLM 概率特性影响，首次尝试将设计变更同步回代码时可能存在偏差，需要补充提示引导 AI 正确识别颜色和布局调整。
