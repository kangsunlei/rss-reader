📌 一句话摘要

文章介绍了开源项目 story-to-handdrawn-video 的功能原理和使用方法，展示了如何将中文故事或插画转化为手绘动画视频，解决了手绘视频制作中重复操作的问题。

📝 详细摘要

文章详细介绍了 story-to-handdrawn-video 开源项目，这是一个将中文故事或插画制作成 3:4 竖屏手绘视频的工具。项目由 Agent Skill 和 Remotion 渲染器两部分组成，AI 负责准备画面，程序负责让画面按照规则动起来。文章阐述了该项目如何通过拆分镜、保留原文、扩展画风库、提供两种动画方式（逐层展开和翻书转场）等功能，帮助创作者高效制作手绘视频。同时指出该项目不提供配音、音乐等完整后期服务，仍需创作者参与文字校对、人物连续性检查等工作。

💡 主要观点

  1. 项目由 Agent Skill 和 Remotion 渲染器两部分组成，AI 负责准备画面，程序负责让画面按照规则动起来 这种分工模式避免了直接使用文生视频模型生成动画，已确认的图片可以作为素材继续制作和调整，提高了制作效率和可控性
  2. 支持两种动画方式：逐层展开和翻书转场，适合不同素材需求 逐层展开模式将文字、黑白画稿、彩色插画依次出现，适合强调步骤或情绪推进；翻书模式保留完整页面，从右下角卷起露出下一页，适合绘本、漫画等排版完整的素材
  3. 扩展了 297 条画风配方和 30 套主题配色，涵盖日记、线描、彩铅、水墨、水彩等多种风格 这些配方是围绕线条、画材、造型和颜色整理的视觉规则，减少了反复描述风格的工作，但仍需注意角色参考和必要的重生成
  4. 已有插画也能直接做视频，不必重新生图 对于长期做图文的创作者，这是一种值得尝试的内容复用方式，翻书模式可以直接使用完整页面，逐层揭示模式则需要可靠地区分文字区与插画区
  5. 项目采用 MIT 许可证，但实际制作仍可能涉及生图服务、Agent 使用等成本 Remotion 有自己的许可规则，个人、小型团队和较大组织的使用条件不同，商业项目应核对适用条款；文字准确性、人物连续性等仍需创作者把关

💬 文章金句

  • 它将 Agent Skill 与 Remotion 渲染器结合起来，支持把中文故事或已经画好的图片，制作成 3:4 竖屏手绘视频
  • AI 负责准备画面，程序负责让画面按照规则动起来
  • 分镜可以先看，画风可以复用，素材可以导入，预览确认后再输出正式画面轨
  • 真正有价值的自动化，不是让人完全不看过程，而是把重复操作交给工具，让人有更多时间判断故事好不好看
