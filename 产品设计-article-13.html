OpenCode 中文翻译误导：请求数不等于请求次数，真实用量最多 60 美金/月

5/2/2026, 12:19:10 PM

📌 一句话摘要

Ding 指出 OpenCode 的中文翻译存在误导，澄清其 API 费用是按请求次数而非请求数计算，真实月消费上限为 60 美元。

📝 详细摘要

这条推文针对 OpenCode（一个 AI 编程工具）的中文翻译问题进行了澄清。Ding 指出，OpenCode 的中文翻译将「请求数」和「请求次数」混淆，导致用户误解其 API 费用计算方式。他明确说明，OpenCode 的真实用量上限是每月最多 60 美元，而非按请求数计费。这条推文对于正在评估或使用 OpenCode 的开发者具有重要的实用价值，能够帮助他们避免因误解而产生的额外费用。
