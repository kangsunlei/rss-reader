📌 一句话摘要

Dominik Rose 探讨了 AI 时代 B2B SaaS 产品管理的演进，重点强调了模型上下文协议 (MCP) 作为智能体工作流和商业模式转型的关键桥梁作用。

📝 详细摘要

本文总结了 LeanIX 产品总监 Dominik Rose 关于产品经理 (PM) 面向 2026 年战略转型的演讲。文章介绍了模型上下文协议 (MCP)，将其比作标准化的“USB 接口”，允许 AI 智能体安全地访问 Confluence 和 API 等各种系统中的企业数据。Rose 讨论了从云原生到 AI 原生架构的转变，并以 LeanIX 实施 MCP 服务器为例，展示了如何在不托管大型 LLM 的情况下实现客户驱动的 AI 用例。此外，文章还探讨了 AI 对传统按席位计费模式构成的生存威胁，并概述了 PM 的六项核心能力，强调了技术素养、架构投入和以客户为中心的领导力。

💡 主要观点

  1. 模型上下文协议 (MCP) 是 AI 智能体集成的关键基础设施。 MCP 充当标准化的接口（类似于“USB 接口”），使 AI 智能体能够即时与企业数据和 API 交互，从而超越简单的聊天界面，实现功能性的系统执行。
  2. AI 正在迫使定价模式从按席位计费向按价值计费发生根本转变。 由于 AI 智能体可以通过单个界面或 API 整合多个用户的工作，传统的按用户许可模式将变得过时，这要求 B2B 公司重新定义衡量和获取价值的方式。
  3. 对协议和架构的技术素养现在是产品经理不可或缺的技能。 未来的产品经理必须理解 MCP 和智能体对智能体 (A2A) 协议等底层技术标准，以便设计出超越简单 UI 套壳的、可扩展、安全且具有互操作性的 AI 产品。
  4. B2B AI 的成功取决于“架构投入”而非“模型托管”。 LeanIX 的成功表明，为企业客户提供正确的连接性和架构框架（如托管 MCP 服务器），比开发专有的 LLM 更有价值。

💬 文章金句

  • 你可以将 MCP 视为智能体的 USB 插头。通过这个插头，智能体可以即时访问数据并变得更加聪明。
  • 如果你的定价模式是按席位计费的，AI 可能会给你沉重打击……它将迫使 B2B 公司重新思考如何衡量业务价值。
  • 产品开发仍然是一项团队运动。虽然 AI 提高了个人效率，但打造伟大的产品仍需要与工程和设计团队进行密切沟通。
  • 人的价值仍然是核心：产品经理对商业模式、客户需求、财务指标和技术趋势的综合理解是不可替代的。
