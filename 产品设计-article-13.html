AI 小白：如何用 1-2 个 Agent 搞定日常工作？

7/23/2026, 12:42:00 AM

📌 一句话摘要

本文通过作者使用 Trae Agent 完成培训备课、PPT 制作及飞书同步的全过程，展示如何用 1-2 个 AI Agent 简化日常工作流。

📝 详细摘要

作者以 AI 小白的身份，详细记录了使用 Trae Agent 进行下载安装、模型购买与配置、通过反复调整提示词生成教学大纲、逐字稿及 PPT，以及如何授权飞书应用实现文档自动同步的完整流程。文章还透露了 Token 成本（约 3-4 毛钱/份 PPT）以及对更强大模型和 Agent 组合的展望，强调闭环工作体验和 Vibe Work 的心流感受。

💡 主要观点

  1. 以小白身份从零开始使用 Trae，包括下载、安装、模型购买与配置。 作者亲自体验了 Trae 的获取与设置过程，解决了免费额度限制和按量计费的问题，为新手提供了可参考的步骤和成本估算。
  2. 通过反复调整提示词与 AI 协作，完成教学大纲、逐字稿及 PPT 的生成，强调明确诉求与迭代优化的重要性。 作者经历多轮沟通才得到符合需求的输出，说明有效的提示工程是让 AI 产出高质量材料的关键。
  3. 实现从文档生成到飞书同步的闭环流程，通过授权飞书应用让 Agent 直接操作，避免手动粘贴。 闭环符合 Vibe Work 原则，提升工作沉浸感和效率，避免了在不同工具间切换的摩擦。
  4. 讨论 Token 成本与模型选择，以 DeepSeek V4 为例说明按量计费的实际花费，并指出更强大模型可实现更复杂自动化但成本更高。 成本透明帮助用户评估可行性，为后续扩展使用多个 Agent 提供参考，同时提醒模型与 Agent 组合的性价比考量。

💬 文章金句

  • 第一次真正感受到了 AI 的魅力
  • 第一次感受到了用 AI 进行 Vibe Work 的心流状态
  • 我觉得自己是可以实现驱动 2-4 个 Agent 来工作的。
  • 必须确保流程闭环------从生成文档、制作课件 PPT，到同步至飞书或邮件，只在一个聊天窗口即可完成。
  • 我购买了一个 DeepSeek V4 的模型，它属于'按需充值，按量计价'。我大概统计了下，生成一份 PPT 大约需要花费 3-4 毛钱。
