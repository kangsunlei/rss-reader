什么是 Harness？Claude Code、CodeX、WorkBuddy 与 DeepSeek Harness 的关系

8/19/2026, 12:51:00 AM

📌 一句话摘要

本文通过对比 Claude Code 的封闭式 Harness 与 DeepSeek 开源的模块化 Harness，揭示了 AI Agent 的核心架构：Agent = Model + Harness，并分析了不同 Agent 产品的本质差异与应用场景。

📝 详细摘要

文章深入解析了 Harness（挽具）这一 AI Agent 架构核心概念。首先明确 Harness 的本义（马具/安全绳），并通过对比 Claude Code（封闭式成品）与 DeepSeek Harness（开源模块化框架）的差异，揭示了 AI Agent 的核心架构：Agent = Model + Harness。文中详细拆解了 Claude Code 的九大机制（主循环、记忆系统、技能、子智能体、钩子、MCP 集成、Headless 模式、Agent SDK、插件生态），以及 DeepSeek Harness 的插件化设计（模型适配器、工具、技能、会话、沙箱、存储、Agent 主循环、任务调度、UI）。通过对比 Claude、Claude Code、CodeX、Trae、QoderWork、WorkBuddy 等产品的本质差异，文章归纳出 Agent 产品的三种形态：封闭式整车（Claude Code/CodeX）、场景化整车（Trae/QoderWork/WorkBuddy）、开源零件库（DeepSeek Harness）。最后，文章从个人用户、开发者、SaaS 从业者三个视角，分析了 Harness 的实际应用价值，并强调 AI 竞争的核心已从模型转向 Harness 这一层。

💡 主要观点

  1. Harness 是 AI Agent 的核心架构，决定了模型的实际能力。 Agent = Model + Harness，模型提供智力，Harness 提供手脚和秩序。Claude Code 的九大机制与 DeepSeek Harness 的九类插件共同构成了 Harness 的核心能力。
  2. Claude Code 是封闭式成品，DeepSeek Harness 是开源模块化框架。 Claude Code 的九大机制是封闭的，无法替换；DeepSeek Harness 的九类插件可以自由组合和替换，适合自研 Agent 底座。
  3. Agent 产品可分为三种形态：封闭式整车、场景化整车、开源零件库。 Claude Code/CodeX 是封闭式整车；Trae/QoderWork/WorkBuddy 是场景化整车；DeepSeek Harness 是开源零件库。
  4. AI 竞争的核心已从模型转向 Harness 这一层。 Harness 的差异比模型差异更重要，真正的竞争在于让模型真正干活的这一层。

💬 文章金句

  • Agent = Model + Harness------模型决定智力，Harness 决定能力。
  • Claude Code 把它做成封闭的成品卖给你，DeepSeek 把它拆成开源的积木送给你------一个问'怎么把 Agent 做得最好用'，一个问'怎么把 Agent 的底座彻底打开'。
  • 真正的差异，正在从'引擎'移到'整车'，从模型移到了让模型真正干活的这一层。
