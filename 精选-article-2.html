Anthropic 发布 AI Agent 上下文工程指南

10/2/2025, 3:13:00 PM

📌 一句话摘要

Anthropic 发布 AI Agent 上下文工程指南，强调超越提示词工程，通过优化信息管理、工具设计及长期策略构建高效智能体。

📝 详细摘要

文章深入探讨了 Anthropic 提出的“上下文工程”概念，将其定位为“提示词工程”的自然演进，强调在构建工业级 LLM 应用时，需全面管理模型可访问的整体状态。文章指出，尽管 LLMs 处理能力增强，但仍存在“上下文衰减”现象，因此需要精心设计上下文以应对有限的“注意力预算”。指南详细介绍了高效上下文的结构，包括清晰的系统提示词、高效的工具设计和规范的少样本示例。此外，文章还提出了针对长期任务的上下文工程策略，如信息压缩、结构化笔记和子智能体架构，旨在帮助智能体在长时间跨度内保持连贯性与目标导向性，克服上下文窗口限制。

💡 主要观点

  1. 上下文工程是提示词工程的自然演进，强调全面管理 LLM 可访问的整体状态。 随着智能体能力增强，仅关注单次提示已不足，需系统性管理所有输入 token，以持续引导模型做出期望行为，提升应用稳定性。
  2. LLMs 存在“上下文衰减”，需高效利用有限的“注意力预算”来优化模型性能。 模型在处理大量上下文时注意力会分散，因此需要精心筛选最少但信息量最高的 token 集，以最大程度地促使期望结果的出现。
  3. AI Agent 应采用动态上下文检索策略，如即时调用工具获取信息，以模拟人类认知模式并优化信息利用。 这种策略允许智能体在运行时按需动态获取所需信息，模拟人类认知模式，有效利用外部工具和数据源，从而优化上下文利用率并提升处理复杂任务的能力。
  4. 针对长期任务，可采用压缩、结构化笔记和子智能体架构克服上下文窗口限制。 这些策略能帮助智能体在长时间序列中保持连贯性和目标导向性，有效管理和利用信息，避免上下文污染，实现复杂任务的执行。

💬 文章金句

  • 构建 AI 应用的重心，已经从寻找合适的提示词，转向一个更根本的问题：怎样的上下文配置最有可能引导模型做出我们想要的行为？
  • 上下文工程指的是在 LLM 推理过程中策划和维护最优 token 集合（信息）的一系列策略，包括提示词之外可能出现的所有其他信息。
  • 上下文应该被视为一种边际收益会递减的有限资源。就像人类的工作记忆容量是有限的一样，LLM 在处理大量上下文时也存在一个'注意力预算'。
  • 优秀的上下文工程应该去寻找最少数量但信息量最高的 token 集，从而最大程度地促使期望结果的出现。
  • 即使现在模型的性能在持续提升，但在较长的交互过程中保持一致性仍将是构建更有效智能体的关键挑战。
