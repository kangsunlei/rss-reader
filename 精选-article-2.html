EMNLP 2026｜京东零售 AI Infra 团队提出分离式多模态训练框架 FlowTrain

10/27/2026, 1:28:00 PM

📌 一句话摘要

FlowTrain 是一个基于流式解耦的工业级多模态训练框架，通过统一内存池、异构并行分配和动态打包调度，显著提升了视觉语言模型的训练效率，在超节点实验中实现了超过 50% 的 MFU 和最高 1.7 倍的吞吐量提升。

📝 详细摘要

本文介绍了京东零售 AI Infra 团队提出的 FlowTrain 框架，该框架旨在解决多模态大模型训练中存在的同步等待、资源利用率低和负载不均等问题。FlowTrain 通过将训练过程重构为生产者-消费者数据流，并结合超节点的硬件优势，实现了高效的异构模块并行和动态微批次调度，从而大幅提升了训练性能。

💡 主要观点

  1. FlowTrain 实现了时间解耦和空间解耦 通过 Unified Memory Pool，FlowTrain 打破了 encoder 和 backbone 的批次级同步，允许数据在全局地址空间中异步流转。同时，Heterogeneous Parallel Allocator 根据吞吐匹配原则，为不同模块选择最优的并行策略，避免了资源错配。
  2. 动态调度优化了变长样本的处理 Dynamic Packing Scheduler 根据样本的实际计算成本进行动态分桶，而不是简单的 token 数分桶。这有效降低了 padding 浪费，并平衡了 pipeline stage 的负载，提高了整体的计算效率。
  3. 实验验证了显著的性能提升 在超节点环境下，FlowTrain 在 InfoVQA 和工业数据集上分别实现了 1.7 倍和 1.4 倍的吞吐量提升。MFU 超过 50%，远高于传统方法的 30% 左右，证明了该框架在工业级训练中的实用价值。

💬 文章金句

  • FlowTrain 将多模态训练从传统的'同步 pipeline'重构为'生产者-消费者数据流'。
  • Unified Memory Pool 通过 64 位全局虚拟地址统一管理跨节点 HBM 与 DRAM 资源，将 encoder 产生的多模态 embedding 与文本 token 纳入全局可寻址空间。
  • Heterogeneous Parallel Allocator 将资源分配转化为生产速率与消费速率的匹配问题，而非依赖经验调参。
  • Dynamic Packing Scheduler 依据 LLM 侧的实际计算代价动态构造 microbatch，降低 padding 浪费并平衡 PP/DP 负载。
