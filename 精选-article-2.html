OpenAI 开发者日 2025：开发者成为 AGI 分发的关键

10/7/2025, 5:50:03 PM

📌 一句话摘要

OpenAI 2025 开发者日强调通过新模型、ChatGPT 应用 SDK 和 AgentKit，打造开发者和应用分发平台。AgentKit 旨在简化复杂应用构建。

📝 详细摘要

本文是一篇播客回顾，由 OpenAI 平台团队成员 Sherwin Wu 和 Christina Huang 分享，深入探讨了 OpenAI 的 2025 开发者日。文章强调 OpenAI 致力于发展成为强大的 AGI 开发者和应用分发平台，ChatGPT 周活跃用户达 8 亿，开发者数量已增长至 400 万。主要发布包括 GPT-5 Pro 和 Sora-2 等先进前沿模型，以及 gpt-realtime-mini 和 gpt-image-1-mini 等新型、成本优化的迷你版本，使强大的 AI 能力更易于使用。核心亮点是 Apps SDK 的推出，它使开发者能够直接在 ChatGPT 中构建交互式、自适应和个性化的应用程序。该 SDK 基于 MCP 协议，具有创新的 React 组件捆绑功能，用于定制用户界面，为开发者提供了前所未有的分发潜力。此外，文章还深入研究了 AgentKit，这是一个旨在简化复杂 AI 代理的创建、部署和优化的综合套件，包括 Agent SDK、用于工作流设计的可视化 Agent Builder、连接器注册表和 ChatKit。作者们持续关注历届开发者日，对 OpenAI 的战略执行和日趋成熟的开发者生态系统充满信心，并将这些发布视为通过繁荣的第三方开发者社区在全球范围内分发 AGI 收益的关键步骤。

💡 主要观点

  1. OpenAI 正在巩固其作为 AGI 开发者和应用分发平台的地位。 OpenAI 致力于赋能第三方开发者，扩展 AI 技术的应用范围和商业价值，构建更广泛的应用生态。
  2. Apps SDK 能够将自定义应用程序深度集成到 ChatGPT 中。 Apps SDK 基于 MCP 协议，为开发者提供完整的技术栈，用于创建交互式 UI 并连接数据。这为开发者在 ChatGPT 的庞大用户群中提供了前所未有的分发潜力。
  3. AgentKit 提供了一套全面的工具，用于构建和部署先进的 AI 代理。 AgentKit 平台简化了代理开发流程，提供可视化构建器、SDK 和优化工具，助力开发者将复杂的 agentic 工作流部署到生产环境。

💬 文章金句

  • OpenAI 2025 开发者日 最大的收获是，OpenAI 致力于成为卓越的开发者和应用分发平台，同时也在不断扩展其前沿研究、聊天机器人和社交网络。
  • 今天，我们将向开发者开放 ChatGPT，以便在 ChatGPT 内部构建真正的应用程序。这将使新一代的应用程序成为可能，这些应用程序是交互式的、自适应的、个性化的，你可以与之互动。
  • 我认为这与迭代式学习有关，我们从之前的插件开发中获益良多。
  • 所以我们今天推出了 AgentKit，一套完整的解决方案来构建、部署和优化代理。
  • 他们希望这一技术能被广泛采用。
