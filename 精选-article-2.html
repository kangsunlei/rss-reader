OpenAI 推出由 Sora 2 驱动的全新视频 API 功能

3/12/2026, 5:11:29 PM

📌 一句话摘要

OpenAI 发布了增强版视频 API 功能，由 Sora 2 模型提供支持，包括自定义角色、更长的视频片段和场景续接功能。

📝 详细摘要

这条推文宣布了 OpenAI 视频 API 的重大更新，现在由 Sora 2 提供支持。此次更新为开发者带来了多项备受期待的功能：支持自定义角色和物体、灵活的宽高比（16:9 和 9:16）、最长 20 秒的视频片段、场景续接功能，以及用于高效视频生成的批量处理能力。这标志着通过 API 访问高质量 AI 视频生成迈出了重要一步。
