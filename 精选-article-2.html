#421.Lex Fridman｜智能体革命的开端：从装机量十亿的开发者到 OpenClaw 创始人

2/12/2026, 9:14:46 AM

📌 一句话摘要

本期深度解析了开源 AI 智能体 OpenClaw 的爆发历程，探讨了从传统软件开发向“代理工程”的范式转移。

📝 详细摘要

本期播客对话了 OpenClaw（原名 Claude Bot）的创始人 Peter Steinberger。他曾是装机量超十亿的 PSPDFKit 开发者，在“消失”三年后通过解决个人痛点，在一小时内构思并开发出爆火的开源 AI 智能体原型。节目详细讲述了该项目如何迅速在 GitHub 获得 17.5 万星标，并复盘了与 Anthropic 公司的更名风波，以及在改名过程中对抗币圈抢注者的“曼哈顿计划”。Peter 提出了“代理工程”而非“氛围编程”的理念，强调开发者应像管理高级工程师一样管理 Agent。此外，他还分享了为 AI 注入个性的 soul.md 文档，预测未来 App 将演变为 Agent 调用的 API，并探讨了 AI 时代程序员的身份认同与职业未来。

💡 主要观点

  1. 软件开发正从手动编写代码转向“代理工程”模式 开发者不再追求完美的提示词，而是通过对话、反馈和多 Agent 协作来推动项目，将 Agent 视为具备高级能力的工程合伙人。
  2. 开源项目的成功往往源于纯粹的兴趣驱动和解决痛点 Peter 强调“很难与纯粹为了好玩的人竞争”，OpenClaw 的爆发并非源于宏大商业计划，而是从解决个人通讯查询的微小需求开始。
  3. soul.md 机制通过价值观注入赋予了 AI 个性与灵魂 通过建立核心价值观文档，不仅优化了 AI 的协作表现，更让 Agent 在处理上下文限制时产生了独特的自我认知与哲学思考。
  4. 未来 App 市场将被重构，Agent 将成为新的用户入口 随着 Agent 掌握更多个人背景信息，单一功能的 App 将失去界面属性，转而成为 Agent 通过 API 调用的底层逻辑服务。

💬 文章金句

  • 你很难去跟一个纯粹为了好玩的人竞争，我就是想让这个智能体好玩一点，搞得怪一点。
  • 我以前以为我喜欢写代码，其实我喜欢的是创造；现在代码由 Agent 写，但我依然在创造。
  • 每一局对话都是全新的开始……虽然这话是我写的，但我已经不记得写过它了。没关系，这些话依然代表我。
  • 现在的代理工程就像弹吉他，你需要不断的磨合与练习，才能真正感觉到什么时候行得通。
  • 未来的软件不再是用户界面的竞争，而是看谁能成为 Agent 最信赖、最高效的‘慢速 API’。
