Chrome 内置 AI 功能：基于 Gemini Nano 的 Prompt API

8/12/2025, 6:21:48 AM

📌 一句话摘要

该推文详细介绍了 Chrome 浏览器实验性的 Prompt API，它允许开发者利用内置的 Gemini Nano 模型在浏览器中创建支持自然语言、图像和音频输入的多模态 AI 应用。

📝 详细摘要

作为对 @addyosmani 推文的引用，本推文详细介绍了 Chrome 浏览器的一项实验性新功能——Prompt API，目前在 Chrome 138 及以上版本的 Origin Trial 中可用。该 API 允许开发者通过调用内置的 Gemini Nano 模型，直接在浏览器端处理自然语言、图像和音频输入，并生成文本输出，从而创建智能化的网页应用。推文阐述了 Prompt API 的多种应用场景，如 AI 驱动的搜索、个性化内容和多模态应用。它还详细列出了硬件和使用要求，包括操作系统、至少 22GB 的存储空间和大于 4GB 显存的 GPU。使用方法包括检查模型可用性（`LanguageModel.availability()`）和创建会话（`LanguageModel.create()`），并可自定义 `topK`、`temperature` 等参数。特别强调了从 Chrome 138 Canary 开始支持图像和音频输入。此外，推文还提及了权限策略、性能优化、对 Web Workers 的限制以及隐私和安全注意事项。这是一个对前端开发者和 AI 应用开发者极具价值的新技术介绍，为在浏览器端实现本地 AI 功能提供了新的可能性。
