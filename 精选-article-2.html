Qwen-Image-Edit：全能图像编辑，驱动内容创作提质增效

8/19/2025, 1:52:00 PM

📌 一句话摘要

通义千问团队开源发布 Qwen-Image-Edit 图像编辑模型，具备语义/外观双重编辑和精准文字编辑能力，并在多项基准测试中达到 SOTA。

📝 详细摘要

文章详细介绍了通义千问团队最新开源的 Qwen-Image-Edit 模型。该模型基于 20B 的 Qwen-Image 模型进一步训练，成功将 Qwen-Image 的文本渲染能力拓展到图像编辑任务，实现精准文字编辑。其核心特性在于支持语义/外观双重编辑，这得益于将输入图像同时送入 Qwen2.5-VL（获取视觉语义控制）和 VAE Encoder（获得视觉外观控制）。模型能处理保持语义不变的 IP 创作、视角转换、风格迁移等高级编辑，也能进行增删改、修复等局部外观编辑。文章通过丰富的示例图展示了模型在原创 IP 编辑、MBTI 表情包制作、视角转换、虚拟形象生成、物体增删、文字修复、海报编辑等多种场景下的强大效果。此外，文章还提供了模型推理的 Python 代码示例以及基于 DiffSynth-Studio 进行 LoRA 微调的详细步骤和示例数据集，极大地降低了开发者使用和定制模型的门槛。

💡 主要观点

  1. Qwen-Image-Edit 实现语义/外观双重编辑，覆盖广泛的图像编辑需求 模型能同时处理高层级的语义编辑（如 IP 创作、风格迁移）和低层级的外观编辑（如物体增删改），极大地扩展了图像编辑的应用场景和灵活性。
  2. 模型具备精准的中英双语文字编辑能力，保持文字风格和大小 得益于 Qwen-Image 强大的文字渲染基础，Qwen-Image-Edit 能对图片中的中英文文字进行增删改，且能保留原有字体和风格，对于海报、书法等文字密集场景具有高实用价值。
  3. 提供完整的推理和微调代码，降低模型使用和定制门槛 文章不仅展示了模型效果，还提供了详细的 Python 推理代码和 LoRA 微调脚本，包括环境依赖和数据集准备，使开发者能够快速上手并根据自身需求进行模型定制。

💬 文章金句

  • Qwen-Image-Edit 基于 20B 的 Qwen-Image 模型进一步训练，成功将 Qwen-Image 的文本渲染特色能力拓展到编辑任务上，以支持精准的文字编辑。
  • Qwen-Image-Edit 不仅支持 low-level 的视觉外观编辑（例如增删改等，需要保持图片部分区域完全不变），也支持 high-level 的视觉语义编辑（例如 IP 制作，物体旋转，风格迁移等，整体像素值可以变化，但需要保持语义不变）。
  • Qwen-Image-Edit 支持中英双语文字编辑，可以在保留文字大小/字体/风格的前提下，直接编辑图片中文字，进行增删改。
  • 在多个公开基准测试中的评估表明，Qwen-Image-Edit 在编辑任务中均获得 SOTA，是一个强大的图像生成基础模型。
  • 想要微调图像编辑模型，需要准备编辑图像对和输入 prompt。
