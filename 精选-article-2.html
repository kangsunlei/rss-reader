介绍 EmDash —— WordPress 的精神继任者，解决插件安全问题

4/1/2026, 2:00:01 PM

📌 一句话摘要

Cloudflare 推出了 EmDash，这是一个基于 TypeScript 的开源无服务器 CMS，旨在成为 WordPress 的安全且现代的继任者，具备插件沙盒、Astro 驱动的前端以及 AI 原生管理工具。

📝 详细摘要

EmDash 是 Cloudflare 推出的全新开源 CMS，旨在通过解决 WordPress 长期存在的安全和架构限制来推动网络发布现代化。EmDash 完全使用 TypeScript 构建，由 Astro 框架驱动，引入了一种安全的插件模型，其中每个插件都在具有明确声明能力的隔离 Dynamic Worker 沙盒中运行。它专为无服务器时代设计，支持缩容至零，且仅按 CPU 时间计费。主要功能包括内置对 x402（按次付费）支付的支持、默认的通行密钥（passkey）身份验证，以及通过 Agent Skills 和 MCP（模型上下文协议）服务器实现的 AI 原生集成。EmDash 采用 MIT 许可证，并为现有的 WordPress 网站提供了迁移工具。

💡 主要观点

  1. 通过沙盒实现插件安全 与 WordPress 的共享执行环境不同，EmDash 插件在具有作用域权限的隔离 Dynamic Worker 中运行，防止对数据库或文件系统的未经授权访问。
  2. 现代无服务器架构 基于 Cloudflare 的 workerd 运行时和 Astro 框架构建，它支持缩容至零，并通过仅对活跃 CPU 时间计费（而非空闲服务器实例）来优化成本。
  3. AI 原生管理与扩展性 包含 Agent Skills 和 MCP 支持，允许 AI 智能体以编程方式处理内容迁移、模式管理和插件开发。
  4. 原生网络支付 (x402) 集成了 x402 标准以实现按次付费的内容货币化，为 AI 智能体时代提供了内置的商业模式，无需订阅。
