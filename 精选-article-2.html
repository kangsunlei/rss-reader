DeepSeek Harness 桌面端：现在，开箱即用。

9/29/2026, 12:04:00 PM

📌 一句话摘要

DeepSeek Harness 发布 v0.2 预览版，推出 macOS 和 Windows 桌面端安装包，实现开箱即用，并增强了插件管理、自动化任务及代码变更展示能力。

📝 详细摘要

DeepSeek Harness v0.2 预览版正式发布，核心变化是从命令行安装转向提供 macOS 和 Windows 桌面端安装包，极大降低了用户上手门槛。新版本优化了文件展示、内容预览和代码变更差异对比，并内置了可按需开启的自动化定时任务插件。在插件生态方面，新增了无需命令行的可视化插件管理页面，支持通过 npm 包名直接安装/卸载，并推出实验性的「创造模式」，允许用户通过对话让 AI 编写和修改插件。未来计划包括改善沙箱安全、引入长期记忆、实现 GUI 自动化操作以及建设官方插件市场，旨在构建一个开源、可组合的智能产品生态。

💡 主要观点

  1. 推出桌面端安装包实现开箱即用。 提供 macOS 和 Windows 客户端，用户无需通过命令行安装即可快速上手，降低了非技术用户的使用门槛。
  2. 优化办公与开发的工作流体验。 增强了文件预览、代码变更差异展示，并引入自动化任务插件，支持将重复性工作设为定时执行并管理运行记录。
  3. 构建「一切皆插件」的可视化管理体系。 新增插件管理页面，支持通过 npm 包名直接安装、停用和卸载插件，并支持通过对话描述需求来生成或修改插件。
  4. 明确未来产品演进路线与生态建设。 计划在沙箱安全、长期记忆、GUI 自动化、移动端支持及官方插件市场等方面持续迭代，并与 DeepSeek 模型协同进化。

💬 文章金句

  • DeepSeek Harness 桌面端延续"一切皆插件"的设计理念：小到一个工具，大到整个交互界面，都能以插件的方式融入其中。
  • 在实验性的创造模式中，你还可以通过对话描述需求，让 DeepSeek Harness 编写和修改插件。
  • 我们希望让智能融入更多人的日常工作和生活，也期待更多插件开发者参与"一切皆插件"的生态，共同拓展智能的应用边界。
