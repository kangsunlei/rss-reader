V4-Flash-Vision-Exp 上线，开启多模态 API 服务

8/21/2026, 9:12:00 AM

📌 一句话摘要

DeepSeek 官方发布实验性多模态视觉理解模型 V4-Flash-Vision-Exp，文本能力与 V4-Flash 持平，多模态 Agent 能力接近 Opus-4.8，支持三种 API 调用格式及 Files API。

📝 详细摘要

DeepSeek 官方宣布实验性多模态视觉理解模型 DeepSeek-V4-Flash-Vision-Exp 上线 API 平台。该模型在纯文本能力上与正式版 V4-Flash 持平，在需要视觉理解的 Agent Benchmark 上实现大幅跃升，多模态 Agent 能力接近 Opus-4.8。文章展示了三个应用场景：生成商业定制西藏自驾游 PPT、对官网进行二次创作、制作黏土怪物风格动态特效前端 Demo。API 支持 Chat Completions、Messages、Responses 三种格式，图片按 token 计费（最多 384 tokens/张），价格与 V4-Flash 一致。Files API 同步开放，支持图片上传后通过 file_id 引用以节省带宽。

💡 主要观点

  1. V4-Flash-Vision-Exp 在文本与多模态能力间取得平衡。 纯文本能力与 V4-Flash 正式版持平，多模态 Agent Benchmark 上实现大幅跃升，接近 Opus-4.8 水平。
  2. 多模态能力可解锁更多 Agent 应用场景。 文章展示了 PPT 生成、网页重构、动态特效创作三个示例，体现模型在视觉理解与创作任务中的适配能力。
  3. API 接入方式灵活，Files API 降低重复传输成本。 支持三种调用格式和三种图片传入方式，Files API 免费且支持 file_id 引用，适合多轮交互场景。
