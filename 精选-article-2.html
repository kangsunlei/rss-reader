Instinct 创始人对谈：Personal Agent 最激进的产品，凭什么估值 100 亿美元？

9/30/2026, 11:32:00 AM

📌 一句话摘要

Instinct 创始人 Noah Shinn 详解这款没有 App、只有手机号电脑邮箱的个人助理：如何用「可理解性」而非能力做产品、靠交易抽成而非广告变现，以及主动式 Agent 带来的算力与信任难题。

📝 详细摘要

本文是 Founder Park 对 Instinct 创始人 Noah Shinn 长访谈的编译整理。Instinct 是一款没有 App 的 Personal Agent，用户通过短信、电话、邮件与它交互，它拥有独立手机号、电脑和邮箱，可端到端完成订餐、退订、旅行预订、穿搭生成等任务，平台年化交易额已接近 10 亿美元，其中约 50% 来自旅行。Noah 阐述了几个核心判断：人不该为与 AI 交互而学新应用，应在用户已习惯的渠道交付体验；产品设计原则是「可理解性」优先于「能力」，连一条消息的形状都要设计；不做《Her》式情感关系，而做有社交意识的 Operator；商业模式拒绝广告，选择按交易抽成，因为靠注意力赚钱的生意会被 Agent 冲击，而交付真实服务的生意会因摩擦归零而交易更多。此外，他披露了每天 10% 增长带来的算力复利难题、3 周内 40% 用户交出信用卡的信任数据，以及防火墙与实时监控等安全架构。

💡 主要观点

  1. Personal Agent 最好的界面可能是没有界面，应在用户已习惯的渠道交付体验 Instinct 没有 App，只有手机号、电脑和邮箱，用户通过短信、电话、邮件使用。Noah 认为人不应该为了与 AI 交互再去学一款新应用，超过 50% 的流量并不经过 iMessage，形态可随用户习惯变化。
  2. 产品设计应优先关注「可理解性」而非「能力」 用户能否预测交互后会发生什么，比模型能做什么更重要。Instinct 连一条消息的形状都设计，把关键信息放在前两行，因为用户扫读时注意力集中在前 30%，这被视为参与度和自然传播的关键。
  3. 主动式 Agent 的算力需求可能比预期高出几个数量级 用户每天增长 10% 意味着底层算力几乎每周翻倍，而算力有数月交付周期、临时采购要付三到四倍价格。Instinct 允许 Agent 在一天中任意时间「醒来」和「睡去」，后台主动工作规模远超代码生成类产品。
  4. 商业模式选择按交易抽成，而非广告或高价订阅 Noah 明确反对以违背用户意愿的方式变现，认为靠注意力赚钱的生意会被 Agent 冲击，而交付真实服务的生意会因摩擦降到零而交易更多。Instinct 参照 Apple Pay、Shopify、OTA 的分发抽成模式，旅行行业渠道佣金水平提供了参照。
  5. 信任建立有明确的数据指标，安全需要解耦的独立系统 使用 3 周后 40% 的用户交出信用卡，只要用户交出一项敏感信息、真正信任 Instinct，留存率可达 80%。安全上采用「防火墙」拦截恶意内容，并用与 Agent 不处于同一激励体系的系统在动作执行前验证、审查和拦截。

💬 文章金句

  • 人不应该为了与 AI 交互，再去学习一款新应用。
  • 我们很早就确立了一条原则，先不要关注 Capability（能力），只关注 Understandability（可理解性）。
  • 建立情感关系，或者追求类似方向，并不是我们希望 Instinct 去做的，也不是我们想让它和用户发展的东西。
  • 靠用户注意力赚钱的生意，会受到 Personal Agent 的冲击。但交付真实服务的生意，反而会因为摩擦降到零，和用户打交道得更多。
  • 只要用户至少交出一项敏感信息、真正信任 Instinct，留存率就能达到 80%。
