“让天下没有难做的 Agent” | 对谈旭卿（阿里云无影事业部总裁）、安陈（AgentBay 产品负责人）

8/17/2025, 4:00:00 PM

📌 一句话摘要

探讨 AI Agent 基础设施（Agent Infra）的关键组成、阿里云 AgentBay 的实践，及其对 AI 应用和商业模式的深远影响。

📝 详细摘要

本期播客深度聚焦 AI Agent 基础设施（Agent Infra）的兴起与发展，邀请阿里云无影事业部总裁张献涛（旭卿）和 AgentBay 产品负责人屈立威共同探讨。播客首先明确了 Agent Infra 与传统 AI Infra 的区别，强调 Agent Infra 涵盖记忆管理、工具使用、任务规划、沙箱环境、多 Agent 协作及安全隐私等六大核心组成部分，这些是构建高效 Agent 应用不可或缺的基石。嘉宾详细介绍了阿里云 AgentBay 作为普惠型 Agent Infra 产品的定位，旨在将复杂组件转化为低代码平台，赋能中小开发者。同时，深入对比了云端沙箱与本地沙箱在安全性、并发能力上的优势，并分享了阿里云在数据安全方面的“肌肉记忆”和长期投入。讨论还触及了 AI Agent 对云计算商业模式的影响，预判将从算力售卖转向更侧重应用层的服务化收费。最后，嘉宾分享了无影事业部从云电脑业务向 Agent Infra 转型的战略思考，强调了长期价值创造、技术前瞻性布局的重要性，并展望了通用 Agent、编码 Agent 以及企业内部自动化、金融、医疗等垂直领域的巨大投资与创业机会。

💡 主要观点

  1. Agent Infra 是 AI Agent 能力上限的关键基础设施 包含记忆、工具使用、任务规划、沙箱、多 Agent 协作及安全隐私等，是构建高效 Agent 应用不可或缺的基石，重要性不亚于模型本身。
  2. 阿里云 AgentBay 致力于普惠化 Agent 基础设施服务 AgentBay 提供云端沙箱、算力及工具链，旨在将复杂的 Agent Infra 组件转化为低代码平台，赋能中小开发者更高效地构建 Agent 应用。
  3. 云端沙箱在安全性、并发性与能力扩展上优于本地沙箱 云服务商在数据安全投入巨大，云端沙箱提供隔离环境，支持高并发，且不影响本地系统，是未来 Agent 复杂任务运行的趋势。
  4. AI Agent 发展推动云计算商业模式从算力售卖转向服务化 随着 Agent 对 Token 消耗和并发能力需求激增，云计算收费将更侧重应用层服务，体现 AI 应用价值，而非单纯基础设施成本。
  5. AI Agent 在企业内部自动化及特定垂直领域蕴含巨大机会 除通用和编码 Agent 外，电商、财务、HR、金融投资及民生医疗等领域的内部自动化改造和新应用，是当前增长最快且具投资潜力的方向。

💬 文章金句

  • 决定 Agent 能力上线的，除了模型本身之外，除了大家在工程上，在用户体验上的打磨之外，还有非常重要的基础设施 Agent Infra。
  • Agent Infra 是指构建和运行 Agent 应用所需的全套组件和环境，包括但不限于 AI infer 相关的计算集群、存储、网络等基础设施。
