QCon 上海 2026：百度 SRE Agent 规模化落地实践解读

11/4/2026, 10:00:00 AM

📌 一句话摘要

本文详述了百度 SRE 团队如何构建 AgentOps 平台，解决 Agent 规模化落地的部署、版本、观测、安全等问题，实现从单点试用到持续进化的全生命周期托管。

📝 详细摘要

文章聚焦百度 SRE 部门在大模型 Agent 规模化落地中的实践，指出从单点试用到生产化的关键挑战包括：接入部署、配置版本、运行观测、安全权限、能力复用和质量演进六类问题。为此，作者构建了 AgentOps 整体架构，采用自下而上的五层设计（基础设施、能力供给、平台、网关、接入），并强调控制面与数据面的分离。核心在于五大中心能力：Agent 管理、安全、变更、评估、知识。通过 Runtime 全生命周期托管、四道安全防线（L1-L4）、场景仿真回放、知识沉淀闭环和 Agent 自主进化机制，最终实现了从稳定运行到持续进化的闭环。实践表明，平台化后 Agent 交付周期从周级降至天级，迭代从天级缩至小时级，MTTR 从 60 分钟降至 10 分钟。

💡 主要观点

  1. 规模化落地的核心挑战 当 Agent 从单点试用走向生产，必须解决接入部署、配置版本、运行观测、安全权限、能力复用和质量演进六大问题，这些缺失会导致企业用得着但管不住、不敢放大的局面。
  2. AgentOps 五大核心能力 通过 Agent 管理、安全、变更、评估、知识五大中心统一管控，形成从 Runtime 全生命周期托管到 Agent 自主进化的主线，确保 Agent 从"能跑"走向"敢用"。
  3. 四道安全防线机制 从 L1 构建时约束、L2 意图审计、L3 本地 Hook 到 L4 网关代理，形成从构建到执行的全程护栏，配合委托令牌和 5W 审计，确保生产环境的安全可控。
  4. 场景仿真回放驱动迭代 通过自动记录 Trace、沉淀标准 Case、回放沙盒验证，实现不碰生产的评估闭环，支撑 Agent 可评估、可回滚的持续进化。
  5. 平台化带来的实质提升 覆盖 10+业务线、20+Agent、50+Skill，交付周期从周级降至天级，迭代从天级缩至小时级，MTTR 从 60 分钟降至 10 分钟，验证了平台化的价值。

💬 文章金句

  • 难点已经不再是"能不能做出来"，而是"能不能稳定地托管起来、能不能安全地跑起来、能不能持续地变好"。
  • AgentOps 要解决的，就不是某一个 Agent 的问题，而是这一组规模化问题。
  • 安全不是最后一道闸，而是从构建到执行的全程护栏。
  • 好的平台不是消灭矛盾，而是把每一组权衡都变成可控的工程选择。
  • 最终我们想要的，是"让每一次执行都更安全，让每一份经验都可复用"。
