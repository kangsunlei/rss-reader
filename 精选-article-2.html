📌 一句话摘要

机器人/物理 Agent Harness 综合分析与对比：从 "更强的模型" 到 "更好的系统"

📝 详细摘要

本文覆盖五个在 2026 年集中出现、共同回答 "如何为机器人/物理 Agent 构建 Harness" 这一问题的代表性项目：X-OmniClaw、MemoHarness、HumanCLAW、RoboClaw 和 RPent。

💡 主要观点

  1. 提出无需外部模块的自记忆管理机制（Self-Memory） MemPO 让模型在每轮交互开头自主生成记忆摘要，仅保留最近一轮的工具结果，倒逼模型通过强化学习端到端学会 "什么值得记、怎么记"，无需依赖外部复杂的记忆检索模块。
  2. 设计双通路奖励机制解决信用分配难题 结合全局轨迹级的结果奖励（Outcome Reward，全序列广播）与局部记忆奖励（Memory Reward，基于 P_mem - P_full 差值，仅作用于记忆区间），实现对记忆质量和任务正确性的协同优化。
  3. 梳理基于 VeRL 框架的源码核心路径 将代码划分为 A（记忆奖励计算与叠加）、B（结果奖励计算）和 C（系统主循环与工具调用）三条核心路径，清晰展示了 MemPO 对 VeRL 框架在数据收集、优势函数和主循环层面的外科手术式修改。
  4. 构建异步多轮 Agent Loop 充当强化学习环境 摒弃传统 Gym 环境，采用基于 SGLang 推理引擎的 ToolAgentLoop 异步状态机，通过停止词机制截断模型输出并动态注入真实 RAG 检索服务的结果，实现 "自己既是环境也是 Agent" 的闭环。

💬 文章金句

  • MemPO 的核心目标是：不仅要 "用 RL 训练 Agent"，还需要为记忆本身设计可学习、可归因的优化信号，让模型在交互过程中主动压缩、组织并保留最有助于任务完成的信息。
  • MemPO 的核心洞察：不需要外部记忆模块，AgentMemory.prepare_prompt()在构建下一轮 prompt 时，让模型在每个 assistant 轮次的开头自己写下记忆摘要...
  • MemPO 是让 AI 学会 "边做笔记边推理"，用 RL 奖励来训练它把最重要的信息压缩进每轮的小纸条，这样就算查了很多很多轮，也不会 "书包太重"。
  • MemPO 的环境是完全自己实现的，基于 VeRL 框架 + SGLang 推理引擎定制。它不是传统 RL 的 Gym 环境，而是一个异步多轮 Agent Loop 充当环境角色。
