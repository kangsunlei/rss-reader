开源 Agent 模型榜第一名，现在是阿里通义 DeepResearch

9/18/2025, 5:48:57 AM

📌 一句话摘要

阿里开源了高性能轻量级深度研究 Agent 模型通义 DeepResearch，通过创新数据策略和训练范式在多项权威评测中取得 SOTA 成绩，并已应用于内部产品。

📝 详细摘要

文章详细介绍了阿里巴巴开源的首个深度研究 Agent 模型通义 DeepResearch。该模型采用 30B-A3B 轻量级架构，在 HLE、BrowseComp-zh、GAIA 等多个权威评测集上取得了 SOTA 成绩，超越了 OpenAI Deep Research 和 DeepSeek-V3.1 等竞品。文章深入阐述了模型能力提升的关键因素，包括一套不依赖人工标注、大规模生成高质量训练数据的多阶段数据策略，以及创新的 IterResearch 范式和 Research-Synthesis 框架，有效解决了 Agent 在复杂多步任务中的认知瓶颈和噪音污染。此外，还介绍了革新的端到端 Agent 训练流程（Agentic CPT → Agentic SFT → Agentic RL）和基于策略的强化学习优化实践，强调了数据质量和训练环境稳定性对 Agentic RL 成功的决定性作用。文章最后展示了通义 DeepResearch 在高德出行 Agent 和通义法睿等内部应用中的落地成果，并提供了模型、框架和方案的开源地址，具有极高的实践参考价值。

💡 主要观点

  1. 通义 DeepResearch 通过创新的数据策略和训练范式实现 SOTA 性能 模型不依赖昂贵人工标注，利用 Agentic CPT 和全自动合成数据方案，结合 IterResearch 范式和端到端 RL 训练流程，显著提升了 Agent 能力，并在多个权威评测集上超越竞品。
  2. IterResearch 范式有效解决了 Agent 在长期复杂任务中的“认知瓶颈” 该范式将任务解构为迭代研究轮次，通过精简工作空间和“综合与重构”过程，帮助 Agent 在执行复杂任务时保持清晰的“认知焦点”和高质量推理能力。
  3. 数据质量和训练环境稳定性是 Agentic 强化学习成功的关键 团队实践表明，相比算法优化，高质量合成数据和稳定高效的基础设施对 Agent 模型强化学习的成功更具决定性作用，能有效提升模型的学习和泛化能力。
  4. 通义 DeepResearch 已成功应用于高德出行和通义法睿等实际场景 模型在高德 App 中提升复杂查询体验，并在通义法睿中提供权威法律分析服务，展现了其强大的实用价值和在垂域的落地能力。

💬 文章金句

  • 不依赖昂贵的人工标注，也能大规模地生成高质量的训练数据。
  • IterResearch 范式的创建是为了解决 Agent 将所有信息堆积在一个不断扩展的单一上下文窗口中时出现的认知瓶颈和噪音污染。
  • 数据质量和训练环境的稳定性，可能是决定强化学习项目成败的更关键一环。
  • 相比之下，像 BrowseComp 这样的人工标注数据，本身就含有更多噪声，加之其规模有限，导致模型很难从中提炼出一个可供学习的潜在分布，从而影响了其学习和泛化（generalize）能力。
  • 这种全栈方法为训练能够在动态环境中稳健地解决复杂任务的 AI 代理提供了一种全新的范例。
