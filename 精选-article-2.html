Nano Banana Pro，也称 gemini-3-pro-image-preview，是目前最好的图像生成模型

11/20/2025, 4:32:25 PM

📌 一句话摘要

Nano Banana Pro (Gemini 3 Pro Image) 是一款先进的图像生成模型，具有卓越的推理能力、文本渲染能力和实时数据支持。

📝 详细摘要

本文介绍了谷歌的新图像生成模型 Nano Banana Pro（也称为 Gemini 3 Pro Image），强调了其惊人的能力。它擅长高分辨率输出（1K-4K）、复杂资产的高级文本渲染，并利用谷歌搜索进行实时数据支持。该模型还具有独特的“思考模式”，可以在生成最终图像之前改进复杂提示。作者通过详细的例子展示了它的强大功能，包括复杂的指导图像和信息图表的创建，展示了它精确遵循指令并准确渲染文本的能力。虽然功能强大，但文章指出该模型显著的 API 定价，特别是对于高分辨率输出和多个参考图像。最后，它讨论了谷歌集成 SynthID 用于不可察觉的数字水印，从而能够检测 AI 生成图像的透明度。

💡 主要观点

  1. Nano Banana Pro 擅长高分辨率图像生成和复杂图像生成任务。 该模型在生成高分辨率 (1K-4K) 视觉效果和处理具有高级推理能力的复杂、多轮创建任务方面表现出惊人的能力。
  2. 实时数据支撑和“思考模式”等创新功能增强了输出。 它利用谷歌搜索进行实时数据支持，并采用具有临时“思考图像”的“思考”过程来改进复杂提示，以获得卓越的结果。
  3. 该模型的高级功能需要较高的 API 成本。 生成高分辨率图像和使用多个参考输入会产生较高的 API 费用，使其成为 AI Studio 中不免费提供的高级服务。
  4. 谷歌集成了 SynthID 用于 AI 生成图像检测。 谷歌工具（包括 Nano Banana Pro）创建的所有媒体都嵌入了不可察觉的 SynthID 水印，从而可以验证 AI 来源的透明度。

💬 文章金句

  • 旨在通过高级推理处理最具挑战性的工作流程，它擅长复杂的多轮创建和修改任务。
  • 该模型可以利用谷歌搜索验证事实，并基于实时数据（例如当前天气地图、股票图表、最近发生的事件）生成图像。
  • 该模型利用“思考”过程推理复杂提示，生成临时的“思考图像”（在后端可见但不收费），以改进构图并生成最终高质量输出。
  • 如果您使用所有 14 张参考图像来创建 4K 输出，则单个 API 调用需要 1.18 美元（再加上几美分来支付您的文本提示，按每百万个 token 2.00 美元收费。）
  • 我们认为知道图像何时由 AI 生成至关重要。这就是为什么谷歌工具生成的所有媒体都嵌入了我们不可察觉的 SynthID 数字水印。
