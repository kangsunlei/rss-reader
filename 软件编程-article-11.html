150%训练效率提升：感知检测小模型训练优化方法

7/24/2025, 12:30:00 AM

📌 一句话摘要

文章详细阐述了智能驾驶感知检测小模型在多算力卡上的训练优化实践，涵盖环境配置、代码适配及 CPU/GPU/存储性能调优，实现了训练效率显著提升。

📝 详细摘要

本文章基于智能驾驶领域对环境实时感知和决策的迫切需求，深入探讨了在不同算力卡上提升感知检测小模型训练效率的实战方法。作者首先介绍了当前智能驾驶面临的模型复杂度和数据量挑战，以及高性能计算平台的重要性，并详细配置了基于阿里云 PAI DSW 实例的测试环境与所用模型、数据集。文章核心内容聚焦于解决模型训练中遇到的三大类问题：一是环境依赖冲突，通过版本排查与适配解决了 mmcv、torch、flash-attn 和 transformers 等库的兼容性难题；二是源代码适配，针对不同算力卡的调度逻辑差异，提出了 local_rank 参数调整和 NCCL P2P 通信问题的解决方案；三是性能优化，系统性地从 CPU 数据预处理（进程池、共享内存）、PyTorch 应用层（pin_memory、num_workers、torch.compile）和外部存储（CPFS 可用区选择与 eRDMA 网络）三个层面提供了具体且可操作的优化策略。文章通过实际测试验证了这些优化措施能显著提升训练效率并保持模型收敛一致性，为智能驾驶及类似场景的模型训练提供了宝贵的实践指导。

💡 主要观点

  1. 针对小模型训练中 CPU 瓶颈，可通过进程池和共享内存加速数据预处理。 小模型训练时，GPU 常因等待 CPU 进行数据预处理而空闲，利用进程池并行处理和共享内存减少数据拷贝，可有效提高 CPU 侧数据吞吐，充分利用 GPU 算力。
  2. PyTorch 内置优化功能如 pin_memory、num_workers 和 torch.compile 能有效提升训练效率。 通过启用 pin_memory 加速 CPU 到 GPU 数据传输，增加 num_workers 并行数据加载，以及使用 torch.compile 优化计算图，能全面提升 PyTorch 模型训练的性能。
  3. 外部存储（如 CPFS）的选型和配置对分布式训练性能至关重要。 存储系统 I/O 延迟是分布式训练的潜在瓶颈，选择支持高速 eRDMA 网络的存储服务并确保正确的可用区配置，可大幅降低数据读写时延，保障训练效率。

💬 文章金句

  • 本文章基于业务实践，总结有关感知检测小模型在不同算力卡上的训练方法，为有智能驾驶的场景提供可行的借鉴方法。
  • 总体的性能优化可以从调度层、应用层、挂载区三个方面来考虑。
  • 对 cpu 计算要求高的小模型可以使用进程池来加速计算，进程数一般设置成 cpu 核心数。
  • 使用多个 workers 并行读取和处理数据，可以显著提升训练效率，在 GPU 进行模型训练的同时，workers 可以提前准备好下一个 batch 的数据，实现"GPU 计算 + 数据加载"并行。
  • 要启用 cpfs 的高速 eRDMA 网络读写，cpfs 的可用区需要选择乌兰 C 区。
