GitHub 为 Copilot CLI 推出 “Make Contribution” 技能

2/21/2026, 6:00:47 PM

📌 一句话摘要

GitHub 为 Copilot CLI 推出的新技能，使 AI 智能体在提交 PR 时能自动遵循仓库指南和模板。

📝 详细摘要

GitHub 为 Copilot CLI 发布了一项名为 “Make Contribution” 的智能体技能。该功能允许 AI 智能体通过识别并遵循特定仓库的贡献指南与模板，自主处理 PR 流程。通过提供这些结构化的“技能”，开发者可以更有效地引导 AI 智能体执行代码贡献等复杂任务，同时确保符合项目的标准和一致性。
