webclaw：网页转干净 Markdown/JSON，支持 RAG

6/24/2026, 7:30:08 AM

📌 一句话摘要

webclaw 是一个开源工具，可将网页内容转换为干净的 Markdown 或 JSON，便于 RAG 流程使用。

📝 详细摘要

webclaw 工具可自动化清除网页中的导航、广告和脚本代码，提取核心正文并转换为 Markdown 或 JSON 格式，支持单个页面提取、批量爬取文档站、页面变化对比及品牌信息提取，同时支持 MCP 服务接入主流 Agent 工具（如 Claude Code、Codex）。
