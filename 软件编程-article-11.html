Vercel AI Gateway 现已支持 OpenResponses API - Vercel

1/15/2026, 1:00:00 PM

📌 一句话摘要

Vercel AI Gateway 现已集成 OpenResponses API，这是 OpenAI 的开源规范，为多提供商 AI 交互（如文本生成、流式传输、工具调用和图像输入）提供统一接口。

📝 详细摘要

Vercel 宣布其 AI Gateway 成为 OpenResponses API 的 day-0 发布合作伙伴，这是 OpenAI 设计的开源规范，旨在标准化跨多个提供商的 AI 交互。此集成为开发者提供了统一接口来处理各种 AI 功能，包括文本生成、令牌的实时流式传输、带结构化参数的复杂工具调用，以及面向视觉模型的图像输入。该 API 还支持可配置工作量的高级推理，并提供提供商回退链以增强可靠性。开发者可以利用其现有的 AI Gateway 密钥，通过简单地更改请求中的模型字符串，在不同 AI 模型和提供商之间无缝切换，通过单一端点简化多样化 AI 生态系统的管理。

💡 主要观点

  1. Vercel AI Gateway 现支持 OpenResponses API，实现统一的 AI 交互。 此集成允许开发者通过 Vercel 的 AI Gateway 使用单一接口访问不同提供商的各种 AI 服务（文本、流式传输、工具调用、图像输入）。
  2. OpenResponses API 标准化了多提供商 AI 功能。 该 API 是 OpenAI 的开源规范，为常见任务（如文本生成、工具调用和流式传输）与多样化 AI 模型交互提供了一致的方式。
  3. 它提供诸如提供商回退和可配置推理级别等功能。 该集成通过允许在模型/提供商之间自动切换并为更复杂的 AI 任务启用扩展思考，增强了可靠性和灵活性。
  4. 开发者可通过简单的模型字符串更改轻松切换 AI 模型和提供商。 使用其 AI Gateway 密钥，用户可以抽象掉特定于提供商的复杂性，从而更轻松地试验和部署各种 AI 模型。

💬 文章金句

  • Vercel AI Gateway 是 OpenResponses API 的 day 0 发布合作伙伴，这是 OpenAI 用于多提供商 AI 交互的开源规范。
  • OpenResponses 为跨提供商的文本生成、流式传输、工具调用、图像输入和推理提供了统一接口。
  • 使用您的 AI Gateway 密钥配合 OpenResponses，并通过更改模型字符串在提供商之间切换模型。
