Kanban Code：用看板管理你的 Claude Code 并行任务

7/17/2026, 9:00:02 AM

📌 一句话摘要

开源工具 Kanban Code 为 Claude Code 提供可视化任务看板，自动追踪并行任务状态并支持手机通知。

📝 详细摘要

GitHubDaily 介绍了一款名为 Kanban Code 的开源工具，它能为 Claude Code 用户提供一个可视化的任务看板。该工具可以将每个 AI 编程任务转化为卡片，并根据状态（待办、进行中、等待确认、待评审、已完成）自动流转，解决了在终端中并行运行多个 Claude Code 任务时，需要手动切换标签页检查进度的问题。工具内置终端，支持 macOS 和 Windows，并能在任务需要确认时推送手机通知。
