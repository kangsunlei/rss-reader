ReSharper 2025.2 EAP 2：率先支持进程外模式的公开预览版 | .NET 工具博客

📌 一句话摘要

ReSharper 2025.2 EAP 2 推出 Visual Studio 进程外模式公开预览版。

📝 详细摘要

JetBrains 发布了 ReSharper 2025.2 EAP 2，这是首个支持与 Microsoft Visual Studio 进行进程外 (OOP) 模式集成的公开预览版。这项重大的架构变更旨在提高稳定性和性能。其原理是在独立进程中运行 ReSharper，使其与 Visual Studio 进程分离。用户可以通过 ReSharper 的选项或状态栏切换轻松启用此预览功能。虽然这是一个预览版本，但潜在的初始异常是预期的。文章列出了当前已知的 OOP 模式限制，包括 AI 功能、调试器集成、性能分析工具（DPA、dotMemory 等）、模板编辑器和结构化搜索等功能尚未完全支持。此外，EAP 2 版本还包含了对多个 C++ 26 功能和其他 C++ 更新的初始支持。JetBrains 鼓励用户提供反馈，以帮助优化 OOP 模式的实现。

💡 主要观点

  1. ReSharper 2025.2 EAP 2 提供了 OOP 模式的公开预览。 这项重大的架构变更将 ReSharper 与 Visual Studio 进程分离，以增强未来的稳定性和性能。
  2. 可以通过设置或状态栏切换来启用 OOP 模式。 提供了简单的步骤来切换进程内和进程外模式，以测试新架构。
  3. OOP 模式是一个具有已知限制的预览版。 AI、调试器和性能分析工具等功能尚未完全支持，表明仍在开发中，可能存在潜在问题。
  4. EAP 2 增加了对 C++ 26 的初步支持。 更新包括对 `= delete("reason")`、占位符变量和结构化绑定的属性的支持，与 C++ 开发人员相关。

💬 文章金句

  • 我们很高兴地宣布，ReSharper 2025.2 EAP 2 是首个引入进程外 (OOP) 模式，支持在 Microsoft Visual Studio 中运行 ReSharper 的公开版本。
  • 这种期待已久的架构变更奠定了未来更好稳定性和性能的基础。它通过将 ReSharper 进程与 Visual Studio 进程分离来实现这一点。
  • 进程外运行 ReSharper 有助于将 ReSharper 的工作负载与 Visual Studio 隔离，从而降低冲突和长时间卡顿的可能性。
  • 某些功能在进程外模式下尚未完全支持，可能无法按预期运行。
