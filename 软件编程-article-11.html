Datalore 2025.2 发布：报表标签页、增强的 DuckDB 支持和 Snowflake 密钥对认证 | Datalore 博客

4/17/2025, 1:30:57 PM

📌 一句话摘要

Datalore 2025.2 通过引入报表标签页、增强数据源支持和 Snowflake 密钥对认证等功能，旨在提升数据分析效率和安全性。

📝 详细摘要

Datalore 2025.2 版本为 Datalore Cloud 和 On-Premises 用户带来多项新功能。包括：报表标签页，允许用户将报表内容组织成多个视图；扩展了对 DuckDB 的支持，允许用户在 SQL 单元中直接分析本地文件；支持 Snowflake 密钥对认证，增强了 Snowflake 数据连接的安全性；以及允许为 Datalore 服务器使用自定义 JDBC 驱动，方便本地部署。此外，文章还提醒用户即将到来的 Python 版本升级，该升级会影响所有用户。

💡 主要观点

  1. 报表标签页提升了复杂报表的可读性和组织性 通过将报表内容组织成多个标签页，用户可以更轻松地浏览和理解复杂的数据分析结果，类似于 Excel 中的工作表。
  2. DuckDB 集成使得 Datalore 能够直接分析本地 CSV、Parquet 等格式的数据 Datalore 现在可以直接使用 DuckDB 查询本地 CSV、Parquet 等格式的文件，无需额外的数据导入和转换步骤。
  3. Snowflake 密钥对认证增强了数据连接的安全性 通过使用公钥 - 私钥加密技术，Datalore 可以更安全地连接到 Snowflake，避免了密码泄露的风险。
  4. 即将到来的 Python 版本升级需要用户注意兼容性问题 Datalore 将在 2025.3 版本将默认 Python 解释器升级到 Python 3.11，用户需要注意现有 notebook 的兼容性。
