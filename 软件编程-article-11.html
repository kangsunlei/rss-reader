Grafana Cloud Serverless Azure 指标与日志集成方案，告别 Alloy 依赖

4/9/2025, 1:10:05 PM

📌 一句话摘要

Grafana Cloud 推出 Serverless Azure 监控功能，简化配置并提供更深入的网络和事件中心洞察。

📝 详细摘要

Grafana Cloud 发布了针对 Microsoft Azure 指标和日志的 Serverless 功能，旨在简化配置，降低上手难度，免除基础设施管理。相比之前使用 Grafana Alloy 需要编写大量配置代码的方式，新的 Serverless 功能集成 Azure Prometheus exporter，实现 Azure 资源及指标的自动发现和收集，并使用 Azure Monitor Metrics Batch API 避免速率限制错误。此外，该功能还提供 Azure Monitor 无法提供的额外指标，如虚拟网络的 IP 地址使用情况和事件中心的容量信息。对于 Azure 日志，Grafana Cloud 提供了一个 Azure Function，可以订阅事件中心并将日志发送到 Loki 端点，并支持使用 jq 管道进行过滤和预处理。Grafana Labs 计划在未来将新的 Azure Metrics exporter 开源，并计划替换 Alloy。

💡 主要观点

  1. Serverless 功能简化了 Azure 指标和日志的配置。 无需编写大量 Alloy 配置，即可自动发现和收集 Azure 资源及指标，简化配置与管理流程。
  2. 新的 Azure Prometheus exporter 解决了速率限制问题。 使用 Azure Monitor Metrics Batch API，避免了速率限制错误，提高了数据收集的稳定性和可靠性。
  3. Serverless 功能提供 Azure Monitor 之外的虚拟网络 IP 地址和事件中心容量指标。 提供虚拟网络的 IP 地址使用情况和事件中心的容量信息等指标，帮助用户更好地了解 Azure 环境状态。

💬 文章金句

  • 现在，您可以通过我们新的 Serverless 功能，获得 Azure 指标和日志的相同甚至更好的结果。
  • 我们使用 Azure Monitor Metrics Batch API，它消除了可能妨碍您正确观察 Azure 环境的速率限制错误。
  • 通过 Cloud Provider Observability 解决方案，我们支持所有三个主要的云平台：AWS、Azure 和 Google Cloud。
