OpenAI 开发者日 2025 推出 GPT-5 Pro API、AgentKit、智能体工具包等

10/10/2025, 12:36:00 PM

📌 一句话摘要

OpenAI 的开发者日 2025 发布了“ChatGPT 内部应用”，配备 SDK，正式推出了用于开发的 AgentKit 和 Agents SDK，发布了 GPT-5 Pro 和 Sora 2 API，并强调了安全和评估的进展……

📝 详细摘要

OpenAI 于 2025 年 10 月 6 日举行的开发者日，重点是将聊天机器人转变为交互式软件平台。主要公告包括“ChatGPT 内部应用”，通过新的 SDK 实现，允许第三方软件呈现交互式 UI 并共享上下文，Canva 和 Zillow 等合作伙伴展示了它们与 ChatGPT 的集成应用。OpenAI 还通过 AgentKit 智能体工具包正式确定了智能体开发，提供用于可视化构建、数据源连接器、可嵌入 UI 和集成评估的工具。为了便于移植，引入了 Python 和 TypeScript 中的开源 Agents SDK。此外，Codex 已全面上市，定位于复杂的“为我做”工作流程，并通过 API 发布了新模型 GPT-5 Pro 和 Sora 2，讨论了它们增强的功能、延迟问题以及对版权问题的关键考虑。此次活动还强调了新连接器的安全影响和先进的评估方法。

💡 主要观点

  1. ChatGPT 内部应用将聊天机器人转变为集成的软件平台。 新的 SDK 允许第三方应用程序直接在 ChatGPT 中嵌入交互式 UI，从而创建一种新颖的分发渠道和用户体验，使软件在对话中运行。
  2. OpenAI 通过 AgentKit 智能体工具包和开源 Agents SDK 正式确定了人工智能智能体开发。 这些工具为构建、连接、评估和部署人工智能智能体提供了全面的框架，解决了开发人员常见的编排和治理挑战。
  3. 新模型 GPT-5 Pro 和 Sora 2 现在可以通过 API 使用，从而扩展了人工智能功能。 GPT-5 Pro 提供了增强的推理能力，而 Sora 2 则支持高级视频生成，突破了人工智能应用程序的界限，但也引发了关键的安全和伦理考虑。

💬 文章金句

  • 当天的主题是将聊天机器人变成一个软件运行、协作并在对话内部销售的地方。
  • 其目的是创建一个新的分发渠道，这个渠道将聊天界面作为应用程序的运行环境，而不仅仅是用户交互的界面。
  • AgentKit 智能体工具包包含一个可视化智能体构建器、一个用于管理数据源的连接器注册表、用于可嵌入智能体 UI 的 ChatKit 以及集成的评估和跟踪，以便团队可以观察工作流程并改进它们。
  • 如果您打算将 Sora 2 引入商业管道，请从一开始就计划好出处、同意和内容审查，而不是稍后才进行。
  • 将连接器视为生产集成，保留审计跟踪，并假设恶意提示攻击将到达您的系统的各个入口点。
