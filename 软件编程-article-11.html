MNN-Sana-Edit-V2：端侧运行的图像漫画风编辑大模型

4/22/2026, 9:02:00 AM

📌 一句话摘要

MNN-Sana-Edit-V2 是淘宝与杭电联合研发的端侧图像编辑大模型，基于 Sana 架构和 MetaQuery 思想，融合 Qwen3-0.6B 文本理解能力，在 iPhone 17 Pro 上仅需 14.7 秒即可完成漫画风格转换，较云端方案提速 2.5 倍，并已全面开源。

📝 详细摘要

本文详细介绍了 MNN-Sana-Edit-V2，一款由淘宝 Meta 技术团队与杭州电子科技大学联合研发的端侧图像漫画风编辑大模型。该模型基于 Sana 和 MetaQuery 学术成果，创新性地将 Qwen3-0.6B 作为冻结的预训练 LLM，通过 Learnable Query 和 Connector 模块桥接文本理解与图像生成。文章深入解析了其网络架构，包括 Learnable Query 作为连接理解与生成的桥梁、Connector 模块实现跨模态对齐、Deep Compression Autoencoder 实现 32 倍压缩、Linear DiT 降低计算复杂度等核心技术。训练策略采用三阶段渐进式训练，从文本到图像预训练，到图像生成微调，再到图像编辑微调。在端侧部署方面，通过 MNN 框架的 4/8bit 量化技术，在 iPhone 17 Pro 上实现 14.7 秒的漫画风格转换，显著优于云端方案。文章还提供了真机速度测试数据、运行要求和最优超参说明，并附有完整的开源代码和模型权重链接。

💡 主要观点

  1. MNN-Sana-Edit-V2 实现了端侧高效的图像漫画风格编辑。 该模型基于 Sana 架构和 MetaQuery 思想，融合 Qwen3-0.6B 的文本理解能力，在 iPhone 17 Pro 上仅需 14.7 秒即可完成 512x512 图像的漫画风格转换，较 OpenAI 云端方案提速 2.5 倍。
  2. Learnable Query 和 Connector 模块是桥接文本理解与图像生成的关键。 Learnable Query 作为可学习参数向冻结的 LLM 提问，提取适合图像生成的条件；Connector 模块则负责将 LLM 的语义表示对齐到 DiT 的输入空间，实现跨模态对齐。
  3. 三阶段训练策略确保了模型的最佳编辑效果。 训练分为文本到图像预训练、图像生成微调和图像编辑微调三个阶段，逐步对齐 LLM 与图像生成任务，并引入参考图像作为额外输入，保持图像结构一致性。
  4. MNN 框架的量化部署优化是端侧运行的核心保障。 通过将 PyTorch 模型转换为 MNN 格式，并对 LLM 采用 4Bit 量化、其他模型采用 8Bit 量化，显著减少内存占用并提高推理速度，使全部模型可在手机端本地运行。

💬 文章金句

  • Learnable Query 是可学习的'问题'向冻结的 LLM '提问'，提取适合图像生成的条件。
  • 经测试，OpenAI 的吉卜力风格图像生成耗时 38s-45s，我们在 iPhone 17 Pro 上，以端侧模型比云端模型的配置，做到了 2.5 倍的提速。
