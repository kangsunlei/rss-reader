安全通告：CVE-2025-66478

12/3/2025, 4:00:00 PM

📌 一句话摘要

React 服务器组件 (RSC) 协议中发现了一个严重远程代码执行 (RCE) 漏洞 (CVSS 10.0)，影响使用 App 路由器的 Next.js 应用，建议立即升级。

📝 详细摘要

本安全通告详细说明了一个严重的远程代码执行漏洞 CVE-2025-66478，该漏洞源于 React 服务器组件 (RSC) 协议中 React 官方代码的问题 (CVE-2025-55182)。此漏洞的 CVSS 评分为 10.0，允许未受信的输入影响未打补丁环境中的服务器端执行，可能导致 RCE。此漏洞特别影响在 15.x、16.x 版本以及从 14.3.0-canary.77 开始的金丝雀版本（用于小范围测试的预发布版本）上使用 App 路由器的 Next.js 应用。Next.js 13.x、14.x 稳定版、Pages 路由器应用和 Edge 运行时不受影响。Vercel 已经发布了修复版本（例如，15.0.5、16.0.7）来解决此问题。强烈建议所有受影响的用户升级到各自发布线中的最新修复版本，或者将金丝雀版本降级到稳定的 14.x 版本。在不升级的情况下，没有配置选项可以规避此漏洞。该通告特意省略了技术细节，以保护未打补丁的系统，并感谢 Lachlan Davidson 的负责任披露。

💡 主要观点

  1. RSC 协议中存在一个严重的 RCE 漏洞 (CVSS 10.0)，影响 Next.js App 路由器。 易受攻击的 RSC 协议允许未受信的输入触发意外的服务器端执行路径。这可能在特定的 Next.js 配置中导致远程代码执行。
  2. 特定的 Next.js 版本（15.x、16.x 和某些 14.3.0+ 金丝雀版本）容易受到攻击。 此漏洞影响在 15.x、16.x 版本以及从 14.3.0-canary.77 开始的金丝雀版本上使用 App 路由器的 Next.js 应用，而其他版本和配置不受影响。
  3. 建议立即升级到已修复的版本，目前没有其他临时解决方案。 用户必须升级到指定的已修复 Next.js 版本或将金丝雀版本降级到稳定的 14.x，因为没有配置选项可以禁用易受攻击的代码路径。
