1Password 客户记录遭窃，员工 GitHub 账号成黑客突破口

11/26/2026, 10:01:00 AM

📌 一句话摘要

1Password 员工 GitHub 账号被攻击者入侵，导致客户账户记录被窃取，但核心密码库未受影响，公司已升级验证码防护并轮换所有泄露凭证。

📝 详细摘要

1Password 披露安全事件，攻击者通过员工企业 GitHub 账号窃取客户账户记录。公司于 11 月 19 日发现异常，调查发现攻击者利用该账号向后端服务推送恶意代码，获取客户数据。窃取的记录包含姓名、邮箱、账户标识符、创建时间、登录时间、公钥、SRP 参数及部分邮件链接令牌。核心密码库、密钥和恢复密钥均未受影响。攻击者还获取了私有代码仓库源代码和 CI/CD 系统访问权限。公司已轮换所有泄露凭证，升级验证码为 10 位字母数字组合，封禁涉事账号，聘请独立专家验证。

💡 主要观点

  1. 攻击者通过员工 GitHub 账号窃取客户账户记录 攻击者利用员工企业 GitHub 账号向公司后端服务推送恶意代码，通过代码下载了客户相关管理数据，包括姓名、邮箱、账户标识符、创建时间、登录时间、公钥、SRP 参数及邮件链接令牌。
  2. 客户核心密码库未受影响 公司披露公告指出攻击者始终无法访问客户保险库中的内容，客户保险库、库内存储的条目以及保护保险库的密钥均未受影响，公司本身不存储账户密码和 Secret Key。
  3. 公司采取多项应急措施 已升级邮件验证码从 6 位数字到 10 位字母数字组合，封禁涉事 GitHub 账号，作废被盗令牌，收紧内部管控，同时聘请独立网络安全专家验证遏制与修复工作的有效性。

💬 文章金句

  • 攻击者始终无法访问，也从未接触到客户保险库中的内容。
  • 1Password 绝不会主动联系用户索要账户密码或 Secret Key。
