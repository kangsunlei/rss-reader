又一个神级画图 Skill，开源了！

10/13/2026, 10:54:00 AM

📌 一句话摘要

Anatomy 是一个开源的 AI 画图工具，通过自然语言描述即可生成交互式的 3D 机器原理结构图解。

📝 详细摘要

本文介绍了一个名为 Anatomy 的开源项目，它允许用户通过 Claude Code、Codex 或 OpenCode 等工具，利用简单的指令生成发动机、机械机芯等复杂机器的立体拆解图。生成的图像支持等距视角、实时数据交互（如拖动油门观察转速变化）以及 WebGL 实时渲染效果，极大地降低了复杂机械原理图的制作门槛。

💡 主要观点

  1. 自然语言驱动复杂模型生成 用户只需通过对话描述机器类型及运行逻辑，AI 即可自动绘制零件并生成结构示意图。
  2. 高度交互的视觉演示 生成的图解不仅是静态的，还支持交互，如通过鼠标移动零件、模拟油门操作并伴随实时数据变化。
  3. 精细的视觉表现力 工具采用等距视角（Isometric View）设计，并支持 WebGL 渲染火焰、水波和灯光等特效，视觉质量极高。
  4. 极简的集成与安装 通过 npx 命令即可快速安装，无需额外的 API Key 或复杂的依赖配置，非常适合开发者快速上手。

💬 文章金句

  • 只要说清楚想看哪台机器、想让它怎么动，剩下的活基本都可以交给 anatomy 去干。
  • 以前想做一张能拆能动的机器图解，没点建模和动画功底根本下不了手。
