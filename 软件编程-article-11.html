agent 优化之 GEPA——一种提示词自进化的优化方案

9/16/2026, 6:12:00 AM

📌 一句话摘要

本文介绍了基于 GEPA 算法的 Prompt 自进化系统，通过构建“推理-评分-反思-选择”的闭环实现提示词的自动化优化与权衡。

📝 详细摘要

文章基于 GEPA（Genetic-Pareto， Reflective Prompt Evolution）算法，解决了 Prompt 优化依赖人工经验导致的盲目、难以复制等痛点。系统通过构建“推理→评分→反思→选择”的闭环，利用数据驱动的反思式变异机制，让 LLM 自动分析 Bad Case 并归因至具体规则，生成候选变体，并基于帕累前沿（Pareto Frontier）进行多目标择优，避免单点优化导致的指标性退化。

💡 主要观点

  1. 传统 Prompt 优化存在四大核心痛点 盲目性高（依赖直觉）、伪自动化（静态扫描缺乏深度反思）、难以复制（经验沉淀个人）以及无权衡机制（单点优化顾此失彼）。
  2. GEPA 的核心技术路径是反思式变异 通过 LLM 自动分析 Bad Case 并将其归因到具体的 Prompt 规则中，将人工试错转化为可量化的自动化寻优。
  3. 引入帕累前沿（Pareto Frontier）进行多目标择优 不再始终选择表现最优的单一候选，而是从多个任务的最优集中筛选采样，确保在指标震荡中保留最优权衡面。
  4. 系统架构采用分层设计以支持工程落地 分为配置层（定义任务）、引擎层（核心循环排调度）、组件层（解析、评分、反馈逻辑）和服务层（CLI、API），支持任务无关的通用适配。

💬 文章金句

  • Prompt 优化依赖人工经验导致的盲目性高、难以复制、缺乏权衡机制等痛点。
  • GEPA 将 Prompt 优化从人工试错变为有量化依据的自动化寻优。
  • 在指标震荡中保留最优权衡面。
