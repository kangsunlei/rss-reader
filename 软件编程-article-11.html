“我用 Java 8”已成过去式！Java 25 正式发布：Oracle 提供八年更新、18 项新功能上线

9/17/2025, 10:20:00 AM

📌 一句话摘要

Java 25 作为最新的长期支持（LTS）版本正式发布，带来了 18 项新功能，包括语言改进、库更新、安全增强及性能提升，并提供长达八年的 Oracle 商业支持。

📝 详细摘要

文章详细介绍了 Oracle 最新发布的 Java 25，这是一个重要的长期支持（LTS）版本，将获得至少八年的 Oracle Premier 商业支持。文章首先阐明了 NFTC 和 OTN 两种许可模式在免费使用和商业部署上的区别。随后，深入剖析了 Java 25 带来的 18 项功能更新，涵盖语言改进（如原始类型模式匹配、灵活构造函数体）、库更新（如结构化并发、作用域值、向量 API），以及安全（如 PEM 加密对象编码、密钥派生函数 API）和性能提升（如紧凑对象头、AOT 编译、JFR 增强、分代 Shenandoah GC）。其中，部分特性如原始类型模式匹配、结构化并发、PEM 加密对象编码仍处于预览或孵化阶段，而灵活构造函数体、作用域值、密钥派生函数 API、紧凑对象头、分代 Shenandoah GC 则已正式定型。文章还提及了其中 5 项功能可助力 AI 开发。最后，文章结合最新数据，指出 Java 17 和 21 已成为主流，并对 Java 25 能否取代老版本成为新的主力表达了期待。

💡 主要观点

  1. Java 25 作为 LTS 版本提供长期支持，并明确了商业许可模式。 Oracle 为 Java 25 提供长达八年的商业支持，并详细解释了 NFTC 与 OTN 许可在开发和生产环境中的使用差异，这对于企业级应用和长期规划至关重要。
  2. Java 25 引入多项语言、库和安全层面的重要新功能，提升开发效率和代码质量。 包括原始类型模式匹配、模块导入、结构化并发、作用域值、向量 API、PEM 加密 API 和密钥派生函数 API 等，这些特性使 Java 语法更一致、开发更便捷、系统更安全。
  3. Java 25 在性能优化方面取得显著进展，旨在提升应用启动和运行效率。 通过紧凑对象头、AOT 编译改进、JFR 增强和分代 Shenandoah GC 的正式化，Java 25 有效减少内存占用、加快启动速度，并提高运行时性能与可观测性。

💬 文章金句

  • 值得注意的是，Oracle 最新发布的 Java 25 是最新的长期支持（LTS）版本，回看上一版 LTS 还是 2023 年 9 月推出的 JDK 21。
  • 据 Oracle 公告显示，此番 Java 25 共计带来了 18 项功能更新，其中 5 项 Oracle 宣称可以助力 AI 开发。
  • 该功能将 HotSpot JVM 中对象头的大小，从原本的 96 位到 128 位压缩到 64 位（在 64 位架构上），从而减小堆内存占用，提高部署密度和数据局部性。
  • 对于 Java 25 的正式发布，虽然不少网友继续调侃道，'你发任你发，我用 Java 8'，但根据今年 Azul 组织发布关于 Java 使用的最新数据显示，开发者们最关心的还是长期支持版（LTS）。
