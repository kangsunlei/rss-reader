MonkeyCode 是一个提供免费每日 3000 万 Token 和云端开发机器的开源 AI 编程平台，最近推出桌面端 MonkeyWork，支持本地文件、模型、MCP 和浏览器操作。

📝 详细摘要

文章介绍了开源项目 MonkeyCode，该平台在 GitHub 上已获 4000+ Star，提供免费用户每日 3000 万基础模型 Token 和免费云端开发机器，降低 AI 辅助编程的门槛。重点讲解了 récemment 发布的桌面端 MonkeyWork：它把 Agent 带到本地文件夹，能够读取、修改代码、文档、表格和图片，并通过模型配置、MCP 能力（如联网搜索、图片生成）以及浏览器扩展桥实现网页操作。文章还说明了三种任务模式（本地任务、云端任务、独立会话）、私有化部署方案及最低硬件要求，并给出了在线使用、客户端下载和文档链接。整体内容围绕免费额度、功能扩展和使用方式展开，适合对 AI 开发工具感兴趣的读者快速了解并上手。

💡 主要观点

  1. 免费额度与云端资源：每日 3000 万基础模型 Token 和免费云端开发机器。 免费用户自动获得每日 3000 万 Token 额度，可调用 Kimi K2.5、MiniMax M2.5、Qwen3.5 Plus 等基础模型；云端开发环境同样免费使用且正常任务时会自动续期，无需自行准备服务器或购买 API。
  2. MonkeyWork 桌面端功能：本地文件、模型、MCP 与浏览器操作一体化。 通过选择本地文件夹授权，MonkeyWork 能读取、修改代码、文档、表格和图片；支持绑定百智云或自定义模型地址，同步 MCP 能力（联网搜索、图片生成等）；配合浏览器扩展桥，可在用户授权的标签页上进行网页读取、点击、输入和截图。
  3. 三种任务模式适配不同场景。 本地任务绑定文件夹，适合处理代码、文档和素材；云端任务同步网页端和 App 中的任务，继续使用免费云端机器；独立会话不绑定文件夹，适合临时问答、记录想法和梳理思路。
  4. 私有化部署与使用方式灵活。 团队可将控制台和开发环境宿主机部署在内网服务器，官方给出最低配置（控制台 2 核 CPU/4GB RAM/40GB 磁盘，宿主机 8 核 CPU/16GB RAM/100GB 磁盘）；个人可直接访问在线版注册后使用免费额度，或下载 MonkeyWork 客户端进行本地任务。
