TypeGPU：基于 TypeScript 的 WebGPU 库

📌 一句话摘要

TypeGPU 是一个新的 TypeScript WebGPU 库，其 'use gpu' 指令可将 JavaScript 代码编译为 WGSL，并在 GPU 上执行。

📝 详细摘要

这条推文介绍了 TypeGPU，一个用于 WebGPU 的 TypeScript 库，展示了其创新的 'use gpu' 指令。该指令允许开发者编写 JavaScript 代码，然后将其编译为 WebGPU 着色语言 (WGSL) 并在 GPU 上直接执行，从而在 Web 应用程序中实现高性能计算。这条推文包含一个代码示例，演示了如何使用这个指令，并提到了一个用它构建的“奇迹”，表明了其在 Web 图形和计算方面的强大功能。
