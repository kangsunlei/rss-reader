TikTok 原生跨平台 UI 框架 Lynx 宣布开源

4/1/2025, 9:14:52 AM

📌 一句话摘要

字节跳动开源原生跨平台 UI 框架 Lynx，通过 Web 技术栈和双线程架构实现高性能原生应用开发，已应用于 TikTok。

📝 详细摘要

字节跳动开源了原生跨平台 UI 框架 Lynx，该框架允许开发者使用 Web 技术（HTML、CSS、JavaScript）构建原生移动应用。Lynx 借鉴了 Chromium、Flutter 和 React Native 的设计思想，旨在解决多平台适配和开发效率问题。它通过自定义 JavaScript 引擎和**像素级 UI 渲染**，实现了接近原生应用的性能。Lynx 采用**双线程架构**，优化了首帧渲染时间，并保证了交互的流畅性。该框架包含核心引擎、ReactLynx、Rspeedy 打包工具、PrimJS 引擎和 Lynx DevTool 等组件，目前已应用于 TikTok 的搜索框和 TikTok Studio 等场景。未来，Lynx 还将扩展到桌面端、电视和 IoT 设备等更多平台。

💡 主要观点

  1. Lynx 框架旨在解决多平台应用开发的效率和性能问题。 通过统一的技术栈和优化后的架构，减少了重复开发工作，提高了应用在不同平台上的性能表现。
  2. 双线程架构是 Lynx 实现高性能的关键。 主线程处理高优先级任务，后台线程执行用户代码，优化了首帧渲染时间，并保证了交互的流畅性。
  3. Lynx 框架已在 TikTok 的关键业务中得到应用。 这证明了该框架在实际应用中的可行性和价值，为开发者提供了参考案例。

💬 文章金句

  • Lynx 框架延续了相似的设计理念------"专为应用开发定制的替代性 Web 方案"。
  • Lynx 受 Chromium、Flutter 和 React Native 启发，意在通过应对日益复杂的设备形态差异和多平台支持需求，实现规模化且更高效的原生级体验。
  • 主线程专用于处理高优先级的同步非阻塞任务，后台线程则负责执行用户代码。
  • Lynx 项目最初命名时并未考虑长远影响。鉴于已有大量代码库和用户依赖现有名称，我们决定保持原名，不因项目的开源而更名。
  • 字节跳动将持续推进 Lynx 框架的开源进程，未来将陆续公开更多 UI 组件、定制化渲染引擎及其他前端方案。
