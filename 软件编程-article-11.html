Google Cloud Run 现在提供用于 AI 和批量处理的无服务器 GPU

6/9/2025, 12:00:00 AM

📌 一句话摘要

Google Cloud Run 全面推出用于 AI 推理和批量处理的无服务器 GPU 支持。

📝 详细摘要

Google Cloud 已为其无服务器平台 Cloud Run 提供了 NVIDIA GPU 支持的全面可用性。此增强功能专为 GPU 加速工作负载设计，主要用于 AI 推理和批量处理。重点强调的关键优势包括按秒计费、自动缩容至零以提高成本效益、快速启动时间（不到 5 秒），以及对实时 LLM 响应等交互式应用的全面流式支持。该服务提供 NVIDIA L4 GPU 支持，无需配额请求，并且已生产就绪，提供 SLA 覆盖和区域冗余选项。在开发者社区中，该服务被认为相对于 AWS Lambda 等平台在现代 AI 工作负载方面具有竞争优势，因为 Lambda 的限制（超时、仅限 CPU）对现代 AI 工作负载构成了限制。然而，用户讨论也提出了对缺少硬计费上限以及与 Runpod.io 等专业提供商相比可能存在的成本差异的担忧。Cloud Run 作业（私有预览）也提供 GPU，扩展了异步任务的能力。

💡 主要观点

  1. Cloud Run 现在提供具有按秒计费和自动缩容至零功能的无服务器 GPU。 这使得 GPU 密集型任务能够以成本效益高的方式执行，通过消除空闲成本，这对于零星或不可预测的 AI 和批量工作负载尤其有益。
  2. Cloud Run 上提供 NVIDIA L4 GPU 无需配额请求。 这消除了一个重要的进入门槛，简化了开发者在 Google Cloud 上构建 AI 应用时访问高性能计算的过程。
  3. 配备 GPU 的 Cloud Run 解决了现有无服务器计算对于现代 AI 的限制。 与具有超时和仅限 CPU 计算的 AWS Lambda 等产品不同，Cloud Run GPU 使得 Stable Diffusion 或实时视频分析等任务得以在无服务器环境中实现。
  4. 该服务已生产就绪，具有 SLA 覆盖并提供区域冗余。 这确保了关键 GPU 加速应用的可靠性和正常运行时间，提供了可配置的弹性（或 容错能力）和成本选项，这对于全面可用性至关重要。

💬 文章金句

  • 无服务器 GPU 加速代表着一项重大进步，使前沿 AI 计算更易于访问。
  • Cloud Run GPU 现已全面可用。这是 AWS 几年前就应该构建的东西：真正可用的无服务器 GPU 计算。
  • 尝试在 Lambda 中运行 Stable Diffusion 推理、微调模型或使用 AI 处理视频。你做不到。
  • 虽然 Cloud Run 允许设置最大实例限制，但它不提供实际的基于美元的消费上限。
