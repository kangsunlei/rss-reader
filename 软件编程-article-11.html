月耗 890 万元！OpenClaw 之父晒 AI 账单引全网热议：30 天调用 6030 亿 Token、760 万次 API 请求

5/18/2026, 8:16:00 AM

📌 一句话摘要

OpenClaw 项目创始人公开了一张由 OpenAI 买单的 130 万美元月 API 账单，揭示了 100 个 AI 编程代理在无预算约束下的惊人 Token 消耗与成本，引发行业对 AI 开发真实成本与可持续性的热议。

📝 详细摘要

文章报道了 OpenClaw 项目创始人 Peter Steinberger 公开的一张 OpenAI API 使用账单，显示其 3 人团队在 30 天内消耗了 130.5 万美元（约 890 万元人民币），调用 6030 亿 Token、发起 760 万次 API 请求，支撑约 100 个 Codex 代理全天候运行。这些 AI 代理自主执行代码审查、漏洞修复、Issue 去重、功能 PR 提交和性能监控等任务。账单由 OpenAI 全额买单，且使用了计费更高的快速模式。文章引用了网友的尖锐评论，指出当前 AI API 定价建立在厂商补贴之上，真实算力成本远高于账面数字。Steinberger 的探索性实验引发了关于 AI 开发成本、价值衡量和商业模式可持续性的广泛讨论。

💡 主要观点

  1. OpenClaw 项目 30 天 API 账单高达 130 万美元，由 OpenAI 全额买单。 3 人团队使用约 100 个 Codex 代理，消耗 6030 亿 Token 和 760 万次 API 请求，日均成本近 2 万美元，揭示了 AI 编程在无预算约束下的极端成本规模。
  2. AI 代理已能自主执行多项软件开发任务，大幅提升效率。 这些代理覆盖代码审查、安全漏洞修复、Issue 去重、功能 PR 提交和性能监控等环节，将传统需数十人团队的工作压缩至 3 人把控方向，效率提升数十倍。
  3. 当前 AI API 定价建立在厂商补贴之上，真实成本远高于账面。 网友评论指出，130 万美元月费相当于一支旧金山资深工程师团队的年薪，且仅为 Token 消耗。若按真实算力成本计算，费用只会更高，引发对 AI 商业模式可持续性的质疑。
