研究人员攻破多款开发工具内嵌浏览器，代码执行与数据泄露风险曝光

10/31/2026, 10:00:00 AM

📌 一句话摘要

研究人员发现 Cursor、GitHub Copilot 等 AI 编程工具的内嵌浏览器存在 EMBRACE 漏洞，可导致代码执行与数据泄露。

📝 详细摘要

安全团队 Forever Security 披露了多个热门 AI 编码工具（Cursor， GitHub Copilot， Codex， VS Code， Claude Desktop）的内嵌浏览器存在安全缺陷。这些漏洞源于工具对内嵌预览页面的过度信任，允许攻击者通过构造恶意页面绕过沙箱限制，从而执行任意代码或窃取 SSH 密钥、env 配置文件等敏感信息。目前 Cursor 和 Copilot 已修复漏洞，其他厂商正在跟进。

💡 主要观点

  1. 多款 AI 编程工具内嵌浏览器存在 EMBRACE 漏洞 漏洞核心在于工具在处理内嵌预览页时，未严格验证上报地址与实际加载地址的一致性，赋予了恶意页面额外权限。
  2. Cursor 允许通过 HTML 属性隐藏恶意指令 攻击者可在 HTML 属性中隐藏恶意片段，用户只需按下回车键，Agent 就会拼接并执行 npm 安装命令，绕过沙箱。
  3. GitHub Copilot 存在地址欺骗导致钓鱼风险 其预览功能仅校验地址格式，攻击者可让恶意页面的地址栏伪造为 github.com，误导用户输入虚假凭据。
  4. Codex 与 VS Code 可绕过 Web Worker 限制窃取文件 恶意预览页面可在后台运行脚本，利用主页面的检查规则读取项目文件夹之外的本地文件，如 SSH 密钥和 npm 令牌。

💬 文章金句

  • 研究人员将这类攻击命名为 EMBRACE，全称为'被当作信任的内嵌浏览器'
  • 这类漏洞虽具体表现不同，但根源是同一类缺陷：原本用于帮助助手预览、读取标签页的功能给了不可信内容应有的权限
  • AI 助手内置浏览器一旦获得宿应用的额外权限，就可能突破原有边界
