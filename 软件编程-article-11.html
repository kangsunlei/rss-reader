WorkSwarm：引领办公智能体新范式，让 AI 从一个助手，进化为一支与你并肩作战的团队

8/17/2026, 5:40:00 AM

📌 一句话摘要

WorkSwarm 通过多智能体协作与协同工程，让 AI 从单一助手进化为可分工协作的办公团队，支持文档、音乐、编程等场景。

📝 详细摘要

文章介绍了由华为 2012 实验室、华为云、终端、计算联合打造的 openJiuwen 旗下办公智能体 WorkSwarm。WorkSwarm 采用多智能体协作模式，根据任务自动组建不同角色的 Agent 团队，实现任务拆解、上下文共享、成果接力以及过程透明。文中通过写歌、续写《岳阳楼记》、批量生成 PPT、编程热量记录工具等具体案例，展示了单 Agent 与集群两种工作模式，以及团队成员如何在真实工具中读写文件、调用专业技能并交付成品。此外，文章还提到 WorkSwarm 支持鸿蒙 PC、Windows、Mac 平台，提供移动端入口，并通过 Swarm Skill 机制将成功的协作流程沉淀为可复用的能力。整体内容围绕 AI 办公智能体从助手向团队形态的演进展开，兼具技术描述与应用场景阐释。

💡 主要观点

  1. WorkSwarm 根据目标自动组建多角色 Agent 团队，实现任务拆解与协同。 系统会根据用户给出的主题或需求，匹配具备相应能力的 Agent（如作词师、作曲师、编曲师等），分配子任务，让团队成员在共享项目背景下继续上游成果的工作。
  2. 提供单 Agent 轻量模式与多 Agent 集群模式，适配不同任务复杂度。 查询、文字修改等简单工作可由单个 Agent 完成；涉及多角色、多轮交付的复杂任务则由集群模式下的多个 Agent 协同，例如 20 分钟内生成 200 页高质量 PPT。
  3. 团队成果与过程可视化、可追踪，支持人类随时介入与调整。 所有成员的讨论、任务状态、执行记录和项目文件集中在同一工作台，用户可查看进度、修改要求或直接参与其中一环，实现人与 AI 的无缝接力。
  4. 通过 Swarm Skill 机制将成功的协作流程沉淀为可复用能力。 一次高效协作的角色组合与流程可以被保存为 Swarm Skill，后续类似任务可直接调用，提升团队在特定业务场景下的效率与一致性。

💬 文章金句

  • WorkSwarm 用 Coordination Engineering（协同工程）来组织这些环节。
  • 团队里有人规划，有人执行，也有人专门找问题。
  • 大纲不满意就打回，技术细节 @专家智能体会诊，中途还能加一名美化成员。
  • 集群模式下输入主题、受众和风格，系统自动组建团队分头开工------调研、搭结构、补内容、整合同步推进，原本串行的工序变成并行任务链，20 分钟交付 200 页高质量 PPT。
  • 最终交付包含 MP3、歌词、作曲规划、编曲总结、演唱说明、伴奏建议、间奏评审、版本记录、交付总结和 Style Prompt，共 12 项文件。
