📌 一句话摘要

Maigret 是一个开源用户名搜索工具，输入一个用户名即可在 3000+ 网站中查找其注册信息，并汇总成报告。

📝 详细摘要

本文介绍了 GitHub 上 Star 数达 2.4 万的开源项目 Maigret。该工具的核心功能是输入一个用户名，自动在超过 3000 个网站上搜索该用户名是否被注册，并汇总所有公开信息生成报告。文章详细阐述了其关键特性：覆盖 3000+ 站点、支持递归搜索（发现新线索后自动继续搜索）、2026 年 4 月新增的 AI 分析模式（接入 LLM 进行智能分析）、丰富的报告输出格式（HTML、PDF、XMind、JSON、CSV 及交互式 D3 图谱）以及内置 Web 界面。文章还提供了简单的安装和使用方法（pip 安装、Docker 部署），并强调了其合法用途和隐私保护意义。

💡 主要观点

  1. Maigret 是一个强大的开源用户名搜索工具，覆盖 3000+ 网站。 用户只需输入一个用户名，工具即可自动在大量网站上搜索该用户名的注册情况，并汇总公开信息，无需 API Key。
  2. 工具具备递归搜索和 AI 分析等高级功能。 递归搜索能根据发现的关联信息自动扩展搜索范围；新增的 AI 分析模式利用 LLM 对结果进行智能梳理，提升信息价值。
  3. Maigret 提供了多种使用方式和丰富的报告输出格式。 支持 CLI、Docker Web 界面、Telegram 机器人以及作为 Python 库集成；报告可输出为 HTML、PDF、JSON 等多种格式。

💬 文章金句

  • Maigret 做的事情很直白：你给它一个用户名，它去 3000 多个网站上搜索这个用户名是否注册了账号，然后把找到的所有公开信息汇总成一份完整的报告。
  • 它不只是机械地匹配用户名，当在一个站点上发现了新的关联 ID 或者其他用户名时，会自动拿这些新线索继续搜。
  • 在这个数字痕迹无处不在的时代，了解自己的信息暴露面，某种程度上也是一种自我保护...
