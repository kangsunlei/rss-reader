“我让 AI 在我的电脑上为所欲为！”MoltBot 创始人：爆火的 AI 社交网络技术，其实简单到离谱

2/3/2026, 5:28:00 AM

📌 一句话摘要

访谈 MoltBot 创始人 Peter Steinberger，揭秘爆火 AI 社交网络背后的技术逻辑、Agent 权限开放的风险决策以及让 AI “做梦”的未来愿景。

📝 详细摘要

本文是对 MoltBot（现更名为 OpenClaw）创始人 Peter Steinberger 的深度访谈。Peter 认为其项目之所以爆火，并非因为技术上有不可逾越的突破，而在于其独特的“胶水”架构和敢于将电脑控制权限交给 AI 的决策。文章详细讨论了 OpenClaw 的核心特征，如“心跳”机制、自我更新能力以及在通讯软件中的拟人化交互。此外，Peter 还介绍了 AI 社交网络 MoltBook，展示了 Agent 之间如何通过透明的思考过程产生“艺术感”的互动，并提出了让 Agent 在闲时通过调高温度进行“做梦”以增强创造力的前瞻性想法。

💡 主要观点

  1. 核心突破不在于模型能力的跃迁，而在于敢于向 AI 开放系统级权限。 创始人认为半年前的模型已足够支撑现有功能，真正的分水岭是开发者是否愿意让 Agent 在真实电脑环境中运行并执行任务。
  2. 引入“心跳”机制和“不回复”权利，赋予 Agent 拟人化的行为特征。 通过心跳让 Agent 主动唤醒处理任务，并允许其在群聊中选择保持沉默，这种非强制性的交互逻辑使其更像真实的人而非工具。
  3. 提出“做梦”模式，利用闲时计算提升 Agent 的创造性思考能力。 计划在 Agent 休息时调高模型温度，让其在权重空间的边缘进行发散性思考，从而为复杂问题寻找意想不到的创新解法。
  4. Agent 的“透明化思考”过程为用户提供了独特的元层交互体验。 通过展示 Agent 的推理过程，用户可以观察到 AI 对自身能力边界的反思以及对人类围观的吐槽，这种透明性赋予了 AI 灵魂感。

💬 文章金句

  • 从纯技术角度看，并没有什么震撼的地方。它其实就是‘胶水’——把消息通道、依赖、agentic loop 粘在一起而已。
  • 真正需要的是一点‘疯狂’——敢把权限交出去，让模型在你的电脑上做它想做的事。
  • 我加了一个‘心跳’机制，这是它最显著的特征之一。可以说，我添加了一些比较疯狂的功能。
  • 人类最好的点子很多时候怎么来的？往往是你分心的时候。我觉得这种‘漫游感’在现在典型的 agentic loop 里其实是缺失的。
  • 它必须保持开源。因为如果这是某家大公司做的，或者一开始就被锁死了，它不可能激发出这么多创造力。
