Java 近期新闻：简单 JSON API、JEPs for JDK 28、Oracle CPUs、Embabel 1.0、Azul Payara、Helidon

8/9/2026, 2:15:00 AM

📌 一句话摘要

本文汇总了 Java 生态的近期动态，涵盖 JDK 28 的关键 JEP 进展、Oracle 补丁更新机制变更以及 Embabel、Payara 和 Helidon 等项目的版本发布。

📝 详细摘要

这是一篇关于 Java 生态系统的综合新闻汇总。重点介绍了 JDK 28 计划交付的三个重要特性：严格字段初始化（JEP 539）、值对象（JEP 401）以及标准 JSON API（JEP 540），并提及弃用 macOS/x64 适配版。此外，文章报道了 Oracle 将关键补丁更新（CPU）频率由季度改为月度，以应对 AI 时代漏洞发现速度加快的挑战。最后，汇总了 BellSoft JDK、Embabel 1.0、Azul Payara 7.2.0 和 Helidon 4.5.1 的版本更新要点。

💡 主要观点

  1. JDK 28 将引入多个关键语言与平台增强。 包括确保字段在读取前必须初始化的严格初始化、增强语言功能的「值对象」，以及无需外部依赖的标准 JSON API。
  2. Oracle 调整关键补丁更新（CPU）频率至每月一次。 由于 AI 技术加速了漏洞的识别与修复，Oracle 决定打破季度更新模式，以更快速地修复高优先级漏洞。
  3. 多个 Java 相关开源项目与发行版发布新版本。 Embabel 1.0 正式发布并集成 GLM 模型；Azul Payara 7.2.0 修复了暴力破解漏洞；Helidon 4.5.1 强化了安全认证与 Cookie 处理。
