微软商店恶意应用关联 Vinci RAT，黑客可远程控制 Windows PC

11/27/2026, 10:00:00 AM

📌 一句话摘要

黑客通过虚假下载站诱导用户安装微软商店应用 Setup Assistant，从而投递 Vinci RAT 远程访问木马，实现对 Windows PC 的远程控制。

📝 详细摘要

eSentire 威胁响应部门发现，攻击者利用虚假下载站点分发带有数字签名的安装程序，诱导用户通过微软商店安装名为 Setup Assistant 的恶意应用。该应用基于 Electron 构建，安装后会连接 C2 服务器并利用 PowerShell 加载器下载 Vinci RAT。Vinci RAT 具备收集系统信息、执行命令、写入文件及反向 Shell 等完整远控能力，并通过 Windows 计划任务实现持久化。该恶意应用已在商店上架约 5 个月，提醒用户即使是正版商店应用也可能存在安全风险。

💡 主要观点

  1. 攻击链路利用虚假下载站引流至微软商店真实应用 攻击者分发带有数字签名的假冒截图工具安装程序，引导用户跳转至微软商店下载名为 Setup Assistant 的真实应用，这种方式比单纯仿冒界面更具迷惑性。
  2. Setup Assistant 作为载荷投递 Vinci RAT 该应用通过连接 C2 服务器接收指令，利用 PowerShell 加载器从独立域名拉取 Vinci RAT，并通过创建每 10 分钟执行一次的 Windows 计划任务实现持久化。
  3. Vinci RAT 具备全面的远程控制能力 该木马可收集计算机名、用户名、Windows 版本及安全工具信息，支持反向 Shell、执行可执行文件、DLL 及 PowerShell 脚本，部分载荷可在内存中直接运行。
  4. 防御建议侧重于异常行为监测与权限限制 安全团队应关注异常 PowerShell 活动、新建计划任务及可疑出站连接；企业可通过 Intune、AppLocker 等工具限制商店应用安装权限。

💬 文章金句

  • 即使用户进入的是正版微软商店，也不代表下载的应用安全可靠。
  • 这种滥用 Windows 计划任务实现持久化的特征辨识度很高。
