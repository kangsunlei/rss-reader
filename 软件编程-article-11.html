B 站大数据平台元数据血缘建设与应用

7/25/2025, 4:05:00 AM

📌 一句话摘要

B 站详细阐述了其大数据平台元数据血缘体系的建设历程、技术架构演进、质量保障体系及在数据治理、质量与安全中的应用实践。

📝 详细摘要

文章深入介绍了 Bilibili 大数据平台元数据血缘系统的建设与应用。面对公司业务扩展导致的数据关系复杂化和血缘信息分散问题，B 站着手构建统一的元数据血缘平台。文中详细阐述了大数据平台的数据加工全链路，并设计了两套通用血缘模型以覆盖多维度血缘关系。系统架构从初期业务方主动上报的 V1 版本，逐步演进到元数据采集服务主动拉取的 V2 版本，有效解决了运维困难、信息遗漏和消息丢失等痛点，并创新性地实现了算子级血缘解析和非 SQL 类型任务血缘的落地。文章还详细分析了血缘的时效性、覆盖率和准确率等核心质量指标。最终，这套完整的血缘系统在数据查找与影响评估、数据质量保障、数据安全管控和数据治理等多个关键场景中发挥了巨大价值，并展望了未来行级血缘解析和更广场景覆盖的规划。

💡 主要观点

  1. 统一元数据血缘是应对大数据复杂性的核心策略 通过集中采集、统一建模和存储血缘信息，解决数据来源、流向和变更历史不清等问题，为数据治理、质量和安全提供基础支撑，实现全局视角洞察数据流转。
  2. 血缘采集架构从被动上报演进为主动拉取，显著提升数据质量 V2 架构通过自运维、接口对接、数据量对比和分级队列等机制，大幅提高了血缘数据的完整性、准确性和时效性，减少了信息遗漏和运维成本。
  3. 细粒度血缘（算子级、非 SQL 任务）拓展了数据治理深度 通过 SQL AST 解析实现算子级血缘，发现并治理重复加工模型；通过 HDFS 审计日志解决非 SQL 任务血缘难题，进一步提升数据治理效率和覆盖率。
  4. 元数据血缘在企业级应用中发挥多重价值 支撑数据影响分析、链路基线保障、敏感数据安全传递、报表分类分级以及无热度数据治理和数据寻主，全面提升数据管理和使用效率。

💬 文章金句

  • 元数据血缘的建设是理清这些复杂数据关系的最佳途径，它不仅能够明确数据的来源、流向和变更历史，向用户清晰明了的展示出数据之间的依赖关系，还为数据平台内的数据治理、数据质量和数据安全提供了重要的支持。
  • 我们着手对元数据血缘进行统一收口，推动各业务模块将血缘信息集中上报和采集，汇聚到统一元数据血缘平台。
  • 通过对 AST 语法树中规则的不断递归和遍历解析出 SQL 中不同关键字所对应的逻辑，从而获得算子级血缘。
  • 通过对非 SQL 任务的血缘补充，我们已覆盖约 60%的非 SQL 任务数据链路。新增的血缘信息有助于业务更清晰地了解数据加工流程，并实现更精准的数据治理与问题识别。
  • 在数据平台的治理活动中，几乎大多数治理规则都使用了元数据血缘。
