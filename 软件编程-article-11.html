Java 三十周年重磅发声：James Gosling 怒斥 AI 是“一场骗局”，是科技高管“疯狂压榨”程序员的新工具

5/26/2025, 5:35:00 AM

📌 一句话摘要

Java 之父 James Gosling 在 Java 三十周年之际，对 AI 浪潮提出尖锐批评，认为其存在过度炒作。

📝 详细摘要

基于对 Java 之父 James Gosling 的访谈，文章回顾了 Java 语言诞生 30 年来的发展历程和影响力，并重点呈现了他对技术行业及当前 AI 浪潮的深刻见解。Gosling 讲述了自己谦逊的科技旅程，从早期接触计算机到创造 Java，以及在 Sun 被收购后在 Google、Liquid Robotics 和 AWS 的工作经历。他高度评价了 Java 在可靠性、垃圾收集等方面的持续改进，并强调其在企业级系统中的持久生命力。文章最引人注目的部分是 Gosling 对 AI 的批判，认为其名称具有误导性，本质是“高级统计方法”，许多投资将“烧个精光”。他认为 AI 编程助手实用性有限，而科技高管宣称 AI 将淘汰程序员是“自私自利的胡说八道”，旨在压榨员工。最后，他总结了 Java 成功的秘诀在于聚焦实际问题、尊重用户和追求可靠性。

💡 主要观点

  1. Java 的成功源于聚焦实际问题和可靠性，而非追逐潮流。 Java 三十年经久不衰是因为它始终致力于解决工程师的实际需求，强调稳定性和可靠性，尤其在企业级应用中价值突出。
  2. 当前 AI 浪潮存在过度炒作，许多投资将无法回本。 James Gosling 认为 AI 名称有误导性，本质是高级统计方法，警告科技行业充斥骗子和炒作者，许多 AI 投资会失败。
  3. AI 编程助手实用性有限，不能取代开创性软件开发。 虽然第一眼印象深刻，但 AI 助手基于现有代码，难以处理复杂和开创性问题，更有价值的应用在于生成文档等辅助工作。
  4. 科技高管关于 AI 将淘汰程序员的说法是误导和压榨。 驳斥了 AI 会减少软件工程师需求的观点，认为这是一种自私策略，目的是为了让高管能更疯狂地压榨程序员产出。

💬 文章金句

  • 科技行业里骗子和炒作者的数量之多，令人难以置信。
  • 绝大多数 AI 投资都会被烧个精光。
  • 对于 AI 和机器学习，我最难接受的就是它们的名称。
  • 刚开始接触氛围编程，会觉得它特别的酷炫。可一旦项目变得稍微复杂一点，氛围编程就会很快耗尽开发者的脑力。
  • 如果现在我有个小孩，那我绝对会先教他们编程。
  • （AI 技术将减少软件工程师需求）这完全是自私自利的胡说八道。
