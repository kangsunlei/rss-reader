我们在外滩大会，用 5 分钟介绍了 Sive

9/14/2026, 10:00:00 AM

📌 一句话摘要

AntV 团队在外滩大会用 5 分钟介绍了 AI Native 可视化分析创作平台 Sive，目标是把从数据到洞察再到可分享网页报告的全流程收进同一个平台。

📝 详细摘要

本文是 AntV 团队对新产品 Sive 的首次公开介绍。文章从一份四年跨度、近万条交易明细、21 个字段的订单数据切入，指出当前用 AI 分析数据的痛点：AI 能快速读数据、做计算、给结论，但把对话里的文字和截图整理成图表、报告或 PPT 仍需大量手工搬运，原始数据、AI 分析与最终汇报产物分散在多个工具中，流程是断开的。Sive 的定位是 AI Native 可视化分析创作平台，让「从数据，到洞察，再到最终可以汇报的内容」在一个平台内完成。现场演示中，Sive 先读取表结构、字段类型与数据规模，再由数据分析 Agent 拆解任务、调用 Tool 完成查询计算，结论可回溯到数据来源，并支持选中结果后生成可直接预览、发布、分享的网页报告，追问时上下文仍留在同一段对话里。文章还介绍了应用广场收录统计图表、关系网络、3D 图表和地图等可视化内容，以及背后由 Skill、Tool、SubAgent 与主 Agent 组成的架构，并提到可通过 Open API 接入自有 Agent，未来或拓展到 PPT 等产物形式。

💡 主要观点

  1. 现有 AI 数据分析流程是断开的，真正的耗时在分析之后 AI 读数据、做计算、总结结论都很快，但用户还要把对话里的文字和截图复制出来、重新整理图表、放进报告或 PPT 排版并补叙事说明；原始数据、AI 分析和最终汇报产物分散在多个工具中，需要来回切换窗口。
  2. Sive 的定位是把数据、洞察与可汇报内容收进同一平台 Sive 是 AntV 推出的 AI Native 可视化分析创作平台，目标是让从数据到洞察再到最终可汇报内容的流程在一个平台内完成，而不是在多个工具间搬运结果。
  3. 分析过程可追溯，结论能回到数据来源并生成可分享的网页报告 Sive 先读取表结构、字段类型和数据规模，再由数据分析 Agent 拆解任务、由具体 Tool 完成查询和计算，结果整理成简报且每条结论都能回到对应数据来源；选中结果后可生成网页报告，直接预览、发布并获得分享链接，追问时前面的数据和分析过程仍留在同一段对话里。
  4. 可视化表达由应用广场与 AntV 多年积累的能力支撑 应用广场收录统计图表、关系网络、3D 图表和地图等内容，用户可先判断数据要回答什么问题再选择表达方式；背后由 Skill 保存可复用的方法与设计风格，Tool 负责查询计算，不同 SubAgent 分别处理分析、内容组织和作品生成，主 Agent 负责理解问题并串联这些工作。
  5. Sive 支持接入自有 Agent，并计划拓展更多产物形式 用户可在 Sive 申请 API Key，通过 Open API 调用数据分析和可视化能力；团队也在继续探索更多产物形式，未来或拓展到 PPT 等场景。

💬 文章金句

  • 从数据，到洞察，再到最终可以汇报的内容，都应该在一个平台里完成
  • 原始数据、AI 分析和最后用于汇报分享的产物，整个流程是断开的，分散在好几个工具中。
