Vercel AI Gateway 零数据留存功能

4/6/2026, 8:02:03 PM

📌 一句话摘要

Vercel AI Gateway 引入了团队级和请求级的零数据留存 (ZDR) 功能以及提示词训练选择退出机制，旨在统一管理跨多个 AI 提供商的数据合规性。

📝 详细摘要

Vercel 为其 AI Gateway 增强了零数据留存 (ZDR) 功能，旨在简化 OpenAI、Anthropic 和 Google 等不同 AI 提供商之间碎片化数据策略的管理。此次更新为 Pro 和 Enterprise 用户提供了团队级的 ZDR 开关，无需更改代码即可强制执行合规性，同时针对特定敏感任务提供了细粒度的请求级控制。通过将这些控制集成到网关中，Vercel 将数据隐私从手动、逐个请求的配置转变为可扩展的基础设施组件，并配有响应元数据中的审计追踪，以验证路由决策。

💡 主要观点

  1. 跨多个 AI 提供商的集中式 ZDR 执行。 AI Gateway 通过自动将流量路由至支持预协商零数据留存协议的 OpenAI、Anthropic 和 Google 模型，抽象化了各个提供商条款的复杂性。
  2. 无需修改代码的团队级合规性。 Pro 和 Enterprise 团队可以在仪表板中启用全局开关，确保所有外发 AI 请求都遵守严格的数据留存策略，防止开发者意外导致数据泄露。
  3. 针对敏感工作流的细粒度请求级控制。 开发者可以使用 Vercel AI SDK 以编程方式为特定 API 调用启用 ZDR 或选择退出提示词训练，从而根据具体用例实现灵活的数据敏感度处理方法。
  4. 通过响应元数据实现透明的审计追踪。 每个 API 响应都包含路由详情，明确了根据请求的合规性过滤器考虑和过滤了哪些提供商，为安全团队提供了清晰的审计日志。

💬 文章金句

  • 通过将这些规则移至网关，合规性变成了基础设施，而不是应用程序的繁琐工作。
  • AI Gateway 确保仅路由至我们已协商过零数据留存协议的提供商，从而自动满足您的数据要求。
  • 团队级 ZDR……适用于您团队发出的每一个请求，无需更改代码。
  • ZDR 是该控制的超集。如果您启用了 ZDR，则已涵盖了训练选择退出功能。
