WordPress CVE-2026-87902 披露数小时即遭在野利用

9/25/2026, 10:00:00 AM

📌 一句话摘要

WordPress 严重漏洞 CVE-2026-87902（CVSS 9.2）在补丁发布数小时内即遭在野利用，攻击者通过加载本地 PHP 文件实现远程代码执行，建议立即升级至最新版本。

📝 详细摘要

文章报道了 WordPress 高危漏洞 CVE-2026-87902 的快速武器化过程。该漏洞允许未授权攻击者通过操纵页面模板解析逻辑加载任意本地 PHP 文件，进而触发远程代码执行（RCE），但需满足特定主题目录结构和服务器权限前提。安全公司 Previdian 和 Patchstack 监测显示，首次利用尝试发生在补丁发布当天，攻击流量源自美国、印度尼西亚等地 IP，涉及恶意脚本写入及 GitHub 托管的 Web Shell 下载。尽管默认自动更新机制可能限制大规模入侵，但鉴于在野利用活跃，官方强烈建议管理员立即升级至 WordPress 7.1.2 等修复版本并进行站点审计。

💡 主要观点

  1. CVE-2026-87902 具备高危害性但存在利用门槛 该漏洞 CVSS 评分高达 9.2，允许未授权 RCE。但成功利用需同时满足两个条件：当前主题包含以 'page-' 开头的顶级目录，且服务器存在攻击者可读的特定 PHP 文件（如 pearcmd.php）。
  2. 漏洞披露后极短时间内即出现自动化在野利用 Previdian 蜜罐网络监测到自 2026 年 9 月 23 日起已有 68 次利用尝试，首次攻击发生在补丁发布当天（9 月 22 日 UTC 11:49）。攻击模式包括加载本地 PHP 文件向 /tmp 写入恶意内容，并下载 GitHub 上的 Web Shell。
  3. 默认自动更新机制在一定程度上缓解了大规模入侵风险 Previdian CEO Ryan Dewhurst 指出，虽然攻击尝试频繁，但由于 WordPress 默认开启自动更新，真正被成功入侵的站点数量预计相对较少，但这不意味着可以忽视即时修补的重要性。
  4. 官方提供明确的修复版本与审计建议 WordPress 已发布 7.1.2、7.0.6、6.9.9 和 6.8.10 等版本的补丁。安全厂商建议网站管理员尽快升级，并对站点进行全面审计以排查潜在的恶意活动痕迹。

💬 文章金句

  • 未授权攻击者可通过操纵 get_page_template()函数的页面模板解析逻辑，加载当前主题目录外任意可读的本地.php 文件。
  • 尽管这确实是一个严重漏洞，但特定的前置条件提高了利用门槛。WordPress 默认开启自动更新，因此我们预计会看到大规模的利用尝试，但真正被入侵的站点数量会相对较少。
  • 攻击者加载 pearcmd.php 文件，借助该文件向磁盘写入 PHP 恶意文件，这一结论与 Previdian 的监测结果相互印证。
