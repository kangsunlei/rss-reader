Spring 新闻综述：Spring Vault 里程碑版本，点版本发布 和 OSS 支持结束

6/23/2025, 12:00:00 AM

📌 一句话摘要

近期 Spring 项目 点版本发布、Spring Vault 4.0.0-M1 里程碑版本以及即将到来的 OSS 支持结束日期的总结。

📝 详细摘要

本文综述了 Spring 生态系统在 2025 年 6 月 16 日 这一周内的重要活动。文章详细介绍了多个 Spring 项目的 点版本发布，包括 Spring Boot、Spring Security、Spring Authorization Server 以及各种集成项目（AMQP、Kafka、Pulsar、Web Services），重点列举了每个版本中的关键 bug 修复、依赖升级 和 细微的新功能。文章还宣布了 Spring Vault 4.0 的首个里程碑版本发布，并指出其与 Spring Framework 7.0 的对齐以及对 JSpecify 的支持。至关重要的是，文章列出了多个 Spring 项目 版本系列，包括 Spring Boot 3.3 和 Spring Framework 6.1，它们将于 2025 年 6 月 30 日 达到 OSS 支持结束日期，而企业支持将在一年后结束。

💡 主要观点

  1. 多个 Spring 项目发布了包含 bug 修复 和 依赖升级的 点版本。 许多 Spring 核心项目，如 Spring Boot、Security 等，发布了维护版本，解决了问题 并 更新了依赖，提高了稳定性和兼容性。
  2. Spring Vault 4.0.0-M1 已发布，与 Spring Framework 7.0 对齐 并 增加了功能。 Spring Vault 4.0 的首个里程碑版本引入了与即将发布的 Spring Framework 7 的兼容性，并支持 JSpecify 以改进 空安全，同时提高了客户端配置的灵活性。
  3. 多个主要的 Spring 项目 版本将于 2025 年 6 月 30 日 面临 OSS 支持结束。 Spring Boot 3.3 和 Spring Framework 6.1 等关键 版本系列 在此日期之后将不再获得公开 bug 修复 或 安全更新，用户需要升级到支持版本 或 购买商业支持 以维持应用稳定性和安全性。

💬 文章金句

  • 在 2025 年 6 月 16 日 这一周内，Spring 生态系统活动频繁，重点包括：Spring Vault 4.0 的首个里程碑版本发布；以及 Spring Boot、Spring Security、Spring Authorization Server、Spring Session、Spring Integration、Spring Modulith、Spring REST Docs、Spring AMQP、Spring for Apache Kafka、Spring for Apache Pulsar 和 Spring Web Services 的 点版本发布。
  • 许多 Spring 项目的 版本系列 也将于 2025 年 6 月 30 日 达到 OSS 支持结束。
  • Spring Boot 的 3.5.1、3.4.7 和 3.3.13 版本... 都提供了 bug 修复、文档改进 和 依赖升级。
  • Spring Vault 4.0.0 的首个里程碑版本发布特色包括：与 Spring Framework 7.0 的对齐；引入对 JSpecify 的支持，以改进 空安全；以及一个新的 ClientConfiguration 类...
  • 所有这些项目的企业支持将于 2026 年 6 月 30 日 生命周期结束。
