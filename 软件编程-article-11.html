📌 一句话摘要

dompdf.js 的 V1.1.0 版本新增分页功能，让前端能够高效、精准且可定制地生成多页可编辑 PDF，解决原有单页限制和常见痛点。

📝 详细摘要

文章详细介绍了前端 PDF 生成库 dompdf.js V1.1.0 版本的重要更新，核心是新增了多页 PDF 生成功能。该库允许前端将 HTML 页面生成非图片式、可编辑、小体积的 PDF 文件，解决了传统方法生成 PDF 清晰度低、不可搜索、体积大、分页不准等问题。新版本支持精确的分页控制（包括图片、左右布局、文本和复杂表格的分页），可自定义页眉页脚，并提供了 PDF 密码、权限设置及压缩功能。文章还深入剖析了分页的实现原理，通过 DOM 解析、边界判断重计算以及 jsPDF 的 API 调用，实现了内容在不同页面间的智能分割和渲染。最后提供了详细的使用文档，包括安装、基础用法、分页渲染、字体导入解决乱码、以及利用 foreignObjectRendering 处理复杂样式等，展示了该库在前端 PDF 生成领域的强大能力。

💡 主要观点

  1. dompdf.js V1.1.0 版本核心新增了多页 PDF 生成功能 解决了之前版本只能生成单页 PDF 的限制，现在能够高效生成数千页 PDF，满足了开发者处理大量内容的文档输出需求。
  2. 该库生成的 PDF 具有非图片式、可编辑、体积小等优势 与传统的基于图片生成的 PDF 不同，dompdf.js 生成的 PDF 内容可搜索、可编辑，且文件体积更小，提升了用户体验和文档实用性。
  3. 提供了精准的分页控制和丰富的定制选项 支持图片、文本、复杂表格等内容的精确分页，并允许自定义页眉页脚、设置 PDF 密码、操作权限和压缩，大幅提升了 PDF 生成的灵活性与专业度。
  4. 详细揭示了分页功能的底层实现原理 通过解析 HTML 为 DOM 树、递归判断元素边界进行分页、重计算元素位置并结合 jsPDF 进行渲染，解释了如何将复杂 HTML 内容有效转换为多页 PDF 的机制。
