分享一个小工具，把不同 Coding Agent 的对话记录实时同步到网上，方便自己浏览和分享给同事

6/14/2026, 5:07:23 AM

📌 一句话摘要

作者分享了一个自建的开源工具 Jieli，通过 Hook 机制将不同 Coding Agent 的对话记录实时同步到网页，方便浏览、切换和分享。

📝 详细摘要

作者在尝试 Claude Code、Codex、Opencode、Amp 等多种 Coding Agent 后，为解决「不同工具间对话记录分散、难以追溯」的问题，基于 Amp 的启发，开发了一个名为 Jieli（接力）的网站。该工具利用 Agent 提供的 Hook 机制，将对话实时同步到网页，并为每个会话生成独立链接，支持在不同 Agent 间无缝切换。插件还具备脱敏功能、读取对话的 Skill（通过 API-KEY 认证），以及复刻自 Amp 的 `handoff` Skill。此外，插件会在 Git 提交信息后附上会话链接，方便 Code Review 或 Debug 时回溯上下文。插件已开源，支持 Codex 和 Claude Code，安装简单。

💡 主要观点

  1. Jieli 通过 Hook 机制实时同步多个 Coding Agent 的对话记录。 用户可在不同 Agent（如 Claude Code、Codex）间切换时，通过网页统一查看和管理所有对话历史，避免信息分散。
  2. 插件提供脱敏、会话链接生成和 Git 提交信息关联功能。 脱敏保护敏感信息；每个会话生成独立链接便于分享；Git 提交信息后附链接，方便 Code Review 时回溯上下文。
  3. Jieli 复刻了 Amp 的 `handoff` Skill，并开源了插件。 `handoff` 功能允许在不同 Agent 间传递上下文，提升工作流连续性；插件开源（支持 Codex 和 Claude Code），安装仅需两行命令。

💬 文章金句

  • 插件主要负责脱敏和对话同步，同时自带了读取对话的 skill (通过 API-KEY 认证）， 还有一个类似 Amp 的 `handoff` 的 skill
  • 另外插件还会在 git 提交信息后面附上会话链接， 方便 code review 或者 debug 时，通过提交信息就可以知道上下文。
