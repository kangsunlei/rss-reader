GitHub Copilot 集成 Claude 与 OpenAI Codex 智能体

2/4/2026, 5:01:15 PM

📌 一句话摘要

GitHub Copilot Pro+ 和 Enterprise 用户现在可以利用 Claude 和 OpenAI Codex 智能体，在工作流中自动处理积压任务和瓶颈问题。

📝 详细摘要

GitHub 宣布对其 AI 驱动的开发者平台进行重大更新。GitHub Copilot Pro+ 和 Copilot Enterprise 的订阅者现在可以选择特定的 AI 智能体（包括 Anthropic 的 Claude 和 OpenAI 的 Codex）来处理开发任务。该功能允许开发者定义意图，让专业智能体直接在 GitHub 和 VS Code 中清理积压工作并解决瓶颈，标志着软件开发向多模型智能体工作流（agentic workflows）的转变。
