Cloudforce One 威胁事件平台：提升威胁情报分析的上下文关联性

3/18/2025, 1:00:00 PM

📌 一句话摘要

Cloudflare 发布 Cloudforce One 威胁事件平台，利用其网络流量为客户提供实时威胁情报，增强安全防御能力。

📝 详细摘要

Cloudflare 推出 Cloudforce One 威胁事件平台，旨在解决网络安全防御者在分析威胁情报时面临的挑战。该平台利用 Cloudflare 网络优势，提供差异化的威胁情报，通过监控和缓解威胁来获取上下文数据，为安全专业人员和决策者提供全球视角的实用见解，例如 IOCs 和攻击者画像等。通过 Cloudflare 每天处理的数百万 HTTP 请求和 DNS 查询，该平台能够提供全面、实时的互联网威胁活动视图。用户可以通过 Cloudflare 控制面板中的安全中心或 Cloudforce One 威胁事件 API 访问，通过自定义过滤器探索事件，识别模式并有效响应。Cloudforce One 威胁情报分析师可以提供额外的上下文信息进行后续调查。该平台使用 Cloudflare Workers 和 SQLite-backed Durable Objects 构建，以实现可扩展性和灵活性。

💡 主要观点

  1. Cloudflare 威胁事件平台提供实时的威胁情报。 该平台利用 Cloudflare 网络流量数据，为客户提供实时网络攻击情报，帮助他们更好地防御。
  2. 该平台集成了 MITRE ATT&CK 框架和网络杀伤链。 通过将威胁事件映射到 MITRE ATT&CK 框架和网络杀伤链，该平台帮助用户更好地理解攻击者的行为和策略。
  3. Cloudflare 威胁事件平台使用 Cloudflare Workers 构建。 该平台使用 Cloudflare Workers 和 SQLite-backed Durable Objects 构建，以实现可扩展性和灵活性。
  4. 该平台允许用户通过自定义过滤器识别特定威胁，实现主动防御。 Cloudforce One 客户可以通过 Cloudflare 控制面板或 API 使用自定义过滤器，主动识别和响应针对其组织的特定威胁。
