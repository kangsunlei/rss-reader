只有 4B，一个令人惊艳的国产 Agent 神器，开源了！

9/4/2026, 9:05:00 AM

📌 一句话摘要

科大讯飞全资子公司词元星火开源了 Spark-X2.5-1.7B 和 Spark-X2.5-4B 两款端侧模型，它们将 Agent 能力压缩到小模型尺寸，支持 100 万 Token 上下文，并在多项评测中表现出超越同尺寸模型的性能，尤其在 Agent 任务方面断层领先。

📝 详细摘要

过去，Agent 调用工具需要上百亿参数的大模型。现在，Spark-X2.5-1.7B 和 Spark-X2.5-4B 改变了这一现状，将 Agent 能力装进小模型。这些模型支持 100 万 Token 上下文，可在本地笔记本电脑上运行，并展现出强大的翻译、代码理解和架构图生成能力。它们代表了端侧 AI 的新阶段，有望在数据敏感行业中广泛应用。

💡 主要观点

  1. 小模型也能拥有 Agent 能力 Spark-X2.5-1.7B 和 Spark-X2.5-4B 证明了，即使只有几百亿参数，模型也能具备调用工具、理解复杂指令和执行多步任务的能力，打破了对大模型的依赖。
  2. 超长上下文支持 模型原生支持 100 万 Token 的上下文，这意味着可以一次性读取大量代码或文档，而不会丢失关键信息，这对于分析大型项目非常有用。
  3. 本地部署的便利性 这些模型可以轻松部署在个人笔记本电脑上，使用 llama.cpp 等框架运行。这不仅降低了使用门槛，还解决了数据隐私问题，因为所有计算都在本地进行。
  4. 多场景应用潜力 从翻译、代码理解到架构图生成，Spark-X2.5 展示了广泛的适用性。特别是在医疗、法务等数据敏感行业，本地运行的 Agent 模型将有巨大的应用前景。
