Spring Data MongoDB：支持向量搜索与可查询加密

6/23/2025, 4:18:51 PM

📌 一句话摘要

Spring Data MongoDB 4.5.0 引入向量搜索、索引创建和可查询加密等重要新功能。

📝 详细摘要

Spring Data MongoDB 4.5.0 版本增强了与 MongoDB 的集成，主要体现在对向量搜索、向量搜索索引创建和可查询加密等关键现代功能的支持。向量搜索允许存储和查询向量嵌入以及其他数据，从而在无需外部数据库或 ETL（提取、转换、加载）的情况下实现 AI 应用。此更新提供了直观的原生 Spring Data API（应用程序编程接口，如 `VectorIndex` 类），可轻松创建向量搜索索引并利用 `$vectorSearch` 聚合阶段。此外，该版本还集成了 MongoDB 可查询加密，使开发人员能够加密敏感数据，并直接在加密数据上通过 `CollectionOptions` 执行相等/范围查询，从而增强静态和使用中的数据安全性。这些功能使 Java 开发人员能够使用 Spring Data MongoDB 构建更复杂、安全的应用程序。

💡 主要观点

  1. Spring Data MongoDB 4.5.0 增加了对 MongoDB 向量搜索的原生支持。 开发人员现在可以使用熟悉的 Spring Data 约定轻松地将向量搜索功能集成到 Java 应用程序中，从而避免了复杂的手动实现。
  2. 新的 API 简化了在 MongoDB 中创建向量搜索索引的过程。 `VectorIndex` 类在 Spring Data 中提供了一个易用的 API，可以直接从应用程序代码中定义和创建向量搜索索引。
  3. 现在可以使用与 MongoDB 可查询加密的集成。 应用程序可以利用 MongoDB 的客户端加密功能对敏感数据执行查询，同时保持加密状态，从而提高安全性。

💬 文章金句

  • MongoDB 很高兴地宣布 Spring Data MongoDB 4.5.0 版本发布，带来了多项增强功能，包括向量搜索、向量搜索索引创建和可查询加密。
  • 通过使用 `$vectorSearch` 阶段预过滤数据，并对索引字段执行语义搜索，可以在聚合管道中轻松处理向量嵌入。
  • 现在，您可以将 `encryptedFields` 直接传递给 `CollectionsOptions` 类，以便 Spring 识别已加密的字段。
  • QE 允许您加密敏感的应用程序数据，将其安全地以加密状态存储在 MongoDB 数据库中，并直接对加密数据执行相等和范围查询。
