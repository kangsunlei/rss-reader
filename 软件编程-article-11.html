📝 详细摘要

本文围绕长期记忆的写入与加载流程，涵盖 LLM 判断、语义检索、Token 预算控制、冲突处理等关键技术。文章首先介绍了 MultiAgent 平台的背景和整体架构概览，然后深入讨论了四层记忆模型、短期历史的读取与写入、MemOS 的按 scope 检索，以及会话结束后的异步沉淀。最后，文章总结了核心设计与运行观测，包括并行加载、新增消息标记、预算控制和可靠写入等策略。

💡 主要观点

  1. 四层记忆模型 包括 Working Memory、Session Memory、User Memory 和 Agent Memory，分别对应不同的生命周期。
  2. 短期记忆加载 实现重点是读取时延、Redis/MySQL 回退以及 Token 窗口控制。
  3. 长期记忆加载 包括并行加载设计、语义检索实现和 Token Budget 分配策略。
