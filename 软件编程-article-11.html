“Anthropic 不再是 AI 圈的信仰”

8/20/2026, 8:26:00 AM

📌 一句话摘要

本文结合 TickerTrends 与 SemiAnalysis 数据，揭示 Anthropic 虽在 AI 编码工具 ARR 规模上仍领先 OpenAI Codex，但增速显著放缓、高依赖云厂商渠道导致利润率承压，且用户体感与企业版定价逻辑引发开发者流失。

📝 详细摘要

文章深度剖析 Anthropic 旗下 Claude Code 与 OpenAI Codex 的竞争态势。数据显示，Claude Code ARR 达 151.2 亿美元，仍是 Codex（88.3 亿美元）的 1.7 倍，但近月 Codex 增幅超 50%，远高于 Claude Code 的 6%，市场份额正加速向后者倾斜。核心原因在于：开发者体感上 Codex 更听指令、推理更清晰，而 Claude Code 出现“AI 腔”严重、拒绝执行等退化现象。 营收结构层面，Anthropic 近 40% ARR 来自 AWS Bedrock 等间接渠道，虽加速了企业分销，但云厂商分成与算力成本大幅压缩模型公司利润率，导致 ARR 增长与利润增长严重背离。企业版订阅按 Token 计费且含上下文重复计费机制，单位成本远高于个人固定套餐，引发企业用户强烈不满。 Gary Marcus 等观察者认为，受中国模型冲击、价格战及堆 Token 模式走到尽头影响，Anthropic 营收增速拐点已现。文章通过多源数据交叉验证，系统梳理了 AI 模型公司在商业化、渠道博弈与产品体验三重困境中的真实处境。

💡 主要观点

  1. Codex 增速显著超越 Claude Code，开发者正用脚投票迁移。 TickerTrends 数据显示，近 5 周 Codex ARR 增幅超 50%（月环比 20.8%），而 Claude Code 仅 6%（月环比 5.2%），ARR 差距从 83.8 亿缩至 63 亿美元。开发者反馈 Codex 更遵循指令、推理更连贯，Claude Code 则出现语无伦次、过度道歉等体验退化。
  2. Anthropic 高 ARR 掩盖利润率隐忧，间接渠道占比超 40% 导致收入结构不健康。 SemiAnalysis 数据显示，Bedrock 等云渠道贡献超 40% ARR。云厂商抽成约 4 成，Anthropic 还需承担算力成本，导致间接渠道 100 美元 ARR 利润远低于直销。渠道占比越高，营收增长与利润增长背离越严重，且议价权向云厂倾斜。
  3. 企业版订阅定价逻辑与 Token 计费机制导致单位成本极高，引发企业用户不满。 企业版按 API 调用量计费，上下文历史重复计费使有效成本放大 10-20 倍；个人版固定套餐覆盖重度使用。同一模型下，企业版额度耗尽速度远快于个人版，本质是采购管控逻辑与产品定价逻辑的错位，被指‘企业版给全业务输血’。
  4. 模型能力感知倒挂与价格策略加速用户流失，中国模型成潜在替代项。 用户吐槽 Opus 4.8 等高性能模型被锁定在更贵的 Fable 5.0 等高阶套餐，基础版体验被故意压制。配合 Token 消耗激增、任务耗时变长，部分开发者已转向研究国产模型替代方案。

💬 文章金句

  • 做 Anthropic 的用户，就像身处一段有毒的关系中。体验时好时坏，但日子久了，攒下来的只有满心怨气。
  • 通过 Bedrock 产生的 100 美元 ARR，与 Anthropic 直接面向客户销售产生的 100 美元 ARR，经济价值并不完全相同。前者有利于扩大收入规模，却可能因为 AWS 分成而贡献较低的利润。
  • 渠道占比越高，营收增长和利润增长就越不能直接画等号。如果只看 ARR 的话，可能会高估这些收入对 Anthropic 最终利润的贡献。
