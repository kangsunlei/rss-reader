FunProxy - 使用 Rust 构建跨平台全链路测试抓包代理工具

5/7/2025, 12:01:00 PM

📌 一句话摘要

介绍 vivo 使用 Rust 开发的创新性跨平台全链路测试抓包代理工具 FunProxy，解决多系统环境配置复杂的问题

📝 详细摘要

文章详细介绍了 vivo 开发的 FunProxy 工具，这是一个基于 Rust 语言和 Tauri 框架构建的创新性跨平台全链路测试抓包代理工具。文章首先分析了全链路测试的现状和痛点，包括系统数量众多、环境配置不一致等问题。FunProxy 的设计目标包括跨平台支持(Windows/macOS/Linux/Android/iOS)、高性能、易于扩展和安全性高。工具提供了多项创新功能：全功能抓包能力支持多种协议、云端 hosts 和规则管理(不修改系统 hosts)、协同抓包实时共享数据等，显著简化了全链路测试的配置流程。文章深入讲解了核心技术实现，包括 MITM(中间人)方案、虚拟 hosts、自动安装证书、创新的跨平台流量拦截方案等。最后分享了未来规划和工作流功能展望，体现了工具'让全链路抓包和环境代理如丝绸般丝滑'的愿景。

💡 主要观点

  1. Rust+Tauri 实现跨平台高性能代理工具 选择 Rust 语言保证了工具的性能和安全性，Tauri 框架实现了跨平台能力，使工具能在 Windows/macOS/Linux/Android/iOS 等平台运行
  2. 创新的云端 hosts 和规则管理解决环境配置问题 通过云端共享 hosts 和规则配置且不修改系统 hosts，解决了全链路测试中各系统环境配置不一致的痛点，提高了团队协作效率
  3. 创新的协同抓包功能提升团队效率 通过 WebSocket 实现抓包数据实时共享，团队成员可以同步查看和分析抓包结果，极大提升了协作效率
  4. 全面的 MITM 方案支持多种协议 实现了完整的中间人代理方案，支持 HTTP/HTTPS/WebSocket 等多种协议，提供重写、断点、数据对比等丰富功能
  5. 创新的跨平台流量拦截方案 针对不同平台采用最优拦截方案，PC 端直接调用系统 API，移动端通过 VPN 服务实现，确保各平台都能有效拦截流量

💬 文章金句

  • 全链路测试就是'验证整个软件系统在不同组件、服务和模块之间协同工作时的性能、功能和稳定性'
  • 让 vivo 的全链路抓包和环境代理，如丝绸般丝滑
  • Rust 是系统级别的通用编程语言，上至 web 下至 OS 统统能轻松驾驭，并且能够保证内存安全和并发安全
  • FunProxy 所有的 hosts 都是虚拟 hosts，并不会修改系统 hosts，保证系统 hosts 的干净
  • 动态函数解析让 FunProxy 几乎能解所有的密文，这样我们在查看接口的时候就非常的方便
  • 通过 FunProxy，我们只需要简单的通过选择，比如选择项目，选择环境，选择规则，就能将全链路测试过程中复杂的配置流程，变得异常的简单
