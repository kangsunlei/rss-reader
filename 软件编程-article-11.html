Docker 发布强化基础镜像

6/21/2025, 12:00:00 AM

📌 一句话摘要

Docker 发布强化镜像 (DHI)，这是一类最小且安全的基础镜像，能够将容器漏洞足迹减少高达 95 %。

📝 详细摘要

Docker 推出了 Docker 强化镜像 (DHI)，这是一套新的最小基础镜像，专为生产环境使用而设计，并采用无发行版方法构建。通过移除 shell 和包管理器等不必要的组件，这些镜像显著减小了攻击面，与传统镜像相比，已知漏洞减少高达 95 %。DHI 包括针对严重漏洞的自动化补丁，并带有 SLA 保障，同时提供签名的 SBOM 和出处元数据，以增强软件供应链安全。它们被设计为与现有 Dockerfile 兼容的直接替换品，并提供一个定制层。与 Microsoft 和 GitLab 等合作伙伴的早期集成确保了与 CI/CD 工具的兼容性。初始目录涵盖 Python、Go 和 Java 等运行时，可根据订阅级别通过 Docker Hub 获取。

💡 主要观点

  1. 强化镜像大幅减少容器漏洞足迹。 通过采用无发行版方法并移除不必要的组件，DHI 与标准镜像相比，可将漏洞数量减少高达 95 %。
  2. 自动化补丁和 SBOM 提高了安全性和合规性。 DHI 包括持续的安全更新，针对严重问题提供 SLA 保障，并提供签名的 SBOM 以满足透明度和合规需求。
  3. 镜像设计易于集成到现有工作流中。 DHI 设计为带有定制层的直接替换品，与标准 Dockerfile 兼容，并通过合作关系集成了主要的 CI/CD 和安全工具。

💬 文章金句

  • Docker 强化镜像 (DHI) 是一组精选的最小镜像，使用无发行版方法从源代码构建。
  • 据 Docker 称，强化镜像与传统基础镜像相比，将漏洞足迹减少了高达 95 %。
  • 严重和高危漏洞将在七天内获得补丁，并有明确的服务级别协议保障。
  • DHI 镜像还包括签名的软件物料清单 (SBOM) 和出处元数据，以支持提高透明度和供应链可见性。
  • 在内部测试中，Docker 报告称，将标准 Node.js 镜像替换为强化变体后，已安装软件包数量减少了 98 %，并消除了已知的 CVE。
