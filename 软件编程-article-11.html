Google 推出 Agent 异常检测系统，可检测工具误用、执行循环与越界行为

9/18/2026, 10:00:00 AM

📌 一句话摘要

Google 推出基于推理的 Agent 异常检测审计层，通过多层分析架构覆盖 OWASP Agentic Top 10 风险，实现对自主 Agent 运行行为的实时监控与预警。

📝 详细摘要

Google 近期推出了一套面向 Gemini Enterprise Agent 平台的异常检测审计层，旨在解决自主 Agent 在运行中可能出现的工具误用、权限滥用、级联故障及失控行为。该系统通过 ADK 捕获遥测数据，采用分层分析策略：第一层进行轻量级统计异常扫描，第二层利用 LLM 进行深度推理分析，必要时启动第三层调用级核查。系统不仅覆盖了 OWASP Agentic Top 10 的核心风险，还支持用户通过自然语言定义业务逻辑规则。该检测过程在异步环境中运行，不影响请求延迟，并能通过 API 或回调机制实现自动化阻断与处置，为企业级 AI 应用提供了更精细的安全治理手段。

💡 主要观点

  1. 分层分析架构平衡检测效能 系统采用轻量扫描（统计异常）、LLM 推理（深度分析）与调用级分析（单次执行核查）三层架构，在保证检测深度的同时，通过异步执行避免了对业务请求延迟的影响。
  2. 覆盖 OWASP Agentic Top 10 核心风险 内置规则重点针对工具误用、身份与权限滥用、Agent 级联故障（如无限循环）及失控 Agent（偏离指令）等关键威胁进行监控。
  3. 支持自定义业务异常规则 用户可利用自然语言编写灵活的检测规则，并结合历史流量数据验证准确率，从而将通用的安全防护扩展至特定的业务合规场景。
  4. 集成化安全处置流程 告警信息可推送至 Security Command Center，应用端亦可通过 API 或 ADK 回调获取告警，实现基于置信度阈值的自动阻断或对话中止。

💬 文章金句

  • Agent 异常检测系统会评估 Agent 生成的追踪数据，判断其运行是否超出预设边界，标记行为异常、可疑意图与策略违规行为。
  • 为平衡检测速度、成本与覆盖范围，系统会分层分析追踪数据与日志。
  • 检测过程在实时执行路径外异步运行，不会增加被分析请求的延迟。
