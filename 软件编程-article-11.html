Cloudflare 发布公开测试版 Containers

7/8/2025, 7:16:00 AM

📌 一句话摘要

Cloudflare 发布 Containers 公开测试版，允许用户在全球边缘网络上部署 Docker 容器，以支持 Workers 难以处理的复杂工作负载。

📝 详细摘要

文章宣布 Cloudflare 的 Containers 服务进入公开测试版，该服务允许开发者在全球边缘网络上部署 Docker 容器。Containers 旨在解决 Serverless Workers 平台难以支持的资源密集型、需要完整文件系统或特定运行时环境的工作负载，例如在边缘进行媒体处理和复杂数据分析。该服务与 Cloudflare 的 Workers 平台深度集成，并建立在 Durable Objects 这一用于有状态应用和分布式系统的构建块之上，从而提供了对容器生命周期的细粒度控制。文章详细阐述了 Containers 如何支持运行任何语言的用户生成代码、执行完整的 Linux 环境下的 CLI 工具，以及在无需重大重写的情况下从其他提供商移植现有应用程序。此外，文中还引用了 Cloudflare 产品经理和软件工程师的解释，探讨了 Containers 作为 API 网关、服务网格或编排器的潜在使用场景。目前，Containers 已向所有付费计划的开发者开放测试版，并包含一个免费层，但公开测试版仍存在一些功能限制，例如全球自动扩展和延迟感知路由功能尚未完全可用，未来将增加更多 Workers 与容器之间的通信方式。

💡 主要观点

  1. Containers 解决 Workers 局限性，支持复杂边缘工作负载 Containers 允许在 Cloudflare 边缘网络部署 Docker 容器，弥补了 Workers 在资源密集型、特定运行时或完整文件系统需求上的不足，适用于媒体处理等场景。
  2. 与 Cloudflare 现有服务深度集成，实现精细控制 Containers 与 Workers 和 Durable Objects 紧密结合，Workers 可作为可编程的 Sidecar，代理请求并管理容器生命周期，实现灵活的路由和调度。
  3. 提供灵活的容器部署和计费模式 服务支持运行任何语言的用户代码，移植现有应用，并提供多种实例大小和按活跃运行时间计费的模式，降低了边缘容器部署的门槛。

💬 文章金句

  • 该服务允许用户部署 Docker 容器以运行在 Serverless 计算平台 Workers 上难以支持的工作负载，例如在边缘进行媒体和数据处理。
  • Durable Objects 不仅允许对容器生命周期进行细粒度控制，整个 Workers 平台还允许根据需要扩展路由和调度行为。
  • 将我们熟悉的 Docker 容器世界与 Cloudflare 对'简单、全球和可编程'计算的愿景结合起来的想法，开启了各种新的可能性（...）我很高兴看到这项技术将重塑我们对 serverless 架构的思考。
