Viking AI 搜索 CLI 正式发布：会说话，就能做搜索推荐

5/28/2026, 9:00:00 AM

📌 一句话摘要

字节跳动发布 Viking AI 搜索 CLI，通过 IaC 范式让 Agent 自动完成数据入库、策略配置和效果调优，实现「会说话就能做搜索推荐」的零代码智能搜索搭建体验。

📝 详细摘要

本文介绍了字节跳动 Viking 团队正式发布的 AI 搜索 CLI 工具（SearchCLI）。该工具基于 Infrastructure as Code 范式，将传统搜索推荐系统搭建中涉及的数据清洗、Embedding 选型、索引构建、策略配置、效果调优等复杂环节，整合为一组简洁命令。用户只需通过 AI Agent（如 Trae、Claude Code 等）以对话方式发出指令，即可自动完成从数据导入、搜索推荐问答策略配置到效果评测与自动化调优的全流程。文章以独立设计师小 V 管理上万条 AI 生成素材的案例，详细演示了 SearchCLI 的安装授权、智能数据预处理与导入、多模态搜索配置、个性化推荐与相似推荐、智能问答助手搭建，以及自动化效果评测与策略调优的完整闭环。最终，用户无需编写任何代码，即可将本地素材库打造成支持搜索、推荐、问答一体化的智能图库。文章还介绍了该工具在电商平台、社交内容平台、企业知识库等场景的泛化能力。

💡 主要观点

  1. SearchCLI 通过 IaC 范式将搜索推荐系统搭建流程命令化，Agent 可自动完成全流程。 传统搜索推荐系统涉及数据清洗、Embedding 选型、索引构建、策略配置等复杂环节，SearchCLI 将其整合为简洁命令，Agent 通过对话即可自动执行，大幅降低技术门槛。
  2. 工具提供数据入库、搜推问一体化配置和 AI 驱动的策略调优三大核心能力。 数据入库支持智能预处理和批量导入；搜索、推荐、问答能力一键拉起；效果评测可自动发现问题并生成优化建议，Agent 可完成策略热更新。
  3. 零代码搭建智能搜索推荐系统，面向非技术用户和开发者。 独立设计师等非技术用户无需编写代码，通过自然语言指令即可管理海量素材，实现多模态搜索、个性化推荐和智能问答。
