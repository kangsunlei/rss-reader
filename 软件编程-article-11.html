AI 专栏 | 别再手动造数据了！LLM 与 CTGAN 组合拳破解测试数据难题

7/23/2026, 9:00:00 AM

📌 一句话摘要

本文提出 CTGAN 与 LLM 结合的测试数据生成方案，让 CTGAN 负责数据丰富度，LLM 负责字段间关联，实验验证覆盖率近 100%且逻辑一致。

📝 详细摘要

文章首先指出测试人员约 44%的时间花在数据构造上，现有合成数据方案要么丰富度高但不学字段逻辑（如 CTGAN），要么语义强但输出不可控低效（如 LLM）。接着对高斯、TVAE、CTGAN 和 LLM 四种模型进行对比分析，发现 CTGAN 在枚举字段覆盖率上达 100%，而 LLM 能够捕捉字段间的隐式关联关系。基于此，作者提出一种工程化的 LLM-CTGAN 组合方案，分为关联关系识别、数据生成、指标监控和数据修复四个模块：利用 LLM 识别存在关联的字段组，CTGAN 负责无关联字段的丰富度生成，LLM 负责关联字段的生成；通过分批训练和模型参数缓存提升 CTGAN 效率，通过分类+评分抽样压缩训练集缓解 LLM 上下文限制；引入判别器得分和规则有效性进行质量监控，最后对不足进行修复。实验在六张库表上表明，该方案兼具 CTGAN 的枚举字段覆盖率（接近 100%）和 LLM 的字段间关系提升，显著降低了人工造数据的成本。

💡 主要观点

  1. CTGAN 负责数据丰富度，LLM 负责字段间关联 CTGAN 通过条件生成对抗网络能够保持枚举字段的完整覆盖率；LLM 凭借语义理解能力可学习隐式的计算与映射关系，二者互补提升合成数据质量。
  2. 四模块方案：关联关系识别、数据生成、指标监控、数据修复 先用 LLM 识别存在关联的字段组，再分别用 CTGAN 和 LLM 生成独立与关联字段数据，随后通过判别器得分和规则有效性监控质量，最后对不足进行修复。
  3. 分批训练与数据压缩提升生成效率 CTGAN 采用批次递增训练降低内存消耗，使用保存的模型参数使单条生成时间降至 0.16s；LLM 通过分类+评分抽样压缩训练集，保持丰富度同时缩短上下文。
  4. 实验验证表明枚举字段覆盖率接近 100%，字段间关系显著提升 在六张库表上的对比实验中，CTGAN 实现枚举字段覆盖率 100%，LLM-CTGAN 合成数据在字段间关系指标上优于单模型，验证了方案有效性。
  5. 工程化方案可直接落地测试场景，降低人工数据构造成本 通过自动化管道实现端到端数据生成、监控与修复，测试人员可定时获取高质量合成数据，减少手动造数据的时间投入。

💬 文章金句

  • 测试人员 44%的时间耗在数据构造上------合成数据本是"解药"，但市面方案总缺一角：CTGAN 丰富度高却学不会字段逻辑，LLM 语义强但输出不可控且低效。
  • LLM 能够在数据生成时获取字段间存在的隐式关联关系，使得生成的数据更具备可用性。
