📌 一句话摘要

阿里巴巴开源 AI 代码审查工具 Open Code Review 登顶 GitHub Trending 周榜，其核心在于采用“确定性工程 + LLM Agent”的混合架构以解决 AI Review 的幻觉与成本问题。

📝 详细摘要

本文报道了阿里巴巴开源项目 Open Code Review 在 GitHub 上获得极高关注（Star 数突破 40，000）的情况。该工具通过将文件筛选、规则匹配等确定性环节由工程逻辑固化，仅将语义理解任务交给 Agent，有效解决了 AI 代码评审中常见的覆盖率不足、行号定位幻觉及 Token 成本失控等痛点。项目作者李峥峰将在 QCon 上海站分享其在百万真实任务验证下的工程实践，探讨如何将通用 Agent 收敛为垂直领域 Agent，并建立 AI 深度参与研发后的新评估体系。

💡 主要观点

  1. 采用“确定性工程 + LLM Agent”的混合架构 将不能出错的环节（如文件筛选、规则匹配、行号定位）交给工程逻辑，将深度语义审查交给 Agent，以消除幻觉并降低成本。
  2. 解决 AI Code Review 的三大核心痛点 通过上述架构设计，直接应对当前 AI 评审中覆盖率不足、行号定位不准（幻觉）以及 Token 消耗过高的问题。
  3. 基于大规模生产环境的验证 该工具在阿里内部经过两年验证，服务 2 万多名开发者，识别了数百万个真实代码缺陷，具备极强的实战参考价值。
  4. 推动 AI Review 向质量基础设施演进 探讨通过分治并发、上下文分层管理等工程实践，建立新的评估体系，使 AI 从简单的辅助工具转变为研发流程中的基础设施。

💬 文章金句

  • 确定性工程 + LLM Agent 混合架构：把文件筛选、规则匹配、行号定位这些 "不能出错" 的环节从大模型手中收回，用工程逻辑固化；只把需要语义理解的深度审查任务交给 Agent。
  • 让确定性的工作交给工程系统，让需要语义理解的任务交给大模型，实现更高的稳定性、更低的成本和更好的评审质量。
