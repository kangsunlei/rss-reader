Web 分析降价高达 80% - Vercel

5/8/2025, 1:00:00 PM

📌 一句话摘要

Vercel 宣布 Web 分析事件和 Plus 附加组件降价高达 80%，同时提升了免费套餐的事件数量上限。

📝 详细摘要

Vercel 宣布大幅降低 Web 分析的价格。Web 分析事件现在按每次事件 0.00003 美元（每 10 万次 3 美元）计费，价格降低 79%。Plus 附加组件的价格也降低了 80%，降至每月 10 美元。Web 分析 Plus 是一个可选的附加组件，可解锁更长的保留期和 UTM 参数，使小型企业和个人开发者受益。此外，免费套餐的事件数量上限已增加，Hobby 套餐从 2，500 增加到 50，000 事件/月，Pro 套餐从 25，000 增加到 100，000 事件/月。

💡 主要观点

  1. Vercel 大幅降低 Web 分析价格，降幅高达 80%。 此次降价旨在降低用户使用 Web 分析的成本，增强其竞争力。同时，也能吸引更多用户。
  2. Web 分析 Plus 附加组件价格降低。 Plus 附加组件降价 80%，让用户更容易体验增加保留期和 UTM 参数等高级功能。
  3. Web 分析现在按每次事件计费，提供更大的灵活性。 新的计费方式允许用户根据实际使用量付费，避免了固定增量计费可能造成的浪费。
  4. 免费套餐的事件数量上限提升，更多用户将从中受益。 Hobby 和 Pro 套餐的事件数量上限提升，更多用户将从中受益。

💬 文章金句

  • 我们将 Web 分析事件和 Web 分析 Plus 附加组件的价格降低了高达 80%。
  • Web 分析的计费方式调整为按每次事件计费，不再采用 10 万次增量的模式。
  • 价格为每次事件 0.00003 美元（每 10 万次 3 美元，比之前的每 10 万次 14 美元降低了 79%）。
