VoidZero 的 Rolldown 库：兼具 Rust 速度与 Rollup 兼容 API

11/14/2025, 8:00:00 AM

📌 一句话摘要

Rolldown 是 VoidZero 开发的基于 Rust 的新型 Bundler，它提供 Rollup 兼容的 API，显著提升 JavaScript/TypeScript 项目的速度。

📝 详细摘要

本文介绍了 Rolldown，一个由 Vite 维护者 VoidZero 开发的 Rust 高性能 JavaScript/TypeScript Bundler。Rolldown 旨在取代 Vite 中现有的 esbuild 和 Rollup，利用原生多线程执行显著缩短构建时间。关键特性在于其与 Rollup 插件系统的高度兼容，使得大多数现有插件只需进行少量修改即可正常工作。除了 Rollup 之外，Rolldown 还提供高级功能，如代码分片、TypeScript/JSX 的内置转换、实验性的 CSS 打包和模块联邦。虽然该项目声称比 Rollup 快 10-30 倍，但引用的实际测试显示提高了 1.8 倍到 5 倍，并承认这些测试可能是在旧版本上进行的。行业专家强调，Rolldown 有潜力结合 esbuild 的速度与 Rollup 的全面功能集及插件生态系统。对于大型应用、monorepos 以及寻求更快构建速度而无需大量插件重写的框架来说，Rolldown 极具吸引力。

💡 主要观点

  1. Rolldown 利用基于 Rust 的原生多线程技术，显著提升构建速度。 通过用 Rust 编写，Rolldown 可以利用原生多线程执行，承诺比基于 JavaScript 的 Bundler（如 Rollup）快 10-30 倍的构建时间，并且在某些测试中优于 esbuild。
  2. 它完全兼容 Rollup 插件生态系统，简化了开发者的迁移过程。 Rolldown 的 API 被设计为与 Rollup 的插件系统兼容，允许大多数现有的 Rollup/Vite 插件以最小的更改运行，从而减少了采用新 Bundler 的摩擦。
  3. Rolldown 集成了超出 Rollup 范围的高级构建功能。 除了 Rollup 兼容性之外，Rolldown 还引入了高级代码分片、内置的 TypeScript/JSX 转换、实验性的 CSS 打包和模块联邦等功能，以满足现代构建需求。

💬 文章金句

  • Rolldown 为传统 Bundler 提供了一个高性能的替代方案，并且完全兼容 Rollup 插件生态系统。
  • Rollup 和 Rolldown 的一个关键区别在于，Rolldown 使用 Rust 编写，能够利用原生多线程执行，相比基于 JavaScript 的工具，开销更低。
  • Rolldown 可以“比 Rollup 快 10-30 倍”，并且根据 X 上的这篇文章，它在他们的测试中也大大优于 esbuild。

  • 如果您正在构建大型应用程序、monorepos 或框架，并且希望在不重写插件层的情况下更快地构建，那么 Rolldown 是一个引人注目的选择。
