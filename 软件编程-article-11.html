GPT-5 重磅登陆 Microsoft Azure AI Foundry 平台，开启企业 AI 新纪元

8/20/2025, 10:00:00 AM

📌 一句话摘要

GPT-5 模型套件现已在 Microsoft Azure AI Foundry 平台 上全面上市。它采用创新内部协调器和专用子模型，赋能企业级工作负载。

📝 详细摘要

本文宣布 OpenAI 的 GPT-5 模型套件在 Microsoft Azure AI Foundry 平台（一个用于企业人工智能运营的统一平台）上全面上市。GPT-5 的一项关键创新是其内部协调器设计，该设计可自动将任务路由到专门的子模型，从而实现更高质量的输出，减少幻觉，并降低提示工程的复杂性。该套件包括 GPT-5（用于复杂的任务，如分析和代码生成，具有 272k 令牌的上下文）、GPT-5 mini（用于实时应用程序和代理）、GPT-5 nano（用于超低延迟和微调）和 GPT-5 chat（用于自然的、多模态的对话，具有 128k 令牌的上下文）。这些模型通过 API 提供，并集成到 GitHub Copilot 和 Visual Studio Code 等开发者工具中，旨在为企业实现可扩展的、有影响力的人工智能部署。部署选项包括全球和数据专区，以实现成本效益和合规性。

💡 主要观点

  1. GPT-5 模型套件现已在 Microsoft Azure AI Foundry 平台 上全面上市。 在统一的企业平台上全面上市，标志着 AI 在企业和真实场景部署上迈出重要一步。
  2. GPT-5 具有创新的内部协调器设计。 这种设计允许模型将任务路由到专门的子模型，从而显著提高输出质量，减少幻觉，并降低提示工程的需求。
  3. GPT-5 套件为各种工作负载提供专门的模型。 GPT-5 套件提供多种模型，包括完整推理的 GPT-5、低延迟的 GPT-5 nano 和多模态的 GPT-5 chat。这些模型满足各种应用需求，提高灵活性和性能。
  4. GPT-5 正在集成到关键的开发者工具中。 集成 GitHub Copilot 和 Visual Studio Code，为复杂编码问题提供更强的推理能力，直接赋能开发者。

💬 文章金句

  • 今天，GPT-5 在我们的平台（包括 Microsoft 365 Copilot、Copilot、GitHub Copilot 和 Azure AI Foundry 平台）上发布。作为 OpenAI 合作伙伴迄今为止最强大的模型，它在推理、编码和聊天方面实现了显著提升，所有这些都基于 Azure 训练。
  • GPT-5 的一项核心创新是其设计为内部协调器，可自动将任务路由到专门的子模型或“专家”团队，这种方法允许模型通过在幕后这些专家之间切换来处理单个提示的不同部分，例如文本理解、规划和创意写作。
  • 在底层，GPT-5 统一了高级推理、代码生成和自然语言交互。它将分析深度与直观的对话相结合，以解决端到端问题并解释其方法。
  • GPT-5 在 Azure AI Foundry 平台的发布，标志着 Microsoft 将该平台定位为企业人工智能转型的核心引擎，助力企业从实验阶段迈向可扩展、有影响力的人工智能部署。
