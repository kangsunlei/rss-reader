Java 新闻综述：JDK 25 第二候选版本，Eclipse JNoSQL，Quarkus，Apache TomEE，Apache Camel

8/26/2025, 2:30:00 AM

📌 一句话摘要

本次 Java 新闻综述：JDK 25 第二候选版本、Spring Framework 里程碑版本及 Eclipse JNoSQL、Quarkus、Apache TomEE 维护更新。

📝 详细摘要

本周的 Java 新闻摘要，日期为 2025 年 8 月 18 日，重点介绍了 Java 生态系统中的几项重大进展。JDK 25 已达到其第二个候选发布版本，确认其作为下一个长期支持（LTS）版本的地位，具有 18 个最终确定的功能，并有望在 2025 年 9 月 16 日发布正式版（GA）。包括 Spring Boot、Spring Security 和 Spring for GraphQL 在内的各种 Spring 项目已经发布了它们的第二个里程碑版本。Eclipse JNoSQL 1.1.10 引入了 Jakarta Data 的性能改进，并增强了对 JPA 实体的支持，将其定位为首个通过 JPA 的独立 Jakarta Data 1.0 TCK 测试的实现。Quarkus 在其 LTS 版本中发布了 CVE-2025-55163 的紧急修复程序，该修复程序针对一个关键的 HTTP/2 漏洞。同时，Quarkus 还在最新的维护版本中包含了其他错误修复和依赖项升级。最后，Apache TomEE 10.1.1 和 Apache Camel 4.14.0 都收到了维护更新，其中 TomEE 确保 Java 21+ 与 JDK 25 的兼容性，而 Camel 提高了 RabbitMQ 生产者性能。

💡 主要观点

  1. JDK 25 已进入其第二个候选发布阶段，确认了其作为下一个 LTS 版本的角色。 随着 18 个功能最终确定，并计划于 2025 年 9 月 16 日发布正式版，JDK 25 将成为下一个长期支持版本，这对企业应用至关重要。
  2. Quarkus 在其 LTS 版本中修复了一个关键的 HTTP/2 DDoS 漏洞 (CVE-2025-55163)，增强了安全性。 Quarkus 3.15.6.1 和 3.20.2.1 中的紧急修复程序解决了 Netty 漏洞，该漏洞可能导致通过格式错误的 HTTP/2 帧耗尽资源，从而保护应用程序免受 DDoS 攻击。
  3. Eclipse JNoSQL 1.1.10 增强了 Jakarta Data 和 JPA 的集成，提供了独特的独立实现。 此版本显著提高了 Jakarta Data 的性能，并增加了对 JPA 实体的强大支持，成为首个通过 JPA 的 Jakarta Data 1.0 TCK 的独立实现。

💬 文章金句

  • JDK 25 进入第二候选版本，Build 36 中发现的一致性问题已得到解决。
  • JNoSQL 1.1.10 将成为基于 JPA 实体的一种新的 Jakarta Data 实现，它通过了独立的 Jakarta Data 1.0 TCK 测试。作为首个通过 JPA 实体的 Jakarta Data 独立实现，它可以与任何 JPA 提供程序配合使用。
  • Quarkus 团队披露了在 Quarkus 3.15.6.1 和 3.20.2.1（两个 LTS 版本）中实施的紧急修复程序，以解决 CVE-2025-55163，这是 Netty 4.1.124.Final 和 4.2.4.Final 之前的版本中的一个漏洞...
  • 此版本确保 TomEE 在 Java 21+ 上运行，为即将发布的 JDK 25 做准备。
