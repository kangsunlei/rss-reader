视频理解霸榜！快手 Keye-VL 旗舰模型重磅开源，多模态视频感知领头羊

11/28/2025, 8:01:00 AM

📌 一句话摘要

快手开源旗舰多模态大模型 Keye-VL-671B-A37B，在通用视觉理解、视频分析和复杂推理等多项核心 benchmark 中全面领跑。

📝 详细摘要

快手正式发布并开源了其新一代旗舰多模态大语言模型 Keye-VL-671B-A37B，该模型具备“善看会想”的核心能力，在通用视觉理解、视频分析、数学推理等多项核心 benchmark 中表现突出，全面领跑。技术上，Keye-VL 以 DeepSeek-V3-Terminus 为 LLM 基座，结合 KeyeViT 视觉模型，并通过三阶段预训练和监督微调、冷启动、强化学习等后训练策略进行优化。尤其在强化学习阶段，引入了 GSPO 算法和高精度验证器（Verifier）来增强奖励信号，显著提升了模型性能和训练稳定性。Keye-VL 已通过 Github 和 HuggingFace 开源，未来将进一步融合多模态 Agent 能力，拓展其应用边界。

💡 主要观点

  1. Keye-VL 模型通过深度感知和推理，能克服视觉错觉，做出比人类更严谨的判断。 示例中模型能准确识别电影票与小吃券的区别，体现其在复杂视觉场景下综合分析细节和上下文信息的能力，展现出“看得清、想得明白”的优势。
  2. Keye-VL 在视频理解中展现出精准的时序把握和跨帧推理能力。 模型能详细描述视频镜头变化、识别关键物体和建筑，并准确推理出镜头运动轨迹，证明其对复杂视频信息（如中环夜景）的强大处理能力。
  3. 创新的后训练策略，特别是 GSPO 算法和高精度验证器（Verifier），显著提升了模型性能和稳定性。 GSPO 通过 sequence-level 建模解决了 MoE 模型训练的不稳定性，而 Verifier 则通过提供高质量奖励信号增强了模型逻辑性和答案准确性，共同确保了模型在多项评测中领先。
  4. 快手将旗舰多模态模型 Keye-VL 开源，为 AI 社区和行业提供了强大的基础模型，推动了多模态技术的发展与应用。 Keye-VL 通过 Github 和 HuggingFace 开放，降低了技术门槛，鼓励开发者在此基础上进行创新，加速了通用视觉智能与高难度推理任务的落地。
  5. Keye-VL 未来将融合多模态 Agent 能力，通过工具调用和“think with image/video”实现更复杂的智能形态。 模型将强化自主调用外部工具、进行深度思考与链式推理的能力，旨在构建更通用、可靠、强推理的下一代多模态系统。
