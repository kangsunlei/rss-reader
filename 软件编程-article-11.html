AWS 发布欧洲主权云，美国法律管辖权问题仍存疑

1/22/2026, 10:19:00 AM

📌 一句话摘要

AWS 在德国推出了欧洲主权云，提供物理隔离的基础设施，但在《云法案》下能否保护数据免受美国法律管辖仍面临巨大质疑。

📝 详细摘要

AWS 正式在德国勃兰登堡推出了欧洲主权云（ESC），并投入 78 亿欧元资金。该服务拥有独立的分区（aws-eusc），由一家专门的德国子公司管理，员工全部为欧盟居民，以满足严格的监管要求。虽然工程师确认了技术上的隔离——指出即使是总部的 AWS 员工也无法访问该环境——但此举引发了激烈辩论。批评者和法律专家认为，只要 AWS 是一家总部位于美国的公司的子公司，它就仍受《云法案》和 FISA 的约束，这可能允许美国当局强制要求披露数据，无论其物理位置如何。文章将 AWS 的方案与 Hetzner、Scaleway 等欧洲本土供应商进行了对比，突显了技术主权与法律管辖权之间的紧张关系。

💡 主要观点

  1. AWS 欧洲主权云通过专用基础设施实现了高度的技术隔离。 ESC 在独立的逻辑分区上运行，拥有专属的 IAM 和计费系统，确保数据和运营控制权在物理和逻辑上均保留在欧盟境内。
  2. 尽管存在技术和运营屏障，美国的法律管辖权仍是核心担忧。 法律专家认为，《云法案》（CLOUD Act）允许美国法院强制美国母公司提供其海外子公司持有的数据，这可能会绕过当地的主权主张。
  3. 极端隔离的代价是运营敏捷性和调试速度的显著下降。 工程师报告称，全球 AWS 与 ESC 之间的严格界限意味着，通常只需几天就能修复的问题，由于沟通成本增加，可能需要长达一个月的时间。
  4. 美国控股的“主权”云与欧洲本土供应商之间存在市场竞争。 虽然 AWS、微软和谷歌都提供主权解决方案，但像 Hetzner 和 Scaleway 这样的本土供应商被定位为唯一真正不受美国法律管辖的主权选择。

💬 文章金句

  • AWS 在欧洲主权云 (ESC) 与全球 AWS 之间建立了妥善的边界。所有数据确实 100% 保留在 ESC 内部。
  • 除非我误解了美国《爱国者法案》……否则新的欧盟 AWS 主权云方案在保护客户数据免受美国政府访问方面毫无作用。
  • 法院可以要求母公司提供子公司持有的数据，这可能导致 AWS 欧洲主权云有限公司（AWS European Sovereign Cloud GmbH）的独立架构在法律上失效。
  • 主权云产品并不能凌驾于《爱国者法案》之上。它们主要减少了其他背景下的重叠：数据位置、运营控制、员工访问和客户管辖权。
