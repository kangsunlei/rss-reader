为什么你们的前端视野只剩下 Vue 和 React？

6/20/2025, 2:24:34 AM

📌 一句话摘要

文章探讨前端视野局限于 Vue/React 的现象，呼吁开发者关注浏览器底层和多技术栈，提升长期价值。

📝 详细摘要

文章分析了当前前端开发者视野普遍狭窄，过度依赖 Vue 和 React 框架的现象。作者认为，这种局限源于项目驱动的学习模式、大厂影响和社区生态的强化。然而，实际前端开发中遇到的断点续传、实时弹幕、图像渲染等复杂问题，往往需要深入理解浏览器底层 API 和机制，而框架有时反而会遮蔽这种感知力。文章进一步指出，框架生态正在形成“圈地运动”，导致不同框架生态之间的不互通性。作者推荐 Svelte（编译时思维）、Web Components（跨框架标准）、Qwik/Solid（优化 hydration）和 ThreeJS/WebGL/WASM（视觉/低延迟）等技术方向，并提供了诸如脱离框架实践、阅读源码、构建无框架组件系统等扩展视野的实操建议，强调技术视野的广度决定了开发者的长期价值，不应将框架视为全部。

💡 主要观点

  1. 当前前端开发者视野易被主流框架 Vue/React 局限 项目需求、大厂招聘导向和社区热点共同强化了“学前端就是学 Vue/React”的观念，导致开发者忽略了其他重要技术和方向。
  2. 解决复杂前端问题需要浏览器底层知识，非仅框架能力 断点续传、实时渲染、高性能图像处理等复杂场景依赖 FileReader、Canvas、WebGL、WASM 等底层技术，而框架掌握度与此无直接关系，框架有时反而会削弱对底层的感知。
  3. 导致视野局限的原因复杂，包括技术生态的焦虑、公司招聘导向及主流框架形成的“圈地运动” 开发者因就业焦虑和项目需求倾向于学习主流框架，同时不同框架生态互相排斥，共同限制了开发者探索更广阔技术领域的动力和机会。
  4. 扩展技术栈至非主流框架和底层技术是提升价值关键 拥抱 Svelte、Web Components、Qwik、ThreeJS 等非主流技术，理解编译时、跨框架标准、性能优化、图形处理和底层机制，才能应对未来多样化的前端需求，提升开发者长期价值。

💬 文章金句

  • 一问框架认知，全员只聊 Vue 和 React。
  • 大部分开发者对 Vue 和 React 的认知，其实来源于"项目驱动 + 大厂影响"的双重强化。
  • 框架越重，越遮住了我们对浏览器底层的感知力。
  • 企业系统做组件库，不考虑 Web Components，就是给维护者挖坑。
  • 你用过的工具越多，你的判断力才会越清晰。
