Azure MCP 服务器进入公开预览：扩展 AI 智能体能力

4/25/2025, 12:00:00 AM

📌 一句话摘要

Azure MCP 服务器公开预览版发布，通过 Azure 资源赋能 AI 智能体。

📝 详细摘要

Microsoft 发布了开源 Azure MCP 服务器的公开预览版，该工具旨在通过提供对 Azure 资源的访问来增强 AI 智能体的能力。模型上下文协议 (MCP) 是一种开放协议，旨在标准化 AI 智能体与外部资源之间的交互。Azure MCP 服务器实现了 MCP，允许 AI 智能体与 Azure 服务（如文件存储、数据库和日志）进行交互，并执行 CLI 命令，为开发者提供构建上下文感知智能体的能力。它支持多种 Azure 服务，包括 Cosmos DB、Azure 存储服务和 Azure 日志分析。任何支持 MCP 客户端模式的智能体都可以使用 Azure MCP 服务器，Microsoft 计划通过更多智能体示例、文档和 Azure 服务集成来增强 Azure MCP 服务器。

💡 主要观点

  1. Azure MCP 服务器通过 MCP 协议实现 AI 智能体与 Azure 服务的交互。 该服务器允许智能体使用自然语言查询 Azure Cosmos DB 中的数据，访问 Azure 存储服务文件以进行存储管理，并分析 Azure 日志分析日志以进行监控和故障排除，从而实现上下文感知。
  2. Azure MCP 服务器支持多种 Azure 服务和工具。 支持的服务包括 Azure Cosmos DB (支持数据查询)、Azure 存储服务 (支持文件管理)、Azure Monitor (日志分析，支持日志分析)、Azure 应用配置、Azure 资源组、Azure CLI 和 Azure Developer CLI (azd)。
  3. Azure MCP 服务器可与 GitHub Copilot Agent Mode 和自定义 MCP 客户端集成。 Microsoft 建议将 Azure MCP 服务器与 GitHub Copilot for Azure 扩展结合使用，以获得增强的开发体验。可以使用 Semantic Kernel 等框架构建自定义智能体。
  4. Azure MCP 服务器与其他云厂商的类似举措一致，体现了行业趋势。 Cloudflare 允许在其平台上构建和部署远程 MCP 服务器，AWS 发布了用于代码助手的开源 AWS 模型上下文协议 (MCP) 服务器，这些都体现了增强 AI 智能体能力的行业趋势。
