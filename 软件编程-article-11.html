GitHub Copilot 代码查找能力提升：全新向量模型解析

9/24/2025, 1:24:18 PM

📌 一句话摘要

GitHub Copilot 全新向量模型通过包括 Hard Negatives（困难负样本）在内的先进训练方法，显著提高代码检索的质量和效率。

📝 详细摘要

本文详细介绍了 GitHub Copilot 通过部署一种新的专用向量模型，代码检索能力得到的显著增强。此次更新使检索质量提升 37.6 %，嵌入吞吐量提升约 2 倍，并将索引内存大小减少了 8 倍。这些改进直接转化为 GitHub Copilot Chat 和智能代理功能更准确的响应、更快的代码建议以及 VS Code 中更低的内存消耗。这项进步的核心在于该模型复杂的训练方法，其中包括使用 InfoNCE 损失的对比学习和 Matryoshka 表示学习。训练的一个关键方面涉及 Hard Negatives（困难负样本）的战略性使用 —— 这些代码示例在语义上相似，但对于给定的查询最终是不正确的。这项技术对于模型区分高度相关和近似代码至关重要，从而提高泛化能力，减少过拟合。

💡 主要观点

  1. 全新向量模型显著增强了 GitHub Copilot 的代码检索性能。 检索质量提升 37.6 %，吞吐量提升约 2 倍，索引大小缩小 8 倍，Copilot 响应速度和准确性显著提高。
  2. 该模型利用对比学习和 Hard Negatives（困难负样本）来提高准确性。 使用 Hard Negatives（困难负样本）进行训练有助于模型区分高度相关和语义相似但不正确的代码，从而提高泛化能力并减少错误。
  3. 增强的代码搜索功能使从搜索到调试的各种开发者场景受益。 开发人员可以更准确地在大型代码库中找到特定的方法、测试函数或错误处理逻辑，从而提高生产力。

💬 文章金句

  • 更好的向量模型带来更好的代码搜索质量，并带来更好的 GitHub Copilot 体验。

  • 新的 Copilot 向量模型是使 AI 编码助手不仅更智能，而且对于日常开发更可靠的一步。
