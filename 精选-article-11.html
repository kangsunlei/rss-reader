这一年做 Agent 的公司，Coding 赚了钱，客服融了钱，你呢？

11/4/2025, 2:51:00 PM

📌 一句话摘要

文章基于 CB Insights 报告，深度分析了 2025 年 AI Agent 行业的商业化现状、未来趋势、机会方向及面临的挑战，指出编程类 Agent 盈利最高，客服类估值溢价最高，并强调语音和支付是未来重点。

📝 详细摘要

文章基于 CB Insights 的《AI Agent Bible》报告，全面梳理了 2025 年 AI Agent 行业的全景概况。它首先指出 Agent 已成为 AI 产品标配，并预测未来 1-2 年六大趋势，包括语音成为主流交互、大公司并购潮、推理成本严峻、Agent 购物支付基础设施关键、用户数据争夺以及 Agent 监控工具成刚需。文章进一步分析了 Agent 创业公司的分布，指出近一半做通用工具，其中客服和软件开发商业化进展最明显。商业化方面，编程类 Agent 收入最高，人均营收达 140 万美元，而客服类 Agent 估值溢价最高，平均估值倍数高达 219 倍。文章还深入探讨了高昂推理成本对商业模式的冲击，以及行业正在探索基于工作量的任务定价。最后，文章提供了 AI Agent 的技术栈图谱，并着重强调了支付和语音 AI 两大新兴领域的机会，以及 YC 对 Agentic AI 的四大押注方向和三大垂直领域（购物、制造业、金融/保险）的落地现状与趋势。

💡 主要观点

  1. 编程类 Agent 展现出最高盈利能力，客服类 Agent 则拥有极高估值溢价 编程类 Agent 在收入榜单中占据主导地位，人均营收显著；客服类 Agent 虽收入非最高，但其估值与收入之比高达 219 倍，显示市场对其未来潜力高度认可
  2. AI Agent 行业面临高昂推理成本的严峻挑战，促使定价模式变革 推理模型导致 Token 数量膨胀，计算成本失控，严重挤压利润空间，尤其对企业级包年合同冲击巨大，推动行业探索基于工作量的任务定价
  3. 语音和支付是 AI Agent 未来发展的两大新兴关键领域 语音将成为 Agent 主流交互方式，语音 AI 领域融资活跃；Agent 购物的支付基础设施是实现自主购物的最大障碍，市场处于早期但潜力巨大
  4. AI Agent 的可靠性、推理能力和系统访问权限受限是实现完全自主 Agent 的三大核心障碍 这些限制导致目前多数 Agent 在“护栏式”架构下运行，需要人工监督，也催生了 Agent 监控、评估和治理工具的市场需求
  5. 大型科技公司正通过并购、数据限制及协议标准制定，积极布局 AI Agent 生态 大公司开始收购 Agent 创业公司，并通过 API 限制等方式争夺用户数据，同时在 Agent 通信标准上展开竞争，显示对 Agent 主导权的争夺

💬 文章金句

  • 未来 2 年的趋势预测：语音将成为 Agent 主流交互方式、Agent 购物的支付基础设施很关键、用户数据会成为软件巨头争夺的关键，Agent 监控工具成为企业刚需，以及大公司开始收购 Agent 创业公司。
  • 编程类 Agent 最赚钱。在收入排名前 10 的企业中，有 6 家专注软件开发，且编程类 Agent 企业的人均营收达 140 万美元。
  • 客服类 AI Agent 虽然收入不是最高的，但估值溢价非常高。客服类 Agent 的平均估值倍数（估值与收入之比）高达 219 倍，对比其他所有赚钱的 AI Agent 公司平均只有 80 倍。
  • 要实现完全自主的 Agent 目前受限于三大问题：可靠性不足、推理能力有限、系统访问权限受限。
  • 因此，在短期内，行业正在探索一种折中的方案：基于工作量的任务定价（effort-based task pricing），Agent 在执行前为明确定义的结果提供固定报价。
