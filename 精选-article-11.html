美团开源 LongCat-Flash-Lite：实现轻量化 MoE 高效推理

2/8/2026, 9:10:00 AM

📌 一句话摘要

美团开源 68.5B MoE 模型 LongCat-Flash-Lite，通过创新 N-gram Embedding 架构实现极低激活参数与超高速推理，在 Agent 与编程任务中表现卓越。

📝 详细摘要

文章详细介绍了美团 LongCat 团队开源的 LongCat-Flash-Lite 模型。该模型采用“非典型 MoE”设计，将近一半参数（31.4B）分配给 N-gram 嵌入层，配合专用缓存、内核融合及推测解码技术，实现了以 3B 级激活参数达到 80B 级性能的效果。在推理效率上，其 API 可达 500-700 token/s。评测显示其在 Agent 工具调用和代码修复（SWE-Bench）等实战场景中显著领先同类模型。文章还提供了基于 Transformers 和 SGLang 的生产级部署指南及 Function Calling 实战示例，并宣布该模型采用 MIT 协议开源。

💡 主要观点

  1. 创新 N-gram Embedding 架构改变了传统 MoE 的堆叠专家路径。 将 46% 的参数投入嵌入层，利用 O(1) 查找复杂度降低计算开销，在保持高稀疏度的同时有效减少了专家模块间的通信与调度负担。
  2. 系统级推理加速优化大幅降低了 I/O 延迟并提升了 GPU 利用率。 通过 N-gram Cache 专用缓存机制、定制 CUDA 内核融合（如 RMSNorm 融合）及 PDL 技术，解决了嵌入查找与动态调度中的性能瓶颈。
  3. 推测解码与稀疏激活的深度协同进一步压低了推理延迟。 利用 3 步投机推理扩大实际批次大小，并针对草案模型优化规避 N-gram 查找开销，充分发挥了低激活参数模型的吞吐优势。
  4. 模型在 Agent 工具调用与 Coding 场景中展现出极强的实战性能。 在 τ²-Bench 行业场景和 SWE-Bench 代码修复测试中均取得高分，证明其在理解复杂指令、修复 Bug 及跨语言开发方面的卓越能力。

💬 文章金句

  • 无需堆专家，30B 参数投入 Embedding，推理速度提升显著，Agent 与 Coding 能力碾压同级模型。
  • 尽管模型总参数量达 685 亿，但通过动态激活机制，每次推理仅激活 29 亿～45 亿参数。
  • N-gram 嵌入层不仅能提升模型能力，其结构特性还为推理加速提供了新方向。
  • 在输入 4K，输出 1k 的典型负载下，LongCat API 可提供 500-700 token/s 的生成速度。
  • LongCat-Flash-Lite 以更少激活参数实现大幅领先，特别适合构建高效 AI Agent 系统。
