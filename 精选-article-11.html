GLM-5.3-Flash：前沿智能进入普惠时代

8/26/2026, 2:11:00 PM

📌 一句话摘要

智谱发布 GLM-5.3-Flash，一个基于 320B 参数的超轻量级多模态模型，在 AA 综合智能指数中与 Claude Opus 4.8 持平，但定价仅为后者的 1/40，实现了前沿智能的普惠化。

📝 详细摘要

GLM-5.3-Flash 是智谱推出的首个原生多模态模型，由 GLM-5.3 微调而来。该模型采用稀疏注意力与线性注意力混合架构，显著降低了长上下文服务成本。在各项基准测试中，GLM-5.3-Flash 表现优异，尤其在视觉编码和专业工作（如金融、法律）方面展现出超越同级别模型的理解能力。模型已在国产芯片上进行大规模测试，并正式开源，接入 ZCode 等平台，为开发者提供高效、经济的推理服务。

💡 主要观点

  1. 超轻量级架构，极致成本优化 GLM-5.3-Flash 基于 320B 参数，但通过稀疏注意力与线性注意力混合架构，将注意力计算量降低 3.01 倍，KV 缓存大小降低 4.44 倍，从而实现极低的推理成本，定价仅为 GLM-5.3 的 1/10。
  2. 前沿智能，全球领先水平 在 Artificial Analysis Intelligence Index（AA）中，GLM-5.3-Flash 取得 57 分，与 Claude Opus 4.8 持平，进入全球前沿模型能力区间。在 Z.ai Code Bench 体感评估中，其编程表现也与 Opus 4.8 相当。
  3. 原生多模态，视觉编码能力强 作为首个原生多模态模型，GLM-5.3-Flash 在视觉编码方面表现出色，能够自主判断何时需要观察，并利用视觉反馈指导下一步行动。在前端开发、游戏开发等领域，该能力显著提升了模型的实用性。
  4. 专业领域优化，覆盖金融法律 模型针对金融、法律等专业工作进行了专门优化。在金融方面，可覆盖从研究到建模的完整流程；在法律方面，可审查合同并按律师惯例批注，生成即时可交付的专业文档。
  5. 国产芯片部署，高效可靠服务 GLM-5.3-Flash 已在国产芯片集群上进行大规模测试，通过自研推理引擎和内存优化，实现了与主流 GPU 相当的硬件效率和单 token 成本，证明了国产芯片支撑前沿模型的可行性。

💬 文章金句

  • 大家好像已经习惯将前沿智能与前沿价格绑定，并认为这是技术进步必须支付的成本。今天，GLM-5.3-Flash 来了：320B 总参数，能力超过 GLM-5.2，在全球权威的 Artificial Analysis Intelligence Index（AA 综合智能指数）中取得 57 分，进入全球前沿模型能力区间，与 Anthropic 最受欢迎的模型 Claude Opus 4.8 得分持平。在自研 Z.ai Code Bench 体感评估中，其编程表现与 Claude Opus 4.8 相当。
  • 与此同时，GLM-5.3-Flash 定价为 GLM-5.3 的 1/10，限时折扣内为 GLM-5.3 的 1/20，为 Opus 4.8 的 1/40。同样智力，1/40 价格，前沿智能，第一次不需要省着用。
  • 为降低模型长上下文场景下的注意力成本，我们采用线性注意力与稀疏注意力相结合的混合架构。其中，线性注意力通过递归机制捕获局部依赖关系，稀疏注意力则借助轻量级索引器召回全局上下文。我们引入 IndexPool 为进一步降低 1M 上下文下索引器的时延与内存开销，通过加权池化将索引器的 4 个缓存向量压缩为 1 个。
