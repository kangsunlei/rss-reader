DeepSeek-Prover 核心作者辛华剑分享 AI 在形式化数学证明领域进展及 Agent 与 AGI 的关系。

📝 详细摘要

本文是对 DeepSeek-Prover 核心作者辛华剑的访谈，深入探讨了 AI，特别是大语言模型（LLM）在形式化数学证明领域取得的突破。辛华剑阐述了形式化数学的意义和挑战，以及其与程序验证、更广泛的推理任务的关联。他强调，AI 对复杂数学证明的进展，如 DeepSeek-Prover 系列工作，显示了强化学习（RL）和思维链（CoT）在提升 AI 推理能力中的作用。访谈核心观点是将形式化数学视为探索和发展 AI Agent 和 AGI 的理想环境，并提出了 Proof Engineering Agent 和 Certified AI 的概念。文章还讨论了数据合成、Test Time Scaling 和 Evaluation Benchmark 的重要性，认为高质量的评估标准是驱动模型能力增长的关键“钉子”。

💡 主要观点

  1. AGI 的下一个形态是 Agent，核心是实现知识生产和发现能力。 超越简单的知识使用者，未来的 AGI 需要像人类一样主动发现、整理和积累知识，这与当前对 Agent 的追求高度一致，要求 AI 具备更复杂的推理和规划能力。
  2. 形式化数学是发展和探索 AI Agent 及推理能力的理想“实验场”。 数学领域的逻辑严谨性、抽象性和无需物理交互的特性，使其成为低成本、大规模探索 AI 推理、规划和验证能力的优质环境，可为 AGI 发展提供指导。
  3. 复杂形式化证明任务天然适合 Multi-Agent 或人机协作模式。 将大型证明任务分解为子任务，由不同 Agent 或人协力完成并通过计算机验证聚合，这种 Proof Engineering 思路是高效处理复杂问题的关键，契合 Agent 协作范式。
  4. 自动形式化是从自然语言到形式化语言迁移知识、弥补数据不足的关键。 通过将更丰富、更易获取的自然语言数学内容翻译成形式化语言，可以有效扩充训练数据，加速形式化数学和相关 AI 模型的发展，也泛化到代码等领域。
  5. Evaluation Benchmark 的设计和质量比模型训练本身更重要。 AI，特别是 RL 的有效训练依赖于精确可靠的反馈信号。缺乏能提供适当难度的、符合实际需求的评估标准，会限制模型能力的提升，高质量 Benchmark 是关键的“钉子”。
  6. 未来 GenAI 将走向 Certified AI，强调对生成内容质量的控制和验证。 仅有强大的生成能力不足，还需要确保生成内容的准确性、可靠性和可控性，这需要将生成能力与形式化等验证手段结合，是 AI 应用落地的关键一步。

💬 文章金句

  • 但到了 2025 年，我们对 AGI 的要求更高了，实际上是向更 Agent 的方向提出了要求，我们希望 AGI 不但是个知识的使用者，而且能够像人一样是知识的发现者、整理者。
  • 总而言之，现在所有对 AGI 的刻画和想象，实际上已经和大家现在对 Agent 的追求非常相近，我认为对 AGI 的讨论如果不涉及其他模态以及和世界的交互的话，我们说的 AGI 就是 Agent 的 AGI。
  • 我们现在的模型就像是很好的"锤子"，但我们却缺少足够好的"钉子"。
  • 形式化数学是我们发展和探索 Agent 一个比较好的场景。
  • GenAI 的下一步是 Certified AI 强调：我们不仅需要生成能力，更需要对生成质量有良好的控制。
  • 下一个 GPT-4 时刻是实现具备自主规划、执行和反思能力的 Agent。
