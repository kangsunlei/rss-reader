DeepSeek-V4.1-Flash 技术报告深度解读：长程 Agent 如何重新分配预算

9/10/2026, 9:33:00 AM

📌 一句话摘要

文章深入解读了 DeepSeek-V4.1-Flash 技术报告，阐述了 CED、CSA2、FP4 量化等多项技术优化如何显著降低 KV 缓存开销和计算成本，使长程 Agent 能够更高效地执行复杂任务。

📝 详细摘要

本文对 DeepSeek-V4.1-Flash 技术报告进行深度解读，重点分析了如何通过 Causal Encoder-Decoder (CED) 架构、Compressed Sparse Attention 2 (CSA2) 机制、FP4 量化技术等创新设计，大幅降低了长程 Agent 处理长上下文时的计算和存储开销。文章详细解释了历史 KV 缓存的优化策略，包括跨层共享、低精度存储和会话恢复机制，以及如何通过 Single-Pass mHC、Engram 记忆模块和 DSpark 草稿机制进一步提升推理效率。报告还介绍了 45T 多模态 tokens 的预训练、稀疏注意力扩展至 1M 长度、以及 SFT→RL→OPD 三阶段训练流程。实验结果显示，该模型在 DeepSWE v1.1、Terminal-Bench 3.0 和 GPQA Diamond 等基准测试上取得优异成绩，验证了架构优化对提升长程 Agent 性能的显著作用。

💡 主要观点

  1. CED 架构显著减少历史位置的计算量 将主干分为前因果编码器和后解码器，decoder 的全局 KV 由 encoder 最后一层的隐藏状态经投影直接产生，无需完整计算 decoder 各层，从而大幅降低 prefill 阶段的计算开销。
  2. CSA2 机制实现跨层 KV 共享，降低存储重复 通过 Full、Reindex、Reuse 三种模式，实现历史表示的跨层共享，同时保留每层自己的查询和注意力计算，有效减少缓存存储量。
  3. FP4 量化技术进一步压缩 KV 缓存空间 对主 KV 引入量化感知训练 QAT，采用 E2M1 格式，在 RoPE 之后量化，显著降低 global KV 的存储占用。
  4. 综合优化后实现显著的资源节省 global KV 占用降至原来的 25%，持久缓存总量降至原来的 12.5%（约 890 字节/token），为长程 Agent 的高效运行提供了坚实基础。
  5. 训练方法支持 1M 长度稀疏注意力 采用 45T 多模态 tokens 进行预训练，稀疏注意力从 64K 长度开始训练，在累计 34T tokens 时扩展到 1M，支持超长上下文处理。

💬 文章金句

  • 持久缓存压到原来的约八分之一
  • prefill 每个 token 激活 8B 参数，decode 每个 token 激活 16B
  • CED 改变了 decoder 全局 KV 的来源：它由 encoder 最后一层的隐藏状态，经对应投影直接产生
  • global KV 继续持久保存，保证至少 72 小时的保留时间
  • 890 字节/token 的 global KV 占用
