Gemini 代码助手新功能：代理模式、IDE 改进和 Gemini CLI 更新

8/21/2025, 12:00:00 AM

📌 一句话摘要

Google 推出了 Gemini 代码助手的重大更新，包括 VS Code 和 IntelliJ 中全面推出的代理模式，以及增强的 IDE 功能和扩展的 Gemini 命令行工具能力。

📝 详细摘要

本文详细介绍了 Google Gemini 代码助手的最新进展，重点关注三个关键领域：代理模式、IDE 改进和 Gemini 命令行工具更新。代理模式现已在 VS Code 和 IntelliJ 中全面推出，使开发人员能够与 AI 协作处理复杂的多步骤编码任务，并提出详细的计划以供用户审查和批准。此功能旨在提高工作流程效率和代码质量。文章重点介绍了代理模式的几个 VS Code 特定增强功能，例如集成的内联差异和持久的聊天记录。此外，VS Code 和 IntelliJ 的 IDE 改进包括停止进行中的聊天响应、IntelliJ 的“思考令牌”以及更快的代码完成。最后，涵盖了开源 Gemini 命令行工具的重大更新，特别是 Gemini 命令行工具 GitHub Actions 的发布，用于执行诸如问题分类和拉取请求（PR）审查之类的自主编码任务，以及更深入的 VS Code 集成，以实现上下文感知的建议和原生编辑器内差异比较。这些更新共同旨在提高开发人员的生产力并简化编码工作流程。

💡 主要观点

  1. Gemini 代码助手的代理模式现已全面推出，实现了 AI 驱动的多步骤任务自动化。 代理模式允许开发人员描述复杂的编码目标，Gemini 提出详细的计划以供审查和批准，从而显著提高效率和对多文件更改的控制。
  2. IDE 体验通过停止聊天响应和改进的代码完成等功能得到改进。 诸如停止不需要的 AI 响应和“思考令牌”之类的新功能使开发人员能够更好地控制和洞察，而性能增强则简化了编码过程。
  3. Gemini 命令行工具通过 GitHub Actions 和更深入的 VS Code 集成进行扩展，从而增强了自动化工作流程。 Gemini 命令行工具 GitHub Actions 的引入自动化了诸如问题分类和 PR 审查之类的例行编码任务，而增强的 VS Code 集成提供了上下文感知的建议和原生差异比较，从而提供更有针对性的帮助。

💬 文章金句

  • IDE 中的代理模式可帮助您通过智能协作的方式处理复杂的多步骤任务。
  • 通过将 AI 的强大功能与您的专业知识相结合，代理模式可帮助您实现更高效的工作流程并生成更好的代码，同时节省大量时间和精力。
  • 由于具有停止进行中的聊天响应的新功能，您现在可以更好地控制与聊天的交互，因此您可以立即停止不需要的冗长或错误的聊天响应。
  • Gemini 命令行工具 GitHub Actions 现已推出，是您存储库的免费、功能强大的 AI 编码助手。
  • Gemini 命令行工具也已更新，并更深入地集成到 VS Code 中。它可以感知您打开的文件，并且可以访问选定的文本。
