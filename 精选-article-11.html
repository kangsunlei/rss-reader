喝点 VC｜a16z 圆桌：每一次平台迁移，改变的不仅是应用，更是人与计算交互的抽象层次

9/10/2025, 2:57:00 AM

📌 一句话摘要

a16z 圆桌讨论指出，AI Agent 正推动平台级变革，重塑人与计算的交互抽象层次和工作本质，未来将是专业化多 Agent 协作而非单体 AGI。

📝 详细摘要

本文编译自 a16z 的一场专家圆桌讨论，深入探讨了 AI Agent 的本质、发展趋势及其对工作流和商业模式的深远影响。与会专家（Aaron Levie， Steven Sinofsky， Martin Casado）认为，Agent 的真正价值在于深度赋能人类，而非简单替代，尤其能大幅提升专家群体的生产力。他们强调，AI Agent 的发展趋势是任务的细分化和多 Agent 协作，这与传统的单体 AGI 叙事相反。文章指出，每一次平台迁移，改变的不仅是应用，更是人与计算交互的抽象层次，AI Agent 正在颠覆传统工作流，从人类适应 Agent 的使用方式，到工作本身因 Agent 能力而重塑。此外，讨论还聚焦于 AI Agent 带来的巨大商业机会，认为垂直领域的 Agent 公司将大量涌现，模型厂商难以垄断所有应用层市场。文章也理性探讨了递归自我改进的复杂性、AI 预测的徒劳性，以及人类审查和清晰上下文在 AI 应用中的关键作用。

💡 主要观点

  1. AI Agent 的本质是能够在后台自主执行真实工作的系统，其发展趋向专业化和多 Agent 协作。 Agent 通过将输出作为输入进行处理，实现自主执行，但其发展路径更可能是由多个在特定任务上深度专业的 Agent 协同工作，而非单一的通用智能体。
  2. AI Agent 正引发平台级变革，改变人与计算的交互抽象层次，并根本性地重塑工作流。 如同历史上的技术转型，Agent 不仅自动化旧工作，更将使人类反过来适应 Agent 的使用方式，导致工作本身和组织分工发生结构性变化。
  3. 专家群体将成为 AI 的最大受益者，AI 赋能而非取代，但人类审查和清晰上下文仍不可或缺。 AI 系统本质上具有概率性，需要专家对结果进行验证，且高质量的提示词和上下文是获得高效输出的关键，这使得专家生产力得到显著提升。
  4. AI Agent 的兴起将催生数千个垂直领域创业机会，模型厂商难以通吃所有应用。 市场将趋向更细致的颗粒度，每个特定的工作流环节都可能孕育出独立的 Agent 公司，解决长尾问题并利用私有数据，这与大模型厂商的泛化能力形成互补。

💬 文章金句

  • 每一次平台迁移，改变的不仅是应用，更是人与计算交互的抽象层次。
  • 我们正在看到提示词变得越来越复杂，Agent 越来越多，任务越来越细分——这与 AGI 的宏大叙事恰恰相反。
  • 专家正在成为 AI 的最大受益者，他们的生产力提升远超其他群体。
  • 人类必须摆脱把 AI 拟人化的思维方式，因为这正是阻碍发展的原因。
  • 大公司很难在 50 个领域同时深入，预训练可以做到广覆盖，但一旦进入应用层，就会变成执行力的问题。没有哪家公司能打赢 50 个领域里的 50 个创业公司。
