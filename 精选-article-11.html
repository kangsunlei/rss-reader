📌 一句话摘要

OpenAI 发布 GPT-5，主打集成模型与“博士级”智能，性能提升但基准图错误引争议。

📝 详细摘要

文章详细报道了 OpenAI 最新发布的 GPT-5 模型。GPT-5 被定位为一款集成模型，无需用户手动切换，能根据任务自动调用不同处理模式（高效应答与深度推理）。文章列举了 GPT-5 在数学、编程、多模态理解和健康等多个领域基准测试中的显著性能提升，并强调其在降低幻觉、提升指令遵循精度方面的改进。同时，文章也指出了发布会中出现的基准图错误，以及行业内外对 GPT-5 表现未达预期的争议，包括埃隆·马斯克的质疑。文章还提及了 GPT-5 的免费版、Plus 和 Pro 计划以及面向开发者的 API 定价，并强调了其在微软 Azure AI 超级计算机上的训练。

💡 主要观点

  1. GPT-5 采用集成模型架构，通过智能路由自动切换处理模式。 该架构包含高效应答、深度推理及实时路由系统，能根据任务复杂性自动分配最优模型，提升处理效率和用户体验。
  2. GPT-5 在多领域基准测试中性能显著提升，尤其在复杂推理任务。 模型在数学、编程、视觉理解和健康等专业测试中取得高分，其“Thinking 模式”在研究生级科学问题解决上表现突出。
  3. GPT-5 致力于降低幻觉生成并提升指令遵循精度。 这些改进提高了模型输出的可靠性和准确性，使其在文本创作、编程和健康咨询等核心应用场景中更具实用价值。
  4. GPT-5 发布伴随争议，包括基准图错误和表现未达预期。 尽管模型性能有所提升，但现场演示的失误以及部分行业观点认为其进步不足，引发了公众和行业专家的质疑与讨论。

💬 文章金句

  • 等了多年的 GPT-5，终于在这个凌晨发布了。
  • 尽管奥特曼强调 benchmark 不重要，但他们还是晒出了不少跑分结果。
  • GPT‑5 是一个包含三个模型的统一系统：回答大部分常规问题的高效应答模型、解答复杂难题的深度推理模型「GPT‑5 Thinking 模式」，以及根据对话类型、问题复杂度、工具需求及用户明确指令自动分配最优处理模型的实时 router。
  • GPT‑5 在大约半数案例中的表现达到或超越人类专家水平，同时在法律、物流、销售、工程等 40 多个职业领域的综合任务表现上全面优于 o3 模型和 ChatGPT Agent。
  • 不过，现场也出了一些小 bug，比如做出的跑分图竟然是错的，奥特曼也承认了错误。
