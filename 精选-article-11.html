Dify 官方命令行工具：difyctl 正式发布

7/8/2026, 12:05:00 PM

📌 一句话摘要

Dify v1.15.0 发布官方命令行工具 difyctl，支持 Agent、脚本、CI 流水线一键调用 AI 应用和工作流，同时带来界面优化、思维链展示扩展、人工介入增强等多项更新。

📝 详细摘要

Dify v1.15.0 版本发布官方命令行工具 difyctl，实现 AI 应用向真实工作流的全面延伸。该工具支持企业版、云端版、社区版统一使用，提供 Dify 账号和 External SSO 两种受控登录方式，便于 Agent、脚本、CI 流水线调用 Dify 应用和工作流，无需编写对接代码。同期更新还包括界面焕新、思维链展示扩展至 CLI（--think 参数）、Human Input 节点增强（支持下拉选择和文件上传）、知识库 Excel 内嵌图片提取等企业级功能，以及社区贡献的 /create 指令生成工作流和凭据按用户授权隔离等亮点。

💡 主要观点

  1. difyctl 官方命令行工具正式发布，支持 Agent、脚本、CI 流水线一键调用 Dify 应用和工作流。 用户可通过统一命令调用 Dify 应用，无需编写对接代码，支持企业版、云端版、社区版统一使用。
  2. difyctl 提供两种受控登录方式，便于企业接入内部系统和 Agent 场景。 支持 Dify 账号登录（继承安全权限）和 External SSO 登录（适配外部身份提供方），让 Dify 真正接入组织流程。
  3. 思维链展示扩展至网页版、工作流调试和 CLI，--think 参数可查看 reasoning 内容。 推理过程与最终答案分开展示，适用于金融、法律、医疗等对 AI 决策过程有审计需求的业务场景。
  4. Human Input 节点增强，支持下拉选择和文件上传，强化企业级人工介入流程。 审批流程可直接设定通过/驳回/转审，知识处理流程可上传文件附件，使 Dify 更自然地契合企业级流程。
  5. 知识库支持提取 Excel 内嵌图片，提升 RAG 检索召回完整性。 处理 Excel 时可一并提取图表、流程图等内嵌图片资源，避免企业文档信息遗漏。

💬 文章金句

  • Agent 逐渐从'对话框里的建议者'，变成可以调用工具、读取信息，执行流程的业务协作者，不只是回答问题，而是真正进入企业已有的系统、数据和工作流中。
  • 这也是 CLI 在 AI Agent 时代重新变得重要的原因，当 Agent 需要调用一个已经搭建好的 Dify 应用或工作流时，difyctl 就提供了这样一个稳定入口。
