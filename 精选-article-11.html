刚刚，OpenAI 发布 GPT-5-Codex：可独立工作超 7 小时，还能审查、重构大型项目 ｜ 机器之心

9/16/2025, 2:25:47 AM

📌 一句话摘要

OpenAI 发布 GPT-5-Codex，这是一款专门为智能体编程任务优化的模型，具备长时间独立工作、代码审查和大型项目重构能力，并集成了 Codex CLI、IDE 插件和 GitHub。

📝 详细摘要

文章详细介绍了 OpenAI 最新发布的 GPT-5-Codex，这是一款针对智能体编程任务进行优化的 GPT-5 模型。它在真实软件工程任务中表现出色，能够快速响应交互式会话，并独立完成长达 7 小时的复杂任务，包括项目构建、功能开发、测试编写、调试和大规模重构。GPT-5-Codex 的代码审查能力尤为突出，能主动发现关键漏洞，在 OpenAI 内部已审查绝大多数 PR。该模型在 SWE-bench Verified 和 Code refactoring tasks 基准测试中均优于 GPT-5，并能根据任务复杂度动态调整思考时间。同时，文章还介绍了 Codex 平台的一系列升级，包括全新设计的开源 Codex CLI（支持图片输入、待办清单、工具调用和权限管理）、支持 VS Code 等 IDE 的插件（提供上下文感知、云端本地无缝切换）以及与 GitHub 的深度集成。OpenAI 还强调了 Codex 的安全措施，如默认沙箱环境、权限机制和可配置安全设置。Codex 已包含在 ChatGPT 的 Plus、Pro、Business、Edu 和 Enterprise 订阅中，并计划很快通过 API 开放 GPT-5-Codex。

💡 主要观点

  1. GPT-5-Codex 专为自主式软件工程任务优化，能独立完成复杂开发工作。 该模型接受过完整项目构建、功能开发、测试编写、调试、大规模重构等任务训练，可独立运行超过 7 小时，显著提升开发效率和代码质量。
  2. 模型具备卓越的代码审查能力，可主动发现关键漏洞并提供修改建议。 GPT-5-Codex 通过分析代码库、依赖并运行测试来验证正确性，其审查意见更准确，帮助团队在人工审查前识别并解决问题。
  3. Codex 平台通过 CLI、IDE 插件和 GitHub 集成，提供无缝的开发者体验。 新版 Codex CLI 支持图片输入和工具调用，IDE 插件实现上下文感知和云本地切换，GitHub 集成则将 AI 智能体融入日常开发工作流，极大提升了易用性。

💬 文章金句

  • GPT-5-Codex 的训练重点放在真实的软件工程任务上。它既能在短时间的交互式会话中快速响应，也能独立完成冗长复杂的任务。
  • 在测试中，我们看到 GPT-5-Codex 能独立运行超过 7 小时，不断迭代实现、修复测试，最终交付可用代码。
  • GPT-5-Codex 的审查意见更少出现错误或无关内容，更能把注意力集中在关键问题上。
  • 在 OpenAI 内部，Codex 已经审查了我们绝大多数 PR，每天能发现数百个问题，很多在人工审查开始之前就已经被拦下。
  • 我们始终建议开发者在上线前先检查 Codex 的工作结果。Codex 会在每个任务中提供引用、终端日志和测试结果，方便人工验证。
