OpenClaw 之后，我只想未来 3-6 个月的事情｜对谈 Sheet0 创始人王文锋

3/14/2026, 2:00:00 PM

📌 一句话摘要

对话深入剖析了 Coding Agent 对 SaaS 行业的颠覆、10 倍效能提升的实战经验及 AI 时代的务实创业观。

📝 详细摘要

本期播客对话 Sheet0 创始人王文锋，深度探讨了以 OpenClaw 为代表的第二波 Agent 热潮。王文锋提出，Coding Agent 已成为所有智能体的核心引擎，通过将大模型能力与文件系统结合，解决了长程任务的不确定性与自我修复问题。访谈揭示了 AI 如何解构 SaaS 作为“专家能力规模化载体”的本质，认为定制化 AI 专家将取代标准化的最佳实践。此外，王文锋分享了团队通过“AI 管 AI”实现开发周期从一年缩短至两周的效能飞跃。最后，他反思了创业心态的转变：在技术极速更迭的当下，应放下长期预判的 Ego，聚焦未来 3-6 个月的确定性，通过“优化胜率而非赔率”来应对 AI 带来的深刻变革。

💡 主要观点

  1. Coding Agent 将成为所有智能体的统一底座 所有的垂直领域 Agent 最终都会演化为基于代码能力的通用型智能体，通过 Coding 能力释放模型的推理极限。
  2. AI 正在解构传统 SaaS 作为专家能力载体的价值 AI 提供了低门槛、即时且定制化的专家能力，打破了传统软件依靠预设工作流和最佳实践来复制经验的模式。
  3. “AI 管 AI”是实现百倍效能提升的新范式 从人驱动 AI 转向由高级 AI 自动指派任务并闭环修复，将工程师从代码编写者转变为最后的质检员和决策者。
  4. 创业策略应从长期预判转向短期确定性跟随 在 AI 快速进化的环境中，预判 5-10 年毫无意义，应关注 3-6 个月的现实瓶颈，追求高胜率的落地价值。

💬 文章金句

  • AI coding 是大模型的零销售……接下来所有的 agent 都会发现，最后本质又变成了一个 code agent 一个套壳。
  • 软件本质上在过去的一个核心地位，是说它可能是规模化复制专家能力的一个载体。现在有了 agent 以后，获得专家能力变得更容易了。
  • 现在的瓶颈不在于生产效率上，生产效率没有瓶颈，核心的瓶颈是做什么，做成什么样。
  • 文锋我觉得更大的作用就是说 AI 管 AI……我觉得 practice 就是一个 AI 管 AI 的一个 agent。
  • 不要去尝试解决那些人们还没有遇到瓶颈的问题。本账其实是在优化赔率，而不是在优化胜率。
