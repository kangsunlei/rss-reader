Claude 技能的卓越性：或超越 MCP 的潜力

10/16/2025, 9:25:18 PM

📌 一句话摘要

Claude 技能利用 Markdown 和编码环境中的脚本，显著增强 LLM 作为通用代理的能力，为现有 LLM 扩展方案提供了一种更灵活和 token 高效的替代方案。

📝 详细摘要

本文介绍了 Anthropic 的“Claude 技能”，这是一种旨在扩展 Claude 能力的创新机制。技能是包含指令的 Markdown 文件，可能附带脚本和资源，Claude 会在与用户任务相关时动态加载。这种设计具有很高的 token 效率，因为最初只扫描简洁的 YAML 前置元数据。技能的一个关键方面是它们依赖于强大的编码环境，该环境配备了文件系统访问和命令执行功能，从而使 Claude Code 成为强大的“通用代理”。作者将技能与之前扩展 LLM 的尝试（如 ChatGPT 插件和模型上下文协议（MCP））进行了对比，强调了技能的卓越简洁性、token 效率和易于共享的特点。与复杂的 MCP 规范不同，技能是简单的文本文件，使其具有高度的适应性，并可在各种 LLM 工具和模型中使用。文章预测技能的采用将出现“寒武纪大爆发”，这归因于它们易于创建和传播。其固有的简单性是核心优势，能够实现从自动文档创建到专业数据新闻代理等各种应用。

💡 主要观点

  1. Claude 技能通过模块化、token 高效的文本文件简化了 LLM 能力扩展。 技能利用 Markdown 和可选脚本，仅在相关时加载，从而在不消耗过多上下文资源的情况下实现专门任务。
  2. 技能通过强大的编码环境将 LLM 转变为强大的“通用代理”。 它们对文件系统访问和命令执行的依赖使 LLM 能够自动化复杂的计算机任务，从而通过强大的编码环境，使 LLM 成为强大的“通用代理”。
  3. 技能为现有的 LLM 扩展协议（如 MCP）提供了一种更实用、灵活和可共享的替代方案。 它们固有的简单性、易于创建和跨模型兼容性预计将推动广泛采用，并促进 LLM 应用中的重大创新。

💬 文章金句

  • Claude 现在可以使用*技能*来改进其执行特定任务的方式。*技能*是包含指令、脚本和资源的文件夹，Claude 可以在需要时加载。
  • 技能机制*完全依赖于*模型具有访问文件系统、导航文件系统的工具以及在该环境中执行命令的能力。
  • 事后看来，Claude Code 的命名并不恰当。它不仅仅是一个编码工具：它是一个用于通用计算机自动化的工具。
  • 我预计我们将看到技能的寒武纪大爆发，这将使今年 MCP 的热潮相形见绌。
  • 技能设计的核心简单性是我对它如此兴奋的原因。
