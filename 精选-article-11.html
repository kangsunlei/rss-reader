把 UI 生成接进流水线：基于半监督评测体系的 UI 自动化生产实践

5/12/2026, 7:33:00 AM

📌 一句话摘要

本文分享了蚂蚁集团在生成式 UI 领域的工程实践，通过构建 prompt 工作台、需求改写、组件检测、风格管理、流式渲染和自动化评审体系，将 UI 生成从技术能力转化为可接入生产流水线的工程能力。

📝 详细摘要

本文是蚂蚁集团前端工程师黄兆嵩在 QCon 2026 上的演讲整理，系统阐述了将 AI 生成式 UI 接入生产流水线的工程实践。文章首先分析了当前 UI 生成面临的核心困境：prompt 管理混乱、需求描述不完整、设计稿还原精度不足、生成结果不符合品牌规范。针对这些问题，团队构建了模块化 prompt 工作台、需求自动改写模块、基于两万条精标数据的组件检测模块，以及风格管理仓库与 RAG 召回机制。在 LUI 场景落地方面，通过流式渲染（拓展 Markdown-XML 协议）和三级缓存召回方案，解决了生成延迟和计算成本问题。质量保障方面，建立了规则驱动的 Agent 自动评审体系，实现机审与人工协同审核，并利用审核数据自动迭代 prompt，形成正向循环。文章最后展望了生成式 UI 从辅助工具到个性化引擎再到前端生产范式革命的演变趋势，认为 LUI 与 GUI 的融合是交互形态的终局。

💡 主要观点

  1. 构建模块化 prompt 工作台，解决 prompt 管理混乱问题。 将整块 prompt 拆分为独立模块，产品、设计、研发各自维护，支持版本管理和试运行，大幅降低协作成本和试错周期。
  2. 通过需求改写和组件检测提升生成质量。 在生成前自动将一句话需求扩写为完整业务描述；训练专用组件检测模块，精确识别设计稿中元素位置和尺寸，提升布局还原精度。
  3. 流式渲染和三级缓存解决 LUI 场景下的延迟和成本问题。 通过拓展 Markdown-XML 协议让智能体直接输出 UI 渲染信息，实现边输出边渲染；三级缓存方案将相似用户请求命中预生成 UI，实现生产与消费解耦。
  4. 规则驱动的 Agent 自动评审体系实现质量监督自动化。 内置通用规则和可配置业务规则，自动对生成 UI 打分并输出评审意见；机审通过率与人审吻合度约七成，且无漏网案例，可作为有效质量门禁。
  5. 利用审核数据自动迭代 prompt，形成质量正向循环。 系统自动汇总审核标注信息，分析共性问题根因，生成针对性 prompt 优化建议并自动更新到生成链路，审核越多质量越高。

💬 文章金句

  • 能生成，不等于能用。
  • prompt 变成了一个没有 IDE、没有版本控制的代码仓库。
  • 让前端生产自动运转，让用户体验随需而变。
  • 机审比人审更严，不会放水。可以做一道真实有效的质量门禁——先过机审，再给人看。
  • CLI 不是终局形态，而是技术快速革命下，体验技术还没来得及适应的中间态产物。
