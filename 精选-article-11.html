📌 一句话摘要

微软 Build 2025 大会聚焦“主动式网络”，AI 代理赋能开发者与应用平台。

📝 详细摘要

本文详细记录了微软 CEO 萨提亚·纳德拉在 Build 2025 大会的主旨演讲核心内容。演讲提出并阐释了构建开放、可扩展、具能动性的“主动式网络”（Agentic Web）愿景，标志着计算范式向 AI 代理驱动转变。文中介绍了微软在开发者工具（VS Code Copilot 开源、GitHub Copilot 2）、Microsoft 365 平台（M365 Copilot 全面上市、Copilot Studio/Tuning 构建企业级代理）、Azure AI Foundry（支持多模型、推出智能路由器、集成 Grok/Mistral、代理服务、可观测性）和 Windows（Windows AI Foundry、WSL 开源）等方面的最新进展与能力升级，旨在为开发者构建 AI 原生应用和智能代理提供全栈支持。文章通过高层对话和客户案例，展现了 AI 代理的应用潜力和微软构建开放生态的决心。

💡 主要观点

  1. 微软将 AI 代理视为新计算时代核心，提出“主动式网络”愿景。 AI 不再是单一工具，而是开发者能力的延伸，通过构建开放平台，赋能个人和组织创建应用与智能代理，推动下一代互联网形态变革。
  2. 微软全线开发者工具深度集成 AI 能力，从辅协走向自主代理。 Copilot 在 VS Code 中开源，GitHub Copilot 升级迈向同侪程序员，能自主完成代码维护、应用现代化等任务，提升开发效率和自动化水平。
  3. Microsoft 365 平台以 Copilot 为界面，Agentic 能力革新生产力。 M365 Copilot 整合多功能，Copilot Studio/Tuning 支持企业定制和编排复杂多代理工作流，极大提升办公效率和企业知识的应用。
  4. Azure AI Foundry 打造企业级 AI 应用服务器，支撑规模化 Agent 部署。 提供丰富的模型选择（含 Grok），智能路由器简化模型调用，代理服务支持声明式和多代理编排，具备可观测性，满足生产环境需求。
  5. Windows 转型为 AI 最佳平台，本地 AI 能力与云端协同。 发布 Windows AI Foundry，开放本地运行时和 SDK，支持设备端 AI 开发，原生支持 Agent 协议（MCP），结合 WSL 开源，构建强大的混合开发环境。
