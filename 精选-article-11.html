Harness is the New Dataset：模型智能提升的下一个关键方向

3/26/2026, 12:06:00 PM

📌 一句话摘要

本文深入探讨了 AI Agent 时代的工程范式演进，指出随着模型能力成熟，构建围绕模型的系统工程（Harness Engineering）已成为决定 Agent 上限的关键，并强调了 Harness 作为数据飞轮的核心价值。

📝 详细摘要

文章系统性地阐述了「Harness Engineering」这一概念，将其定义为模型外围的运行环境与管控系统（包括记忆、工具、编排、基础设施、评估、追踪等）。作者指出，AI 工程范式已从 Prompt 和 Context 演进至 Harness，核心瓶颈从模型智力转移至系统工程。文章详细拆解了 Harness 的六大组件及设计原则（如渐进式披露、工具精简、反馈闭环等），并深入分析了模型与 Harness 的共生关系（训练即部署）。最后，文章梳理了该领域的创业机会，涵盖上下文管理、工作流编排、安全与沙箱及评估观测等方向。

💡 主要观点

  1. AI 工程范式演进至 Harness Engineering。 随着模型能力成熟，瓶颈外移。Harness 决定了 Agent 能看到什么、用什么工具以及如何处理失败，是构建可靠 Agent 的核心，标志着 AI 开发从模型中心转向系统中心。
  2. Harness 不仅是脚手架，更是数据飞轮。 核心观点为「The Harness is the Dataset」。通过 Harness 捕获的高质量执行轨迹是模型持续进化的关键，模型与 Harness 需共同优化，形成数据闭环。
  3. Harness 设计需遵循精准与闭环原则。 核心原则包括信息渐进式披露、工具精简、Context 隔离、以及构建自动化的评估与验证闭环，以实现系统性能的复利增长。

💬 文章金句

  • The Harness is the Dataset. Competitive advantage is now the trajectories your harness captures.
  • Agent = LLM+harness，如果说模型决定了要做什么，Harness 决定了模型能看到什么、能用什么工具，以及失败时该怎么办。
  • 我们认为，在 RL 过程中，coding 环境本身的质量，对模型最终表现的影响是最大的。
