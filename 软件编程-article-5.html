涨价 30 倍仍是最便宜的模型，DeepSeek 可能有这个底气

8/7/2026, 7:52:00 AM

📌 一句话摘要

本文剖析 DeepSeek 在涨价传闻下的低价底气：结合第三方报价、缓存命中率实测与架构设计，论证其缓存优势足以支撑大幅提价，并提出 AI Coding 竞争正从模型智力转向 Harness 体系。

📝 详细摘要

文章围绕 DeepSeek V4 涨价传闻展开。作者先呈现一个反常现象：DeepInfra、百度千帆等第三方平台对 V4 Flash 的报价比官方低约 36%，原因在于权重开源，第三方可自行部署生产 Token，而非亏本转售 API。随后用开发者实测说明订阅服务 OpenCode Go 看似划算（月付 10 美元换约 60 美元额度），但在长会话下实际成本可达官方 API 的 4 倍甚至 10 倍以上，核心差异在缓存命中率。文章进一步用三天两万次请求的测试数据（DeepSeek 缓存 12 小时命中率 100%）与架构拆解（Token-wise Compression + DSA、公共前缀落盘）解释低价护城河，估算官方缓存价仅为第三方约一成，只提高 Cached Read 则需提价约 30 倍才与第三方持平。最后提出独立观点：同款模型在不同 Coding Agent 中表现差异明显，Harness（消息路由、记忆管理、工具调用）可能成为比模型智力更深的护城河。

💡 主要观点

  1. DeepSeek 涨价更像流量调控而非亏损倒逼。 第三方可用开源权重自行部署，报价比官方低约 36%，说明官方成本仍有空间；高智、低价、稳定在当前属于不可能三角，提价可压需求缓过载。
  2. OpenCode Go 在长会话下并不比官方 API 便宜。 实测显示其消耗金额约为官方 API 的 4 倍甚至超 10 倍，主因是缓存命中率的差异；短任务方便，长会话成本会被明显放大。
  3. DeepSeek 的低价底气来自缓存与架构设计。 12 小时缓存命中率保持 100%，V4 的 Token-wise Compression 与 DSA 将 KV Cache 缩小约 8.7 倍，使 0.0028 美元的缓存价几乎等于白送输入 Token。
  4. 同款模型在不同 Coding Agent 中表现差异巨大。 V4 Flash 在 Codex 中可与 Fable 5 基本打平，在 OpenCode 中只发挥约一半水平，差异体现在整体问题理解与长程记忆连贯性。
  5. Harness 可能成为比模型智力更深的护城河。 消息路由、记忆管理与工具调用等能力来自长期工程沉淀且 SDK 不会完整公开，AI Coding 竞争重心正从模型本身转向周边体系。
