斯坦福 CS329Z Agent 课作业解析：从零搭建 Agent Harness

11/21/2026, 12:00:11 AM

📌 一句话摘要

分享斯坦福 CS329Z 工程 AI Agents 课程的第一次作业内容，讲解如何搭建包含循环、工具、记忆的完整 Agent 系统，并通过邮件处理任务进行验证。

📝 详细摘要

本推文分享了斯坦福 CS329Z《Engineering AI Agents》课程的第一次作业，要求从零搭建 Agent Harness——包裹在模型外层，负责调工具、跑循环的程序。作者以公司邮件存档为素材，设计了邮件优先级分类、每日摘要、关键词检索和邮件问答四个模块。作业强调严格测试：非模型测试专查异常处理，模型测试需调用 60 次以上，最后还有角色模拟测试。每次调用都会计账并设预算上限，防止无限循环。作者认为这份作业比教程更实用，测试要求让问题暴露得更彻底。

💡 主要观点

  1. 作业通过邮件处理场景构建完整 Agent 体系 涵盖优先级分类、摘要生成、关键词检索和问答四个功能，验证了 Agent 在实际任务中的可行性和集成效果。
  2. 提出严格的双轨测试方法确保 Agent 稳定性 非模型测试聚焦异常处理，模型测试需高频调用大模型，最后还设置角色模拟测试，有效暴露问题。
  3. 通过计账机制和预算控制防止循环失控 每次模型调用计账，设定上限可自动终止无限循环，提升 Agent 运行的可控性和安全性。
