Chat SDK 将智能体带给你的用户 - Vercel

3/19/2026, 6:32:03 PM

📌 一句话摘要

Vercel 推出了 Chat SDK，这是一个开源的 TypeScript 库，它抽象了各种消息传递 API，使开发者能够一次构建 AI 智能体，并将其部署到 Slack、Discord 和 WhatsApp 等多个平台。

📝 详细摘要

本文宣布了 Vercel Chat SDK 的发布，该框架旨在解决在多个通信平台部署 AI 智能体时遇到的“集成地狱”问题。正如 AI SDK 统一了 LLM 提供商的 API 一样，Chat SDK 为 Slack、Microsoft Teams、Discord、Telegram 和 WhatsApp 等消息平台提供了标准化的接口。它处理了复杂的平台特定挑战，例如实时流式传输回退、通过 JSX 进行 UI 组件渲染（表格、卡片、按钮）以及自动将 Markdown 转换为原生格式。此外，它还支持 Redis 和 PostgreSQL 的可插拔状态管理，并与 Vercel 的 AI SDK 深度集成，实现 LLM 响应的无缝传输。

💡 主要观点

  1. 用于多平台 AI 智能体部署的统一抽象层。 Chat SDK 通过将特定平台的 API 特性抽象为一致的基于适配器的框架，允许开发者编写一次智能体逻辑，并将其部署到 Slack、Discord、WhatsApp 等多个平台。
  2. 自动处理特定平台的 UI 和格式不一致问题。 该 SDK 管理标准 Markdown 和 JSX 组件到平台原生格式（如 Slack 的 Block Kit 或 Discord 的 GFM）的转换，确保在无需手动重构的情况下提供一致的用户体验。
  3. 与 AI 流式传输和状态管理的无缝集成。 它原生支持将 AI SDK 的文本流传输到聊天界面，并为 Redis 和 PostgreSQL 提供可插拔的状态适配器，以处理大规模的线程订阅和分布式锁。

💬 文章金句

  • 与其要求人们主动寻找智能体，我们更需要将智能体带到他们已经在工作的地方。
  • 就像 AI SDK 将模型提供商的 API 统一为一个接口一样，我们构建 Chat SDK 是为了将消息 API 的各种特性抽象为一个简单的框架。
  • 平台特定的行为由适配器处理，因此当你的部署目标发生变化时，你的处理程序无需更改。
  • 你的团队构建的智能体不必只存在于一个平台上。它们可以去往你的用户真正所在的地方。
