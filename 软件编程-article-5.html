Java 近期新闻：Groovy 5.0、Leyden 项目、Helidon MCP、JReleaserLangChain4j

9/14/2025, 6:17:00 AM

📌 一句话摘要

汇总了 Java 生态系统中 OpenJDK、Groovy、Quarkus 等多个项目的最新进展和版本发布。

📝 详细摘要

本文全面概述了 Java 生态系统的近期动态。Leyden 项目发布了早期访问构建版本，旨在通过提前编译（AOT）技术显著改善 Java 程序的启动时间、达到峰值性能的时间和占用空间。Apache Groovy 5.0.0 实现了与 JDK 11 至 JDK 25 的完全兼容，并重构了 groovysh，提供了更强大的终端体验。Quarkus 3.26.0 带来了 Hibernate Reactive 的改进、Dev UI 增强以及 HQL 控制台的重新设计，同时发布了紧急版本修复了关键的 HTTP 客户端连接回归问题。Helidon 团队介绍了其 MCP Server 的技术概况，支持命令式和声明式 API，并运行在虚拟线程 Web 服务器上。其他重要更新包括 Hibernate Validator 9.1.0 Alpha 1 提升了验证性能，Open Liberty 25.0.0.9 Beta 增强了 FIPS 140-3 合规性，JReleaser 1.20.0 改进了 JBang 支持。特别值得关注的是，LangChain4j 1.4.0 正式版新增了对 watson.ai、Azure OpenAI 音频转录和 Anthropic token 计数等 AI 集成功能，进一步拓展了 Java 在人工智能领域的应用。Apache Camel Quarkus 3.26.0 也与 Quarkus 保持同步，带来了相应的更新。

💡 主要观点

  1. Leyden 项目通过 AOT 编译显著提升 Java 应用性能 Leyden 项目发布早期访问构建，旨在通过 AOT（Ahead-of-Time）编译技术，从根本上改善 Java 程序的启动时间、达到峰值性能的时间和占用空间。这对于云原生应用和微服务架构至关重要，能够降低资源消耗并提高响应速度。
  2. Groovy 5.0 提升语言兼容性与开发者体验 Groovy 5.0.0 版本实现了与 JDK 11 到 JDK 25 的完全兼容，确保了其在最新 Java 环境中的可用性。同时，重新设计的 groovysh（基于 JLine 3）提供了更强大的跨平台终端支持、彩色语法高亮和命令补全，显著提升了 Groovy 开发者的工作效率和编码体验。
  3. LangChain4j 1.4.0 强化 Java 在 AI 集成领域的实力 LangChain4j 1.4.0 新增了对 watson.ai、Azure OpenAI 音频转录模型以及 Anthropic token 计数等功能的集成。这标志着 Java 在与主流 AI 模型和平台进行深度集成方面取得了重要进展，为开发者在 Java 生态中构建更智能、更具创新性的 AI 应用提供了强大支持。
  4. Quarkus 等云原生框架持续迭代，优化开发效率与稳定性 Quarkus 3.26.0 带来了 Hibernate Reactive 和 Dev UI 等多项改进，并及时发布了紧急补丁修复了关键的 HTTP 客户端连接回归问题。这体现了云原生框架在不断优化开发体验、提升系统性能和确保应用稳定性方面的持续努力，以满足现代分布式应用的需求。
  5. Java 核心组件及周边工具持续优化，关注性能、安全与发布流程 OpenJDK 的 JEP 522 致力于通过减少同步来提高 G1 GC 的吞吐量，Open Liberty 增强了 FIPS 140-3 合规性，JReleaser 1.20.0 改进了 JBang 支持以简化项目发布。这些更新共同反映了 Java 生态系统在核心技术优化、安全性提升和开发工具链效率方面的全面进步，为开发者提供了更稳定、更高效的开发环境。
