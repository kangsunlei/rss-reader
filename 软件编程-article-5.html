OpenWorkBuddy：本地闭环交付的开源 AI 办公助理

10/12/2026, 12:00:10 AM

📌 一句话摘要

OpenWorkBuddy 是一款本地运行的开源 AI 办公助理，具备自主规划、文件生成与磁盘自我验收能力，并支持主流国产大模型及本地 Claude Code 或 Codex 驱动。

📝 详细摘要

OpenWorkBuddy 是一款运行在本地的 AI 办公助手，直击传统 AI 仅提供大纲而非成品的痛点，能够直接生成可交付的 PPT、Word、Excel 及网页文件。该项目具备自动校验机制，若未在磁盘生成文件会拦截重做；同时支持切换接入 DeepSeek、通义、智谱、Kimi 等模型，或直接复用本机的 Claude Code/Codex 免额外购买 Token，并支持定时任务与多平台快速安装。

💡 主要观点

  1. 端到端生成与自主验收闭环 不同于仅输出文本大纲的对话式 AI，该工具能够直接生成实际可用的办公文档，且在检测到磁盘未写入文件时会当场重做。
  2. 多模型支持与本地引擎复用 界面支持一键切换国产主流大模型，同时能直接接入本地已配置的 Claude Code 或 Codex 作为推理核心，降低 Token 成本。
  3. 自动化办公与低门槛部署 具备定时运行及断点补跑特性（如自动抓取晨报推送飞书），并提供 macOS 和 Windows 的快速安装支持。

💬 文章金句

  • 比较有意思的是它会自己验收，说写了文件但磁盘上找不到，会当场拦下来重做。
  • 本机装了 Claude Code 或 Codex 的，还能直接拿来当发动机，不用另外买 token。
