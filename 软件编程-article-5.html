微软发布 Microsoft 安全副驾驶代理和新的人工智能保护 | Microsoft Security Blog

3/28/2025, 5:11:38 PM

📌 一句话摘要

微软发布安全副驾驶代理和人工智能保护，增强在钓鱼防护、数据安全和身份管理方面的能力。

📝 详细摘要

微软在 Microsoft 安全副驾驶中引入人工智能代理，以自动化安全任务。这些任务包括钓鱼邮件分流、数据丢失防护和身份管理等。例如，钓鱼邮件分流代理可以处理例行的钓鱼警报，漏洞修复代理可以监控漏洞并确定优先级。这些代理与合作伙伴解决方案一起，旨在改进威胁检测、事件响应和安全态势。该公司还宣布在 Microsoft Purview 中推出新的人工智能驱动的数据安全调查，并在 Microsoft Defender 中增强人工智能安全态势管理，将覆盖范围扩展到多云环境，并解决新兴的人工智能威胁。此外，Microsoft Teams 中还增加了新的钓鱼防护，以实现更安全的协作。

💡 主要观点

  1. 安全副驾驶中的人工智能代理可以自动执行安全任务，从而提高效率。 这些代理处理例行警报，从而使安全团队能够从日常警报处理中解放出来，专注于应对更复杂的威胁和采取主动安全措施。
  2. Microsoft Purview 通过人工智能驱动的分析来增强数据安全调查。 人工智能识别敏感数据风险，简化事件调查和缓解流程。
  3. Microsoft Defender 将人工智能安全态势管理扩展到多云环境。 覆盖范围包括 Google VertexAI 和 Azure AI Foundry 模型，从而提供更广泛的可见性和保护。

💬 文章金句

  • 建立人工智能代理是现代安全的一个必要条件。
  • 安全需要团队协作。微软致力于构建开放平台，赋能安全生态系统中的合作伙伴，共同为客户创造价值。
  • 人工智能转型需要强大的网络安全基石。
