📌 一句话摘要

React 中文周刊第 269 期，汇总了三大 SSR 框架性能对比、Aha! 自研 RSC 框架、TanStack Start 性能提升 5 倍、Next.js 16.2 发布、Vercel 服务条款更新等 React 生态热点资讯。

📝 详细摘要

本期 React 中文周刊是一期典型的资讯聚合内容，汇集了 2026 年 3 月中下旬 React 生态圈的热点新闻。核心内容包括：Platformatic 发布的 TanStack Start、React Router 与 Next.js SSR 性能基准测试对比；Aha! 团队分享自研 RSC 框架的技术决策；TanStack Start 宣布 SSR 吞吐量提升约 5 倍；Next.js 16.2 版本聚焦开发者体验与 Turbopack 改进；Vercel 更新服务条款允许免费用户代码用于 AI 训练等。另有 Expo UI、React Native Reanimated DnD 2.0、RevoGrid 等工具库更新，以及 Node.js 安全更新、Bun v1.3.11 发布等行业快讯。整期为链接摘要形式，未包含原创深度分析。

💡 主要观点

  1. 三大 SSR 框架基准测试显示 TanStack Start 性能领先，测试结果推动了框架自身改进。 Platformatic 发布的基准测试在重负载下对比了 TanStack Start、React Router 与 Next.js 的 SSR 性能，测试发现的问题促使维护者修复了框架缺陷，包括对 React 本身的性能优化。
  2. TanStack Start 实现 SSR 吞吐量约 5 倍提升，平均延迟下降约 90%。 TanStack 团队通过深入剖析 SSR 热路径，实现了显著的性能改进，吞吐提升约 5 倍，平均延迟下降约 90%。
  3. Next.js 16.2 聚焦开发者体验，next dev 启动更快、渲染速度提升约 50%。 新版本带来大量 Turbopack 改进和面向 AI 辅助开发的增强，next dev 启动速度和渲染性能均有明显提升。
  4. Vercel 更新服务条款，默认允许免费用户代码用于 AI 模型训练。 付费用户默认关闭此权限，Hobby 用户需手动选择退出。这一变更引发了对开源代码使用边界的讨论。
  5. Aha! 团队选择自研 RSC 框架以满足现有框架无法满足的特定需求。 现代 React 与 Vite 已使自研框架成为可行选项，Josh Wilson 详细拆解了如何从零搭建 RSC 系统。

💬 文章金句

  • 与所有基准测试一样，它们只是某一时刻的快照，很难做到完全准确，真实场景差异也很大。
  • 若你打算深入「自研框架」路线，不妨关注 Nitro v3，现已支持将 Vite 与 React 结合构建服务端应用。
  • 问题不再是「如何生成更多代码」，而是「我们如何更理解正在上线的代码？」
  • 所有仍受维护的 Node.js 大版本将于下周发布安全更新，修复九项漏洞。
