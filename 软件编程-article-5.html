微软发布 Azure DevOps MCP 服务器公开预览版

7/12/2025, 12:00:00 AM

📌 一句话摘要

微软发布 Azure DevOps 模型上下文提供程序 (MCP) 服务器公开预览版，使 GitHub Copilot 能够在开发者环境中使用自然语言交互 Azure DevOps 项目数据。

📝 详细摘要

微软发布 Azure DevOps 模型上下文提供程序 (MCP) 服务器公开预览版，这是一个本地桥梁，允许代理模式下的 GitHub Copilot 访问并交互 Azure DevOps 项目数据。该服务器为 GitHub Copilot 提供结构化的项目信息，如工作项、拉取请求和测试计划作为上下文，使开发者无需离开 IDE（如 VS Code）即可通过对话方式查询、创建和更新项目数据。MCP 服务器在本地运行，确保项目数据保留在开发者网络内，并通过 Node.js 服务和 Azure CLI 身份验证进行集成。此初始预览版支持核心 Azure DevOps 服务功能，包括列出项目和存储库，以及通过自然语言提示创建和编辑工作项与测试用例。此次发布旨在通过最大限度地减少上下文切换来提高开发者生产力。

💡 主要观点

  1. MCP 服务器充当本地桥梁，使 GitHub Copilot 能够访问 Azure DevOps 项目数据。 这使得 GitHub Copilot 能够直接从开发者的环境中理解和交互结构化的项目信息（工作项、拉取请求等），从而提供上下文感知的帮助。
  2. 开发者可以使用 IDE 中的自然语言提示来管理 Azure DevOps 工作流程。 这显著减少了上下文切换，使开发者无需离开 VS Code 或 Visual Studio 即可通过对话方式查询、创建和更新项目数据，从而提高效率。
  3. MCP 服务器在本地运行，确保项目数据安全和合规性。 通过在开发者的本地机器上运行，该服务器可防止敏感的 Azure DevOps 项目数据离开内部网络，从而解决潜在的安全问题。
