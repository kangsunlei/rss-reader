从 AI 取数到智能分析：企业级数据 Agent 的多阶段演进与工程化落地

7/2/2026, 7:29:00 AM

📌 一句话摘要

本文系统复盘 Shopee 构建企业级 Data Agent 的实践，从 Text-to-SQL 准确率不足 40%起步，历经 Multi-Agent、语义模型、工程底座与 Skill 机制五阶段演进，最终将取数工具进化为支持场景化智能分析的可靠生产力工具，强调数据治理与运营闭环的关键作用。

📝 详细摘要

文章基于 Shopee 技术专家王新波在 QCon 2026 北京站的分享，详细回顾了团队打造企业级 Data Agent 的完整技术演进路径。面对 OLAP 场景下 Text-to-SQL 准确率从纸面 90%骤降至 10%的现实，团队通过五次关键跃迁逐步突破：从单链路 RAG 转向 Multi-Agent 加元数据渐进式披露，解决找表不准和体验割裂；引入用户画像与持久化记忆实现个性化响应；通过语义模型和辅助建模 Agent 突破纯大模型准确率天花板；构建包含文件系统上下文与 Sandbox 的工程底座支撑复杂分析；最终引入 Skill 机制实现从取数到场景化分析的跨越。文章还重点分享了元数据治理的 AI 协同四步流程，以及包含评测集建设、线上反馈采集与运营闭环的工程体系。整体呈现了从工具到平台、从 AI 取数到智能分析的完整工程实践，核心价值在于将数据质量、工程底座与运营迭代视为与模型能力同等重要的成功要素。

💡 主要观点

  1. 企业级 OLAP 场景下 Text-to-SQL 准确率远低于学术 Benchmark，从 90%骤降至 10%左右。 学术数据集 Spider 与真实企业场景存在巨大差距，包括表结构相似性、业务语义缺失、语法不兼容等问题，导致纯 RAG 方案落地效果极差。
  2. Multi-Agent 架构配合元数据渐进式披露，是解决找表不准的核心方案。 系统分为 Supervisor Agent 与专业子 Agent 两层，通过三层元数据披露（业务域定位→域内表发现→深度知识展开）将上下文窗口控制在精准范围，辅以两层 Human-in-loop 确认保证推理不偏。
  3. 语义模型作为数据抽象层，是突破大模型 SQL 生成准确率瓶颈的关键。 通过预定义标准指标、维度和过滤条件，将业务概念映射为 DSL，由确定性引擎翻译为 SQL，大幅降低大模型推理负担。同时采用混合 Workflow 根据复杂度路由到 Text-to-SQL 或 Text-to-DSL。
  4. 元数据治理对 Agent 效果提升显著，AI 协同流程使核心表治理效率提升 67%，找表准确率最高提升 15 个百分点。 通过表分组、AI 生成描述、人工审核、血缘扩散的四步流程，以 2000 张核心表治理带动 15 万张表的描述覆盖，且 70%的 AI 生成描述直接被业务采纳。
  5. Skill 机制通过可定制的多步骤分析流程，解决了自由分析的不可信问题。 由数据分析师定义五步归因流程，Agent 严格按照定义执行，中间结果存储在文件系统中，实现步骤可追溯、结果可验证，将资深分析经验沉淀为平台级资产。

💬 文章金句
