最近又刷到 4 个黑科技 GitHub 项目，第 3 个重点看看。

📌 一句话摘要

文章介绍 4 个实用 GitHub 开源项目：ESP32 开发板让 AI 操作 iPhone、geo-sleuth 根据照片找拍摄地、CCBaga 管理 Claude 身份防封、PlayCover 在 Mac 运行 iOS 应用。

📝 详细摘要

本文介绍了 4 个近期热门的 GitHub 开源项目。第一个是 ESP32 iPhone Agent，通过 ESP32-S3 开发板连接视觉大模型与 iPhone，实现 AI 自动操作手机设置闹钟等功能，成本约 7 美元。第二个是 geo-sleuth，作为 Agent Skill 能根据照片中的文字、路牌或风景线索推断拍摄位置，并给出朝向、误差范围和卫星证据。第三个是 CCBaga，Claude 本地身份管理工具，可保存切换账号、清理缓存、统一语言时间设置并检查环境一致性，被开发者当作防封神器。第四个是 PlayCover，最初为运行《原神》开发，现支持在 Mac 上运行 iOS 应用和游戏，并可将触控操作映射为键盘按键，提升操作体验。

💡 主要观点

  1. ESP32 iPhone Agent 通过 7 美元开发板实现 AI 控制 iPhone ESP32-S3 开发板接收 iPhone 屏幕镜像并被识别为 USB 鼠标键盘，手机 App 调用视觉模型分析画面并生成操作指令，配合辅助触控实现自动点击和滑动，可用于设置闹钟等任务。
  2. geo-sleuth 能根据照片线索推断拍摄地点并提供卫星证据 对于含文字的照片通过 OCR 和图片搜索定位；对于风景照则分析山脊轮廓、道路走向、桥梁结构和阴影等线索推断位置，并给出朝向、误差范围和卫星证据图。
  3. CCBaga 是 Claude 本地身份管理工具，可一键清理缓存、轮换指纹并验证环境 支持保存切换多个 Claude 账号、清理浏览器缓存、统一语言时区设置、检查浏览器与网络环境一致性，因具备一键清理加指纹轮换功能被开发者当作防封方案。
  4. PlayCover 最初为运行《原神》开发，现支持在 Mac 运行 iOS 应用并映射触控操作 可将屏幕上需要触控的操作映射为键盘按键（如 WASD 移动、鼠标控制视角），提升手机游戏在电脑上的操作体验，但具体兼容性取决于游戏和版本。

💬 文章金句

  • 给它一句任务，它会看着屏幕一步步点击、滑动
  • 开发板价格大概是 7 美元
  • 即使没有文字，这个 Skill 也会教 Agent 去看山脊轮廓、道路走向、桥梁结构和阴影
  • 因为它能一键清理+指纹轮换+环境验证，很多人就用它当做 Claude 防封的神器了
  • PlayCover 最初其实为了想在 Mac 上运行《原神》开发，后来才不断扩展的
