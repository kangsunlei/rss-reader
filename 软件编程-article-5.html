效果惊艳！MiniCPM5-2B 开源了！

9/8/2026, 4:05:00 AM

📌 一句话摘要

面壁智能开源 MiniCPM5-2B 端侧模型，以 2B 参数实现 4B 以下最强性能，并同步开源训练数据与框架，初步形成端侧通用 Agent 能力。

📝 详细摘要

面壁智能开源了 MiniCPM5-2B 高密度端侧语言模型，参数仅 2B，却在 Artificial Analysis 榜单上位列全球 4B 以下开源模型第一，多项基准超过 4B 甚至更大模型。模型在代码智能体（SWE-bench Verified 46.4）、长文本理解（AA-LCR 59.0）和工具调用（τ²-Bench Telecom 97.1）等 Agent 相关任务上表现突出，并支持思考模式。面壁智能同时开源了训练数据（UltraData-Code、UltraData-SFT-Agent-2609、UltraData-RL-2609、UltraX-Preview）和强化学习框架 Meshy 及算法 JustRL II，展示了从预训练到后训练全链路围绕 Agent 优化的思路。文章还介绍了本地部署方法（Ollama、LM Studio、vLLM 等）及将部署技能集成到 Claude Code 等 Agent 工具的方式。作者认为这标志着端侧通用 Agent 能力的雏形，并强调开源训练数据的价值大于权重开源。

💡 主要观点

  1. MiniCPM5-2B 以 2B 参数实现 4B 以下最强性能，Agent 能力尤为突出。 在 Artificial Analysis 榜单上排名 4B 以下开源模型第一，SWE-bench Verified 46.4、AA-LCR 59.0、τ²-Bench Telecom 97.1，远超同尺寸模型，初步形成端侧通用 Agent 能力。
  2. 面壁智能从预训练阶段就围绕 Agent 优化训练链路。 通过预训练数据注入、监督微调和大规模强化学习，使 2B 模型具备工具调用、深度搜索、代码生成等 Agent 能力，可在本地端侧设备运行。
  3. 开源训练数据与框架，透明度极高。 除模型权重外，还开源了 UltraData 系列数据集（含代码、Agent 轨迹、RL 数据）和 UltraX 数据精炼工具，以及 RL 框架 Meshy 和算法 JustRL II，便于社区复现和优化。
  4. 本地部署门槛低，且支持主流推理框架与 Agent 集成。 可通过 Ollama、LM Studio 等工具快速部署，支持 vLLM、SGLang、llama.cpp 等框架，并提供部署/微调 Skill 集成到 Claude Code、Cursor 等 Agent 工具。
  5. 作者认为开源训练数据的价值大于权重开源。 数据治理和训练调优是各家核心技术，面壁智能公开训练配方与数据，为社区提供了可优化的基础，有望推动更多团队跟进，加速端侧 AI 落地。

💬 文章金句

  • 一旦涉及到让 Agent 调用工具、查资料、执行命令这些多步任务就会掉链子。
  • 初步来看端侧通用 Agent 能力的雏形已形成。
  • 数据在本地，而且离线也能运行，最重要是没有了按 Token 计费的那种焦虑。
  • 比起模型权重开源还有一层更大的价值，那就是这次面壁智能开源的训练数据。
  • 这种能把权重和数据都公开的做法，简直大气，相信往后会有越来越多的团队跟进。
