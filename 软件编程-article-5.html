不靠低价抢客户，月之暗面 Kimi 出海，凭什么硬刚海外 AI“御三家”？

6/28/2026, 2:15:00 AM

📌 一句话摘要

本文通过专访月之暗面 Kimi B 端负责人，揭示其以 All in one 高性能模型差异化策略、借助 AWS 渠道加速全球化，并坚持生产力导向、不做娱乐化的 B 端出海路径。

📝 详细摘要

文章深入报道了月之暗面 Kimi 在 C 端爆款之外的 B 端模型服务与全球化布局。Kimi B 端负责人黄震昕明确表示不做低价竞争，而是聚焦高性能 All in one 模型——将视觉理解、Coding 和 Agent 能力融合在一个模型中，实现视觉到代码的跨模态能力。在全球化方面，Kimi 选择与亚马逊云科技深度合作，通过 Marketplace 和 Bedrock 两种路径触达全球企业，并借助其行业经验与合规体系补齐最后一公里。技术路线上，Kimi 坚持 Scaling Law 持续向前，在底层架构进行 Muon 优化器、注意力残差、Kimi Linear 等创新，并通过高 Cache 命中率控制成本。B 端业务构建了从基础模型、API、Agent SDK 到企业产品的分层服务体系，重点聚焦 Coding 与 Agent 场景，不做娱乐化应用。

💡 主要观点

  1. Kimi 坚持 All in one 模型路线，融合视觉、编码与 Agent 能力。 与将视觉作为外接模块的模型不同，Kimi 在预训练阶段即混合视觉与文本数据，实现 Visual-to-Code 等跨模态能力，提升在程序员 Debug 等场景的实用性。
  2. 通过 AWS 渠道全球化，以“飞轮”模式拓展企业客户。 Kimi 同时采用 Marketplace 标准化采购和 Bedrock 基础设施级托管两种路径，利用亚马逊云科技的全球基础设施、行业经验与合规体系，优化分发效率且不加重自身交付负担。
  3. 坚持生产力导向，布局分层 B 端服务体系。 B 端业务从底层模型到上层企业产品层层递进，包括模型 API、搜索 API、PPT API 以及 Agent SDK 和企业版 Kimi，当前主推 Coding 和 Agent 场景。
  4. 底层技术创新驱动效率与成本优化。 Kimi 采用 Muon 优化器、注意力残差、Kimi Linear 等创新提升模型效率与长序列计算能力，并通过 Cache 命中率（超过 90%）显著降低实际使用成本。
  5. 坚信 Scaling Law，布局 Loop Engineering 以降低对 Harness 的依赖。 Kimi 认为基础模型变强可兼容更多环境，从而简化外部 Harness；内部已开始实践更简洁的 Loop Engineering，代表模型工程的新阶段。

💬 文章金句

  • 我们的定位并不是做最便宜的模型，而是希望做最高性能的模型。
  • 只有在底层架构上实现突破，才能做更大的模型，才能让 Scaling Law 持续向前。
  • 只要 Cache 命中，成本就会显著降低。
