“开发 Linux 是业余爱好”？内核开发者：这是 Linus 唯一的错话，曾被忽视、嘲笑的 OS 打破“未来全是 Windows”的幻想！

10/7/2025, 7:34:00 AM

📌 一句话摘要

资深内核开发者 Jonathan Corbet 回顾了 Linux 从“业余爱好”到全球主导操作系统的 34 年发展历程，并展望了未来挑战。

📝 详细摘要

文章整理了 Linux 资深内核开发者 Jonathan Corbet 在欧洲开源峰会上的演讲内容，深度回顾了 Linux 内核从 1991 年诞生至今的非凡发展。文章将 Linux 的成长分为“被无视”、“被嘲笑”、“战斗与抗争”和“赢得胜利”四个阶段，详细阐述了每个阶段的关键事件和从中汲取的经验教训。初期 Linux 因被视为“玩具”而遭忽视，但其独特的开放开发流程、GPL 许可证和内核与用户空间分离的模块化设计，使其建立了强大的社区并迅速成长。面对微软的嘲笑和 SCO 的法律诉讼，Linux 社区展现出惊人的韧性，并通过 BitKeeper 事件催生了 Git。文章还强调了开发工具、尽早集成变更、以及“上游优先”原则的重要性。最后，Corbet 指出了 Linux 未来面临的挑战，包括社区多元性不足、维护者支持、开发工具现代化（特别是 AI 工具的整合）以及编程语言的选择（转向 Rust）等，呼吁社区持续改进以应对未来的发展。

💡 主要观点

  1. Linux 的持续成功源于其独特的开放开发流程和强大的社区协作模式。 通过接受任何补丁、GPL 许可证避免碎片化、内核与用户空间分离的模块化设计，Linux 构建了一个强大且独立于任何公司的社区，是其长期发展的基石。
  2. Linux 在面对外部挑战和商业化冲击时展现出惊人的韧性与适应能力。 面对微软的嘲讽、SCO 的诉讼、互联网泡沫破裂以及 BitKeeper 的许可证撤销，Linux 社区通过坚守原则、创新工具（如 Git）和专业化管理基础设施，克服了重重困难，并从中吸取教训。
  3. 未来的 Linux 开发需要关注多元性、维护者支持、工具革新和编程语言现代化。 社区需解决多样性不足和维护者倦怠问题，并积极探索 AI 工具的整合和向 Rust 等更安全编程语言的过渡，以吸引新一代开发者并保障长期发展。

💬 文章金句

  • 我想我们可以得出一个结论：林纳斯·托瓦兹说错了，而且这恐怕是有史以来唯一一次。Linux 确实变得既庞大又专业。
  • 你的开发流程决定了项目的成长潜力。你如何组织项目、如何接受他人的贡献，将直接影响项目的成功与否。
  • Linux 的生命力在很大程度上独立于任何公司。它不被任何公司拥有，也不受任何公司控制。
  • 专有软件是不稳定的基础。如果依赖别人的平台，就会受制于他们的意愿，他们迟早可能利用这一点对付你。
  • 我相信，如果不改变这一点（C 语言选择），将越来越难吸引新一代开发者加入。
