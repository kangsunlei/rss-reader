CheckMyGit：一键将 GitHub 账号变成漂亮个人主页

5/4/2026, 11:26:00 AM

📌 一句话摘要

一个基于 SvelteKit 的开源工具，输入 GitHub 用户名即可生成包含贡献热力图、语言占比图和置顶项目的个性化展示页。

📝 详细摘要

该推文介绍了一个名为 CheckMyGit 的开源工具，它利用 SvelteKit 框架开发，部署在 Cloudflare Pages 上。用户无需注册，只需输入 GitHub 用户名，即可生成一个美观的个人主页。该工具提供三种展示样式：侧边栏风格、网格风格和简约简历风格。核心功能包括展示 GitHub 贡献热力图、编程语言占比统计、置顶项目列表，并支持导出为 PNG 图片或生成分享链接。这是一个实用性强、上手简单的开发者个人品牌展示工具。
