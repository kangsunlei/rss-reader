AI 智能体如何将 Vercel 的设计流程转化为工程实践

2/21/2026, 2:54:06 AM

📌 一句话摘要

Vercel CEO Guillermo Rauch 详细介绍了设计师如何利用 v0 和 Claude Code 等 AI 工具构建内部工程智能体，特别是名为 “Leap” 的社交媒体素材生成工具。

📝 详细摘要

Guillermo Rauch 强调了一个战略性的转变：设计流程正在演变为一门工程学科。Vercel 的设计师们正利用 v0、Claude Code 和 Cursor 等 AI 驱动的开发工具来构建功能性的内部工具。一个核心案例是 “Leap”，这是一个内部智能体 (Agent) 和 Web UI，能够自动创建和预览 X 平台上的社交分享卡片。这一转变使设计从手动创建素材转向构建自助式系统，在无需传统长期规划或“冲刺 (sprint)”的情况下，显著提升了效率和质量。
