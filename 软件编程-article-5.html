📝 详细摘要

本期早报精选了 10 条 AI 与工程前沿动态。重点包括：OpenAI 发布模型失准公开报告框架以提升安全透明度；Matt Pocock 提出从战术编程转向工程决策，利用 Spec 和 Ralph loop 管理复杂任务；GitHub 分享将 Copilot runtime 从 Node.js 迁移至 Rust 的原子变更实践；此外，还涵盖了阿里、字节、腾讯、美团在 Agent 评测、经验记忆和 Token 优化方面的工程实践，以及智谱 AI 的 RSI 成果和 Homa 协议对 AI 网络延迟的优化。

💡 主要观点

  1. AI 编程应从简单的代码生成转向工程决策 通过 grill-me 追问边界，将结论沉淀为 Spec 和 Ralph loop，确保大任务在干净的上下文中分段推进，避免长上下文导致的关系丢失。
  2. 大规模运行时迁移应采取原子变更策略 GitHub 在 Copilot runtime 迁 Rust 过程中，通过 128 个 PR 逐步替换组件，利用端到端测试校验并保持行为契约，而非整体改写。
  3. AI 集群网络需解决 TCP 的延迟瓶颈 TCP 在 incast 和队头阻塞下失效，基于消息的 Homa 协议可将短消息 P99 延迟降低约 13 倍，适应 AI 推理的高频小消息负载。
