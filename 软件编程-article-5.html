LongCat 开源 VitaBench 2.0：长期动态智能体基准新标杆

6/30/2026, 6:42:04 AM

📌 一句话摘要

本文介绍美团开源的 VitaBench 2.0，首个评估大语言模型在长期动态用户互动中个性化与主动性能力的智能体基准，并揭示时间遗忘、高智商不等于高情商、AI 缺乏主动沟通等核心洞察。

📝 详细摘要

文章详细介绍了美团 Longcat 团队开源的 VitaBench 2.0 基准，这是首个面向长期动态用户建模的智能体评测基准。基准包含 56 名基于真实统计构建的虚拟用户、819 个复杂任务、超 2000 个动态偏好及 66 个可执行工具，平均每位用户拥有 2093 个交互事件，时间跨度长达 1580 天。文章从设计原理出发，阐述了三维创新：搭建包含完整生活轨迹的「人生副本」、引入长时间轴持续评测用户理解、设立 Agentic Memory 与 RAG Memory 两种记忆模式的统一评测平台。实验核心洞察包括：所有模型性能随时间显著衰减；开启思考模式在个性化任务上不总是有益；模型在主动性任务上得分断崖式下跌；即使直接告知真实偏好，多数模型仍无法正确应用；随着基础能力提升，个性化已成为当前 Agent 的最大瓶颈。文章最后总结了 VitaBench 2.0 推动的评测范式演进，并提供了开源链接。

💡 主要观点

  1. VitaBench 2.0 是首个面向长期动态用户建模的智能体评测基准。 它包含 56 名真实的虚拟用户、819 个复杂任务和超 2000 个动态偏好，时间跨度长达 4.3 年，系统评测 AI 在持续互动中的个性化与主动性能力。
  2. 时间越长模型性能下降越明显，记忆机制并未成为有效解药。 实验显示所有模型性能随任务序列索引（时间）增加而衰减，且接入 Agentic Memory 或 RAG Memory 后性能反而低于全历史记录场景，说明记忆的更新、检索和利用仍是难题。
  3. 开启思考模式在个性化任务上并不总是有帮助。 与常见假设相反，开启模型的思考模式并未稳定提升个性化任务表现，表明高「智商」（推理能力）不等于高「情商」（理解用户偏好）。
  4. AI 普遍缺乏主动提问的意愿，在主动性任务上表现断崖式下跌。 所有模型家族在需要主动提问的任务上得分大幅下降，例如 Claude 家族从平均 46.0 降至 27.4，说明 AI 倾向于「想当然」而非在不确定时多问一句。
  5. 即使直接告知用户真实偏好，多数模型仍无法正确应用。 分离「提取偏好」与「利用偏好」的实验表明，即便把真实偏好「喂到嘴边」，在高压、多约束的决策场景中正确应用偏好本身仍是巨大挑战，个性化已成当前 Agent 最大瓶颈。

💬 文章金句

  • VitaBench 2.0 是首个真实生活场景下面向长期动态用户建模的智能体评测基准，它系统性地评测大语言模型在长期、真实、动态的用户互动中个性化与主动性的能力。
  • 记忆不是装上就好，如何正确更新、检索和利用，才是真正的挑战。
  • 即便把真实偏好直接告诉模型，多数模型仍然失败。这说明，即使拥有了准确的用户画像，在高压、多约束的决策中正确应用这些偏好，本身就是一个巨大的挑战。
  • 随着模型基础能力的提升，个性化已是当前 Agent 的最大瓶颈。
