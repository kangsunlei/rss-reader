GitHub 安全公告数据库数据解读：已知安全漏洞及应对措施

6/27/2025, 4:00:00 PM

📌 一句话摘要

GitHub 安全公告数据库(GitHub Advisory Database)分析显示，2024 年经过审核的安全公告数量显著增长至 20，000 余条，借助通用漏洞评分系统(CVSS)和漏洞利用预测评分系统(EPSS)等工具可帮助优先处理开源安全中的关键漏洞。

📝 详细摘要

GitHub 安全公告数据库从 2019 年不足 400 条审核公告增长至 2024 年的 20，000 余条，现已成为保障开源安全的关键资源。GitHub 将该数据库中的公告分为已审核（人工验证）、未审核（来自国家漏洞数据库(NVD)）和恶意软件类型，其中 Maven（Java 包管理工具）和 Composer（PHP 包管理工具）软件包占所有公告的近半数。仅 2024 年，GitHub 的公告数量就增长了 39%，作为 CVE 编号颁发机构(CNA)发布了 2，000 多条通用漏洞披露(CVE)记录，并引入了 CVSS 评分和 EPSS 等优先级工具，帮助开发者聚焦最关键漏洞（15% 为严重级别，35% 为高危级别）。文章还详细介绍了覆盖 12 个包管理器的生态数据来源，从最大的 NVD 到 Python 包权威机构(PyPA)和 Rust 安全公告数据库(RustSec)等专业生态源。

💡 主要观点

  1. GitHub 安全公告数据库呈现指数级增长与生态变迁 已审核公告从 2019 年 <400 条增长至 2024 年 >20，000 条，生态主导从 npm（Node.js 包管理器）转向 Maven/Composer（现占近 50% 公告量）
  2. 多源公告提供全面覆盖 国家漏洞数据库（最大来源）、GitHub 仓库公告及 Python 包权威机构、Rust 安全公告数据库等专业源共同提供 85% 覆盖率，平均每个公告 ≤3 个来源
  3. GitHub 在漏洞披露中发挥重要作用 作为 CVE 编号颁发机构，GitHub 在 2024 年发布 2，000+ 个 CVE（第五大 CNA），其中 58% 属于支持生态
  4. 优先级工具助力应对漏洞泛滥问题 CVSS 评分（50% 公告为高危/严重）和 EPSS（聚焦 7% 利用概率 >10% 的漏洞）实现高效修复
  5. 跨站脚本攻击(XSS)仍是首要漏洞类型 CWE-79（跨站脚本）领跑 2024 年公告（936 例），其次是敏感数据泄露（CWE-200）和路径遍历（CWE-22）

💬 文章金句

  • 过去五年间，该数据库从 2019 年不足 400 条审核公告增长至 2024 年的 20，000 余条。
  • 2024 年来自各源的公告数量显著增长（39%）...源于发布的 CVE 记录数量增加。
  • Maven 和 Composer 软件包占数据库近半数公告...npm、pip（Python 包管理器）和 Go 语言构成其余主要部分。
  • GitHub 在 2024 年发布超 2，000 条 CVE 记录，成为 CVE 计划中第五大编号颁发机构。
  • 根据这些评级，半数漏洞（15% 为严重，35% 为高危）需要立即或近期处理。
  • CWE-79（网页生成期间输入净化不当）在 2024 年涉及 936 条公告——最常见的漏洞类型。
