Elastic 9.0/8.18：BBQ、EDOT 和 LLM 可观测性、攻击发现、自动导入以及 ES|QL JOIN

4/15/2025, 3:28:46 PM

📌 一句话摘要

Elastic 发布 9.0 和 8.18 版本，带来 BBQ、EDOT、LLM 可观测性等一系列性能和安全增强功能。

📝 详细摘要

Elastic 发布了 9.0 和 8.18 版本，这两个版本都带来了重要的更新，主要集中在性能提升、可观测性和安全性增强三个方面。Elastic 9.0 基于 Lucene 10.0，利用其内置的并行处理、智能索引和硬件优化等改进，显著提升了性能和效率。8.18 版本也引入了 9.0 中的许多新功能，如更好的二元量化 (BBQ)、Elastic OpenTelemetry 分布 (EDOT) 和 ES|QL LOOKUP JOIN。Elastic Cloud Serverless (弹性云无服务器) 提供了快速启动和扩展的部署选项。主要亮点包括：更好的二元量化 (BBQ) 性能提升 5 倍，Elastic OpenTelemetry 分布 (EDOT) 和 LLM 可观测性为 GenAI 应用提供可见性，攻击发现和自动导入增强了 AI 驱动的安全分析，ES|QL 增加了强大的数据连接功能。这些更新覆盖了 Elasticsearch、可观测性和安全等多个方面，旨在提升用户体验和效率。

💡 主要观点

  1. 更好的二元量化 (BBQ) 显著提升了性能 BBQ 技术在 Elastic 9.0 中正式发布，相比 OpenSearch，性能提升高达 5 倍，适用于大型生产工作负载。
  2. Elastic OpenTelemetry 分布 (EDOT) 增强了可观测性 EDOT 使用 OpenTelemetry 原生模式，跨所有信号增强了关联和分析能力，并提供企业级支持。
  3. LLM 可观测性提供了 GenAI 应用的全面洞察 LLM 可观测性提供了对 LLM 性能、错误、提示、响应、使用情况和成本的全面洞察，支持 Amazon Bedrock、Google Vertex AI、Azure OpenAI 和 OpenAI。
  4. ES|QL 增强了数据查询和连接能力 ES|QL 在数据查询和连接方面进行了增强，解决了安全分析师和检测工程师需要从安全数据中获取上下文的许多数据丰富用例。

💬 文章金句

  • A cutting edge quantization technique designed at Elastic that was first introduced in 8.16 as a technical preview， **Better Binary Quantization (BBQ)**， is now generally available for large production workloads with an updated algorithm that provides even better performance and relevance gains.
  • Elastic Distributions of OpenTelemetry (EDOT) is now generally available (for 9.0 only)， using OpenTelemetry-native schemas across all signals for enhanced correlation and analysis and enterprise-grade support without proprietary add-ons.
  • Attack DiscoveryandAutomatic Importare now generally available， empowering SecOps teams with AI-driven security analytics.
  • The technical preview of **ES|QL LOOKUP JOIN** introduces a join capability in ES|QL that solves many data enrichment use cases common to security analysts and detection engineers who need to gain context from their security data.
