Mellum：JetBrains 代码补全模型的训练之路

4/24/2025, 12:45:44 PM

📌 一句话摘要

本文介绍了 JetBrains 自研代码补全模型 Mellum 的训练过程和评估方法。

📝 详细摘要

本文详细介绍了 JetBrains 如何训练其代码补全模型 Mellum。文章分析了直接使用现有大型语言模型的局限性，阐述了 Mellum 模型的训练过程，包括预训练、上下文感知微调和使用 RLAIF 进行优化的三个阶段。预训练阶段使用了 TheStack 数据集，并通过 FIM 技术提高模型对代码上下文的理解。微调阶段则通过 Code Engine 工具收集上下文信息，并针对不同编程语言进行专门优化，该工具在上下文信息收集方面起到了关键作用。最后，通过 RLAIF 方法，使用规则和模型生成的反馈来提升代码质量，从而减少无意义代码的生成。文章还介绍了 Mellum 模型的评估方法，包括内部基准测试和公共基准测试，以及在线评估指标 RoCC 和 AR。最后，文章展望了 Mellum 模型未来的发展方向，包括扩展参数规模和支持更多 AI-for-code 任务。

💡 主要观点

  1. Mellum 通过上下文感知微调提升代码补全效果 通过 Code Engine 工具收集工程上下文信息，使模型能够更好地理解代码结构和依赖关系，生成更准确的建议。
  2. Mellum 通过三阶段训练过程实现高质量代码补全 包括预训练、上下文感知微调和 RLAIF 优化，每个阶段针对特定问题，逐步提升模型性能和代码质量。
  3. RLAIF 方法有效提升代码质量和用户满意度 通过规则和模型生成的反馈，模型能更好地识别和避免生成无意义或低质量的代码片段。

💬 文章金句

  • JetBrains 的优势在于其在符号解析、用法搜索等 IDE 工具方面的专业积累。
  • 我们假设像我们这样的小模型可以从专业化中受益匪浅。
  • 编辑器中出现的生成文本越多，我们的代码补全就越好。
