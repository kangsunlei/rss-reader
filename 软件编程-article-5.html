Proxmox PVE 9.0 正式发布：基于 Debian 13，核心组件全面升级

8/5/2025, 2:56:22 PM

📌 一句话摘要

Proxmox Virtual Environment (PVE) 9.0 版本已正式发布，新版基于 Debian 13，并对 Linux 内核、QEMU、LXC、ZFS 和 Ceph 等核心组件进行了同步升级。

📝 详细摘要

这条推文宣布了 Proxmox PVE 9.0 的正式发布。新版本基于最新的 Debian 13 "Trixie"，带来了更稳定的 Linux 内核 6.14.8-2，并全面升级了虚拟化和存储相关的核心组件，包括 QEMU 10.0.2、LXC 6.0.4、ZFS 2.3.3 以及 Ceph Squid 19.2.3。这对于使用 Proxmox 进行虚拟化管理的用户来说是一个重要的更新，预示着系统性能、稳定性和功能将得到显著提升。
