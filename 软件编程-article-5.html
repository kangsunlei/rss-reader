TinyShip 的 Cloudflare Worker 版本完成全量 E2E 测试并计划独立轻量仓库

7/21/2026, 1:28:22 PM

📌 一句话摘要

Viking 发现 Cloudflare Worker 的 nodejs_compat 对标准 Node.js 应用存在兼容性问题，已在 TinyShip 中完成全量 E2E 测试并计划将 CF 专用代码拆分为轻量独立仓库。

📝 详细摘要

Viking 在将 TinyShip 的 Cloudflare Worker 版本进行全量端到端（E2E）测试时，发现一些旧依赖中仍存在 eval() 或 new Function() 等不兼容 Node.js 的代码，于是进行了相应的更新和修复。目前该版本已经支持 tanstack 框架的 Node.js 和 Cloudflare Worker 两种运行环境，以及两种数据库，每次代码更新都会让自动化 Agent 运行 8 轮验证以确保全部通过。他计划将仅适用于 Cloudflare Worker 的代码 fork 出一个独立的轻量级仓库，以便只需要 CF 环境的用户可以直接使用。未来 TinyShip 不仅会保持基础模板，还会基于作者的真实项目经验在此基础上开发更多实际用例。
