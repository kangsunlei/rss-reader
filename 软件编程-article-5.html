BigQuery 数据传输服务增强

11/21/2025, 12:00:00 AM

📌 一句话摘要

谷歌云 BigQuery 数据传输服务扩展了连接性，包括新的正式版/预览版连接器；同时，该服务还增强了安全性和合规性，改善了用户体验，并引入了基于消耗的定价。

📝 详细摘要

本文详细介绍了谷歌云 BigQuery 数据传输服务的重大增强。该服务是一种全托管解决方案，旨在自动执行并简化从各种来源向 BigQuery 加载数据的过程。主要更新包括连接器生态的显著扩展，为关键的运营数据库（如 Oracle）、客户关系管理系统（如 Salesforce）、营销平台（如 Salesforce 营销云和 Facebook 广告）以及分析工具（如 Google Analytics 4）提供了新的正式版连接器。此外，还引入了金融平台（Stripe、PayPal）和迁移场景（Snowflake、Hive 管理表）的新的预览版连接器。该服务还拥有强大的安全性和合规性增强功能，包括访问透明性、欧盟数据边界支持、FedRAMP High（联邦风险与授权管理计划高级别），以下简称 FedRAMP High 和 CJIS 合规性（刑事司法信息服务合规性），以及自定义组织策略和区域端点。通过 BigQuery 中直观的“添加数据”用户界面（UI）以及新项目的默认应用程序编程接口（API）启用，简化了用户体验。最后，宣布了第三方连接器新的基于消耗的定价模型，在正式发布后提供有竞争力的定价，同时保持预览版连接器免费。这些更新旨在简化数据集成，增强受监管工作负载的安全性，并为各种数据源提供经济高效的解决方案。

💡 主要观点

  1. BigQuery 数据传输服务显著扩展了其连接器生态。 通过新增的正式版连接器（Oracle、Salesforce、GA4 等）和预览版连接器（Stripe、PayPal、Snowflake、Hive），该服务能够从运营、营销和金融等多种来源摄取更广泛的数据。
  2. 增强的安全性和合规性功能支持高度监管的工作负载。 访问透明性、欧盟数据边界、FedRAMP High 和 CJIS 合规性以及自定义组织策略等新功能可满足严格的安全性和数据驻留要求。
  3. 通过直观的用户界面（UI）和默认 API 启用，简化了用户体验。 “添加数据”向导简化了数据加载，默认 API 启用消除了手动设置步骤，从而加快了从数据工程师到新分析师的所有用户获得见解的速度。
  4. 为第三方连接器引入了新的基于消耗的定价模型。 此模型为正式版连接器提供有竞争力的、基于使用量的计费，同时保持预览版连接器免费，从而确保成本效益和对平台的持续投资。

💬 文章金句

  • 这项新功能将访问透明性控制应用于客户定义属性的读取以及可能用于识别客户或客户工作负载的任何客户服务配置。
  • BigQuery 用户界面（UI）中的“添加数据”体验现在提供了一个单一、简化的入口点，以指导您完成数据加载过程。
  • 在预览阶段，所有连接器仍然完全免费。这使您可以测试、试验和验证新的集成，而无需任何经济承诺。
