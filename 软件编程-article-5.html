商汤开源 SenseNova U1 V3：支持 AI 信息图编辑与自主迭代

7/17/2026, 10:00:02 AM

📌 一句话摘要

商汤在 GitHub 上开源了 SenseNova U1 V3，新增信息图编辑功能并计划加入自主迭代能力。

📝 详细摘要

两个月前，商汤在 GitHub 上悄然开源了信息图神器 SenseNova U1。该项目支持一键生成各种精美海报、图表、食谱卡片、明信片以及 arXiv 风格的页面。最近，增强版 V3 正式发布，首次加入了信息图编辑能力，支持高精度调整局部文字和整体风格，AI 修改后的文字会自动适配原图像的设计风格与排版，使用户能够在保留核心信息与结构的同时换取不同品牌、主题与传播场景的视觉表达。此外，模型权重、GitHub 文档和魔搭社区链接均已提供，且下一步计划融入自主迭代能力，让模型在生成信息图后自主检查并纠错，持续优化结果。
