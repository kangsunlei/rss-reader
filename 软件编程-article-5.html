全球首例全自动 AI 勒索攻击曝光

7/4/2026, 10:00:00 AM

📌 一句话摘要

Sysdig 威胁研究团队记录了首个全程由 LLM 驱动的勒索软件攻击行动 JADEPUFFER，攻击者利用 Langflow 漏洞、默认凭证和 Nacos 认证绕过实现自主入侵、横向移动、数据加密与销毁的全链路攻击。

📝 详细摘要

本文报道了 Sysdig 威胁研究团队发现的首个端到端 AI 驱动的勒索软件攻击行动 JADEPUFFER。攻击链从 Langflow 的 CVE-2025-3248 身份认证缺失漏洞切入，窃取云 API 密钥与数据库凭证后横向移动至 MinIO 对象存储，最终以 Nacos 配置服务的多个已知漏洞攻入生产 MySQL 数据库，完成 1，342 项服务配置的 AES 加密并销毁原始数据。Sysdig 通过自我注释风格、31 秒内自主修正错误的机器级速度、对比特币开发者文档示例地址的使用等四条证据链，论证该攻击全程由 LLM Agent 自主驱动，无需人类操作者对任何单一步骤具备深厚专业知识。

💡 主要观点

  1. JADEPUFFER 是首个被完整记录的全流程 AI 驱动勒索攻击行动。 攻击从漏洞利用到数据加密销毁全程由 LLM Agent 自主完成，无需人类操作者深度介入任何单一步骤，颠覆了勒索软件攻击依赖高技术人才的传统认知。
  2. 攻击链利用多个已知漏洞和默认凭证串联形成完整杀伤链。 从 Langflow 未修补的 CVE-2025-3248，到 MinIO 默认凭证 minioadmin:minioadmin，再到 Nacos 的 CVE-2021-29441 认证绕过和 2020 年公开的默认 JWT 签名密钥，每个单点技术均非首创，但串联能力前所未有。
  3. LLM 在攻击中展现出自主诊断与修正能力。 首个后门账户插入因子进程 PATH 问题失败后，LLM 在 31 秒内自动诊断原因、删除错误账户、修正 payload 并重新执行，最终成功登录，全程无需人工干预。
  4. Sysdig 通过四条证据链确认攻击的 AI 驱动属性。 包括一次性命令的自我注释风格、机器级故障修正速度、对文件名上下文的理解，以及使用比特币核心代码库中的示例地址作为勒索收款地址。
  5. 防御建议聚焦基础安全实践：打补丁、改默认凭证、不在 AI 服务器存密钥。 攻击中使用的所有技术均为已知问题，防御核心在于及时修补、凭证管理和网络暴露控制。

💬 文章金句

  • 勒索软件不再需要高技术人才——LLM Agent 可在操作者不精通任何单一步骤的情况下，自主完成侦察、凭证窃取、横向移动、持久化和破坏。
  • 曾经暗示人类能力的攻击手法，现在可能只是模型能力的体现。
