Anthropic 为 Claude Code 推出全新的“自动模式”

3/7/2026, 4:19:13 PM

📌 一句话摘要

Levelsio 对 Anthropic 宣布的 Claude Code 自动模式（Auto Mode）研究预览版表示赞赏，该功能旨在简化开发者的工作流程。

📝 详细摘要

这条推文引用了 Anthropic 的一项重大更新：Claude Code 的“自动模式”。该功能旨在消除长时间编码过程中重复的权限确认提示，允许 AI 自动处理特定操作，同时保持对提示词注入（Prompt Injections）等威胁的安全防护。目前该功能处于研究预览阶段，建议在沙盒（Sandboxes）等隔离环境中运行。
