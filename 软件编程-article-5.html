📝 详细摘要

该推文介绍了一款用 Rust 编写的轻量运行时，旨在作为 Docker Desktop / OrbStack 的平替。它在跨平台（macOS、Windows、Linux）上运行，兼容现有的 Docker CLI、Compose 和 buildx，容器通过小型 Linux VM 实现。

💡 主要观点

  1. 跨平台轻量运行时 基于 Rust 开发，支持 macOS、Windows 和 Linux，提供更轻量的容器运行体验。
  2. Docker 生态兼容 完全兼容 Docker CLI、Compose 和 buildx，使用现有工作流无需额外适配。
  3. 小型 Linux VM 架构 容器运行于内部小型 Linux 虚拟机中，显著降低资源占用。
