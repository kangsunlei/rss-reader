ML Kit Prompt API｜赋能设备端 Gemini Nano，打造专属定制体验

12/25/2025, 10:11:00 AM

📌 一句话摘要

谷歌发布 ML Kit GenAI Prompt API Alpha 版，允许开发者在 Android 应用中通过 Gemini Nano 实现自定义、高隐私保护的设备端生成式 AI 功能。

📝 详细摘要

谷歌正式发布了 ML Kit GenAI Prompt API 的 Alpha 版本，标志着 Android 设备端生成式 AI 发展的重要里程碑。该 API 赋能开发者直接在 Android 应用中利用 Gemini Nano，实现低延迟、高隐私保护的定制化生成式 AI 功能。不同于之前针对特定用例的预构建 API，Prompt API 提供了更高的灵活性和可控性，支持开发者创建独特的、复杂的 GenAI 用例，如图像理解、智能文档扫描、面向界面的数据转换、内容提示和情感分析等。文章详细介绍了 Prompt API 的实现方式，包括通过少量代码即可创建自定义提示和设置生成参数，并强调了 Gemini Nano 在 Pixel 10 设备上的最佳性能，以及 Gemma 3n 模型在原型设计中的同源优势。谷歌鼓励开发者通过官方文档和 GitHub 示例开始集成。

💡 主要观点

  1. ML Kit GenAI Prompt API 赋能 Android 设备端定制化生成式 AI 应用。 此 API 的推出允许开发者直接在 Android 应用中集成 Gemini Nano，实现高度可定制的生成式 AI 功能，突破了以往预构建 API 的限制。
  2. Prompt API 强调设备端处理，保障用户隐私和离线可用性。 通过利用设备本地的 Gemini Nano 模型，数据处理在设备上完成，从而增强了用户隐私保护，并支持应用在无网络连接的情况下运行 AI 功能。
  3. API 支持多种定制化用例，提升应用的智能化水平。 开发者可利用 Prompt API 实现图像理解、智能文档扫描、内容提示、情感分析等功能，为用户提供更个性化、智能化的体验。
  4. Gemma 3n 模型可用于原型设计，降低开发门槛。 即使没有特定的 Pixel 10 设备，开发者也可以利用与 Gemini Nano 同源的 Gemma 3n 模型进行本地原型设计和提示词调试，加速开发进程。

💬 文章金句

  • Android 设备端生成式 AI 迎来重要里程碑——ML Kit GenAI Prompt API 的 Alpha 版本正式发布！借助该 API，您可以在 Android 应用中轻松构建低延迟、高隐私保护的定制化生成式 AI 功能。
  • Prompt API 突破了预构建功能的局限，支持自定义或特定于某个应用的 GenAI 用例，助您打造涉及复杂数据转换的独特功能。
  • Prompt API 使用设备端 Gemini Nano 进行本地数据处理，在实现离线可用的同时，还能进一步强化用户隐私保护。
  • 目前 Prompt API 在 Pixel 10 系列设备上表现最佳，该系列设备运行的是最新版本的 Gemini Nano (nano-v3)。
