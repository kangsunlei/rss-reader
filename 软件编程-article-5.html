OpenAI 研究：大型语言模型幻觉的成因与解决

10/12/2025, 4:00:00 PM

📌 一句话摘要

OpenAI 的研究表明，大型语言模型幻觉源于奖励自信猜测的训练和评估方法，并强调了关于幻觉问题的持续讨论。

📝 详细摘要

文章详细介绍了一篇 OpenAI 的研究论文，该论文指出，大型语言模型（LLM）的幻觉源于训练和评估方法，这些方法侧重准确性而忽视不确定性，导致模型倾向于猜测。预训练阶段的错误是幻觉的根源，因为模型仅接触到正面示例。这些错误在后训练阶段持续存在，因为评估指标存在不一致。OpenAI 提出了一种彻底的评估转变，主张采用对自信错误进行严厉惩罚并奖励不确定性表达的系统，而不仅仅是添加新的测试。虽然 OpenAI 报告称，在原型模型（GPT-5-thinking-mini）中成功降低了幻觉率，但批评者对用户接受度表示担忧，如果模型经常回答“我不知道”。文章还突出了围绕 LLM 幻觉的讨论，Rebecca Parsons 认为幻觉是预测模型的“特征”，而 Gary Marcus 则强调 LLM 缺乏对现实的理解。

💡 主要观点

  1. LLM 幻觉主要是由不一致的训练和评估方法引起的。 标准的评估指标惩罚弃权，优先考虑准确性，导致模型学习在不确定时也自信地猜测。这使得预训练数据暴露中的错误持续存在。
  2. 减少幻觉需要从根本上重新评估如何对 LLM 性能进行评分。 OpenAI 倡导更新广泛使用的、基于准确性的评估方法，更严厉地惩罚自信错误，奖励适当的不确定性表达，以此来阻止猜测。
  3. LLM 幻觉的定义和含义是专家们持续争论的主题。 批评者质疑 LLM 错误的拟人化。有些人认为幻觉是预测模型的“特征”，而另一些人则强调 LLM 缺乏对真实现实的真正理解。

💬 文章金句

  • 我们发现，现有的主要评估普遍惩罚不确定性，因此根本问题在于大量评估标准未能对齐。
  • 如果记分牌持续奖励侥幸的猜测，模型将继续学习猜测。修复记分牌可以促进减少幻觉技术的应用，包括新开发的技术和之前的研究。
  • 超过一半的回复最终会是“我不知道”。没有人会使用这样的东西。
  • 如果你停止对它们进行拟人化，然后回到它们作为预测模型的实际性质，那么预测结果可能是错误的，这甚至不是一个令人惊讶的结果。
  • LLM 所做的就是产生幻觉，只是我们发现其中一些是有用的。
