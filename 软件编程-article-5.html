📌 一句话摘要

Kimi 发布 WebBridge 浏览器扩展件，让 AI Agent 能像人类一样操作浏览器，并开放兼容多款 Agent 工具，定位为 Agent 通用基础设施。

📝 详细摘要

本文报道了 Kimi 最新发布的 WebBridge 浏览器扩展件。该工具允许 AI Agent 像人类一样与网页进行交互，包括搜索、滚动、点击、输入、切换页面和完成任务。与 Codex 等封闭生态产品不同，Kimi WebBridge 采用开放策略，不仅支持自家的 Kimi Code CLI，还兼容 Claude Code、Codex、Cursor、Hermes 等多个 Agent 工具，定位为 Agent 世界的通用基础设施。文章通过多个官方演示案例展示了 WebBridge 的实际能力，包括跨平台抓取热帖并自动汇总成表、精准复刻完整网页、将日常工作流定制为可重复调用的 Skill、自动创建调查问卷、筛选招聘信息以及商品比价等。安装过程也较为简易，只需两步即可完成部署。文章认为，WebBridge 的开放性和实用性使其成为 Kimi 在 Agent 时代的一次关键布局。

💡 主要观点

  1. Kimi WebBridge 是一款让 AI Agent 能像人类一样操作浏览器的浏览器扩展件。 它支持搜索、滚动、点击、输入、切换页面等完整网页交互能力，使 Agent 能自主完成复杂的网页操作流程。
  2. WebBridge 采用开放策略，兼容多款主流 Agent 工具，定位为通用基础设施。 与 Codex 等封闭生态产品不同，WebBridge 不仅支持 Kimi 自家产品，还兼容 Claude Code、Codex、Cursor 等，旨在成为 Agent 生态的基础设施层。
  3. WebBridge 展示了多种实际应用场景，包括信息聚合、网页复刻、工作流定制、表单创建、职位搜索和商品比价。 官方演示案例覆盖了从跨平台热帖抓取到精准网页复刻，再到日常任务自动化等多个领域，展示了其广泛的应用潜力。
