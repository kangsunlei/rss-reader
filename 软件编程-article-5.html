Anthropic 开源工具，追踪大型语言模型的“内部机制”

6/8/2025, 12:00:00 AM

📌 一句话摘要

Anthropic 开源了一款工具，利用电路追踪技术追踪大型语言模型的内部计算（或称“内部机制”）。

📝 详细摘要

Anthropic 发布了一款开源工具，使研究人员和开发人员能够在大型语言模型（LLMs）推理期间追踪其内部流程或“电路”。该工具包含一个 Python 库，用于利用从转码器派生的稀疏特征表示，从开源权重模型生成归因图。Neuropedia 上的 Web 前端允许可视化这些图。这种方法有助于理解模型的中间计算步骤，为其推理和决策提供洞见。Anthropic 已将该工具应用于研究 Gemma-2-2b 和 Llama-3.2-1b 等模型，并将其视为迈向机械可解释性的关键一步，这对于 AI 安全研究至关重要。该库和前端均可使用，并提供了教程 Notebook。

💡 主要观点

  1. Anthropic 开源了一款用于 LLMs 的电路追踪工具。 该工具由一个 Python 库和一个 Web 前端组成，允许用户在推理期间探究开源权重模型的内部机制。
  2. 该方法使用了稀疏激活特征和归因图。 通过转码器将神经元替换为稀疏激活特征，该工具通过构建图来显示影响特定输出 Token 的特征，从而揭示了计算步骤。
  3. 该工具是迈向机械可解释性和 AI 安全的一步。 理解 LLM 内部机制对于构建安全的 AI 系统至关重要，该工具有助于识别核心计算单元及其交互。

💬 文章金句

  • Anthropic 研究人员开源了他们用于追踪大型语言模型在推理过程中内部运行机制的工具。
  • 它计算了每个非零转码器特征、转码器错误节点和输入 Token 对其他非零转码器特征和输出 Logit 的直接影响。
  • 现在你正在识别模型跨层协同工作以执行某个复杂任务的单个特征。
  • 取决于 AI 加速的速度以及我们工具的现状，我们可能尚不能从根本上证明一切都是安全的。
