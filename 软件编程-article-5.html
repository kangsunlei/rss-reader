如何使用 Bubblewrap 将您的网站转换为安卓应用

8/19/2025, 5:52:20 PM

📌 一句话摘要

本文提供了一个分步指南，介绍如何将任何网站转换为 PWA，然后使用 Google 的 Bubblewrap 工具将其打包到原生安卓应用中。

📝 详细摘要

本文为 Web 开发者提供全面的教程，帮助他们无需新的框架或编程语言，即可将现有网站转换为安卓 应用。首先解释如何将网站转换为 PWA，详细说明 Manifest 文件和 Service Worker 的作用，并为 Vite 项目提供具体的配置步骤，包括图标生成和插件设置。随后，介绍了 Google 的 Bubblewrap 命令行工具，该工具使用 TWA 将 PWA 打包到安卓 应用中。本指南涵盖了 Bubblewrap 的安装和初始化，包括解决 JDK 和 Android SDK 设置的常见问题。更重要的是，它介绍了如何使用数字资产链接设置 TWA 验证，确保应用在全屏模式下运行且不显示浏览器地址栏。最后，它包括一个可选部分，介绍如何通过传递查询参数来自定义应用内体验，从而实现条件内容渲染。本文有效地简化了一个复杂的过程，使 Web 开发者可以轻松地创建应用。

💡 主要观点

  1. 将网站转换为 PWA 是应用转换的基础步骤。 正确的 PWA 配置（包括 Manifest 和 Service Worker 设置）对于网站的“可安装性”至关重要，这使得 Bubblewrap 能够识别并将其打包为安卓 应用。
  2. Bubblewrap 简化了使用 TWA 将 PWA 打包到原生安卓 应用中的过程。 Google 的 Bubblewrap CLI 自动化了从 PWA 的 manifest 生成安卓 应用包 (APK/AAB) 的过程，利用 TWA 来实现类似原生的体验。
  3. 数字资产链接对于 TWA 验证和全屏应用显示至关重要。 在网站的 `.well-known` 文件夹上实现 `assetlinks.json` 文件可以验证应用和网站之间的信任，从而实现全屏模式和深度链接。

💬 文章金句

  • 本文尤其适合不熟悉应用开发的 Web 开发者。
  • PWA 代表渐进式 Web 应用，其目标是使您的网站看起来和感觉起来就像一个原生应用。
  • Bubblewrap 是 Google 制作的命令行工具，它使用 TWA 将您的 PWA 转换为安卓 应用。
  • 可信 Web 活动 (TWA) 是一种现代安卓 特性，可让您在安卓 应用内全屏显示您的实时网站。
  • 这种信任是使用一种称为数字资产链接的系统来验证的。
