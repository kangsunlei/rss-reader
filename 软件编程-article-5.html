GitHub Copilot SDK 正式发布

1/22/2026, 5:01:00 PM

📌 一句话摘要

GitHub 宣布推出 Copilot SDK，开发者只需寥寥几行代码，即可将 Copilot 的智能体核心嵌入到任何应用程序中。

📝 详细摘要

GitHub 官方宣布正式发布 GitHub Copilot SDK。该 SDK 封装了与 GitHub Copilot CLI 相同的“智能体核心 (Agentic Core)”，让开发者能够轻松地将 AI 驱动的代码辅助功能直接集成到自己的应用中。公告强调了其极简的集成方式，仅需几行代码即可完成。推文中还附带了该 SDK 的 GitHub 仓库链接，方便开发者获取更多技术细节。
