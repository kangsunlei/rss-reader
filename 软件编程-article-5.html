📝 详细摘要

文章深入分析了尤雨溪宣布 Vite 将用 Rust 编写的 Rolldown 逐步替代现有 Rollup 打包器的重大改动。作者指出，这不仅仅是打包器的替换，而是 Vite 底层的全面 Rust 化，包括配套工具如 Babel、Terser、ESLint 也将被 Rust 实现的 Oxc 接管。文章解释了为何 JS 构建工具已达性能瓶颈，以及 Rust 在提升构建效率方面的优势，并提供了官方性能数据，同时提醒读者应结合实际项目评估。更重要的是，文章解读了这一举动背后的战略意义：Rolldown 和 Oxc 是尤雨溪新公司 Void(0)的产品，通过将这些 Rust 工具链“回注入”到 Vite 等主流前端工具中，尤雨溪正下一盘掌控整个前端构建基础设施的大棋，旨在让 Void(0)成为生态标准，摆脱对外部 JS 工具的依赖，构建“Vue + Vite + Void(0)工具链”的闭环。

💡 主要观点

  1. Vite 底层正进行全面 Rust 化，核心是替换 JS 打包器 Rolldown 不仅打包器从 Rollup 换成 Rust 的 Rolldown，配套工具如 Babel、Terser 也将被 Rust 实现的 Oxc 接管，构建链路将全面迁移到 Rust。
  2. Rust 构建工具旨在突破 JS 性能天花板，显著提升构建效率 面对日益增长的项目体积和构建时间，JS 工具已达瓶颈，Rust 能提供更高级别的执行效率，大幅缩短 CI/CD 及本地开发构建时间。
  3. 此举是尤雨溪及其新公司 Void(0)掌控前端工具链生态的战略布局 Rolldown 和 Oxc 是 Void(0)产品，通过将它们集成到 Vite，Void(0)寻求成为前端构建基础设施标准，减少对外部 JS 工具依赖。
