让 Agent 直接操控电脑的神器，开源了！

📌 一句话摘要

Cua 是一个开源项目，让 AI Agent 在沙箱中安全流畅地操作桌面系统，支持多平台接入，并内置评测基准。

📝 详细摘要

文章介绍开源项目 Cua，它专注于让 AI Agent 安全流畅地操控整个桌面系统，包括看屏幕、移动鼠标、键盘输入、运行命令等。Cua 支持 Linux、macOS、Windows 甚至安卓系统，运行环境可放在云或本地；通过沙箱隔离，Agent 不会抢占真实鼠标焦点。内置 VNC 服务可在浏览器实时查看操作，并支持通过 MCP 接入 Claude Code、Codex 等 Agent 工具。文章还提及 Cua 的架构（Sandbox、Driver、Cua-Bench、Lume）以及快照调试功能，展示 Cua-Bench 对 Gemini 3.5 Flash 等模型的评测结果，最后给出 macOS/Windows 的安装命令和 MCP 集成方法。

💡 主要观点

  1. Cua 让 AI Agent 在沙箱中安全操作桌面系统。 通过沙箱隔离，Agent 不抢占真实鼠标焦点，不暴露用户隐私数据，支持本地运行或云端部署。
  2. Cua 架构包括 Sandbox、Driver、Cua-Bench 和 Lume。 Sandbox 管理跨系统运行环境，Driver 进行后台操控，Cua-Bench 用于训练和评测，Lume 创建虚拟 macOS。
  3. Cua 支持多种集成方式，包括 MCP 接入和 VNC 实时查看。 可通过 MCP 协议接入 Claude Code、Codex 等 Agent 工具，并在浏览器中实时查看 Agent 的操作过程。

💬 文章金句

  • Cua 不止是一个单一工具，而是一个整套 Agent 操作系统。
