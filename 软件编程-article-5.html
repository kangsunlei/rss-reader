JetBrains AI 助手 - Visual Studio Code 版

5/19/2025, 11:11:06 AM

📌 一句话摘要

JetBrains 发布 Visual Studio Code 版 AI 助手，赋能先进 AI 编码。

📝 详细摘要

JetBrains 将其 AI 助手扩展到 Visual Studio Code，此前该助手仅限于 JetBrains IDE 和 Android Studio。此举旨在覆盖更广泛的开发者社区，并展示了对 IDE 无关 AI 辅助的承诺。公共预览版适用于 Java、Kotlin、JavaScript、TypeScript、Python、C#、C++ 和 C 等多种语言。该助手依托 JetBrains 丰富的编程语言经验，并利用其专有的、现已开源的 Mellum LLM，实现云端代码补全。它还支持 Gemini、Claude 和 GPT 模型等其他顶级 AI 模型。主要功能包括具备代码库理解能力的 AI 聊天、用于复杂任务的内置编码 AI 代理、生成提交信息、文档、代码解释和错误检测等。

💡 主要观点

  1. JetBrains AI 助手现已支持 Visual Studio Code 将 AI 助手扩展到 VS Code，使先进的 AI 编码功能可以被 IntelliJ 平台之外的更广泛受众所使用。
  2. 依托 JetBrains 的语言技术积累和 Mellum LLM 建立在多年的经验和一个代码特定的 LLM (Mellum) 之上，用于精确的上下文收集和准确的代码补全建议。
  3. 支持多种顶级 AI 模型，并集成编码 AI 代理 用户可以选择首选的 LLM（Gemini、Claude、GPT），并利用专门的 AI 代理来处理复杂的开发任务。
  4. 具备 AI 聊天功能，可深度理解代码库和编程语言 可以在 AI 聊天界面中直接实现自然语言查询、迭代改进和多文件编辑。

💬 文章金句

  • 我们坚信，AI 创新不应受限于单一技术提供商、单一 IDE，乃至同一厂商的一系列 IDE。
  • JetBrains AI 助手 for Visual Studio Code 无缝集成至您的开发工作流程，提升效率与乐趣。
  • Mellum - JetBrains 自研 LLM (现已开源)，从零训练，专为 JetBrains AI 助手提供云端代码补全能力。
  • 探索 AI 的全部潜力 - 将复杂任务委托给内置的编码 AI 代理，充分发挥其优势，并在您的监督下达成最优结果。
