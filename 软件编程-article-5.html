💡 主要观点

  1. Claude Code 2.1.318 在联网请求中将用户邮箱写入 User-Agent，触发隐私泄露风险 GitHub 用户报告称模型默认未启用隐私检查模块，已有用户反馈检查仍未生效，甚至可能包含项目名、客户名等额外敏感信息，暴露了代理可读上下文与对外发送权限之间的边界问题。
  2. 特斯拉计划于 2027 年收缩 Cybertruck 生产，转向 Cybercab NBC News 报道称 Cybertruck 2025 年美国销量为 20，237 辆，同比降 48%，远低于 Musk 预测的 25 万辆，高价格、锐角造型及法规限制是主要因素，Cybercab 承载自动驾驶战略。
  3. Kagi 开放免注册搜索试用，前 50 次免账号，注册后再获 100 次 公司称此举降低口碑传播摩擦，区分免费试用与付费订阅，用户可通过 Android 应用和桌面组件体验完整功能，但访客体验不等于付费套餐。
  4. CVE-2026-83844 将 Windows Paint 列为高危远程代码执行漏洞 CVSS 3.1 评分为 8.1，影响 Paint 11.0.0.0 起至低于 11.2609.401.0 版本，官方记录简略缺乏完整攻击链说明，需核查应用版本而非仅依赖 Windows 更新。
  5. BUI 将 Blender 界面组件化为独立 C 运行时，支持多语言绑定 在 Ryzen 7 5800U 笔记本上，BUI CPU 版约 40ms 出首帧，显著快于 GPUI 的 231ms，但缺乏屏幕阅读器支持、IME 和 macOS GPU 后端，GPL 许可限制了商业集成。
