Now & Again — 用 Go+Vue3 写了一个家庭事务管理平台：Web/CLI/API 三端统一，插件化架构，支持巡检+AI 助手

7/5/2026, 12:26:33 PM

📌 一句话摘要

作者开源了一款名为 Now & Again 的家庭事务管理平台，支持普通任务、巡检、任务链三种可嵌套的任务类型，提供 Web/CLI/AI 对话三端入口，采用 Go+Vue3 技术栈并支持 Docker 一键部署。

📝 详细摘要

文章介绍了作者开源的家庭事务管理平台 Now & Again 的设计背景、核心功能与技术特点。该平台以「Now（一次性事务）」和「Again（周期性事务）」为核心理念，解决家庭成员间任务分工不清、周期性事务遗忘、巡检走过场等痛点。核心功能包括：家庭分组与任务分配、周期性任务自动排期、可远程订阅的任务模板、巡检发现问题自动生成跟进任务、多步骤任务链自动推进、三种任务类型的自由嵌套、ICS 日历同步、户型图标记、基于 OpenClaw 的 AI 对话管理，以及可扩展的插件化架构。项目采用 Go 后端 + Vue3 前端，支持 Docker 一键部署，提供 Web、CLI、AI 对话三种交互方式，数据可完全自建。

💡 主要观点

  1. 三种任务类型自由嵌套，覆盖从简单待办到复杂流程的完整场景。 普通任务、巡检、任务链可互相嵌套——巡检发现问题自动生成跟进任务，任务链步骤可以是巡检或子任务链。这种设计让简单场景不臃肿，复杂场景能拆解，比单一 todo 模型更具扩展性。
  2. 模板支持 HTTP 远程订阅，实现社区共享与分级隔离。 模板不仅内置常用场景，还支持通过 URL 订阅远程模板（如 GitHub 上的 YAML），且系统级与家庭级隔离。这降低了重复配置成本，也为社区贡献提供了标准接口。
  3. AI 对话管理通过 OpenClaw 框架实现多平台接入。 接入 OpenClaw 后，用户可用自然语言管理事务，无需学习界面操作。OpenClaw 的开放性意味着可接入微信、钉钉、Telegram 等任意聊天工具，显著降低了非技术用户的使用门槛。
  4. 插件化架构设计，任务类型、模板、调度方式、地点类型均可扩展。 核心代码与扩展点解耦，未来新增任务类型（如投票、计时、计数）或地点类型（户外、车辆）无需修改核心。这种设计保证了项目的长期可维护性和社区参与空间。
  5. 三端统一与数据自建，兼顾易用性与隐私。 Web 端面向普通用户，CLI 面向开发者习惯，AI 对话面向口语化交互；Docker 一键部署且数据存储在本地服务器，解决了家庭敏感数据的隐私顾虑。
