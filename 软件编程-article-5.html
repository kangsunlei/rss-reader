📌 一句话摘要

介绍 GitHub 发布的 Spec-Kit 工具包，倡导“规格先行”的 AI 编码方法论，以取代随意的 Vibe Coding。

📝 详细摘要

这条推文详细介绍了 GitHub 新发布的开源项目 `spec-kit`。这是一个命令行工具和配套的方法论，核心目标是改变 AI 辅助编码的随意性（Vibe Coding），转向“规格先行”的严谨流程。其工作流分为六个步骤：制定项目原则、明确需求规格、澄清歧义、规划技术方案、拆解任务、最终执行。该工具通过 Specify CLI 安装，可与 Copilot、Claude Code 等 30 多种 AI 编码代理配合使用。推文附带了项目链接和介绍图。
