2025 年 Databricks Lakehouse 上的 SQL

12/17/2025, 4:21:02 PM

📌 一句话摘要

Databricks SQL (DBSQL) 2025 年更新显著提高了性能，将 AI 直接集成到 SQL 工作流中，增强了成本管理，并扩展了开放 SQL 功能，以简化数据仓库的迁移。

📝 详细摘要

本文重点介绍了 Databricks SQL (DBSQL) 在 2025 年的关键进展，将其定位为传统数据仓库的有力的替代方案。DBSQL 提供了自动性能改进，包括在现有快 5 倍的基础上，将查询速度再次提高了 25%，且无需手动调优。它还引入了 `ai_query` 和 `ai_parse_document` 等原生 AI 功能，允许分析师直接在 SQL 中利用大型语言模型（LLM）进行摘要和文档解析等任务。预测优化通过持续收集统计数据和改进执行计划来自动化性能管理。此外，DBSQL 通过存储过程和递归 CTE 等功能增强了开放 SQL 能力，简化了从遗留系统的迁移。新的成本管理工具提供了关于支出的粒度洞察，帮助团队有效监控和控制资源使用。这些更新共同提升了 DBSQL 在现代数据分析中的效率、智能和开放性。

💡 主要观点

  1. DBSQL 在无需手动调优的情况下实现了自动且显著的查询性能改进。 在现有快 5 倍的基础上，查询速度再次提高了 25%，自动交付给所有客户，无需索引管理或手动配置，从而加速了跨团队的决策制定过程。
  2. 原生 AI 功能将大型语言模型（LLM）直接集成到 SQL 工作流中。 `ai_query` 和 `ai_parse_document` 等功能使数据分析师能够在 SQL 中执行摘要和文档解析等任务，减少工具切换并提高工作流效率。
  3. 预测优化自动化了性能管理并防止了性能随时间的推移而逐渐下降。 自动统计管理和持续的执行计划改进减少了运营开销，并确保了随着数据量和工作负载的演变而获得一致的性能。
  4. 扩展的开放 SQL 功能简化了从遗留数据仓库的迁移。 存储过程、SQL 脚本和递归 CTE 等新功能符合开放标准，使组织更容易摆脱专有系统。
  5. 成本管理方面的增强提供了对支出的详细可见性和控制。 新的仪表板、标签、预算和系统表允许团队在粒度级别监控和识别成本驱动因素，优化资源消耗。
