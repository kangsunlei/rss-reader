如何使用 Java 构建生成式 AI 应用

7/11/2025, 5:00:00 AM

📌 一句话摘要

本文为 Java 开发者提供分步指南，介绍如何使用 Spring AI 和 Docker 模型运行器构建生成式 AI 应用。该指南展示了如何使用检索增强生成 (RAG) 技术优化模型响应，并在本地执行大语言模型 (LLM)。

📝 详细摘要

本文旨在消除一种常见的误解，即认为 Python 是构建生成式 AI 项目的必要条件。文章展示了 Java 开发者如何利用强大的 Java 生态系统，特别是 Spring AI，来构建此类应用。通过一个实用的分步演示，重点介绍了检索增强生成 (RAG) 技术，以增强大语言模型 (LLM) 的响应，减少模型产生不准确或虚假信息的可能性。关键组件包括：Spring AI，用于与聊天模型（如 OpenAI）和向量数据库（Qdrant）集成；Docker 模型运行器，用于在本地运行 AI 模型，并提供与 OpenAI 兼容的 API。该指南涵盖了以下内容：设置 Spring Boot 项目，配置 Docker 模型运行器，使用 Llama 3.1 和 mxbai-embed-large 模型，实现聊天和 RAG 端点，以及将文档导入向量数据库。本文还强调了 RAG 如何改进 LLM 答案的上下文基础，从而提高应用程序响应的准确性和可靠性。此外，文章还简要介绍了如何使用 Testcontainers 进行测试，以及使用 Grafana 实现可观测性。

💡 主要观点

  1. Java 开发者可以有效地构建生成式 AI 应用，而无需学习 Python。 Java 生态系统，尤其是 Spring AI 这样的库，提供了强大的工具和集成，方便 Java 开发者构建和部署生成式 AI 应用。
  2. Docker 模型运行器支持使用与 OpenAI 兼容的 API 在本地执行 LLM。 Docker 模型运行器简化了在本地运行 Llama 3.1 等 AI 模型的过程，减少了对云托管服务的依赖，并提供了一个便捷的开发和测试环境。
  3. 检索增强生成 (RAG) 通过提供上下文数据，显著提高了 LLM 的准确性。 通过集成向量数据库以提供精选的相关文档，RAG 有助于减少 LLM 产生不准确或虚假信息的可能性，并确保响应基于特定的准确信息。

💬 文章金句

  • 但是，如果您已经是 Java 开发者，则无需学习一门新语言。Java 生态系统提供了强大的工具和库，使构建生成式 AI 应用既易于上手又高效。
  • 此外，我们将使用 Docker 模型运行器（而不是云托管的 OpenAI 模型），它提供了一个与 OpenAI 兼容的 API，使其易于在本地运行 AI 模型。
  • 我们可以看到 LLM 提供的答案存在一些错误，例如，PostgreSQLEnvironment 在 testcontainers-python 中不存在。另一个错误是文档链接，testcontainers.io 也不存在。因此，我们可以看到模型生成了一些不准确或虚假的信息。
  • 为了改善这种情况，让我们为模型提供一些关于 Testcontainers 的精选上下文！
  • Spring AI 提供了许多 advisor。在此示例中，我们将使用 QuestionAnswerAdvisor 对向量搜索数据库执行查询。它负责与向量数据库的所有单独集成。
