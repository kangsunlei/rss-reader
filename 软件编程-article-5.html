NVIDIA 曝高危漏洞，超 2000 台 GPU 主机暴露

10/12/2026, 10:00:00 AM

📌 一句话摘要

NVIDIA DCGM Exporter 存在 CVE-2026-47483 漏洞，攻击者可通过未授权的性能分析接口耗尽资源导致监控任务中断。

📝 详细摘要

NVIDIA 曝出 DCGM Exporter 工具存在高危漏洞（CVE-2026-47483）。该漏洞由于 /debug/pprof 路径下的 Go 性能分析接口未设置登录校验和频率限制，攻击者可通过发送大量请求导致服务器内存和 CPU 占用失控，引发 GPU 监控崩溃并中断 AI 工作负载。研究发现全球约 300 家机构的 12000 台 GPU 存在风险，涵盖 H100、B200 及 RTX 4090 等。NVIDIA 建议用户升级至 4.8.2 版本或禁用 --enable-pprof 参数。

💡 主要观点

  1. 漏洞源于未授权的性能分析接口 漏洞存在于 /debug/pprof 路径下的 Go 性能分析接口，受影响版本未配置登录校验和频率限制，导致直接暴露在公网。
  2. 攻击后果会导致资源耗尽与监控中断 攻击者通过短时间内发送大量请求，可引发内存和 CPU 失控，使 DCGM Exporter 崩溃，导致运维人员无法监控 GPU 健康状态及 AI 任务。
  3. 影响范围极其广泛 扫描发现全球约 300 家机构有 12000 台 GPU 暴露风险，包括主流的 H100、B200 (Blackwell) 等。
  4. 官方已发布修复方案 NVIDIA 建议用户升级至 4.8.2 及以上版本，或在非必要场景下手动禁用 --enable-pprof 参数。

💬 文章金句

  • 攻击者只要短时间内发送大量请求，就会导致服务器内存和 CPU 占用失控，最终使 DCGM Exporter 运行慢甚至直接崩溃
  • 一旦 DCGM Exporter 崩溃，运维人员将无法查看 GPU 健康状态、运行错误资源占用
