HTTP2Shell 漏洞影响范围扩大，波及.NET、FFmpeg 等主流软件

10/26/2026, 10:05:00 AM

📌 一句话摘要

HTTP2Shell 漏洞的根源是 Brotli 解码器中的一个缺陷，该缺陷不仅影响 Web 流量，还波及 .NET 应用、FFmpeg 媒体处理、ClickHouse 服务器以及 Apache Arrow 工作负载，导致程序崩溃、内存损坏和无限解码循环等问题。

📝 详细摘要

HTTP2Shell 漏洞的底层是 CVE-2026-111497，一个 Brotli 解码器中的缺陷，导致无效块切换操作被误判为需要更多输入，从而引发越界写入。该漏洞影响多个软件栈：FFmpeg 通过 libjxl 库可能触发内存损坏；.NET 的内置解压 API 会导致原生程序崩溃；ClickHouse 在处理压缩请求体时会崩溃；Apache Arrow 则会陷入无限循环。虽然 Node.js 已推送修复，但其他受影响应用仍需等待官方更新。

💡 主要观点

  1. 漏洞根源是 Brotli 解码器缺陷 CVE-2026-111497 是一个逻辑错误，导致解码器在遇到无效块切换时进入错误状态，进而引发越界写入。这与 HTTP 协议本身无关，但影响了使用该解码器的所有应用。
  2. FFmpeg 媒体处理流程受影响 通过 libjxl 库，攻击者可以构造特殊的 JPEG XL 图像，在压缩元数据中嵌入畸形 Brotli 数据，导致内存损坏和程序崩溃。虽然尚未实现完整 RCE，但风险已显现。
  3. .NET 应用触发原生崩溃 使用 .NET 的 Brotli 解压 API，攻击者可以构造两阶段流，导致解码器越界访问堆内存，引发段错误并终止进程。微软已开始推送修复补丁。
  4. ClickHouse 和 Apache Arrow 也受波及 ClickHouse 在处理压缩请求体时会崩溃，而 Apache Arrow 会陷入无限循环，消耗大量 CPU 资源。这些问题均由相同的底层解码器缺陷引起。

💬 文章金句

  • 这一发现意味着，仅核查 Node.js 版本会遗漏其他存在暴露风险的软件。
  • 攻击者可构造特殊图片，在其压缩元数据块中嵌入畸形 Brotli 数据，libjxl 解码这类数据时会在内存清理阶段触发内存损坏，导致程序崩溃。
  • 后续内存操作会越界访问合法堆范围外的数据，触发的段错误会直接终止进程，这与普通托管异常的表现完全不同。
