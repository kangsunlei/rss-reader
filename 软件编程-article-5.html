原生版 TypeScript 正式发布，10 倍性能提升！

5/24/2025, 11:48:00 AM

📌 一句话摘要

微软发布 Go 重写的原生版 TypeScript 预览，性能提升高达 10 倍。

📝 详细摘要

文章介绍了微软发布的原生版 TypeScript 预览版，其核心是用 Go 语言重写了原有的 JavaScript 编译器。作者解释了重写的原因，主要是解决旧版在大型项目中性能慢、内存占用高的问题，以及 JavaScript 单线程模型的限制。文章详细阐述了选择 Go 语言的考量，包括与 TS 相似的语法、自动内存回收、并发能力和跨平台支持。文中引用微软测试数据，展示了在新编译器下，多个知名项目编译速度提升约 10 倍。文章还提供了体验原生版 TypeScript 的安装和使用命令行工具 `tsgo` 及 VS Code 编辑器插件的方法，并列出了当前预览版已知的功能缺失和未来的发展计划，最终目标是将其融入未来的 TypeScript 7 版本。

💡 主要观点

  1. 原生版 TypeScript 用 Go 重写，显著提升编译器性能。 旧版 JS 编译器面临性能瓶颈和内存问题，新版利用 Go 的特性实现了高达 10 倍的编译速度提升，尤其对大型项目效益显著。
  2. 选择 Go 语言基于其特性，易于移植、内存管理和并发优势。 Go 语言的语法风格、垃圾回收、并发模型和跨平台能力使其成为重写 TypeScript 编译器的合适选择。
  3. 用户可通过命令行工具 tsgo 和 VS Code 插件体验原生预览版。 微软提供了预览版的安装和使用指南，包括独立的命令行工具和集成到编辑器的实验性插件，方便开发者试用。
  4. 预览版尚存功能缺失，未来将逐步完善并集成到正式版本。 当前版本缺少部分命令行和编辑器功能，但微软计划持续迭代，最终将其发展为 TypeScript 7 的核心组成部分。

💬 文章金句

  • 通过使用 Go 语言重写，TypeScript 实现了高达 10 倍的性能提升，开发者可以更快编译，使用起来也更流畅。
  • 在大型项目中，**性能迟缓、内存占用高**。
  • 新版编译器在一些有名的项目中速度提升非常明显。
  • 这个工具以后会替代现在的 tsc，并成为官方 TypeScript 的一部分。
  • 原生版 TypeScript 还没有开发完，目前已知的问题包括：功能缺失，配置问题。
