💡 主要观点

  1. JDK 27 发布计划已正式提出，预计于 2026 年 9 月正式发布。 Oracle 首席架构师 Mark Reinhold 公布了从 Rampdown 到最终发布的详细时间线，为开发者提供了明确的版本升级规划参考。
  2. Spring Cloud Gateway 存在一个可能误导管理员的 SSL 配置静默绕过漏洞。 CVE-2026-22750 漏洞会导致 `spring.ssl.bundle` 属性被忽略且无警告，默认使用 SSL 配置，可能带来安全风险，提醒开发者及时关注和修复。
  3. 多个主流 Java 框架和工具发布重要更新，引入新特性和规范支持。 Hibernate 7.3.0 增强了自然 ID 支持；Keycloak 26.6.0 支持 RFC 7523 和 MCP 规范；Google ADK for Java 更新至 1.1.0；这些更新反映了生态的技术演进方向。
  4. Java 生态与 AI 开发工具的融合趋势明显。 Keycloak 实验性支持 MCP 规范，Helidon 支持配置 LangChain4j MCP 客户端的 TLS，以及 Google ADK for Java 的更新，都显示了 Java 技术在 AI 应用开发栈中的持续集成。
