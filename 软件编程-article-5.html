Google Gemini 3.1 Pro 在 GitHub Copilot 中开启公共预览

2/19/2026, 5:31:37 PM

📌 一句话摘要

GitHub 宣布在 GitHub Copilot 中推出 Google Gemini 3.1 Pro 模型的公共预览版，重点提升了工具精度和编码循环效率。

📝 详细摘要

GitHub 已将 Google 的 Gemini 3.1 Pro 集成到 GitHub Copilot 中，目前已开放公共预览。早期测试表明，该模型具有极高的工具精度（通过更少的工具调用即可获得理想结果），并能提供更高效的“编辑-测试”循环。开发者现在可以在 VS Code 中选择并测试该模型，利用 Google 最新的 AI 能力来处理软件开发任务。
