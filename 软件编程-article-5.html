DeepResearch-30B-A3B：开源 Web Agent 媲美 OpenAI 深度研究，现已上线魔搭

9/17/2025, 1:23:35 PM

📌 一句话摘要

博主推荐 DeepResearch-30B-A3B 结合 Tavily 搜索工具，称其为“深度搜索研究青春版”，在质量与速度上达到完美平衡，有望替代传统搜索引擎，并已在魔搭 Modelscope 平台上线。

📝 详细摘要

此推文引用了阿里云通义实验室关于其最新开源 Web Agent——Tongyi DeepResearch 的发布信息，并由博主 Geek 进行了体验评价。Tongyi DeepResearch 是首个完全开源的 Web Agent，在仅 30B（激活 3B）参数下，其性能已能与 OpenAI 的 Deep Research 相媲美。该 Agent 在多项基准测试中表现出色，例如在 Humanity's Last Exam 中获得 32.9 分，BrowseComp 中获得 45.3 分，以及 xbench-DeepSearch 基准测试中获得 75.0 分。博主 Geek 进一步指出，结合 Tavily 搜索工具使用时，该模型可实现“深度搜索研究青春版”的效果，在质量和速度之间取得完美平衡，并认为其完全有能力平替传统搜索引擎。目前，该模型已在魔搭 Modelscope 平台上线，供用户体验。
