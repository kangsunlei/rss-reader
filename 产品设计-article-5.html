是时候该给 Token 算算 ROI 的账了

7/14/2026, 11:45:00 PM

📌 一句话摘要

文章指出企业 AI Token 消耗激增却产出不成比例，呼吁从 Token 最大化转向纪律，并预测模型分层与成本效率将决定未来格局。

📝 详细摘要

文章通过引用德勤、Jellyfish、a16z 等数据，揭示企业 AI 投入中 Token 消耗的快速增长与生产力提升的失衡，指出过去将 Token 视为创新指标的做法正在转变，企业开始审视模型定价并实施 Token 纪律。接着分析模型分层趋势：高价值复杂任务仍依赖前沿模型，而大量常规任务正被成本更低的开源或国产模型取代。文章认为，未来模型竞争的胜负将取决于 Token 效率——要么性能卓越，要么成本低廉；中国模型在降低智能成本下限方面具有独特优势，而智能上限仍由美国前沿模型主导。最终建议企业通过智能路由实现复杂推理与基础任务的分离，以最大化单位成本的产出。

💡 主要观点

  1. Token 消耗已从创新指标转变为企业成本中心，产出增长未匹配支出增长。 数据显示高 Token 使用工程师生产力仅 2 倍却消耗 10 倍 Token，表明收益递减，AI 投入远赶不上产出。
  2. 企业正从‘Token 最大化’转向‘Token 纪律’，要求模型价格下降并重新评估收费模式。 CEO 们公开吐槽 Token 定价过高，认为若 AI 能带来 10 亿美元增收，模型公司应分成而非按 Token 收费。
  3. 模型分层成为必然：高价值复杂任务用前沿模型，常规任务转向高性价比或开源模型以提升 ROI。 a16z 调研显示企业正增加多模型使用，未来智能路由将把任务精准拆分，实现单位成本产出最大化。
  4. 未来模型胜负将取决于 Token 效率——要么足够出色，要么足够便宜；中国模型在成本下限上具优势。 类比法拉利与丰田，智能上限由美国模型刷新，成本下限则被中国模型不断压低，决定产业格局。

💬 文章金句

  • 美国模型继续刷新智能的上限，而中国模型正在不断刷新智能的成本下限。
  • Token 的增长速度，已经开始跑赢价值的增长速度。
  • 换句话说，AI 的投入远远赶不上产出。
  • 未来只有两种模型能够活下来------要么足够出色，要么足够便宜。
  • 模型准确率通常会在中等 Token 消耗区间达到峰值，之后便进入明显的收益递减阶段。
