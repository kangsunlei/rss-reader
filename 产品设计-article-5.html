GitHub 3.1 万 Star！开源堡垒机 JumpServer 正式进入 V5 时代。

9/30/2026, 1:25:44 AM

📌 一句话摘要

开源堡垒机项目 JumpServer 发布 v5.0.0 版本，通过统一客户端实现多资产连接并引入 AI 辅助运维能力。

📝 详细摘要

JumpServer 正式进入 V5 时代。该版本在保留原有账号管理、权限分配及审计核心能力的基础上，重点改造了运维工作入口。新版原生客户端支持 SSH、RDP、Kubernetes 及 Web 资产的统一接入，减少了工具间切换的成本。此外，V5 引入了 AI 助手，可辅助脚本生成、SQL 语句编写及文件传输，未来计划支持操作风险预警和自动审计报告。

💡 主要观点

  1. JumpServer V5 核心改进在于统一了客户端入口 通过原生客户端实现了对 Linux 服务器、数据库、Kubernetes 集群及 Web 资产的统一管理，解决了多工具切换频繁的问题。
  2. 引入了全新的终端 UI 交互体验 KoKo TUI 重新设计了终端页面，支持标签化管理会话，允许运维人员在多个资产连接间快速切换。
  3. 深度集成 AI 辅助能力 内置 AI 助手可辅助生成巡检脚本、提供 SQL 语句建议及管理文件传输，并利用运维上下文识别高风险操作。
  4. 优化了 Web 资产的访问流程 运维可以直接从客户端访问业务系统或网络设备后台，无需再通过 Windows 中转设备，并支持验证码交互。
