重磅！Claude Code 官方开源：AI 屎山代码，终于有解了~（附提示词）

📌 一句话摘要

本文详细介绍了 Claude Code 官方开源的 `code-simplifier` 插件，通过分析其核心提示词和工作流，阐述了其如何帮助开发者治理 AI 生成的“屎山”代码，提升可维护性，并提供了安装与定制化建议。

📝 详细摘要

文章介绍了一个由 Claude Code 核心开发者开源名为 `code-simplifier` 的插件，旨在解决 AI 生成代码易出现“屎山”的问题，提升代码的可维护性。该插件的核心是基于一套详细的提示词（Prompt）来指导 AI 进行代码重构。作者详细拆解了该提示词的五个核心原则：功能守恒、强制执行项目规范、清晰度优先于简洁度、拒绝过度简化、以及聚焦于最近修改的代码。文章强调了此插件对于提升 AI 编程代码质量的重要性，并提供了安装及个性化配置（微调 Prompt）的方法，指出 AI 编程正从单纯的代码生成转向代码治理，对于非科班或独立开发者而言具有巨大价值，相当于一位不知疲倦的 Code Review 技术总监。

💡 主要观点

  1. `code-simplifier` 是官方开源的 AI 代码简化插件，解决 AI 生成代码的“屎山”问题。 此插件旨在通过一套明确的规则和指引，帮助开发者整理由 AI 生成的、可能存在可维护性问题的代码，提升代码质量。
  2. 插件核心基于五个原则：功能守恒、强制项目规范、清晰优先、拒绝过度简化、聚焦当下。 这些原则确保代码重构过程中不改变功能，强制遵循编码标准，优先考虑可读性，避免盲目简化，并集中处理近期修改的代码，提升重构效率和精确性。
  3. 该插件为开发者提供了应对“代码熵增”的有效工具，特别是对 AI 辅助编程而言。 通过自动化的代码整理和优化，插件帮助开发者保持代码库整洁，降低维护成本，尤其在使用 AI 进行大量代码生成时，能有效规避高强度输出带来的代码质量下降。
  4. 用户可以根据自身或团队需求，自定义插件的提示词以适应特定编码规范。 插件提供的个性化定制能力，允许开发者修改其内部的 Prompt 文件，使其成为一个完全符合个人或团队习惯的专属代码管家，兼顾通用性与灵活性。
  5. 文章指出 AI 编程正从代码生成转向代码治理，强调代码可维护性的重要性。 这一趋势表明 AI 辅助开发工具正日益成熟，不仅能提高开发速度，还能通过智能优化来提升代码质量，帮助开发者更好地管理复杂项目。

💬 文章金句

  • 这哪里是什么插件，这分明是官方内部让 Claude Code 整理屎山代码的终极方案。
  • 它的核心作用只有一个：在不改变代码功能的前提下，让代码变得更清晰、更统一、更易读。
  • 提示词里原话是这么说的：Choose clarity over brevity。翻译过来就是：宁愿代码写得长一点、啰嗦一点，也要让看代码的人一眼就能看懂。
  • 这个 Agent 懂得什么时候该删减，什么时候该保留。它不会为了减少代码行数，而牺牲代码的可维护性。
  • AI 编程正在从单纯的生成代码，向代码治理转变。
