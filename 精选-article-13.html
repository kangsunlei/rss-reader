LlamaIndex 新闻通讯 2025-03-18

📌 一句话摘要

LlamaIndex 新闻通讯发布了 LlamaExtract Beta 版，以及 RAG 教程、Agent 模板和框架社区更新。

📝 详细摘要

LlamaIndex 新闻通讯重点发布了 LlamaExtract 公开测试版，该工具旨在简化复杂文档的结构化数据提取。同时，还包括 Agentic RAG 教程、任务特定 Agent 模板，以及其他框架和社区更新。本期还包括 AI Web 开发活动、LLM 法律黑客松等社区活动信息。

💡 主要观点

  1. LlamaExtract Beta 版简化了复杂文档的结构化数据提取，提高效率。 LlamaExtract 工具旨在简化从长而复杂的文档中提取结构化数据的过程，从而提高效率。
  2. 任务特定 Agent 模板助力自动化知识工作流程，降低代码量。 通过使用提供的模板，用户可以用更少的代码来编排各种任务的工作流，例如处理幻灯片和提取发票行项目。
  3. 模型上下文协议 (MCP) 集成允许 LlamaIndex 代理使用任何 MCP 兼容服务器公开的工具。 此集成允许用户仅用一行代码即可在 LlamaIndex 代理中使用任何 MCP 兼容服务器公开的工具，从而扩展了代理的功能。
