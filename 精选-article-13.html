刚刚，DeepSeek 发布新模型，Flash 把 Pro 给干掉了

9/10/2026, 7:33:00 AM

📌 一句话摘要

DeepSeek 发布 V4.1 Flash，通过 CED 非对称架构、CSA2 稀疏注意力和 FP4 KV Cache 等优化，让 552B MoE 模型以约 8B/16B 激活参数运行，性能反超 V4 Pro 并推动其下线。

📝 详细摘要

DeepSeek 正式发布 V4.1 Flash 并上线官网、App 与 API。该模型总参数 552B，采用全新 Causal Encoder Decoder（CED）非对称架构，输入阶段激活约 8B、输出阶段约 16B，兼顾能力上限与推理成本。配套技术包括 Compressed Sparse Attention 2（跨层复用 KV Cache 与 Top-K 索引）、FP4 KV Cache（HBM 需求降至四分之一、SSD 降至八分之一，相比初代 KV Cache 缩小约 437 倍）以及 DSpark 生成加速。经大规模强化学习后训练，V4.1 Flash 在多项 Agent 测试中超过 V4 Pro，官方计划逐步下线 V4 Pro 并将请求自动路由至 Flash。同时发布的 Harness v0.1.5 支持保留 KV Cache 更新系统提示词、文件处理、插件生态与多 Agent 协作，DeepSeek 正从单一模型转向 Agent 工作环境。

💡 主要观点

  1. CED 非对称架构让大参数模型以低激活成本运行 V4.1 Flash 总参数 552B，但输入阶段激活约 8B、输出阶段约 16B，通过区分理解与生成的计算需求，在保留能力上限的同时降低实际推理开销。
  2. CSA2 与 FP4 KV Cache 共同缓解长上下文效率瓶颈 CSA2 通过跨层复用 KV Cache 和 Top-K 索引减少重复计算，FP4 KV Cache 进一步压缩存储，使 HBM 需求降至四分之一、SSD 降至八分之一，相比初代 KV Cache 缩小约 437 倍。
  3. Flash 定位从轻量版升级为新一代主力模型 经过大规模强化学习后训练，V4.1 Flash 在多项 Agent 能力测试中超过 V4 Pro，官方计划逐步下线 V4 Pro，并将 deepseek-v4-pro 请求自动路由至 V4.1 Flash 并按 Flash 价格计费。
  4. Harness v0.1.5 把模型调用扩展为 Agent 工作环境 新版支持保留 KV Cache 更新系统提示词、上传图片与 PDF、工作区文件管理、插件生态，以及父子 Agent 双向通信和实验性 Agent Teams，降低连续 Agent 任务的上下文重算成本。

💬 文章金句

  • V4.1 Flash 总参数规模达到 552B，但输入阶段激活参数约为 8B，输出阶段激活参数约为 16B。
  • 与上一代模型相比，DeepSeek V4.1 Flash 对 HBM 的需求降低至原来的四分之一，对 SSD 的需求降低至原来的八分之一。
  • 如果与初代模型相比，DeepSeek 表示，目前 KV Cache 规模已经缩小约 437 倍。
