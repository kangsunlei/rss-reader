扣子 3.0 正式上线：新一代 AI 团队，从扣子开始

6/1/2026, 7:46:00 AM

📌 一句话摘要

扣子 3.0 正式上线，通过项目空间、多端协同和技能商店，将 Agent 从单点工具升级为可协作的 AI 团队，开启人与 Agent 协作的新方式。

📝 详细摘要

本文是字节跳动旗下扣子（Coze）平台 3.0 版本的官方发布公告。文章核心阐述了扣子 3.0 的定位转变：从单一的 AI 助手升级为「新一代 AI 团队」协作平台。新版本引入了「项目空间」概念，允许用户在同一个上下文中创建、调度和管理多个 Agent，实现任务拆解与接力协作。同时，扣子打通了网页端、桌面端和手机 App 三端，支持 Agent 处理本地文件，并可通过手机远程调度电脑端的 Agent（如 Claude Code、Codex CLI）。此外，升级后的「技能商店」提供了金融、法律、科研等领域的专家级技能包，让 Agent 能更专业地处理特定任务。文章还介绍了与扣子编程（code.coze.cn）和视频项目（搭载 Seedance 2.0）的深度整合，支持对话式开发和视频创作。整体而言，这是一篇产品功能宣发文章，详细介绍了扣子 3.0 在 Agent 协作、多端协同和专业化能力上的核心更新。

💡 主要观点

  1. 扣子 3.0 的核心是引入「项目空间」，实现多 Agent 协作。 项目空间是一个独立的任务管理空间，可以容纳目标、成员、多个 Agent 和过程产出，让复杂任务在统一的上下文中拆解、分配和推进，实现人与 Agent 的团队式协作。
  2. 三端全面打通，实现多设备协同和远程调度。 网页端、桌面端和手机 App 数据同步，Agent 可以处理本地文件，用户甚至可以通过手机 App 远程调度电脑端的本地 Agent（如 Claude Code），实现任务在不同设备间的无缝接力。
  3. 升级技能商店，提供专家级技能包，提升 Agent 专业度。 技能商店提供了金融、法律、科研等领域的权威数据集和技能包，用户可以一键为 Agent 添加行业语境，使其能更专业地处理特定领域的复杂任务。
  4. 与扣子编程和视频项目深度整合，支持对话式创作。 扣子 3.0 打通了编程项目（code.coze.cn）和视频项目（Seedance 2.0），用户可以通过对话式交互完成网页/App 开发或视频创作，并支持多人协作和导出至剪映等工具。

💬 文章金句

  • 开启人和 Agent 协作新方式
  • 我们把 Agent 带进了更完整的工作现场
  • 在升级后的扣子中，你可以创建项目，召集不同 Agent，完成从想法、讨论到执行和交付，让人和 Agent 像真正的团队一样一起工作。
  • 人负责设定目标、判断方向和确认结果，Agent 负责各自擅长的环节，并围绕同一个目标接力。
  • Agent 不再只是某个人手边的助手，而是项目里的协作成员。
