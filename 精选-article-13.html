RSInfer：首个 RSI 原生 LLM 推理引擎，秒级多卡热更新，真实 Agent 吞吐超越 DeepInfer

11/24/2026, 9:48:00 AM

📌 一句话摘要

RSInfer 是首个面向递归自我改进（RSI）的 LLM 推理引擎，实现秒级多卡热更新，实测显示其在 DeepSeek-V4.1-Flash-1017 上超越 DeepInfer，Agent 吞吐提升 25.6%--31.8%。

📝 详细摘要

本文介绍了 RSInfer——首个从第一性原理构建、专为递归自我改进（RSI）优化的生产级 LLM 推理引擎。它通过极简微内核与插件化 Unit 架构，将代码生命周期与 GPU 物理状态解耦，实现秒级热更新。文章详细阐述了七级动作阶梯、后台 CUDA 编译、TLA+ 形式化验证等安全机制，并在 NVIDIA SM100 集群上完成从 Qwen3.8-27B 到 DeepSeek-V4.1-Flash-1017 的跨代演进验证。实测数据显示，RSInfer 在 4×SM100 上实现 95 次在线更新、0 次重启，稳态吞吐显著超越 DeepInfer，且在 AgentX 验证集和盲测集中分别提升 25.6%--26.5% 和 19.0%--31.8%。

💡 主要观点

  1. RSInfer 的微内核与 Unit 架构 引擎采用 7 个子系统的微内核（仅 10，055 行 Python 代码），将 44 个可热重载 Units 拆分为 10 个长生命周期 State Units 和 34 个无状态 Logic Units，实现代码热更新时无需重新加载权重或显存池。
  2. 七级动作阶梯与安全热更新机制 通过三种绑定模式（Live、By-Address、By-Value）将改动映射到 Rung 0--6 七级台阶，结合后台 CUDA 编译、两轮提交屏障和 TLA+ 形式化验证，确保多卡原子变更的同时维护生产级可靠性。
  3. 跨代演进验证与性能超越 在不改动微内核代码的前提下，RSInfer 从 Qwen3.8-27B 演化至 4 卡 DeepSeek-V4.1-Flash-1017，实测显示 Decode 吞吐达 SGLang 的 104.5%，在 AgentX 场景下超越 DeepInfer 25.6%--31.8%。
  4. 秒级热更新提升 Agent 研发效率 单卡 SM100 上热切换仅需 1.00 秒，4 卡部署下 5.18 秒中位延迟；6 小时自主 RSI 会话中完成 95 次在线更新、0 次重启，显著缩短了 Agent 迭代的冷启动时间。
