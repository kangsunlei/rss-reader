V3→R1→V3.2｜一文看懂 DeepSeek 技术演进

12/6/2025, 10:56:00 AM

📌 一句话摘要

文章深入剖析了 DeepSeek 大模型从 V3 到 V3.2 的技术演进，详细介绍了 MoE、MLA、RLVR、DSA 以及自验证自改进等核心技术。

📝 详细摘要

本文系统性地追溯了 DeepSeek 大模型从 V3 到 V3.2 的演进历程，详细阐述了每个主要版本背后的技术创新与考量。首先，文章介绍了 V3 版本中 MoE（专家混合）架构和 MLA（多头潜在注意力）机制，分别解决了大模型效率与长序列显存占用的问题。接着，R1 版本引入的 RLVR（可验证奖励的强化学习）训练范式，通过程序自动验证答案，显著提升了模型在数学和代码等推理任务上的准确性和可靠性，并阐述了其与传统 RLHF 的区别。V3.1 标志着 DeepSeek 向混合模型的转变。随后，V3.2-Exp 版本核心创新 DSA（DeepSeek 稀疏注意力）机制，通过让模型自主学习关注关键 token，将注意力计算复杂度从 O(L²)降至 O(L×k)，大幅提升了长文本处理效率。最后，文章重点分析了 DeepSeekMath V2 中验证的自验证（Self-Verification）和自改进（Self-Refinement）技术，如何通过多模型协作和迭代优化，确保模型推理过程的严谨性与答案的精确性，最终这些技术被整合到 V3.2 中，使其成为一个兼具强大性能、高效推理和严谨逻辑的产品级模型。

💡 主要观点

  1. V3 的核心创新 MoE 和 MLA 机制，有效提升了大模型效率与显存利用率。 MoE 通过激活部分专家实现大参数量与高效率兼顾；MLA 通过压缩 KV Cache 降低显存占用，解决长文本推理难题。
  2. R1 引入 RLVR 训练范式，利用程序可验证奖励提升模型推理能力和可靠性。 RLVR 摆脱了对昂贵的人工标注和不精确的奖励模型的依赖，通过直接程序验证数学、代码等任务的答案，实现了更准确的强化学习。
  3. V3.2-Exp 引入 DSA 稀疏注意力，显著降低长序列计算复杂度，提升推理效率。 DSA 使模型能自主学习关注关键 token，将注意力计算复杂度从 O(L²)降至 O(L×k)，在大规模长文本场景下实现高效推理。
  4. DeepSeekMath V2 验证的自验证与自改进技术，确保模型推理过程的严谨性与答案准确性。 自验证通过独立的验证器和元验证器，避免模型“自欺”，确保推理逻辑正确性；自改进则让模型能根据反馈迭代优化答案。

💬 文章金句

  • V3.2 的性能已经追平 GPT-5 和 Gemini 3.0 Pro，而且开源
  • R1 用的是 RLVR （Reinforcement Learning with Verifiable Rewards，可验证奖励的强化学习）
  • MLA 的做法是：先把 key 和 value 压缩到一个低维空间，存压缩后的版本
  • DSA 不用固定窗口，让模型自己学习应该关注哪些 token
  • 用同一个模型既生成又验证，模型会自己骗自己
