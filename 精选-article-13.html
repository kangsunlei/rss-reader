130: 手机 Agent 大幕拉开！从刚上线的 AutoGLM 2.0 聊起，大模型如何改造手机|Agent#4

8/20/2025, 11:00:00 PM

📌 一句话摘要

深入探讨了智谱 AutoGLM 2.0 作为首个手机通用 Agent 的发布，分析了 AI Agent 在移动端的市场潜力、技术挑战及未来生态发展。

📝 详细摘要

本期播客聚焦于人工智能 Agent 在手机和电脑端的应用，特别是智谱 AI 最新发布的 AutoGLM 2.0。该产品作为首个面向手机端的通用 Agent，无需邀请码且免费开放，能够执行点外卖、买票、订餐等多种生活服务和工作提效任务。节目强调了手机端 Agent 市场相较于网页端的巨大潜力，并指出其已成为大模型公司、移动互联网巨头和手机厂商的兵家必争之地。嘉宾刘潇，AutoGLM 2.0 的算法、工程和产品负责人，深入分享了产品从内测到全面上线的技术洞察和研发历程。讨论涵盖了 AI Agent 在跨应用操作、用户隐私安全、支付机制升级等方面的挑战与解决方案。特别提及了强化学习，尤其是端到端在线强化学习在提升 Agent 能力、实现多步复杂任务中的关键作用，以及 Agent Bench 等评估基准的建立。同时，节目探讨了 GUI（图形界面）和 API（接口）两种 Agent 操作模式的优劣与共存策略，以及通用 Agent 与垂直应用 Agent、手机厂商自研 Agent 之间的竞合关系。最后，展望了 AI Agent 连接更多终端、实现全天候后台运行的未来，强调行业需共建生态，共同推动 AGI 目标的实现。

💡 主要观点

  1. 手机端 AI Agent 市场潜力巨大，AutoGLM 2.0 率先探索通用 Agent 应用。 相较于网页端，手机用户基数更广，AI Agent 在手机端能深入日常生活与工作场景，提供点外卖、工作提效等服务，成为兵家必争之地。
  2. AI Agent 在移动端面临隐私安全、跨应用操作及用户心智培养挑战。 需确保用户数据安全和支付环节可控，同时要解决 Agent 跨应用执行的复杂性，并引导用户理解和接受 AI Agent 作为个人助理的使用模式。
  3. 强化学习是提升 AI Agent 能力、实现复杂多步任务的关键技术。 通过端到端在线强化学习和大规模环境仿真，AI Agent 能像人类一样通过探索和试错来学习使用手机与电脑，显著提升任务完成能力和稳定性。
  4. AI Agent 与 APP 厂商、手机厂商将长期竞合，GUI 与 API 模式共存。 Agent 与 APP 厂商可通过 GUI 或 API 合作，共同提升用户体验和流量。手机厂商也在积极布局，未来将形成通用与垂直 Agent 并存的复杂生态。
