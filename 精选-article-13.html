重塑记忆架构：LLM 正在安装「操作系统」 ｜ 机器之心

7/16/2025, 5:00:00 AM

📌 一句话摘要

文章深入探讨了大型语言模型（LLM）的记忆缺陷，详细解析了长上下文处理与记忆管理的关系，并重点介绍了受操作系统和人类大脑启发的多种创新型 LLM 记忆系统架构。

📝 详细摘要

文章围绕大型语言模型（LLM）长期记忆能力不足这一核心问题展开，指出尽管上下文窗口不断扩大，LLM 仍面临“失忆”挑战。文章首先区分了“长上下文”与“记忆”的概念，并详细阐述了长上下文处理的四大能力（长度泛化、高效注意力、信息保留、提示词利用）。接着，文章将 LLM 记忆分为事件记忆、语义记忆和程序性记忆，并介绍了实现 LLM 记忆的两种主要方法：通过 RAG、分层摘要和滑动窗口推理等技术提升长上下文能力；以及通过固定/非固定记忆池来管理记忆。文章重点介绍了 MemGPT、MemOS、MemoryOS 和 MIRIX 等受传统操作系统内存机制启发的记忆系统，以及 Larimar 和 M+等受人类大脑记忆模式启发的创新研究，为 LLM 构建持久、可管理的记忆提供了多元视角和解决方案。

💡 主要观点

  1. LLM 的记忆缺陷限制了其长期交互和智能体系统的发展 尽管上下文窗口不断增大，LLM 仍难以在多轮对话中维持一致性，记忆是实现反思和规划的关键，也是构建高级智能体系统的基础。
  2. 长上下文处理能力与记忆能力紧密相关且可协同工作 长上下文是模型一次性处理历史文本的能力，而记忆是跨多轮对话的信息保留机制，两者可相互补充，共同提升模型性能。
  3. RAG 是构建 LLM 外部知识库和记忆系统的基础 RAG 通过检索外部知识增强 LLM 的生成能力，其动态更新和可扩展性为构建实时、可编辑的 LLM 记忆系统提供了有效途径。
  4. 受操作系统启发的记忆系统是解决 LLM 长期记忆的关键方向 MemGPT、MemOS 等研究借鉴传统分层内存管理机制，为 LLM 设计了持久、高效的记忆调度、融合和归档方案，使其拥有类似操作系统的记忆管理能力。
  5. 借鉴人类大脑记忆模式为 LLM 记忆管理提供新思路 Larimar 和 M+等项目受大脑情景记忆和神经激活存储方式启发，探索在隐空间中存储和管理记忆，以实现更高效、更接近人类的知识更新和泛化能力。

💬 文章金句

  • 超长上下文窗口的大模型也会经常「失忆」，「记忆」也是需要管理的。
  • LLM 存在一个内在的「记忆缺陷」，即拥有的上下文窗口是有限的，这严重限制了它们在多轮次、多会话的长期交互中维持一致性的能力。
  • 记忆系统本质上和 RAG 检索是几乎一致的，但记忆系统机制会在记忆存储的基础上增加更丰富的信息组织、信息管理和信息检索方法，将记忆存储管理与计算机操作系统的原理相结合，能够构建更加完善的记忆机制，使 LLM 拥有更持久的记忆。
  • 在论文《MemGPT: Towards LLMs as Operating Systems》中，作者提出使用一个 LLM 代理来管理该上下文窗口。
  • Larimar ------ 一种受大脑启发的新型架构，用于通过分布式情景记忆增强 LLMs。
