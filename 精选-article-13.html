GLM-5.4：瞄向泛 Coding，首个 Loop Transformer 带来的惊喜

11/23/2026, 9:42:00 AM

📌 一句话摘要

智谱发布 GLM-5.4，首个采用 Loop Transformer 架构的旗舰模型，实现 2-3T 级智能水平，开启泛 Coding 时代，支持代码生成视频、3D 建模等多场景应用。

📝 详细摘要

GLM-5.4 是智谱推出的首个采用 Loop Transformer 架构的旗舰模型，通过在不增加参数量的前提下，让共享权重的层循环执行多轮推理，等效获得更大尺寸模型的效果。模型智能水平达到 2-3T 级，在编程实战评测中表现突出，尤其在视觉 Coding、视觉复刻和长程任务方面。得益于代码和视觉能力的双重提升，GLM-5.4 能够用代码生成视频、构建游戏、完成 3D 建模和机械设计等。模型已向 GLM Coding Plan 全量用户开放，同步上线 ZCode、Trae、WorkBuddy、Qoder 等平台。

💡 主要观点

  1. Loop Transformer 架构实现深度推理提升 GLM-5.4 引入 Loop Transformer，让一组共享权重的层循环执行多轮，每轮在上一轮隐状态基础上继续推演。通过门控渐进更新、KV Cache 全局共享+滑窗独立、复用稀疏注意力索引等技术，显著降低了部署成本，使模型在参数不变的情况下获得更大尺寸模型的效果。
  2. 泛 Coding 能力开启，扩展至视频、3D、工程领域 GLM-5.4 在编程能力上实现质的飞跃，创作者 Mike Luan 用其从 0 到 1 完成视频创作，夜神不说话通过数学几何与 GLSL 着色器生成 3D 互动观鸟体验，亦有人用 FreeCAD 构建机械臂模型并通过 Blender 可视化。
  3. 推理链更长，Loop 的帮助越大 在 GPQA、MMLU-Pro 等基准上，Loop 模型平均输出长度下降 10%-14%，推理从 token 流转移到了循环带来的额外深度中，尤其在数学推理、长上下文和代码等任务上提升显著。
  4. 高效推理与丰富额度提升日常生产力 GLM-5.4 在非高峰时段速度最高可达 200 token/s，高峰时段仍能提供 70-80 token/s。通过模型结构与推理 Infra 的深度协同设计，把循环带来的额外开销压到了最低。Coding Plan V2/V3/团队版用户可享额度提升至 1.5 倍。

💬 文章金句

  • GLM-5.4 是我们第一代采用 Loop Transformer 架构的旗舰模型。收获了效果，智能水平达到 2-3T 级模型。
  • Loop Transformer 可以让一组共享权重的层循环执行，模型因此可以在参数量不变的情况下进行更深度的推理，等效获得更大尺寸的模型效果。
  • 为降低模型长上下文场景下的注意力成本，我们采用线性注意力与稀疏注意力相结合的混合架构。其中，线性注意力通过递归机制捕获局部依赖关系，稀疏注意力则借助轻量级索引器召回全局上下文。
  • 我们发现了一些问题，比如模型很容易进入"雷霆大思考"模式（但我们发现这种长时间思考可以持续提升效果------模型在思考中不断反思、自我修正，这正是我们在长程任务上一直想要的能力）。
  • GLM-5.4 在非高峰时段速度最高可达 200 token/s，高峰时段依然能提供 70-80 token/s。
