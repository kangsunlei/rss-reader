Xiaomi MiMo 携手 TileRT｜1T 模型首次突破 1000 tokens/s 输出速度

6/9/2026, 3:32:00 AM

📌 一句话摘要

小米 MiMo 与 TileRT 联合发布 MiMo-V2.5-Pro-UltraSpeed，通过 FP4 量化与 DFlash 投机解码的模型-系统协同设计，在通用 8 卡 GPU 上实现万亿参数模型首次突破 1000 tokens/s 输出速度。

📝 详细摘要

本文是小米大模型团队与 TileRT 推理系统团队的联合技术发布。文章宣布 MiMo-V2.5-Pro 旗舰模型在 UltraSpeed 模式下，输出速度首次突破 1000 tokens/s，并限时开放 API 申请与 Chat 体验。技术层面，文章详细拆解了实现这一突破的两大核心技术：FP4 混合量化（仅对 MoE Expert 进行 FP4 量化，保留其他模块精度）和 DFlash 块级 masked 并行预测投机解码（利用滑动窗口注意力实现常数级 draft 开销，在 Coding 场景达到平均 6.30 的接受长度）。系统侧，TileRT 通过常驻内核引擎与异构流水线协作，在微秒级尺度上消除算子边界带来的执行间隙。文章强调，这是模型与系统极致协同设计（Codesign）的成果，而非依赖专用硬件。最后展示了 10 秒生成贪吃蛇、1 分钟复刻 MacOS 等效果演示，并开源了 FP4-DFlash checkpoint。

💡 主要观点

  1. MiMo-V2.5-Pro-UltraSpeed 在通用 8 卡 GPU 上实现 1T 模型 1000+ tokens/s 输出速度。 通过模型-系统协同设计而非专用硬件，在标准 GPU 集群上实现了业界领先的推理速度，标志着万亿模型实时推理进入新阶段。
  2. FP4 混合量化是核心模型侧优化之一。 仅对 MoE Expert 进行 FP4 量化，大幅缩减模型体积与访存开销，同时通过 QAT 保持模型能力基本持平，其他模块保留原精度以避免退化。
  3. DFlash 块级并行预测投机解码打破传统 draft 瓶颈。 采用滑动窗口注意力使 draft 开销常数化，在 Coding 场景达到平均 6.30 的接受长度，大幅提升单次验证的 token 产出效率。
  4. TileRT 通过常驻内核与异构流水线消除微秒级执行间隙。 摒弃逐算子启动模式，让计算流水线常驻 GPU，实现数据搬运与计算的极致重叠，将通用 GPU 的物理潜能压榨到极限。
