📝 详细摘要

文章以泡泡玛特 2026 年一季报为引，指出其业绩增长但资本市场存在分歧的现状，进而深入分析公司创始人王宁的创业历程。通过 28 个关键切片，文章系统梳理了王宁从大学创业、转型潮玩、签约 Molly、搭建核心团队，到全球化布局、乐园探索等关键节点的选择逻辑。文章揭示了泡泡玛特的核心战略思想：坚持线下零售的「包裹感」、以「七分饱」原则克制放量、走反迪士尼的 IP 路径、用「尊重时间」的慢节奏对抗互联网焦虑。同时，文章也直面当前风险：单一 IP 依赖、海外流量退潮、成本压力等。最终结论是泡泡玛特是一家值得持续跟踪但需保持清醒的公司，其长期价值取决于能否在规模扩张中维持独特性。

💡 主要观点

  1. 泡泡玛特的成功源于创始人王宁一系列「反共识」的战略选择。 在移动互联网狂飙年代死磕线下零售，拒绝奶茶、社区团购等快钱诱惑，选择「尊重时间，尊重经营」的慢节奏，这些看似逆势的选择构成了公司的核心竞争壁垒。
  2. 泡泡玛特走的是反迪士尼的 IP 路径：不需要故事，靠高频产品迭代和场景陪伴建立情感连接。 在内容大爆炸时代，迪士尼通过电影做 IP 的效率在降低。泡泡玛特选择让 IP 通过门店、乐园、盲盒等高频触点出现在大众身边，用「陪伴」替代「叙事」建立情感价值。
  3. 全球化战略的核心是开放而非输出：在世界范围内挖掘本地化艺术家。 CRYBABY 在泰国的成功验证了全球化不是将中国 IP 强推世界，而是挖掘全球艺术家资源。泡泡玛特采取「由东向西」的务实路径，从东南亚起步，用业绩证明自己。
  4. 当前泡泡玛特面临单一 IP 依赖、海外增长可持续性、成本压力等核心挑战。 LABUBU 带来的新用户对品牌其他 IP 无感，原材料和航运成本上涨侵蚀利润，海外流量退潮。公司需要证明从 1 到 100 的体系化能力，而非仅靠直觉和坚持。
