Z Potentials｜专访 YC 录取的华人团队，用 Agent 重塑 Excel 的亿万级生意，她押注电子表格的下一个 Gamma

10/25/2025, 3:02:00 PM

📌 一句话摘要

CambioML 创始人 Rachel Hu 分享了其团队如何利用 AI Agent 重塑 Excel，专注于解决非专业用户的痛点，并在亿万级电子表格市场中掘金的创业历程与思考。

📝 详细摘要

文章深入访谈了 CambioML 创始人 Rachel Hu，她从 AWS 机器学习科学家背景出发，创立 CambioML 并成功获得 Y Combinator 录取。她提出“模型是电力，创业公司应专注于‘最后一公里’接入”的理念，并据此将产品方向从大模型微调工具转向了电子表格 AI Agent。该 Agent 旨在服务全球数亿 Excel 和 Google Sheets 的非专业用户，通过数据接入、清洗、分析和可视化，解决传统数据处理的繁琐问题。文章详细探讨了 AI Agent 在质量、速度和成本方面的技术挑战，以及 CambioML 如何通过专用模型和工作站环境实现差异化竞争。Rachel 还分享了其对 AI 行业发展、团队建设的独到见解，并强调用户信任和长期成本优势是成功的关键。

💡 主要观点

  1. AI Agent 重塑 Excel，专注于解决非专业用户的痛点。 CambioML 通过 AI Agent 自动化数据清洗、结构化转换、报表生成和可视化，服务全球 7 亿 Excel 和 9 亿 Google Sheets 用户中 90%的非专业群体，极大提升数据处理效率。
  2. 创业公司应聚焦“最后一公里”应用，而非模型底层研发。 创始人 Rachel Hu 认为大模型是“电力”，创业公司应依托巨头的基础模型，专注于开发解决实际问题的“电器”，提供让用户省时省钱的工具。
  3. AI Agent 面临质量、速度和成本挑战，需确保每一步准确性。 针对 Agent 幻觉问题，CambioML 投入巨大精力进行评估验证，确保在多步骤任务中每一步都不出错，并通过专用模型优化成本和速度，以赢得用户信任。
  4. 电子表格市场规模巨大，AI Agent 有望创造亿万级营收。 Excel 和 Google Sheets 用户基数远超 PPT，且涉及资金和数据决策，商业价值更高。AI Agent 在此领域有广阔发展空间，将诞生多家优秀公司。

💬 文章金句

  • 模型更像电力。百年前，每一家电器制造商都想做自己的发电厂，但最终，真正的价值来自谁能在电力基础上造出更节能、更好用的产品。
  • 我们要做电子表格领域的 Gamma 这个方向。就像 Gamma 重新定义了 PPT 一样，我们希望用 AI Agent 重新定义 Excel 的工作方式。
  • 我们真正服务的是那 90%的非专业用户，他们只是希望用 Excel 辅助决策。
  • 我们不可能第一天就实现 L5 级别，而是要不断覆盖各种边缘情况。在某些业务场景中，我们可以确保每一步、每个数字都有公式或原始数据支撑，而不是凭空猜测。
  • 长期来看，竞争终将回归到成本。大模型就像电力，放到百年前，大家都是电器制造商，而大模型厂商则是发电厂。
  • 我相信这个行业完全有可能实现从千万到数亿美元的 ARR，行业天花板非常高。
