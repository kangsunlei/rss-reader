Agent 时代启示录: 当 Agent 作为新物种加入经济系统

4/21/2026, 12:02:00 PM

📌 一句话摘要

本文提出 Agent 时代的关键市场坐标已从 To B/To C 转变为 To Human/To Agent，并系统分析了 Agent 作为新经济物种将如何颠覆软件形态、商业模式和基础设施，同时指出了未来的创业投资机会。

📝 详细摘要

文章认为，Agent 时代的到来正在颠覆过去 30 年基于 DAU/MAU、To B/To C 的互联网分析框架。核心论点是市场坐标应转变为 To Human（服务具体任务的人）和 To Agent（Agent 本身成为生产者和消费者）。作者从多个维度展开论述：旧尺度（如用户规模、付费逻辑）正在失效；软件形态正从为人类设计的 GUI 向为 Agent 设计的原生格式（如 CLI）迁移；范式转移将催生新赢家，OpenAI 的庞大用户基础可能成为其适应 Agent 范式的包袱。文章进一步指出，Agent 作为新物种加入经济系统，将形成生产侧和消费侧均由 Agent 主导的双边市场，其商业模式将从卖 Token 转向类似 AWS 的云平台生态。最后，文章将 Agent 解构为 Model + Harness，并基于一个四层结构（Runtime、Context、Orchestration、Model）分析了在 Agent 基础设施、垂直领域 Harness 和 Orchestration 层（如身份、支付）的创业投资机会。

💡 主要观点

  1. Agent 时代的关键市场坐标是 To Human / To Agent，而非传统的 To B / To C。 To Human 指服务有具体任务的人，模糊了 B/C 界限；To Agent 则意味着 Agent 本身成为独立的生产者和消费者，这是一个全新的增量市场和物种级别的变化。
  2. 软件形态正经历系统性格式迁移，从为人类优化的 GUI 转向为 Agent 优化的原生接口。 未来的软件可能不再是完整界面的应用，而是 Model + Agent Harness + 按需生成的人类审阅层。CLI 等底层接口将成为 Agent 的‘母语’。
  3. Agent 将形成生产与消费的闭环，其商业天花板是全球白领人力成本，商业模式向云平台演进。 Agent 替代的终极预算池是人力成本（全球约 18-20 万亿美元）。模型公司的商业模式正从卖 Token 扩展为卖 OS/云平台式的生态，通过 Harness（状态、记忆）建立护城河。
  4. 在 Agent 范式下，旧范式的领先者可能因路径依赖而陷入困境，为新原生公司创造机会。 以 OpenAI 为例，其庞大的对话用户基础可能成为优化 Agent 深度任务的包袱，而像 Anthropic 这样没有历史包袱的公司可能更灵活地构建 Agent-native 产品。
  5. 围绕 Agent 的基础设施（Runtime、垂直 Harness、Orchestration）存在巨大的创业投资机会。 需要为 Agent 重做基础设施（如沙盒、状态管理）、在垂直领域构建深度 Harness、并解决 Agent 作为一等公民的身份、支付等 Orchestration 层问题。

💬 文章金句

  • Anthropic 的 DAU 总和只有 OpenAI ChatGPT 的 2%，但两家公司的 ARR 已经追平了。用 DAU 这样的互联网指标给 AI 公司估值，就像 1999 年用页面停留时间给 Google 估值。
  • To Agent 的定义：Agent 本身成为生产者和消费者。它自主搜索、调用 API、开启 runtime、做采购决策、完成支付。在这里，商业逻辑的主体发生了物种替换。
  • 软件从设计之初是 To Human 的。GUI、软件中的每一层抽象都是为了降低人类操作的认知负担，而 Agent 不需要这些。
  • OpenAI 的 8 亿用户是战略包袱，不是战略资产。每一个面向轻度对话用户的优化，都是对 Agent 深水区的一次妥协。
  • Agent 的商业模式开始不再只是 token 定价，而是接近 AWS 云平台模式。以前客户今天用 Claude 明天可以切 GPT，切换成本是写几行代码；现在 Agent 定义、状态、记忆如果能全部存在 Anthropic 这儿，切换成本就是 AI workflow 的重建。
