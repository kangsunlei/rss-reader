发布 Qwen3，阿里云拉开新一轮开源模型竞赛的序幕

4/29/2025, 7:18:49 AM

📌 一句话摘要

阿里云发布 Qwen3，一款关注混合推理和 Agent 能力的开源模型，旨在提升开发者和 B 端用户体验。

📝 详细摘要

阿里云发布了新一代开源大模型 Qwen3，其旗舰型号参数量仅为 DeepSeek-R1 的 1/3，但性能全面超越 R1 和 OpenAI-o1 等顶尖模型。Qwen3 的一大亮点是其国内首个混合推理模型设计，能够根据任务复杂度灵活调整推理方式，平衡推理质量与成本。此外，Qwen3 还增强了 Agent 能力，优化了对 MCP 协议的支持，降低了 Agent 开发的复杂性。阿里云希望通过 Qwen3 在开源模型领域建立生态优势，与 DeepSeek、Meta 等厂商形成差异化竞争。Qwen3 的发布标志着开源模型新一轮竞赛的开始，同时也预示着 AI 模型正朝着混合推理和 Agent 驱动的方向发展。

💡 主要观点

  1. Qwen3 性能全面超越 R1 和 OpenAI-o1，登顶全球最强开源模型 Qwen3 在 AIME25、LiveCodeBench 和 ArenaHard 等多个测评中刷新了开源模型的性能记录，展示了其强大的综合能力。
  2. Qwen3 是国内首个混合推理模型，能灵活控制思考预算 Qwen3 集成了思考模式与非思考模式，用户可以根据任务需求调整推理方式，实现推理质量和成本之间的平衡。
  3. Qwen3 增强了 Agent 能力，并优化了对 MCP 协议的支持 Qwen3 通过支持 MCP 协议和工具调用，降低了 Agent 开发的复杂性，提升了模型在实际场景中的应用能力。
  4. 阿里云致力于构建开源生态，与竞争对手形成差异化 阿里云通过全方位开源和贡献，以及与自身电商、钉钉、夸克等 AI 应用的结合，构建了独特的开源生态系统。

💬 文章金句

  • Qwen3 家族的多尺寸、内置 MCP 支持、支持混合推理等实用性的功能点。
  • Qwen3 正在迈向以训练 Agent 为中心的阶段，当前 Qwen3 优化了 Agent 和 代码能力，同时也加强了对 MCP 的支持。
  • 阿里云是全世界唯一一家积极研发基础大模型并全方位开源、全方位贡献的云计算厂商。
  • Qwen3 是国内首个「混合推理模型」
