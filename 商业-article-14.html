和四位一线创业者聊聊：ToC Agent 那么卷，ToB 的机会在哪、落地卡点在哪？

8/6/2026, 11:16:00 AM

📌 一句话摘要

四位一线创业者从金融、营销、搜索、语音客服等不同视角，探讨了 ToB Agent 落地的核心挑战：可靠性、闭环执行、责任归属与组织适配，而非模型智能本身。

📝 详细摘要

本文是 Founder Park 在 AGI Playground 2026 上的一场圆桌对谈实录。四位来自不同 ToB 领域的创业者——Airwallex（全球支付）、易点天下（数字营销）、Ateve（Agent 搜索）、WIZ.AI（语音客服）——围绕 Agent 在企业环境中的真实落地展开讨论。核心共识是：Agent 的下一阶段不取决于它有多聪明，而在于能否持续、可靠、低成本地交付结果。文章深入探讨了多个关键议题：语音 Agent 的响应时间与首次呼叫解决率、营销 Agent 的 MCP 标准化与成本分层、Agent 搜索的自我进化与医疗行业 Know-how、金融 Agent 的权限控制与责任归属、以及企业从 Demo 到生产部署的信任鸿沟、数据鸿沟与组织鸿沟。多位嘉宾指出，企业组织架构而非技术是当前最大瓶颈，未来需要将组织基础设施从为人类设计改造为适应 AI Agent。

💡 主要观点

  1. Agent 落地的分水岭是能否端到端闭环执行，而非智能水平。 Airwallex 的吴恺提出 2×2 矩阵：执行闭环+智能瓶颈（如 AI Coding）最具颠覆性；执行闭环+智能非瓶颈（如自动化对账）同样有价值；而最后一公里仍需人工的流程会成为瓶颈，大幅降低自动化效率。
  2. 企业组织架构是 Agent 落地的真正瓶颈，而非技术或模型。 易点天下的 Bill Cao 指出，通过 MCP 对工具和数据库进行标准化是 AI 原生转型的关键，但真正这样做的公司不多。Ateve 的 Eileen Weng 补充了信任鸿沟、数据鸿沟和组织鸿沟三大障碍，传统层级结构并非为 Agent 设计。
  3. Agent 自主权越大，责任边界越要清楚，Human on the loop 是当前主流。 Airwallex 对不可逆操作（如转账）要求用户确认，可撤销操作则减少人工介入。WIZ.AI 的陆剑锋强调，信任来自对错误的控制，语音 Agent 需要设置护栏防止越狱和违规回应，但防御机制不能过度推高延迟和成本。
  4. Token 成本仍是障碍，但'错误的 Token'（Agent 犯错后的返工与人工审查）成本更高。 Ateve 的 Eileen Weng 指出，Agent 探索错误路径、犯错后返工，加上人工审查，总成本远超首次推理调用。未来需像组建人才团队一样组建 Agent 团队，不同岗位匹配不同能力与成本的模型。
  5. 数字营销正从单任务 AI 向 Agent 对 Agent 的网络演进。 易点天下通过 MCP 标准化所有工具和数据源，让 Agent 贯穿从数据检索、分析到智能决策的完整工作流。未来 SSP 的 Agent 可直接与 DSP 的 Agent 对话，取代僵化的固定协议。

💬 文章金句

  • 从技术上说，实现完全自主并不难，真正的问题是责任归属。
  • 信任来自你能多好地控制和减少错误。
  • 90%和 100%之间存在巨大差距。如果 Agent 能完成 100%的流程，采用速度会快得多。
  • 企业组织架构才是真正的瓶颈，而不是技术或模型。
  • 今天最昂贵的是'错误的 Token'。
