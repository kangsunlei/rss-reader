百度、阿里争夺 AI 定义权

5/9/2025, 10:34:00 AM

📌 一句话摘要

分析百度、阿里等大厂通过 MCP 协议争夺 AI Agent 生态定义权和控制权的竞争格局

📝 详细摘要

文章深入探讨了百度、阿里等科技巨头如何通过推广 MCP（模型上下文协议）来争夺 AI Agent 领域的定义权和生态控制权。内容揭示了 MCP 协议的技术本质及其在 AI 工具调用标准化中的作用，分析了各大厂商推动 MCP 背后的商业动机和生态战略。文章特别指出 PC 端与移动端屏幕限制对 Agent 产品体验的影响，以及开源策略在生态扩张中的关键作用。虽然 MCP 本身并未带来新的技术能力，但统一标准有助于降低开发成本、扩大生态规模。同时，作者预见了未来 AI Agent 应用可能演变为大厂间的流量和广告竞争，并详细讨论了商业化路径和潜在问题，包括开源与商业化的平衡策略。

💡 主要观点

  1. MCP 协议成为大厂争夺 AI 定义权和生态控制权的关键 百度、阿里等通过推广 MCP 协议试图建立行业标准，掌握 AI Agent 生态的话语权和控制权，虽然协议本身并未带来新技术能力，但统一接口标准降低了开发门槛
  2. 开源策略与生态完备性决定未来竞争优势 大厂通过开源 MCP 服务和上架模型平台扩大生态规模，数据壁垒和生态完整性将成为未来竞争的关键差异化因素，同时面临开源与商业化的平衡挑战
  3. 终端屏幕限制显著影响 Agent 产品体验 移动端屏幕空间限制和 PC 端交互效率问题构成技术挑战，百度心响等产品正在探索跨终端适配方案以优化用户体验
  4. AI Agent 商业化将转向广告和流量模式 文章预测 AI Agent 应用最终可能演变为流量分发平台，通过广告、数据变现和生态闭环延续现有互联网商业模式
  5. 统一标准增加开发者对大厂生态的依赖 MCP 协议简化了 AI 工具调用流程，但筛选机制使开发者更依赖大厂生态体系，后期可能形成流量竞价格局

💬 文章金句

  • MCP 仅是个协议，并没有提升或给大模型带来任何新的能力
  • 生态越完备，数据壁垒越高，在行业中的话语权就越大
  • Agent 应用似乎可以杀死多款应用，但杀不死既有的广告投流体系
  • 背后的成本太大了，假设把 Tool Use 做成 MCP，乘以 1000 或许还是能承担的成本，但如果乘以 1000 万、1 亿呢
  • 大厂通过 Agent 应用引流，向商家收取广告费；用户行为数据被用于精准广告投放
  • 手机屏幕太小，想要用户看清楚东西或者快速交互，很困难。反之，PC 端屏幕虽大，但问题是如何高效利用起来
