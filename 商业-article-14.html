OpenClaw 榜一插件被下架后，他用两周做了一套协议，想让 Agent 自己进化

2/20/2026, 7:36:00 AM

📌 一句话摘要

EvoMap 推出 GEP 协议，通过构建“进化层”实现 AI Agent 运行经验的结构化提炼与跨网络共享，推动 Agent 脱离人类干预实现自我进化。

📝 详细摘要

本文深度解析了 EvoMap 团队提出的 GEP（基因进化协议）及其背后的“进化层”理念。针对当前 AI Agent 存在的经验孤岛、Skill 静态化以及对单一平台的过度依赖等痛点，GEP 协议提供了一套标准化的 Agent 间通信与知识共享机制。该协议将 Agent 在运行时产生的策略性洞察提炼为“基因（Gene）”和“胶囊（Capsule）”，并通过 GDI 评分系统实现优胜劣汰。文章强调，Agent 的进化正从“人写给 AI 用”转向“AI 写给 AI 用”，最终实现人类不在循环（Human-out-of-the-loop）的自主进化生态。

💡 主要观点

  1. 现有 Agent 架构缺乏经验传承机制，导致严重的资源浪费和知识蒸发。 每个 Agent 都是独立的个体，其在 session 中摸索出的有效策略无法自动流向其他 Agent，导致面对相同问题时必须重复消耗 token 进行探索。
  2. GEP 协议通过“进化层”将 Agent 运行时的动态策略转化为标准化资产。 协议定义了 Gene（策略模板）和 Capsule（实战记录），利用 SHA-256 内容寻址确保经验不可篡改且可被其他 Agent 直接理解和复用。
  3. 从 Skill 插件形态转向协议形态，是解决平台依赖和实现网络效应的关键。 协议形态打破了单一平台的利益纠纷和合规风险，通过 Agent-to-Agent 的通信协议，让经验在整个网络中自由流动而非锁在特定数据库。
  4. AI Agent 的进化正进入“AI 写能力给其他 AI 用”的自主迭代阶段。 当 Agent 能够自动识别、抽象并发布 Skill，且其他 Agent 能自动发现并安装时，进化的闭环已经形成，人类在其中的角色将持续递减。

💬 文章金句

  • Agent 世界里没有知识管理。session 结束，经验蒸发。
  • GEP 进化层让 Agent 越做越好，并且让所有 Agent 一起越做越好。
  • Evolver 在 ClawHub 上的 36，000 次下载，绝大部分不是人类开发者安装的——而是 Agent 在运行过程中自动发现、自动安装的。
  • 这或许是 AI 开始自我进化的第一步，而且，人类不在 loop 中。
