o3 解读：OpenAI 发力 tool use，Manus 们会被模型取代吗？

4/30/2025, 12:31:39 PM

📌 一句话摘要

文章解读 OpenAI 最新 o3 模型在 tool use、agentic 能力和多模态 CoT 方面的提升，并探讨其对 Agent 产品格局的影响及未来发展方向。

📝 详细摘要

文章深入分析了 OpenAI 发布的 o3 和 o4-mini 模型，重点关注 o3 在 agentic 能力、多模态 CoT 以及 tool use 方面的显著提升。通过与 Manus 等 Agent 产品的对比测试，揭示了 o3 在完成复杂任务时的优势。尤其是在图像理解和问题解决方面，o3 的多模态 CoT 展现出强大的应用潜力。文章还探讨了 OpenAI 开源 Codex CLI 的战略意图，并分析了用户对 o3 模型在视觉推理和 coding 能力方面的负面评价。最后，文章结合强化学习领域的最新进展，展望了 Agent 产品未来的发展趋势，强调了从经验中自主学习的重要性。

💡 主要观点

  1. o3 模型 agentic 能力显著提升，更接近 Agent 的理想形态 o3 在 tool use 上的无缝体验和更长的思考推理过程，使其在复杂任务中表现出色，接近 Deep Research 等专业 Agent 产品。
  2. 多模态 CoT 解锁新应用机会，提升模型在 factual 任务中的可用性 o3 能理解并操作图像，结合视觉与文本推理，在处理模糊图像和地理位置识别等任务时表现出强大的能力。
  3. OpenAI 开源 Codex CLI 旨在普及 coding agent，占领市场 Codex CLI 通过多模态推理和与本地代码环境的集成，降低了 AI 参与实际编程任务的门槛，加速了 AI 在开发领域的应用。

💬 文章金句

  • o3 是目前最先进的推理模型，有最全面的推理能力、最丰富的 tool use 方式和全新的多模态 CoT 能力
  • Agentic 能力是 o3 和之前 o 系列模型区别最大的地方，o3 已经接近我们对 agent 的想象了
  • OpenAI 选择在自身暂时落后的地方，比如 coding 和终端操作，先把竞争对手已有的产品普及化，从而占领市场
  • large-scale RL 呈现出与 GPT 系列 pre-training 相同的规律：more compute = better performance
  • 新一代 agent 需要从 experience 中学习来达到 superhuman 水平
