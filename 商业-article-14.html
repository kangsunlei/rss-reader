海外 Agent 落地有哪些新趋势？听听 OpenAI 第 5 号员工创办的公司这么看

3/22/2025, 7:34:51 PM

📌 一句话摘要

Convergence AI 工程负责人分享了海外 Agent 落地的新趋势，重点介绍了其公司在构建 Agent 核心竞争力、解决通用 Agent 开发痛点以及 Proxy 产品实践方面的经验与思考。

📝 详细摘要

文章主要围绕 AI Agent 的开发与落地、创业公司如何构建核心竞争力以及通用型 Agent 的商业化与未来发展展开讨论。Convergence AI 的工程负责人郑浅分享了通用型 Agent 开发面临的痛点，如速度与延迟、身份认证、用户引导和基础设施等方面。他认为 Agent orchestrator 是创业公司的核心壁垒，并详细阐述了其在任务规划、并行处理和多 Agent 协作中的重要性。文章还探讨了通用型 Agent 和垂直型 Agent 的边界与发展趋势，并介绍了 Convergence AI 的产品 Proxy 在自动化任务、用户认证管理和并行 Agent 等方面的特点与优势，Proxy 通过自动化功能帮助用户周期性重复执行任务，通过用户认证管理确保 Agent 在安全可控的环境中执行任务，并通过并行 Agent 极大地提升运行效率。文章为 Agent 创业公司提供了有价值的参考，强调了 Agent orchestrator 的重要性以及通用型 Agent 的发展潜力。

💡 主要观点

  1. 构建高效的 Agent Orchestrator 是 Agent 创业公司的核心竞争力。 Agent Orchestrator 决定了 Agent 的任务规划、并行处理和多 Agent 协作能力，是构建有效 Agent 的关键。
  2. 通用型 Agent 整合多种功能，更具长期优势。 通用型 Agent 能一站式满足用户需求，随着 Agent 功能增多，用户更倾向于选择通用型 Agent。
  3. 基础设施成本和扩展性是 Agent 落地的重要瓶颈。 现有云服务难以兼容短时高并发与长时大规模需求，限制了 Agent 的扩展和应用。
  4. 通用型 Agent 需重视用户教育和引导，才能充分发挥其价值。 通过提供预设模板和用户画像等方式，帮助用户快速了解 Agent 的功能和应用场景。

💬 文章金句

  • Agent 核心是 '大脑' 即 Agent orchestrator。若单纯缝合工具而不加强 Agent orchestrator 开发，就像没有大脑只有工具的人，无法很好执行任何任务。
  • 通用型 Agent 的出现，正是为了解决这个痛点，帮助用户在一个平台中完成多项任务。
  • 我们希望提供的是大脑和四肢，为用户提供一些基础工具，而对于更复杂的工具，就像公司引进一位非常优秀的人才一样，作为管理者可以直接与这个人合作，利用他的优势完成任务。
  • 目前所有 AI 公司都在烧钱，就像大家看到 OpenAI 烧了多少钱一样。我们首先需要确定的是产品能够达到什么样的创新程度，等产品定型后再去考虑合理的收费模式。
  • Proxy 不仅是一项技术尝试，更是经过市场验证、快速增长的产品。
