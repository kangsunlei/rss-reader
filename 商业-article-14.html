上门安装 OpenClaw，年入百万？

3/2/2026, 4:27:35 PM

📌 一句话摘要

本文深度解析了围绕开源 AI 代理平台 OpenClaw 兴起的代装生意，揭示了其背后的技术门槛、高昂的运行成本以及严峻的安全隐私风险。

📝 详细摘要

文章探讨了 OpenClaw 这一热门开源 AI 代理平台引发的付费安装现象。虽然安装本身涉及 Node.js 和命令行操作对普通用户有门槛，但文章指出，真正的挑战在于安装后的运维：OpenClaw 的「心跳机制」会导致高额的 API Token 消耗，且存在严重的公网暴露风险和恶意插件威胁。作者通过 Meta 高管的翻车案例警告，将不成熟的 Agent 接入核心资产（如邮箱、日历）具有极高风险，提醒读者在追逐 AI 热潮时需保持理性，关注数据安全与成本控制。

💡 主要观点

  1. OpenClaw 的代装生意反映了 AI 普及过程中的「技术鸿沟」与「错失恐惧」。 尽管是开源软件，但复杂的命令行配置让普通用户宁愿支付高额服务费，这与早期代注册 ChatGPT 账号、卖 Prompt 课程的逻辑一致，本质是利用信息差变现。
  2. OpenClaw 的「心跳机制」是隐藏的资金黑洞，可能导致高额账单。 系统每 30 分钟自动唤醒检查状态，会发送大量上下文和提示词，导致即便在无实际任务产出的状态下，也会因为频繁调用云端 API 而产生每月数百美元的费用。
  3. 自主代理（Agent）的权限边界与安全性面临严峻挑战，存在数据泄露风险。 大量实例暴露在公网且缺乏身份验证，加之恶意插件的威胁，使得接入邮件、日历等高权限渠道的用户面临隐私裸奔、账号被封甚至数据被 Agent 误删的极端风险。

💬 文章金句

  • 「能学会」和「愿意学」之间，往往差之毫厘谬以千里。
  • 系统在没有太多实际产出的状态下，仅靠心跳机制维持每天就消耗 20 美元，一个月白白烧掉近 750 美元。
  • 把一个还不够稳定的 Agent，直接绑在邮件、日历、账号这类核心资产上，然后期待它乖乖听话——本身就是一件需要打一个很大问号的事。
  • 懂技术的人自己就能装，不懂的人根本用不上。
