如何让 Kimi 的新 Agent 给我做国庆攻略，跟着 AI 旅游会踩雷吗？

10/3/2025, 8:22:09 PM

📌 一句话摘要

文章实测 Kimi 新 Agent 模式“OK Computer”在旅游规划、网页生成等方面的表现，并对比其他主流 AI Agent，深入剖析当前 AI Agent 的局限性与未来发展方向。

📝 详细摘要

本文深度评测了 Kimi 新推出的“OK Computer”Agent 模式，通过国庆旅游攻略和手机对比网站的实际案例，展示了其在网站部署和内容生成方面的能力。文章指出，尽管 Kimi Agent 速度快、审美在线，但在旅游推荐的实用性和内容深度上仍有不足，与阿里千问等结合生态系统的 Agent 相比存在差距。同时，文章扩展讨论了当前 AI Agent 普遍面临的“能做但做不好”的困境，引用 OpenAI 的 GDPval 基准测试和 Thinking Machines Lab 的研究，分析了训练数据不足和缺乏强化学习环境是制约 Agent 发展的核心原因，并展望了未来 Agent 技术走向“能做好”的路径。

💡 主要观点

  1. Kimi 的“OK Computer”Agent 模式在多任务处理上展现出潜力，但实用性仍需提升 Agent 能快速生成网站、规划行程，但内容深度和实际可用性有待加强，尤其在需要真实世界信息和避免大众化选择时表现不足。
  2. 当前 AI Agent 普遍面临“能做但做不好”的挑战，缺乏实用价值是主要瓶颈 尽管多数 Agent 宣称能完成多种任务，但实际交付成果往往难以达到可放心使用的标准，这是行业普遍存在的痛点。
  3. Agent 技术突破的关键在于解决训练数据不足和构建强化学习环境 文章指出，与人类学习不同，Agent 需要大量标注的“强化学习环境”来模拟真实任务，通过反复尝试和反馈来学习，以提升任务完成的可靠性。

💬 文章金句

  • OK Computer 能做的不止是一份可视化报告，而是直接给了我们一台电脑。我们用电脑能完成的事情，OK Computer 智能体都可以做到。
  • 大多数时候，我可能只是知道了有这些地方，但是我不知道我为什么要去，以及怎么去。而且，总是对这些内容，有一些不信任感。
  • 经过这些测试，倒不是说 Kimi K2 的 Agentic 能力不行，只是觉得 Agent 这类产品，大多数都还停留在「我可以做出来一个东西，但是这个东西不一定有用」的阶段。
  • Agent 要交付的内容复杂，现实世界中的任务繁多，无法归类到某个单一的媒体类型。
  • 目前我们经常看到的 Agent 任务，也大多数是集中在做一个 PPT、做一个网页、预订餐厅、代替我们刷社交媒体、自动购物等等，这仅仅只是现实世界里非常小的一部分，更不用说这些任务，没有明确的评估标准。
