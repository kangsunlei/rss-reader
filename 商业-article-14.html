中美 AI 之间的蒸馏，要撕破了 |【经纬低调分享】

2/25/2026, 3:45:00 AM

📌 一句话摘要

Anthropic 公开指控 DeepSeek 等中国 AI 实验室实施规模化“蒸馏攻击”，引发了关于技术边界、法律合规及中美 AI 竞争格局的深度博弈。

📝 详细摘要

本文深度解析了 2026 年 2 月 Anthropic 对 DeepSeek、月之暗面及 MiniMax 的技术指控。文章详细阐述了“蒸馏攻击”的定义，即通过虚假账户和代理网络（九头蛇集群）绕开限制，针对性抽取模型推理、编程等核心能力。分析指出，争议核心在于“普通蒸馏”与“对抗性能力抽取”的界限，并从法律层面探讨了合同违约与《计算机欺诈和滥用法》（CFAA）的适用性。文章最后预测，这一事件将推动闭源模型走向更严密的封闭防御，同时加剧全球 AI 产业的技术管制与生态分化。

💡 主要观点

  1. 蒸馏攻击与普通蒸馏的区别在于规避机制与能力抽取的系统性。 普通蒸馏是合法的效率优化手段，但若通过虚假账户绕过地理限制，并结构化地抽取链式思维等核心差异化能力，则被定义为具有对抗性的“蒸馏攻击”。
  2. 法律争议焦点在于“违约”与“违法”的界定，尤其是 CFAA 的适用范围。 根据 Van Buren 判例，单纯动机不纯不构成刑事违法，但若涉及伪造身份、绕过技术访问控制（如 Hydra 集群），则可能触犯美国计算机欺诈法律。
  3. API 模式的本质决定了模型能力无法实现绝对的封闭保护。 只要模型提供 API 接口，其输出就是可观察的，而可观察即意味着可学习。防御手段的本质在于通过技术和合同手段提高对方的抽取成本，而非彻底杜绝。
  4. 此争议将加剧 AI 闭源阵营的封闭化趋势并影响开源生态发展。 受害企业可能隐藏链式思维过程、收紧 API 权限并强化出口管制；而开源模型可能通过蒸馏扩散的能力，在性能上进一步逼近前沿闭源模型。

💬 文章金句

  • 蒸馏攻击与普通蒸馏之间的分界线，在于是否存在系统性规避限制与针对性能力抽取。
  • API 模式本身意味着输出可观察，而可观察即意味着可学习。
  • 防御的本质是提高成本，而非实现绝对封闭。
  • “门是开的”，你进去但动机不纯，不算黑客。但范布伦判例没有保护规避技术限制的行为。
  • 这一指控将 AI 模型蒸馏的技术争议，推至企业合规、国际竞争与国家安全的交叉地带。
