DeepSeek Harness 桌面版实测：更像「个人助理」，还给你送钱

9/29/2026, 4:06:00 PM

📌 一句话摘要

DeepSeek 正式推出 Harness 桌面版，通过开箱即用的安装、插件化系统及自动化任务，让普通用户能通过 AI 代码自主定义软件功能。

📝 详细摘要

DeepSeek 正式发布了 Harness 桌面客户端，改变了以往需要通过终端部署的局限，提供 macOS 和 Windows 原生安装包。该版本核心亮点在于支持标准、PC、极简、创作四种 Agent 预设，并内置智能体团队、自动审查、自动化任务及语音输入插件。用户可以处理 Word、Excel、PDF 等本地文件，进行数据分析并生成汇报 PPT。未来计划将强化沙箱安全、多 Agent 协作、长期记忆以及 Computer/Browser Use 自动化功能。

💡 主要观点

  1. 从终端部署转向开箱即用 Harness 桌面版告别了复杂的命令行安装，提供了适用于 macOS 和 Windows 的原生安装包，极大降低了普通用户的上手门槛。
  2. 插件化的功能扩展体系 通过智能体团队、自动审查、自动化任务和语音输入等插件，将 AI 能力从单一的对话框转变为可常驻本地的生产力工具。
  3. 本地文件深度处理与协作 支持直接在 Workspace 中处理 Word、Excel、PDF、Markdown 等文件，并能完成信息整理、数据核对及生成汇报大纲等复杂任务。
  4. 软件功能边界的重塑 AI 生成的代码可直接改变软件运行逻辑，使得软件的功能不再完全由产品经理决定，而是让用户能根据需求自主定义。

💬 文章金句

  • 现在，人人都可以用「万物皆插件」了
  • 传统软件的功能边界由产品经理决定，Harness 想尝试的，是让我们普通用户也可以自己决定自己的 AI 最后是什么样。
