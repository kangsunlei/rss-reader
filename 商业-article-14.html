语核科技翟星吉：离钱最近的 Agent，才是 AI ToB 的唯一出路

12/11/2025, 10:02:00 AM

📌 一句话摘要

语核科技创始人翟星吉分享了 AI Agent 在 ToB 企业服务领域的实践与思考，强调 Agent 需专注于解决企业核心业务的“堵塞点”，尤其是在销售场景中创造增量价值，并提出 Agent 将重塑组织形态的未来愿景，实现“人类规划器+AI 执行器”的高人效模式。

📝 详细摘要

文章通过访谈语核科技创始人翟星吉，深入探讨了 AI Agent 在 ToB 领域的发展路径和商业化策略。翟星吉认为，AI Agent 要真正创造价值，必须“离钱近”，即切入企业最核心的业务流程，解决“堵塞点”，而非仅仅提供工具。他以语核科技在销售场景中赋能售前解决方案为例，说明 Agent 如何帮助企业实现营收增长。文章还探讨了 AI 作为杠杆如何撬动高价值生产力，人机协作从 L2 到 L4 的演进，以及创业者认知迭代速度的重要性。最后，翟星吉展望了 Agent 将重塑组织形态，催生“人类规划器+AI 执行器”模式和高人效组织的未来。

💡 主要观点

  1. AI Agent 的核心价值在于解决企业核心业务的“堵塞点”而非制造“工具”。 Agent 应专注于企业最痛的瓶颈问题，直接量化其带来的价值，如销售额增长，从而促使客户付费，避免成为非必需的管理工具。
  2. AI 作为杠杆，应撬动高价值生产力，尤其在 ToB 场景下效果显著。 C 端用户时间价值有限，而 B 端企业追求高效生产力，AI 带来的效率微小提升在高基数下能产生巨大的商业回报，如销售转化率的提升。
  3. Agent 将重塑组织形态，向“人类规划器+AI 执行器”模式演进。 未来企业可能实现极高的人效比，少量核心人类负责战略规划，AI Agent 负责具体执行，甚至催生新形态的人力资源外包平台。
  4. 年轻团队选择“老登”场景 ToB 销售，聚焦为 Sales 提供“武器弹药”。 语核科技专注于为销售提供售前解决方案和技术支持，避免强人际交互的销售环节，解决传统 SaaS 定制化和价值天花板问题。
  5. 创业者在 AI 时代的核心竞争力是认知迭代速度和快速纠错能力。 面对快速变化的技术浪潮，保持开放心态、迅速决策和在发现错误后快速修正（“滑跪”）是成功的关键素质。

💬 文章金句

  • 离钱最近的 Agent，才是 AI ToB 的唯一出路。
  • ToB 的核心是解决「堵塞点」而非制造「工具」。
  • AI 的本质是杠杆，要撬动高价值生产力。
  • 最终的商业模式就是，你把发给人的工资发给我就好了，人背 KPI，我们的 Agent 也可以负责。
  • 创业者的核心竞争力是「认知迭代速度」。
  • 我们团队讲究「滑跪」的能力，就是说我上一秒还在和你激烈争论，下一秒发现你是对的，就立刻采纳你的观点。
