2009 年的 iPhone 跑 ChatGPT？17 岁开发者“魔改”应用，让老机重生！

4/11/2025, 9:18:53 AM

📌 一句话摘要

17 岁开发者 Mali 为老旧 iOS 设备开发 ChatGPT 应用，让 iPhone 3GS 等设备也能体验 AI 聊天服务，并在 GitHub 上开源。

📝 详细摘要

文章介绍了 17 岁开发者 Mali 为老旧 iOS 设备（如 iPhone 3GS）开发的 “ChatGPT for Legacy iOS” 应用。该应用基于 OpenAI API 开发，让无法运行官方 ChatGPT App 的旧设备也能使用 ChatGPT，支持聊天、上下文记忆、聊天记录同步等功能，界面设计灵感来自 iOS 7，简洁流畅。**该项目在技术上的挑战在于需要适配老旧设备的性能和兼容性，实现现代 AI 应用在 16 年前设备上的运行。** 安装该应用需越狱设备并配置 API 密钥。Mali 还在 GitHub 上开源了该项目，引发网友怀旧和调侃。文章还介绍了 Mali 的其他项目，如为 iPhone 5 写 App 等，展现了他对老设备的热爱和技术能力。

💡 主要观点

  1. ChatGPT for Legacy iOS 让老旧设备也能使用 ChatGPT 该应用为无法运行官方 ChatGPT App 的设备提供了一个入口，让用户在旧设备上体验 AI 聊天服务。
  2. 应用基于 OpenAI API 开发，功能完整 该应用支持聊天对话、上下文记忆、聊天记录同步等功能，提供较完整的 ChatGPT 体验。
  3. 开发者 Mali 热衷于为老旧设备续命 Mali 擅长为旧设备开发应用，解决兼容性问题，让老设备焕发新生。

💬 文章金句

  • 很多人一提到 ChatGPT，脑海中浮现的都是最新的 AI 技术，只能跑在现代设备上。但谁能想到，如今它竟然也能在 2009 年发布的 iPhone 3GS 上运行了，要知道，这个时候，Siri 都还没出生。
  • 这次一向喜欢挑战的 Mali 带来的这款名为 "ChatGPT for Legacy iOS" 的应用程序，是专为无法运行 OpenAI 官方 App 的设备设计的，相当于给这些被淘汰的设备提供了一个进入 AI 世界的 "密码"。
  • 我就是个住在德国、17 岁的普通高中生，平时时间多，就爱捣鼓点老设备的东西。
