Agent OS 的崛起：Agent 正成为计算设备的新入口

9/29/2026, 11:10:59 PM

📌 一句话摘要

玉伯指出，随着 Claude、Grok 等产品的发布，Agent 正在成为操作系统之上的新基础设施，传统 GUI OS 将退居幕后。

📝 详细摘要

作者通过近期 Claude、Grok、Muse 等 Agent 产品的密集发布，观察到 Agent 正在进化为一种具备编程、工作和个人助理能力的「新物种」。他认为计算历史是分层的，Agent 正在成为手机和电脑之上的新交互层。未来用户可能只需通过 Agent 这一唯一入口进行操作，而传统的 macOS 或 Windows 等 GUI 操作系统将逐渐演变成类似底层的「终端」，被隐藏在 Agent 界面之后。此外，他也提及这可能催生少量创新的硬件机会。

💡 主要观点

  1. Agent 正在成为计算机与手机的新基础设施层 正如电池和网络已成为透明的底层，Agent 将成为用户与设备交互的主要入口，使底层操作系统退居幕后。
  2. GUI 操作系统将转变为 Agent 的「终端」 Windows 或 macOS 等图形化操作系统将失去直接入口地位，其功能将被 Agent 调取和封装，用户将主要在 Agent OS 界面停留。

💬 文章金句

  • agents 正在成为新的一层。对用户来说，后续电脑和手机上，最重要甚至可能是唯一入口的一个界面应用，就是某个 agent 了。
  • mac os 和 windows 等 gui os，正在成为 terminal，会被藏在 agent os 的后面去。
  • 对用户来说，agent is all you need。
