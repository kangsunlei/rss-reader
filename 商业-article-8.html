OpenAI 将关闭其强大的 AI 视频模型、应用及 API —— Sora

3/24/2026, 9:25:21 PM

📌 一句话摘要

OpenAI 突然宣布停止其 Sora 视频生成应用和 API，这标志着其战略转向整合的“超级应用”模式，并重新聚焦于对抗 Anthropic 的企业竞争力。

📝 详细摘要

OpenAI 正在关闭其独立的 Sora AI 视频生成应用和 API，考虑到该公司近期的投资和产品更新，此举令人意外。该决定包括取消与迪士尼价值 10 亿美元的重要合作伙伴关系。这一战略转变似乎是更广泛重组的一部分，OpenAI 旨在通过将包括 ChatGPT 和 Codex 在内的各种工具整合到一个“超级应用”中来简化用户体验。此次转型很大程度上是由于需要更好地与在企业和编码领域获得显著进展的 Anthropic 的 Claude 竞争，同时也伴随着 OpenAI 领导层和非营利基金会部门的重组。

💡 主要观点

  1. OpenAI 正在停止独立的 Sora 应用和 API。 该公司突然关闭了其视频生成平台，尽管该平台近期刚进行过更新并达成了备受瞩目的迪士尼合作伙伴关系，这标志着其产品方向的重大调整。
  2. 战略整合为“超级应用”。 OpenAI 正将重心转向一个统一的界面，整合其各种 AI 能力（如 ChatGPT 和 Codex），以简化用户体验并精简运营。
  3. 来自 Anthropic 的竞争压力。 此次转型很大程度上是为了应对 Anthropic 在企业和编码市场日益增长的主导地位，迫使 OpenAI 将资源重新聚焦于其核心优势，以保持市场领先地位。

💬 文章金句

  • OpenAI 正在关闭 Sora，即其独立的 AI 视频生成应用和社交网络，并停止开发者通过其 API 访问 Sora 2 视频模型系列。
  • 此举正值 OpenAI 公开表示其意图专注于构建一个“超级应用”，该应用将整合其各类产品部分或全部的功能。
  • 关于 Sora 终结的消息传出之际，正值 OpenAI 领导层及其非营利基金会部门进行重组之时。
