星动纪元创始人陈建宇：要实现万亿级市场，核心是打造上限更高、更通用的机器人

1/19/2026, 10:38:00 AM

📌 一句话摘要

星动纪元创始人陈建宇阐述了通过打造“大脑”与“身体”协同进化的通用人形机器人，实现万亿级智能终端市场的路径与技术进展。

📝 详细摘要

文章整理自星动纪元创始人陈建宇在创业邦年会上的演讲。陈建宇指出，机器人产业规模未达预期的核心在于现有产品过于专业化，缺乏通用性。他提出打造“上限更高、更通用”的机器人是破局关键。技术上，他详细介绍了具身大脑模型的三次进化：从全球首个机器人 VLA 模型 Hirt，到引入世界模型 Ctrl-world 以增强预判与泛化能力，再到基于强化学习的自主探索。硬件层面，星动纪元实现了灵巧手、电机等核心部件的全栈自研，并推出了 L7 双足机器人与 Q5 轮式机器人。商业化上，公司采取“终端场景方案”与“工具链 API 开放”双线并行策略，已与顺丰、海尔等巨头达成合作。

💡 主要观点

  1. 通用性是机器人成为万亿级智能终端的核心前提。 现有机器人多适配单一场景，需通过软硬一体化研发，使机器人具备像人一样的通用适配能力，降低新场景的研发门槛。
  2. 具身模型需从单纯的动作模仿进化到具备“世界模型”的预判能力。 通过引入世界模型，机器人能构建物理常识并预测交互效果，使动作从条件反射转向具备思考和举一反三的能力。
  3. 全栈自研核心硬件是支撑聪明“大脑”落地的物理基础。 自主研发灵巧手、电机和减速器等部件，能确保机器人具备高响应速度、高力量和高精度，以适应复杂的工业和生活环境。
  4. 采取“场景落地”与“工具链开放”双线并行的商业化策略。 通过真实场景获取数据反馈优化模型，同时开放 API 赋能合作伙伴，共同探索多样化的应用场景，形成商业闭环。

💬 文章金句

  • 现在机器人比较专业化，一款机器人只能适配基本一种场景和一个任务，要做新的场景和任务，要重新研发整个硬件和软件。
  • 人类之所以会思考，是因为能在脑内构建世界模型，这是对物理世界的常识性认知，对各种各样的场景有快速的预判。
  • 再好的技术，如果不能落地，那就没有意义。
  • 我们希望做相对通用的机器人，希望它像人一样，通用适配到各类场景，这样才能最终达到想要的市场。
