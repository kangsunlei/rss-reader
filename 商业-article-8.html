红杉对话 LangChain 创始人：2026 年 AI 告别对话框，步入 Long-Horizon Agents 元年

1/27/2026, 12:31:00 PM

📌 一句话摘要

红杉资本对话 LangChain 创始人 Harrison Chase，深度探讨 Long-Horizon Agents 的崛起、Harness 架构演进及 Coding Agent 作为通用 AI 终局形态的潜力。

📝 详细摘要

本文编译自红杉资本对 LangChain 创始人 Harrison Chase 的访谈。文章指出 2026 年将成为长程智能体（Long-Horizon Agents）的元年，AI 将从对话框交互转向自主目标导向的执行。Harrison 详细阐述了 Agent 发展的三个阶段，强调当前已进入以“Harness（软件外壳）”为核心的第三个拐点，其中上下文工程（Context Engineering）、文件系统权限和压缩技术是提升智能体性能的关键。此外，访谈还探讨了 Coding Agent 作为通用智能体原型的可能性，以及 Tracing（追踪）如何取代代码成为 Agent 开发中的“单一事实来源”。最后，文章展望了未来异步管理与同步协作相结合的混合交互模式，并强调了 Memory（记忆）在构建垂直领域竞争壁垒中的核心作用。

💡 主要观点

  1. Long-Horizon Agents 的核心价值在于为复杂任务提供高质量初稿。 虽然 Agent 无法达到 99.9% 的可靠性，但其能在长时程内自主运行，在 Coding、SRE 和金融报告等场景中替代人类完成繁琐的初级工作。
  2. Agent 开发的重心正从通用框架转向具有“主见”的 Harness 架构。 Harness 默认内置规划工具、文件系统交互和上下文压缩原语，通过深度适配模型特性来挖掘性能提升，而非仅仅依赖模型本身。
  3. Tracing（追踪）成为 Agent 开发中的“单一事实来源”和协作支点。 由于 Agent 行为具有非确定性，开发者必须通过 Trace 复现内部每一步的上下文状态，这改变了传统软件以代码为核心的测试和调试逻辑。
  4. 文件系统权限和代码执行能力是构建长程智能体的标配。 文件系统是管理长周期上下文的有效手段，而代码则是让计算机执行复杂指令的最通用方式，暗示所有 Agent 最终可能都是 Coding Agent。
  5. Memory（记忆）是 Agent 在垂直场景下真正的护城河。 经过长时间磨合、内化了特定任务模式和背景记忆的 Agent，其用户粘性和性能表现远超通用模型，是实现自我改进的关键。

💬 文章金句

  • 如果说过去的 AI 是 Talkers 的时代，那么 2026 年则是 Doers 的元年。
  • 软件的 Source of Truth 是代码；Agent 的 Source of Truth 是代码 + Tracing。
  • 我深信，构建 Long Horizon Agent 必须给它文件系统权限。
  • 未来的交互形态就是这种 Hybrid Mode：你异步管理一堆后台运行的 Agent，但在关键时刻，你进入 Sync Mode 与它 Chat。
  • 复杂度没有消失，只是变成了自然语言。因此，Prompting、编辑 Prompt 甚至自动优化 Prompt 成了核心。
