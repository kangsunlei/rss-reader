把 DeepSeek 接入 Codex ，额度自由了，还不用手机号验证｜附保姆级指南

6/3/2026, 6:00:00 AM

📌 一句话摘要

本文介绍通过 CC Switch 工具将 DeepSeek 等第三方模型接入 Codex，以绕过额度限制和手机号验证，并附详细操作指南。

📝 详细摘要

文章首先报道了 Codex 并入 ChatGPT 的消息，以及近期 Codex 收紧手机号验证、额度从周重置改为月重置（额度砍 75%）等变化，引发用户「额度焦虑」。随后，文章重点介绍了使用 CC Switch 工具将 DeepSeek、小米 MiMo、Qwen、Kimi、MiniMax 等第三方模型接入 Codex 的方法，以绕过官方额度限制和手机号验证。文章详细说明了 CC Switch 的安装、配置步骤，包括如何添加 API Key、启用本地路由以解决 Responses API 与 Chat Completions API 的格式兼容问题。文章还对比了 Moon Bridge 等更极客的配置方案，并指出使用第三方模型可能存在的局限性，如无法使用远程连接 Codex Mobile、插件功能受限、稳定性不如原生 GPT-5.5 等。最后，文章提及部分模型（如 Qwen3.7-Max、MiniMax M3）已开始原生支持 Responses API，并展望了未来 Agent 产品的发展趋势。

💡 主要观点

  1. Codex 近期收紧额度与验证，催生第三方模型接入需求。 Codex 将免费和 Go 会员用户的额度从周重置改为月重置，额度砍 75%，并强制要求手机号验证，导致用户寻求通过第三方模型绕过限制。
  2. CC Switch 是配置第三方模型接入 Codex 的最佳途径。 相比 Moon Bridge 等需要手动安装 Go 和配置文件的极客方案，CC Switch 提供可视化界面，操作更简便，且能通过本地路由解决 Responses API 与 Chat Completions API 的格式兼容问题。
  3. 使用第三方模型存在功能与稳定性折衷。 接入第三方模型后，无法使用 Codex Mobile 远程连接、部分插件功能受限，且可能出现断连等问题。追求极致稳定性和原生 Agent 体验，仍建议使用官方 GPT-5.5。

💬 文章金句

  • 虽然配置第三方模型能解决额度焦虑，绕过手机登录，但要是追求最极致的稳定性和原生 Agent 体验，和 Codex 官方建议的一样，使用 GPT-5.5 大概仍是最好的选择。
