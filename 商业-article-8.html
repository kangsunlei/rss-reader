#427.对话 Claude Code 负责人：从工程师到“开发者”的范式转移

2/19/2026, 4:24:43 PM

📌 一句话摘要

对话 Anthropic 负责人，探讨了 AI 编程工具 Claude Code 如何重塑软件工程，预示了从“程序员”向“开发者”的范式转移。

📝 详细摘要

本期播客深度对话 Anthropic 的 Claude Code 负责人 Boris Cherny。节目聚焦于 AI 在软件开发领域的爆发式增长——目前全球 4% 的代码提交已由 Claude 完成。Boris 分享了他个人“百分百 AI 驱动”的工作流：自 2023 年 11 月起不再亲手改写代码，每日通过 AI 提交多达 30 个 PR，生产力提升 200%。对话探讨了 Claude Code 从简单的终端工具进化为行业标杆的过程，并提出了激进的预测：2025 年底开发者可能不再需要传统 IDE。此外，Boris 详细阐述了“潜在需求”驱动的产品创新原则，以及 Anthropic 在 AI 安全领域的三层防御机制：机械可解释性、模拟评估与真实世界监测。最后，他将 AI 编程比作“印刷机时刻”，强调未来每个人都将成为具备跨学科能力的“开发者（Builder）”，并建议从业者通过拥抱通用模型和“为六个月后的模型做开发”来保持长期竞争力。

💡 主要观点

  1. 软件工程正经历从“底层编码”向“高阶构思”的范式转移 随着 AI 解决编码底层细节，工程师将从琐碎语法中解放，转而关注系统架构、产品意图与用户需求，从传统“程序员”进化为全能的“开发者（Builder）”。
  2. 产品创新应遵循“潜在需求”原则，通过观察用户“误用”发掘新功能 观察用户如何在极端环境下魔改工具是识别爆款的强信号。Claude Code 桌面端 Cowork 的诞生正是基于数据科学家在终端里进行非技术性数据分析的观察。
  3. 开发者应采取“为六个月后的模型做开发”的前瞻性策略 押注通用模型的演进速度，避免构建复杂的临时脚手架。当下一代更强模型发布时，适配良好且预留能力空间的产品将通过模型能力的自动增强迎来爆发式增长。

💬 文章金句

  • 我现在的编程体验比以前任何时候都好，因为我再也不用去处理那些琐碎的细节了。
  • 如果你是为六个月后的模型做准备，等新模型一发布，你的产品会瞬间爆发。
  • 软件工程师这个头衔会慢慢消失，取而代之的是开发者 Builder。
  • 创新这东西确实没法强求，你得给人们空间或者说一种安全感，让他们觉得失败也没关系。
