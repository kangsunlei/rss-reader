OpenAI 组织内部，到底是如何运作的？

7/17/2025, 10:25:00 AM

📌 一句话摘要

一位前 OpenAI 工程师分享了他在公司一年间的所见所感，揭示了这家 AI 巨头既混乱又高效、自下而上驱动的独特文化和技术运作模式。

📝 详细摘要

文章通过一位前 OpenAI 工程师 Calvin 的亲身经历，深入揭示了这家全球最受关注 AI 公司的内部运作机制和独特文化。Calvin 观察到 OpenAI 在极速扩张中形成了“既混乱又高效，既集中又分散”的文化，尤其强调“从下到上”的项目推动和“偏爱行动”的决策风格，同时展现出内部高度开放与对外严格保密的鲜明对比，被比作“洛斯阿拉莫斯实验室”的现代版本。技术层面，OpenAI 以 Python 为主，核心代码运行在庞大的 monorepo 上，并高度依赖 Azure 但偏好自研系统，其“Chat 架构”深入骨髓。文章还详细描述了 Codex 产品在 7 周内极速上线的故事，展现了团队的冲劲和 ChatGPT 强大的影响力。Calvin 分享了他在 OpenAI 的收获，包括对模型训练的直觉、与优秀人才共事，以及发布打动人心的产品。他认为 OpenAI 的文化是科研机构与创业公司的奇特混合体，并在 AI 安全和红利分配上表现出认真态度，最终目标是帮助全人类。

💡 主要观点

  1. OpenAI 文化独特，兼具混乱与高效，强调自下而上与行动偏好。 公司在高速扩张中形成高度去中心化、鼓励个人驱动的文化，内部通过 Slack 高效协作，领导层直接参与，但对外保密严格。
  2. 技术架构以 Monorepo 和 Python 为主，重度自研，并受“Chat 架构”深远影响。 核心代码库庞大且风格不统一，偏好自研系统，所有系统都围绕聊天消息和对话概念构建，决策架构扁平化。
  3. 产品开发极致快速，以 Codex 项目为例展现团队强大冲劲和执行力。 Codex 从确定目标到上线仅用 7 周，团队高强度投入，体现了 OpenAI 在产品落地上的惊人速度和 ChatGPT 带来的巨大流量效应。
  4. OpenAI 在 AI 安全和红利分配上认真，致力于实现 AGI 并造福人类。 公司内部有专门团队负责 AI 安全，关注现实风险；同时坚持将最先进的模型免费提供给普通用户和开发者。
  5. 作者 Calvin 的个人成长与对创业者的建议。 Calvin 在 OpenAI 的经历刷新了其对“大品牌”和模型训练的认知，从最初的怀疑到最终的巨大收获，并鼓励创业者在项目停滞时考虑激进试错或加入顶级实验室，亲身见证未来构建。

💬 文章金句

  • 这里没有任何商业机密，只有我对历史上最迷人的组织之一，在当下飞速迭代时期的所思所感。
  • OpenAI 非常依赖工程师和研究者「从下到上」推动项目。
  • OpenAI 的公司文化还鲜明地「偏爱行动（action-bias）」：你可以直接行动让想法落地，不必等上层批准。
  • OpenAI 更像是从「洛斯阿拉莫斯实验室」（Los Alamos，美国研究出原子弹的实验室）的现代版本。
  • OpenAI 所有的产品设计几乎都是围绕「Pro 用户」展开的，哪怕是面向开发者的 Codex，也主要以个人用户为导向，而非团队。
