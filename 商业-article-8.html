12/13/2025, 3:40:00 AM

📌 一句话摘要

前 OpenAI CTO Mira Murati 创办的 Thinking Machines Lab 发布 Tinker 平台，旨在降低大模型微调门槛，通过提供一站式工程系统，支持 KimiK2、千问 VL 等模型，并实现全面开放可用。

📝 详细摘要

文章详细介绍了前 OpenAI CTO Mira Murati 创办的 Thinking Machines Lab 及其核心产品 Tinker。该平台致力于解决大模型微调中“模型训练与模型使用之间的断层”，将复杂的分布式训练、GPU 集群和基础设施管理进行抽象，让开发者能专注于数据和算法。Tinker 已全面开放，无需等待名单，并新增了 Kimi K2 Thinking 模型支持、Qwen3-VL 系列视觉语言模型以及与 OpenAI API 兼容的脚手架功能。文章强调了 Tinker 能够实现模型在训练过程中被调用和验证，统一推理方式，并将推理、微调、多模态能力整合于一个工程平台。通过案例展示了 Tinker 能以极少数据样本微调 VLM 模型识别新物种的能力，并分析了该实验室被业界看重的原因，包括 Mira Murati 的个人光环、AI 民主化浪潮以及抓住 AI 竞赛白热化时机等。

💡 主要观点

  1. Tinker 平台旨在解决大模型训练与使用之间的工程难题，降低微调门槛。 Tinker 通过抽象复杂的分布式训练和基础设施管理，使得开发者无需关注底层细节，而能专注于模型的数据和算法，将微调从少数大厂专属变为大众可用。
  2. Tinker 新增 Kimi K2 Thinking、Qwen3-VL 模型支持，并兼容 OpenAI API。 这使得 Tinker 能够支持前沿的万亿参数级推理模型和视觉语言模型，同时通过与 OpenAI API 的兼容，大幅提升了平台的易用性和生态集成能力。
  3. Tinker 支持模型在训练过程中进行调用和验证，提升开发效率。 这一特性解决了传统“训完再看”的弊端，允许开发者实时评估模型效果，从而加快迭代周期和优化过程。

💬 文章金句

  • 微调不是一项算法能力，而是一整套工程系统能力。
  • 提供高质量的研究工具，是提升更广泛社区研究效率最有效的方式之一，而 Tinker API 正是我们朝这个使命迈出的重要一步。
  • Tinker 并非一个让微调变简单的黑盒，而是一个清晰的抽象层。它在为用户屏蔽分布式训练复杂性的同时，完整保留了用户对训练循环和所有算法细节的控制权。
  • Tinker 把门槛砸到地板，让中小团队、独立开发者也能玩转前沿 AI！
  • 让人工智能系统被更广泛地理解、可定制并具有普遍能力，通过坚实的基础、开放的科学和实际的应用，让人工智能变得更有用、更易懂，从而推动人工智能的发展。
