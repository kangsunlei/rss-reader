杨植麟交卷，Kimi 万亿参数 K2 开源：Agent 能力紧逼 Anthropic，延展 DeepSeek，上手实测如何？

7/12/2025, 1:37:00 AM

📌 一句话摘要

月之暗面开源万亿参数 Kimi K2 模型，主攻 Agent 能力，实测表现出色，旨在对标 Anthropic 等领先模型。

📝 详细摘要

文章详细介绍了月之暗面最新开源的 Kimi K2 模型。该模型是万亿参数的混合专家（MoE）模型，核心能力从长文本转向智能体任务，并在编程、智能体、工具调用等基准测试中表现优异，紧逼 GPT-4.1 和 Claude 4 Opus。文章指出，Kimi 的技术路线受 DeepSeek 影响，并在架构上选择了与其类似的 MLA。文章深入分析了 K2 的技术细节，包括其 MLA 架构、Muon 优化器，以及“模型即 Agent”的技术赌注。通过实测，K2 在代码生成、数据分析和信息提取等 Agent 任务中展现出强大的自主规划和执行能力，尽管在风格化文本生成方面仍有提升空间。文章还探讨了 K2 的高硬件运行门槛及其对开源生态和 C 端产品的影响，并指出其明确对标 Anthropic 的 Agent 能力。

💡 主要观点

  1. Kimi K2 模型核心能力从长文本转向智能体任务，并在基准测试和实际应用中展现出色性能。 K2 作为万亿参数 MoE 模型，在编程、智能体、工具调用等基准测试中超越开源模型并接近顶级闭源模型，同时在代码生成、数据分析等 Agent 任务中展现强大的自主规划和执行能力，大幅提升了其实用价值。
  2. 月之暗面通过 K2 的开源，明确了“模型即 Agent”的技术战略和理念。 K2 采用“零结构”智能体理念，通过强化学习和自我评价机制提升泛化能力，预示着 Agent 技术将成为月之暗面未来发展的核心方向，并对标 Anthropic 的 Agent 能力。
  3. Kimi K2 虽性能强大，但高硬件门槛限制了其广泛本地部署，对中小开发者构成挑战。 K2 的运行需要至少 16 块 H200 GPU 组成的集群，尽管支持多种推理框架和并行策略，但高昂的硬件成本将绝大多数个人开发者和中小团队排除在本地部署之外，是其推广面临的现实问题。

💬 文章金句

  • 这次发布的 Kimi K2 是一个万亿（1T）参数规模的混合专家（MoE）模型，激活参数为 320 亿。
  • 其核心能力发生了清晰的转向，Kimi 此前的标签是长文本，而 K2 则为智能体任务（agentic tasks）做了专门优化。
  • Kimi K2 的发布，是杨植麟在给月之暗面调整方向后，交出的一份重要答卷。
  • 这些技术投入背后还有一个清晰的技术赌注：“模型即 Agent，Agent 即模型”的理念。
  • 此次 K2 对标 Claude 的思路很明显，在模型能力上也做了很明显的取舍。
