ChatGPT Agent 团队专访：基模公司做通用 Agent，和 Manus 有什么不一样？

7/23/2025, 1:24:00 PM

📌 一句话摘要

OpenAI 核心团队专访揭示了 ChatGPT Agent 通过强化学习实现“具身化”能力，能自主使用多种工具完成复杂任务，并探讨了其在安全和未来通用 Agent 发展中的挑战与愿景。

📝 详细摘要

文章是 Founder Park 对 OpenAI ChatGPT Agent 团队三位核心成员的专访编译，深入探讨了 ChatGPT Agent 的技术细节、训练方法、应用场景及面临的挑战。该 Agent 是“深度研究”和“Operator”能力的结合，通过集成文本浏览器、图形界面浏览器和终端，以及调用 API，实现了所有工具的“共享状态”，使其能像人类一样与数字世界交互。其核心技术是强化学习，通过让模型在数千个虚拟机上自行实验，发现最优工具使用策略，实现了长达一小时的复杂任务“不失控”。文章强调了通用 Agent 的未来愿景，即一个能自主理解并完成各种任务的统一 Agent，而非特定子 Agent。同时，团队也坦承 Agent 与现实世界交互带来的巨大安全风险，并介绍了多层级安全护栏和持续迭代的缓解措施。文章为理解 OpenAI Agent 的最新进展和未来方向提供了宝贵的一手资料。

💡 主要观点

  1. ChatGPT Agent 通过“具身化”能力实现多工具共享状态下的复杂任务执行 Agent 整合了文本/图形浏览器、终端及 API 调用能力，并实现工具间状态共享，使其能像人类一样灵活切换工具，处理耗时复杂任务，显著提升了交互和执行效率。
  2. 强化学习是 Agent 实现长时任务自主性和解决复杂问题的关键 通过 RL 训练，模型在没有明确指令的情况下，能自行探索并发现最优工具使用策略，使其在长达一小时的任务中保持控制，展现出强大的自主推理能力。
  3. 未来 Agent 将走向统一的通用 Agent，但与现实世界交互的安全问题是核心挑战 团队认为最终会是一个强大的通用 Agent 处理所有需求，而非特定子 Agent。然而，Agent 对现实世界的影响力越大，其潜在风险也越高，安全防护和持续迭代成为重中之重。

💬 文章金句

  • 我们基本上是给了模型一堆工具，然后把它「锁在房间里」让它自己去实验。我们并不会明确告诉它什么时候该用什么工具，它会自己琢磨出来。
  • 随着 Agent 变得越来越有自主性，任务的时长会越来越长，这是一个很好的例子。
  • 我们有一些工具，能让模型突破其原有的上下文长度限制，进一步扩展它的处理范围。
  • 它在进行真正的数据科学研究，并将发现总结到电子表格里的能力，表现得相当不错。在一些数据科学的基准测试中，它的表现实际上已经超过了人类基线。
  • 正是这种与真实世界的直接交互，让一切都变得非常困难。
