万字长文，聊聊下一代 AI Agent 的新范式

3/25/2025, 8:48:26 AM

📌 一句话摘要

腾讯研究院圆桌会议探讨了下一代 AI Agent (以 Manus 为代表) 的技术范式、产品创新和未来趋势，以及 AI 时代就业的应对之策。

📝 详细摘要

文章是腾讯研究院举办的关于下一代 AI Agent 的圆桌会议纪要。会议聚焦于 Manus 等 AI Agent 的产品创新、技术前沿和未来发展趋势，探讨了 AI Agent 的关键技术，如多 Agent 系统、记忆和上下文管理、端到端训练等。其中，Manus 侧重多 Agent 协同，Deep Research 侧重端到端训练。与会专家认为，未来的 AI Agent 需要强化自我评估、跨环境和自主学习能力。同时，讨论了 AI Agent 对就业带来的影响，提出了增量思维和 AI 领导力的应对策略，即从执行具体事务转变为制定目标、管理并验收 AI 的工作成果。专家们还分享了他们对 AI Agent 未来发展方向的看法，强调了模型即产品、模型即服务的趋势，以及 Agent 在特定场景下的专业化发展方向。

💡 主要观点

  1. 下一代 Agent 需具备自我评估和反思能力 Agent 需要评估结果是否达到预期，从而提升自主能力和智能水平，系统需要提供环境闭环反馈或奖励学习机制。
  2. 端到端训练是 Agent 发展的重要方向 通过端到端训练，将整个 AI 助手的能力直接做成一个模型，减少对人工控制流程的依赖，使 Agent 更智能。
  3. AI 领导力是应对 AI 时代就业转变的关键 从执行具体事务转变为制定目标、管理并验收 AI 的工作成果，成为 AI 的领导者，是未来工作本质的重大转变。
  4. Agent 需要具备跨环境能力和自主学习能力 Agent 需要能够跨越不同的应用环境，自主使用各种软件工具来解决问题，并从使用数据中持续学习和进化，以提升解决问题的效率和个性化程度。

💬 文章金句

  • AI 的能力就像一条锯齿状的线，远远看是一条直线，但走近了才能看清它在不同方面的强弱。
  • Agent 是一个能够自主思考、规划，并使用工具来完成用户任务的系统。
  • 我们需要用增量思维来看待 AI 的发展，借助 AI 能力，我们每个人都能成为 “超级个体”。
  • 模型即产品、模型即服务，这正是下半场我们需要重点关注的技术方向。
  • 我们要学会给 AI 打工。跟 AI 协作的态度就是说去确认我能给 AI 提供什么样的价值。
