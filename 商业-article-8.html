实测腾讯 Hy3 正式版，这次终于赶上了「AI 下半场」

7/6/2026, 10:23:00 AM

📌 一句话摘要

本文通过多场景实测，展示了腾讯混元 3 正式版在 Agent、前端生成、代码分析等方面的显著提升，认为其能力已接近国内旗舰模型水平。

📝 详细摘要

文章基于腾讯混元 3 正式版（Hy3）的实测体验，从预览版到正式版的迭代过程切入，通过多个前端网页生成（如 3D 金门大桥、主题公园、SVG 动画）、游戏复刻（我的世界、黑神话悟空、地铁跑酷）、代码分析（论文代码 Bug 查找与优化）、办公场景（专业调研报告、多文件处理）等测试，对比展示 Hy3 相比预览版的巨大进步。文章引用官方博客数据，对比了 DeepSeek V4 Pro、GLM 5.2、GPT-5.5 等模型，指出 Hy3 在 SWE-bench 等多项 Benchmark 上已逼近 GLM 5.2，在 WorkBuddy 场景下的任务成功率从 72%升至 90%。文章也提到 Hy3 的 API 定价（输入 1 元/百万 tokens）和 WorkBuddy、元宝两款产品的集成能力。最后指出，Hy3 两个月完成一次肉眼可见的迭代，但后续能否保持速度更值得关注。

💡 主要观点

  1. Hy3 正式版在 Agent 和 Coding 能力上相比预览版有实质性提升。 多项实测显示，前端网页生成质量显著提高（如 3D 场景、游戏复刻），代码分析和修复能力增强，办公场景任务成功率从 72%升至 90%。
  2. Hy3 在多项基准测试中逼近国内旗舰模型水平，尤其接近 GLM 5.2。 官方 Benchmark 对比显示，Hy3 在 SWE-bench、HLE 等榜单上提升显著，综合表现与 GLM 5.2 相当，部分场景甚至超过同期模型。
  3. Hy3 与 WorkBuddy、元宝深度集成，提供全场景 AI 工作台体验。 用户可通过 WorkBuddy 和元宝调用 Hy3 完成文档生成、代码转换、多文件处理等任务，实测中多格式文件交付稳定。
  4. 模型迭代速度本身可能比单版本能力更重要。 文章指出，Hy3 从 Preview 到正式版仅用两个月，但后续能否保持这一迭代速度才是更值得关注的问题。

💬 文章金句

  • 十年磨一剑，两月一模型。
  • 我们先发一个 Preview 模型最主要的目的之一，是希望获得真实世界反馈，修复榜单里发现不了的问题。
  • 从 Preview 到正式版，Hy3 用两个月完成了一次肉眼可见的迭代 。下一次还能不能保持这样的速度，可能比这一代模型本身更值得关注。
