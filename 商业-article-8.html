Qwen-UI-Agent：让模型真正“会用”每一块屏幕

8/20/2026, 9:42:00 AM

📌 一句话摘要

本文介绍阿里研究院发布的 Qwen-UI-Agent，一个覆盖移动、电脑、网页及 DeepSearch 的 GUI 智能体基座模型，具备真机训练、安全防护、GUI+CLI 混合操作、长程在线 RL 及主动跨平台服务等能力。

📝 详细摘要

文章详细阐述了 Qwen-UI-Agent 的设计理念与技术实现：构建了 100+台真实手机、150+应用的真机环境进行训练与评测，在 MobileWorld-Real 等多项基准上超越 GPT-5.6、Claude Opus 等旗舰模型；模型在任务执行全程融入安全判断，对违法高风险请求直接拒绝，对支付、数据删除等敏感操作主动停手等待用户确认；支持 GUI 与 CLI 混合动作空间及批量操作（Batched Actions），显著提升执行效率；采用可扩展的长程在线强化学习，能够在超过 100 步的超长轨迹上进行 RL 训练，完成如数据分析报告生成等长程任务；通过 Harness 机制实现主动服务与跨平台工作流，例如航班取消后自动提供改签方案并在手机与电脑间无缝协作。文中还给出了咖啡探店、高铁行程、居家办公方案规划及深度数据分析等具体使用场景，展示了模型在真实世界中的通用执行能力。

💡 主要观点

  1. Qwen-UI-Agent 是一个覆盖移动、电脑、网页及 DeepSearch 的 GUI 智能体基座模型。 模型以真实世界为中心，能够在手机、电脑和网页界面上执行操作，并结合 DeepSearch 进行跨来源信息检索，形成统一的交互入口。
  2. 真机训练与评测保证了模型在实际设备上的可靠性。 构建了 100+ 台真实手机、150+ 应用的环境，建立 MobileWorld-Real 基准，模型在此基准上达到 92.2% 性能，超越多个业界旗舰模型。
  3. 安全判断贯穿任务执行全过程，能够拒绝高风险请求并对敏感操作主动确认。 面对违法或高风险请求直接终止；在支付、数据删除、隐私授权等关键步骤停手并向用户说明情况，待明确确认后继续，确保既能执行又懂得何时停手。
  4. GUI + CLI 混合动作空间及批量操作（Batched Actions）显著提升执行效率。 模型除了 GUI 操作外还能直接执行命令行，且约 40% 动作以批量形式输出，大幅缩短执行轨迹，适用于跨网站调研、生成比价方案等场景。
  5. 可扩展的长程在线强化学习支持超过 100 步的超长轨迹训练。 配合约 10000 个并发环境和自适应课程学习，模型能够完成如数据分析、报告生成等长程任务，并在过程中进行视觉校验与修正。
  6. Harness 机制实现主动服务与跨平台工作流，例如航班取消后自动提供改签方案。 Agent 能主动识别受影响行程、检索备选航班与高铁、结合日程给出方案，经用户确认后执行，并在手机与电脑之间无缝接力完成后续工作。

💬 文章金句

  • GUI 智能体有望成为现有数字设备上的通用执行器，只要有界面，它就能上手替你操作。
  • Qwen-UI-Agent 将安全判断贯穿任务执行全过程：面对违法或高风险请求，它会不执行任何界面操作，直接拒绝并终止任务；面对支付、数据删除、隐私授权等敏感场景，则会在关键步骤主动停手，向用户说明情况，待获得明确确认后再继续。
  • GUI 操作之外，模型还能直接执行命令行操作，并在单次决策中批量输出多个动作。在电脑任务中，CLI 动作占比近半，约 40%动作以 batched actions 形式输出，大幅缩短执行轨迹、拓展能力边界、提升执行效率。
  • 支持在超过 100 步的超长轨迹上进行在线 RL 训练，约 10000 个并发环境同时 rollout，配合模型自适应课程学习，持续攻克长程任务。
  • 通过强大的 Harness 能力，Agent 不再被动等待指令，而是主动服务。比如收到航班取消通知，Agent 可主动识别受影响的行程、检索备选航班与高铁、结合日程给出改签方案，经用户确认后执行，并在手机与电脑之间无缝接力完成后续工作。
