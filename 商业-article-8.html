DeepSeek Harness 大起底：这一次，重新定义「插件」

8/19/2026, 11:58:00 AM

📌 一句话摘要

DeepSeek Harness 通过重新定义插件概念，将模型的工作配套从固定框架解耦为可替换模块，实现更灵活、可组合的 Agent 工作流。

📝 详细摘要

文章深入剖析了 DeepSeek Harness 对传统插件的全新定义，指出 Harness 的本质是让大模型从“有能力”转变为“能上岗”的完整工作配套系统。它把模型的能力接入真实环境所需的工具、文件系统、会话、沙箱等底层资源都视作可插拔的模块，并通过 Cordis 框架实现插件的可插拔、可组合与可验证。文章将传统插件比作“添砖加瓦”，而 DSH 的插件则像可随时替换的办公室模块，展示了从 Pi 的极简核心到 DSH 可全面替换的演进路径，并解释了可组合性背后的结构实现细节。

💡 主要观点

  1. Harness 让大模型从“有能力”转变为“能上岗”的完整工作配套 通过为模型准备工位、权限、上下文、文件系统、沙箱等基础设施，使其能够在真实环境中安全、可预测地执行任务。
  2. 传统插件是锦上添花，而 DeepSeek Harness 将插件概念内化为可替换的 Harness 模块 把文件系统、会话、沙箱等底层能力也视为可替换的插件，实现对工作流的高度定制和组合。
  3. 通过 Cordis 框架实现插件的可插拔、可组合与可验证 插件通过 inject 声明依赖，卸载时自动回收；seam 由接口定义、实现提供、消费者使用组成，所有配置可视觉化输出，保证可验证的组合。
  4. 把文件系统、会话、沙箱等底层资源也视为可替换的插件，实现更灵活的工作流 只要遵守统一的接口标准，就可以在不同实现之间切换，如将本地文件系统替换为远程沙箱，而无需修改上层 Agent 逻辑。

  • 模型决定了这个「员工」本身大概有多聪明、会不会推理、会不会写代码；Harness 则负责把这些能力接进真实环境。
  • DSH 的「插件」，更像可以随时替换的办公室模块
