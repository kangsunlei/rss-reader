#692.Neil Movva：把 AI 推理成本降 10 倍，智能充裕时代如何绕开芯片与电力瓶颈

8/28/2026, 8:24:28 PM

📌 一句话摘要

Sail Research 创始人 Neil Movva 分享如何通过软件优化、非主流芯片与分散式小型数据中心，将 AI 推理成本降低十倍，实现长周期后台 Agent 的「智能充裕」愿景。

📝 详细摘要

本期对话 Sail Research 创始人 Neil Movva，探讨如何将 AI 推理成本降低十倍，从而催生全新的产品品类。Neil 认为，降低 token 成本比追求低延迟更重要，因为未来的 AI Agent 将主要在后台长时间运行，完成深度研究、网络安全、互联网索引等任务。他详细解释了 GPU 吞吐量与延迟的根本权衡、Tensor Core 与 NVLink 的作用、Cerebras 等新型加速器的潜力，以及 KV cache 对长上下文推理的瓶颈。Neil 提出「拾荒者策略」：通过购买被低估的芯片（如 AMD、TPU、Trainium）和利用分散的小型数据中心（甚至可用性仅 95%），结合自研软件实现异构调度，以极低成本提供推理服务。他还讨论了 Transformer 的可扩展性、数据从互联网向强化学习环境的转变、英伟达的供应链瓶颈，以及他对英伟达短期看好的逆向观点。核心愿景是让智能变得充裕，使机器能够持续思考，让每个人都能负担得起智能服务。

💡 主要观点

  1. 把 token 成本降低十倍是创造新需求的关键 Neil 认为，当智能足够便宜，Agent 就能在后台持续运行，执行过去因成本过高而无法完成的长周期任务，从而催生全新的产品品类，如深度研究和主动型个人助理。
  2. 未来 AI 的形态将从实时对话转向长周期后台 Agent 低延迟不再是唯一指标，后台运行的 Agent 可以接受数小时甚至数天的运行周期，因此吞吐量优化比延迟优化更重要，这改变了整个技术栈的设计方向。
  3. 通过异构芯片和分散基础设施可以有效降低成本 Neil 采取「拾荒者策略」，购买被低估的 AMD、TPU、Trainium 等芯片，并利用可用性较低（如 95%）的小型数据中心，通过软件调度组合成高效的推理网络。
  4. KV cache 是长上下文推理的主要瓶颈 KV cache 随对话增长而动态变化，占用的内存常常超过模型权重本身，成为限制推理速度和成本的关键因素，需要混合计算方案来优化。
  5. 数据来源将从互联网转向强化学习环境 互联网数据已近枯竭，未来模型将通过可验证任务和强化学习环境实现自我提升，这比随机人类反馈更有效。

💬 文章金句

  • 我们认为只要你把某样东西便宜十倍，它就会成为一个全新的产品品类。
  • 一种说法是，最好的延迟就是完全没有延迟。
  • 随着你不断给 agent 发 prompt 并等待回复，你在其中参与的越多，实际上，你反而成了决定 Agent 能做多少工作的瓶颈。
  • 没有坏的芯片。只有不合理的价格。
  • 我会买 95% 可用性的数据中心。
