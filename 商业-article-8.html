张鹏对谈李广密：Agent 的真问题与真机会，究竟藏在哪里？

6/14/2025, 2:32:00 AM

📌 一句话摘要

对谈探讨 AI Agent 的核心问题、机会、技术路径和商业模式，聚焦编程 Agent 及底层基础设施。

📝 详细摘要

本文是一篇关于 AI Agent 的深度对谈，邀请拾象科技创始人李广密和 AI Research Lead 钟凯祺，共同剖析 Agent 热潮下的真问题与真机会。讨论覆盖 Agent 的产品形态（通用与垂直、Model as Agent）、务实成长路径（从 Copilot 到 Agent，以 Cursor 为例）、Coding 作为通往 AGI 关键试炼场的逻辑、评估好 Agent 的标准（数据飞轮、Agent Native、效率、成本、用户粘性）、商业模式创新（从成本到价值、按次/工作流/结果/Agent 付费）以及人与 Agent 的协作关系（Human in/on the loop）。对话还探讨了 Agent 基础设施的机会（环境、上下文、工具、安全）以及巨头（OpenAI、Anthropic、Google、Microsoft）在 Agent 领域的布局与分化。最后展望了多模态、自主学习、记忆机制和新交互作为 AI 未来关键技术台阶，指出 AI 产品正从工具走向关系。

💡 主要观点

  1. Agent 核心瓶颈在底层基础设施而非模型能力。 可控运行环境、记忆系统、上下文感知和工具调用等基础设施的缺失是 Agent 从演示走向实用的主要阻力，构成高价值创业蓝海。
  2. Coding 是衡量 AGI 的关键指标和潜在首个实现环境。 编程环境数据干净、易闭环、结果可验证，适合强化学习构建数据飞轮，能锻炼 AI 核心能力，有潜力拿走大模型产业阶段性 90%价值。
  3. 从 Copilot 到 Agent 是务实的演进路径。 Agent 不需一开始就完全自动化，可从 Copilot 形态起步，通过提升特定功能准确率（如代码补全），收集用户数据，逐步过渡到后台异步 Agent。
  4. 好的 Agent 需构建数据飞轮和具备上下文感知。 通过可验证的回报（如代码/数学任务）建立数据循环，并整合多源上下文（代码库、文档、沟通记录）提升 Agent 效率和用户体验。
  5. AI 产品正从工具转向与用户的“关系”。 具有记忆、理解用户、能产生心流体验的 AI Agent，将与用户建立类似伙伴的关系，形成强大的用户粘性和壁垒。
