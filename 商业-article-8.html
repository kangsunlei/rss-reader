Claude Code 正在重写你的第二大脑

5/14/2026, 12:55:00 PM

📌 一句话摘要

本文通过 Noah 的实践案例，展示了如何将 Claude Code 与 Obsidian 笔记库、Git、个人服务器和手机终端深度集成，把「第二大脑」从一个收藏系统改造成一个会追问、会整理、会帮你推 PR 的工作伙伴。

📝 详细摘要

本文基于播客内容整理，详细介绍了 AI 策略咨询师 Noah 如何将 Claude Code 深度嵌入个人工作流。核心实践包括：将 Claude Code 运行在整个 Obsidian 笔记库根目录，使其能读取旧笔记、会议资料和网页剪藏；通过「thinking mode」和「writing mode」的明确划分，避免 AI 过早生成不成熟的成品；利用手机终端远程连接家中服务器，在移动场景下完成深度思考、研究和代码修改。文章还探讨了 AI 如何像「Thomas' English muffin」一样钻进组织缝隙，绕过官僚流程实现信息打通；以及代码复用从「封装给人调用」转向「让模型读懂再转译」的趋势。作者认为，Claude Code 的入口不只在代码仓库，也可以在笔记库、演讲项目和个人服务器里，工程师、产品经理和内容工作者都可以从自己的真实工作流开始。

💡 主要观点

  1. Claude Code 可以接管笔记库，将全库上下文带入思考现场。 Noah 将 Claude Code 运行在整个 Obsidian vault 根目录，使其能读取旧笔记、会议资料、网页剪藏和研究文档，在准备演讲时自动关联相关素材，实现知识库的主动检索和整合。
  2. 明确划分「思考模式」和「写作模式」，避免 AI 过早生成成品。 在项目说明中直接禁止 AI 写任何东西，只要求它提问、记录和整理想法。这防止了模型过早滑向成品输出，让用户先完成素材堆叠和判断，再进入生成阶段。
  3. 手机通过远程连接变成深度工作入口。 利用 Tailscale、GitHub 和 Termius，在手机上远程连接家中服务器启动 Claude Code，可以完成思考研究、代码修改和 PR 推送等需要上下文的复杂任务，突破了手机仅适合轻量操作的局限。
  4. AI 像「Thomas' English muffin」一样钻进组织缝隙，打通信息孤岛。 AI 作为模糊接口，不在意输入输出形式，员工可以保留原有工具和流程，由 AI 负责翻译、连接和补齐，绕过传统企业软件 adoption 和 change management 的难题。
  5. 代码复用从「封装给人调用」转向「让模型读懂再转译」。 不再将通用能力抽象成统一库，而是让 Claude Code 读取现有实现，再迁移出适合自己技术栈的版本，实现隐性代码共享，降低复用成本。

💬 文章金句

  • 当你只是在思考时，必须明确告诉 Claude Code：我不想让你现在帮我写东西。
  • 第二大脑在这里承担的任务，是把全库上下文带进当下的思考现场。
  • AI 有点像模糊接口，它不太在意输入输出的形式。
  • 知识复用从「封装给人调用」，变成「让模型读懂再转译」。
  • 一个工具如果能让 10 岁孩子做出一个应用，我看不到它会是泡沫。
