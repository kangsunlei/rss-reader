有关第三代模型，苹果管理层回应一切

6/9/2026, 8:06:00 AM

📌 一句话摘要

苹果在 WWDC 2026 上发布第三代基础模型 AFM 3，包含 5 款模型，通过指令跟随剪枝、MoE 架构和与谷歌 Gemini 的蒸馏合作，在端侧和云端实现了 AI 能力的全面升级，并明确了隐私边界与合作细节。

📝 详细摘要

本文是腾讯科技对苹果 WWDC 2026 上发布的第三代 Apple Foundation Models（AFM 3）的深度解读。文章详细介绍了 5 款模型（端侧 AFM 3 Core、AFM 3 Core Advanced；云端 AFM 3 Cloud、ADM 3 Cloud、AFM 3 Cloud Pro）的架构、技术亮点和性能提升。重点解析了 AFM 3 Core Advanced 的「指令跟随剪枝」技术，该技术通过将模型参数分层存储在 DRAM 和 NAND 闪存中，实现了 200 亿参数模型在端侧的高效推理。文章还披露了苹果与谷歌的合作边界：苹果使用专有数据训练模型，并借助 Gemini 模型进行蒸馏（「优化精炼」），而非直接部署 Gemini。此外，AFM 3 Cloud Pro 是唯一针对英伟达 GPU 优化的模型，运行在谷歌云上，但通过苹果的 Private Cloud Compute 架构保障隐私。文章引用了苹果高管在技术交流会上的发言，并提供了详尽的基准测试数据，全面展示了苹果在 AI 领域的战略布局和技术实力。

💡 主要观点

  1. 苹果发布第三代 AFM 3 模型家族，包含 5 款模型，覆盖端侧与云端。 端侧模型为 AFM 3 Core（常规升级）和 AFM 3 Core Advanced（200 亿参数稀疏模型）；云端模型为 AFM 3 Cloud（主力）、ADM 3 Cloud（图像生成）和 AFM 3 Cloud Pro（最强推理）。
  2. AFM 3 Core Advanced 通过「指令跟随剪枝」技术，实现 200 亿参数模型在端侧运行。 该技术将注意力层等核心权重常驻 DRAM，FFN 专家参数存储在 NAND 闪存中，推理时仅按需加载少量专家，解决了端侧内存瓶颈。每次响应仅激活 10-40 亿参数。
  3. 苹果与谷歌的合作仅限于模型蒸馏，而非直接部署 Gemini。 苹果使用专有数据训练模型，并利用 Gemini 前沿模型进行「优化精炼」（即蒸馏），提升自身模型能力。iOS 中未集成任何 Gemini 客户端代码或谷歌搜索知识库。
  4. AFM 3 Cloud Pro 是唯一针对英伟达 GPU 优化的模型，运行在谷歌云上，但受苹果隐私架构保护。 苹果通过 Private Cloud Compute 架构确保数据不被存储、苹果无法访问，且第三方研究人员可验证隐私属性。苹果完全控制部署在谷歌云节点上的软件。
  5. 第三代模型在文本、图像理解和语音处理等基准测试中实现显著提升。 AFM 3 Cloud 的文本偏好比例从 8.7% 飙升至 64.7%；AFM 3 Core Advanced 的 TTS 得分提升 0.28 分，听写任务以 44.7% 对 17.6% 的优势碾压前代。

💬 文章金句

  • 我们使用的谷歌助手组件量为零。
  • AFM Core、AFM Core Advanced、AFM Cloud 和 ADM Cloud 这四款模型，为苹果芯片定制构建，使用专有数据训练，并利用 Gemini 前沿模型进行优化精炼。
  • 性能与谷歌 Gemini 前沿模型相当。
