免費 AI Agent 終於來了！Hermes Agent 五大功能，串起你所有工作軟體！

9/28/2026, 11:16:41 PM

📌 一句话摘要

漢克蔡以自家公司部署經驗完整教學免費 AI 代理工具 Hermes Agent，涵蓋硬體條件、四種部署選項、安裝設定，以及工具、整合、技能、排程工作與記憶管理五大功能，最後用 Ollama 引進開源模型，不燒 Token 讓 AI 全天候替你工作。

📝 详细摘要

這支影片系統性教學免費 AI 代理工具 Hermes Agent。講者先釐清跑開源模型的硬體條件——RAM 16GB 以上即可起步，並給出 Mac Studio、月費 5 到 6 美元的 VPS、閒置舊電腦與 Docker 容器化四種選項，還分享任務集中在週一清晨導致當機、改分批排程的實際教訓。接著示範安裝與初始設定，包含把 Claude 的記憶匯出成 MD 檔搬進 Hermes Agent，以及開啟保持電腦喚醒以支援全天候運行。影片主體逐一講解五大功能：工具示範以網頁搜尋加圖表產出 AI 晶片報告；整合打通 LINE、Telegram 等通訊平台，任何軟體只要有 MCP 或 API 都能接入；技能把重複工作 SOP 化，例如股票基本面分析；排程工作用 Cron Jobs 定時產出週報與每日簡報；記憶管理拆解 memory.md、user.md、soul.md 三檔架構與對話搜尋，再推薦外部工具 Honcho 推理使用者行為模式，講者估計可省下五成以上 Token。最後教學用 Ollama 引進開源模型，搭配閉源做高階工作、開源做例行產出的混合策略，兼顧品質、成本與資料保密。

💡 主要观点

  1. 跑開源模型的硬體門檻不高，四種方案對應不同預算 RAM 16GB 以上即可起步；Mac Studio 最穩、VPS 月費 5 到 6 美元、閒置舊電腦可再利用，現用電腦則建議用 Docker 容器化隔離，避免工作時當機。
  2. 混合模型策略：高階工作用閉源，例行產出用開源 AI 軟體開發與抓 bug 交給 Anthropic 等閉源模型，日常報告與 PPT 由地端開源模型處理，兼顧品質與 Token 成本，客戶資料也不外流。
  3. 工具、整合、技能、排程與記憶構成完整代理工作流 工具負責搜尋與生成，整合透過 MCP 或 API 打通 LINE 等第三方軟體，技能把重複工作 SOP 化，Cron Jobs 定時執行，記憶管理則維持長期產出品質。
  4. 記憶管理是產出符合預期的關鍵，檔案膨脹會推高出錯率 memory.md、user.md、soul.md 分別儲存設定、使用者與代理本身資訊；搭配對話搜尋與外部工具 Honcho 推理行為模式，講者估計可省五成以上 Token。
  5. Ollama 引進開源模型，免費實現全天候自動化 Ollama 管理地端開源模型，裝好後從 Apps 頁面複製指令接入 Hermes 桌面版，再開啟保持電腦喚醒，就能不燒 Token 讓代理 24 小時運行。

💬 文章金句

  • 你的東西只要有 API 或者是 MCP，基本上都是可以連到 Hermes Agent，讓 Hermes Agent 來幫你執行代理這件事情——簡而言之，就是幫你工作啦。
  • 你要真正的把 AI 融入到自己的生活，重點就是你要創造一個讓你自己很容易進入數位世界的窗口。
  • 第一個，你在學新東西；第二個，你又覺得這件新東西是你一直重複會做的。這兩個元素滿足之後，你就可以把這件事情技能化。
  • 最大的重點是，記憶管理做得好，其實可以幫你省下五成以上的 Token 使用量。
