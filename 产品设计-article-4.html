租来的智能不会产生复利，拥有的才会

8/20/2026, 12:48:00 AM

📌 一句话摘要

本文翻译并点评了 YC 总裁 Garry Tan 的演讲《Own Your Intelligence》，强调通过拥有个人知识库和技能文件构建私人 AI，使智能成为可复利的资产而非租用的产品。

📝 详细摘要

文章首先介绍了 Garry Tan 的背景及其在 YC Startup School 2026 上的 42 分钟演讲核心观点：智能不应被租用，而应通过个人拥有的上下文（如 22 万页 markdown 知识库、技能文件、agent）实现复利增长。演讲从斯宾诺莎被逐出教门的历史类谈起，指出现代人对 AGI 的错误期待，主张 Personal AGI——跑在个人基础设施上的通用智能。接着详细描述了 Tan 个人系统的构成：知识库、技能文件（可被聪明实习生执行的 markdown 说明）、agentic 编程框架 GStack 以及工作流程（睡眠中处理收件箱、晨间简报、技能文件定时任务）。通过四百倍产出的案例、YC 内部公司数据以及父亲为患病儿子建 8 万个 markdown 文件的真实故事，论证了拥有智能带来的指数级产出与职业所有权。文章最后给出五步操作指南（选择 harness、建图书馆、写技能文件、设定定时任务、永不做一次性工作），并警告若技能文件不属于个人，则等同于认知被榨取。全文结合历史哲理、实证数据与个人实践，提供了构建私人 AI 的方法论与行动激励。

💡 主要观点

  1. 智能应被拥有而非租用，只有自建的个人知识库和技能文件才能产生复利。 演讲指出，将技能文件放在他人仓库里相当于让认知成为他人的榨取物；只有跑在自己基础设施上的 agent 才能每天多知道一点你的人生，从而实现指数级增长。
  2. Personal AGI 的核心是将强大模型与个人独有上下文结合，使用 markdown 技能文件驱动 agent 执行。 模型质量是租的，但上下文（知识库、技能文件）是你拥有的；技能文件只需写清英文说明，任何识字的人都能让 agent 照做，实现『聪明的实习生测试』。
  3. 构建个人 AI 系统的五步法：选择 harness、建立知识库、编写首个技能文件、设定定时任务、坚持不做一次性工作。 先在本机运行 agent，再导出笔记邮件形成图书馆，针对厌恶的重复工作写技能文件并让 agent 执行，每日定时触发，任务结束时将所做事项技能化，形成复利循环。
  4. 拥有技能文件意味着职业所有权；若文件归他人所有，离职时将失去积累的判断力，等同于被榨取。 以虚构的支持工程师 Maya 为例，技能文件在个人仓库里可随身携带，而在公司仓库里则离职两手空白，个人判断被公司锁定，历史上第一次认知可被萃取、存储、版本化并被他人拥有。
  5. 真正的快乐来自行动力的增强，而非单纯的便利；Personal AGI 能让行动力持续增长，带来持续的满足感。 引用斯宾诺莎的定义，快乐是行动能力在增强的感觉；当 agent 在下午干完一周的工作时，带来的不仅是方便，而是咔哒般的行动力提升，这种感觉才是持续动力的源泉。

💬 文章金句

  • 你的技能文件放在谁的仓库里，决定了你的认知是你的资产，还是别人的榨取物。
  • AGI 不是作为事件到来的，它是弥散着到来的：你的 agent，跑在你的上下文上，做你的工作。
  • 一个是你消费的产品，一个是你建造的资产。
  • 技能文件是你的。拥有你的技能------因为如果你不拥有，你的工作就会变成一个技能文件。
  • 一切卓越之物，既困难，又稀有。
