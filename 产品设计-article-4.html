📝 详细摘要

Andy Clarke 在本文中详细介绍了一套实用的 SVG 准备、优化和构建工作流，专门针对 Web 动画和性能优化。作者从经典动画片中汲取灵感，强调从 Sketch 或 Affinity Designer 等矢量工具入手，进行简洁的设计，专注于简化路径和最小化锚点，以减小文件大小。他提到，虽然这些工具已经很优秀，但 Adobe Illustrator 也能用于路径简化。一个关键步骤是利用 Jake Archibald 的 SVGOMG 等在线工具进行严格的代码优化，删除不必要的元数据和臃肿的路径数据。随后，文章介绍了一种结构化的分层方法，通过按顺序导出和组合 SVG 元素，创建易读且易于管理的代码，从而更轻松地识别各个组件，并使用 CSS 关键帧动画等技术实现动画效果。最后，文章强调使用 `` 元素来复用重复元素，这是一种有效的方法，既能减小文件大小，又能简化管理，对于包含大量相似形状的复杂图形而言至关重要。这一全面的流程在视觉质量、可访问性、性能和可维护性之间实现了平衡。

💡 主要观点

  1. 在设计工具中简化路径并减少锚点。 最小化锚点可以使 SVG 文件更小，更易于渲染，并且通常不会降低视觉质量，这对性能至关重要。
  2. 使用 SVGOMG 等专业的 SVG 优化工具。 设计工具通常会生成冗余的 SVG 代码；专业的优化工具可以去除不必要的数据，从而显著减小文件大小。
  3. 应使用分层方法构建 SVG 代码。 使用分层方法按顺序导出和组合图层来构建 SVG，可以使代码更易读、更易于管理，并且更容易定位需要进行动画处理的元素。
  4. 对于重复的图形，应采用 `` 元素。 定义可重用元素可以减少代码冗余，降低文件大小，简化更新，并增强复杂 SVG 的可管理性。

💬 文章金句

  • 但是，要使动画快速加载并流畅运行，需要的不仅仅是情怀，更需要简洁的设计、精简的代码以及一套能够简化复杂 SVG 动画制作流程的方法。
  • 保持简洁是制作经过优化且易于动画处理的 SVG 的关键。
  • 形状包含的锚点越多，文件就越大。因此，简化路径并减少锚点数量可以显著减小 SVG 文件的大小，而且通常不会造成明显的视觉差异。
  • 我依赖于 Jake Archibald 的 SVGOMG，它使用 SVGO v3，并且始终能够提供最佳的优化效果。
  • 我为动画准备 SVG 的流程远不止绘制矢量图形和优化路径，还包括如何组织代码本身。
