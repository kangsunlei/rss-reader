腾讯刚入局，Manus 又要融资 33 亿

9/17/2026, 12:25:52 PM

📌 一句话摘要

AI Agent 初创公司 Manus 在与 Meta 分拆后计划融资 5 亿美元，估值翻倍至 40 亿美元，引发关于独立 Agent 公司在基础模型能力增强时代能否生存的探讨。

📝 详细摘要

本文分析了 AI Agent 初创公司 Manus 离奇的资本路径：从被 Meta 收购到因监管被叫停，再到由腾讯等投资方回购并计划以 40 亿美元估值进行新一轮融资。作者探讨了在基础模型（如 Claude、Kimi）纷纷推出 Computer Use 等 Agent 能力的背景下，资本为何依然给应用层公司高估值。核心观点认为，模型能力不等于产品能力，Manus 的价值在于将模型、工具与用户任务组织成稳定工作流的能力。文章最后指出，独立 Agent 公司未来的挑战在于如何建立用户习惯和生态，以避免被模型厂商直接挤压生存空间。

💡 主要观点

  1. Manus 的资本路径与估值跳跃 Manus 经历了被 Meta 收购、监管叫停、投资方回购（约 20 亿美元）到计划新融资（估值 40 亿美元）的过程，账面身价在短时间内翻倍。
  2. 模型能力与产品能力的差异化 尽管基础模型厂商在增强通用桌面任务能力，但将能力转化为普通用户可用的复杂任务交付结果（稳定工作流）仍有较高门槛，这是独立 Agent 公司的机会点。
  3. AI 创业估值逻辑的转移 AI 公司的估值正从单纯追求模型参数和 Benchmark，转向关注面向用户的入口和工作流的掌控力，类似于移动互联网时代 OS 与应用的关系。
  4. 独立 Agent 公司的生存危机 面对模型厂商和操作系统原生的 Agent 竞争，独立公司必须在模型之外构建用户习惯、任务数据和工具生态，否则将被模型能力的延伸所覆盖。

💬 文章金句

  • 模型能力不等于产品能力。
  • 底层模型越来越像基础设施，真正面向用户的入口和工作流，也可以成为一门大生意。
  • 在大模型越来越强的时代，一家不自己训练基础模型的 AI Agent 公司，到底能不能独立长成一家巨头。
