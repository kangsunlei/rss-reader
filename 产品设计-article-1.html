OpenAI 开始大规模封号且不退款，中转站业务受冲击

6/5/2026, 2:23:24 PM

📌 一句话摘要

OpenAI 开始对 ChatGPT 进行大规模封号，且不退款，对 API 中转站业务造成冲击。

📝 详细摘要

博主 Ding 指出，OpenAI 终于开始大规模封禁 ChatGPT 账号，且不退款。此前用户认为 Anthropic 做法不妥，但 OpenAI 的做法更甚。这一行动将对依赖 API 中转站的服务商造成重大影响。
