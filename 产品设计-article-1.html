基元律动发布 NeoHorse-Jev，开源 Jev 综合评测第一

9/26/2026, 1:46:21 AM

📌 一句话摘要

基元律动发布开源轻量级决策模型 NeoHorse-Jev-4B，以 4B 参数在六组基准测试中获综合第一，主打毫秒级实时决策与标准化接口，已全量开源权重与代码。

📝 详细摘要

本文介绍了创业公司基元律动（由华为诺亚方舟实验室前主任王云鹤创办）发布的轻量级 AI 模型 NeoHorse-Jev-4B。该模型仅含 40 亿参数，但在涵盖决策、迁移、知识与语义判断的六组基准测试中取得 77.70 的综合平均分，位列成绩完整的开源参评模型第一。与传统生成式模型不同，NeoHorse-Jev-4B 采用 prefill-only 推理机制，直接返回候选概率或分数而非生成文本，从而将单次决策耗时压缩至毫秒级（服务端平均 74.3ms），并支持 Choice、Noul、Score 三种标准化调用方式。文章通过贪吃蛇、俄罗斯方块、Flappy Bird、麻将、自动驾驶仿真及机械臂具身智能等多个场景演示，展示了模型从“回答问题”向“驱动动作”的能力延伸，特别是在未针对具身数据专门训练的情况下完成了 Meta-World 任务。目前，模型权重、推理源码及部署示例已在 Hugging Face、ModelScope 和 GitHub 上以 Apache-2.0 协议全量开源。

💡 主要观点

  1. NeoHorse-Jev-4B 以小参数规模实现高性能开源排名 尽管仅有 4B 参数，该模型在六组基准测试中综合得分 77.70，超越更大参数的 Open-Jev-9B，并在 Nimble、VitaminC、MASSIVE 三项核心测试中较原始模型提升显著，证明了其在特定决策场景下的优化效率。
  2. 创新的 Prefill-only 推理架构大幅降低延迟 模型不逐 Token 生成自然语言答案，而是直接计算候选项概率并返回结构化结果（如单选、是非判断、打分）。这种设计省去了生成阶段的延迟，使得服务端平均决策耗时仅为 74.3ms，适合高频嵌入软件执行链路。
  3. 标准化的决策接口简化了应用集成 开发者可通过自然语言定义任务，模型直接返回概率分布或量化分数。这种“输入状态->返回判断->执行动作”的范式，替代了传统的 if-else 规则引擎或额外分类模型，降低了接入门槛。
  4. 跨场景泛化能力验证了从游戏到具身智能的潜力 演示涵盖了贪吃蛇、麻将等逻辑游戏以及自动驾驶、机械臂仿真等复杂环境。值得注意的是，模型在未针对具身数据专门训练的情况下成功完成 Meta-World 任务，显示了其通用决策能力的跨场景迁移潜力。

💬 文章金句

  • 3000 步，89 个目标，蛇还活着。
  • NeoHorse-Jev-4B 取得了 77.70 的综合 AVG 分数，一举超越参数规模更大的 Open-Jev-9B（领先 2.03 分），在成绩完整的开源参评模型中位居第一。
  • 传统生成式模型通常要经历：理解输入 → 逐 Token 生成答案 → 解析答案 → 执行；而 NeoHorse-Jev-4B 的路径被缩短为：理解输入 → 返回候选概率 → 执行。
  • 在一组由 1158 个真实文本请求构成的混合负载测试中，32 并发情况下，服务端记录的平均决策耗时为 74.3ms。
  • 更值得注意的是，这款模型并未针对具身数据进行专门训练。也就是说，这一结果更多体现的是，基于 NeoHorse-1-4B 的通用能力，决策接口本身已经具备了一定的跨场景迁移潜力。
