张一鸣该跟豆包算账了

1/21/2026, 11:45:00 PM

📌 一句话摘要

本文深度剖析了字节跳动旗下 AI 应用“豆包”的财务现状，探讨其如何从依赖 B 端卖 token 的亏损模式转向借鉴 OpenAI 的 C 端广告与会员商业化路径。

📝 详细摘要

文章指出，尽管豆包已成为国内日活过亿的超级 AI 应用，但目前面临严重的“收支错配”：百亿美元级的投入与数亿美元的 B 端收入形成巨大反差。通过对比 OpenAI、智谱、MiniMax 等国内外同行的财务数据，文章揭示了 AI 行业普遍的大额亏损现状。作者认为，豆包应发挥字节跳动的“流量基因”优势，摆脱单一的 B 端 token 售卖模式，转而通过 C 端会员费、App 内广告投放以及构建 AI 购物闭环来提升变现效率。此外，文章还提出了分拆豆包独立发展以优化估值和对外合作的战略建议，强调将商业重心回归 C 端流量生意是豆包扭亏为盈的关键。

💡 主要观点

  1. 豆包目前处于严重的收支失衡状态，B 端收入难以覆盖巨额投入。 字节在 AI 领域的资本开支达百亿美元级别，而 B 端云服务收入占比极低，卖 token 的商业模式在激烈竞争下利润空间有限。
  2. 豆包应借鉴 OpenAI 模式，通过 C 端会员和广告实现规模化营收。 利用过亿日活的流量基础，通过设置会员门槛和引入广告，可将 AI 流量转化为高价值的商业回报，缓解亏损压力。
  3. AI 流量具有高目的性和高转化率，商业价值优于传统短视频流量。 AI 用户需求明确且对反馈信息依赖度高，更易被引导和转化，豆包应开掘这一“流量金矿”而非仅做卖铲子生意。
  4. 分拆独立发展可能是豆包优化财务表现与战略灵活性的有效路径。 独立分拆能让字节轻装上阵，同时让豆包在融资、跨平台电商合作（如接入阿里、京东）等方面更加自如。

💬 文章金句

  • 相比几个亿的收入，百亿美元级别的投入高了两个数量级。
  • 豆包赔的远比赚的多，且一时半会儿改不了。
  • 豆包最合理的商业化选择，其实就是回到字节熟悉的流量生意上。
  • 豆包放着 AI 流量金矿不去开掘，仅仅围绕 API 调用做‘卖铲子’的生意，多少有点儿暴殄天物。
  • 字节也需要给豆包算算账，甚至彻底‘放飞’豆包了。
