在 AI Agent 出现之后，我重新思考了自己的职业下注

3/1/2026, 11:46:00 PM

📌 一句话摘要

本文通过分析 Remote Labor Index 数据指出 AI Agent 现状与潜力，探讨了自然语言驱动的软件交互范式变革，以及在这一浪潮下个人职业选择的战略思考。

📝 详细摘要

作者结合 Remote Labor Index (RLI) 数据指出，当前 AI Agent 仅能替代约 2.5% 的人类工作，呼吁读者在喧嚣的 AI 舆论中保持冷静。文章核心观点认为，我们正处于从“工业级复杂 UI”向“自然语言交互”转变的软件范式革命中。这种变革将对传统 SaaS 产生降维打击，Agent 原生产品将以低门槛和按结果收费的模式走向大众。作者预测未来软件将呈现“对话框为主、传统图表为辅”的混合形态，并分享了自己全线押注 AI Agent 领域的职业决策逻辑。

💡 主要观点

  1. AI Agent 对人类工作的直接替代目前尚处于极早期阶段。 根据 RLI 数据，目前仅 2.5% 的工作能被 AI 追平或超越。虽然未来比例会大幅提升，但当下谈论全面替代为时过早，行业仍处于爆发前夜。
  2. 自然语言将成为下一代软件的核心交互范式，降低使用门槛。 软件正从 Adobe 式的专业工具向自然语言驱动转型。用户不再需要学习复杂的规则和 UI 操作，通过简单的对话即可获得满意的结果，实现工具的大众化。
  3. Agent 原生产品将通过“降维打击”重塑传统 SaaS 行业格局。 传统 SaaS 存在高学习和订阅门槛，而 Agent 原生产品凭借低门槛和按结果收费的模式，将直接冲击细分赛道的流量，每个领域都将出现原生 Agent 产品。
  4. 未来软件形态将是对话框交互与传统数据操作区的有机结合。 交互范式的变革是逐步侵蚀的过程。对于策略分析等环节，对话框效率更高；但对于效果监控等任务，仍需保留传统 SaaS 的图表和数据展示功能。

💬 文章金句

  • 我们要么成为构建 AI Agent 来替代他人的人，要么就可能成为被 AI Agent 所替代的人。——这可能是 AI 时代的“囚徒困境”。
  • 真正的变革来了：“自然语言”将成为软件交互的主要方式。
  • 颠覆 Adobe 的绝对不是另一款更好用的 Adobe，打败传统燃油车的也不是更好的燃油车。
  • AI Agent 的使用低门槛+按结果收费的模式，会让工具真正走向大众。
