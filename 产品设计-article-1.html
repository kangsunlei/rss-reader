AI 圈新热词 Skills 到底是个啥？一篇文章整明明白白

1/7/2026, 11:45:00 PM

📌 一句话摘要

本文全面讲解 AI 圈热词“Skills”，阐释其作为大模型预设提示词、工具调用和渐进式披露机制，以及对 AI 开发者和产品经理的关键意义。

📝 详细摘要

本文深度解析了 AI 领域新热词“Skills”的概念、原理、应用场景及其在 AI 工作流中的定位。作者从 Skill 与 MCP、Commands、SubAgents 等功能的关系入手，通过通俗易懂的类比和图示，阐明了 Skill 的本质是预设提示词、工具调用和渐进式披露上下文以节省 Token 的机制。文章进一步详述了 Skill 的运行原理、创建方式以及支持 Skills 的客户端（如 Claude、Qwen Code、Alma 等）。最后，作者强调对于普通用户而言，了解其概念即可，但对 AI 产品经理和算法工程师来说，Skills 代表了一种将最佳实践产品化、实现大模型工具调用标准化、优化上下文工程的关键方法，具有重要的研究价值和实践意义。

💡 主要观点

  1. Skills 是 Claude 推出的一种高级功能，本质上是通过预设提示词和工具调用，提升大模型执行复杂任务的能力。 Skills 与 MCP、Commands、SubAgents 等功能同属一类，但其独特之处在于支持渐进式披露和附件文件形式，能在模型需要时才加载相关信息和脚本，从而节省 Token 消耗和提高灵活性。
  2. Skills 的核心在于将工具调用和知识库管理，通过配置文件和脚本实现模型的“使用工具”能力。 通过在特定文件夹内定义 `SKILL.md` (包含技能名称、描述和用法) 并关联资料文档和程序脚本，AI 能够在需要时加载和执行这些工具，使其具备类似人类使用工具的“技能”。
  3. Skills 主要适用于客户端应用而非网页版，因其需要客户端的本地文件读写和代码执行权限。 与 MCP 支持云端调用不同，Skills 的实现机制要求在本地文件系统进行配置和操作，因此其应用场景多限于 Claude 客户端、Claude Code、Qwen Code、Alma 等桌面或终端工具。
  4. Skills 对 AI 产品经理和算法工程师具有重要价值，是实现 AI 最佳实践产品化、优化上下文工程的关键手段。 对于专业人士，Skills 提供了一种将特定业务流程或复杂任务标准化、封装并让 AI 接管的有效方法，同时通过渐进式披露机制，有效管理上下文和 Token 成本，是提示词工程的进阶实践。

💬 文章金句

  • 所有这些花里胡哨的名词，本质上都是预设或者现场编写一些提示词、在需要的时候发给大模型，让 AI 按提示词干活。
  • SKills 渐进式披露，节省 Token 消耗；以“附件文件”形式提供，更灵活。
  • 但，众所周知，大模型它只能给你回复文本，没手没脚。只能由人类来伺候它（我想到了一个科学家，但我不能说，显得很不尊重人......）
  • 对于普通人来说，看完这篇文章，知道这东西是个啥、有谈资就够了。
  • 一种把最佳实践产品化、且让大模型接管的最小实现，AI 产品经理的必备技能。
