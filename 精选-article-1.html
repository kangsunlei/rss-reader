LLM 辅助编码体验优化之旅

8/24/2025, 7:46:50 PM

📌 一句话摘要

Andrej Karpathy 分享了他不断发展和多样化的 LLM 辅助编码方法，详细介绍了一个分层工作流，利用从简单的 tab complete 到 GPT-5 Pro 等高级模型。

📝 详细摘要

Andrej Karpathy 详细介绍了他的个人工作流，旨在优化 LLM 辅助编码体验。他概述了一个多层策略，其中 75% 的帮助来自 Cursor 的 tab complete，用于实现高效的任务定义方式。 随后，他会突出显示代码以进行修改；对于更大、更易于指定的功能，他则使用 Claude Code 或 Codex 等工具。 尽管他承认这些工具在不熟悉的领域进行《vibe-coding》或进行临时调试时很有用，但他同时也指出了它们在“代码风格”方面的局限性（例如，过度防御、过度复杂化）。 对于最具挑战性的问题，如细微的 Bug 或文献综述，他依赖于 GPT-5 Pro，并认为它非常强大。 Karpathy 总结说，LLM 深刻地拓展了编码的可能性，同时也让人产生了一种对跟上集体进步步伐的焦虑感。
