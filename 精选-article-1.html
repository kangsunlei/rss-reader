📌 一句话摘要

李宏毅教授深入探讨 2025 年影像与声音生成策略，重点解析 Autoregressive 模型在影像生成上的应用，并结合 Flow Matching 原理，展示连续 Token 生成技术如何解决离散 Token 限制。

📝 详细摘要

文章详细阐述了生成式 AI 在影像和声音生成方面的最新进展。李宏毅教授首先展示了 Sora、Suno 等模型在视频、音乐生成上的惊人能力，并逐步引入技术核心。报告深入分析了像素与采样点作为基本单位的局限性，进而引出 Tokenization 的概念及其在语音和影像生成中的重要性。文章详细讲解了传统 Autoregressive 模型在影像生成上的应用，包括 MaskGIT 的非固定顺序生成策略以及多尺度生成方法。为了突破离散 Token 的限制，文章强调了 Continuous Token 的必要性，并详细介绍了另一条技术路线——Flow Matching 的原理、训练方式及其在代码实现上的表现。最后，文章总结了 Autoregressive 与 Generative Head（基于 Flow Matching/Diffusion）结合的最新架构，指出了这是 2025 年影像与声音生成领域的主流趋势，有效解决了 Continuous Token 的多模态分布问题，并展望了未来技术发展。

💡 主要观点

  1. Autoregressive 与 Flow-matching/Diffusion 的结合是 2025 年影像声音生成前沿。 文章核心观点，指明了未来生成式 AI 发展方向，通过将两种技术路线融合，突破了各自的局限性，实现了更高效、高质量的生成。
  2. Tokenization 是解决像素/采样点生成效率低下的关键。 明确了 Token 化的必要性，其将细粒度数据转换为更大单位，简化序列长度，大幅提升了生成模型的效率，尽管存在信息失真。
  3. Continuous Token 结合 Generative Head 能克服离散 Token 的瓶颈。 解决了离散 Token 的表达上限问题，通过将离散 Token 替换为连续向量，并引入 Flow Head/Diffusion Head 处理多模态分布，持续提升生成质量。
  4. Flow Matching 通过向量场引导，将简单分布转换为复杂目标分布。 剖析了 Flow Matching 作为生成模型核心机制，它能有效处理开放式生成任务中的不确定性，是提升模型生成多样性和质量的重要手段。
  5. MaskGIT 等非顺序生成策略提升了图像生成效率和质量。 介绍了 MaskGIT 通过并行解码和置信度选择顺序等方式，解决了传统自回归模型效率低下的问题，并能生成更具内容感知的图像。

💬 文章金句

  • 今天主要讲 Autoregressive（接龙）这个角度，以及它如何与 Flow Matching 和 Diffusion Model 这另一条研究路线结合，在 2025 年"走在一起"。
  • 用采样点或像素接龙有一个大问题：效率太低。我们需要更大的单位，也就是 Token。
  • 随着对画质要求提高，我们发现 Discrete Token (离散 Token) 限制了上限。解决方法是使用 Continuous Token (连续 Token)。
  • Flow Matching 的运作就像一个向导 (Guide)：模型本质上是一个 Vector Field (向量场)，在旅程的每一步告诉我们"接下来往哪个方向走"。
  • 2025 年的趋势是将这两条世界线结合：Autoregressive Model (负责接龙) + Generative Head (负责生成 Continuous Token)。
