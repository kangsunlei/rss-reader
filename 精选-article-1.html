智谱深夜开源新一代 GLM 模型，推理速度快 DeepSeek-R1 八倍，还启用了全新域名 Z.ai

4/15/2025, 4:08:13 AM

📌 一句话摘要

智谱开源 GLM-Z1 系列模型，推理速度媲美 DeepSeek-R1，并创新推出具备自主 Agent 能力的沉思模型，同时启用全新域名 Z.ai。

📝 详细摘要

智谱开源了新一代 GLM 系列模型，包括 GLM-4 和 GLM-Z1 两个系列，涵盖 32B 和 9B 两种尺寸。其中，GLM-Z1 推理模型在小参数量下实现了与 DeepSeek-R1 相当的推理性能，尤其在数理推理能力上表现出色，成本更低。GLM-Z1-Rumination 沉思模型具备“实时搜索 - 深度分析 - 动态验证”的循环思考模式，拥有联网搜索、工具调用和自我验证能力，能更好地处理开放性问题，代表了新一代 AI 的发展方向。智谱还推出了面向企业用户的 MaaS 平台，提供极速、高性价比和免费三个版本的推理模型 API 服务。同时，个人用户可以通过 z.ai 平台免费体验最新的 GLM 模型，包括沉思模型的深度调研能力。智谱希望通过开源和提供多样化的服务，推动 AI 的普及应用。

💡 主要观点

  1. GLM-Z1 推理模型以小参数量实现媲美更大模型的推理性能 通过优化 GQA 参数、量化和投机采样等技术，GLM-Z1 在消费级显卡上实现了高速推理，降低了使用成本，并在 AIME 24/25、LiveCodeBench、GPQA 等基准测试中表现出色。
  2. GLM-Z1-Rumination 沉思模型具备联网搜索和自我验证能力，代表新一代 AI 发展方向 该模型能够主动联网搜索资料、调用工具并进行深度分析，在处理开放性问题时更加灵活，展现出更强的自主 Agent 能力。
  3. 智谱 MaaS 平台为企业提供多种版本的 GLM 模型 API 服务，降低使用门槛 包括极速、高性价比和免费三个版本，满足不同业务场景的需求，并降低了大模型的使用门槛，加速大模型规模化应用。
  4. 智谱宣布 2025 年为开源年，持续加码生态建设 智谱积极拥抱开源，通过开源顶尖模型和提供多样化的服务，推动 AI 的普惠应用。
