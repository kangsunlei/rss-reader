JavaOne 2025 Day 1：Java 的世界

3/21/2025, 12:00:00 AM

📌 一句话摘要

JavaOne 2025 回顾历史、展望未来，发布 JDK 24 和 Learn.java，持续赋能开发者。

📝 详细摘要

JavaOne 2025 大会在 Oracle Conference Center 举行，重点回顾了 Java 的发展历程以及 Oracle 如何通过平衡守旧与创新来管理 Java。会议期间，Oracle 提出了 11 个开发者痛点及解决方案，例如 “Java is too difficult to teach!（Java 难以学习）” 和 “GC pauses are too long!（GC 暂停时间过长）”。此外，会议还介绍了如何使用 Java 21 和 Oracle 数据库构建下一代应用，以及如何使用 SQL、JSON 和 Java 进行数据处理。演讲者们分享了使用融合数据库简化微服务和分布式系统的方法，并详细介绍了 Oracle 的 OSON 格式在性能和易用性方面的优势，以及如何使用 Spring Data 技术。

💡 主要观点

  1. Java 持续创新，关注开发者生产力和程序性能。 Oracle 团队致力于在不断变化的编程范式、应用、部署风格和硬件环境中实现这些目标，并强调平衡守旧与创新。
  2. 融合数据库提供了一个统一的平台，用于存储、管理和分析各种数据类型和工作负载。 开发者应使用融合数据库来消除对多个专用系统的需求，从而降低运营成本并提高可扩展性。
  3. Oracle 的 OSON 格式优化了 JSON 的原生二进制存储，可与 Spring Data 技术兼容。 OSON 提供了流式、树/DOM 和数据绑定等多种模型，方便开发者在 Java 中使用 SQL 和 JSON 进行数据处理。
  4. Java 在云原生领域展现出强大的生命力。 通过与 Oracle 数据库等技术的结合，Java 能够更好地支持云原生应用的开发和部署，简化微服务和分布式系统的构建。
