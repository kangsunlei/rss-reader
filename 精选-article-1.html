百度文心大模型 4.5 系列正式开源 同步开放 API 服务

6/30/2025, 3:25:51 AM

📌 一句话摘要

百度文心大模型 4.5 系列基于 Apache 2.0 协议正式开源，包含 10 款不同参数规模的模型，覆盖文本和多模态任务，并同步开放 API 服务。

📝 详细摘要

百度宣布文心大模型 4.5 系列正式开源，一次性推出 10 款不同参数规模的模型，从 47B 参数的混合专家（MoE）模型到 0.3B 稠密型模型，覆盖文本和多模态任务。这些模型采用 Apache 2.0 协议开源，权重与代码完全开放，并提供 API 服务。文心大模型 4.5 系列在多个主流基准测试中表现优异，尤其在指令遵循、世界知识记忆、视觉理解和多模态推理任务上效果突出，性能超越 DeepSeek-V3、Qwen3 等竞品。百度还提供了开箱即用的工具链，包括 ERNIEKit 和 FastDeploy，以降低模型的后训练和部署门槛。特别值得注意的是，文心大模型 4.5 系列采用了创新的多模态异构模型结构，模型 FLOPs 利用率达到 47%，并实现了框架层与模型层的'双层开源'。

💡 主要观点

  1. 百度文心大模型 4.5 系列正式开源，包含 10 款不同参数规模的模型。 此次开源覆盖从 47B 参数的 MoE 模型到 0.3B 稠密型模型，满足多种任务需求，权重与代码完全开放，采用 Apache 2.0 协议。
  2. 文心大模型 4.5 系列在多个主流基准测试中表现优异。 在文本和多模态任务上，尤其在指令遵循、世界知识记忆、视觉理解和多模态推理任务上效果突出，性能超越 DeepSeek-V3、Qwen3 等竞品。
  3. 百度提供开箱即用的工具链，降低模型后训练和部署门槛。 包括 ERNIEKit 和 FastDeploy，支持开发者快速上手和使用文心大模型 4.5 系列，模型 FLOPs 利用率达到 47%。
  4. 文心大模型 4.5 系列采用创新的多模态异构模型结构。 该结构适用于从大语言模型向多模态模型的持续预训练范式，在保持文本任务性能的基础上显著增强了多模态理解能力。
  5. 百度实现了框架层与模型层的'双层开源'。 基于飞桨深度学习框架，文心大模型 4.5 系列在训练、推理和部署上表现出色，构建了完整的 AI 技术栈。
