DeepSeek 发布全家桶应用 API

11/13/2026, 2:19:00 PM

📌 一句话摘要

DeepSeek 开放全家桶应用 API，支持联网搜索、文件、语音等功能的独立调用，让开发者能轻松复刻完整的 DeepSeek App 体验。

📝 详细摘要

DeepSeek 今日正式开放全家桶应用 API，将 DeepSeek App 中的联网搜索、文件输入、阅读链接、语音交互及安全等能力整合至原有 API 中。开发者只需开启对应参数，即可获得深度思考搜索、文件输入等对话功能；语音及底层能力（OCR、ASR、TTS 等）也开放独立接口，支持单独或组合调用。此举旨在减少开发者重复构建基础功能的工作量，让他们能够专注于打造更具想象力的产品。

💡 主要观点

  1. 全家桶应用 API 开放，支持独立调用 开发者可通过开启对应参数获取联网搜索、文件输入、语音等功能，或单独调用底层接口（Search、Fetch、OCR、ASR、TTS），大幅降低复刻 DeepSeek App 所需工作量。
  2. 模型安全校验功能上线 开启安全校验参数后，服务端将进行输入输出风控，命中风险时返回拒答标识，开发者在对外提供服务时可确保内容安全合规。
  3. API 定价包含工具调用费用 除 Token 费用外，使用扩展能力时还需支付相应工具调用费用，费用结构在文中表格中明确，帮助开发者提前规划成本。
