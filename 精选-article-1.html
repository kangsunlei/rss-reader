Agent in the Shell，豆包手机是敲键盘的“机械手指”吗？

1/1/2026, 3:57:00 PM

📌 一句话摘要

文章深刻分析了 Agent 崛起后与现有互联网规则的冲突，指出 Agent 为获通行权被迫“伪装”成人类，并借鉴爬虫经验，提出 Agent 发展需重塑“注意力税”与“风险承担”契约，建立可识别、可授权、可追责的制度，以实现“可代理的社会”。

📝 详细摘要

文章深入探讨了在 Agent 成为新行动者后，数字世界如何应对这一变化的问题。作者提出，当前的互联网基础设施默认人类为行动者，导致 Agent 不得不通过模拟人类操作 GUI 的方式来“伪装”自己。这种“Agent in the Shell”的现象，不仅是技术上的不成熟，更是因为 Agent 的出现撕毁了互联网赖以运转的“注意力税”和“风险承担”两大“隐形契约”。文章借鉴了爬虫与网站从对抗走向协同的历史经验，提出 Agent 获得合法通行权需要“重签契约”，即建立可识别、可授权、可追责的制度，并引入“能力税”的结算方式。最终，GUI 将从主通道退位为橱窗和仲裁庭，新的权力结构和入口争夺将随之而来，而 Agent 的发展方向将取决于制度设计能否实现真正的“可代理社会”。

💡 主要观点

  1. Agent 发展受制于现有互联网的“人本设计”，被迫采取“机械手指”式伪装。 当前数字基础设施默认行动者是人类，Agent 在执行任务时必须通过模拟点击、填写等 GUI 操作，这是一种效率低下且不自然的“Agent in the Shell”状态。
  2. Agent 撕毁了互联网建立在“注意力”和“风险承担”上的“隐形契约”。 Agent 绕过了平台通过注意力赚取收益的模式，压缩流程、直达目标；同时，Agent 的高并发、低成本操作使平台难以用传统方式（如摩擦、追责）控制风险，导致平台抵制。
  3. Agent 需通过“重签契约”获得合法通行权，建立可识别、可授权、可追责的制度。 借鉴爬虫历史，Agent 需获得“身份证”（可识别）、“授权委托书”（可表达边界）、“审计账本”（可追责），并引入“能力税”的结算方式，才能从“游击队”转变为“合法代理”。
  4. Agent 时代的权力结构和入口将重塑，GUI 角色将被边缘化。 合法代理将成为默认，GUI 从“必经之路”变为“橱窗和仲裁庭”，拥有“默认代理”者将掌握新流量入口，Agent Broker（代理经纪人）可能成为新中介。
  5. 真正的进步在于实现“可代理的社会”，而非 Agent 本身。 Agent 的终局是带来解放还是集中化，取决于授权、审计、路由的透明度和开放性，以及反垄断与监管的跟进，需要制度设计来确保 Agent 以本来的身份被承认。

💬 文章金句

  • 当 Agent 成为新行动者，而互联网仍默认行动者必须是"人"，系统会如何排异？又会如何被迫重写规则？
  • Agent 明明是软件，却被迫用人的方式生活。
  • 一个强大的意图与规划能力（像 ghost），被困在一个为人类手眼设计的交互外壳（shell）里。
  • 协同不是因为平台突然拥抱技术，而是因为"机器能力"被装进了三种制度容器：可表达的边界、可结算的利益、可追责的身份。
  • 真正的进步，不是让机械手指敲得更像人；而是让 Agent 不必伪装成人，也能被世界承认为行动者------用它本来的身份，走正门，通过新契约。
