Anthropic 发布 Claude 4，大幅提升 AI 编程和推理能力，并通过新工具融入开发者工作流程。

📝 详细摘要

文章报道了 Anthropic 发布 Claude Opus 4 和 Claude Sonnet 4 两大模型。重点介绍了 Opus 4 作为顶尖编程模型，在 SWE-bench 和 Terminal-bench 测试中取得领先成绩，并具备连续长时间复杂任务处理能力。强调了两款模型在高级推理、结合工具使用、记忆能力和降低走捷径行为方面的改进。文章还宣布了 Claude Code 的发布，通过其 SDK 和 VS Code/JetBrains 集成，将 AI 编程能力融入开发者工作流，并新增文件 API、提示词缓存等 API 功能。文中也提及 AI 行业向推理模型转变趋势及用户实测反馈。新模型已通过 API、Amazon Bedrock、Vertex AI 开放，并公布了定价。

💡 主要观点

  1. Claude Opus 4 和 Sonnet 4 大幅提升编程与推理能力 两款模型在 SWE-bench 等编程基准测试中表现卓越，尤其是 Opus 4 擅长复杂长时间任务，刷新了 AI 在代码生成和复杂问题解决上的标杆。
  2. 模型创新性地将工具使用融入推理流程 Claude 4 能在推理过程中暂停并使用工具（如网络搜索），这种同步研究与推理的方式更接近人类思维，提升了解决复杂问题的效率和效果。
  3. Anthropic 推出 Claude Code 及 IDE 集成工具 通过发布 Claude Code SDK 和 VS Code/JetBrains 扩展，Anthropic 将强大的 AI 编程能力直接融入开发者日常工作流，简化 AI 辅助开发的落地，并增强了 API 能力如文件访问和提示词缓存。
