自动化评测的九九归一——评测 agent

2/5/2026, 12:30:00 AM

📌 一句话摘要

本文介绍了阿里云基于评测 Agent 架构，通过识图-推理解耦、多阶段 GRPO 强化学习等技术，实现 AI 应用评测全链路自动化的实战经验。

📝 详细摘要

面对 AI 助理场景爆发式增长带来的评测压力，阿里云开发者团队提出并落地了统一评测 Agent 架构。该方案通过让 Agent 自主学习业务标注文档，实现了评测集生成、自动打分、人审预验收及 Badcase 分析的全流程闭环。技术核心在于：采用“小模型识图+大模型推理”的解耦策略抑制多模态幻觉；基于 Qwen3-VL 基座，通过 Post-pretraining、SFT 及 GRPO 课程学习强化长程逻辑推理能力；并设计了包含格式、逻辑、RM 偏好在内的多维奖励函数。目前该系统机审覆盖率突破 97%，大幅降低了人工标注成本。

💡 主要观点

  1. 采用识图与推理解耦架构，有效抑制多模态大模型的视觉幻觉问题。 针对多模态模型“推理越多，识图越差”的缺陷，使用小尺寸模型负责 OCR 级的忠实描述，再由大模型基于描述进行逻辑推理打分。
  2. 通过多阶段课程学习（SFT+GRPO），显著提升 Agent 的长程逻辑推理能力。 模型经历领域知识注入、指令对齐及强化学习三个阶段，借鉴 DeepSeek-R1 模式，通过逐步思考（CoT）提升复杂业务场景下的评分准确性。
  3. 设计多维奖励函数体系，在缺乏标准答案的情况下实现高质量模型训练。 整合格式奖励、逻辑一致性奖励、RM 偏好奖励及 Ground-truth 奖励，通过平滑的 Reward 引导模型在探索中收敛至正确方向。
  4. 构建三位一体的评估体系，确保模型在训练迭代过程中的综合能力与稳定性。 通过综合能力集、评分准确性集和一致性回归集，从通用逻辑、业务准确度及线上行为一致性三个维度严控模型上线质量。

💬 文章金句

  • 多模态大模型在复杂推理过程中普遍存在视觉幻觉问题，呈现出“推理越多，识图越差”的现象（More Thinking， Less Seeing）。
  • 做一个小尺寸模型单独识图，尽量避免思考评价，只做 OCR 级别的忠实描述，看完把文字识图梗概+图一起发给负责思考打分的主模型推理。
  • 评测 agent 就像一个真正的评测同学一样，学习标注文档和标准之后，就拥有做自动标注、验收、badcase 分析的能力。
  • 这种识图-推理解耦的架构，可以将原基座相关能力原地提升 10 个点，非常简易有效。
  • 每月机审样本达百万级，机审覆盖率突破 97%，年度节省千万级标注成本。
