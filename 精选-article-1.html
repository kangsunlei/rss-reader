Code Mode：仅需 1，000 个 token 即可让智能体调用完整 API

2/20/2026, 2:00:00 PM

📌 一句话摘要

Cloudflare 为 MCP 推出了 “Code Mode”，通过沙箱化的 JavaScript 执行，让 AI 智能体仅需 1，000 个 token 即可访问其包含 2，500 多个端点的完整 API。

📝 详细摘要

本文探讨了 AI 智能体开发中的一个关键瓶颈：“上下文窗口张力”，即添加更多工具会消耗处理任务所需的 token。Cloudflare 的解决方案 “Code Mode” 改变了范式，不再定义数千个独立工具，而是仅提供两个：search() 和 execute()。通过允许大语言模型（LLM）针对类型化的 OpenAPI 规范编写 JavaScript，并在安全的沙箱化 Cloudflare Worker 环境中执行，该系统将整个 Cloudflare API 的上下文占用减少了 99.9%。这种方法使智能体能够以固定的 token 成本执行复杂的多步操作（如配置 DDoS 防护），无论 API 多么复杂。文章还将这种服务器端执行模型与客户端替代方案及动态工具搜索进行了对比，强调了其在安全性、便携性和效率方面的优势。

💡 主要观点

  1. Code Mode 通过将单个工具替换为基于代码的接口，解决了上下文窗口瓶颈。 传统的 MCP 实现将每个 API 端点映射为一个工具，这可能会消耗数百万个 token。Code Mode 仅使用两个工具（search 和 execute），在固定的 1，000 个 token 占用内提供对整个 API 的访问。
  2. 该系统利用安全的沙箱化 V8 环境来执行智能体生成的代码。 为了防止提示词注入或数据泄露等安全风险，代码在 Dynamic Worker Loader 中执行。这个轻量级沙箱没有文件系统和环境变量，确保智能体的行为保持隔离且安全。
  3. 通过 search 工具进行的渐进式发现，允许智能体动态地导航海量 API。 智能体不再将完整的 OpenAPI 规范加载到上下文中，而是编写 JavaScript 来查询规范的类型化表示。这允许模型将数千个端点过滤为任务所需的特定端点。
  4. 与客户端执行相比，服务器端 Code Mode 提供了卓越的便携性和安全性。 通过在服务器上处理执行，智能体不需要本地沙箱或 shell 访问权限。这减少了攻击面，并确保该方法可以在不同环境中运行，而无需复杂的客户端修改。

💬 文章金句

  • 对于像 Cloudflare API 这样的大型 API，Code Mode 将使用的输入 token 数量减少了 99.9%。
  • 无论存在多少个 API 端点，占用空间都保持固定。
  • 完整的 OpenAPI 规范永远不会进入模型上下文。智能体仅通过代码与其交互。
  • 服务器不再导出数千个工具，而是仅导出两个：search() 和 execute()。两者都由 Code Mode 提供支持。
  • 代码充当了一个紧凑的计划。模型可以探索工具操作，组合多个调用，并仅返回其所需的数据。
