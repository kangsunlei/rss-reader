Cursor 的第三个时代：云端智能体

3/6/2026, 2:42:37 AM

📌 一句话摘要

本文探讨了 Cursor 向“云端智能体”时代的转型，在这一时代，AI 智能体利用完整的虚拟机和“计算机使用（Computer Use）”能力来自主构建、测试和演示软件。

📝 详细摘要

本文源自 Latent Space 播客的访谈录，讨论了 AI 辅助编程的演进——从简单的 Tab 键自动补全到复杂的云端智能体。Cursor 的“第三个时代”专注于为智能体提供独立的云端虚拟机，使其能够执行代码、运行测试，并通过“计算机使用”（输入像素，输出坐标）与 UI 交互。核心创新包括智能体生成工作视频演示以简化 PR 审查、使用模型上下文协议（MCP）进行调试，以及向 Slack 等平台协作开发的转变。演讲者认为，传统的 IDE 正在被更高层级的抽象所取代，在这种模式下，“手动编码”已成为智能体编排的次要活动。

💡 主要观点

  1. 行业正从“Tab 键自动补全”转向完全的智能体工作流。 数据表明，开发者正日益依赖智能体来执行复杂任务，而不仅仅是接受逐行建议，这标志着传统 IDE 时代的终结。
  2. 云端智能体需要完整的虚拟机访问权限，以超越对代码的“视读”阶段。 通过为智能体提供具备完整计算机访问权限的“盒中大脑”，它们可以自行上手、运行开发服务器，并在真实环境中验证自己的更改。
  3. 视频演示正成为 PR 审查过程的关键组成部分。 为了克服审查海量 AI 生成代码差异（diffs）的瓶颈，智能体现在提供简短的视频演示，让开发人员能够快速验证 UI 和逻辑更改。
  4. 开发工作正从本地环境迁移到 Slack 等协作平台。 Cursor 的集成允许团队在 Slack 线程中触发智能体并协作开发功能，将沟通工具转变为共享的开发界面。
  5. “测试优先”的方法对于自主智能体的可靠性至关重要。 智能体现被设计为在提交工作前复现 Bug 并运行端到端测试，确保人类审查者收到的是经过验证的解决方案而非猜测。

💬 文章金句

  • 硅谷压倒性的共识是“IDE 已死”。
  • 观看视频并不能取代代码审查，但与浏览巨大的代码差异相比，它是一个容易得多的切入点。
  • 如果你站在模型的角度，看着 Token 流过，而你唯一能做的就是视读代码……你的表现会非常糟糕。
  • 我们现在把亲手敲出每个字母的行为称为“手动编码”……这太老派了。
  • 真正的突破不在于一个人利用模型完成更多工作……而在于我们将管道拓宽，通过智能体集群实现更大规模的并行。
