拾象 AGI 观察：LLM 路线分化，AI 产品的非技术壁垒，Agent“保鲜窗口期”

8/22/2025, 12:00:00 AM

📌 一句话摘要

文章深度分析了当前大模型领域的分化趋势、AI 产品的非技术壁垒、Agent 的“保鲜窗口期”以及 L4 级别体验的出现。

📝 详细摘要

本文作为拾象 AGI 观察季报，通过对硅谷大模型公司（如 OpenAI、Google Gemini、Anthropic、xAI 等）的访谈与分析，揭示了 LLM 路线从通用型向垂直领域分化的趋势，呈现出“横向全家桶”与“纵向垂直整合”两大方向。文章强调，在智能上限探索的同时，产品和非技术性壁垒的重要性日益凸显，尤其以 ChatGPT 的品牌和用户心智为例。同时，AI 产品面临“保鲜窗口期”缩短的挑战，巨头加速布局 Agent 产品，挤压创业公司空间。文中还提出了 L4 级别 Agent 体验的概念，认为信息搜索（如 ChatGPT Deep Research）和软件开发（如 Claude Code）已率先实现，并探讨了未来 AI 产品经理所需的核心能力。

💡 主要观点

  1. 大模型路线正在分化，通用与垂直整合并存 OpenAI 和 Google Gemini 追求通用能力，而 Anthropic 聚焦 Coding 和 Agentic，Thinking Machines Lab 探索多模态，显示出 LLM 领域从“智能为先”向“智能与产品并重”的战略转变。
  2. AI 产品的非技术性壁垒日益关键 ChatGPT 的成功不仅依赖模型技术，更在于其品牌心智、用户留存和流量规模效应，这些非技术壁垒使其在竞争中具有强大优势，远超纯技术壁垒。
  3. AI 产品“保鲜窗口期”显著缩短，创业公司面临挑战 基础模型公司加速向 Agent 应用端拓展，快速复制和超越垂直产品，使得创业公司最初凭借模型能力溢出获得的“挖矿”红利窗口期大幅缩短。
  4. L4 级别 Agent 体验已在特定领域实现 ChatGPT 的 Deep Research（信息搜索）和 Anthropic 的 Claude Code（软件开发）已率先提供端到端的“Magic moment”，预示着 Agent 在语言和代码领域的巨大潜力。

💬 文章金句

  • 最突出的感受是模型在分化。未来真正的通用模型可能就是 Google Gemini 和 OpenAI。
  • 非共识就是 Coding 和 Agentic 会比外界想想的都要大。
  • ChatGPT 身上有很多非技术性壁垒，而 Coding 或模型公司只是技术壁垒。
  • 最好的模型，带来最大的流量产品。最好的模型，拿走了最大的价值。
  • 做 AI 产品很像挖矿，保鲜窗口很关键。
  • L4 级别的体验就是端到端的体会到 Magic moment。
