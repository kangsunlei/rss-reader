Promptions：改进生成式 AI 交互的动态提示 UI

12/10/2025, 5:00:00 PM

📌 一句话摘要

微软研究院发布了 Promptions，这是一个动态 UI 框架，通过提供实时、上下文感知的控件优化 AI 输出，从而提高用户精确度并减少提示工程工作量。

📝 详细摘要

微软研究院推出了 Promptions，这是一个开源 UI 框架，旨在通过在生成式 AI 交互中提供精确、实时的反馈和控制，有效缓解反复试错提示所带来的挫败感。Promptions（即“提示 + 选项”）提供动态 UI 控制，允许用户实时优化 AI 响应，根据特定需求调整输出。基于对知识工作者如何使用 AI 进行理解任务的研究，Promptions 通过自动生成上下文细化选项（例如，细节级别、焦点区域、学习目标）来解决复杂提示措辞的挑战。对比静态与动态控制的研究表明，动态细化显著减少了提示工程的工作量，增强了用户控制和探索，并鼓励用户更审慎地思考学习目标。该框架作为一个轻量级中间件运行，包含一个选项模块（用于生成 UI 控件）和一个聊天模块（根据控制变化更新 AI 响应）。Promptions 已在 Microsoft Foundry Labs 和 GitHub 上发布，采用 MIT 许可证，旨在赋能开发者在客户支持、教育和医疗等各种场景中创建更具响应性和精确性的 AI 体验。

💡 主要观点

  1. Promptions 提供动态、实时、上下文感知的 UI 控件来优化 AI 输出，提高精确度并显著减少提示工程的工作量。 该框架允许用户通过调整实时、上下文感知的选项，而非冗长的手动提示修订，更有效地与 AI 互动，使交互过程更像一场不断演进的对话，从而直接缓解了用户在反复试错提示中遇到的挫败感。
  2. 动态提示优化提高了用户控制力，鼓励探索，并有助于澄清 AI 理解任务中的学习目标。 通过呈现上下文选项，Promptions 引导用户尝试可能未曾设想的优化，从而促进更深层次的参与，并使其理解目标与 AI 输出更好地保持一致。这也有助于用户更审慎地思考自身需求。
  3. Promptions 作为一个轻量级中间件，包含一个用于生成 UI 控件的选项模块和一个用于实时响应更新的聊天模块。 这种技术设计简化了与现有对话式 AI 界面的集成，允许开发者轻松添加动态优化功能，而无需复杂的数据存储，充当用户和语言模型之间的关键中介。

💬 文章金句

  • Promptions（提示 + 选项），一个帮助开发者构建具有更精确用户控制的 AI 界面的 UI 框架。
  • Promptions 作为一个轻量级中间件层，位于用户和底层语言模型之间。
  • 参与者一致表示，动态控制让他们更容易表达任务的细微之处，而无需反复重新措辞提示。
  • 上下文选项促使参与者尝试他们自己可能没有考虑过的优化。
  • 通过将 Promptions 开源，我们希望帮助开发者创建更智能、响应更迅速的 AI 体验。
