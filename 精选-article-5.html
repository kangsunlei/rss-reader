动线 Agent：AI 驱动的全链路用户转化引导

11/18/2026, 8:37:00 AM

📌 一句话摘要

本文介绍了淘特 App 推出的动线 Agent——一套由 LLM 驱动的全链路用户转化引导系统，通过 TensorLiftAgent、PeiAgent 和 DeepFlowAgent 三个智能体在进端、在端、离端三个时机实现精细化经营，显著提升转化 ROI 并降低 token 成本。

📝 详细摘要

文章聚焦淘特 App 的动线 Agent 系统构建，旨在解决电商转化链路中 90%用户未完成转化的痛点。系统围绕用户「进端→在端→离端」三个核心时机部署三个差异化智能体：TensorLiftAgent 通过多维用户特征张量分解实现精细化人群策略，后台天级寻优、入端毫秒命中；PeiAgent 采用端云协同实时计算购物热情指数（PEI），在热情衰减时触发干预；DeepFlowAgent 在用户离端未购时执行长链 CoT 深度归因推理。实践表明，三个模式均实现显著业务增益，峰值增量 GMV 占比超大盘 5%，token 成本降低 60%以上。

💡 主要观点

  1. 动线 Agent 通过三个智能体覆盖用户全链路转化路径 TensorLiftAgent 负责进端精细化策略生成，PeiAgent 负责在端实时热情干预，DeepFlowAgent 负责离端深度归因推理，形成三种互补的决策模式，解决用户旅程中不同时机的转化引导问题。
  2. TensorLiftAgent 实现后台驱动的毫秒级策略命中 采用多层 Loop 寻优方案，将人群切分为网格，通过 AB 实验持续优化策略，用户进端时仅做实时匹配预先生成的策略，保证响应速度。
  3. PeiAgent 通过端云协同实现购物热情实时感知 在 App 端构建 PEI 实时计算体系，端上算分免除网络往返，能在 200ms 内感知热情衰减并触发服务端意图推理和干预策略。
  4. DeepFlowAgent 采用三轮 Chain 架构完成深度归因 链式推理拆分为召回判断、选品定价、文案生成三个环节，分别降低不同错误代价，实现基于用户行为序列的深度意图推理和精准化策略生成。
  5. 系统通过技术手段显著降低 token 成本 在数百亿 token/日的规模下，通过架构设计和优化措施将 token 成本降低 60%以上，实现高效的 LLM 驱动转化引导。

💬 文章金句

  • 动线 Agent 是一套面向电商用户全动线、由 LLM 驱动并受确定性规则约束的智能经营系统
  • TensorLiftAgent 于进端时机，通过多维用户特征张量分解，生成网格人群和差异化的权益策略，后台天级寻优、入端毫秒命中
  • PeiAgent 于在端时机，端云协同实时计算用户的个性化购物热情指数（PEI），当判断用户的指数衰减达到某个阈值，立即触发基于行为序列与意图的 AI 推理的权益干预
  • DeepFlowAgent 于离端未购时机，异步执行长链 CoT 深度归因推理，生成个性化权益与营销话术并多渠道召回
  • 动线 Agent 的价值，在于尝试建立一种新的用户经营方式：平台能够沿着用户完整旅程持续感知状态，在不同时间尺度上做出合适决策
