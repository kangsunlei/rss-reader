OpenAI 一线开发现实观察：能同时盯住 10～20 个 Agent、跑小时级任务的人，正在把其他工程师远远甩开

2/18/2026, 5:30:00 AM

📌 一句话摘要

OpenAI API 负责人揭示 AI 正在重塑工程分层，工程师正转型为管理多 Agent 线程的调度员，且模型能力的进化将逐步取代现有的技术脚手架。

📝 详细摘要

本文是 OpenAI API 负责人 Sherwin Wu 的深度访谈综述，核心探讨了 AI 对软件工程、组织管理及商业模式的深远影响。在 OpenAI 内部，AI 已实现 100% 的代码审查覆盖，导致顶尖工程师与普通人的产出差距拉大 70%。文章指出，工程师的角色正从“代码编写者”转向“Agent 调度员”，通过并行管理多个长时任务线程实现高杠杆产出。同时，访谈提出了“模型将吞噬脚手架”的深刻洞察，认为向量数据库、Agent 框架等过渡工具将被更强的模型能力取代。此外，文章还分析了企业 AI 部署 ROI 为负的原因，并预测了长时任务稳定性和原生音频多模态将是下一阶段的技术爆发点。

💡 主要观点

  1. 工程师角色从“手写代码”转向“并行调度 Agent 舰队”。 资深工程师正转型为类似 Tech Lead 的角色，同时盯着 10-20 个并行线程，主要工作变为引导、验收和兜底，而非亲手编写每一行代码。
  2. 模型能力的进化将逐步“吞噬”现有的技术脚手架。 向量数据库、复杂的 Agent 框架等工具可能只是过渡期的“拐杖”，随着模型上下文管理和逻辑能力的增强，这些中间层将被模型原生能力取代。
  3. AI 时代的管理杠杆应向顶尖表现者（High Performers）倾斜。 管理者应将 50% 以上的时间花在赋能前 10% 的顶尖人才上，利用 AI 消除组织流程阻碍，让高主观能动性的人才实现“超级加速”。
  4. “小时级任务”的稳定性将成为下一代模型的能力分水岭。 未来 12-18 个月，模型将能稳定、连贯地完成 6 小时量级的长时任务，这将彻底改变产品的形态和模型能覆盖的工作宇宙。
  5. 业务流程自动化（BPA）是比软件工程更被低估的巨大机会。 现实世界中大量可重复、强约束的标准作业流程（SOP）是 AI 深入企业运作的核心，其市场规模和影响力远超硅谷精英的讨论热度。

💬 文章金句

  • 这是模型此生最差的一刻。
  • 模型会把你的脚手架当早餐吃掉。
  • 工程师正在变成技术负责人，基本就像是管理者一样，在管理一整支又一整支的 Agent 舰队。
  • 为模型将要去的地方而构建，而不是只为模型今天能做到什么而构建。
  • 永远别可怜自己（Never feel sorry for yourself）。
