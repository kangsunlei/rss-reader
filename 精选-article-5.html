维护 3.3 万字符的长 Prompt？让优化 Agent 迭代执行 Agent

11/12/2026, 1:09:00 AM

📌 一句话摘要

本文介绍了如何借助 Google Research 开源的 harness² 框架，构建一个自动迭代的优化 Agent 来提升 3.3 万字符长 Prompt 的性能，在 611 条评测数据上将问题识别 F1 从 82.78% 提升至 89.89%，显著降低了人工调 Prompt 的成本。

📝 详细摘要

在输入法联想场景中，作者面对一份超过三万字符的历史累积 Prompt，人工调节繁琐且难以持续。他们引入 harness² 框架，构建了两个相互独立的优化 Agent：负责「怎么工作」（INV）和「需要知道什么」（DOM），通过 Propose、Probe、Compose 三步实现 Prompt 的自动化迭代。该方案在 611 条评测数据上完成 1 轮迭代（约 95 分钟），问题识别 F1 从 82.78% 提升至 89.89%，准确率从 78.84% 提升至 87.43%，召回率从 87.13% 提升至 92.49%。文章详细阐述了框架如何映射到具体任务、如何处理长 Prompt 超限、如何整合真值反馈、以及如何防止过拟合，并总结了 5 条实践经验，为其他基于 Prompt 的 LLM 任务优化提供了可借鉴的路径。

💡 主要观点

  1. harness² 通过分层递归实现 Prompt 的自动化迭代优化 框架将改进拆分为任务级递归（Propose、Probe、Compose）和 harness 级递归（经验沉淀），通过 INV 与 DOM 两条独立路径分别聚焦工作流程和领域知识，最终合成得到的版本才能综合提升准确率和召回率。
  2. 将人工标注和可量化指标完整传递给优化 Agent 文章将评测指标（准确率、召回率、F1）、分歧样本及模型判断依据全部纳入执行证据，使优化 Agent 能精准定位根因，避免仅依赖模型直觉进行修改。
  3. 通过经验库实现改进经验的沉淀与复用 每轮结束后，系统复盘改动并将有证据支撑的经验写入经验库，后续任务可按需检索复用，形成持续完善的改进机制，避免每次从零开始。
  4. 严格控制 Prompt 长度、编辑范围及防止过拟合 将常驻内容上限放宽至 50000 字符，限定仅修改 Prompt 本体，增加校验防止对评测集样本直接记忆，确保优化的改进是对模型能力的真实提升。
  5. 单轮迭代即可显著提升问题识别性能 在 611 条数据上完成 1 轮迭代后，F1 提升 7.11 个百分点，验证了 harness² 相较于传统 Skill 闭环在组织化改进、评估信号利用和经验沉淀方面的显著优势。
