美团 LongCat-2.0 正式发布：在国产算力集群上完成全流程训练与推理的万亿参数模型

7/1/2026, 8:02:04 AM

📌 一句话摘要

美团发布业界首个在五万卡国产算力集群上完成全流程训练与推理的万亿参数 MoE 模型 LongCat-2.0，原生支持 1M 超长上下文，聚焦 Agentic Coding 任务，在多项基准测试中表现优异。

📝 详细摘要

文章正式宣布美团新一代万亿参数大模型 LongCat-2.0 的发布与开源。该模型总参数 1.6T，平均激活约 48B，动态范围 33B-56B，是业界首个在五万卡国产算力集群上完成从零预训练到推理全流程的模型。团队从稳定性、正确性、效率三方面攻克了国产算力挑战，将月均日故障率降低 70% 以上，训练 MFU 提升 1.5 倍。架构上采用 LongCat Sparse Attention（LSA）实现 1M 超长上下文的线性复杂度推理，通过零计算专家 + ScMoE 实现 token 级动态激活，并以 MOPD 架构融合 Agent、Reasoning、Interaction 三组专家。评测方面，LongCat-2.0 在 SWE-bench Pro（59.5）、SWE-bench Multilingual（77.3）等编程基准上领先或接近最先进闭源模型，在 Search、BrowseComp 等 Agent 场景也表现均衡。文章还展示了基于 LongCat-2.0 的真实应用案例，包括 AI SQL Agent、代码库迁移、3D 交互演示等，验证了其在真实工作场景中的实用价值。

💡 主要观点

  1. LongCat-2.0 是业界首个在五万卡国产算力集群上完成全流程训练的万亿参数模型。 总参数 1.6T，平均激活 48B，训练数据超 30T tokens，通过稳定性、正确性、效率三方面优化，实现稳态日吞吐超过 1T tokens/day。
  2. 架构创新实现高效长上下文与动态算力分配。 LongCat Sparse Attention 将长文本计算量从平方级降至线性级，支持 1M 上下文；零计算专家实现 token 级动态激活，简单 token 不消耗算力；MOPD 多专家融合使模型同时擅长编程、推理与交互。
  3. 在编程与 Agent 基准测试中表现突出。 SWE-bench Pro 得分 59.5，领先 Gemini 3.1 Pro、GPT-5.5 和 Claude Opus 4.6；SWE-bench Multilingual 77.3，与 Claude Opus 4.6 持平；在终端指令交互评测 Terminal-Bench 中取得 70.8。
  4. 真实场景验证了模型在 Agentic Coding 与复杂任务中的实用能力。 内测案例涵盖 AI SQL Agent、代码库迁移、完整应用开发、3D 交互演示等，展现了模型在真实工作场景中的闭环交付能力。

💬 文章金句

  • 业界首个在五万卡国产算力集群上完成全流程训练与推理的万亿参数模型
  • LongCat-2.0 验证了我们已具备在国产算力集群上进行大规模模型训练的能力。它不只是‘能训出’万亿参数模型，还让万亿参数模型能够在真实任务中稳定运行。
  • 传统模型在处理超过 100K 上下文后就开始‘遗忘’前面的内容。LongCat-2.0 采用 LongCat Sparse Attention（LSA）稀疏注意力机制，在处理长文本时不再‘逐字逐句地看’，而是智能筛选关键信息。
