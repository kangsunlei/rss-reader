AI 智能体沙盒化，速度提升 100 倍

3/24/2026, 1:00:00 PM

📌 一句话摘要

Cloudflare 推出了 Dynamic Worker Loader，这是一种基于隔离（isolate）的沙盒 API，执行 AI 生成代码的速度比传统容器快 100 倍，且效率更高。

📝 详细摘要

Cloudflare 宣布推出 Dynamic Worker Loader 公测版，这是一种专为 AI 智能体时代设计的轻量级沙盒解决方案。传统的基于容器的沙盒通常启动缓慢且资源密集，而 Dynamic Workers 利用 V8 隔离（isolates）实现了毫秒级的启动时间和极小的内存占用。该基础设施支持 Cloudflare 的“代码模式”（Code Mode）理念，即智能体通过编写和执行 TypeScript 代码来执行任务，而不是进行连续的工具调用。这种方法可以将 Token 使用量减少 80% 以上。本文详细介绍了使用 TypeScript RPC 替代冗长的 OpenAPI/HTTP 接口的技术优势，解释了 Cloudflare 隔离架构久经考验的安全模型，并介绍了一套用于在这些沙盒中进行打包和文件操作的辅助库。

💡 主要观点

  1. Dynamic Worker Loader 利用 V8 隔离实现近乎即时的沙盒化。 通过使用与 Cloudflare Workers 相同的隔离技术，它实现了比 Linux 容器快 100 倍的启动速度和显著更高的内存效率，从而允许为每个请求提供全新的沙盒。
  2. 代码模式（Code Mode）显著优化了 LLM 的 Token 效率。 将工具定义转换为 TypeScript API，使智能体能够编写逻辑密集型代码，与传统的基于 MCP 或 OpenAPI 的工具调用相比，Token 消耗减少了高达 81%。
  3. 与 HTTP 相比，TypeScript RPC 是 AI 智能体更优的接口。 与 OpenAPI 规范相比，TypeScript 接口更简洁，更易于 LLM 解析，通过 Cap'n Web RPC 网桥减少了错误并降低了延迟。
  4. Cloudflare 为智能体沙盒化提供了全面的 SDK 生态系统。 诸如 @cloudflare/codemode、@cloudflare/worker-bundler 和 @cloudflare/shell 等新库简化了智能体的代码执行、依赖解析和虚拟文件系统管理。

💬 文章金句

  • 一个隔离（isolate）只需几毫秒即可启动，并占用几兆字节的内存。这比典型的容器快约 100 倍，内存效率高出 10 到 100 倍。
  • 如果我们想要支持消费级规模的智能体——即每个终端用户都有一个（或多个！）智能体，且每个智能体都在编写代码——容器是不够的。我们需要更轻量级的东西。
  • JavaScript 本身在 Web 上就是为沙盒化而设计的。它是完成这项工作的正确语言。
  • 使用 TypeScript 接口……更容易缩小接口范围，从而精确地暴露你想要提供给智能体的功能，这既简单又安全。
