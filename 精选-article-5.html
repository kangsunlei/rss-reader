Agent Infra，巨头都在布局的隐秘赛道｜与百度王雁鹏聊模型、智能体与 AI 基建的新动向

7/28/2026, 2:07:38 AM

📌 一句话摘要

百度智能云 AI 计算首席科学家王雁鹏深度解读从模型时代到 Agent 时代的范式转移，剖析巨头在 Agent Infra 这一隐秘赛道的不同布局，并揭示了算力、开源与工程化如何重塑未来 AI 竞争格局。

📝 详细摘要

本期节目，百度智能云 AI 计算首席科学家王雁鹏从基础设施的宏观视角，深度剖析了 AI 正从模型时代迈向 Agent 时代的关键变化。他指出，AI 基础设施正从纯软件视角转向以 GPU 为核心的软硬一体，而 Agent 的兴起则要求 Infra 层支持长上下文、复杂任务编排及工具调用。他从算力、网络、存储三大支柱出发，详细拆解了 Agent 在生产环境落地的挑战，如任务的可控、可信任与可复现性。王雁鹏还深入比较了谷歌的垂直整合、英伟达的系统生态、Anthropic 的轻资产聚焦和 OpenAI 的平台型打法，揭示了巨头们围绕「模型即 OS」的入口争夺战。针对中国市场，他强调了多芯适配的现实与开源生态带来的后发优势，并透露百度智能云正通过提升算力效率、转型云业务，以及扶持未来的新星应用，试图在这轮浪潮中找到自己的生态位。

💡 主要观点

  1. 新一代 AI Infra 的本质是软硬一体，以 GPU 为核心牺牲通用性换取极致算力 与 CPU 时代的纯软件抽象不同，GPU 极大地释放了算力但牺牲了通用性，迫使 Infra 工作必须深入芯片体系结构，实现软硬件协同设计，以充分发挥算力效能。
  2. Agent 从 Demo 到生产环境的核心瓶颈是模型的边界决定了抽象层的稳定性 由于底层大模型能力仍在快速迭代，导致 Agent 开发的范式（如记忆系统是否应像文件系统般通用）尚不稳定，就像一个快速成长的孩子，难以立刻定制合身的衣服。
  3. 巨头们的垂直整合路径各异，争夺的是未来的「模型 OS」超级入口 谷歌走全栈自研的垂直整合路线，英伟达凭借系统级优势锁死训练生态并转向推理，Anthropic 聚焦模型与高价值入口采取轻资产合作模式，而 OpenAI 则试图构建类 App Store 的生态平台。
  4. 中国 AI Infra 的特殊路径依赖于多芯适配和超前的开源生态 受限于芯片环境，中国需要解决多种国产芯片的适配问题。同时，国内领先的开源生态让模型架构更透明，为底层芯片设计指明了方向，有望走出独特的技术路径。
  5. 评价 Agent 的价值应从 Token 消耗量转向 DAA（Daily Active Agents） Token 数是一个容易被刷量的指标。DAA 更能反映 Agent 在生产环境中完成真实高价值任务的活跃度，引导 Infra 层关注如何让 Agent 开发更快、运行更稳、聚焦更高价值的任务。

💬 文章金句

  • 前一代的 Infra 基本上全是软件视角，这一代 AI Infra 有一个巨大的区别：它是以 GPU 为核心构建的。
  • 模型的能力的边界在哪里，其实就决定了你最终的那个基建。
  • 完成一个真实的任务意味着我得有一个完整的环境，就今天人操作的所有的这些基础设施和软件，都要被 agent、被 AI 去用了。
  • 今天最先进的模型是最先进的硬件这个系统去催生出来的。
  • Token 数是一个会被玩坏的指标。
