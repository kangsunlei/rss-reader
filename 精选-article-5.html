深入浅出 Harness Engineerring 之核心模式与理念

4/29/2026, 12:46:00 AM

📌 一句话摘要

本文系统梳理了 Claude Code、Claude Managed Agents 和 Hermes 三种智能体架构的核心模式与设计理念，涵盖持久化指令、上下文压缩、三组件解耦、多智能体协作及五层记忆架构等关键技术。

📝 详细摘要

文章以 Harness Engineering 为主题，深入剖析了三种 AI 智能体架构的设计模式与核心理念。第一部分聚焦 Claude Code，介绍了持久化指令文件、作用域上下文组装、分层记忆、做梦整理、渐进式上下文压缩、工作流编排（探索-规划-行动循环、上下文隔离子智能体、分支-合并并行）以及工具与权限管理（渐进式工具扩展、命令风险分类、单用途工具设计）等模式，并逐一指出其代价。第二部分讲解 Claude Managed Agents，提出宠物与牲畜基础设施哲学，详细阐述智能体三件套（Claude 大脑、Harness 双手、Sandbox 工作台）的解耦设计、Session 不可变事件流、凭证永不进沙盒的安全架构、多智能体协作模式以及上下文工程和性能优化策略。第三部分介绍 Hermes 会进化的智能体，提出五段式循环（规划-执行-观察-学习-适应）和五层记忆架构（短期记忆、技能手册、知识库、用户建模、工作日志），其中用户建模部分引入了黑格尔辩证式思想。

💡 主要观点

  1. Claude Code 通过持久化指令、分层记忆和上下文压缩等模式管理智能体上下文。 持久化指令文件确保规则一致性但需维护；分层记忆将记忆分为常驻摘要、按需加载细节和可搜索历史，以节省 Token；渐进式上下文压缩在长对话中平衡信息保留与成本，但压缩必有信息损失。
  2. Claude Managed Agents 采用三组件解耦架构，实现灵活的多智能体协作。 Claude 负责推理，Harness 驱动运行循环，Sandbox 提供隔离执行环境。Session 作为不可变事件流支持状态恢复。凭证通过保险库+代理架构管理，永不进入沙盒。解耦后支持多脑一手、一脑多手、多脑多手三种协作模式。
  3. Hermes 智能体通过五段式循环和五层记忆架构实现自我进化。 五段式循环（规划-执行-观察-学习-适应）使智能体能从经验中持续改进。五层记忆包括短期记忆、技能手册（自动生成 SKILL.md）、知识库（向量检索）、用户建模（黑格尔辩证式动态更新用户画像）和工作日志（FTS5+LLM 摘要）。

💬 文章金句

  • Session（会话）是宠物：精心培育、持久保存、不可丢失。Harness（控制器）和 Sandbox（沙盒）是牲畜：可以随时创建、销毁、替换。
  • 凭证永不进沙盒：所有第三方凭证存储在独立的保险库中，Harness 和 Sandbox 都无法直接访问。
  • 不是一次判断就定终身，允许你改变、允许情况复杂，通过不断观察、思考、调整，越来越懂真实的你。
