OpenAI 发布 GPT-5.4：支持原生计算机使用与 100 万 token 上下文

3/5/2026, 6:19:02 PM

📌 一句话摘要

山姆·奥特曼宣布发布 GPT-5.4，其特点是增强了知识工作能力、具备原生计算机使用功能，并拥有 100 万 token 的上下文窗口。

📝 详细摘要

OpenAI 正式发布了 GPT-5.4，目前已通过 API 和 Codex 提供，并正在向 ChatGPT 逐步推送。这一重大更新显著提升了模型在知识密集型任务和网页搜索中的表现。关键技术突破包括原生计算机使用能力（允许模型直接与操作系统界面交互）、响应中途引导以及庞大的 100 万 token 上下文窗口，标志着大语言模型演进过程中的一个重要里程碑。
