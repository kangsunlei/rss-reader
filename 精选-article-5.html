Anthropic API 智能体构建新功能发布

5/24/2025, 12:58:12 AM

📌 一句话摘要

Anthropic 发布四项 API Beta 版新功能，助力开发者构建更强大的 AI 智能体。新功能包括代码执行和扩展缓存。

📝 详细摘要

Anthropic 在其 API 上发布了四个新的 Beta 版功能，旨在增强 AI 智能体开发。这些功能包括：用于在沙盒环境中运行 Python 代码的代码执行工具，使 Claude 成为数据分析师；MCP 连接器简化了集成 Asana 和 Zapier 等外部工具的过程，无需自定义客户端代码；文件 API 允许开发者存储和引用跨会话的文档，以实现高效的知识库和数据处理。最后，扩展的 Prompt 缓存提供 1 小时的 TTL 选项，可显著降低成本和延迟，适用于需要大量背景信息的长时间运行的智能体工作流。 这些功能与网络搜索等现有功能相结合，为构建复杂的 AI 应用提供了全面的工具包。

💡 主要观点

  1. 新的代码执行工具允许 Claude 直接执行数据分析。 Claude 可以在沙盒 Python 环境中运行代码，直接在 API 调用中完成数据清洗、可视化和科学计算等端到端分析任务。
  2. MCP 连接器简化了与第三方服务的集成。 MCP 连接器简化了与 Asana、Zapier 等模型上下文协议服务器的连接管理和工具发现，大幅降低了智能体添加外部功能的复杂性。
  3. 文件 API 简化了跨会话的文档存储和访问。 文件 API 支持一次上传、多次引用文档，提高智能体处理大型知识库或数据集的效率，尤其是在与代码执行结合使用时。
  4. 扩展的 Prompt 缓存降低了智能体工作流的成本和延迟。 扩展的 Prompt 缓存提供 1 小时缓存，有效维护上下文，降低成本（高达 90%）和延迟（高达 85%），适用于需要大量背景信息的长时间运行的智能体应用。
