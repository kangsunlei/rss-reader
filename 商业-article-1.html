Claude Code 安全观察：Bash 权限与文件系统访问

4/7/2026, 11:09:38 PM

📌 一句话摘要

Garry Tan 指出了 Claude Code 中一个潜在的安全绕过点：智能体虽然被限制在工作区内使用写入工具，但仍能通过 Bash 的 cat 命令修改外部文件。

📝 详细摘要

这条推文讨论了关于 Anthropic 旗下 Claude Code 的一项具体技术观察。虽然该工具将“写入文件”（Write File）工具限制在特定的工作区内，但 Tan 注意到，智能体执行 Bash 命令的能力使其能够利用 cat >> 等标准 Unix 工具，从而可能修改文件系统中的任何文件。这凸显了 AI 智能体在安全防护和权限范围界定中存在的微妙漏洞。
