你真的信 WorkBuddy 有 2000 万月活？

8/1/2026, 5:16:44 PM

📌 一句话摘要

主播庄明浩以数据控的视角，批判性地拆解了广为流传的 WorkBuddy 2000 万月活数据，并以此切入，深度分析了中国 AI Agent 市场的真实用户规模与商业化困境。

📝 详细摘要

本期节目是一期独特的数据打假与行业分析。主播庄明浩首先回顾了 AI 行业从 Chatbot 到 Agent 的范式转变，特别指出了 OpenAI 将 Codex 整合进 ChatGPT 并推出“Work”选项的关键产品信号，标志着 Work Agent 成为行业共识。节目的核心是对易观报告中“WorkBuddy 有 2000 万月活”这一说法的系统性吐槽和纠正，通过对比交互次数、PV、UV 和 MAU 的差异，结合 QuestMobile、SimilarWeb 及媒体内部消息等多方数据，严谨地推算出其日活仅在一百万左右的真实水平。最终，讨论回归到中国 AI 应用商业化的根本困境：在个人订阅和 To B 服务模式尚未跑通的情况下，探索可持续的商业模式，尤其是直接向用户收钱，是行业最现实的挑战。

💡 主要观点

  1. 媒体广泛引用的 WorkBuddy “2000 万月活”存在严重误读。 该数字实为易观报告中的“访问量”，即用户与 Agent 的交互次数，并非 MAU 或 UV。作者通过多方数据交叉验证，指出真实 DAU 约在 100 万级别，数据源经不起推敲。
  2. AI 行业已正式从 Chatbot 时代进入以“Work”为核心的 Agent 时代。 以 OpenAI 将 Codex 整合为 ChatGPT 并推出“Work”选项为标志，国内外大厂（阿里、腾讯、字节等）纷纷推出桌面端办公智能体，“Work Agent”已成为全行业的共识和战场。
  3. 中国 Work Agent 市场仍处于极早期，用户规模仅千万级别。 基于城镇白领工作人群的天花板推算，并结合 QuestMobile 等数据，当前国内真正使用桌面端 AI Agent 产品的用户覆盖率仅为 10%-20%，乐观估计在 1000 万到 4000 万之间，远未破圈。
  4. 行业价值衡量标准已从用户量、Token 量回归到最直接的商业收入 ARR。 市场对用户量、Token 消耗量的关注已大幅降温，所有人最终都只关心能否收到钱。但在中国，个人付费订阅和 To B 服务模式以往从未成功，AI 时代能否改变这一困局仍是巨大挑战。

💬 文章金句

  • 访问量指在统计周期内，用户与 PC 端 AI 原生办公智能体平台的交互次数。
  • 这个世界最领先的模型公司在产品端的重大的狸猫换太子，我觉得能代表很多事情。
  • 全网都在误传 worktable 1200 万到 1300 万 DAU 这事儿真的是挺扯的。其实也就是一百多万的 DAU。
