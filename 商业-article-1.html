淘宝闪购｜耐克复苏遇阻，Patagonia 运费政策引发争议

4/1/2026, 11:00:00 PM

📌 一句话摘要

本期播客综述了近期全球及中国市场的商业科技动态，重点解析了智谱 AI 的 API 市场反馈、华为业务重心向智能汽车偏移以及 Patagonia 的环保运费争议。

📝 详细摘要

本集播客深入拆解了多个行业的最新财报与市场策略。核心关注点包括：智谱 AI（原文误为智浦）在 API 涨价 80% 的背景下，其调用量逆势增长 400%，揭示了大模型基础设施在 B 端市场的强劲需求；华为在手机市场增速放缓的同时，智能汽车解决方案业务实现 72% 的高速增长，成为其新的增长引擎。此外，节目还讨论了名创优品通过自有 IP 研发实现营收突破、耐克在大中华区的复苏困境、霸王茶姬应对内卷的加盟模式调整，以及 Patagonia 因「地球使用费」运费政策引发的品牌溢价与环保争议。内容揭示了在存量竞争环境下，企业在 IP 化、AI 化及环保叙事方面的实操矛盾与探索。

💡 主要观点

  1. 智谱 AI 展现出极强的市场定价权与需求粘性 智谱 AI 在大幅提高 API 价格后，调用量反而实现数倍增长，反映出国产大模型底座已进入高频应用阶段，B 端客户对优质模型资源的依赖性增强。
  2. 华为业务增长动力发生结构性位移 随着国内手机市场饱和，华为的增长重心正从传统终端业务转向智能汽车解决方案，后者高达 72% 的增速证明了其技术栈迁移的成功。
  3. 品牌环保叙事与商业现实的摩擦加剧 Patagonia 通过加收运费减少退货碳排放的尝试，在缺乏线下服务支撑和国内外政策不对等的情况下，极易被消费者解读为成本转嫁而非环保贡献。

💬 文章金句

  • 长期的低价竞争并不利于整个行业的发展。
  • 消费者在买鞋子的时候，首先关注的往往是款式、价格和舒适度，环保可能是最后才会考虑的因素。
  • 耐克的复苏工作要花费比预期更长的时间，2027 年春季才能够看到产品团队重组之后的成果。
