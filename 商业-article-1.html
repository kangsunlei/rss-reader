腾讯汤道生：和 AI 一起长跑的这两年

8/28/2026, 7:50:00 AM

📌 一句话摘要

腾讯汤道生回顾两年 AI 实践，强调 AI 长跑中熬得久比起得早更重要，AI 应用需算法与工程结合，个人 Agent 与服务 Agent 互补，并以 AI 原生方式重构组织力，坚持长期主义与以人为本。

📝 详细摘要

汤道生借腾讯《知点》年刊分享两年 AI 实践思考。他认为 AI 竞赛如马拉松，起得早不如熬得久，腾讯虽起步晚但坚持长期投入。AI 应用不止大模型，算法决定天花板，工程能力决定触达速度，场景是腾讯最厚的底牌。创新不可规划但能力可积累，CodeBuddy 和 WorkBuddy 的诞生源于长期积累与快速迭代。个人 Agent 与服务 Agent 并存互补，构成企业 Agent 完整架构。AI 原生组织需更扁平、目标前置、评测清晰，产品与模型 Co-Design 至关重要。最后强调两个不变：长期主义与以人为本，并以基层防汛案例说明 AI 帮助人而非替代人。

💡 主要观点

  1. AI 竞赛如马拉松，熬得久比起得早更重要。 汤道生以移动设备历史为例，说明早期玩家未必胜出，长期投入、冷静思考本质、识别真实信号才能穿越周期。腾讯虽被外界认为 AI 起步慢，但坚持投入，混元模型多次重构，效果突出。
  2. AI 应用不止大模型，算法与工程结合，场景是腾讯最厚的底牌。 大模型能力是基础，但落地需要 AI Infra 工程加持，包括数据整理、训练、推理、场景落地。腾讯拥有大量 to C 和 to B 产品，每个都连接真实用户与场景，场景数据为模型提供上下文，形成护城河。
  3. 创新不可规划，但能力可以积累。 CodeBuddy 和 WorkBuddy 并非预先布局，而是源于长期积累的 DevTools 能力，在 AI Coding 机遇出现时快速响应。WorkBuddy 上线后以 AI 原生方式疯狂迭代，三个月四十多个版本，证明基于场景痛点、快速试错、重视反馈的重要性。
  4. 个人 Agent 与服务 Agent 并存互补，构成企业 Agent 完整架构。 个人 Agent 站在用户侧，高效完成任务；服务 Agent 遵循服务提供者意图，对数据输出负责，连接企业系统。两者结合，如 WorkBuddy 调用服务 Agent 获取客户数据，实现权限把关与准确结果，才是完整的企业 Agent 应用。
  5. AI 原生组织需重构研发模式，产品与模型 Co-Design 至关重要。 AI 能同时做好多个环节，角色边界模糊，大团队流水线变得臃肿。AI 原生组织需更扁平、目标前置、评测清晰，产品与模型协同设计，共同优化目标、构造数据、加强后训练，避免灵魂与肉体分离。

💬 文章金句

  • 熬得久，比起得早更重要
  • AI 应用落地应该是算法与工程的结合。也许算法决定天花板，工程能力决定你多快触达它
  • 创新不可规划，能力可以积累
  • 技术只是手段，人才是目的
  • AI 不是替代人，而是帮助人把那些繁琐、重复、低效但又重要的事情做得更好
