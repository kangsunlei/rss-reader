姚顺雨最新访谈：AI 下半场，机会在这一点

1/17/2026, 1:32:00 PM

📌 一句话摘要

姚顺雨访谈指出，AI 发展已进入“下半场”，机会在于设计非 ChatGPT 的交互方式，Language Agent 通过语言推理实现泛化，是通往 AGI 的关键路径，并强调任务定义和用户上下文积累的战略价值。

📝 详细摘要

本文整理了 OpenAI 前研究员、腾讯首席 AI 科学家姚顺雨的访谈内容，深入探讨了 AI 发展进入“下半场”的核心观点。他指出，AI 竞赛的胜负手已从单纯追求“更强模型”转向“定义有价值的任务和环境”，强调 Language Agent 是通往 AGI 的必经形态。文章详细阐述了 Agent 通过语言实现推理，进而实现泛化的核心机制，并预判未来 AI 世界将呈现“单极多元”格局。姚顺雨还提出了构建下一代 AI 系统的四大支柱：任务定义、交互创新、能力演进和系统思维，为创业者、企业决策者和研究者提供了在 AI 范式转换期的行动指南。核心洞察是“最大的机会，在于设计不同于 ChatGPT 的交互方式”以及长期积累 Context 的重要性。

💡 主要观点

  1. AI 竞赛进入“下半场”，核心矛盾从“如何训练更强模型”转变为“如何定义有价值的任务和环境”。 上半场 AI 关注模型和算力，下半场则聚焦于通过 Language Agent，依靠语言的推理能力实现跨任务、跨环境的泛化，这是达到 AGI 的必经之路。
  2. Agent 是构建 AGI 的必然形态，其核心在于通过语言赋予的推理能力实现泛化。 语言作为人为了泛化而发明的工具，使 Language Agent 能够进行推理，从而将学习能力从特定环境迁移到更广泛的场景，打破传统 AI 的训练局限性。
  3. 未来 AI 世界将呈现“单极多元”格局，交互创新是差异化竞争的关键。 少数强大的基础模型构成“单极”，而围绕不同交互方式构建的多元 Agent 应用生态则提供巨大想象空间，创业公司的机会在于设计“非拟人化”的新交互界面。
  4. 构建下一代 AI 系统需关注任务定义、交互创新、能力演进和系统思维四大支柱。 强调任务需结果导向、白盒规则且对应真实场景；交互方式可分为侵入式和原生式；能力演进需突破 Utility、Intrinsic Reward 和多智能体协作问题；研究应追求简单且通用。
  5. 创业公司壁垒短期靠交互创新，长期靠积累独特的用户上下文（Context）和环境。 面对高昂的 Agent 运行成本，创业成功的核心在于找到真正有价值的应用场景，通过创新的交互方式吸引用户，并长期积累用户上下文形成竞争壁垒。

💬 文章金句

  • 最大的机会，在于设计不同于 ChatGPT 的交互方式。
  • 我之所以这么说，是因为在此前，如果你在一个特定环境上训练，模型只能在这个环境表现良好，不能轻易迁移到其他环境。但现在，你在一个环境上训练，模型可以适应更多不同环境。所以，我觉得它还是泛化的，它能够推理。
  • 现在主线正从“上半场”转向“下半场”，我说的主线是基于“Language Agent”（语言智能体）。
  • 对于创业公司来说，最关键的是做新的交互方式设计。
  • 最终的智能边界，是由不同交互方式决定，而不是由一个 single model（单一模型）决定。
