#389.Tailwind CSS 创始人的至暗时刻：从风靡全球到裁员 75%，开源商业化的残酷真相

1/10/2026, 9:32:09 PM

📌 一句话摘要

Tailwind CSS 创始人 Adam 坦露商业挫败，因收入下滑裁员 75% 工程团队，反思开源商业化困境，并展望 AI 辅助下的未来。

📝 详细摘要

本期播客中，Tailwind CSS 创始人 Adam Wathan 坦诚分享了其开源项目商业化过程中遇到的巨大挫折。尽管 Tailwind CSS 广受欢迎，公司收入却持续缓慢下滑，最终导致他不得不做出裁员 75%（即 4 名工程师中的 3 名）工程团队的艰难决定。Adam 深刻反思了“温水煮青蛙”式的经营危机，开源项目的流行度与商业成功之间的悖论，以及开源社区中“理所当然”的需求对商业生存的冲击。他指出 AI 虽导致文档流量下降，但也成为小团队应对工作量、提高效率的“救命稻草”，例如利用 Claude Code 辅助 DevOps。面对困境，Adam 仍保持乐观，计划重回一线开发，并通过优化产品、拓展合作伙伴等方式寻求业务的可持续发展。播客中也提及了他对即将离职的优秀工程师的深情推荐，展现了其作为创始人的责任感与对团队成员的关怀。

💡 主要观点

  1. 开源项目流行度与商业成功可能存在反比关系。 尽管 Tailwind CSS 全球流行，但 Adam 观察到其商业收入长期缓慢下滑，他称之为“温水煮青蛙”式的危机，这揭示了开源项目在变现上的固有挑战。
  2. 为保证公司生存和员工权益，裁员是艰难但必要的商业决策。 面对现金流仅能支撑六个月的严峻现实，Adam 提前裁员 75% 的工程团队，旨在为员工争取体面的遣散费和找新工作的时间，体现了创始人的责任感。
  3. AI 是双刃剑，既是业务挑战也提供效率杠杆。 AI 导致产品文档流量下降，影响商业产品曝光。但同时，Adam 也利用 Claude Code 等 AI 工具辅助运维和问题诊断，以应对团队缩减后的工作量，提高小团队的效率。
  4. 开源社区的“理所当然”需求与商业生存存在冲突。 当社区提出增加“复制 Markdown”功能的需求时，Adam 必须基于公司生存优先级的考量，将其排在能够带来直接收入的工作之后，甚至暂时关闭，这折射出开源维护者的困境。

💬 文章金句

  • 收入已经慢慢下滑好几年了，但这个过程特别慢、特别稳，就像温水煮青蛙一样，你几乎都感觉不到。
  • 我做了一个疯狂成功的开源项目，结果商业上的成功却跟项目的流行度成了反比。这感觉真的太难受了。
  • 作为老板，这可能就是你必须背的锅。不幸的是全世界有时候都会觉得你是个恶魔。
  • 我觉得 AI 这东西显然是把双刃剑，我认为 AI 是我们业务陷入困境的一个重要原因。
