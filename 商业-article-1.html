从 E2B 到 Browserbase，Agent Infra 新热点中有哪些大机会？ | 对谈 Grasp 创始人雷磊

6/14/2025, 2:00:00 PM

📌 一句话摘要

播客探讨了 AI 代理(Agent)热潮后的基础设施新机会，特别是为 Agent 设计产品及运行环境的关键差异与挑战。

📝 详细摘要

本期播客邀请 Grasp 创始人雷磊，深入分析了 AI 代理(Agent)兴起后，Agent Infrastructure 领域蕴藏的巨大机会。对话首先区分了 Agent 与传统 SaaS 的本质不同，Agent 交付的是结果，且工作模式为多线程并行，这与人类的单线程、线性思考有根本区别。因此，为 Agent 设计软件和环境需要全新的思路，核心在于构建高效的反馈循环系统。播客探讨了 Agent Infra 的两大明星项目 E2B 和 Browserbase，解释了它们如何为 Agent 提供安全隔离的代码执行环境（沙盒/Micro VM）和云化浏览器。强调了 Agent 的运行环境和相关产品必然走向云端化，并讨论了安全边界、状态管理等技术挑战。雷磊认为，理解 Agent 痛点、具备 Agent 构建经验和深度的技术实践经验是做 Agent Infra 产品的关键。最后，展望了 AI Agent 将通过与环境的真实交互进行自我提升的未来范式，以及 Agent Infra 在此过程中的重要性，认为这是一个千亿甚至万亿美金规模的新兴市场机会。

💡 主要观点

  1. AI Agent 与人类工作模式和软件设计理念存在根本差异 Agent 是多线程、以结果为导向的，需要为其设计具备高效反馈循环、非线性的新工具和环境，而非简单复制人类工作流程。
  2. Agent Infra 是 AI Agent 时代的关键基础设施和市场机会 随着 Agent 数量激增，为它们提供安全、高效的运行环境（如代码执行沙盒、云化浏览器）将成为一个巨大的增量市场。
  3. Agent 运行环境及相关产品正向云端化演进 为了实现 Agent 的弹性、7x24 小时运行和模型/环境协同，将其运行在云端是必然趋势，客户端可保持本地，但核心处理在云端进行。
  4. 构建 Agent Infra 需深入理解 Agent 痛点并具备实践经验 成功的 Agent Infra 产品需要开发者既是 Agent 的使用者和构建者，也要具备深度的底层技术实践经验，才能解决安全边界、状态管理等复杂问题。

💬 文章金句

  • agent 它是一个交付结果的店面，所以店面的数量是无数多的，只要你能够交付在你这个垂直领域的更好的结果，那你就会收获一波你的用户。
  • 在我看来未来应该是人为 agent 去服务，因为 agent 的它就是有更高的带宽，它能接触到比人更多的知识或者比人更多的信号。
  • 人是一个单线程的工作模式，而 agent 它是一种多线程的并行的工作模式... 所以我们需要去为 AI 的这种新的工作范式去设计一些新的工具和环境。
  • 给 AI 用的浏览器与人本身用浏览器的具体区别：给 AI 用的浏览器运行在云端，AI 通过 headless 模式读取页面，安全层面需要防止 AI 获取用户账号密码，以及多步骤长时间操作时的 session 保持功能。
  • 在未来的 AI 的发展，它一定要是通过跟这个环境和这个世界进行真实的交互，然后去获取一些真实的反馈，所以这就是我认为在整个的 agent 的发展中，环境为什么非常重要的一个原因。
