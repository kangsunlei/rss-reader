EP127 从 Skills 到自动化工作流，论 Agent 如何接管真实生产力 ⚙️

6/9/2026, 2:02:10 PM

📌 一句话摘要

三位硬地骇客深度复盘 AI Skills 半年实战：如何用「真实验证」、需求澄清及个性化自动化，将 Agent 从编程助手升级为接管全链路生产力的数字分身。

📝 详细摘要

本期硬地骇客围绕 Anthropic 的 Skills 机制进行了深度年度复盘。嘉宾们分享了筛选与保留 Skills 的核心标准：重点解决不擅长领域的知识盲区（如前端设计、SEO）与高频重复性工作。在编程工作流上，他们已从关注代码细节转向只看架构与结果，构建了从需求讨论、自动计划、自我审查到自动化发版的 Agent 全自动闭环。讨论推荐了如 grill me 等需求澄清利器，强调了 playwright、computer use 等「真实验证」Skills 对于闭环开发的关键性。节目还跳出代码范畴，展示了 Skills 在知识管理自动同步、AI 辅助编写高阅读量解密文章、邮件润色及投资辅助等日常琐事中的实战应用，并深入探讨了全权委托 AI 带来的「失控感」与心理信任重构。

💡 主要观点

  1. 筛选 Skills 遵循「短板补齐」与「高频重复」原则 不应盲目安装网红 Skills，应优先选择解决不擅长领域（如前端设计、营销）或固化高频重复测试部署流程的 Skills，避免过度消耗 Token 与增加系统混乱。
  2. 「真实验证」是 Agent 实现开发闭环的基石 如 Playwright 或 Computer Use 这类能对迭代结果进行真实环境验证的 Skills，比单纯的技术栈最佳实践更重要，它能驱动真正的 Loops 循环，让人从繁琐的验收中解放。
  3. 人的信任边界与对代码的控制欲正在急剧退让 前端开发已进化到用 AI 生图定义风格再转译成代码，后端开发则只校验架构版图而忽略具体代码实现。工作重点从「掌控代码细节」转向「管控输入需求与最终结果」。
