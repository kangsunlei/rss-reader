前苹果设计师无意「曝光」了 iPhone 的新软件设计

6/5/2025, 6:29:59 PM

📌 一句话摘要

前苹果设计师预测 iPhone 新 UI 将受 visionOS 影响，转向基于“有生机的玻璃”的动态物理性设计。

📝 详细摘要

文章由前苹果设计师 Sebastiaan de With 撰写，深入探讨了 iPhone 操作系统 UI 设计可能的重大变革。作者回顾了 iOS 设计从早期的拟物化（“阴影时代”）到扁平化（“扁平时代”）的演变历程，分析了视觉风格如何适应硬件和用户认知。接着，文章重点介绍了苹果 visionOS 中强调的“物理性”设计原则，即界面元素具有维度、对光线动态响应并相互投射阴影。基于这些基础和灵动岛等现有动态 UI 元素，作者大胆预测未来的 iOS 设计将进入“有生机的玻璃”（living glass）时代，界面元素将更具动态材质感，能反射、模糊、响应周围环境和内容。文章通过概念图展示了标签栏、控件、App 图标等可能的新形态，并强调苹果在软硬件深度集成方面的独特优势是实现这一愿景的关键。

💡 主要观点

  1. iOS 设计历史演变揭示了 UI 风格随技术及用户认知调整的趋势 从拟物化到扁平化的转变，表明 iOS 设计不断适应硬件（如视网膜屏）发展和用户对智能设备界面的熟悉度，为理解未来变革提供了历史视角。
  2. visionOS 的“物理性”设计强调界面元素的材质感和环境动态响应 visionOS 将界面视为具有真实物理属性的物体，它们能对光线、环境做出动态反应，这种理念预示着未来界面设计可能突破二维限制。
  3. 未来 iOS UI 可能采用“有生机的玻璃”概念，界面更具动态材质感和沉浸感 将 visionOS 的物理性融入 iPhone 的玻璃屏幕，使 UI 元素能反射、模糊并响应内容，增强界面的真实触感和与设备的契合度，提升用户体验的生动性。
  4. 苹果软硬件集成优势是实现下一代复杂动态 UI 的关键 只有通过深度的软硬件结合，苹果才能实现如灵动岛、visionOS 材质渲染这类需要底层系统和图形性能支持的复杂动态界面效果。

💬 文章金句

  • 关于 iPhone 操作系统即将进行大规模改版的传闻甚嚣尘上------据说是「长久以来规模最大的一次」。
  • visionOS 设计语言的基本原则似乎是要求，界面元素始终由「真实」的材质构成，不能存在任何纯二维的面板或者色彩。
  • 从某种意义上说，灵动岛其实回归了拟物化界面------但不再是给所有元素都喷上高光漆，而是通过清晰与高度图形化的界面，让灵动岛的行为类似我们在现实生活中熟悉的事物，或者「更有可能」存在于这个世界中------这就是新的拟物化，也就是一种物理性（physicality）。
  • 从设计理念上来说，如果我是苹果，我会将这套新的界面描述为一套「终于配得上我们精美硬件的界面」。
  • 也许，只有苹果能够将你的屏幕玻璃赋予生命，推进人机界面迈入下一时代。
