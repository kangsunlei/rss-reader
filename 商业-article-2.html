Fable 5.1 来了：号称全球最强，Anthropic 也开始卷“缓存价格”

9/1/2026, 11:33:00 PM

📌 一句话摘要

Anthropic 发布 Claude Fable 5.1 和 Mythos 5.1，重点提升了长任务稳定性、科研 Agent 能力及代码能力，并大幅下调缓存读取价格以降低 Agent 运行成本。

📝 详细摘要

Anthropic 推出的 Fable 5.1 和 Mythos 5.1 基于相同底层模型，但采取不同的安全限制策略。Fable 5.1 显著增强了在复杂编码、科学研究和业务自动化等长任务链中的稳定性，并在 Terminal-Bench-Science 等测试中表现优异。Mythos 5.1 则面向专业用户，在蛋白质设计和 GPU 内核优化等高精尖科研领域展现出极强的实用价值。此外，Anthropic 引入了 Enterprise Frontier Safeguards (EFS) 增强企业数据控制权，并将缓存读取价格降低 75%，旨在通过降低重复上下文读取成本来推动高度 Agent 化任务的普及。

💡 主要观点

  1. Fable 5.1 强化了处理长且复杂任务的稳定性，显著提升了 Agent 的执行能力。 模型在 Terminal-Bench-Science 0.1 等测试中得分大幅领先，能够执行包含反汇编分析、长时间机器学习任务等需要不断检查结果并调整路径的复杂工作流。
  2. Mythos 5.1 在专业科研领域（生物学与计算）展现出极高的实际应用价值。 在蛋白质设计中，其有效结合剂命中率接近 50%（远高于行业 10%-15% 均值）；在计算生物学中，通过编写定制 GPU 内核将部分模型推理速度提升最高 2.5 倍。
  3. 通过大幅降低缓存读取价格，降低高度 Agent 化任务的运行成本。 缓存读取价格下降 75%（从 1 美元降至 0.25 美元/百万 Token），虽然输出 Token 增加可能抵消部分降幅，但对于频繁读取上下文的智能体任务具有显著的成本节省作用。
  4. 实施分级安全机制与企业级数据隐私保护。 将模型分为面向大众的 Fable 和面向审核专业人士的 Mythos；同时推出 EFS 允许企业将数据保存在自有云基础设施中，增强数据主权。

💬 文章金句

  • 「缓存读取价格从每百万 Token 1 美元降到了 0.25 美元，降幅达到 75%。」
  • 「在 12 个目标上，Mythos 5.1 生成的设计中，接近 50%最终被验证为有效结合剂。」
  • 「Fable 5.1 需要处理的已经不只是一个问题对应一个答案。一次任务可能从读取资料开始，经过代码分析、工具调用、实验验证，再回到前面的结果重新判断，最后形成可以交付的结果。」
