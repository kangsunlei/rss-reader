AI Agent 摩尔定律：每 7 个月能力翻倍，带来软件智能大爆炸

4/11/2025, 11:03:24 AM

📌 一句话摘要

文章分析了 AI Agent 能力增长的 scaling law，并探讨了其自主研发的潜力与挑战。

📝 详细摘要

文章深入分析了 AI Agent 的能力增长，指出其存在类似于摩尔定律的 scaling law，即 Agent 能够完成的任务长度大约每 7 个月翻倍，甚至可能加速至每 4 个月翻倍。文章基于 META、Forethought 和 AI Digest 的研究，强调了“任务长度”作为衡量 Agent 能力的重要指标，并分析了 Agent scaling law 出现的原因，包括算力提升和算法改进等硬件和软件的突破。文章提出了 Agent 自主开发 Agent (ASARA) 的终局猜想，并讨论了硬件制约和训练时间过长等潜在瓶颈及解决方案。文章的结论是 AI Agent 将在软件智能爆炸中扮演关键角色。

💡 主要观点

  1. AI Agent 能力增长的 Scaling Law 正在加速，大约每 7 个月翻倍 META 的研究表明，Agent 能够完成的任务长度呈指数级增长，与 Agent 成功率高度相关，预估 2029 年 Agent 能完成 1 个月任务。
  2. AI Agent 能力增长的驱动力来自 LLM 硬件、软件和数据的突破 硬件方面，算力规模的提升带来模型能力的增强；软件方面，AI 技术范式、系统架构、训练算法等方面的进步提升了效率和能力；数据方面，更多高质量的数据加速了模型训练和优化。
  3. Agent 开发 Agent (ASARA) 是终局猜想，可能引发软件智能爆炸 (SIE) 当 AI Agent 能力足够强时，可能出现 AI 系统完全自动化 AI 研发的情况，大幅提升 AI 进展速度，甚至达到仅由软件驱动的反馈循环。

💬 文章金句

  • Agent 能完成的任务长度的增加可能最终成为人类历史上最重要的趋势之一。
  • AI Agent 领域也存在 scaling law，甚至还在加速。
  • AI scaling law 的终局是 AI agent 自主开发 AI agent，到了那个时候我们就会进入软件智能爆炸时代（Software Intelligence Explosion，SIE）。
