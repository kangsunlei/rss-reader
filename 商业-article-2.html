OpenAI 提出以 AI 加速美国国家科学研究的长期计划

7/22/2026, 10:05:49 PM

📌 一句话摘要

OpenAI 宣布为美国能源部 Genesis Mission 的研究者提供数百万美元 API 额度，以加速 AI 在基础科学领域的应用。

📝 详细摘要

OpenAI 发布了一项旨在加速美国国家科学研究的长期计划，承诺为约 2，000 名参与美国能源部 Genesis Mission 的研究人员提供 400 万美元的 Codex 额度，并为两项聚焦于高温超导和“机器可及前沿”图谱的科学挑战投入 300 万美元的 API 支持。推文作者 Panda 点评认为，这标志着美国顶尖大模型开始向其他行业渗透，并预测 2026-2027 年将是 AI/LLM 大规模在企业真实环境落地的关键年份。
