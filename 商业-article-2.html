OpenAI 举行 DevDay 2026 并发布多项更新

9/30/2026, 2:04:00 AM

📌 一句话摘要

OpenAI 在 DevDay 2026 发布了全天候自主智能体 Dot，以及一系列高性能模型更新与企业级协作功能。

📝 详细摘要

OpenAI 举办 DevDay 2026 并推出超过 20 项更新。核心亮点是由 GPT-6 Astra 驱动的自主智能体 Dot，它支持跨平台交互、自主代码编写及多任务处理。同时，官方发布了性价比更高的 GPT-6.1 Sol 和极速的 Astra Ultrafast 模型，并推出了 Decisions API 和托管 Agents API。此外，还升级了 ChatGPT 资料空间和 Codex 系列等工作流工具。

💡 主要观点

  1. 发布全天候自主智能体 Dot Dot 基于 GPT-6 Astra 驱动运行在独立云端电脑，拥有专属浏览器和身份，支持自主编写/测试代码及跨 Slack、Teams 等多平台同步交互。
  2. 模型性能与成本优化 推出 GPT-6.1 Sol（价格仅为 Astra 标准版四分之一）和 Astra Ultrafast（速度提升 6-8 倍），满足不同成本与性能的需求。
  3. 企业级治理与安全增强 通过微软集成 Agent 365 治理，Dot 默认开启恶意指令防护与操作审核，且主动研究阶段的数据不用于训练模型。
  4. 工作流工具链升级 上线了支持动态页面和协作幻灯片的 ChatGPT 资料空间，以及升级的 Codex Cloud 和 CLI，提升开发者协作体验。
