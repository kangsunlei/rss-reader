OpenClaw 开发者：为什么 80% 的应用会消失？丨 Y Combinator

2/8/2026, 1:28:00 PM

📌 一句话摘要

本文通过 OpenClaw 开发者 Peter Steinberger 的视角，探讨了 AI Agent 从对话向执行的转变，并提出了本地优先架构、App 界面消亡及长期记忆等前瞻性观点。

📝 详细摘要

文章总结了 OpenClaw 创始人 Peter Steinberger 对 AI Agent 未来发展的深度思考。他认为 AI 革命的核心在于从“思考者”转向“行动者”，即 AI 需具备直接调用 API 执行任务的能力。Peter 极力主张“本地优先”架构，强调数据主权与隐私保护在 AI 时代的重要性。此外，他提出了激进的“App 消失论”，认为未来 80% 的应用将退化为纯粹的 API 接口，用户将通过统一的自然语言界面进行交互。在技术实现上，他推崇多模型协作的“群体智能”而非全能大模型，并认为 CLI 交互比模拟人类点击（MCP）更高效，长期记忆则是构建个性化 AI 助手的关键护城河。

💡 主要观点

  1. AI 必须从单纯的“对话工具”进化为具备实际执行能力的“数字管家”。 当前的 AI 痛点在于能说不能做。未来的机会点在于让模型安全、稳定地连接现实世界的 API，直接处理日历、邮件和复杂工作流，实现从生成内容到执行任务的跨越。
  2. “本地优先”架构是解决 AI 隐私隐患与实现数据主权的核心路径。 将模型运行、索引建立和决策过程保留在本地设备，不仅能消除对云端服务的依赖，还能确保用户对核心业务数据和个人资产拥有绝对的控制权，这是 AI 时代的无价资产。
  3. 未来 80% 的 App 将会消失，软件形态将从图形界面转向“界面即服务”的终结。 当 AI Agent 能通过自然语言统一调用各类服务的 API 时，传统的孤立 App 界面将失去存在意义。服务商的竞争焦点将从争夺屏幕时间转向争夺 AI Agent 的调用权限。
  4. 采用“群体智能”架构，让多个专业小模型协作比追求全能大模型更高效。 全能模型存在参数冗余和幻觉风险。通过设计精密的组织架构，让负责 SQL、文案、调度等不同任务的小模型各司其职，能显著降低推理成本并提升系统的鲁棒性。
  5. 长期记忆是 AI 从通用工具进化为个性化助手的关键，也是不可复制的护城河。 通过本地向量数据库记录用户的交互偏好和文档数据，AI 能构建完整的用户画像并打破数据孤岛。这种在长期互动中形成的深度理解，是 AI 产生质变并提供真正价值的核心。

💬 文章金句

  • 真正的 AI 革命不是造一个更聪明的大脑，而是造一双能干活的手。
  • 你不拥有云端的数据。如果服务商决定关闭账号，你什么都没了。本地优先意味着你拥有控制权，这在 AI 时代是无价的。
  • 未来 80% 的 App 将会消失，或者退化为纯粹的 API 接口。这种中间层将会被彻底抹平。
  • 不要试图让机器人像人一样去点鼠标。那是对算力的浪费。给它们最原始的接口，它们能跑得飞快。
  • 真正的个性化不是你填一张表，而是 AI 在长期的互动中默默记住了你的所有习惯。那是无法复制的护城河。
