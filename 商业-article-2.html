Gemini API 工具更新：上下文循环、工具组合及 Gemini 3 的地图接地功能

3/18/2026, 5:05:13 PM

📌 一句话摘要

Google 更新了 Gemini API，支持内置工具与自定义工具的组合使用、跨工具上下文循环、唯一的工具响应 ID，以及 Gemini 3 系列的 Google 地图接地功能。

📝 详细摘要

本文介绍了 Gemini API 的关键更新，旨在简化智能体工作流。开发者现在可以在单个请求中结合内置工具（如 Google 搜索和 Google 地图）与自定义函数，从而降低编排复杂度。此次更新引入了跨工具上下文循环，允许模型在工具调用之间传递数据以进行复杂的推理，并引入了唯一的工具响应 ID 以改善调试和异步执行。此外，Gemini 3 模型系列现已支持 Google 地图接地功能，助力开发位置感知应用。文章建议使用新的 Interactions API 以实现更好的服务端状态管理。

💡 主要观点

  1. 统一的工具交互 开发者现在可以在单个请求中混合使用内置工具（搜索/地图）和自定义函数，从而简化智能体架构并降低延迟。
  2. 跨工具上下文循环 模型现在可以将一次工具调用的输出作为后续调用的输入，从而实现更复杂的多步推理工作流。
  3. 改进的调试与异步处理 引入唯一的工具响应 ID（id）允许将工具调用精确映射到客户端响应，这对并行执行至关重要。
  4. 扩展的地图接地功能 Gemini 3 模型现已支持 Google 地图接地功能，提供对空间数据、本地商家信息和通勤时间的访问。

💬 文章金句

  • 现在，你可以在同一个请求中同时传递内置工具和你自己的自定义工具。
  • 内置工具的上下文循环会在模型上下文中保留每一次工具调用及其响应，因此后续步骤可以访问并基于这些数据进行推理。
  • 为了提高可调试性并确保异步工具执行过程中的精确映射，我们为每一次工具调用引入了唯一的调用标识符（id）。
