技术路线之争本质是权力斗争

9/11/2026, 12:54:14 AM

📌 一句话摘要

作者借 Shopify 从 React Native 回归 iOS 原生一事，认为大部分公司技术路线之争本质是权力斗争，与技术好坏无关。

📝 详细摘要

作者以 Shopify 从 React Native 回归 iOS 原生为引子，提出大部分公司的技术路线之争本质上是权力斗争，与技术好坏无关：新人上位就要淘汰旧人写的东西。作者认为原生 iOS 切到 React Native 并不会带来效率提升，反而更复杂、问题更多，当年的 React Native 稳定性远不如现在；并举例国内某鱼用 Flutter 做出的 App 体验很差，但一旦做大就没人能动。

💡 主要观点

  1. 技术路线之争常常是组织权力更替的投影，而非技术优劣的比较。 作者认为新人上位需要通过「淘汰」前任的技术选型来确立话语权，因此技术决策的动因往往在组织政治而非工程收益。
  2. 跨端方案并不必然带来效率提升，反而可能增加复杂度。 作者以原生 iOS 切 React Native 为例，认为它没有效率提升、问题更多，且当年的 React Native 稳定性远不如现在。
  3. 技术选型一旦随产品做大，纠错成本极高。 作者以某鱼使用 Flutter 为例，认为其 App 体验不佳，但因为体量做大后已无人能推动改动。

💬 文章金句

  • 但一旦做大了，也就没人能动了
