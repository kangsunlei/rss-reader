DeepSeek 终于长出“眼睛”，V4 Flash 视觉模型上线

8/21/2026, 9:54:00 AM

📌 一句话摘要

DeepSeek 发布 V4 Flash 视觉模型实验版，首次支持图片输入，定价与纯文本版一致，文章分析其可能是组合已有视觉模块而非原生多模态训练。

📝 详细摘要

8 月 21 日，DeepSeek 官方 API 文档上线 deepseek-v4-flash-vision-exp，这是 V4 系列首个支持图片输入的视觉模型，拥有 1M 上下文、384K 最大输出，定价与 V4 Flash 完全一致。文章回顾了此前 V4 系列缺乏视觉能力时，社区如何通过 Qwen-VL 等第三方模型 workaround 的尴尬局面，并指出 DeepSeek 在 Harness rc.8 版本已提前埋下多模态支持。分析认为，Vision Exp 可能采用组合架构——将已有视觉编码/OCR 模块接到 V4 Flash 之前，而非像 Gemini、GPT 那样原生统一多模态训练。产品定位上，视觉能力优先接入更小更快的 Flash 而非 Pro，瞄准的是 Agent 场景中的高频视觉任务（截图识别、报错分析、UI 查看等），而非追求单次图片理解最强。Exp 后缀表明 DeepSeek 仍在收集社区反馈，为正式版迭代做准备。

💡 主要观点

  1. DeepSeek V4 Flash 视觉模型首次支持图片输入，定价与纯文本版一致。 模型名为 deepseek-v4-flash-vision-exp，1M 上下文、384K 输出，图片按尺寸折算 Token 统一计费，高峰缓存未命中输入 3 元/百万 Token、输出 9 元。
  2. 视觉能力可能是组合已有模块而非原生多模态训练。 DeepSeek 此前有独立 OCR 产品线，V4 Flash 此前明确只支持文本输入，Vision Exp 可能是将视觉编码器接到 V4 Flash 前端的组合架构，与 Gemini、GPT 的原生多模态路径不同。
  3. 视觉能力优先接入 Flash 而非 Pro，瞄准 Agent 高频视觉任务。 Flash 定位高吞吐低成本，视觉任务如读截图、识别报错、分析图表等更在意速度和价格，而非单次理解最强，符合 Flash 的产品逻辑。
  4. Exp 后缀表明仍在收集社区反馈，为正式版迭代做准备。 DeepSeek 此前 V3.2-Exp 通过社区测试验证 DSA 稀疏注意力机制，Vision Exp 可能承担类似角色，在真实 Agent 工作流中发现问题后再推出正式版。

💬 文章金句

  • DeepSeek 正在补齐一套 Agent 系统最基础的感知入口。
  • 这形成了一个略显尴尬的局面：DeepSeek 刚刚发布了一套高度插件化的 Agent Harness，但面对最常见的截图、网页图片和报错界面时，仍需要借用其他公司的模型。
  • 如果正式版继续维持这一策略，视觉理解可能再次进入 DeepSeek 熟悉的价格战区间。
