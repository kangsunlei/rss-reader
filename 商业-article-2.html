AI 原生公司长啥样？他们造了个 Agent，也造了一种新公司

7/4/2026, 1:30:00 PM

📌 一句话摘要

本文深度记录了一家 AI 创业公司在产品盈利时主动转型，用 5 周时间从 0 到 1 打造 Agent 产品 Cola，并同步将组织改造为「人做判断、AI 写代码」的 AI 原生形态的全过程。

📝 详细摘要

文章以创业公司「火星电波」为样本，详细拆解了其在核心产品 ListenHub 实现 300 万美元 ARR 并盈亏平衡后，主动放弃安全路径、全面转向通用 Agent 的决策与执行过程。创始人冯雷和 CTO 徐文健在 2026 年 1 月达成共识，随后团队经历了两周的「只看不写」探索期、方向分歧与拍板，最终在 5 周内，以「人做判断，99% 代码由 AI 生成」的 Vibe coding 模式，做出了有「灵魂」的 AI Agent 产品 Cola。转型同步引发了组织变革：层级与项目管理工具消失，全员通过 Agent 共享 GitHub 知识库，诞生了专门负责人格输出的「Soul Team」。文章也坦诚记录了核心成员因理念不合离开的代价，以及创始团队从「婚前协议」到背靠背信任的成长，为观察 AI 原生公司的诞生提供了高信息密度的真实案例。

💡 主要观点

  1. 在看似安全的盈利期主动转向，源于对 Agent 时代机遇的紧迫感和对旧产品过渡性质的清醒判断。 创始人认为 ListenHub 只是 AI 时代早期的过渡产品，若不亲自从 0 到 1 做一个 Agent，就无法理解新的工作方式，公司未来将失去竞争力。
  2. 「人做判断，AI 写代码」的 Vibe coding 模式，使产品开发周期从数月压缩至 5 周，并彻底改变了组织协作方式。 团队 99% 的代码由 AI 生成，人专注于定义方向、判断质量和复盘。想法可被快速实现，减少了沟通损耗，线性协作被点对点沟通取代。
  3. 新产品 Cola 的诞生，同步催生了一种「AI 原生组织」形态。 项目管理工具（Linear、Notion）被废弃，全员通过 Agent 共享 GitHub 仓库获取上下文；出现了专门负责人格与情感输出的「Soul Team」，工作边界消失，每个人更像一个「超级 OPC」。
  4. 组织转型必然伴随阵痛，核心成员因理念分歧离开是追求非共识方向必须承担的代价。 一位能力强但坚持多 Agent 路径的核心成员无法被说服而离开，创始人反思了理性沟通的不足，但也认识到创业本身就是一种无法被完全论证的非共识。
  5. AI 带来的效率提升在组织层面并非线性，需要建立「前置思考 + 后置复盘」的新治理节奏来平衡速度与质量。 AI 快速生成导致代码库膨胀，团队摸索出每月初对齐方案、月底重构代码的节奏，强调「并不是越快越好」，管理的重心从管流程转向管判断与质量。

💬 文章金句

  • 如果我们还在用 ListenHub 的方式去做 ListenHub，那今年我们公司可能就没有任何竞争力。
  • 很多事情很难论证对错，我们现在也没有办法判断这个方向就一定是对的，但干就完了，做了再说。
  • DAU 已经过时，Agent 是新的人口红利，人类的价值将转向「愿力驱动」。
  • 当生产力在 Vibe coding 时代不再稀缺，那么「人味」和「灵魂」会变成稀缺品。
  • 没有办法验证谁是对的时候，你就只能选一个方向往前走。你停在这儿纠结是不对的，今天组织纠结的话就完蛋了。
