2/5/2026, 9:45:00 PM

📌 一句话摘要

YC 现在允许 2026 年春季班申请者提交 Claude Code 记录或 Markdown 文件，以展示其 AI 辅助构建的过程。

📝 详细摘要

Y Combinator 为 2026 年春季班引入了一个新的申请问题，旨在更好地了解创始人如何利用 AI 进行构建。申请者现在可以上传来自 Claude Code 等工具（或其他编程助手）的 Markdown 文件或记录。这一变化旨在让 YC 合伙人深入了解创始人在 AI 原生开发工作流中如何规划、设计、调试和交付功能。
