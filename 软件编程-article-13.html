VLDB2025 | Magnus: 字节跳动面向大规模机器学习的数据管理方案

9/4/2025, 10:03:00 AM

📌 一句话摘要

字节跳动基于 Apache Iceberg 打造的 Magnus 数据管理方案，通过存储、索引、元数据及更新机制创新，高效支撑 EB 级大规模机器学习与大模型训练。

📝 详细摘要

文章详细介绍了字节跳动面向大规模机器学习的数据管理解决方案 Magnus。该方案在开源 Apache Iceberg 基础上，针对机器学习训练场景的存储效率、索引能力、元数据管理、高频更新以及大模型训练适配等痛点进行了深度优化。Magnus 引入自研 Krypton 列存和 Blob 多模态格式，实现了轻量级元数据管理与 Git 式版本控制，并创新性地设计了高性能 Merge-on-Read 更新机制。此外，它还针对推荐大模型和多模态大模型训练进行了深度适配，有效解决了 EB 级数据的管理难题，显著提升了存储效率、读写性能和训练吞吐量，相关成果已被 VLDB 2025 收录。

💡 主要观点

  1. Magnus 通过自研存储格式与高效索引设计显著提升数据管理效率 引入 Krypton 列存和 Blob 多模态格式，优化宽表与多模态数据存储；内置哈希/HFile 主键索引及倒排/向量索引，实现数据存储与检索统一，满足多样化查询需求。
  2. 轻量级元数据管理与 Git 式版本控制解决了海量数据挑战 精简 Iceberg 元数据，提升解析效率；引入 Rebase/Merge 等 Git 操作实现高效数据版本管理与可追溯性，支持特征调研与模型迭代。
  3. 高性能 MOR 更新与 Upsert 机制有效应对机器学习高频数据更新 基于 MOR 策略实现列级更新与主键表 Upsert，避免 COW 高开销，通过高效读时合并与并发处理，大幅提升读写效率，尤其适用于特征工程场景。
  4. 深度适配大模型训练场景，优化存储与计算效率 针对 LRM 设计 Main+Extra 双表架构，大幅节省用户序列存储；为 LMM 训练优化内存占用和启动性能，提升训练吞吐量，有效支撑大规模模型训练。

💬 文章金句

  • 字节跳动在开源 Apache Iceberg 的基础上，打造了一套面向大规模机器学习的数据管理解决方案 Magnus，在存储格式、索引、元数据管理、更新机制、训练框架集成等多个维度实现优化。
  • Magnus 已在字节内部部署超过五年，在搜索、广告、推荐、大模型等核心业务中大规模落地，数据规模超 5EB，相关成果已被 VLDB 2025 收录。
  • Magnus 在 Iceberg 的快照与分支机制的基础上，进一步引入类 Git 的分支 Rebase 与 Merge 等操作，实现高效的调研流程，所有分支操作仅修改元数据，无需复制底层数据文件。
  • Magnus 基于轻量级 Merge-on-Read（MOR）策略，构建了一套高性能 Update 与 Upsert 机制，以适配机器学习场景中数据更新需求，既规避了 Copy-on-Write（COW）的高写入开销，又突破了开源数据湖 MOR 策略的性能瓶颈。
  • LRM 训练任务中，Magnus Main x Extra 表节省 50×存储，吞吐量提升 70%；LMM 训练中，内存占用减少约 40%，启动性能提升一倍，训练耗时打平甚至更优。
