狼人杀 AI 对决：手把手教你打造高分 Agent

7/17/2025, 12:31:00 AM

📌 一句话摘要

本文详细阐述了在 AI 狼人杀比赛中，如何通过工程优化、模块化 Prompt 设计和针对性策略，构建并调优高性能大模型 Agent 的全过程。

📝 详细摘要

文章分享了作者在 AI 狼人杀比赛中打造高分 Agent 的实践经验。面对局部信息博弈、自然语言理解和时间响应约束等核心挑战，作者提出了基于宏观概率决策、意图识别和高可用 Agent 的解题思路。技术实现上，文章详细介绍了时域请求合并缓存机制以优化响应时间，多路并发集成提升模型思考机会，以及模块化 Prompt 设计（引入 Jinja2 模板引擎）以提高迭代效率和维护性。特别地，文章深入探讨了针对主持人提示词注入和逻辑炸弹攻击的防护与反击策略。在模型调优方面，作者强调了模型选取的重要性，并借鉴强化学习思想对 Prompt 进行迭代优化。最后，文章还分享了狼人、村民、女巫和预言家四种角色的具体战术策略，并开源了相关代码，为 AI Agent 开发者提供了宝贵的实践指导。

💡 主要观点

  1. 通过时域请求合并缓存和多路并发提升 Agent 鲁棒性与响应速度 结合缓存机制减少重复 LLM 请求，并异步并发调用多个 Prompt，再由轻量模型筛选最优结果，显著提升 Agent 在复杂博弈中的稳定性和响应效率。
  2. 采用模块化 Prompt 设计与强化学习思想进行模型调优 引入 Jinja2 模板引擎实现 Prompt 的组件化和动态渲染，并通过模拟强化学习范式，根据比赛结果迭代优化 Prompt，提升 Agent 决策质量和适应性。
  3. 构建针对提示词注入和逻辑炸弹攻击的防御机制 利用 XML 标签封装系统信息和 Prompt 中对比学习的思想，有效识别并防御了伪造的主持人信息和逻辑陷阱攻击，增强了 Agent 在对抗环境下的安全性。

💬 文章金句

  • Agent 必须在充满谎言和伪装的环境中，构建对局势的动态认知。
  • 当主持人发起一次请求时，异步使用多个 prompt 同时发起 LLM 请求，然后使用轻量化模型（便宜、快）选取效果最好的结果返回。
  • 通过模块化 prompt 设计，可以将这些内容抽象出来，提升复用性和维护成本，在使用时，根据当前上下文动态渲染生成。
  • 没有绝对优秀的战术、也没有完全没用的战术。相同的战术不同的时机也会有不同的效果。
  • 对于一个新的业务场景，强化学习的大模型也同样有可能快速达到一个超越普通人的专家水平。
