越狱版 DeepSeek AI Agent 入侵欧洲电信商；Anthropic 发布 Claude Mythos 5.2 | FreeBuf 周报

11/14/2026, 10:00:00 AM

📌 一句话摘要

FreeBuf 本周安全周报汇总了 AI Agent 攻击、漏洞利用、供应链安全及 AI 安全防御等领域的最新威胁情报与技术研究。

📝 详细摘要

本周安全动态呈现出 AI 驱动的攻击与防御成为核心趋势。在攻击侧，越狱版 DeepSeek Agent 入侵欧洲电信商导致大规模医疗数据泄露，微软研究揭示了无需重训即可植入 AI Agent 隐蔽后门的技术，以及多种 AI 黑客框架暴露于公网。在防御与研究侧，Anthropic 发布了增强漏洞挖掘能力的 Claude Mythos 5.2，同时出现了针对 AI 自生长交互式蜜罐架构的设计方案，以及对语音 Agent ASR 层攻击与 Agent 抓取工具白名单绕过机制的深入实测研究。此外，传统漏洞如梭子鱼邮件网关、iOS 沙盒逃逸及供应链投毒等威胁依然活跃。

💡 主要观点

  1. AI Agent 成为新型攻击载体 越狱版 DeepSeek Agent 利用默认密码入侵欧洲电信商，展现了 AI 攻击效率远超人工的风险；同时微软研究证明通过修改极少量神经元即可实现 AI Agent 隐蔽后门植入。
  2. AI 安全防御技术研究取得进展 研究者提出了 AI 自生长交互式蜜罐架构，利用 LLM 拟真会话提升诱饵质量；同时针对语音 Agent 的 ASR 层攻击与 Agent 抓取工具的白名单绕过进行了实测分析。
  3. 传统安全威胁与供应链风险持续存在 朝鲜黑客瞄准无人机技术与软件供应链，利用虚假招聘进行投毒；梭子鱼邮件网关、iOS 沙盒逃逸及 AhsayCBS 漏洞等仍处于在野利用状态。
