本文是 Hacker News 每日热门话题的中文摘要，覆盖十个领域。文化方面，乡村音乐传奇多莉·帕顿与演员蒂姆·库里相继去世，引发社区对其艺术成就与慈善贡献的缅怀。技术方面，Nitter 与 XCancel 收到 Twitter 的停止并终止信函，引发关于平台控制与数据抓取的讨论；DuckDB 开发公司 DuckLabs 加入 AWS，但项目保持 MIT 开源许可；GLM-5.3-Flash 与 Qwen3.8-Flash-Next 两款新模型发布，前者以 18B 激活参数实现接近 Claude Opus 4.8 的性能，后者以 6B 激活参数大幅降低训练成本。医疗方面，FDA 授权首款可同时监测酮体和血糖的可穿戴设备 Libre Duo，可提前预警糖尿病酮症酸中毒。法律方面，Meta 同意支付最高 180 亿美元和解儿童伤害诉讼，并承诺限制青少年使用时长。此外，Firefox 157 将默认启用基于 Rust 的 JPEG XL 解码器，文章还建议 RAG 构建应避免过度工程化。

💡 主要观点

  1. GLM-5.3-Flash 以 18B 激活参数实现接近 Claude Opus 4.8 的编码与智能体性能，成本仅为 GLM-5.2 的十分之一。 该模型总参数 320B，通过混合稀疏与线性注意力架构，大幅降低长上下文服务成本，在多个基准上超越 GLM-5.2，并在 Z.ai Code Bench 上接近 Claude Opus 4.8，体现了高效模型设计的进步。
  2. Qwen3.8-Flash-Next 以 6B 激活参数实现训练成本约为 Qwen3.7-Plus 的 1/9，并原生支持 262k 上下文。 该模型采用 GDN 与 QSA 混合注意力、Gated Residual、N-gram 嵌入和 Muon 优化器，在提升性能的同时显著降低训练与推理成本，为 Qwen4 架构提供早期预览。
  3. FDA 授权首款可同时连续监测酮体和血糖的可穿戴设备 Libre Duo，可提前识别糖尿病酮症酸中毒风险。 该设备适用于 2 岁及以上糖尿病患者，每分钟向手机发送数据并在酮体达危险阈值时报警，基于六项临床研究、600 多名参与者的数据，有助于在 DKA 成为医疗紧急情况前干预。
  4. Meta 同意支付最高 180 亿美元和解儿童伤害诉讼，并承诺限制青少年每日使用时长和夜间使用。 协议要求十年内将青少年每日使用限制为两小时，午夜至凌晨 6 点禁止使用，并关闭上学时段推送通知，但 HN 评论质疑其实际效果，认为商业模式未变。
  5. Firefox 157 将默认启用基于 Rust 的 JPEG XL 解码器，解码性能与 Safari 相当。 该功能基于 jxl-rs 解码器，支持动画与渐进式显示，但不支持 HDR；社区讨论指出无损解码速度较慢，但 JPEG XL 可无损重压缩现有 JPEG 节省 15-25% 空间。

💬 文章金句

  • DuckDB 及其相关开源组件将继续保持 MIT 开源许可，由非营利组织 DuckDB 基金会继续管理。
  • GLM-5.3-Flash 是 GLM-5 系列首个原生多模态模型，总参数量 320B，激活参数仅 18B，性能超越 GLM-5.2，成本仅为十分之一。
  • 这是美国首个能够连续监测酮体水平的可穿戴设备，也是世界上首个在单个设备中同时连续监测酮体和血糖的设备。
  • 协议要求 Meta 在十年内将青少年每日使用时长限制为两小时，午夜至凌晨 6 点禁止使用，并关闭上学时段（早 8 点至下午 3 点）的推送通知。
  • JPEG XL 的核心优势之一是可无损重新压缩现有 JPEG 文件，节省 15-25% 空间，且能 100% 字节级还原原始 JPEG。
