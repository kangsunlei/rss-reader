Cloudflare Zero Trust：升级后量子密码学，应对传统加密威胁

3/17/2025, 1:00:00 PM

📌 一句话摘要

Cloudflare Zero Trust 平台提供后量子密码学保护，助力企业防御量子计算威胁，无需单独升级应用。

📝 详细摘要

Cloudflare 宣布其 Zero Trust 平台的量子安全能力，旨在帮助企业防御量子计算机的潜在威胁，标志着第一阶段的完成。文章指出，传统密码学正面临量子计算的挑战，美国国家标准与技术研究院 (NIST) 也已制定 RSA 和 ECC 等算法的淘汰时间表。Cloudflare 通过其 Zero Trust 平台，利用后量子密码学保护企业网络流量，无需单独升级每个应用。具体通过无客户端访问 (Clientless Access)、WARP 客户端和 Gateway 三种主要量子安全用例实现：无客户端访问 (Clientless Access) 保护内部 Web 应用，WARP 客户端保护任何协议，Gateway 保护对第三方 Web 应用的访问。文章还探讨了迁移到后量子密码学的必要性，包括解决密码算法过时和应对“先收集后解密”的攻击。Cloudflare 自 2017 年以来一直在研究和标准化后量子密码学，并提出了分阶段迁移策略，重点是 TLS 1.3 协议的密钥协议和数字签名。

💡 主要观点

  1. NIST 计划在 2030 年前弃用传统加密算法，并在 2035 年前完全禁用 美国国家标准与技术研究院 (NIST) 宣布了淘汰 RSA 和 ECC 等传统加密算法的时间表，凸显了升级到后量子密码学的紧迫性。
  2. Cloudflare Zero Trust 平台通过无客户端访问 (Clientless Access)、WARP 客户端和 Gateway 等组件，提供端到端的后量子加密保护 Cloudflare 的 Zero Trust 平台通过无客户端访问 (Clientless Access) 保护内部 Web 应用，WARP 客户端保护任何协议，Gateway 保护对第三方 Web 应用的访问，为企业提供端到端的后量子加密保护，无需对每个应用单独升级。
  3. 迁移到后量子密码学可应对“先收集后解密”的攻击 即使目前量子计算机无法破解传统加密，攻击者仍可能先收集加密数据，待未来量子技术成熟后再解密，因此提前部署后量子密码学至关重要。

💬 文章金句

  • 超过 35% 的通过 Cloudflare 的非机器人 HTTPS 流量是后量子安全的。
  • 我们认为隐私是一项基本人权，先进的密码学应该在不妥协的情况下让所有人都能使用。
  • 只需通过 Cloudflare 的量子安全连接传输您的流量，即可立即防范“先收集后解密”的攻击，而无需自己升级每个加密库。
