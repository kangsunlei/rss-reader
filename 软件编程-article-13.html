防止 React Router 漏洞 CVE-2025-31137 - Vercel

4/17/2025, 1:00:00 PM

📌 一句话摘要

Vercel 声明其平台不受 React Router 漏洞 CVE-2025-31137 的影响，并建议用户升级到最新版本。

📝 详细摘要

Vercel 发布声明，指出安全研究人员在 Remix Web 框架中发现的 React Router 漏洞 CVE-2025-31137，该漏洞允许通过 `Host` / `X-Forwarded-Host` header 进行 URL 操纵。经过调查，Vercel 确认其平台和客户不受此漏洞影响，原因是 Vercel 通过 query 缓存来防止该漏洞。此外，Vercel 还限制了 `X-Forwarded-Host` 的转发。Remix 2.16.3 / React Router 7.4.1 中已发布安全补丁，建议客户更新到最新版本。

💡 主要观点

  1. Vercel 平台不受 React Router 漏洞 CVE-2025-31137 的影响。 Vercel 的缓存机制有效防御该漏洞。同时，终端用户也无法将任意 `X-Forwarded-Host` 转发到 Function。
  2. Remix 2.16.3 / React Router 7.4.1 已发布补丁。 建议使用 React Router 和 Remix 框架的客户尽快升级到最新版本，以修复 CVE-2025-31137 漏洞。

💬 文章金句

  • Our investigation determined that Vercel and our customers are unaffected
  • We use query as part of the cache key， which protects against cache poisoning driven by the `_data` query praram.
  • A patch has been issued and released in Remix 2.16.3 / React Router 7.4.1. We recommend customers update to the latest version.
