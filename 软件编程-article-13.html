Node.js v22.15.0 长期支持版本发布，主要关注安全增强、性能优化和新功能，以及多个依赖项的更新和问题修复。

📝 详细摘要

Node.js v22.15.0 'Jod' (LTS) 现已可用，包含多个值得关注的更新。断言模块包括部分错误比较和改进的 `partialDeepStrictEqual`，以增强测试的灵活性和性能。CLI 现在允许在 `NODE_OPTIONS` 中使用 `--cpu-prof*`，从而帮助进行 CPU 性能分析。密码模块将根证书更新到 `NSS 3.108` 并支持 macOS 系统证书，从而提高应用程序安全性。此外，DNS 模块引入了 TLSA 记录查询和解析（传输层安全认证机构记录）。主要依赖更新包括 `zstd 1.5.6`、undici、sqlite 和 openssl，整合了新功能和错误修复。此长期支持版本强调稳定性和长期支持，使其成为生产环境的可靠选择。

💡 主要观点

  1. 断言模块增强功能提高了测试的灵活性和性能 部分错误比较和改进的 `partialDeepStrictEqual` 方法提供了更灵活和高效的断言能力。
  2. 密码模块增强了安全性和证书管理，包括 macOS 系统证书支持和根证书更新到 `NSS 3.108` 这些更新加强了 Node.js 应用程序的安全性，并简化了跨不同平台的证书处理。
  3. CLI 工具增强功能有助于 CPU 性能分析 在 `NODE_OPTIONS` 中使用 `--cpu-prof*` 的能力为开发人员提供了更方便的 CPU 性能分析选项。
  4. 依赖更新引入了新功能和性能优化 对 zstd、undici、sqlite 和 openssl 的更新提供了对新功能、错误修复和性能改进的访问。
