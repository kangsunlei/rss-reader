Pulumi 新增对 Terraform 和 HCL 的原生支持

1/17/2026, 8:00:00 AM

📌 一句话摘要

Pulumi 现在提供对 Terraform 和 HCL 的原生支持，允许直接执行 HCL 并托管 Terraform 状态，在市场变化中将自身定位为多样化 IaC 环境的统一平台

📝 详细摘要

Pulumi 通过增加对 HashiCorp Terraform 和 OpenTofu 的原生支持显著扩展了其平台功能，现在可以在 Pulumi Cloud 中直接执行 HCL 并托管 Terraform 状态。这一举措是 Pulumi 的战略转变，该公司此前专注于使用通用编程语言进行基础设施即代码（IaC）。这些功能目前处于私有测试阶段，旨在帮助组织迁移遗留代码，并应对 IBM 收购 HashiCorp 及其许可证变更带来的担忧。Pulumi 首席执行官 Joe Duffy 强调了企业中混合工具环境的普遍需求。在技术层面，Pulumi Cloud 现在可以作为 Terraform/OpenTofu 的状态后端，提供治理和 AI 智能体访问功能，而 Pulumi CLI 将 HCL 作为一等语言支持，通过 Terraform 桥接器进行解释。这使得团队可以维护 HCL 代码库，同时利用 Pulumi 的编排能力和庞大的提供商生态系统。Pulumi 还推出了财务激励计划以简化迁移。这一集成使 Pulumi 在竞争激烈的 IaC 市场中成为统一平台，管理包括行业标准 Terraform 和开源 OpenTofu 在内的各种格式

💡 主要观点

  1. Pulumi 现在原生支持 Terraform 和 HCL，打破了此前对通用编程语言的独家专注 这一战略扩展允许用户通过 Pulumi 直接执行 HCL，并在 Pulumi Cloud 中管理 Terraform 状态，迎合更广泛的市场需求并解决遗留集成挑战
  2. 该集成为混合 IaC 环境提供了统一的操作平面，应对 HashiCorp 收购等市场变化 Pulumi 旨在为不愿完全从 Terraform 迁移的组织或担心近期许可证变更的组织减少摩擦，提供统一的治理和管理平台
  3. 技术实现包括将 Pulumi Cloud 作为 Terraform 状态后端，并将 HCL 作为 Pulumi CLI 中的一等语言 这使得可以维护现有的 HCL 代码库，同时利用 Pulumi 的编排能力及其提供商生态系统（包括其 AI 工程智能体 Neo）的访问权限
  4. Pulumi 提供财务'逃生舱'计划以激励从 HashiCorp 合同的迁移 客户可以将其剩余的 HashiCorp 合同价值等值的积分用于 Pulumi 使用，减轻转型的财务负担

💬 文章金句

  • Pulumi 通过宣布对 HashiCorp Terraform 和 OpenTofu 的原生支持，显著扩展了其平台范围
  • '我们对语言并不教条，我们热爱所有语言，'Duffy 表示。'HCL 和 YAML 中的 L 代表"语言"，我们一直秉持"来者不拒"的心态。一旦我们看到某个语言有足够的市场需求，我们就会添加它。嗯，HCL 的这个时刻已经到来'
  • 首先，Pulumi Cloud 现在可以作为 Terraform 和 OpenTofu 的状态后端和管理平面，直接与 HashiCorp Terraform Cloud 竞争
  • 其次，Pulumi CLI 现在将 HCL 作为一等语言支持。这使得引擎能够使用 Terraform 桥接器访问提供商来解释 HCL 代码
