CSS 全新属性如何实现一个内凹圆角

6/16/2025, 12:30:00 AM

📌 一句话摘要

介绍 CSS 新属性`shape()`，对比`path()`，详解语法及实现内凹圆角等不规则图形。

📝 详细摘要

文章详细介绍了 CSS 新的`shape()`函数，作为`clip-path`和`offset-path`属性的新值。对比了`shape()`与现有的`path()`函数的优劣，重点阐述了`shape()`支持 CSS 标准语法、百分比单位、变量和数学函数等优势，使其具备更好的响应性和灵活性，解决了`path()`在适应不同尺寸比例时的限制。文章通过简单的矩形、三角形、圆弧示例逐步讲解`shape()`的`from`， `line`， `hline`， `vline`， `arc`等命令语法和用法。最后展示了利用`shape()`实现 Chrome 选项卡和内凹圆角等复杂不规则图形的实践案例，并提及当前的浏览器兼容性（主要限于 Chrome 135+）。

💡 主要观点

  1. shape()函数比 path()更灵活强大 shape()支持 CSS 标准语法，如百分比、变量、calc()等，解决了 path()仅限 px 单位的痛点，提升了不规则图形的响应性和适应性。
  2. shape()通过命令组合定义任意复杂形状 利用 line， arc 等基础命令，可以像 SVG 路径一样绘制复杂的闭合形状，实现各种创意性的 UI 效果。
  3. shape()结合 CSS 变量实现灵活图形 通过 CSS 变量定义半径等参数，可以方便地调整形状，实现内凹圆角等需要计算的图形效果。

💬 文章金句

  • shape() 函数使用一组大致等同于 path() 所用命令的命令，但它使用的是更标准的 CSS 语法，并且允许使用完整的 CSS 功能，例如 pxrem%单位和数学函数
  • 从这个意义上说，shape() 是 path() 的超集。
  • 我们使用 shape()可以适配不同比例以及不同大小，而使用 path()由于不支持百分比只能按照最初的大小展示！
  • shape()需要 chrome >= 135 才有效果！
  • shape 其实是可以和 border-radius 结合来使用的
