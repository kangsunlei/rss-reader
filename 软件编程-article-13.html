Cloudflare 年度回顾：AI 机器人疯狂爬网、后量子加密普及率达 50%、Go 语言用户翻倍

1/8/2026, 5:25:00 AM

📌 一句话摘要

Cloudflare 年度报告揭示了 2025 年互联网的关键趋势，包括全球流量增长、AI 机器人爬取激增、后量子加密普及率达 50%，以及 Go 语言在 API 客户端中的应用翻倍。

📝 详细摘要

Cloudflare 发布了第六版 Radar 年度回顾报告，基于其庞大的基础设施数据，深入分析了 2025 年的互联网格局。报告显示全球互联网流量同比增长 19%，其中 Googlebot 仍然是最大的爬虫来源，且 AI 平台的爬取引流比持续攀升，表明 AI 机器人对内容的“饥渴”。在安全方面，为了防范“先收集、后解密”攻击，人类 Web 流量中采用后量子加密技术的比例已达 50%，几乎翻倍。在技术栈方面，jQuery 和 React 依然是前端主流，而 PHP、Node.js 和 Java 仍是最常用的后端语言。值得注意的是，Go 语言在 API 客户端中的采用率激增，自动化 API 请求中 Go 语言客户端已占 20% 以上。报告还指出，2025 年有 174 次重大互联网中断事件，近半数是计划内停机，DDoS 攻击的频率和规模也日益增长。

💡 主要观点

  1. AI 机器人爬取行为激增，但未带来相应流量回馈。 Googlebot 仍是最大的网络爬虫，而 OpenAI 和 Anthropic 等 AI 平台的爬取引流比非常高，表明 AI 对内容的需求旺盛，但并未有效反哺原始网站流量。
  2. 后量子加密技术应用普及率显著提升，以应对未来安全挑战。 采用后量子加密技术的 Web 流量占比已达 50%，这对于防御“先收集、后解密”的量子攻击至关重要，显示了互联网在安全协议升级方面的快速进展。
  3. Go 语言在自动化 API 客户端中的采用率迅速增长。 Go 语言在自动化 API 请求中的占比从去年的 12% 翻倍至 20%，体现了其在构建高性能、高并发 API 客户端方面的日益普及和优势。
  4. 互联网中断事件与网络攻击持续高发，凸显网络环境的复杂性。 2025 年发生了 174 次重大互联网中断事件，且超大规模网络层 DDoS 攻击的频率和规模不断增长，表明互联网基础设施面临持续的挑战和压力。

💬 文章金句

  • 2025 年，Googlebot 再次成为 Cloudflare 请求流量的最大来源，它爬取了数百万个 Cloudflare 客户网站用于搜索索引和人工智能训练。
  • 内容饥渴的 AI 爬虫（仅 Googlebot 就占所有 HTML 请求量的 4.5%，“用户操作”爬取量激增 15 倍），超过半数人类 Web 流量采用了后量子加密技术，以及 174 次重大互联网中断事件。
  • Meta 的 llama-3-8b-instruct 模型在其边缘 AI 平台 Workers AI 上最受欢迎。该平台支持在网络边缘直接运行 AI 模型，其中最热门的任务类型是文本生成。
  • 在构建 API 客户端最常用的编程语言排名中，20% 的自动化 API 请求来自基于 Go 的客户端，与 Go 语言 2024 年 12% 的份额相比增长显著。
  • Cloudflare 的 Radar 年度回顾不仅是数据统计，更是互联网真实面貌的压力测试报告——它揭示了网络环境的脆弱、快速以及机器人泛滥的现状。
