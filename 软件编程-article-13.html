把 80+ 项音视频能力装进 Claude Code 后，我合上了 FFmpeg 手册

11/18/2026, 10:00:00 AM

📌 一句话摘要

作者通过 Claude Code 调用火山引擎 AI MediaKit Skill，实测了画质增强、字幕擦除、智能剪辑等 80 项音视频能力，展示了 Agent 化处理在干视频生产中的实用价值与成本效益。

📝 详细摘要

本文作者尝试使用火山引擎 AI MediaKit Skill 通过 Claude Code 实现音视频处理，实测了三个核心场景：480p 老视频提升至 1080p（耗时 3 分 45 秒，体积增至 3.4 倍），字幕擦除（标准版 0.4 元/分钟、精细化版 1 元/分钟，分别耗时 4 分 18 秒和 6 分 35 秒），以及剪辑和智能剪辑。文章详细介绍了 AI MediaKit 的三层架构：80 项原子能力、mediakit-cli 命令行工具和 5 个 Agent Skill。作者指出，双模设计（本地 FFmpeg + 云端算力）实现成本可控，鉴权极简，适合开发者批量处理、自媒体二创及团队快速集成音视频能力。

💡 主要观点

  1. AI MediaKit Skill 通过三层架构实现 Agent 化音视频处理 80 项原子能力覆盖视频、图像、音频三模，mediakit-cli 封装为终端命令，5 个 Agent Skill 按 Claude Code 规范包装，实现自然语言指令到自动执行的闭环。
  2. 双模设计（本地+云端）降低成本并提升灵活性 本地模式走 FFmpeg，零成本同步即时；云端模式处理高阶任务，两边共享同一套参数设计，支持本地裁剪后直接喂给云端增强，实现流水线式无人值守。
  3. 实测显示 Agent 化处理在批量场景下具备显著效率优势 字幕擦除、画质增强等任务耗时与视频时长成正比（5~9 倍 RTF），适合挂机、批量处理；而手动 FFmpeg 或剪映在学习成本和批量效率上均有明显不足。
  4. 按量计费模式需用户心理预期和成本控制 字幕擦除标准版 0.4 元/分钟、精细化版 1 元/分钟，产出文件体积显著增大（7 倍以上），需配合转码或自有存储，批量使用前需做好成本预估。

💬 文章金句

  • 把这个视频里的字幕擦掉。
  • AI MediaKit 是火山引擎智能处理产品线下的能力集合，背后是字节系视频业务的算法沉淀------抖音那套亿级日处理量磨出来的画质增强、字幕擦除、高光识别。
  • 80 项能力没法全试，收尾前又顺手点了三个，还是同一套短剧 demo：人声分离、语音转字幕、图像抠图。
