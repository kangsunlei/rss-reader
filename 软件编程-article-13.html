你的 Mac 就是一个 AI Agent，4B 模型本地操控电脑。

5/7/2026, 4:53:00 AM

📌 一句话摘要

本文介绍了明略科技开源的 Mano-P 端侧 GUI Agent 模型和 Cider 推理加速框架，展示了在 Mac 本地运行 AI Agent 操控电脑的能力。

📝 详细摘要

文章详细介绍了明略科技开源的两个项目：Mano-P 和 Cider。Mano-P 是一个 4B 参数的 GUI-VLA 模型，能够纯视觉理解桌面界面，像人类一样操作 Mac 上的任何软件，所有数据在本地处理，不上传云端。Cider 是基于 Apple MLX 生态的推理加速框架，通过调用 Metal 4 API 实现硬件加速的 INT8 TensorOps 计算，可将 MLX 模型推理速度提升 1.4-1.9 倍。文章还展示了 Mano-P 在自动化应用构建、商业视频智能系统等场景的应用，并与 Claude Computer Use 进行了对比，强调了端侧方案在隐私和成本方面的优势。

💡 主要观点

  1. Mano-P 是一个纯视觉的端侧 GUI Agent 模型，可在 Mac 本地操控任何软件界面。 该模型不依赖 CDP 协议或 HTML 解析，直接通过屏幕截图理解界面并执行操作，覆盖桌面软件、专业工具和 3D 应用，数据完全在本地处理。
  2. Cider 推理加速框架基于 MLX 生态，通过 Metal 4 API 实现硬件加速的 INT8 量化计算。 Cider 补齐了 MLX 缺失的 W8A8 和 W4A8 激活量化能力，在 W8A8 模式下算子速度比 MLX 原生提升 1.4x 到 1.9x，且接入方式简单，一行代码即可替换模型 Linear 层。
  3. 端侧 GUI Agent 在隐私敏感和成本控制场景中具有显著优势。 与 Claude Computer Use 等云端方案相比，Mano-P 虽然综合准确率较低（58.2% vs 72.1%），但数据不出设备、不消耗 API token，适合企业内部系统测试和敏感数据处理。

💬 文章金句

  • Mano-P 是一个 GUI-VLA 模型，说白了就是用纯视觉的方式理解和操作图形界面。
  • Cider 通过调用 Apple 底层 Metal 4 API，首次在 Apple GPU 上实现了硬件加速的 INT8 TensorOps 计算。
  • Mano-P 把这部分开销直接归零，不调 API，不传截图，不花一分钱。
