Hugging Face 将开源 LLM 集成到 VS Code 的 GitHub Copilot Chat 中

9/17/2025, 9:55:00 AM

📌 一句话摘要

Hugging Face 将其推理服务提供商与 VS Code 中的 GitHub Copilot Chat 集成，使开发人员能够直接在编辑器中使用各种开源 LLM。

📝 详细摘要

本文详细介绍了 Hugging Face 的新集成，旨在将开源大语言模型与 Visual Studio Code 中的 GitHub Copilot Chat 直接连接起来。这项重大更新使开发人员能够访问和试验各种开源 LLM，例如 Kimi K2、DeepSeek V3.1 和 GLM 4.5，所有这些都在他们熟悉的 VS Code 环境中进行，无需在平台之间切换或管理多个工具。该集成简化了开发人员的工作流程，用户只需安装 Hugging Face Copilot Chat 扩展，配置其 Hugging Face 令牌，然后从统一的界面中选择所需的模型。对于用户来说，一个重要的实用注意事项是需要 VS Code 2025 年 8 月 1.104.0 版本。此举使 GitHub Copilot Chat 摆脱了之前对封闭的专有模型的依赖。它提供了对实验性和高度专业化的开放模型的访问，从而增强了开发人员的灵活性和选择。核心价值在于统一，提供一致的 API 来查询跨各种提供商的模型，确保即时访问前沿 AI，促进零供应商锁定，并提供生产就绪的推理性能。Hugging Face 还通过每月免费的推理信用额度以及 Pro、团队和企业计划的透明定价来确保可访问性。

💡 主要观点

  1. Hugging Face 的新集成使开发人员可以直接在 VS Code 中的 GitHub Copilot Chat 中访问开源 LLM。 这打破了对专有模型的依赖，为开发人员提供了前所未有的灵活性，可以从各种专门的和实验性的开源 AI 模型中进行选择，以完成编码任务。
  2. 该集成通过统一的界面访问各种 LLM 推理服务。 开发人员可以查询来自多个提供商的模型，而无需管理不同的 API，从而降低了复杂性，最大限度地减少了供应商锁定，并确保了一致的、生产就绪的性能。
  3. 通过将先进的 AI 功能引入熟悉的 IDE 环境，从而增强了开发人员的选择和工作流程效率。 将先进的 AI 功能引入熟悉的 IDE 环境，增强了开发人员的选择和工作流程效率。
