Anthropic 推出 Claude 4 系列及 Claude Code

6/3/2025, 12:00:00 AM

📌 一句话摘要

Anthropic 发布 Claude 4 Opus 和 Sonnet 模型，声称在编码基准测试中达到业界领先水平，并推出 Claude Code 编程助手。

📝 详细摘要

Anthropic 发布了 Claude 4 Opus 和 Sonnet 4，这是其大语言模型的最新迭代版本。这些是“混合”模型，支持快速响应和“深入思考”，并增强了工具使用能力（并行执行、利用本地文件）。它们在代理任务性能方面也显示出显著改进（使用捷径的可能性降低 65%）。Claude 4 Opus 在 SWE-bench (72.5%) 和 Terminal-bench (43.2%) 等编码基准测试中取得了业界领先的结果。除了模型之外，Anthropic 还宣布其专用编程助手 Claude Code 全面可用，并为 JetBrains 和 VS Code 提供了测试版扩展。此次发布包括广泛的安全性测试，激活了 AI 安全等级 3 (ASL-3) 保护措施，尽管承认可能存在罕见的“极端行为”。行业反应褒贬不一，但也包括开发者对实际编码可用性的积极反馈。

💡 主要观点

  1. Claude 4 模型具备深入思考和改进的工具使用能力。 新模型可以进行多步推理，并行执行多个工具，并利用本地文件作为记忆，从而增强了处理复杂任务的能力。
  2. Claude Opus 4 为编码性能设定了新的业界领先基准。 Opus 4 在 SWE-bench 和 Terminal-bench 上取得高分，表明其在自动化代码生成和问题解决方面比其他模型具有更强的能力。
  3. Anthropic 推出专用编程助手 Claude Code，并支持 IDE 集成。 Claude Code 及其针对 VS Code 和 JetBrains 等流行 IDE 的测试版扩展的发布，旨在为开发者提供强大的 AI 结对编程伙伴。
  4. 此次模型发布伴随着增强的安全措施，包括激活 ASL-3。 Anthropic 通过实施更高的安全标准和广泛的测试，继续专注于负责任地扩展 AI，尽管承认存在潜在风险。
