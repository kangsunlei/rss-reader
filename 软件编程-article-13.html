📝 详细摘要

本报告详细介绍了一起针对 Axios JavaScript 库（一种广泛使用的 HTTP 请求工具）的严重供应链攻击。攻击者破坏了该 npm 包，注入了一个名为“plain-crypto-JS”的恶意依赖，该依赖通过执行“postinstall”脚本来部署远程访问木马（RAT）。该恶意软件能够窃取包括 AWS 和 OpenAI API 密钥在内的敏感凭证，随后清除痕迹以逃避检测。文章为开发者提供了可操作的步骤，用于审计项目、检查恶意包并执行必要的安全补救措施。

💡 主要观点

  1. 通过恶意依赖进行的 Axios 供应链攻击。 攻击者通过名为“plain-crypto-JS”的流氓依赖注入了一个“postinstall”脚本，该脚本会在开发者机器上下载并执行 RAT，从而绕过标准安全检查。
  2. 隐蔽执行与清理以逃避检测。 该恶意软件利用 npm 安装生命周期运行，随后删除包括“postinstall”脚本在内的自身痕迹，导致通过“npm audit”进行检测失效。
  3. 对受感染系统进行立即补救至关重要。 开发者必须手动检查“package.json”和“node_modules”以查找恶意包；如果发现，应视系统已完全被入侵，需要彻底重置所有 API 密钥和令牌。
