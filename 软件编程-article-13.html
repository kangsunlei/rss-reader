OpenRouter 集成 Claude Code 并提供免费模型

12/20/2025, 6:47:51 AM

📌 一句话摘要

OpenRouter 平台现已支持 Claude Code 模型，并提供超过 320 个大语言模型（含 39 个免费模型）用于编程，结合 CC Switch 使用体验更佳。

📝 详细摘要

该推文分享了 OpenRouter 平台的一项重要更新，即已集成 Claude Code 模型。这意味着开发者现在可以通过 OpenRouter 访问由 Anthropic 开发的 Claude Code，一个专注于代码生成和理解的强大 AI 模型。推文还强调 OpenRouter 提供了超过 320 种大型语言模型供编程使用，其中包含 39 个免费模型，并建议结合 CC Switch 工具来最大化免费模型的效用，为编程工作流带来便利和成本效益。
