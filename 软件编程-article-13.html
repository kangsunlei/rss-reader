📌 一句话摘要

本期周刊涵盖了前端领域的重要更新，包括 TypeScript 的 Rust 移植、Deno 的遗产、ViteConf 2026 的亮点、Bun 的 AOT 编译进展、Node.js 的安全更新，以及多个新版本库的发布。

📝 详细摘要

在行业动态方面，Cloudflare 和 VoidZero 合作推出了 tsrs，一个基于 Rust 的 TypeScript 编译器，性能显著提升。Deno 团队虽然加入 Cloudflare，但其对 JavaScript 生态的推动作用被广泛认可。Safari 引入了新的隐私保护措施，而 Core Web Vitals 开始实验性地纳入软导航数据。安全方面，Next.js 修复了两个高危漏洞，Node.js 也发布了多个版本的安全更新。文章部分，Jake Archibald 比较了 JPEG XL 和 AVIF 的性能，Nolan Lawson 探讨了 Web Components 的未来，而 Miro 则分享了其从 Jest 到 Vitest 的大规模测试迁移经验。工具和库方面，推出了用于调试滚动动画的 Chrome 扩展、免费的无障碍检查器 pour、以及新的图表库 Chartist 2.0 和地图库 Maplair 4.0。

💡 主要观点

  1. tsrs：TypeScript 的 Rust 移植 Cloudflare 和 VoidZero 基于 Rust 重写了 TypeScript 编译器，性能最高提升至原版的 8 倍，并支持在 WebAssembly 中运行。该项目已进入实验阶段，并计划并入 Oxc。
  2. Deno 的遗产 尽管 Deno 团队已加入 Cloudflare，但其对 JavaScript 生态的贡献被广泛认可。Deno 和 Bun 的出现推动了 Node.js 和 npm 的改进，例如引入了更好的包管理和模块系统。
  3. ViteConf 2026 亮点 ViteConf 2026 涵盖了多场演讲，包括 Evan You 关于 agent 时代工具链的 keynote，以及 Vitest 5 和 Vite DevTools 的更新。大会还介绍了 Oxc 中更快的解析器。
  4. Bun 的 AOT 编译 Bun 宣布了 AOT（Ahead-of-Time）编译的进展，允许将 JavaScript 直接编译为不包含 JIT 的二进制文件。这一功能将显著提高启动速度，并适用于受限的运行环境。
  5. Node.js 安全更新 Node.js 发布了 26.12、24.22 和 22.14 版本，修复了多个安全漏洞，包括一个高危的 DNS 解析漏洞。这些更新还包括对 ES 模块同步加载的改进。

💬 文章金句

  • TypeScript 团队也给了意见，成果会并入 Oxc。
  • Deno 和 Bun 一起，逼着 Node 和 npm 把那些好点子一个个学了过去。
  • Safari 里早就不让跨站 Cookie 了，于是追踪方换了个路子：做『身份解析』。
  • 升到 16.4.1 或 15.5.28，公开的 PoC 已经放出来了。
