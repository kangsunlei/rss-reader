Vercel AI SDK 增加 Telegram 支持，实现通用 Agent 部署

2/27/2026, 7:54:41 PM

📌 一句话摘要

Vercel 的 Chat SDK (AI SDK) 现已支持 Telegram，为在多个聊天平台部署 AI Agent 提供通用 API。

📝 详细摘要

Vercel 首席执行官 Guillermo Rauch 宣布，其 AI SDK（原 Chat SDK）现已初步支持 Telegram。此次更新被视为迈向 AI Agent 通用 API 的重要一步，允许开发者构建“OpenClaw 风格”的体验，即界面完全基于聊天。通过使用全新的 `createTelegramAdapter()`，开发者可以无缝地将现有的机器人扩展到 Telegram 生态系统，简化了跨平台的 Agent 开发工作。
