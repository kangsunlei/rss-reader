📌 一句话摘要

Claude Context 利用 MCP 插件和语义搜索技术，解决 AI 编程工具在大项目中的上下文窗口限制及 Token 消耗问题。

📝 详细摘要

该推文介绍了 GitHub Trending 榜首项目 Claude Context。该工具通过 MCP 插件为 AI 编程助手提供全代码库语义搜索能力，避免将整个项目塞入上下文。其核心技术包括基于语法树的智能代码切分和增量索引。测试显示，在保持检索质量的同时可减少约 40% 的 Token 消耗，且兼容 Claude Code、Cursor、VS Code 等主流工具，非常适合处理大型项目的开发者。
