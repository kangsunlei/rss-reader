全球最流行 MCP 应用市场，来自一位中国独立开发者

5/10/2025, 2:39:00 AM

📌 一句话摘要

介绍中国独立开发者艾逗笔及其开发的全球最大 MCP 应用市场 MCP.so，以及他对 MCP 协议及其在 AI 时代应用前景的展望。

📝 详细摘要

文章介绍了前腾讯工程师、全栈开发者艾逗笔（idoubi）独立开发的 MCP 应用市场 MCP.so。该市场收录了超过 10000 个 MCP Server，支持网页直接调用 AI 工具、在线调试和集成 Chat 能力，是全球最大的 MCP 应用市场。文章还分享了艾逗笔对 MCP 协议走红的看法，他认为这是 AI 发展的必然产物，类似于 Web 时代的 HTTP 协议。此外，文章还探讨了独立开发者在 AI 时代的机会，艾逗笔认为 AI 加速了生产力，使得独立开发者能够以最小的成本实现最大的产出，并快速试错。最后，文章预告了艾逗笔将在 AICon 全球人工智能开发与应用大会上分享关于独立开发和 AI 产品经验。

💡 主要观点

  1. 独立开发者在 AI 时代拥有更多机会，可以快速试错 AI 加速生产力，独立开发者可以不断试错，用最小的成本实现最大的产出，具有明显的杠杆效应。
  2. MCP 协议是 AI 发展的必然产物，加速各类服务 AI 化 MCP 协议的出现，让 AI 智能体集成各种数据与功能变得规范，类似于 Web 时代的 HTTP 协议，将推动 AI 生态的快速发展。
  3. MCP.so 将开放 API，并部署更多服务到云端，方便用户体验各类 MCP 服务，同时举办开发者大赛，吸引更多开发者 MCP.so 计划部署更多服务到云端，方便用户体验各类 MCP 服务，同时开放 API 给更多客户端接入，并通过开发者大赛来丰富 MCP 服务。

💬 文章金句

  • 大势所趋，AI 发展的必然产物。就跟 web 时代 http 协议发布之后，互联网生态迅速发展类似的趋势，MCP 协议的出现，让 AI 智能体集成各种数据与功能变得规范，会加速各类服务 AI 化。
  • 独立开发者在 AI 时代的机会比过去多了很多，太多可以做的方向，靠 AI 加速生产力，再开发各种类型的 AI 产品，闭环了。
  • 主要的优势是独立开发可以做得快，可以不断试错，可以用最小的成本实现最大的产出，杠杆效应明显。
