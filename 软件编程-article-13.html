本文聚合了 Hacker News 当日十条高热度讨论，每条均附官方来源、社区评论要点与证据边界说明。DeepSeek 发布 DeepInfer 开源推理框架，支持 V4.1 Flash、NVIDIA SM100 与昇腾 950，但当前仅提供离线推理，完整在线服务所需组件未包含；Redact 检查 545 个 WhatsApp 帮助页，发现 80 页含 102 个隐藏 AI 指令，Meta 称其原供客服机器人使用，页面暴露源于已修复错误；eMudhra 八个中间 CA 因密钥生成缺陷可被恢复，主流浏览器已封锁，但大量命令行工具与运行时仍需各自更新信任数据；DHS 公开 DeepSeek 排除命令，适用于联邦民事机构及相关第三方，60 天为申请例外期限而非统一移除宽限期；MiniMax M3.1 Flash API 计费为输入 0.15、输出 0.60、缓存输入 0.015 美元/百万 token，中位速度超 170 token/秒，但权重尚未发布；po-ru.com 作者归档 Ruby gems，批评 Ruby 社区拥抱 LLM 削弱创作乐趣；教师报告 iPadOS 27 AirPlay 多窗口行为暴露整屏，打断课堂演示；OpenBSD 8.0 发布，加入每虚拟机最多 64 vCPU、arm64 休眠支持及 amd64 内核地址空间扩展；Ashley Gullen 称 Facebook 主页每月超两条外链需订阅至少 50 美元，但适用范围未独立核实；Cretezy 用 Projectivy、SmartTube 等整理无广告 Android TV。

💡 主要观点

  1. DeepSeek 开源 DeepInfer 推理框架，但离线版本不包含完整在线服务所需组件，部署仍需额外工作。 DeepInfer 支持 DeepSeek-V4.1-Flash、NVIDIA SM100 和昇腾 950，提供优化内核和并行计算，但当前仅提供离线推理，缺少 KV 缓存系统、VE/Prefill/Decode 拆分部署及负载均衡，运行依赖 Linux、Python 3.12 及特定 CUDA 或 CANN 环境，不能直接替换现有服务。
  2. WhatsApp 帮助页隐藏 AI 指令，Meta 解释为客服机器人指令，但暴露了内部指令公开的风险。 Redact 检查 545 个帮助页，发现 80 页含 102 个隐藏文本块，包括不推荐监管机构和不引用法律文件等限制。Meta 称这些是客服机器人指令，因错误公开已修复，但未证实实际影响，也未说明隐藏文本存在时间及语言覆盖，区分了发现指令与证明实际操控结果两个证据层次。
  3. eMudhra 中间 CA 密钥生成缺陷可被恢复，浏览器已封锁，但非浏览器客户端仍需单独更新信任数据。 八个中间 CA 私钥因生成错误可从公开证书恢复，Firefox、Chrome 已封锁，Apple 设备随后措施，但许多命令行工具、语言运行时和软件包不消费相同撤销信息，仍需更新自身信任数据，缺陷自 2025 年 4 月存在，未确认攻击者是否实际利用。
  4. DHS 禁止联邦民事机构使用 DeepSeek，60 天是申请例外期限而非统一移除宽限期。 DHS 要求美国民用政府机构从 IT 系统中移除 DeepSeek 产品及第三方服务，禁止采购，称存在多重威胁向量，担心敏感数据转移和情报搜集。命令涵盖联邦民事机构及相关第三方，60 天是申请例外期限，不能理解为所有机构统一移除宽限期，也不适用于私人用户。
  5. MiniMax M3.1 Flash API 价格低廉，但权重尚未发布，独立验证不足。 M3.1 Flash 定位智能体工作流，API 每百万 token 输入 0.15 美元、输出 0.60 美元、缓存输入 0.015 美元，中位速度超 170 token/秒，但厂商数据未独立验证，权重尚未发布，整体任务成本下降与单项单价变化不同口径，需按真实请求组成计算。

💬 文章金句

  • 当前提供的是离线推理，完整在线服务所需的 KV 缓存系统、VE/Prefill/Decode 拆分部署及副本间负载均衡并未包含。
  • 浏览器恢复安全不能代表同一机器上的所有 HTTPS 客户端都已修复。
  • 60 天是申请例外期限，而非统一移除宽限期。
  • 整体任务成本下降与输入、输出、缓存各项单价变化是不同口径，需要按真实请求组成计算。
  • 这是特定多任务投影工作流的用户报告，不能据此推断所有 iPad 演示均已不可用。
