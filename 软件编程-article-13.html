📌 一句话摘要

文章详细介绍了一种利用 SVG 滤镜实现全新、复杂且高交互性的点击劫持攻击技术——“SVG Clickjacking”，并演示了其在数据泄露和绕过传统防御方面的潜力。

📝 详细摘要

文章提出并详细阐述了“SVG Clickjacking”这一新型网络攻击技术，它利用 SVG 滤镜的强大图像处理和组合能力，实现了比传统点击劫持更复杂、更具交互性且难以察觉的攻击。作者首先通过“液态 SVG”效果的意外发现，引出了 SVG 滤镜在跨域 iframe 中生效的可能性。随后，文章深入分析了多个 SVG 滤镜元素（如 feDisplacementMap、feComposite、feBlend 等）的功能，并逐步演示了如何利用它们实现数据泄露（如伪造验证码）、UI 重塑（隐藏灰色文本）以及最关键的像素读取和逻辑门构建。通过构建逻辑门，攻击者可以在 SVG 滤镜内部实现“编程”般的复杂逻辑判断，从而执行多步骤、条件化的点击劫持攻击，甚至成功攻击了 Google Docs。最后，文章探讨了二维码攻击，展示了如何在 SVG 滤镜中生成动态二维码以悄无声息地窃取数据。这篇技术文章不仅揭示了一种新颖且强大的攻击手法，也强调了前端技术在安全领域的潜在风险，对于前端开发者和安全研究人员具有重要的参考价值。

💡 主要观点

  1. “SVG Clickjacking”是一种新型攻击，利用 SVG 滤镜在跨域 iframe 中实现复杂交互，颠覆传统点击劫持。 传统点击劫持受限于静态交互，而 SVG 滤镜可在不依赖 Canvas 和 Shader 的情况下，通过 feFilter 元素对跨域 iframe 内容进行视觉和逻辑层面的高复杂性操控，实现高级交互欺骗。
  2. SVG 滤镜可用于像素读取和构建逻辑门，实现条件化、多步骤的攻击逻辑。 通过 feTile、feComposite、feBlend 等滤镜元件，攻击者能读取特定像素颜色以判断目标状态，进而模拟逻辑门（如 AND、OR、NOT），在滤镜内部实现任意复杂的攻击流程，而非线性的单一点击。
  3. 该技术已成功实现在 Google Docs 上的攻击，并通过动态二维码攻击实现数据外传。 文章详细描述了利用 SVG 滤镜模拟复杂的 Google Docs 交互流程，诱导用户泄露信息，从而获得了漏洞奖励。此外，还展示了在 SVG 滤镜中动态生成包含窃取数据的二维码以绕过数据导出限制。

  • 理论上，你甚至可以在一个 SVG 滤镜中构建一台计算机。
