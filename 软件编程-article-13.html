📌 一句话摘要

Amper 0.6.0 发布，专注于提升 IDE 模板工作流程和 CLI `show` 命令组，以改善开发者体验。

📝 详细摘要

Amper 0.6.0 已发布，显著改善了 IDE 和 CLI 开发体验，旨在提高开发者效率。在 IDE 中，它通过提取和内联重构等功能增强了模板工作流程，为设置添加了便捷别名，并支持自动 Gradle 依赖转换。CLI 引入了用于项目检查的 `show` 命令组、交互式 `init` 命令、更清晰的日志和 Tab 自动补全。Amper 现在使用 Kotlin 2.1.20、Compose 1.7.3 和 kotlinx.serialization 1.8.0。本文指导用户更新现有项目并鼓励提供反馈。

💡 主要观点

  1. Amper 集成了最新的 Kotlin 和 Compose 版本。 采用 Kotlin 2.1.20 和 Compose 1.7.3 使开发者能够利用最新的语言特性和 UI 框架功能。
  2. Amper 0.6.0 专注于提高 IDE 和 CLI 开发效率。 通过改进的模板工作流程、便捷别名和自动依赖转换，简化了配置管理并提高了开发效率。
  3. `show` 命令组的引入增强了 CLI 的可用性。 集中了项目信息查看命令，使开发者能够快速访问模块、配置和任务详细信息，从而改善 CLI 交互体验。
  4. Tab 自动补全支持提高了开发效率。 在 `bash`、`zsh` 或 `fish` 中启用 Amper 命令的 Tab 自动补全，这有助于提高开发效率。

💬 文章金句

  • 模板允许您在多个模块之间共享通用配置。
  • 此版本向 IDE 添加了新的重构功能，使模板的使用更加容易。
  • 用于创建新项目的 `amper init` 命令现在提供可用模板之间的交互式选择，从而更容易上手。
