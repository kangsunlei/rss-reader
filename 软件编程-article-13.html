Docker Desktop for Mac：QEMU 将于 90 天后弃用

4/15/2025, 9:12:27 AM

📌 一句话摘要

Docker Desktop 将在 90 天后弃用 Apple Silicon Mac 上的 QEMU 虚拟化选项，建议用户尽快迁移到 Apple Virtualization Framework 或 Docker VMM。

📝 详细摘要

Docker 宣布将在 90 天后弃用 Apple Silicon Mac 上 Docker Desktop 的 QEMU 虚拟化选项，最终停止支持 QEMU。由于 Apple Virtualization Framework 和 Docker VMM 提供了更好的性能、稳定性和与 macOS 更新的兼容性，因此做出了此更改。用户可以手动切换到 Docker VMM (Beta) 或 Apple Virtualization Framework。在弃用后的 30 天内，QEMU 选项仍可在设置中使用，以解决迁移问题。建议用户在自动迁移前主动切换至较新的 VMM 选项。
