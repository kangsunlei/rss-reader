teardown：开源 Claude Code Skill 生成 3D 机械原理模拟器

11/5/2026, 1:00:06 PM

📌 一句话摘要

teardown 是一个开源 Claude Code Skill，能通过文字说明生成可交互的 3D 机械模型模拟器，支持 V8 发动机、塞斯纳飞机等示例。

💡 主要观点

  1. 文字到 3D 可视化转化 通过问答方式让 Claude 生成可拆解查看的 3D 模拟器，直观展示机械运行原理
  2. 交互式学习体验 支持逐帧录制 60fps 视频，配程序生成音效，适合科普视频素材和儿童教学
  3. 丰富的示例案例 包含 V8 发动机、塞斯纳飞机和海滩仿生养三个完整示例，可直接体验效果
  4. 离线 HTML 实现 整个模拟器为离线 HTML 页面，无需服务器，中央旋转机器，四周实时读数，按钮式部件拆解

💬 文章金句

  • teardown 这个开源的 Claude Code Skill 给了个更直观的办法，用大白话问它某台机器怎么工作，它会做出一个能拆开看的 3D 模拟器。
  • 整个模拟器就是一个离线 HTML 页面，机器在中间运转，四周面板显示实时读数。
  • 还能把讲解过程逐帧录成每秒 60 帧的视频，配上程序生成的音效。
