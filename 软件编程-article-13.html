React 中文周刊 #275 - TanStack 实验性 React 克隆、Next.js 安全更新

5/9/2026, 2:00:00 AM

📌 一句话摘要

本期 React 中文周刊汇总了 TanStack 实验性 React 克隆、Next.js 安全更新、Expo SDK 56 Beta 等本周热点，以及多篇技术文章和工具发布。

📝 详细摘要

本期周刊涵盖了 React 生态的多个重要动态。TanStack 创始人 Tanner Linsley 用 AI agent 实验性地重写了 React 公共 API，生成了一个约 9KB 的运行时，速度是原版 React 的 2-3 倍，但未正式发布。Next.js 发布了 2026 年 5 月安全更新，修复了与 RSC 相关的 DoS 漏洞，建议用户升级到 15.5.18 和 16.2.6 版本。Expo SDK 56 Beta 发布，重点提升了速度和稳定性。此外，还介绍了 TanStack Form、从 React 迁移到 Web Components 的实践、React Router 中的 Dialog 实现等文章，以及 MapLibre React Native、shadcn CLI 4.7、React DayPicker 10.0 等工具。生态方面，Node.js 26.0 和 26.1 发布，Rolldown 达到 v1.0 稳定版，Astro 预告了 v7 Alpha。

💡 主要观点

  1. TanStack 创始人实验性地用 AI 克隆了 React 公共 API，速度提升 2-3 倍。 Tanner Linsley 用一天时间通过 AI agent 生成了一个约 9KB 的 React 运行时，速度是原版 React 的 2-3 倍，但出于兼容性考虑未正式发布，仅限在 TanStack Start 中使用。
  2. Next.js 发布 5 月安全更新，修复 RSC 相关 DoS 漏洞。 Next.js 15.5.18 和 16.2.6 版本修复了与 React Server Components 相关的拒绝服务漏洞，所有 RSC 用户应同步升级 React 到 19.2.6 等版本。
  3. Expo SDK 56 Beta 发布，聚焦速度和稳定性提升。 新版本带来了更快的 iOS 构建和 Android 应用启动时间，并稳定了 Expo UI 中的 Jetpack Compose (Android) 和 SwiftUI (iOS) API。

💬 文章金句

  • Projecting React：Tanner Linsley 的实验性 React 克隆 --- 这位 TanStack 创始人花了一天时间用 AI agent 将 React 的公共 API 重生为一个约 9KB 的运行时，作用域限定在 TanStack Start 中。
  • Next.js 2026 年 5 月安全更新 --- 更多的安全问题是，但通过升级到 Next.js 15.5.18 和 16.2.6 可以快速解决。
  • Expo SDK 56 Beta 现已推出。速度和稳定性是亮点，包括更快的 iOS 构建、更快的 Android 应用启动时间。
