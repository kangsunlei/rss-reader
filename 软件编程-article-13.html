Strata：用游戏显卡在消费级硬件上跑 1250 亿参数大模型

10/18/2026, 12:00:05 PM

📌 一句话摘要

Strata 通过混合专家路由机制，让 RTX 5070 加 64GB 内存的普通游戏电脑以每秒 53 到 94 token 的速度运行 1250 亿参数的千问大模型。

📝 详细摘要

Strata 解决了一个看似不可能的任务：在仅有 12GB 显存的消费级游戏显卡上运行 1250 亿参数的千问大模型。其核心思路是利用混合专家（MoE）架构——模型由 24576 个小型专家组成，每个 token 仅激活其中约 10 个，将最常用的数千个专家放入显存，其余放入内存，CPU 辅助计算。作者用 RTX 5070 配 64GB 内存的普通游戏电脑实测，每秒生成 53 到 94 个 token，比阅读速度更快。项目已获得 2.6 万 Star，支持 Windows 和 Linux 安装，以及 Claude Code 和 Codex 接入，数据全程在本地处理。

💡 主要观点

  1. 混合专家架构的稀疏激活是关键 1250 亿参数的模型由 24576 个小专家组成，每个 token 只激活约 10 个，频繁使用的数千个专家可放入 12GB 显存，其余放入内存由 CPU 辅助计算。
  2. 消费级硬件实测性能可实用 RTX 5070 加 64GB 内存达到每秒 53-94 token 的生成速度，比阅读速度更快，已具备实际使用价值。
  3. 全程本地运行保障隐私 支持 Claude Code、Codex 等工具接入，数据不出电脑，适合对隐私有要求的场景。
