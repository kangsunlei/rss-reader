微软 Foundry 新增生产级智能体运行时、工具链与管控能力

6/12/2026, 4:39:00 AM

📌 一句话摘要

微软在 Build 2026 上为 Foundry 平台新增了生产级智能体所需的运行时、工具链、记忆、场景对齐与可观测能力，补齐了从实验到生产的关键拼图。

📝 详细摘要

本文报道了微软在 Build 2026 大会上为 Azure AI Foundry 平台推出的多项新功能。文章指出，Foundry 被定位为「AI 智能体工厂」，本次更新并非仅新增模型接口，而是补齐了搭建生产级智能体所需的全套能力。核心更新包括：Agent Service 中的托管智能体运行时（支持状态管理、文件系统、长时智能体与定时任务）、Toolboxes（统一工具注册与发现、MCP 协议支持）、平台级记忆能力（过程性记忆、用户记忆、会话记忆）、Foundry IQ 场景对齐与检索层（整合 Work IQ、Fabric IQ 等，SLA 保障，时延低于 200ms），以及新增 MAI 系列模型和 Fireworks AI 的正式发布。文章还梳理了 Foundry 与 Copilot Studio、Agent Builder 的分层定位，强调 Foundry 是代码优先的生产级平台，具备评估、可观测性与管控能力。

💡 主要观点

  1. Foundry 定位为生产级 AI 智能体平台，而非仅模型接口。 本次更新补齐了运行时、工具、记忆、场景对齐、可观测性与管控能力，使智能体能够真正落地生产环境。
  2. 平台级记忆能力是本次更新的关键差异化特性。 过程性记忆帮助智能体在多次运行中学习任务执行方式，Tau bench 测试显示绝对成功率提升 7%-14%，且成本几乎持平。
  3. Toolboxes 实现了工具的统一注册与运行时发现。 工具只需注册一次即可被所有智能体发现使用，支持 MCP 协议、版本管理和工具检索，避免了逐个接入的重复工作。
  4. Foundry IQ 作为统一知识层，整合了多源数据。 将 Work IQ、Fabric IQ、Azure SQL 等整合至单一检索端点，时延低于 200ms，具备 SLA 保障与安全能力。
  5. Foundry 与 Copilot Studio 形成分层架构。 Copilot Studio 面向低代码场景，Foundry 是代码优先平台，当需要自定义逻辑、高级检索与深度集成时使用 Foundry。

💬 文章金句

  • 过程性记忆帮助智能体在多次运行中学习如何执行任务，而不仅仅是记录了什么，早期 Tau bench 测试结果显示，绝对成功率提升了 7% 到 14%，而成本几乎与基线持平。
  • 要对各类智能体框架进行追踪与评估，团队无需在技术栈和可观测能力之间二选一。你可以继续使用 LangChain、Semantic Kernel 或自研代码，同时在 Foundry 中获得生产级的追踪与评估能力。
