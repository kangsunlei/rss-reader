GitHub 上狂揽 1 万 Star！这个飞书命令行 CLI 开源项目起飞了。

5/15/2026, 3:04:00 AM

📌 一句话摘要

飞书官方开源 CLI 工具 lark-cli 在 GitHub 上不到两个月获得 1 万 Star，其 Agent-Native 设计将 2500+ API 封装为 200 多条命令和 24 个 AI Skill，让 AI Agent 能通过自然语言直接操控飞书全部核心功能。

📝 详细摘要

本文介绍了飞书官方开源 CLI 工具 lark-cli 的崛起。该工具在不到两个月内于 GitHub 上获得超 1 万 Star，成为办公软件 CLI 领域的领跑者。文章详细阐述了 lark-cli 的 Agent-Native 设计理念，即其并非为人类用户设计，而是专门为 AI Agent 打造。核心亮点包括：将 2500+ 飞书 API 压缩为 200 多条命令和 24 个开箱即用的 AI Agent Skill，覆盖日历、消息、文档、多维表格、审批等 17 个业务域；采用三层命令架构（Shortcuts、API Commands、Raw API），从简单快捷到精确控制再到全面覆盖；每个命令都经过真实 AI Agent 测试，输出格式对 AI 友好，支持 JSON、dry-run 预览等功能。文章还提供了两种安装方式（手动或由 AI 自动安装），并展示了通过自然语言在飞书中创建文档、管理日程等实际应用场景。作者认为，飞书通过 lark-cli 将自己从一个办公软件转变为一个 AI Agent 可调用的企业能力平台，在办公软件与 AI Agent 结合的道路上处于领先地位。

💡 主要观点

  1. lark-cli 是专为 AI Agent 设计的 Agent-Native 工具，而非面向人类用户的传统 CLI。 其设计核心是让 AI Agent 能高效调用飞书功能，通过 24 个预定义的 Skill 和三层命令架构，降低 Agent 的使用门槛和出错率。
  2. lark-cli 通过三层命令架构实现了从简单到复杂的全面覆盖。 Shortcuts 层提供快捷命令，API Commands 层与飞书 API 一一对应，Raw API 层则允许直接调用任意端点，兼顾了易用性与灵活性。
  3. lark-cli 的成功标志着飞书从办公软件向 AI Agent 可调用的企业能力平台转型。 通过 CLI 将 IM、文档、审批等所有核心功能暴露给 AI Agent，使飞书成为数字员工的操作系统，在办公软件与 AI 结合赛道中领先。

💬 文章金句

  • CLI 是 AI Agent 时代最重要的接口，因为命令行的纯文本指令天然契合大语言模型。
  • lark-cli 提供了 24 个 AI Agent Skill，涵盖日历、消息、文档、表格、邮箱、任务、审批、OKR 等所有飞书核心场景。
  • 未来每个 SaaS 都需要回答一个问题：如果用户只通过 AI Agent 与我交互，我的产品该长什么样？飞书给了一个答案。
