这 2 个免费的开源 Skill 太给劲儿，直接替代 Playwright。

6/3/2026, 2:10:00 AM

📌 一句话摘要

本文介绍 BrowserAct 开源项目，它是一个面向 AI Agent 的浏览器自动化 CLI，通过 Stealth 浏览器、动态代理和 Skill 封装机制，解决 Playwright 等基础框架在真实互联网场景中遇到的反爬、验证码、Session 管理等痛点。

📝 详细摘要

文章从作者自身使用 Playwright 进行浏览器自动化的痛点出发，引出 BrowserAct 开源项目。项目包含两个核心 Skill：browser-act CLI（实时浏览器控制）和 browser-act-skill-forge（网站能力封装）。文章重点介绍了其三大核心能力：三种浏览器模式（Stealth 反检测浏览器、Chrome 复用登录态、Chrome-Direct 直连）、突破反爬的完整技术栈（指纹伪装、动态代理、验证码自动解决、人机接力），以及多任务/多账号的隔离运行机制。文章还列举了项目已提供的 31 个开箱即用 Skill，覆盖电商、线索获取、搜索研究、社交监听、视频平台五大场景。整体以项目介绍和功能展示为主，包含作者的个人使用体验和操作示例。

💡 主要观点

  1. BrowserAct 通过 Stealth 浏览器和动态代理解决真实互联网场景中的反爬与验证码问题。 项目内置指纹伪装、动态 IP 轮换和验证码自动解决能力，从环境层和执行层绕过网站反爬机制，弥补 Playwright 等基础框架在复杂场景下的不足。
  2. browser-act-skill-forge 可将网站操作封装为可复用 Skill，沉淀自动化经验。 该工具能自动探索网站 API 和操作流程，生成 SKILL.md 和 Python 脚本，将踩坑经验固化，后续任务可走最优路径，提升效率并降低 LLM 调用成本。
  3. 项目提供三种浏览器模式，覆盖不同使用场景。 Stealth 模式用于突破反爬，Chrome 模式复用登录态操作已登录后台，Chrome-Direct 模式直连当前浏览器实现人机协同，用户可根据需求灵活选择。

💬 文章金句

  • Playwright 这种基础框架对于很多真实场景并没有专门优化。
  • 它自动剥离 90% 的无效 HTML，广告、追踪代码、框架噪音全砍掉，只把有意义的内容喂给 LLM。省钱，而且 Agent 拿到的信息更干净。
