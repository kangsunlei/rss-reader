Vercel 推出 Streamdown 开源库，解决 AI 流式 Markdown 渲染痛点

8/20/2025, 8:53:15 AM

📌 一句话摘要

Vercel 发布了名为 Streamdown 的开源库，专门用于解决 AI 驱动的流式渲染中 Markdown 格式可能出现的渲染错误问题。

📝 详细摘要

此推文介绍了 Vercel 新推出的开源库 Streamdown。当前，AI 驱动的应用普遍采用流式渲染方式返回内容，但传统的 Markdown 渲染工具（如 React Markdown）在处理这种流式 Markdown 格式时，常会出现格式错误或显示问题。Streamdown 旨在解决这一痛点，它能够出色地渲染各种复杂的 Markdown 格式，包括代码块、数学公式和 GFM（GitHub Flavored Markdown）等，即使在流式处理场景下也能保证渲染效果。这为需要处理 AI 流式 Markdown 输出的开发者提供了一个非常有价值的解决方案。
