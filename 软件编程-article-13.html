我用 Codex 破解了家里这个设备，还能语音遥控。。。

10/20/2026, 2:10:00 AM

📌 一句话摘要

作者利用 OpenAI Codex 逆向破解极米投影仪的 Wi-Fi 与蓝牙控制协议，结合局域网截图实现视觉感知，开发语音唤醒 Mac 应用「小 C」接入固定 Codex 会话，打造可语音闭环控制的智能家居 Agent，并开源两个项目。

📝 详细摘要

作者分享了用 OpenAI Codex 将家用极米 Z7X 投影仪接入 AI Agent 的全过程：先让 Codex 通过 Wi-Fi 学习控制指令，再配合 iPhone 官方 App 采样蓝牙信号破解开机广播，封装成 Mac 菜单栏常驻应用与 Agent 可调用 Skill；接着利用局域网截图让 Codex 在 Agent Loop 中「看见」投影仪画面，实现「指令→读屏→决策→操作→复核」的视觉闭环；最后开发语音助手「小 C」，本地唤醒后将语音转文本发送至固定 Codex 会话保持上下文，任务完成后自动朗读回复。两个核心组件 xgimi-agent 与 voice-control-agent 已开源。文章展示了从单设备控制向全屋 Agent 协同的演进思路，并指出该模式对老年人友好交互的潜力。

💡 主要观点

  1. Codex 能在一小时内自主完成投影仪 Wi-Fi 控制协议的逆向与蓝牙开机广播的破解 作者仅提供型号与 IP，Codex 先通过 Wi-Fi 实现方向键、确认、音量等常规操作，再配合 iPhone 官方 App 采样蓝牙信号，最终让 Mac 直接发送广播实现开机，全过程无需人工编写协议解析代码。
  2. 局域网截图 + Agent Loop 让 Codex 拥有「视觉感知」，实现从盲操作到视觉闭环控制 电脑通过同一局域网获取投影仪实时画面截图，Codex 在每轮循环中读取画面、决策下一步点击、执行后再读取评估，能自动处理首页、弹窗、选中位置变化等动态界面。
  3. 语音助手「小 C」通过固定会话 ID 保持上下文，实现自然语音交互的持久化 本地唤醒词检测后，语音转文本发送至同一 Codex 会话，后续指令可承接前文（如「关掉投影仪」无需重复设备信息），任务完成后 Codex 回复经 TTS 朗读，形成完整语音闭环。
  4. 两个核心组件已开源，为个人智能家居 Agent 落地提供可复用的工程样板 xgimi-agent 封装投影仪控制与截图能力，voice-control-agent 提供唤醒、ASR、TTS 与会话管理，均为 Mac 原生应用，开发者可直接在此基础上扩展灯光、空调等设备，加速家庭 Agent 原型构建。
  5. 作者展望半年内将出现更多可用的家庭 Agent，并强调对老年人友好交互的社会价值 设想电脑或常驻设备作为大脑协调多设备，老人只需自然语言即可完成「接着放昨天的剧」等复杂任务，Agent 在信息不足时主动追问，降低智能电视复杂界面的操作门槛。

💬 文章金句

  • 我让 Codex 研究了 1 小时，实现了下面这个效果：我的 MacBook 放在我客厅的桌子上，我在沙发上说："小 C，请你打开我的投影仪，然后打开腾讯视频找到我之前看的综艺，帮我点开"。
  • 这样，Codex 就可以看一眼屏幕，决定下一步按什么，操作后再看一眼。遇到首页、弹窗或者不同的选中位置，也可以根据实际画面调整。
  • 我希望它平时在后台等着，喊一声 小 C，它就响一下表示听到了。接着我说出指令，说完稍微停顿，它就把语音转成文字，发给 Codex。这里我特意要求了一点：每次都要发到同一个专用会话。
  • 如果灯、空调、窗帘这些设备的控制方式，也能逐个被接通，Agent 就可以根据我的需求，协调它们一起工作。
