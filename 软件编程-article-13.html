Grafana 云平台中的 Prometheus 原生型直方图：精度更高、使用更简单、兼容性更好

5/6/2025, 12:11:25 PM

📌 一句话摘要

Grafana 云平台引入 Prometheus 原生型直方图，提供更高精度、更简单的使用方式，以及与 OpenTelemetry 等格式的更好兼容性，从而提升系统可观测性。

📝 详细摘要

本文介绍 Grafana 云平台中 Prometheus 原生型直方图的公开预览功能，重点分析其相对于经典直方图的优势。原生型直方图具有更高分辨率，通过单一时间序列存储简化指标采集过程，并能更好地兼容 OpenTelemetry 指数直方图等格式。内容详细说明两种操作模式：支持自定义分桶的兼容模式，以及标准指数分桶模式。提供了原生型直方图与经典直方图的全面对比，包括可视化差异和简化的查询语法。实践指导部分涵盖多种集成方案（JSON 提交、OpenTelemetry 和 Prometheus）及代码示例。文章还讨论了迁移注意事项以及与 Datadog 分布数据等其他系统的兼容特性。

💡 主要观点

  1. 原生型直方图通过单一时间序列存储实现更高精度 新型原生型直方图将信息整合为单一数据序列，相比经典直方图的多个独立序列，提供更高分辨率和更简单的指标采集方式。
  2. 两种操作模式满足不同使用场景 原生型直方图同时支持兼容模式（自定义分桶）和标准指数分桶模式，满足不同精度需求和迁移场景。
  3. 与 OpenTelemetry 等格式的无缝兼容 原生型直方图通过自动转换与 OpenTelemetry 指数直方图和 Datadog 分布数据协同工作，增强跨平台互操作性。
  4. 简化的查询语法与迁移指导 文章提供了清晰的原生型直方图 PromQL 查询示例，以及从经典实现过渡的实用建议。
  5. 多种集成方案及代码示例 通过 JSON 提交、OpenTelemetry 指标采集和 Prometheus 配置提供详细的实现方案，并附有实际代码示例。

💬 文章金句

  • 与经典 Prometheus 直方图相比，Prometheus 原生型直方图（简称原生直方图）提供更高分辨率和精度。
  • 原生型直方图兼容其他格式，如 OpenTelemetry 指数直方图和 Datadog 分布数据。
  • 当您不确定数值分布且希望避免选择分桶时，可使用标准指数分桶的原生型直方图。
  • OpenTelemetry 收集器中的 Prometheus 远程写入导出器默认将 OpenTelemetry 指数直方图转换为采用标准指数分桶的原生型直方图。
  • 原生型直方图完全兼容 OpenTelemetry，支持指数直方图与原生直方图格式间的相互转换。
