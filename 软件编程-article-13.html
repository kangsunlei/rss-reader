写了个插件，给代码里藏东西，线上可用！

📌 一句话摘要

文章介绍了如何开发一个 Webpack/Vite 插件，用于在构建产物中嵌入 Git 信息和自定义内容，并可在浏览器控制台通过特定指令查看。

📝 详细摘要

本文详细讲解了如何创建一个前端构建插件，该插件兼容 Webpack 和 Vite，核心功能是将当前项目的 Git 信息（提交人员、版本、分支、说明、时间）以及用户自定义内容嵌入到最终的构建产物中。文章首先阐述了插件的实现思路：在构建过程中获取 Git 信息，然后在构建完成后将包含这些信息的 JS 脚本注入到 HTML 文件中。接着，作者介绍了如何利用 Node.js 的`child_process`模块执行 Git 命令获取信息，以及如何在网页端通过劫持`window.info`属性来安全地触发信息展示。文章提供了 Webpack 和 Vite 环境下实现注入的 Hooks 代码示例，并通过实际项目演示了插件效果。最后，作者提出信息加密、控制台美化和增加配置项等优化建议，并提供了插件的 npm 包和 GitHub 仓库地址。

💡 主要观点

  1. 开发插件在构建产物中嵌入 Git 信息和自定义内容 通过自定义构建插件，可以在前端代码上线后快速追溯其对应的 Git 版本和相关信息，方便调试和管理。
  2. 利用 Node.js 获取 Git 信息并动态注入到 HTML 中 插件在构建时调用 Node.js 执行 Git 命令获取信息，并利用构建工具的钩子将生成的信息脚本注入到最终的 HTML 文件里。
  3. 通过劫持 window 属性实现安全的信息访问 采用类似 Vue 2 的数据劫持原理，通过访问`window.info`触发信息打印，避免信息默认暴露在控制台，提高了安全性。
  4. 插件同时支持 Webpack 和 Vite 构建工具 文章提供了针对 Webpack 和 Vite 的差异化注入实现，确保插件的广泛适用性。

💬 文章金句

  • 有时候我们想在代码中 "夹带一点私货"，比如留下一些自定义信息或标识，如部署文档、关联资料、构建时间等信息，让这些内容跟着上线代码一并部署。
  • 要实现插件的效果，我们的大致思路如下：打包或编译时，通过 node 获取当前的 git 信息；打包结束后，将获取的 git 信息注入打包后的代码中；在浏览器控制台，通过特殊方式展示打包信息。
  • 参考 vue2 的数据劫持原理，我们可以对 window 对象的特殊属性进行数据劫持。
  • 把代码的打包信息直接输出在控制台是不安全的，我们并不希望所有人打开控制台都可以看到打包信息。
  • 通过上述的代码，我们已经实现了一个功能完备的网站打包信息追踪插件，但它还不完善，以下是一些可以改进的地方：信息加密，console 美化，增加配置项。
