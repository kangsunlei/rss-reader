IBM Cloud Code Engine 无服务器舰队 (Serverless Fleets)：赋能高性能 AI 和并行计算

10/16/2025, 10:00:00 AM

📌 一句话摘要

IBM Cloud Code Engine 推出集成 GPU 支持的无服务器舰队 (Serverless Fleets)，旨在简化大规模高性能 AI 和并行计算工作负载的执行。

📝 详细摘要

IBM Cloud Code Engine 推出了集成 GPU 支持的无服务器舰队 (Serverless Fleets)，解决了在无服务器平台上运行计算密集型工作负载（如企业 AI、生成式 AI、机器学习 (ML) 和复杂模拟）的挑战。这项新功能提供了一个统一的端点，用于提交大量批量作业 (Batch jobs)，自动配置必要的资源（包括虚拟机 (VM) 和 NVIDIA L40 GPU），并弹性扩展以完成运行任务。资源在执行后自动释放，确保高性价比的按需付费模式。IBM 通过为 Web 应用程序、函数和 GPU 加速的批量作业提供统一的环境来区分无服务器舰队 (Serverless Fleets)，旨在降低运营复杂性，消除组合多个不同服务的需求，从而简化开发人员体验，并减少 SRE 运维负担。

💡 主要观点

  1. IBM Cloud Code Engine 现在支持 GPU 加速的无服务器舰队 (Serverless Fleets)。 这使得在按需付费模式下简化大规模、计算密集型 AI、ML 和模拟工作负载的执行成为可能，解决了无服务器平台历史上的局限性。
  2. 无服务器舰队 (Serverless Fleets) 为复杂的并行作业提供了一个统一的简化平台。 它简化了基础设施编排，从单个端点自动配置和扩展 GPU 支持的虚拟机 (VM)，从而显著降低了运营复杂性和 SRE 工作量。
  3. IBM 的产品优势在于为各种工作负载提供单一的集成解决方案。 与可能需要组合多个服务的竞争对手不同，无服务器舰队 (Serverless Fleets) 为 Web 应用程序、函数和 GPU 加速的批量作业提供了一个整体环境。

💬 文章金句

  • 此功能的架构在很大程度上是通过运行具有数十万个处理器的大型实际工作负载来了解和驱动的。它以一种非常强大的方式构建，可以以基本上为零的站点可靠性工程师团队 (SRE) 运行这些工作负载。
  • 该服务自动配置必要的计算资源，包括虚拟机 (VM) 和无服务器图形处理单元 (GPU)，例如 NVIDIA L40，以同时运行多个任务。
  • 竞争对手可能要求开发人员组合多个服务，如无服务器运行时、容器服务和批量协调器。Serverless Fleets 旨在简化此过程，通过完全管理 GPU 支持的虚拟机 (VM) 的配置和弹性扩展，降低复杂性和运营开销，从而优化云中弹性 GPU 密集型工作负载的运行。
  • 无论您是在处理媒体处理、AI 推理 (AI inference) 还是科学工作负载，IBM Cloud Code Engine 无服务器舰队 (Serverless Fleets) 都提供了一个强大且对开发人员友好的解决方案。
