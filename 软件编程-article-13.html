如何使用 Python 的 hashlib 模块实现安全哈希

12/15/2025, 10:56:01 PM

📌 一句话摘要

本教程全面解释了如何使用 `hashlib` 模块在 Python 中实现安全的密码哈希，涵盖了基本哈希、加盐和像 PBKDF2 这样的密钥派生函数。

📝 详细摘要

本文详细介绍了如何使用 Python 的 `hashlib` 模块进行安全哈希。文章首先介绍了使用 SHA-256 进行数据完整性验证的基本哈希概念，并强调了简单哈希不足以用于密码的原因——它容易受到彩虹表攻击。本教程接着演示了如何在哈希密码之前添加随机的“盐”，以确保相同的密码产生不同的哈希值，从而显著提升安全性。它还涵盖了验证加盐密码的过程。最后，文章介绍了像 PBKDF2 这样的密钥派生函数（KDFs），强调了它们故意的慢速和高计算成本以阻止暴力破解攻击，并提供了一个 Python 实现及其速度比较。目标是让读者掌握在应用程序中安全存储密码的实用知识。

💡 主要观点

  1. 基本哈希（例如 SHA-256）适用于数据完整性检查，但不适用于安全的密码存储。 简单哈希会为相同的输入生成一致的输出，若密码直接以哈希形式存储，则易受到彩虹表攻击。
  2. 加盐涉及在哈希之前向每个密码添加唯一的随机数据，以防止彩虹表攻击。 加盐确保即使相同的密码也能产生不同的哈希，使预计算的攻击表失效，并要求攻击者单独破解每个哈希。
  3. 密钥派生函数（KDFs），如 PBKDF2，因其计算缓慢而被专门设计用于密码哈希。 KDFs 通过重复迭代有意地消耗更多的计算资源，显著增加攻击者执行暴力破解尝试的时间和成本。

💬 文章金句

  • 与加密不同，哈希是一个单向过程：你无法逆转它来获取原始数据。
  • 解决方案是**加盐**：在哈希之前向每个密码添加随机数据。这样，即使相同的密码也能产生不同的哈希值。
  • 这些算法被有意设计得很慢，且需要更多的计算资源，从而大大增加了暴力破解攻击的难度。
