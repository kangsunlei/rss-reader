openJiuwen 首发双维度 RSI 框架，AI 自修改，落地办公智能体，算力亲和助力又快又省

9/12/2026, 3:35:00 AM

📌 一句话摘要

openJiuwen 发布双维度 RSI 框架，通过 Harness 与 Artifacts 优化及算力亲和实现 AI 自我改进的工程闭环。

📝 详细摘要

openJiuwen 由华为多团队联合构建的开源 AI Agent 平台，提出双维度 RSI 框架：将优化对象划分为 Harness（Prompt、Skill、Tool、Rail）和 Artifacts（科研论文、算法程序）。框架通过建立基线、从失败和轨迹定位问题、生成候选版本、重新执行评测、仅采纳验证有效的改进并将经验沉淀，形成可验证的工程闭环。在 WorkSwarm 蜂群办公智能体中落地，Harness 优化使 SWE-bench Lite Dev 通过率从 61.0% 提升至 87.0%，Evo-Bench General 通过率从 60.9% 提升至 71.9%；引入算力亲和能力后，TTFT 下降 15.83%，P90 下降 19.16%，KV Cache 命中率提升至 14.36%，显著降低多轮优化的算力开销。框架已集成到华为云 AgentArts 商业化平台，提供开箱即用的体验。

💡 主要观点

  1. 双维度 RSI 框架将优化对象划分为 Harness 与 Artifacts，覆盖工作方式与交付产物的持续迭代。 Harness 包括 Prompt、Skill、Tool、Rail，决定 Agent 如何完成任务；Artifacts 是 Agent 生成的科研论文和算法程序。两者均可进入版本化优化闭环，使工作方法和工作成果都能持续改进。
  2. 可验证的工程闭环确保只有经实证有效的改进才被采纳，成功与失败经验均进入下一轮迭代。 流程包括：建立基线 → 从失败、执行轨迹和指标定位问题 → 生成候选版本并重新执行评测 → 仅验证有效的修改被采纳 → 将成功与失败经验沉淀为下一轮的参考，避免主观判断导致无效方向。
  3. 算力亲和能力通过动态调度 KV Cache 显著降低多轮优化的算力开销与时延。 依托昇腾算力基础设施，框架通过 Agent Hint 将任务状态传给推理引擎，在 NPU 显存、CPU 内存和远端缓存池之间主动调度上下文缓存：等待时卸载到低成本存储，恢复前预取，结束后释放。实验显示 TTFT 下降 15.83%，P90 下降 19.16%，KV Cache 命中率提升至 14.36%，HBM 与 DDR 峰值使用率分别下降 22.82% 与 30.74%。
  4. Harness 优化在实际基准上显著提升任务成功率，且具备泛化能力。 在 DeepSeek-V4-Flash 任务模型配置下，Harness 优化使 SWE-bench Lite Dev 23 道题通过率从 61.0% 提升至 87.0%；冻结后的 Harness 在 Evo-Bench General 64 道独立评测题上的单次执行通过率从 60.9% 提升至 71.9%，表明优化收益可泛化至未参与迭代的任务。
  5. 框架已落地 WorkSwarm 并接入华为云 AgentArts，提供开箱即用的 AI 自改进平台。 用户可在 WorkSwarm 的 "实验" 页面发起 Harness 或产物优化，查看每轮改进过程和搜索路径，最终获得经过验证的插件或产物。华为云 AgentArts 将 openJiuwen 引入商业化平台，提供免费 Token 的在线体验入口，便于工程团队快速落地。
