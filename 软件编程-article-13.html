WebStorm 2025.2: TypeScript-Go 语言服务器支持，Web 平台基线支持，Bun 改进，以及更多 | The WebStorm Blog

8/4/2025, 12:52:49 PM

📌 一句话摘要

WebStorm 2025.2 引入了实验性的 TypeScript-Go 语言服务器支持，Web 平台基线支持集成，显著的 Bun 改进，以及增强的 AI 助手功能。

📝 详细摘要

WebStorm 2025.2 版本带来了一系列新功能和改进，主要集中在增强 Web 技术开发者的体验。主要亮点包括实验性支持 TypeScript-Go 语言服务器，提供原生的 TypeScript 体验。同时，Web 平台基线信息也被直接集成到快速文档中，以更好地了解浏览器兼容性。该 IDE 还对 Bun 进行了重大改进，提供自动检测作为包管理器和简化的运行/调试配置。AI 功能得到了显著升级，更快的 Junie 编码助手现在支持模型上下文协议 (Model Context Protocol， MCP) 和远程开发，同时 AI 助手也变得更智能，具有项目感知聊天和 VS Code 集成。此外，该更新还包括对 Angular 的 `in` 关键字的增强支持，当使用 Prettier 时自动禁用内置格式化程序，更新的 Prisma LSP 和重新设计的 GraphQL 语言注入。UI/UX 方面的改进主要集中在优化参数信息弹出窗口，同时重要的修复增强了 Vitest 和 Jest 的测试支持。

💡 主要观点

  1. TypeScript-Go 语言服务器支持提升了跨语言开发的效率。 引入了对原生 TypeScript 语言服务器的实验性支持，可能会提高涉及 TypeScript 和 Go 的项目的性能和集成度。
  2. Bun 改进简化了包管理和执行。 WebStorm 现在自动检测 Bun 并创建运行/调试配置，从而显著改善了基于 Bun 的项目开发工作流程。
  3. Junie 和 AI 助手等 AI 功能得到了显著增强。 Junie 通过 MCP 和远程开发变得更快，而 AI 助手提供了更智能、项目感知的聊天和 VS Code 集成，从而提高了开发人员的生产力。
  4. Web 平台基线支持提供了关键的兼容性信息。 将 Web 平台基线数据集成到快速文档中，可以帮助开发人员快速确定 Web API 的浏览器支持，从而确保更广泛的兼容性。
  5. 框架和技术支持已更新，以支持现代技术栈。 Angular、Prettier、Prisma 和 GraphQL 的更新确保 WebStorm 与最新的 Web 开发趋势保持一致，从而提供强大而一致的工具。

💬 文章金句

  • 此版本引入了各种新功能并解决了若干挑战。主要改进包括实验性的 TypeScript-Go 语言服务器支持，基线支持，Bun 改进以及一系列必要的更新。
  • WebStorm 现在在快速文档中显示 Web 平台基线支持的详细信息。

  • JetBrains AI 助手刚刚进行了一次重大升级，为您带来更快、更具项目感知的 AI 辅助功能。该功能已完全集成到您的开发工作流程中。
