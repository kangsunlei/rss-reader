微软发布开源代理框架，简化 AI 代理开发

10/2/2025, 8:33:00 AM

📌 一句话摘要

微软新的开源代理框架统一了语义内核和 AutoGen，通过生产就绪的功能和企业集成，简化了所有技术水平的 AI 代理开发。

📝 详细摘要

本文宣布了微软的开源代理框架，这是一个新的软件开发工具包，旨在简化所有技术水平的开发人员创建和部署人工智能代理的过程。该框架代表了一次重要的整合，统一了语义内核和 AutoGen 的功能，不再需要在创新和生产稳定性之间做出妥协。它使开发人员能够以最少的代码构建 AI 代理，尤其方便那些不具备深厚 AI 专业知识的开发者使用。该框架建立在四个核心支柱之上：开放标准和互操作性（支持模型上下文协议、代理间通信和 OpenAPI 等标准）、研究管道（提供生产级 AutoGen 编排模式，例如群聊和辩论）、可扩展设计（通过连接器连接到 Azure AI Foundry、Microsoft Graph 等服务，并支持声明式 YAML/JSON 配置），以及生产就绪（提供可观测性，并与 OpenTelemetry/Azure Monitor、Entra ID 安全和 CI/CD 兼容）。支持 Python 和 .NET 环境，它与更广泛的 Azure AI 生态系统和 Visual Studio Code 深度集成，并为语义内核或 AutoGen 的现有用户提供迁移指南。

💡 主要观点

  1. 该框架整合了现有的微软 AI 项目，以提供统一的、生产就绪的解决方案。 通过合并语义内核和 AutoGen，该框架兼顾了实验性创新和企业稳定性，简化了 AI 代理的开发流程，降低了开发复杂性。
  2. 它通过最少的代码要求和强大的功能，大大降低了 AI 代理开发的入门门槛。 开发人员可以用少于 20 行的代码构建复杂的代理，利用内置连接器、声明式配置和生产级可观测性，从而降低了使用门槛。
  3. 该框架支持开放标准以及与微软企业生态系统的深度集成。 它通过模型上下文协议、代理间通信和 OpenAPI 确保互操作性，同时与 Azure AI Foundry、Microsoft Graph 和 VS Code 等开发工具无缝集成。

💬 文章金句

  • 构建 AI 代理不应该是火箭科学。
  • 这种连续性意味着开发人员可以保留他们现有的投资，同时解锁新的功能。微软代理框架不是对先前事物的替代，它是统一创新和稳定性的自然演变。
