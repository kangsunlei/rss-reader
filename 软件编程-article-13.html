可认领的部署现已支持第三方资源 - Vercel

9/23/2025, 1:00:00 PM

📌 一句话摘要

Vercel 的“可认领的部署”功能使第三方平台能够创建包含集成资源的项目，允许用户无缝认领并转移完全所有权。

📝 详细摘要

Vercel 推出了“可认领的部署”，这是一项旨在简化包含第三方资源的项目的所有权创建和转移流程的新功能。现在，AI 工具、编码环境和工作流应用等平台可以利用 Vercel API 来部署应用程序以及附加的第三方服务，例如数据库。当用户认领此类部署时，所有关联资源都会自动转移，从而授予用户完全所有权。Prisma 是首个支持此即时部署功能的 Vercel 市场提供商，使客户能够将数据库和 Vercel 托管的应用程序部署为单个集成堆栈。Vercel 计划将此功能扩展到更多的市场合作伙伴，包括身份验证、可观测性和工作流管理等服务，通过一键认领的方式，促进更集成的开发体验。

💡 主要观点

  1. Vercel 使第三方平台能够部署具有集成外部资源的项目。 这项新功能简化了全栈应用的创建，允许将数据库等外部服务直接与 Vercel 部署捆绑。这简化了开发人员和用户的设置。
  2. 用户可以无缝地认领这些部署，从而转移应用程序和附加资源的完全所有权。 这可以自动执行复杂项目配置的交接，从而无需手动设置，并确保将所有组件完整、直接地转移给最终用户。
  3. Prisma 是首个合作伙伴，并计划将此功能扩展到更多的 Vercel 市场提供商。 这证明了该功能的直接适用性以及 Vercel 促进更广泛的集成一键式解决方案生态系统以增强开发者工作流的战略。

💬 文章金句

  • 现在，AI 平台、编码工具和工作流应用程序可以在 Vercel 上创建项目。用户稍后可以声明这些项目，并将部署所有权与第三方提供商的资源一起转移。
  • 任何第三方都可以使用 Vercel API 创建项目、部署应用程序和附加资源存储（例如数据库）。
  • 当用户认领 Vercel 部署时，附加的资源会自动随之移动。用户将获得完整部署的完全所有权。
  • Prisma 客户现在可以将数据库和 Vercel 托管的应用程序一起启动为单个捆绑堆栈。
  • 我们正在将此流程扩展到更多的市场提供商，以便他们可以通过一键认领将身份验证、可观测性和工作流服务等产品与 Vercel 部署配对。
