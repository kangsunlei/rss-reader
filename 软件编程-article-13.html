太糟心了，我准备全面放弃 Claude Code...

5/21/2026, 4:10:00 AM

📌 一句话摘要

本文作者因 Claude Code 的网络不稳定、地域限制等问题，决定全面转向开源免费的 Kilo Code，并通过实际项目验证了其作为平替工具的出色能力。

📝 详细摘要

文章以「你喜欢的女孩，喜欢你的女孩，你会选谁？」为引子，引出作者在使用 Claude Code 过程中遇到的网络不稳定、支付障碍、地域限制等痛点。作者调研后发现 Kilo Code 作为开源免费工具，在全球知名度高且国内友好，于是决定全面转向。文章详细记录了作者使用 Kilo Code 的 Plan 模式和 Code 模式，从零开发一个在线学习平台的全过程，包括需求撰写、计划生成、代码编写、测试和部署。整个过程耗时不到 2 小时，产出质量超出预期。作者强调，即使未使用顶尖模型和高级技能，Kilo Code 的原生能力已足够强大，并宣布将全面放弃 Claude Code。

💡 主要观点

  1. Claude Code 存在网络不稳定、地域限制等痛点，影响国内用户体验。 作者列举了使用 Claude Code 时遇到的 api.anthropic.com 丢包、支付注册障碍、模型绑定、API 速率限制、地域限制、实名认证和封号风险等问题，认为其对中国用户不友好。
  2. Kilo Code 作为开源免费的 AI 编程工具，是 Claude Code 的理想平替。 Kilo Code 具有零门槛、无地域限制、国内友好、模型灵活、支持 VS Code/JetBrains 插件和 CLI 等优势，且在全球范围内有较高知名度和用户基础。
  3. Kilo Code 的 Plan 模式和 Code 模式能高效完成复杂项目开发。 作者通过实际项目验证，Kilo Code 的 Plan 模式能生成详细的项目计划和子步骤，Code 模式能自动并发编码，最终在不到 2 小时内完成一个包含注册登录、学习中心、沙盒终端等功能的在线学习平台。
