Vue 常见面试题总结，涵盖 Vue2/3 区别、API 使用、JS/CSS 基础等。

📝 详细摘要

本文总结了作者裸辞后面试中遇到的 Vue 相关问题，为 Vue 面试准备提供参考。内容涵盖 Vue2 和 Vue3 的区别，如响应式原理（Proxy 替代 Object.defineProperty）、组合 API、`v-if` 和 `v-for` 优先级等；组件双向数据绑定的实现；Composition API 与 Options API 在代码组织和逻辑复用上的差异；以及 Vue 中 `$nextTick` 的作用、`keep-alive` 组件的用法等。同时，总结了 JS/CSS 基础知识，如数组去重、对象拷贝、CSS 居中等。

💡 主要观点

  1. Vue 3 在响应式原理、编译优化等方面进行了改进，提升了性能。 Vue 3 使用 Proxy 替代 Object.defineProperty 实现响应式，无需深度遍历所有属性，减少了内存占用，优化了大型应用的性能；同时在编译阶段对静态节点进行标记和提升，diff 时只需对比动态节点内容。
  2. Composition API 通过自定义 Hook 实现逻辑复用，提高代码可维护性。 相比 Options API 的 mixins，Composition API 避免了命名冲突，使代码结构更清晰，逻辑复用更灵活。
  3. 理解 Vue 的异步更新机制，使用 $nextTick 确保 DOM 更新后执行代码。 Vue 不会立即更新 DOM，而是在下一个事件循环中批量处理。`$nextTick` 提供了一种机制，确保在 DOM 更新完成后再执行代码，避免获取未更新的 DOM 状态。
  4. `keep-alive` 用于缓存动态组件和路由组件，避免重复创建和销毁，提升性能。 `keep-alive` 是 Vue 的内置组件，通过 include/exclude 属性可以控制需要缓存的组件。被缓存的组件激活时会触发 `activated` 钩子，停用时触发 `deactivated` 钩子。

💬 文章金句

  • Vue 的响应式系统是异步的。
  • keep-alive 是 vue 的内置组件，主要用来**缓存动态组件** 和**路由组件**的，避免组件在切换时被销毁和重新创建。
  • 确保每个组件实例都有自己独立的数据副本，避免多个组件实例共享同一个数据对象，从而导致数据污染和状态混乱。
