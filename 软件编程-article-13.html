新的 ObjectRef 数据类型将 非结构化数据 引入 BigQuery

6/25/2025, 12:00:00 AM

📌 一句话摘要

Google Cloud BigQuery 引入 ObjectRef 数据类型，用于集成 Cloud Storage 中的 非结构化数据，支持 多模态分析 和 AI/ML。

📝 详细摘要

本文宣布在 Google Cloud BigQuery 中推出新的 数据类型 `ObjectRef`，旨在引用 Cloud Storage 中的 对象。这项创新允许用户将 非结构化数据（如 音频、图像 和 视频）直接集成到 BigQuery 表中，与 结构化数据 并存。`ObjectRef` 类型消除了对不同 数据类型的 分隔 数据管道 和 独立治理 模型的需求。它可以使用标准 SQL 或 Python（通过 BigQuery DataFrames）实现 多模态数据处理，并与 无服务器 Python UDF、BigQuery ML 以及 Gemini 等 生成式 AI 模型无缝集成。此功能目前处于 预览版 阶段，在一个统一且可治理的平台中，为 结构化 和 非结构化数据 分析 以及 AI/ML 工作负载 的结合开辟了新的可能性。

💡 主要观点

  1. ObjectRef 将 非结构化数据 集成到 BigQuery 表中。 新的 ObjectRef 数据类型允许直接在 BigQuery 中 引用 Cloud Storage 中的 对象，实现 结构化 和 非结构化数据 的统一存储和处理。
  2. 使用 SQL 和 Python 实现 多模态数据 处理。 用户可以使用熟悉的工具（如 SQL、Python UDF 和 BigQuery DataFrames）以 无服务器 方式处理 结构化 与 非结构化 混合数据。
  3. 促进在 非结构化数据 上的 AI/ML 和 生成式 AI 工作流程。 ObjectRefs 在 BigQuery ML 函数 和 Gemini 集成中是一等公民，允许将 AI 模型 直接应用于存储在 Cloud Storage 中的 非结构化数据。
  4. 提供统一的 治理 和 访问控制。 BigQuery 现有的 治理功能，如 细粒度访问控制 和 数据脱敏，现在也适用于 ObjectRefs 引用的 非结构化数据，从而简化了 数据管理。

💬 文章金句

  • 今天我们推出一种新的 数据类型 ObjectRef，目前在 BigQuery 中处于 预览版，它代表对 Cloud Storage 中任何 对象 的引用，包含一个 URI 和额外的 元数据。
  • ObjectRef 数据类型消除了 数据处理 和 访问控制 中的 分散，提供了一种统一的、多模态的、可治理的方式来处理所有 数据模态。
  • 使用处理 表格数据 的相同 SQL 或 Python 脚本，通过 LLM、ML 模型 和 开源 Python 库 来处理 非结构化数据。
  • 所有 BigQuery ML 生成式 AI 函数，如 AI.GENERATE、ML.GENERATE_TEXT 和 ML.GENERATE_EMBEDDING，现在都将 ObjectRefs 作为 一等公民 支持。
