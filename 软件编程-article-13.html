GoLand 2025.1 版本发布 | GoLand 博客

4/16/2025, 12:29:54 PM

📌 一句话摘要

GoLand 2025.1 发布，增强 AI 支持，集成 golangci-lint，改进重构功能，全面支持 Go 1.24，提升代码质量与开发效率。

📝 详细摘要

GoLand 2025.1 版本带来了多项更新，旨在提升 Go 代码编写效率和开发体验。主要更新包括：增强了 JetBrains AI 的支持，将 AI Assistant 和 Junie 整合到统一订阅中，提供无限代码补全和本地模型支持；原生支持 `golangci-lint`，允许在 IDE 中实时进行代码检查；改进了结构体字段的重命名重构功能，自动更新 JSON 标签；增强了对`工具链`指令的处理和通知；全面支持 Go 1.24 的新特性，包括泛型类型别名、go.mod 中的工具指令、Delve 调试器更新和 go get 行为改进。此外，GoLand 还集成了 IntelliJ IDEA、WebStorm 和 DataGrip 的最新功能，进一步提升了 IDE 的整体性能和用户体验。

💡 主要观点

  1. JetBrains AI 增强，提供代码补全和云模型支持 JetBrains AI 提供无限代码补全和本地模型支持，并支持 OpenAI GPT-4.5、Claude 3.7 Sonnet 等云模型，提升代码编写效率和智能化水平。
  2. 原生支持 golangci-lint，提升代码质量 GoLand 集成了 Go Linter 插件，原生支持 `golangci-lint`，允许在 IDE 中实时进行代码检查，尽早发现并解决潜在问题。
  3. 改进重构功能，JSON 标签自动更新 在重命名结构体字段时，GoLand 会自动更新对应的 JSON 标签，确保代码库中的重构一致性。
  4. 全面支持 Go 1.24 新特性 GoLand 2025.1 全面支持 Go 1.24 的泛型类型别名、go.mod 中的工具指令、Delve 调试器更新和 go get 行为改进等新特性。

💬 文章金句

  • GoLand now integrates the Go Linter plugin， bringing native support for `golangci-lint`.
  • When renaming struct fields， GoLand now automatically updates the corresponding JSON tags.
  • GoLand 2025.1 aligns with the latest version of Go and fully supports its new language features
