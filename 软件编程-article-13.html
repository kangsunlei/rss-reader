Grafana 云更新：Fleet Management 正式发布，统一的 IRM 应用等

3/18/2025, 11:49:34 AM

📌 一句话摘要

Grafana 云更新包括 Fleet Management 的正式发布 (GA)，统一的 IRM 应用，增强的数据可视化，OTel 资源属性标签，以及数据源插件和告警功能更新。

📝 详细摘要

本文重点介绍了 Grafana 云的最新更新，包括用于大规模管理遥测收集器部署的正式发布的 Fleet Management 功能，以及新的统一 Grafana 云 IRM 应用，该应用合并了 OnCall (值班) 和 Incident (事件) 应用，以实现简化的事件响应体验。数据可视化和仪表板功能得到增强，包括：通过 WebGL 改进的地理地图性能；新增可视化操作；以及对所有转换的仪表板变量支持。此更新还在 Grafana 云指标中引入了 OTel 资源属性标签，简化了数据探索，以及数据源插件的更新，特别是 Grafana SLO 对 Graphite、Splunk 和 AppDynamics 的支持，以及新的告警功能，如 Jira Service Management 联系点支持和告警规则版本历史记录。

💡 主要观点

  1. Fleet Management 已正式发布 (GA)，支持大规模的遥测收集器管理。 通过 Terraform 配置和 Kubernetes 部署简化遥测数据收集和管理，从而增强可观测性。
  2. 统一的 Grafana 云 IRM 应用提供更快的事件响应和管理。 合并 OnCall (值班) 和 Incident (事件) 应用，集中告警组和事件，以简化事件管理流程。
  3. 增强的数据可视化包括改进的地理地图性能和可视化操作。 通过 WebGL 提高地理地图性能，并支持直接从仪表板面板触发 API 调用，从而增强数据可视化和交互功能。
  4. Grafana 云指标中的 OTel 资源属性标签简化了数据探索和关联。 提供资源属性的默认列表作为标签，使用户更容易发送 OTel 指标以探索和关联数据。

💬 文章金句

  • Fleet Management 现已正式发布，并包含诸多新功能，可帮助您监控和管理您的收集器集群。
  • 借助新的 Grafana 云 IRM 应用，您现在可以在一个统一的主页上查看所有告警组和事件。
  • 在 Grafana 云中，操作允许您启动基本的、未经身份验证的 API 调用，以启动特定流程，例如直接从仪表板面板触发 API 调用以关闭服务器。
