.NET Aspire 和 Azure 函数集成预览

4/9/2025, 12:00:19 PM

📌 一句话摘要

.NET Aspire 简化了 Visual Studio 中 Azure 函数的集成，通过内置的编排和实时监控功能，简化开发流程。

📝 详细摘要

本文介绍了 Visual Studio 中 .NET Aspire 和 Azure 函数的集成预览。此集成简化了将无服务器技术集成到 .NET 项目的过程。创建新的 Azure 函数项目时，开发人员可以选择启用 .NET Aspire 编排。该编排功能会自动配置应用宿主和默认服务配置，并提供实时监控和调试功能。现有的 Azure 函数项目也可以通过 .NET Aspire 获得增强。运行或调试这些项目会启动 .NET Aspire 仪表板，从而提供实时监控和调试功能。

💡 主要观点

  1. .NET Aspire 简化了 Azure 函数项目的创建和配置。 可以创建启用 .NET Aspire 编排的 Azure 函数项目，项目将自动包含应用宿主、默认服务配置等必要组件。
  2. 现有的 Azure 函数项目可以通过 .NET Aspire 进行增强。 开发人员可以将 .NET Aspire 支持添加到现有项目，无需从头开始，从而利用其优势。
  3. .NET Aspire 仪表板提供实时监控和调试。 该仪表板允许开发人员实时监控 Azure 函数的执行并直接管理它们，从而增强调试。

💬 文章金句

  • Visual Studio 的新更新已经为您准备好了。
  • 现在，通过 .NET Aspire 集成设置新的独立 Azure 函数项目非常简单，只需轻松勾选即可。
  • 这个强大的工具允许您实时监控 Azure 函数的执行。
