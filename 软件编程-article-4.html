Vercel Sandboxes 现在支持唯一且可自定义的名称 - Vercel

3/26/2026, 10:32:02 PM

📌 一句话摘要

Vercel Sandboxes 现在通过 SDK 和 CLI 支持唯一且可自定义的名称，从而更易于识别并实现自动会话持久化。

📝 详细摘要

Vercel 更新了其 Sandbox 功能（目前处于测试阶段），允许用户为环境分配唯一且可自定义的名称，取代了之前的基于 ID 的系统。此次更新简化了在项目中查找和引用特定 Sandbox 的流程。此外，命名后的 Sandbox 是实现自动持久化的主要机制，使开发人员能够无缝恢复会话。该功能可通过更新后的 @vercel/sandbox SDK 和新的测试版 CLI 访问，其中包含用于配置管理和会话检查的工具。

💡 主要观点

  1. 从基于 ID 的 Sandbox 标识转向基于名称的标识。 开发人员现在可以为 Sandbox 分配易于阅读的名称，与随机 ID 相比，这使得在项目中管理、搜索和引用它们变得更加容易。
  2. 与自动会话持久化的集成。 命名后的 Sandbox 是持久化会话的主要标识符，允许开发人员停止并准确地从上次中断的地方恢复工作，而不会丢失状态。
  3. 通过 SDK 和 CLI 增强管理能力。 此次更新包括新的 SDK 方法和 CLI 命令，用于以编程方式和手动方式控制命名环境，包括会话检查功能。

💬 文章金句

  • 名称使 Sandbox 更易于查找和引用。
  • 命名后的 Sandbox 是识别自动持久化的机制，这使得您的会话在创建和恢复时都能更容易地被识别。
