Notion2API：将 Notion AI 能力包装为 OpenAI 兼容 API 的 Go 中间层

4/19/2026, 2:34:44 PM

📌 一句话摘要

Notion2API 是一个用 Go 编写的中间层服务，可将 Notion AI 的能力包装成标准的 OpenAI 兼容 API。

📝 详细摘要

这条推文介绍了一个名为 Notion2API 的开源工具。该工具是一个用 Go 语言编写的中间层服务，其核心功能是将 Notion AI 的能力封装成与 OpenAI API 标准兼容的接口，包括 `/v1/chat/completions`、`/v1/models` 和 `/v1/responses` 等端点。这使得开发者可以像调用 OpenAI 服务一样，在自己的应用中集成 Notion AI 的功能，为 AI 应用开发提供了新的集成选项和灵活性。推文附带了项目截图并提供了 GitHub 链接。
