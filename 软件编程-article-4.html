Cloudflare One 是首个在全平台提供现代后量子加密的 SASE 产品

2/23/2026, 2:00:08 PM

📌 一句话摘要

Cloudflare One 已在其整个 SASE 平台（包括 IPsec 隧道和硬件设备）中集成了混合后量子加密（ML-KEM），以抵御未来的量子威胁。

📝 详细摘要

Cloudflare 宣布 Cloudflare One 成为首个提供全面后量子（PQ）加密的安全访问服务边缘（SASE）平台。通过在所有入口和出口（包括安全 Web 网关、零信任和 WAN 使用场景）实施混合 ML-KEM（基于模块格的密钥封装机制），Cloudflare 解决了“现在收获，以后解密”的威胁。文章详细介绍了 Cloudflare IPsec 和 Cloudflare One 设备向后量子标准的迁移技术细节，强调了加密敏捷性和互操作性的重要性。它特别强调了对 draft-ietf-ipsecme-ikev2-mlkem 标准的采用，以避免密码套件膨胀和专有硬件要求的陷阱，确保向量子安全网络进行可扩展且符合标准的过渡。

💡 主要观点

  1. Cloudflare One 通过混合 ML-KEM 实现了全平台后量子加密。 该平台现在在所有主要入口和出口（包括 IPsec、TLS 和 MASQUE）支持后量子加密，为企业流量提供端到端保护。
  2. 由于“现在收获，以后解密”攻击，后量子密码学（PQC）迁移迫在眉睫。 攻击者目前正在收集加密数据，以便在量子计算机可行时进行解密；现在实施后量子密钥协商是保护长期有效数据的唯一方法。
  3. Cloudflare 通过遵循新兴的 IETF 和 NIST 标准，优先考虑互操作性。 Cloudflare 没有采用专有解决方案或量子密钥分发（QKD），而是采用了最近 IETF 草案中指定的混合 ML-KEM，确保了与其他供应商的兼容性并降低了配置复杂性。
  4. 为了获得即时安全性，迁移重点放在密钥建立而非数字签名上。 升级密钥协商（迁移 1）可以阻止当下的数据收集威胁，而后量子签名（迁移 2）则不那么紧迫，因为它们防御的是尚不存在的主动量子对手。
  5. 后量子安全性已集成到现有产品中，无需额外费用。 Cloudflare 正在将其设备和云服务中的后量子密码学作为标准功能进行部署，消除了通常与高级加密升级相关的财务和硬件障碍。

💬 文章金句

  • Cloudflare One 是首个在我们的安全 Web 网关以及零信任和广域网（WAN）使用场景中支持符合现代标准的后量子（PQ）加密的 SASE 平台。
  • 如果您的数据保质期超过几年（例如财务信息、健康数据、国家机密），除非受到后量子加密的保护，否则它已经处于危险之中。
  • 我们特意选择了互操作性和简单性的道路——即 IETF 和 NIST 倡导的混合 ML-KEM 方法，而不是将我们的客户锁定在专有实现中。
  • 向混合 ML-KEM 的过渡非常成功，因为它阻止了‘现在收获，以后解密’攻击，且对性能几乎没有影响。
  • 后量子 SASE 的价值主张很明确：组织可以通过受混合 ML-KEM 保护的隧道发送私有网络流量，从而获得即时的端到端保护。
