GitHub Copilot Spaces ：为每个建议带来正确的上下文

6/18/2025, 4:00:00 PM

📌 一句话摘要

GitHub Copilot Spaces 通过特定的项目上下文增强了 AI 编码建议。

📝 详细摘要

本文介绍了 GitHub Copilot Spaces，这是一项目前处于公开预览阶段的功能，它允许用户将代码、文档和其他文本捆绑到可复用的“空间”中，以便为 Copilot 提供特定的上下文。这解决了通用 LLM 猜测而不是了解项目特定细节的局限性，从而带来更准确、更相关的代码建议和回答。文章解释了什么是空间（一个知识和指令的容器），提供了快速入门指南，分享了使用自定义指令个性化 Copilot 行为的技巧，并展示了实际用例，如可访问性合规、数据查询和新手引导。它强调了协作功能、基于 GitHub 权限的安全性，并暗示了未来与 IDE 和 Issues/PR 的集成。Spaces 对所有 Copilot 许可类型均可用。

💡 主要观点

  1. Copilot Spaces 根据项目特定上下文校准 AI。 通过提供精选的代码和文档，Spaces 使 Copilot 能够根据特定的代码库或团队知识提供高度相关的建议。
  2. 自定义指令个性化 Copilot 的语气和风格。 用户可以定义格式化、约定和沟通风格的规则，使 Copilot 的输出符合团队标准。
  3. Spaces 为各种开发工作流提供了实际解决方案。 自动化合规检查、协助数据查询和构建新手引导中心等用例展示了具体的实际价值。
  4. 无缝 GitHub 集成简化了管理。 Spaces 使用现有的 GitHub 权限并与仓库保持同步，减少了访问控制和知识时效性的开销。

💬 文章金句

  • GitHub Copilot Spaces 解决了这个问题，它让你**捆绑 Copilot 应该读取的精确上下文**——代码、文档、转录文本、示例查询等等——到一个可复用的“空间”中。
  • 没有那种上下文，AI 助手只能猜测。
  • 将空间视为一个安全、可共享的**知识容器**加上**行为指令**。
  • 自定义指令是空间的“个性层”，这也是空间真正闪光之处，因为它们与附件 *一同存在*。
  • Spaces 遵循你已使用的相同权限模型。
