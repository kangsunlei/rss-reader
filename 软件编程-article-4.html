妙言 V2.0 发布：全新“New Face”，专为工程师打造的 Markdown 笔记本

9/21/2025, 10:43:13 AM

📌 一句话摘要

开源 Markdown 笔记本工具“妙言”发布 V2.0 版本“New Face”，带来全新设计、功能优化及底层技术升级，旨在提供更适合工程师的写作体验。

📝 详细摘要

开源 Markdown 笔记本应用“妙言”（MiaoYan），一个累计维护约五年的项目，正式发布了 V2.0 版本，命名为“New Face”。此版本旨在为工程师提供更高效、更舒适的 Markdown 写作和管理体验，其核心特点包括：快捷键内容切换、类代码编辑器的原生体验、支持导出多种内容格式、Markdown 编写 PPT 以及对 LaTeX 和 Mermaid 等富文本操作的支持。V2.0 的主要更新亮点包括：全新的图标设计和更流畅的主题切换；重构的设置面板，优化了字体和语言设置并终于支持自定义字体；新增顶部导航和快捷键操作（如 ESC/→ 键切换内容）；优化导出效果，使生成内容更稳定精致；项目底层全面升级至 Swift 6，提升了代码实现并适配新特性；同时优化了异步图片上传和预览性能，提升了编辑体验的一致性。
