CC GUI：为 IntelliJ IDEA 集成 Claude Code/Codex 的可视化 AI 编程插件

4/13/2026, 1:30:15 PM

📌 一句话摘要

CC GUI 是一个开源 JetBrains 插件，为 IntelliJ IDEA 提供了 Claude Code 和 Codex 模型的可视化操作界面，支持文件上下文引入、图片识别和 MCP 服务。

📝 详细摘要

这条推文推荐了一个名为 CC GUI 的开源插件，专为使用 IntelliJ IDEA 的开发者设计。该插件在 IDE 内集成了 Claude Code 和 Codex 模型，提供了一个侧边栏对话界面。其特色功能包括：通过 @ 符号精准引入工程中的代码文件作为对话上下文；支持发送图片以说明复杂需求；能够对 AI 生成的代码进行 Diff 差异比对。此外，插件还内置了 Agent 系统和 MCP 服务支持，可用于处理复杂任务。插件可直接从 JetBrains 市场安装，支持主题适配和中英文切换。
