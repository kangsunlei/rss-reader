新型 CSS 攻击可突破 Webmail 防线，窃取密码与令牌

8/10/2026, 10:30:00 AM

📌 一句话摘要

新型 CSS 攻击利用 Webmail 的 HTML 与 CSS 漏洞，可窃取密码、令牌并劫持 AI 邮件操作，提醒服务商加强沙箱隔离与 CSS 限制。

📝 详细摘要

FreeBuf 报道了在 Black Hat USA 2026 上展示的最新 CSS 攻击研究。研究者利用 Webmail 允许的 HTML 与 CSS 以及浏览器差异，构造两条攻击路径：一是通过 label 元素和媒体查询在 Outlook/Firefox 中伪装密码输入框，实现实时密码捕获；二是利用 Yahoo/AOL 的粘贴竞态和 Gmail 的 image‑set() 回退机制，泄露登录令牌并劫持 Slack、Claude Cowork 等 AI 邮件工具。部分服务已修复漏洞，但 Outlook 的 label‑jacking 与 Gmail 的 image‑set() 绕过仍在生效。论文建议将 HTML 邮件沙箱化、限制 CSS、禁用自定义属性和下拉菜单等防御措施。

💡 主要观点

  1. 两条 CSS 攻击路径可跨越邮件与受信任界面之间的安全边界。 一种利用 label 与媒体查询在 Outlook/Firefox 中伪装密码框，实现实时密码捕获；另一种利用粘贴竞态和 image‑set() 绕过，泄露登录令牌并劫持 AI 邮件工具。
  2. 多家主流 Webmail 服务仍存在未修复的 CSS 漏洞。 Fastmail 已修复两处漏洞，Proton Mail 代理绕过失效，但 Outlook 的 label‑jacking 与 Gmail 的 image‑set() 绕过仍可用，攻击者可继续窃取凭证。
  3. 防御建议包括沙箱化 iframe、严格 CSS 白名单以及禁用下拉菜单等。 作者建议将 HTML 邮件隔离在沙箱化 iframe 中，限制 CSS、自定义属性、select 元素和图片请求，以阻断攻击链的关键环节。

💬 文章金句

  • 该论文呈现的是概念验证（proof-of‑concept）研究，并未报告恶意利用事件。
  • 研究人员称，Fastmail 已修复两个 CSS 突变漏洞，Proton Mail 的代理绕过在他重新测试时已不再生效。
  • 论文建议 Webmail 服务商将 HTML 邮件隔离在沙箱化 iframe 中，并严格限制 CSS、自定义属性、下拉菜单（select menu）和图片请求。
