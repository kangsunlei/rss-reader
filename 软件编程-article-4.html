微软官方开源：一键把全新 Windows 11 变成干净、清爽的开发机

9/27/2026, 8:13:35 PM

📌 一句话摘要

微软开源 Windows Developer Config 工具，通过 PowerShell 脚本一键完成 Windows 11 开发环境配置，包括移除系统干扰项、预装主流开发栈及优化终端体验。

📝 详细摘要

微软近期在 GitHub 上开源了名为 Windows Developer Config 的配置工具，旨在解决新装 Windows 11 系统后繁琐的开发环境搭建问题。该工具提供「标准」和「完整」两种模式：标准模式主要清理开始菜单和文件资源管理器中的推荐与干扰内容，并安装 VS Code、Git、Python、Node.js 等核心开发组件；完整模式则进一步深度定制系统行为，如关闭 Widgets、禁用搜索 Web 结果、开启开发者模式和长路径支持等，实现真正的「无干扰」开发体验。此外，工具还包含 WSL Comfort 模块用于自动化配置 Linux 终端环境（如 zsh、Starship 等），以及 Single-language workloads 功能允许用户按需单独安装特定语言环境（如仅 Python 或 Java）。这一官方工具的推出显著降低了 Windows 平台开发者的初始配置成本。

💡 主要观点

  1. 提供分级配置方案以平衡易用性与深度定制 工具分为 Standard 和 Full 两种模式。Standard 模式侧重于基础软件安装和轻度界面清理，适合大多数用户快速上手；Full 模式则深入系统底层设置，关闭各类广告、通知和非必要服务，适合追求极致纯净环境的资深开发者。
  2. 覆盖从原生 Windows 到 WSL 的全链路环境配置 除了配置 Windows 原生开发环境（VS Code， Git， .NET 等），工具还专门提供了 WSL Comfort 模块，可自动配置 Ubuntu 下的 Shell 环境（zsh/bash， Starship， fzf 等），解决了跨平台开发中 Linux 子系统的重复配置痛点。
  3. 支持模块化按需安装，避免冗余 通过 Single-language workloads 功能，用户可以只安装特定语言所需的运行时和工具链（如仅安装 Python 3.14 + uv 或 Java OpenJDK），而不必引入整套重型 IDE 或无关依赖，提高了配置的灵活性。
