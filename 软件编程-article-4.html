基于 LLM 的 AI 应急：多模态信息智能化分析整合助力字节事故处置效率提升 30%

6/4/2025, 3:37:00 AM

📌 一句话摘要

字节跳动基于 LLM 多模态能力提升事故应急效率 30%，涵盖智能监控、变更推荐及信息整合。

📝 详细摘要

文章介绍了字节跳动基础架构团队如何利用大型语言模型（LLM）的多模态信息分析能力，赋能其 GOC（全球运维中心）的事故应急流程。针对海量报警难处理、故障根因定位慢、多方协同信息同步效率低等痛点，团队构建了基于 LLM 的智能化解决方案。核心能力包括全链路智能监控与诊断（提升 MTTR 收敛率）、智能变更推荐（提升 MTTK 收敛率）和智能问答与总结（提升信息同步效率 30%+）。实践表明，该方案显著提高了事故应急初期的研判、发起、定位和信息同步效率，平均 MTTR 和 MTTK 均有大幅收敛。文章最后展望了实现值班台无人值守、主动交互和构建 GOC Agent 等未来规划。

💡 主要观点

  1. LLM 赋能全链路智能监控诊断，加速根因定界 整合全链路核心指标，利用时序异常检测和 LLM 专家经验，快速定界根因组件/实例，将 MTTR 收敛 39.91%。
  2. 智能变更推荐利用 LLM 提升故障定位效率 通过 LLM 改写变更对象、完善故障信息并判断相关性，将变更类故障的 MTTK 收敛 59.24%。
  3. 基于 LLM 的智能问答与总结，提高信息协同效率 学习多模态信息，自动回答故障进展等关键问题，减少人工梳理，提升应急工作效率 30%以上。
  4. 将 LLM 应用于应急流程多环节，实现整体提效 从事故发现、根因定位到信息同步，LLM 的应用贯穿应急流程，实现了事故应急的 AI 智能化升级，整体效率提升 30%。

💬 文章金句

  • 基础架构-SRE-GOC、基础架构-SRE-数据化和基础架构-SRE-基础平台三个团队深入合作，将 LLM 的多模态信息智能化分析能力应用于故障应急领域，助力事故应急的 AI 智能化升级，事故应急整体效率提升 30%。
  • 全链路的智能监控和诊断，赋能事故及时发现和初步定界，迅速拉起相关方应急。
  • 可疑变更推荐先基于时间相关性、故障语义相关性等因素进行初步排序，但是在这个过程中存在上报故障不准、产品知识缺乏、变更事件上报不规范等问题，导致初步排序效果不佳。我们引入 LLM 的总结和推理能力进行精排。
  • 故障应急期间，GOC 信息同步工作大部分可由 LLM 代替，工作提效 30%；在涉及多部门的复杂故障场景下，通过聚合答复与主动推送，进一步提升了沟通效率，整体应急效率可提升 40%+。
  • 未来，我们将沉淀更多私域知识，训练 LLM 成为一个越来越聪明的稳定性值班长。
