VS Code 新功能：提示变身可执行程序

📌 一句话摘要

GitHub 展示了一项新功能，允许开发者直接在 Visual Studio Code 中为 GitHub Copilot 创建并运行可执行的 `.prompt.md` 文件，将提示转化为程序。

📝 详细摘要

这条来自 GitHub 的推文介绍了一项强大的工作流程增强，专为在 Visual Studio Code 中使用 GitHub Copilot 的开发者设计。通过创建 `.prompt.md` 文件，开发者可以将自然语言提示转化为可执行程序，并一键运行 AI 生成的代码或脚本。这不仅增强了 AI 辅助的互动性，也优化了开发流程，提高了生产力。
