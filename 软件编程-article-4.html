规模化人类判断：Dropbox 如何利用 LLM 改进 RAG 系统的标注

3/7/2026, 6:00:00 PM

📌 一句话摘要

Dropbox 利用“人类校准的 LLM 标注”工作流来扩展其 RAG 系统的相关性数据，通过使用 LLM 增强人类判断，实现了 100 倍的效率提升。

📝 详细摘要

本文探讨了 Dropbox 工程师如何通过解决文档检索瓶颈来改进“Dropbox Dash” RAG 系统。由于 RAG 的性能在很大程度上取决于搜索排名的质量，Dropbox 开发了一种需要大量标注查询-文档对的监督学习方法。为了克服人工标注成本高、速度慢的问题，他们实施了一个“人类校准”系统，即使用少量高质量的人工标签来校准 LLM。随后，该 LLM 会生成数百万个标签。该过程包括针对“硬错误”（LLM 评分与实际用户点击之间的差异）的复杂错误分析，并允许 LLM 进行内部搜索以理解公司特定的术语，从而确保在专业语境下的高准确性。

💡 主要观点

  1. 在大规模企业环境中，文档检索质量是 RAG 系统的主要瓶颈。 索引中包含数十亿个文档，RAG 系统只能处理极小的一部分。因此，排名模型识别最相关文档的能力是决定最终回答质量的最关键因素。
  2. “人类校准的 LLM 标注”工作流在保持高准确性的同时，将人类的工作效能放大了约 100 倍。 通过使用少量由人类标注的金标准数据集来校准 LLM 评估器，Dropbox 能够以纯人工流程所需成本和时间的一小部分，生成数百万个高质量标签。
  3. 关注“硬错误”为提高排名模型的性能提供了最强的学习信号。 评估过程专门针对 LLM 的判断与实际用户行为发生冲突的情况（例如用户点击了 LLM 评为低相关性的文档），从而突出模型改进的关键领域。
  4. 通过内部术语查询进行上下文落地，对于基于 LLM 的准确相关性评估至关重要。 为了防止由内部术语引起的错误，系统允许 LLM 进行额外的搜索并查阅内部文档，确保模型理解其正在标注的查询的具体业务语境。

💬 文章金句

  • Dash 只能将检索到的文档中的一小部分传递给 LLM。这使得搜索排名的质量——以及用于训练它的标注相关性数据——对最终回答的质量至关重要。
  • 人类标注一个少量的高质量数据集，随后用于校准 LLM 评估器。LLM 接着生成数十万甚至数百万个标签，将人类的工作效能放大了约 100 倍。
  • 评估还侧重于最难的错误，即 LLM 的判断与用户行为不一致的情况，例如用户点击了 LLM 评级较低的文档，或跳过了 LLM 评级较高的文档。
  • 允许 LLM 运行额外的搜索、查找上下文并理解内部术语，这显著提高了标注的准确性。
