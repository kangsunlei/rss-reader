Netflix 如何使用 Maestro 编排数百万个工作流作业

4/15/2025, 3:31:16 PM

📌 一句话摘要

Netflix 使用 Maestro 来编排大规模、高可靠性的工作流作业。

📝 详细摘要

Netflix 使用 Maestro 来克服其之前的工作流调度器 Meson 的瓶颈。Maestro 具有分布式、可扩展的架构，能够以高可靠性和低运营成本处理大量的工作流和作业。它通过无状态微服务架构、分布式队列、用于持久存储的 CockroachDB 以及对嵌套 foreach 循环的支持来实现这一点，从而实现水平可扩展性。Maestro 通过预定义的步骤类型、直接的 Jupyter notebook 执行和 Docker 容器支持，简化了工作流定义和执行。它还提供了多种创建和管理工作流的方式，包括 DSL (YAML、Python、Java) 和图形用户界面 (GUI)。这些选择满足了具有不同技术背景的用户的需求，从而增强了用户友好性。

💡 主要观点

  1. Maestro 的核心是基于微服务的架构，该架构允许系统有效地扩展。 Maestro 的所有服务都构建为无状态微服务，允许任何服务实例处理请求，无需在服务内部存储会话或工作流数据。
  2. Maestro 使用分布式队列来处理组件之间的通信并协调工作流执行。 这些队列将服务彼此分离，允许每个服务以自己的速度处理请求，并实现跨系统的可靠消息传递，即使在流量高峰或故障期间也是如此。
  3. Maestro 使用 CockroachDB 来持久存储工作流定义、步骤实例和状态数据。 CockroachDB 是一个分布式 SQL 数据库，提供强大的数据一致性保证，非常适合 Maestro 的水平可扩展性和高可用性要求，而无需显著的运营复杂性。
  4. Maestro 支持嵌套的 foreach 循环，从而能够构建复杂的、大规模的工作流，这些工作流可以在单个工作流实例中执行数百万甚至数十亿个单独的步骤。 此功能允许用户构建可以动态扩展到大量任务运行的工作流，同时保持可管理性和高性能。
  5. Maestro 通过各种 DSL 和 UI 为具有不同技术背景的用户提供服务。 用户可以从 YAML、Python、Java DSL、图形用户界面或编程 API 中进行选择，以根据其需求和偏好定义和管理工作流。

💬 文章金句

  • Maestro 从一开始就构建了一个分布式、可扩展的架构，能够处理大量的工作流和作业，同时保持高可靠性和低运营成本。
  • Maestro 设计的核心是基于微服务的架构，该架构允许系统有效地扩展。
  • 为了处理组件之间的通信并协调工作流执行，Maestro 使用分布式队列。
  • 此外，Maestro 支持嵌套的 foreach 循环，这意味着一个 foreach 块可以包含另一个。这允许用户构建复杂的、大规模的工作流，这些工作流可以在单个工作流实例中执行数百万甚至数十亿个单独的步骤，同时保持可管理性和高性能。
