别再骂 Claude 限速了，Boris 亲口承认：最挑剔的用户，反而最离不开我们

5/22/2026, 8:42:00 AM

📌 一句话摘要

Anthropic Claude Code 负责人 Boris 在深度访谈中系统性阐述了 AI Agent 的发展现状、Token 限制争议、自我改进前景以及 AI 时代的商业护城河，揭示了 Anthropic 内部已实现 Claude Code 100% 自开发的里程碑。

📝 详细摘要

本文是 InfoQ 对 Anthropic Claude Code 负责人 Boris 在《Big Technology Podcast》访谈的编译整理。Boris 在近一小时的对话中，围绕多个核心议题展开讨论：Claude Code 的爆发式增长已使 Anthropic 年营收预估达 450 亿美元；产品已实现 100% 自开发，从 Opus 4.5 时期就已开始；针对用户对 Token 限制的抱怨，Boris 表示重度用户占比很小，且已翻倍额度并上线新算力；他驳斥了 Token 刷量是主流现象的质疑，认为企业应围绕 AI 重构业务流程；对于 Agent 效率问题，他认为智能优先于效率，模型能力正在快速迭代；他预测 AI 自我改进可能在 2028 年左右发生，但强调安全是前提；在商业层面，他认为网络效应等护城河依然有效，但切换成本会被削弱；最后，他通过非工程师用户成功使用 Claude Code 的案例，论证了 AI Agent 并非技术幻觉。

💡 主要观点

  1. Claude Code 已实现 100% 自开发，Anthropic 内部形成 AI 写 AI 的闭环。 从 Opus 4.5 时期开始，Claude Code 的代码已完全由自身编写，Cowork 也是如此。这标志着 AI 自我递归增强的早期阶段已在实际产品中实现。
  2. Token 限制问题被夸大，重度用户占比小，但 Anthropic 已采取措施应对。 Boris 指出大部分用户不会频繁触达 Rate Limit，但重度用户（如同时运行数百个 Agent）确实面临挑战。公司已翻倍额度、上线新算力，并计划将 Token 消耗透明化。
  3. AI Agent 的效率问题可通过模型智能提升和用户控制来解决。 Boris 认为智能优先于效率，模型变聪明后再优化效率。用户可通过选择模型（Opus/Sonnet/Haiku）和设置 Effort 级别来控制 Token 消耗。
  4. AI 时代商业护城河将分化：网络效应增强，切换成本削弱。 Boris 引用《Seven Powers》框架，认为网络效应和规模经济依然强大，但 AI 降低了系统迁移成本，企业需重新审视自身护城河。
  5. 非工程师用户正在成为 AI Agent 的重要使用群体，市场验证充分。 通过 Hackathon 案例（医生、电工、木工获奖）和用户主动学习 Terminal 安装 Claude Code 的行为，Boris 论证了 AI Agent 并非技术幻觉。

💬 文章金句

  • Claude Code 本身，现在已经是 100% 使用 Claude Code 开发的。
  • 我认为 token 刷量并不占据主流使用比例。
  • 我们一般是先提升能力，再优化效率。
  • 未来企业真正应该思考的问题是：你的护城河到底是什么？
  • 真正重要的问题只有一个：人们会不会每天持续使用它？而现在答案是：会。
