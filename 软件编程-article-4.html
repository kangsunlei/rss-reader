这个新的 Linux 发行版故意违法…

📌 一句话摘要

Fireship 探索 Ageless Linux 项目，该项目通过在操作系统层面提供禁用强制年龄验证 API 的脚本来规避加州《数字年龄保证法》。

📝 详细摘要

本视频探讨了加州 AB 1043（《数字年龄保证法》）的影响，该法案要求从 2027 年 1 月起在操作系统层面进行年龄验证。演示者认为，这项由 Meta 和 OpenAI 等大型科技公司支持的立法，实际上是打着儿童保护幌子的监控基础设施。视频重点介绍了 Ageless Linux——一个基于 Debian 的脚本，可禁用年龄验证 API 并修改系统元数据以声明不合规。视频解释了运行该脚本如何在法律上将用户归类为「操作系统提供商」，可能使每位使用该系统的加州儿童面临 7500 美元的罚款。本内容既是技术文档，也是关于数字隐私权的政治评论。

💡 主要观点

  1. 加州《数字年龄保证法》要求在 2027 年前实现操作系统层面的年龄验证 该立法要求所有操作系统收集用户年龄信息，并为开发者提供用作访问控制的 API，从根本上改变了设备连接互联网的方式。
  2. Ageless Linux 通过脚本化公民不服从提供技术解决方案 该项目提供了一个 Debian/Ubuntu 脚本，可修改系统发布元数据并部署无效的年龄验证 API，使系统有效地选择不遵守该法律。
  3. 部署该解决方案的用户存在法律风险 运行该脚本在技术上将用户归类为「操作系统提供商」，可能使他们因未提供年龄收集界面而面临每位儿童 7500 美元的罚款。
  4. 该立法是打着儿童保护幌子的监控基础设施 演示者认为，要求所有联网设备进行身份验证创建了一个有利于大型科技公司同时消除网络匿名的监控系统。

💬 文章金句

  • 到 2027 年，你的操作系统必须知道你的确切年龄，才能让你连接应用程序和网站。
  • 一旦所有设备都连接并进行身份验证，就会形成一个无法逃脱的监控系统。
  • Ageless Linux 不是一个新的发行版，而是一个誓言违反所有年龄验证法律的转换脚本。
  • 在那个未来，孩子们未经大型科技守门人批准就无法连接互联网。
