📌 一句话摘要

本期 Node 中文周刊汇总了 npm v12 默认禁用安装脚本、Node 27 改为年度大版本、Node-RED 5.0 编辑器重大改版等关键动态，以及多篇深度技术文章与工具更新。

📝 详细摘要

本期周刊以 Node.js 生态安全与版本演进为主线。头条是 npm v12 将默认阻止安装脚本（preinstall/install/postinstall），需通过 `npm approve-scripts` 显式批准，这是对供应链攻击的回应；同时默认不再解析 git 或远程 URL。Node 27 起改为每年一个大版本，并新增 alpha 通道用于试验。数据方面，热门 npm 包的 ESM 支持率升至 38%。深度文章涵盖 Playwright Fixtures API 原理、Deno 发展方向反思、VS Code Agent Hook 实践。工具方面，Node-RED 5.0 带来史上最大编辑器改版（深色主题、侧边栏更新、可暂停调试），DepsGuard 可提前加固包管理器配置。快讯包括 Node.js 安全更新预告、npm 蠕虫攻击持续、Drizzle ORM 因 npm 元数据上限无法发布等。

💡 主要观点

  1. npm v12 默认禁用安装脚本，以应对供应链攻击。 preinstall、install、postinstall 脚本默认不执行，需通过 `npm approve-scripts` 显式批准；同时默认不再解析 git 或远程 URL。用户可提前升级到 npm 11.16.0 查看警告。
  2. Node 27 起改为每年一个大版本，并新增 alpha 通道。 Luciano Mammino 的文章深入分析了新发布节奏的变化原因与影响，旨在加快试验性功能的迭代速度。
  3. 热门 npm 包的 ESM 支持率升至 38%，其中 16% 为纯 ESM。 Titus Wormer 的半年期统计显示，ESM 采用率持续增长，但纯 ESM 包仍占少数，CJS/ESM 双格式兼容仍是主流。
  4. Node-RED 5.0 发布史上最大编辑器改版。 侧边栏全面更新、加入深色主题、可暂停的调试输出，以及在 Function 节点中调用 Link 节点的能力，显著提升低代码开发体验。
  5. DepsGuard 等工具可提前加固包管理器配置。 在 npm v12 正式发布前，DepsGuard（基于 Rust）可审计并重写 npm/pnpm/Yarn/Bun 配置，禁用安装脚本、强制冷却期等。

💬 文章金句

  • npm v12 将不再执行 preinstall、install 或 postinstall 脚本，除非你通过新的 npm approve-scripts 工作流显式批准。
  • 从 Node 27 开始，Node 将改为每年发布一个主版本，并新增一个「alpha」通道用于测试与试验。
  • Node-RED 5.0 迎来了「史上最大的一次编辑器体验变化」：侧边栏全面更新、加入深色主题、可暂停的调试输出。
