📝 详细摘要

此推文是作者对 Quoted Tweet 中 Git Worktree 脚本的更新。原脚本在处理主仓库路径时可能要求严格的命名格式，现在通过 AI 的建议，更新为使用 Git 原生命令 `git rev-parse --git-common-dir`。这个命令能返回主仓库的 `.git` 目录路径，从而更简单、不易出错地获取主仓库的真实路径。这一改进提高了脚本的健壮性和易用性，方便开发者更好地利用 Git Worktree 进行并行开发。推文还提供了更新后的 Gist 链接和演示视频。
