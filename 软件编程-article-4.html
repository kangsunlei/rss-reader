尤雨溪：Vite 换“芯”发布，性能更强！

6/1/2025, 2:06:00 AM

📌 一句话摘要

尤雨溪发布基于 Rust 新打包工具 Rolldown 驱动的 Vite 技术预览版，显著提升构建性能。

📝 详细摘要

尤雨溪宣布基于 Rust 编写的新一代打包工具 Rolldown 正式驱动 Vite，并发布了技术预览版 rolldown-vite。Rolldown 旨在替代 Vite 目前使用的 Rollup，通过 Rust 语言的性能优势，显著提升了生产构建阶段的速度和内存效率。测试显示，构建时间可缩短 3 到 16 倍，内存使用最多减少 100 倍。rolldown-vite 兼容现有 Vite 项目，且底层集成了 Rust 工具集 Oxc，优化了代码解析、转换和压缩。当前以独立包发布，未来计划稳定后合并至 Vite 主包。

💡 主要观点

  1. Vite 换用 Rust 构建的 Rolldown 提升性能 用 Rust 重写打包工具 Rolldown 替换 Rollup，显著提升生产构建速度和内存效率，优化前端工作流。
  2. 集成 Oxc 工具集增强代码处理能力 Rolldown 采用 Rust 编写的 Oxc 工具集进行解析转换压缩，相比 esbuild 等有更好表现，提升构建质量。
  3. 发布技术预览版方便用户尝鲜 `rolldown-vite`作为独立包发布，用户可轻松替换现有 Vite 依赖进行测试，收集反馈以推进主包集成。

💬 文章金句

  • 性能提升显著：在多个项目中测试显示，生产构建时间缩短 3 到 16 倍，内存使用最多减少 100 倍。
  • 兼容现有项目：rolldown-vite 可替代原有 Vite 包，配置无需大改。
  • 基于 Oxc 构建：Rolldown 使用 Oxc 工具集代替 esbuild，在代码解析、转换和压缩方面表现更好。
  • 当前 rolldown-vite 以独立包形式发布，方便试用和反馈收集。
