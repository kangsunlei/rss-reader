Jaade：一个让 coding agent「跑得见、管得住」的 macOS 桌面工作台

7/5/2026, 2:51:45 PM

📌 一句话摘要

Jaade 是一个 macOS 本地桌面工作台，将 Claude Code、Codex 等 coding agent 的会话、终端、文件与版本控制整合进一个可视可控的界面，解决 agent 工作过程黑盒化的问题。

📝 详细摘要

作者介绍了一款名为 Jaade 的 macOS 桌面应用，旨在解决当前 coding agent 工作过程不透明、难以管控的问题。Jaade 将 Claude Code、Codex、OpenCode、Cursor 四种 agent 集成到一个统一的工作台中，提供多会话管理、可视化思维导图式的 Session Overview、内置终端与 Git 审查、项目任务 DAG 编排以及用量分析等功能。文章详细阐述了产品的设计理念——让开发者始终作为决策者，在 agent 的每一步操作落地前都能进行审查，并提供了丰富的功能截图与下载链接。作者表示该工具已成为其主力开发环境。

💡 主要观点

  1. 当前 coding agent 的工作过程如同黑盒，缺乏可见性与可控性。 作者指出，agent 在后台运行大量命令和文件修改，开发者只能在事后审查，Jaade 的设计初衷就是让整个过程保持透明。
  2. Jaade 通过统一工作台整合了 agent 会话、终端、文件与版本控制。 应用将多 agent 会话管理、真正的 PTY 终端、文件编辑器与 Git 审查工具集成，让开发者无需切换窗口即可完成所有操作。
  3. Session Overview 将 agent 运行过程渲染为可缩放的思维导图。 这是产品的亮点功能，将每次 agent 运行的每个步骤、工具调用和文件编辑都可视化为节点，便于实时监控和历史回溯。
  4. 开发者始终是决策者，每一步改动落地前都能审查。 Jaade 的设计哲学强调人的主导地位，通过显式的权限控制和审查机制，确保 agent 的行为在开发者的监督下进行。

💬 文章金句
