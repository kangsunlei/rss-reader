App 时代要结束了？OpenAI 总裁：未来用户只需指挥 Agent，每个软件都得学会被调用

8/3/2026, 9:40:00 AM

📌 一句话摘要

本文基于 OpenAI 总裁 Greg Brockman 的访谈，阐述 Agent 时代软件交互范式的转变：用户只需下达目标，Agent 将接管界面并调用软件能力，要求开发者将 App 转变为可被安全调用的工具。

📝 详细摘要

文章基于 Greg Brockman 的采访，阐述了 Agent 时代软件交互范式的转变：用户不再打开 App，而是通过 Agent 调用软件能力。作者详细分析了这一转变对开发者的工程挑战，包括云端状态管理、工具接口标准化（MCP）、幂等性设计、权限隔离以及可审计性。最后给出了六条具体的改造建议，帮助开发者将业务逻辑从 UI 流程中抽离，以适应 Agent 的调用方式。

💡 主要观点

  1. App 的角色从用户操作入口转变为 Agent 可调用的能力集合。 用户只需下达目标，Agent 在后台调用 Codex、浏览器等工具完成任务，界面将更多用于展示进度和风险确认。
  2. 开发者需解决状态管理、工具接口标准化、幂等性、权限隔离及可审计性等工程问题。 文章深入探讨了云端执行、清晰的输入输出定义、防止重复执行的幂等键设计、按任务分配最小权限等具体技术要求。
  3. 建议将核心能力抽离为服务，提供清晰的 API 或 MCP 接口，并按任务分配最小权限。 开发者应优先改造边界清楚的工作流，将业务逻辑从 UI 流程中解耦，确保软件具备被 Agent 安全调用的能力边界。
