看到有 V 友做了拼豆站，手痒也 Vibe Coding 了一个拼豆图纸生成器

6/16/2026, 11:26:30 AM

📌 一句话摘要

作者受社区启发，使用 Vibe Coding 方式快速开发了一个将照片自动转为拼豆图纸的在线工具，并分享了当前 MVP 的功能、技术栈与下一步计划。

📝 详细摘要

作者在 V2EX 看到拼豆项目后，利用 Vibe Coding 方式快速开发了 PindouAI 工具站。该工具的核心功能是将用户上传的照片自动像素化，并映射到 Perler、Hama 等主流拼豆品牌的色板，生成带色号标注的施工图。文章介绍了已实现的核心生成算法、参数调节（亮度/对比度/过滤白底）、PNG 图纸导出功能，以及基于 Next.js + Tailwind CSS + Cloudflare Pages 的技术栈。作者明确当前为 MVP 版本，尚未实现用户系统与云端存储，并诚邀社区测试算法效果与反馈 Bug。

💡 主要观点

  1. 用 Vibe Coding 快速验证了一个垂直工具创意。 作者受社区项目启发，利用 Vibe Coding 方式在短时间内完成了从想法到 MVP 的落地，体现了 AI 辅助开发在快速原型验证中的价值。
  2. 核心功能是照片到拼豆图纸的自动转换。 工具实现了上传图片、自动像素化、映射主流品牌色板、生成带色号网格的施工图这一完整流程，解决了手动打点的痛点。
  3. 当前为 MVP 版本，功能聚焦于工具核心。 作者明确暂未实现用户系统与云端存储，优先保证核心生成逻辑的可用性，并计划后续用 D1 数据库完善登录与图纸保存功能。
