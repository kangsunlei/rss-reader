在 Visual Studio Chat 中引入自定义模型

8/20/2025, 3:40:20 PM

📌 一句话摘要

VS Chat 现在支持通过 API 密钥集成主要提供商的外部 LLM。

📝 详细摘要

本文宣布了 Visual Studio Chat 的一项新功能——引入自定义模型功能，使开发人员能够连接来自 OpenAI、Anthropic 和 Google 的 API 密钥。这提供了更多的选择、针对安全和性能需求的定制、对使用和计费的直接控制以及在模型之间无缝切换的灵活性。它详细介绍了一个简单的五步设置过程，供现有 API 密钥持有者使用。主要考虑因素包括该功能仅限于聊天、模型能力可能存在差异，以及第三方模型输出绕过 Copilot 的负责任的 AI 过滤机制。旨在为开发者提供更多控制权，并支持他们在 IDE 中直接访问最新的 LLM。

💡 主要观点

  1. VS Chat 现在集成外部 LLM。 开发人员可以连接他们自己的 API 密钥（OpenAI、Anthropic、Google），以便在内置默认设置之外扩展模型选择。
  2. 用户可在 IDE 中更灵活地控制 AI 模型。 该功能提供了选择、针对安全/性能的定制、对使用/计费的直接控制以及无缝切换。
  3. 实施简单，但需注意特定事项。 设置很快，但仅适用于聊天，模型能力各不相同，并且一些核心 Copilot 服务仍在单独运行。

💬 文章金句

  • 我们很高兴地宣布，您现在可以在 Visual Studio Chat 中使用自己的语言模型。
  • 您可以连接来自提供商（OpenAI、Anthropic 和 Google）的 API 密钥，以访问更广泛的模型。
  • 这使得测试最新版本、自定义工作流程或在您控制的基础设施上运行变得容易。
  • 此功能目前仅适用于 Visual Studio 中的 Chat（不包括完成、提交消息或其他 AI 功能）。
  • 来自第三方模型的输出直接来自提供商，可能不会通过 Copilot 的负责任的 AI 过滤器。
