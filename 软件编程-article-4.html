把最新开源的 2B 端侧模型接入 DeepSeek Harness，有点子神奇。

9/8/2026, 4:11:00 AM

📌 一句话摘要

面壁智能开源 MiniCPM5-2B 端侧模型，作者将其接入 DeepSeek Harness 实现本地 Agent 运行，展示了端侧 Agent 在隐私保护和低成本方面的优势。

📝 详细摘要

文章介绍了面壁智能最新开源的端侧语言基础模型 MiniCPM5-2B，该模型在 Artificial Analysis 开源模型榜单中排名第一，具备工具调用、深度搜索和代码生成等能力，初步形成端侧通用 Agent 雏形。作者将模型接入 DeepSeek Harness，演示了处理本地会议纪要和批量解析简历等场景，强调端侧 Agent 在数据隐私、离线工作和成本控制上的优势。文章还提及面壁智能在预训练、SFT 和强化学习阶段的专项优化，以及配套开源的 UltraData 系列数据和 Meshy、JustRL II 两项强化学习技术，最后提供了通过 llama.cpp、Ollama 或 DeepSeek Harness 部署的简要指引。

💡 主要观点

  1. MiniCPM5-2B 在 4B 以下参数模型中表现领先，具备端侧通用 Agent 雏形 该模型在 Artificial Analysis 开源模型榜单中以 23 分排名第一，领先第二名 7 分，并超过多款 3B、4B 模型，体现了较强的参数效率。其能力覆盖工具调用、深度搜索和代码生成，可处理更完整的任务。
  2. 端侧 Agent 相比云端 Agent 具有隐私、离线、成本优势 端侧模型运行在本地设备，数据无需上传，断网也能工作，且没有持续调用云端 API 的费用。作者通过 DeepSeek Harness 接入 MiniCPM5-2B，演示了处理敏感会议纪要和批量解析简历等场景，说明其适合处理敏感数据和批量结构化任务。
  3. 面壁智能开源了配套的训练数据和强化学习技术，提升模型可复现性 文章提到 UltraData-Code、UltraData-SFT-Agent-2609、UltraData-RL-2609、UltraX 等数据集的开放，以及 Meshy 和 JustRL II 两项强化学习技术，这些资源有助于社区复现和改进模型，体现了对数据质量和训练过程的重视。

💬 文章金句

  • 端侧 Agent 则把模型运行在手机或你的电脑上。
  • 它的价值是数据不用上传、断网也能工作，响应很快，也没有持续调用云端大模型 API 的费用。
  • 端侧 Agent 很适合处理敏感数据。
  • 聊天记录、会议纪要、合同和邮件可以留在本地电脑中，上传云端可能会有隐私顾虑。
