Node.js 被黑客武器化，合法运行时变为恶意软件投递工具

9/4/2026, 10:00:00 AM

📌 一句话摘要

攻击者利用 Node.js 的合法签名和灵活性，将其作为恶意载荷的投递和执行平台，绕过传统基于签名的检测，并在多个行业中实施持久化攻击。

📝 详细摘要

自 2026 年 2 月以来，威胁行为者在针对政府、科技和酒店行业的攻击中，频繁使用 Node.js 运行时来部署恶意软件。通过下载官方安装程序并执行恶意脚本，攻击者能够建立长期访问权限，并利用 EtherHiding 等技术隐藏命令与控制通信。这种手法因其合法性和隐蔽性，已被多个组织采用，包括与 ModeloRAT 和 Mistic 后门相关的攻击。

💡 主要观点

  1. 合法工具的滥用 Node.js 作为一款广泛使用的开发工具，其可执行文件具有合法签名，这使得攻击者可以绕过基于签名的安全检测，将恶意代码伪装成正常运行的脚本。
  2. 持久化与隐蔽性 攻击者通过修改注册表中的 Run 键，确保恶意脚本在每次系统登录时自动执行，从而实现持久化。同时，利用 EtherHiding 技术，他们能够将命令与控制信息隐藏在区块链交易中，进一步增加检测难度。
  3. 多组织协同攻击 这种攻击手法并非孤立，而是被多个威胁行为者（如 KongTuke 和 Woodgnat）用于不同的攻击链中，包括部署 AdaptixC2、Cobalt Strike 和 C2Looper 等后门，表明其在地下市场中的流行。

💬 文章金句

  • 该技术吸引人的地方在于，node.exe（运行 Node.js 的可执行文件）是一款合法、经过签名的开发者工具。攻击者的恶意代码存在于解释执行的脚本中，而非二进制文件中，因此不太容易触发基于签名的检测。
  • 使用 Node.js 的攻击者似乎乐于结合使用离地攻击工具和双用途工具，以及商品恶意软件和 Backdoor.Mistic、C2Looper 以及新版 AsukaStealer 等新工具。这表明不同技能水平的攻击者可能都在使用 Node.js，因为它已经重新流行起来。
