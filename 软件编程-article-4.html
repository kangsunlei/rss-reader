烧钱换能力，老员工经验作废！一线 Agent 厂商、用户经验亲述：抛弃技术驱动，巨额投入如何不打水漂？

7/21/2025, 3:41:00 AM

📌 一句话摘要

InfoQ 对话来也科技与英科医疗，揭示 AI Agent 时代企业如何“烧钱换能力”并“抛弃老员工经验”，通过模式创新和客户需求驱动，确保巨额投入不打水漂。

📝 详细摘要

文章通过 InfoQ 对 AI Agent 产品提供商来也科技 CEO 汪冠春和应用方英科医疗 CTO 陈坤的深度访谈，探讨了 AI Agent 在企业落地的多维度实践与思考。两位受访者一致认为，Agent 的应用已从最初的技术驱动转向紧密结合客户需求的模式，能否找到实际应用场景是当前竞争的关键。在投入方面，英科医疗现阶段更侧重模式创新而非短期降本增效，并计划未来实现规模化应用后向 Agent 要效益。文章还深入探讨了企业推广新技术的内部阻力与应对策略，强调拥抱新技术需要心态年轻化和组织文化转型，而非简单依赖老员工经验。在技术架构上，来也科技将 RPA 和 IDP 重新定位为智能体的工具，并推动能力原子化。同时，文章也指出了 Agent 应用面临大模型能力和业务结果量化等瓶颈，并分享了企业在成本投入衡量、C/B 端机会以及出海战略方面的经验。整体而言，文章提供了 Agent 企业级落地的全面视角和宝贵经验。

💡 主要观点

  1. AI Agent 应用从技术驱动转向客户需求驱动是关键 企业引入 Agent 的成功在于找到明确的业务场景，而非单纯追求技术先进性，强调“紧密结合客户需求”而非“拿着锤子找钉子”。
  2. 企业对 Agent 的投入应先着眼于模式创新而非短期降本增效 在 Agent 应用初期，企业应将重心放在探索新业务模式和增长点上，而非立即追求成本效益，降本增效是长期规模化应用后的必然结果。
  3. 拥抱 AI 新技术需要企业文化和人才策略的转变 成功推广 Agent 需要董事长亲自推动，营造创新文化，并招聘和培养心态年轻、接受新技术的员工，老员工经验不再是唯一标准。
  4. Agent 与传统工作流结合是企业落地的务实路径 目前端到端完全依赖智能体自主编排仍有挑战，将 Agent 能力融入现有工作流并实现能力原子化，是更稳定可靠的复合编排方式。
  5. Agent 应用面临模型能力和业务结果量化等瓶颈 通用大模型的精确度、智能体输出的“幻觉”问题，以及长业务链条中 Agent 价值的量化评估，是当前企业落地 Agent 的主要挑战。

💬 文章金句

  • Agent 的采用就像抛硬币，虽然结果难以预料，但几乎每个人跃跃欲试。
  • 当前的产研已逐渐转向“紧密结合客户需求”的模式，而非最初的技术驱动，不再“拿着锤子找钉子”。
  • 目前阶段，我们并不特别关注落地项目是否能立即带来降本增效的效果。事实上，我们正处于一个重投入的时期，因此现阶段我们更看重的是模式创新。
  • 心态是关键，年轻其实是一种心态。
  • 通用大模型可能无法完全满足我们的需求。此外，有些业务链条较长，需要较长时间才能看到实际的业务结果。
