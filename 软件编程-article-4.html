YuE2：可精细化编辑的开源音乐生成模型

9/18/2026, 1:30:04 PM

📌 一句话摘要

YuE2 是由港科大等机构推出的开源音乐模型，支持通过可编辑的旋律与和弦谱实现对歌曲的精准控制，并提供配套 Agent Skill 以集成至 AI 编程工具。

📝 详细摘要

YuE2 是一款开源音乐模型，其核心特点是将生成过程分为「谱曲」和「演唱」两步。用户可以通过修改中间生成的旋律和和弦谱来精准控制歌曲的走势，支持翻唱、风格转换及多轮对话迭代修改。该模型性能可比肩 Suno v5/v6，并提供 Agent Skill 供 Claude Code 等工具调用。硬件要求为 Linux 环境及 24GB 显存，对个人及音乐人完全免费且支持商业变现。

💡 主要观点

  1. 解耦生成流程实现精准可控 通过先生成可编辑的旋律和和弦谱，再据此生成音频，打破了传统音乐 AI 的「黑盒」生成，允许用户手动微调音符、速度和和声。
  2. 强大的风格迁移与翻唱能力 支持将现有录音转换为谱子并重新演绎，可在多轮迭代中实现从中文流行到英文爵士等大幅度的风格转变。
  3. 工程化集成与低门槛商业化 配套 Agent Skill 降低了调用门槛，且在授权上对个人和音乐人极度友好，允许作品直接变现。
