腾讯朱雀开源了一个好东西

8/18/2026, 9:05:00 AM

📌 一句话摘要

本文介绍腾讯朱雀实验室开源的 AI 红队安全平台 AI-Infra-Guard，结合作者实测展示其安装使用方式，帮助开发者检测 Agent、Skill、MCP 及大模型的安全隐患。

📝 详细摘要

文章从作者两个安全困惑切入：一是无法确认 Agent 中安装的 Skill 与 MCP 服务器是否藏有可疑代码，二是缺乏有效手段验证接入公司知识库的 Agent 是否存在提示词泄露等风险。随后介绍腾讯朱雀实验室开源的 AI-Infra-Guard（AIG）全栈 AI 红队安全平台，覆盖 OpenClaw、Agent、Skill、MCP、AI 基础设施扫描与大模型越狱评测。作者实测了通过 npx 安装 aig-agent-redteam Skill、用自然语言触发扫描的流程，重点展示自我安全检测与自动化诱导获取系统提示词两个场景，说明报告带完整证据链、数据在本机运行不外传。文章还概述了覆盖 1900+ CVE 的漏洞库、Agent Scan 等能力，并坦诚指出项目局限：需配置 LLM API Key、存在误报漏报、Web 界面无鉴权不宜公网部署。

💡 主要观点

  1. AI-Infra-Guard 是腾讯朱雀实验室开源的 AI 红队安全平台。 覆盖 Agent、Skill、MCP、AI 基础设施扫描及大模型越狱评测，可通过 npx 安装轻量 Skill 使用，也可部署完整平台。
  2. 安全检测报告带完整证据链，而非简单打分。 报告会记录触发问题的 payload、Agent 的实际响应并给出修复建议，帮助开发者快速定位与修复。
  3. 自动化多轮诱导能有效发现提示词泄露等 AI 特有漏洞。 通过假样本降低模型警惕性、多轮动态调整问法逼近目标，比手动试问更全面，实测发现系统提示词泄漏与间接注入。
  4. AIG 支持模块独立拆用，前后端完整开源。 Skill 扫描、MCP 扫描可当命令行工具单独运行，也便于集成进现有系统或按需二次开发。
  5. 项目存在局限，Web 界面不宜公网部署。 审计依赖 LLM 理解代码语义，存在误报漏报；Web 界面无鉴权机制，官方明确仅限企业内部使用。

💬 文章金句

  • 报告里不是简单打个分，而是带有完整的证据链，具体是哪条 payload 触发了问题，Agent 当时给出了什么响应，再配一条对应的修复建议。
  • 一个强大的 Agent 来自它能连更多工具、处理更多上下文、完成更多动作，风险也正来自这些能力。
  • 与其等上线后出事再翻日志复盘，不如先自己动手测一遍。
