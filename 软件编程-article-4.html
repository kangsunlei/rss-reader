用户太蠢不配用 Fable？被 Anthropic 的回应气笑了：最贵的模型，最憋屈的体验

7/2/2026, 7:29:00 AM

📌 一句话摘要

Anthropic 发布 Fable 5 但因安全过滤器导致请求被降级至 Opus 4.8，同时被曝光在 Claude Code 中嵌入隐蔽水印用于反蒸馏，引发用户对其安全叙事与商业策略的集中质疑。

📝 详细摘要

本文围绕 Anthropic 模型 Fable 5 的发布争议展开，梳理了三大焦点事件：Fable 5 的高定价（输入 $10/百万 token）与“回退机制”——安全过滤器将大量无害请求误判后转交更便宜的 Opus 4.8 处理，用户查询日志时发现“TOO_DUMB_TO_NEED_FABLE”标记，工程师回应“没想到你会去看日志”；随后揭露 Claude Code 在系统提示词中嵌入肉眼难辨的隐写字符，用于识别中国时区及中转代理请求，以实现反蒸馏目的，该行为被社区批评为“间谍软件”；最后汇总了 Reddit 等平台用户对 Anthropic 不断变更使用限制、误导性沟通、服务不透明的长期不满，以及业界对其安全神话与商业利益矛盾的剖析。文章引用了开发者、蚂蚁集团工程师陈成、前白宫官员等多方言论，指出 Anthropic 正面临维持安全品牌与提升变现效率之间的失衡。

💡 主要观点

  1. Fable 5 的安全过滤器导致用户支付双倍价格却获得旧模型回复。 新模型回退机制将大量无害编码请求标记后转交 Opus 4.8 处理，用户实际未获得付费模型的能力，引发“F1 法拉利换普锐斯”的讽刺比喻。
  2. Claude Code 嵌入隐蔽水印用于反蒸馏，暴露信任边界问题。 Anthropic 在系统提示词中通过修改日期分隔符和撇号 Unicode 编码来编码用户时区和代理信息，流量回传官方后可识别中国中转渠道。尽管称是实验性反滥用措施，但未向用户披露，被视为越界监控。
  3. Anthropic 的安全叙事与其商业实践之间的裂缝正在扩大。 公司以“安全”为品牌核心，却通过限制访问、提高价格、秘密监控等手段让用户体验受损，社区批评其安全警告是制造稀缺、推动融资的策略。
  4. 用户信任危机可能动摇 Anthropic 的企业客户基础。 越来越多开发者转向 OpenAI 或开源模型，认为 Anthropic 的定价、额度管理、服务稳定性均存在问题，而竞争对手以更低成本提供同等级别常规编码能力。
