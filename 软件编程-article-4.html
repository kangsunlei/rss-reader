Cloudflare 在 R2 SQL 中引入聚合功能以支持数据分析

1/17/2026, 6:13:00 AM

📌 一句话摘要

Cloudflare 通过聚合函数和模式发现功能增强了 R2 SQL，支持直接在 R2 数据上进行分析工作负载，减少了对独立数据仓库的需求

📝 详细摘要

Cloudflare 宣布通过引入聚合支持显著扩展了 R2 SQL 的能力。这一增强功能包括 SUM、COUNT、AVG、MIN、MAX 等聚合函数以及 GROUP BY 和 HAVING 等 SQL 子句，使开发人员能够直接在 R2 存储的数据上执行分析工作负载。这消除了对独立数据仓库工具和复杂 OLAP 基础设施的需求。文章强调这些新功能支持快速数据汇总、趋势发现、报告生成和日志异常检测。此外，R2 SQL 现在支持模式发现命令（SHOW TABLES、DESCRIBE）。Cloudflare 解释了使用 scatter-gather 和 shuffling 策略执行 GROUP BY 查询的底层分布式执行机制。文章还提到了相关更新，例如 R2 Data Catalog 中 Apache Iceberg 表的自动快照过期和压缩功能，这些功能进一步优化了查询性能。虽然 R2 SQL 仍处于公开测试阶段，但这些更新表明 Cloudflare 持续努力将数据分析能力推向边缘，使其开发者平台能够支持更广泛的工作负载

💡 主要观点

  1. Cloudflare R2 SQL 现在支持聚合函数和 SQL 子句，可直接进行分析工作负载 SUM、COUNT、AVG、MIN、MAX、GROUP BY 和 HAVING 现在可以直接在 R2 数据上使用，使开发人员无需外部数据仓库即可执行分析
  2. 新功能简化了开发人员的数据分析、趋势发现和异常检测 开发人员可以直接在 Cloudflare 平台内快速汇总数据、识别趋势、生成报告和检测日志中的异常模式，消除了 OLAP 基础设施开销
  3. Cloudflare 在 R2 SQL 中使用 scatter-gather 和 shuffling 的分布式执行机制来处理 GROUP BY 查询 这种方法允许 R2 SQL 通过在工作节点之间分发工作并收集结果来高效处理聚合查询，构建在其现有的分布式查询引擎之上
  4. R2 Data Catalog 的改进（如自动快照过期和压缩）补充了聚合能力 这些增强功能通过保持数据表的高效和整洁来优化元数据管理和查询性能，特别是对于聚合查询

💬 文章金句

  • 无论您是生成报告、监控高容量日志中的异常，还是简单地尝试发现数据趋势，现在都可以在 Cloudflare 开发者平台内轻松完成所有这些操作，而无需管理复杂 OLAP 基础设施或将数据移出 R2 的开销
  • Cloudflare 通过在 R2 SQL 中支持聚合功能，继续将数据推向边缘，扩展了开发人员可以在那里实际运行的工作负载类型
  • 没有 "HAVING" 和 "ORDER BY" 的聚合查询可以以类似于过滤查询的方式执行
  • 这些功能相辅相成，因为快照过期有助于的元数据清理/管理将加速这些聚合查询的性能，特别是在启用压缩的情况下
