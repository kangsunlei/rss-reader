Atlas 背后的架构：OpenAI 基于 ChatGPT 的新浏览器

2/11/2026, 4:30:38 PM

📌 一句话摘要

OpenAI 的 Atlas 浏览器利用名为 OWL 的解耦架构，在独立进程中运行 Chromium，从而实现了响应迅速的 SwiftUI 界面和安全的 AI 智能体功能。

📝 详细摘要

本文深入探讨了 OpenAI 新浏览器 ChatGPT Atlas 的架构。为了克服传统 Chromium 嵌入方式的局限性（如紧耦合、启动慢和 UI 定制困难），OpenAI 开发了 OWL (OpenAI’s Web Layer)。该架构将浏览器引擎分离到宿主进程中，而 Atlas 应用程序作为客户端，通过带有自定义 Swift 绑定的 Mojo IPC 进行通信。关键技术创新包括使用 macOS CALayerHost 进行跨进程渲染以实现无缝 UI 集成，以及为无头 Chromium 引擎转换原生事件的专门输入处理系统。此外，该架构通过隔离的存储分区和安全事件路由支持“智能体模式”，确保 AI 驱动的操作保持在沙箱中且是临时性的。

💡 主要观点

  1. OWL 架构将 Chromium 引擎与主应用程序进程解耦。 通过将 Chromium 作为独立的“OWL Host”运行，OpenAI 实现了 UI 的即时启动，并防止引擎挂起导致界面冻结，同时允许为浏览器外壳使用 SwiftUI 等现代原生框架。
  2. 通过 macOS 特有的图层托管技术实现跨进程渲染。 Atlas 使用私有的 CALayerHost API 将 Chromium 渲染的帧嵌入到自己的窗口中。这允许两个进程高效共享 GPU 内存，确保高性能视觉效果，而无需传统窗口嵌入的开销。
  3. 使用 Mojo 的自定义 IPC 层实现了 Swift 与 Chromium 之间的无缝通信。 OpenAI 为 Chromium 的 Mojo 系统实现了自定义的 Swift 和 TypeScript 绑定，允许 Atlas 客户端控制会话、配置文件和 Web 视图，同时为开发者保持清晰的抽象层。
  4. 智能体模式利用隔离的存储分区来确保安全和会话隐私。 为了支持 AI 驱动的浏览，Atlas 使用 Chromium 的 StoragePartition 基础设施创建临时的内存数据存储。这可以防止会话之间的状态泄漏，并确保 AI 生成的事件与特权浏览器功能隔离。

💬 文章金句

  • Atlas 不仅仅是另一个换壳的 Chromium 浏览器……OpenAI 的解决方案是构建 OWL，一个将 Chromium 作为独立进程运行的架构层。
  • 该架构背后的核心原则是，OpenAI 不再将 Chromium 嵌入到 Atlas 应用程序内部，而是在主 Atlas 应用程序进程之外运行 Chromium 的浏览器进程。
  • 进程隔离意味着如果 Chromium 的主线程挂起，Atlas 仍能保持响应。如果 Chromium 崩溃，Atlas 仍能继续运行并可以恢复。
  • OWL 不仅仅是为了在今天构建一个更好的浏览器。它为 AI 驱动的 Web 体验的未来创造了基础设施。
