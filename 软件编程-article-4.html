4 人起步，Next.js 之父带队冲出 Agent 爆款：开发者用户一年超过去十年，一秒生成 7 个应用！

9/28/2025, 11:17:00 AM

📌 一句话摘要

Vercel CEO Guillermo Rauch 分享了 V0 从“AI 搭建网页”到全栈 Agent 的演进，阐述了 Vercel AI Cloud 的基础设施愿景，并探讨了 Agent 时代下开发者的新机遇与挑战。

📝 详细摘要

文章深入访谈了 Vercel 创始人兼 CEO Guillermo Rauch，详细介绍了其产品 V0 如何从一个 AI 网页搭建工具升级为能够自动完成规划、研究、构建与调试的全栈 Agent。Rauch 指出，V0 在不到一年内用户数已超越 Vercel 过去十年的总和，生成了超过 1 亿个应用，是“Vibe coding”理念的典型体现。他将 V0 定位为验证 Vercel AI Cloud 基础设施价值的“零号病人”，旨在实现大规模智能生产。文章还探讨了“Vibe coding”与“Agentic engineering”的区别与衔接，以及 V0 通过第三方集成实现全栈能力。最后，Rauch 描绘了 AI Cloud 的愿景，即提供专为 AI 应用打造的云服务，包括自愈系统、新的安全原语和 MCP（Machine-to-Agent Communication Protocol）协议支持，以应对未来 Agent 经济的需求。他强调，在 Agent 接管代码的未来，理解系统运作、局限与抽象层演进至关重要，并分享了个人在技术选择、团队管理和终身学习方面的哲学。

💡 主要观点

  1. Vercel V0 从 AI 网页搭建工具升级为全栈 Agent，极大降低开发门槛，实现应用生成效率飞跃。 V0 的进化使得非专业开发者也能轻松将想法转化为可用的软件，每秒生成 7 个应用，一年内用户数超越 Vercel 过去十年总和，推动了“Vibe coding”的普及。
  2. Vercel 正构建 AI Cloud 基础设施，以支持大规模智能生产，并定义 Agent 时代的新型开发范式。 AI Cloud 旨在为 AI 应用提供专属服务、自愈系统和新的安全机制，通过 MCP 协议实现 Agent 间的互操作性，是企业拥抱 AI 经济的关键。
  3. 未来代码将由 Agent 接管，开发者需关注系统运作、局限性及抽象层演进，部署的价值超越编码本身。 Guillermo Rauch 强调理解底层系统和抽象层的重要性，认为部署和运行才能创造价值，并建议年轻人关注新领域、提升数学与语言能力以适应 AI 时代。

💬 文章金句

  • V0 的意义在于，可以把潜在用户规模从 140 万扩展到数亿甚至数十亿。以前需要庞大团队的全栈开发，现在借助完善的基础设施，小团队也能迅速启动，比如三四个人就能完成。
  • 未来写代码会逐渐被 Agent 接管，真正重要的，是理解系统的运作、局限与抽象层的演进。
  • 代码是静态的，唯有运行与部署，才能创造真正的价值。
  • 我们认为 AI Cloud 应当配备 Agent，直接生成解决方案，而非只报告问题。
  • 最终我们会进入一个‘完全生成式’的互联网，没有固定僵化的界面，而是不断根据用户需求、专业程度和动态环境来生成。
