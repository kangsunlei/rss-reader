所有传统职业划分都将消失？Claude Code 创始人：去年就卸载了 IDE，一株番茄促成 Claude Cowork，产品品味也不是护城河

6/4/2026, 8:03:00 AM

📌 一句话摘要

本文整理自 Claude Code 创始人 Boris Cherny 的播客访谈，分享 Claude Code 与 Claude Cowork 的起源故事，并预言传统职业角色划分将在年底消失，通才时代来临。

📝 详细摘要

本文基于对 Anthropic 核心产品负责人 Boris Cherny 的播客访谈整理而成。Boris 详细讲述了 Claude Code 的起源——最初只是一个原型设计团队的意外产物，从只能写 10%-20% 的代码，到随着 Opus 4 和 4.5 等模型能力的阶跃式提升，最终让他本人卸载了 IDE。他分享了 Claude Cowork 的诞生契机：一位用户用 Claude Code 种番茄并得到 AI 的情感回应，让他意识到大众市场时机成熟。文章核心观点是：AI 正在消解工程师、产品经理、设计师等传统职业边界，所有角色正在融合为统一的「构建者」；资历和经验不再是优势，新人反而更擅长使用 AI 工具；「产品品味」也不是护城河，因为模型很快会具备同样的能力。最终要教给模型的，是价值观。

💡 主要观点

  1. Claude Code 的能力跃升核心驱动力是底层模型的进步，而非产品功能。 Boris 指出，从只能写 10% 代码到完全替代人工，阶跃性节点来自 Sonnet 4、Opus 4 和 Opus 4.5 的发布，产品优化只是辅助。
  2. 传统职业角色划分将在年底消失，所有人将融合为统一的「构建者」。 Anthropic 内部已出现工程师做设计、设计师提交代码、财务同事也发布代码的现象，角色边界正在消解，通才的黄金时代来临。
  3. 「产品品味」不是护城河，最终要教给模型的是价值观。 Boris 认为，当前模型已能提出 20% 的好产品想法，未来绝大多数想法都会是好的；人类不可替代的领域是价值观的传递与对齐。
  4. 资历不再是优势，新人反而更擅长使用 AI 工具。 20-30 年经验的工程师需要数月「卸载」旧习惯，而刚毕业的新人能原生地利用 Claude Code，甚至反过来教老员工。

💬 文章金句

  • 所有这些关于工程师、产品经理、设计师、用户研究员的传统划分，到今年年底都将消失。
  • 人们经常谈论的一个话题是：核心的竞争优势在于「产品品味」。但我觉得这也将消失。
  • 我认为我们最终要教给模型的，是价值观，以及如何像我们教育孩子成为好人一样，去教模型如何成为一个好的模型。
  • 对于那些想要做不止一件事的人来说，现在是最有趣、也是最容易的时期。
