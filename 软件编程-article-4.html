微软发布 TypeScript 7 更新进展

1/12/2026, 5:00:00 PM

📌 一句话摘要

微软的 TypeScript 7 更新（代号 Project Corsa）正在用 Go 重写编译器，构建速度提升高达 10 倍，并默认启用严格模式，引发了开发者对性能提升的兴奋和对工具迁移的担忧。

📝 详细摘要

微软发布了 TypeScript 7（Project Corsa）的进展更新，该项目涉及用 Go 语言对 TypeScript 编译器进行根本性重写。这一转变预计将带来显著的性能提升，构建速度最高可提升 10 倍，并大幅降低内存使用量。新的原生编译器 `tsgo` 利用了 Go 的性能特性和并行处理能力。TypeScript 7 的一个关键变化是默认启用严格模式，这有助于提升类型安全性，但可能需要对现有项目进行调整。选择 Go 的理由在于其原生优先的方法、自动垃圾回收特性以及适合 TypeScript 函数式编码风格的特点。虽然开发者对性能提升表示兴奋，但也对依赖 TypeScript 编译器的工具的迁移路径和 API 兼容性表示担忧。此举使 TypeScript 与 esbuild、SWC 和 oxc 等其他高性能原生 JavaScript 工具保持一致。

💡 主要观点

  1. TypeScript 7 正在用 Go 对其编译器进行根本性重写 作为 Project Corsa 的一部分，这次重写旨在通过利用 Go 的原生能力显著提升性能，包括构建速度和内存使用效率
  2. 新的原生编译器（`tsgo`）承诺构建速度提升高达 10 倍 这一性能提升对开发者来说是一个重大利好，特别是那些处理大型代码库的开发者，并使 TypeScript 能够与其他高性能原生 JavaScript 工具竞争
  3. TypeScript 7 将默认启用严格模式，促进更好的类型安全性 这一变化虽然可能对某些项目造成破坏性影响，但符合行业最佳实践，有助于开发者更早发现错误，提高代码质量和可维护性
  4. 对现有工具的迁移路径和 API 兼容性存在担忧 转向原生 Go 编译器给工具作者带来了关于如何与新编译器 API 交互的问题，可能需要重大的调整或重写
