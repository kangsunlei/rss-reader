GitHub 开源 Security Lab Taskflow Agent

3/23/2026, 8:05:01 PM

📌 一句话摘要

GitHub 已开源其 Security Lab Taskflow Agent，这是一个旨在检测身份验证绕过 (Auth Bypasses) 和 IDOR 等复杂漏洞的 AI 驱动框架。

📝 详细摘要

GitHub 正式开源了 Security Lab Taskflow Agent，这是一款专门用于识别那些往往能逃过标准自动化扫描器的安全漏洞的工具。该 Agent 专门针对身份验证绕过 (Authentication Bypasses)、不安全直接对象引用 (IDORs) 和令牌泄露 (Token Leaks) 等复杂问题。此次发布让开发者能够将先进的 AI 驱动安全扫描直接集成到自己的开发工作流中。
