freeCodeCamp 宣布发布新的 React、性能和测试课程章节，并分享未来内容和考试的更新信息。

📝 详细摘要

本文提供了 freeCodeCamp 全栈课程体系的最新开发进展。文章宣布立即发布三个新的综合章节：React Hooks 和状态、性能以及测试，其中包括约 50 个视频、工作坊、实验和项目，例如井字棋游戏和颜色选择器。团队还说明了模块结束考试的状态，解释说它们仍在开发中，重点是创建一个自定义的隐私保护环境。展望未来，更新提到了即将推出的关于 CSS 库和 TypeScript 的模块，以及早期的 Python 内容，并预告了诸如 RPG 角色构建器和集换式卡牌游戏等项目。最后，它包含了一个行动号召，鼓励有兴趣通过 GitHub 和 Discord 为课程体系开发做出贡献的社区成员参与。

💡 主要观点

  1. freeCodeCamp 发布了涵盖 React、性能和测试的新课程章节。 这些新发布的章节通过大量内容，包括视频、工作坊和编程项目，显著扩展了全栈课程体系。
  2. 模块考试仍在开发中，重点是自定义测试环境。 虽然尚未可用，但考试正在精心开发中，旨在自定义环境中平衡学术诚信和用户隐私。
  3. 未来的课程体系更新将包括 CSS 库、TypeScript 和早期的 Python 模块。 团队正在积极开发下一波内容，扩展范围以涵盖更多 Web 开发和基础编程主题。
