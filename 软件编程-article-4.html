在 iOS 上运行 Java

11/13/2025, 6:00:00 AM

📌 一句话摘要

OpenJDK 的 Hotspot-on-iOS 项目进展显著，通过结合 Zero 解释器和源自 Leyden 项目的 AOT 编译技术，克服了 Apple 的 JIT 限制，从而使 Java 能够在 iOS 上运行。

📝 详细摘要

本文报道了 OpenJDK 的“Hotspot-on-iOS”项目的重大进展，该项目已成功使 Java 能够在 iOS 设备上构建和执行。该项目由 Gluon 的 Johan Vos 领导，其愿景是实现“一个 Java，可以在任何平台上运行”的目标，旨在将 Java 的强大功能扩展到移动应用开发领域，同时优先考虑可维护性以及与上游 OpenJDK 的完全一致。该项目的技术基础依赖于 Zero 解释器，这是一个纯 C++ 实现，确保了紧密对齐。关键挑战在于 Apple 禁止运行时生成汇编代码，这导致无法使用传统的 JIT 编译技术，从而影响性能。创新的解决方案采用了一种混合策略：利用 Zero 解释器以及提前编译 (AOT) 技术，并从 OpenJDK 的 Leyden 项目中汲取灵感和技术。这种方法旨在实现接近原生的性能，同时保留 Java 的动态特性。该项目已经为 iOS 和 Android 生成了可编译的虚拟机和类库，可以部署在真实设备上。未来的工作包括集成 GUI 工具包（如 OpenJFX），并建立协作社区，以将 Java 发展成为现代移动开发的重要选择之一。

💡 主要观点

  1. OpenJDK 的 Hotspot-on-iOS 项目已达到关键里程碑，使 Java 能够在 iOS 上构建和运行。 这一进展标志着向着允许 Java 开发人员利用其现有技能和生态系统为 Apple 的移动平台创建应用迈出了重要一步，从而实现了“一个 Java”的愿景。
  2. 该项目采用 Zero 解释器和通过 Leyden 项目进行的 AOT 编译的混合策略，以克服 iOS 的“No JIT”规则。 这种创新组合确保了动态 Java 代码的执行，同时通过预编译技术实现了高性能，从而保持了与核心 OpenJDK 的严格一致性。
  3. 核心重点是可维护性以及与上游 OpenJDK 的完全一致，这使其与以前的方法有所不同。 这项承诺保证了长期的可行性，简化了更新并减少了碎片化，从而使该解决方案对于未来的 Java 移动开发而言是强大且可持续的。
  4. 未来的工作包括集成 GUI 工具包（如 OpenJFX）并建立一个社区以进行更广泛的协作。 除了核心执行之外，启用丰富的用户界面并吸引各种开发人员的贡献对于 Java 成为移动应用的全面且具有竞争力的平台至关重要。

💬 文章金句

  • 备受期待的 Hotspot-on-iOS 项目正在报告重大进展 - OpenJDK 现在能够在 iOS 上构建和运行。
  • “一个 Java，可以在任何平台上运行”的概念仍然至关重要。Java 仍然是后端和云系统高性能、可扩展和可维护应用的绝佳选择，因此，Java 开发人员完全可以使用他们喜爱和擅长的语言和生态系统来创建移动应用。
  • 新策略是使用 Zero 解释器，并通过来自 OpenJDK 的 Leyden 项目的 AOT 编译技术和其他改进来增强 Zero，从而绕过 Apple 的“No JIT”规则。
  • Vos 认为，Leyden（用于提前创建本机代码）和 Zero（用于运行未提前编译的动态代码）的组合对于 iOS 上的 Java 来说可能是一个成功的组合，因为它允许完全执行而又不牺牲 Java 的（经常被低估的）动态特性。
  • OpenJDK Mobile 所采用的方法侧重于可维护性以及与 OpenJDK 的完全一致。
