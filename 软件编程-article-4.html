语音 AI 爆发了，这 3 个 GitHub 开源项目建议了解一下。

8/9/2026, 8:42:00 AM

📌 一句话摘要

本文整合推荐 3 个语音 AI 开源项目：一站式字幕翻译配音工具 Voice-Pro、组件可替换的 speech-to-speech 语音助手框架，以及支持边对话边执行后台任务的 Qwen Audio Agent。

📝 详细摘要

文章是一篇语音 AI 方向的 GitHub 开源项目盘点，共推荐 3 个项目。Voice-Pro 将视频下载、人声分离、字幕识别、翻译与配音整合到同一 Gradio WebUI，支持 100 多种语言和零样本声音克隆，适合内容创作者；Hugging Face 开源的 speech-to-speech 把语音助手拆成 VAD、STT、LLM、TTS 四个可替换环节，默认采用 Parakeet TDT、OpenAI 兼容接口与 Qwen3-TTS，适合搭建本地语音链路；Qwen Audio Agent 将前台语音对话与后台 Agent 任务并行化，支持在执行任务时追问进度、取消任务与多任务并发，可复用 OpenCode、Claude Code 等已有 Agent 配置。每个项目均给出功能拆解、适用人群、硬件要求与 GitHub 地址。

💡 主要观点

  1. Voice-Pro 将字幕、翻译与配音整合进一个 WebUI，降低多语言视频制作门槛。 内置 Demucs 人声分离、Whisper 系列识别与多种 TTS 配音方案，支持 100 多种语言及零样本声音克隆，但需下载约 10GB 模型，且 Mac/Linux 支持未充分验证。
  2. Hugging Face speech-to-speech 以四个可替换模块组成语音助手链路。 VAD、STT、LLM、TTS 各环节可灵活更换，默认用 Parakeet TDT 与 Qwen3-TTS，也可切换 Whisper、Kokoro 等，适合桌面助手和机器人原型打底。
  3. Qwen Audio Agent 用并行双链路解决语音 Agent 等待任务时的静默断点。 前台对话与后台任务并行，可边聊天边查资料、调工具，并支持追问进度、取消任务和多任务并发，兼容 OpenCode、Claude Code 等后端与现有 MCP 配置。
