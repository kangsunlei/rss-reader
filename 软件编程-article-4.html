📝 详细摘要

本文是作者利用 AI 工具进行创意生产的实践分享。作者先用 Claude Code 辅助创作了科幻小说《存续》，指出 Claude 文字能力优秀但存在翻译腔问题。随后结合 Seedance 2.0 和 GPT Image 2.0 将小说改编为短片，参考了《齐马蓝》的艺术风格。作者将剧本、分集 prompt 和参考图全部开源在 GitHub，并在 Bilibili 发布了最终短片。文章核心价值在于展示了从文字创作到视觉呈现的完整 AI 工作流，为其他创作者提供了可复用的经验与资源。

💡 主要观点

  1. Claude Code 可用于小说创作，但需注意翻译腔问题。 作者实际使用 Claude Code 创作科幻小说，发现其文字能力优秀，但存在「carry it」译成「帮你扛」等翻译腔问题，需要人工润色。
  2. 结合多种 AI 工具可实现从文字到短片的完整创作链路。 作者将 Claude Code 创作的小说，通过 Seedance 2.0 和 GPT Image 2.0 转化为短片，展示了 AI 工具链在创意生产中的协同价值。
  3. 开源创作资源降低了他人尝试的门槛。 作者将剧本、分镜 prompt 和参考图全部开源在 GitHub，为其他创作者提供了可直接参考和复用的素材。
