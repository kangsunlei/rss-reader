GitHub Copilot 正式推出 GPT-5.2-Codex 模型

1/14/2026, 6:11:50 PM

📌 一句话摘要

GitHub 宣布在 GitHub Copilot 中推出 OpenAI 的 GPT-5.2-Codex 模型，该模型尤其擅长大规模代码重构与迁移，并在 Windows 环境下的性能有所提升。

📝 详细摘要

GitHub 官方宣布，OpenAI 的 GPT-5.2-Codex 模型现已在 GitHub Copilot 中正式可用。该模型特别擅长处理如代码重构或迁移这类大规模的代码变更。公告同时指出，其在 Windows 开发环境下的性能也得到了改进。用户可在 Visual Studio Code 中体验这一新模型，更多详情请参阅官方更新日志。
