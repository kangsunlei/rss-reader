OpenViking 上线原生 3D 内容理解模型

10/28/2026, 10:34:00 AM

📌 一句话摘要

OpenViking 推出首个 3D 内容理解模型，支持 STEP 文件导入与解析，实现 100% 信息还原，帮助 Agent 理解三维结构、整理 BOM 和应对断供风险。

📝 详细摘要

OpenViking，火山引擎的 Agent 上下文数据库，现已上线 3D 内容理解模型，支持三维 STEP 文件的导入与解析。该模型能生成正交六视图、轴侧八视图、信息摘要和模型明细，并建立索引用于下游推理。接入 Agent 后，可用于零件检索、BOM 整理、成本估算和断供影响分析，显著提升工作效率。

💡 主要观点

  1. 原生 3D 数据解析 OpenViking 的 3D 内容理解模型支持直接导入和解析三维 STEP 文件，生成多种视图和详细信息，实现 100% 的信息还原，为 Agent 提供丰富的上下文数据。
  2. 零件检索与复用 通过将历史零件库上传至 OpenViking，工程师可以利用 Agent 进行自然语言查询，快速找到符合特定几何和安装要求的零件，避免重复设计。
  3. 自动化 BOM 整理 Agent 可以读取 CAD 软件导出的明细，结合 OpenViking 中的历史报价数据，自动生成 BOM 清单并进行成本估算，简化采购准备流程。
  4. 风险应对与断供分析 当供应商断供时，Agent 可以利用 OpenViking 的索引快速定位受影响的产品和零件，分析用量和替代方案，帮助企业及时应对风险。

💬 文章金句

  • OpenViking 是火山引擎推出的 Agent 上下文数据库，支持文档、图片、音视频等多模态数据理解。
  • 现在你可以把零件模型、工程图纸和项目资料都交给 OpenViking，在豆包工作/Workbuddy/Codex/Claude 等 Agent 中描述你要找的结构，让 AI 帮你找候选零件、整理 BOM，核对供应变更带来的影响。
