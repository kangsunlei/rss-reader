MySQL 仓库分析揭示开发活动减少和贡献者数量萎缩

12/5/2025, 4:20:00 PM

📌 一句话摘要

数据分析显示 MySQL 核心开发和贡献者数量显著下降，令人担忧 Oracle 是否继续支持开源版本。

📝 详细摘要

本文报道了 Percona 对 MySQL 服务器仓库统计数据的最新分析，表明自 2011 年以来，开发活动持续下降，唯一贡献者数量也在减少。过去 14 年中，年度代码更新数量减少了约四倍，活跃贡献者从 2006 年的 198 人下降到 2025 年的约 75 人。Oracle 将开发资源战略性地分配给例如 Heatwave 和企业版等商业计划，以及最近影响社区版的裁员，加速了 MySQL 开源社区的衰退。包括 AI 和 JavaScript 函数在内的关键功能越来越多地为专有版本所独有，这引发社区关注，PlanetScale 和 Meta 等公司已创建分支。该分析突显了 MySQL 开源未来的关键时刻。

💡 主要观点

  1. MySQL 的核心开发活动和唯一贡献者数量持续下降。 仓库统计数据显示，自 2011 年以来，年度提交次数和活跃开发者人数显著减少，这表明项目整体开发速度放缓，可能影响长期发展。
  2. Oracle 正在战略性地将资源转移到商业 MySQL 计划上。 更多地关注 Heatwave 和企业专有功能，加上影响社区版的裁员，表明专有产品优先于开源核心。
  3. 专有版本的功能限制正在引发社区的关注和分支。 像 AI 功能和 JavaScript 函数这样的关键新功能通常是企业版独有的，因此 PlanetScale 和 Meta 等公司创建了社区分支，以添加必要功能。

💬 文章金句

  • 自 2011 年以来的总体趋势表明，提交数量持续下降，唯一贡献者数量也在减少。
  • 该趋势线是一个明确的警告，即如果没有干预，预计总体开发速度将进一步放缓。
  • 然而，越来越多地专注于 Heatwave 表明，开发资源正在战略性地分配给更广泛的 MySQL 生态系统中高优先级的商业计划。
  • 在开发者关注度开始减少之前，Oracle 可以将 MySQL 工程缩减到什么程度？大型企业将接受功能限制作为连续性的代价多久？
