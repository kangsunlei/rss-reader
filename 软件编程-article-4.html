Claude-Red：把 78 个渗透测试方法论封装成 Claude Skill

9/15/2026, 12:00:05 AM

📌 一句话摘要

Claude-Red 将渗透测试各方向的方法论、工具链与边界情况整理成 78 个 Skill，按话题在 Claude 对话中自动加载，覆盖 Web、无线、云、移动端、逆向等 23 类方向。

📝 详细摘要

推文介绍 Claude-Red 项目：渗透测试仅 Web 方向就有 SQL 注入、XSS、SSRF 等十几种攻击面，每种都涉及不同思路、工具与坑点。该项目把这些方法论整理成 78 个安全测试 Skill，分 23 类，其中 Web 应用 16 个覆盖 OWASP 常见问题、无线 14 个，另含漏洞挖掘、云、移动端、逆向等方向。每个 Skill 是一个 SKILL.md，写明某领域的方法、工具链与边界情况，装入 Claude 后按话题自动加载。作者注明适用场景为授权红队项目、漏洞赏金、安全研究与 CTF 备赛，并提醒先确认授权范围。

💡 主要观点

  1. 用 Skill 机制解决安全知识碎片化问题 渗透测试各攻击面的思路、工具与坑点分散且需长期记忆，Claude-Red 将其结构化为 78 个 SKILL.md，按话题自动加载对应技能，使模型在特定方向上给出更专业的回答而非泛泛而谈。
  2. 覆盖面按方向分类，Web 与无线占比最高 78 个 Skill 分为 23 类，Web 应用 16 个覆盖 OWASP 常见问题，无线 14 个，另含漏洞挖掘、云、移动端、逆向等方向，便于按测试目标定位所需技能。
  3. 明确限定授权使用场景 作者写明适用于授权的红队项目、漏洞赏金、安全研究与 CTF 备赛，并提醒动手前确认自身在授权范围内，属于安全工具常见的合规声明。
