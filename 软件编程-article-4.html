构建你的首个 MCP 服务器：如何通过自定义功能扩展 AI 工具

8/22/2025, 4:52:27 PM

📌 一句话摘要

本文介绍模型上下文协议 (MCP)，它是一种用于扩展 AI 工具（如 GitHub Copilot）自定义功能的标准化方法，并通过回合制游戏服务进行演示。

📝 详细摘要

本文深入探讨模型上下文协议 (MCP)，该标准旨在克服 AI 工具的局限性，例如无法访问私有数据、实时信息或在外部系统上执行操作。文章解释了 MCP 的客户端-服务器架构，其中 AI 宿主程序（如 GitHub Copilot）连接到提供扩展功能的自定义 MCP 服务器。作者演示了如何使用 TypeScript、Next.js 和 MCP TypeScript SDK 构建一个回合制游戏（井字游戏、石头剪刀布）的 MCP 服务器。MCP 的关键概念——工具（AI 可以采取的行动）、资源（AI 可以通过 URI 访问的上下文）和提示（用户的可重用指南）——通过游戏服务器的示例进行了透彻的解释。文章还涉及实际应用、安全考量以及可用的 SDK，强调了 MCP 在标准化 AI 工具扩展方面的作用。

💡 主要观点

  1. MCP 标准化了 AI 工具的自定义功能扩展，从而解决了固有的局限性。 AI 工具通常缺乏访问私有数据、实时信息或执行操作的能力。MCP 提供了一个统一的标准协议，用于集成外部上下文和操作，简化开发并实现更强大的 AI 助手。
  2. MCP 服务器提供工具、资源和提示，作为 AI 交互的核心构建块。 工具定义了 AI 可以执行的操作，资源允许 AI 通过 URI 访问特定上下文，提示提供了可重用的指导。这些组件使开发者能够构建复杂的、具备上下文感知能力的 AI 集成。
  3. 实施 MCP 服务器是使 AI 工具能够与自定义系统交互的实用方法。 本文使用游戏服务器示例来说明 MCP 服务器如何协调 AI 的行动，演示了 MCP 将 AI 代理连接到特定后端逻辑和外部服务的实际应用。

💬 文章金句

  • 这是一种使用自定义功能扩展 AI 工具的标准化方法。
  • MCP 通过提供**一种标准方法**将工具和功能集成到任何支持模型上下文协议的工具中，从而改变了这一点。
  • 工具定义了 MCP 服务器可以执行的操作。
  • 资源提供了一种让 AI 收集上下文的方式，并且通常具有基于 URI 的标识符。
  • MCP 不仅仅是用 AI 玩游戏（虽然这很有趣）。 它是为了打破你的 AI 助手和他们需要帮助你有效工作的系统之间的障碍。
