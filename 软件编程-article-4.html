Spring 新闻综述：Spring Boot、Data、Security、Auth、Session、Integration、Web Services 的发布候选版本

4/27/2025, 12:00:00 AM

📌 一句话摘要

2025 年 4 月 21 日这一周，Spring 生态系统迎来多个项目的重大更新，包括 Spring Boot、Data 和 Security 的发布候选版本和里程碑版本，包含了错误修复、依赖升级和新功能。

📝 详细摘要

本文总结了 2025 年 4 月 21 日这一周 Spring 生态系统中的更新，重点介绍了 Spring Boot、Spring Data、Spring Security、Spring Authorization Server、Spring Session、Spring Integration、Spring Modulith 和 Spring Web Services 的发布候选版本，以及 Spring Data 2025.1.0、Spring for Apache Kafka 和 Spring Vault 的里程碑版本。Spring Boot 3.5.0-RC1 引入了新的注解，如 `@ServletRegistration` 和 `@FilterRegistration`。Spring Security 6.5.0 改进了 OAuth 2.0 DPoP 的实现。每个部分都详细介绍了错误修复、依赖升级和新功能，为 Spring 开发人员提供了快速了解最新更新的渠道。

💡 主要观点

  1. Spring Boot 3.5.0-RC1 引入了用于 Servlet 和 Filter 注册的新注解。 `@ServletRegistration` 和 `@FilterRegistration` 注解提供了一种替代使用 `ServletRegistrationBean` 和 `FilterRegistrationBean` 类来注册 servlet 和 filter bean 的机制，从而简化了 Web 应用程序配置。
  2. Spring Data 2025.1.0 增加了对 JSpecify 的支持。 Spring Data Commons、Spring Data JPA 和 Spring Data MongoDB 等子项目包含对 JSpecify 的支持，从而增强了 null 安全性和 API 接口清晰度。
  3. Spring Security 6.5.0 增强了 OAuth 2.0 DPoP 的实现。 一个新的 `AuthenticationEntryPoint` 接口在 DPoP 身份验证失败时返回 `WWW-Authenticate` 标头，从而提高了安全性并符合 OAuth 2.0 标准。

💬 文章金句

  • Spring Boot 3.5.0 的第一个候选发布版本提供了错误修复、文档改进、依赖升级和新功能，例如：新注解 **[@ServletRegistration](https://docs.spring.io/spring-boot/3.5/api/java/org/springframework/boot/web/servlet/ServletRegistration.html)** 和 **[@FilterRegistration](https://docs.spring.io/spring-boot/3.5/api/java/org/springframework/boot/web/servlet/FilterRegistration.html)** 。
  • Spring Data 2025.1.0 的 [第二个里程碑版本](https://spring.io/blog/2025/04/22/spring-data-2025-1-0-M2-released) 附带了对子项目 [JSpecify](https://jspecify.dev/) 的支持：Spring Data Commons、Spring Data JPA、Spring Data MongoDB、Spring Data LDAP、Spring Data Cassandra、Spring Data KeyValue、Spring Data Elasticsearch 。
  • [Spring Authorization Server](https://spring.io/projects/spring-authorization-server) 1.5.0 的 [第一个候选发布版本](https://spring.io/blog/2025/04/23/spring-authorization-server-1-5-0-RC1-1-4-3-and-1-3-6-available-now) 提供了依赖升级和新功能，例如：为 OAuth 2.0 DPoP 和 Pushed Authorization Requests (PAR) 规范添加了授权服务器元数据支持。
