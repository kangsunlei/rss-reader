Anthropic 未发布模型可自主构建多平台攻击链

10/29/2026, 11:03:00 AM

📌 一句话摘要

Anthropic 的未发布 Claude 模型能自主构建跨平台漏洞利用链，涉及 Chrome、Safari 等，但测试环境安全，漏洞已修复。

📝 详细摘要

文章报道了 Anthropic 未发布的 Claude 研究模型在实验室环境中成功编写多平台漏洞利用链的能力。该模型能针对 Chrome、Safari、安卓、Windows 和 Linux 构建完整攻击链，例如 Chrome 利用链组合四个漏洞实现一键攻击，Linux 利用链可零点击获取 Root 权限。所有测试未造成真实攻击，Anthropic 已上报漏洞，厂商发布修复补丁。文章还描述了发现方法，如并行扫描 Agent，并强调 AI 能力的双刃剑效应，建议用户及时更新软件。

💡 主要观点

  1. Anthropic 未发布 Claude 模型能自主构建多平台漏洞利用链 测试显示模型可编写针对 Chrome、Safari、安卓、Windows 和 Linux 的完整攻击链，但限于实验室环境，未发生真实攻击。
  2. 漏洞细节涉及多个平台的具体利用 Chrome 利用链组合 V8、CacheStorage 等四个漏洞实现沙箱逃逸；Safari 突破同源策略读取敏感数据；安卓通过 USB 提取数据；Windows 导致远程崩溃；Linux 零点击获取 Root 权限。
  3. 漏洞已上报并修复，强调 AI 能力的双刃剑 Anthropic 及时上报，Google、Apple 等厂商发布补丁。文章提醒 AI 能力可被滥用，需加快修复速度。
  4. 发现方法基于并行扫描 Agent 和标准化流程 Anthropic 通过并行运行大量扫描 Agent 核验漏洞，并建议在代码拉取阶段开展安全扫描，已发布 Claude Code 安全插件。

💬 文章金句

  • Anthropic 前沿红队透露，一款尚未发布的 Claude 研究模型已成功编写出可在 Chrome、Safari、安卓、Windows、Linux 平台生效的完整漏洞利用链。
  • 整条利用链共组合利用了四个漏洞。第一个漏洞位于 Chrome 的 JavaScript 引擎 V8 中，可触发内存损坏。
  • Anthropic 表示，之所以能发现如此多漏洞，是因为并行运行了大量扫描 Agent，并通过标准化流程核验每一个发现的问题。
