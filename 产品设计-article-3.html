美团、腾讯，想再造一个 AppStore？

10/20/2026, 8:43:00 AM

📌 一句话摘要

美团和腾讯分别推出 DeepSkill Market 和 SkillHub，试图构建 AI 技能的交易与评价平台，但随着 Agent 自主能力的提升，用户对主动安装 Skill 的需求正在减弱，未来 Skill 商店可能更像后台服务而非前台市场。

📝 详细摘要

本文分析了美团和腾讯在 AI 技能市场上的布局，指出尽管 Skill 商店在当前阶段提供了便利，但随着大模型和 Agent 的快速发展，用户对主动搜索、安装 Skill 的依赖正在降低。未来，Skill 商店可能会从一个需要用户频繁访问的界面，转变为一个由 Agent 自动查询和调用的后台服务，而用户体验将更加无缝和智能化。

💡 主要观点

  1. 大厂布局 AI 技能市场 美团和腾讯分别推出了 DeepSkill Market 和 SkillHub，试图通过提供技能搜索、安全验证和用户评价，来构建一个类似 App Store 的 AI 技能生态系统。
  2. Agent 自主能力提升 随着 AI 模型的进化，Agent 已经能够自主理解任务、搜索工具、调用 API，甚至生成自定义工作流程，这大大降低了用户对预装 Skill 的依赖。
  3. Skill 商店的未来角色 未来，Skill 商店可能不再是一个需要用户频繁访问的前台界面，而是变成一个由 Agent 自动查询和调用的后台服务，用户体验将更加无缝，由 Agent 负责管理技能的生命周期。

💬 文章金句

  • 如果未来 AI 自己就能搞定这些事，那么现在热闹非凡的 Skill 商店，会不会很快就陷入尴尬？
  • 用户负责提出需求，Agent 负责决定需要什么能力。
  • 我越来越觉得，AI 时代最好的 Skill 商店，可能就是一个用户从来不需要打开的网站。
