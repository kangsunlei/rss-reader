对标 Muse，Manus 上线专属私人 Agent「Cue」

9/30/2026, 1:27:42 AM

📌 一句话摘要

Manus 发布 2.0 版本并推出名为 Cue 的云端个人专属私人 Agent，其核心功能对标 Meta 的 Muse。

📝 详细摘要

近日宣布独立运营的 Manus 迎来重大改版，升级至 2.0 版本并引入了专属私人 Agent —— Cue。Cue 是一个与 Manus 并列的独立产品，支持桌面端和移动端，运行在云端并允许用户自主创建和配置。用户只需提供信号（提示），Agent 即可完成复杂任务。Cue 拥有专属的云电脑、存储空间、邮箱、电话和支付等资产，并支持多个 Agent 的群组协作。

💡 主要观点

  1. Manus 升级 2.0 并推出 Cue 产品 Manus 在独立运营后进行重大更新，提供了全新的界面设计并推出了对标 Meta Muse 的专属私人 Agent Cue。
  2. 云端运行与资源解耦 Cue 运行在云端环境，所有任务和文件均在云电脑执行，不占用用户本地笔记本资源。
  3. 高度自定义的个人资产配置 用户可以为每个 Agent 配置专属的邮箱、电话和 Link 钱包支付方式，实现处理邮件、购物、退款等自动化操作。
  4. 多 Agent 协作模式 支持创建多个不同职责的 Agent（如工作、育儿、理财），并允许它们拉入群组进行协同工作。

💬 文章金句

  • Cue，是提示、信号的意思。
  • Your personal team of agents
  • 所有的任务在 Agent 自己的电脑上运行，不会占用你的笔记本电脑。
  • 甚至可以进行多个 Agent 协作。
