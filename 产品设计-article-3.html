实测小米新模型 MiMo V2.6，我真服了第一次看开源那么彻底的

9/24/2026, 2:56:51 AM

📌 一句话摘要

小米发布的新模型 MiMo V2.6 在价格、性能和多模态能力上均有显著提升，实测表现优异，尤其在网站复刻、动画生成、PPT 制作及 3D 模型制作等任务上展现出强大的通用性和易用性，有望成为日常 Agent 的主力模型。

📝 详细摘要

本文作者对小米新发布的 MiMo V2.6 模型进行了深度实测。MiMo V2.6 在价格上极具优势，相比海外模型低至 1/20 到 1/60。性能方面，MiMo-V2.6-Pro 在 Artificial Analysis 评测中获得 46.32 分，位列开源模型第一，国产模型第一，较 V2.5 版本有巨大飞跃。模型在 Terminal-Bench 4.0、CritPT 和 DeepSWE v1.1 等多项评测中表现出色。 实测环节，MiMo V2.6 在网站复刻、生成可动的鹈鹕骑自行车 SVG 动画、制作 Artemis II 演示文稿以及 3D 折叠纸盒模型和动画制作等方面都展现了惊人的能力。尤其是在制作 PPT 时，模型能理解并整合 PDF、音频和图片等多模态信息，并按要求生成内容和排版。在 3D 模型制作中，模型甚至能自主安装缺失的 Blender 软件并完成任务。 此外，作者还将其应用于一个实际项目：优化 AI 提示词案例网站的数据更新逻辑，通过与 Jev 模型协同工作，实现了更精准的热度衰减计算。作者认为 MiMo V2.6 不仅能处理日常任务，更有潜力成为主力 Agent 模型，并对其持续进步和低廉价格表示赞赏。

💡 主要观点

  1. MiMo V2.6 模型在性能和价格上实现重大突破 MiMo-V2.6-Pro 在 Artificial Analysis 评测中达到 46.32 分，位列开源与国产第一，价格仅为海外模型的 1/20 到 1/60，极具性价比。
  2. 模型展现出强大的多模态处理和内容生成能力 实测中，MiMo V2.6 成功完成了网站复刻、视频转动画 SVG、演示文稿制作、3D 模型与动画生成等复杂任务，并能处理 PDF、音频、图片等多种格式信息。
  3. 模型在专业评测和实际项目应用中表现优异 在 Terminal-Bench 4.0、CritPT、DeepSWE v1.1 等评测中得分显著提升；在优化 AI 提示词网站数据逻辑的项目中，展现了其作为 Agent 的潜力。
  4. MiMo V2.6 有望成为主力 Agent 模型 作者认为该模型已超越基础任务处理能力，随着信任积累，可考虑将其从够用级别提升至主力模型。

💬 文章金句

  • Pro 以 46.32 分位列开源第一、国产第一。
  • Pro 的缓存命中输入每百万/0.025 元，Flash/0.02 元。输出端 Pro 是 6 元，Flash 是 2 元。
  • 跟同级海外模型摆在一起，差距能到 1/20 到 1/60。
  • V2.5 那会儿 26 分，一次小版本迭代就涨到 46，比吃了炫迈还炫迈。
  • Pro 从 58.4 涨到 72.57，Flash 从 48.8 涨到 65.68。
  • 这样一看小米在开源和 API 价格两个方向都是赛博大善人了。
  • MiMo V2.6 这次我换了个玩法，它是原生全模态的，视频能直接丢进去的。
  • 它按 PDF 里的飞行顺序重新讲了一遍故事，发射，地球轨道检查，跨月注入，月球飞越，返回溅落。
  • MiMo V2.6 一上来没找到，自己就把 Blender 装上了接着干。
  • MiMo V2.6 到底能不能当我的日常 Agent 里的内置模型，到这一条，我心里有数了。
  • 把斩杀线，嗯一头往上抬啊，能干的活越来越多，价格反倒是越来越低了，我又是米粉了真的。
