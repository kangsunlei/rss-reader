📌 一句话摘要

关于使用 `getBoundingClientRect` 或现代视图转换 API 创建“移动高亮”导航栏的教程。

📝 详细摘要

本文提供了两种使用原生 JavaScript 和 CSS 在导航栏上构建“移动高亮”效果的方法，灵感来源于早期的 jQuery 实现，但已更新以适应现代 Web 开发。第一种方法利用 `getBoundingClientRect()` 方法来计算元素的位置和大小，并通过 CSS transitions 来实现高亮元素的动画效果。第二种方法演示了一种更为简化的方法，即使用新的视图转换 API，通过在活动类发生变化时自动处理快照和过渡效果，从而简化动画实现。本文包含代码示例，并强调在不依赖外部库的情况下实现类似原生应用的用户体验。同时，也涵盖了针对不支持视图转换 API 的浏览器的降级方案。

💡 主要观点

  1. `getBoundingClientRect` 方法可以创建动态 UI 动画。 通过计算元素的精确位置和大小，开发人员可以使用 CSS 过渡显式控制和动画显示其他元素（如高亮）。
  2. 视图转换 API 简化了单页应用程序中的状态转换。 此 API 通过处理前后快照和使用最少 JavaScript 的过渡，自动化创建不同 UI 状态之间平滑动画的过程。
  3. 实现“移动高亮”需要不同的 CSS/JS，具体取决于方法。 手动 `getBoundingClientRect` 方法需要单独的高亮元素和手动位置/大小更新，而视图转换使用伪选择器并依赖于 API 的内置动画功能。

💬 文章金句

  • 在 2025 年，我们拥有更好的工具，可以使用原生 JavaScript 操作 DOM。
  • 使用 `getBoundingClientRect`，我们可以获取有关元素的位置和大小的信息。
  • 视图转换 API 提供了在网站视图之间创建动画过渡的功能。
  • 视图转换对于在文档之间创建动画很有用，提供了 Astro 等框架中类似原生应用的用户体验。
