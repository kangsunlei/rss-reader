📌 一句话摘要

本文介绍了一种创新的方法，利用飞书多维表格、Chrome 插件和扣子 AI 智能体，自动化抖音爆款文案的提取、分析和改写，显著提升内容创作效率。

📝 详细摘要

本文详细介绍了如何构建一个抖音视频文案提取和改写的一站式工具，解决了内容创作者手动提取和改写抖音文案的痛点。该工具通过 Chrome 插件自动筛选高赞视频，并将视频标题和链接存入飞书多维表格。接着，利用扣子 API 自动提取视频文案，并在多维表格中完成文案的风格分析和改写。文章提供了详细的操作步骤和配置要点，包括飞书应用的创建和权限配置、Chrome 插件的开发和安装、扣子智能体的配置和发布，以及在飞书多维表格中设置风格分析和文案改写的方法。最后，展示了整个工作流程的成果，并提出了拓展应用的可能性。

💡 主要观点

  1. 利用 Chrome 插件实现抖音视频信息的自动化批量筛选和保存，极大地提高数据采集效率。 通过自定义 Chrome 插件，可以根据点赞数等指标筛选视频，并将标题和链接自动保存到飞书多维表格，省去手动收集的时间。
  2. 结合扣子智能体和飞书多维表格，实现视频文案的自动提取和分析。 通过扣子平台创建智能体，配置视频链接提取和字幕获取插件，可以自动提取视频文案，并将其作为飞书多维表格的字段捷径。
  3. 在飞书多维表格中集成 DeepSeek R1，实现文案风格分析和多风格改写。 利用飞书多维表格的字段捷径功能，调用 DeepSeek R1 模型，可以对提取的文案进行风格分析，并生成多种风格的改写版本。
