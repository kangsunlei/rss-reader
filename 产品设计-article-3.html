本文介绍了腾讯混元 Hy4 正式版的视觉理解、电脑操作、长上下文等核心能力升级，以及其 API 定价、开源计划和实际应用场景。

📝 详细摘要

本文聚焦腾讯混元 Hy4 正式版的发布，阐释了其在视觉理解、电脑操作、长程任务和深度研究方面的升级。文章首先说明，模型不再仅生成内容，还能参与实际工作流程。随后详细介绍了视觉理解如何让截图和图像成为任务输入，以及通过 Blender、CAD 等专业软件的训练提升开发能力。文章还阐述了 1024k 的上下文窗口优势与局限，强调大上下文不等于永久记忆。关于办公协作，文章指出幻觉率下降但仍需核对数据。开源方面，正式版服务已上线，权重计划近期开放。最后讨论了 API 定价、折扣政策以及不同入口的使用建议，总结指出 Hy4 的核心价值在于减少用户返工和重新解释的需求。

💡 主要观点

  1. Hy4 正式版新增视觉理解和电脑操作能力，提升模型参与实际工作的能力 通过视觉感知和工具调用，模型能处理图像分析、复杂图表，结合命令行与图形界面执行操作，实现从看懂图片到完成实际任务的闭环。
  2. 1024k 上下文窗口支持大规模信息处理，但需注意其非永久记忆的局限 虽然能容纳大量代码、文档和任务资料，但实际用量受分词影响，且跨会话保存仍需产品层面的存储机制。
  3. 幻觉率从 15.76%降至 5.45%，但仍需核对关键数据和结论 改进提升了可靠性，但财报、研究报告等高风险内容仍需人工验证，不能完全依赖 AI 输出。
  4. 正式版 API 定价保持不变，腾讯云提供限时五折优惠，开源计划在近期推进 基础定价 6 元/100 万输入、18 元/100 万输出，折扣后分别为 3 元和 9 元，权重和系统卡片计划近期开放。
  5. 不同入口适配不同使用场景，建议先小范围验证后再扩大任务范围 元宝、ima 适合日常内容处理，WorkBuddy 适合文件任务，CodeBuddy 适合代码分析，首选小任务验收可降低风险。

💬 文章金句

  • 用户想要的不是再多一个会解释的聊天框，而是少一点自己接手的收尾工作。
  • 让模型看到更多信息，也能通过工具完成更多步骤。
  • 百万 Token 不等于百万汉字。实际用量取决于内容和模型的分词方式。
  • 大上下文不等于永久记忆。跨会话保存信息、连接项目资料和持续跟进任务，还需要产品层面的存储与管理机制。
  • 排版漂亮可以加分，但数据和结论正确才是基础。
  • 它能不能把你交代的事情做完，而且让你少返工、少盯着、少重新解释？
