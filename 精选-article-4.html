获 NVIDIA 致谢：悟空 Agent 的实践、复盘与迭代

11/7/2025, 9:38:00 AM

📌 一句话摘要

腾讯悟空 Agent 通过多智能体架构和数据飞轮，有效应对 AI 时代代码安全审计挑战，并获得 NVIDIA 致谢。

📝 详细摘要

本文详细介绍了腾讯悟空 Agent 在代码安全审计领域的实践、复盘与迭代。面对 AI 时代代码复杂度爆炸，传统人工审计和 SAST 工具效率低下、误报率高的问题，悟空 Agent 提出了一种多智能体（Multi-Agent）协作架构，通过 Client、Remote、Audit、Review、Fix 五类智能体协同作业，实现漏洞发现、复现、披露到修复的全闭环，并成功发现 NVIDIA Megatron-LM 项目中的反序列化漏洞，获得官方致谢。文章深入探讨了多智能体迭代中面临的“上下文断流”和“调度失衡”两大瓶颈，并提出了“上下文工程”和强化学习调度等优化方案。此外，悟空 Agent 构建了数据飞轮体系，通过 Bad Case 的持续学习与模型微调，将问题闭环解决率提升至 97%以上。文章强调 AI 基础设施的安全不容忽视，真正的风险常在于模型之外的工程细节，并指出 AI Agent 的价值在于放大人类判断力，让安全真正融入业务生产线，成为长期竞争力。

💡 主要观点

  1. 传统代码安全审计方式难以应对 AI 时代代码复杂度爆炸的挑战 人工审计成本高、周期长，SAST 工具误报率高、上下文缺失，两者均无法跟上 AI 框架快速迭代的速度，亟需新的解决方案。
  2. 悟空 Agent 采用多智能体架构实现高效、闭环的代码安全审计流程 通过 Client、Remote、Audit、Review、Fix 五类智能体协同作战，将复杂审计任务标准化、自动化，显著提升扫描效率和准确率，并实现从漏洞发现到修复的全流程管理。
  3. “上下文断流”和“调度失衡”是多智能体协作中的关键瓶颈 复杂代码框架导致模型上下文提取不足，内部知识缺乏覆盖；智能体倾向串行处理任务而非协同分发，影响系统整体表现。
  4. 通过“上下文工程”和强化学习调度等机制优化 Agent 表现 针对上下文问题，引入专用提取工具和 RAG-like 知识补全；计划通过强化学习训练模型实现任务场景与角色最优分配，解决调度失衡。
  5. 数据飞轮体系是 Agent 持续迭代和自我进化的核心 通过 Bad Case 的收集、模型判断、人工质检、微调训练和效果评测闭环，系统能不断学习并消化绝大多数问题，大幅减少人工调试依赖。
  6. AI 基础设施的安全风险不容忽视，且常隐藏在模型之外的工程细节 配置文件校验缺失、不安全序列化、依赖包漂移等细节，在复杂的 AI 流水线中可能暴露出被利用的攻击面，需要持续关注和修复。

💬 文章金句

  • AI 的意义不在于取代，而在于放大人类的判断力。它让代码安全审计重新回归'人'的部分------分析、推理、决策。
  • 悟空 Agent 的核心不是'模型大'，而是'迭代快'。 我们致力于让每一个误报、漏报、复测都能成为下一个版本的训练素材。
  • 真正的风险往往在模型之外：它可能是一段被沿用的 YAML 加载逻辑、一个疏忽的 WebUI 参数解析，也可能是某个未更新的依赖版本。
  • 真正的安全，不只是防御漏洞，更是让业务、算法与信任可以共同成长的能力。
  • AI Agent 帮我们分担了疲惫的机械环节，让安全团队有更多精力去思考'为什么这样设计'，而不是'哪里出了错'。
