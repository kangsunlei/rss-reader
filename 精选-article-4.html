Kimi K2 模型更新，带来更强的代码能力、更快的 API

9/5/2025, 12:00:00 AM

📌 一句话摘要

Kimi K2 模型发布最新 0905 版本，全面提升代码能力、扩展上下文至 256K 并提供高速 API。

📝 详细摘要

文章宣布了月之暗面 Kimi K2 模型的 0905 最新版本更新。此版本显著提升了模型在真实编程任务中的表现，包括增强 Agentic Coding 能力和优化前端编程体验。核心升级点还包括将上下文长度从 128K 扩展至 256K，以更好地支持复杂和长线任务。此外，Kimi 开放平台同步推出了支持 60-100 Token/s 输出速度的高速版 API，并具备 Anthropic API 兼容性、WebSearch Tool 支持及全自动 Context Caching 功能。文章还提及 Kimi K2 作为一款混合专家架构的开源基础模型，已被多种 AI 编程工具和云服务厂商集成。

💡 主要观点

  1. Kimi K2 模型在 Agentic Coding 和前端编程能力上显著增强。 新版本在 SWE-bench 等基准测试中表现更优，提升了模型处理复杂编程任务的能力，并优化了前端代码生成质量和实用性。
  2. 上下文长度翻倍至 256K，大幅提升模型处理长文本能力。 扩展的上下文窗口使模型能更好地理解和处理复杂、长期的编程和文本任务，减少信息丢失和理解偏差，支持更宏大的项目。
  3. 开放平台提供高速版 API，并支持 Anthropic API 兼容与 WebSearch Tool。 高速 API 提升了开发效率，兼容性降低了迁移成本，WebSearch Tool 和 Context Caching 则进一步增强了模型的实用性和经济性，满足多样化开发需求。

💬 文章金句

  • Agentic Coding 能力提升：在公开基准测试和真实的编程任务中均展现出更好的性能
  • 扩展上下文长度：从 128K 升级到 256K，为复杂长线任务提供更好的支持
  • 提供高速版 API：支持高达 60-100 Token/s 的输出速度
  • Kimi 开放平台（platform.moonshot.cn）已上架 kimi-k2-0905-preview 模型 API
  • Kimi K2 模型最初发布于 7 月 11 日，它是一款混合专家架构（MoE）的开源基础模型，总参数 10000 亿，激活参数 320 亿。
