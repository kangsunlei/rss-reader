「模型能力已经够了，要卷就卷 infra」｜对谈戴冠兰：Runta 创始人

8/9/2026, 4:00:00 PM

📌 一句话摘要

Runta 创始人戴冠兰与 Koji 深度对谈，阐述为什么 Agent 执行底座是 AI 的下一场核心竞争，并分享从 Token Maxxing 到 Token Minimizing 的行业反转、创业方法论以及对灾难性事故的预言。

📝 详细摘要

本期十字路口邀请到刚完成 a16z 领投 2000 万美元种子轮、Jeff Dean 与李飞飞个人天使投资的 Runta 创始人戴冠兰，系统拆解 Agent Infra 赛道。访谈从行业风向急转切入——短短半年，企业从鼓励消耗 Token 的 “Token Maxxing” 转向强调 ROI、预算与归因的 “Token Minimizing”，揭示出模型落地的成本与治理困境。戴冠兰结合自己在 Cloudflare 和 Kong 的 Infra 构建经验，指出 AI 正在动摇软件世界的确定性地基：当执行单元从确定性逻辑变成概率性的大模型，执行层已经成为系统工程里最难的问题。他详细阐述了 Runta 的解题思路，即在不改动模型的前提下，通过执行底座为 Agent 加入确定性的管控、审计与恢复能力，让企业敢于把生产权限交给智能体。对话还对比了创业公司、公有云与大模型公司在 Infra 赛道的优劣势，戴冠兰提出暴论“模型能力已经够了，要卷就卷 infra”，并预测未来必然会发生灾难性的 Agent 安全事故，这将是行业建立执行底座共识的转折点。后半部分还分享了职场新人如何识别浪潮、选择团队、用投资人视角思考职业，以及团队如何使用 Codex 进行 95% 以上的 Vibe Coding 实践。

💡 主要观点

  1. 模型能力已趋于饱和，下一场核心竞争在于 Agent 执行基础设施 戴冠兰认为模型能力的爬坡已经放缓，而企业落地最大的瓶颈是缺少为概率性 Agent 设计的执行底座，这将是比模型更重要的平台级机会。
  2. Token Maxxing 到 Token Minimizing 的反转，折射出企业 AI 落地从狂热走向理性 企业从鼓励员工刷 Token 作为 KPI，转向严格管控用量与 ROI，背后是成本高企、安全意识觉醒以及对生成式 AI 实际回报的再评估。
  3. Agent 执行底座的本质是为概率性执行单元注入确定性 传统软件是确定性的，大模型是概率性的，但企业需要可控、可审计、可恢复的执行环境，这必须由 Infra 层解决，而非靠模型或 harness 单方面完成。
  4. 灾难性 Agent 安全事故必然发生，将倒逼行业建立执行底座共识 当前企业普遍用安全换便捷，大量敏感数据和工作被交给 Agent，可以预见会出现难以挽回的邮件发送、数据泄露等事故，这将成为执行底座从可选变刚需的契机。
  5. 工程师应掌握“往下钻一层”的能力，并用投资人视角选择职业机会 戴冠兰分享自己筛选早期公司的心得：看重团队是否对底层技术有深刻好奇心；年轻职场人可用大量时间做深度研究，像做投资一样去判断一家公司和一个浪潮。
