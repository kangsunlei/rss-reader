从 DeepSeek-V3 到 Kimi K2：八种现代 LLM 架构大比较

7/25/2025, 2:07:00 PM

📌 一句话摘要

文章深度对比了 DeepSeek-V3、Kimi K2 等八种现代大型语言模型（LLM）的架构差异与核心技术，揭示了其在效率、稳定性和长序列处理上的演进。

📝 详细摘要

本文对八种现代 LLM 架构进行了深入比较，包括 DeepSeek V3/R1、OLMo 2、Gemma 3、Mistral Small 3.1、Llama 4、Qwen3、SmolLM3 和 Kimi K2。文章指出，尽管 LLM 核心架构仍基于 Transformer，但通过引入多头潜在注意力（MLA）、混合专家（MoE）、后归一化（Post-Norm）、QK-Norm、滑动窗口注意力以及无位置嵌入（NoPE）等创新技术，显著提升了模型的计算效率、训练稳定性、内存管理和长序列处理能力。例如，DeepSeek V3 和 Kimi K2 利用 MLA 和 MoE 优化效率，OLMo 2 和 Gemma 3 通过归一化策略提升训练稳定性，SmolLM3 则探索无位置嵌入以增强长度泛化能力。文章通过图示和代码片段辅助理解，为读者提供了当前 LLM 架构演进的全面视角。

💡 主要观点

  1. MLA 和 MoE 是提升 LLM 计算效率的关键技术 多头潜在注意力（MLA）通过压缩键值张量显著减少内存占用，而混合专家（MoE）则通过选择性激活专家层，在保持模型能力的同时降低推理成本。
  2. 归一化层放置和 QK-Norm 对模型训练稳定性至关重要 OLMo 2 采用的后归一化（Post-Norm）和查询-键归一化（QK-Norm）设计，能有效提高模型训练过程的稳定性，减少数值不稳定性问题。
  3. 滑动窗口注意力与无位置嵌入是长序列处理的优化方向 Gemma 3 的滑动窗口注意力通过限制上下文范围减少 KV 缓存需求，SmolLM3 的无位置嵌入（NoPE）则依赖因果注意力掩码，在处理超长序列时展现出更好的泛化能力。
  4. 现代 LLM 在核心 Transformer 基础上进行多维度微创新 尽管 LLM 架构核心相似，但通过对注意力机制、前馈网络、归一化和位置编码等模块的持续创新，显著提升了模型性能、效率和特定场景下的表现。

💬 文章金句

  • 距离最初的 GPT 架构问世，已经过去了七年。乍看之下，回溯到 GPT-2（2019 年），再展望 DeepSeek-V3 和 Llama 4（2024-2025 年），人们或许会惊讶于这些模型在结构上竟依然如此相似。
  • MLA 旨在解决传统多头注意力（MHA）在大规模模型中内存占用过高的问题。
  • MoE 将传统的前馈模块替换为多个专家层，每个专家层也是一个前馈模块。
  • 研究表明，后归一化有助于训练稳定性，尤其是在不使用精心设计的学习率预热策略时。
  • 研究表明，NoPE 在长度泛化方面表现更好，即在处理更长序列时性能下降较少。
