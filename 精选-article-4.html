万字长文详解腾讯优图 RAG 技术的架构设计与创新实践

9/8/2025, 9:36:00 AM

📌 一句话摘要

腾讯优图详解 RAG 架构与创新实践，涵盖多阶段 Embedding、分层 Reranker、Text2SQL 及自研 GraphRAG，提升智能问答与知识检索。

📝 详细摘要

本文深度解析了腾讯优图实验室在 RAG（检索增强生成）技术上的全栈解决方案与创新实践。文章首先介绍了语义检索环节，通过多阶段训练管线、精细化数据工程和多任务均衡配置，打造了在中文 IR 和 STS 任务上均达到 SOTA 水平的 2B 级 Embedding 模型。接着，详细阐述了基于 LLM 的 Reranker 模型，引入分层知识蒸馏损失和自动化高质量业务数据构造流程，显著提升了重排序准确性。在结构化信息检索方面，文章提出了融合 Text2SQL 技术，构建了基于 Agent 的多智能体协作框架（MAC-SQL），并通过自动化数据合成、智能结构化解析和双引擎 SQL 查询，有效解决了非技术人员访问和分析结构化数据的难题。最后，介绍了自研的 GraphRAG 框架，通过构建 Knowledge Tree、S2Dual-perception 社区检测和 AgenticGraphQ 模块，大幅优化了图谱构图成本、检索效率和复杂查询的理解与推理能力。优图 RAG 技术已成功应用于多个产品和领域，并计划进一步发展 Agentic RAG 与低成本精细化方向。

💡 主要观点

  1. 多阶段 Embedding 模型训练与优化显著提升中文检索性能 通过弱监督/有监督对比学习、精细化数据工程及多任务均衡配置，优图 2B 级 Embedding 模型在 C-MTEB 中文 IR 和 STS 任务上均取得 SOTA 表现，超越参数量更大的竞品。
  2. 基于 LLM 的分层知识蒸馏 Reranker 提升文档重排序准确性 将 Reranker 模型升级为 LLM，引入分层知识蒸馏损失强化模型层级输出能力，结合自动化高质量业务数据构造流程，有效捕捉深层语义关联，提高检索结果的准确性。
  3. 融合 Text2SQL 与 Agent 框架高效处理结构化数据问答 提出 MAC-SQL 多智能体协作框架，结合自动化数据合成、智能结构化解析非标准表格，以及双引擎 SQL 查询，实现了自然语言到精准结构化数据查询的高效转化。
  4. 自研 GraphRAG 框架通过创新构图与推理优化复杂查询 构建 Knowledge Tree、S2Dual-perception 社区检测算法和 AgenticGraphQ 模块，有效解决了现有 GraphRAG 在构图成本、检索效率和复杂多跳 Query 理解上的难题，大幅提升了推理能力。

💬 文章金句

  • 在信息爆炸的时代，如何从海量数据中精准获取知识并生成智能回答，已成为 AI 落地的核心挑战。
  • 优图实验室自研的 RAG 技术已应用在多个领域和产品，未来，我们更将着力于迈向 Agentic RAG 与低成本精细化方向，推动产业智能化升级。
  • 为了提升 Reranker 模型在实际复杂场景中的表现，使用 LLM 训练 Reranker 模型成为必要方案。
  • 我们提出基于大语言模型的多智能体（Multi-Agent）协作框架，该框架由三个 Agent 组成：筛选器、分解器、优化器。
  • 通过融入两类方法的优点，每个节点类型都有特定的功能和角色：实体和关系节点用于连接语义单元；属性节点用于表示实体的特征；社区节点用于总结社区的核心信息。
