OpenAI GPT-6 Astra 实测：一句话，造出一栋可以走进去的房子

9/6/2026, 1:50:00 AM

📌 一句话摘要

OpenAI Codex 工程师实测 GPT-6 Astra：仅用一句提示词，便让 AI 直接在 Blender 中建出一栋可编辑、可走动、有生活痕迹的完整住宅，展示了 computer use 在 3D 创作中的系统性突破。

📝 详细摘要

本文作者 Thomas Ricouard 是 OpenAI Codex 工程师，通过完整记录一个名为 Solace 的住宅项目，展示了 GPT-6 Astra 如何在 Blender 中直接从一句自然语言提示生成可编辑的 3D 场景。文章详细描述了从氛围确认、平面图制定、房间与家具搭建、材质与灯光打磨，到导入 Unreal Engine 5 实现第一人称自由行走的全流程。Astra 不仅能生成高质量模型，还会主动查看预览图、发现并修复穿模和法线等问题，体现了 computer use 能力的显著提升。此外，作者还展示了同一方法在 HELIOS 戴森球、Shipyard 巡洋舰、吉维尼花园等完全不同场景中的应用，证明其通用性。文章中引用了 ScreenSpot-Pro 和 BenchCAD 基准数据的提升，强调这代表了视觉理解与三维重建的双重进步。

💡 主要观点

  1. Astra 能在 Blender 中直接完成完整的 3D 场景生成与编辑 通过 Blender Python API，Astra 可以从一句提示词搭建建筑结构、家具、植物、材质、灯光和摄像机，且所有元素均为可编辑的真实 3D 模型，而非贴图或图片。
  2. 主动验证和迭代是 GPT-6 Astra 的核心突破 Astra 会自行查看渲染预览、发现穿模和法线异常等问题并主动修复，无需人类逐条指令。这与 ScreenSpot-Pro（76.9%→92.7%）和 BenchCAD（83.3%→95.9%）的显著提升数据一致，体现了视觉理解与操作执行的同步进步。
  3. 流程设计决定了最终质量：先审平面图，再建模型，最后做实时体验 作者强调在扩建前必须确认平面布局，因为空间问题无法靠堆砌家具解决。这一分阶段的检查逻辑（氛围→平面→模型→细节→实时）是项目成功的关键，也为其他用户提供了可复用的工作流框架。
  4. 同一方法可迁移到多种完全不同类型的 3D 场景 除了住宅，作者在 HELIOS 项目中搭建了几千块面板的戴森球，在 Shipyard 项目中创建了细节丰富的科幻巡洋舰，还参照真实花园设计了吉维尼水景。每次都是先看整体设计、再由 AI 自查改进，证明 Astra 具备跨领域的通用 3D 创作能力。

💬 文章金句

  • Astra 并没有交出第一版就收工。它自己看预览图，调构图、调灯光，还顺手修掉了植物互相穿模、沙发毯摆得不自然这类细节。
  • 这个顺序很重要：先审平面图，再审模型，最后才投入额外精力做实时体验版。
  • 这些都不是贴图或后期效果，而是场景里实打实建出来的模型。换个角度照样经得起检查。
  • ScreenSpot-Pro 从 GPT-5.6 Sol 的 76.9% 提升到 92.7%，BenchCAD 从 83.3% 提升到 95.9%。
  • Astra 负责场景、脚本和 Unreal 工程，我只负责判断——这个空间应该长成什么样。
