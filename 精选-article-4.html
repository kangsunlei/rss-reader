让 AI 组队干活，最强模型也只完成约一半任务：AgentWorld 如何评测 Agent 协作能力？

10/10/2026, 5:39:00 AM

📌 一句话摘要

研究团队推出面向多智能体长时程协作的评测基准 AgentWorld，发现即使顶尖大模型在沙盒任务中的最高协作成功率也仅约 52%，并提出了因果协作有效性（CCE）指标以衡量跨角色行动贡献。

📝 详细摘要

随着单个 AI Agent 能力的增强，团队层面的协作效率成为新的瓶颈。研究团队构建了面向多智能体协作能力的评测基准 AgentWorld。该基准将长时程任务、角色不对称与黑盒交互引入 MMORPG 沙盒环境，通过封装的高层 API 聚焦多智能体分工与协调。评测结果显示，在主任务集中表现最好的模型（Gemini 3 Flash）成功率仅为 52.0%，且通信量多并不等同于高成功率。研究进一步提出了因果协作有效性（CCE）指标，通过反向回溯因果依赖图来量化哪些具体行动与消息切实推进了任务目标。分析揭示了智能体在协作中常出现的重复劳动、信息误传和提前终止等失败模式，为设计具备更优记忆与通信架构的多智能体系统提供了标准评测工具。

💡 主要观点

  1. AgentWorld 针对多智能体协作痛点，构建了长时程、角色不对称与黑盒交互的 MMORPG 沙盒评测环境。 评测不仅考察对话本身，而是通过涵盖 3 至 20 个智能体的连续资源交接与行动依赖任务，利用 13 个高层 API 屏蔽底层导航干扰，专注于检验多 Agent 在彼此依赖条件下的分工与协调能力。
  2. 主流大模型的多智能体协作成功率普遍偏低，且通信频率与协作质量不成正比。 在基准测试中，表现最好的 Gemini 3 Flash 在主任务集上的完整成功率仅为 52.0%，部分模型仅有 20.0%；同时数据显示，发送大量消息（如 GPT-5 Mini 发送 44.1 条）并未带来高成功率（36.0%），说明协作的关键在于信息的有效性而非数量。
  3. 提出因果协作有效性（CCE）指标，用于细粒度追溯跨角色行动与通信的真实贡献。 CCE 从最终成功的任务目标反向回溯依赖链，计算被判定为推动结果的动作占总执行动作的比例，使研究者能够区分高冗余试错与高效配合，深入分析协作失败的具体症结。

💬 文章金句

  • AgentWorld 是一个面向 Agent 协作能力的评测基准（benchmark）：让多个由大语言模型驱动的智能体，在同一个持续变化的环境中分工、沟通、共享资源，并共同完成任务。
  • 这组结果并不能证明少聊天会提升成功率，但它提醒我们：消息数量无法直接替代协作质量。
  • 衡量 Agent 团队，既要看成员能做什么，也要看它们能否在彼此依赖的条件下，共同把事情做完。
