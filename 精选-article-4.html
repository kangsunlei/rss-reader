让 Agent 成为音视频工作台：AI MediaKit CLI + Skill 发布

7/13/2026, 10:00:00 AM

📌 一句话摘要

火山引擎发布 AI MediaKit CLI + Skill，提供 100+ 音视频原子能力并通过命令行和 Skill 让 Agent 能直接调用并编排音视频处理工作流。

📝 详细摘要

文章介绍了火山引擎在 2026 Force 源动力大会上发布的 AI MediaKit CLI 与 Skill。AI MediaKit 是面向 Agent 时代的音视频开发套件，内置 100+ 音视频原子能力，涵盖视频理解、剪辑、字幕、画质增强、字幕擦除、转码、音频与图像处理等环节。CLI 部分提供面向 Agent 的原生命令行工具，支持视频裁剪、拼接、加字幕、画质增强等操作；Skill 部分面向 Agent runtime，允许通过自然语言描述需求由 Agent 自动调用并编排相应能力。此外，文章还详细说明了 Agent 友好的任务机制（任务 ID、状态轮询、结果回收），以及能力结构化、长任务可回收、端云协同、多入口统一底座等设计理念，强调其不仅是 API 包装，而是面向 Agent 的音视频工作台入口。文中通过具体示例展示了如何通过一句话让 Agent 完成剪辑加字幕或画质增强等复杂流程，并指出随着 AI MediaKit 能力持续开放，CLI 与 Skill 将持续跟进，推动音视频 Agent 生态的发展。

💡 主要观点

  1. AI MediaKit 提供 100+ 音视频原子能力，覆盖从理解到交付的全链路处理。 这些能力包括视频理解、剪辑、字幕、画质增强、字幕擦除、转码、音频与图像处理等，过去分散在不同软件或 API 中，如今被统一为面向 Agent 的能力底座。
  2. CLI + Skill 为 Agent 提供标准化入口，支持命令行调用和自然语言编排。 开发者可通过命令行直接使用媒体处理能力；Agent 通过 Skill 插件理解用户意图、自动生成并执行对应命令链，实现从一句话到可交付视频的全过程。
  3. 任务机制将异步音视频任务的提交、状态查询、结果回收下沉到工具层，免除 Agent 需要自行轮询或记忆状态的负担。 通过 task_id、轮询等待和终态结果回收，Agent 能够可靠地完成长链路音视频处理任务，提升自动化可靠性。
  4. 设计强调能力结构化、端云协同和多入口统一，使同一套能力可被 CLI、API 或 Agent 灵活调用。 基础剪辑适合本地执行，重算力任务如画质增强交给云端；不同入口面向不同使用场景，但都连接同一套 AI MediaKit 能力体系。

💬 文章金句

  • AI MediaKit CLI + Skill 并不是把 API 简单包一层命令。
