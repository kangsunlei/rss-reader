GPT-5-Codex

9/23/2025, 11:59:20 PM

📌 一句话摘要

Simon Willison 宣布 OpenAI 的 `gpt-5-codex` 模型开放 API，重点介绍其在编码、工具支持和多模态方面的能力，并提供了实际案例。

📝 详细摘要

本文宣布了 OpenAI 的 `gpt-5-codex` 模型的完整 API 发布，该模型之前仅限于 CLI 工具。文章详细说明了其定价与 `gpt-5` 相同，并强调了缓存输入 token 的 90% 显著折扣，这对 Agentic 工作流程的成本控制至关重要。该模型可通过 Responses API 访问，需要 `llm-openai-plugin` 进行 LLM 集成，新增的工具支持大部分由 GPT-5 Codex 自动生成。文章重点介绍了该模型在 Agentic 和交互式编码方面的专业性质，提倡“少即是多”的提示原则，因为它内置了编码最佳实践。实际演示包括 pelican 基准测试和成功的多模态图像描述，展示了其多功能能力。

💡 主要观点

  1. 完整 API 发布与定价 `gpt-5-codex` 现在可以通过 OpenAI 的 Responses API 完全使用，与 `gpt-5` 共享相同的定价，并且对于缓存的输入 token 享有 90% 的显著折扣，这对于 Agentic 工作流程非常有利。这使得开发者能更广泛地使用这一专业编码模型，而不仅仅是最初的 CLI 工具，从而实现具有成本效益的迭代开发。
  2. 具有“少即是多”提示的专用编码模型 该模型专为 Agentic 和交互式编码用例而构建，许多编码最佳实践都内置于其中，因此“少即是多”是核心提示原则，以避免过度提示并保持质量。该指南对于开发者有效利用 `gpt-5-codex` 至关重要。它明确了 `gpt-5-codex` 的最佳使用方式，使其有别于通用 LLM。
  3. 增强的工具支持，部分为自编写 `llm-openai-plugin` 现在包括工具支持，其中很大一部分是由 GPT-5 Codex 本身使用 OpenAI 的 Codex CLI 编写的。这表明该模型具备强大的自生成工具的能力，突出了其在开发者工作流程中进行自主开发和集成的潜力。
  4. 多模态能力演示 文章展示了该模型准确描述图像（鹈鹕骑自行车）的能力，表明其在纯代码生成之外的多模态理解。这拓宽了 `gpt-5-codex` 的应用范围，使其不仅限于文本编码，还可应用于需要视觉上下文进行代码生成或文档编制的领域。

💬 文章金句

  • GPT-5-Codex 专为 Codex CLI、Codex IDE 扩展、Codex 云环境以及在 GitHub 中工作而构建，并且还支持多功能的工具使用。
  • 由于该模型是专门为编码而训练的，因此很多以前需要通过提示才能让通用模型实现的最佳实践，现在已内置于该模型中，过度提示反而会降低质量。
  • GPT-5-Codex 的核心提示原则是“少即是多”。
  • 我今天向该插件添加了工具支持，主要由 GPT-5 Codex 本身使用 OpenAI 的 Codex CLI 编写。
