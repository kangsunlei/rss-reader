DeepSeek V4.1 Flash：更强、更快、更普惠

9/10/2026, 5:44:00 AM

📌 一句话摘要

DeepSeek 正式发布具备原生多模态能力的 V4.1 Flash 模型，采用 552B MoE 和非对称 Causal-Encoder-Decoder 结构，大幅降低 KV Cache 资源占用并下调 API 价格，同步开源模型与论文。

📝 详细摘要

深度求索（DeepSeek）宣布正式发布原生多模态模型 DeepSeek V4.1 Flash。该模型为 552B 参数的 MoE 架构，创新性地采用了 Causal-Encoder-Decoder 非对称结构，输入激活 8B、输出激活 16B，综合智能在 Benchmark 上超越了 V4 Pro。在推理与存储成本方面，KV Cache 对 HBM 和 SSD 的需求分别降至上一代的 1/4 和 1/8。API 方面，V4.1 Flash 全面替代上一代 Flash 模型，并拟于近期路由兼容 V4 Pro 请求；同步推行峰谷优惠定价。此外，官方已公开 Hugging Face 模型权重与技术报告论文。

💡 主要观点

  1. 全新架构兼顾高性能与低成本 采用 552B MoE 和非对称 Causal-Encoder-Decoder 结构，输入激活仅 8B、输出激活 16B，在 Agentic Benchmark 上性能超越了 V4 Pro。
  2. 大幅降低 KV Cache 显存与存储开销 相比上一代模型，对 HBM 的需求降至 1/4，对 SSD 降至 1/8，极大地降低了大上下文和 Agent 场景的推理解析成本。
  3. 平滑的 API 路由演进与降价政策 新模型上线并同步下调 API 单价，实行闲时半价策略；旧版 Flash 模型及未来的 V4 Pro 请求均平滑路由至 V4.1 Flash。
  4. 坚持开源生态与全面开放技术细节 同步在 Hugging Face 开源模型权重并附带技术报告，积极推动开源社区的推理适配与大规模集群部署。

💬 文章金句

  • DeepSeek V4.1 Flash 为 552B 参数的 MoE 模型，采用了全新的 Causal-Encoder-Decoder 结构，输入和输出不对称，输入激活只有 8B，输出激活 16B，成本显著低于已知的同尺寸模型。
  • 与上一代模型相比，对 HBM 的需求减少到 1/4，对 SSD 的需求减少到 1/8。
  • 北京时间 2026 年 9 月 14 日 12:00 之后，至未来 V4.1 Pro 上线之前，用户访问 deepseek-v4-pro 的请求将全部路由到 V4.1 Flash，并按 V4.1 Flash 单价计费。
