📌 一句话摘要

与 Altimeter Capital 合伙人 Freda Duan 深度对话，剖析 Token 经济本质、模型公司竞争格局、组织架构变革在 AI 时代的核心逻辑，以及资本市场的深层焦虑。

📝 详细摘要

本期播客是《Freda 的投资札记》系列第二集，延续了前作对 AI 投资与商业的深度剖析。嘉宾 Freda Duan 从「Token」这一基础计量单位入手，揭示了其作为认知陷阱的本质——Token 消耗的盲目堆砌往往对应着低效，而行业正逐步理解「Token per Task」和模型性价比的重要性，并预测收费模式将从按量付费转向按效果付费。节目深入评估了 Anthropic、OpenAI 等模型公司的竞争形势，指出 Coding Agent 成熟后触发的「better AI makes better AI」递归循环正在急剧拉大领先者与追赶者的差距。Freda 还提出了「接力赛变篮球赛」的经典组织架构比喻，强调 AI 时代的组织需要从层级化的信息传递模式，转向小团队同步推进、自主决策的灵活模式。同时，节目探讨了 AI 对软件行业、投资行业及普通从业者的冲击，坦诚地分享了在技术变革中的孤独感和焦虑，探讨了真诚的人际连接在不确定时代中的价值。

💡 主要观点

  1. Token 是一个极易误导人的计量单位，核心在于 Token per Task 的效率。 同样一个任务，不同模型消耗的 Token 可能相差几十倍甚至上百倍。追求 Token 消耗量本身是误区，行业需要更多关注模型性价比和实际效果，而非简单堆砌 Token。
  2. Coding Agent 成熟后引发模型收敛，头部模型公司技术壁垒急剧升高。 更好的 AI 能训练出更好的 AI，这个递归循环正在加速迭代。一旦领先者跨过临界点，追赶者将面临无法追上的「马车换汽车」式代差。
  3. AI 时代的组织架构应从「接力赛」向「篮球赛」演进。 传统公司层级本质是解决信息传递成本。AI 让同步推进成为可能，未来组织应转向 3-5 人的小分队，必要技能齐全、自主决策，仅重大方向向上汇报，大幅削减翻译成本和中间层级。

💬 文章金句

  • Token 其实是一个非常容易误导人的单位。同样一个 Task，不同模型消耗的 Token 可能差几十倍，甚至上百倍。
  • 当 Coding Agent 成熟之后，出现了一个非常重要的 loop：better AI makes better AI。
  • 过去是接力赛，一棒接一棒；未来更像篮球赛，3 到 5 个人的小分队，必要技能都在队里，同步推进，自己拍板，只有重大方向才往上升级。
  • 投资行业是一个非常低效的行业，大量时间花在找信息、清洗数据、比较预期。如果给 Agent 足够干净的数据和清晰的交易目标，它有没有可能做得比我好？
  • 焦虑无非就是第一是你很在乎这个，然后第二就是你作为本体，你没有足够的确定感，人都会有一种想要掌控未来的冲动。
