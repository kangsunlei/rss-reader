实测 DeepSeek V4 正式版：3 块钱干完 5 件事，AI「智价比」之战开打了

7/31/2026, 7:50:59 PM

📌 一句话摘要

文章通过对 DeepSeek V4-Flash 与 OpenAI 降价模型的实测对比，表明顶尖大模型的竞争正从单纯比拼能力转向争夺『智价比』，低成本高效模型正推动 Agent 时代的到来。

📝 详细摘要

文章详细测试了 DeepSeek 刚刚发布的 V4-Flash 模型在五项实际任务中的表现，包括数据分析报告生成、打砖块游戏、三体轨道模拟、科幻控制舱仪表盘以及基于 GitHub API 的开源 AI 项目周报。测试显示该模型在保持每百万 token 输入 1 元、输出 2 元低价的同时，通过后训练显著提升了代码与工具使用能力，Terminal Bench 分数从 61.8 提升至 82.7，DeepSWE 分数从 7.3 提升至 54.4。文章对比了 OpenAI 近期将 GPT-5.6 Luna 价格下调约 80% 的情况，指出顶级模型竞争正从规模扩张转向效率优化（韬定律），低成本高性能模型使得 AI Agent 能够长时间运行、反复试错，承担以前因成本过高而难以落地的复杂工作。全文共消耗约 3422 万 token，花费仅 2.85 元，展示了极高的智价比。

💡 主要观点

  1. 价格大幅下降，智价比成为新竞争焦点 OpenAI 降价约 80%，DeepSeek 保持低价，使模型调用成本显著降低，价格成为模型竞争的关键维度。
  2. DeepSeek V4-Flash 通过后训练显著提升代码与工具使用能力 在 Terminal Bench 和 DeepSWE 基准测试中得分大幅提升，表明模型能更好完成端到端的代码和任务执行。
  3. 实际任务测试表明低成本模型能完成复杂 Agent 工作流 五项任务（数据分析、游戏、三体模拟、仪表盘、GitHub 周报）仅花费 2.85 元，验证了低价高效模型的实用性。
  4. 价格与能力同步下降推动 Agent 时代的到来 低成本高效模型使 AI 能长时间运行、反复试错，承担以前因成本过高而难以落地的复杂工作。
  5. 模型竞争正从规模扩张转向效率优化（韬定律） 模型结构未变，仅靠后训练提升，说明即使不堆参数，通过数据质量、强化学习等手段仍可挖掘潜力。

💬 文章金句

  • 顶级模型的竞争，正在从单纯比拼能力，转向争夺『智价比』。
  • DeepSeek V4-Flash 的 API 价格仍是每百万 token 输入 1 元、输出 2 元。
  • 官方给出的提升幅度确实很大，甚至宣称『远超 V4-Pro-Preview』。
  • 5 个任务全部结束后，我回头看了一眼费用------DeepSeek 后台一共记录了 393 次 API 请求，累计消耗约 3422 万 token，前前后后只花了 2.85 元。
  • 当模型能力继续提升，调用成本持续下降，真正被打开的，或许不只是一个更便宜的聊天机器人，而是一个可以长时间运行、反复试错，并真正替人完成复杂工作的 Agent 时代。
