从 LOOP 到图探索 —— 算法模型的 AutoResearch 自进化系统架构演进之路

10/22/2026, 10:02:06 PM

📌 一句话摘要

本文详细介绍了美团技术团队如何将 Karpathy 的 AutoResearch 理念从单线程循环扩展为分布式图探索架构，通过状态机、业务知识库和真实大闭环实现算法研究的自进化，显著提升了模型优化效率和稳定性。

📝 详细摘要

在算法模型优化中，工程师经常面临重复性实验和等待时间的困扰。美团技术团队基于 AutoResearch，经过三次架构重构，构建了一套可在企业云端运行的自进化系统。系统从单线程 LOOP 模式升级为 CyclicGraph Engine 图探索架构，利用状态机确保长周期运行的稳定性，并通过业务知识库和真实大闭环实现经验的自动沉淀。在两个不同业务场景中，系统分别将单任务完成耗时减少约 85% 和 83%，其中一个方案已成功推全上线，证明了架构的通用性和有效性。

💡 主要观点

  1. 架构演进：从单线程 LOOP 到分布式图探索 初始的单线程 LOOP 架构虽然实现了自动化，但存在上下文爆炸和状态同步问题。通过引入 CyclicGraph Engine，系统实现了并行探索和集中决策，显著提高了迭代速度和资源利用率。
  2. 状态机驱动的稳定性保障 为了应对长周期运行中的不可靠性，系统采用了状态机驱动的异步触发机制。Agent 不再同步等待训练，而是通过状态文件恢复现场，这不仅提高了稳定性，还为后续的并行化打下了基础。
  3. 业务知识库与自进化 通用 Agent 缺乏业务理解，因此系统通过构建业务知识库和利用真实大闭环反馈，实现了经验的自动积累和沉淀。这种自进化机制确保了系统在垂直场景中的持续优化。
  4. 可信度与错误治理 在无人值守的循环中，错误治理至关重要。系统通过将约束写入代码、使用状态文件作为唯一事实源、以及实施交叉验证，确保了决策的可靠性和可审计性。
