11/24/2026, 11:30:00 PM

📌 一句话摘要

前 xAI 预训练成员沈驿康复盘 2026：xAI 因缺稳定战略方向与产品反馈机制而掉队，造模型必须靠市场反馈迭代，多模态理解比生成更关键，RSI 仍处早期。

📝 详细摘要

本期是张小珺对前 xAI 预训练团队成员、Learning Machine 创始人沈驿康的年度复盘，录制于黄仁勋辞任英伟达一周后。开场从硅谷情绪谈起：Anthropic 上市估值从两万亿美元一路下调到 1.3 万亿至 1.4 万亿，AI 泡沫担忧升温；沈驿康判断调整可能持续一到两年，关键变量是每年五六百亿美元的刚性算力支出能否转成真实收益，并称 AI 的实际经济价值现在更像一个 loading 符号。中段复盘 xAI：工程效率与人才密度都极高，但缺少稳定的战略方向，长期也没有像样的产品团队，「马斯克就是最好的产品经理」的说法让团队错失从市场收集反馈的机会。他由此提出造模型与造火箭的本质差别——火箭的对错可以自己回收验证，模型必须靠大规模用户反馈才能迭代，因此只有 frontier 才转得动数据飞轮，而反馈链路要半年到一年。他还比较 OpenAI、Anthropic、Meta 与 Google 的路线与组织，把 leadership 视作人才、算力之外的第三驾马车。后段谈多模态生成价值有限、多模态理解才是让模型读懂物理世界的关键，以及这一年 coding 与 Agent 的跃升、RSI 的门槛。转录在讨论学术界复现前沿训练技术时中断。

💡 主要观点

  1. 市场正在从「AI 一定变现」的乐观切回验证期，调整可能持续一到两年，核心变量是巨额算力支出能否转成真实收益。 Anthropic 上市估值从两万亿下调到 1.3 至 1.4 万亿，直接引爆泡沫担忧；沈驿康指出 OpenAI、Anthropic 每年五六百亿美元的刚性算力支出如果不能变成收入，就会从资产变成包袱。他把 AI 的经济价值形容为一个 loading 符号：十几人的创业公司已经能做过去上百人团队的产出，但大公司很难把效率提升直接换成收入增长，因为市场已饱和、产品线也没因 AI 扩张。技术侧他仍然乐观，认为真正待解的是组织架构与商业模式的适配。
  2. xAI 的问题不是资源或人才，而是没有稳定的战略方向，加上长期缺少产品反馈机制。 他肯定 xAI 工程效率极高（几十万卡集群几个月建成）、人才密度高，但战略不聚焦导致每个方向都差第一梯队一档，「所有这些东西都是后面的 0，前面那个一不存在就没用」。更具体的组织病灶是：公司长期没有成规模的产品团队，因为内部相信「马斯克就是硅谷最好的产品经理」，一旦他本人不投入，团队就失去了从市场收集反馈的通道；同时 xAI 不是用户量最大的团队，能拿到的反馈本就更少。他认为合理的研发模式是多个方向并行试错、按正反馈加注，这正是 OpenAI 的做法。
  3. 造火箭与造模型的本质差别在反馈闭环：火箭对错可自证，模型必须靠大规模用户反馈才能迭代，所以 frontier 地位本身就是飞轮的前提。 火箭炸了可以把残骸全部收回来分析；模型训完好不好，要投进市场、被大量用户使用才知道。因此非 frontier 的团队很难建立数据飞轮，剩下的路径往往是蒸馏前沿模型的行为模式。他也纠正了「用户数据不能提升智能」的说法：用户数据确实不如最初想象的高效，链路要走通产品层、后训练一直到预训练的数据配比，周期半年到一年，但它给头部公司的是不对称优势——知道下一步该解决什么问题，Anthropic 押中 coding 就是例子。
  4. 领导力是人才、算力之外的第三驾马车，有效组织趋向精简与目标高度一致。 他认为大模型一号位既要深刻理解模型，又要对组织与战略有清晰想法，这种组合型人才极稀缺。对比来看：Meta 在大组织内部建小团队、有耐心地一版版迭代，最终在个人 agent 方向找到位置；Google 资源近乎无限、能持续试错，但团队林立各自圈地，资源被稀释；OpenAI 靠 bottom-up 多线并进不断冒出机会。因为算力、数据、顶尖人力和高层注意力都有限，只有精简且目标一致的小组织才能避免内耗、快速长期推进。
  5. 多模态生成不是主战场，多模态理解才是补齐物理世界常识的关键；这一年的实质跃升在 coding、Agent 与模型架构，RSI 仍在早期。 视频生成市场体量有限（好莱坞加影视并不大）、创意属性强、信息密度低，从视频里学决策的效率远不如直接提升模型智能，因此 xAI 裁撤多模态生成、OpenAI 把 robotics 团队并入大模型训练都合乎逻辑。理解侧进步明显：一年前模型连表格里数字在第几行第几列都看不准，现在已不是问题，他借用自动驾驶里 sensor 清晰度决定上限的比喻说明「视力」是瓶颈。此外，Claude 写手机应用从去年的粗制滥造到今年超过他本人水平、开发周期从一两周压到一两天；Muse 能代打电话完成退款；架构层重新活跃（GDN、KDA、SPA attention、hyper connection）。但他质疑不少创业公司的「RSI」其实是搭在 Claude 上的 agent，模型领先才是 RSI 的前提。

💬 文章金句

  • 我觉得 XI 最大的问题就是他没有自己稳定的战略方向。
  • 造火箭你对和错你都是可以自己试出来的。做模型需要市场反馈，然后你才能快速迭代。
  • 整个 XI 其实在很长一段时间是没有比较大的产品团队或者产品经理的。
  • 我觉得模型领先其实对于实现 RSI 是非常重要的。
  • 我们的公司只有十几个人，但是我们能做的事情已经是以前一个几十人，上百人或者几百人的一个团队在做的事情了。
