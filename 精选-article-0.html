Kimi 16B 胜 GPT-4o！开源视觉推理模型：MoE 架构，推理时仅激活 2.8B

4/10/2025, 5:34:03 AM

📌 一句话摘要

Kimi 团队开源了轻量级视觉语言模型 Kimi-VL 及其推理版，采用 MoE 架构，推理时仅激活 2.8B 参数，性能超越 GPT-4o，并在多模态推理和 Agent 能力上表现出色，并支持 128K 上下文窗口。

📝 详细摘要

文章介绍了 Kimi 团队新开源的视觉语言模型 Kimi-VL 及其推理版 Kimi-VL-Thinking。该模型基于 MoE 架构，总参数 16B，但推理时仅激活 2.8B，具备强大的多模态推理和 Agent 能力，支持 128K 上下文窗口。模型训练使用了包括预训练数据（字幕数据、图像文本交织数据等）、指令数据和推理数据三大类数据集。文章通过多个示例展示了 Kimi-VL 在视觉理解、推理、OCR 字符识别和多轮 Agent 交互任务中的出色表现，并在特定基准测试中超越了 GPT-4o。文章还介绍了模型的技术细节，包括模型架构和训练过程。最后，文章还提及了 Kimi 团队可能即将推出 K1.6 模型。

💡 主要观点

  1. Kimi-VL 模型采用 MoE 架构，实现了轻量级和高性能的平衡 通过 MoE 架构，Kimi-VL 在推理时仅激活 2.8B 参数，降低了计算成本，同时保持了强大的多模态推理能力。
  2. Kimi-VL 在多模态推理和 Agent 任务中表现出色 该模型在视觉理解、推理、OCR 字符识别和多轮 Agent 交互任务中均取得了 SOTA 水平的结果，展示了其强大的能力。
  3. Kimi-VL 支持 128K 上下文窗口，能够处理更长的文本和视频信息 更长的上下文窗口使得模型能够捕捉和理解更长的文本和视频信息，从而提高推理和 Agent 任务的准确性。
  4. Kimi-VL 具备强大的 OCR 字符识别能力，是其处理多模态数据的基础 OCR 字符识别能力使得 Kimi-VL 能够从图像和视频中提取文本信息，从而实现对多模态数据的理解和处理。
