Claude Cowork 初体验：Anthropic 的通用智能体

1/12/2026, 9:46:13 PM

📌 一句话摘要

Simon Willison 评测 Anthropic 的新产品 'Claude Cowork' 通用智能体，重点介绍了其功能、实际应用场景以及严重的提示注入安全担忧，同时将其定位为 AI 智能体未来发展的重要一步。

📝 详细摘要

本文提供了 Anthropic 新产品 'Claude Cowork' 的初体验，这是一个研究预览版，设计为适用于各种计算机任务的通用智能体，扩展了其前身面向开发者的 'Claude Code'。作者重点介绍了其集成在 Claude Desktop macOS 应用程序中的用户界面，并详细描述了一个实验用例：Cowork 成功审阅了博客草稿。分析的重要部分聚焦于此类智能 AI 系统中固有的提示注入风险，指出了 Anthropic 坦诚的警告，并讨论了用于文件访问的沙盒环境。尽管存在安全担忧，作者仍将 Cowork 视为 AI 智能体未来发展方向的重要指标，并预计 Gemini 和 OpenAI 等竞争对手将推出类似产品。文章最后以一个关于建议标志的轻松 '彩蛋' 部分作结。

💡 主要观点

  1. Claude Cowork 将 Anthropic 的智能 AI 能力从编码扩展到通用计算机任务 Cowork 被描述为 '适用于其他工作的 Claude Code'，旨在将 Claude Code 复杂的代码执行和终端命令能力应用于更广泛的用户需求，使其成为一个通用智能体。
  2. 该产品在沙盒环境中展示了基于文件任务的有效自动化能力 通过审阅博客草稿的实际例子，Cowork 成功识别并分析了本地文件，表明其在为安全而设的容器化文件系统内执行有用工作的能力。
  3. 提示注入仍然是智能 AI 的关键安全担忧，尽管有缓解措施 文章强调了提示注入的持续威胁，Anthropic 承认了这种风险，作者指出即使有摘要层等高级防御措施，非技术用户可能仍难以识别 '可疑操作'。
  4. Claude Cowork 标志着向更通用、更强大 AI 智能体的重要趋势 尽管存在当前限制和安全风险，作者仍将 Cowork 视为 AI 未来的重要指标，预计其他主要 AI 开发者将跟进推出类似的广泛能力智能体产品。

💬 文章金句

  • 我一直在说 Claude Code 是一个伪装成开发者工具的 '通用智能体'。
  • Anthropic 表示 Cowork 只能访问您授予其访问权限的文件——在我看来，他们似乎将这些文件挂载到容器化环境中，这意味着我们可以信任 Cowork 无法访问该沙盒之外的任何内容。
  • 您还应该意识到 '提示注入' 的风险：攻击者试图通过 Claude 可能在互联网上遇到的内容来改变其计划。
  • 这是一个通用智能体，看起来很有条件将 Claude Code 极其强大的能力带给更广泛的受众。
  • 如果 Gemini 和 OpenAI 不在此类别中推出自己的产品，我会非常惊讶。
