智谱旗舰模型 GLM-4.6 上线，代码能力全面进阶

9/30/2025, 6:53:00 AM

📌 一句话摘要

智谱发布旗舰代码模型 GLM-4.6，在代码能力上取得显著提升，支持国产芯片部署，并推出升级版商业套餐。

📝 详细摘要

文章宣布了智谱最新旗舰代码模型 GLM-4.6 的上线，强调其在代码能力上的全面进阶，较 GLM-4.5 提升 27%。GLM-4.6 在高级编码、长上下文处理（200K）、推理、搜索和写作能力方面均有提升，并在公开基准测试和真实编程任务中表现优异，部分榜单对齐 Claude Sonnet 4，被誉为国内最佳代码模型。文章还指出 GLM-4.6 在平均 token 消耗上比上一代节省 30%以上，并首次在寒武纪和摩尔线程等国产芯片上实现 FP8+Int4 混合量化部署，为国产芯片在大模型本地化运行开创了可行路径。智谱同步升级了 GLM Coding Plan，提供个人和企业版套餐，并公开了部分测试数据以供业界验证。

💡 主要观点

  1. GLM-4.6 在代码能力上实现显著突破，成为国产最佳代码模型。 在多个权威基准和真实编程任务中，GLM-4.6 表现对齐甚至超越 Claude Sonnet 4，并大幅提升上下文长度和推理能力，为开发者提供更强的代码辅助。
  2. GLM-4.6 优化了资源效率并适配国产硬件，推动 AI 生态发展。 模型平均 token 消耗降低 30%以上，并首次在寒武纪、摩尔线程等国产芯片上实现高效混合量化部署，有效降低推理成本，支持国产 AI 软硬件协同。
  3. 智谱通过升级商业套餐，加速模型商业化与开发者生态建设。 推出个人和企业版 GLM Coding Plan，提供更强的 API 服务和编程工具支持，旨在吸引更广泛的开发者和企业用户，促进模型应用落地。

💬 文章金句

  • GLM-4.6 是我们最强的代码 Coding 模型（较 GLM-4.5 提升 27%）。
  • 在公开基准与真实编程任务中，GLM-4.6 的代码能力对齐 Claude Sonnet 4，是国内已知的最好的 Coding 模型。
  • GLM-4.6 已在寒武纪领先的国产芯片上实现 FP8+Int4 混合量化部署，这是首次在国产芯片投产的 FP8+Int4 模型芯片一体解决方案。
  • 在平均 token 消耗上，GLM-4.6 比 GLM-4.5 节省 30%以上，为同类模型最低。
