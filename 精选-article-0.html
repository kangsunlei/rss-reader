GLM-5 技术报告：技术细节全公开

2/22/2026, 9:40:00 AM

📌 一句话摘要

智谱发布下一代基础模型 GLM-5，通过 DSA 稀疏注意力、异步强化学习基础设施及智能体算法创新，推动 AI 从“氛围编程”向“智能体工程”跨越。

📝 详细摘要

本报告详述了 GLM-5 的技术架构与训练突破。GLM-5 采用 744B 参数的 MoE 架构，核心创新在于引入 DeepSeek 稀疏注意力（DSA）以极低成本实现 200K 长上下文处理。在后训练阶段，智谱构建了全新的异步强化学习（RL）基础设施，通过解耦生成与训练过程，解决了长程智能体任务中的计算气泡问题。此外，模型针对真实软件工程场景进行了深度优化，提出了异步 Agent RL 算法及 TITO 机制，显著提升了模型在复杂、长周期交互中的自主决策与纠错能力。报告还展示了 GLM-5 在国产算力生态上的深度适配成果，以及在 ARC 基准测试和真实世界工程评估（CC-Bench-V2）中的 SOTA 表现。

💡 主要观点

  1. 从“氛围编程”向“智能体工程”的范式转移 GLM-5 不再仅是被动响应指令，而是进化为能够自主进行规划、实现与迭代的智能体，专注于解决真实世界中复杂的端到端软件工程挑战。
  2. 引入 DSA 稀疏注意力机制优化长上下文效率 通过动态细粒度选择机制替代传统密集注意力，在不损失推理深度的前提下，将 200K 长序列的计算开销降低 1.5-2 倍，大幅削减了推理成本。
  3. 构建异步强化学习基础设施解决训练瓶颈 通过 slime 框架实现生成与训练的深度解耦，支持大规模智能体轨迹探索，消除了长程任务中常见的同步瓶颈，极大提升了 GPU 利用率和迭代效率。
  4. 针对 Agent 任务的算法创新与稳定性优化 提出异步 Agent RL 算法，利用 Token-in-Token-out (TITO) 和双侧重要性采样机制，解决了异步训练中的策略滞后与 token 不匹配问题。
  5. 原生适配国产算力生态实现软硬协同优化 深度适配华为昇腾等七大国产芯片平台，通过 W4A8 混合量化、高性能定制融合算子及专项推理调度，使单节点性能可媲美主流国际 GPU 集群。

💬 文章金句

  • 追求 AGI 并非单纯扩张参数规模，而是要从底层重构智能效率与自主演进架构。
  • GLM-5 旨在推动编程范式从'Vibe Coding'（氛围编程）转向'Agentic Engineering'（智能体工程）。
  • DSA 将长序列的注意力计算降低约 1.5-2 倍，能够以一半 GPU 成本处理 200K 上下文。
  • 真实世界体验比排行榜更重要。
  • GLM-5 不仅是一个更强大的模型，更是下一代 AI Agent 更高效、更实用的基础模型。
