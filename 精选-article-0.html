Claude Code 重构 Projects：引入 Thread 多智能体并行架构与共享记忆

9/17/2026, 9:18:52 PM

📌 一句话摘要

Anthropic 为 Claude Code 测试上线全新 Projects 功能，将单会话重构为「协调者+并行 Thread」的多智能体架构，支持任务自动拆解、云端后台持续执行及跨会话共享记忆。

📝 详细摘要

Anthropic 针对 Claude Code 测试上线了全新的 Projects 功能，借鉴了 Slack 的 Thread 交互与 Claude Tag 的多智能体架构。新版 Projects 采用「中央协调者+多工作 Thread」模式：用户在主对话中提出总体目标，协调者智能体自动拆解任务并在云端分发给多个并行的独立会话执行，任务完成后汇总给用户。项目内所有 Thread 共享统一的上下文记忆与资料库，支持离线异步运行与用量监控，适用于复杂性能优化、跨多端多代码库协同等复合场景。

💡 主要观点

  1. 新版 Projects 从静态文件夹重构为「协调者+多 Thread 并行」的多智能体协作模式。 主对话充当中央调度者负责需求理解、任务拆解与结果验收，派发的每个 Thread 均为独立的云端会话，具备独立代码分支和副本，且支持继续调用子智能体并行执行。
  2. 引入全局共享记忆与统一资料库，消除多任务之间的上下文割裂。 项目内的所有 Thread 均可读写同一份背景记忆（如配置规则、业务决策背景），避免在每个提示词中重复交代上下文，并支持 Overview 面板跨设备集中管理。
  3. 承袭 Claude Tag 架构并将多智能体协同能力下沉至个人 Pro 和 Max 订阅用户。 该功能将此前面向企业的 Slack 端 Claude Tag 架构原生迁移至 Claude 自身平台，大幅降低了个人在多终端手动调度多个 Agent 的操作与协作成本。

💬 文章金句

  • 新版变成一个持续的主对话：你在里面说要做什么，Claude 自己拆任务，分给多个并行的 Thread 去干，检查结果后汇总给你。关掉电脑，活儿还在云端继续跑。
  • 结构上是一个协调者加一群干活的。主对话里的 Claude 是协调者，负责理解需求、派活、跟进和验收。
