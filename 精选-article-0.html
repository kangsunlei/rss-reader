如何在 Vertex AI 中使用 Gemini Live API 原生音频

12/13/2025, 12:00:00 AM

📌 一句话摘要

Google Cloud 的 Gemini Live API 采用 Gemini 2.5 Flash 原生音频技术，通过单一 WebSocket 连接实现低延迟、多模态且具备情感智能的对话式 AI。

📝 详细摘要

本文宣布 Google Cloud 的 Gemini Live API 已在 Vertex AI 上全面推出，该 API 由最新的 Gemini 2.5 Flash 原生音频模型提供支持。这标志着对话式 AI 系统从传统的高延迟、多阶段架构，向统一、低延迟、实时、具备情感感知和多模态对话架构的根本性转变。Gemini Live API 提供原生音频处理、实时多模态交互、情感交互能力、主动音频（含更智能的抢话机制）、工具调用和连续记忆等高级功能，为构建下一代 AI 应用奠定了坚实基础。文章为开发者提供了两个快速入门模板（Vanilla JS 和 React）以及三个生产就绪的参考演示（实时主动顾问、多模态客户支持、实时视频游戏助理），并附带 GitHub 仓库链接。这些资源旨在帮助开发者通过单一 WebSocket 连接，快速理解和实现具有自然、拟人化界面的 AI 代理。

💡 主要观点

  1. Gemini Live API 通过低延迟、统一的原生音频处理彻底革新了对话式 AI 架构。 通过利用单一的、低延迟的 Gemini 2.5 Flash 原生音频模型直接处理原始音频，该 API 大幅降低了传统 STT-LLM-TTS 管道的延迟，从而实现更自然流畅的对话。
  2. 该 API 支持实时多模态交互和情感智能，使 AI 代理更具拟人化特点。 Gemini Live API 统一了音频、文本和视觉信息的处理。它能解读语音中细微的声学特征，如语调和情感，使 AI 代理能够以更高的情感智能进行交互，并适应各种复杂场景。
  3. 开发者可利用提供的模板和演示，集成工具使用和连续记忆功能，快速构建生产级 AI 应用。 文章提供了 Vanilla JS 和 React 两种快速入门模板，以及实时顾问、多模态客户支持和游戏助理这三个实践演示，展示了如何利用工具调用、知识注入和连续记忆等功能来构建复杂且功能强大的 AI 代理。

💬 文章金句

  • 今天，我们宣布 Gemini Live API 在 Vertex AI 上全面可用，该 API 由最新的 Gemini 2.5 Flash 原生音频模型提供支持。
  • Gemini Live API 彻底改变了工程方法，采用了统一的、低延迟的原生音频架构。
  • 通过原生处理原始音频，模型可以解读细微的声学特征，如语调、情感和语速。
  • 开发者可以无缝地将函数调用和基于谷歌搜索的事实增强等工具集成到这些实时对话中。
