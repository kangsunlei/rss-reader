2025：大语言模型年度回顾

12/31/2025, 11:50:40 PM

📌 一句话摘要

Simon Willison 的 2025 年 LLM 回顾突出了推理能力的兴起、编程智能体、中国开源权重模型、先进的图像编辑、学术突破以及人工智能领域竞争格局的转变。

📝 详细摘要

本文对 2025 年 LLM 领域的重大趋势和发展进行了全面的年度回顾，延续了 Simon Willison 的系列文章。核心亮点包括 LLM 中“推理”能力（RLVR）的出现，这带来了更强的工具使用能力和高效的智能体，尤其是在编程领域。作者讨论了 Claude Code 等编程智能体及各种 CLI 工具的崛起，强调了它们对开发者工作流的影响，以及某款 CLI 产品达到 10 亿美元年营收额的惊人表现。文章还探讨了安全担忧（YOLO 模式、偏差正常化）、向每月 200 美元的高价 LLM 订阅模式的转变，以及排名领先的中国开源权重模型的戏剧性崛起。其他趋势还包括 LLM 处理“长任务”的能力、提示词驱动的图像编辑（特别是 Google 的 Nano Banana）的普及、模型在学术竞赛中夺金，以及对 Llama 和 OpenAI 领导地位下降的批判性观察，因为行业正在迎头赶上并趋于多元化。它描绘了一个快速演进、竞争激烈且能力日益增强的 AI 景观。

💡 主要观点

  1. 推理能力（RLVR）显著提升了 LLM 使用工具和规划多步任务的能力。 OpenAI 的 o1 模型引发了推理革命，使 LLM 能够分解复杂问题、执行计划并根据结果调整策略，特别增强了工具驱动的 AI 应用，如改进的搜索和代码调试。
  2. 以 Claude Code 为代表的编程智能体成为软件开发领域的主要颠覆力量。 这些 LLM 系统可以编写、执行、检查和迭代代码，各种 CLI 和异步 Web 版本正在改变开发者的工作流并取得巨大的商业成功，甚至影响了传统的命令行工具。
  3. 中国开源权重模型在 LLM 排名中迅速攀升至全球领先地位。 从 2024 年底开始，DeepSeek、Qwen、Moonshot AI、Z.ai 和 MiniMax 等中国实验室发布了极具竞争力且通常是开源的模型，挑战了西方同行的主导地位，并引起了 AI 和半导体行业的市场转变。
  4. LLM 在处理长周期复杂任务和学术竞赛方面的能力大幅提升。 新模型可以独立完成需要人类花费数小时的软件工程任务。此外，LLM 在国际数学奥林匹克和 ICPC 等顶尖竞赛中获得了金牌表现，展示了增强的内部推理和代码执行能力。
  5. 提示词驱动的图像编辑工具（以 Google 的 Nano Banana 模型为代表）彻底改变了消费者和专业视觉内容的创作。 通过自然语言提示词上传和修改图像的能力（以 OpenAI 的未命名功能和 Google 的 Nano Banana 为代表，后者以生成实用的文本和信息图表著称）引发了大规模的用户采用，并推动了多模态技术的重大进步。
  6. LLM 领域的竞争格局趋于多元化，挑战了 Llama 和 OpenAI 此前的领导地位。 Llama 模型因发布过于庞大的版本而难以保持影响力，而 OpenAI 则面临着 Anthropic 和 Google 等其他实验室的激烈竞争，这些实验室在推理和智能体能力上已追平或超越，表明市场正变得更加碎片化和竞争激烈。

💬 文章金句

  • 事实证明，推理能力的真正释放在于驱动工具。具备工具访问权限的推理模型可以规划多步任务、执行任务并继续对结果进行推理，从而更新计划以更好地实现预期目标。
  • Claude Code 是我所称的编程智能体中最突出的例子——这些 LLM 系统可以编写代码、执行代码、检查结果并进一步迭代。
  • 中国模型的革命真正始于 2024 年圣诞节 DeepSeek 3 的发布，据称其训练成本仅为 550 万美元左右。
  • 图表显示了人类需要长达 5 小时才能完成的任务，并绘制了能够独立实现相同目标的模型的演进过程。
  • Nano Banana 引起了人们的注意，因为它能生成有用的文本！它显然也是遵循图像编辑指令表现最好的模型。
