唐杰、杨植麟、姚顺雨、林俊旸罕见同台分享，这 3 个小时的信息密度实在太高了。

1/10/2026, 12:03:00 PM

📌 一句话摘要

本文记录了唐杰、杨植麟、林俊旸、姚顺雨等中国 AI 领军人物在“AGI-NEXT”会议上的圆桌对话，深入探讨了 AI 模型分化、自主学习的下一代范式、Agent 战略以及中国 AI 未来在全球的引领潜力。

📝 详细摘要

本文是对“AGI-NEXT”技术分享会圆桌对话环节的实录总结。智谱唐杰、Kimi 杨植麟、Qwen 林俊旸和腾讯姚顺雨等中国 AI 领军人物，围绕模型分化趋势、下一代范式（自主学习）以及 Agent 战略等议题展开了深入探讨。姚顺雨认为未来模型将出现 To C 与 To B、垂直整合与应用分层的显著分化，并指出 To B 场景下对模型智能需求更高。林俊旸强调 AI 应服务于真实世界问题，并提出 AI 自主学习和主动性的重要性，但也警示了安全风险。杨强教授则从学术界角度探讨了智能上界、持续学习以及通用模型与本地专家模型协作等问题。唐杰老师对自主学习和创新范式充满信心，认为需要关注 AI 解决问题的价值、成本及开发速度，并肯定了中国年轻一代 AI 人才的冒险精神。与会者对中国 AI 公司在 3-5 年内引领全球 AI 的概率持乐观态度，但同时指出算力瓶颈与商业环境的挑战，并呼吁更多人勇于探索前沿。

💡 主要观点

  1. 大模型发展已进入“Doing things”和“Agent”时代，竞争焦点从 Chat 转向行动和搜索问题。 唐杰和杨植麟提出，在基础模型聊天能力趋于饱和后，AI 的下一个前沿是让模型执行具体任务（Action）和利用 Agent 解决搜索问题，这将是模型的关键竞争点。
  2. AI 模型在 To C 和 To B 市场将走向分化，To B 市场更需极致智能，To C 则重在用户体验和个性化上下文。 姚顺雨认为，To B 场景下智能越高生产力越高，用户愿意为最强模型支付溢价；而 To C 场景下，除基础能力外，更需要通过丰富上下文(Context)和个性化来提升用户体验，模型智能并非唯一指标。
  3. 自主学习（Self-Learning）被认为是下一代 AI 范式，但其定义、应用场景和衡量标准仍需探索。 与会者普遍认为自主学习是未来趋势，但强调其并非单一方法论，而是在特定场景下通过奖励函数进行学习。同时，该范式正逐步发生，而非突变，并面临想象力、安全等挑战。
  4. Agent 战略需关注创造的价值、执行成本和落地速度，模型公司和创业者在通用 Agent 领域并行发展。 唐杰、姚顺雨和林俊旸均认为 Agent 的核心在于能否解决有价值的问题、成本是否可控以及是否能快速迭代。姚顺雨指出 To B Agent 正快速发展，林俊旸则鼓励创业者探索长尾需求，模型公司则可将模型能力直接产品化。
  5. 中国 AI 引领全球的概率较高，但仍需突破算力瓶颈、拓展 To B 市场并增强创新和冒险精神。 姚顺雨和林俊旸对中国 AI 的未来持乐观态度，认为中国能快速复现并优化技术。然而，算力（光刻机）、To B 市场成熟度以及科学家和创业者在探索未知领域的冒险精神，是中国实现引领的关键挑战。

💬 文章金句

  • 下一仗是什么？是 Action，是 Doing things。
  • Agent 的本质，其实是一个搜索问题。智能和电力不一样，它不是等价交换品。
  • 未来的模型竞争，比的就是谁更有 Taste，谁更有品味，做模型本质上是在创造一种世界观，你在这个模型里注入了什么样的价值观，它就会涌现出什么样的智能。
  • 最大的问题是想象力，我们很容易想象强化学习或者推理这个范式，如果实现大概是什么样。
  • 中国想要突破新的范式或者做非常冒险事情的人可能还不够多，这里面有经济环境、商业环境包括文化的因素。
