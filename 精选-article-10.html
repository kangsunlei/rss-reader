AI Coding 新王登场！MiniMax M2.1 拿下多语言编程 SOTA

12/24/2025, 1:24:55 AM

📌 一句话摘要

MiniMax 发布了其旗舰级 Coding & Agent 模型 M2.1，在多语言编程榜单 Multi-SWE-bench 上以 10B 激活参数拿下全球 SOTA，并在后端开发、多语言支持及移动端开发方面取得显著突破。

📝 详细摘要

MiniMax 公司近日发布了其最新的旗舰级 Coding & Agent 模型 M2.1，该模型在多语言软件工程能力榜单 Multi-SWE-bench 中，以仅 10B 的激活参数取得了 49.4%的成绩，超越了包括 Claude Sonnet 4.5 在内的国际顶尖竞品，达到了全球 SOTA 水平。文章指出 M2.1 的核心进化在于解决了以往模型在后端架构和底层逻辑处理上的“偏科”问题，显著提升了对工程上下文的理解和对主流开发工具链的适配能力，尤其在 Rust、Java、Golang、C++等多种语言及原生 Android/iOS 开发上表现出色。MiniMax 还开源了全新的测试基准 VIBE，以更全面地评估模型在 Web、仿真、Android、iOS 及后端领域的真实表现。文章通过 H5 游戏开发和 Java 权限系统开发的实例，展示了 M2.1 从设计文档生成到代码实现及 UI 交付的完整能力，以及其在不同语言间代码迁移的潜力，强调了其在推进 IPO 进程中，通过技术实力增强市场信心的战略意图。

💡 主要观点

  1. MiniMax M2.1 在多语言软件工程能力榜单 Multi-SWE-bench 上取得全球 SOTA，突破了 AI 编码模型在后端和底层逻辑上的“偏科”问题。 M2.1 以仅 10B 激活参数超越顶尖竞品，证明其在工程上下文理解和处理复杂后端开发任务上的卓越能力，解决了以往 AI 模型在此领域的短板。
  2. M2.1 大幅提升了多语言支持和原生移动端开发能力，并能深度适配主流编程工具，成为工程级“熟手”。 模型系统性增强了对 Rust、Java、Golang、C++等多种语言的支持，解决了移动端开发难题，并能配合 Cursor 等主流编程工具进行代码修复与重构，具备实际工程实践能力。
  3. 通过实际案例（H5 游戏与 Java 权限系统），M2.1 具备从需求分析到代码实现甚至 UI 交付的端到端项目开发能力。 案例展示了 M2.1 能生成详细设计文档、高质量代码，并完成项目 UI 界面的构建，甚至支持不同语言的代码迁移，展现了其作为全栈开发助手的潜力，且开发效率极高。
  4. M2.1 引入 Interleaved Thinking 模型系列，并开源 VIBE 测试基准，旨在更真实、全面地评估 AI 在应用开发中的能力。 Interleaved Thinking 模型能够兼顾代码正确性和复合指令整合执行能力。VIBE 测试基准将 AI 编程考核维度从纯文本扩展到 Web、仿真、Android、iOS 及后端，为行业提供了更可靠的评估标准。
  5. 新模型的发布是 MiniMax 在 IPO 前夕的硬核自证，旨在展现其在 AI 编码和 Agent 领域的深厚实力和创新能力。 M2.1 的发布纠正了外界对 MiniMax 多模态能力单一的认知，强调其在文本模型上的 Coding 与 Agent 实力，并体现了其通过“内用转外售”模式提升研发效率和构建 AI 原生组织的战略愿景。
