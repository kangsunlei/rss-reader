E249｜Token 经济转点：OpenClaw、Hermes 到本地自研的 Agent 进化之路

8/20/2026, 12:00:00 AM

📌 一句话摘要

张宏江与黄东旭对谈 Token Maxing 到 Token Efficient 的行业转折，拆解 OpenClaw、Hermes、Agent 蜂群的演进路径，主张本地开源模型与云端前沿模型混合部署，并给出 AI Agent 创业与投资判断。

📝 详细摘要

本期节目聚焦 2026 年 AI 行业从「关注模型能力」转向「关注 Agent 工程」的关键转折。硅谷经历了 Token Maxing 烧钱竞赛——Uber 四个月烧穿全年 AI 预算、Meta 限制员工 Token 用量——如今开始转向更经济的 Token Efficient 策略。黄东旭分享了一线实战：从每天烧掉四五百美元的最强模型拥趸，到用本地开源模型+云端前沿模型混合部署，月账单降至两三百美元；他还复盘了 OpenClaw、Hermes、Slog 等 Agent 产品的演进，认为 GPT-5.5 的智商碾压和 DeepSeek V4、GLM-5.2 等开源模型的实用化是两大关键变量。张宏江从宏观视角判断 AI 基建远未泡沫化，Token 价格每年降十倍、消耗量持续增长，Agent 创业最好时机已到，关键是别做容易被大模型碾压的应用。两位嘉宾一致看好 to B 市场、Agent Native 企业和垂直行业数据护城河，并讨论了 AGI 奇点已来背景下的就业冲击与人类自处问题。

💡 主要观点

  1. Token Maxing 是策略而非目的，盲目烧 Token 必然导致成本失控 黄东旭指出，无脑用最强模型的合理前提是任务足够复杂；Uber、Meta 等大公司因缺乏设计而出现大量无效调用，正从 Token Maxing 转向 Token Efficient。
  2. Agent 产品正从单一 Agent 向多 Agent 协作网络演进 OpenClaw 让 Agent 走进千家万户，Hermes 以 Skill 沉淀成功经验，Slog 用 Agent 蜂群讨论解决复杂问题，未来将出现 Agent-to-Agent 网络与 Agent Harness 工程。
  3. 本地开源模型与云端前沿模型混合部署是当前最优成本方案 黄东旭实测本地跑 DeepSeek V4 仅需约 1 美元/天电费，月账单从四五百美元降到两三百美元；日常任务交给开源模型，复杂任务才调用 GPT-5.5、Fable 5 等顶级模型。
  4. AI 基础设施投资远未到泡沫阶段 张宏江认为 AI 基建占 GDP 比例仍低于铁路、公路建设时代；Token 价格每年降十倍，消耗量指数级增长，技术革命初期的高投入是正常现象。
  5. AGI 奇点已来，Agent 创业需避开大模型碾压区 张宏江判断机器 IQ 已超人类，重点转向 Agent 应用与垂直行业数据护城河；黄东旭看好 to B、基础设施与 Agent Native 企业的投资机会。
