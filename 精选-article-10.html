Claude 开发者平台 (API) 现已支持结构化输出

11/14/2025, 7:09:27 PM

📌 一句话摘要

Anthropic 宣布 Claude 开发者平台 API 推出结构化输出功能，Sonnet 4.5 和 Opus 4.1 模型率先支持公开测试版。

📝 详细摘要

Claude AI (Anthropic) 宣布其开发者平台新增一项重要功能：通过 API 提供结构化输出。开发者现在可以 JSON 等预定义格式接收 AI 响应。此功能已在 Sonnet 4.5 和 Opus 4.1 模型上推出公开测试版，对于将 LLM (大型语言模型) 集成到复杂应用至关重要，并能显著提高 Claude API 的可靠性和可用性，方便开发者构建可用于生产的 AI 系统。
