对话 MiniMax 择因：Agent 终会超过人类，我们又将何去何从？

6/8/2026, 1:15:28 PM

📌 一句话摘要

本文通过与 MiniMax Agent 研发工程师择因的深度对话，揭示了 Agent Team 架构的设计哲学、技术细节，以及行业在 Agent 工程上从模型竞争转向脚手架竞争的共识与趋势。

📝 详细摘要

文章以 APPSO 与 MiniMax Agent 研发工程师择因的对谈形式展开，深入探讨了 Agent 工程的最新进展。核心围绕 MiniMax 推出的 Agent Team 架构（Leader-Worker-Verifier），解释了其如何通过状态机、上下文隔离和对抗式验证来解决长程 Agent 任务中的上下文污染、共谋等顽疾。对话对比了 Anthropic（强约束）与 OpenAI（极简循环）的不同工程哲学，指出当前行业共识已从模型能力转向「脚手架」能力。择因还分享了 MiniMax 在 Agent 产品上的差异化思路（人与 Agent 同权限、全模态、强调细节），并探讨了 Agent 对工作方式的改变、未来就业市场的推演，以及一个关于用算力构建「人生分身」的开放性构想。文章信息密度高，包含大量一手技术认知和行业洞察。

💡 主要观点

  1. Agent 工程的核心已从模型能力转向脚手架。 文章指出，模型间的差距在缩小，真正拉开差距的是套在模型外的「壳」，即脚手架。Claude Code 泄露的代码中，仅 1.6% 属于模型决策，其余均为管理权限、上下文和兜错的 harness 代码。
  2. MiniMax 的 Agent Team 采用 Leader-Worker-Verifier 对抗式架构。 该架构通过状态机管理，将执行与验证职责分离，并实现上下文隔离，旨在解决长程任务中的上下文污染和 Agent 共谋问题，允许用户随时介入调整。
  3. Anthropic 与 OpenAI 的 Agent 工程哲学截然不同。 Anthropic 不信任模型，采用强约束框架，但导致了「黑天鹅」效应；OpenAI 采用极简的 agentic loop，配合遵循度极好的模型，反而效果更佳。这体现了模型与脚手架之间的长短板关系。
  4. Agent 产品应闭环到模型训练，并放大模型能力。 择因认为，模型公司做 Agent 的根本目的是让模型以完全体形态呈现，放大其能力，并让使用量乘以系数。Agent 产品需要能反馈到模型训练中，而非单纯堆砌产品。
  5. Agent 将改变工作范式，未来可能需「付费上班」。 随着 Agent 能力全面超越人类，初级员工的价值将被压缩。择因推演，未来可能出现「付费上班」现象，即个人需先自费使用 Agent 进行学习，成为资深员工后才能开始赚钱。

💬 文章金句

  • 模型之间仍然存在差距，但拉开模型公司之间真正差距的，早已不再是模型本身，而是套在外面的那层壳。
  • 一个极简框架养出了遵循度极好的模型，一个约束极强的框架却养出了「黑天鹅」。
  • 关于 agent 的所有东西，都在这篇论文里了。如果一篇就能说清楚，还有什么壁垒？
  • Agent 和模型是长短板的关系，你的 agent 足够强大，可以榨干模型的能力；相反如果模型足够强大，其实 agent 不需要特别复杂。
  • 我们是从过去迫使模型、agent 和我们一起干活，变成我们可以更多深度思考我们的工作，对工作进行抽象和模式识别，形成 skill 和规范——每一个人都变得更加 senior 了。
