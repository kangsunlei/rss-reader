AI x 大前端性能稳定性：快手亿级 DAU 下的智能诊断实践

3/5/2026, 5:57:00 AM

📌 一句话摘要

快手通过构建「柯南 AI」平台，利用 Agent 架构将专家排障经验模型化，实现了亿级 DAU 规模下大前端性能问题的智能诊断与自动化应急处置。

📝 详细摘要

本文是快手移动端稳定性负责人李锐在 QCon 大会上的演讲实录，深度分享了快手在性能稳定性领域引入 AI 的实践路径。面对亿级 DAU 带来的极高系统复杂度和排障成本，快手构建了「柯南 AI」平台，其核心是自研的 Agent 架构。文章详细介绍了 AI 在三个关键场景的应用：一是根因排障，通过 Holmes 工具采集 UI 视图和系统数据，利用 Agent 破解无堆栈 NPE 等疑难问题；二是性能分析，AI 简化了超大规模火焰图的解读流程，直接定位源码瓶颈；三是应急处置，AI 辅助 Ekko 工具生成兜底配置，有效规避了高压环境下的人为失误。作者强调，AI 的价值在于将专家经验转化为组织能力，实现排障效率的平民化与自动化。

💡 主要观点

  1. AI 在稳定性领域的定位是团队产出放大器而非替代者。 AI 的核心价值在于将少数专家的隐性经验转化为可规模化的组织能力，通过自动化处理体力型排障任务，释放人力进行更高价值的研发。
  2. 构建可扩展的 Agent 架构是实现智能诊断的技术基石。 快手从 AutoGen 演进到自研 Agent 框架，支持图编排和多种策略，通过将复杂问题拆解为单一职责的 Agent 协作，提升了推理的准确性。
  3. 将“零线索”排障场景转化为数据驱动的“适定”问题。 利用 Holmes 等工具采集静态日志与动态 UI 视图，为 AI 提供充足的上下文，从而在仅有系统堆栈的极端情况下也能推导出崩溃根因。
  4. AI 能够显著降低复杂性能分析工具的使用门槛。 针对动辄数十兆的火焰图数据，通过 AI 预处理算法进行数据压缩与源码关联，使普通研发无需深厚的底层知识也能快速定位性能瓶颈。
  5. 在应急处置中引入 AI 以对冲人类在高压下的非理性判断。 故障发生时，AI 能够保持冷静并基于历史案例提供标准 Checklist 和自动生成的兜底配置，有效减少了因紧张导致的操作失误和二次事故。

💬 文章金句

  • AI 定位首先不是取代谁，而是成为团队产出放大器，把'专家经验'转化为组织能力。
  • Code is cheap， debug is expensive—show me the fix。
  • 排障本质上是一场科学推理实验，本质上是演绎推理、归纳推理、溯因推理、类比推理等推理方法论的组合。
  • 故障处置里依赖人做判断非常不靠谱。人在高压下会紧张、肾上腺素飙升，很容易漏掉关键信息。
  • 自动化工具历来只是人类能力的延伸……真正决定价值的，始终是我们如何驾驭它。
