Cursor AI Agent 提升上下文效率，降低 Token 用量

1/6/2026, 8:57:18 PM

📌 一句话摘要

Cursor 的 AI agent 现已在所有模型中采用动态上下文，智能优化上下文填充，在使用多个 MCP 服务器时，可在不牺牲质量的前提下，将总 token 用量减少 46.9%。

📝 详细摘要

这条推文宣布了 Cursor 的 AI agent 的一项重大改进：对所有模型实施了动态上下文。这一增强功能使 agent 能够更智能地管理和填充上下文，在使用多个 MCP 服务器时，总 token 用量减少 46.9%，同时保持相同的性能质量。此次技术更新提升了效率，并可能为用户节省成本，因为 token 用量是许多 AI 模型的一项直接成本。
