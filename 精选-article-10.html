📌 一句话摘要

通义 DeepResearch 作为完全开源的 AI Agent 模型、框架与方案，通过创新数据和训练范式，将 AI 从“能聊天”推向“会做研究”，并在深度研究基准上实现 SOTA 性能，媲美海外旗舰模型。

📝 详细摘要

文章详细介绍了通义 DeepResearch 的发布，旨在将 AI 从“能聊天”提升到“会做研究”，以应对海外旗舰模型昂贵且受限的挑战。该项目在多项权威基准测试上取得 SOTA 表现，综合能力对标并跑赢海外旗舰模型，并实现了模型、框架和解决方案的全面开源，极大地降低了深度研究 AI Agent 的门槛。文章深入阐述了其独特的多阶段数据策略，包括基于全合成数据的增量预训练和后训练，以及创新的推理模式（ReAct Mode 和 IterResearch 深度模式）。此外，它革新了端到端 Agent 训练范式，涵盖 Agentic CPT、SFT 冷启动和基于 GRPO 优化的强化学习，并强调数据质量和训练环境稳定性是强化学习项目成功的更关键因素。最后，文章展示了 DeepResearch 在高德出行 Agent 和通义法睿等内部应用中的成功落地案例，证明了其在复杂任务中的实用价值和潜力。

💡 主要观点

  1. 通义 DeepResearch 实现模型、框架、方案全面开源，性能比肩海外旗舰。 此举降低了 AI Agent 开发和应用的门槛，赋能更多开发者，加速深度研究 AI 的普及和创新，提供高性价比的解决方案。
  2. 创新性地采用全合成数据策略进行增量预训练和后训练，不依赖人工标注。 摆脱对昂贵人工标注数据的依赖，通过自动化生成高质量、高难度数据，有效提升模型泛化能力和鲁棒性，解决数据瓶颈。
  3. 引入 IterResearch 深度模式解决 Agent 在长期复杂任务中的认知瓶颈。 该范式将复杂任务解构为迭代研究轮次，通过精简工作空间和核心报告整合，使 Agent 在复杂推理中保持清晰的“认知焦点”和高质量推理能力。
  4. 提出端到端 Agent 训练新范式，打通 Agentic CPT、SFT 到强化学习链路。 通过系统化、闭环的训练流程，结合算法创新和高稳定性基础设施，有效提升 Agent 在动态环境中稳健解决复杂任务的能力，引领 Agent 模型训练新范式。
