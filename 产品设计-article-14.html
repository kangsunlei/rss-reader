奉劝各位产品经理，放弃网页 AI 立即开始使用 Agent

6/21/2026, 2:00:00 AM

📌 一句话摘要

本文主张产品经理应从使用网页 AI 聊天转向使用 Agent，通过交付文档、分析 Skill、设计 Skill 来真正理解 AI，并以此实现职业转型。

📝 详细摘要

文章以直播内容为基础，核心观点是产品经理必须从使用网页 AI 聊天转向使用 Agent。作者认为，使用 Agent 的核心在于「交付资产」（如文档），而非简单的问答，这才能让 AI 真正进入工作循环。文章进一步提出，产品经理不仅要会用 Agent，还要能分析和设计 Agent 的 Skill（技能包），将 Skill 视为「给 Agent 用的产品」。作者将产品经理的 AI 能力分为四个层级：会用 AI、引入 AI、设计 Skill、设计 Agent Harness，并给出了对应的薪资范围。文章后半部分为作者线下 AI 产品经理课程的推广。

💡 主要观点

  1. 产品经理必须从使用网页 AI 转向使用 Agent，核心在于交付资产。 网页 AI 问答与搜索引擎无异，而 Agent 能产出文档等可被下游消费的交付物，使 AI 进入工作循环，成为真正的协作伙伴。
  2. 产品经理需要学会分析和设计 Agent 的 Skill，将其视为给 Agent 用的产品。 分析 Skill 如同做竞品分析，理解其设计逻辑；设计 Skill 则要求产品经理从 Agent 的视角思考流程、工具调用和兜底策略，是真正理解 AI 的标志。
  3. AI 产品经理的职业路径分为四个层级，薪资随能力提升显著增长。 四个层级为：会用 AI（保底）、引入 AI（20K+）、设计 Skill（25K+）、设计 Agent Harness（40K-50K+），越往高层对传统产品经验要求越低，对 Agent 理解要求越高。

💬 文章金句

  • Agent 要交付资产。你必须让它给你产出文档……因为只有当你要求 Agent 交付文档的时候，AI 才真正进入了你的工作循环。
  • 设计 Skills 就是设计给 Agent 用的产品。
  • 未来的产品要么是给人用的，要么是给 Agent 用的。
