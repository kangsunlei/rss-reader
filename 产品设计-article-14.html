Chrome 终于能分屏了！交互设计有点水平

12/19/2025, 12:20:00 AM

📌 一句话摘要

文章详细评测了 Chrome 浏览器新推出的分屏功能，对比了其与操作系统及 Edge 的分屏差异，并指出了其在交互设计上的优缺点。

📝 详细摘要

本文对 Chrome 浏览器新推出的分屏功能进行了深度体验和分析。作者首先肯定了 Chrome 分屏的便捷性，尤其是在触发分屏操作上优于 Mac 和 Edge 的现有方案。然而，文章也指出了该功能在实际使用中的多个交互设计问题，包括地址栏显示逻辑不清、关闭按钮功能重复且不明确、以及缺乏便捷的视窗替换功能。作者认为虽然 Chrome 分屏有亮点，但在细节上仍有待优化，甚至显得有些“未完工”。最后，文章结合这些设计缺陷，引出了作品集包装中如何突出亮点、规避缺陷的观点。

💡 主要观点

  1. Chrome 的分屏功能在触发操作上比操作系统和 Edge 更便捷。 Chrome 通过右键菜单直接触发分屏，步骤简化，提高了操作效率，相比 Mac 和 Edge 的复杂流程更符合用户直觉，这是其主要亮点。
  2. Chrome 分屏功能存在地址栏显示、关闭按钮逻辑和视窗替换等交互设计问题。 单个地址栏对应双视窗导致混淆、关闭按钮功能重叠且不明确、以及无法便捷替换视窗，这些设计缺陷导致用户在使用中产生困惑和不便，降低了用户体验的流畅性。
  3. 大厂产品也可能存在设计缺陷，产品设计应在突出亮点的同时，关注端到端的完整用户体验和细节优化。 即使是像 Chrome 这样由大厂开发的产品，也可能在功能细节上存在不足，这提醒产品设计师在追求创新功能的同时，更应重视用户端到端的完整体验，避免功能出现“未完工”感，并从用户角度出发进行持续迭代和优化。

💬 文章金句

  • 很多这种小众功能，实际用起来会觉得麻烦。但这个功能，后续我是真的有用起来。
  • 相对而言，Chrome 这个选择标签页的交互，效率高也符合直觉。
  • 但是实际使用下来，发现还是有不少问题，甚至让我感觉这个功能是不是还没完工就放出来了。
  • 即便是大厂，设计出的东西也不是面面俱到。有亮点，也有缺陷。
