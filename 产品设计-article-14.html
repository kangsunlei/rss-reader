AI 大厂，打起了“Token 奶茶大战”

8/2/2026, 11:19:00 AM

📌 一句话摘要

本文分析 AI 大厂近期推出的 Token 促销策略，探讨其背后的商业逻辑、用户增长与留存挑战，以及算力成本与用户忠诚度之间的矛盾关系。

📝 详细摘要

文章从多个维度解析 AI 大厂近期推出的 Token 优惠策略，指出其本质是通过类似互联网优惠券的方式争夺用户习惯。通过 OpenAI、Anthropic、DeepSeek 等公司的案例，分析 Token 定价策略的演变（如峰谷定价、套餐分层），探讨用户增长模式（非开发者用户增速快、Agent 使用深度增加）、用户忠诚度问题（企业用户多路接入、开发者随时切换模型）以及算力成本控制（限流、分层定价）。文章指出 AI 公司正面临商业化转型困境：补贴拉新与成本控制之间的平衡，用户留存与模型迁移成本之间的博弈，预计未来竞争将转向生态整合与用户习惯养成。

💡 主要观点

  1. AI 大厂通过 Token 促销争夺用户习惯 通过价格下调、额度赠送、会员套餐等策略，模仿互联网优惠券模式，试图建立用户使用惯性。
  2. 用户行为模式发生显著变化 非开发者用户增速快，Agent 使用深度增加（如长时任务、多 Agent 协作），导致 Token 消耗量大幅上升。
  3. 用户忠诚度薄弱，厂商难以锁定 企业用户多路接入模型，开发者可灵活切换，厂商通过补贴试图建立壁垒，但用户可能随时迁移。
  4. 算力成本与用户增长形成矛盾 Token 多送增加成本压力，厂商通过分层定价（如峰谷价）、限流策略试图控制成本，但收入增长不确定。

💬 文章金句

  • 模型能力负责把人吸引过来，补贴则负责给用户一个'先别走'的理由。
  • Token 不能无限发，用户又随时可能迁移，厂商只能把适用的人群、模型和时间切得越来越细。
