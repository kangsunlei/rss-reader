一个 AI 创始人的虚荣心、装，和愚昧之巅｜对谈 invoko.ai 创始人梦琪

5/23/2026, 1:30:00 PM

📌 一句话摘要

invoko.ai 创始人梦琪坦诚复盘从字节高 P 到 AI 创业的完整心路历程，剖析垂直 Agent 的结构性困局，分享从 ToB 转向 C 端浏览器插件的实战经验与认知觉醒。

📝 详细摘要

本期播客对谈 invoko.ai 创始人梦琪，她是一位典型的字节背景 AI 创业者：组华丽团队、借 Agent 势能融资、跟随技术 pivot。节目坦诚回顾了她过去一年的创业经历，包括从做垂直 Agent（达人营销方向）到最终转向 C 端产品（浏览器插件「可可」及客户端）的多次 pivot 决策过程。梦琪深刻反思了创业初期被虚荣心和性感叙事牵制的问题，指出「刚拿到融资的时候往往是创始人最接近愚昧之巅的时刻」。她剖析了垂直 Agent 面临的结构性困局：客户不用产品却想挣钱，最终被迫沦为 agency；以及 ToB 业务在中国「不值得创业」的判断。节目还分享了做 C 端产品的实战经验，包括用 Reddit 做用户研究的粗暴有效方法、产品设计的「第一性原理是解决问题最短路径」理念，以及从做客户端产品的 49 次迭代中重新找回对软件的敬畏与信心。最后，她呼吁创业者保持务实的理想主义，在 AI 快速变化的时代找到自己的位置。

💡 主要观点

  1. 垂直 Agent 面临结构性困局：客户不用产品，被迫沦为 agency 很多垂直 Agent 产品是给投资人看的「景观」，真正盈利靠的是服务而非产品。客户不用你的产品，但又想挣钱，最终只能出人去服务他，导致本质变成 agency。
  2. 「愚昧之巅」是创业者拿到融资后的普遍状态 刚拿到钱时最容易自我膨胀，以为自己的逻辑自洽、叙事性感就代表成功。但实际上逻辑与现实的差距巨大，落地是极其恶心、充满细节的过程。
  3. 产品设计的第一性原理是「解决问题最短路径」 不要为了装逼而塞入流行概念，不要追求「弄潮儿」式的 UI/UX 创新。回归本质：用户需要什么，就用最短路径解决它。其他都是周边。
  4. ToB 对 AI 创业者来说「不值得创业」 ToB 业务难以吃到新模型带来的能力跃迁红利，且在中国 ToB 是贬义词。创业应追求高赔率创新，而不是做一个逻辑推演出来的「证明题」。
  5. AI Coding 越强，越让人对软件充满敬畏 一个看似简单的客户端产品需要 49 个版本迭代才能稳定。软件由 15000 个细节组成，每一个细节都需要耐心打磨，AI 编码不能替代品质追求。

💬 文章金句

  • 刚拿到融资的时候往往就是创始人最接近「愚昧之巅」的时刻。
  • 很多 AI 产品其实就是给投资人看的一个景，真正挣钱靠的是服务而不是产品。
  • 第一性原理是解决问题最短路径，其他的事儿其实都是周边的一些东西。
  • AI Coding 越强，反而越让我对软件有敬畏之心。它是由 15000 个细节组成的，你得一点点的把那 15000 个屎吃掉。
  • 我觉得那会儿左脑用太多了，天天盘这些概念逻辑，被概念给骗了——而不是用心去感受你想做什么样的事。
