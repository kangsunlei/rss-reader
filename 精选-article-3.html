Agent 元年第 500 天：什么在消失，什么在诞生——为什么我们不该再投资 GUI 思维的软件？

7/1/2026, 5:30:00 PM

📌 一句话摘要

真格基金投资总监与 AI 开发者深度复盘 Agent 发展 500 天，核心观点是软件应从 GUI 思维转向 Headless、CLI 和 Skill 驱动的 Agentic Economy，并呼吁创业者和投资人拥抱这一根本性转变。

📝 详细摘要

本期播客是「十字路口」与真格基金「此话当真」的串台节目，深度探讨了 AI Agent 在过去 500 天的演进。嘉宾钟天杰（真格基金投资总监）和归藏（AI 开发者）以「GUI 退场」为主线，串联起六大关键词：Headless（无头软件）、CLI（命令行界面复兴）、Skill（技能封装）、Agentic Economy（智能体经济）、OpenClaw 的启示以及 Token Grant。对话深入剖析了为何当任务不再需要人类参与时，为人类认知缺陷服务的 GUI 便不再是必需品，软件应彻底转向以结果为导向的 Headless 形态。同时讨论了 CLI 在 AI 时代为何复兴，以及 Skill 如何成为封装个人品味与工作流的核心资产，并预示着一个脱离人类网络、由 AI 进行价值交换的 Agentic Economy 正在萌芽。此外，还分享了 Token Grant 如何以算力赞助的方式支持早期 AI 创业者。

💡 主要观点

  1. 不应再投资 GUI 思维的软件，Headless 是未来 当 AI Agent 成为完成任务的主体，原有的图形界面（GUI）就从原本服务于人的辅助工具，变成了额外的负担。软件应转向只有数据库和工具核心的无头形态，通过 Agent 直接调用。
  2. CLI 复兴是 AI 时代的必然，因为它与 AI 天然契合 命令行界面（CLI）用文本执行指令，对人是高门槛的死记硬背，但对大语言模型这正是原生交互方式。AI 解决了人类记不住海量命令的痛点，使 CLI 成为高效的人机协作接口。
  3. Skill 是将个人品味与工作流产品化的关键载体 Skill 不仅是提示词的封装，它能自我沉淀、进化，并可根据用户的上下文和品味，将重复性任务提炼成可复用的、交付高质量结果的品牌化产品，具备商业价值。
  4. Agentic Economy 需要一个脱离人类的新网络 未来，AI Agent 之间将形成一个独立于人类现有网络的价值交换体系，用于高效匹配需求与供给（如技能、作品），这需要新的基础设施如支付和记忆系统，但目前仍处于大基建时代。

💬 文章金句

  • GUI 本身都是基于这些人类注意力的机制去优化的一个产物。这个前提都是人类和信息交互的这个方式是某种意义上带有缺陷的。
  • 如果一旦某件事物不再需要人类参与的时候，他就不需要为人类的缺陷去服务。
  • 作为 PM 其实最重要的是定义问题。所以我认为不管是创业也好，做新的产品也好，就是不要去解一个上个时代已经被解决的很好的问题。
  • 如果你认为你的工具可以通过 A 智能更好的找到用户，你你你的公司传递的价值能找到用户，你就应该开放你的口味。
  • 我觉得代替人类完成某些信息的价值交换这件事儿，一定是一个脱离人类网络存在的一个新的网络。
