英伟达 RTX Spark 笔记本首发实测，我实现了 WorkBuddy 额度自由

10/16/2026, 6:52:37 PM

📌 一句话摘要

爱范儿首发实测搭载英伟达 RTX Spark 超级芯片的华硕 ProArt 创 16 笔记本，验证其本地运行 270 亿参数大模型的性能、续航与 WorkBuddy 协作体验。

📝 详细摘要

英伟达首次以 ARM CPU、Blackwell RTX GPU 与统一内存组合的完整计算平台进入 Windows PC 核心硬件领域，首批搭载 RTX Spark 的笔记本已开售。作者实测华硕 ProArt 创 16（64GB 统一内存版，售价 28999 元），在 12.9mm、约 1.77kg 的机身内可本地运行 Qwen 3.8 27B 等模型，生成速度约 14 token/s，30B 级模型推理可达 55-60 token/s。续航方面，持续跑 27B 模型时放电功率约 86.5W，满电理论续航约 1 小时 15 分钟。文章还测试了 WorkBuddy 的本地模型 Beta 功能，可一键下载腾讯优化的 500 亿参数 MoE 模型（16GB，CUDA 13 加速），并支持通过 LM Studio API 接入自定义模型。作者认为本地 AI 硬件已就绪，但软件适配与续航取舍仍是门槛，普通云端 AI 用户暂无换机必要。

💡 主要观点

  1. 英伟达首次以完整计算平台身份进入 Windows PC 核心硬件 过去英伟达只向厂商提供显卡，此次将 ARM CPU、Blackwell RTX GPU 与统一内存整合为可运行 Windows 的 RTX Spark 平台，兼顾 Apple Silicon 式高能效与 Windows 应用生态及 CUDA 能力。
  2. 64GB 统一内存可本地运行 30B 级模型，但速度与续航存在明显取舍 实测 Qwen 3.8 27B 生成速度约 14 token/s，Qwen3 32B（NVFP4）可达 55-60 token/s；持续推理时放电功率约 86.5W，满电理论续航约 1 小时 15 分钟，高负载下 GPU 利用率接近 100%。
  3. WorkBuddy 的本地模型 Beta 功能显著降低了本地 AI 部署门槛 可在应用内直接下载并管理本地模型，实测腾讯优化的 500 亿参数 MoE 模型（16GB，CUDA 13 加速）可完成 Three.js 游戏等任务，耗时约 14 分钟；也支持通过 LM Studio API 接入自定义模型到 WorkBuddy、DeepSeek Harness 等工具。
  4. Windows 正在补齐开发者与本地 AI 的软件短板 微软推进 MXC 安全容器、Windows ML 引入 llama.cpp 支持、WSL、Windows Terminal、WinGet 及 ARM64 原生工具链持续完善，新版 Windows Search 与 Copilot 也在加入本地执行能力。
  5. 本地 AI 硬件已就绪，但换机决策应视使用场景而定 对每天运行本地模型、开发 AI 应用或处理敏感数据的用户，该设备提供了新选择；仅使用云端 AI 工具的用户暂无必要为此换机，软件适配、模型能力与续航取舍仍影响体验。

💬 文章金句

  • 英伟达开始把自己的 ARM CPU、Blackwell RTX GPU 和统一内存结合起来，推出一套能够运行 Windows 的完整计算平台
  • 对于 64GB 的统一内存来说，30B 左右的模型大概就是这类电脑的舒适区。
  • 硬件已经能够运行大型模型，软件却还没有完全做好让每个人都轻松使用它的准备。
  • 如果你平时只是使用 ChatGPT、Gemini 等云端 AI 工具，现在还没有必要为了本地运行一个大模型，就专门换掉手里的笔记本。
