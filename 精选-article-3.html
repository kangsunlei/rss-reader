连写 5 遍 SQL 后，他从“人肉 Agent”的荒诞感里，死磕出了一款企业副驾驶

7/9/2026, 9:11:00 AM

📌 一句话摘要

文章访谈数势科技创始人岑润哲，讲述从人肉 Agent 到产品化 SwiftAgent 的历程，强调语义层、共识放大器、Human-in-the-loop 及 L4 行动闭环的价值与挑战。

📝 详细摘要

本文通过对数势科技创始人岑润哲的深度访谈，描述其在头部互联网公司五年量化运营期间反复编写相同 SQL、对齐指标口径的“人肉 Agent”经历，促使他思考如何将方法论产品化。SwiftAgent 通过自研指标语义层实现 NL2Semantics，在业务人员校验过的语义空间里让大模型进行选择与组合，从而实现 100% 消除幻觉（在语义层覆盖范围内）。产品演进经历了从分析-归因-报告到分析-决策-行动的 L4 闭环，核心升级包括 Human-in-the-loop 的反问澄清机制、可配置的流程编排层以及与钉钉、飞书等 IM 平台的入口后台化策略。文章指出，技术层面的难题已基本解决，真正的瓶颈在于组织决策权限、数据治理基础及业务共识的对齐；只有当企业内部指标口径统一、数据责任明确且管理层为 AI 建议预留快速通道时，Agent 才能发挥效能。最后强调，Data Agent 是共识的放大器而非制造者，技术只能加速已有共识的决策，若共识缺失则会放大混乱。

💡 主要观点

  1. 语义层是消除模型幻觉的关键，模型只在已授权的业务共识空间内做选择与组合。 SwiftAgent 采用 NL2Semantics，让大模型在业务人员校验过的指标语义空间里工作，避免生成未被授权理解的内容，从而在语义层覆盖范围内实现 100% 消除幻觉。
  2. 客户更看重‘知道自己不知道’的反问澄清能力，而非炫技的多智能体或思维链。 基于 Human-in-the-loop 的主动追问机制让用户在模糊或未覆盖问题时获得澄清，建立信任；可视化层面的升级对业务价值边际递减。
  3. L4 行动闭环在零售场景已跑通，但在金融等高合规行业受限于决策权限与审批流程。 Agent 能自动发现异常、归因、生成整改建议并推送至责任人，但在金融等场景中监管和内部风控导致高阶行动接受度低，零售则因试错成本低、效果可快速验证而推进更快。
  4. 企业采纳 Data Agent 的前提是内部业务共识、数据治理及决策快速通道三个信号至少满足两个。 若指标口径不统一、数据无责任人或 AI 建议需走完整传统审批，Agent 只会放大混乱；因此需先补基础治理再考虑上系统。

💬 文章金句

  • 真正稀缺的不是分析能力，是能被规模化复用的分析能力。
  • 客户对'知道自己不知道'的信任，远高于对'看起来很聪明'的信任。
  • Data Agent 是共识的放大器，不是共识的制造者。
  • 模型越强，语义层越重要。
  • 企业的决策权限没有为'机器发起的建议'预留一条快速通道，Agent 再准也只能停在'建议'这一步。
