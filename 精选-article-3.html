我的 2025 年度 AI 大盘点 - 前路已明。

12/31/2025, 1:19:00 AM

📌 一句话摘要

本文作者主观盘点了 2025 年度 AI 领域的大模型和 AI 产品/功能，包括写作、编程、绘图、音乐、声音、视频等不同垂类中的佼佼者，并特别强调了 DeepSeek R1 和 Manus 等对行业具有里程碑意义的产品。

📝 详细摘要

本文是对 2025 年度 AI 大盘点的总结，作者以个人主观视角，评选出年度大模型和年度 AI 产品与功能。在大模型方面，GPT-5.2 Thinking 被评为年度写作大模型，Gemini 3.0 Pro 获得年度 Coding 大模型，Nano Banana 和 Suno V5 分别成为年度绘图和音乐大模型，MiniMax Speech 2.0 被选为年度声音大模型，Sora2 则夺得年度视频大模型奖项。最终，DeepSeek R1 因其对中国 AI 开源生态的影响和推动作用，被评为 2025 年度大模型。在 AI 产品与功能方面，Claude Code 因其强大的编程能力和本地代码库探索功能，成为年度 AI 编程产品；Lovart 因其针对设计场景的优化和丰富功能，成为年度 AI 设计产品；ChatGPT DeepResearch 因其在深度研究方面的显著提效，荣获年度 AI 功能。而 Manus 则因其开启通用 Agent 时代并被 Meta 收购，成为年度 AI 应用。Plaude Note Pro 因其开启了 AI 硬件新品类并取得成功，被评为年度 AI 硬件。

💡 主要观点

  1. 大模型在写作、编程、多模态（绘图、音乐、声音、视频）等多个垂类领域均取得显著进展。 GPT-5.2 Thinking 在写作中展现出接近人类的自然文笔，Gemini 3.0 Pro 在编程审美和交互上表现突出，Nano Banana、Suno V5、MiniMax Speech 2.0 和 Sora2 分别在各自领域提供了创新和破圈级的体验。
  2. DeepSeek R1 作为开源大模型，极大推动了中国 AI 在全球的领军地位和国民认知。 DeepSeek R1 以超越当时顶级闭源模型的性能和极低的 API 价格发布并开源，震惊了世界，并借助春节的社会影响力，普及了国人对 AI 的认知，具有重要的战略意义。
  3. AI 产品和功能在编程、设计、深度研究和通用 Agent 方面展现出强大的实用价值。 Claude Code 提供本地代码库探索和自定义 Skill 以提升编程效率；Lovart 为设计场景优化并集成了前沿绘图模型；ChatGPT DeepResearch 能快速生成高质量研究报告，大幅提升信息获取效率；Manus 则作为通用 Agent 的雏形，开启了 Agent 时代。
  4. AI 硬件产品开始崭露头角，Plaude Note Pro 开创了全新的 AI 硬件品类。 Plaude Note Pro 通过实现录音、实时转录会议、自动总结和识别说话人等功能，将会议场景做到了极致，并以百万销量证明了市场的真实需求，引领了 AI 硬件的创新。

💬 文章金句

  • GPT-5.2 Thinking 在指令遵循、风格迁移、世界知识这块，都达到了极佳的效果，比 Gemini 2.5 Pro 幻觉更少和指令遵循更强，比 GPT-4.5 风格迁移效果更佳文笔更自然。
  • Gemini 3.0 Pro 的超强前端和审美，带给我的震撼，依然是最强的。它让我的创意不再只存于脑海，而是想到什么就直接去开发，这是真正的，帮我实现灵光乍现的模型。
  • DeepSeek R1，让国民对 AI 的认知，借着春节的风，又前进了一大步，也直接奠定了，中国在世界模型中的开源领军地位。
  • ChatGPT DeepReaserch 对我个人提效最大的工具，没有之一，它把我的查找资料的效率，提升了百倍千倍。
  • Manus 开启了一个属于 Agent 的时代。作为第一个通用 Agent，他们也做到了雏形，让通用 Agent 正式进入到了大众的视野，将 Agent 这个概念，往前推了一大步。
