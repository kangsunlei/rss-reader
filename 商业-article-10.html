DeepSeek 卖出白菜价，AI 公司还靠什么挣钱？

8/8/2026, 8:58:00 AM

📌 一句话摘要

本文以 DeepSeek V4-Flash 白菜价为切入点，指出模型能力廉价化不会直接冲击 ChatGPT、Claude 等订阅产品，AI 行业的价值正从底层模型向工作流、Agent 能力与用户信任转移。

📝 详细摘要

文章从 DeepSeek V4-Flash 的定价切入，指出其 API 价格每百万输入 token 0.14 美元、每百万输出 token 0.28 美元，被 Artificial Analysis 称为知名模型中成本最低，且官方将其定位为面向 Agent 的模型，兼容 OpenAI 与 Anthropic 接口。作者认为，这类低价并不直接冲击 ChatGPT、Claude 等订阅产品，因为后者卖的不只是模型调用，还包括界面、搜索、记忆、工具调用等整套被组织起来的能力与持续维护。真正值得关注的变化是：当足够好的智能变得廉价，价值会向模型之外移动；能接入工作流、稳定完成任务的 Agent 产品，才有机会守住价值。模型越便宜，AI 产品越需要证明自己在去掉底层模型后的独特价值。

💡 主要观点

  1. DeepSeek 低价不会直接冲击 ChatGPT、Claude 等订阅产品。 订阅产品卖的不仅是模型调用，还包括界面、文件、搜索、记忆、工具调用等整套被组织起来的能力与公司的持续维护。
  2. 智能变廉价后，价值会向模型之外移动。 谁能把模型接入工作流、让 Agent 稳定完成任务，并积累用户数据、习惯与信任，谁就更可能保住产品价值。
  3. 模型越便宜，AI 产品越要证明自身独特价值。 底层模型不再是护城河，产品需要证明拿掉模型之后，自己仍能构成用户愿意付费的完整产品。

💬 文章金句

  • 价值会向模型之外移动，谁能把模型接进工作流、让 Agent 稳定完成任务，积累用户数据、习惯和信任，谁就更有可能保住产品价值。
  • 当发动机越来越便宜，整台车不会因此失去价值。
  • 当足够好的智能变得廉价，AI 行业还会为什么东西收费？
