📌 一句话摘要

XGO-Duck 用 Arduino UNO Q、较便宜的舵机与开源装配资料回应 Microduck 复刻难题，但主控涨价抵消了舵机节省，整机成本大致持平。

📝 详细摘要

Microduck 复刻项目陆续出现后，讲者认为 XGO-Duck 是目前较有希望的替代方案，并逐项解释理由。硬件上，它以 Arduino UNO Q 替换原版的四核 ARM Linux 平台，连接高通 ARM CPU 与 STM32 MCU，兼顾上层计算和实时控制；舵机采用 Feetech 1910，姿态传感器采用 QMI8658A。较便宜的舵机让该部件成本降低约三分之一，但 UNO Q 比原版主控更贵，因此讲者判断整机成本大致持平。控制方面，项目在原版 50 Hz 策略流之外通过 MCU 实现 100 Hz 动作循环。除硬件参数外，XGO-Duck 提供 3D 打印图纸和装配指南，团队还完成舵机与机体动力学标定、建立仿真环境，并用仿真到现实的迁移训练起身、抓取等动作。视频适合关注开源机器人复刻与嵌入式控制的读者；成本、频率及性能主要来自讲者介绍，缺少独立测试和完整物料清单。

💡 主要观点

  1. UNO Q 将上层计算与实时控制结合 XGO-Duck 采用高通 ARM CPU 与 STM32 MCU 连接的 Arduino UNO Q，除原版 50 Hz 策略流外，经 MCU 实现 100 Hz 动作循环。
  2. 舵机省钱不等于整机降价 Feetech 1910 让舵机成本下降约三分之一，但 UNO Q 主控比原版方案更贵，讲者认为两者相抵后成本大致持平。
  3. 开源资料降低复刻门槛 相较只提供整机的原版，XGO-Duck 提供 3D 打印图纸和装配指南，便于自行组装与改装。
  4. 标定与仿真决定动作能否落地 团队标定舵机和机体动力学、建立仿真环境，再通过仿真到现实迁移训练起身与抓取动作。
