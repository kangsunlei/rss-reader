大模型价格战背后，真正稀缺的不是 Token

5/7/2026, 12:53:00 PM

📌 一句话摘要

前沿大模型市场正从 Token 价格竞争转向「准入经济」，模型公司通过邀请制、安全审查和伙伴筛选控制最强模型的访问权，形成「前沿层配给、工作层通缩」的双轨市场结构。

📝 详细摘要

本文是《Token 经济学》系列第七期，由上海期智研究院研究员李彪撰写。文章以 Anthropic 发布 Mythos 模型并采用 invitation-only 的 Project Glasswing 框架为切入点，深入分析了前沿大模型市场的结构性变化。作者指出，在能力最强的前沿层，模型公司不再单纯按 Token 定价出售推理资源，而是通过准入权、安全审查、伙伴筛选和使用边界设定来分配能力。这形成了「双轨策略」：前沿层卖的是绑定了安全义务的能力授权，工作层卖的是够用、够稳、够便宜的运行时。文章进一步讨论了算力扩张速度、工作层价格周期和两层边界稳定性对这套结构的潜在冲击，并指出企业实际面对的「交付价格」与官网 Token 标价存在显著差异。最终结论是，要读懂 AI 经济，更值得关注的是下一个前沿模型发布时的准入方式，而非单纯的 Token 价格表。

💡 主要观点

  1. 前沿大模型市场正从 Token 价格竞争转向「准入经济」。 在能力最强的前沿层，模型公司通过邀请制、安全审查和伙伴筛选控制访问权，价格不再是唯一门槛，准入本身成为价格体系的一部分。
  2. 模型公司采用「双轨策略」：前沿层配给，工作层通缩。 前沿层卖的是绑定了安全义务的能力授权，工作层卖的是够用、够稳、够便宜的运行时。两者遵循完全不同的市场逻辑和定价机制。
  3. 企业实际面对的「交付价格」与官网 Token 标价存在显著差异。 企业通过云平台、集成商、私有化部署等方式接入，实际支付的价格包含资源、合规、运维、服务等成本，模型公司公布的是「能力价格」，企业面对的是「交付价格」。
  4. 前沿层的权力集中是脉冲式的，每次能力跳跃会重新集中。 算力扩张速度、工作层价格周期和两层边界稳定性都可能动摇当前结构，但差距不会消失，每一代新模型都会重新拉开差距。

💬 文章金句

  • 越往前沿模型走，真正重要的可能不是价格表，而是谁能先用、谁被邀请、谁被限制、谁只能等待开放。
  • 在前沿这一层，价格已经不是唯一门槛。这里的顺序变成了：先被允许进入，再谈调用成本。
  • 前沿层可能越来越像配给市场，工作层却越来越像通缩市场。前者卖的是能力边界与使用资格，后者卖的是够用、够稳、够便宜的执行能力。
  • 要读懂 2026 年的 AI 经济，我们关注 token 价格表只是表层。更值得盯的，是下一个前沿模型发布时的准入方式。
  • 模型公司公布的是「能力价格」，企业真正面对的是「交付价格」。
