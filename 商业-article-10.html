119: YouWare 明超平：他们不信 AI coding 是新创作方式，我很开心

6/5/2025, 6:30:00 AM

📌 一句话摘要

YouWare 创始人分享 AI 创业、AI coding 作为新创作方式的愿景，及对 AI Agent 和未来硬件的深度思考。

📝 详细摘要

本期播客是《晚点 LatePost》对 AI 初创公司 YouWare 创始人明超平的访谈。明超平，曾就职于一加、剪映、月之暗面，拥有丰富的产品经验。他将 YouWare 定位为 web coding 创作社区，旨在让非开发者也能通过 AI 进行编程创作。访谈深入探讨了创业公司的产品哲学，强调环境而非工具决定用户行为，并以福格行为模型解释如何激发用户创作动机。明超平分享了他在摸索产品方向时的“顿悟”，意识到产品应顺应并被“智能不断提升”这一时代趋势赋能，从而追求每个 token 的价值最大化，而非单纯消耗。他详细分析了 AI Agent 未来的演进方向，区分了调度型 Agent 和被调度 Agent，并预测了可能的市场格局，强调数据和经验对 Agent 价值的重要性。此外，明超平还讨论了智能眼镜作为 AI 载体的潜力与挑战，特别是捕捉环境上下文信息的重要性。整期节目不仅分享了 YouWare 的产品理念和实践，更包含了创业者对技术趋势、商业模式、人才管理和个人成长的深刻洞察，对于技术从业者、产品人员及创业者具有高度参考价值。

💡 主要观点

  1. AI 产品的核心应是构建环境，激发用户创作动机，而非仅提供工具。 产品成功不仅在于提供简单易用的工具，更在于创造一个能触发用户灵感、提供支持和内容引导的环境，如 YouWare 通过社区实现创作动力与能力的结合。
  2. 优秀的创业公司必须顺应并被智能不断提升的时代趋势赋能。 创业公司应利用 AI 技术加速发展，追求每个 token 的价值最大化，将智能高效转化为生产力，而非逆势而为或过度工程化限制 AI 潜力。
  3. 未来的 AI Agent 格局将分为调度者和被调度者，数据和经验是竞争关键。 AI Agent 可能形成类似 Agent Rank 的网络，多数公司将成为提供特定高质量、低成本服务的被调度 Agent，其价值取决于背后数据的经验沉淀。
  4. AI 眼镜的关键价值在于捕捉手机/电脑无法获取的物理世界上下文信息。 与现有设备不同，AI 眼镜能持续采集环境数据，为 AI 提供独特的 context，这可能是颠覆现有科技巨头生态系统的潜在路径。

💬 文章金句

  • 大家好像一直都会有这样的一个看法，就是我们好像会把产品分为工具产品和社区产品。但在我们的视角里，社区只是我们要去解决用户问题的一种方式。
  • 好的公司可能都是他必须得跟着这些趋势，或者被这些趋势去赋能。如果你背离了这个趋势，你我我就跟团队讲说，靠我们 20 个人每天加班 24 小时，你是做不出来一个字节跳动的。
  • 我觉得可能看他对于智能本身的消耗程度到底怎么样。就是它消耗 token 的加速度是在变快还是很很缓慢的。如果它变化很快，那代表着它利用了这个时代最牛的或者说最主旋律的一个趋势。
  • 未来可能会出现非常多的老，but 或者假设 coding 夜间很多 UL 好吧，类似这样的 coding 夜间的产品就跟今天这个世界上有非常多的设计公司是一样的。所以未来会出现一个什么样的东西，叫做我要去选一个设计公司，帮我做品牌设计的时候我选谁？
  • AI 是一个技术，而不是用户价值本身，它更不是商业价值本身。
