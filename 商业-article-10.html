DeepSeek 为什么敢涨价？

8/11/2026, 8:06:00 AM

📌 一句话摘要

本文分析了美国头部模型通过降价争夺 Agent 工作负载，而中国开放权重模型则因成本优势扩大替代空间，导致 DeepSeek 等模型尝试涨价以验证定价权，并提出了任务成本与模型采用度的新视角。

📝 详细摘要

文章指出，Anthropic 取消了 Claude Sonnet 5 原定的 50% 涨价，而 OpenAI 大幅下调 GPT-5.6 Luna/Terra 价格，同时通过减少额度消耗变相降价；与此相反，DeepSeek 在官方 API 页面预告近期将整体涨价，称涨幅较大。文章解释这种中美模型价格分叉的原因：美国厂商在激烈的 Agent 竞争中降价以降低使用门槛，获取更多真实任务反馈以改进模型；中国开放权重模型（如 DeepSeek、Qwen、Kimi、GLM）凭借低价抢占常规任务，压缩了美国旗舰模型能够收取高溢价的任务范围。企业开始把模型视为可替换零件，关注每成功完成一任务的成本（Cost per successful task），而非单纯的 Token 单价。DeepSeek 和 Kimi 分别代表两种涨价路线：前者凭借巨大使用规模测试定价权，后者从一开始就采用高价旗舰模型定位。文章还引用斯坦福企业 AI 调研、OpenRouter 数据、DRadar Coding Agent 测试等资料，提出模型采用度指数（MAI）和任务成本作为衡量模型商业价值的更好维度。

💡 主要观点

  1. 美国头部模型通过降价争夺 Agent 工作负载，以获取更多真实任务反馈改进模型。 降价降低使用门槛，促使更多真实任务运行，暴露失败模式，从而反哺评测、产品和推理策略迭代，形成 Agent 竞争的正向循环。
  2. 中国开放权重模型利用低价抢占常规任务，压缩美国旗舰模型的高溢价空间。 DeepSeek、Qwen 等模型在分类、信息抽取、简单代码修改等场景中可替代昂贵的 Claude/GPT，使旗舰模型仅承担规划等高价值工作，价格溢价被迫向下压缩。
  3. 企业开始将模型视为可替换零件，关注 Cost per successful task，而非单纯 Token 价格。 在 Agent 场景中，一次用户指令可能触发数十至上百次模型调用，真实成本取决于 Token 价格、Token 数量、Agent 步骤和重试次数，企业因而更看重每完成一任务的实际成本。
  4. DeepSeek 和 Kimi 代表两种不同的涨价路线：前者测试定价权，后者靠高价旗舰模型定位。 DeepSeek 凭借极低价格积累巨大使用规模和开放生态，涨价可验证其定价权；Kimi 从发布起就设定高价（输出 100 元/百万 Token），瞄准高价值长程编程和知识工作场景。
  5. 文章提出模型采用度指数（MAI）和成本 per 任务作为衡量模型商业价值的新维度。 MAI 综合真实调用、生产部署、分发渠道、开发者生态、商业变现和持续使用六个维度，而成本 per 任务更能反映 Agent 场景下的真实经济价值，超越单纯的 Token 单价。

💬 文章金句

  • 美国头部模型开始压低价格，中国最新最强的一批模型却开始尝试提高单位价格。为什么？
  • 企业真正关心的指标逐渐变成：Cost per successful task。
  • DeepSeek 目前仍处于全球前沿模型的最低价区间。V4-Flash 每百万 Token 输入 0.14 美元、输出 0.28 美元，根据 Artificial Analysis 测算，它完成一组 benchmark 的平均成本约 3 美分，远低于 GPT-5.6 Sol 的 1.86 美元。
  • 规划和复杂推理交给 Claude 或 GPT，分类、信息抽取、简单代码修改、格式转换等大量步骤交给 DeepSeek、Qwen 或者其他便宜模型。
  • 价格因此开始向两边挤压。美国高端旗舰模型过去享有的溢价正在向下压；中国开放权重模型长期依靠的巨大价格优势开始向上收缩。
