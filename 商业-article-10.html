WebMCP 预览版发布：开启“浏览器即 API”新模式

2/14/2026, 2:12:40 AM

📌 一句话摘要

WebMCP 预览版发布，通过将浏览器转化为 API，改变了 AI Agent 与网页交互的传统模式。

📝 详细摘要

推文宣布了 WebMCP 预览版的发布，并分享了开源 Demo。其核心技术突破在于改变了 AI Agent 必须通过“视觉识别”或“模拟点击”来操作浏览器的传统方式，转而让浏览器本身成为可直接调用的 API 接口。这种方式极大地提升了 Agent 访问网页数据的效率和稳定性。推文附带了 GitHub 仓库链接，具有很高的实操参考价值。
