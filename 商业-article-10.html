DeepSeek 流量下滑，这半年梁文锋都干了啥？

7/14/2025, 8:53:00 AM

📌 一句话摘要

文章分析了 DeepSeek 流量下滑背景下，其创始人梁文锋坚守 AGI 技术理想，并小步快跑推进 C 端产品迭代和 Agent 布局，以应对市场挑战和商业化压力。

📝 详细摘要

文章深入分析了中国 AI 大模型公司 DeepSeek 在流量下滑背景下的战略与发展。尽管数据显示其官网和移动端用户量有所回落，但创始人梁文锋仍坚持 AGI 的纯粹技术理想，并认为当前是技术创新期而非应用爆发期。文章指出 DeepSeek 作为拥有底层模型和 C 端用户的 AI 平台，正面临巨头追赶和商业化压力。面对挑战，DeepSeek 正通过招聘智能产品人才、小步快跑式产品迭代（如新增登录方式、模型升级、APP 功能增强）来优化用户体验和布局 Agent 产品。文章还探讨了初创公司发力 C 端应用对融资和模型能力成长（通过 Agent 积累用户意图数据）的重要性。尽管 DeepSeek 背靠幻方量化有资金保障，但其构建 AI 生态的道路才刚刚开始，面临商业化和生态建设的长期挑战。

💡 主要观点

  1. DeepSeek 流量下滑但战略定力未受影响，坚持 AGI 技术理想。 尽管 Semianalysis 和 QuestMobile 数据显示 DeepSeek 用户量下滑，创始人梁文锋仍聚焦 AGI，认为当前是技术创新期，而非应用爆发期，显示其长期战略定力。
  2. DeepSeek 通过小步快跑式产品迭代和人才布局应对市场挑战。 文章指出 DeepSeek 在模型能力、网页/APP 功能（如识图、文件上传）上持续优化，并积极招聘产品与全栈开发人才，为未来智能体产品做准备。
  3. 大模型初创公司发力 C 端应用是融资和模型能力成长的关键。 C 端超级 APP 能吸引融资并积累用户意图数据，尤其是 Agent 产品，能帮助模型建立用户壁垒，促进模型能力持续成长。

💬 文章金句

  • 当前阶段是技术创新期，而不是应用爆发期。从长远来看，我们希望建立一个生态系统，让行业直接使用我们的技术和成果。
  • 2025 年也许就是从技术加速期到应用加速期的转换点，应用全面落地的雷声已经隐隐可闻。
  • OpenAI 的产品路径并非由一份清晰的产品需求文档（PRD）主导，它是一种在不可预测性中构建未来的全新模式，这是研究、产品与工程团队之间的一种紧密循环，而这种模式的核心，是迭代部署（Iterative Deployment）的哲学。
  • 超级 APP 只会沉淀很浅层的数据，大量用户数据不会在 APP 上，因此，聊天机器人类型的超级 APP，如果不附加其他深度应用功能，就很难构造自己的数据飞轮。
  • Agent 出现了，用户为了解决问题，必须给 Agent 输入更多'意图'（Context）以及专有信息，用户用得越多，Agent 越了解用户，这可能让 APP 建立用户壁垒。
