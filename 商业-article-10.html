张小珺对谈李广密：Q1 AGI 热点回顾，非共识下什么才是 AGI 的主线？

4/4/2025, 5:17:02 AM

📌 一句话摘要

李广密和张小珺对谈，强调 Pre-training 在 AGI 中的关键作用，Coding 作为 AGI 环境的重要性，并对比了 OpenAI 与 Anthropic 的不同发展路径。

📝 详细摘要

文章是张小珺与李广密的对话，深入探讨了 2025 年 Q1 中美 AI 领域的热点问题，核心聚焦于 AGI 的路线图。李广密强调了 Pre-training 的重要性，认为它是模型能力涌现的关键，并对 OpenAI 的战略选择和组织问题进行了分析。他还提出 Coding 是实现 AGI 的最佳环境，Agentic AI 是更关键的未来，Agent 落地有 Long Context reasoning、Tool use 和 Instruction following 三个关键能力。此外，文章还对比了 OpenAI 和 Anthropic 在 AGI 路线上的差异，认为 OpenAI 更关注 RL 和 C 端市场，而 Anthropic 则专注于 Pre-training 和 B 端市场。文章还展望了 AI for Science 的未来，强调其潜在的巨大价值和长期影响，并认为智能提升是 AGI 的主线。

💡 主要观点

  1. Pre-training 是模型能力涌现的关键，决定了模型内在的上限。 只有 Pre-training 才能涌现出新的能力，Post-training 和 RL 只是激发或加强能力，不能从根本上提升模型的能力。
  2. Coding 是实现 AGI 的最佳环境，是模型与现实世界交互的重要手段。 Coding 不仅在于编程本身，而在于它提供了一个动态、可操作的环境，Agent 可以通过生成和执行代码来实现对外部信息的采集、处理和反馈。
  3. Agentic AI 将是 AGI 的关键，Long Context reasoning、Tool use 和 Instruction following 是其核心能力。 Agentic AI 能够完成更复杂的任务，需要模型具备更强的推理能力、工具调用能力和指令遵循能力，才能更好地与环境交互。
  4. OpenAI 和 Anthropic 在 AGI 路线上存在分歧，前者关注 RL 和 C 端，后者关注 Pre-training 和 B 端。 OpenAI 希望通过 O 系列和 ChatGPT 实现 AGI，而 Anthropic 则专注于打造强大的 Base Model，并押注 Coding 和 Agentic AI。
  5. AGI 的核心在于智能的持续提升，智能本身即是最大的应用场景。 AGI 探索就像是爬一座科学的高山，而智能提升是攀登这座高山的主线，ChatGPT 只是第一站，后面还有 Coding、Agent、AI for Science 等。
  6. Online Learning 是未来可能的技术范式，核心是让模型可以自主在线探索并学习。 Online Learning 类似于人类的生存方式，在生存和激励的基础上，有充分的好奇心做探索，把好的 workflow 抽象并自动化成自己的 workflow。

💬 文章金句

  • 最大非共识是 pre-training 空间还非常大，甚至可以说是刚开始，还会迎来新的能力涌现。
  • Coding 是实现 AGI 最好的环境，Coding 意义不在于编程本身，而在于'环境'，现实世界的绝大多数任务都可以用 Coding 来表达，Coding 可能是数字经济 GDP 活动最重要的环境。
  • ChatGPT 只是前菜，接下来 Agent 才是正餐，AI for Science 科学探索才是珠穆朗玛峰。
  • 今天还是围绕智能主线，最重要的事情就是 push 智能往上走，做应用的要构建一个环境或容器，承接住研究溢出的智能红利。
  • 智能提升是唯一主线，智能本身就是最大应用，要围绕智能本身去投资和思考。
