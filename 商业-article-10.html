OpenAI 后训练工程师翁家翌，给 Agentic AI 提出了新范式假设

5/9/2026, 9:17:00 AM

📌 一句话摘要

OpenAI 后训练工程师翁家翌提出 Heuristic Learning（启发式学习）新范式，通过让 coding agent 自主编写、测试和迭代代码策略，在 Atari Breakout 中达到满分，并论证了经验可以沉淀为可读、可改、可测试的软件系统而非神经网络权重。

📝 详细摘要

本文报道了 OpenAI 工程师翁家翌在个人博客中提出的 Heuristic Learning（HL）新范式。核心实验是让 Codex 模型通过自主编写策略代码、运行环境、读取日志、定位失败、修改代码的闭环，在 Atari Breakout 中达到 864 分理论满分，在 MuJoCo 机器人控制仿真中也接近常见深度强化学习算法的水平。翁家翌将这一过程定义为 Heuristic Learning，其核心思想是：当 coding agent 足够强大时，学习不必发生在神经网络权重中，经验可以被写进代码、测试、日志和回放，变成可阅读、修改、复查和审计的软件系统。文章详细分析了实验过程、HL 与 Deep RL 的对比、Atari57 批量验证的结果与边界（如 Montezuma's Revenge 暴露的表达力极限），并探讨了该范式在机器人控制、安全关键场景可审计性、持续学习工程化、Agent 产品能力沉淀等四个产业落点。文章最后指出，HL 不能替代神经网络，更合理的分工是神经网络负责快速感知（System 1），HL 负责规则、测试和安全边界（System 1），LLM agent 担任 System 2 提供反馈。

💡 主要观点

  1. Heuristic Learning 提出了一种新的学习范式：经验可以沉淀为代码而非神经网络权重。 通过让 coding agent 自主编写策略、运行环境、读取日志、定位失败、修改代码的闭环，经验被写进代码、测试、日志和回放，变成可阅读、修改、复查和审计的软件系统。
  2. HL 在 Atari Breakout 中达到理论满分，在 Atari57 上样本效率与 PPO 相当。 Codex 通过多轮迭代，在 Breakout 中从 99 分逐步提升至 864 分满分；在 Atari57 全集上，画面输入版本在 970 万步时达到 0.81 HNS，接近 PPO 水平，且前期样本效率明显更高。
  3. HL 的表达力存在边界，Montezuma's Revenge 暴露了其难以处理长视野规划任务。 在 Montezuma's Revenge 中，Codex 生成的策略是一串硬编码的 86 个动作序列，而非真正的通用策略，说明普通程序策略难以处理需要严格动作时序和长期规划的任务。
  4. HL 的产业意义在于可审计性、持续学习工程化和 Agent 能力沉淀。 策略以代码形式存在使安全问题可进入软件工程流程（代码评审、CI 拦截）；HL 将参数更新问题转化为软件系统维护问题，可利用回归测试、版本 diff 等现成工具链；Agent 的执行记忆可沉淀为跨会话复用的代码资产。
  5. HL 与神经网络的合理分工是 System 1 / System 2 的协作模式。 神经网络负责快速感知和分类（System 1），HL 负责规则、测试、安全边界和局部恢复（System 1），LLM agent 担任 System 2 提供反馈和改进，三者协同处理在线学习和持续学习。

💬 文章金句

  • 当 coding agent 足够强，学习是否一定要发生在神经网络权重里？
  • 经验被写进代码、测试、日志和回放，变成一套可以阅读、修改、复查和审计的软件系统。
  • HL 把'如何更新参数'这个数学问题，改写成'如何维护一套不断吸收反馈的软件系统'这个工程问题。
  • 在 coding agent 时代，经验也许可以重新变成可读、可改、可测试的软件。
  • Montezuma 暴露的是 Heuristic Learning 的表达力极限。
