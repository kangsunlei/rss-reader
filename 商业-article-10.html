Agent 跌跌撞撞进入世界

7/22/2026, 8:30:00 AM

📌 一句话摘要

文章梳理了 2026 年二季度 AI Agent 从聊天工具迈向通用代理的八大趋势，涉及技术、经济、组织和社会影响。

📝 详细摘要

文章回顾了 AI 从聊天工具向能够自主读取文件、运行代码、操作软件甚至接入企业系统的 Agent 演进过程。它指出，通用 Agent（如 Codex、Claude Code、Workbuddy）正在成为新的软件入口，逐步取代传统浏览器和 App 作为用户与数字世界的交互入口。随后描述了 Tokenmaxxing 现象的兴起与快速消退——大规模赋予员工更多 Token 导致大量无效计算和重复工作，因审核、判断和协作环节成为瓶颈，导致 Token 消耗与实际产出脱节。文章进而探讨了多智能体（Multi-Agent）与自进化 AI（RSI）作为提升效率的新方向，但指出其协作效果往往依赖额外计算而非真正的群体智能，仍需人类设计的制度与反馈机制。接着分析了 CPU 在 Agent 工作中的角色上升，成为算力瓶颈的关键，推动服务器 CPU 市场快速增长。最后讨论了 AI Agent 带来的就业、安全、信息污染和人类认知依赖等社会影响，强调需要制度设计和人类判断来弥补自动化带来的风险。全文数据丰富、结构清晰，为理解 AI Agent 的当前发展及其广泛影响提供了系统视角。

💡 主要观点

  1. 通用 Agent 成为新的软件入口，正在取代传统浏览器和 App 作为用户与数字世界的交互入口。 文章指出，Codex、Claude Code 等通用 Agent 能够直接操作文件、终端和本地应用，无需依赖图形界面，因而成为 AI OS 的雏形，使得浏览器仅剩展示结果的角色。
  2. Tokenmaxxing 热潮快速升温又迅速降温，暴露出算力成本低效和组织协作瓶颈。 大规模赋予员工更多 Token 导致大量无效计算和重复工作，因审核、判断和协作环节成为瓶颈，导致 Token 消耗与实际产出脱节。
  3. 多智能体（Multi-Agent）与自进化 AI（RSI）成为提升效率的新方向，但仍依赖人类设计的制度与反馈机制。 通过任务拆解、并行执行和自优化代码，Agent 能在特定场景提升速度，然而协作效果往往来自额外计算而非真正的群体智能，缺乏合作机制时反而会降低准确率。
  4. CPU 在 Agent 工作中的角色上升，成为算力瓶颈的关键，推动服务器 CPU 市场快速增长。 Agent 工作大量时间花在工具调用、文件状态和非 GPU 计算上，导致 CPU 成为延迟和能耗的主导因素，市场已开始为这一趋势定价。
  5. AI Agent 的广泛使用开始影响就业、安全、信息污染和人类认知，亟需制度设计和人类判断来弥补。 自动化基础岗位、算力成本挤压预算、AI 生成内容的回音室效应以及人类对 AI 的过度依赖，都提示需要在高风险环节保留人工审核与反馈。

💬 文章金句

  • 人还得判断题目值不值得做、答案会带来什么后果，并且为它负责。
  • 因为不知编程，需要 Agent。这世界上所有需要可重复流程的事儿，都得要 Agent。
  • Tokenmaxxing 是整个 5 月可能最火的一个词。
  • 钱还不是最麻烦的地方。即使 Agent 把 Token 全烧对了，你做出来的东西也不一定能最终到交付这步。
  • 多 Agent 接下来要补的是制度。任务怎么分，信息怎样共享，错误算谁的，奖励如何沿工作链回流，长期表现差的 Agent 会不会被淘汰，这些都需要设计。
