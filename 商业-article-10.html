最强生图模型要来了？OpenAI 被曝偷偷测试 GPT Image 2.5

8/21/2026, 6:03:00 AM

📌 一句话摘要

OpenAI 在 LMArena 上测试的 luna-lisa-alpha 模型在人物一致性、图像真实感和文字生成方面显著提升，展示了其下一代 GPT Image 2.5 的潜力。

📝 详细摘要

文章报道称 OpenAI 正在内部测试名为 luna-lisa-alpha 的新图像模型，该模型在人物一致性、图像真实感、文字生成能力以及噪点减少等方面相较于前代 GPT Image 系列有显著改进。通过 LMArena 上的对比测试，作者展示了模型在复杂场景下的稳定性和细节表现，并与 GPT Image 2.0、Nano Banana Pro 等主流模型进行对比，指出其在 UI 设计、产品原型甚至代码转换等多模态应用场景的潜力。与此同时，OpenAI 近期还发布了 GPT Image 2 API 的透明背景生成功能，进一步暗示其在商业化路径上的布局。文章最后呼吁对多模态 AI 感兴趣的读者关注，并提供招聘信息。

💡 主要观点

  1. luna-lisa-alpha 强化人物一致性与图像真实感，降低噪点 测试结果显示，该模型在连续生成同一角色时能更好保持外观、服饰和整体风格，同时减少以前版本常见的颗粒感和噪点，提升整体视觉质量。
  2. 文字生成能力提升，可生成复杂 UI 与设计稿 多位测试者使用该模型生成手机界面、网页设计稿等，能够输出结构清晰、细节丰富的 UI 元素，甚至能够直接绘制可折叠 iPhone 官网的界面示例。
  3. 与 GPT Image 2.0、Nano Banana Pro 等模型对比，展示相对优势 对比实验表明，luna-lisa-alpha 在人物还原、细节处理以及整体稳定性上优于其他模型，尤其在复杂纹理和重复图案的产生上表现更为稳健。
  4. OpenAI 发布 GPT Image 2 API 透明背景功能，暗示多模态布局 该功能让用户生成带透明背景的素材，适用于产品图片、网页设计和营销内容，显示出 OpenAI 正在通过多个 checkpoint 进行 A/B 测试，推动图像模型的商业化应用。

💬 文章金句

  • checkpoint 是模型训练过程中的阶段性版本，通常用于内部测试和能力评估，并不代表最终公开发布版本。
  • AI 不应该只是帮少数人提高生产效率的工具，也应该成为更多人表达、创造和解决问题的新入口。
  • 图像模型的重要性可能被低估，因为它们未来不仅可以生成图片，还可能直接参与网站设计、产品原型甚至代码转换。
