📌 一句话摘要

Stripe 数据负责人基于内部数据，揭示了 AI 经济中 Agent 作为新行动者带来的欺诈模式、增长指标、定价逻辑和开发者体验的深刻变化。

📝 详细摘要

本文编译自播客节目 Every，核心内容是 Stripe 数据与 AI 负责人 Emily Glassberg Sands 的访谈。她基于 Stripe 处理全球约 2% GDP 的独特视角，分析了 AI 经济正在发生的几个关键变化：互联网的主要行动者从人扩展到 Agent，这要求产品在发现、购买、结账、身份、风控和开发者工具上全面重新设计。AI 公司的欺诈模式从信用卡盗刷转向偷算力，免费试用额度成为新的获客成本和攻击面。AI 公司增长迅猛，达到 3000 万美元 ARR 仅需约 18 个月，是传统 SaaS 的三倍。定价模式正从按座席收费转向按用量和结果付费。开发者体验方面，LLM 到 Stripe 文档的流量同比增长 10 倍，机器成为文档的主要读者，要求 API 和文档为“人机共同开发”设计。最后，文章介绍了 Agentic Commerce 的现状，Stripe 正通过 Agent Commerce Protocol 和共享支付 Token 等基础设施，为 Agent 时代的交易做准备。

💡 主要观点

  1. 互联网的主要行动者正从人扩展到 Agent，产品设计需全面适应。 Agent 正在访问文档、调用接口、比较商品、发起支付，商家需要优化机器可读的商品目录、价格和结账流程，而非仅针对人类用户优化网页导航和表单。
  2. AI 公司面临的新型欺诈是“偷算力”，免费试用成为新的攻击面。 与传统 SaaS 不同，AI 公司的每次 API 调用都有推理成本。欺诈者注册账号、领取试用额度、消耗大量 token 后失联，导致公司损失。风控必须从注册环节开始，而非仅在结账时。
  3. AI 公司的增长指标和定价模式正在发生根本性变化。 增长团队需关注每个注册账号消耗的不可追回推理成本。定价正从按座席收费转向按用量和结果付费，因为 Agent 可能让单个开发者产出提高数倍，绑定开发者人数的定价模式不再合理。
  4. 机器成为开发者基础设施的用户，文档和 API 需为“人机共同开发”优化。 LLM 到 Stripe 文档的流量同比增长 10 倍，机器正在读取文档、生成代码。因此，文档需要稳定结构、清晰示例和可预期的错误返回，以服务 Agent 和人类开发者。

💬 文章金句

  • 互联网出现了一种新行动者，Agent 会成为互联网上主要的行动者。
  • 欺诈者正在偷算力，而这是一类完全不同的问题。
  • 免费算力正在成为新的获客成本。
  • 达到 3000 万美元 ARR 的 AI 公司大约用 18 个月，是 2018 年顶尖 SaaS 公司的三倍速度。
  • 如果 Agent 让每个开发者生产力提高十倍，收入为什么还要和开发者人数绑定？
