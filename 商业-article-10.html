📌 一句话摘要

AI Agent 商业化落地面临通用与垂直之争，各方激辩破局之道，共探技术瓶颈、行业实践与生态博弈。

📝 详细摘要

本文整理了甲子光年主办的 AI Agent 论坛的圆桌对话内容，多位企业代表围绕 AI Agent 的商业化落地展开激烈的讨论。议题包括通用与垂直路径的选择，嘉宾们对通用 Agent 和垂直 Agent 的发展路径持有不同观点，以及各自的商业化策略。技术瓶颈与行业实践方面， 嘉宾们分享了各自在 AI Agent 领域的探索与实践，包括易点天下在垂直营销领域的应用、容联云在智能客服领域的实践、e 签宝在智能合同领域的应用，以及 Flowith 在 C 端通用 Agent 的探索，并指出 Agent 落地难点在于数据工程、知识工程的建设滞后等问题。此外，还探讨了 AI Agent 在企业内部信息化、销售服务、合同管理等方面的应用，以及商业模式、生态合作等问题。嘉宾们普遍认为，AI Agent 的商业化落地仍处于早期探索阶段，未来发展充满不确定性，需要深入理解业务流程、解决技术难题、构建合适的商业模式和生态合作。

💡 主要观点

  1. 通用 Agent 需达到 AGI 级别才具普适性，当前更应深耕垂直场景 通用 AI Agent，需要足够智能才能满足各种需求，目前更适合在垂直领域深耕，解决特定问题
  2. Agent 的核心在于任务规划与工具调用，以及与现有软件体系的融合 AI Agent 的核心在于任务的规划和工具的调用，通过大模型理解需求，并调用合适的工具完成任务，同时需要融合新旧软件体系。
  3. AI Agent 的商业化定价应与其带来的效率提升挂钩 企业级智能体的定价应该与其带来的效率提升挂钩，例如节省的人力成本，是更合理的定价依据
  4. 人机协同是 AI Agent 的重要发展方向 在复杂或关键任务中，人类的判断和引导是必要的，AI Agent 需要支持人机协同，实现“人可干预、AI 辅助”的模式。
