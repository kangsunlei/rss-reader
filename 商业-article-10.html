DeepMind 重磅：AGI 可能正在你眼皮底下「拼凑」出来，我们却毫无准备

12/23/2025, 3:20:00 AM

📌 一句话摘要

DeepMind 提出“拼凑型 AGI”概念，指出未来的通用人工智能可能由大量协同工作的普通 AI Agent 组合而成，而非单一超级模型，并为此提出了系统的安全框架和挑战。

📝 详细摘要

DeepMind 最新论文《Distributional AGI Safety》颠覆性地提出“拼凑型 AGI”理论，认为未来的通用人工智能（AGI）将以众多普通 AI Agent 协作涌现的形式出现，而非单一“超级大脑”。该理论基于 AI Agent 快速部署、Agent 间通信标准化及市场对专业化 Agent 的经济激励。文章通过金融分析案例阐释了其运作和快速涌现的风险。DeepMind 提出一套基于“受监管市场”的四层纵深防御框架，涵盖技术、运营、治理和法律层面，引入庇古税、熔断机制、AI 裁判、加密身份等创新概念以应对分布式智能的安全挑战。尽管论文坦诚框架仍处于理论阶段且存在局限性，但它填补了 AI 安全研究盲点，为多 Agent 安全提供系统性思路，并可能改写 AGI 的到来时间线。

💡 主要观点

  1. AGI 可能以“拼凑型”形式出现，而非单一超级 AI 模型。 DeepMind 挑战了主流的 AGI 概念，指出通用人工智能并非通过单一超强模型实现，而是由成百上千个普通 AI Agent 协作涌现形成，这表明现有 AI 安全准备的方向可能存在偏差。
  2. 拼凑型 AGI 的出现具备技术基础和强大的经济驱动力。 AI Agent 的快速部署、Agent 间通信协议的标准化（如 Anthropic 的 MCP）以及市场对“够用就好”的定制化专业 Agent 的需求，共同推动了分布式智能生态的兴起，为 Patchwork AGI 的实现提供了现实基础。
  3. DeepMind 提出一套整合跨学科理念的四层纵深防御框架应对拼凑型 AGI 的安全风险。 该框架核心在于构建一个“受监管的 Agent 市场”，通过技术层面的结构性约束（如庇古税、熔断机制、AI 裁判、加密身份）、运营层面的市场准入管理、实时监控以及法律层面的监管与问责，全面应对多 Agent 系统带来的复杂安全挑战。其创新性在于借鉴了环境经济学、金融监管、公司法等多个领域的成熟机制，为 AI 安全治理提供了系统性、多维度的解决方案。

💬 文章金句

  • 我们可能一直在为错误的敌人做准备。
  • AGI 或许不会以「超级大脑」的形式出现，而是通过多个「次级 AI」的协作，像拼图一样组合而成。
  • 「在这种观点下，AGI 不是一个实体，而是一种'事态'------一个成熟的、去中心化的 Agent 经济体系。」
  • 「这种转变可能是快速而突然的......更令人担忧的是，这种转变可能不会被立即识别，这带来了重大风险。」
