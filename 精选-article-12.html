《AI Native 研发范式实践手册》重磅发布

9/23/2026, 6:49:00 AM

📌 一句话摘要

阿里巴巴发布《AI Native 研发范式实践手册》，总结了从 Copilot 到 Agentic 时代的变革，强调了企业级 Agent 基础设施的重要性。

📝 详细摘要

本文总结了从 Copilot 到 Agentic 时代的变革，强调了企业级 Agent 基础设施的重要性，包括模型能力的进步、Harness 框架的演进、Agent 的运行环境、身份与权限体系、可观测与评测能力等方面的发展。

💡 主要观点

  1. 模型能力的进步为 Agentic 时代的变革提供了基础 截至 2026 年中，主流模型在 SWE-bench Verified 上的通过率已从两年前的不足 30% 攀升至 80% 左右，Coding 能力正在被快速"解决"
  2. 企业级 Agent 基础设施成为新的竞争焦点 Anthropic 于 2026 年 5 月推出 Claude Managed Agents，提供托管的 Agent 运行时、自托管沙箱执行和 MCP 隧道
  3. 企业是否建设了一套完整的 Agent 基础设施以支持 Agent 安全可靠地访问操作各类内部系统 企业是否通过重塑工作流、整理历史知识，让 Agent 能够访问到围绕目标的清晰上下文
  4. 企业是否重塑了组织文化、人才画像及激励机制、团队协同模式，以支撑个体和团队发挥 10x 的效能 带着上述问题，我们首先从三个真实的业务实践案例出发，分别是 AIDC 数字投手智能营销助手、千问用增 Agent 和万有无界平台

💬 文章金句

  • 唯有积极投身其中才有可能真正理解这一变革的路径和意义
  • 模型能力的自然溢出显然不够，因为我们认识到从模型及 Harness 框架的能力，到像阿里巴巴这样的大型企业的研发效能 10x 提升，中间存在着非常大的 gap
