像智能体一样思考：我们如何在 Claude Code 中设计工具 | Claude

4/9/2026, 4:00:00 PM

📌 一句话摘要

Anthropic 的工程师分享了他们在 Claude Code 智能体工具设计上的迭代理念，强调通过“像智能体一样思考”来平衡模型能力与工具复杂度。

📝 详细摘要

本文探讨了 Claude Code 智能体工具背后的设计原则。作者认为，工具设计应针对模型的特定能力进行定制，即他们所说的“像智能体一样思考”。通过对信息获取（AskUserQuestion 工具）、任务管理（从 Todos 到 Tasks 的转变）以及代码库搜索（从 RAG 到 Grep 的演进）的案例研究，他们展示了一种迭代式的工具开发方法。核心策略包括利用渐进式披露来管理上下文衰减，以及使用子智能体（如 Claude Code Guide）来处理专业知识，从而避免主智能体的工具集或上下文窗口过于臃肿。

💡 主要观点

  1. 工具设计必须根据模型的固有推理能力进行校准。 智能体在处理为其能力“量身定制”的工具时表现最佳，而不是使用通用工具。开发者必须观察模型的输出，以确定工具对于当前模型版本来说是过于复杂还是限制过多。
  2. 迭代式的失败是找到正确工具抽象的关键。 团队通过多次尝试修改现有工具和更改输出格式的失败经历，最终确定了一个专门用于阻塞循环以获取用户输入的工具。
  3. 渐进式披露可防止上下文衰减和工具臃肿。 通过使用子智能体或可搜索的文档链接，而不是将所有内容塞入系统提示词中，主智能体可以在保持对专业信息访问权限的同时，专注于其主要任务。
  4. 应赋予智能体构建自身上下文的能力。 从预索引的 RAG 转向为智能体提供“Grep”工具，使 Claude 能够动态探索代码库，这模拟了人类开发者查找信息的方式。

💬 文章金句

  • 你需要提供与模型自身能力相匹配的工具。但你如何知道这些能力是什么？你需要保持关注，阅读它的输出，并进行实验。你学会了像智能体一样思考。
  • 随着模型能力的提升，模型曾经需要的工具现在反而可能成为它们的束缚。
  • 添加新工具的门槛很高，因为这会给模型增加一个需要考虑的选项。
  • 为模型设计工具既是一门科学，也是一门艺术。
