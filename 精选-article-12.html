阶跃发布 Step 3.7 Flash，面向生产级 Agent 的高效率 Flash 模型

5/29/2026, 12:03:00 AM

📌 一句话摘要

阶跃星辰发布并开源 Step 3.7 Flash 模型，该模型围绕生产级 Agent 场景进行系统优化，在速度、成本、可靠执行和复杂任务完成能力之间取得更优平衡。

📝 详细摘要

阶跃星辰正式发布并开源 Step 3.7 Flash 模型，定位为面向生产级 Agent 的高效率基座模型。该模型采用稀疏 MoE 架构，总参数 196B+1.8B（ViT），激活参数仅 11B，最高生成速度可达 400 Tokens/s。模型围绕四大核心能力进行优化：原生多模态理解与执行、联网与视觉搜索增强、高可靠工具调用与编排、Agent 生态兼容优化。在 Toolathlon、ClawEval-1.1、GDPval 等 Agent 相关基准测试中表现优异，并已适配 Claude Code、KiloCode、RooCode、Hermes Agent 等主流 Agent 框架及 MCP/Skills 等工具调用协议。文章强调，Flash 模型已从单纯的「更快更便宜」定位，演进为 Agent 生产化阶段的关键基础设施。

💡 主要观点

  1. Step 3.7 Flash 是面向生产级 Agent 场景优化的高效率 Flash 模型。 模型不再单纯追求速度或成本，而是围绕 Agent、Coding、Search 与多模态工作流进行系统优化，在速度、成本、可靠执行和复杂任务完成能力之间取得平衡。
  2. 模型具备原生多模态理解与执行能力，支持视觉感知与搜索深度结合。 能够理解 UI、图表、文档、图片和应用界面，在复杂视觉任务中可自主裁剪、放大、重读图像，并在信息不确定时主动发起搜索进行交叉验证。
  3. 采用稀疏 MoE 架构，激活参数仅 11B，最高生成速度达 400 Tokens/s。 在模型能力、推理成本与执行效率之间实现更优平衡，适合高频、多轮、低等待的 Agent 应用场景。
  4. 针对主流 Agent 框架和工具调用协议进行了兼容优化。 可稳定接入 Claude Code、OpenClaw、Hermes Agent 等框架，支持 MCP/Skills 等协议，降低模型接入和工作流编排成本。

💬 文章金句

  • 下一阶段的模型竞争，不只是峰值智能，而是可规模化的高效智能。
  • Flash 模型正在进入新的阶段。它不再只是大模型的'更快、更便宜替代品'，而是在 Agent 生产化阶段承担越来越关键的基础模型角色。
  • Step 3.7 Flash 的核心方向：不是只追求单点速度，而是提升真实任务完成效率；不是只服务单轮问答，而是服务多轮、工具化、上下文丰富、多模态的 Agent 工作流。
