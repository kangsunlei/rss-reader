在 Spring I/O 2025 大会上使用 Spring AI 和 Vaadin 的真实世界 AI 模式，作者：Marcus Hellberg / Thomas Vitale

10/2/2025, 1:59:42 PM

📌 一句话摘要

本次演讲展示了如何使用 Spring AI 和 Vaadin 在 Java 应用中实现真实世界的人工智能模式，包括内存管理、安全防护、RAG 以及工具调用等。

📝 详细摘要

本次演讲探讨了将 AI 功能实际集成到 Java 应用程序中，从实验阶段过渡到生产阶段。它涵盖了重要的 AI 模式，例如为大型语言模型 (LLM) 提供短期和长期记忆，通过工具调用，将 LLM 与 API 集成，构建更强大的智能代理，以及实施安全防护以保护 AI 工作流程免受提示词注入和敏感数据泄露。本次演讲还深入探讨了多模态，通过图像交互进行演示，并利用高级检索技术 (RAG) 来增强 LLM 上下文与自定义数据。通过使用 Spring AI 和 Vaadin 的现场演示，演讲者为开发人员提供了即时实用的见解，无论工作负载是在本地还是在云中运行，都适用。主要内容包括系统提示配置、流式响应、结构化输出的情感分析以及模型概念协议(MCP)在工具发布中的应用。

💡 主要观点

  1. Spring AI 简化了将各种 AI 模式集成到 Java 应用程序中以供生产使用。 它为 LLM 提供了抽象，从而能够实现诸如内存、安全防护、RAG 和工具调用等模式，以构建强大的、真实的 AI 驱动应用程序，简化底层模型的复杂性。
  2. 安全防护对于在企业环境中保护 AI 工作流程免受提示词注入和敏感数据泄露至关重要。 实施输入和输出安全防护有助于验证用户查询和模型响应，防止未经授权的数据暴露，并确保人工智能应用的合规性和可靠性。
  3. 检索增强生成 (RAG) 使 LLM 能够利用来自专有数据源的自定义、最新的上下文。 RAG 允许模型通过向量存储（例如 PostgreSQL）利用公司内部数据，克服知识更新的局限性并实现有意义的、上下文相关的业务应用程序。
  4. 工具调用将 LLM 转换为能够与外部 API 交互并修改业务数据的代理。 通过将内部服务公开为工具，开发人员可以使 LLM 能够执行预定义的操作、获取数据甚至修改系统，从而增强自动化和实用性，但务必重视安全性。

💬 文章金句

  • Spring AI 对底层模型进行了良好的抽象，因此您可以使用类似的方式使用不同的模型。
  • 安全防护非常重要，但有时会被忽视。
  • 应用程序需要负责记录与模型的对话历史。
  • RAG 现在非常热门。
  • 任何暴露给 LLM 的内容，都应视作对外服务一样谨慎对待。
