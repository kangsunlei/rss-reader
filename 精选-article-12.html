Spring AI 支持 Anthropic 智能体技能

1/28/2026, 12:00:00 AM

📌 一句话摘要

Spring AI 现已支持 Anthropic 的原生智能体技能，使 Claude 模型能够通过精简的 Java API 生成真实的 Excel、PowerPoint、Word 和 PDF 文件。

📝 详细摘要

本文介绍了 Anthropic 原生技能 API 与 Spring AI 的集成，允许开发者利用 Claude 生成实际文档而非仅仅是文本的能力。文章详细说明了对预置技能（XLSX、PPTX、DOCX、PDF）以及用于组织特定品牌或合规性的自定义技能的支持。文中强调了 Spring AI 如何通过自动管理 Beta 请求头、代码执行工具和文件 ID 提取来简化流程。此外，它还对 Anthropic 特定技能与 Spring AI 通用智能体工具进行了清晰对比，并根据移植性和环境需求提供了选型建议。

💡 主要观点

  1. Spring AI 自动化了 Anthropic 技能 API 所需的复杂手动步骤。 它处理代码执行工具的注入，管理多个 Beta 请求头，并为技能配置提供类型安全的枚举和构建时验证。
  2. Anthropic 技能支持原生生成 Excel 和 PDF 等二进制文件。 与标准的 LLM 输出不同，这些技能允许 Claude 生成带有公式的功能性电子表格和格式化文档，并可通过 Files API 下载。
  3. 自定义技能支持可重用的、工作区范围的文档模板和品牌定制。 开发者可以将 SKILL.md 文件上传至 Anthropic，以在所有生成的文档中强制执行公司特定的页眉、页脚或法律免责声明。
  4. 供应商特定技能与通用智能体工具之间存在明确区别。 Anthropic 技能最适合在安全云环境中进行专门的文档生成，而 Spring AI 的通用工具则提供了跨不同 LLM 供应商的可移植性。

💬 文章金句

  • 启用技能后，Claude 会生成真实的 Excel 表格、PowerPoint 演示文稿、Word 文档和 PDF，你可以直接下载并使用。
  • Spring AI 自动处理所有这些操作……包括三个 Beta 请求头：skills-2025-10-02、code-execution-2025-08-25、files-api-2025-04-14。
  • 自定义技能允许你将自己的指令封装成可重用的模块，Claude 会在文档生成过程中应用这些指令。
  • 当你需要生成实际的文档文件时，请使用 Anthropic 技能；当你需要可移植的、与 LLM 无关的智能体能力时，请使用通用智能体技能。
