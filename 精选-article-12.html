对谈 Macaron 创始人陈锴杰：RL + Memory 让 Agent 成为用户专属的“哆啦 A 梦”｜Best Minds

9/11/2025, 12:02:00 PM

📌 一句话摘要

Macaron 创始人陈锴杰深入探讨了通过强化学习和记忆机制，构建能理解用户、定制工具并持续进化的个性化 AI Agent 的理念与实践。

📝 详细摘要

文章通过对 Macaron 创始人陈锴杰的访谈，详细阐述了其产品 Macaron 如何利用强化学习（RL）和深度记忆机制，致力于打造用户专属的“哆啦 A 梦”式个人 AI Agent。陈锴杰指出，AI 记忆应被视为一种智能能力进行训练，而非单纯的信息存储，并通过 RL 优化 Agent 在特定场景下的表现，使其记忆方式更贴近人类。Macaron 创新性地采用多 Agent 系统，将负责情感交互和记忆管理的“朋友”Agent 与专注于工具开发的“Coding Agent”分开训练，以期平衡情商与智商。文章还介绍了 Macaron 的“Sub Agent 进化论”社区模式，鼓励用户分享和演化定制化的生活方式 Agent。在技术实现上，Macaron 在 671B 级别模型上进行 RL 训练，并提出了“all-sync RL”技术，将训练周期从“周”缩短至“天”，强调 RL 在 AI 智能提升下半场的核心作用。访谈还深入探讨了 Macaron 上线后用户对其产品速度慢、有“妈感”等反馈的应对策略，以及 RL 基础设施标准化、记忆系统设计和个性化小应用的市场潜力等关键挑战和机遇。

💡 主要观点

  1. 通过强化学习将 AI 记忆能力视为智能进行训练，而非简单存储。 Macaron 团队在 671B 模型级别上进行记忆强化学习，目标是让 Agent 在具体场景中更好地回答问题，使其记忆方式更贴近人类的认知和需求。
  2. 采用多 Agent 系统平衡 AI 的情商与智商，提升用户体验。 将负责用户交互和记忆管理的“朋友”Agent 与专注于工具开发的“Coding Agent”分开训练，确保两者都能高效且有温度地服务用户，解决单一 Agent 的局限性。
  3. 提出“Sub Agent 进化论”，构建个性化生活方式分享平台。 用户可根据自身生活方式生成定制小工具（Sub Agent），并在社区分享和演化，形成独特的网络效应和强化学习反馈循环，满足高度个性化的需求。
  4. 强化学习是 AI 智能提升下半场的核心，并创新“all-sync RL”加速训练。 在大模型上应用 RL 能将智能推向上限，Macaron 通过全同步 RL 将训练周期缩短至“天”，兼顾智能提升和产品迭代速度，实现快速迭代和优化。

💬 文章金句

  • Memory 不是一个目的，而是一个方法。记住一个东西的目的不是'记住'本身，毕竟这不是考试，目的是更好地帮助用户。
  • Macaron 会自己决定总结什么、压缩什么，哪些信息多放一点，哪些少放一点。这其实是机器的 Memory 和人的 Memory 在拟合、对齐。
  • Macaron 最好的类比就是哆啦 A 梦：哆啦 A 梦首先是大雄的朋友。只有当大雄遇到问题时，哆啦 A 梦才会从口袋里掏出一个道具，尝试帮他解决。
  • 和用户对话、管理记忆和偏好的模型，和帮用户做小工具的 Coding Agent，其实是两个不同的 Agent。它们之间有一个互通的协议，但职能是分开的。
  • RL 是智能提升下半场的核心。RL 对场景的要求很强，很难有一个'超通用'的 RL 场景，让一个超通用 Agent 在所有能力上同时提升。
