Agora：以 Git 为共享状态的多智能体协作科研系统

9/17/2026, 11:36:52 PM

📌 一句话摘要

NVIDIA 提出的 Agora 系统通过将科研过程构建在 Git 的有向无环图（DAG）之上，解决了多 Agent 协作中的状态丢失与重复搜索问题，并在权重迁移任务中实现了显著的指标提升。

📝 详细摘要

该推文深度解读了 NVIDIA 关于 Agora 的论文。针对单智能体自主科研可行但多智能体协作时缺乏共享状态导致重复搜索的问题，Agora 将 Git 视为唯一的制度层和状态源，每条主张均为一个可重跑的 commit。系统通过贡献图溯源、基于下游证据的质量衡量以及多样性感知的注意力分配机制，引导 Agent 在探索与利用之间取得平衡。在为期 12 天的权重迁移实验中，13 个 Agent 将目标模型的指标从 3.3923 提升至 1.899 bpb，并发现供体行为（低秩转移算子）可跨架构迁移而参数不行。

💡 主要观点

  1. Git 作为科研状态的制度层 将研究过程建模为 Git 中的 DAG，确保每条结论可追溯、可复现，避免了多 Agent 会话隔离导致的重复工作。
  2. 基于证据而非投票的质量评估 通过计算一个贡献被后续账号构建的加权子代数来衡量价值，且强制验证必须针对他人工作，防止自引操纵。
  3. 三槽位注意力分配机制 将候选节点分为 exploit（精修领先者）、explore known（扩展薄聚类）和 explore novel（触碰新节点），防止社区坍缩为单一文化。

💬 文章金句

  • 把整个研究过程变成一个存在 Git 里的、只追加的有向无环图（DAG），每一条主张都是一个任何人可以 checkout 并重跑的 commit。
