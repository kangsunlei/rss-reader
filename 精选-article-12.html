基于 LangGraph 的开放式深度研究

7/16/2025, 5:31:22 PM

📌 一句话摘要

本文介绍了构建于 LangGraph 之上的 LangChain 开源深度研究代理，详细阐述了其灵活的多阶段架构以及缓解 LLM 常见局限的关键经验。

📝 详细摘要

本文介绍了 LangChain 的“开放深度研究”代理，这是一个构建于 LangGraph 之上的灵活且可配置的开源解决方案，旨在解决深度研究任务的复杂性和开放性问题。文章强调，有效的研究策略无法轻易预先确定，因此需要一种自适应的方法。该系统分为三个核心阶段：范围界定、研究和撰写。“范围界定”阶段旨在明确用户需求，产出简洁的研究概要；“研究”阶段则采用多智能体架构，由监督代理将子任务分配给并行的子代理。这些子代理负责收集信息，并且至关重要的是，在向监督代理报告之前，负责修剪和清理其研究结果，以避免令牌超载。这种迭代过程允许监督代理动态调整研究深度。最后的“撰写”阶段将所有收集到的信息综合成一份综合报告。作者分享了关键的经验教训：多智能体系统最适合于固有并行化的任务（如研究），但不适合于顺序任务（如报告撰写，其中会出现协调问题）。它能有效隔离不同子主题的上下文，避免长文本处理中可能出现的失败。文章还强调了上下文工程在管理令牌使用方面的关键作用，这在研究代理中非常重要，从而带来实际的好处，如降低成本和避免 API 速率限制。

💡 主要观点

  1. LangChain 的开放深度研究代理利用灵活的三阶段 LangGraph 架构进行自适应研究。 该系统通过范围界定、研究和撰写三个阶段，能够根据不同的研究需求（如比较、深度验证等）动态调整策略，从而优化研究过程。
  2. 多智能体设计通过隔离上下文和优化令牌效率来提高研究质量。 通过将子代理专门用于特定主题并预处理其研究结果，该架构可以防止上下文冲突和令牌超载，这对于深入的多主题调查和提高 LLM 性能至关重要。
  3. 战略性地应用多智能体系统是关键；最适合并行化任务（如研究），而不是顺序写作。 经验教训表明，多智能体擅长并行数据收集，但会导致报告生成中缺乏一致性的输出。采用单次生成的方式完成报告撰写可确保连贯性，从而优化整体工作流程。

💬 文章金句

  • 开放深度研究的一个关键设计原则是根据请求灵活地探索不同的研究策略。
  • 我们通过额外的 LLM 调用清理子代理的研究结果，为监督代理提供干净、处理后的信息。
  • 多智能体很难协调，如果在并行编写报告的各个部分时，性能可能会很差。我们将多智能体限制在研究中，并采用单次生成的方式完成报告撰写。
  • 研究期间子主题的上下文隔离可以避免各种长上下文失败模式。
  • 上下文工程具有许多实际好处。它可以节省令牌，有助于避免上下文窗口限制，并有助于保持在模型速率限制之下。
