📝 详细摘要

这条推文（及其引用的详细内容）总结了 Anthropic 技术团队成员 Cal Rueb 在 2025 年 5 月“Code w/ Claude”大会上关于 Claude Code 最佳实践的演讲。演讲深入探讨了 Claude Code 作为 AI 编程助理的强大功能和高效使用方法。Cal Rueb 分享了自己从重度用户到核心贡献者的亲身经历，并揭示了 Claude Code “行之有效的简单方案”的设计哲学。核心内容包括：理解 Claude Code 的心智模型，其通过“智能体式搜索”探索代码库的内部工作原理，以及从项目探索、结对编程、从零构建应用到添加单元测试、撰写提交信息、大规模代码迁移等核心应用场景。此外，演讲还提供了大量实用最佳实践，如利用 `claude.md` 文件提供上下文、高效管理权限、集成 CLI 工具、通过 `/compact` 管理上下文窗口、同时运行多个 Claude 实例、无头模式自动化集成 CI/CD 等。最后，Cal Rueb 演示了模型切换、工具调用间的“深度思考”以及与 VS Code 和 JetBrains 的深度集成等最新功能。这是一份全面而深入的指南，对于希望提升 AI 编程效率的开发者极具价值。
