阿里巴巴发布全新推理模型 Qwen3-Max-Thinking，支持自适应工具调用

1/26/2026, 3:13:37 PM

📌 一句话摘要

阿里巴巴 Qwen 团队推出最强推理模型 Qwen3-Max-Thinking，具备自适应工具使用、测试时扩展（Test-time scaling）等特性，并在各项基准测试中表现卓越。

📝 详细摘要

Qwen 团队官方宣布推出其迄今为止最先进的推理模型 Qwen3-Max-Thinking。该模型基于大规模数据与先进的强化学习（RL）训练而成。核心创新点包括：1) 自适应工具使用：无需手动干预，即可智能调用搜索、记忆及 Code Interpreter；2) 测试时扩展：通过多轮自我反思机制，在推理性能上超越了 Gemini 3 Pro；3) 复杂任务表现优异：在数学竞赛 HMMT Feb 取得 98.0 分，在智能体搜索基准 HLE 取得 49.8 分。用户可通过推文链接直接体验模型、调用 API 或阅读技术博客。
