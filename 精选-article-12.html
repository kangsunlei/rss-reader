黄仁勋的“Agent 工厂”里，装了什么新故事？

6/1/2026, 8:01:00 AM

📌 一句话摘要

英伟达在 COMPUTEX 2026 上发布 Vera Rubin 平台、DSX 工厂操作系统、Cosmos 3 世界模型等全栈产品，围绕 Agent 生态重构从芯片到机器人的技术体系。

📝 详细摘要

本文详细报道了英伟达 CEO 黄仁勋在 COMPUTEX 2026 GTC Taipei 上的主题演讲。与三个月前强调芯片全家桶不同，本次演讲聚焦于 Agent 时代的基础设施建设。核心发布包括：已量产的 Vera Rubin 平台，专为 Agent 工作负载设计，效率是上一代的 10 倍；AI 工厂操作系统 DSX，涵盖设计、仿真、建设到运营的全流程；专为 Agent 设计的 Vera CPU；面向 Windows 生态的 DGX Station 工作站；5500 亿参数的 Nemotron 3 Ultra 模型；以及重构物理 AI 的 Cosmos 3 世界模型。此外，英伟达还与宇树联合发布人形机器人 H2 Plus，并开源物理 AI 技能工具集。文章指出，英伟达正围绕 Agent 拼凑完整蓝图，从芯片、数据中心、模型、软件到机器人平台，每一层都试图嵌入英伟达的技术。

💡 主要观点

  1. 英伟达战略重心从芯片转向 Agent 生态，发布全栈基础设施。 Vera Rubin 平台专为 Agent 工作负载优化，效率是上一代 10 倍；DSX 操作系统管理 AI 工厂；Nemotron 3 Ultra 模型和 Cosmos 3 世界模型分别服务数字和物理 Agent。
  2. Vera Rubin 平台已量产，引入 CPO 网络和机密计算。 平台集成 Spectrum-X Ethernet Photonics 网络系统，首次大规模应用共封装光学技术；同时将机密计算扩展到整个平台，保障企业数据安全。
  3. 英伟达推出专为 Agent 设计的 Vera CPU，性能达同期 x86 的 1.8 倍。 Vera 采用自研 Olympus 核心架构，通过第二代 NVLink-C2C 与 Rubin GPU 连接，互联带宽达 1.8TB/s，降低 CPU-GPU 数据传递开销。
  4. Cosmos 3 世界模型实现架构重构，统一视觉推理、世界生成和动作预测。 采用混合 Transformer 架构，原生支持多模态输入输出，有望将物理 AI 训练和评估周期从数月压缩到数天。
  5. 英伟达与宇树联合发布人形机器人 H2 Plus，降低 Physical AI 开发门槛。 H2 Plus 是全球首款基于 Isaac GR00T 的开放式人形机器人参考设计，旨在解决硬件集成、数据采集、训练等环节的碎片化问题。

💬 文章金句

  • Agent AI 和实用型人工智能时代已经到来。现在 token 是利润单位，AI 是 GDP 生成器。
  • 智能体把企业数据变成了一个实时、活生生的系统，而这个系统必须在数据移动之处、上下文存储之处、智能体行动之处都得到保护。
  • 英伟达不只是卖芯片，而是要给基础设施建设者一套完整的 AI 工厂蓝图。
  • Vera 是为 AI 时代设计的 CPU，为智能体打造。
  • 当 Agent 成为 AI 基础设施，每一层都能有英伟达。
