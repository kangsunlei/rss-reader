DeepSeek-V3.1 发布，迈向 Agent 时代的第一步

8/21/2025, 12:00:00 AM

📌 一句话摘要

DeepSeek 发布 V3.1 模型，引入混合推理架构，显著提升 Agent 能力和思考效率，并支持 API 和模型开源。

📝 详细摘要

DeepSeek 正式发布 V3.1 模型，核心亮点包括创新的混合推理架构，使其能同时支持“思考模式”与“非思考模式”，并能自由切换。新模型通过 Post-Training 优化，大幅增强了在编程智能体（SWE、Terminal-Bench）和搜索智能体（browsecomp、HLE）任务中的表现。在思考效率方面，V3.1-Think 模式在保持性能的同时，能将输出 token 数减少 20%-50%，显著提升了响应速度，并带来潜在的成本效益和资源优化。API 服务已同步升级，上下文扩展至 128K，支持严格模式的 Function Calling 和 Anthropic API 格式。同时，DeepSeek-V3.1 的 Base 模型和后训练模型已在 Hugging Face 和魔搭开源。文章还提到了 API 价格将于 2025 年 9 月 6 日进行调整，这可能会对用户的长期使用成本和策略产生影响。

💡 主要观点

  1. DeepSeek-V3.1 引入混合推理架构，支持思考与非思考模式切换 该架构允许模型根据任务需求，在快速响应的非思考模式和深度推理的思考模式之间灵活切换，提升了模型的使用效率和适应性。
  2. Agent 能力显著增强，在编程和搜索任务中表现优异 通过 Post-Training 优化，V3.1 在代码修复、命令行任务和复杂多步搜索等 Agent 应用中取得了显著进步，预示着其在自动化任务中的潜力。
  3. 思考效率大幅提升，减少 token 消耗同时保持性能 V3.1-Think 模式在输出 token 量减少 20%-50%的情况下，仍能保持与 R1-0528 相当的性能，提高了推理速度和成本效益。
  4. API 服务升级并支持多平台开源，提升开发者友好度 API 上下文扩展至 128K，支持严格 Function Calling 和 Anthropic API 格式，同时 Base 和后训练模型均已开源，极大方便了开发者接入和使用。
  5. DeepSeek API 价格将于 2025 年 9 月 6 日调整，同时服务资源已扩容 API 价格调整（取消夜间优惠，执行新价格表）将影响用户的长期使用成本和计费策略，但服务资源的扩容确保了对用户调用需求的更好支持，以满足日益增长的调用需求。

💬 文章金句

  • 混合推理架构：一个模型同时支持思考模式与非思考模式
  • 更强的 Agent 能力：通过 Post-Training 优化，新模型在工具使用与智能体任务中的表现有较大提升。
  • DeepSeek API 也已同步升级，deepseek-chat 对应非思考模式，deepseek-reasoner 对应思考模式，且上下文均已扩展为 128K。
  • V3.1 的 Base 模型在 V3 的基础上重新做了外扩训练，一共增加训练了 840B tokens。
  • V3.1-Think 在输出 token 数减少 20%-50% 的情况下，各项任务的平均表现与 R1-0528 持平。
