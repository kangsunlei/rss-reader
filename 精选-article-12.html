宣布 ADK for Java 1.0.0 发布：构建 Java AI 智能体的未来

3/30/2026, 12:00:00 AM

📌 一句话摘要

Google 宣布发布 Agent Development Kit (ADK) for Java 1.0.0 版本，为构建具备接地（grounding）工具、插件架构和人机回环（human-in-the-loop）工作流的 AI 智能体提供了强大的框架。

📝 详细摘要

Google 正式发布了 Agent Development Kit (ADK) for Java 1.0.0 版本，将其智能体生态系统从 Python 扩展到了 Java。这一里程碑式的版本为 Java 开发者引入了企业级功能，包括 GoogleMapsTool 和 UrlContextTool 等新的接地工具。它具备用于全局执行控制的集中式插件架构、通过事件压缩（event compaction）来管理 Token 限制的高级上下文工程，以及通过工具确认（tool confirmations）实现的原生人机回环（HITL）支持。此外，该框架还支持用于跨框架协作的 Agent2Agent (A2A) 协议，并提供了与 Vertex AI 和 Firestore 集成的会话及记忆管理标准化服务。

💡 主要观点

  1. 引入强大的接地和执行工具。 GoogleMapsTool 和 UrlContextTool 等新工具允许智能体访问实时位置数据和 Web 内容，而代码执行器则支持在容器或 Vertex AI 中进行安全的代码执行。
  2. 通过 App 和插件架构实现集中式执行控制。 新的 App 容器管理着 LoggingPlugin 和 GlobalInstructionPlugin 等全局插件，允许开发者在整个层级结构中的所有智能体上应用一致的规则和监控。
  3. 通过事件压缩实现高级上下文工程。 为了防止上下文窗口溢出并降低成本，该框架支持基于可配置 Token 阈值的滑动窗口和旧对话事件摘要。
  4. 原生人机回环 (HITL) 工作流。 ToolConfirmation 工作流允许智能体暂停执行并请求人工审批敏感操作，从而确保智能体流程的安全性和合规性。
  5. 支持 Agent2Agent (A2A) 的跨框架协作。 对 A2A 协议的原生支持使 ADK 智能体能够与远程智能体进行通信和协作，无论后者是用何种语言或框架构建的。

💬 文章金句

  • 智能体的核心在于感知并与外部世界交互，超越了驱动它们的底层大语言模型 (LLM) 的固有知识范畴。
  • App 类是智能体应用新的顶层容器。它锚定根智能体，持有全局配置，并管理整个应用的插件。
  • 事件压缩允许你通过仅保留最近事件的滑动窗口和/或总结旧事件，来管理智能体的事件流（历史记录）大小。
  • ADK 中的人机回环 (HITL) 工作流是围绕 ToolConfirmation（工具确认）这一概念构建的。
