E255｜模型越来越强，为什么用户没感觉？再访阿里国际站总裁张阔

10/9/2026, 12:00:00 AM

📌 一句话摘要

阿里国际站总裁张阔以 Accio Work 的跨境电商实践解释为什么模型榜单进步不等于用户完成更多商业任务，并讨论 Agent 的真实评测、长期经营与人的判断边界。

📝 详细摘要

硅谷 101 再访阿里国际站总裁张阔，追问模型能力提升为何没有等比例转化为商家体验。他认为编程任务数据充分、结果容易验证，而跨境电商涉及供应商沟通、物流、报价、平台规则和长期经营目标，反馈周期更长。Accio Work 的方向从采购搜索扩展到产品设计、找工厂、样品、运输和多平台经营。他提出 Agent = Model × Harness × Context，强调模型、工程框架与企业数据缺一不可，并介绍团队从真实业务中构建 107 个电商任务的评测集；在无人干预条件下，最前沿模型通过率约为 61%。访谈还讨论了报价中的钓鱼邮件、订船和纠纷等可验证任务，以及低成本模型路由。张阔承认 AI 可承担大量调研和执行，但产品品味、市场判断、预算分配及最后的商业责任仍应由人承担。内容是一手产品与经营观察，具体成效和成本数字主要来自受访企业自述。

💡 主要观点

  1. 商业 Agent 比编程 Agent 更难评估，因为数据分散且结果反馈慢。 代码易于编译和验证；采购、销售与经营涉及多平台、多主体和数周甚至更长的反馈周期，单次操作正确不等于业务成功。
  2. 模型、工程框架和企业上下文必须共同优化。 张阔用乘法公式描述 Agent：模型能力再强，缺少工具授权、记忆、供应链数据和商家经营上下文，也难交付结果。
  3. 真实业务任务评测比通用榜单更能反映商家体验。 团队以 107 个任务衡量无人干预完成情况，覆盖报价、钓鱼邮件识别、订船和纠纷；模型版本也需要持续回归评测。
  4. AI 可以加速执行，但经营目标和风险取舍仍由人决定。 Agent 能整合多平台数据、辅助选厂与上架，老板仍要判断产品是否值得做、广告和库存如何分配以及最终利润目标。

  • 有大量的流水进来 但是不代表你最后的经营是有利润
