微软 CTO 下场整活，用“Windows 画图”畅玩 DOOM

8/6/2026, 3:20:00 PM

📌 一句话摘要

微软 Azure CTO 马克·鲁西诺维奇利用 Windows 画图板实现 Doom，突破 35 FPS，展示了把画图当作像素显示器的创意黑客技术。

📝 详细摘要

文章介绍了微软 Azure 首席技术官马克·鲁西诺维奇将《毁灭战士》移植到 Windows 自带的画图软件上运行的全过程。作者回顾了两年前的尝试及其瓶颈，阐述了本次实现的核心思路：后台引擎负责所有计算，生成的帧图像通过剪贴板实时粘贴到画图中显示，并通过底层拦截键盘信号实现玩家控制。为解决画图刷新速度与后台计算速度不匹配的问题，马克在系统底层加入了“传话机制”。该项目命名为 DoomPaint，已开源到 GitHub，具备撤销回放、直接保存截图等奇特功能。文章强调这是一场极客的浪漫实验，虽与 Azure 云服务关联不大，却体现了技术爱好者的创新精神。

💡 主要观点

  1. 把 Windows 画图当作像素显示器，实现 Doom 的实时渲染。 后台引擎完成所有物理、AI 与画面生成，将每帧图像复制到剪贴板并粘贴进画图，画图仅负责显示，突破了以往数分钟一帧的瓶颈。
  2. 通过“传话机制”同步画图与后台渲染速度。 如果画图未完成上一帧粘贴就被新帧覆盖，画面会崩掉。系统底层加入报告机制，画图确认粘贴完成后才发送下一帧，保证流畅度达 35 FPS。
  3. 拦截键盘信号实现玩家控制，提供撤销与截图等独特功能。 键盘输入在到达画图前被拦截并直接“偷渡”到后台引擎，玩家可以正常操作角色；Ctrl+Z 可倒带复活，文件保存即为高质量截图。

💬 文章金句

  • 画图渲染了游戏，但它不计算游戏。
  • 每当玩家按下 WASD 或鼠标控制角色时，按键信号就会在传达 Windows 画图之前，抢先一步被拦截并直接"偷渡"到后台的游戏引擎。
  • 玩家如果不小心被怪物打死了，不需要找存档，直接狂按 Ctrl + Z 撤销，画面就会像倒带一样，一帧一帧地退回到你几秒钟前还没死的健康状态。
