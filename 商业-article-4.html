📌 一句话摘要

该文章详细定义了大型语言模型（如 ChatGPT）作为代码 Agent 在执行 Git 操作、文件修改和 PR 创建时应遵循的行为规范和指令，并强调了对`AGENTS.md`文件和引用格式的遵守。

📝 详细摘要

该文章提供了一份针对大型语言模型（如 ChatGPT）的系统级指令，旨在规范其作为代码代理（Agent）在开发任务中的行为。核心内容包括：通用指令，要求 Agent 在完成任务时等待所有终端命令完成，且任务涉及 Git 仓库。Git 操作规范，明确 Agent 在修改文件时不得创建新分支，必须使用 Git 提交更改，处理 pre-commit 失败，确保工作区干净，且仅提交代码会被评估，不得修改现有提交。`http://AGENTS.md`规范，详细定义了 Agent 如何理解和遵守`AGENTS.md`文件中的指令，包括其作用域、优先级（更深层嵌套的优先，直接提示优先于`AGENTS.md`）、内容类型（编码约定、代码组织、运行/测试说明、PR 消息说明），并强调必须运行其中包含的任何编程检查。引用指令，规定了 Agent 在最终响应中引用文件路径和终端输出的格式，包括文件路径引用和终端输出引用，并强调了引用的准确性、相关性、优先级和使用场景。PR 创建指令，明确 Agent 在提交更改后必须调用`make_pr`工具，未提交则不得调用。最终消息指令、截图指令、环境指南、最终答案指南、PR 指南、代码风格指南和互联网访问等也提供了详细的规范。这份系统提示为 LLM Agent 提供了一个清晰、详细且可操作的行为框架，旨在提高其在代码开发任务中的效率、准确性和规范性。

💡 主要观点

  1. AI Agent 行为规范的标准化是确保其在代码开发中一致性和可靠性的关键 该系统提示为 LLM Agent 提供了详细、标准化的行为规范，确保 Agent 在 Git 操作、文件修改和 PR 创建时保持一致性、准确性和可追溯性，提高自动化开发流程的可靠性。
  2. 引入`AGENTS.md`文件作为项目特定上下文指令源，增强 Agent 适应性 通过`AGENTS.md`文件，Agent 能获取项目特定的指令（如编码约定、测试方法），提升了其在复杂开发环境中的适应性和执行效率，同时允许人类通过文件控制 Agent 行为。
  3. 强制执行详细的引用和输出格式，提高 Agent 输出的可验证性和透明度 规定了 Agent 在最终响应中必须使用标准化的文件和终端输出引用格式，有助于提高 Agent 输出的可验证性和透明度，方便用户快速定位信息来源，增强了 Agent 生成内容的信任度。

💬 文章金句

  • You are ChatGPT， a large language model trained by OpenAI.
  • If pre-commit fails， fix issues and retry.
  • For every file you touch in the final patch， you must obey instructions in any http://AGENTS.md file whose scope includes that file.
  • Direct system/developer/user instructions (as part of a prompt) take precedence over http://AGENTS.md instructions.
  • If you browsed files or used terminal commands， you must add citations to the final response (not the body of the PR message) where relevant.
