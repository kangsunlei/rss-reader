速递｜GitHub Copilot 计划涨价，已成为 Github 收入最大业务

4/6/2025, 4:55:26 AM

📌 一句话摘要

GitHub Copilot 针对高级 AI 模型调整定价，实施高级请求限制和收费。

📝 详细摘要

GitHub Copilot 调整了针对高级 AI 模型使用的新定价策略，对 Copilot Pro、Business 和 Enterprise 用户，在使用 Anthropic 的 3.7 Sonnet 等高级模型时，设置了每月高级请求的限制，超出部分需要额外付费或升级到 Copilot Pro+ 计划。此举反映了 AI 模型推理所需的更高计算成本，同时也影响了依赖 Copilot 进行开发的用户的成本和使用习惯。Copilot 已成为 GitHub 收入的重要增长点，占据了 GitHub 收入增长的 40% 以上。

💡 主要观点

  1. GitHub Copilot 通过实施高级请求限制和收费，调整了针对高级 AI 模型的定价策略 用户在使用 Agent 编程和多文件编辑等任务时，切换到基础模型以外的 AI 模型会受到每月高级请求的限制，影响开发者使用习惯和成本。
  2. Copilot 已成为 GitHub 收入增长的主要驱动力 Copilot 在 2024 年占据了 GitHub 收入增长的 40% 以上，成为一项重要的业务。
  3. 定价调整反映了 AI 模型更高的计算成本 像 3.7 Sonnet 这样的推理模型需要更多时间来核实其答案，增加了运行所需的计算量。

💬 文章金句

  • GitHub 宣布推出 '高级请求'，这是一种新系统，当用户切换到基础模型以外的 AI 模型进行 'Agent' 编程和多文件编辑等任务时，将施加速率限制。
  • Copilot Pro+ 的起价为每月 39 美元，提供 1500 个高级请求，并且 '可以访问最佳模型'，GitHub 表示，包括 OpenAI 的 GPT-4.5。
  • 微软首席执行官 萨提亚 · 纳德拉 去年八月表示，Copilot 在 2024 年占据了 GitHub 收入增长的 40% 以上，并且已经成为一个比七年前科技巨头收购时的 GitHub 更大的业务。
