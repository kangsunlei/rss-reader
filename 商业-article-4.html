EP120 从 Prompt 到 Agent Skills，论 Anthropic 的野心与大模型应用的终极抽象

1/13/2026, 4:56:49 PM

📌 一句话摘要

本期播客深度剖析 Anthropic 的 Agent Skills 及其与 MCP、Function Calling 的关系，探讨其在 AI 领域的工程化价值、低代码开发潜力以及对行业标准和未来生态的影响。

📝 详细摘要

本期《硬地骇客》深入探讨了 Anthropic 推出的 Agent Skills 概念，将其界定为一次显著的工程进化。节目首先阐释了 Agent Skills、MCP 和 Function Calling 之间的层级关系：Function Calling 负责底层 API 调用，MCP 作为标准协议进行 API 发现和管理，而 Agent Skills 则在更高层级，以文档形式组织业务逻辑和知识，指导模型完成复杂任务。嘉宾们强调，Skills 通过增加抽象层、降低使用门槛，将领域知识模块化，有效解决了传统 Agent 在维护、复用和上下文长度方面的挑战，并赋能低代码甚至无代码开发。结合 Podwise 的实践案例，讨论了 Skills 如何应用于自动化日常工作、优化 Prompt 调试和进行运维流程检查。节目还探讨了 Skills 在稳定性、准确率及智能上限方面的特性，提出人机协作的重要性。最后，展望了 Skills 可能成为大模型厂商吸引社区贡献、加速行业工程化进程的“阳谋”，并类比 Linux 生态，暗示 Skills 有望推动 AI 应用的模块化和个性化发展。

💡 主要观点

  1. Agent Skills 是工程进化的体现，而非单纯的概念迁移。 Skills 通过引入抽象层，将复杂的模型使用逻辑简化为文档驱动的用户界面，降低了非开发者的使用门槛，并把领域知识模块化，提升了 Agent 的复用性和可维护性。
  2. Agent Skills、MCP 和 Function Calling 构成多层级体系。 Function Calling 提供模型调用外部 API 的能力，MCP 是 API 发现和调用的标准协议，Skills 在最高层组织业务逻辑，可能包含 MCP，共同实现复杂任务的自动化。
  3. Skills 推动了 AI 时代的低代码开发和自动化实践。 通过将常用操作和流程封装为可复用的技能，Skills 使非技术人员也能便捷地构建 AI 应用，实现日常工作和运维流程的自动化，显著提升效率。
  4. Skills 在稳定性和智能上限方面与传统工作流存在差异。 工作流注重稳定性与可控性，而 Skills 则赋予模型更多的智能决策空间，以无规则运行方式突破智能上限，但可能牺牲部分确定性与调用成功率。
  5. Agent Skills 可能成为大模型厂商构建生态和加速行业工程化的策略。 Skills 通过开源生态吸引社区贡献领域知识，大模型公司可能将其整合入核心产品或通过收购，从而加速 AI 应用的标准化和专业化进程。
