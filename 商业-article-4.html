5/22/2026, 7:40:00 AM

📌 一句话摘要

本文深度编译了与 Claude Code 负责人 Boris Cherny 的访谈，揭示了该产品指数级增长背后的技术范式转移、生产力实证、组织变革启示以及对软件行业护城河重塑的深刻洞察。

📝 详细摘要

本文是对 Anthropic 旗下 Claude Code 负责人 Boris Cherny 深度访谈的编译与整理。文章核心围绕 Claude Code 从传统聊天机器人向具备工具使用能力的主动型智能体（Agent）的范式转移展开。Cherny 透露，Anthropic 内部数据显示，引入 Claude Code 后工程师代码产出量增长约 250%，且质量保持稳定。他驳斥了 AI 使用量由 Token Maxing 驱动的观点，强调真正的生产力提升源于围绕 AI 重构业务流程，而非简单叠加。文章还探讨了 AI 如何降低软件转换成本，使得网络效应和规模经济成为未来更重要的商业护城河。最后，访谈触及了 AI 自我改进、世界模型与 AGI 路径等前沿话题，Cherny 认为模型已实现自我编写，未来将走向自我强化的循环，但最终仍需人类提出正确的问题。

💡 主要观点

  1. Claude Code 的核心突破是从对话预测到主动使用工具的智能体范式转移。 不同于传统聊天机器人，Claude Code 能连接浏览器、操作本地文件、登录云平台，从被动响应变为主动执行，这是其能力边界和增长的根本原因。
  2. Anthropic 内部数据显示，Claude Code 使工程师代码产出量增长约 250%，且质量稳定。 这一阶跃式提升远超传统每年 1-3% 的生产力改进，证明了 AI 智能体在复杂系统构建中的成熟度和巨大价值。
  3. 企业需围绕 AI 重构业务流程，而非将其作为边缘工具，才能释放其全部潜力。 引用 90 年代计算机生产力悖论，指出若企业仅将 AI 当作高级搜索引擎，而不在核心业务流中为 AI 代理预留位置，则无法获得实质性收益。
  4. AI 将显著降低软件转换成本，网络效应和规模经济将成为更重要的商业护城河。 由于 AI 可自动执行迁移任务，依赖客户绑定的软件公司将面临危机；而拥有庞大用户连接和基础设施规模优势的公司，其竞争优势将进一步放大。
  5. 未来人类工作的核心价值在于提出正确的问题，而非执行具体任务。 随着 AI 代理链条不断深化，个人杠杆效应爆炸式增长，最终仍需要人类来掌控方向，提出正确问题所蕴含的影响力将成为核心价值。

💬 文章金句

  • 在使用聊天机器人时，你是在进行来回的对话，而智能体——Claude Code 就是一个智能体——它可以使用你的工具。
  • 自我们引入 Claude Code 以来，Anthropic 每位工程师编写的代码量增长了约 250%。同时，代码质量、可靠性都保持在稳定水平。
  • 要想从计算机中获益，必须围绕计算机重构整个业务流程。如果你依然保留着实体文件柜，计算机只是边缘工具，你便无法获益。
  • 如果你想从供应商 A 切换到供应商 B，你只需要让智能体去执行迁移即可。
  • 提出正确的问题所蕴含的影响力，将成为未来人类工作的核心价值。
