泡泡玛特王宁：快乐会是一个更大的市场，「无用」的东西才是永恒的

6/15/2025, 7:12:00 AM

📌 一句话摘要

泡泡玛特王宁分享以 IP 为核心构建商业模式的思考，强调“无用之用”、尊重经营和未来“快乐”大市场。

📝 详细摘要

文章是泡泡玛特创始人王宁的一次深度分享精选，核心阐述了其独特的商业哲学和发展战略。王宁认为，艺术品、潮玩等看似“无用”的商品具有永恒价值，能满足人们的“存在感”而非仅是“满足感”。他面对市场对潮玩的不理解，认为行业门槛远超想象，核心在于发现和商业化稀缺的艺术家资源，构建类似“唱片公司”的模式。同时，他强调成功经营需要“尊重时间，尊重经营”，再好的概念最终要回归到供应链、零售细节等枯燥但核心的日常管理与迭代。公司战略正从聚焦“潮流”和“时尚”向满足更大的“快乐”市场转型，业务模式也从“乐高模式”走向“迪士尼模式”。未来的核心战略是全球化和围绕 IP 进行集团化拓展（游戏、乐园等）。文章对 IP 的生命力提出独到见解，认为在时间碎片化的当下，持续健康的投入比传统讲故事更重要。整体提供了一个成功消费品牌创始人对行业、商业模式和未来趋势的深刻洞察。

💡 主要观点

  1. “无用”商品具有永恒价值，满足存在感需求 艺术品、潮玩等没有实用功能，但能满足人们表达自我、彰显品味等深层次需求，其价值随时间沉淀而非贬值。
  2. 泡泡玛特是 IP 核心的产业公司，类似“唱片公司” 公司核心能力在于挖掘稀缺艺术家资源，并为其作品进行规模化、商业化开发，将艺术转化为受大众喜爱的 IP 商品，这构成了行业的软性门槛。
  3. 成功经营需“尊重时间，尊重经营” 伟大的事业需要长期积累，再好的概念最终都要回归到供应链、零售细节等枯燥但核心的日常管理与迭代，这是行业的硬性门槛。
  4. 公司战略从“潮流”转向“快乐”大市场 目标用户需求从追求优越感的“潮流”，扩展到满足大众情感陪伴和“快乐”体验，业务模式从“乐高”转向“迪士尼”生态，以覆盖更大的消费群体和需求。
  5. IP 生命周期在于可持续的健康投入 认为 IP 的延续和成长关键在于持续、健康地投入资源进行内容、产品和体验的迭代与唤醒，而非仅依赖传统的故事载体，这在时间碎片化的当下尤为重要。

💬 文章金句

  • "无用"的东西才是永恒的。产品只要有了功能属性，都意味着生命周期的短暂和与生俱来的衰变。只有那些"无用"的东西，才能够经历更长的时间，这就是艺术的魅力，也是我们这个行业的魅力。
  • 再好的商业模式，再花哨的概念，到最后都要回到柴米油盐酱醋茶的具体细节，回到对人、对事、对钱、对复杂问题的处理迭代上。
  • 我觉得"快乐"可能会是一个更大的市场。
  • 我觉得我们可能算是中国本土消费品里，包括作为一个中国企业的文化品牌，在国外做的最好的企业之一。
  • 所以每一个企业都要找到对 IP 持续且健康的投入方法。
