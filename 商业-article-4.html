Linus Torvalds 怒斥 Linux 6.15 中“恶心”的测试代码：这玩意儿必须被干掉！

4/1/2025, 10:33:58 AM

📌 一句话摘要

Linus Torvalds 怒斥 Linux 6.15 中的 hdrtest 代码，因其影响构建速度和开发体验，并强烈要求移除。

📝 详细摘要

本文报道了 Linux 之父 Linus Torvalds 对 Linux 6.15 版本中 hdrtest 代码的强烈不满。该测试代码旨在检查 DRM 头文件的完整性，确保其符合 kernel-doc 规范，但 Torvalds 认为它强制纳入内核常规构建流程，拖慢构建速度，并在 include 目录下留下无用的测试文件，破坏了 Git 操作和文件名补全功能，严重影响了开发体验。Torvalds 毫不留情地建议开发者将 hdrtest 放在自己的检查流程中，并已将其标记为损坏禁用。

💡 主要观点

  1. Torvalds 建议将测试代码从常规构建流程中移除 Torvalds 认为测试代码应该作为单独的测试工具存在，而不是强制所有开发者都运行它，影响他们的开发体验。这是整个事件的解决方案和核心观点。
  2. hdrtest 代码的引入降低了 Linux 内核的构建效率 该测试代码被强制纳入内核的常规构建流程，导致所有 Linux 内核开发者在编译时都要额外运行它，浪费了大量时间。
  3. hdrtest 代码会在系统中产生不必要的垃圾文件 这些文件没有被 .gitignore 忽略，导致 Git 提示开发者有未跟踪的文件，影响了开发流程，并且破坏了终端的文件名补全功能。
  4. hdrtest 代码本意是为了优化 Linux 内核开发体验，但其实现方式太过粗暴，反而恶化了开发体验 该测试的初衷与实际效果形成了鲜明对比，体现了在软件开发中良好意图与糟糕实现之间的矛盾。
