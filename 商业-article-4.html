Y Combinator 发布 Terminal Use：为 AI Agent 打造的基础设施

2/16/2026, 5:30:00 PM

📌 一句话摘要

Y Combinator 推出 Terminal Use，这是一个采用 CLI 优先模式的托管基础设施，旨在简化后台 AI Agent 的开发与迭代。

📝 详细摘要

此推文宣布了 YC 孵化项目 Terminal Use 的发布，该初创公司为 AI Agent 提供专业的基础设施。其核心理念是，Agent 应用的成功取决于“运行环境”（harness，即环境和工具链），而非仅仅是底层的 LLM。Terminal Use 提供了诸如可 Fork 的文件系统和并行 Agent 执行等功能，并针对 CLI 优先的工作流进行了优化，以便与 Claude Code 和 Codex 等编程 Agent 集成。
