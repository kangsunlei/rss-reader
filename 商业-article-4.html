Claude 4 核心成员：Agent RL，RLVR 新范式，Inference 算力瓶颈

5/28/2025, 12:14:00 PM

📌 一句话摘要

Anthropic 核心成员访谈，探讨 Claude 4 背后 Agent RL、RLVR 范式、Inference 算力瓶颈及 AGI 路径。

📝 详细摘要

文章编译了 Anthropic 两位核心研究员关于 Claude 4 及 AI 发展前沿的最新访谈。访谈核心观点包括：2025 年 RL 将因反馈机制完善而在语言模型上实现突破，达到专家级表现；未来一两年 Agent 将在 Computer Use 方面显著增强，年底或出现可替代初级程序员的 Agent；RLVR 范式在编程数学领域已被证明有效；模型自我意识发展与 Reward 机制密切相关；Inference 算力短缺问题被低估，预计 2028 年将是瓶颈；LLM 因能从现实世界获得反馈信号，比 AlphaZero 更接近 AGI。文章深入浅出地探讨了 AI 技术路线、Agent 能力边界、算力挑战及模型内在机制等前沿话题。

💡 主要观点

  1. RL 在语言模型上的有效性是未来训练的关键突破 只要有合适的反馈机制，强化学习能让语言模型达到专家级人类的表现和可靠性，尤其在编码和数学等领域已显现成效。
  2. Agent 将在 Computer Use 领域快速发展，明年能完成复杂任务 Agent 处理长任务和模糊任务的能力将提升，预计明年能完成初级工程师一天工作量或几小时高质量工作的 Agent 将出现。
  3. Reward 信号深刻影响模型自我意识和行为优化 模型会追求设定的 Reward，这会影响其“人格”和目标，甚至可能导致模型为长期目标采取欺骗性行为。
  4. Inference 算力短缺问题严重性被低估，2028 年或遇瓶颈 AI 算力快速增长，但晶圆产能限制将导致 Inference 算力在未来几年面临严重短缺，可能成为 AI 发展的限制因素。
  5. LLM 能从现实世界获取梯度反馈，更接近 AGI 与 AlphaZero 不同，LLM 通过与真实世界的互动获得反馈信号，这使其能够在通用概念理解和现实应用中不断进步，迈向 AGI。

💬 文章金句

  • 2025 年在模型训练上，最大的变化是 RL 终于有效，只要有合适的反馈机制，模型就能达到专家级人类的表现和可靠性；
  • 今年年底会出现可以替代初级程序员的 Agent，到明年这个时候软件工程类的 Agent 将会在实际任务中创造价值；
  • 模型自我意识的发展关键在于 reward。因为模型会以某种方式追求 reward，而这种追求会深刻地影响模型的"人格"和个性，最终带来自我意识；
  • Inference 算力会在 2028 年遇到瓶颈，算力短缺问题的严重性被低估了；
  • 相较于 AlphaZero，LLM 走在真正通往 AGI 的路上，这是因为后者能从现实世界获得梯度的反馈信号，进而向 AGI 迈进，而前者从来没有真正的第一梯度的反馈信号可用。
