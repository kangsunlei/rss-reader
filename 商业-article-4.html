阿里千问 3 登顶全球最强开源模型，性能超越 DeepSeek-R1、OpenAI-o1

4/29/2025, 12:36:54 AM

📌 一句话摘要

阿里千问 3 登顶全球最强开源模型，性能超越 DeepSeek-R1 和 OpenAI-o1，并提供多种参数规模选择。

📝 详细摘要

阿里巴巴开源了新一代通义千问模型 Qwen3，该模型采用了混合专家（MoE）架构，总参数量为 235B，激活仅需 22B。千问 3 是国内首个「混合推理模型」，对简单需求可低算力「秒回」答案，对复杂问题可多步骤「深度思考」，大大节省算力消耗。千问 3 在推理、指令遵循、工具调用和多语言能力等方面均有显著增强，并在多个测评中创下新高，性能超越 DeepSeek-R1 和 OpenAI-o1 等模型。千问 3 为即将到来的智能体 Agent 和大模型应用爆发提供了更好的支持，大幅降低 Agent 调用工具的门槛。此外，千问 3 还提供了多种模型版本，以满足不同场景的需求，并采用宽松的 Apache2.0 协议开源，支持 119 多种语言，方便全球开发者使用。阿里通义已开源 200 余个模型，全球下载量超 3 亿次，千问衍生模型数超 10 万个，成为全球第一开源模型。

💡 主要观点

  1. 千问 3 采用混合专家架构，实现性能与成本的平衡 通过 MoE 架构，千问 3 在保证性能的同时，显著降低了部署成本和算力消耗，使得更多开发者能够使用。
  2. 千问 3 在多项测评中超越其他顶尖模型 在 AIME25、LiveCodeBench 和 ArenaHard 等测评中，千问 3 均取得了优异成绩，证明其在推理、代码能力和人类偏好对齐方面的卓越性能。
  3. 千问 3 支持多种模型版本和混合推理模式 千问 3 提供多种参数规模的模型，并支持按需设置思考预算，灵活满足不同 AI 应用场景对性能和成本的需求。
  4. 千问 3 为即将到来的智能体 Agent 和大模型应用爆发提供了更好的支持 千问 3 在评估模型 Agent 能力的 BFCL 评测中创下新高，超越 Gemini2.5-Pro、OpenAI-o1 等顶尖模型，将大幅降低 Agent 调用工具的门槛。

💬 文章金句

  • 千问 3 是国内首个「混合推理模型」，「快思考」与「慢思考」集成进同一个模型，对简单需求可低算力「秒回」答案，对复杂问题可多步骤「深度思考」，大大节省算力消耗。
  • 千问 3 的 30B 参数 MoE 模型实现了 10 倍以上的模型性能杠杆提升，仅激活 3B 就能媲美上代 Qwen2.5-32B 模型性能；千问 3 的稠密模型性能继续突破，一半的参数量可实现同样的高性能，如 32B 版本的千问 3 模型可跨级超越 Qwen2.5-72B 性能。
  • 千问 3 系列模型依旧采用宽松的 Apache2.0 协议开源，并首次支持 119 多种语言，全球开发者、研究机构和企业均可免费在魔搭社区、HuggingFace 等平台下载模型并商用，也可以通过阿里云百炼调用千问 3 的 API 服务。
