📌 一句话摘要

OpenInterviewer 是一个开源的自适应 AI 定性研究平台，支持多种部署模式（Cloudflare/Node/Vercel）及 BYOS（自带密钥）架构，旨在为研究人员提供从访谈配置、数据收集到合成分析的全流程工具。

📝 详细摘要

该文档介绍了 OpenInterviewer，一个用于辅助定性研究的开源平台。其核心功能包括配置研究项目、生成匿名参与者链接、以及通过仪表盘查看转录和合成分析结果。平台提供了四种主要使用路径：无需凭证的脚本化演示、推荐在 Cloudflare 上自托管（利用 Durable Objects 存储）、在 Node/Vercel 上自托管（依赖 Upstash），以及由运营商管理的多租户托管账户模式。技术架构上，它支持 Gemini、Claude、OpenAI 和 OpenRouter 等多种 LLM 提供商，并详细说明了不同部署环境下的安全配置要求（如加密密钥管理、OAuth 设置）及运维最佳实践（如备份、恢复、CI/CD 集成）。文档强调了隐私保护设计，例如参与者链接的不透明性以及服务器端密钥隔离。

💡 主要观点

  1. 提供灵活的多模式部署架构以适配不同用户需求 平台设计了四种明确的使用旅程：1) Keyless Demo 用于体验流程；2) Cloudflare 自托管作为推荐方案，利用 Workers 和 Durable Objects 实现无外部数据库依赖的持久化；3) Node/Vercel 自托管，适合已有 Vercel 基础设施的用户，需配合 Upstash Redis；4) 托管多租户模式，由运营商统一配置基础设施，研究者仅需添加自己的 API 密钥和数据存储凭证。
  2. 实施严格的 BYOS（Bring Your Own Secrets）安全与隐私策略 在托管模式下，研究者的 AI 提供商密钥和 Upstash 凭证均经过加密存储，且仅在服务器端解密使用，确保平台运营商无法直接访问明文密钥。参与者链接采用不透明令牌机制，防止身份泄露。同时，文档详细规定了密钥轮换、独立随机盐值生成以及 OAuth 回调的安全配置要求。
  3. 深度集成现代云原生基础设施特性 针对 Cloudflare 部署，利用了 OpenNext 框架运行 Next.js 应用，并通过 Queue 处理后台分析任务，实现了异步解耦。针对 Node/Vercel 部署，则依赖 Vercel AI Gateway 或直连适配器。这种设计充分利用了 Serverless 环境的扩展性和成本效益，同时明确了不同运行时环境下的性能限制（如 Worker CPU 时间限制对渲染的影响）。
