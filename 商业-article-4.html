📝 详细摘要

文章介绍了 Claude Code 新推出的自定义指令功能，特别是 ultrathink-task 指令的使用方法。该指令可以调用架构智能体、研究智能体、编码智能体和测试智能体，模拟一个开发团队协作完成任务。文章提供了详细的使用说明和双语(中英文)提示词参考，包括任务描述格式、角色分工、工作流程和输出格式要求。通过这个指令，用户可以更系统地利用 Claude Code 完成复杂任务。该功能源自 Reddit 社区分享，展示了 AI 协作的新范式。

💡 主要观点

  1. 增强 AI 协作的系统性和可靠性 通过角色分工和流程规范，提高 AI 解决复杂问题的可靠性和系统性
  2. ultrathink-task 指令模拟开发团队分工协作 通过架构、研究、编码和测试四个智能体的分工协作，系统化解决复杂任务
  3. 提供清晰的工作流程和输出格式要求 分步思考、任务分派、超深度思考和迭代完善的工作流程，确保解决方案质量
  4. 提供双语提示词参考 同时提供中英文版本的使用说明，方便不同语言背景的开发者使用

💬 文章金句

  • `/project:ultrathink-task <任务描述>`
  • 你是协调智能体，负责统筹协调以下四个专家子智能体的工作
  • 进行一次'超深度思考'（ultrathink）阶段，将所有见解融合成一个完整的解决方案
  • 如果仍存在空白或疑问，继续迭代（再次调用子智能体），直至你对最终结果充满信心
