📌 一句话摘要

文章从第一性原理深度拆解 Claude Agent Skills 系统，揭示其基于提示词扩展和上下文修改的“元工具”架构及其工作机制。

📝 详细摘要

文章对 Claude Agent `Skills` 系统进行了深度解构，阐明其并非传统可执行代码，而是通过提示词扩展和上下文修改来增强大语言模型（LLM）能力的“元工具”架构。它详细阐述了`Skills`的生命周期，从文件解析、API 请求结构到 Claude 的决策过程，强调其决策完全基于 LLM 的自然语言理解，而非算法式的技能选择器。文章深入介绍了`SKILL.md`的构成（Frontmatter 和 Markdown 内容），以及`scripts/`、`references/`、`assets/`等辅助目录的作用，并提供了多种技能构建模式和最佳实践。此外，文章还详细分析了`Skill`元工具的内部设计，特别是通过`isMeta`标志实现的用户可见元数据与隐藏详细指令的双通道消息注入机制，以及其在实际执行中的生命周期，为开发者提供了构建高效 Agent 技能的全面指导。

💡 主要观点

  1. Claude Agent Skills 是一种基于提示词扩展和上下文修改的“元工具”架构 Skills 不执行可执行代码，而是通过注入特定指令和动态修改对话/执行上下文来扩展 LLM 能力，其决策完全基于 LLM 的自然语言理解，而非算法匹配。
  2. 技能的构建核心是`SKILL.md`及其辅助目录，遵循渐进式披露原则 `SKILL.md`定义了技能的元数据和核心指令，而`scripts/`、`references/`、`assets/`目录则按需提供详细内容和资源，有效防止上下文过载。
  3. Skill 元工具通过双通道消息注入机制实现透明度与效率的平衡 系统利用`isMeta`标志，将用户可见的简洁元数据与隐藏的详细技能提示词分开，确保用户了解 Agent 状态，同时为 Claude 提供完整的执行指令。
  4. 文章提供了多种实用的技能构建模式和最佳实践 从脚本自动化到迭代优化，这些模式指导开发者高效设计和实现复杂的 Agent 工作流，提升 LLM 应用的自动化和智能化水平。

💬 文章金句

  • `Skills` 是专门的提示词模板，用于将领域特定的指令注入到对话上下文中。
  • 代码层面不存在算法式的"技能选择器"或 AI 意图检测模块。所有的决策都发生在 Claude 的推理过程中，完全基于提供的技能描述。
  • **核心洞察**：技能 (Skill) = 提示词模板 + 对话上下文注入 + 执行上下文修改 + 可选的数据文件和 Python 脚本
  • **渐进式披露（Progressive Disclosure）** ------只展示足够的信息来帮助 Agent 决定下一步做什么，然后根据需要披露更多细节。
  • 双消息分离通过给每条消息不同的 `isMeta` 值解决了这个问题。消息 1 (`isMeta: false`) 提供面向用户的透明度。消息 2 (`isMeta: true`) 为 Claude 提供详细指令。
