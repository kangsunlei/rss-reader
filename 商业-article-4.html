Claude Code 负责人：编程正在消失，但软件机会才刚刚开始丨 Lenny's Podcast

2/22/2026, 2:26:00 PM

📌 一句话摘要

Claude Code 负责人 Boris Cherny 探讨了 AI 如何彻底解决编程语法问题，并预言软件工程师将转型为“建设者”，强调定义问题和系统设计将成为核心竞争力。

📝 详细摘要

本文总结了 Anthropic 旗下 Claude Code 负责人 Boris Cherny 在 Lenny's Podcast 中的深度访谈。核心观点认为，传统的“编程”（将业务逻辑翻译为计算机语法）动作已被 AI 基本解决，软件工程的门槛正在消失。文章详细介绍了 Claude Code 成功的“反直觉”原则，如通过无限 Token 激发团队寻找高维杠杆。未来，AI 将从辅助工具进化为能主动思考、处理反馈的“虚拟同事”（Cowork）。这种范式转移将导致工程师与产品经理的职能边界消融，催生出具备端到端交付能力的“建设者”角色，使人类精力从底层实现转向更高维度的需求定义与系统设计。

💡 主要观点

  1. 编程动作已被 AI 彻底“解决”，核心稀缺性转向定义问题。 随着 AI 能够精准实现业务逻辑，单纯的语法编写和框架调用不再是护城河，未来的关键能力在于准确定义“实现什么”以及“为什么实现”。
  2. 从“代码辅助”向“虚拟同事（Cowork）”的协同范式演进。 AI 不再只是被动接受指令的打字机，而是能主动查阅 Bug 报告、分析遥测数据并提出功能建议的独立任务执行者，分担人类的认知负荷。
  3. 工程师与产品经理的边界正在消融，所有人将成为“建设者”。 AI 抹平了技术实现门槛，PM 可以直接构建原型，工程师能独立完成业务闭环，传统的职能划分将被追求端到端交付的超级个体所取代。
  4. 利用“无限算力”假设来重塑 AI 时代的工作流。 不应受限于计算成本，而应思考在 AI 可以无限制调用的前提下，如何将“脏活累活”外包给系统，从而将人类精力释放到高维决策中。

💬 文章金句

  • 代码正在被解决，但“该做什么”反而更稀缺。
  • 编程在消失，软件的机会才刚刚开始。
  • 不要把 AI 当作“帮你写两行代码”的辅助工具，要把它当作可以独立运行子任务的“虚拟员工”。
  • “软件工程师”这个头衔将开始消失，它将被“建设者”所取代，这对很多人来说将是痛苦的。
  • 当“写代码”的动作从枯燥的劳作中消失，我们真正迎来的，是一个思想能够以光速转化为现实的黄金时代。
