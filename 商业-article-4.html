深度｜LangChain 创始人：MCP 是“昙花一现”还是未来标准？

3/22/2025, 3:59:40 AM

📌 一句话摘要

LangChain 创始人 Harrison Chase 探讨了 MCP 协议的适用场景和局限性，并与 LangGraph 负责人 Nuno Campos 进行了辩论，展望其未来发展方向，认为 MCP 有潜力成为连接 Agent 和工具的桥梁。

📝 详细摘要

文章围绕 Model Context Protocol (MCP) 展开讨论，LangChain 创始人 Harrison Chase 和 LangGraph 负责人 Nuno Campos 就 MCP 的价值和未来发展方向进行了辩论。Harrison 认为 MCP 在将工具集成到无法控制的 Agent 中非常有用，尤其对于非开发者构建 Agent 而言，类似于 Zapier 在小众和特定集成方面的价值。Nuno 则认为 MCP 存在局限性，例如，Agent 需要根据提供的工具进行定制，仅仅嵌入一个工具可能行不通。尽管存在争议，Harrison 仍然对 MCP 的未来充满信心，认为它有潜力成为连接各种小众或特定集成的桥梁。Nuno 则认为 MCP 需要变得更像 OpenAI 的 Custom GPTs 才能真正流行起来，并提出了 MCP 需要改进的几个方面。

💡 主要观点

  1. MCP 在将工具集成到无法控制的 Agent 中非常有用 对于非开发者构建 Agent 而言，MCP 提供了一种无需编辑 Agent 逻辑本身即可访问特定工具的途径，降低了技术门槛。
  2. 生产环境中 Agent 需要根据提供的工具调整系统消息 仅仅嵌入一个神奇的工具可能无法提供新增的能力，需要根据提供的工具调整系统消息，甚至调整架构的其他部分。
  3. MCP 的当前形式很糟糕，但未来可期 MCP 需要变得更像 OpenAI 的 Custom GPTs 才能真正流行，并且 Harrison 对 MCP 未来发展充满信心。

💬 文章金句

  • 当你想将 tool 带入一个你**无法控制的** Agent 时，MCP 就是有用的。
  • 生产环境中 Agent 需要根据提供的工具调整系统消息
  • 我想象一个未来的 MCP 状态：**你可以一键安装 MCP 应用，不再需要在本地终端运行服务器，并且它们可以在 Web 应用中使用。
