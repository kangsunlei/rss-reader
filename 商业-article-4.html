手搓 Skill，年轻人的荒诞艺术大舞台

4/18/2026, 10:13:00 AM

📌 一句话摘要

本文报道了 AI Agent 技能包（Skill）在 GitHub 和社交媒体上引发的创作热潮，从饺子馆排队到人格蒸馏，展现了年轻人将 AI 技术用于功能服务和荒诞艺术表达的多元实践。

📝 详细摘要

文章以北京金谷园饺子馆老板李博开发「饺子馆.Skill」为引子，报道了近期在 GitHub 上兴起的 AI Agent 技能包（Skill）创作风潮。这股风潮始于「同事.Skill」，旨在通过 AI 模拟离职同事的工作习惯以减轻工作压力，随后迅速演变为一场全民参与的「行为艺术」。年轻人创作了诸如「前任.Skill」、「自己.Skill」、「反蒸馏.Skill」乃至「厉鬼.Skill」等充满想象力和荒诞感的作品，将人格「蒸馏」技术用于情感疗愈、自我反思甚至社会讽刺。同时，也有开发者将这一技术用于更实用的「女娲.Skill」，以快速创建名人或专家的数字人格进行咨询。文章指出，Skill 的开发门槛因自然语言编程（vibe coding）而大大降低，普通人也能轻松参与，这预示着 AI Agent 生态正进入一个由大众创意驱动的野蛮生长期。

💡 主要观点

  1. Skill 创作已从专业提效工具演变为大众参与的创意表达和荒诞艺术。 文章展示了 Skill 生态的多样性：从解决实际排队问题的「饺子馆.Skill」，到充满情感和讽刺意味的「前任.Skill」、「反蒸馏.Skill」，体现了技术被赋予的社会和文化表达功能。
  2. 自然语言编程（vibe coding）极大降低了 AI 应用开发门槛，推动了 Skill 的野蛮生长。 饺子馆老板和普通开发者通过 Coze 等工具，无需深厚编程基础即可快速创建 Skill，这标志着 AI 应用开发正从专家领域走向大众创新。
  3. 「人格蒸馏」技术引发了关于数字永生、职业替代和伦理边界的新讨论。 通过 AI 模拟特定人物的思维和语言模式（如乔布斯、张雪峰），技术实现了某种形式的「赛博永生」，同时也引发了关于岗位被 AI 替代的焦虑和相应的「反制」创意。
  4. Skill 的繁荣预示着一个由无数「小程序」构成的未来 AI Agent 超级生态。 文章引用开发者观点，认为未来的 AI Agent（如微信）将是一个超级入口，而 Skill 则是其中的小程序，其数量和创意将决定生态的丰富度。

💬 文章金句

  • 既然同事.Skill 是为了减缓同事离职后自己的工作压力，那怎么就不能用来减轻情感压力呢？
  • 但有没有想过——最该被蒸馏的，其实是你自己？毕竟你才是那个 24 小时在线、跟你对话最多的人。与其蒸馏别人，不如蒸馏自己。欢迎加入数字永生！
  • 如果说未来的微信就是一个巨大的 Agent，那么 Skill 就是这个生态里的小程序。
  • 讲一句废话文学，当 Skill 越多的时候，Skill 也就越多。一个饺子馆老板的深夜冲动，可能就会带动更多人的效仿甚至超越。Skill 的野蛮生长期，才刚刚开始。
