WAIC 随记｜我们画了一张 Agent 时代的脉络图

7/20/2026, 12:30:00 PM

📌 一句话摘要

本文基于 2026 年 WAIC 现场观察，描绘了以 Agent 为中心的产业网络图谱，梳理出 AgentOS、增强服务、硬件、能力生态四层架构，并指出各方正在争夺 Agent 时代的关键节点与用户关系。

📝 详细摘要

文章是作者在 2026 年 WAIC 现场的观察笔记，系统梳理了 Agent 产业网络的现状与趋势。作者指出当前产业呈现三重特征：Agent 是创新引爆中心、刺激创业者生态繁荣、数据闭环与服务开放并存。在此基础上，作者将产业格局归纳为四层架构：AgentOS 争夺系统控制权、记忆与情绪服务补足基础体验、硬件承担感知与交互、出行/设计/剪辑等工具负责把意图变成现实结果。文章详细分析了阶跃、荣耀、努比亚等大厂的 AgentOS 路径，以及知夏科技、记忆张量等创业公司在增强服务层的探索，同时指出手机正从移动互联网的中枢地位降级为 Agent 时代的核心节点之一。作者认为，Agent 时代不会简单复制移动互联网秩序，各方都在争夺谁能掌握用户关系和数据资产。

💡 主要观点

  1. Agent 产业网络呈现三重特征：创新引爆中心、创业者生态繁荣、数据闭环与服务开放并存。 大厂与创业者各有定位，数据被视为竞争杀手锏不愿共享，短期内难以形成统一大市场。
  2. 产业格局可归纳为四层架构：AgentOS、增强服务、硬件、工具生态，相互交错而非简单上下游关系。 AgentOS 负责系统控制权与经验沉淀，增强服务补足记忆与情绪等细腻体验，硬件承担感知交互，工具负责将意图转化为结果。
  3. 手机正从移动互联网的中枢降级为 Agent 时代的核心节点之一，多设备协同成为新方向。 阶跃、荣耀在推 Agent 手机的同时强调多端协同，AI 眼镜、耳机等可穿戴设备也在争夺感知入口。
  4. 增强服务层存在差异化机会：情绪陪伴与记忆打通是当前 AgentOS 难以做透的环节。 知夏科技的 MemoPin 针对 ADHD 用户优化记忆，记忆张量的 Memmy 解决跨 Agent 上下文打通问题。
  5. Agent 时代不会简单复制移动互联网秩序，各方争夺的核心是谁能掌握用户关系和数据资产。 操作系统、App、硬件的边界正在被打散，谁能回答「开放能力同时留住数据、调用服务同时掌握用户关系」是制胜关键。

💬 文章金句

  • 方向是确定的，终点是模糊的，路径也是不尽相同的。
  • 过去，操作系统控制入口，App 承接需求，硬件负责交互；现在，这些边界正在被重新打散。
  • 目前还没人能回答的是，谁能在开放能力的同时留住数据，在调用外部服务的同时掌握用户关系。
