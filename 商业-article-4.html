275.AI 办公的热闹还没散，个人 Agent 的战争已经开始｜拆解 Town、Instinct、Grok Bot 与 Muse

9/21/2026, 12:00:00 AM

📌 一句话摘要

以 Town、Instinct、Grok Bot、Muse 四款产品为切口，拆解个人 Agent 为何突然爆发、上一批产品为何成先烈，以及模型、Context、执行能力、生态与用户信任中谁能定义终局。

📝 详细摘要

本期「乱翻书」由潘乱主持，嘉宾为前 TikTok 产品经理莫唯书、Today 创始产品经理 Suki，以及前字节 AI 产品经理 Vanessa。节目从个人 Agent 赛道的狂热估值切入：Instinct 尚未正式上线，估值半年从 5000 万美元升至百亿美元；Meta 的 Muse 上线后迅速登顶美国 App Store，首周下载接近 90 万。嘉宾区分了「工具」与「人」：办公 Agent 围绕任务组织 Context，个人 Agent 围绕用户本人组织长期记忆与画像，并具备不等指令的主动性。四人逐一比较四款产品的赌注——Town 先做深邮箱以换取用户委托权，Instinct 取消独立 App 把交付成本压成一条消息并接管支付，Grok Bot 主打多 Bot 队伍与云虚拟电脑，Muse 以免费、分发和专用虚拟机直接补贴市场。节目指出上一批小龙虾产品失败的原因：追热点、产品粗糙、门槛过高，以及云上三套环境（设备、云端服务、执行环境）的状态保持远比本地复杂。跑通的场景集中在退订、改签、预约、账单、家校邮件和育儿等生活琐事，而非宏大任务。讨论还涉及 Agent 替人花钱后的「意图经济」、豆包是否需与抖音数据彻底打通、独立 App 与 IM 的入口之争，以及最后押注模型、Context、设备、供给还是用户信任。

💡 主要观点

  1. 个人 Agent 与上一波 Agent 的分界线是「是人还是工具」 工具用完即止，下次还要重新交代上下文；个人 Agent 围绕用户本人构建长期记忆与画像，并具备不等指令、基于目标主动提方案的主观能动性，而非依赖 prompt 的自动化。
  2. 四款产品代表四种不同的赌注，而非同一条路线上的参数差异 Town 以邮件这一高频场景换取信任与最终委托权；Instinct 赌极致降低启动成本、住在 IM 里并接管支付；Grok Bot 赌给用户一个多 Bot 团队；Muse 赌用免费和 Meta 的分发能力烧钱培养市场心智。
  3. 上一批小龙虾类产品成为先烈，主因是追热点、产品粗糙与门槛过高 大量产品同质化严重、打磨不足，且照搬命令行安装与本地部署，普通人既不懂命令行也无从理解其价值；同时云端 Agent 需处理用户设备、云端服务与执行环境三套状态，技术难度被严重低估。
  4. 个人 Agent 最先跑通的是生活里的麻烦事，而非宏大任务 订阅续费、机票退改签、账单、预约、家校邮件和育儿等高频琐事最先被验证；Town 在美国学校家长群体意外破圈，说明价值来源是科技平权，把过去只有特权阶层享有的私人助理普惠给普通人。
  5. 用户对个人 Agent 的第一印象决定了它被当成同事还是生活助理 从桌面端和办公工具切入，用户天然把它用于工作；从手机和 IM 切入，交互更像秘书打字，用户更倾向交付生活事务。因此同一能力在不同入口下会演化出完全不同的使用画像。
  6. 产品创新很容易被复制，长期壁垒可能只剩数据打通、执行机制与用户信任 嘉宾认为豆包已拥有用户，缺的是与抖音等平台数据彻底打通以及处理机制；创业公司的产品创新会被大厂迅速复制，真正难复制的是一端亲近用户的理解与信任，以及复杂执行系统的沉淀。

💬 文章金句

  • 不是 AI 需要大屏，是人需要监督
  • 它不再是 another 的工具，而是一个人。
  • 还有一个差别就是主动性。这个主动性并不是那种比如说我们在 menus 里面或者在其他的 agent 里面，也会给他布置很多自动化的任务。但这些自动化的任务还是依赖很依赖你的 prompt。
  • 只不过之前这种技术科技没有办法像就是科技其实可以平权，就可以普惠到每一个普通人。只不过之前这种待遇是特权阶级的待遇，他们有钱人才能享受。但今天 AGI 有可能让这种体会让每一个人都有。
  • 我们不管这个商业模式，你到底是广告，你是订阅还是抽用，但至少是在个人 agent 这个方向是理论上大家是可以看到有商业模式的这。
