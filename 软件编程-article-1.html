Node.js v24.7.0 引入后量子密码学，使用现代算法扩展 Web 密码学 API，并增强单一可执行应用程序配置。

📝 详细摘要

Node.js v24.7.0 带来了重要的更新，主要侧重于增强安全性和应用程序部署。它集成了后量子密码学 (PQC) 算法，即 ML-KEM 和 ML-DSA，到 `node:crypto` 和 Web 密码学 API 中，旨在增强应用程序抵御量子计算威胁的能力。Web 密码学 API 还增加了现代密码学算法，如 AES-OCB、ChaCha20-Poly1305、SHA-3 和 SHAKE，以及新的实用工具函数，如 `subtle.getPublicKey()` 和 `SubtleCrypto.supports()`。此外，该版本通过允许开发人员指定 Node.js 执行参数并控制这些参数在运行时如何扩展，从而改进了单一可执行应用程序 (SEA) 配置，从而为捆绑的应用程序提供了更大的灵活性。至关重要的是，根证书已更新到 NSS 3.114，从而增强了信任和安全性。其他值得注意的增强功能包括用于密码哈希的新 `argon2()` 方法、用于 HTTP 的 `Agent.agentKeepAliveTimeoutBuffer` 选项、HTTP/2 流中对原始标头数组的支持以及 `CompressionStream` 中的 Brotli 压缩支持。

💡 主要观点

  1. 集成后量子密码学 (PQC) 以实现前瞻性安全保障。 Node.js 现在在 `node:crypto` 和 Web 密码学 API 中支持 ML-KEM 和 ML-DSA 算法，从而解决了量子计算威胁带来的潜在漏洞。
  2. 通过现代算法和实用工具函数扩展 Web 密码学 API。 诸如 AES-OCB、ChaCha20-Poly1305、SHA-3 和 SHAKE 等新算法，以及 `subtle.getPublicKey()` 和 `SubtleCrypto.supports()`，增强了 Web 安全功能。
  3. 增强了单一可执行应用程序 (SEA) 的配置。 SEA 现在允许指定 Node.js 执行参数 (`execArgv`) 并控制它们的运行时扩展 (`execArgvExtension`)。这使得对捆绑的应用程序的控制更加精细。
  4. 更新了根证书和其他加密功能。 NSS 3.114 的根证书更新提高了信任度，同时增加了用于安全密码哈希的 `argon2()` 方法。

💬 文章金句

  • 24.x 上的 OpenSSL 3.5 通过允许使用 NIST 的后量子密码学标准来保护应用程序免受量子计算威胁，从而启动了 Node.js 中的后量子密码学工作。
  • 以下后量子算法现在可在 `node:crypto` 中使用：ML-KEM（FIPS 203，基于模块格的密钥封装机制标准），通过新的 `crypto.encapsulate()` 和 `crypto.decapsulate()` 方法。
  • Web 密码学 API (`globalThis.crypto.subtle`) 的第二个实质性扩展最近被 WICG 接受孵化。
  • 单一可执行应用程序配置现在支持其他字段，以指定 Node.js 执行参数，并控制这些参数在应用程序运行时如何扩展。
