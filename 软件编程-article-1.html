OpenViking 网关：让任意客户端用上 Agentic 记忆

10/23/2026, 11:20:00 AM

📌 一句话摘要

OpenViking 网关位于客户端和模型服务之间，帮助模型查找和使用 OpenViking 中的记忆，让兼容客户端不必各自实现一套记忆功能，从而实现自动召回、信息补充和对话保存。

📝 详细摘要

文章介绍了 OpenViking 网关的功能、接入方式、支持的客户端以及部署方法。网关提供自动记忆召回、信息补充和对话保存等能力，通过简单的配置即可让现有客户端拥有 Agentic 记忆。部署方式包括与本地 OV 共用端口和连接火山托管 OV，并详细说明了接入 Claude Code 的步骤。

💡 主要观点

  1. 全托管的 Agent 基础设施 火山引擎 Managed Agents 提供了稳定的 Agent 运行时、上下文持久化、云端环境和工具接入等基础设施，开发者无需自建这些组件，可以专注于业务逻辑和用户体验。
  2. 设备连接与跨平台操作 通过添加设备连接（如 iPhone、Mac），Agent 可以跨平台运行，用户可以在手机上发起指令，在电脑上查看结果，实现无缝的跨设备协作。
  3. 主动触达与目标跟进 Agent 具备主动触达能力，可以发送每日问候、到点提醒，并定期跟进进行中的目标，确保用户不会错过重要事件或任务。
  4. 操作审批与隐私保护 对于敏感操作，Agent 会先征求用户同意，确保用户对自己的数据和操作有完全的控制权，同时提供资源库来管理生成的文档和数据。
