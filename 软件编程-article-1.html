有没有人经历过 XML\EXCEL+SVN 的死亡地狱

6/11/2026, 12:57:41 PM

📌 一句话摘要

本文介绍了一个为解决游戏公司策划用 Excel+SVN 管理配置时无法有效 diff 和合并而开发的工具，能自动识别数据变更并支持单元格级三方合并。

📝 详细摘要

文章作者分享了在游戏公司工作中遇到的痛点：策划使用 Excel 格式（XML 或 xlsx）的配表直接提交到 SVN，导致每次提交后难以追踪实际数据变更，甚至样式调整也会被标记为改动。为此，作者利用 AI 开发了一个工具，核心功能包括：自动识别 ID 列并按行身份匹配，过滤样式、列宽等噪音，仅展示数据变更（新增、删除、修改）；支持单元格级的三方合并，能自动合并不同人的修改，仅在冲突时提示手动选择；提供类似 GitHub Files changed 的总览页面。工具使用 Python + Flask 后端和原生 JS 前端，打包为单文件 exe，方便同事使用。文章末尾附上了 GitHub 仓库链接，并邀请用户试用。

💡 主要观点

  1. Excel+SVN 的配置管理方式存在严重的 diff 和合并痛点。 策划的配表直接进 SVN，样式、列宽等噪音会被标记为改动，导致无法有效追踪数据变更，且多人协作时合并困难。
  2. 开发的工具通过智能解析和过滤，实现了数据级别的变更追踪。 工具自动识别 ID 列，按行身份匹配，过滤掉样式等噪音，只展示数据的新增、删除和修改，并显示旧值到新值的变化。
  3. 工具支持单元格级的三方合并，提升了协作效率。 当两人修改同一张表的不同列时，工具能自动合并，仅在修改同一单元格时提示手动选择，解决了传统版本控制工具在 Excel 文件上的合并难题。

💬 文章金句

  • 样式、列宽这些噪音在解析阶段就扔掉了，只剩数据变更:绿色新增行、红色删除行、黄色改动格(旧值 → 新值)
  • 两个人改了同一张表，可以做单元格级的三方合并。一个人改价格列、另一个改描述列，自动就合了;真撞到同一格才需要手动选
