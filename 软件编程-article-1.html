本文介绍了一款将 Capslock 映射为 Hyper 键的 macOS 原生应用，并展示了其核心功能与使用场景。

📝 详细摘要

文章作者分享了自己开发的一款 macOS 原生应用 HyperCapslock，旨在解决快捷键空间不足的问题。该应用将 Capslock 键映射为一个全新的虚拟 Hyper 键，而非传统的 Command+Control+Shift+Option 组合。其核心优势在于，当 Hyper 键与方向键等组合时，能自动衍生出更多修饰键组合（如 Hyper+Option+H 向左跳一个单词）。文章列举了作者常用的映射场景，包括全局 Vim 导航、调出 Spotlight、启动特定应用、执行 Shell 脚本等，并提供了 GitHub 下载链接。

💡 主要观点

  1. HyperCapslock 将 Capslock 映射为全新的虚拟 Hyper 键，而非传统组合键。 该应用创造了一个独立的虚拟键，使其能与 Command、Option 等修饰键自由组合，从而大幅扩展快捷键空间，解决快捷键冲突问题。
  2. 应用支持自动衍生修饰键组合，提升操作效率。 例如，将 Hyper+H 映射为左方向键后，系统会自动生成 Hyper+Option+H（向左跳一个单词）和 Hyper+Shift+Option+H（向左选中一个单词）等组合，无需逐一配置。
  3. 应用提供了丰富的自定义映射场景，覆盖导航、应用启动、脚本执行等。 作者展示了全局 Vim 方向键导航、双击 Hyper 调出 Spotlight、在特定终端下启动 tmux 浮动窗口、一键切换输入法等实用功能，体现了其高度的可定制性。

💬 文章金句

  • 如果你的快捷键很紧缺了，需要更多的快捷键空间，或者说想要全局的 Vim 导航，可以试试
  • HyperCapslock 把 Capslock 映射为 Hyper 键，这里并不是把 Hyper 不等于通常意义上的 Command + Control + Shift + Option ，而是完全新造了一个虚拟的键。
