SolidCraft：Rust 编写的开源参数化 3D 建模软件

10/20/2026, 11:59:58 AM

📌 一句话摘要

GitHub Daily 推荐 SolidCraft，一款用 Rust 编写的开源参数化 3D 建模工具，支持跨平台与 AI Agent 调用，适合 3D 打印入门与树莓派外壳设计。

📝 详细摘要

作者介绍 SolidCraft：开源参数化 3D 建模软件，用 Rust 编写，通过草图、标注尺寸、拉伸建模，所有步骤记录在时间线上，修改参数即可自动重建模型。提供 Windows/macOS/Linux 安装包及浏览器版，内置接口供 AI Agent 直接建模。作者用 76 个公开参考零件验证，75 个体积、面积、重心等指标吻合，认为适合 3D 打印爱好者入门及小零件设计。

💡 主要观点

  1. 参数化建模降低修改成本 通过时间线记录每一步操作，修改单一尺寸参数（如树莓派外壳高度 24→32 mm）即可触发全模型自动重建，避免传统建模需从头重画。
  2. 工程级验证增强可信度 作者对 76 个公开参考零件进行核对，75 个在体积、面积、重心等关键指标上通过验证，显示软件几何内核具备较高工程精度。
  3. 多端部署与 AI 就绪 原生跨平台桌面端与浏览器版并存，内置 API 接口允许 AI Agent 直接驱动建模流程，扩展了自动化设计场景。

💬 文章金句

  • 参数化的好处是改一个数全跟着变，演示里把树莓派外壳的高度从 24 毫米改成 32 毫米，整个模型自动重建。
  • 作者拿 76 个公开的参考零件做了核对，体积、面积、重心这些有 75 个对得上，这种较真劲儿我认。
