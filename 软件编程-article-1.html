GitHub Copilot CLI 现已支持多模型切换

📌 一句话摘要

GitHub 展示了如何通过 /model 和 /plan 命令在 Copilot CLI 中灵活切换不同的 LLM。

这条推文重点介绍了 GitHub Copilot CLI 的一项核心功能：根据具体任务需求灵活选择和切换大语言模型 (LLM)。通过 Scott Hanselman 的演示，推文介绍了用于模型选择的 /model 命令和 /plan 命令，强调了开发者如何通过为特定工作匹配合适的模型，来优化终端环境下的 AI 辅助体验。
