Databricks 为 Apache Spark 提供了 Spark 声明式管道

7/13/2025, 2:15:00 AM

📌 一句话摘要

Databricks 将其 Delta Live Tables 技术贡献给 Apache Spark，命名为 Spark 声明式管道，旨在通过声明式语法简化流式数据管道的开发与维护。

📝 详细摘要

文章详细介绍了 Databricks 在 Data+AI 峰会上宣布将其核心技术 Delta Live Tables (DLT) 作为一项重大贡献提供给 Apache Spark 项目，并将其更名为 Spark 声明式管道。这项新特性允许开发者使用声明式 SQL 语法或简单的 Python SDK 定义数据流管道，从而避免了传统命令式 Spark 代码的复杂性，显著提升了流式管道的开发和维护效率。它在后台能够自动解释查询、创建依赖图并优化执行计划，并宣称可以减少对 Apache Airflow 等外部编排器的依赖。Spark 声明式管道支持来自 Apache Kafka 等流式数据源的流表，并提供自动更新的物化视图。此外，它还内置了数据质量检查、变更数据捕获（CDC）、批处理与流处理逻辑、重试机制以及可观测性钩子，全面增强了数据处理的可靠性和灵活性。文章引用了早期使用者对 DLT 在效率和数据质量保证方面的积极评价，并指出该特性计划于 2026 年 1 月在 Spark 4.10 版本中正式推出。

💡 主要观点

  1. Databricks 将 DLT 贡献给 Spark，显著简化流式管道开发。 通过引入声明式语法，新特性使开发者无需编写复杂的命令式 Spark 代码，从而大幅降低了构建和维护数据流管道的难度，显著提升了开发效率。
  2. 声明式管道内置高级特性，提升数据处理的可靠性与灵活性。 该特性集成了数据质量检查、CDC、批流一体处理、自动重试和可观测性等功能，全面增强了数据管道的稳定性、适应性和易用性。
  3. 框架自动化优化执行，减少对外部编排器的依赖。 后台自动解释查询、创建依赖图并优化执行计划，有效减少了对 Apache Airflow 等外部编排工具的管理需求，简化了整体数据架构。

💬 文章金句

  • Databricks 宣布将 Delta Live Tables（DLT）背后的技术贡献给 Apache Spark 项目，这个项目中，它将被称为 Spark 声明式管道（Spark Declarative Pipelines）。
  • 这个新特性允许开发人员定义数据流管道，而不需要在 Spark 中创建常见的命令式命令。
  • 有了 DLT，你只需要几个小时就可以构建一个摄取管道，相比之下，开发一个自定义框架需要几天的时间。此外，内置的数据质量保证提供了额外的可靠性层。
  • 声明式管道支持来自流式数据源（如 Apache Kafka 主题）的流表，并为存储聚合和结果提供物化视图。
