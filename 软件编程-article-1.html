腾讯开源 BrowserSkill：让 Agent 复用本地浏览器已登录状态，无缝处理人机验证

9/21/2026, 12:00:06 AM

📌 一句话摘要

腾讯开源的 BrowserSkill 技能让 AI Agent 能直接操作用户本地已登录的浏览器，通过标签页借用和人机交互接管机制，解决跨站重复登录和验证码卡死的问题。

📝 详细摘要

腾讯团队开源了名为 BrowserSkill 的技能，旨在解决 AI Agent 在浏览器自动化中频繁遇到的重复登录和人机验证问题。该工具允许 Agent 直接利用用户电脑上 Chrome 或 Edge 浏览器已登录的标签页进行操作。它会开启一个可见的 Agent 窗口，用户原有的标签页可正常使用；需要时可“借走”特定标签页，用完归还。遇到验证码、登录弹窗等必须人工介入的环节，Agent 会暂停并请用户手动处理，完成后继续。安装极为简便，只需将安装说明丢给 Agent 即可完成配置。该技能支持 Cursor、Claude Code、Codex、OpenClaw、CodeBuddy 等 9 款主流 Agent，适用于 macOS、Linux 和 Windows 系统。

💡 主要观点

  1. 复用本地已登录状态，破解验证难题 Agent 直接操作用户本地 Chrome/Edge 已登录标签页，遇到验证码或登录弹窗时暂停，交由用户手动处理，突破自动化瓶颈。
  2. 标签页借用与并行机制，保障用户正常办公 Agent 窗口与用户标签页分离，仅在明确借用时接管特定标签页，用完归还，确保用户手头工作不受干扰。
  3. 广泛的兼容性与极简安装 支持 Cursor、Claude Code 等 9 款 Agent 及主流操作系统，用户只需将仓库安装说明丢给 Agent，即可自动完成环境配置。

💬 文章金句

  • 它另开一个可见的 Agent 窗口干活，我们手头的标签页照常用。真要碰已经打开的某个标签，得明确借走，用完还回来。
  • 碰到验证码、登录、确认弹窗这种只能人来做的步骤，Agent 会停下来请我们接手，点完它接着往下跑。
