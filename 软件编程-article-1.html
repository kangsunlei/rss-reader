Fleet 1.47 版本发布，支持多行注释折叠、全新 AI 聊天功能及更多增强功能 | Fleet 博客

3/21/2025, 1:48:35 PM

📌 一句话摘要

Fleet 1.47 版本发布，通过引入多行注释折叠、AI 聊天增强等功能，旨在提升开发效率和代码可读性。

📝 详细摘要

JetBrains Fleet 1.47 版本发布，带来多项更新，旨在优化开发体验。主要包括：支持 Java、JavaScript、TypeScript、Kotlin、C#、C++、Python、Swift 和 XML 等语言的多行注释折叠，增强代码可读性；AI 聊天新增网页内容搜索和链接内容提取功能；在编辑器和 Git diff 工具中增加只读指示器，避免误操作；文本搜索预览窗口增加导航栏，显示完整文件路径。此外，该版本还修复了在 Windows 上删除文件、远程工作区设置更改和主题选择等方面的 Bug。这些更新旨在提高开发效率和用户体验。

💡 主要观点

  1. 多行注释折叠提高代码可读性 通过折叠冗长的注释块，开发者可以更专注于代码逻辑，减少视觉干扰，快速定位关键代码段。
  2. AI 聊天功能集成网页搜索能力 开发者可以直接在 IDE (集成开发环境) 中搜索网页内容并提取链接信息，无需切换应用，提高信息检索效率。
  3. 只读指示器提升代码安全性，避免意外修改 在编辑器和 Git diff 工具中清晰显示文件只读状态，有效防止开发者对不可修改的文件进行编辑，减少潜在错误。

💬 文章金句

  • 在此版本中，我们通过引入多行注释折叠功能，增强了代码可读性和导航。
  • 我们在 AI 聊天中引入了两项新功能。现在，您可以直接通过聊天在网络上搜索内容并从链接中检索内容。
  • 为了提高清晰度和可用性，在编辑器或 Git diff 工具中工作时，我们向剪贴板添加了只读指示器。
