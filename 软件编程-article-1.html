Intel DeepMath 推出智能架构，提升 LLM 数学能力

1/5/2026, 9:00:00 PM

📌 一句话摘要

Intel 的 DeepMath 引入了一种新型架构，通过在安全沙箱环境中集成并执行小型 Python 脚本，使 LLM 能够更准确、高效地进行数学推理。

📝 详细摘要

Intel 推出了 DeepMath，这是一个基于 Qwen3-Thinking 构建的轻量级智能体，专门用于增强大语言模型（LLM）的数学推理能力。DeepMath 解决了 LLM 在生成准确数学解法时面临的固有挑战，即通常会产生冗长且错误的算术结果。其创新架构将小型 Python 脚本执行器集成到 LLM 的推理过程中。这些脚本被生成并在安全沙箱中运行，结果会反馈给模型，据报道可减少高达 66% 的错误和输出长度。DeepMath 采用了群体相对策略优化（GRPO）进行微调，这是一种奖励正确答案和代码片段生成、鼓励简洁输出并利用多变温度来平衡探索与熟练度的训练方法。在四个数据集（MATH500、AIME、HMMT、HLE）的评估中，DeepMath 显示出准确率的提升，主要是通过将 LLM 难以处理的确定性计算外包给 Python 执行器。该项目强调了 Python 沙箱的安全考虑，包括严格的模块白名单、执行超时以及受限的文件和网络访问。DeepMath 已在 GitHub 和 Hugging Face 上开源。

💡 主要观点

  1. DeepMath 通过集成 Python 脚本执行器增强 LLM 数学推理。 Intel 的 DeepMath 通过为中间步骤生成并执行小型 Python 脚本来解决 LLM 在数学方面的局限性，与传统的 LLM 输出相比，显著减少了错误和冗余。
  2. 该架构将确定性计算外包给 Python，提高了准确性。 LLM 经常在精确算术上遇到困难。DeepMath 利用 Python 执行器处理这些确定性任务，从而获得更准确的数学结果和更短的推理路径。
  3. DeepMath 使用群体相对策略优化（GRPO）进行微调。 GRPO 训练奖励正确答案和简洁代码片段的生成，促进了高效学习和更好的性能，特别是通过训练期间的多变温度。
  4. Python 执行环境经过安全沙箱化处理。 为了降低安全风险，Python 执行器在安全沙箱内运行，具有受限的模块访问权限、执行超时，且没有文件或网络访问权限，这对于生产部署至关重要。

💬 文章金句

  • DeepMath 基于 Qwen3-4B Thinking 构建，并使用 GRPO（群体相对策略优化）进行微调。该模型不再输出冗长的文本，而是为中间步骤生成微小的 Python 片段，在安全沙箱中运行它们，并将结果折叠回其推理中，从而减少了错误和输出长度。
  • 最显著的收益来自于使用 Python 执行器来卸载 LLM 不擅长的确定性计算，从而由于代码的简洁性减少了算术和数值错误以及路径长度。
  • 用于运行执行器的 Python 环境是沙箱化的，仅允许白名单中的模块。每个片段都受到执行超时的限制，并且不允许任何文件或网络访问。
