如何在 Flutter 中使用 GenUI 构建动态、人工智能驱动的界面

12/23/2025, 5:15:21 PM

📌 一句话摘要

本指南演示了如何使用谷歌的 GenUI SDK，通过一个由 Gemini 模型驱动的圣诞贺卡生成器实例，在 Flutter 中构建动态、人工智能驱动的界面。

📝 详细摘要

本文介绍了 GenUI，这是谷歌为 Flutter 推出的生成式 UI SDK，它允许 AI 根据预定义的组件目录（Catalog）和特定目标动态生成用户界面。与静态 UI 开发不同，GenUI 能够使界面实时适应用户需求。本指南通过构建一个人工智能驱动的圣诞贺卡生成器，详细阐述了 GenUI 的概念模型（如界面区域、状态、对话）以及如何将其组件（GenUiConversation、Catalog、DataModel、ContentGenerator、A2uiMessage）映射到应用程序。它强调 GenUI 帮助 AI 参与到应用程序的状态机中，而不会破坏 Flutter 的规则。本教程提供了分步实现，包括项目设置、依赖管理、API 密钥配置，以及连接 Flutter 与 Firebase AI（Gemini 模型）以生成个性化贺卡的详细代码。它还涵盖了如何将自定义组件集成到 GenUI 目录中，以实现更大的 UI 控制。

💡 主要观点

  1. GenUI 通过组件目录和 AI 指导，在 Flutter 中实现了动态的 AI 驱动 UI 生成。 不同于静态的组件树，GenUI 允许 AI 代理（如 Gemini）根据用户输入和目标，从预定义的目录中选择和组合 UI 组件，从而使界面具有动态性和适应性。
  2. GenUI 架构将 AI 集成到 Flutter 的状态机中，而非取代它。 AI 作为其状态机的参与者与应用程序交互，确保 AI 生成的 UI 符合 Flutter 的渲染规则，并保持应用程序的稳定性和可预测性。
  3. “目录”是关键的设计约束，确保 AI 生成的 UI 保持一致和符合规范。 通过在目录中定义可用的 UI 组件及其属性，开发人员可以指导 AI 生成一致的、可用于生产的界面，并防止 AI“生成不存在或不符合规范的组件”。
  4. 提示工程是指导 GenUI 的 AI 生成所需 UI 元素和内容的关键。 详细的系统指令和动态用户提示允许开发人员精确控制 AI 的输出，从而创建个性化且视觉吸引人的界面。

💬 文章金句

  • 通过谷歌的生成式 UI SDK GenUI，您的应用程序界面将变得动态。您无需硬编码组件树。相反，您向 AI 代理（例如 Google 的 Gemini）提供一个称为目录（Catalog）的 UI 组件“工具包”和一个目标。
  • 在您阅读本指南时，应将 GenUI 理解为一个协作系统，而非一个自主系统。您仍然负责定义 AI 可以使用的目录，审查这些组件的组装结果，并在实际场景中测试生成的界面。
  • GenUI 之所以强大，并非因为它使用了 AI。很多工具都这样做。它之所以强大，是因为 AI 从不违反 Flutter 的规则，因为状态是集中的，渲染是受控的，事件是明确的，并且更新是增量的。
  • 一旦您理解了这个流程，您就不再将 GenUI 视为“AI 生成 UI”，而是开始将其视为 AI 参与您应用程序的状态机。
