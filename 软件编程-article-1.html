Instructed Retriever：解锁搜索智能体中的系统级推理能力

1/6/2026, 8:00:57 PM

📌 一句话摘要

Databricks 推出 Instructed Retriever，这是一种新架构，通过在 RAG 管道中传播系统规范来解锁系统级推理，显著提升搜索智能体的指令遵循能力

📝 详细摘要

本文介绍了 Instructed Retriever，这是一种新颖的检索架构，旨在通过启用系统级推理和全面指令遵循来增强搜索智能体的能力。它通过在整个搜索管道（从查询生成到响应生成）中传播完整的系统规范（包括用户指令、标记示例和索引模式），解决了传统检索增强生成（RAG）的局限性。Instructed Retriever 在复杂的企业问答基准测试中显著提高了检索召回率（比传统 RAG 高 35-50%）和整体响应质量（比简单 RAG 高 70%，比带重排的 RAG 高 15%）。它通过添加查询分解、上下文相关性和元数据推理等能力来实现这一点。文章还重点介绍了新数据集 StaRK-Instruct 的创建，用于评估指令遵循，并展示了即使是通过离线强化学习优化的小型模型，也能在指令遵循方面匹配大型专有模型的性能

💡 主要观点

  1. 传统 RAG 管道无法有效将细粒度用户意图和系统规范转化为精确的搜索查询和强大的指令遵循 现有的 RAG 方法经常忽略关键的系统规范，当涉及复杂指令或异构知识源时会导致不准确或不完整的答案
  2. Instructed Retriever 架构在整个搜索管道（检索和生成）中传播完整的系统规范 这包括用户指令、标记示例和索引描述，使能查询分解、上下文相关性和元数据推理等能力，以实现精确的指令遵循
  3. 与传统 RAG 甚至多步 RAG 智能体相比，Instructed Retriever 显著提高了检索召回率和响应质量 实验显示在 StaRK-Instruct 基准测试中召回率提高 35-50%，在企业 QA 数据集上响应质量提高高达 70%，展示了其在处理复杂指令和异构数据方面的卓越能力
  4. 为 Instructed Retriever 优化的高效小型模型可以实现与大型专有模型相当的性能 使用离线强化学习（TAO 机制），为 Instructed Retriever 开发的 40 亿参数模型几乎匹配了 GPT-5.2 和 Claude-4.5 Sonnet，使其成为企业部署的经济高效选择
  5. 将 Instructed Retriever 集成到多步智能体中进一步提升了性能并减少了任务完成时间 作为 Databricks Agent Bricks Knowledge Assistant 的一部分，它将多步智能体性能提升超过 30%，并将任务完成时间减少 8%，展示了其在复杂智能体工作流程中的价值

💬 文章金句

  • 大多数现有解决方案实际上忽略了这个问题，使用现成的搜索工具。其他解决方案严重低估了这一挑战，仅依赖自定义模型进行嵌入和重排，这些模型在表达能力上存在根本性限制
  • 关键创新在于这种新架构提供了一种简化的方式，不仅能解决用户的即时查询，还能将系统规范的全部内容传播到检索和生成系统组件
  • Instructed Retriever 架构在检索召回率上实现了显著的 35-50% 提升，实证证明了系统级指令感知对查询生成的好处
  • 小型高效模型可以通过优化来匹配大型专有模型的指令遵循性能，使 Instructed Retriever 成为适合现实世界企业部署的经济高效智能体架构
  • 当与 Agent Bricks Knowledge Assistant 集成时，Instructed Retriever 架构直接转化为更高质量、更准确的最终用户响应
