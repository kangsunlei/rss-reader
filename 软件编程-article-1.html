欢迎来到开源世界的“永恒九月”。以下是我们计划为维护者做的事情。

2/12/2026, 8:14:13 PM

📌 一句话摘要

GitHub 正在通过引入新工具和准入机制来应对开源领域的“永恒九月”——即大量低质量、通常由 AI 生成的贡献，从而保护维护者免于职业倦怠。

📝 详细摘要

本文探讨了在 AI 生成的“垃圾内容”和海量贡献时代，维护者可持续性面临的危机。文章指出，虽然降低贡献者的门槛曾是开源运动的主要目标，但由此产生的失衡——即创作成本骤降而审核成本居高不下——正在透支协作所依赖的信任。GitHub 概述了支持维护者的多项策略：包括旨在减少评论噪音的即时 UI 改进、即将推出的限制受信任协作者创建 Pull Request 的仓库级控制，以及对基于标准的准入机制和自动分流工具的长期探索。最终目标是在不将开源项目变成难以进入的“堡垒”的前提下，为维护者提供更好的信号和控制力。

💡 主要观点

  1. 开源正面临“永恒九月”，贡献量已超过审核能力。 由于生成式 AI 的出现，生成代码和 Issue 的成本大幅下降，导致大量低质量贡献涌入，使维护者不堪重负，并动摇了信任基础。
  2. 摩擦力是维持社区质量和参与度的必要过滤器。 虽然降低准入门槛在历史上具有积极意义，但目前缺乏摩擦力导致了“AI 垃圾内容”和自动化噪音的泛滥，因此有必要重新平衡贡献与审核所需的精力。
  3. GitHub 正在转向为维护者提供对其贡献工作流更细粒度的控制。 仓库级 PR 限制、交互限制和基于标准的准入机制等新功能，允许维护者优先处理受信任的协作者，并减轻分流低价值噪音的负担。
  4. 开源软件维护的未来涉及基于信任的系统和自动化分流工具。 GitHub 正在探索实验性模型，如声誉评分和基于项目指南的自动评估，以帮助维护者更高效地识别高价值贡献，而无需手动审核每一项提交。

💬 文章金句

  • 创作成本已经下降，但审核成本却没有。
  • 开放协作建立在信任之上。长期以来，这种信任受到一种天然但并不完美的过滤器保护：摩擦力。
  • 如果我们只建立屏蔽和禁令，我们创造的是堡垒，而不是集市。
  • 维护者经常提出同样的问题：“你真的在试图帮助我，还是只是在帮你自己？”
  • 维护者的可持续性是开源的基石，也是我们的基石。
