📝 详细摘要

本期 Node 中文周刊涵盖了 Node.js 生态的多项重要动态。Express 完成了品牌重塑，网站和文档全面更新，重回前沿。npm 引入了阶段性发布机制，为包上线前提供审核期，以提升供应链安全。Node.js 26.2.0 发布，stream.compose 标记为稳定，并新增对 Temporal.Instant 的支持。TypeORM 在 0.3.x 多年后终于发布 1.0 版本，带来了清理和现代化工作。此外，周刊还收录了 TanStack 供应链攻击后的加固措施、Yelp 从 Webpack 迁移到 Rspack 的实践、官方 Axios 迁移到 fetch 的 Codemod 工具、以及 Bun 的 Zig 到 Rust 移植等话题。整体上，本期内容聚焦于 Node.js 生态的工具演进、安全实践和性能优化。

💡 主要观点

  1. Express 完成品牌重塑，网站和文档全面更新。 Express.js 在经历了一段时间的沉寂后，于 2024 年开始大规模重振，此次品牌更新标志着其重回 Node.js Web 框架前沿的决心。
  2. npm 引入阶段性发布机制，提升包安全性。 npm 11.15.0 发布了阶段性发布模式，允许在包正式上线前设置审核期，有助于缓解供应链攻击风险，是 npm 安全策略的重要演进。
  3. TypeORM 1.0 正式发布，带来多项现代化改进。 经过多年 0.3.x 版本的迭代，TypeORM 1.0 带来了代码清理、INSERT INTO ... SELECT 支持、跨驱动事务隔离级别等新特性，是 TypeScript ORM 生态的重要里程碑。

💬 文章金句

  • Express 全新面貌与品牌重塑 --- 一段时间以来，Node 历史悠久的 Web 框架 Express.js 看起来有些过时，Fastify 等项目开始接过接力棒，但 2024 年开始的大规模重振 让 Express 重回前沿。
  • npm 引入阶段性发布机制 --- 在首次预告几个月后，npm 发布了新的「阶段性发布」模式，在包正式上线前提供审核期。
  • TypeORM 1.0：DataMapper 和 ActiveRecord ORM --- 流行的 TypeScript 优先 ORM 支持所有主要关系数据库，在 0.3.x 上经过多年后达到 1.0，带来了清理和现代化工作。
