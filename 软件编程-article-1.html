Vercel 推出 Drains 统一数据导出方案

10/4/2025, 4:35:00 PM

📌 一句话摘要

Vercel Drains 将日志、追踪、分析和指标统一到一个流式机制中，实现向外部可观测性服务的无缝导出。

📝 详细摘要

Vercel 推出了 'Vercel Drains'，旨在简化从其平台导出可观测性数据。该系统整合了运行时、构建、防火墙、函数日志，以及兼容 OpenTelemetry 的追踪数据、Web 分析事件（页面浏览量、自定义事件）和 Speed Insights 指标（Core Web Vitals）等多种数据类型。Vercel 的一个关键优势是其自动化的日志条目丰富功能，使用 traceId 和 spanId 链接日志和追踪，无需任何手动设置。Drains 支持自定义 HTTP 端点以实现灵活配置，并直接与主要可观测性供应商集成，例如 Datadog、Honeycomb、Grafana Tempo 和 New Relic。这项创新解决了可观测性流水线中常见的碎片化问题，使团队能够减少基础设施管理开销，并更多地关注数据分析。这使得在监控工具之间切换变得更加容易。

💡 主要观点

  1. Vercel Drains 将各类可观测性数据整合至统一的流式导出机制中。 该系统整合了日志、分布式追踪、Web 分析事件和性能指标，简化了数据收集并减少了监控流水线中的碎片化。
  2. 它简化了与外部可观测性供应商的集成，并支持 OpenTelemetry 标准。 Drains 提供灵活的 HTTP 配置和直接集成，提供兼容 OpenTelemetry 的追踪数据，从而增强了与现有监控栈的兼容性和厂商无关的灵活性。
  3. 该功能减少了基础设施管理开销，并增强了开发者工作流。 通过自动化数据丰富（例如，链接日志和追踪）和整合导出，团队花费更少的时间在设置和维护上，从而可以更多地关注分析和开发。

💬 文章金句

  • 该功能将日志、分布式追踪、Web 分析事件和性能指标统一到一个单一的流式机制中。
  • 由于 Vercel 控制从客户端到无服务器执行的请求路径，因此该平台会自动使用 traceId 和 spanId 丰富日志条目，无需额外设置即可链接日志和追踪。
  • 新一代可观测性体验！追踪、分析、日志的统一同步，加上一键导出？这绝对会革新开发者工作流。
  • Vercel Drains 提供实时的可观测性数据，可供您在选择的工具中使用。这是因为企业通常拥有多个团队和多种工具，需要不同维度的数据。
  • 通过将指标、日志和追踪整合到一个导出层中，团队可以减少在基础设施管理上的时间，而将更多时间用于分析。
