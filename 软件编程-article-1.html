GPT-5.6 三档模型全面围剿 Claude Fable 5

7/10/2026, 1:21:00 AM

📌 一句话摘要

OpenAI 推出 GPT-5.6 三档模型（Sol、Terra、Luna），在编程、Agent 任务执行、成本效率等方面全面超越 Claude Fable 5，并公布详细定价与安全评估。

📝 详细摘要

文章报道 OpenAI 于 2026 年 7 月发布 GPT-5.6 系列模型，包括旗舰版 Sol、均衡版 Terra 与轻量版 Luna，分别在智能水平、性价比与成本效率上树立新标准。通过对比 Fable 5 与 Opus 4.8 的公开基准，展示其在编程、代理任务、推理模式及安全防护等维度的显著提升；同时公布每百万 Token 的输入输出价格、缓存机制及多智能体协作的 ultra 模式，并说明其在内部研发、代码产出与 Agent 使用量激增中的落地效果。文章还讨论了模型对安全评估的加强、对用户提示词的新建议以及对 ChatGPT Work 超级应用的展望，指出其在降低单位成本、提升任务效率方面的商业价值。

💡 主要观点

  1. GPT-5.6 Sol 在编程与 Agent 任务上超越 Fable 5，完成时间减半、成本降至四分之一。 在 Artificial Analysis Coding Agent Index v1.1 中得分 80 分，超越 Claude Fable 5 2.8 分，输出 Token 量仅其一半，整体成本降低约三分之一，且在 Terminal‑Bench 2.1、DeepSWE v1.1 等测试中同样刷新最高分。
  2. 三档模型提供分层定价与缓存机制，显著降低使用成本。 Sol 5 美元/百万输入，30 美元/百万输出；Terra 2.5 美元/百万输入，15 美元/百万输出；Luna 1 美元/百万输入，5 美元/百万输出；新增显式缓存断点与 30 分钟缓存生命周期，读取缓存仅付 10% 输入价，整体单位成本可降至传统模型的四分之一。
  3. 多智能体协作的 ultra 模式提升复杂任务质量。 通过 Responses API 的程序化工具调用，GPT-5.6 可自动过滤中间数据、动态调整工作流，并在 ultra 模式下动员 4 个智能体并行处理，显著提升复杂任务的完成质量与速度，同时消耗更多 Token。
  4. 安全防护体系全面升级，但未达关键风险阈值。 OpenAI 进行规模最大安全评估，投入约 70 万 A100e GPU 小时进行红队测试，强化模型内置安全训练、实时检测与访问控制；在 ExploitBench2、ExploitGym 等测试中性能提升，但在生物与网络安全攻击能力仍未达到关键风险水平。

💬 文章金句

  • 这意味着更高的单位成本性能（performance per dollar）：用户可以用相同预算完成更多工作，也可以用更低成本获得接近的结果。
  • 这无疑是我们有史以来最出色的作品了。
  • GPT-5.6 同时引入了更可预测的 Prompt 缓存机制，包括支持显式缓存断点以及最低 30 分钟的缓存生命周期。
  • 在内部的 Agents' Last Exam 测试中（该测试用于评估覆盖 55 个专业领域的长期运行工作流能力）GPT-5.6 Sol 创下新的最高分：53.6 分。
