Next.js 15.3

4/9/2025, 8:00:00 PM

📌 一句话摘要

Next.js 15.3 发布，包含 Turbopack 构建加速、客户端监控、导航钩子及 TypeScript 插件性能优化。

📝 详细摘要

Next.js 15.3 版本带来了多项重要更新。最显著的是 Turbopack 构建工具的 alpha 版本，它能显著提升生产环境的构建速度。此外，新版本还引入了客户端 Instrumentation Hook，方便开发者在应用启动之初设置监控和分析。Navigation Hooks 允许开发者更精细地控制客户端路由行为。TypeScript 插件的性能也得到了显著提升，尤其是在大型代码库中。同时，社区对 Rspack 的支持也为需要 Webpack 兼容的 Next.js 用户提供过渡方案。这些更新旨在提升开发效率、改善应用性能并增强开发者工具。

💡 主要观点

  1. Turbopack 构建工具显著提升 Next.js 应用的构建速度 Turbopack 在多核 CPU 上表现出更强的性能，与 Webpack 相比，构建速度提升显著，尤其是在大型项目中。
  2. 客户端 Instrumentation Hook 便于开发者尽早集成监控与分析工具 通过在应用启动前运行监控代码，开发者可以更全面地了解应用性能，及时发现并解决潜在问题。
  3. Navigation Hooks 提供了更灵活的客户端路由控制能力 开发者可以使用 onNavigate 和 useLinkStatus 等 API，实现自定义加载状态和更复杂的导航控制逻辑。

💬 文章金句

  • Over 50% of development sessions on Next.js 15 are now using Turbopack.
  • One advantage of Turbopack's architecture versus our previous Webpack implementation is that performance scales when adding CPU cores
  • The LSP provides inline Intellisense features such as server/client boundary validation， component prop hints， configuration autocompletion， and error detection for disallowed APIs in React Server Components.
  • `next build --turbopack`
