用 Rust 写了一个 OKX v5 API SDK，附带实时行情终端 🦀

6/20/2026, 4:48:17 PM

📌 一句话摘要

作者因不满现有 OKX Rust SDK，自研了一个全类型化、异步优先的 v5 REST + WebSocket SDK，并附带一个终端行情工具。

📝 详细摘要

本文作者在加密量化学习过程中，发现现有 OKX Rust API 客户端库（尤其是 WebSocket 方面）不满足需求，因此借助 AI 开发了 rust-okx 项目。该 SDK 的核心设计原则是「不手动解析 JSON」，所有请求和响应都有对应的 Rust 类型，在编译期即可发现问题。文章列举了其主要特性：全类型化、基于 tokio + reqwest 的异步优先、模拟盘支持、多地区切换、WebSocket 实时推送以及可替换的 Transport 层。为了验证 SDK 功能，作者还开发了一个 TUI 终端行情工具 okx-cli，支持 K 线图、实时成交、挂单列表、账户余额和快速下单。文章最后给出了安装命令和 GitHub 仓库链接，并说明项目处于早期阶段，欢迎贡献。

💡 主要观点

  1. 自研全类型化 OKX v5 Rust SDK，解决现有库不足。 作者因找不到满意的 OKX Rust 客户端库，尤其是 WebSocket 方面，决定自研一个全类型化、异步优先的 SDK，避免手动解析 JSON 带来的运行时错误。
  2. SDK 设计强调编译期安全与异步性能。 通过为所有请求和响应定义 Rust struct，在编译期就能发现类型错误；基于 tokio + reqwest 实现异步优先，适合高性能量化场景。
  3. 附带终端行情工具，验证 SDK 可用性。 作者开发了 okx-cli TUI 工具，支持 K 线图、实时成交、挂单列表等，既作为 SDK 的演示，也为用户提供了可直接使用的命令行行情终端。
