TinyShip 里程碑更新：新增 SQLite 与 Cloudflare D1 支持，全面适配 Cloudflare 环境

5/3/2026, 12:47:55 PM

📌 一句话摘要

TinyShip 框架迎来里程碑更新，新增 SQLite 与 Cloudflare D1 数据库支持，实现 All in Cloudflare 部署，并支持通过 Cloudflare Email 发送邮件。

📝 详细摘要

独立开发者 Viking 宣布其 SaaS 模板框架 TinyShip 迎来重大更新，核心是数据库能力升级，新增对 SQLite 和 Cloudflare D1 的支持。这意味着 TinyShip 现已完全适配 Cloudflare 环境，基于 TanStack App 构建的项目可以直接在 Cloudflare Workers 中部署，并使用 D1 数据库和 Cloudflare Email 服务。作者强调这并非 Vendor Locking，而是体现了框架的可扩展性。推文还提及使用 HyperFrame 制作了更新演示视频。结合被引用的原始发布推文，TinyShip 是一个支持 Next.js 和 Nuxt.js 双框架、兼顾国内（微信支付/登录）和出海（Stripe/OAuth）双市场的 SaaS 启动模板。
