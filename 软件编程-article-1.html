Cloudflare Wrangler 新增 Local Explorer，本地可视化与 AI Native 支持

4/14/2026, 1:34:44 PM

📌 一句话摘要

Cloudflare Wrangler 的 Local Explorer 功能允许开发者在本地 Web 界面可视化操作 KV、R2、D1 等资源，并暴露 OpenAPI 规范供 AI Agent 调用。

📝 详细摘要

这是对前一条推文的引用和补充。作者详细介绍了 Cloudflare 新版 Wrangler 中一个名为 Local Explorer 的具体功能。该功能解决了过去 `wrangler dev` 运行时本地资源（如 KV、R2、D1、Durable Objects）不可见的痛点，现在可以通过一个本地 Web 应用像操作生产环境 Dashboard 一样浏览和操作这些数据。更重要的是，它暴露了本地的 OpenAPI 规范，使得 AI Agent 能够读取并理解当前 Worker 有哪些可用资源，进而通过 HTTP 调用进行操作，作者认为这体现了 AI Native 的设计理念。推文鼓励开发者更新并体验此功能。
