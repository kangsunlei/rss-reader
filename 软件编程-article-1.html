Salesloft Drift 漏洞对 Cloudflare 及其客户的影响

9/2/2025, 6:10:01 PM

📌 一句话摘要

Cloudflare 详细介绍了通过 Salesloft Drift 发起的复杂供应链安全漏洞，该漏洞影响了 Salesforce 客户支持数据。文章概述了 Cloudflare 的响应措施，并提供了关键的安全建议。

📝 详细摘要

这篇来自 Cloudflare 的文章详细介绍了一起涉及 Salesloft Drift 聊天机器人集成的供应链安全漏洞，该漏洞导致 Cloudflare 的 Salesforce 实例被入侵。一个被归类为 GRUB1 的威胁行动者窃取了客户联系信息和支持案例文本，可能包括像 API 密钥这样的敏感数据。文章提供了从初始侦察到数据泄露和掩盖的详细攻击时间线。Cloudflare 迅速采取了全面的响应措施，包括：立即进行威胁遏制；保护第三方生态系统；保护更广泛的系统；以及进行客户影响分析。作为响应的一部分，Cloudflare 轮换了 104 个暴露的 API 密钥。该公司强调，没有 Cloudflare 服务或基础设施受到损害。最后，它为所有组织提供了可行的建议，以减轻类似的威胁，例如断开 Salesloft 应用程序的连接，轮换凭据，实施最小权限原则以及加强监控。

💡 主要观点

  1. 通过 Salesloft Drift 发起的复杂供应链安全漏洞破坏了 Salesforce 实例，包括 Cloudflare 的实例。 威胁行动者 GRUB1 利用来自 Salesloft Drift 集成的受损 OAuth 凭证来访问和窃取 Salesforce 中的客户支持案例数据，影响了全球数百个组织。
  2. 泄露的数据包括客户联系信息和支持案例文本，以及潜在的敏感凭据。 虽然附件没有受到损害，但支持案例的自由文本字段（客户有时会在其中共享令牌或日志以进行故障排除）已暴露，因此需要进行凭据轮换。
  3. Cloudflare 实施了强大的多阶段事件响应，确保没有核心服务受到损害。 响应包括立即进行威胁遏制，保护第三方集成，保护内部系统以及彻底的客户影响分析，从而轮换所有已识别的受损 API 密钥。
  4. 组织必须对第三方 SaaS 集成采取严格的安全措施，以防止类似的漏洞。 主要建议包括断开受损集成的连接，频繁轮换凭据，实施最小权限原则，审查支持数据以查找暴露情况以及加强对异常情况的监控。

💬 文章金句

  • 鉴于 Salesforce 支持案例数据包含与 Cloudflare 的支持工单的内容，客户可能已通过我们的支持系统与 Cloudflare 共享的任何信息（包括日志、令牌或密码）都应被视为已泄露。我们强烈建议您轮换您可能通过此渠道与我们共享的任何凭据。
  • 我们的调查显示，这是一起针对企业对企业第三方集成的复杂供应链攻击的一部分，影响了全球数百家 Salesloft 客户。
  • 作为此次漏洞的结果，没有 Cloudflare 服务或基础设施受到损害。
  • 此事件凸显了在保护软件即服务(SaaS)应用和其他第三方集成方面提高警惕的迫切需要。
