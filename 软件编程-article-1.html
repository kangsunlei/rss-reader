统一的 IntelliJ IDEA：更多免费功能，更佳体验，更流畅的工作流程

12/8/2025, 10:45:57 AM

📌 一句话摘要

JetBrains 将 IntelliJ IDEA 的社区版和旗舰版整合为单一产品，集成了更多免费功能，旨在提升质量、促进创新，同时坚守其对开源的承诺。

📝 详细摘要

JetBrains 宣布，自 2025.3 版本起，IntelliJ IDEA 将合并为一个统一的产品，取代此前的独立社区版和旗舰版。这一变动旨在简化用户选择，提升产品质量，并集中资源推动创新。文章强调，所有社区版功能将继续免费，并新增了免费功能，包括 Spring 和 Jakarta EE 的基本语法高亮、Spring Boot 项目向导以及增强的数据库支持。旗舰版订阅将提供扩展工具集，并有 30 天免费试用期。此次统一预计将为所有用户带来更高质量的产品，为现有和新用户提供更流畅的体验和升级路径，同时继续支持教育用户和开源社区。JetBrains 强调，通过整合资源和简化分发，他们可以更好地专注于集成开发环境的性能优化和新功能开发，以满足开发者的需求。

💡 主要观点

  1. IntelliJ IDEA 的产品线统一旨在简化用户选择并提升产品质量。 社区版和旗舰版合并为一个产品，消除了用户在不同版本之间做出选择的需要。JetBrains 现在可以将研发资源集中于单一产品，加速功能迭代和错误修复，并通过提升性能和推动创新，提供卓越的 IDE 体验。
  2. 众多高级功能现已免费提供，降低了入门门槛并增加了实用性。 随着统一，以前旗舰版独有的功能，如 Spring/Jakarta EE 语法高亮、Spring Boot 向导和高级数据库功能，现在在免费层级中也可使用。这为免费用户，尤其是在 Java 和 Kotlin 开发中，提供了更全面的开发支持，无需任何授权或激活即可增强日常开发的便利性。
  3. JetBrains 通过维护社区版代码库并支持 GitHub Action 构建，重申其对开源的承诺。 JetBrains 明确表示，将继续维护并使 IntelliJ IDEA 的开源代码库在 GitHub 上与未来的版本保持同步。这一承诺确保了开源生态系统的持续发展，允许社区参与和自定义构建，包括支持来自 JetBrains Marketplace 的插件。

💬 文章金句

  • IntelliJ IDEA 现在是一个统一的产品！社区版的所有功能仍可免费用于非商业和商业用途。
  • 通过统一 IntelliJ IDEA，我们可以集中精力提升单一产品的质量，提高性能，并推动创新，为您提供最好的 IDE。
  • 我们完全致力于开源，并将保持 IntelliJ IDEA 在 GitHub 上的代码库最新并对所有人开放。
