GitHub Copilot：全新代理面板，随时随地委托任务

8/19/2025, 7:55:16 PM

📌 一句话摘要

GitHub 推出 Copilot 全新代理面板，让开发者能够在 GitHub 的任何页面上委托编码任务，并由 AI 自动创建拉取请求以供审查。

📝 详细摘要

这条推文宣布了 GitHub Copilot 的一项重要新功能：代理面板。这个面板允许开发者直接从 GitHub 内的任何页面将特定的编码任务委托给 GitHub Copilot 代理。用户只需提供一个提示，AI 代理便会在后台自动完成任务，并创建一个拉取请求 (PR) 供开发者审核。此举旨在减少开发过程中的干扰，并通过自动化日常编码任务来优化开发工作流程，标志着 AI 驱动的开发者工具的演变。
