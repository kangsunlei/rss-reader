📌 一句话摘要

本文介绍一个基于通达信协议的开源 Python 工具 easy-tdx，为 AI Agent 提供免费、无注册的 A 股/港股/美股/期货行情数据与缠论分析能力。

📝 详细摘要

文章介绍作者开源的 easy-tdx 工具，它通过通达信协议获取金融行情数据，无需注册、无需 API Key、完全免费。工具支持 A 股、港股、美股、期货的 K 线、实时报价、分时明细、逐笔成交、资金流向等数据，内置 32 个技术指标计算与缠论分析（K 线合并→分型→笔→中枢→线段→买卖点→背驰）。所有命令默认输出 JSON，Python API 返回 DataFrame，可直接接入 Claude Code、OpenClaw 等 AI Agent 工作流。还支持离线读取通达信本地 .day 文件、全市场数据同步、自动选服务器等功能。项目采用 MIT 协议完全开源。

💡 主要观点

  1. easy-tdx 通过通达信协议提供免费、无注册的行情数据，降低散户数据获取门槛。 工具直接对接通达信行情服务器，无需任何注册或付费，即可获取 A 股、港股、美股、期货的 K 线、实时报价等数据，解决了散户与机构之间的数据不对称问题。
  2. 工具原生支持 JSON 输出与 Python DataFrame，天然适配 AI Agent 工作流。 所有命令行默认输出 JSON，Python API 返回 DataFrame，无需解析网页或处理 API 鉴权，可直接将数据喂给 LLM 或 Agent 做分析决策。
  3. 内置缠论分析与 32 个技术指标，提供从数据到分析的完整链路。 除基础行情数据外，工具还集成了 MACD、KDJ、RSI 等常见技术指标计算，以及完整的缠论分析流程（K 线合并→分型→笔→中枢→线段→买卖点→背驰），一键输出结果。
