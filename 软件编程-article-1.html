WinToastRelay – 将 Windows 系统通知转发到手机｜Codex 跑完，手机会叫你

9/6/2026, 4:09:36 PM

📌 一句话摘要

WinToastRelay 可将 Windows 系统通知实时转发到手机，支持 Bark、WxPusher、ntfy 和 Webhook 等多种渠道，让 Codex 等长时间任务完成后自动推送提醒。

📝 详细摘要

文章介绍了一款名为 WinToastRelay 的开源工具，由开发者 @RavelloH 提交至发现频道。该工具的核心功能是将 Windows 系统通知实时转发到手机，解决了用户在电脑前执行长时间任务（如运行 Codex）时无法随时查看进度、又忍不住频繁返回查看的问题。工具支持 Bark、WxPusher 等主流推送服务，也提供 Webhook 接口供自定义接入。针对不同平台，作者给出了推荐配置：iOS 首选 Bark，原生支持且功能完善；Android 则推荐 WxPusher，可适配国内厂商推送，或在已有服务上通过 ntfy/Gotify 自托管实现。工具内存占用约 14MB，从微软商店或 GitHub 均可获取。文末还整理了移动端可用的通知接收应用清单。

💡 主要观点

  1. WinToastRelay 将 Windows 通知实时转发至手机端 工具监听 Windows 系统通知并将其推送到 Bark、WxPusher 或 Webhook，实现任务完成/失败时手机即时收到提醒，适合 Codex 等长时间运行场景。
  2. 平台差异化推荐配置 iOS 用户建议使用 Bark，原生支持且功能完善；Android 用户推荐使用 WxPusher，可适配国产厂商推送，或通过 ntfy/Gotify 自建服务实现通知接收。
  3. 适用于任意发送系统通知的应用 不仅限于 Codex，任何会触发 Windows 通知的桌面软件均可通过 WinToastRelay 转发，扩展了工具的通用性。
  4. 轻量且多通道获取 工具后台内存占用约 14MB，提供微软商店和 GitHub 双渠道获取，便于不同习惯的用户安装。

💬 文章金句

  • WinToastRelay 就是单纯的将 Windows 通知实时转发到 Bark、WxPusher 或 Webhook 等渠道。
  • 不止是 Codex，只要发送系统通知的软件，都可以。
  • 建议在 CodeX 设置中打开始终通知，防止 CodeX 在前台就不发送通知了。
  • 软件在后台需要大概 14 MB 内存，请确保你的电脑具有至少 20 MB 可用运行内存。
