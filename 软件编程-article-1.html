VisualStudio.Extensibility：编辑器分类与用户提示增强

5/27/2025, 4:00:42 PM

📌 一句话摘要

Visual Studio Extensibility SDK v17.14 引入编辑器分类和增强的用户提示功能。

📝 详细摘要

本文详细介绍了 Visual Studio Extensibility SDK 17.14 版本的新功能，重点是通过进程外执行提升性能和可靠性。主要新增功能包括编辑器中的文本分类支持，用于语义和语法着色，构建于之前的标记器功能之上。本文提供了一个 C# 代码片段，演示如何创建分类标签。此外，`ShowPromptAsync` API 得到增强，支持图标和用户输入提示，以满足社区需求。代码片段演示了新 API 的用法，包括默认文本、图标和标题等选项。文章还提到了关于 .NET 运行时管理的变更，使 SDK 的生命周期与 .NET LTS 更新保持一致。提供了指向文档、GitHub 仓库、问题跟踪器、示例和视频系列的链接，方便开发者上手并提供反馈。

💡 主要观点

  1. VisualStudio.Extensibility SDK 采用进程外运行，以获得更好的性能。 在主 IDE 进程之外运行扩展可以提高稳定性和安装效果，而无需 IDE 重启，这是优于传统 VSSDK 的关键优势。
  2. 17.14 版本新增编辑器文本分类功能。 基于之前的标记器支持，此功能允许开发人员在 Visual Studio 编辑器中实现自定义语义和语法文本着色。
  3. ShowPromptAsync API 现在支持图标和用户输入。 为了响应社区反馈，增强的 API 提供了更灵活的选项，用于创建具有视觉提示和数据收集功能的用户提示。
  4. SDK 的 .NET 运行时管理遵循 .NET LTS 生命周期。 VisualStudio.Extensibility 扩展依赖于单独的 .NET 运行时宿主，需要定期更新以与 .NET LTS 服务模型保持一致。

💬 文章金句

  • VisualStudio.Extensibility 帮助您构建在主 Visual Studio IDE 进程之外运行的扩展，从而提高性能、可靠性和安装效果，而无需重启 Visual Studio。
  • 此增强为 17.14 版本引入的文本分类功能奠定基础。
  • 文本分类支持自定义文本着色，也称为语义和语法着色。
  • 17.14 版本中，我们很高兴地宣布，ShowPromptAsync API 新增图标支持，以满足社区需求。
