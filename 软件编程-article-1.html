分享我的 macOS 输入法切换工具，专门适配了 AI Coding 场景

6/6/2026, 7:58:57 AM

📌 一句话摘要

本文介绍一款为 AI Coding 场景专门适配的 macOS 输入法自动切换工具，通过细粒度规则实现中英文无感切换。

📝 详细摘要

作者分享了自己开发的 macOS 输入法自动切换工具 AutoSwitch，针对 AI Coding 场景做了专门优化。文章指出市面主流工具大多只能实现 App 级别的输入法切换，且稳定性不足。作者的做法是增加更细粒度的规则：在 Codex、Claude Code 或终端内，当需要输入 /usage 等命令或 Skill 时自动临时切换到英文模式，输入完成后按回车、空格或 Tab 自动切回中文。终端内识别到命令提示符时也会默认切英文。此外还提供兜底规则：通过 Shift 临时切英文后，若 X 秒内无输入则自动切回中文，且切换 App 时会自动清空临时状态。

💡 主要观点

  1. 针对 AI Coding 场景设计细粒度输入法切换规则。 在 Codex、Claude Code 或终端内，输入命令时自动临时切英文，按回车/空格/Tab 后自动切回中文，实现无感切换。
  2. 终端命令提示符识别与兜底超时机制。 识别到终端命令提示符时默认切英文；通过 Shift 临时切英文后，若 X 秒无输入则自动切回中文，且切换 App 时自动清空临时状态。
  3. 工具定位为简洁稳定，去除了不必要的花哨功能。 作者认为市面工具功能冗余且稳定性不足，因此开发了更简洁的版本，专注解决 AI Coding 场景的核心痛点。

💬 文章金句

  • 当我们在 Codex、Claude Code 或终端软件内，需要输入 /usage 这类命令，或者输入一些 Skill 时，可以自动临时切换到英文模式。
  • 按回车、空格或 Tab，都能自动切换回中文。因为这些本来就是 AI Coding 场景里常见的调用结束符，所以不需要额外的认知和记忆负担。
