Introducing BigQuery managed and SQL-native inference for open models

1/16/2026, 12:00:00 AM

📌 一句话摘要

BigQuery now offers managed and SQL-native inference for open models from Hugging Face and Vertex AI Model Garden， streamlining deployment， management， and cost control directly within SQL.

📝 详细摘要

This article introduces BigQuery's new managed inference capability for open models， allowing users to run models from Hugging Face or Vertex AI Model Garden directly within BigQuery using SQL. This feature simplifies deployment with a single `CREATE MODEL` statement， automates resource management (including idle resource release)， offers granular control over backend compute resources， and provides a unified SQL interface for the entire model lifecycle. The article provides practical examples for creating and utilizing both embedding and text generation models， and details options for automated and manual cost control like `endpoint_idle_ttl` and `ALTER MODEL` statements， ensuring that all associated Vertex AI resources are cleaned up upon model deletion. This development aims to remove operational friction and make powerful open models accessible to BigQuery users from data analysts to AI/ML engineers.

💡 主要观点

  1. BigQuery now supports managed and SQL-native inference for open models from Hugging Face and Vertex AI Model Garden. This feature extends BigQuery's existing LLM capabilities (Gemini， partner models) to a broader range of open models， allowing their integration directly into SQL workflows.
  2. The new capability simplifies deployment and automated resource management for open models via SQL. Users can deploy models with a single `CREATE MODEL` statement， which automatically provisions compute resources and de-provisions idle resources to manage costs， enhancing operational efficiency.
  3. Granular resource control and a unified SQL interface are key benefits. Users can customize machine types and replica counts within `CREATE MODEL` and manage the entire model lifecycle—from creation and inference to cost control and cleanup—using SQL directly in BigQuery.
  4. Practical examples demonstrate creating embedding and text generation models and performing inference using SQL. The article illustrates how to define models from Hugging Face or Vertex AI Model Garden and run batch inference using `AI.GENERATE_EMBEDDING` or `AI.GENERATE_TEXT` functions.

💬 文章金句

  • Today， we are bringing this same simplicity and power to any model you may choose from Hugging Face or Vertex AI Model Garden.
  • With the launch of managed third-party generative AI inference in BigQuery (Preview)， you can now run open models using just two SQL statements.
  • BigQuery's new managed inference capability for 3P models fundamentally changes how data teams access and use third-party gen AI models.
  • By consolidating the entire model lifecycle management into a familiar SQL interface， we're removing the operational friction and making powerful open models accessible to every BigQuery user， from data analysts to AI/ML engineers.
