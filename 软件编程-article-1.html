漏洞透明性：通过负责任披露提升安全性

5/16/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 承诺提升漏洞透明性和负责任披露，具体行动包括加入 CISA 的 Secure by Design 承诺并详细介绍 CVE 发布流程。

📝 详细摘要

本文阐述了 Cloudflare 通过漏洞透明性加强网络安全的承诺，重点是他们参与 CISA 的 "Secure by Design" 承诺。文章强调，公开披露漏洞对于建立信任和加深对安全问题的共同认知至关重要。文章定义了关键概念，如常见漏洞与暴露 (CVE) 和 CVE 编号授权机构 (CNA)，解释了 Cloudflare 自 2009 年以来作为 CNA 的角色。文章概述了 Cloudflare 发布和披露 CVE 的内部流程，特别是对于开源和分布式闭源产品，以及补救后典型的 90 天披露时间表。文章提供了 Cloudflare 处理的几个值得注意的 CVE 示例，包括其 quiche 库、WordPress 插件和 WARP 客户端中的问题，展示了所披露的漏洞类型。文章最后鼓励其他组织采用 "Secure by Design" 承诺，并强调漏洞透明性是一项需要持续投入技术资源和优化流程的可持续努力。

💡 主要观点

  1. Cloudflare 承诺通过 CISA 的 "Secure by Design" 承诺来加强安全透明性。 加入该承诺标志着 Cloudflare 采取的具体步骤，以符合网络安全最佳实践并促进漏洞管理方面的开放性，有助于增强客户和社区的信任。
  2. 漏洞报告的透明性是信任和集体安全的基础。 明确披露漏洞的性质、影响和解决方案有助于建立与客户的信任，并有助于加深对数字生态系统安全风险的认识。
  3. Cloudflare 作为 CVE 编号授权机构 (CNA)，制定了明确的披露流程。 作为 CNA，Cloudflare 为其范围内的漏洞分配和管理 CVE，遵循结构化的内部评估，并力争在补救后 90 天内披露。
  4. Cloudflare 披露影响其产品和开源贡献的漏洞。 例如，Cloudflare 针对 quiche 库、WordPress 插件和 WARP 客户端等不同类型的漏洞，采取了发布 CVE 或提供替代披露等措施。

💬 文章金句

  • CISA 的 Secure by Design 承诺的核心目标之一，就是大力推动漏洞报告的透明化。
  • 我们坚信，对漏洞保持开放透明的态度，是赢得并维护客户、合作伙伴及整个安全社区信任的关键。
  • 作为授权的 CVE 编号授权机构 (CNA)，Cloudflare 可以为在我们产品和生态系统中发现的漏洞分配 CVE 标识符。
  • 我们的标准披露时间表在 90 天内。此时间表使我们能够确保适当的补救、彻底的测试以及与相关方的负责任协调。
