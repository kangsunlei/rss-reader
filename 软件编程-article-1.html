Databricks 发布流表和物化视图共享公开预览版

4/25/2025, 6:45:00 PM

📌 一句话摘要

Databricks 推出流表和物化视图共享的公开预览版，旨在提升实时数据共享的效率和降低成本。

📝 详细摘要

Databricks 宣布公开预览流表和物化视图共享功能。流表持续摄取流数据，非常适合实时数据管道，而物化视图通过预计算提升 SQL 分析和 BI 仪表板性能。共享流表使数据接收者无需复制管道即可访问实时数据。例如，零售公司可以通过 Delta Sharing 与物流合作伙伴共享实时销售数据。数据提供商通过 Unity Catalog 的细粒度权限实现完全访问控制，从而促进跨平台数据共享。

💡 主要观点

  1. 流表非常适合构建实时数据管道，能够持续摄取和处理流数据。 流表持续摄取流数据，非常适合需要实时处理和分析的场景，例如日志、事件或传感器数据。
  2. 物化视图通过预计算来提高性能。 物化视图预先计算并存储查询结果，从而减少查询时间，特别是在需要重复访问相同数据的 SQL 分析和 BI 仪表板中。
  3. Delta Sharing 允许跨平台访问流表。 通过 Delta Sharing，数据使用者无需在 Databricks 上即可访问共享的流表，从而实现跨云、跨区域和跨平台的灵活数据共享。
  4. 数据提供商通过 Unity Catalog 完全控制访问权限。 Unity Catalog 提供细粒度的权限管理，确保数据提供商可以安全地与外部合作伙伴和平台共享流表。

💬 文章金句

  • 共享流表使数据接收者能够实时访问最新数据，无需重复构建数据管道或复制数据。
  • 流表用于摄取实时数据，通常形成“bronze”层（“bronze”层指原始数据层），原始数据首先落在此处。
  • 物化视图更适合“silver”或“gold”层（“silver”和“gold”层分别指精炼和聚合后的数据层），在这些层中，数据经过提炼或聚合。
  • 数据提供商保留对访问的完全控制权，通过 [Unity Catalog](https://www.databricks.com/product/unity-catalog) 管理细粒度权限。
