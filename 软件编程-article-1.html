GitLab 发布 Duo Agent 平台公开 Beta 版，引入 Agent 编排的 DevSecOps

8/31/2025, 12:00:00 PM

📌 一句话摘要

GitLab 发布 Duo Agent 平台公开 Beta 版，引入 Agent 编排的 DevSecOps，实现 AI 智能体与人类的协作。

📝 详细摘要

GitLab 发布了 Duo Agent 平台的公开 Beta 版，这是一款旨在促进开发者和 AI 智能体在整个 DevSecOps 生命周期中进行异步协作的编排工具。该平台将传统工作流程转变为动态的、多智能体系统，使 AI 能够管理诸如重构和安全扫描等日常任务，助力开发者摆脱重复劳动，从而能够专注于解决复杂的难题。该平台的核心功能是利用 GitLab 全面的信息中心，包括代码、CI/CD 流水线和合规性检查，为 AI 智能体提供完整的组织背景，以便其做出明智的贡献。主要功能包括专业智能体（例如，软件开发者、安全分析师）的并行操作、通过 IDE 和 GitLab Web UI 进行的自然语言交互以及可自定义的智能体规则。该平台还通过模型上下文协议 (MCP) 与外部系统集成。虽然收到了积极的早期反馈，但 GitLab 通过专注于整个 DevSecOps 生态系统中的多智能体编排和深度组织背景，从而将自己与 GitHub Copilot / Workspace（代码生成）、JetBrains AI Assistant（以 IDE 为中心的功能）和 Atlassian Intelligence（项目管理 AI）等竞争对手区分开来。这标志着 GitLab 在推动 AI 智能体成为软件工程核心参与者方面迈出了重要一步。

💡 主要观点

  1. GitLab Duo Agent 平台引入了 Agent 编排的 DevSecOps，以增强 AI 智能体与人类的协作。 该平台将传统的线性开发转变为动态的多智能体系统，使 AI 能够处理诸如重构和安全等日常任务，使开发者能够专注于解决复杂的难题和创新。
  2. 该平台利用 GitLab 的集中式信息中心，为 AI 智能体提供全面的组织背景。 通过访问代码、CI/CD 和项目历史记录，AI 智能体可以做出明智的、自主的贡献，这些贡献与已建立的开发标准和工作流程保持一致，从而确保一致性和合规性。
  3. GitLab 通过多智能体编排和深度组织背景来区分其产品。 与主要以代码为中心或以项目管理为中心的竞争对手工具不同，GitLab 的平台在整个 DevSecOps 生命周期中编排各种 AI 智能体，将它们深度集成到开发过程中。

💬 文章金句

  • GitLab 发布了 GitLab Duo Agent 平台的公开 Beta 版，这是一款编排工具，使开发者能够与 AI 智能体在整个 DevSecOps 生命周期中进行异步协作。
  • Duo Agent 平台的核心在于利用 GitLab 的集中式信息中心地位，该系统包含代码、MR、CI/CD 流水线、测试结果、合规性检查和项目历史记录，从而为 AI 智能体提供完整的组织背景。
  • 通过将编排、开发者背景和智能自动化引入统一的、基于智能体的框架中，GitLab 的 Duo Agent 平台公开 Beta 版让人们得以一窥软件工程协作的未来。
  • RedMonk 的研究总监 Rachel Stephens 补充说，GitLab 的编排平台代表着“在将 AI 智能体集成到现有 DevSecOps 工具链中迈出的重要一步”。
  • 虽然 GitLab 通过其智能体编排平台与这些竞争对手区分开来，但所有公司都在朝着相同的愿景发展：AI 智能体成为软件开发生命周期的核心参与者。
