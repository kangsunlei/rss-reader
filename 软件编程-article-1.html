Claude Opus 4.6 正式集成至 Vercel AI Gateway 与 v0

2/5/2026, 6:34:23 PM

📌 一句话摘要

Vercel CEO Guillermo Rauch 宣布 Claude Opus 4.6 现已在 Vercel AI Gateway 和 v0 平台上线。

📝 详细摘要

Vercel 首席执行官 Guillermo Rauch 确认，最新的 Claude Opus 4.6 模型已在 Vercel AI Gateway 及其生成式 UI 工具 v0 上正式发布。该模型具备适应性思考、交织推理能力，并拥有高达 100 万 token 的超大上下文窗口。此次集成专门针对 Vercel 生态系统内构建 AI 智能体和处理复杂推理任务进行了深度优化。
