GitHub 与 JFrog 集成：构建安全可追溯的软件供应链

9/9/2025, 10:00:00 PM

📌 一句话摘要

GitHub 和 JFrog 的集成实现了从代码提交到产品上线的安全可追溯的软件供应链管理。

📝 详细摘要

本文介绍 GitHub 和 JFrog 之间的新集成，旨在通过连接源代码和认证后的二进制文件，简化 DevSecOps 流程。它解决了构建后可追溯性缺失、分散的安全扫描和脱节的 CI/CD 流水线等常见问题。该集成使用密码学技术将代码提交与构建产物关联起来，统一安全扫描（GitHub 高级安全、Dependabot、JFrog Xray），并促进基于策略的制品晋升控制。它利用 GitHub Actions 进行构建证明，并利用 JFrog Artifactory 进行制品管理，从而确保完整的生命周期可见性，并能根据生产环境信息，自动对漏洞进行优先级排序。文章提供了设置说明和最佳实践，例如使用 OIDC 和自动化晋升，以帮助开发人员实施更安全、更高效的软件供应链。

💡 主要观点

  1. 该集成集中了 DevSecOps，实现了端到端的可追溯性。 它使用密码学技术将代码提交与构建产物关联，将 GitHub 的认证信息导入到 JFrog 中，并统一安全扫描，从而解决了工具分散和手动协调的问题。
  2. 自动化的、基于策略的制品晋升提高了安全性和效率。 可以根据基于策略的门禁控制将制品从开发环境自动晋升到生产环境，从而减少手动交接并确保安全合规性。
  3. 通过生产环境上下文改进了漏洞优先级排序。 通过将 JFrog 的制品生命周期数据与 Dependabot 警报集成，开发人员可以根据生产环境中是否存在包含该漏洞的构建产物来确定其优先级。

💬 文章金句

  • 此集成可以节省时间和精力，将所需资源集中于一处。
  • 我们的目标：消除摩擦、降低风险，并让开发人员有更多时间专注于构建功能，而不是管理工作交接。
  • 我们今天宣布的集成开启了无缝体验，使您可以：运行统一的安全扫描、发布和晋升制品、自动将 GitHub 上创建的所有证明（溯源信息、SBOM、自定义证明）提取到 JFrog 凭证中并与构建制品相关联。
  • 利用 JFrog 凭证中的溯源信息来实现即时可追溯性。
  • 尽早设置安全门，以便未经证明或易受攻击的构建永远不会进入生产环境。
