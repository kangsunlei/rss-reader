📌 一句话摘要

JetBrains 发布 IntelliJ IDEA 和 Android Studio 的 KMP 插件测试版，助力跨平台开发！

📝 详细摘要

JetBrains 宣布推出适用于 IntelliJ IDEA 和 Android Studio 的新 Kotlin 多平台 (KMP) 插件的测试版本。该插件简化了 KMP (Kotlin 多平台) 开发生命周期，从集成的“新建项目”向导开始，该向导支持 Android、iOS、桌面、Web 和服务器的所有目标组合，以及原生或共享的 Compose UI 界面。它提供自动环境检查、自动运行配置生成、增强的 Kotlin 和 Swift 跨语言支持，以及全面的 Compose 多平台 IDE 功能，包括 UI 界面预览和 Compose 热重载，可在不丢失状态的情况下快速迭代 UI 界面。该插件目前处于测试版，并且已为 MacOS 做好生产准备，未来计划支持 Windows / Linux 以及进一步的工具链增强。本文档提供了安装指南，并提供了收集反馈的渠道。

💡 主要观点

  1. 集成的“新建项目”向导简化了跨各种平台的 KMP 项目设置。 该插件在 IDE 中提供了一个统一的向导，用于创建以 Android、iOS、桌面、Web 和服务器为目标的 KMP 项目，支持原生和共享的 Compose UI 界面。
  2. 自动环境检查，帮你快速搞定环境配置问题。 打开项目后，该插件会验证必要的组件（如 SDK 和配置），并提供修复缺失或过时依赖项的建议。
  3. 对 Compose 多平台代码的全面 IDE 支持，包括 UI 界面预览。 开发人员可以获得 Compose 多平台的完整 IDE 功能，例如自动完成和重构，还可以直接在 IDE 中预览 UI 界面组件。

💬 文章金句

  • 今天，我们将这些计划付诸行动，为您最喜欢的 IDE —— IntelliJ IDEA 和 Android Studio 发布新的 KMP 插件的测试版。
  • 该插件简化了 KMP 体验的每个部分，从项目设置到跨平台开发和 Compose UI 界面预览。
  • 使用 Compose 热重载，您可以立即看到 UI 界面更改，而无需重新启动应用程序或丢失其状态。
  • KMP 插件目前处于测试版。它已准备好投入生产使用，并已为 Kotlin 多平台开发提供坚实的基础。
