ArcMD：从 Arc 借鉴的 Markdown 编辑器

11/12/2026, 1:00:05 AM

📌 一句话摘要

ArcMD 是一个基于 Go 的轻量级 Markdown 编辑器，借鉴了 Arc 浏览器的空间管理和可视化界面，支持离线编辑、多窗口布局和附件管理。

📝 详细摘要

ArcMD 是一款开源的 Markdown 编辑器，由 Go 语言编写，并直接使用原生 UI 而不是 Electron 或 WebView，保证了安装包的轻量化。它通过引入 '空间' 的概念，让用户将不同的项目或主题分组在独立的文件夹内，每个空间都有专属的图标和主题色。编辑界面支持多种布局，包括双栏视图和多文档同时打开，同时内置了对表格、公式、代码块和双链的支持。文档和附件都存储在本地，并提供自动保存和版本管理功能，使得写作过程更加安全和高效。

💡 主要观点

  1. 轻量化的本地编辑器 ArcMD 使用 Go 语言直接构建，没有依赖于重量级的 JavaScript 框架，安装包仅为 4 MB，但提供了丰富的文本编辑功能。
  2. 基于空间的组织结构 编辑器引入了视觉化的空间管理，每个工作或学习项目都可以作为一个独立的空间存在。这使得文档的组织更为直观，也方便通过侧边栏快速切换。
  3. 全面的 Markdown 支持和扩展功能 除了标准的 Markdown 语法，ArcMD 还支持 LaTex 公式、UML 图表绘制、CSV 表格编辑，并提供了 PDF 导出和版本历史查看功能，满足了专业写作需求。
