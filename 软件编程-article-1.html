7-Eleven 如何利用 Databricks Agent Bricks 变革维护技术人员的知识获取方式

1/9/2026, 11:00:00 PM

📌 一句话摘要

7-Eleven 使用 Databricks Agent Bricks 创建了一个 AI 驱动的维护助手（TMA），通过 Microsoft Teams 为技术人员提供快速、智能的设备文档和支持访问。

📝 详细摘要

本文详细介绍了 7-Eleven 如何利用 Databricks Agent Bricks 开发'技术人员维护助手'（TMA），以简化维护技术人员的知识获取。面对分散且格式多样的设备文档挑战，7-Eleven 旨在创建一个 AI 驱动的助手，实现精确文档检索、基于图像的零件识别以及与 Microsoft Teams 的无缝集成。该解决方案利用 Unity Catalog Volumes 进行安全文档存储，使用带有 BAAI bge-large-en-v1.5 嵌入的 Databricks Vector Search 实现快速信息检索，并通过 Teams Bot API 层协调 Databricks Model Serving。这一举措显著提高了技术人员获取关键维护信息的效率，通过集中化和智能化呈现文档来增强门店运营的一致性。

💡 主要观点

  1. 7-Eleven 通过 AI 驱动的助手解决了维护知识获取的挑战。 现有的维护文档分散在各种格式和位置，使得技术人员难以快速找到信息。AI 助手旨在集中化和智能检索这些知识。
  2. '技术人员维护助手'（TMA）集成了文档检索、视觉模型和协作工具。 TMA 旨在从文档中提供精确答案，从图像中识别零件，并无缝集成到 Microsoft Teams 中，提供全面的支持解决方案。
  3. Databricks 的 Unity Catalog 和 Vector Search 是解决方案数据管理和检索的核心。 Unity Catalog Volumes 存储文档和图像等非表格数据，而使用 BAAI bge-large-en-v1.5 嵌入的 Vector Search 能够高速、低延迟地检索相关信息。
  4. 该解决方案可直接通过 Microsoft Teams 访问，简化了技术人员的工作流程。 技术人员通过 Teams Bot 与 TMA 交互，该机器人通过 API 查询 Databricks Model Serving，确保在他们现有的通信平台内提供上下文答案和文档链接。

💬 文章金句

  • 7-Eleven 的维护技术人员通过维护各种设备来确保门店平稳运行。
  • 随着时间的推移，设备文档已发展为包含多种格式，分散在各个位置。
  • 为了应对这些挑战，7-Eleven 设想了一个 AI 驱动的助手，能够：从维护文档中检索精确答案，从图像中识别设备零件并建议相关材料，无缝集成到 Microsoft Teams 中。
  • 技术人员直接通过 Microsoft Teams 访问 TMA。Teams Bot 通过 API 层路由每个查询，该层协调对 Databricks Model Serving 的调用。
