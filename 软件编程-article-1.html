Docker 容器安全转型，免费提供安全强化镜像

12/28/2025, 7:00:00 PM

📌 一句话摘要

Docker 已根据 Apache 2.0 许可证免费提供其包含 1，000 多个安全强化容器镜像的目录，旨在增强软件供应链安全、减少攻击面，并使开发人员能够普遍使用安全的基础镜像。

📝 详细摘要

Docker 宣布，其包含 1，000 多个安全强化容器镜像的目录（此前为商业产品）现已根据 Apache 2.0 开源许可证免费提供。这一战略举措旨在增强软件供应链安全，这是一个日益增长的问题，预计到 2025 年，攻击造成的全球成本将达到 600 亿美元。这些基于 Debian 和 Alpine Linux 构建的安全强化镜像，旨在通过移除不必要的组件、以非 root 用户身份运行，以及提供完整的软件物料清单 (SBOM)、漏洞数据和 SLSA 构建级别 3 溯源，最大限度地减少攻击面。Docker 声称这些镜像与传统基础镜像相比，可将攻击面减少高达 95 %。这项由云原生计算基金会 (CNCF) 等组织支持的倡议，使 Docker 与 Google 的无发行版镜像和 Chainguard 的产品等竞争对手并肩，它们都致力于使安全且最小化的镜像易于访问。Docker 将继续提供包含服务水平协议 (SLA) 、FIPS 合规性和扩展生命周期支持的商业服务层，但优先考虑向所有开发人员普及安全基础镜像的访问。该公司还宣布了一项实验性的 Docker AI 助手功能，以帮助将现有容器迁移到安全强化镜像。

💡 主要观点

  1. Docker 已将其此前商业化的安全强化容器镜像开源，以增强软件供应链安全。 超过 1，000 个基于 Debian 和 Alpine Linux 构建的安全强化镜像，现已根据 Apache 2.0 许可证免费提供，旨在通过消除不必要的组件并提供强大的安全功能（如 SBOM 和 SLSA 溯源）来减少攻击面。
  2. 此举是应对日益升级的软件供应链攻击并普及安全基础镜像的战略性一步。 Docker Hub 处理数十亿次拉取，免费提供这些镜像对容器生态系统具有重大意义，为开发人员提供了普遍可用的安全基准，符合行业转向最小化、注重安全的镜像的趋势。
  3. 安全强化镜像提供了显著的安全改进，并附带了透明的安全数据。 这些安全强化镜像在攻击面方面可减少高达 95 %，以非 root 用户身份运行，并包含完整的软件物料清单 (SBOM) 和透明的漏洞数据，确保了更高水平的信任和安全。
  4. Docker 在免费层之外保留了商业产品，以满足企业对增强支持和合规性的需求。 企业服务层提供关键漏洞修复的服务水平协议 (SLA) 、FIPS 合规性、可定制镜像以及对遗留系统的扩展生命周期支持，这体现了 Docker 兼顾多样化客户需求与促进安全实践更广泛采用的策略。
  5. 正在开发未来的工具，包括一个 AI 助手，以促进迁移到这些安全强化镜像。 实验性的 Docker AI 助手可以扫描现有容器并推荐等效的安全强化镜像，从而简化采用过程，并将安全性进一步嵌入到开发工作流中。
