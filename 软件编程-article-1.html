如果未能按时完成 AWS S3 迁移，每天将损失五千美元

3/26/2025, 6:00:36 PM

📌 一句话摘要

Basecamp 计划在 6 月 30 日截止日期前从 AWS S3 迁移到 Pure Storage，以避免每天 5000 美元的 S3 费用，预计五年内节省近 500 万美元。

📝 详细摘要

David Heinemeier Hansson (DHH) 详细阐述了 Basecamp 从 AWS S3 迁移到 Pure Storage 自建存储方案的原因和计划。目前，Basecamp 每年在 AWS S3 上花费近 150 万美元，并且签订了四年合同。随着合同即将到期，Basecamp 决定迁移到 Pure Storage 提供的 S3 兼容 API 的存储方案，该方案拥有 18 PB 的容量，并安全地复制在两个数据中心，提供更快的 NVMe 存储。AWS 提供 60 天的免费数据迁出窗口，这使得 Basecamp 可以免费迁出近 6 PB 的数据。如果未能按时完成迁移，Basecamp 每天将支付 5000 美元的 S3 费用。预计迁移到 Pure Storage 后，五年内将节省近 500 万美元。

💡 主要观点

  1. AWS 提供的免费数据迁出窗口降低了迁移成本，是迁移决策的关键因素。 AWS 提供的 60 天免费数据迁出窗口，使得 Basecamp 可以免费迁出近 6 PB 的数据，大大降低了迁移成本，提升了迁移的可行性。
  2. 高昂的云存储成本是促使 Basecamp 离开 AWS S3 的主要原因。 每年 150 万美元的 AWS S3 费用，以及到期后可能产生的更高费用，促使 Basecamp 寻找更经济的存储解决方案。
  3. Pure Storage 提供的 S3 兼容 API 简化了迁移过程。 Pure Storage 提供的 S3 兼容 API 使得 Basecamp 可以轻松地从 AWS S3 迁移，而无需修改应用程序代码。

💬 文章金句

  • We're spending just shy of $1.5 million/year on AWS S3 at the moment to host files for Basecamp， HEY， and everything else. // 目前，我们每年在 AWS S3 上花费近 150 万美元，用于托管 Basecamp、HEY 和所有其他内容的文件。
  • If we don't get this done in time， we'll be paying a cool *five thousand dollars a day* to continue to use S3 (if all the files are still there). // 如果我们不能及时完成这项工作，我们将每天支付高达 *五千美元* 的费用来继续使用 S3（如果所有文件都还在那里）。
  • Over five years， it'll now be almost five million! Maybe even more， depending on the growth in files we need to store for customers. // 五年下来，现在将近 500 万美元！甚至可能更多，这取决于我们需要为客户存储的文件增长情况。
