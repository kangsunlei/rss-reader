GitHub Copilot 集成 MCP，实现与工具的直接互连

2/14/2026, 10:00:07 PM

📌 一句话摘要

GitHub 宣布 Copilot 编程智能体支持 MCP (Model Context Protocol)，允许直接从 Sentry 和 Notion 等工具中提取数据。

📝 详细摘要

GitHub 推出了为 Copilot 编程智能体配置 MCP (Model Context Protocol) 服务器的功能。该特性使 Copilot 能够直接与开发者的工具链交互，例如从 Sentry 抓取最新的崩溃报告，或从 Notion 读取功能规范，从而实现自动化的 Bug 修复和 PR 生成。这一举措大幅减少了手动切换上下文和复制粘贴的操作，极大地优化了端到端的开发流程。
