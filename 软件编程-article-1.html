GitHub Copilot 推出智能体记忆功能

2/22/2026, 6:27:56 PM

📌 一句话摘要

GitHub Copilot 现已具备记忆功能，允许 AI 智能体在整个代码仓库中学习并保持上下文。

📝 详细摘要

GitHub 宣布了其 Copilot 平台的重大更新：引入“记忆（Memory）”功能。该功能允许包括 Copilot、Claude 和 Codex 在内的各种智能体在用户的仓库中学习并保留上下文。目前，该更新正逐步推送到 VS Code Insiders、Copilot CLI 以及特定的编程和代码审查智能体中，显著增强了 AI 在复杂代码库中提供上下文感知辅助的能力。
