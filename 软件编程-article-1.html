Android Studio Narwhal：Gemini AI 功能再升级

9/4/2025, 9:00:00 PM

📌 一句话摘要

Android Studio Narwhal 通过 Gemini AI 增强开发者在 UI 代码、上下文和工具集成方面的效率。

📝 详细摘要

最新的 Android Studio Narwhal 3 功能更新引入了显著增强，旨在通过高级 Gemini AI 集成和全新开发工具，提高开发者生产力。核心创新在于引入 `AGENTS.md` Markdown 文件，它允许开发团队定义项目特定的上下文，包括详细指令、编码风格规则等。此功能支持根据项目需求定制更精细、更一致的 AI 行为，从而有效促进团队协作。一个主要亮点是图像附件功能，使开发者能够直接从 UI 屏幕截图或模型生成 Compose UI 代码；早期采用者报告称，通过在几分钟内将 Figma 设计转换为功能性 UI 结构，UI 开发时间减少了 40%，效果显著。此外，`@File Context` 功能简化了在 Gemini 查询中包含整个文件的过程，通过提供扩展的上下文理解，从而产生更准确、更具针对性的 AI 响应。除了 AI 功能之外，Narwhal 还增加了对 MCP 协议的支持，从而增强了与 GitHub 等外部工具的兼容性，以便获取问题并提出实现建议。其他值得注意的改进包括可调整大小的 Compose 预览，它简化了在各种屏幕尺寸上测试应用程序的适配性，以及强大的应用程序备份和恢复工具，以确保用户在迁移到新设备时能够平稳过渡。这些功能共同旨在简化 Android 开发工作流程。

💡 主要观点

  1. Android Studio 集成 Gemini AI，可直接从屏幕截图生成 UI 代码，大幅缩短开发周期！ 图像附件功能允许开发者上传 UI 模型，Gemini 生成相应的 Compose 代码，从而使 UI 构建时间最多减少 40%。
  2. 通过 AGENTS.md 文件定义项目编码规范，并通过文件附件提供详细的上下文信息，Gemini AI 能够更准确地理解开发者意图，提供更具相关性的建议。 AGENTS.md 文件使团队能够定义编码风格和指令，而 @File Context 允许包含整个文件，从而确保 Gemini 为开发者提供更量身定制和准确的帮助。
  3. Android Studio Narwhal 通过核心 AI 功能之外的新工具改进了互操作性和开发者体验。 对外部工具的 MCP 协议支持、可调整大小的 Compose 预览以及增强的应用程序备份/恢复工具等新功能有助于形成更全面、更高效的开发环境。

💬 文章金句

  • 通过上传 Figma 设计的屏幕截图，Gemini 可以在几分钟内生成构建整个屏幕所需的 UI 结构。
  • 随着时间的推移，这种方法已成为他们原型设计过程的标准部分，该团队报告说，每个屏幕的平均 UI 构建时间减少了 40%。
  • 他特别指出，GitHub 只是这个蓬勃发展的工具生态系统中的冰山一角。同时，他也建议，如果当前项目未使用 MCP 支持，应及时禁用，以避免不必要地增加 Gemini 的处理负担。
