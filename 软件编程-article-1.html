从 AWS 事故看本地优先软件的重要性：推荐 Bruno 和 Obsidian

10/26/2025, 12:30:24 PM

📌 一句话摘要

针对近期 AWS 事故导致 Postman 等服务中断，作者强调本地优先软件的重要性，并推荐使用 Bruno 替代 Postman，以及结合 Git 使用 Obsidian。

📝 详细摘要

该推文引用了近期 AWS 因 DNS 问题导致服务中断的事故（其中 Postman 也受影响），引发了作者对“本地优先”（local-first）软件哲学的思考。作者认为，许多软件过度依赖云端账户和同步是“画蛇添足”，并分享了他将 Postman 替换为开源工具 Bruno 的经验。Bruno 将每个 API 请求存储为`.bru`格式的本地文件，这使得通过 Git 进行版本控制和团队同步变得非常方便。此外，作者还提到 Obsidian 作为另一款他非常喜欢的本地优先软件，同样能通过 Git 插件满足其所有需求。这篇推文不仅对云服务可能出现的风险进行了反思，也为开发者在工具选择和数据管理上提供了一种更独立、更可控的思路。
