MiniMax H3 打斗技能开源

11/16/2026, 9:01:01 AM

📌 一句话摘要

作者通过两周研发将 MiniMax H3 的打戏打造成可用的开源技能 h3-fight，显著提升了 AI 生成内容的质量。

📝 详细摘要

本人花费两周时间，将 MiniMax H3 的打斗场景优化为名为 h3-fight 的开源 Skill。通过对比社区底模、Pika H3 Flex、加速 LoRA 等多种方案，最终选用 BUNNY 的打斗 LoRA 系列模型，再结合 FL2VA/Ref2VA 混合版主干和 188 个镜头块，实现自动化打戏生成。该项目已开源，用户可通过 Claude Code 或 Codex 一键生成高质量打斗 scenes，支持仙侠、日漫、真人古装等多种风格，效果从 70 提升至 90。

💡 主要观点

  1. 系统性优化 AI 打斥生成 通过多阶段模型对比与 LoRA 微调，解决了打戏机位单调与动作生硬的问题。
  2. 引入镜头块化管理 将所有优质打斥片段拆解为 188 个镜头块，实现结构化提示词与自动化检查。
  3. 集成至 Claude Code 与 Codex 用户只需一句话调用，即可自动挑选镜头、拼接并自检，大幅提升工作流效率。

💬 文章金句

  • 终于把 MiniMax H3 的打戏做成了一个拿来就能用的 Skill：h3-fight，已经开源。
  • 现在只要对 Claude Code 或 Codex 说一句：“帮我写一段打戏”，它就会自己挑镜头、拼好、自检，一条命令出片。
  • 自我打分从 70 涨到 90。
