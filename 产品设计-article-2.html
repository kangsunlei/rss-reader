Notion 与 Linear 正变成通用 AI Agent 平台

7/24/2026, 1:35:05 AM

📌 一句话摘要

Ding 引用 Notion as code 的 beta 更新，认为 Notion 和 Linear 已从工具演变为可执行任意任务的 AI Agent。

📝 详细摘要

Ding 引用 Notion 官方发布的 Notion as code beta 推文，该功能允许用户通过 TypeScript 定义整个工作空间（团队空间、数据库、自定义 Agent）并部署到 API。Ding 据此评论：Notion 不再是单纯的文档工具，Linear 也不再是项目管理工具，它们都正在转型为能做任何事的 AI Agent 平台。
