UI 字体的十个核心知识点

9/1/2025, 2:34:00 PM

📌 一句话摘要

文章详细阐述了 UI 设计中字体选择、字重、字号、字色、装饰、文本布局、对齐、行高、字距和段间距等十个核心知识点，并结合 Figma 操作提供了实用指导。

📝 详细摘要

本文围绕 UI 设计中的字体运用，系统性地介绍了十个核心知识点，旨在帮助新手高效掌握字体设计。文章分为“文字的基础属性认识”和“文字的排版属性认识”两大模块。在基础属性方面，详细讲解了字体选择（根据系统类型区分中英文）、字重（不同文本类型的推荐字重）、字号（不同文本的字号范围及中英文差异）、字色（HSB 灰度值设置及 OLED 屏纯黑注意点）和文本装饰（下划线、删除线）。在排版属性方面，深入剖析了文本布局（自动、固定宽度和固定尺寸）、对齐方式（水平与垂直）、行高（默认行高、Vertical trim 应用及多行文本建议值）、字距（中英文排版差异）和段间距（设置原则）。文章强调了遵循设计规则而非凭感觉的重要性，并结合 Figma 界面进行直观说明，提供了大量可操作的实践建议。

💡 主要观点

  1. UI 字体选择需根据面向系统，并考虑中英文混排的特殊性 不同操作系统（iOS、Android、网页）有推荐的默认字体，中文界面可直接用中文字体输出英文，而英文界面或独立英文信息才需切换英文字体，确保显示效果与系统一致性。
  2. 字重、字号、字色、装饰等基础属性需遵循特定规则以保证文本的易读性和视觉层级 针对标题、正文、注释等不同文本类型，需选择合适的字重、字号和字色（如 HSB 的 B 值），并合理运用下划线、删除线等装饰，以提升信息传达效率和用户体验。
  3. 文本布局、对齐、行高、字距、段间距等排版属性，在 Figma 中各有应用场景和最佳实践 通过自动宽度、固定宽度、固定尺寸等布局模式，结合水平/垂直对齐、行高（1.6-2 倍字号）、字距（英文排版关键）和段间距，能构建清晰、有节奏的文本结构。

💬 文章金句

  • 字体一直是 UI 设计中最重要的组成部分之一，而 UI 的字体设计运用又和平面有很大的差异，所以也是新手需要优先掌握的知识之一。
  • 在 Figma 中进行 UI 设计时，字体选择主要根据面向的系统类型决定，以模拟真实的显示情况。
  • 中文 10 号字以下基本已经无法看清，不要轻易使用，而英文因为笔画比中文简单，所以最小字号可以用到 8 左右。
  • 在白底中，字色从浅到深可以分为三档，可以参考下面的规则：标题/正文：B 值 5-40，次要文本：B 值 40-60，注释文本：B 值 60-80。
  • UI 字体设置要掌握的核心知识点就上面这些，建议大家就是强行背也要背下来，而不是在实际设计过程中"凭感觉"去设计。
