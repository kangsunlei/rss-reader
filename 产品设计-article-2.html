Manus 2.0 发布后肖弘发声，在激烈的个人 Agent 市场如何突围？

9/30/2026, 1:28:47 AM

📌 一句话摘要

Manus 发布 2.0 版本及个人 Agent 产品 Cue，通过通用智能体定位、云电脑及视频/游戏开发功能在激烈的 Agent 市场中突围。

📝 详细摘要

面对 Meta 旗下 Muse 霸榜应用商店的挑战，Manus 发布了 2.0 版本及个人智能体 Cue。创始人肖弘强调 Manus 的核心是通用智能体（General Agent），并将其类比为卖电脑的生意。产品亮点包括：本地客户端 Manus Studio 支持通过代码生成视频及开发联机游戏；云电脑功能解决了 computer use 的硬件冲突与任务中断问题；Cue 则为智能体提供独立身份（邮箱、手机号、钱包）并在云空间实现 24 小时持续运行。尽管目前通用 Agent 市场面临 Claude Code 和 Codex 的竞争，Manus 试图通过更深度的场景整合和通用性实现差异化竞争。

💡 主要观点

  1. Manus 定位为通用智能体（General Agent） 创始人肖弘认为 Manus 不仅仅是单一工具，而是像‘电脑’一样的通用底座，旨在涵盖工作、视频创作和游戏开发等多种释放创造力的场景。
  2. 云电脑技术解决 Agent 运行痛点 通过租用云端 Linux/Mac/Windows 环境，解决了 computer use 功能与本地操作冲突资源的问题，并确保任务在电脑关机后仍能于云空间持续运行。
  3. Manus Studio 强化内容创作能力 该客户端并非依赖传统的视频模型，而是通过编写代码转译视频，并利用云端能力支持开发多人协作的联机游戏。
  4. Cue 定义了个人 Agent 的身份与持久化特征 Cue 为每个智能体配备独立的邮箱、手机号和钱包，使其具备网络授权和支付能力，并在云空间内实现随叫随到的 24 小时服务。
