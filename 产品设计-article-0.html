📌 一句话摘要

本文展示了如何利用 CSS 相对颜色值和 OKLCH 色彩空间为 SVG 图形实现动态主题化和动画效果，简化了复杂的调色板管理和动态设计。

📝 详细摘要

本文是 'Smashing Animations' 系列的一部分，探讨了如何有效利用 CSS 相对颜色值和 OKLCH 色彩空间来为主题化和动画化 SVG 图形。作者借鉴了经典卡通动画技术中的复用思想，详细介绍了创建动态调色板的方法。文章展示了如何定义一个单一的 '基础' 颜色，并使用相对颜色计算从中派生出所有其他颜色（填充色、描边色、渐变），而不是手动更新阴影和色调。它引入了调整明度（移动）、色度（缩放）和色相（旋转）的具体规则，以在不同基础颜色之间保持一致的视觉关系。至关重要的是，文章将这一概念扩展到动画领域，展示了如何为 OKLCH 颜色通道注册自定义 CSS 属性，从而实现平滑的颜色过渡、创建 '呼吸' 动画，甚至为 SVG 场景构建一个小的动态光照系统，所有这些都通过动画化单一颜色令牌来驱动。这极大地简化了复杂的主题化和动画任务，提供了更好的控制力和效率。

💡 主要观点

  1. CSS 相对颜色值，尤其是结合 OKLCH，为 SVG 图形提供了简化且更可控的动态主题化方案。 无需手动更新单个颜色，而是可以定义一个单一的 '基础' 颜色，然后使用 CSS 中的相对调整以编程方式从中派生出调色板中的所有其他颜色（阴影、色调、互补色）。
  2. 采用特定的 '移动它、缩放它、旋转它' 规则，确保在不同基础颜色之间保持稳健的颜色关系。 当基础颜色改变时，明度应被 '移动'（线性加减），色度应被 '缩放'（按比例相乘），色相应被 '旋转'（角度加减），以保持一致的感知效果。
  3. CSS 自定义属性可以注册为 '类型化' 值，以实现颜色通道的平滑动画。 通过将 OKLCH 通道（明度、色度、色相）注册为数字，浏览器可以平滑地对它们进行插值计算，从而只需对少数基础值进行动画处理即可实现复杂的颜色动画（例如，'呼吸' 效果或动态光照系统）。
  4. 该系统允许在动画中实现动态的、上下文感知的颜色变化，例如时间主题或交互式光照效果。 文章演示了如何构建一个基于动画化的 '火焰' 颜色令牌进行着色的叠加层，创建一个逼真的、动态光照的场景，其中所有相关颜色都会自动更新。

💬 文章金句

  • 我开始思考 CSS 相对颜色值是否能在简化流程的同时给我更多控制权。
  • 可以把相对颜色理解为：'取这个颜色，调整它，然后把结果给我。'
  • 只需更改一次基础颜色，每个派生颜色都会自动更新，无需手动重新计算任何东西。
  • 但动画图形很少是静止的——顾名思义。所以，如果颜色是系统的一部分，那么它没有理由不能也动起来。
  • 我不是分别对叠加层和灯进行动画处理，而是对一个单一的 '火焰' 颜色令牌进行动画处理，并从中派生出其他所有东西。
