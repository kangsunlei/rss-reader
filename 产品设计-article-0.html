Penpot 正在尝试使用 MCP 服务器实现 AI 驱动的设计工作流 — Smashing Magazine

1/8/2026, 8:00:00 AM

📌 一句话摘要

Penpot 正在尝试使用 MCP 服务器将 AI 安全地集成到设计工作流中，利用其'以代码表达设计'的方法打造强大的交互式设计工具。

📝 详细摘要

本文介绍了 Penpot 在其开源平台中尝试使用 MCP（模型上下文协议）服务器将 AI 集成到设计工作流中的实验。文章强调了 MCP 服务器如何作为安全桥梁，让 AI 能够理解和交互 Penpot 设计文件，克服了由于安全和隐私问题而直接与 LLM 交互的限制。作者解释说，Penpot 的'以代码表达设计'方法使其 MCP 实现特别强大，能够实现设计的程序化创建、编辑和分析。文章详细介绍了与 Penpot API、Python SDK 的集成以及 LLM 无关支持等功能，并展示了各种用例，如设计到代码转换、设计验证、文档生成、高级导出和一致性检查。最终目标是促进无限数量的 AI 驱动工作流，同时不暴露敏感设计数据，Penpot 正在积极寻求社区参与开发和测试。

💡 主要观点

  1. Penpot 的 MCP 服务器通过充当'安全桥梁'使 AI 能够安全地与设计文件交互 这种机制允许 AI 助手理解用户意图并通过 Penpot 的 API 执行操作，通过不将原始设计数据直接暴露给外部 LLM 来确保数据隐私和安全
  2. '以代码表达设计'的方法赋予 Penpot 的 MCP 服务器独特的威力和粒度 与通用的 AI 驱动设计工具不同，Penpot 基于代码的设计表示允许精确的程序化操作和分析，从而实现更强大和上下文感知的 AI 交互
  3. MCP 服务器促进了广泛的 AI 驱动设计工作流，超越了简单的'描述-生成'模型 展示的用例包括无缝的设计到代码和代码到设计转换、自动文档生成、设计系统元素创建、设计验证以及各种重复任务的自动化，显著增强了设计师和开发者的协作
  4. Penpot 的 MCP 解决方案是 LLM 无关的，提供了工具链集成的灵活性 用户可以选择他们偏好的 AI 助手（如 Claude、Junie AI）并将其与现有的开发环境集成，提供适应性并减少对 AI 功能的供应商锁定

💬 文章金句

  • 可以这样理解：AI 就像是餐厅里接受你点单的服务员，MCP 服务器既是菜单又是厨师，而 API 请求就像是（希望是）热披萨放在温暖的盘子上。
  • 虽然 Penpot MCP 服务器确实充当了**安全桥梁**，使用你的 Penpot 文件和数据作为上下文，将 AI 意图转换为 API 请求。
  • 更好的是，因为 Penpot 采用了**以代码表达设计的方法**，设计可以在粒度级别上进行程序化创建、编辑和分析。
  • 本质上，由于你选择的 LLM/LLM 客户端的效率和易用性，Penpot MCP 服务器引领了通往**无限工作流**的道路，但不会将你的数据暴露给它。
