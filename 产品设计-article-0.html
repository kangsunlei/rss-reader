Claude Code 支持 AGENTS.md 格式

9/18/2026, 10:08:35 PM

📌 一句话摘要

作者评论 Anthropic 的 Claude Code 正式支持竞争对手的 AGENTS.md 标准，视为大厂向开放标准妥协的标志性时刻。

📝 详细摘要

作者以「曾经高高在上，现在终于低头了」评价 Claude Code 2.1.277 版本新增对 AGENTS.md 的支持。引用官方公告显示，当项目中没有 CLAUDE.md 时，Claude 会自动检查并使用 AGENTS.md，用户可在配置中切换该行为。这被解读为 Anthropic 承认并兼容了由竞品推动的 Agent 配置文件开放标准。

💡 主要观点

  1. Claude Code 官方兼容 AGENTS.md 标准 Anthropic 在 2.1.277 版本中加入对 AGENTS.md 的原生支持，标志着主流 AI 编码工具开始拥抱统一的 Agent 配置格式，降低了开发者在不同工具间切换的成本。
  2. 大厂态度从封闭走向开放互操作 作者将其解读为 Anthropic 此前坚持自有 CLAUDE.md 格式，如今被迫兼容竞品主导的开放标准，反映 AI 编程工具链生态正在向标准化、互操作方向演进。
