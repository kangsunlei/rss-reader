📌 一句话摘要

DHH 倡导 Hotwire 的 Turbo 等服务器端渲染技术所带来的速度优势，并将其与当下网页的“React 化”趋势形成对比。

📝 详细摘要

DHH 回顾了在 React 等重量级客户端框架广泛普及之前，网页所展现出的卓越性能。他引用了一条关于 GitHub 在 2013 年惊人速度的推文，指出 Hotwire 的 Turbo 框架正是基于早期 GitHub 所采用的 Pjax 概念构建的。他认为，只要避免过度工程化的前端技术栈，如今依然能够实现这种级别的速度。
