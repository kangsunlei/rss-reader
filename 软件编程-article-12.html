MNN LLM：让你手机本地也能跑 DeepSeek R1 还能支持多模态

4/21/2025, 8:02:12 AM

📌 一句话摘要

MNN LLM 是一款支持多模态的开源工具，可在手机本地运行 DeepSeek R1 等大模型，解决了服务器依赖问题并优化了端侧推理性能。

📝 详细摘要

文章介绍了 MNN LLM，一款由大淘宝技术 Meta Team 开发的开源工具，旨在解决 DeepSeek R1 等大语言模型服务器不稳定和下载困难的问题，实现了大语言模型的端侧部署。MNN LLM 支持本地部署和移动端运行，可以在 Android、iOS 和桌面端使用，支持包括 7B 模型在内的多种模型。它通过模型量化和硬件优化提升了推理速度和稳定性，并支持文生图、语音输入等多模态功能。此外，MNN LLM 还优化了模型下载流程，支持 Modelscope 下载和断点续传，方便国内用户使用。

💡 主要观点

  1. MNN LLM 实现了大语言模型的本地端侧部署，摆脱了对服务器的依赖 通过本地部署和优化的下载流程，用户无需依赖远程服务器，即可在本地设备上运行大语言模型。
  2. MNN LLM 通过多项优化提升了推理速度和稳定性 模型量化、混合存储和硬件特定优化等措施，使得 MNN LLM 在移动端设备上具有更高的性能和更稳定的输出。
  3. MNN LLM 支持文生图、语音输入等多模态功能 MNN LLM 不仅支持文字聊天，还支持图片输入、语音输入和文生图等多模态功能，扩展了应用场景。
  4. MNN LLM 支持 Android、iOS 和桌面端，覆盖广泛的用户群体 MNN LLM 提供了跨平台的解决方案，使得更多的用户可以在自己的设备上体验大语言模型。
