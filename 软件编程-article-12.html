Grails 7.0，现为 Apache 软件基金会旗下项目，为 Micronaut 和 GORM 提供增强功能

11/7/2025, 2:30:00 AM

📌 一句话摘要

Grails 7.0 现在是 Apache 顶级项目，为 Micronaut 和 GORM 提供增强功能，需要 JDK 17 及以上版本和 Spring Boot 3.5。

📝 详细摘要

Apache Grails 7.0.0 已经发布，引入了错误修复和显著的变化。主要更新包括：通过 Grails 插件禁用 Micronaut 自动配置以进行调试；解决随机闭包排序问题，提高 GORM 服务的可重复性；以及在实现兼容性之前，临时移除对 Neo4J 的 GORM 支持。此版本强制要求 JDK 17 及以上版本，并符合 Spring Boot 3.5 和 Jakarta EE 10。文章还重点介绍了 Grails 的历程，最终成为 Apache 软件基金会（ASF）的顶级项目，标志着向社区管理、供应商中立的开发模式转变。经过 18 个月的协作工作，这一里程碑旨在通过简化的全栈工作流程、增强的安全性以及保留 Grails 的核心原则来增强开发人员的能力。

💡 主要观点

  1. Grails 7.0 针对 Micronaut 集成和 GORM 服务引入了多项关键增强。 开发人员现在可以禁用 Micronaut 自动配置以进行更轻松的调试，并且 GORM 服务中的可重复性问题已得到解决，从而提高了应用程序的稳定性和可靠性。
  2. Grails 已正式晋升为 Apache 软件基金会的顶级项目。 这标志着向供应商中立、社区管理的开发模式转变，确保了长期可持续性，遵守 Apache 任人唯贤的原则，并为框架提供了健康的贡献者基础。
  3. 新版本需要现代依赖项，包括 JDK 17、Spring Boot 3.5 和 Jakarta EE 10。 此更新确保与当代 Java 生态系统标准兼容，使开发人员能够在构建 Grails 应用程序时利用最新的功能和安全增强功能。

💬 文章金句

  • Grails 7.0 需要 JDK 17 的最低版本（已通过高达 JDK 21 的测试验证），并符合 Spring Boot 3.5 和 Jakarta EE 10。
  • 2025 年 10 月晋升为顶级项目确认 Grails 现在符合 Apache 关于独立管理、健康的贡献者基础和定期发布节奏的标准，遵循 The Apache Way。
  • Apache Grails 7.0.0，这是我们在晋升为 Apache 软件基金会顶级项目后的第一个稳定版本，汇集了 18 个月的协作工作，并引入了主要的依赖项升级和功能。
  • 此版本通过简化的全栈工作流程以及增强的安全性与合规性来增强开发人员的能力，并保留了 Grails 的基本 DRY（Don't Repeat Yourself，不要自我重复）和约定优于配置原则，所有这些都由数千个社区提交驱动。
