攻击者利用疑似 AI 生成的 PowerShell 脚本映射 Active Directory

7/14/2026, 10:00:00 AM

📌 一句话摘要

文章分析了利用 AI 生成的 PowerShell 脚本枚举 Active Directory 的攻击链，指出其通过五级回退机制快速获取 AD 信息并外泄。

📝 详细摘要

文章报道了网络安全研究人员发现的一次入侵事件，攻击者利用一个通过 AI 生成的 PowerShell 脚本（标题为“100% Working AD Information Gathering Script - FULLY FIXED”）对 Active Directory 进行枚举。脚本通过五级回退机制定位域控制器，映射用户、计算机和域，创建目录导出多个文件，最终生成 AD_Report.html 进行验证。攻击链从 RDP 登录加入域的 Windows Server 开始，随后部署 s5cmd 与 SharpShares 进行批量文件操作与网络共享枚举，最后将数据导出为 CSV 并通过 HTML 归档外泄。研究人员指出，这一过程很可能是 LLM“良心注入”的结果，攻击者只是顺手接受了 AI 输出的代码，而非有意编写。文章还引用 Sygnia 的报告，说明 AI 并未带来新的攻击技术，而是加速了既有攻击手法的执行，使技术能力较弱的攻击者能够在短时间内完成高效侵入，成为网络攻击的倍增器。

💡 主要观点

  1. 脚本通过五级回退机制枚举 AD 结构并生成报告。 研究人员指出该脚本会定位域控制器，映射用户、计算机和域，创建目录导出多文件，最终生成 AD_Report.html 验证枚举成功，标题暗示‘100% Working’，实际为 LLM 反复交互后接受的代码。
  2. 攻击者利用已泄凭据通过 RDP 登录域控制器并部署工具。 攻击链从 RDP 访问加入域的 Windows Server 开始，将脚本部署在 ProgramData 目录，随后使用 s5cmd 和 SharpShares 批量枚举并导出数据，最终通过 HTML 归档外泄。
  3. AI 降低攻击门槛，使攻击者可快速生成功能强大的恶意脚本。 文章指出 AI 并未引入新技术，而是加速了既有攻击手法的执行，使技术能力较弱的攻击者能够以最小精力实现高效侵入，成为攻击的倍增器。

💬 文章金句

  • 该脚本会寻找域控制器（Domain Controller，DC），映射用户、计算机和域，然后在创建目录并导出多个文件后，最终生成 AD_Report.html 来验证枚举尝试的成功程度。
  • 这很可能是 LLM'好心'注入的结果，攻击者只是顺手接受了，而不是有意将其编写到脚本中。
