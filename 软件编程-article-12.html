Node 中文周刊 #224 - JavaScript 新特性一览、Node 26.0 延期至 5 月 5 日发布

📌 一句话摘要

本期 Node 中文周刊汇总了 JavaScript ES2025/ES2026 新特性、Node 26.0 延期发布、pnpm 11.0 重大更新、Fresh 2.3 框架改进等 Node.js 生态热点资讯。

📝 详细摘要

本期 Node 中文周刊为 Node.js 开发者提供了本周生态内的关键动态。核心内容包括：一篇汇总了 ES2025 和 ES2026 中 Promise.try、Set 新方法、Array.fromAsync 等新特性的文章，并标注了在 Node 中的支持情况；Node 26.0 因 macOS 构建问题延期至 5 月 5 日发布，但 Temporal API 等新功能值得期待；pnpm 11.0 正式发布，引入了 SQLite 存储索引、原生包发布工具和默认供应链保护等重大特性；Deno 的全栈框架 Fresh 2.3 获得了一流的 WebSocket 支持和 View Transitions API 集成。此外，还介绍了 Vercel 的 portless 工具、SQLite 的 NOTIFY/LISTEN 实现 Honker、Cloudflare Agent Skills 等实用工具，以及 AVA 8.0、Hono Node.js Adapter 2.0 等版本发布信息。

💡 主要观点

  1. JavaScript ES2025/ES2026 新特性汇总，标注了在 Node 中的支持情况。 文章推荐了一篇将 ES2025 和 ES2026 新特性（如 Promise.try、Set 的 union/intersection/difference、Array.fromAsync、Math.sumPrecise 等）汇聚一处的文章，并指出大多数特性已在 Node 中支持，为开发者提供了清晰的兼容性参考。
  2. Node 26.0 因 macOS 问题延期至 5 月 5 日发布，Temporal API 默认启用。 Node 26.0 原本计划发布，但因 macOS 相关问题导致构建失败而延期。该版本将默认启用 Temporal API，这是一个重要的日期时间处理 API，值得开发者关注。
  3. pnpm 11.0 发布，引入 SQLite 存储索引和默认供应链保护。 pnpm 11.0 是一个重要版本，其核心变化包括使用 SQLite 支持新的存储索引以提升性能，同时新增了原生包发布工具、全局安装隔离化，并默认启用供应链保护，增强了包管理的安全性和效率。
  4. Fresh 2.3 获得一流 WebSocket 支持和 View Transitions API 集成。 Deno 的全栈框架 Fresh 2.3 更新带来了原生 WebSocket 支持，并优化了无 JavaScript 页面的渲染，同时通过单个属性即可轻松使用 View Transitions API，提升了开发体验和页面交互效果。

💬 文章金句

  • 如果你不想去读规范或无数篇关于每个新语言特性的帖子，这篇文章将 ES2025 和 ES2026 所有相关有用的内容汇聚在一处。
  • Node 26.0 (Current) 原本预计本周二发布，带着默认启用的 Temporal API，却因 macOS 相关问题导致构建失败。
  • pnpm 11.0 在本周发布了 pack-app 命令，可将应用打包为使用 Node SEA（Single Executable Applications）特性的独立可执行文件。
  • Deno 的全栈 Web 框架获得了一流 WebSocket 支持，不再为不需要 JavaScript 的页面发送任何 JavaScript。
