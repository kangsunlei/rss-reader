📌 一句话摘要

作者用 AI 辅助编写了一个极简 Python 静态博客框架，核心代码仅数百行，不依赖外部库，实现了短链、自渲染 Markdown、按需加载 KaTeX 和基于 GitHub Issues 的评论系统。

📝 详细摘要

本文是作者分享自己用 Copilot 辅助编写的 Python 静态博客框架。框架核心代码仅几百行，不依赖任何外部库，完全自主控制逻辑。文章详细介绍了几个关键特性：基于 CRC24 哈希和 Base36 的 5 位短链生成机制，并处理了冲突与保留字；自实现的 Markdown 渲染器，支持常用语法并在构建时完成代码高亮，无需前端 JS 加载；通过正则检测按需加载 KaTeX 数学公式渲染；以及基于 GitHub Issues 的评论系统，自动匹配已有讨论。整个项目托管在单一 GitHub 仓库中，通过 GitHub Actions 自动构建部署。文章以作者对「写博客是为了记录」的个人感悟收尾。

💡 主要观点

  1. 作者用 AI 辅助编写了一个极简的 Python 静态博客框架。 核心代码仅数百行，不依赖任何外部库，完全自主控制，旨在解决现有博客框架过于复杂、模板语法学习成本高的问题。
  2. 框架实现了基于 CRC24 哈希的 5 位短链系统。 通过 `_slug_hash` 函数将文章文件夹名哈希为 5 位短链，并设计了冲突检测与自动加后缀的机制，确保 URL 简洁且唯一。
  3. Markdown 渲染与代码高亮在构建时完成，无需前端 JS。 作者自实现了 Markdown 解析器，并在构建时将代码块渲染为带 token 类名的 HTML 标签，通过 CSS 变量适配暗色/亮色模式，显著提升页面加载速度。
  4. 评论系统基于 GitHub Issues，无需第三方服务。 每篇文章的评论按钮链接到新建 Issue 页面，页面加载后通过 GitHub API 自动搜索匹配的现有 Issue，避免重复创建讨论。
