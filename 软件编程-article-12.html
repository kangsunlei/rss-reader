高效 CI 加速实践：智能分片与并行构建

11/16/2026, 12:44:07 PM

📌 一句话摘要

作者分享了加速前端 CI 的实用方法，包括智能测试分片、diff 触发测试、工具替换和全流程并行等技巧。

📝 详细摘要

本推文详细介绍了加速前端 CI 流水线的实用技巧：1. 将测试按历史耗时智能分片并行，使各分片时间更均衡；2. PR 只运行受影响的测试，通过静态分析 import graph 决定执行范围；3. 替换工具提升速度，tsc 改为 bun check，lint 使用 oxlint；4. 利用并行执行 lint、类型检查、build、test 四个环节。

💡 主要观点

  1. 智能测试分片并行运行 根据历史测试耗时记录，将测试重新分配到各分片，使每个分片的总时间尽量接近，避免时间消耗不一致。
  2. diff 触发受影响测试 通过分析代码 diff，仅执行与修改相关的测试，而非全量运行，结合静态分析 import graph 确定测试范围。
  3. 工具替换提升执行效率 将 tsc 替换为 bun check，lint 使用 oxlint 等更快的工具，显著缩短类型检查和代码检查时间。
  4. 四大环节全链路并行 将 lint、类型检查、build 和 test 四个步骤并行执行，最大化流水线吞吐，显著缩短总耗时。

💬 文章金句

  • 把测试按照历史耗时智能分片并行跑，让每个分片的总时间尽量接近
  • PR 只跑受影响的测试，根据代码 diff 只执行相关测试
  • tsc 改成 bun check，lint 使用 oxlint
  • 所有都并行，lint/类型检查/build/test 同时跑
