📌 一句话摘要

SnapFind 是一款功能极简的开源 Windows 工具，支持本地离线 OCR 文字识别，无需联网即可从屏幕截图中提取文字。

📝 详细摘要

SnapFind 是一款功能极简的开源 Windows 工具，专注于屏幕区域的离线 OCR 文字识别。它内置 RapidOCR（PP-OCRv4）模型，支持 Windows 10、11，提供安装版与便携版。用户只需按下 Ctrl + Alt + S 快捷键选取屏幕区域，即可自动完成文字识别，识别结果可自动复制到剪贴板。整个过程无需联网，完全本地离线处理，采用 MIT 协议开源。

💡 主要观点

  1. 极简的本地离线 OCR 工具 SnapFind 只做一件事：从屏幕上提取文字，无需联网，完全本地离线处理，适合隐私敏感或无网络环境。
  2. 基于 RapidOCR (PP-OCRv4) 离线模型 内置成熟的 PP-OCRv4 模型，支持中英文混合识别，准确率较高，无需依赖云端 API。
  3. 简便的交互操作流程 默认使用 Ctrl + Alt + S 快捷键选区，松手后自动识别并复制到剪贴板，操作无需额外配置。
