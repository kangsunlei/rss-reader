Azure Logic Apps 为智能体工作流新增沙箱化代码解释器

6/1/2026, 8:03:00 AM

📌 一句话摘要

微软为 Azure Logic Apps 引入代码解释器，使 AI 智能体能在 Hyper-V 隔离沙箱中生成并执行 Python、JavaScript、C# 和 PowerShell 代码，实现工作流内的数据转换与分析。

📝 详细摘要

本文介绍了微软为 Azure Logic Apps 新增的代码解释器功能。该功能由 Azure 容器应用（ACA）动态会话提供支持，允许 AI 智能体在 Hyper-V 隔离沙箱中生成并执行多种编程语言代码。文章详细阐述了其技术架构、安全隔离机制（Hyper-V 硬件级隔离）以及实际应用场景，例如智能体可自动处理电子表格、生成数据可视化图表。文章还对比了微软与 Cloudflare、Google 在沙箱方案上的技术差异，并分析了 Logic Apps 在微软智能体平台生态中的独特定位，即作为集成密集型工作流的首选平台。该功能目前处于公开预览阶段。

💡 主要观点

  1. Azure Logic Apps 新增代码解释器，支持 AI 智能体在沙箱中执行代码。 该功能允许大语言模型在 Hyper-V 隔离的沙箱中生成并运行 Python、JavaScript、C# 和 PowerShell 代码，用于数据转换、分析和可视化，无需用户手动编写代码。
  2. Hyper-V 硬件级隔离提供了强大的安全边界。 每个代码解释器会话都在独立的 Hyper-V 微虚拟机中运行，即使生成的代码包含恶意指令，也无法影响主机系统或外泄数据，确保了执行环境的安全性。
  3. Logic Apps 在微软智能体平台中定位为集成密集型工作流平台。 相比 Microsoft Foundry 和 Copilot Studio，Logic Apps 凭借 450 多个连接器和内置治理、重试逻辑，更适合需要跨企业系统（如 ERP、CRM）进行编排的复杂场景。

💬 文章金句

  • 这让代码解释器拥有了媲美 ChatGPT 高级数据分析工具的强大能力，并且该功能已直接集成到 Logic Apps 运行时中。
  • 生成的代码在隔离环境中运行，而不是在主机进程中运行，因此即使出现类似 import os; os.remove('/') 这类模型幻觉产生的恶意代码也不会造成任何破坏。
  • 当你的场景需要跨多个企业系统、ERP、CRM、数据库、API 进行编排，并且需要内置治理、重试逻辑和审计跟踪时，Logic Apps 智能体循环最为适合。
