37signals 全面采用 Omarchy

8/9/2025, 3:24:12 PM

📌 一句话摘要

37signals 正式将其运维和 Ruby 团队迁移到 Omarchy Linux 和 Framework 笔记本电脑，旨在提升控制力、提高性能，并与他们的开源理念保持一致。

📝 详细摘要

David Heinemeier Hansson 宣布 37signals 的一项战略决策：在未来三年内，其运维和 Ruby 编程团队将全面采用 Omarchy（他们基于 Arch 的 Linux 发行版）和 Framework 笔记本电脑。他挑战了普遍接受的 macOS / Windows 强制规定，并对 Linux 规范经常受到的质疑提出异议，认为 Linux 因其开源特性而提供无与伦比的控制力。虽然 DHH 承认与 Apple 芯片相比，电池续航时间略有减少等小缺点，但他强调了显著的生产力提升，尤其是在原生 Docker 支持和 PC 硬件上更快的 Ruby on Rails 测试套件执行方面，他声称其性能甚至优于最快的 M4 Max Mac。此举反映了 37signals 长期以来秉持的理念，即采用具有挑战性但最终能带来更大赋能的技术，这也让人想起他们早期对 Ruby 的投入和信任。

💡 主要观点

  1. 拥抱 Linux 提供了优于封闭源代码操作系统的控制权和自主性。 Linux 的开放性提供了完全的代码访问权限，从而实现了强大的定制和问题解决能力，这与商业替代方案不同，完全符合 37signals 的理念。
  2. 在 PC 硬件上切换到 Linux 可以显著提高开发人员的生产力。 原生 Docker 支持和在 Framework 台式机上更快的 Ruby on Rails 测试套件执行甚至优于高端 Mac，直接改善了开发周期和效率。
  3. 37signals 提倡选择具有挑战性但能带来长期效益的技术，即使初期面临困难。 37signals 采用 Ruby 等新兴技术以及现在的 Linux 的历史，反映了对能够提供更大控制和潜力的工具的承诺，即使最初存在障碍。
