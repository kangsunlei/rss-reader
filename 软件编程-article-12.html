GPT-5 与 Claude Code Opus 4.1：复杂编程任务实测对比

8/9/2025, 2:02:23 AM

📌 一句话摘要

一位开发者通过实际测试发现，在处理复杂 3D 渲染项目时，Claude Code Opus 4.1 表现远超 GPT-5，后者甚至可能破坏现有代码，引发对 AI 模型实际编程能力的讨论。

📝 详细摘要

这条推文引用了一位开发者对 GPT-5 和 Claude Code Opus 4.1 在实际编程任务中的详细对比测试。该开发者让模型从零开始构建复杂的 3D 生化机制渲染，结果显示 Claude Code Opus 4.1 能够有效接近可行方案，即使在极少提示下。然而，当尝试用 GPT-5 修复问题时，GPT-5 不仅未能修复，反而主动破坏了正常工作的代码。测试结论指出，虽然 GPT-5 在简单任务上尚可，但在从头开始的复杂项目构建和理解现有代码库方面，Claude Code Opus 4.1 明显更优。推文质疑了对 GPT-5 的过度宣传，并强调了对 AI 模型实际能力的“祛魅”视角。
