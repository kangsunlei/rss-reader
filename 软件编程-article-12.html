ByteBrain x 清华 VLDB25｜时序多模态大语言模型 ChatTS

📌 一句话摘要

ChatTS：基于纯合成数据训练的首个时间序列原生多模态大语言模型，入选 VLDB 2025。

📝 详细摘要

文章介绍了字节跳动与清华大学联合提出的 ChatTS，一个专为理解和推理时间序列数据设计的多模态大语言模型。针对时序数据缺乏大规模对齐训练数据的痛点，ChatTS 创新性地采用纯合成数据进行微调。该方法通过属性驱动的时间序列生成和 TSEvol 问答扩展机制，构建了高质量的多变量时序问答数据集。模型基于 Qwen2.5-14B 并设计了原生时序输入编码方式。实验结果显示，ChatTS 在时序属性识别和复杂推理任务上显著优于 GPT-4o 及现有基线方法，尤其在多变量场景下优势明显。文章表明，纯合成数据训练范式在时序多模态 LLM 构建中具有高度潜力，并已成功入选 VLDB 2025。

💡 主要观点

  1. 构建原生时序多模态 LLM 克服现有方法局限 区别于文本、图像或 Agent 方式，ChatTS 能原生处理时序数据数组输入，避免信息损失和工具依赖，实现端到端问答推理。
  2. 首创纯合成数据驱动的时序 MLLM 训练范式 通过属性控制的时间序列生成与 TSEvol 问答演化机制，有效解决了时序-文本对齐数据稀缺问题，支撑模型训练。
  3. ChatTS 在时序理解与推理任务上显著超越基线 在单、多变量属性识别、归纳、因果等任务中表现出更高的准确率和稳定性，尤其擅长捕捉多变量间关联。
  4. 原生时序模态输入带来性能及成本双重优势 相比文本编码输入，原生时序模态输入对于多变量任务尤其有效，且能显著降低 token 成本开销，提升实用性。

💬 文章金句

  • 我们提出了 ChatTS ，一个基于纯合成数据（synthetic data）微调的具备时间序列理解与推理能力的多模态大模型，该模型在多个真实和合成数据集上取得的显著效果提升。
  • 是否可以构建一种 "时间序列原生"的多 模态 LLM ，使其像处理图像一样，能够原生地理解时间序列的形状、波动与语义含义，并进行进一步的问答和 推理 ？
  • 为了突破训练数据匮乏这一核心瓶颈，我们从"合成"出发，设计了一整套基于属性控制的时间序列生成与对齐框架。
  • ChatTS 在所有指标上均大幅超越 GPT-4o 及其他基线方法，分类任务 F1 提升 46%--75%，数值任务相对准确率提升超过 80%。
