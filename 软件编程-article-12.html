谁是 Agent 最强守门员？首个 Agent 技能安全评测基准 SkillTrustBench 正式发布

6/16/2026, 9:33:00 AM

📌 一句话摘要

腾讯朱雀实验室联合港中深发布首个面向 Agent 技能安全评测的基准 SkillTrustBench，从 6 万+ 真实 Skill 中构建 5520 个用例，覆盖九大威胁类型，首期评测揭示高召回不等于可落地的行业困境。

📝 详细摘要

本文由腾讯朱雀实验室与香港中文大学（深圳）联合发布，正式推出 SkillTrustBench——首个面向真实落地场景、兼顾 Agent Skills 安全可信度与外部扫描方案检测效能的双重评测基准。文章首先梳理了 Agent Skill 安全威胁的严峻现状：2026 年初的 ClawHavoc 事件导致 1184 个恶意 Skill 上架，Snyk 报告显示 36.82% 的 Skill 存在安全问题，腾讯朱雀实验室全量扫描发现五万个 Skill 中 74.6% 声明了网络请求权限，且外联通道高度分散。接着指出当前扫描方案的不足：不同工具间阳性样本重合度最高仅 10.4%，81.9% 的被标记样本只被单一方案发现，且攻击者已开始利用输入截断、文件类型盲区、社会工程等手段绕过检测。SkillTrustBench 从 62，652 个真实 Skill 中提炼出 5，520 个评测用例，覆盖九大类威胁（T01-T09），特别引入「T09 不安全编码行为」以评估非恶意但存在安全缺陷的 Skill。首期评测对比了 Skill Vetter、Cisco Skill Scanner、NVIDIA SkillSpector 三款开源方案，以及 Claude Opus 4.6、GLM 5.1、DeepSeek V4 Flash 等模型底座的表现，发现高召回往往伴随高误报，真正可落地的方案需要在召回与误报之间取得平衡。

💡 主要观点

  1. Agent Skill 安全威胁已呈现规模化、矩阵化生产迹象。 五万个 Skill 背后 Top 20 发布者合计发布 12.9%，极端账号日均发布 10.6 个，多组账号矩阵表明生态已具备批量制造、投放、伪装的条件。
  2. 现有扫描方案间缺乏共识，阳性样本重合度极低。 OpenClaw 官方数据显示，任意两类扫描的阳性样本重合度最多 10.4%，81.9% 的被标记样本只被单一方案发现，行业亟需统一评测标尺。
  3. 高召回不等于可落地，误报控制是生产环境的前提。 Cisco Skill Scanner 召回率不错但误报率达 24%，高误报会导致用户忽略安全提示；Skill Vetter + Hermes Agent 误报最少，综合表现更优。
  4. 非恶意 Skill 同样存在严重安全缺陷。 大量正常开发的 Skill 存在硬编码凭证、敏感权限过度声明、缺乏输入校验等不安全编码行为，可能被黑客通过提示词注入劫持。

💬 文章金句

  • 能抓住恶意样本是第一步。能放过正常样本，才是进入生产流程的前提。
  • 不同扫描方案看到的是不同风险切面，甚至对同一批样本的判断也缺少稳定共识。
  • Agent Skill 安全扫描的核心问题已从有没有工具，迈向如何证明有效的新阶段。
