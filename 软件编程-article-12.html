Uno Platform 6.6 发布：Android 启动性能最高提升 61%

8/18/2026, 5:40:00 AM

📌 一句话摘要

Uno Platform 6.6 发布，引入原生 AOT 提升 Android 启动性能最高 61%，新增可选 Vulkan 渲染并简化 XAML 与 AI 工作流。

📝 详细摘要

Uno Platform 6.6 在 Windows、WebAssembly、Android、iOS、macOS 和 Linux 五大平台上带来原生 AOT 发布、可选的 Vulkan 渲染后端以及框架模型上下文协议（MCP）服务器的自动注册。该版本通过隐式提供标准 WinUI 和 x: 命名空间简化 XAML 编写，允许纯 XAML 页面存在；同时扩大了 WinUI API 的跨平台覆盖，改进了无障碍支持（屏幕阅读器可访问 Windows、macOS 和 WebAssembly 界面）并完善了多语言文本处理（IME 组合输入、自动字体回退）。性能方面，原生 AOT 在 Android 上可实现最高 61% 的启动提升，Vulkan 在某些测试中将每帧渲染成本降低多达 50%。文章还说明了升级路径和依赖变更，并指向官方公告、GitHub 发布说明和文档获取更多细节。

💡 主要观点

  1. 原生 AOT 提升 Android 启动性能最高 61%， iOS 提升 21%。 Uno 报告称在使用 .NET 10 的 Chefs 示例应用中，原生 AOT 使 Android 启动性能提升幅度达 61%， iOS 为 21%，实际效果取决于应用结构、硬件和部署配置。
  2. 新增可选 Vulkan 渲染后端，可降低每帧渲染成本最高 50%。 据 Uno 团队称，在 Windows、Linux 和 Android 上引入的可选 Vulkan 后端在某些测试中将每帧渲染成本降低多达 50%，适用于动画或图形密集型应用。
  3. 简化 XAML 编写：隐式命名空间及自动生成 code‑behind。 通过隐式提供标准 WinUI 表示命名空间和 x: 命名空间，以及让声明 x:Class 的页面自动获得生成的代码隐藏类，开发者可使用纯 XAML 页面而无需空的 .xaml.cs 文件。
  4. AI 辅助工作流：App MCP 和 Docs MCP 服务器自动注册到支持的智能体。 Uno 的 App MCP 向智能体开放正在运行的应用程序以进行检查和交互；Docs MCP 提供对最新 Uno 文档的访问，支持的工具包括 Visual Studio、VS Code Copilot、Claude Code、Cursor、Codex CLI 和 Gemini CLI。
  5. 扩大无障碍支持和多语言文本处理。 通过 Skia 渲染的应用程序现在可在 Windows、macOS 和 WebAssembly 上被屏幕阅读器访问；所有主要平台提供完整的 IME 组合输入功能，并引入自动字体回退以支持多书写系统界面。

💬 文章金句

  • Uno 报告称启动性能的提升幅度从 iOS 上的 21% 到 Android 上的 61% 不等，不过结果将取决于应用程序结构、硬件和部署配置。
  • 据 Uno 团队称，在某些测试中，Vulkan 将每帧渲染成本降低了多达 50%。
  • 通过隐式提供标准 WinUI 表示命名空间和 x: 命名空间，简化了 XAML 编写。
  • 此外，声明 x:Class 的页面现在可以自动获得生成的代码隐藏类，从而允许仅包含 XAML 的页面存在，而无须再提供一个空的 .xaml.cs 文件。
  • 通过 Skia 渲染的应用程序也获得了更广泛的无障碍支持。屏幕阅读器现在可以访问 Windows、macOS 和 WebAssembly 上的 Uno 界面。
