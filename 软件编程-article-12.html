攻击者爆破微软 SQL 服务器，猜解密码植入挖矿远控程序

11/14/2026, 10:00:00 AM

📌 一句话摘要

攻击者通过暴力破解公网暴露的微软 SQL Server 弱口令，利用 xp_cmdshell 权限植入门罗币挖矿程序与 Gh0st RAT 远控木马。

📝 详细摘要

本文分析了一起针对公网微软 SQL Server 的高危攻击活动。攻击者首先利用 Go 语言编写的扫描器定位开放 1433 端口的主机，随后使用包含 2700 多个密码的字典进行高并发爆破。一旦入侵成功，攻击者通过 T-SQL 开启 xp_cmdshell 执行系统命令，植入伪装成系统进程的下载器，最终部署门罗币挖矿程序以窃取算力，以及 Gh0st RAT 变种木马以实现远程控制和数据窃取。文章详细拆解了从扫描、爆破到持久化植入的完整感染链，并提供了防御建议与 IoC 指标。

💡 主要观点

  1. 利用高并发字典爆破实现初始入侵 攻击者使用内置 Naabu 扫描器的 dllhost.exe 定位 1433 端口，并利用 dwm.exe 启动多达 500 个线程，尝试 2700 组常见用户名和密码进行暴力破解。
  2. 滥用 T-SQL 扩展功能获取系统权限 登录成功后，攻击者执行 2018.sql 脚本开启 xp_cmdshell 功能，使 SQL Server 能够直接执行 Windows 操作系统命令，从而下载并运行恶意载荷。
  3. 部署双重恶意载荷实现算力窃取与远程控制 植入的载荷包括一个经过加壳保护的门罗币挖矿程序（伪装成 Edge 更新）和 Gh0st RAT 变种（winlogon.exe），后者支持键盘记录、文件管理及窃取 QQ 数据。
  4. 通过多种手段实现持久化与规避检测 攻击者通过创建伪装成微软更新的计划任务、修改注册表启动项、注册系统服务以及检测 78 种安全产品进程名来确保木马的长期运行并规避杀软。

💬 文章金句

  • 攻击者使用包含超过 2700 个密码的字典尝试登录，成功后在被控机器上安装加密货币挖矿程序和远程访问木马（RAT）。
  • 一旦登录成功，工具就会在服务器上执行名为 2018.sql 的文件。文件中的命令会开启 xp_cmdshell 功能，允许 SQL Server 直接执行 Windows 系统命令。
  • 其中一个载荷名为 MicrosoftEdgeUpdate.exe，本质上并非 Edge 更新程序，而是经过 Themida 和自定义 LZSS 两层加壳保护的门罗币挖矿程序。
