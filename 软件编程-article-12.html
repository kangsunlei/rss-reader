一句话让 Claude Code 生成轻量动画动效，好玩好玩。

6/29/2026, 6:21:00 AM

📌 一句话摘要

本文介绍 Text-to-Lottie 开源项目，让 AI Agent（如 Claude Code）通过自然语言指令生成生产级 Lottie 动效，并自带播放器实现闭环验证。

📝 详细摘要

文章首先简介 Lottie 动画格式的优势与应用场景，指出其创作与集成门槛较高。随后重点介绍 YC 孵化公司 DiffusionStudio 开源的 Text-to-Lottie 项目，用户可以一行命令将其作为 Skill 集成到 Claude Code 中，通过自然语言描述生成 Lottie JSON 动效。文章对比了直接让 AI 写 JSON 与使用本项目的区别，强调项目自带 Vite + SolidJS 播放器实现实时预览、Agent 可通过 /__context 端点自检播放状态、支持帧级审查与 live reload，形成「写→看→改」闭环。最后给出官方五条 Prompt 心法（提供真实素材、使用动效术语、模拟镜头运动、声明控制项、指定帧率时长），并说明复杂动效仍需人工微调。整体为项目介绍与推广性质。

💡 主要观点

  1. Text-to-Lottie 项目让 AI Agent 直接生成生产级 Lottie 动效，降低动画创作门槛。 用户通过自然语言描述，AI 可生成完整的 Lottie JSON 文件，无需手动编写复杂 JSON 或依赖设计师从 After Effects 导出。
  2. 项目提供了完整的闭环验证工具，包括播放器、自检端点、帧级审查和 live reload。 这些机制让 AI 能自己检查生成效果并迭代，解决了以往 AI 动效生成中“盲写”的问题，提升了生成质量。
  3. 官方提示使用真实素材、动效术语、镜头运动等技巧可显著提升 AI 生成质量。 遵循这些 Prompt 心法（如提供 SVG、声明 ease-in/ease-out、模拟推拉摇移镜头）能使 AI 更准确地理解需求，生成更专业的动画效果。
  4. 当前 AI 生成复杂动效仍需人工微调，但已能高效完成基础动画。 文章指出粒子、精细形变、复杂物理动效仍需手动调整，但该项目提供的「写—看—改」闭环思路对降低动效制作门槛具有参考价值。
