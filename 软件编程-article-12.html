Agent Browser：基于 Accessibility Tree 的高效 AI 浏览器自动化工具

2/26/2026, 12:19:17 PM

📌 一句话摘要

Viking 推荐使用 Agent Browser 进行浏览器自动化，通过 Accessibility Tree 显著降低 Token 消耗并提升 AI 脚本稳定性。

📝 详细摘要

推文详细介绍了 Agent Browser 工具在 AI Agent 操纵浏览器方面的优势。该工具的核心创新在于使用 Accessibility Tree（无障碍树）和语义引用（如 @e1、@e2）代替完整的 DOM 或 HTML 结构，将单次快照的 Token 消耗控制在 200-500 之间。这种方法利用自然语言定位，使 AI 编写的脚本能更好地应对前端结构的变动。作者还分享了其高效工作流：先由 Agent 跑通真实流程，再据此编写 Playwright 的 e2e 测试脚本，极大提升了开发效率。
