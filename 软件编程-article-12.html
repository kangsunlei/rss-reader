Pub/Sub 单消息转换

6/9/2025, 12:00:00 AM

📌 一句话摘要

新的 Pub/Sub 单消息转换功能可以直接在服务内部进行轻量级数据修改。

📝 详细摘要

Google Cloud 推出了 Pub/Sub 的单消息转换 (SMTs)，通过允许直接在服务内部修改消息来简化流式数据管道。首个 SMT 功能，即 JavaScript 用户定义函数 (UDFs)，现已正式发布。UDFs 实现了灵活、轻量级的转换，例如格式转换、基于数据的增强过滤以及 PII 数据遮盖和编辑，无需为了这些简单任务而使用 Dataflow 或 Cloud Run 等外部服务。这种方法减少了延迟和运维开销，提升了流式架构的性能和简洁性。SMTs 可以在主题或订阅级别应用，并通过 Google Cloud 控制台或 gcloud CLI 进行配置。计划中的其他 SMTs 功能包括模式验证和 AI 推理。

💡 主要观点

  1. Pub/Sub SMTs 允许直接在服务内部进行消息转换 这套新功能通过直接在 Pub/Sub 内部执行过滤或数据遮盖和编辑等轻量级修改，简化了流式数据管道，避免使用外部处理服务。
  2. JavaScript UDFs 是首个可用的 SMT 功能 JavaScript UDFs 提供了灵活性，允许使用简单的代码片段对消息属性和数据进行自定义转换，适用于格式转换或数据遮盖和编辑等多种用例。
  3. 直接转换减少了延迟和运维开销 对于简单任务，无需使用 Dataflow 或 Cloud Run 等中间服务，这提高了端到端性能并简化了基础设施管理。

💬 文章金句

  • 今天，我们正在推出 Pub/Sub 单消息转换 (SMTs)，方便直接在 Pub/Sub 内部执行简单的数据转换。
  • Pub/Sub 单消息转换 (SMTs) 旨在提供一套功能，方便在消息实时传输过程中轻松验证、过滤、丰富和修改单个消息。
  • 首个 SMT 功能现已正式发布：JavaScript 用户定义函数 (UDFs)，它允许您通过 JavaScript 代码片段直接在 Pub/Sub 内部对消息属性、数据或两者进行简单、轻量级的修改。
  • 转换直接在 Pub/Sub 内部执行，无需维护额外的服务或基础设施来进行数据转换。
  • 通过避免为轻量级转换使用额外产品，流式架构的端到端延迟得到了改善。
