Toolbox App 2.6 发布，支持远程开发 | Toolbox App 博客

4/15/2025, 10:02:45 AM

📌 一句话摘要

JetBrains Toolbox App 2.6 发布，引入远程开发支持和插件 API，简化远程开发流程，并增强在 Windows ARM64 上的性能，改进用户体验。

📝 详细摘要

JetBrains Toolbox App 2.6 版本发布，重点在于引入对远程开发的支持，允许用户管理本地和远程服务器上的 JetBrains 工具和项目。该应用支持连接到 Windows、macOS 和 Linux 等不同的主机平台，并使用集成的 OpenSSH 实现安全的 SSH 连接，从而提供安全灵活的远程连接能力。Toolbox App 还支持通过 Coder、Gitpod 和 CodeCanvas 等提供商连接到环境。此外，新版本还引入了插件 API，允许合作伙伴定制和扩展其功能。Toolbox App 现在可以在 Microsoft Store 中找到，并且原生支持 Windows ARM64 设备，同时用户可以更改界面中的字体大小。早期用户的反馈积极，认为该功能对于远程 IDE 的启动非常方便。

💡 主要观点

  1. Toolbox App 2.6 引入远程开发支持，显著简化远程开发流程，提高了开发效率 新版本允许用户像管理本地 IDE 一样，轻松地在远程主机上安装、访问、更新和监控 JetBrains IDE。
  2. 插件 API 扩展了 Toolbox App 的功能，可以集成第三方远程开发平台 通过与 Coder、Gitpod 和 CodeCanvas 等平台的合作，Toolbox App 可以更好地适应特定的工作流程和远程环境。
  3. Toolbox App 2.6 在 Windows ARM64 上原生运行，性能得到提升 新版本针对 Windows ARM64 架构进行了优化，提供更好的性能，并改进了用户体验。

💬 文章金句

  • Toolbox App 2.6 introduces support for remote development， allowing you to manage JetBrains tools and projects both locally and on remote servers.
  • The Toolbox App's remote development support leverages OpenSSH， offering enterprise-level security and flexibility.
  • Toolbox App 2.6 introduces a Plugin API， which allows approved partners to customize and add to its functionality to match specific workflows and remote environments.
