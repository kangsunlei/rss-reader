📝 详细摘要

本文盘点了 2025 年 5 月 PHP 生态系统的最新进展。主要亮点包括庆祝 PHP 成立 30 周年，以及针对 PHP 8.1、8.2、8.3 和 8.4 发布的多个安全更新，解决了关键漏洞。讨论了 PHP 基金会的首次外部安全审计结果，确认已修复的问题。重点介绍了值得关注的新工具和受支持的工具，例如 FrankenPHP 的官方支持、用于在 Node.js 中运行 PHP 的 php-node，以及 NativePHP 和 Boson 的桌面应用开发更新。探索了 PHP 的 AI 工具的日益增长的态势，包括 MCP 服务器的实现和大型语言模型（LLM）框架。还涵盖了 Laravel 和 Symfony 等流行框架的更新，以及各种其他技术文章和即将举行的 PHP 会议列表。本文为 PHP 专业人士提供了一种简洁的方式来了解社区和技术进步。

💡 主要观点

  1. 多个 PHP 版本收到了关键的安全更新。 发布了 PHP 8.1.32、8.2.28、8.3.19 和 8.4.5，以修复最近安全审计发现的多个漏洞，强调了升级的重要性。
  2. 像管道操作符 v3 和新的数组函数这样的关键 RFC 已被 PHP 8.5 接受。 PHP 8.5 将引入管道操作符（`|>`），以实现更简洁的代码链接，以及 `array_first()` / `array_last()` 函数，以提高数组操作的便利性。
  3. 新的工具涌现出来，用于在不同的环境中运行 PHP，包括 Node.js 和桌面应用。 像 php-node、NativePHP 和 Boson 这样的项目展示了在传统 Web 服务器之外，部署和集成 PHP 的创新方法，利用了 Rust、Electron 和 Webview 等技术。
  4. 将 AI 和 LLM 集成到 PHP 应用程序中的生态系统正在迅速扩展。 新的库、MCP 服务器实现和 ONNX 运行时绑定使 PHP 开发人员可以更轻松地直接在 PHP 中构建 AI 驱动的功能。
