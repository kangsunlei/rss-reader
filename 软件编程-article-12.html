Anthropic 宣布 Claude 订阅计划新增程序化调用专用额度

5/14/2026, 12:39:23 AM

📌 一句话摘要

Anthropic 将从 2026 年 6 月 15 日起，为所有付费版 Claude 计划增加月度专用额度，用于 Agent SDK、Claude Code 等程序化调用场景，降低个人开发者和团队构建 Agent 工作流的门槛。

📝 详细摘要

该推文详细解读了 Anthropic 的一项重大订阅策略调整：从 2026 年 6 月 15 日起，所有付费 Claude 计划（Pro、Max、Team、Enterprise）将在现有对话额度之外，增加一个专门用于程序化调用的月度专用额度。此额度覆盖 Agent SDK、claude -p 命令行工具、Claude Code 在 GitHub Actions 中的任务以及基于 Agent SDK 的第三方应用。这标志着程序化访问能力被正式捆绑进订阅模式，用户无需再单独申请 API Key 和计费账户即可运行自动化工作流。同时，Claude Code 的每周使用限额从 6 月起临时提升 50%，持续到 2026 年 7 月 13 日。两项变化叠加，对个人开发者和团队而言，近期是加大 Claude 使用密度的好时机。推文引用了 ClaudeDevs 的官方公告，并进行了深入解读。
