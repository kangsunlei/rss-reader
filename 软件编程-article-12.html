📌 一句话摘要

本文介绍了名为 rust-anything 的开源工具，它帮助将旧项目的性能瓶颈代码迁移到 Rust，实现显著的性能提升。

📝 详细摘要

rust-anything 是一个开源项目，利用 Claude Code 将性能较慢的旧代码（如 Prettier、json-server、x18n）迁移到 Rust 实现。通过逐字节对比测试，确保功能一致的同时显著提升性能：Prettier 从 128.6 秒降至 6.9 秒，快 19 倍；json-server 内存占用从 74MB 降至 3.5MB；x18n 搜索延迟从 10ms 降至 0.5ms。该工具通过自动化测试输入输出比对，帮助开发者精准定位并重构性能瓶颈。

💡 主要观点

  1. rust-anything 通过自动化测试确保迁移后功能一致 工具会先用原代码运行大量测试输入，记录输出和错误情况；迁移后再用相同输入测试 Rust 版，逐条对比结果，确保功能完全一致。
  2. 迁移后显著提升性能和资源占用 Prettier 性能提升 19 倍（128.6 秒→6.9 秒），json-server 内存从 74MB 降至 3.5MB，x18n 搜索延迟从 10ms 降至 0.5ms，证明 Rust 在高性能场景的优势。
  3. 作者用 Claude Code 完成约 17 小时迁移工作 项目作者花约 17 小时使用 Claude Code 辅助完成 Prettier 等项目的 Rust 迁移，展示了 AI 编程工具在实际开发中的高效应用。
