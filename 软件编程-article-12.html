“AI 火了，我们却快完了！”顶级开源框架 Tailwind 之父含泪裁掉 75%兄弟：半年后，这个项目可能就没了

1/8/2026, 5:25:00 AM

📌 一句话摘要

开源前端框架 Tailwind CSS 的创始人 Adam Wathan 透露，因 AI 编程工具的广泛使用导致文档流量和商业收入急剧下滑，公司被迫裁员 75% 的工程师，并面临仅剩半年生存期的严峻挑战。

📝 详细摘要

InfoQ 报道，前端著名开源项目 Tailwind CSS 正面临严峻生存危机。尽管其作为 UI 构建的“默认选项”在 AI 编程工具中被广泛使用，导致流行度空前，但创始人 Adam Wathan 表示，这种成功并未转化为商业回报。AI 通过直接爬取文档和生成代码，减少了用户对其官方文档的访问，进而降低了付费产品的曝光和收入。文档流量下滑 40%，收入锐减近 80%。为求生存，Tailwind Labs 不得不裁掉 75% 的工程团队（即 4 名工程师中的 3 名），目前仅剩 3 位合伙人和 2 名员工。Adam Wathan 强调，当前首要任务是让公司活下去，以避免项目最终无人维护成为“弃置软件”，并表示开源项目的受欢迎度与商业可持续性之间已出现反向关系。

💡 主要观点

  1. 开源框架 Tailwind CSS 尽管在 AI 时代变得异常流行，但其商业收入却遭受严重冲击。 AI 编程工具直接利用 Tailwind CSS 的底层优势生成代码，导致用户不再直接访问官方文档，进而影响了付费产品的推广和收入，开源的成功与商业成功出现反向关系。
  2. 营收持续下滑迫使 Tailwind Labs 裁减 75% 的工程团队，公司面临仅半年现金流的困境。 创始人 Adam Wathan 透露，公司收入已累计下滑近 80%，文档流量减少 40%。为避免现金流断裂，确保留守员工工资及体面遣散，不得不进行大规模裁员。
  3. AI 在前端开发中扮演“无代码工具包”角色，提高了开发效率，但对内容生态造成负面影响。 AI 模型擅长利用 Tailwind 高度一致的 class 命名和样式模式，使其成为生成 UI 的“默认选项”。这虽加速了开发，但也削弱了开发者对原始文档和相关服务的需求。
  4. 开源项目的商业可持续性面临新挑战，如何在高度 AI 化的环境中找到新的商业模式成为关键。 Tailwind 的案例揭示了 AI 浪潮下，即使是最受欢迎的开源项目也可能因商业模式受侵蚀而面临生存危机，促使团队重新思考如何利用 AI 来实现商业化。

💬 文章金句

  • 因为这件事，我感觉自己像个失败者：我做出了一个几乎'统治世界'的开源 CSS 框架，用的人越来越多、越来越火，但商业上的成功，却和开源的成功呈现出一种反向关系。
  • 就在昨天，我们工程团队里有 75% 的人失去了工作，这是 AI 对我们造成的残酷冲击。
  • 我们的文档流量相比 2023 年初已经下滑了大约 40%。而文档是他们的唯一分发渠道，没有客户，就意味着 '我们根本负担不起继续维护这个框架'。
  • 收入并没有触底企稳，而是以几乎固定的绝对值持续下滑------这意味着，从比例上看，下滑速度只会越来越快。如果假设什么都不改变，那么大约 6 个月之后，公司就将无法继续支付工资。
  • 现在，开源项目越受欢迎，生意反而越艰难。这真的很残酷。这就是现状。
