CLion 2025.1 发布：支持 CLion Nova 项目外文件 | CLion 博客

4/16/2025, 12:36:35 PM

📌 一句话摘要

CLion 2025.1 增强了项目外文件支持、调试器功能，并引入了 STM32 嵌入式开发新特性。

📝 详细摘要

CLion 2025.1 版本带来了多项重要更新。CLion Nova 增强了项目外文件的代码分析和辅助功能，并提供 Objective-C 的初步支持。调试器方面，新增 Qt 渲染器以更友好的方式展示 Qt 变量，并支持自定义 LLDB 调试器、.natvis 文件位置和 OpenCV 图像查看。嵌入式开发方面，引入了专为 STM32 芯片设计的 ST-LINK 调试服务器模板，并改进了 STM32CubeMX 项目创建流程。此外，新版本还增强了对 Zephyr West 的支持，并捆绑了包含 CMake 预设 v10 支持的 CMake v3.31.4。AI 助手的所有功能现在都免费提供，并新增了自然语言提示处理功能。这些更新旨在提升 C 和 C++ 开发者的效率和体验。

💡 主要观点

  1. CLion Nova 扩展了对项目外文件的支持，提升了代码编辑的灵活性。 新版本为未包含在项目中的头文件和源文件提供完整的代码分析和辅助功能，方便开发者快速编辑和查看代码。
  2. 调试器增强了 Qt 应用的调试体验，并支持自定义 LLDB 调试器。 Qt 渲染器以更易读的方式展示 Qt 变量，简化了 Qt 应用的调试过程。支持自定义 LLDB 调试器，让开发者可以选择最适合项目的版本。
  3. 新增 ST-LINK 调试服务器模板，简化了 STM32 项目的调试配置，并支持更多 STM32 芯片。 专为 STM32 芯片设计的 ST-LINK 调试服务器模板，包含必要的配置，简化了调试流程，提高了开发效率。

💬 文章金句

  • CLion Nova now provides full code analysis and code assistance for header and source files that are not included in a project.
  • Qt renderers allow you to view variables， such as `QList`， `QString`， or `QByteArray`， in a human-readable form.
  • When debugging STM32 projects， you can now use the ST-LINK debug server template， which was designed specifically for STM32 chips.
