前端周刊第 228 期：tsrs、感谢 Deno、ViteCon

10/26/2026, 1:26:00 AM

📌 一句话摘要

本期周刊重点介绍了 Cloudflare 和 VoidZero 的 TypeScript 编译器重写项目 tsrs，Deno 团队的解散及其对 Node.js 生态的贡献，Safari 的跨站追踪拦截，CrUX 对软导航的实验性支持，以及 Next.js 的高危漏洞修复。

📝 详细摘要

Cloudflare 和 VoidZero 合作推出了 tsrs，一个基于 Rust 的 TypeScript 编译器，宣称最高可将编译速度提升 8 倍，并支持 WASM 运行。Deno 团队在加入 Cloudflare 后宣布停止运行时开发，但其对 JavaScript 生态的创新影响被广泛认可。Safari 浏览器开始在域名层面拦截身份解析服务，以防止跨站追踪。CrUX 正在实验性地将软导航纳入 Core Web Vitals 评估，这将对 SPA 应用的性能评分产生影响。Next.js 发布了两个高危漏洞的修复补丁，涉及缓存函数和 SVG 图片处理。

💡 主要观点

  1. tsrs：基于 Rust 的 TypeScript 编译器 Cloudflare 和 VoidZero 开发了 tsrs，旨在通过 Rust 替代 JavaScript 提高 TypeScript 编译速度。该项目支持 WASM，并声称在某些情况下速度可提升 8 倍，目前处于实验阶段。
  2. Deno 团队解散及其影响 Deno 团队在加入 Cloudflare 后决定停止开发运行时，但其对 JavaScript 生态的贡献被高度评价。Deno 的创新推动了 Node.js 和 npm 的改进，包括模块化、权限控制和标准化。
  3. Safari 拦截跨站追踪 Safari 浏览器开始在域名层面拦截身份解析服务，防止网站通过表单数据进行跨站追踪。这一举措旨在保护用户隐私，限制追踪方的能力。
  4. CrUX 支持软导航 Chrome 用户体验报告（CrUX）正在实验性地将软导航（SPA 路由切换）纳入 Core Web Vitals 评估。这一变化将更准确地反映现代 Web 应用的性能，并可能影响 SEO 排名。
  5. Next.js 高危漏洞修复 Next.js 修复了两个高危漏洞，分别涉及 use cache 函数和 SVG 图片优化器。公开的利用代码已出现，建议用户立即更新到 16.4.1 或 15.5.28 版本。

💬 文章金句

  • Cloudflare 和 VoidZero 把 TypeScript 编译器用 Rust 重写了，叫 tsrs。官方说最高能快 8 倍，还能跑在 WASM 里。
  • Deno 团队加入 Cloudflare 后，决定收摊不搞运行时了。有人专门写了封感谢信：它的价值不光是自己活得好不好，更在于它和 Bun 一起，硬是逼着 Node 和 npm 把那些好点子一个个学了过去。
  • Safari 开始在域名层面拦截「身份解析」了。以前跨站 Cookie 被拦，追踪方就改从表单偷邮箱转成 ID 来认人。WebKit 这次直接把这类服务干掉，拿到邮箱也追不了。
  • CrUX 开始实验性地把软导航算进 Core Web Vitals 了。软导航就是 SPA 里不重新加载页面的路由切换。等明年转正，Search Console 也会跟着换，导航频繁的 SPA 分数应该会好看不少。
  • Next.js 刚补了两个高危漏洞，公开的利用代码已经放出来了。一处出在 use cache 函数上，另一处在图片优化器处理 SVG 的逻辑里。赶紧升到 16.4.1 或 15.5.28 打补丁。
