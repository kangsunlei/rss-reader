本期 Node 中文周刊汇总了 Node.js 生态的最新动态，包括 Temporal API 的推进计划、24.15.0 LTS 版本发布、多个新工具库介绍以及社区技术文章精选。

📝 详细摘要

文章是第 222 期 Node 中文周刊，由印记中文团队编辑。主要内容分为几个板块：首先介绍了 Node.js 核心进展，包括 Temporal API 计划在 Node 26 中默认启用，以及 Node.js 24.15.0 LTS 版本的发布，该版本稳定了 require(esm) 和模块编译缓存等特性。其次，文章推荐了多篇技术文章，如 OWASP NPM 安全最佳实践速查表、关于嵌套 Promise 的深度探讨等。最后，文章重点介绍了多个新发布的工具和库，例如用于 Node 端病毒扫描的 Pompelmi 1.0、解析 Office 文件的 officeParser、高性能网页 CAD 引擎 FluidCAD 等。整体内容覆盖面广，时效性强，为 Node.js 开发者提供了有价值的信息聚合。

💡 主要观点

  1. Node.js 核心特性持续演进，Temporal API 计划在 Node 26 中默认启用。 Temporal API 作为现代化日期时间处理方案已达到 stage 4，Node 社区正推进其在 V8 中默认启用，这将是 Node.js 生态的重要更新。
  2. Node.js 24.15.0 LTS 版本发布，带来多项稳定特性。 该 LTS 版本从 v25 引入了 require(esm) 和模块编译缓存的稳定支持，以及 --max-heap-size 和 OpenSSL 4.0 构建支持，对生产环境有直接影响。
  3. 社区涌现出多个实用的新工具和库，覆盖安全、文件处理、音频、CAD 等多个领域。 如 Pompelmi（病毒扫描）、officeParser（Office 文件解析）、Audio（高级音频处理）、FluidCAD（网页 CAD 引擎）等，展示了 Node.js 生态的活跃度和多样性。
  4. 技术文章精选提供了深度学习和最佳实践参考。 周刊筛选了 OWASP 安全指南、嵌套 Promise 的深度分析、AWS Lambda 连接复用陷阱等文章，为开发者提供了超越工具本身的知识深度。

💬 文章金句

  • Temporal API 旨在现代化 JavaScript 的日期时间处理，已于上月达到 stage 4。
  • Node LTS 版本从 v25 引入了多项特性，包括 require(esm) 和模块编译缓存标记为稳定版。
  • Pompelmi 1.0 实现 Node 端病毒文件扫描，独立运行，无需守护进程，按需启动 ClamAV。
  • FluidCAD 是一个将参数化 CAD 带入 JavaScript 世界的新项目，可以用代码创建/操作对象并实时预览效果。
