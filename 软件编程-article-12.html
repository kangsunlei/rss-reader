Java 新闻汇总：JDK 26 进入功能冻结期，JDK 27 专家组成立，GlassFish、TornadoVM、Spring gRPC 发布新版

12/8/2025, 2:30:00 AM

📌 一句话摘要

本文总结了 Java 生态系统中的重要更新，包括 JDK 26 进入功能冻结阶段一、JDK 27 专家组的成立以及 GlassFish、TornadoVM、Spring gRPC、Spring AI 等产品的新版本发布。

📝 详细摘要

2025 年 12 月 1 日的 Java 新闻汇总涵盖了广泛的开发进展。JDK 26 已进入功能冻结阶段一——这是一个关键阶段，在此期间不会添加新功能——并最终确定了 10 个 JDK 增强提案（JEP），预示着其预计在 2026 年 3 月正式发布。与此同时，JDK 27 专家组已正式宣布成立，抢先体验版构建也已发布。多个关键的 Java 相关项目发布了新版本：GlassFish 7.1.0 提供了错误修复、依赖项升级和 MicroProfile 4.0 实现；TornadoVM 2.0.0 引入了压缩普通对象指针（COOPs）和 GPU 原生 `Int8` 支持；Spring gRPC 1.0.0 支持 Spring Boot 4.0 和 JDK 17 基线，而 Spring AI 1.1.1 增强了与 OpenAI Java SDK 和 Azure Cosmos DB 的集成。Open Liberty 25.0.0.12 改进了安全性并解决了漏洞。Micronaut 框架 4.10.3 和 JHipster 9.0.0 Beta 1（默认为基于 TypeScript 的生成器和无区 Angular）也进行了更新，Hibernate Search 8.2.0 CR1 也提供了与 Hibernate ORM 7.2 的兼容性。

💡 主要观点

  1. JDK 26 携最终确定的 10 个 JEP 进入功能冻结阶段一。 这标志着其发布周期中的一个关键阶段，在该阶段不会添加新功能，从而明确了 2026 年 3 月正式发布版本的范围。
  2. 广泛的关键 Java 框架和运行时获得重大更新。 GlassFish、TornadoVM、Spring gRPC、Spring AI、Open Liberty、Micronaut、JHipster 和 Hibernate 等项目发布了包含错误修复、依赖项升级和新功能的新版本，涵盖了 Java 生态系统的各个方面，提升了它们的能力和相关性。
  3. 现代化和性能改进是许多更新的核心。 示例包括 TornadoVM 旨在提升内存效率的 COOPs 实现、JHipster 为提高性能而转向无区 Angular，以及 Spring gRPC 的 JDK 17 基线和 JSpecify 空安全，这反映了开发更健壮和高性能应用程序的趋势。

💬 文章金句

  • 这意味着主线源代码库已分叉到 JDK 稳定版库，并且 JDK 26 不会再添加额外的 JEP。
  • GlassFish 7.1.0 的发布带来了错误修复、依赖项升级和新功能，例如 MicroProfile 4.0 规范的实现。
  • JHipster 9.0.0 的第一个测试版发布带来了错误修复、依赖项升级和显著变化，例如使用 TypeScript 完全重新设计了 JHipster 生成器，以提高可维护性。
