big-arrow-on-the-screen：为 AI Agent 提供屏幕指引的协作工具

10/11/2026, 10:00:10 AM

📌 一句话摘要

开源工具 big-arrow-on-the-screen 能在 Mac 屏幕上绘制箭头与提示框，让 AI Agent 在遇到授权、验证码等需人工介入的场景时直观指引人类操作。

📝 详细摘要

开源工具 big-arrow-on-the-screen 解决 AI Agent 在 Mac 运行中遭遇系统授权弹窗或验证码等卡点问题。该工具不获取点击、输入和截图权限，仅在屏幕上绘制显眼箭头和提示框指向目标按钮，支持语音提示与一键复制，可供 Claude Code 和 Codex 等终端 Agent 快速调用，以极低特权实现高效的人机协同。

💡 主要观点

  1. 以最小权限实现人机安全交互 工具不点击、不打字、不截图，画箭头本身不需要系统权限，确保 Agent 不越权的同时由人类完成高危操作。
  2. 覆盖多种需人工兜底的关键场景 针对授权弹窗、两步验证、验证码与付款等操作，Agent 通过屏幕指示引导用户，并支持语音呼叫与内容一键复制。

💬 文章金句

  • big-arrow-on-the-screen 给 Agent 配了一根手指，能在 Mac 屏幕上画出大箭头、框和文字，直接指着要点的那个按钮。
  • 作者说得很直白，它从不点击、不打字、不截图，只负责指，画箭头本身也不需要任何系统权限。
