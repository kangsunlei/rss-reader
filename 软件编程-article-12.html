browser4agent：把 AI Agent 接到现成浏览器里的扩展

10/10/2026, 4:00:08 AM

📌 一句话摘要

browser4agent 是一个 Chrome/Edge 扩展，让 Claude Code 和其他 AI Agent 直接操控你已经登录的浏览器，避免每次都从头开新窗登录。

📝 详细摘要

browser4agent 是一个开源 Chrome 扩展，让 AI Agent 能够直接操控你已经在用的浏览器（Chrome、Edge 或 Firefox），并保持你的登录状态。它通过本地通信将浏览器控件暴露给 Agent，支持运行在本机或云端的 AI 服务，并提供专门的页面工具来优化网页内容的读取效率。

💡 主要观点

  1. 无缝继承登录状态 与独立浏览器实例不同，browser4agent 利用已有的浏览器扩展机制，确保 AI Agent 可以继承所有现有的登录凭证和 Cookie，无需进行冗余的登录操作。
  2. 高效的网页内容读取 该扩展包含专门的页面工具（如 YouTube 字幕解析和 Hacker News 评论抓取），能够将冗长的 HTML 页面转换为结构化的、低 token 消耗的 JSON 数据，显著提高分析效率。
  3. 广泛的兼容性 该项目支持与几乎所有主流的本地或云端 AI Agent 进行集成，包括 Claude、Codex、Cursor，并专门优化了与 NVIDIA Ising-Calibration-1.5 模型的交互。

💬 文章金句

  • browser4agent 换了个思路，做成浏览器扩展，把我们平时在用的 Chrome、Edge、Firefox 直接交给 AI Agent，登录状态都在。
  • 我觉得最有意思的是页面工具，相当于给 AI 用的油猴脚本，按网站订阅，读出来的是整理好的数据。
