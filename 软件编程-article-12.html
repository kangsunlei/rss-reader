月烧 4 万元，两工程师用 Claude Code 跑出 15 人团队效率：值不值全网吵翻了！

6/21/2025, 2:16:00 AM

📌 一句话摘要

两工程师通过重度依赖 Claude Code 等 AI Agent 实现 15 人团队效率，探讨 AI 编程新范式引发热议。

📝 详细摘要

文章深度报道了初创公司 Every 的两名工程师如何利用 Anthropic 的 Claude Code 等 AI Agent 工具，以每月数万元人民币的 AI 使用成本，实现了堪比 15 人团队的开发效率。他们认为这标志着软件开发范式的根本性转变，人类角色从编写代码转变为“指挥”AI Agent 执行从需求分析到部署上线的全流程任务，称之为“Agentic Programming”和“复利式工程”。文章详细介绍了他们的工作流程，包括语音输入触发自动化任务、Agent 进行调研和代码编写、人类在早期阶段进行严格审查等关键环节，并对比了多种主流智能编码工具的优劣。核心洞见在于 AI 应融入开发全流程，并且早期人工介入评审至关重要，这为技术从业者展示了一种未来软件开发的新可能性和潜在挑战。

💡 主要观点

  1. AI 编程应贯穿开发全流程，非仅限代码生成 利用 Agent 工具贯穿从需求研究到工作流构建、具体执行等各个环节，而非传统方式仅用于代码补全或片段生成，极大扩展了 AI 在开发中的应用范围。
  2. 人类开发者转变为“指挥家”，管理并行 Agent 完成任务 AI Agent 承担具体执行工作，人类聚焦更高层级的策略、任务分配和结果审阅，这种模式允许并行处理多个任务，显著提升整体效率。
  3. 在流程早期严格审查 AI 输出，降低返工风险 强调在 GitHub issue 文档生成等“价值最低阶段”发现并修正 AI 的潜在偏差，避免后期 Agent 在错误方向上投入资源，造成巨大浪费。
  4. 不同专长的 Agent 可协同工作，构建高效辅助系统 针对不同任务（如界面实现、代码审查、调研等）选择最合适的 Agent 工具，整合形成适应现有开发流程的强大体系，优化了工具链的使用。

💬 文章金句

  • 花了 6000 美金，多个 Agent 并行运行，一天提交了 10 个 PR，还完成重构并部署上线了。
