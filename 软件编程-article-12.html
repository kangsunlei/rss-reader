Vercel Drains 介绍：全面的可观测性数据，触手可及 - Vercel

📌 一句话摘要

Vercel Drains 现在可以将日志、OpenTelemetry 链路数据、Web Analytics 和 Speed Insights 指标统一导出到外部可观测性工具。

📝 详细摘要

认识到仅凭日志不足以理解现代应用程序的行为，Vercel Drains (之前 Log Drains 的演进) 现在提供了一个全面的解决方案，用于从 Vercel 部署将所有关键的可观测性数据 (包括日志、OpenTelemetry 链路数据、Web Analytics 事件和 Speed Insights 指标) 导出到现有的第三方可观测性平台。其核心价值在于提供跨整个请求路径 (从浏览器到动态无服务器函数执行) 的一致且相关联的信号。这种自动关联 (例如，使用 `traceId` 和 `spanId` 丰富日志) 实现了真正的端到端可观测性，使团队能够无缝地将前端性能问题 (例如 LCP 峰值) 连接到后端 API 调用或错误日志到特定请求。该平台通过自定义 HTTP 端点 (允许用户配置数据类型、采样率和格式，如 JSON、NDJSON、Protobuf) 以及与流行的可观测性供应商 (如 Datadog、Honeycomb 和 Grafana) 的直接开箱即用集成，提供了灵活性。Vercel Drains 在 Pro 和 Enterprise 计划中可用，并且按每 GB 0.50 美元的价格计费，旨在通过集中数据导出并利用 OpenTelemetry 等行业标准协议，简化和增强现代无服务器和边缘应用的可观测性策略。

💡 主要观点

  1. Vercel Drains 将不同的可观测性数据流统一到单个导出管道中。 此功能结合了日志、OpenTelemetry 链路数据、Web Analytics 和 Speed Insights 指标，为现代分布式系统提供全面的应用程序行为视图，并简化数据管理。
  2. 从 Vercel Drains 导出的数据在整个请求路径中是一致且相关联的。 从浏览器到无服务器函数执行的信号会自动丰富和链接 (例如，日志中的 traceId )，从而可以从日志无缝导航到链路数据，以进行端到端调试和问题解决。
  3. Vercel Drains 提供灵活的数据导出选项，支持自定义 HTTP 端点和开箱即用集成。 用户可以使用特定的数据类型、采样和格式配置自定义数据通道，或者利用与流行的可观测性供应商的直接集成，以简化设置并加快获得洞察的时间。

💬 文章金句
