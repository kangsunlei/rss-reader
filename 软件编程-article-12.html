三篇重磅论文，拆解 OpenViking 核心技术

10/9/2026, 11:00:00 AM

📌 一句话摘要

OpenViking 通过 VikingMem、TrieHI 和 VikingRAG 三大创新，解决了 AI Agent 在记忆管理、目录搜索和结构化文档检索中的关键问题，显著提升了办公效率和准确性。

📝 详细摘要

文章详细介绍了 OpenViking 的三项核心技术：VikingMem 实现了高效的事件-实体记忆管理，解决了 Agent 记忆重复和过时的问题；TrieHI 引入了目录感知搜索，避免了跨项目文档混淆；VikingRAG 提供了分层、按需的文档检索，大幅降低了查询时间和 token 消耗。这些技术共同构建了一个高效、准确的上下文数据库，支持 Agent 在复杂工作流中的可靠操作。

💡 主要观点

  1. VikingMem：高效的事件-实体记忆管理 VikingMem 将记忆分为事件（Event）和实体（Entity）两层，通过事件合并和实体更新，解决了 Agent 记忆重复和过时的问题。实验表明，它在 LoCoMo 评测中显著优于其他方法，查询速度快，存储效率高。
  2. TrieHI：目录感知搜索，避免文档混淆 TrieHI 通过将目录结构存储为树，并为每个文件夹生成清单，实现了快速的目录限定搜索。这避免了跨项目文档的混淆，并显著提高了搜索速度，将查询时间从毫秒级降低到微秒级。
  3. VikingRAG：分层、按需的结构化文档检索 VikingRAG 实现了 L0/L1/L2 分层检索，允许 Agent 先看简介和目录，再按需读取原文，从而节省了大量 token。VikingRAG-E 进一步引入了经验记忆，记录了之前的查找路径，提高了重复查询的效率。
