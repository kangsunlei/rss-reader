Spring Data 2024.1.6 和 2024.0.12 发布

5/16/2025, 12:00:00 AM

📌 一句话摘要

发布 Spring Data 2024.1.6 和 2024.0.12 的服务版本，包括依赖升级和问题修复，并通知 2024.0.x 版本即将停止支持。

📝 详细摘要

本文宣布发布 Spring Data 项目的服务版本 2024.1.6 和 2024.0.12。这些版本包含依赖升级，解决了回归问题，并包含了各种 Spring Data 模块的精选改进，如 JPA、MongoDB、Redis、Cassandra、Neo4j 等。该公告还包含一个重要提示，通知用户对 3.3.x 开发线（2024.0.x 发布列车）的开源支持计划于 2025 年 6 月底结束，建议用户考虑升级到最新的 3.4.x (2024.1.x) 版本。 提供了指向每个模块在这些版本中的特定版本的 Javadoc、文档和变更日志的链接。 即将发布的 Spring Boot 版本预计将包含这些新的 Spring Data 版本。

💡 主要观点

  1. Spring Data 的新服务版本 2024.1.6 和 2024.0.12 可用。 这些版本提供了重要的更新，包括依赖升级、错误修复以及各种 Spring Data 模块的细微改进，这对于维护应用程序的稳定性和安全至关重要。
  2. 对 2024.0.x (3.3.x) 发布列车的支持将于 2025 年 6 月结束。 强烈建议当前使用此旧版本的用户计划迁移到最新的 2024.1.x (3.4.x) 版本，以继续获得支持和更新。
  3. 每个模块的详细信息和更改都已链接。 本文提供了指向每个版本中包含的每个特定 Spring Data 模块版本的 Javadoc、文档和 GitHub 变更日志的直接链接，使开发人员能够检查与其用法相关的更改。
