Cloudflare OS：Cloudflare 基于能力模型构建的开源企业级 AI 平台

9/7/2026, 5:47:00 AM

📌 一句话摘要

Cloudflare 开源企业级 AI 平台 Cloudflare OS，通过能力驱动模型和安全沙箱实现个性化工作软件的自动化构建与共享

📝 详细摘要

Cloudflare 发布了 Cloudflare OS，这是一个企业级 AI 平台，使团队能够基于企业知识、专业技能和预配置的连接器自动化重复性工作流，并在安全的沙箱模型内构建个性化、可共享且可定制的工作软件。Cloudflare OS 的核心特点包括：1. 能力驱动型模型，用于执行企业策略；2. 安全的沙箱环境，确保非技术用户可以自由编程；3. 细粒度的访问控制和权限管理；4. 独立的应用程序副本，确保数据安全和环境隔离。Cloudflare OS 的发布源于内部业务扩展的挑战，旨在解决快速部署未经审核的生成式 AI 工作流的安全问题。该平台已在 Cloudflare 内部使用，显著提高了工作效率，并通过自动化审查代理实现了代码质量的提升。

💡 主要观点

  1. Cloudflare OS 是一个企业级 AI 平台，旨在通过能力驱动模型和安全沙箱实现个性化工作软件的自动化构建与共享 Cloudflare OS 使团队能够基于企业知识、专业技能和预配置的连接器自动化重复性工作流，并在安全的沙箱模型内构建个性化、可共享且可定制的工作软件。
  2. Cloudflare OS 的核心特点包括能力驱动型模型、安全的沙箱环境、细粒度的访问控制和权限管理、独立的应用程序副本 Cloudflare OS 的能力驱动型模型用于执行企业策略；安全的沙箱环境确保非技术用户可以自由编程；细粒度的访问控制和权限管理确保数据安全；独立的应用程序副本确保环境隔离。
  3. Cloudflare OS 的发布源于内部业务扩展的挑战，旨在解决快速部署未经审核的生成式 AI 工作流的安全问题 Cloudflare 内部有员工试图快速部署未经审核的生成式 AI 工作流，用于创建定制化的'超级应用'。这些脚本需要更高的管理员权限，并且可以访问数十个内部核心系统的生产环境 API 令牌。为了在不破坏安全边界的前提下满足这一需求，Cloudflare 启用了一个由人工维护的'魔法 AI 邮箱'别名，用于记录日常运营中的摩擦点。
  4. Cloudflare OS 已在 Cloudflare 内部使用，显著提高了工作效率，并通过自动化审查代理实现了代码质量的提升 Cloudflare 的员工自 2026 年 5 月起开始使用 Cloudflare OS，工作效率显著提升。非技术人员在 30 天内构建了超过 4000 个定制化的业务工具，销售团队在区域规划和销售渠道分析方面节省了约 10000 小时的手动数据汇总时间。工程团队采用了'Cloudflare 工程法典'，自动化审查代理会根据该法典评估拉取请求和架构设计，已标记出的潜在缺陷近 25 万个，已阻止不合规合并 1.6 万次，并在实施前发现了约 600 个架构缺陷。

💬 文章金句

  • Cloudflare OS 使企业团队能够自动化重复性工作流，并在安全的沙箱模型内构建个性化、可共享且可定制的工作软件。
  • Cloudflare OS 的底层的能力驱动型模型可以用于执行企业策略。
  • Cloudflare OS 并非运行集中式、多租户的软件即服务（SaaS）应用程序，而是为每位用户提供独立的应用程序副本。
  • 对资源的安全访问由一种基于能力的安全模型进行管控，Cloudflare 将其称为 Gatekeepers。
  • Cloudflare OS 通过官方 cloudflare-os 代码库和 GitHub 上的一个入门部署模板提供，遵循 Apache-2.0 许可。
