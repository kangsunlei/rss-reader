📌 一句话摘要

本文介绍了作者基于 .NET 10 + Vue 3 开源的 XiHan.BasicApp 多租户中后台底座，重点讲解了设计理念中的登录后选租户、字段级权限、动态 API、菜单单一事实源等关键点。

📝 详细摘要

文章由作者分享其开源项目 XiHan.BasicApp 的设计与实践。项目定位为一套基于 .NET 10 + Vue 3 的企业级多租户中后台内核，采用 DDD 分层 + CQRS 架构，前端使用 Vue 3.5 + TypeScript + Naive UI。作者重点阐述了几个关键设计：登录后按归属智能落点选择租户、三层权限体系（RBAC + ABAC + 字段级安全）、后端无 Controller 的动态 API、前后端菜单纯一事实源、前端列表页通过 Schema 配置生成等。此外还介绍了偏好同步、灵动岛、移动端重做、六类审计日志等技术细节。文章最后给出了快速启动命令和开源地址。

💡 主要观点

  1. 登录后按归属智能落点选择租户，而非登录前选择。 以邮箱为全平台唯一身份，登录后系统根据用户归属自动跳转：平台管理员进控制台，单租户用户直接工作台，多租户成员进选择页，超级管理员可切换任意租户。
  2. 权限体系覆盖字段级安全（FLS），实现数据脱敏与细粒度控制。 RBAC 控制页面和按钮，ABAC 控制数据范围（全部/本部门/本人），字段级安全控制敏感字段是否可见或脱敏，越权请求在服务端拦截。
  3. 后端通过 DynamicApi 直接暴露应用服务为 REST 接口，零 Controller 样板代码。 应用服务加 [DynamicApi] 特性即自动生成 REST API 和 Scalar 文档，减少胶水代码。
  4. 菜单、路由、权限码、国际化键统一在后端 PageRegistry 登记，保证前后端契约一致。 避免前端配菜单、后端配权限两边不同步的问题，菜单只有一个事实源。
  5. 前端列表页采用 Schema 驱动配置生成，支持列设置、高级搜索、习惯同步等。 全站二十多个列表页使用统一配置框架，搜索、表格、导出、列拖拽等开箱即用，用户设置同步到云端。
