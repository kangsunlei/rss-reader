突破限制：在 Power Apps PCF 组件中集成 React 19 的终极指南

5/23/2025, 1:22:04 PM

📌 一句话摘要

通过绕过默认限制，将 React 19 集成到 Power Apps PCF 组件中。

📝 详细摘要

本文提供了一个逐步指南，介绍如何在 Power Apps 组件框架（Power Apps Component Framework，简称 PCF）组件中使用最新版本的 React (v19)，从而克服虚拟控件中 React 16/17 的默认限制。它演示了如何创建一个标准的 PCF 项目，手动安装 React 19 依赖项，设置 TypeScript 配置，并使用 PCF 生命周期方法（`init` 和 `updateView`）中的 `createRoot` 渲染 React 组件。这种方法牺牲了内置的虚拟化支持，但可以使用现代 React 功能和工具，从而为复杂的自定义组件提升开发者体验和用户界面灵活性。

💡 主要观点

  1. 突破 PCF 默认 React 版本限制 (16/17)。 通过使用标准的 PCF 控件并手动安装 React，开发人员可以使用更新的 React 版本，如 19。
  2. 手动 React 设置需要特定的依赖项。 安装 `react`、`react-dom` 及其 TypeScript 类型对于自定义 React 集成是必要的。
  3. 渲染 React 组件使用 `createRoot` 和 `updateView`。 `createRoot` API 用于初始渲染，`updateView` 处理数据更改时的重新渲染。

💬 文章金句

  • 创建新的 PCF 项目时，您可以从两种类型的控件中进行选择：**标准控件**和**React 虚拟控件**。
  • 但是，当您将 React 与 PCF 一起使用时，目前在帆布应用中仅限于 React 16，在模型驱动应用中仅限于 React 17。
  • 这并不意味着您*不能*使用较新的版本 - 但这样做意味着选择退出虚拟化支持。
  • 通过手动安装和配置 React，您可以避免 Microsoft 内置 React 控件的版本限制 - 释放现代 React 功能的强大功能。
  • 虽然此设置不支持虚拟化，但对于许多组件来说，这是现代工具和可维护性的一个公平权衡。
