模型测试不再跳来跳去，VS Code + Hugging Face = 真香

9/20/2025, 2:16:00 AM

📌 一句话摘要

Hugging Face 在 VS Code 的 GitHub Copilot Chat 中集成 Inference Providers，使开发者能直接调用和测试开源大语言模型，显著提升开发效率。

📝 详细摘要

文章详细介绍了 Hugging Face 推出的一项新功能，允许开发者在 VS Code 的 GitHub Copilot Chat 中直接接入 Inference Providers。这意味着 Kimi K2、DeepSeek V3.1、GLM 4.5 等开源大语言模型现在可以直接在 VS Code 编辑器内调用和测试，无需频繁切换平台或工具。整个工作流程简洁高效，开发者只需安装 Hugging Face Copilot Chat 插件，输入 token 即可连接并选择模型。此功能需要最新版 VS Code 1.104.0 支持。此次集成打破了 GitHub Copilot Chat 对封闭专有模型的依赖，为开发者提供了更多类型的 AI 工具，包括实验性和高度专业化的开源模型。Hugging Face Inference Providers 服务通过统一 API 访问数百种机器学习模型，并强调了即时访问前沿模型、避免厂商锁定、生产环境性能保障以及便捷集成（兼容 OpenAI Chat Completions API）等优势。在定价方面，Hugging Face 提供免费额度及灵活的付费方案，且不额外加价。

💡 主要观点

  1. Hugging Face 集成 VS Code Copilot Chat 简化开源 LLM 测试流程。 开发者现在可以直接在 VS Code 环境中调用和测试 Kimi K2、DeepSeek V3.1 等开源大语言模型，无需频繁切换工具或平台，显著提升开发效率。
  2. 统一 API 访问数百种机器学习模型，打破厂商锁定。 通过 Hugging Face Inference Providers 服务，开发者能以一致的接口访问来自不同提供方的模型，避免了多 API 差异，并能自由切换提供方。
  3. 扩展 Copilot Chat 功能，支持更多实验性和专业化开源模型。 此集成使开发者能够利用针对特定编程任务优化的开源模型，不再局限于默认的专有模型，从而在 AI 辅助编程中获得更大的灵活性和选择。

💬 文章金句

  • Hugging Face 发布新功能，让开发者可在 VS Code 的 GitHub Copilot Chat 中直接接入 Inference Providers。
  • 整个工作流程设计得非常简洁。开发者只需安装 Hugging Face Copilot Chat 插件，打开 VS Code 的聊天界面，选择 Hugging Face 提供方，输入 Hugging Face 的 token，然后添加想要使用的模型。
  • 此次与 Hugging Face Inference Providers 网络的打通，让开发者能够使用更多类型的 AI 工具，包括实验性和高度专业化的开源模型。
  • 这项服务的最大价值在于'统一'：开发者不必再处理多个 API 的差异和不稳定性，而是能通过一致的接口调用来自不同提供方的模型。
