Cloudflare WAF 主动防御 React 漏洞攻击

12/3/2025, 2:20:00 PM

📌 一句话摘要

Cloudflare 已主动部署 WAF 规则，自动保护所有客户，防御 React 服务端组件和 Next.js 中的关键远程代码执行 (RCE) 漏洞。

📝 详细摘要

本文详细介绍了 Cloudflare 如何快速响应一个关键的远程代码执行 (RCE) 漏洞（CVE-2025-55182，CVSS 10.0），该漏洞影响特定版本的 React (19.0-19.2) 和 Next.js (15-16)。该漏洞源于 React 服务端组件对恶意请求进行反序列化时存在安全隐患。Cloudflare 已在其网络中部署了新的 Web 应用防火墙 (WAF) 规则，默认动作为“阻止”，旨在自动保护所有通过 Cloudflare 代理 React 应用流量的客户，与他们的计划类型无关。文章强调，部署在 Cloudflare Workers 上的应用程序本质上不受此漏洞的影响。虽然已部署了即时 WAF 保护，但 Cloudflare 强烈建议客户将其应用程序更新到最新安全版本的 React (19.2.1) 和 Next.js (16.0.7， 15.5.7， 15.4.8)。它还为 Professional、Business 和 Enterprise 计划的客户提供了特定的 WAF 规则 ID 和说明，以确保启用托管规则。这些规则于 2025 年 12 月 2 日部署，自那时以来未观察到任何利用尝试。Cloudflare 的安全团队致力于持续监控和更新对潜在攻击变体的保护。

💡 主要观点

  1. Cloudflare WAF 主动防御针对 React RCE 漏洞的攻击。 新的 WAF 规则自动阻止针对 React 服务端组件的恶意请求，从而为 Cloudflare 客户提供针对 CVE-2025-55182 的即时、广泛的保护。
  2. 该漏洞影响特定版本的 React 和 Next.js，评级为 CVSS 10.0。 React 19.x 和 Next.js 15-16 中请求的不安全反序列化可能导致远程代码执行，突显了严重性和立即缓解的必要性。
  3. 强烈建议客户更新其应用程序，尽管有 WAF 保护。 虽然 WAF 提供了至关重要的防御，但更新到最新安全版本的 React 和 Next.js 可以消除根本漏洞，确保长期安全和遵守最佳实践。

💬 文章金句

  • 所有 Cloudflare 客户都受到自动保护，包括免费和付费计划的客户，只要他们的 React 应用程序流量通过 Cloudflare Web 应用防火墙 (WAF) 代理。
  • Cloudflare 已收到其安全合作伙伴的警报，称存在一个影响 Next.js、React Router 和其他 React 框架的远程代码执行 (RCE) 漏洞（安全公告 CVE-2025-55182，评级为 CVSS 10.0）。
  • 作为回应，Cloudflare 已在其网络中部署了新规则，默认操作设置为阻止。
  • 我们建议客户更新到最新版本的 React 19.2.1 和最新版本的 Next.js (16.0.7， 15.5.7， 15.4.8)。
