Cloudflare 数据平台发布：直接在 Cloudflare 上进行数据摄取、存储与查询

9/25/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 发布了其新的数据平台，这是一个端到端的无服务器解决方案，用于在 R2 上摄取、存储和查询分析数据，具备零出站费用及开放标准。

📝 详细摘要

本文介绍了 Cloudflare 数据平台。该平台是为分析数据工作负载设计的全面无服务器解决方案。它利用 Cloudflare 的全球网络和零出站费用 R2 对象存储，集成了三个核心组件：Cloudflare Pipelines，用于事件摄取和基于 SQL 的 Iceberg 表转换；R2 数据目录，一个完全托管的 Apache Iceberg 目录，现在具有自动数据压缩功能，以优化查询性能；以及 R2 SQL，新型内部分布式 SQL 引擎，旨在 R2 上执行 PB 级查询。该平台提倡开放标准，从而可以与各种查询引擎（例如 PyIceberg、DuckDB、Spark）和数据平台（例如 Databricks、Snowflake）互操作。Cloudflare 旨在通过提供经济实惠、基于使用量且操作轻便的替代方案来简化传统的、昂贵的数据基础设施，从而使企业能够获得关键见解，无需管理复杂的基础设施，也无需承担高昂的数据传输成本。

💡 主要观点

  1. Cloudflare 数据平台为分析数据工作流程提供了一个集成的端到端解决方案。 它整合了 Cloudflare Pipelines（用于数据摄取与转换）、R2 数据目录（用于托管存储）以及 R2 SQL（用于无服务器查询），所有组件均构建于具备零出站费用的 R2 对象存储之上。
  2. 该平台强调开放标准和互操作性，从而减少了厂商锁定和成本。 利用 Apache Iceberg 可以与各种第三方查询引擎和数据平台无缝集成，并辅以 Cloudflare 的零出站费用策略，以实现经济高效的数据访问。
  3. R2 数据目录的数据压缩功能以及 R2 SQL 等新特性增强了性能和运营简便性。 自动压缩通过管理数据文件来优化查询速度，而 R2 SQL 提供了一个完全无服务器的分布式查询引擎，从而最大程度地减少了用户进行数据分析的运营开销。

💬 文章金句

  • 这些产品共同构成了 **Cloudflare 数据平台**，这是一个用于摄取、存储和查询分析数据表的完整解决方案。
  • 这意味着您可以自带 Iceberg 查询引擎 --- 无论是 PyIceberg、DuckDB 还是 Spark --- 与其他平台（如 Databricks 和 Snowflake）连接 --- 并且无需支付出站费用即可访问您的数据。
  • 我们在 2021 年推出了 R2 对象存储，并采取了激进的定价策略：没有出站费用 --- 传统云提供商收取的数据带宽成本 --- 实际上是在勒索您的数据。
  • 该解决方案是 *压缩*，这是由 Data Catalog 自动执行的定期维护操作。压缩将小文件重写为大文件，从而减少了元数据开销并提高了查询性能。
  • Cloudflare 在其全球网络上任何地方安排计算的能力是 R2 SQL 设计的基础。这使我们可以直接在数据所在的位置处理数据，而无需您管理用于分析工作负载的集中式集群。
