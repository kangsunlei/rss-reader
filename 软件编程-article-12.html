📌 一句话摘要

Redential CLI 通过不泄密的方式把在 GitHub 私有仓库的 NDA 经验生成可验证的技术简历，提升求职可信度。

📝 详细摘要

Redential CLI 是一款开源的命令行工具，旨在把在 GitHub 上签署 NDA 的私有仓库工作经验，转换为一份既不泄露机密又能证明「你真的做过这件事」的技术简历。相较于传统文字简历，它能够让招聘方直接看到经过验证的项目痕迹，从而提升求职者的信任度。文中附带项目截图，链接指向 GitHub 仓库，方便感兴趣的开发者直接获取并使用。
