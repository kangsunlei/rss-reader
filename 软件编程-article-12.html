Google 开源命令行工具 gws：在终端操作 Google Workspace 并集成 AI Agent

3/5/2026, 7:36:58 AM

📌 一句话摘要

Google 推出的 gws 命令行工具支持在终端管理 Google Workspace 生态，并可通过 MCP 协议深度集成 AI Agent 工作流。

📝 详细摘要

Google 官方开源了名为 gws 的命令行工具，旨在让开发者直接在终端操作 Drive、Gmail、Calendar 和 Sheets 等 Google Workspace 服务。该工具不仅支持自动分页、请求预览及多种认证方式（本地、CI、服务账号），还内置了 Model Armor 以过滤 API 响应中的注入风险。更重要的是，它支持 MCP (Model Context Protocol) 协议，可无缝集成到 Claude Desktop、Claude Code 和 Gemini CLI 等 AI 客户端，并提供了 100 多个 AI Agent 技能文件，极大提升了 AI 自动化处理办公任务的能力。
