.NET 10 RC 1：在 Blazor 中引入持久状态、增强验证和生产环境就绪的工具

9/18/2025, 8:13:00 AM

📌 一句话摘要

.NET 10 RC 1 在 Blazor、ASP.NET Core、MAUI、WinForms 和 EF Core 中引入了生产环境就绪的功能，重点关注性能优化、可观测性增强和现代数据处理。

📝 详细摘要

Microsoft 发布了 .NET 10 RC 1，它带有一个正式发布许可，使其适用于具有官方支持的生产环境。此版本与 Visual Studio 2026 Insiders 和 Visual Studio Code 的 C# Dev Kit 兼容。主要增强功能包括 Blazor 中对持久组件状态的支持，以提高导航期间的应用程序性能和用户体验。ASP.NET Core Identity 现在发出内置指标，以增强可观测性和故障排除。验证改进跨越 Minimal APIs 和 Blazor，引入了类型级别验证和跳过验证的选项。OpenAPI 架构生成已得到改进，以实现更好的兼容性和属性说明。.NET MAUI 获得了用于性能分析的新诊断工具，以及 HybridWebView 的事件和 RefreshView 的 `IsRefreshEnabled` 属性。还提供对 Android 的实验性 CoreCLR 支持。Windows Forms 现在完全支持暗模式，并具有生产环境就绪的异步方法，如 `ShowAsync`。Entity Framework Core 10 引入了 SQL Server 向量数据类型，用于相似性搜索、完整的 JSON 列支持以及扩展的 Cosmos DB 功能，用于全文和混合搜索。还包括对复杂类型映射和参数化集合填充的改进。

💡 主要观点

  1. Blazor 通过持久组件状态，提升导航时的用户体验和应用性能。 组件现在可以在增强的导航中保留和恢复其状态，防止数据丢失并提高 Blazor 应用程序的感知响应能力，而无需完全重新加载页面。
  2. 增强的可观测性和验证功能，有助于简化开发流程和生产环境监控。 ASP.NET Core Identity 的新指标可更深入地了解用户操作，而 Minimal APIs 和 Blazor 中改进的验证为数据完整性提供了更多控制和一致性。
  3. .NET MAUI、Windows Forms 和 Android 开发的重大更新改进了跨平台和桌面应用程序的功能。 .NET MAUI 添加了诊断工具和改进的控件，Windows Forms 获得了完整的暗模式支持，在 Android 上实验性 CoreCLR 的引入，预示着移动应用未来性能的提升。
  4. Entity Framework Core 10 引入了现代数据库功能，如向量搜索和强大的 JSON 支持，适用于 SQL Server 和 Cosmos DB。 这些进步使开发人员能够构建具有复杂数据处理能力的应用程序，直接在 ORM 中支持由 AI 驱动的相似性搜索和灵活的无模式数据存储。

💬 文章金句

  • 此版本带有一个正式发布许可，允许开发人员在具有官方支持的生产环境中使用它。
  • 组件现在可以保留和检索以前存储的状态，从而提高应用程序性能并保持用户进度。
  • 新的遥测旨在增强生产环境中的可观测性和故障排除。
  • SQL Server 现在支持新的向量数据类型和 `VECTOR_DISTANCE()` 函数，用于基于向量的相似性搜索。
  • Cosmos DB 功能已扩展到包括全文和混合搜索功能，结合了关键字和向量相似性，以实现更灵活的查询。
