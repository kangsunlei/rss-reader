📝 详细摘要

本期 Node 中文周刊聚焦 Node.js 生态多个重大发布。npm 12 正式版默认禁用安装脚本与 node-gyp 隐式构建，提升安全性但影响原生模块安装；TypeScript 7.0 正式发布，构建性能大幅提升，但迁移需注意 moduleResolution 配置且暂不提供 API；Node.js 26.5 新增 ESM 文本导入（实验性）与 blob.textStream，增强文件处理能力。此外还介绍了 ECMAScript 2026 新特性（Math.sumPrecise 等）、关于 CVE-2026-48931 的事故回顾、不应轻信 npm Trusted Publishing 的提醒、规模化运行 Worker Threads 的实战经验，以及 webpack-dev-server v6.0、eslint-node-test、terminal-image v5.0 等工具发布。快讯包括 Bun 用 Rust 重写的内幕、Error code 属性 TC39 提案、Better Auth 加入 Vercel 等。

💡 主要观点

  1. npm 12 正式发布，默认禁用安装脚本与 node-gyp 隐式构建。 主要破坏性变更：生命周期脚本和隐式构建不再默认运行，.npmrc 未知键仅警告不报错，提升安装安全性但影响原生模块工作流。
  2. TypeScript 7.0 正式发布，构建性能大幅提升。 基于 Go 重写的编译器，需将 moduleResolution 切换为 nodenext 才能获得加速，且 7.0 暂不提供 API，6.0 仍是安全过渡选择。
  3. Node.js 26.5 新增 ESM 文本导入与 blob.textStream。 实验性支持 import 属性导入文本文件，以及 blobs 的流式读取，适合处理大型文本数据，配合 perf_hooks 可采样事件循环延迟。
  4. 规模化运行 Worker Threads 的实战经验分享。 Inngest 团队从生产环境中总结的挑战与最佳实践，涵盖线程池管理、通信开销、调试与监控等，对需要并发处理的 Node 开发者有参考价值。
