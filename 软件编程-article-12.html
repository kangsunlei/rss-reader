📝 详细摘要

本期周刊聚焦 JavaScript 生态的多个热点事件。头条是 TanStack npm 包遭受 Shai-Hulud 蠕虫攻击，攻击者利用 GitHub Actions 漏洞在 26 分钟内影响了约 170 个包，文章提供了安装冷却时间和审计工作流等防御建议。其次，Rolldown 1.0 正式发布，作为 Vite 8 核心的 Rust 打包工具，性能比 Rollup 快 10-30 倍。Vercel 开源了 zero-native，一个基于 Zig + WebView 的桌面应用方案。此外，周刊还收录了从 React 迁移到 Web Components 节省 100KB 的实践、Valibot 迁移指南、33 个 JavaScript 概念网站等文章，以及 BlueJS、Wakaru 等工具和 pnpm、Astro 等版本更新。

💡 主要观点

  1. TanStack npm 包遭供应链攻击，26 分钟内影响 170 余个包。 攻击者利用 GitHub Actions 的 pull_request_target 滥用和缓存投毒，窃取 OIDC token 注入恶意版本，建议设置安装冷却时间和审计工作流。
  2. Rolldown 1.0 发布，性能比 Rollup 快 10-30 倍。 作为 Vite 8 核心的 Rust 打包工具达到稳定版，保持 Rollup 插件 API 兼容性，早期用户报告构建时间大幅下降。
  3. Vercel 开源 zero-native，基于 Zig + WebView 构建桌面应用。 与 Electron/Tauri 竞争，使用系统 WebView 或 Chromium 构建原生 HTML+JS 桌面应用，提供 React、Svelte、Vue 示例。

💬 文章金句

  • 攻击者并未窃取维护者凭证，而是利用 pull_request_target 滥用、缓存投毒和从 CI 内存中窃取 OIDC token 的方式进行攻击。
  • Rolldown 1.0 获得了巨大的性能提升，同时保持与 Rollup 插件 API 的兼容性：比 Rollup 快 10-30 倍。
  • 我是如何将一个站点从 React 迁移到原生 Web Components 的，为什么效果比我预期的更好。
