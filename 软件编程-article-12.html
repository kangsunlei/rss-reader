Compose Multiplatform 1.9.0 发布：Compose 多平台 Web 版进入 Beta 阶段 | Kotlin 博客

9/22/2025, 10:45:12 AM

📌 一句话摘要

Compose Multiplatform 1.9.0 发布，Compose 多平台 Web 版（基于 WebAssembly）进入 Beta 阶段，通过增强的工具和功能，实现跨 Web、移动和桌面平台的统一 UI 开发。

📝 详细摘要

本文宣布了 Compose Multiplatform 1.9.0 的发布，重点在于 Compose 多平台 Web 版，目前已进入 Beta 阶段并由 WebAssembly (Wasm) 提供支持。这一里程碑标志着它已为早期采用者做好准备，使开发人员能够利用他们现有的 Compose 技能，轻松构建 Web 应用程序，或扩展现有的移动/桌面应用。关键的 Web 特定功能包括 Material 3 组件、自适应布局、浏览器导航集成、HTML 互操作性（即与现有 HTML 代码的集成能力）和基本的辅助功能支持，所有这些都具有跨浏览器兼容性。此版本强调了不断增长的多平台库生态系统，并通过 IntelliJ IDEA 和 Android Studio 中的 Kotlin 多平台插件改进了 IDE 集成支持，为 Web 目标提供集成的项目创建、运行和调试。除了 Web 之外，Compose Multiplatform 1.9.0 还为 iOS（性能控制、文本输入）、桌面（窗口管理）和跨所有平台的通用设计/预览功能提供了增强功能，从而进一步巩固了其作为成熟的统一 UI 框架的地位。本文鼓励社区提供反馈以供未来开发，并提供入门资源。

💡 主要观点

  1. 由 Wasm 提供支持的 Compose 多平台 Web 版现已进入 Beta 阶段，可供早期采用者在实际环境中使用。 这一重要的里程碑使开发人员能够自信地应用他们现有的 Compose 技能来构建 Web 应用程序，从而以最小的努力和高可靠性在 Web、移动和桌面平台之间扩展统一的 UI 框架。
  2. 该版本为 Web 开发提供了全面的功能，并为多平台项目提供了增强的 IDE 集成工具。 主要功能包括 Material 3 组件、自适应布局、HTML 互操作性和强大的跨浏览器兼容性。像 IntelliJ IDEA 这样的 IDE 现在为 Web 目标提供集成的项目创建、运行和调试，从而简化了开发工作流程。
  3. Compose Multiplatform 1.9.0 还为 iOS、桌面和整体设计/预览体验带来了关键改进。 iOS 可以更好地控制性能和文本输入，桌面受益于新的窗口管理功能，所有平台都可以看到增强的可配置预览和阴影自定义，从而进一步增强了该框架在 Web 平台之外的功能。

💬 文章金句

  • 由 Wasm 提供支持的 Compose 多平台 Web 版现已进入 Beta 阶段！这一重要的里程碑表明，Compose 多平台 Web 版不再仅仅是实验性的，而是可以供早期采用者在实际环境中使用。
  • 通过 Beta 版本，您现在可以放心地将现有的 Compose 技能和编码模式应用到 Web，以最小的努力创建新应用程序或扩展移动和桌面应用程序。
  • Compose Multiplatform 1.9.0 确保核心 API 实现可在 Web 上运行，并针对辅助功能和导航引入了有针对性的改进，同时还进行了广泛的错误修复和开发人员体验增强。
  • 此版本提供的基础得到了不断增长的多平台库生态系统的支持，该生态系统扩展到了 Web。
  • 借助 Kotlin 多平台插件，您可以：创建具有 Web 目标的新项目，直接从 IDE 在浏览器中运行您的应用程序，使用 Web 入口点的行号图标来立即启动和调试您的 Compose 应用程序。
