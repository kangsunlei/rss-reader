告别 CVE？欧洲漏洞数据库 EUVD 正式上线

6/7/2025, 4:11:00 AM

📌 一句话摘要

欧盟网络安全局 ENISA 正式上线欧洲漏洞数据库 EUVD 测试版，作为独立于美国 CVE 的漏洞平台。

📝 详细摘要

文章介绍了欧盟网络安全局 ENISA 推出的欧洲漏洞数据库 EUVD 测试版。该平台旨在增强欧盟内部漏洞处理的协调性和透明度，并作为对美国 CVE 系统依赖的替代或补充。作者阐述了当前对由美国政府资助的 CVE 系统长期稳定性的担忧背景，指出 EUVD 在提供备用方案的同时，还具备高亮已遭利用漏洞、增强搜索功能等特色，并计划支持 CSAF 格式。尽管采用了独立的 ID 系统，但 EUVD 仍引用 CVE 条目。社区反馈对此褒贬不一，既认可其价值，也担忧额外 ID 的负担和底层数据的新颖性。该计划被视为欧洲提升数字主权和网络安全能力的策略组成部分。

💡 主要观点

  1. EUVD 旨在减少对美国 CVE 的过度依赖并增强欧洲自主性 作为与 CVE 并行且独立的欧洲平台，EUVD 的上线直接回应了因 CVE 资金问题引发的对单一国家控制全球关键基础设施的担忧，提升欧盟数字韧性。
  2. EUVD 提供比现有系统更强的功能和特性 新平台特有高亮已遭利用漏洞、多属性增强搜索功能，并计划支持机器可读的 CSAF 格式，这些功能提升了漏洞信息的可用性和处理效率。
  3. EUVD 采用独立标识系统但与 CVE 保持关联 EUVD 使用自己的 ID 体系以支持独立验证，但仍引用相应的 CVE 条目，这在提供新视角的同时也引出用户对增加需追踪 ID 的担忧。
  4. EUVD 是欧洲提升数字主权战略的一部分 该数据库的推出不仅是技术层面的改进，更是欧盟在网络安全领域强化自身能力、减少外部依赖、掌控关键数字基础设施的宏观战略体现。

💬 文章金句

  • 尽管 CVE 仍是漏洞报告的国际标准，但该系统作为完全由美国政府资助的项目，近期政治动向引发了业界对其长期稳定性的担忧。
  • 尽管该服务仍通过"替代 ID"引用 Mitre 的 CVE 条目，但 EUVD 并未简单复制 CVE 的编号体系，而是采用了自己的标识系统。
  • 看起来不错，不过大概又要多记一套 ID 了。
  • 如果它不只是现有（主要基于美国的）数据库的大集合，这话就成立。除了又多一个需要追踪的标识符外，它没提供任何新东西。
  • EUVD 的计划是欧洲提升数字主权、强化欧盟成员国网络安全能力的整体战略组成部分。
