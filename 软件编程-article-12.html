26 亿次周下载量的主流 NPM 包一夜沦陷，开发者账户被黑客钓鱼攻击

9/9/2025, 10:10:00 AM

📌 一句话摘要

主流 NPM 包遭遇大规模供应链攻击，黑客通过钓鱼邮件入侵开发者账户并植入恶意代码，旨在窃取加密货币钱包信息，影响每周超 26 亿次下载。

📝 详细摘要

文章报道了一起针对 NPM 生态系统的大规模供应链攻击事件。黑客通过伪装成官方通知的钓鱼邮件，成功入侵了知名开发者的账户，并对至少 18 个周下载量合计超过 26 亿次的核心 NPM 软件包植入恶意代码。网络安全机构 Aikido 率先披露了此事件，并指出恶意代码经过混淆，其核心功能是检测并尝试窃取用户的加密货币钱包信息。此次攻击凸显了软件供应链中存在的严重安全漏洞，以及开发者账户安全防护的紧迫性，对整个 JavaScript 生态系统构成了重大威胁。

💡 主要观点

  1. NPM 生态遭遇大规模供应链攻击，多个核心软件包被植入恶意代码。 此次攻击影响了至少 18 个周下载量超 26 亿次的 NPM 包，显示了攻击范围之广和潜在影响之深，对依赖这些包的项目构成严重威胁。
  2. 黑客通过钓鱼邮件入侵开发者账户，恶意代码旨在窃取加密货币钱包信息。 攻击利用了开发者对官方通知的信任，通过钓鱼手段获取账户权限，并植入专门针对加密货币钱包的恶意代码，揭示了账户安全薄弱环节。
  3. 事件凸显了软件供应链安全和开发者账户防护的紧迫性。 此案例再次敲响警钟，强调了对第三方依赖的审计、加强开发者账户的 MFA 保护以及提升安全意识对于防范此类攻击的重要性。

💬 文章金句

  • 短短一夜之间，NPM 软件生态遭遇重创。黑客通过伪装成官方通知的钓鱼邮件，成功入侵知名开发者账户，对至少 18 个高频下载的核心软件包动了手脚，并植入恶意代码。
  • 这些包的周下载量合计超过 20 亿次，而据外媒 BleepingComputer 报道，实际数字甚至高达 26 亿次，影响范围几乎覆盖整个 NPM 主流生态。
  • 经过一定程度的反混淆处理后，安全研究人员发现其中仍然包含一段相当复杂的代码。
