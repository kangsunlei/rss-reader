Java 新闻综述：JDK 26 发布计划，GlassFish，Spring AI，Helidon，Mandrel 25，Seed4j

10/6/2025, 2:30:00 AM

📌 一句话摘要

本次 Java 新闻综述重点介绍了 JDK 26 发布计划、用于后量子 TLS 的 JEP 527，以及 Spring AI、Helidon、Micronaut、WildFly 等框架的新版本。

📝 详细摘要

本周（2025 年 9 月 29 日）的 Java 新闻综述重点介绍了生态系统中的重大进展。主要更新包括 JEP 527 升级为 TLS 1.3 中抗量子混合密钥交换的候选状态（一种能抵抗量子计算机攻击的加密技术），以及 JDK 26 发布计划的正式提案，目标是在 2026 年 3 月 17 日正式发布。企业级 Java 运行时发布了 GlassFish 8.0/7.1 的里程碑版本和 WildFly 38 的 Beta 版本，两者都增强了对 Jakarta EE 11 和 MicroProfile 7.1 的支持。云原生框架也取得了进展，Spring AI 1.0.3 改进了对 GraalVM 本地镜像（一种将 Java 代码提前编译为可执行文件的技术）的支持，Helidon 4.3.0 引入了新的数据和声明式功能，Mandrel 25 为 Quarkus 提供了量身定制的本地镜像。此外，综述还涵盖了各种库的更新：LangChain4j 1.7.1 具有新的 AI 集成和 GPU 支持，Seed4j 2.0.0 (原 JHipster Lite) 用于现代应用程序生成，Gatherers4j 0.12.0 扩展了 Java 流，Keycloak 26.4.0 具有诸如通行密钥和 FAPI 2.0 支持之类的安全增强功能。这份全面的概述帮助 Java 开发者掌握平台发展动态和框架创新。

💡 主要观点

  1. JDK 26 的拟议发布计划和后量子 TLS 的进展标志着 Java 的未来方向。 JDK 26 正式发布日期的提案以及抗量子 TLS 1.3 的 JEP 527 的进展，都突显了 Java 在核心平台功能和安全性方面的持续发展。
  2. 主要的 Java 框架和运行时不断发展，具有新功能、AI 集成和本地镜像支持。 GlassFish、Spring AI、Helidon、Micronaut、WildFly、Mandrel 和 LangChain4j 的更新表明，Jakarta EE、MicroProfile、AI 驱动的应用程序以及通过本地镜像进行的性能优化等领域都在积极开发中。
  3. 诸如 Seed4j、Gatherers4j 和 Keycloak 之类的专用库可提高开发人员的生产力和应用程序安全性。 Seed4j 提供了一个现代 Java 应用程序生成器，Gatherers4j 扩展了 Java 流，Keycloak 通过诸如通行密钥和 FAPI 2.0 之类的功能改进了身份验证，共同为开发人员提供了有价值的工具。

💬 文章金句

  • JEP 527，用于 TLS 1.3 的后量子混合密钥交换，已从其 JEP 草案 8358541 提升为候选状态。
  • Oracle Java 平台组首席架构师 Mark Reinhold 正式提出了 JDK 26 的发布计划，如下所示：正式发布：2026 年 3 月 17 日。
  • Spring AI 1.0.3 发布，包含错误修复、文档改进和新功能。例如，新增了 GemFireAiSearchFilterExpressionConverter 类，并对 OpenAiRuntimeHints 和 AbstractEmbeddingModel 类进行了更改，以更好地支持 GraalVM 本地镜像的提前编译。
  • WildFly 38 的 Beta 版本提供了错误修复、依赖项升级和新功能，例如：通过在 WildFly Preview 中实现 Jakarta Persistence 和 Jakarta Context and Dependency Injection 规范，继续支持 Jakarta EE 11；支持 MicroProfile 7.1。
  • Keycloak 26.4.0 的发布具有安全增强功能、更深入的集成和改进的服务器管理。新功能包括：用于用户无密码身份验证的通行密钥；以及对金融级 API (FAPI) 2.0 安全配置和消息签名标准的支持。
