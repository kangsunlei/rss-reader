Observatory 和 Smart Shield 介绍 — 洞悉网站全球性能，一键加速优化

9/26/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 发布 Observatory，统一的 Web 性能监控平台；以及 Smart Shield，智能解决方案，通过一键式操作实现源站保护和加速，并充分利用其庞大的网络。

📝 详细摘要

为满足对即时、可靠 Web 体验的迫切需求（即使微小延迟也会显著影响收入和用户留存），Cloudflare 推出了全新的 Web 性能产品：Observatory 和 Smart Shield。Observatory 现已开放 Beta 测试，适用于所有订阅层级，它是一款综合性的监控和可观测性工具，不仅能识别性能问题，还能指导问题解决。它整合了包括真实用户监控 (RUM)、合成测试、后端遥测、错误率和缓存命中率等多种数据源，提供应用健康状况的完整端到端视图。Cloudflare 强调 RUM 是性能衡量的基准，在免费区域中默认免费提供（欧盟/英国数据除外）。该平台提供关键指标（如首字节时间 (TTFB) 和最大内容绘制 (LCP)）的诊断细分，以精确定位瓶颈。集成的智能建议提供精确且数据驱动的性能改进方案，例如优化资源压缩。Smart Shield 完善了 Observatory 的功能，将源站保护转变为更智能、更简化的解决方案。它结合了动态流量加速、智能缓存、健康监控和专用出口 IP，只需一键即可修复 Observatory 识别出的常见性能和安全问题。这创建了一个持续的反馈循环，旨在降低总拥有成本，缩短价值交付周期。此外，文章还重点介绍了 Cloudflare 通过动态连接重用在源站连接管理方面的重大改进，从而减少了 30% 以上的源站连接数，节省了大量的握手时间，并降低了出口费用。未来的发展方向包括更深入的诊断数据、更多的解决方案路径和基准测试能力。

💡 主要观点

  1. Observatory 通过集成多种数据源，提供统一且全面的 Web 性能监控。 Observatory 通过将真实用户数据、合成测试、后端遥测、错误率和缓存比率整合到一个平台中，提供了应用程序健康状况的整体视图，从而使开发人员和 SRE 能够比使用分散的工具更有效地精确定位和诊断性能瓶颈。
  2. Smart Shield 基于 Observatory 的洞察，为源站保护和加速提供智能的一键式解决方案。 Smart Shield 通过动态加速、智能缓存和健康监控简化了源站保护，使用户能够以最小的努力应用 Observatory 识别的推荐修复方案。这种集成创建了一个持续的反馈循环，将洞察转化为即时且有影响力的行动，从而实现更好的性能和安全性。
  3. Cloudflare 利用其独特的网络优势，提供准确的 RUM 和可操作的性能建议。 Cloudflare 凭借处理全球 20% Web 流量的独特网络优势，为高度准确的真实用户数据提供了无与伦比的数据集。这使该平台能够将 TTFB 和 LCP 等复杂指标分解为诊断子部分，并提供精确且数据驱动的“智能建议”，从而赋能用户有效地优化其应用程序。
  4. 动态连接重用显著降低了源站负载，提高了稳定性并降低了运营成本。 Cloudflare 自动且动态地扩展源站连接池，可将连接数减少 30% 以上，每天节省大约 402 年的握手时间。这项创新不仅显著提高了源站的稳定性并降低了计算开销，而且还通过降低出口费用为客户节省了实际成本。

💬 文章金句

  • 没有行动的监控毫无用处。
  • 在衡量应用程序的性能和弹性时，真实用户数据应该是性能衡量的基准。
  • Observatory 让您可以前所未有地了解应用程序的健康状况，但洞察力只是成功的一半。接下来，需要将洞察付诸行动……
  • 我们很自豪能够通过寻找智能、创新的方法来减少连接数量，同时支持相同的流量，从而降低互联网运营的隐性成本。
  • Smart Shield 和 Observatory 结合在一起，可以提供强大的洞察力和轻松的修复能力。
