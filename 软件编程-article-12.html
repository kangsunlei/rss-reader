📝 详细摘要

本期 JavaScript 中文周刊深入报道了前端技术栈的最新进展。热点内容包括原生 Vite 测试框架 Vitest 4.0 的发布，它带来了视觉回归测试和稳定的浏览器模式，并被 Angular 21 选为默认测试工具。同时，Next.js 16 也正式发布，引入了组件级缓存、AI 辅助调试等创新特性。此外，周刊还分享了 Nordic.js 2025 会议的视频回放，涵盖 ES2026/ES2027 等前沿内容。除了这些重要更新，周刊还涵盖了多条行业快讯和对其他前端趋势的深入探讨。文章和视频部分则精选了关于 JavaScript 异步循环、JSON 导入方式、CLI 工具构建以及 React/Remix 框架未来走向的深度探讨。最后，工具与代码部分介绍了 Ky v1.13、JustGage v2.0、Solito v5.0 等实用库和框架的更新，并列举了 Boa、Bun、Biome 等多个重要项目的版本发布信息。

💡 主要观点

  1. Vitest 4.0 发布，引入视觉回归测试并成为 Angular 默认测试工具 Vitest 作为 Vite 驱动的测试框架，4.0 版本在功能上取得重大突破，尤其在视觉回归测试和浏览器模式稳定性方面，进一步巩固其在前端测试领域的地位，并获得 Angular 官方认可。
  2. Next.js 16 正式发布，带来组件级缓存和 AI 辅助调试等核心功能 Next.js 作为新时代的 React 框架，其 16 版本通过引入组件级缓存、AI 辅助调试等，显著提升了开发效率和应用性能，推动了 React 生态系统的发展。
  3. 周刊精选多篇深度技术文章，覆盖异步编程、CLI 构建及前端框架演进 文章部分提供了关于 JavaScript 异步循环最佳实践、JSON 导入机制、使用 Ace 构建 CLI 工具以及 React 和 Remix 未来发展方向的专业见解，对开发者具有高度参考价值。

💬 文章金句

  • Vitest 4.0 发布带来视觉回归测试和稳定的浏览器模式（可以直接在浏览器中运行测试）。
  • 从 Angular 21 开始，Vitest 将成为 Angular 的默认测试工具，正式替代以前的 Karma 和 Jasmine。
  • Next.js 16 带来了组件级缓存、AI 辅助调试的 MCP server、Turbopack 和 React Compiler 都变成正式版，以及更多新变化。
  • 重新思考 JavaScript 中的异步循环 ------ 循环里直接用 await，会让你的异步操作一个接一个慢慢来；用 map() 结合 await 却发现根本没等。
