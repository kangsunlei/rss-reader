从端侧到云端：Android 智能应用构建全面升级

11/24/2026, 10:40:00 AM

📌 一句话摘要

本文系统介绍 Android 智能系统如何通过 MCP、ML Kit GenAI、Firebase AI Logic 等技术为开发者构建端侧到云端的智能化应用，涵盖智能体接入、端侧模型部署、A2UI 渲染器及 Connected Apps 平台等核心能力。

📝 详细摘要

本文聚焦 Android 智能系统的最新动态，阐述如何构建智能化应用。它介绍了 Android MCP（远程 MCP 与本地 Android MCP）用于连接 AI 智能体，支持提示式协助和主动式协助；借助 ML Kit GenAI API 在端侧构建智能体工作流，配合 LiteRT 部署自定义模型；Firebase AI Logic 提供云端 Gemini 模型调用方案；A2UI Compose 渲染器让智能体能生成原生 Compose UI；以及 Connected Apps Platform 帮助开发者通过 Gemini 和 Google 搜索触达用户。文章还展示了 Gemini Nano 4 在实际场景中的应用案例，包括智能眼镜的音频体验和 Formula E AI 领航员。

💡 主要观点

  1. Android 智能系统通过 MCP 连接 AI 智能体 基于 MCP 标准的 API 和 AppFunctions Jetpack 库，支持远程 MCP 和本地 Android MCP 两种集成方式，实现跨设备的提示式协助和主动式协助，提升用户与应用间的智能交互。
  2. ML Kit GenAI API 在端侧构建智能体工作流 提供 Prompt API 和 Agentic API，支持模型直接访问、函数调用、对话历史管理及自动安全护机制，借助 LiteRT 在 Google Play 服务中高效运行自定义模型。
  3. Firebase AI Logic 与 A2UI Compose 渲染器实现端云混合智能 Firebase AI Logic 调用云端 Gemini 模型，结合 LiteRT 本地推理；A2UI 渲染器让智能体通过 JSON 流式生成原生 Compose UI，实现「用 UI 表达」的能力。
  4. Connected Apps Platform 拓展 Gemini 与 Google 搜索的触达能力 将 Android MCP 与远程 MCP 服务器结合，开发者可通过 Gemini Apps Developer Mode 本地构建和测试应用，申请预览版候补名单，将应用接入 Gemini 和搜索的用户场景。

💬 文章金句

  • Android 智能系统是专为在保障用户安全的前提下，将 AI 智能体与 Android 设备端应用连接起来的系统级基础架构。
  • 借助 LiteRT，您可以以更快的 GPU 性能运行自定义机器学习模型，同时将运行时从 APK 中剥离，使 APK 体积缩小约 8 MB。
