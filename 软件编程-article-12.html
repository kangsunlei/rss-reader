增强构建现在提供双倍计算能力 - Vercel

4/17/2025, 1:00:00 PM

📌 一句话摘要

Vercel 增强构建为企业客户提供双倍计算能力，提升构建速度和 Turbopack 性能。

📝 详细摘要

Vercel 宣布为企业客户提供增强构建（Enhanced Builds），该服务提供双倍的计算能力，旨在提升大型代码库和 CPU 密集型构建的性能，构建时间最多可减少 25%。此功能专为使用单体仓库或并行运行任务（例如依赖项解析、转译或静态生成的框架）的企业客户设计。现有增强构建用户无需任何操作，即可自动体验性能提升。此外，此更新通过在所有可用核心上高效分配工作，显著加快了 Turbopack 的构建速度。Vercel 内部测试表明，核心数量的增加带来接近线性的性能提升。

💡 主要观点

  1. 增强构建提供双倍计算能力，提升大型代码库和 CPU 密集型构建速度。 Vercel 为企业客户提供的增强构建服务，通过增加计算资源，显著减少大型代码库和 CPU 密集型构建的构建时间。
  2. 现有用户无需操作即可享受性能提升。 已在使用增强构建的企业客户无需任何配置，即可自动体验构建速度提升。
  3. 核心数量增加带来 Turbopack 接近线性性能提升。 增强构建通过更有效地利用所有可用核心，加速 Turbopack 构建过程，内部测试显示性能提升与核心数增加呈线性关系。

💬 文章金句

  • Enhanced Builds now offer double the compute capacity， further improving performance for large codebases and CPU-intensive builds.
  • Customers already using Enhanced Builds are seeing， with no action required， up to 25% reductions in build times.
  • This change also enables significantly faster Turbopack builds by efficiently distributing work across all available cores.
