打不过 Claude 就卷“骨折价”？马斯克 Grok 4.5 杀疯了：数万块 GB300 训练，实测硬刚 GPT、Claude，价格却不到一半

7/9/2026, 9:34:00 AM

📌 一句话摘要

本文综合官方信息与第三方评测，报道马斯克旗下 SpaceXAI 发布的 Grok 4.5 模型，重点分析其编程能力、Benchmark 表现与定价策略，指出其性价比突出但复杂任务能力仍落后于 GPT-5.5 与 Claude 系列。

📝 详细摘要

文章围绕 Grok 4.5 的发布展开，涵盖训练细节（数万块 GB300 GPU、强化学习、数据质量优先）、核心能力（一句话生成完整应用、Office 插件）、Benchmark 数据（Terminal Bench 2.1 接近 GPT-5.5，但 DeepSWE 1.1 和 SWE Bench Pro 差距明显）以及第三方 TryAI 的实测对比（3D 魔方、粒子模拟、打砖块游戏）。文章重点突出其定价策略：输入价格仅为 GPT-5.5 的 40%、Claude Fable 5 的 20%，并强调其低 Token 消耗与高推理速度，最终结论为「绝对性能未必第一，但性价比极高」。文末提供了 API 接入方式和参考链接。

💡 主要观点

  1. Grok 4.5 在简单编程任务上接近一线水平，但复杂真实工程任务差距明显。 Terminal Bench 2.1 得分 83.3% 接近 GPT-5.5 的 83.4%，但 DeepSWE 1.1 仅 53%，远低于 GPT-5.5 的 67% 和 Fable 5 的 70%，说明其在处理真实 GitHub Issue 等复杂场景时仍有较大差距。
  2. Grok 4.5 的最大优势是性价比，定价远低于竞品。 输入价格仅为 GPT-5.5 的 40%、Fable 5 的 20%，同时 Token 消耗约为 Claude Opus 4.8 的 1/4.2，推理速度约 110 Token/s，综合成本优势突出。
  3. 第三方实测显示其一次生成能力尚可，但稳定性不如顶级模型。 在 TryAI 的 3D 魔方测试中，Grok 4.5 首次生成失败，需要重试才成功，而 Claude 两款模型均一次成功；在粒子模拟和打砖块测试中表现合格。

💬 文章金句

  • 绝对性能未必全面第一，但如果把速度和价格一起算进去，它可能是目前最具性价比的 AI 编程模型之一。
