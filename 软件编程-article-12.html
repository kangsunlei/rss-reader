DeepSeek V4 Pro 正式发布，首发实战测评：7 个项目验证编程能力

8/13/2026, 8:33:00 AM

📌 一句话摘要

本文通过 7 个实战项目（前端动画、3D 讲解、游戏仿真、PPT 工具、抽奖系统、肉鸽游戏、全栈 AI 工具）深度测评 DeepSeek V4 Pro 的编程能力，对比 Kimi K3 与 Claude Opus 5，结论为「部分场景夯实，整体仍有差距」

📝 详细摘要

DeepSeek V4 Pro 正式版发布，支持 1M 上下文、384K 最大输出，Agent 能力与 Responses API 进一步增强。作者通过 7 个实战项目（交互式动画讲解网站、3D 版动画知识讲解、竹知了仿真网页游戏、网页 PPT 生成工具、在线抽奖系统、以撒的结合肉鸽游戏、全栈 AI 编程工具）全面测评其编程能力。测评中自建 Harness 系统确保公平对比，发现 DeepSeek V4 Pro 在终端任务完成（Terminal Bench 2.1 得 87.9 分，与 Claude Fable 5 相差 0.1）等基准表现优异，但在前端审美、创意设计、复杂逻辑实现方面仍有明显差距。对比 Kimi K3 与 Claude Opus 5，DeepSeek V4 Pro 在部分场景表现出色（如肉鸽游戏的战斗逻辑），但在整体体验、细节打磨方面仍需提升。最终 300 元测试费用实际消耗约 150 元。

💡 主要观点

  1. DeepSeek V4 Pro 在终端任务完成等基准测试中表现突出 Terminal Bench 2.1 得 87.9 分（与 Claude Fable 5 相差 0.1），DeepSWE 从 12.8 涨至 62.7，Cybergym 从 52.7 涨至 83.3，NL2Repo 从 38.5 涨至 61.5，体现其在多步骤任务执行上的显著提升
  2. 前端审美与创意设计仍是短板 在交互式动画、3D 讲解等项目中，DeepSeek V4 Pro 的前端效果明显不如 Kimi K3 与 Claude Opus 5，存在文字溢出、连线错位、动画敷衍等问题
  3. 后端逻辑与工程能力相对可靠 在抽奖系统中，后端幂等与并发控制做到位，1000 人抢 100 个名额时无超发或重复中奖；在全栈 AI 编程工具中，能完成代码编辑、工具调用等核心功能
  4. 复杂项目实现存在局限性 肉鸽游戏仅实现 1 层，全栈 AI 编程工具未基于 VS Code 源码直接开发而是另起炉灶，显示在大型代码库面前仍有提升空间
  5. 成本效益较高 300 元测试费用实际消耗约 150 元，显示其在成本控制方面具有优势

💬 文章金句

  • 跑分归跑分，模型好不好用，还得拿真实项目来检验。
  • 终端的胜负往往不在首发名单，而在第 60 分钟那块写满数据的白板上。
  • 代码写得再漂亮也没用，效果好不好只能靠耳朵听、凭自己的手感来玩。
  • 从工程角度来说这个选择是合理的，毕竟直接改造 VS Code 源码是要消耗大量成本的。
