两年实盘 +135%，聊聊我用 Claude Code 搭的多 Agent 投研框架

6/23/2026, 2:52:26 AM

📌 一句话摘要

作者分享了一套基于 Claude Code 的多 Agent 对抗投研框架，通过 4 个独立 Agent 并行分析、互相挑战，输出分层投资建议，并附两年实盘收益验证。

📝 详细摘要

文章系统介绍了作者开发并开源的多 Agent 投研框架（ai-berkshire）。框架通过 4 个独立的 Claude Code agent 从商业模式、财务估值、行业竞争、风险评估四个维度分别搜索、交叉验证并给出结论，再由 Team Lead 综合并经受其他 agent 的挑战，以打破 LLM 自我强化倾向。工程上有多个关键设计：用 decimal.Decimal 确保财务计算精度、内置 Benford 定律检测异常数据、多层纠偏机制（信息丰富度分级、逆向检验、快速否决清单）。作者提供了实盘收益（2024 +69.29%，2025 至今 +66.38%）并强调工具只负责研究，买入决策由人做出。文章同时列出了已知局限：token 消耗较大、决策仍依赖人。最后开源项目在 GitHub，MIT 许可，无任何付费版本或课程。

💡 主要观点

  1. 多 Agent 对抗设计：4 个独立 agent 分别研究并互相挑战，避免单一 LLM 的自我强化倾向。 每个 Agent 从不同维度独立搜索、验证并给出结论，最后互相质疑，确保最终报告经过多方检验而非单一路径的自我确认。
  2. 工程细节保证可靠性：精确计算、跨源验证、Benford 定律检测。 所有财务计算走 Python decimal.Decimal，避免 LLM 心算错误；关键数据至少 2 个独立来源交叉验证；内置 Benford 定律检测财务数据异常。
  3. 多层纠偏机制：逆向检验与快速否决清单。 强制思考「这家公司怎么会死」，8 条红线一票否决（如管理层诚信问题），提高分析质量，降低错误决策风险。
  4. 实盘收益验证但不构成因果关系。 作者展示两年实盘（2024 +69.29%，2025 至今 +66.38%）大幅跑赢指数，但明确声明收益来自集中持有深度研究过的公司，框架仅提高研究效率。
  5. 开源且无商业成分，MIT 许可。 项目完全开源，无付费版、无课程、无星球，作者仅提供技术分享，降低读者对营销的疑虑。

💬 文章金句

  • 单个 LLM 容易自我强化——前面说了看好，后面就不自觉找支撑证据。
  • AI 最危险的不是给错答案，而是给一个看起来很对但经不起推敲的答案。
  • 5 句话说不清为什么买，就是不该买。
  • 这个帖子不是来说'用 AI 炒股能赚钱'的——收益来自集中持有深度研究过的公司，框架的作用是提高研究效率和分析质量。
