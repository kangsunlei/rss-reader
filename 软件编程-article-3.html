📝 详细摘要

这篇来自 JetBrains 的文章详细介绍了未来六到十二个月内 Kotlin 多平台 (KMP) 和 Compose 多平台 (CMP) 的战略方向和即将进行的开发，与 Kotlin 路线图规划方向一致。核心优先级包括通过提高构建速度和改进 Swift 导出，显著提升 iOS 开发者体验。对于 Web 目标，重点是通过将 Compose for Web 和 Kotlin/Wasm 推广到 Beta 版，以及改进用于业务逻辑共享的 JavaScript 导出，以支持更多生产环境应用场景。此外，JetBrains 旨在通过扩展在 Windows 和 Linux 上的插件支持、更好的 Swift 集成和必要的 Web 工具，来提升 IntelliJ IDEA 和 Android Studio 中的 IDE 体验。具体举措包括发布 Compose Multiplatform for Web 的 Beta 版，使更多的 Jetpack 库可用于 Compose 多平台，以及在 iOS 上实现新的原生文本输入。Kotlin/Native，包括减少构建时间、推进具有并发支持的 Swift 导出等，Kotlin/JS（为 Compose for Web 引入 Kotlin/JS 后备方案，扩展 JavaScript 导出功能）和 Kotlin/Wasm（带有编译器修复、标准库质量和多模块编译的 Beta 版发布）也计划进行技术改进。文章还强调了简化 Gradle 构建配置、降低 KMP 库的发布难度、提供统一的构建工具 API 以及加速 Gradle 构建和导入的努力。最后，JetBrains 致力于扩展文档和入门资源，包括 Klibs.io，以降低开发者的学习成本。

💡 主要观点

  1. 提升 iOS 开发体验：更快的构建，更完善的 Swift 导出 解决 Kotlin/Native 构建速度慢、Swift 互操作性不足等常见问题，旨在提高使用 KMP 的 iOS 开发人员的生产力和采用率。
  2. 通过将 Compose for Web 和 Kotlin/Wasm 推广到 Beta 版，扩展 Web 用例 这些 Beta 版本的发布标志着成熟和稳定，为 KMP 开发者提供了构建高性能、功能丰富的 Web 应用的信心。
  3. IDE 工具重大改进：Windows、Linux 及 Swift 集成 改进的 IDE 支持跨主要操作系统和增强的语言集成将简化开发工作流程，并减少 KMP 开发人员的摩擦。
  4. 简化构建工具和库发布，助力 KMP 落地 简化 Gradle 配置和库发布的努力旨在降低初学者的入门门槛，并促进多平台组件的生态系统增长。
  5. 致力于文档和入门，以促进 KMP 的学习和采用 更完善的迁移文档和 Klibs.io 有助于新老开发者在复杂项目中成功应用 KMP。

💬 文章金句

  • 让 iOS 开发成为一种享受 虽然 iOS 目标趋于成熟，但开发者体验仍有改进的空间。
  • 通过将 Compose for Web 和 Kotlin/Wasm 推广到 Beta 版，我们期待看到先行者将中小型应用部署到生产环境。
  • 我们的目标是使 IntelliJ IDEA 和 Android Studio 成为多平台开发的卓越环境。
  • 为了降低 KMP 的上手难度，我们将允许在项目级别声明依赖项，并自动传播到所有源集，就像在 JVM 和 Android 项目中一样。
  • 学习一项新技术可能具有挑战性，但良好的指导可以使道路更加轻松。
