Numa：8MB 单文件 DNS 开源工具，广告拦截与本地域名一站式解决

4/29/2026, 1:30:05 PM

📌 一句话摘要

Numa 是一个仅 8MB 的 DNS 开源工具，用 Rust 编写，内置 38 万条广告域名拦截和本地域名功能，支持自动 HTTPS 证书，跨平台且无需云服务依赖。

📝 详细摘要

该推文介绍了一款名为 Numa 的轻量级 DNS 开源工具。其核心卖点在于体积小（8MB 单文件）、功能实用（广告拦截、本地域名解析、自动 HTTPS 证书）以及完全本地化运行（不依赖任何云服务）。工具使用 Rust 语言编写，自带 DNS 缓存和 38 万条广告域名拦截列表，可有效解决公共 WiFi 下的广告骚扰和 DNS 隐私泄露问题。此外，它还支持为本地服务（如开发环境）配置域名并自动签发 HTTPS 证书，方便开发者使用。支持 macOS、Linux、Windows 三大平台，安装简单，手机端也可通过扫码接入。对于经常在公共网络下工作、或需要本地开发域名管理的技术从业者来说，这是一个实用且高效的工具。
