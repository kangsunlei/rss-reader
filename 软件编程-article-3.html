分享一个零依赖的 JSON Formatter(CLI + Web)

📌 一句话摘要

本文介绍一个零依赖的 JSON Formatter 工具，支持自动解析转义字符串、URL 分享和终端管道使用。

📝 详细摘要

文章分享了一个开源的 JSON Formatter 工具，其核心功能包括：自动解析被序列化的 JSON 字符串（支持多层转义），无需手动 unescape；支持将数据序列化到 URL 中实现分享，无需服务器或数据库；以及支持终端管道操作，可直接将 curl 等命令的输出格式化显示。工具同时提供 CLI 和 Web 两种使用方式。

💡 主要观点

  1. 自动解析多层转义的 JSON 字符串。 工具能自动识别并逐层 unwrap 被 stringify 的 JSON 字段值，如日志或接口中常见的转义字符串，无需手动处理。
  2. 通过 URL 实现数据分享。 数据被序列化到链接中，接收方打开链接即可看到相同视图，无需服务器存储或上传。
  3. 支持终端管道操作。 可直接将 curl 等命令的输出通过管道传递给工具进行格式化，无需复制粘贴到网页。
