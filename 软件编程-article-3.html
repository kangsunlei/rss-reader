macOS 遭新型窃密攻击，AmnesiaStealer 可远程控制浏览器

8/16/2026, 10:00:00 AM

📌 一句话摘要

Jamf Threat Labs 披露的新型 macOS 窃密恶意软件 AmnesiaStealer，通过仿冒 GitHub 页面和 ClickFix 技术窃取凭据，并具备实时远程控制受害者浏览器的能力。

📝 详细摘要

Jamf Threat Labs 研究人员披露了 AmnesiaStealer，一种基于 Rust 的多阶段 macOS 信息窃取恶意软件。该恶意软件通过仿冒 GitHub 下载页面（含深色主题、Octocat 标志和「Verified Publisher」徽章）诱导用户粘贴终端命令，利用 ClickFix 技术完成初始感染。攻击链分为三阶段：第一阶段 shell 脚本负责下载并启动有效载荷；第二阶段 Rust 窃密模块负责窃取钥匙串、浏览器数据、Apple Notes 和 Telegram 信息；第三阶段按需获取的 stream_module 赋予操作者对受害者浏览器的实时隐蔽控制，可驱动键盘输入、鼠标点击和导航，而受害者浏览器窗口保持正常显示。恶意软件通过伪装为 macOS 安装器对话框骗取密码，利用 sudo 获取特权读取权限，并针对 16 种 Chromium 系浏览器发起 cookie、凭据和历史记录窃取。在 macOS 26 上，恶意软件会删除 Chrome Safe Storage 密钥并替换为已知密钥，这一行为可作为有效检测信号。C2 后端名为 Amnesia Panel，使用俄语错误信息，基础设施分析显示其为成熟运营活动。

💡 主要观点

  1. AmnesiaStealer 通过仿冒 GitHub 页面和 ClickFix 技术完成初始感染。 诱饵页面高度逼真，包含正确的深色主题、Octocat 标志和「Verified Publisher」徽章，但无下载按钮，而是要求用户粘贴终端命令。同一模板也出现在 Atomic Stealer 和 MacSync 活动中，表明诱饵基础设施在多个恶意软件家族间共享。
  2. 三阶段攻击链设计成熟，第三阶段浏览器劫持能力超出同类恶意软件。 第一阶段 shell 脚本下载并启动有效载荷；第二阶段 Rust 窃密模块窃取钥匙串、浏览器数据、Apple Notes 和 Telegram；第三阶段 stream_module 以无头模式克隆浏览器配置文件，赋予操作者实时隐蔽控制，受害者浏览器窗口保持原样不显示异常。
  3. 恶意软件通过伪装安装器对话框骗取密码并获取特权读取权限。 使用 dscl 命令针对目录服务本地验证密码，错误时循环提示重试。捕获的密码通过管道传递给 sudo -S 和 security unlock-keychain，以明文写入暂存目录和用户主目录，随后解锁钥匙串并窃取大量数据。
  4. 在 macOS 26 上删除并替换 Chrome Safe Storage 密钥可作为有效检测信号。 恶意软件无法正常获取 Safe Storage 密钥时会删除它并替换为已知密钥，使攻击者能解密新窃取的密码和 cookie，但合法浏览器不会通过 security 命令删除并重新创建 Safe Storage 条目。

💬 文章金句

  • AmnesiaStealer 分三个阶段运行：第一阶段是一个 shell 脚本，负责下载并启动有效载荷；第二阶段是一个 Rust 信息窃取恶意软件；第三阶段是一个按需获取的 stream_module，赋予操作者对受害者浏览器的隐蔽交互式控制权。
  • 该流模块会克隆受害者的浏览器配置文件，以无头模式启动，并赋予操作者对会话的实时隐蔽控制权。
  • 一个有效的收集器加上一个有效的浏览器劫持模块，再包裹上一些过时的绕过技术，使其值得持续跟踪。
