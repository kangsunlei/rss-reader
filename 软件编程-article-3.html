GitHub Copilot CLI 新增会话历史功能：基于本地 SQLite 数据库

3/11/2026, 9:15:30 PM

📌 一句话摘要

GitHub Copilot CLI 现已支持本地 SQLite 数据库和全文搜索，帮助开发者即时回溯并检索之前的会话历史。

📝 详细摘要

GitHub 对 Copilot CLI 进行了重大更新，引入了本地 SQLite 数据库来存储会话历史。此次更新包含全文搜索索引，使开发者能够快速找回过去工作的上下文，例如特定的 Bug 修复方案或命令。通过将记忆以往会话细节的负担交给可搜索的本地数据库，该工具旨在提升开发者的生产力，并为大脑“节省空间”。
