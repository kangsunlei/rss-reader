[开源] 我做了一个 macOS 风格的 3D 专辑封面马赛克屏保（Windows 完美单文件版）

6/20/2026, 10:06:00 AM

📌 一句话摘要

作者开发了一款 Windows 单文件版 3D 专辑封面马赛克屏保，支持自动抓取 iTunes 高清封面、28 种音乐类型筛选与多显示器，完全开源免费。

📝 详细摘要

本文是作者在 V2EX 社区发布的自制开源项目介绍帖。项目名为 Mosaic Screensaver for Windows，旨在为 Windows 系统提供一个类似 macOS 经典「Artwork」专辑封面马赛克屏保的替代品。核心功能包括：纯 3D 翻转动画、自动调用 iTunes API 获取 600x600 高清封面、内置设置面板支持 28 种音乐类型筛选、绿色单文件无依赖、多显示器全屏无黑边。项目完全开源免费，附 GitHub 仓库地址与效果图。

💡 主要观点

  1. 为 Windows 系统实现了 macOS 风格的 3D 专辑封面马赛克屏保。 填补了 Windows 平台缺乏同类高质量屏保的空白，提供纯正的 3D 翻转与景深动画体验。
  2. 自动从 iTunes API 获取高清专辑封面，无需本地音乐库。 通过调用 iTunes API 实时抓取 600x600 高清封面，降低了用户使用门槛，无需准备本地音乐文件。
  3. 高度可定制，支持 28 种音乐类型筛选。 内置设置面板允许用户自由勾选 Pop、Rock、Jazz、K-Pop、ACG 等音乐类型，个性化展示内容。
  4. 开箱即用，绿色单文件无依赖。 以 .scr 单文件形式发布，无需安装额外运行库或配置，支持多显示器全屏无黑边。

💬 文章金句

  • 纯正的 3D 翻转体验：平滑的景深动画，视觉效果极佳。
  • 海量封面自动获取：不需要你有本地音乐库！它会自动调用 iTunes API 实时抓取高清（600x600）专辑封面。
