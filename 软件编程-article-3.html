Mac cleaning tool Mole releases v1.18.0， bringing smarter cleaning， enhanced safety and control features， and an optimized user experience.

📝 详细摘要

Mole is a cleaning utility for Mac systems， designed to help users quickly free up disk space. This v1.18.0 update brings three key improvements: First， 'Smarter Cleaning' now includes more intelligent handling of old browser versions， enhanced protection for Zig projects and Rails/Python vendor files， and safer local snapshot management. Secondly， 'Enhanced Safety & Control' adds Dry Run mode support， built-in safeguards for cloud storage directories， and the ability to configure specific scan paths using `mo purge --paths`. Finally， 'Better User Experience' features real-time Mac status (Battery Health， Cached Memory)， smoother Raycast quick launcher integration， and faster Shell command auto-completion. This update further enhances Mole's utility and safety.
