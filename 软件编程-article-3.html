Cinematic Skill：AI 代理生成纪录片短片

11/14/2026, 1:00:00 AM

📌 一句话摘要

Cinematic Skill 是为 Agent 设计的技能，输入「做一个 90 秒的莱特兄弟纪录片」即可自动完成脚本撰写、配音、找图、剪辑等全流程，支持 Claude Code、Codex、Cursor 等多种模型。

📝 详细摘要

Cinematic Skill 是给 Agent 用的技能，输入「做一个 90 秒的莱特兄弟纪录片」即可自动完成写稿、配音、找图、剪辑等全流程。先生成脚本后配音，再从维基共享资源找公有领域老照片并记下授权，使用代码生成画面。画面由代码逐帧渲染而成，非 AI 生成视频。用户可在分镜表、画面风格和 30 秒样片处确认。作者在 16GB 内存笔记本上，92 秒成片输出 1080p 约需 6 分钟。支持纪录片、产品发布、科普讲解等不同画面风格，兼容 Claude Code、Codex、Cursor、Gemini CLI 等。

💡 主要观点

  1. 全流程自动化内容生成 从脚本撰写、配音、查找公有领域图片到代码渲染画面，全部由 Agent 完成，大幅降低创作成本。
  2. 多模型通用设计 支持 Claude Code、Codex、Cursor、Gemini CLI 等多种模型，可灵活集成到不同工作流中。
  3. 代码驱动的可控渲染 画面通过代码逐帧渲染，输出 1080p 视频，运行时长稳定可预测。

💬 文章金句

  • Cinematic Skill 是给 Agent 用的 Skill，跟它说一句「做一个 90 秒的莱特兄弟纪录片」，它就从写稿开始往下做。
  • 画面全是代码一帧帧画出来的，不是 AI 生成的视频。
