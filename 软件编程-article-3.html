Git 安全漏洞公告

7/8/2025, 5:02:11 PM

📌 一句话摘要

Git 项目发布了新版本，旨在解决影响所有先前版本的七个安全漏洞，并提供了升级和缓解措施。

📝 详细摘要

Git 项目发布了新版本，以解决影响所有先前 Git 版本的七个严重安全漏洞（CVE-2025-48384 至 CVE-2025-48386、CVE-2025-27613、CVE-2025-27614、CVE-2025-46334、CVE-2025-46335），其中包括 Windows 和 Git GUI/Gitk 的特定问题。这些漏洞的范围从通过子模块路径处理和包获取协议注入执行任意代码，到凭证助手中的缓冲区溢出，以及图形界面中的任意文件操作。本文详细介绍了每个 CVE 的性质，并强调升级到 Git 2.50.1 是主要的防御措施。此外，文章还为无法立即升级的用户提供了快速缓解措施，并着重介绍了 GitHub 为保护其用户和服务而采取的积极措施。

💡 主要观点

  1. Git 中已发现七个新的严重安全漏洞（CVE）。 这些漏洞影响子模块、包获取、凭证助手、Gitk 和 Git GUI 等各种组件，可能导致严重后果，例如执行任意代码或篡改文件。
  2. 升级到 Git 2.50.1 是修复这些漏洞最有效的解决方案。 新的 Git 版本包含了针对所有已公布 CVE 的修复程序，可提供全面的保护，防止潜在的攻击利用。
  3. 对于无法立即升级 Git 的用户，可以使用快速缓解措施。 这些措施包括避免使用来自不受信任仓库的特定命令或配置，以及禁用某些功能以降低受攻击面。

💬 文章金句

  • 今天，Git 项目发布了新版本，以解决影响所有先前 Git 版本的七个安全漏洞。
  • 如果被移除尾部字符的路径和子模块的钩子目录之间已经存在符号链接，则攻击者可以通过子模块的 `post-checkout` 钩子执行任意代码。
  • 防止这些漏洞的最有效方法是升级到 Git 2.50.1，这是包含上述漏洞修复程序的最新版本。
  • 为了保护用户免受与这些漏洞相关的攻击，GitHub 已采取积极措施。
