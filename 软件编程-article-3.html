📌 一句话摘要

本文介绍一个 Ghostty 终端插件，能在终端里渲染一个实时黑洞，其大小随 Claude Code 上下文窗口使用率动态变化，提供直观的上下文占用视觉反馈。

📝 详细摘要

文章介绍了一个名为 ghostty-blackhole 的开源项目，它是一个 Ghostty 终端的 Shader 插件。该插件利用 Ghostty 1.0 后开放的自定义 Shader 接口，在终端中实时渲染一个基于物理公式（光线追踪）的黑洞。这个黑洞的独特之处在于，它会根据 Claude Code 的上下文窗口使用率动态变化：新会话时只有米粒大小，随着上下文逐渐填满，黑洞会不断长大，扭曲附近的文字，最终在 100% 满时吞噬整个屏幕。文章详细描述了黑洞的视觉效果、工作原理（基于 Eric Bruneton 的 black hole shader）、安装步骤以及如何将其与 Claude Code 的上下文状态联动。该项目旨在为开发者提供一种直观、有趣且非侵入性的方式来感知 AI 编程助手的上下文状态。

💡 主要观点

  1. ghostty-blackhole 是一个将物理渲染的黑洞与 AI 编程工具上下文状态结合的创意项目。 它利用 Ghostty 终端的自定义 Shader 能力，实时渲染一个黑洞，其大小与 Claude Code 的上下文窗口使用率成正比，将抽象的状态可视化。
  2. 黑洞的视觉效果基于 GPU 实时光线追踪，具有物理真实性。 项目基于 Eric Bruneton 的 black hole shader，在 GPU 中实时计算时空弯曲和光线路径，使得文字在黑洞边缘会产生真实的扭曲效果，而非简单的贴图动画。
  3. 该项目提供了一种新颖的、非侵入式的上下文状态监控方式。 开发者无需查看进度条或命令行提示，仅凭余光感知黑洞的大小和位置，即可直观了解 Claude Code 的上下文占用情况，并决定是否执行 /compact 操作。
