Power BI 自动发布功能上线

3/31/2025, 3:00:00 PM

📌 一句话摘要

Databricks 工作流新增 Power BI 任务，简化数据集成，实现 Power BI 语义模型自动更新。

📝 详细摘要

Databricks 宣布在 Azure、AWS 和 GCP 上推出 Databricks 工作流中的 Microsoft Power BI 任务类型公共预览版。通过此任务类型，用户可以直接从 Databricks 更新和刷新 Power BI 语义模型，解决了数据分析师需要在不同平台间手动更新 Power BI 数据的问题，简化了操作，从而降低总体拥有成本，提高效率，并确保 Power BI 报告和仪表板使用者获得最新的数据。主要优势包括直接集成、在数据更新时更新 Power BI，以及为 BI 提供新鲜数据。Power BI 任务完全支持 Unity Catalog 数据对象，包括表、视图、物化视图和流表。Power BI 任务支持以导入 (Import)、直接查询 (Direct Query) 和双重存储模式 (Dual Storage modes) 发布、更新和刷新语义模型，从而为您提供充分的灵活性来平衡性能和安全性。可以通过 Databricks 作业 UI 直观地使用 Power BI 任务，也可以通过作业 API 和 Databricks 资产包以编程方式使用。

💡 主要观点

  1. Power BI 任务通过消除上下文切换，简化 Databricks 与 Power BI 之间的数据集成。 消除了在 Databricks 和 Power BI 之间切换上下文的需要，简化了在 Power BI 中进行可视化和分析的数据可用性过程。
  2. 与 Unity Catalog 的本机集成提高了安全性和合规性。 通过无缝身份验证、授权和数据访问控制，增强了 Databricks 和 Power BI 环境中的安全性和合规性。
  3. Power BI 任务利用 Databricks 工作流的强大功能。 Power BI 任务的数据管道可以扩展任务依赖项、计划/触发器、重试和通知等功能。
