掌控您的 IP：Cloudflare 助力高效地址空间管理

5/19/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 推出服务绑定，实现 BYOIP 前缀在 CDN、Spectrum 和 Magic Transit 间的灵活分配。

📝 详细摘要

本文通过介绍 Cloudflare 的 BYOIP (自有 IP) 前缀服务绑定新功能，解决了 IPv4 地址日益稀缺和成本增加的问题。以前，整个 BYOIP 前缀都绑定到单个服务。新功能允许客户将单个前缀的子范围同时分配给不同的 Cloudflare 服务，如 CDN、Spectrum 和 Magic Transit。文章详细阐述了为实现动态灵活性而克服的技术挑战，包括：使用 iptables/IP 集动态重分配前缀；更新基于 eBPF 的 Tubular 服务，实现动态 IP/端口绑定且无需重启服务；以及在庞大的服务器集群中协调这些变更。一个实际的例子演示了客户如何将 /24 前缀在 Spectrum 和 CDN 之间进行拆分。此增强功能使客户能够更有效地控制和管理其昂贵的 IP 地址空间。

💡 主要观点

  1. IPv4 的稀缺性使得企业需要更高效的 IP 地址管理。 二级市场上 IPv4 地址的成本不断上升和可用性有限，使得优化其使用至关重要，特别是对于那些尚未完全迁移到 IPv6 的企业。
  2. 新的服务绑定提供跨 Cloudflare 服务的精细 BYOIP 前缀分配。 现在，客户可以拆分单个 BYOIP 前缀的子范围，以便与 Cloudflare CDN、Spectrum 和 Magic Transit 同时使用，从而提高灵活性和效率。
  3. 在各项服务中实施动态 BYOIP 前缀分配需要克服重大的技术挑战，包括通过 Tubular 服务利用 eBPF 进行动态 IP/端口绑定而无需重启服务。 主要挑战包括在分布式系统中动态更新 iptables/IP 集，以及专门扩展 eBPF Tubular 服务以支持 CDN 等服务的动态 IP/端口绑定，无需重启服务。这是一项重要的技术创新。
  4. 该功能使用户能够通过 API 根据特定工作负载定制 IP 使用。 服务绑定允许通过简单的 API 调用定义哪些 IP 范围路由到哪些服务，从而更有效地控制流量并优化资源分配。

💬 文章金句

  • 这种不断上涨的成本和有限的可用性使得高效的 IP 地址管理比以往任何时候都更加重要。
  • 现在，客户可以使用任何前缀的一部分——无论是绑定到 Cloudflare CDN、Spectrum 还是 Magic Transit——以便与 CDN 或 Spectrum 进行额外使用。
  • 在 Cloudflare 服务之间动态迁移 BYOIP 前缀并非易事，特别是对于数千台能够接受和处理连接的服务器。
  • Tubular 允许服务监听单个套接字，并动态更新路由到该套接字的地址列表。这样，服务无需在地址更改时重新启动。
  • 我们设想未来客户可以精细地控制其流量如何在 Cloudflare 的全球网络中移动，不仅按服务，而且按端口级别。
