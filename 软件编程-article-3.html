Gemini API 文件大小限制提升并扩展输入支持

1/12/2026, 5:11:10 PM

📌 一句话摘要

Google 的 Gemini API 现在支持从 Google Cloud Storage、外部 HTTPS/签名 URL 直接获取数据，并提高了内联文件大小限制，以简化多模态 AI 应用开发。

📝 详细摘要

Google 宣布了对 Gemini API 的重大更新，扩展了其数据获取能力，以更好地支持生产级 AI 应用。主要改进包括直接支持 Google Cloud Storage 对象注册，以及能够通过来自各种云提供商（AWS S3、Azure Blob Storage）的 HTTPS/签名 URL 使用数据。这消除了之前需要将大文件上传到 Gemini Files API（仅提供 48 小时临时存储）的要求，从而消除了依赖持久数据的应用程序的主要瓶颈。此外，直接上传的内联文件大小限制已从 20MB 大幅提高到 100MB，以满足原型设计、实时用例和较大多媒体资源的需求。这些增强功能旨在减少开发障碍，加速多模态 AI 应用程序的部署，并让开发者更有效地利用现有数据存储解决方案。文章强调，这些功能可通过最新的 GenAI SDK 立即使用。

💡 主要观点

  1. Gemini API 现在支持通过注册文件 URI 直接从 Google Cloud Storage 获取数据。 这消除了移动或重新上传已存储在 GCS 存储桶中的数据的需求，为开发 AI 应用的 Google Cloud 用户简化了工作流程并提高了效率。
  2. 现在支持使用外部 URL（包括来自主要云提供商 AWS S3、Azure Blob 的公共和预签名 URL）作为数据输入。 此功能允许 Gemini API 直接从现有外部存储安全地获取数据，消除了开发者管理中间下载和上传的需要。
  3. 请求中直接传递数据的内联文件大小限制已从 20MB 增加到 100MB。 此增强功能满足了实时应用和原型设计的需求，使得无需为中等大小的输入使用外部存储解决方案即可更轻松地处理较大的图像、短音频片段或文档。
  4. 这些更新解决了先前与临时存储和数据传输相关的瓶颈，加速了生产规模的 AI 开发。 通过提供更灵活和持久的数据输入方法，Google 旨在帮助开发者更无缝、更高效地将 Gemini API 集成到他们的 AI 应用中，特别是对于多模态用例。

💬 文章金句

  • 不再需要从现有存储重新上传数据，让您能够更快地将 AI 应用扩展到生产环境。
  • 以前，使用大文件（视频、长音频、海量文档）需要将它们上传到 Gemini Files API，这些文件在那里仅保留 48 小时。虽然这对于原型设计来说足够了，但这种临时存储对于依赖云存储平台中持久数据的生产应用来说成为了一个瓶颈。
  • Gemini API 在处理过程中安全地获取内容，消除了仅为了将内容转发给 API 而将其下载到后端的需要。
  • 对于喜欢使用内联文件以获得速度和简便性的开发者，我们将内联数据的最大有效负载大小从 20MB 增加到 100MB（Base64 编码，根据数据类型略有不同的限制）。
  • 我们很高兴看到消除这些数据障碍如何帮助您以更少的开销更快地构建和扩展多模态应用。
