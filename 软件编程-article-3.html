Ktor 3.2.0 发布 | Kotlin 博客

6/19/2025, 3:19:23 PM

📌 一句话摘要

Ktor 3.2.0 发布，带来新的依赖注入、HTMX 模块、类型化配置、Unix 域套接字支持以及 Gradle 版本目录集成。

📝 详细摘要

Ktor 3.2.0 版本为 Kotlin Web 框架迎来多项重大增强。主要功能包括一个可选的、基于协程的依赖注入模块，该模块构建于 Coroutine 之上，支持并发初始化和自动资源清理。该框架现在支持将配置文件自动反序列化为类型安全的数据类。新的 HTMX 模块简化了与 kotlinx.html 的集成，用于构建动态服务端渲染界面。CIO 引擎现在支持高效的 Unix 域套接字，用于进程间通信。此外，Ktor 现在提供了一个 Gradle 版本目录，用于类型安全的依赖管理。此版本还包括各种性能改进、错误修复，并注意到 Android R8 存在一个已知回归问题，将在未来的补丁中解决。

💡 主要观点

  1. 引入了一个可选的、基于 Coroutine (协程) 的依赖注入模块。 这个新的 DI 模块与 Ktor 的异步特性无缝集成，为依赖项提供并发初始化和自动资源管理。
  2. 添加了自动类型化配置反序列化。 配置文件现在可以自动反序列化为数据类，从而提升类型安全性和开发者体验。
  3. 包含一个用于 HTMX 集成的新模块。 使用服务端渲染 HTML，将 HTMX 与 kotlinx.html 和 Ktor 的路由领域特定语言无缝集成，以构建交互式 Web 应用程序。
  4. 为 CIO 引擎启用 Unix 域套接字支持。 允许在同一机器上进行高效、低开销的进程间通信，从而提高本地服务的性能。
  5. 提供了一个 Ktor 特定的 Gradle 版本目录。 通过提供类型安全且集中化的方式来声明 Ktor 依赖项，从而简化 Gradle 项目中的依赖项管理。

💬 文章金句

  • 此版本包括两个用于依赖注入和 HTMX 的新模块，支持 Gradle 版本目录、自动配置反序列化、CIO 的 Unix 域套接字支持等功能。
  • 依赖注入 (DI) 是许多团队的关键特性，并且是社区强烈要求的。
  • CIO 客户端和服务器引擎现在支持 Unix 域套接字！这种支持提供了同一系统上进程之间更高效的双向通信，从而完全消除网络开销。
  • 新的 HTMX 模块包括与 kotlinx.html 和 Ktor 路由领域特定语言的紧密集成。
  • 它们允许我们从 Gradle 脚本中以类型安全的方式引用依赖项，并在单个位置管理依赖项。
