opennews-mcp：聚合 85+ 金融消息源，AI 评分影响力的 MCP 工具

9/15/2026, 1:30:06 PM

📌 一句话摘要

opennews-mcp 是一个基于 MCP 的金融消息聚合平台，整合了超过 85 个新闻、交易所、链上和市场数据源，并使用 AI 赋予每条消息影响力评分和情感分析，用于高效跟踪加密货币和金融市场的动态。

📝 详细摘要

opennews-mcp 是一个由 GitHub 用户 qd-team 开发的 MCP 扩展，专门用于金融市场的消息聚合与分析。该工具集成了新闻、交易所、链上交易、市场异动和预测信号等多个领域的 85 家以上数据提供商，通过 AI 进行文本分析，为每条消息分配 0 到 100 的影响力分数、情感判断（偏多/偏空）以及中英文摘要。此外，它还实现了针对大额交易、持仓变化、资金费率和爆仓事件的实时监控。用户在安装并配置 API Key 后，可以通过与 Claude Code 或其他 MCP 兼容应用的对话，实时获取市场上的重要动态。

💡 主要观点

  1. 多源消息聚合 opennews-mcp 整合了 85 个以上的数据源，涵盖新闻、交易所上币、链上交易、市场异动和预测信号，为用户提供一站式的信息入口，避免需要手动访问多个网站。
  2. AI 驱动的影响力评分 每一条消息都经过 AI 处理，生成一个 0 到 100 的影响力分数，帮助用户快速判断哪些信息是市场的热点，哪些是次要新闻。同时，AI 还分析消息的情感，判断其是否对市场产生正面或负面的影响。
  3. 链上与市场异常监控 该工具专门针对链上大额转账和交易所持仓变动进行跟踪，并能够检测市场中的异常情况，如资金费率的大幅波动或爆仓事件，帮助用户及时发现潜在的风险或机会。
