GitHub Copilot 三种模式详解：Ask、Edit 和 Agent

5/2/2025, 4:00:00 PM

📌 一句话摘要

文章对比介绍了 GitHub Copilot 的 Ask、Edit 和 Agent 三种模式，并帮助开发者根据实际场景选择最合适的模式。

📝 详细摘要

文章详细介绍了 GitHub Copilot 的三种模式：Ask、Edit 和 Agent。Ask 模式用于快速解答编程问题，无需修改代码。Edit 模式允许开发者指定文件和修改指令，由 Copilot 生成代码变更，并由开发者最终确认。Agent 模式则可以根据高级指令，自主规划步骤、选择文件、运行命令并迭代代码，完成任务。文章分析了每种模式的适用场景，例如 Ask 适合快速查询，Edit 适合精确修改，Agent 适合新项目或复杂任务，但也需要开发者清晰的指令和对潜在风险命令的审核。同时强调了 Custom Instructions 在 Agent 模式中的重要作用，能帮助 Copilot 更好地理解开发者的偏好和项目规范。开发者应根据实际需求选择合适的模式，并始终保持对代码变更的审核。

💡 主要观点

  1. Ask 模式适用于快速获取编程问题的答案 Ask 模式无需修改代码，能快速解答编程问题，如库的使用、SQL 查询结构、算法效率等，是解决问题的低摩擦方式。总而言之，Ask 模式适用于快速获取编程问题的答案。
  2. Edit 模式在开发者掌控下加速代码修改 Edit 模式允许开发者指定修改内容，Copilot 生成代码变更，开发者审核后确认，适用于精确修改和保持控制权的场景。简而言之，Edit 模式在开发者掌控下加速代码修改。
  3. Agent 模式通过自主规划完成复杂任务，但也需要有经验的开发者 Agent 模式根据高级指令自主完成任务，适用于新项目或复杂任务，但需要开发者清晰的指令和审核潜在风险命令。Agent 模式适用于有经验的开发者，以便给出清晰指令并理解代码结构。因此，Agent 模式通过自主规划完成复杂任务，但也需要有经验的开发者。
  4. Custom Instructions 能提升 Agent 模式的效率和一致性 通过预设代码规范、命名模式和设计原则，Custom Instructions 能帮助 Agent 模式更好地理解开发者意图，减少微管理。所以说，Custom Instructions 能提升 Agent 模式的效率和一致性。

💬 文章金句

  • 无论如何，务必阅读代码变更。
  • Ask 模式是快速获取问题答案的途径。
  • Edit 模式是助手，它会告诉你对你文件所做的修改建议。
  • Agent 模式是直接执行你认为你所要求的助手——只要它遵循你明确和未明确的指令，这个模式就非常棒。
  • 所有这些工具都是为了补充你的判断而设计的。
