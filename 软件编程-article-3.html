Perplexity 搜索 API：赋能下一代 AI 应用

9/30/2025, 5:30:00 PM

📌 一句话摘要

Perplexity 推出搜索 API，以实时、预排序 Web 片段赋能 AI 代理和 RAG (检索增强生成) 应用，提升效率与准确性。

📝 详细摘要

Perplexity 发布了其搜索 API，使开发人员可以直接访问其底层搜索架构。该 API 旨在为构建智能代理、AI 应用和 RAG (检索增强生成) 管道等 AI 密集型应用场景提供实时、可靠的搜索结果。与返回完整文档的传统搜索提供商不同，Perplexity 的 API 提供细粒度、预先排序的片段，从而大大减少了预处理需求，并加速了集成到 AI 工作流程中。该公司强调其准确性和时效性，这得益于每秒更新数千文档的索引系统和 AI 驱动的内容理解模块。这确保了 AI 系统基于及时的数据，从而减轻了幻觉等问题。新的搜索 API 与 Perplexity 现有的 Sonar API 的不同之处在于，它提供原始 Web 结果而不是合成答案，从而使开发人员可以为其他模型提供基础，或构建自定义代理。为了支持其主张，Perplexity 开源了 `search_evals`，这是一个评估框架。据报道，该 API 在质量和延迟方面均优于竞争对手，且成本更低。还提供了全面的开发人员工具，包括控制台、文档和 SDK，以确保易用性。这项新产品确立了 Perplexity 在下一代 AI 产品领域中的关键地位。

💡 主要观点

  1. Perplexity 搜索 API 提供精细化、预排序的 Web 片段，赋能 AI 应用。 这种独特的方法简化了 AI 代理和 RAG (检索增强生成) 管道的数据集成，减少了预处理开销并加快了开发速度。
  2. 该 API 通过快速索引和 AI 驱动的内容理解来确保实时准确性和新鲜度。 通过将 AI 系统构建于最新且可靠的 Web 数据之上，该 API 能有效减少幻觉，提供更准确的答案。
  3. 它提供原始的、排序的 Web 结果，使开发人员能够构建自定义 AI 模型和代理。 直接访问原始 Web 结果，而非合成答案，为开发者利用搜索技术构建 AI 应用提供更大灵活性和控制力。

💬 文章金句

  • Perplexity 推出搜索 API，开放其公共答案引擎的底层架构。
  • 与当前返回合成答案的 Sonar API 不同，新的搜索 API 提供原始的、排序的 Web 结果---因此您可以直接使用它们，为其他模型提供基础，或在其之上构建您自己的代理！
  • 在早期结果中，据报道，搜索 API 在单步查询和多步代理研究工作流程方面的性能均优于竞争对手，在质量和延迟方面的得分均更高。
  • 凭借实时新鲜度、结构化响应和原始 Web 访问，Perplexity 搜索 API 将成为下一波 AI 代理和检索密集型产品的关键基石。
