智体新境｜Chrome 全新升级，打通智能体 Web 开发闭环

8/15/2026, 9:30:00 AM

📌 一句话摘要

本文介绍 2026 Google 开发者大会上 Chrome 面向智能体 Web 开发的核心更新，包括面向智能体的 Chrome 开发者工具、WebMCP 标准提案、Modern Web Guidance 及 Chrome 内置 AI 能力。

📝 详细摘要

文章围绕 2026 Google 开发者大会 Chrome 主题，系统介绍了面向智能体 Web 开发的多项技术与工具更新。核心内容包括：面向智能体的 Chrome 开发者工具，通过 MCP Server 或 CLI 接入编程智能体，使其能在真实浏览器中观察页面状态、读取控制台日志和网络请求，完成「发现问题—修改代码—验证修复」的闭环；WebMCP 作为实验性 Web 标准提案，让网站向 AI 智能体开放结构化工具，智能体可直接调用如 add_pizza_to_cart 等函数，无需逐元素点击；Modern Web Guidance 为智能体补充最新 Web 平台实践，配合 Lighthouse 审计项评估网站的智能体就绪程度。此外还介绍了现代身份验证建议（FedCM、Digital Credentials API、通行密钥）、Chrome 内置 AI（Prompt API、Proofreader API、Summarizer API）、HTML in Canvas 探索，以及端侧 AI 扩展程序等方向。文章引用了合作伙伴 P2ER 的实践数据，称开发速度提升 10 倍。

💡 主要观点

  1. 面向智能体的 Chrome 开发者工具打通了智能体调试与验证的闭环。 智能体可在真实浏览器中打开页面、执行操作、读取控制台和网络请求，定位运行时问题后修改代码并重新验证，减少开发者在代码与浏览器之间反复切换的成本。
  2. WebMCP 让网站向 AI 智能体开放结构化工具，降低操作成本。 智能体可直接调用网站预定义的 JavaScript 函数（如 add_pizza_to_cart），无需逐元素分析截图和 DOM，流程更快速可靠；Chrome 150 起提供专用 Lighthouse 审计项评估智能体就绪程度。
  3. Modern Web Guidance 解决智能体编码实践中采用过时模式的问题。 Google 内部数据显示，缺少指导时编程智能体仅约一半时间主动采用最新 Web 能力；Modern Web Guidance 补充最新实践，配合开发者工具和 Lighthouse 形成完整编码工作流。
  4. Chrome 在身份验证、内置 AI 和端侧模型方面持续扩展能力。 FedCM 与 Digital Credentials API 降低注册门槛并提升安全性；Chrome 内置 Prompt API、Proofreader API、Summarizer API；Transformers.js 与 Gemma 4 支持在扩展程序中运行本地模型。
