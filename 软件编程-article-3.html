Context Mode：通过沙箱隔离与精准索引实现 98% 的 Token 节省

3/1/2026, 11:51:45 AM

📌 一句话摘要

介绍一种名为 Context Mode 的方案，通过在 AI 模型与工具调用间增加隔离层和索引机制，大幅减少上下文 Token 消耗。

📝 详细摘要

该推文分享了 HackerNews 上的热门技术方案 'Context Mode'。针对 MCP (Model Context Protocol) 工具调用中输入输出消耗大量 Token 的问题，该方案在 Claude Code 与外部工具间引入中间层。其核心原理包括：1. 沙箱隔离执行，每个工具在独立子进程运行，仅返回 stdout 结果，防止原始大块数据进入上下文；2. 构建知识库并精简输出，利用 SQLite FTS5 虚拟表和 BM25 排名对内容建索引，实现代码块的精准拉取。测试数据显示，该方法在处理日志、CSV 和 Git 提交等场景下可实现高达 98% 的上下文节省，思路与 Cloudflare 的 Code Mode 类似。
