Node 中文周刊 #232 - Node 26.4 实验性引入 Package Maps，可从静态 JSON 解析依赖

6/26/2026, 10:09:00 AM

📌 一句话摘要

本期周刊涵盖 Node.js 26.4 实验性 Package Maps、npm v12 安装脚本讨论、WebSocket 服务器基准测试、Eve 框架、TypeScript 7.0 RC 等 Node 生态动态。

📝 详细摘要

本周刊汇总了近期 Node.js 生态的多条重要动态。头条是 Node 26.4 实验性引入 Package Maps，允许从静态 JSON 文件解析依赖，减少对 node_modules 的遍历。同时，文章对 npm v12 默认禁用安装脚本的措施进行了锐评，指出仅移除触发点不够，还需结合权限模型。其他内容包括：Node.js 五款 WebSocket 服务器的基准测试（附带调试过程中的有趣发现）、Vercel 推出的类 Next.js 风格的 AI 代理构建框架 Eve、TypeScript 7.0 RC（Go 驱动，性能提升约 10 倍）、以及 Deno 跨平台桌面应用新特性、Vercel Functions 支持 WebSockets、pnpm 的 Rust 版注册中心项目 pnpr 等。工具方面还介绍了 AccessControl v3.0、Camaro v6.5、Tedious v20.0 等。每条条目均附原文链接，便于深入阅读。

💡 主要观点

  1. Node.js 26.4 实验性引入 Package Maps 和 node:vfs 子系统。 Package Maps 允许从静态 JSON 文件解析包依赖，有望减少长时间以来对 node_modules 目录的深度遍历，提升模块查找效率。
  2. npm v12 禁止安装脚本并非安全万能解。 文章引用 Ulises Gascon 的观点，指出禁用安装脚本仅去除了一个触发点，真正被攻陷的代码在 import 时仍会执行，需要配合 Node 的 permissions 模型或沙箱机制。
  3. WebAssembly 运行时性能测评聚焦专用运行时及 Node/V8。 2026 年的基准测试涵盖了多个 Wasm 运行时，包括专用运行时和 V8 引擎，为开发者选择提供参考。
  4. Vercel 推出 Eve 框架，用于构建 AI 代理。 Eve 提供类似 Next.js 的开发体验，支持 TypeScript 和 Markdown，可默认绑定 Vercel 生态，但也支持脱离 Vercel 运行。
  5. TypeScript 7.0 RC 发布，Go 驱动带来约 10 倍构建性能提升。 新版编译器由 Go 实现，性能显著提升，同时 moduleResolution: node/node10 已不再支持，需要显式列出 @types 包。
