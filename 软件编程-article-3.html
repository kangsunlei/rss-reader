我们致力于大规模提升开源软件的无障碍特性

5/15/2025, 8:00:00 AM

📌 一句话摘要

GitHub 承诺大幅提升开源软件的无障碍特性。

📝 详细摘要

GitHub 已签署全球无障碍宣传日 (GAAD) 承诺，旨在提升开源软件的无障碍特性。此承诺聚焦于三大目标：赋能残障人士参与开源贡献、提升免费开源辅助技术（Assistive Technology，AT）的可用性和采纳率，以及增强主流开源项目的无障碍性。文章强调了将残障人士纳入技术开发的重要性，以及对经济实惠的 AT 解决方案的需求。GitHub 计划通过改进平台无障碍性、建立跨部门合作关系（包括开源项目办公室 OSPOs），并直接支持开源社区来实现这些目标。这是一项持续的努力，GitHub 正在筹办开源无障碍峰会，作为下一步行动。

💡 主要观点

  1. 赋能残障人士贡献开源 消除键盘操作、色彩对比度及屏幕阅读器兼容性等障碍，对于赋能残障开发者参与开源，并提升通用技术的普及性至关重要。
  2. 提升免费开源辅助技术 (AT) 的可用性和采纳率 专有辅助技术价格通常较为昂贵。开源替代方案则能降低成本，促进社区支持，并提升屏幕阅读器等工具的可及性。
  3. 增强主流开源项目的无障碍性 鉴于开源的广泛应用，提升核心基础设施和库的无障碍特性，能对大量下游项目产生巨大的积极影响。这也有助于引领行业趋势，并提升开发者的无障碍意识。
  4. 提升 GitHub 平台的无障碍性 GitHub 将无障碍设计融入产品开发生命周期，积极解决无障碍问题，并致力于将无障碍设计前置，确保新功能默认具备无障碍特性 (即“无障碍左移”)。
  5. 建立跨技术生态系统以及与残障社群的合作关系 与开源项目办公室 (OSPOs)、其他组织合作，并直接邀请残障人士参与 (秉持“与残障人士共同进行无障碍设计，而非为他们设计”的原则)，对于推动更广泛的变革，确保倡议的包容性和有效性至关重要。
  6. 支持开源社区 与开源维护者积极互动，有助于他们构建多元和包容的社区，在社区文化中重视并整合无障碍实践。

💬 文章金句

  • 我们的目标是赋能残障人士参与开源贡献，提升开源辅助技术 (AT) 的可用性，并增强主流开源项目的无障碍性。
  • 当残障人士参与贡献时，我们更有可能创造出每个人都能使用的技术。
  • 在 GitHub 上，任何人都可以创建辅助技术，以改善残障人士的访问体验，没有任何财务或官僚障碍。
  • 投资于上游开源项目不仅能使下游应用具备无障碍特性，还能对下游项目产生指数级的积极影响。
  • 无障碍设计不应是“为”残障人士而做，而应是与他们“共同”完成。
