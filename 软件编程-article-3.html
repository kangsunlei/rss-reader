如何构建你自己的 Claude Code 技能

3/27/2026, 8:47:26 PM

📌 一句话摘要

一份关于构建“智能体技能”（Agent Skills）的综合指南——这是一种基于 Markdown 的标准化工作流指令，适用于 Claude Code 及其他 AI 编程助手，旨在自动化重复性的开发任务。

📝 详细摘要

本文介绍了“智能体技能”（Agent Skills）的概念，这是一种使用 Markdown 文件定义可重复开发工作流的跨平台标准。在 Claude Code、Cursor 和 GitHub Copilot 等工具的支持下，开发者可以将特定的流程（如编写提交信息或 PR 描述）编码到 `SKILL.md` 文件中。本教程提供了创建“commit-message-writer”技能的分步指南，并强调智能体是否加载某项技能完全取决于 YAML 中的描述字段。此外，文章还概述了编写指令的最佳实践，例如优先输出结果而非询问澄清，以及保持严格的输出格式。

💡 主要观点

  1. 智能体技能是标准化的 Markdown 文件，可在多个 AI 编程工具中自动化工作流。 通过使用通用的 SKILL.md 格式，开发者只需编写一次工作流，即可在 Claude Code、Cursor、GitHub Copilot 和 Gemini CLI 中保持一致地运行。
  2. YAML 前置元数据中的描述字段是触发技能的关键机制。 智能体仅根据描述来决定是否加载某项技能；因此，描述中必须包含特定的触发短语，并清晰定义技能的功能，以避免触发不足。
  3. 有效的技能指令应优先考虑立即生成结果，而非进行澄清。 为了最大化效率，技能应指示智能体做出合理的假设并优先生成输出，而不是向用户提问，从而减少交互阻力。
  4. 技能是指令文件，而非可执行插件。 它们没有自己的运行时，而是指示智能体使用其现有工具（如 git 或文件系统访问权限）来执行任务。

💬 文章金句

  • 技能是一个 Markdown 文件，当你需要时，它会自动加载到 Claude Code 的上下文中。你只需编写一次工作流，智能体每次都会遵循它。
  • 智能体完全根据描述字段来决定是否加载你的技能。
  • 先生成，后澄清。智能体应该立即产生输出，而不是提出澄清问题。
  • 智能体技能标准是为组合而设计的，而非用于单一的庞大指令。
