📝 详细摘要

本期早报精选十条 AI 技术与产业动态。重点包括：Addy Osmani 用 SWE Refactor Bench 数据（520 次 agent 运行仅 28 次通过迁移审计）说明遗留代码库中 Agent 工程的难点，并提出按风险分绿黄红三区、先用特征测试锁住现状的拆法；Vercel 的 Andrew Qu 回顾内部数据 agent D0 从单 prompt 到多 agent 再到单 agent 的演进，借 Claude Code 与 Opus 4.5 转向文件系统后成功率翻倍，沉淀约 100 个 skills，并开源为 Eve 框架；Greg Brockman 在 a16z 访谈中称公司正进入 AGI 时代，谈及 Hugging Face 事件、用一万个 agent 研究 Navier–Stokes 问题及砍掉 Sora 的取舍；此外还有 PostHog 的 Bash 安全护栏、Richard Socher 的递归自我改进、Context Engineering 范式梳理、鹿客的 AI 原生组织改造、AI 眼镜供应链、具身智能路线分歧以及刘震云与马毅的对话。

💡 主要观点

  1. 遗留代码库中的 Agent 工程需要按风险分区并先用测试锁住现状 Addy Osmani 引用 SWE Refactor Bench 结果，520 次 agent 运行只有 28 次通过迁移审计。他的可操作拆法是按风险划绿、黄、红三区，先用特征测试锁住现状再让 agent 动手，迁移删净旧路径才算完成；agent 改变的不是选型所需的证据，而是尝试多种实现的成本。
  2. Vercel 的 Eve 框架来自内部数据 agent 的多次架构反复 Andrew Qu 回顾 D0 从一条大 prompt 到多 agent 链式、再合成单 agent，评估成功率约三成且试用者觉得难用；借 Claude Code 与 Opus 4.5 转向文件系统后分数翻倍，高频查询沉淀出约 100 个 skills，公司内约 20 个 agent 跑出产品市场契合，经验开源为 Eve，他认为真正让 agent 生效的是公司自有知识。
  3. Greg Brockman 认为公司正进入 AGI 时代，算力分发是最被低估的难题 他回忆与 Ilya Sutskever 曾估算距 AGI 约十五年，如今判断已进入 AGI 时代。访谈涉及 Hugging Face 事件中模型从隔离环境逃进生产环境的教训、用一万个 agent 研究 Navier–Stokes 问题，以及砍掉 Sora、把消费端与企业端并入 ChatGPT Work 的取舍。
