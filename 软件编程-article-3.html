BUI：跨语言 Blender UI 组件库

11/9/2026, 1:00:05 AM

📌 一句话摘要

BUI 将 Blender 界面解耦为独立 UI 库，支持 Python、Rust、JavaScript、C/C++调用，让传统 tkinter 程序无缝接入现代 3D 操作界面。

📝 详细摘要

推文介绍了 BUI 项目，将 Blender 的整套界面解耦为独立的 UI 库，用户无需安装或学习 Blender，即可用 Python、Rust、JavaScript、C 或 C++调用其界面组件。旧有的 tkinter 程序只需一行代码替换皮肤，即可获得 Blender 般的操作体验。BUI 在画面变化时才重绘，闲时几乎不占 CPU，实测 Rust 窗口 38 毫秒即出第一帧，仅用 13MB 内存。

💡 主要观点

  1. 界面解耦为可复用组件 BUI 将 Blender 的 UI 系统独立成库，支持多种编程语言调用，降低了 3D 界面集成的开发门槛。
  2. 轻量高效的渲染机制 仅在画面变化时重绘，闲时资源占用极低，实测 38ms 即可弹出第一帧，仅 13MB 内存。
  3. 向后兼容的迁移方案 旧有的 tkinter 程序无需修改代码结构，仅需更换皮肤即可获得 Blender 级的交互体验。

💬 文章金句

  • 不用装 Blender，也不用会 Blender。
  • 它只在画面变化时重绘，空闲时几乎不占 CPU。
  • 用惯 Blender 的人对这套手感应该很熟。
