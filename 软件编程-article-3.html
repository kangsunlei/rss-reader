推荐 3 个刚开源 Star 在慢慢攀升的 GitHub 开源项目。

5/23/2026, 6:23:00 AM

📌 一句话摘要

本文推荐了三个近期热门的开源项目：具备记忆系统的桌面 AI 助手 OpenHuman、通过修改 Chromium 源码实现反检测的隐形浏览器 CloakBrowser、以及 Markdown 与 HTML 双向转换工具 huashu-md-html。

📝 详细摘要

文章精选并介绍了三个 GitHub 上正在快速获得 Star 的开源项目。第一个是 OpenHuman，一个桌面 AI Agent 助手，通过 Memory Tree 记忆系统连接 Gmail、Notion、GitHub 等 118+ 第三方服务，解决 AI 冷启动问题，并支持 Obsidian 兼容的记忆文件编辑。第二个是 CloakBrowser，一个通过直接修改 Chromium C++ 源码来伪装浏览器指纹的反检测工具，能有效绕过 reCAPTCHA v3、Cloudflare Turnstile 等检测，并内置人性化行为模拟。第三个是 huashu-md-html，一个基于 Claude Code Skill 的 Markdown/HTML 双向转换工具，支持多种文档格式转 Markdown，并提供 4 套出版级 HTML 主题，强调高质量的中文排版。

💡 主要观点

  1. OpenHuman 通过 Memory Tree 记忆系统解决 AI Agent 冷启动问题。 该工具能自动连接用户的 Gmail、Notion、GitHub 等 118+ 第三方服务，将数据标准化为 Markdown 片段并构建层级化摘要树，让 AI 在安装之初就了解用户，无需长时间手动配置。
  2. CloakBrowser 通过修改 Chromium 源码实现高隐蔽性反检测。 与传统的 JS 注入方案不同，该项目直接在 Chromium 的 C++ 源码层面打补丁，覆盖 Canvas、WebGL、Audio 等所有主流指纹点，编译成独立浏览器，能获得 reCAPTCHA v3 0.9 的高分，并内置贝塞尔曲线鼠标移动等人类行为模拟。
  3. huashu-md-html 提供高质量的 Markdown 与 HTML 双向转换流水线。 该工具以 Claude Code Skill 形式发布，支持 PDF、DOCX 等多种格式转 Markdown，并利用 Pandoc 和 4 套精心设计的主题渲染出出版级 HTML，同时强调反 AI slop 的审美和严格的中文排版规范。

💬 文章金句

  • 它的核心思路是在你安装的那一刻就开始认识你，而不是等你慢慢教。
  • 反检测系统看到的是一个真正的浏览器，因为它确实就是一个真正的浏览器。
  • 核心理念是 md 是源代码，html 是产物，两者之间来回切换不应该有成本。
  • 花叔还明确提了反 AI slop 的审美底线：不用紫渐变、不用赛博霓虹、不用深蓝底、不用 Comic Sans。
