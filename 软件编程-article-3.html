Cloudflare：所有客户均可使用全部清除方法

4/1/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 宣布所有客户（包括免费计划用户）均可使用所有缓存清除方法，并提高了企业客户的清除速率限制。

📝 详细摘要

Cloudflare 宣布将所有缓存清除方法（包括按 URL、主机名、标签和前缀清除以及清除所有内容）提供给所有客户，无论其计划类型如何。此前，除“按 URL 清除”和“清除所有内容”之外的方法仅供企业客户使用。Cloudflare 通过两年的工程努力，重建了清除通道，显著提高了吞吐量，同时保持了近乎即时的失效。Cloudflare 还显著提高了企业客户的默认清除速率限制，例如企业用户拥有 500 requests 的存储桶大小（Bucket size）和每秒请求补充速率（Request refill rate）。文章还讨论了如何使用这些新的清除方法，以及各种清除方法的适用场景。最后，文章还介绍了 Cloudflare 未来将继续优化清除平台，提高单文件清除的性能，并提高所有系统的清除吞吐量。

💡 主要观点

  1. Cloudflare 向所有客户开放所有清除方法 所有 Cloudflare 客户现在都可以使用按 URL、主机名、标签和前缀清除以及清除所有内容等清除方法。
  2. Cloudflare 提高了企业客户的清除速率限制 Cloudflare 显著提高了企业客户的默认清除速率限制，允许更高的清除吞吐量。
  3. Cloudflare 使用 CacheDB 减少了存储需求 通过使用 CacheDB，Cloudflare 减少了 10 倍的存储需求，从而增强了缓存保留率，提高了缓存命中率。
  4. Cloudflare 使用单机索引，通过将索引直接集成到缓存代理中来优化清除 Cloudflare 通过将单机索引直接集成到缓存代理中，最小化了网络复杂性，简化了可靠性，并提供了可预测的扩展。
