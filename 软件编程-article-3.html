Node.js — Node v22.16.0 (LTS 长期支持版本)

5/21/2025, 3:31:48 PM

📌 一句话摘要

Node.js v22.16.0 LTS 版本发布，带来了显著更新，包括实验性 API 的稳定化、ECMAScript 模块的增强以及多项模块改进。

📝 详细摘要

本文宣布发布 Node.js v22.16.0，一个长期支持版本（LTS）。它详细介绍了几个显著的变化以及此版本中包含的完整提交列表。主要亮点包括多个实验性 API 的稳定化（例如用于 ECMAScript 模块的 `import.meta` 属性），对 ECMAScript 模块的重大增强，例如支持顶层 WebAssembly 而无需显式的包类型，以及新增功能，例如 `sqlite` 模块中的 `StatementSync.prototype.columns()`，对配置文件 (`node.config.json`) 的支持，以及 `util` (`types.isFloat16Array()`) 和 `worker` (`worker.getHeapStatistics()`) 中的新方法。该版本还包含许多缺陷修复、性能改进（例如，在 `assert`、`util`、`fs` 中）、依赖项更新（V8、zstd、zlib、simdutf、icu）以及文档更正/添加。此版本为使用 LTS 版本的 Node.js 开发人员提供了稳定性更新和关键新功能。

💡 主要观点

  1. 多个实验性 API 已稳定化。 将实验性 API 转移到稳定状态意味着可靠性提高，并为在生产应用程序中更广泛地采用做好准备，从而为开发人员使用这些功能提供更大的信心。
  2. ECMAScript 模块的支持得到增强，包括 `import.meta` 属性的稳定化和顶层 Wasm 支持。 这些更改巩固了 Node.js 对现代 JavaScript 模块的支持，简化了使用 `import.meta` 的开发人员的工作流程，并实现了更直接的 WebAssembly 模块集成。
  3. 添加了新的实用程序和模块功能。 诸如 `util.types.isFloat16Array()` 和 `worker.getHeapStatistics()` 之类的添加为开发人员提供了 Node.js 环境中更精细的控制和诊断功能。
