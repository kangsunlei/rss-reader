Vercel Sandbox 现已支持自动持久化（Beta 版） - Vercel

3/26/2026, 10:32:02 PM

📌 一句话摘要

Vercel 为 Vercel Sandbox 推出了自动文件系统持久化功能（Beta 版），允许沙盒在停止时保存状态，并在恢复时自动还原，无需手动快照。

📝 详细摘要

Vercel 宣布 Vercel Sandbox 自动持久化功能进入 Beta 测试阶段。该功能实现了存储与计算的分离，使沙盒能够在会话结束时自动对文件系统状态进行快照，并在新会话开始时进行恢复。开发者现在可以使用更新后的 Beta 版 SDK 和 CLI 更轻松地管理长期运行的持久化沙盒。主要改进包括透明的会话管理（SDK 会自动重启已停止的沙盒）、动态扩展 vCPU 等资源的能力，以及用于列出、搜索和删除沙盒的增强型生命周期管理命令。

💡 主要观点

  1. 自动文件系统状态持久化 沙盒现在可以在停止时自动对状态进行快照，并在恢复时进行还原，无需手动快照，从而实现持久化的工作流。
  2. 存储与计算分离 通过分离这些层，Vercel 允许文件系统在计算会话不活跃时保持持久化，值得注意的是，在这些非活跃期间，存储是不收费的。
  3. 透明的会话管理 如果对已停止的沙盒运行命令，Beta 版 SDK 会自动创建一个新会话，使开发者在活跃和非活跃状态之间的转换变得无缝。
  4. 增强的生命周期和资源管理 新的 SDK 和 CLI 方法允许扩展 vCPU、检查会话历史记录以及搜索已命名的沙盒，而无需重新创建环境。

💬 文章金句

  • Vercel Sandbox 现在可以在停止时自动保存文件系统状态，并在恢复时进行还原。
  • 自动持久化引入了将存储与计算分离的编排机制，减少了对手动快照的需求。
  • 这种状态存储是不收费的，因此您只需在环境处于活跃状态时付费。
  • 如果沙盒已停止而您运行了命令，SDK 将透明地创建一个新会话，因此您无需检查状态或手动重启。
