Vercel Sandbox 正式发布：面向 AI 智能体的安全计算 API

1/31/2026, 2:24:56 AM

📌 一句话摘要

Vercel Sandbox 现已正式发布，为 AI 智能体执行代码提供经过实战检验的 API 和安全计算环境。

📝 详细摘要

Vercel CEO Guillermo Rauch 宣布 Vercel Sandbox 正式进入全面上市（GA）阶段。它被设计为一个安全的计算环境，让 AI 智能体能够通过简单的 API 拥有“一台电脑”。此次发布包含开源 SDK、CLI 支持以及快照功能（支持克隆、分叉与恢复）。该产品基于 Vercel 十年来在基础设施领域的经验构建，能够处理调度、区域容灾切换和零停机升级等复杂任务，目前已在 Blackbox AI 和 v0 等平台投入生产使用。
