Magpie: AI 编程 Agent 接口的本地中转工具

10/1/2026, 12:00:12 AM

📌 一句话摘要

介绍 Magpie——一个运行在本机的开源中转服务，通过统一 API 格式让 Claude Code、Codex 等不同 Agent 工具共享模型列表与登录凭据。

📝 详细摘要

针对 Claude Code 与 Codex 等 AI 编程工具接口格式不兼容的问题，介绍开源工具 Magpie。该工具在本机运行轻量中转服务，将 OpenAI 与 Anthropic 两种接口格式互相翻译，使多个 Agent 可统一指向同一份模型列表并切换。支持 macOS、Linux、Windows 三端，应用体积不到 15 MB，且能共享已登录的订阅凭据，避免重复配置 API Key。
