被下载超 87 万次，又一个神级 Skill 开源！

📌 一句话摘要

介绍一个名为 grill-me 的开源 Skill，通过提问式对齐需求来避免 AI 编程时的盲目猜测，提升开发效果。

📝 详细摘要

文章介绍了由 TypeScript 领域大神 Matt Pocock 开发的开源 Skill —— grill-me，该 Skill 已有超过 87 万次下载，隶属于拥有 22 万+ Star 的 skills 仓库。grill-me 的核心理念是在用户给出模糊需求时，不直接生成代码，而是像面试官一样通过一系列选择题式的提问，帮助用户逐步澄清目标用户、技术方案、平台覆盖、功能列表等关键决策点，只有在达成共识后才会编写代码。文章通过作者亲手为 DeepSeek Harness 制作跨平台客户端的实例，展示了 grill-me 的使用流程：安装后在对话框中输入 /grill-me，工具会先自行查询已有事实，再逐步提问，最终输出一份设计共识。文章进一步指出，grill-me 与另一款流行的 Agent 工具 Superpowers 形成互补：前者负责「想清楚」（需求对齐），后者负责「做到位」（将共识转化为计划文档并分步执行），二者配合可显著提升需求落地的质量和开发效率。最后文章指出，尽管 AI 能力在提升，但只有在需求被说清楚时才能发挥作用， grill-me 正是解决这一痛点的简单有效方案。

💡 主要观点

  1. grill-me 通过提问式对话帮助用户在编码前澄清需求。 它不会立即生成代码，而是像面试官一样逐步提问，确保每个关键决策点都得到明确答案，从而减少因需求模糊导致的返工。
  2. 该 Skill 能自行查询代码库获取事实，减少对用户的猜测。 grill-me 会先自行检索已有信息，只有在真正需要用户确认时才提出问题，避免无效的重复询问。
  3. 与 Superpowers 配合使用可实现需求对齐与计划执行的闭环。 先用 grill-me 达成需求共识，再让 Superpowers 的 writing-plans 生成计划文档，executing-plans 分步实施，提升开发效率。
  4. 使用简单，仅需一条 npx 命令即可安装并立即在对话框中调用。 安装命令为 `npx skills add https://github.com/mattpocock/skills --skill grill-me`，装完后直接在 AI 对话中输入 `/grill-me` 启动提问流程。

💬 文章金句

  • 更关键的一条，是在双方未确认达成共识之前，在没搞清楚需求前，不会写任何代码。
  • 当输入/grill-me 之后，AI 不会马上动手写代码，而是充当面试官开始盘问我们。
  • 它自己会去查、去翻代码库落实情况，并不是一股脑来询问我们。
  • 一个管「想清楚」，一个管「做到位」，在介入时机一前一后，正好接得上。
  • grill 这个词在英文口语里是「拷问」的意思，连着 grill me，那就是「拷问我」。
