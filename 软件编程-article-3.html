GitHub 移动端新增对 AI Agent 的多模型支持

2/26/2026, 6:03:58 PM

📌 一句话摘要

GitHub 移动端现已支持用户在开启 AI Agent 会话时，在 Claude、Codex 和 Auto 模型之间进行自主选择。

📝 详细摘要

GitHub 宣布其移动应用迎来重大更新，允许用户在启动新的 Agent 会话时选择首选的 LLM。可选模型包括 Anthropic 的 Claude、OpenAI 的 Codex 以及“Auto”模式。此次更新让开发者能够在移动办公时针对响应速度进行优化，或在深度工作时追求更强大的性能，为移动端 AI 辅助开发带来了更高的灵活性。
