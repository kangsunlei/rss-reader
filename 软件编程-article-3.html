📌 一句话摘要

本期 JavaScript 中文周刊报道 Rust 持续替换 JS 工具链、TypeScript v7 用 Go 重写提速十倍、Octane 提供编译时响应式框架及多项工具与标准更新。

📝 详细摘要

本期内容围绕 JavaScript 生态的最新动态展开。首先指出 Rust 继续替换传统 JS 工具链，Rspack、Biome、Turbopack 及 Bun 的重写验证了 Lee Robinson 早期的预测。其次，TypeScript 之父 Anders Hejlsberg 演示了基于 Go 重写的 TypeScript v7 编译器，在 VS Code 代码库上实现约十倍提速，并介绍了新的 LSP 与 API 迁移注意事项。接着介绍了 Octane 框架，它提供类 React 的编程模型但采用编译时响应式，无需虚拟 DOM，支持 TSX/JSX/TSRX 并可与 TanStack Query、Router 等常用库集成。此外，还报道了多项标准与 API 进展：Container Timing API 进入 Chrome 源试用、import defer 提案处于 TC39 Stage 3、Await Dictionary（Promise.allKeyed）进入 Stage 3、Deno 计划使用 QuickJS 替代 V8 生成更小体积二进制、Node.js 新增可搜索的 API 文档预览站点、Oxlint 的类型感知 lint 达到稳定阶段等。文章还包含多篇深度阅读与工具推荐，如 Domenic 的 agent 编程环境、Medium 新目录功能实现、MapLibre GL JS v6.0、Bruno v4 HTTP 客户端、tslog v5 日志库、eslint-package-json 插件、Shadscan UI 审计工具等，以及社区活动如 js1024 高尔夫赛、OpenJS Foundation 贡献者榜单、LLM 相关的 token 使用技巧和 slopsquatting 风险。整体内容信息密度高、结构清晰，适合前端开发者快速捕捉一周的技术趋势与工具更新。

💡 主要观点

  1. Rust 持续替换 JavaScript 工具链，Rspack、Biome、Turbopack、Bun 等项目验证了这一趋势。 Lee Robinson 早期预测的「越来越多 JS 生态工具会使用 Rust 重写」得到持续验证，表明底层工具链向系统语言迁移的趋势明显。
  2. TypeScript v7 采用 Go 重写编译器，在 VS Code 代码库上实现约十倍提速，并介绍了新 LSP 与 API 迁移注意点。 Anders Hejlsberg 的演示展示了语言工具链通过换底层语言实现显著性能提升，同时提醒依赖旧版 API 的库需暂时滞后升级。
  3. Octane 框架提供类 React 的编程模型但采用编译时响应式，无需虚拟 DOM，支持 TSX/JSX/TSRX 并可与常用库集成。 通过在构建阶段生成响应式代码，Octane 兼顾开发体验与运行性能，为现有 React 生态提供了一条替代路径。
  4. 新增标准与 API 如 Container Timing API、import defer 提案、Await Dictionary 进入 Stage 3 等，为性能测量和模块加载提供新手段。 这些标准的进展为开发者提供了更精细的性能测量手段和更灵活的模块加载策略，有助于提升应用加载和运行时效率。
