紧急修补——React 服务器组件关键漏洞 CVE-2025-55182 正在被积极利用

12/10/2025, 12:49:00 AM

📌 一句话摘要

React 服务器组件 (RSC) 和 Next.js 中存在一个严重的远程代码执行 (RCE) 漏洞 (CVE-2025-55182)，正被国家支持的组织积极利用，鉴于其最高严重性，急需立即修补。

📝 详细摘要

本文报道了 React 服务器组件 (RSC) 中一个未经身份验证的严重远程代码执行 (RCE) 漏洞 (CVE-2025-55182)，该漏洞影响使用 App Router 的 React 19.0.0-19.2.0 版本和 Next.js 15.x-16.x 版本。该漏洞于 12 月 3 日披露，严重性等级为 10.0。亚马逊威胁情报团队观察到，该漏洞正被多个中国国家支持的威胁组织积极利用。该漏洞源于 Flight 协议有效载荷在反序列化过程中的服务器端 JavaScript 原型链污染问题，允许攻击者注入并执行任意代码，包括系统命令。尽管修复方案涉及添加 `hasOwnProperty` 检查，但已检测到使用武器化有效载荷的积极利用尝试，这凸显了立即对受影响的软件包及其依赖项进行修补的紧迫性，以减轻严重的安全风险。

💡 主要观点

  1. React 服务器组件和 Next.js 中存在一个关键的远程代码执行 (RCE) 漏洞 (CVE-2025-55182)，且正被积极利用。 此未经身份验证的 RCE，严重性等级为 10.0，允许任意代码执行，并正被国家支持的威胁组织积极利用，构成即时且严重的安全风险。
  2. 该漏洞是由 Flight 协议的有效载荷在反序列化过程中的服务器端 JavaScript 原型链污染引起的。 攻击者精心制作有效载荷，当未经修补的 React 版本对其进行反序列化时，会破坏 JavaScript 对象，从而允许执行注入的 `then` 代码作为任意命令。
  3. 强烈建议所有受影响的 React 和 Next.js 版本及其依赖项立即修补。 鉴于漏洞利用的普遍性和直接性，以及正在进行的攻击，急需进行更新以防止服务器端环境遭到入侵。

💬 文章金句
