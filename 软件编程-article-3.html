Cloudflare 紧急防护 SharePoint 关键漏洞 CVE-2025-53770

7/22/2025, 5:30:01 PM

📌 一句话摘要

Cloudflare 详解 SharePoint RCE 关键漏洞 CVE-2025-53770 及其 ToolShell 攻击链，并介绍 WAF 托管规则的防护方案。

📝 详细摘要

CVE-2025-53770 是 SharePoint Server 中的一个关键零日 RCE 漏洞（CVSS 评分 9.8），其根源在于不当的反序列化操作。文章重点介绍了 ToolShell 攻击链，该攻击链通过身份验证绕过 (CVE-2025-53771)、RCE 最终窃取加密机器密钥（ValidationKey、DecryptionKey），实现持久和独立的访问。这种持久性使得该漏洞具有独特的危险性，因为它绕过了诸如重启之类的标准缓解措施。CISA 已将其添加到其 KEV 目录中，原因是该漏洞正在被积极利用。Cloudflare 通过在 2025 年 7 月 21 日部署紧急 WAF 托管规则做出了响应，为其客户提供了针对初始 RCE 和持久性机制的即时保护。

💡 主要观点

  1. CVE-2025-53770 是一个关键的 SharePoint RCE 漏洞，具有独特的持久性机制。 'ToolShell' 攻击不仅能获取临时访问权限，还会窃取加密密钥，使攻击者能够持久且独立地访问系统，即使在服务器重启等标准缓解措施后仍然有效。
  2. 'ToolShell' 攻击链涉及一个复杂的三阶段攻击。 ToolShell 攻击链包含身份验证绕过 (CVE-2025-53771)、反序列化 RCE (CVE-2025-53770) 以及加密密钥盗窃三个阶段，旨在长期控制被入侵的 SharePoint 服务器。
  3. Cloudflare 的 WAF 托管规则提供即时和全面的保护。 Cloudflare 迅速部署了紧急 WAF 规则，以缓解初始 RCE 漏洞和随后的持久性机制，从而自动保护其客户免受这种关键威胁。

💬 文章金句

  • 拥有这些密钥使威胁行为者能够独立伪造身份验证令牌和 __VIEWSTATE 有效负载，从而使他们能够持续访问，这种访问可以在服务器重启或删除 Web Shell 等标准缓解策略后仍然有效。
  • 安全社区的共识很明确：任何在 Internet 上拥有本地 SharePoint 服务器的组织都应假定其已被入侵，并立即采取行动以完全解决此漏洞。
  • 这种漏洞利用 -> 补丁 -> 绕过的快速循环表明，攻击者不仅在寻找漏洞，还在系统地对补丁进行逆向工程，将绕过手段转化为攻击武器。
  • 这种永久后门使这种攻击方法具有独特的危险性。
