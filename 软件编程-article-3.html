📌 一句话摘要

Google 开源了 design.md，一个让 AI Agent 遵循统一设计系统规范的 Markdown 文件标准，解决 AI 生成 UI 同质化问题。

📝 详细摘要

文章介绍了 Google 开源的 design.md 项目，它是一份写给 AI Agent 看的设计系统规范文件，通过 YAML front matter 放置机器可读的设计 token（颜色、字号、间距等精确值），Markdown 正文解释设计理念。作者指出当前 AI 生成 UI 常出现同质化的「模板味」，而 DESIGN.md 让 AI 既能精确执行数值又能理解设计意图。文章还介绍了配套 CLI 工具（lint、diff、export、spec）、生态项目 Awesome Design.md（70+ 真实品牌样本）以及与 Stitch 工具的集成。最后给出了简单的三步上手方法，强调当 AI 写代码成为常态时，如何定义「好设计」将变成新硬技能。

💡 主要观点

  1. DESIGN.md 通过 YAML + Markdown 双层结构解决 AI 输出 UI 同质化问题。 YAML front matter 存放机器可读的设计 token（颜色、字号、间距等），Markdown 正文存放人可读的设计意图，让 AI 既能精确执行又能理解上下文，从而输出风格一致的 UI。
  2. 配套 CLI 工具实现校验、对比、导出与规范输出。 @google/design.md 提供 lint（校验 8 条规则）、diff（检测 token 回归）、export（导出 Tailwind/W3C DTCG 格式）、spec（生成文档）四条命令，零配置可集成到 AI 工作流。
  3. 生态已开始成形：范例库与第三方聚合站降低了使用门槛。 VoltAgent 的 Awesome Design.md 提供了 70+ 真实品牌的设计规范样本，designkit.sh 等站可浏览和收集 DESIGN.md 文件，方便直接复用。

💬 文章金句

  • 每个值都有出处，每段意图都有解释。
