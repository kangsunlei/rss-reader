Pake 发布“放肆的 Cheeky 🦩”大版本更新，功能全面增强

8/23/2025, 11:32:19 AM

📌 一句话摘要

Pake，一个用 Rust 将网页构建成轻量级多端桌面应用的工具，发布了名为“放肆的 Cheeky 🦩”的大版本更新，带来了智能图标获取、CLI 增强、多端功能优化及构建系统改进等。

📝 详细摘要

这条推文宣布了开源项目 Pake 的重大更新，该项目旨在利用 Rust 轻松将网页打包成轻量级多端桌面应用。此次更新命名为“放肆的 Cheeky 🦩”，带来了多项关键改进：包括智能图标自动获取，大幅增强的命令行接口 (CLI) 功能（如代理设置、无痕模式、自定义标题、系统托盘隐藏和多文件注入等）。此外，更新修复了 Linux 和 Windows 下的图标显示问题，并增强了桌面应用功能，如窗口位置记忆、外部链接跳转修复、Windows 系统主题自动适配及单实例模式。项目还优化了开发流程，引入了全新的 GitHub Actions 工作流系统和构建系统优化（如 Docker 基础镜像升级）。推文末尾提及作者已向 GitHub 官方举报了盗版项目 Pake-plus 并得到处理答复，体现了对开源社区版权的维护。
