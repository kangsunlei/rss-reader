更安全的远程桌面协议 (RDP)：Cloudflare 基于浏览器的安全外部访问解决方案

3/21/2025, 1:00:00 PM

📌 一句话摘要

Cloudflare 推出基于浏览器的远程桌面协议 (RDP) 解决方案，利用零信任实现安全便捷的远程 Windows 服务器访问。

📝 详细摘要

Cloudflare 发布了基于浏览器的远程桌面协议 (RDP) 解决方案，旨在解决传统 RDP 的安全挑战和操作复杂性。该方案构建于 Cloudflare 的零信任网络访问 (ZTNA) 服务之上，利用 IronRDP 客户端在浏览器中提供高性能 RDP 连接，并采用 Cloudflare Workers 构建 WebSocket 代理服务，实现了无需客户端即可通过浏览器安全访问 Windows 服务器。通过集成单点登录 (SSO)、多因素认证 (MFA) 和设备状态验证等零信任安全策略，Cloudflare RDP 解决方案增强了身份验证、授权和审计能力，同时优化了性能。未来，Cloudflare 计划增加会话监控、数据丢失防护 (DLP) 支持和无密码身份验证等功能，并寻求 FedRAMP High 认证，以满足企业和政府组织的需求。

💡 主要观点

  1. Cloudflare 的 RDP 解决方案无需客户端，降低了复杂性 用户可以通过浏览器直接访问 Windows 服务器，无需安装额外的 RDP 客户端软件，简化了部署和维护工作。
  2. Cloudflare Access 集成的 SSO、MFA 等策略增强了 RDP 访问的安全性 通过 Cloudflare Access，RDP 访问受到单点登录 (SSO)、多因素认证 (MFA) 和设备状态验证等策略的保护，减少了潜在的安全风险。
  3. Cloudflare 的全球网络优化了 RDP 的性能 利用 Cloudflare 的全球网络基础设施，RDP 会话的延迟被最小化，提供了更流畅的用户体验。

💬 文章金句

  • Cloudflare 基于浏览器的 RDP 解决方案是 Cloudflare Access 的最新成员，与现有的无客户端 SSH 和 VNC 产品一起，无需 VPN 或 RDP 客户端即可实现安全的远程 Windows 服务器访问。
  • 我们认为，业界普遍吹捧的“安全/性能权衡”是一种过时的思维模式。 凭借正确的底层网络架构，我们可以帮助缓解 RDP 最臭名昭著的挑战。
  • 通过 Cloudflare 网络的每个 RDP 会话都经过加密和身份验证。
