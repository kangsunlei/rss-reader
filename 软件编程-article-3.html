Dev Proxy v1.3.0：HAR 文件生成、LLM 使用跟踪、增强的 API 测试功能

11/17/2025, 4:57:00 AM

📌 一句话摘要

Dev Proxy v1.3.0 引入 HAR 文件生成、OpenAI 使用跟踪和增强的 API 测试功能，全面提升开发者调试与监控效率。

📝 详细摘要

Microsoft 365 开发团队发布了 Dev Proxy v1.3.0，旨在通过解决开发者在调试、测试和 API 监控中面临的痛点来提升效率。新版本引入 HarGeneratorPlugin 插件，通过自动创建 HAR 文件，解决了跨平台网络活动跟踪不统一、协作困难的问题，简化了故障排除和性能分析。针对 AI 应用开发者，OpenAIUsageDebuggingPlugin 插件详细记录 LLM 的令牌消耗和模型调用，帮助开发者在开发早期识别低效使用模式，有效管理和控制日益增长的 AI 相关成本。此外，为应对复杂的多服务集成测试场景，OpenAPI 规范生成功能得到增强，通过文件名中包含端口信息并智能聚合服务调用，解决了早期版本中规范文件可能相互覆盖导致数据丢失的问题。同时，最小权限插件扩展了对多种认证方案的支持，提供了更精细的权限评估控制。这些更新与 Visual Studio Code 工具包的同步升级，共同为开发者提供了更强大、更高效的开发辅助能力。

💡 主要观点

  1. 新增 HAR 文件生成插件，实现网络活动标准化捕获与共享 HarGeneratorPlugin 能自动创建 HAR 文件，作为行业标准格式，便于在多种工具中分析网络跟踪，大幅简化开发、QA 和支持团队的协作与故障排除。
  2. 引入 OpenAI 使用跟踪插件，优化 AI 应用成本管理与效率 OpenAIUsageDebuggingPlugin 详细记录 LLM 的令牌消耗和模型调用，帮助开发者在早期阶段识别低效使用模式，有效管理和控制 AI 相关的开发与测试成本。
  3. 增强 OpenAPI 规范生成与权限分析，提升复杂场景测试能力 OpenApiSpecGeneratorPlugin 现在支持多端口聚合，避免规范文件覆盖，确保复杂微服务集成的测试数据完整性，并为最小权限插件增加了认证方案支持，实现更精准的权限评估。

💬 文章金句

  • 新增的 HarGeneratorPlugin 插件能够基于拦截的 API 请求和响应自动创建 HTTP 存档（HAR）文件。
  • 该插件允许开发者监控和分析他们的应用程序如何使用大型语言模型，帮助他们在开发和测试期间检测低效的使用模式并管理成本。
  • 更新后的 OpenApiSpecGeneratorPlugin 插件在文件名中包含了端口信息，并且可以智能聚合服务调用，确保在复杂的集成测试中也不会丢失数据。
  • 本次更新还扩展了多个插件，包括 MinimalPermissionsPlugin、ApiCenterMinimalPermissionsPlugin 和 MinimalPermissionsGuidancePlugin，增加了新的配置选项，允许开发者定义正在使用的认证方案。
