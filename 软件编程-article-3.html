Crossplane 通过 CNCF 毕业，达到生产成熟度

11/13/2025, 7:00:00 AM

📌 一句话摘要

Crossplane 通过 CNCF 毕业，标志着其作为开源项目的生产成熟度，并使 Kubernetes 能够成为云基础设施的通用控制平面，赋能内部开发者平台。

📝 详细摘要

本文宣布 Crossplane 从云原生计算基金会 (CNCF) 毕业，标志其在运营成熟度、广泛采用和强大治理模型上取得重要进展。Crossplane 最初由 Upbound 创建，并扩展了 Kubernetes，使其能够作为管理各种云基础设施的通用控制平面。这允许从业者使用 Kubernetes 原生 API 来配置和管理 VPC、数据库和 Kubernetes 集群等资源。这种能力使组织能够构建内部开发者平台，为开发者提供自助服务基础设施 API。同时，平台团队可以通过组合管理底层配置、安全性和网络。包括 Nike 和 NASA Science Cloud 在内的知名用户使用 Crossplane 来标准化配置、执行策略，并从单个 Kubernetes 集群管理多云环境。虽然经常与 Terraform 和 Pulumi 等基础设施即代码工具进行比较，但 Crossplane 的独特之处在于它将基础设施视为 Kubernetes 资源，持续协调期望状态并与 GitOps 工作流程无缝集成。尽管有其优势，但早期的采用者报告了陡峭的学习曲线和调试复杂性。随着它的毕业，Crossplane 维护者现在优先考虑改进可观察性、更快的协调和扩展的生态系统。

💡 主要观点

  1. Crossplane 的 CNCF 毕业证实了其生产就绪性以及适用于企业级基础设施管理。 毕业标志着运营成熟度、广泛采用和强大的治理，使 Crossplane 成为构建内部平台和可靠地管理多云环境的可靠基础。
  2. Crossplane 将 Kubernetes 转换为用于基础设施的通用控制平面，从而实现 Kubernetes 原生资源配置方法。 通过使用自定义资源扩展 Kubernetes API，Crossplane 允许使用熟悉的 Kubernetes 清单和 GitOps 工作流程来定义和管理基础设施（例如，数据库、VPC），从而简化开发者体验。
  3. Crossplane 促进了内部开发者平台的创建，提供自助服务基础设施 API 和标准化配置。 平台团队可以定义更高级别的抽象并嵌入策略，从而为开发者提供对基础设施的自助服务访问，同时确保组织标准和策略执行。

💬 文章金句

  • 毕业是为已达到运营成熟度、广泛采用和强大治理模型的项目保留的。
  • 对于从业者来说，这表明 Crossplane 已经不是一个实验性的项目，而是经过生产环境验证的可靠基础，可以用于构建内部平台，提供自助服务 API，并以 Kubernetes 原生方法管理多云环境。
  • 主要的模式是将 Crossplane 用作内部开发者平台的支柱。
  • 从开发者的角度来看，请求数据库变得像应用 Kubernetes 清单一样简单。
  • Crossplane 将基础设施视为由 Operator 和策略控制的 Kubernetes 资源。
