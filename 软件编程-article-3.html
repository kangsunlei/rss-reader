Archify：基于 Agent 的交互式架构图解生成技能

10/12/2026, 1:03:00 AM

📌 一句话摘要

开源技能 Archify 允许 AI Agent 编写类型化 JSON，并自动校验渲染出支持多种视图与主题的独立交互式 HTML/SVG 图解。

📝 详细摘要

作者分享了开源图解生成技能 Archify。该工具让 AI Agent 负责编写类型化 JSON 数据，由 Archify 负责校验并渲染为独立的交互式 HTML 产物。它支持架构、工作流、时序等 5 种图型与 4 种视觉预设，产物支持深浅色主题切换及多种图片格式导出。

💡 主要观点

  1. 基于类型化 JSON 的规范化图解渲染 让 Agent 只需生成规范的 JSON 数据，渲染引擎完成结构校验和多视图呈现，降低可视化图表生成门槛。
  2. 独立产物与多格式导出能力 输出包含内联 SVG 的独立 HTML 文件，内置深浅色主题，支持导出 PNG、JPEG、WebP 与 SVG。

💬 文章金句
