为什么 AI 需要 GPU 和 TPU：LLM 背后的硬件

1/19/2026, 4:30:29 PM

📌 一句话摘要

本文解释了为什么 AI 工作负载需要 GPU 和 TPU 等专用硬件，重点介绍了它们在处理大规模并行矩阵乘法和内存带宽瓶颈方面相对于 CPU 的架构优势。

📝 详细摘要

本文深入探讨了驱动大语言模型（LLM）的硬件架构。文章认为 AI 本质上是一个涉及电子运动和数据传输的“物理问题”。虽然 CPU 是为复杂逻辑和串行执行设计的，但它们在处理 AI 任务时面临“存储墙”和晶体管分配效率低下的问题。相比之下，GPU 利用 SIMT 架构、数千个简单核心以及专门的 Tensor Core 来并行执行矩阵运算。此外，高带宽内存（HBM）使 GPU 能够克服冯·诺依曼瓶颈。文章还探讨了 Google 的 TPU，它利用脉动阵列设计来最小化内存访问并最大化线性代数的能效，展示了行业从通用逻辑向专用并行算术的转变。

💡 主要观点

  1. AI 是一个由并行矩阵乘法主导的“数学工厂”。 神经网络执行数以十亿计的独立乘加运算。与逻辑分支不同，这些运算可以在数千个处理器上同时执行，且无需通信开销。
  2. CPU 在架构上与深度学习工作负载不匹配。 CPU 将大量的硅片面积用于分支预测和乱序执行，而这些功能在 AI 任务中处于闲置状态。它们还面临“存储墙”问题，即缓慢的数据传输限制了计算性能。
  3. GPU 利用 SIMT 和 Tensor Core 实现海量吞吐量。 通过使用单指令多线程（SIMT）和专门的硬件单元（在一个周期内执行 4x4 矩阵乘法），GPU 相比标准核心实现了 64 倍的性能提升。
  4. 高带宽内存（HBM）对 LLM 性能至关重要。 LLM 每生成一个 Token 都需要读取数十亿个参数。HBM 通过垂直堆叠和硅中介层技术，实现了比传统 CPU 内存总线快 20 倍的带宽。
  5. TPU 使用脉动阵列消除内存访问开销。 通过让数据在网格中的算术单元之间直接流动，TPU 将中间值保留在 DRAM 之外，从而降低了能耗并提高了矩阵运算的每瓦性能。

💬 文章金句

  • 人工智能不仅仅是一个软件问题。它是一个涉及电子在硅片中运动的物理问题。
  • 在运行 LLM 时，CPU 中这数十亿个晶体管处于闲置状态，消耗着电力并占据着本可以用于算术单元的空间。
  • 瓶颈不在于算术运算，而在于数据传输到处理器的速率。
  • Tensor Core 是一种专门的硬件单元，可以在单个时钟周期内完成整个矩阵乘累加运算。
  • 从 CPU 到 GPU 和 TPU 的转变代表了计算哲学的根本转变……从逻辑处理转向通过概率运算进行的数据转换。
