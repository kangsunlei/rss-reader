📝 详细摘要

本文汇总了美团技术团队在 EMNLP 2026 大会上接受的 12 篇长论文，代表了团队在自然语言处理与计算语言学领域的前沿研究成果。文章围绕六大技术方向展开：首先，LTS-Agent 提出了“听-想-说”框架，解决实时语音智能体在推理深度与响应延迟之间的矛盾；其次，Latent-GRPO 利用潜空间几何特性构建连续奖励信号，显著降低训练成本；第三，FlexBench/FlexEval 实现了指令条件化的动态评估框架，填补了固定基准的空白；第四，SIRI 通过三阶段强化学习实现了技能的自主发现与内化，提升了智能体在 ALFWorld 与 WebShop 上的任务成功率；第五，SCOPE 引入信号质量感知的自适应蒸馏机制，在 OPD 框架中取得显著性能提升；第六，TRUST-SQL、UniMem、TagPR、ToolForge、RACE、F/S-RM、FG²-GDN 等论文分别解决了未知结构 SQL 生成、长期记忆管理、个性化推理、工具数据合成、神经元一致性、混合判断与长上下文记忆等关键挑战。整体来看，这些论文展示了美团在 LLM 推理、强化学习、评估方法、记忆系统、数据构建等方向的系统性创新。

💡 主要观点

  1. LTS-Agent 提出‘听-想-说’框架，实现实时语音智能体的准确率-延迟-效率三重优化 通过动态语义触发器和双角色流式编排器，系统实现‘边说边想’，在 VERA、Spoken-MQA、BigBenchAudio 等基准上显著优于串行级联基线。
  2. Latent-GRPO 利用潜空间几何特性构建连续奖励信号，消除对外部验证器的依赖 基于正确轨迹在潜空间的高类内相似度聚类特性，引入迭代鲁棒质心估计算法，显著降低训练延迟和内存开销。
  3. FlexBench/FlexEval 实现指令条件化的动态评估框架，填补固定综合基准的空白 根据目标指令动态生成测试套件，输出 COVERAGE 与 ACHIEVEMENT 两个互补指标，对九个当代 LLM 进行 3，888 段对话的评估，发现模型排名随指令差异显著。
  4. SIRI 通过三阶段强化学习实现技能的自主发现与内化，提升智能体任务成功率 模型从自身成功轨迹中提炼技能，验证后蒸馏至无技能策略，Qwen2.5-7B 在 ALFWorld 提升 2.2%，在 WebShop 提升 8.5%。
  5. SCOPE 引入信号质量感知的自适应蒸馏机制，在 OPD 框架中提升推理性能 对错误轨迹采用教师困惑度加权 KL 蒸馏，对正确轨迹采用学生困惑度加权 MLE，六个推理基准上平均相对提升 11.42%。
  6. TRUST-SQL 通过四阶段协议实现面向未知结构的 SQL 生成，无需预载数据库结构 设计‘探索-提议-生成-确认’协议，结合 Phase-Aware GRPO 计算优势，4B/8B 模型平均准确率提升 30.6/16.6 个百分点。
  7. UniMem 提出统一记忆框架，通过可学习路由 Token 协调情景记忆与参数化记忆 实现从短期情景记忆到长期参数记忆的自动内化，无需任务标签即可发现潜在任务结构，优于外部记忆和参数高效微调基线。
  8. TagPR 引入语义标签拆解个性化推理链，提升个性化任务的解释性与迁移能力 通过带标签推理数据监督微调，再结合用户嵌入的个性化奖励模型优化，LaMP 系列任务平均提升 32.65%。
  9. ToolForge 提出无需大规模在线调用的工具使用数据合成框架，支持复杂场景生成 构建 19 类虚拟工具及其变体，模拟正确检索、误选、参数误选等场景，仅用 4，250 条数据微调 Qwen3-8B 即可显著提升性能。
  10. F/S-RM 受双加工理论启发，实现快慢思考混合判断，提升效率与准确率 单模型统一‘快思考’与‘慢思考’模式，面对简单样本直接快速判断，复杂样本自动激活 CoT 推理，平均得分 84.3，token 消耗降低 22.5%。

💬 文章金句

  • 我们希望这套评测体系做到三件事：可测、可信、可优化。
  • 只有当指标与 Trace 结论冲突、局部证据不足、同一问题随机出现，或者仍无法区分 Skill 与模型问题时，才进一步查看完整 Trace、重复执行或补充控制变量验证。
  • 一套真正有价值的业务 Agent 评测体系，不以 Task 数量、指标数量或自动化程度为终点。它的价值在于：业务问题能够被稳定复现，失败能够被快速定位，优化能够被可信验证，线上变化又能持续反哺下一轮评测和业务迭代。
