Oracle 专利到期，开源数据库迎来快速排序算法

1/24/2026, 7:00:00 AM

📌 一句话摘要

Oracle 关于 “Orasort” 的专利到期，使得开源数据库能够采用这种可提供高达 5 倍性能提升的高性能排序算法。

📝 详细摘要

本文讨论了 Oracle 专利 US7680791B2 的近期到期情况，该专利涵盖了由 Mark Callaghan 开发的高效排序算法。该方法在非正式场合被称为 “Orasort”，通过在键比较期间跳过公共前缀字节，并根据数据特征在快速排序和基数排序之间进行自适应切换，从而优化数据库性能。该算法最初在 Oracle 10gR2 中实现，据报道其性能比前代算法提高了 5 倍。随着该专利现已进入公共领域，包括 MySQL 和 PostgreSQL 贡献者在内的开源社区对实施该技术表现出了浓厚兴趣，旨在降低现代数据库系统的延迟并提高缓存效率。

💡 主要观点

  1. 专利 US7680791B2 的到期消除了开源数据库优化的法律障碍。 一项拥有 20 年历史的专有排序方法现已免费供公众使用，允许 PostgreSQL 和 MySQL 等项目集成此前由 Oracle 独占的企业级排序逻辑。
  2. “Orasort” 算法通过公共前缀跳过和自适应排序实现高效性。 通过避免对相同前缀键部分的冗余比较，并根据数据特征在快速排序和基数排序之间切换，该算法显著减少了 CPU 周期和缓存未命中。
  3. Oracle 10gR2 的早期实现展示了 5 倍的性能提升。 来自发明者的历史数据显示，这种内存排序算法的性能优于之前的方法 5 倍，凸显了其对现代数据处理的潜在影响。
  4. 该算法通过支持早期结果流式传输来最小化延迟。 与某些传统排序方法不同，这种方法旨在整个排序操作完成之前生成第一批结果项，这对于响应式数据库查询流至关重要。

💬 文章金句

  • 我在 Oracle 工作期间发明了它，并将其应用在 10gR2 中，据称其性能比 Oracle 之前使用的排序算法提高了约 5 倍。
  • 该算法结合了多种技术：在比较键时跳过公共前缀，在快速排序和基数排序之间自适应切换，缓存键子串以减少缓存未命中。
  • 该专利对算法有很好的描述，它比典型的专利更容易阅读。
  • 我从未考虑过排序算法何时可以交付第一个结果项，以启动响应流并最小化延迟的复杂性。
