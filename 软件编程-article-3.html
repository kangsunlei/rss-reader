Meta 开源 Pyrefly，Rust 中的高性能 Python 类型检查器

6/1/2025, 2:16:00 AM

📌 一句话摘要

Meta 开源高性能 Rust 编写的 Python 类型检查器 Pyrefly，大幅提升检查速度。

📝 详细摘要

Meta 推出了新的开源 Python 类型检查器 Pyrefly，该工具使用 Rust 语言开发，旨在提供极致的性能。其主要动机是满足 Instagram 大型代码库对响应式 IDE 类型检查的需求，以取代基于 OCaml 的旧工具 Pyre。Pyrefly 在 Meta 内部基准测试中展现了显著的速度优势，能在大规模代码库上实现每秒百万行代码的检查速度，远超 Pyre、Pyright 和 MyPy。除了高性能，Pyrefly 还具备自动推断未注解代码类型、跨平台支持和 WebAssembly 能力。目前处于 Alpha 阶段，计划今年夏天进入 Beta，已有 Visual Studio Code 扩展可用。文章还提及了另一款 Rust 编写的 Python 类型检查器 Astral 的 Ty。

💡 主要观点

  1. Pyrefly 是 Meta 基于 Rust 开发的高性能 Python 类型检查器 采用 Rust 语言实现，旨在解决现有工具性能瓶颈，特别针对大型复杂代码库和对实时反馈有需求的场景。
  2. 其核心优势在于显著提升类型检查速度 Meta 内部测试显示，Pyrefly 检查速度远超 Pyre、Pyright 和 MyPy，为实现按键即时类型检查奠定基础。
  3. Pyrefly 支持未注解代码的自动类型推断 除了显式注解，工具还能尝试推断返回值和局部变量类型，提高对现有代码库的实用性。

💬 文章金句

  • 我们构建了 一个自定义的增量计算引擎，并基于多年的渐进类型理论经验和 Rust 专业知识设计了我们的类型检查算法。
  • 根据 Meta 的说法，它可以在大型代码库上每秒检查 180 万行代码，从而使得在每次按键点击时进行类型检查成为可能。
  • 除了对带注解的 Python 代码库进行类型检查之外，Pyrefly 还致力于对未带注解的代码也有用。
