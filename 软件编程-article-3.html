把 Claude Code、Copilot 装进元宝： yuanbao-acp 让 AI 智能体触手可及

6/18/2026, 3:12:30 PM

📌 一句话摘要

yuanbao-acp 是一个开源桥接工具，通过一行命令将 Claude Code、Copilot 等 ACP 兼容的 AI 编程智能体接入腾讯元宝，支持群聊、多实例、文件收发与自动化工作流。

📝 详细摘要

本文介绍作者开源的 yuanbao-acp 项目，旨在解决开发者同时使用多个 AI 编程智能体（如 Claude Code、Copilot、Gemini CLI 等）时入口分散、切换低效的痛点。项目基于 ACP（Agent Client Protocol）协议，将智能体桥接到腾讯元宝平台，利用元宝原生支持的群聊、多机器人并行与开放 API 优势，替代微信机器人的受限生态。核心能力包括：内置 11 个智能体预设、群聊与私聊双模式、文件收发、多部分消息缓冲、多实例并行隔离、本地注入实现自动化，以及运行时配置。文章提供了快速上手的命令行示例，并说明了隐私安全设计（遥测可选、数据最小化、本地存储）。项目以 MIT 协议开源。

💡 主要观点

  1. yuanbao-acp 通过 ACP 协议将 AI 智能体桥接到元宝，解决多工具入口分散问题。 开发者无需在多个终端间切换，在元宝内即可调用 Claude Code、Copilot 等智能体，降低上下文切换成本。
  2. 选择元宝而非微信作为桥接平台，因其原生支持群聊、多机器人与开放 API。 微信机器人生态收紧，群聊与多实例受限；元宝的开放 API 使智能体加入群聊、多实例并行成为可能，更适合承载智能体。
  3. 项目提供群聊协作、文件收发、多实例隔离与自动化注入等实用功能。 团队可在群中 @智能体做代码评审；文件自动下载供智能体读取；--instance 参数实现多项目隔离；inject 命令支持 cron 定时任务触发。
  4. 隐私设计注重数据最小化，遥测可选且不收集敏感信息。 遥测仅收集事件类型与哈希化用户 ID，不收集消息内容、文件名或令牌；配置与状态数据本地存储。
