LangChain 彻底重写：从开源副业到独角兽，一次“核心迁移”干到 12.5 亿估值

10/24/2025, 6:46:00 AM

📌 一句话摘要

LangChain 获 1.25 亿美元融资，发布重写版 1.0，以 LangGraph 为底座，通过`create_agent`和`middleware`提升 Agent 开发可控性。

📝 详细摘要

文章详细阐述了 LangChain 从一个开源副业项目成长为估值 12.5 亿美元独角兽的历程，并重点介绍了其里程碑式的 1.0 版本重写。LangChain 最初旨在解决大模型应用开发的工具碎片化问题，通过整合大量模型和基础设施成为连接大模型生态的“瑞士军刀”。然而，随着项目普及，其高层接口在生产环境中的定制化能力不足成为痛点。为解决此问题，团队先推出了提供底层编排能力的 LangGraph，并最终决定以 LangGraph 为底座，彻底重构 LangChain。新版 1.0 引入了`create_agent`抽象以平衡易用性与可控性，并创新性地提出了`middleware`概念，强化了“上下文工程”和动态模型选择能力，使 Agent 开发告别“拼凑学”，迈向更精简、灵活和强大的工程化阶段。

💡 主要观点

  1. LangChain 1.0 通过重写实现 Agent 开发工程化 新版以 LangGraph 为底座，引入`create_agent`抽象和`middleware`概念，显著提升了 Agent 逻辑编排的可控性、灵活性和生产级应用能力，告别了早期“拼凑学”的开发模式。
  2. `middleware`机制强化上下文工程与动态模型选择 中间件允许在 Agent 循环任意位置插入额外逻辑，有效解决长上下文、人类在环审批等问题，并能基于上下文动态选择最优模型，优化成本与能力。
  3. LangChain 从开源副业成长为 AI 开发领域独角兽 项目通过连接大模型与工具，解决早期开发痛点，坚持模型中立路线，快速迭代并成功商业化，最终实现估值 12.5 亿美元的巨大飞跃。

  • `create_agent + middleware API` 是把'上下文工程'真正落地为可操作抽象的首次清晰尝试。
