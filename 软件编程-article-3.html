Cloudflare 践行 CISA 安全设计承诺：加速内核更新

4/4/2025, 2:00:01 PM

📌 一句话摘要

Cloudflare 通过自动化内核更新，特别是利用 Unimog 和 Reboau 等自研工具，高效履行 CISA 安全设计承诺，显著提升了安全性和可靠性。

📝 详细摘要

Cloudflare 通过自动化 Linux 内核更新，展示了其履行 CISA 安全设计承诺的实践。面对安全补丁和用户体验的平衡难题，Cloudflare 采用 Unimog 负载均衡系统，安全地重启服务器，应用最新的内核补丁。在控制平面，Cloudflare 使用 Reboau 工具实现内核更新的自动化，确保基础设施及时获得安全补丁。Cloudflare 的内核生命周期管理流程，包括内部测试、员工体验和逐步推广到客户流量，确保更新的稳定性和性能。通过这些措施，Cloudflare 将内核更新频率提高到每月一次，显著减少了漏洞暴露时间，提升了整体基础设施的安全性和可靠性。Cloudflare 鼓励其他组织也采纳 CISA 的安全设计原则。

💡 主要观点

  1. 自动化内核更新是 Cloudflare 履行 CISA 承诺的关键措施，Unimog 和 Reboau 是其独特的技术支撑 通过自动化流程，Cloudflare 能够更快速、更一致地部署安全补丁，降低漏洞利用的风险，提升整体安全性。Unimog 负责流量管理和负载均衡。Reboau 则负责控制平面的自动化更新。
  2. 平衡安全补丁和用户体验是 Cloudflare 的重要考量，精细的流量管理至关重要 Cloudflare 通过精细的流量管理和负载均衡策略，在不影响用户体验的前提下安全重启服务器，应用最新的内核补丁。
  3. Cloudflare 关注长期稳定内核分支，并通过多阶段测试确保内核更新的稳定性和性能 Cloudflare 优先采用长期稳定内核分支，并在内部环境、员工体验环境和生产环境进行多阶段测试。通过收集 CPU 利用率、内存使用情况等数据，确保新内核的稳定性和性能。

💬 文章金句

  • 为了确保系统安全，至关重要的是在跨系统执行关键补丁部署的同时，维护用户体验。
  • 边缘重启发布每 30 天开始并完成一次。这保证了我们每个月都在基础设施中运行最新的内核。
  • 现在，我们所有的基础设施都受益于 Linux 内核的更快补丁，从而提高了客户的安全性和可靠性。
