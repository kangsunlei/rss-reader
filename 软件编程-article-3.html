.NET 10 预览版 7 通过 XAML 源码生成器加速 .NET MAUI

8/24/2025, 12:00:00 PM

📌 一句话摘要

.NET 10 预览版 7 通过新的 XAML 源码生成器显著增强了 .NET MAUI，该生成器用于编译时处理，从而提升性能。此外，该版本还引入了改进的媒体处理和更安全的 UI 布局。

📝 详细摘要

本文详细介绍了 .NET 10 中 .NET MAUI 的第七个预览版，重点关注关键的性能改进和控件增强。一个主要的亮点是引入了编译时 XAML 源码生成器，它在构建时编译 XAML，而非运行时编译。此更改显著减少了应用程序启动延迟，在开发周期的早期发现了 XAML 错误，并允许开发人员检查生成的代码。启用此功能需要特定的项目属性和属性配置。此外，`MediaPicker` 控件现在支持来自图像的嵌入式 EXIF 元数据，从而实现更丰富的功能，例如自动照片旋转和更可靠的元数据处理。通过更智能地管理设备特定的屏幕区域（例如，刘海、圆角）来增强 UI 布局安全性，通过 `SafeAreaEdges` 属性为开发人员提供对内容定位的更精细控制。工具栏 API 已经过改进，以支持辅助项目，这些项目呈现为设备特定的辅助菜单选项。该预览版还包括用于以编程方式控制选择器和搜索处理程序的新 API，同时弃用旧类，如 `Accelerator` 和 `ClickGestureRecognizer`。开发者的反馈普遍很积极，特别是对 XAML 源码生成器，这表明大家很认可这个版本对质量的改进。

💡 主要观点

  1. XAML 源码生成器显著提升 MAUI 的性能和开发人员体验。 通过在构建时编译 XAML，它可以减少启动延迟，更早地检测到错误，并允许开发人员检查生成的代码，从而简化 MAUI 的开发过程。
  2. 增强的 UI 布局和媒体处理提高了应用程序在各种设备上的稳健性和用户体验。 更智能的安全区域管理提供了对设备特定元素周围的内容定位的更精细控制，而 `MediaPicker` 中对 EXIF 元数据的支持丰富了图像功能和可靠性。
  3. 改进的工具栏 API 和新的控件 API 为开发人员提供了更大的灵活性和控制力。 包含辅助工具栏项目和以编程方式管理控件状态的能力简化了 UI 自定义，并增强了 MAUI 应用程序中的交互功能。

💬 文章金句

  • 此预览版侧重于编译时 XAML 处理、更丰富的媒体元数据支持、更安全的 UI 布局和改进的工具栏 API。
  • XAML 标记现在在构建时编译，而不是在运行时解释。此更改减少了应用程序启动延迟，在开发人员工作流程的早期发现了 XAML 错误，并使开发人员能够检查生成的代码以获得更深入的了解。
  • 围绕刘海、圆角和显示切口的布局逻辑现在更加智能，使开发人员可以更精细地控制具有不同安全区域的设备上的内容定位。
  • .NET MAUI 10 预览版 7 中的工具栏现在可以包含辅助项目，这些项目将呈现为设备特定的辅助菜单项。
