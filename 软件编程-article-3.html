谷歌 Java 智能体开发工具包：集成 LangChain4j，赋能更强大的 AI 智能体

9/28/2025, 1:00:00 PM

📌 一句话摘要

ADK for Java 0.2.0 集成 LangChain4j，大幅扩展 LLM 支持，解锁多智能体混合模型应用。

📝 详细摘要

谷歌 Java 智能体开发工具包 (ADK) 最新版本 0.2.0 引入了与 LangChain4j 框架的关键集成。集成 LangChain4j 显著扩展了 Java 开发者可用的 LLM 范围，不再局限于 Google Gemini 和 Anthropic Claude。开发者现在可以利用来自 OpenAI、Anthropic、Mistral 以及由 Ollama 或 Docker 模型运行器支持的模型，例如 Gemma、Qwen 和 Phi。关键优势在于支持多智能体场景下的 LLM 混合使用，允许开发者为特定任务选择最佳模型——例如，使用超快速模型进行简单分类，以及使用更强大的模型进行复杂的推理。文章提供 Java 代码示例，演示如何结合 Claude 主智能体和 OpenAI 工具智能体获取天气信息。此外，ADK 0.2.0 还带来了其他重要的增强功能，包括改进的工具功能（例如从对象实例创建 `FunctionTools`），更好的异步工具操作，以及通过回调链和新原语实现的高级智能体逻辑和内存管理。Java 版 ADK 仍处于早期阶段，提供了供开发者入门的资源。

💡 主要观点

  1. LangChain4j 显著扩展 ADK for Java 的 LLM 支持。 以前仅限于 Google Gemini 和 Anthropic Claude，Java 开发者现在可以访问来自 OpenAI、Mistral、Ollama 和 Docker 模型运行器的更广泛的模型，从而提高了灵活性。
  2. 支持多智能体 LLM 混合，优化任务执行。 开发者可以策略性地组合不同的模型，利用专门的或更快的模型来执行特定的子任务，同时使用更强大的模型来进行核心推理，从而提高效率和准确性。
  3. ADK for Java 0.2.0 增强了工具和智能体内存管理。 新功能包括从对象实例创建 `FunctionTools`，改进的异步操作，以及更灵活地控制智能体存储和处理信息的方式。

💬 文章金句

  • ADK for Java 0.2.0 集成 LangChain4j LLM 框架，显著扩展功能，全面支持该框架下的大型语言模型。
  • 多智能体场景下混合模型非常有趣，可以针对任务选择最优模型。
  • 例如，使用超快模型进行简单分类以路由请求，而使用更强大的模型处理复杂任务（如 Gemini 2.5）。
  • 除了 LangChain4j 集成之外，ADK 0.2.0 还引入了一系列旨在提高工具功能和智能体性能的重大增强功能。
