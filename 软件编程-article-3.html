如何使用 GitHub Actions 部署到 Vercel

6/10/2025, 5:57:20 PM

📌 一句话摘要

关于使用 GitHub Actions 和 Vercel CLI 自动化 Web 应用部署到 Vercel 的教程。

📝 详细摘要

本文提供了一份分步指南，介绍如何使用 GitHub Actions 将 Web 应用（特别是 Next.js 项目）部署到 Vercel。内容涵盖了前提条件，包括设置 GitHub 仓库和 Vercel 账户。核心步骤包括：创建 Vercel 令牌，将其作为 Secret 添加到 GitHub 仓库，在本地安装并登录 Vercel CLI 以链接项目并获取项目/组织 ID，最后，创建并配置一个 GitHub Actions 工作流程文件（`.github/workflow/vercel_deploy.yml`），该文件使用 Vercel CLI 命令（`vercel pull`、`vercel build`、`vercel deploy`），在推送到 main 分支时触发。本教程实用且附带详细截图，并提供了必要的 YAML 配置。

💡 主要观点

  1. 使用 GitHub Actions 工作流程自动化 Vercel 部署。 将 Vercel CLI 命令集成到 GitHub Actions 工作流程中，以在代码推送时自动化构建和部署过程。
  2. 使用 GitHub Secrets 安全管理 Vercel 访问。 将敏感的 Vercel 令牌和项目标识符作为加密的 Secret 存储在 GitHub 中，以便在工作流程中验证部署命令的身份。
  3. 为自动化触发器配置 GitHub 工作流程文件。 定义一个 YAML 文件，指定工作流程的运行时间（例如，在推送到 main 分支时）以及部署所需的步骤。

💬 文章金句

  • Vercel 是一个云平台或平台即服务 (PaaS)，旨在帮助前端开发者快速高效地创建、预览和部署 Web 应用。
  • 在你的 Vercel 账户中，前往设置，然后前往令牌。
  • Vercel 令牌是用于验证 GitHub runner 身份的令牌。
  • 项目 ID 用于指定你要部署到 Vercel 的具体项目。
  • 在你的项目文件夹根目录，创建 .github/workflow 文件夹。然后创建一个名为 vercel_deploy.yml 的工作流程文件。
  • 通过这些步骤，Vercel 首先被安装在 GitHub runner 上。然后拉取 Vercel 环境信息。项目使用 vercel build 构建，然后将预构建的构件推送到 Vercel。
