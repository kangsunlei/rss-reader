Open Payment Standard x402 重大升级，功能全面扩展

1/22/2026, 7:00:00 PM

📌 一句话摘要

x402 开放支付标准 V2 升级引入了模块化架构、基于钱包的身份识别以及多链支持，通过 HTTP 402 实现机器对机器及智能体之间的无缝支付。

📝 详细摘要

x402 开放支付标准经历了重大的 V2 版本更新，从简单的单次请求协议演变为 Web 原生支付的综合框架。此次升级引入了模块化 SDK、支持基于钱包的身份验证以及 API 自动发现功能。关键技术改进包括与 CAIP 和 IETF 标准对齐，为链上（Base、Solana）和链下（ACH、SEPA）交易提供统一接口。通过利用 HTTP 402 状态码，该协议允许自主智能体和 Web 应用在请求-响应流中直接结算支付，绕过了传统的基于账户的障碍。Cloudflare 将其集成到开发者工具和 MCP 服务器中，进一步增强了该生态系统，至今已支持超过 1 亿次支付流。

💡 主要观点

  1. 从单次请求支付演进为模块化、多链框架 V2 超越了固定金额支付，支持动态路由、基于钱包的身份识别，并利用 CAIP 标准实现了加密货币与法币通道的跨链兼容性。
  2. 利用 HTTP 402 使支付成为互联网的一等公民 该协议使用原生的 HTTP 402 状态码来发出支付需求信号，无需重定向或手动账户管理即可实现机器对机器交易。
  3. 增强对自主智能体和 AI 驱动工作流的支持 通过与 Cloudflare 的 Agents SDK 和 MCP 服务器集成，x402 使 AI 机器人能够以极低的延迟通过编程方式支付 API 使用费和服务费。
  4. 协议、SDK 与服务商在架构上的解耦 新设计将核心规范与实现层及结算层分离，允许开发者插入自定义支付方案和验证逻辑。

💬 文章金句

  • V2 是一次重大升级，使协议更加通用、灵活，且更易于在网络、传输、身份模型和支付类型之间进行扩展。
  • 该协议利用极少使用的 HTTP 状态码 402（402 Payment Required）来发出需要支付的信号，并在响应中提供支付指令。
  • 它支持微支付、按需付费和机器对机器支付，允许 Web 应用、API 和自主智能体直接通过 HTTP 为服务付费。
  • 规范更加简洁、模块化，并与包括 CAIP 和 IETF 标头惯例在内的现代标准保持一致。
