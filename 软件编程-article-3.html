Java 25：新一代 LTS 版本，聚焦性能与特性优化

9/16/2025, 7:30:00 PM

📌 一句话摘要

Java 25 是最新的 LTS 版本，包含 18 个 JEP，着重优化性能和运行时。同时，也预览了 JDK 26 的新特性。

📝 详细摘要

本文全面介绍了 Java 25，一个长期支持 (LTS) 版本，其中包含 18 个 Java 增强提议 (JEP)。7 个 JEP 已最终确定，9 个专注于 Leyden 项目和 HotSpot JVM 的性能与运行时增强。关键特性包括作用域值、紧凑对象头（减少 JVM 对象头大小）和密钥推导函数 API（用于安全密码密钥生成）。文章详细介绍了面向性能的 JEP，如 JFR 方法计时与追踪、JFR 协同采样、AOT 方法分析和 AOT 命令行人体工学。此外，还涵盖了 JDK 25 发布会，讨论了性能、安全性、Java AI 库和异构加速工具箱 (HAT)。最后，文章预览了 JDK 26 的目标 JEP，包括 G1 GC 改进、HTTP/3 支持和移除 Applet API，突显了 Java 的持续演进。

💡 主要观点

  1. Java 25：重要的 LTS 版本，着重性能与运行时。 作为 JDK 21 之后的第一个 LTS，Java 25 引入了 18 个 JEP，重点是优化 JVM 和应用程序性能，使其成为寻求稳定性和增强功能的开发人员的关键更新。
  2. 几个关键的 JEP 已经最终确定，增强了核心 Java 功能和效率。 紧凑对象头（减少内存占用）和作用域值（改进线程局部状态管理）等特性日趋成熟，提供切实的好处。这些特性直接提高了应用程序的健壮性和整体系统性能。
  3. Leyden 项目和 JFR 增强推动了显著的性能提升和诊断能力。 Leyden 项目中的 JEP，如 AOT 方法分析，以及 JFR 扩展（如方法计时与追踪），为更快的应用启动、更好的可观测性和精确的性能调优提供了关键工具。这些工具帮助开发者构建更高效的系统。

💬 文章金句

  • 作为 JDK 21 之后的第一个 LTS 版本，最终特性集包括 18 个 JEP，其中 7 个已经最终确定。
  • 此版本还侧重于性能和运行时，因为这些 JEP 中有 9 个属于 Leyden 项目和 HotSpot JVM 的范围。
  • JEP 519，[Compact Object Headers](https://openjdk.org/jeps/519)，建议将此特性从实验性提升到产品级。受到 [Project Lilliput](https://wiki.openjdk.org/display/lilliput) 的启发，此特性“将 HotSpot JVM 中对象头的大小从 96 到 128 位减少到 64 位（在 64 位架构上）”。
  • JEP 515，[Ahead-of-Time Method Profiling](https://openjdk.org/jeps/515)，建议通过“使应用程序先前运行的方法执行配置文件在 HotSpot JVM 启动时立即可用”来缩短应用程序的预热时间。
