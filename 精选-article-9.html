我们为何构建并捐赠 Model Context Protocol (MCP)

12/11/2025, 8:14:58 PM

📌 一句话摘要

MCP 联合创始人 David Soria Parra 阐述了该协议如何通过开源和捐赠 Linux 基金会，推动 AI 模型与外部工具和数据的标准化连接。

📝 详细摘要

本视频采访深入探讨了由 Anthropic 发起并开源的 Model Context Protocol (MCP)。MCP 旨在通过提供一个标准化的协议，解决 AI 模型与外部工具（如电子邮件、Slack、Google 云端硬盘、集成开发环境（IDE）甚至 3D 打印机）连接的碎片化问题，类似于 USB-C 统一了设备连接。该协议起源于 Anthropic 的内部黑客马拉松，并迅速获得社区关注，吸引了 Cursor、Block、Sourcegraph 等公司采用。Anthropic 决定将 MCP 的商标和部分代码捐赠给 Linux 基金会旗下的“智能体 AI 基金会”，以确保其作为开放标准的中立性、安全性和长期稳定性，鼓励更广泛的参与和创新。视频还讨论了 MCP 面临的安全性和“上下文臃肿”等批评，并提出了未来的发展方向，包括通过“任务”实现智能体间通信和更丰富的用户界面交互。

💡 主要观点

  1. MCP 旨在标准化 AI 模型与外部工具的连接，解决碎片化问题。 类似于 USB-C 的作用，MCP 提供了一个通用协议，使任何 AI 模型或应用程序都能轻松连接各种外部服务和集成，避免重复开发适配不同模型或工具的连接器。
  2. 将 MCP 开源并捐赠给 Linux 基金会是保障其作为开放标准中立性和可持续性的关键。 通过移交商标权和法律事务，确保 MCP 不受单一公司控制，建立多方信任，鼓励行业巨头和个人开发者共同投入，加速其生态系统的发展和采纳。
  3. MCP 通过促进工具调用极大地扩展了 AI 模型的能力，但需关注相关安全风险和上下文管理。 虽然 MCP 极大便利了 AI 与世界的交互，但工具调用也带来提示词注入等安全问题。同时，大量工具信息可能导致“上下文臃肿”，需通过工具搜索和程序化工具调用等优化方案来缓解。

💬 文章金句

  • MCP 试图实现的是给这个『大脑』装上通向世界的『四肢』，把它与你最关心的事物连接起来。
  • 我们要做的是将其捐赠给一个独立实体，确保所有的大型参与者都能感到安全，保证这个协议不会被夺走。如果你在 MCP 上投入了资源，未来没人能随意改变它。
  • 这是我们试图构建一个空间，让人们可以将开源的智能体 AI 项目捐赠给这里，与 MCP 并列，从而促进基金会内项目之间的互利。它就是一个推动开源智能体 AI 项目的开放社区空间。
  • MCP 打开了各种安全风险的大门，但这不是协议本身造成的，而是源于任何人都可以编写一个能被模型调用的工具。这才是风险所在。
  • 我最自豪的是能够建立一个社区，汇聚了来自开源界、大公司的人们，大家为了一个共同的目标而共同努力。
