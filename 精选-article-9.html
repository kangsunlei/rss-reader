Claude 技能：为你的工作流程定制 AI

10/15/2025, 4:00:00 PM

📌 一句话摘要

Anthropic 推出 Claude 技能，使用户和开发者能够通过特定的指令、脚本和可执行代码定制 Claude AI，以支持所有 Claude 产品中的专业工作流程。

📝 详细摘要

Anthropic 推出了 Claude 技能，这项新功能旨在通过允许用户将专业知识、指令、脚本和资源打包到“技能包”中，来增强 Claude 在特定任务中的性能。当任务相关时，Claude 会智能地加载这些技能，从而确保效率和速度。“技能”的主要特点包括可组合性（可堆叠组合）、可移植性（一次构建，随处使用）、效率（仅加载所需内容）和强大性（支持可执行代码以实现可靠的任务执行）。“技能”可在 Claude 应用（Pro、Max、Team、Enterprise 层级）、Claude 开发者平台 (API) 和 Claude 代码中使用。对于开发者，新的“/v1/skills”API 端点提供了对技能管理的编程控制，需要代码执行工具 Beta 版。Anthropic 提供用于常见任务的预构建技能，例如创建 Excel、PowerPoint 和 Word 文档，同时用户还可以创建自定义技能，通常由“技能创建 AI”指导。来自 Box、Notion、Canva 和 Rakuten 的评价突出了实际好处，例如转换文件、无缝集成、定制代理和简化会计工作流程。文章强调了简化技能创建和企业级部署的未来潜力，同时也提出了关于可执行代码的安全影响的警告。

💡 主要观点

  1. Claude 技能支持对 Claude AI 进行深度定制，以用于专门的任务和工作流程。 用户可以为 Claude 提供特定的指令、脚本和资源，使其能够充当 Excel 操作或遵守品牌指南等领域的专家，从而显著提高任务性能。
  2. 技能具有可组合性、可移植性、高效性和强大性，支持可执行代码以实现可靠的操作。 这种设计使技能可以堆叠使用，可以在所有 Claude 产品中使用，并且会以最小化方式加载以提高速度。此外，它还可以执行传统编程，以处理仅靠令牌生成不太可靠的任务，从而增强 Claude 的能力。
  3. 技能已集成到 Claude 的生态系统中，从而增强了最终用户和开发人员的能力。 技能可在 Claude 应用中通过 API 进行编程控制，并在 Claude 代码中提供，为个人和企业构建用于各种应用的自定义智能代理提供了广泛的实用性。
  4. 该功能强调安全性，提醒用户注意可执行代码的风险。 由于技能可以执行代码，因此建议用户关注技能来源，并尽量使用可信的技能，以确保数据安全和系统稳定。

💬 文章金句

  • Claude 现在可以使用 *技能* 来改进其执行特定任务的方式。技能是包含 Claude 可以在需要时加载的指令、脚本和资源的文件夹。
  • 将技能视为自定义入职材料，让您能够打包专业知识，使 Claude 成为你最重要事项的专家。
  • 对于传统编程比令牌生成更可靠的任务，技能可以包括可执行代码。
  • 智能代理技能（我们通常简称为技能）现在可以添加到消息应用程序编程接口请求中，新的“/v1/skills”端点使开发人员可以对自定义技能版本控制和管理进行编程控制。
  • 以前需要一天才能完成的工作，现在我们一个小时就能搞定。
