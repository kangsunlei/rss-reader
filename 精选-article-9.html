DeepSeek-V4-Pro 正式版上线

8/13/2026, 11:19:00 AM

📌 一句话摘要

DeepSeek 发布 V4 Pro 正式版，Agent 能力显著提升，原生支持 Responses API，新增三档思考强度控制，并将于 8 月 17 日起实施峰谷定价。

📝 详细摘要

DeepSeek 正式发布 V4 Pro 版本，已同步在 APP、网页端和 API 上线。本次更新重点提升 Agent 能力，在生产环境中性能表现显著改善，公开基准测试集中 Code Agent 任务成绩突出。API 方面，原生支持 OpenAI Responses API 格式并适配 Codex，新增 low/high/max 三档思考强度控制。定价方面，将于 2026 年 8 月 17 日起实施峰谷定价，闲时价格为高峰时段的一半。

💡 主要观点

  1. Agent 能力在生产环境中大幅提升。 V4 Pro 正式版在公开基准测试集中的 Code Agent 任务表现突出，生产环境适用性显著增强。
  2. 原生支持 OpenAI Responses API 并适配 Codex。 API 新增对 OpenAI Responses API 格式的原生支持，并提供一键配置脚本完成 Codex 配置。
  3. 新增三档思考强度控制。 V4-Pro 和 V4-Flash 支持 low/high/max 三档思考模式，用户可根据任务复杂度灵活选择。
  4. 实施峰谷定价策略。 API 定价将于 8 月 17 日起调整，闲时价格为高峰时段的一半，鼓励用户合理调配资源。
