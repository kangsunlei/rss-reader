JustHTML：一场生动的“氛围工程”实践

12/14/2025, 3:59:23 PM

📌 一句话摘要

本文以 JustHTML（一个 Python HTML 解析库）为例，阐述了“氛围工程”（vibe engineering）：一种先进的 AI 辅助编程方法，其中人类工程师指导大型语言模型进行代码生成，以产出高质量成果。

📝 详细摘要

本文介绍了 JustHTML 这个全新的 Python HTML 解析库，并将其定位为“氛围工程”（vibe engineering）的典范。作者最初被 JustHTML 吸引，源于其诸多出色特性：纯 Python 实现、100%测试覆盖率、通过全部 9，200 多项 html5lib 测试，以及对 CSS 选择器的支持。深入研究后发现，该库几乎完全是在多种大型语言模型（包括 Claude Code、Claude Sonnet 3.7、Gemini 3 Pro 和 Claude Opus）的协助下构建的，所有这些都在工程师 Emil Stenström 的精心指导下完成。作者将这种方法与“氛围编码”（vibe coding）区分开来，强调“氛围工程”涉及专家程序员在专业监督下有效利用 AI 编码代理。Stenström 有条不紊的流程包括：早期集成全面的测试套件、自主设计的 API、性能基准测试、迭代优化、代码重构、自定义性能分析和模糊测试——所有这些都展示了精密的软件工程实践，尽管具体“敲代码”的工作由 LLM 完成。文章总结认为，这种劳动分工模式，即人类工程师提供“思考”和方向，代表了一种更有价值且高效的时间利用方式。

💡 主要观点

  1. JustHTML 是“氛围工程”的典范，这是一种精细化的 AI 辅助软件开发方法。 这种方法与“氛围编码”形成对比，它通过专家级的人工监督、严格测试以及对生成式 AI 模型（如 Claude Code、Claude Sonnet 3.7、Gemini 3 Pro 和 Claude Opus）的战略指导，从而产出高质量、可用于生产环境的代码。
  2. 即使在大型语言模型生成大部分代码时，精密的软件工程实践依然至关重要。 Emil Stenström 为 JustHTML 制定的流程涵盖了关键的设计决策、广泛的测试、性能优化及代码重构，凸显了人类专业知识在现代开发工作流中不可或缺的核心作用。
  3. 在开发生命周期早期集成全面的测试套件和基准测试对于 AI 辅助项目至关重要。 在开发初期就集成如 html5lib 测试套件和定制基准测试，能为大型语言模型提供必要的约束机制和反馈，确保所生成代码符合严格的质量和性能标准。

  • 用 html5lib 测试套件来设置编码代理，也是设计一个有效的代理循环（agentic loop）的绝佳范例。
