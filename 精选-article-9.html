实录 OpenAI 年度发布会：25 项发布，逐一详解

9/29/2026, 6:53:00 PM

📌 一句话摘要

OpenAI 年度发布会发布了 25 项重大更新，涵盖 Dots Agent 框架、GPT-6.1 Sol 模型及 Pages 协作空间等。

📝 详细摘要

本文详尽记录了 OpenAI 年度发布会的全部内容。核心亮点包括：推出 7x24 小时在线的 Agent 系统 Dots，具备跨上下文和主动研究能力；发布 GPT-6.1 Sol 模型，在推理速度和准确性上接近 Astra 模型，且大幅降低了成本；推出 Pages 动态文档，支持多人与 Agent 协作；此外还有 Codex 支持 Linux、手机端升级等多项功能迭代。

💡 主要观点

  1. 推出 Dots Agent 系统 一种持续在线、能够主动处理任务并跨渠道上下文的 AI Agent。
  2. 发布 GPT-6.1 Sol 模型 在编程、电脑操作和专业工作上接近 Astra，但标准输入输出价格仅为后者的五分之一。
  3. 推出 Pages 协作空间 一种全新的动态文档类型，支持人类与 Agent 协作进行计划、研究和图表生成。
  4. Codex 功能增强 正式支持 Linux 系统、跨文件夹项目管理并优化了移动端体验。
