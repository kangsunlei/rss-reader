Kimi 发布并开源 K2.5 模型，带来全新视觉理解、代码和 Agent 集群能力

1/27/2026, 6:09:00 AM

📌 一句话摘要

月之暗面发布 Kimi K2.5 模型，通过原生多模态架构实现视觉理解、代码生成及首创的「Agent 集群」协作能力。

📝 详细摘要

月之暗面正式发布并开源 Kimi K2.5 模型。该模型采用原生多模态架构，在视觉理解、代码编写和 Agent 任务上达到开源领先水平。核心亮点包括：一是强大的视觉与代码融合能力，支持通过录屏或截图直接复现交互逻辑与前端代码；二是首创「Agent 集群」功能，支持自主创建多达 100 个分身并行协作，显著提升复杂任务处理效率；三是同步发布 Kimi Code 编程工具，深度集成主流编辑器并开源 Agent SDK。K2.5 提供快速、思考、Agent 及集群四种模式，旨在通过技术平权降低 AI 交互门槛并提升办公自动化水平。

💡 主要观点

  1. Kimi K2.5 采用原生多模态架构，实现了视觉理解与代码能力的深度融合。 模型支持拍照、截图或录屏输入，能自动拆解视频中的交互逻辑并复现专业代码，大幅降低了从视觉原型到代码实现的门槛。
  2. 首次引入「Agent 集群」能力，将单兵作战进化为团队协作模式。 模型能根据复杂任务自主创建并调度多达 100 个分身，通过并行处理 1500 个步骤，在长程任务中实现数倍的效率提升。
  3. 发布 Kimi Code 编程工具并开源 Agent SDK，构建开发者生态。 Kimi Code 集成多模态优势并支持主流编辑器，同时开源 SDK 允许开发者自定义 Agent 体验，推动 Coding Agent 的普及。

💬 文章金句

  • 它是 Kimi 迄今最智能的模型，在 Agent、代码、图像、视频及一系列通用智能任务上取得开源 state-of-the-art 表现。
  • K2.5 首次引入了「Agent 集群」能力，让 K2.5 学会自主创建自己的「分身」，按需组成不同角色的团队，并行工作。
  • 在大规模搜索场景下，与单 Agent 执行相比，Agent 集群将达成目标性能所需的最少关键步骤减少了 3 到 4.5 倍。
  • 更智能、更全能，代码能力更强的模型，有助于推动技术平权，让更多人从中受益。
