📌 一句话摘要

万字长文深度评测 Dia、Fellou、Comet、Edge 四大 AI 浏览器，对比其用户体验、交互设计及核心 Agent 能力，揭示各产品优劣。

📝 详细摘要

本文作者耗时三天，对当前热门的四款 AI 浏览器：Arc 旗下的 Dia、Fellou、Perplexity 的 Comet 以及微软 Edge 的 Copilot 模式进行了全面深入的评测。文章主要从用户体验与交互设计、Agent 行动能力两大核心维度，通过具体案例（如机票预订、社交媒体批量操作）详细对比了各产品的表现。作者强调 AI 浏览器是 Agent 的理想载体，因其能利用 Cookie 和历史记录解决传统网页 Agent 的登录限制。评测结果显示，Fellou 和 Comet 在 Agent 自动化能力上表现出色，而 Dia 的 Agent 功能尚未上线，Edge 的 Agent 体验则被作者认为过于繁琐和低效。文章旨在为用户选择和理解 AI 浏览器提供深度参考。

💡 主要观点

  1. AI 浏览器是 AI Agent 的理想载体，能解决传统网页 Agent 的登录限制问题 浏览器天然具备 Cookie 和历史记录，使 AI Agent 能够无缝访问用户已登录的个性化内容，从而实现更强大的自动化和个性化服务。
  2. 各 AI 浏览器在用户体验、交互及个性化设置上差异显著 Perplexity Comet 和 Dia 在交互流畅度和个性化设置方面表现较好，而 Edge 的 Copilot 模式则因模式复杂、交互繁琐被作者诟病。
  3. AI 浏览器的 Agent 行动能力是核心竞争力，且各产品表现差异巨大 Fellou 和 Comet 在复杂任务（如机票预订、社交媒体批量操作）中展现出较高的自动化程度，而 Dia 尚无此功能，Edge 则需频繁人工干预，效率低下。

💬 文章金句

  • 我一直对 AI 浏览器的产品很期待，原因是我一直认为，它是 Agent 最棒的载体之一。
  • 因为浏览器有 Cookie，有历史记录等等。所以，正好借着这个机会，我就花了几天时间做了这个测评。
  • Fellou：因为 Fellou 给于 AI 的权限很高，所以，我可以直接在首页下达指令，它就能自主寻找网页，复用我的全部登录态，直接出票，而且全程自动化。
  • Comet 目前无法在未打开的标签页下进行 Agent 操作，只能先打开标签页，然后对这个页面进行 Agent 操作。
  • Edge：煞笔。根本就没用浏览器的优势，明明是 AI 浏览器，整个 Agent，却都是基于网页操作的。而且整个流程异常复杂和繁琐，必须时刻紧盯，遇到信息输入的部分，就需要手动填写。蠢到家了。
