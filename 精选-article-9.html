抢跑 GPT-5，智谱开源新 SOTA 模型，一句话搞出能看视频、发弹幕的 B 站！

7/28/2025, 4:05:22 PM

📌 一句话摘要

智谱发布 GLM-4.5 旗舰大模型，以 MoE 架构实现代码与 Agent 能力 SOTA，并全面开源，具备超强实用性。

📝 详细摘要

在业界普遍关注 GPT-5 发布之际，智谱发布了新一代旗舰开源大模型 GLM-4.5，采用 MoE 架构，总参数量达 3550 亿。该模型在代码和 Agent 能力上取得开源 SOTA，推理能力位居开源第二，并首次原生融合这三项能力。GLM-4.5 具备极快的生成速度和低廉的 API 调用价格，通过实际案例展示了其强大的代码生成和应用构建能力，如一句话生成可交互的百度、小红书、B 站等。文章还介绍了其技术细节（如 MoE、RoPE、Muon 优化器）和开源的强化学习基础设施 Slime，强调了其卓越的参数效率，为国产开源大模型树立了新标杆。

💡 主要观点

  1. 智谱 GLM-4.5 在代码与 Agent 能力上达到开源 SOTA，推理能力位居第二。 GLM-4.5 首次原生融合了代码、Agent 和推理三大能力，并在多项评测基准上表现卓越，尤其在开源和国产模型中位列第一，展现了其强大的综合实力。
  2. GLM-4.5 采用 MoE 架构实现高效性能，并全面开源。 该模型以远低于同行的参数量实现了超越性性能，且完全开源，同时提供极快的生成速度和低廉的 API 价格，极大降低了 AI 应用开发的门槛。
  3. 模型具备强大的实际应用构建能力，能一句话生成复杂交互网站。 通过实测展示了 GLM-4.5 仅凭一句话指令即可生成功能完善且高度相似的百度、小红书、B 站等网站，极大提升了开发效率和创意实现能力。

💬 文章金句

  • 代码和 Agent，直接拿下开源模型的 SOTA，推理拿下开源模型第二。
  • 更重要的是，这是首次在单个模型中把这三个能力进行了原生融合的那种。
  • 因为它的最快生成速度，已经是来到了 100 tokens/s 大关了！可以说是远超、秒杀其它 AI。
  • 当业界还在纷纷猜测和等待 OpenAI 的 GPT-5 将带来何种革命性功能时，智谱已经将类似的、甚至更强大的 Agent 能力通过 GLM-4.5 直接开源，并开放给所有用户免费体验。
  • 它用硬核的性能、前瞻的架构和开放的姿态，证明了中国 AI 力量不仅能够追赶，更具备了定义下一代模型标准的能力。
