从“做过”到“会做”：用 OpenViking 经验记忆构建 Agent 的进化闭环

9/16/2026, 11:05:00 AM

📌 一句话摘要

OpenViking 通过经验记忆让 Agent 从过去任务中学习可复用的方法，提升任务成功率。

📝 详细摘要

文章指出，Agent 能执行任务却难以从历史中学习，导致重复试错。OpenViking 为 Agent 构建面向执行过程的长期记忆——经验记忆，通过 Session（原始过程）、Trajectory（还原轨迹）和 Experience（提炼可复用方法）三层对象，实现离线学习和在线复用的闭环。离线阶段在任务结束后归档完整轨迹并生成或更新 Experience；在线阶段让 Agent 在新任务开始前检索相关 Experience、核对适用条件后应用。评测表明，在 τ²-bench 上，Retail 场景任务成功率从 70.94% 提升到 77.81%（+6.87pp），Airline 场景从 54.38% 提升到 66.25%（+11.87pp）；单题换货任务在引入经验后从 2/8 成功提升到 8/8 全部成功。文章还展示了经验记忆在内部经营分析助手减少返工和售后助手完成换货流程中的应用，并介绍了低改造成本的接入方式（企业/个人版、MCP、官方 Plugin 等）。整体内容兼具架构设计、实证数据和实际场景，具备较高的工程指导价值。

💡 主要观点

  1. 做过不等于会做，Agent 需要可复用的经验而非更多记录 仅保存聊天记录或日志无法让 Agent 在类似任务中直接使用过去的成功做法；经验记忆提供了可以调用、核对和迭代的方法，解决这一问题。
  2. OpenViking 由 Session、Trajectory、Experience 三层构成经验记忆链路 Session 保存原始对话和工具调用；Trajectory 还原任务目标、执行路径和结果；Experience 从相似轨迹中提炼可迁移的步骤、检查项和风险边界，实现从过去到未来的知识转化。
  3. 离线学习与在线复用形成闭环：执行→记录→提炼经验→召回→核对应用→更新 任务完成后 OpenViking 生成或更新 Experience；新任务开始时 Agent 检索相关 Experience，验证适用性后直接使用其中的步骤和检查项，新结果又成为下一轮经验的证据。
  4. 评测显著提升任务成功率：Retail +6.87pp，Airline +11.87pp，单题换货从 2/8 到 8/8 全部成功 在 τ²-bench 零售和航空场景中，引入经验记忆后成功率均有显著提升；在换货单题测试中，经验的召回使全部八次运行成功，验证了其实际效果。
  5. 经验记忆可用于内部效率和客户服务，接入方式低改造成本 经营分析助手可减少返工，售后助手能更完整完成换货流程；OpenViking 提供企业/个人版、MCP 与 Experience Skill、官方 Plugin 等多种接入路径，降低集成门槛。

💬 文章金句

  • “做过”不等于“会做”
  • Agent 需要的不是更多记录，而是可复用的经验
  • OpenViking 解决这个问题的方式，是为 Agent 建立一类面向执行过程的长期记忆 ：经验记忆。
  • Retail 测试集上，任务成功率从 70.94% 提升到 77.81%，提升 6.87 个百分点；
