215 项 SOTA + 自然涌现 Vibe Coding！Qwen3.5-Omni 发布

3/30/2026, 1:09:00 PM

📌 一句话摘要

通义实验室发布 Qwen3.5-Omni 原生全模态大模型，在 215 项基准测试中取得 SOTA，支持音视频实时交互、音色克隆及自然涌现的 Vibe Coding 能力。

📝 详细摘要

文章详细介绍了通义实验室最新发布的 Qwen3.5-Omni 原生全模态模型。该模型实现了文本、图片、音频及视频的无缝理解，在 215 项 SOTA 基准测试中表现卓越，部分任务超越 Gemini 3.1 Pro。核心亮点包括：支持 256K 超长上下文、自然涌现的音视频 Vibe Coding（根据指令生成代码）、语义打断与音色克隆等实时交互功能。技术上采用升级的 Thinker-Talker 分工架构，结合 Hybrid-Attention MoE 提升处理效率。目前已在阿里云百炼上线 Plus、Flash、Light 三种尺寸，并提供实时交互 API。

💡 主要观点

  1. 原生全模态理解与生成能力。 支持文本、图像、音频、视频四种模态的无缝输入，能够生成细粒度、带时间戳的音视频 Caption，打破了不同模态间的交互壁垒。
  2. 215 项 SOTA 成绩证明了其强大的推理性能。 在音频及音视频分析、翻译等任务上全面超越 Gemini 3.1 Pro，且在增加多模态能力的同时，保持了与单模态模型持平的文本和视觉能力。
  3. 自然涌现的 Audio-Visual Vibe Coding 能力。 模型在未经过专门训练的情况下，展现出根据视频画面逻辑直接生成 Python 代码或前端原型的能力，极大缩短了创意验证路径。
  4. 升级的 Thinker-Talker 分工架构与 MoE 技术。 采用 Hybrid-Attention MoE 架构，Thinker 负责多模态理解与长上下文处理，Talker 通过 RVQ 编码和 ARIA 技术实现稳定、自然的实时语音生成。
