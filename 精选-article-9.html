使用 Cloudflare 适配器在 Cloudflare Workers 上部署 Next.js 应用

4/8/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 发布了适用于 OpenNext 的 Cloudflare 适配器 1.0.0-beta 版本，旨在帮助 Next.js 应用更流畅地部署至 Cloudflare Workers。

📝 详细摘要

Cloudflare 发布了适用于 OpenNext 的 Cloudflare 适配器 1.0.0-beta 版本，该适配器旨在替代基于 Cloudflare Pages 的 Next.js 部署方案（Next on Pages），将 Next.js 应用程序转换为可在 Cloudflare 基础设施上运行的优化包。通过与 OpenNext 代码库集成，简化了部署流程，并支持更多 Next.js 功能，包括缓存、局部预渲染 (PPR)、中间件、App 和 Pages 路由以及图像优化。Cloudflare 正在努力增加对 Microsoft Windows 开发的全面支持，并计划在未来版本中支持 Edge 运行时和可组合缓存等功能。

💡 主要观点

  1. Cloudflare 适配器通过集成 OpenNext 支持更多 Next.js 功能 集成了缓存、局部预渲染、中间件、App 和 Pages 路由以及图像优化等功能，显著增强了 Next.js 应用程序的性能。
  2. Cloudflare 适配器简化了 Next.js 应用在 Cloudflare Workers 上的部署 开发者只需简单的命令，即可轻松地将 Next.js 应用程序部署到 Cloudflare Workers，并充分利用 Cloudflare 的全球网络优势。
  3. Cloudflare 计划在未来版本中进一步优化适配器 Cloudflare 计划在未来版本中减少构建包大小（bundle size）、提高应用程序性能，并允许多个 Workers 部署，从而进一步提升用户体验。

💬 文章金句

  • 相较于 Next on Pages，使用 Cloudflare 适配器是目前将 Next 应用部署到 Cloudflare 平台的更优选择。
  • OpenNext 是一个构建工具，旨在将 Next.js 应用程序转换为针对跨平台部署优化的软件包。
  • 随着 1.0-beta 版本的发布，我们期望大多数 Next.js 14 和 15 应用程序都能够在该平台上无缝运行。
