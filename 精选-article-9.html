OpenAI 年度发布会：Agent 平台/Sora API/第三方接入 ChatGPT/... 讲的没讲的，都在这了

10/6/2025, 9:25:00 PM

📌 一句话摘要

深度解读 OpenAI Dev Day 2025 发布会，涵盖 App Inside ChatGPT、Agent Kit、Codex 正式版及多模态 API 迭代，展现 AI 产品化与开发者生态新趋势。

📝 详细摘要

文章全面分析了 OpenAI Dev Day 2025 发布会的关键内容，核心在于“如何让人更好地用 AI 创造”及“让开发者定义人与 AI 的交互方式”。主要亮点包括：App Inside ChatGPT，作为插件系统的加强版，允许第三方应用在 ChatGPT 内部展示界面；Agent Kit，一个可视化的 Agent 工作流编辑器，包含 Agent Builder、Chat Kit 和 Evals for Agents，并与国内“扣子”平台进行对比；编程工具 Codex 正式版，基于 GPT-5 Codex 模型，支持跨平台使用，并展示了语音控制设备的强大能力。API 方面，开放了 GPT-5 Pro API、Sora 2/Pro 视频生成 API、Real-Time Mini 语音模型 API，并新增了 gpt-image-1-mini 图像生成 API，全面降低了 AI 开发门槛。此外，文章还分享了 OpenAI 用户与开发者数据增长、对开发者的表彰以及 AI 从“玩物”到“生产工具”的转变等大会亮点，并回顾了历届 DevDay 的重点，展现了 OpenAI 在推动 AI 应用和开发者生态方面的决心。

💡 主要观点

  1. App Inside ChatGPT 强化了第三方应用集成与用户交互体验 通过 Apps SDK，开发者可将应用界面直接嵌入 ChatGPT，实现更深度的功能集成和无缝的用户体验，拓展了 ChatGPT 的应用边界。
  2. Agent Kit 的发布及其与国内“扣子”平台的对比，揭示了全球 AI 开发工具链的平台化趋势 Agent Kit 提供可视化工作流编辑（Agent Builder）、简化集成（Chat Kit）和提升可靠性（Evals for Agents），显著降低了 AI Agent 的开发与评估门槛。文章将其与国内“扣子”等平台进行对比，强调了 Agent 平台化和低代码/无代码开发在全球 AI 生态中的趋同性与竞争，预示着 Agent 将成为 AI 应用开发的主流范式。
  3. Codex 正式版与新 API 开放推动 AI 成为核心开发工具 Codex 在编程辅助上达到新高度，GPT-5 Pro、Sora 2、Real-Time Mini 等 API 的发布，使开发者能更便捷地构建多模态 AI 应用，加速 AI 在各行业的落地。
  4. OpenAI 用户与开发者生态快速扩张，AI 正从工具走向生产力 Sam Altman 展示的惊人增长数据，以及 AI 从“研究试验”到“日常生产工具”的转变，预示着 AI 已成为驱动创新和效率提升的核心力量。
