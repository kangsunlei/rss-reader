找刚入职 Manus 的余一聊感受：好快乐啊，好快乐啊，好快乐啊

10/28/2026, 11:19:07 AM

📌 一句话摘要

刚入职 Manus 的余一复盘自己离开腾讯研究院的动因，并讲清「只跟一个主 agent 说话、100% 委托」、AI 原生组织的协作机制和「先开荒再降本」的具体做法。

📝 详细摘要

余一在三天内完成「鹅厂下线、Manus 上线」，本期是她换身份后的返场。她说离开腾讯研究院和两年前转岗研究院是同一句话：「我越来越难以忍受自己是一个旁观者的状态」——超级个体阶段该试的都试过，事情都能做但会累死、也做不好，她更想加入一个彼此信任、同频的团队，去解「人—agent—人—agent」四个主体怎么协作。 工作方式上，她给 Slack、邮箱、X、Notion 等信息源各配一个监控 bot，让它们在一个群里汇报，自己只跟主 agent「AI 余一」说话，由它验收和分派：「凡是他想自己干我就骂他。」主 agent 是幕僚长而不是执行者，这正是 90% 与 100% 委托的差别。她形容 Manus 是 AI 原生组织：所有人都是 AI 重度用户、不必再互相说服；反馈进 Slack 后由 AI 定级、@ 该处理的人、翻出历史上被提过几次；入职先跟内部 bot 聊最近在开什么会、项目进展、组织关系和该找谁。机器人由少数人围绕业务统一建设，而不是人人自建一堆。 她还讲了「先开荒再降本」：先用 Manus 验证一件事能不能做、值不值得做，跑通后再换 Claude Code 或更便宜的模型。一位物业出身的老板用它接海康威视做出巡店系统，回答成本问题时说「不是多少钱的问题，是我根本不会做的问题」。她主张「没有 personal agent，只有 agents」，agent 该有电脑、邮箱、银行卡、知识库和定期清理的记忆；人类剩下的工作是帮 AI 对齐——写清什么叫好、什么叫验收。她计划把攒了一年的 harness 全部移走，用最强模型重跑，并分享了先看作品、再看与 AI 协作过程的招聘标准。

💡 主要观点

  1. 离开腾讯研究院的核心动因不是平台不好，而是「难以忍受旁观者状态」：超级个体能做的都做过了，剩下的问题是团队与协作。 同一个句子两年前把她送进研究院，如今又把她送出来。她观察到今年下半年身边做超级个体的人陆续从膨胀中冷静下来：事情确实都能自己做，但会累死，而且做得多不等于做得好。她更想进入一个彼此信任、目标契合的团队，去探索人、agent 四个主体之间的 action space 与协作关系。
  2. 委托的价值分水岭在 100% 而不是 90%：只跟一个主 agent 对话，让它当幕僚长调度一群 bot。 她用 Claude Code、Codex 时仍要「看一会儿，盯一会儿」，自己始终是那个卡点；现在是每个信息源配一个监控 bot，bot 在一个群里汇报，由主 agent「AI 余一」验收和分派，「凡是他想自己干我就骂他」。她认为产品差异很大程度在 agent 如何跟人沟通、如何向上管理、如何照顾人的带宽；把代码输出分段堆给人看的产品，只会让人换一个地方继续读一大坨信息。
  3. AI 原生组织不是口号，而是 Slack + Notion + AI 调度员的具体机制，机器人由少数人围绕业务统一建设。 反馈进 Slack 后由 AI 定级、@ 该处理的人、翻出这个问题历史上被提过几次；入职时她先跟内部 bot 聊最近在开什么会、项目进展、组织关系和该找谁。她强调不是人人自建 agent，那样组织复杂度会失控；AI 的定位是减少摩擦和负担，人仍然是主体。办公区像「客服区」，所有人都在说话、都在 vibe coding，PRD 的作用被大幅弱化，产品、运营、市场都在自己写代码再让开发审一遍。
  4. 用 AI 的实用策略是「先开荒再降本」：容错率高的事情把 ABCD 全丢到市场上验证，不在 2%、3% 的差别上死磕。 一位做物业管理、没有计算机背景的老板用 Manus 接海康威视做出巡店系统，所有门店在用；问他做这个要多少钱，答案是「不是多少钱的问题，是我根本不会做的问题」。她自己的习惯也是如此：先用 Manus 快速判断能不能做，跑通后再换 Claude Code 或更便宜的模型，或请 IT 做成内部平台。她对 AI 的下限要求很低，「只要能帮我 5% 就很开心」，看开一点，空间就大了。
  5. agent 应被当作「主体」而不是工具，人类剩下的工作是帮 AI 对齐——写清什么叫好、什么叫验收。 她说没有 personal agent，只有 agents：一个主体该有电脑、手机、电话、银行卡、技能、知识库，还要时不时清理自己的记忆，它不该跟你抢资源，它跟你是合作关系。随着工程性工作被 AI 接管，她反而花更多时间打磨那句「一句话顶一万句话」的提示词，例如「所有的特效都是要配合讲解的内容和情绪」。她打算把攒了一年的 harness 全部移走、用最强模型重跑一遍，让 AI 自证哪些该留；招聘上先看作品，再看与 AI 一起 build 的过程，给候选人积分让他一两天做出个东西。
