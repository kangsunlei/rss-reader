一文搞懂个人 AI 记忆系统构建全流程

8/27/2026, 12:45:00 AM

📌 一句话摘要

作者基于半年实践构建了一套跨 AI 工具通用的个人记忆系统，通过五层记忆架构、两级目录、权重绑定、YAML 元数据、双层索引及 recall/curator 两个 skill，实现了身份、原则、偏好、上下文、知识的持久化与按需调用，让 AI 从执行工具进化为具备主动判断力的协作伙伴。

📝 详细摘要

文章详细介绍了一个可落地的个人 AI 记忆系统全流程设计。核心痛点是：在不同 AI 工具间切换时需重复同步个人信息，且经验沉淀绑定在特定工具中无法复用。解决方案包含：1) 五层记忆架构——identity/principles/preferences/context/knowledge，分别回答“我是谁、我如何判断、我希望怎么协作、我正在做什么、我有哪些可复用能力”；2) 两级目录强制扁平化，配合冲突解决规则（按信息来源/用途分类、区分稳定层与动态层）；3) 五级权重（L1-L5）绑定目录而非字段，冲突时高等级优先但保留用户最终决策权；4) 7 字段 YAML frontmatter（type/title/description/status/privacy/tags/timestamp）参考 Google OKF 精简而来，解决 AI 高效检索与调用判断；5) 实战案例：context/relationships/ 维护组织协作关系索引，AI 能主动提醒干系人对齐；6) 双层索引机制：总索引 INDEX.md 存 title+description，子目录 README.md 说明收纳规则，AI 先扫索引按需加载；7) 两个跨平台 skill：personal-memory-recall 按任务类型路由加载相关记忆（L1→L5 顺序），personal-memory-curator 从对话提取候选经我确认后按 README 路由写入并同步索引，单条单 commit 可追溯。作者强调刻意保留人工确认环节，避免自动沉淀把“当下不成熟的判断”固化。半年实践显示切换工具摩擦近零、经验复利显现、AI 从执行者变协作伙伴。后续计划引入自动识别高频经验升级为技能、冲突与过期自动检测。

💡 主要观点

  1. 五层记忆架构将个人信息结构化为身份、原则、偏好、上下文、知识，解决跨 AI 工具的上下文丢失与重复同步问题 每层对应一个核心问题，identity/principles 为稳定层，preferences/context/knowledge 为动态层，分层设计使 AI 能快速理解用户核心画像与当前任务所需上下文，避免把易变信息误判为长期身份。
  2. 两级目录强制扁平化 + 权重绑定目录 + 冲突解决规则，平衡检索效率与维护成本 禁止三级目录避免分类迷宫，权重 L1-L5 绑定目录而非文件字段，冲突时高等级优先但保留用户决策权。冲突解决规则覆盖灰色地带（如价值判断进 principles、操作步骤进 skills、有日期事件进 experiences、无时间绑定方法进 skills、外部输入进 learnings、内化提炼进 skills），并提供经验→技能→原则的升级路径。
  3. 7 字段 YAML frontmatter 与双层索引（INDEX.md + README.md）实现 AI 按需加载、不全量阅读 frontmatter 含 type/title/description/status/privacy/tags/timestamp，每字段解决一个实际问题（如 description 判断是否读正文、privacy 控制敏感信息外泄、tags 弥补单一目录维度）。INDEX.md 作为全库地图存 title+description，README.md 说明目录收纳规则，新 AI 接入即读 README 快速上手。
  4. 两个跨平台 skill 形成使用-维护闭环：recall 按任务路由加载，curator 从对话提取经确认写入 recall 读 README 路由表匹配任务信号→扫 INDEX description 筛文件→按 L1→L5 权重加载；curator 先读 README 路由权威→提取候选→用户确认→提炼属性→路由定位→输出决策报告含排除理由→用户批准→写入文件+同步 INDEX+单条单 commit。任意支持 skill 的 AI 工具均可参与维护，打破工具绑定。
  5. 刻意保留人工确认环节，拒绝全自动沉淀，确保记忆库存储的是“更好版本的我”而非“当下版本的我” 作者认为全自动会把临时、不成熟的判断固化进记忆库，久而久之反而困住自己。每条写入前需用户确认提取准确性与路由决策，体现对记忆质量的长期主义把控。

💬 文章金句

  • 能不能无论我用哪个 AI，他都能快速知道我是谁、我在做什么、我怎么判断、我希望他怎么和我协作、并且这些信息还能自动更新同步……最关键的是，这些信息要属于我并且归我管，而不是绑定在某个工具上。
  • 深目录会稀释判断。路径每深一层，AI（和我自己）定位一条记忆要做的选择就翻倍。两级封顶，任何一条记忆最多两次选择就能定位。
  • 权重等级不作为独立字段写入每个文件，而是和目录绑定，即一个内容所在的目录，决定了它的权重。
  • 这份文档的价值不在于「存了谁是谁」，而在于 AI 能在正确的时机，把正确的人从我的记忆里「捞」出来，摆在我面前。
  • 我故意没把记忆维护做成全自动。每一条记忆写入前都要我确认。不是做不到——是我希望记忆库里维护的是「更好版本的我」，而不是「现在版本的我」。
