Hy-Memory 发布：打造记忆力超强的 Agent 第二大脑

5/28/2026, 2:07:00 PM

📌 一句话摘要

腾讯混元发布 Hy-Memory，一个专为 Openclaw Agent 设计的记忆插件，通过 6 层记忆框架、System1/System2 双系统和演化链机制，解决长期协作场景下的记忆碎片化、信息丢失和认知迭代问题。

📝 详细摘要

本文由腾讯混元官方发布，正式推出 Hy-Memory，这是一个为 Openclaw 等长期协作型 Agent 设计的记忆插件。文章首先指出了 Agent 长期使用中的典型痛点：用户在使用 Agent 三周后，会因记忆丢失导致体验从「能陪你思考的伙伴」降级为「查询工具」。Hy-Memory 的核心设计围绕三层底牌展开：第一层是 6 层记忆框架，将事实、画像、心智模型、前瞻意图等不同形态的记忆分层存储，避免传统系统「一锅捞」的混乱；第二层是 System1/System2 双系统设计，System1 负责实时写入（毫秒级），System2 在后台进行深度认知加工（秒到分钟级），兼顾速度与认知深度；第三层是演化链机制，通过 supersedes 指针将新旧记忆串联成链，确保 Agent 能回溯用户偏好的完整演变路径，而非仅记住最新状态或丢失关键因果。文章还提供了在 LongMemEval 和 PersonaMem 权威评测集上的数据，显示 Hy-Memory 在偏好、时序推理、知识更新等维度显著领先同类框架，同时具备更高的记忆密度和更快的写入速度。最后给出了快速安装指南和 Lite/Pro/Ultra 三档配置建议。

💡 主要观点

  1. Agent 长期使用存在「三周轨迹」痛点，记忆丢失导致体验降级。 用户在使用 Agent 第一周体验最佳，第二周开始发现 Agent 记不住跨天判断，第三周主动降级为仅查询简单问题，从协作伙伴沦为工具。
  2. Hy-Memory 采用 6 层记忆框架，按信息形态分层存储。 将事实、画像、心智模型、前瞻意图等不同形态的记忆分层管理，避免传统系统将所有信息混为一谈，使检索更精准，prompt 更干净。
  3. System1/System2 双系统设计兼顾实时响应与深度认知。 System1 在用户回车后毫秒级写入立即可用记忆，System2 在后台秒到分钟级抽心智模型、构建知识网络，实现越用越懂的效果。
  4. 演化链机制通过 supersedes 指针保留记忆演变因果。 新记忆写入时通过指针指向旧记忆形成链，搜索命中链头时自动展开整条链，让 Agent 理解用户偏好的完整演变路径，避免推荐已踩过的坑。
  5. 在权威评测集上效果显著，且具备更高记忆密度和写入速度。 在 LongMemEval 和 PersonaMem 上得分领先，记忆条数减少 70%+，单条信息密度高 45%+，写入速度是 Graphiti 的 8 倍，token 消耗降低 35%。

💬 文章金句

  • Hy-Memory 用 6 层记忆框架 × System1/System2 双系统 × 演化链三层底牌，让 Agent 在长期使用中真正「记得住、记得对、记得轻、更懂你」。
  • 最常见的结局是，Openclaw 在使用者眼里，慢慢从「能陪你思考的伙伴」，降级成了「一个查询工具」。
  • Hy-Memory 把来自人脑认知科学的 System1 / System2 机制直接复刻到了 Agent 的记忆加工上——就像给 Openclaw 装了一颗符合认知科学的「大脑」。
  • 这个回答的质量，不是来自模型本身，是来自记忆结构。
  • 最新的判断在最前面（链头），但被否过的、被替代的、被废弃的旧版本不会丢——只是退到链身后面，需要时随时展开。
