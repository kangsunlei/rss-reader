我写了个 Skill，让 Agent 自动给文章配图

1/15/2026, 12:00:00 AM

📌 一句话摘要

作者分享了如何设计并实现一个 Agent Skill，使其能够自动化地分析文章、选择风格、生成图像并插入文章，从而解放作者从繁琐的配图工作中，并深入探讨了 Agent Skills 的设计理念和应用价值。

📝 详细摘要

文章详细介绍了作者如何设计并实现一个名为“文章配图”的 Agent Skill，该 Skill 能够自动分析文章内容，识别需要配图的位置，智能选择插画风格，生成图像提示词，并调用图像生成工具生成图片，最终将图片插入到文章的对应位置。作者强调了 Agent Skills 在工作流程自动化中的强大作用，将其比喻为 Agent 的“入职培训手册”，并详细解释了 SKILL.md 文件的构成、提示词模板设计以及整个工作流程。文章旨在向读者普及 Agent Skills 的概念及其在提高效率、自动化重复性工作方面的潜力，鼓励开发者将自己的工作流程抽象为 Skill。

💡 主要观点

  1. Agent Skills 提供了一种将领域知识和工作流程“教”给 AI Agent 的方式。 Agent Skills 类似于“入职培训手册”，允许开发者将复杂的业务逻辑、工具使用方法等封装成可供 Agent 按需调用的模块，从而实现 Agent 的专业化和自动化能力拓展。
  2. 文章配图 Skill 通过拆解复杂任务，实现了从内容分析到图片生成的全自动化流程。 该 Skill 将配图任务拆分为分析文章结构、匹配插画风格、生成提示词、调用图像生成和插入图片五个核心步骤，实现了从文字到图文并茂的自动化转换，大幅提升效率。
  3. Agent Skills 采用渐进式加载机制，有效管理上下文限制并提升扩展性。 Agent 仅在需要时加载 Skill 的详细内容，并在使用后“忘记”，允许开发者安装大量 Skill 而不会超出大型语言模型的上下文窗口限制，并支持 Skill 间的相互调用，实现能力组合。
  4. SKILL.md 文件是 Agent Skill 的核心，包含元信息和详细指令。 SKILL.md 文件分为头部元信息（名称、简介）和正文指令（风格库、自动选择规则、工作流程、文件管理规范），使 Agent 能够理解何时调用及如何执行特定任务。
  5. 自定义提示词模板和预设风格库对于确保生成内容的一致性和高质量至关重要。 通过分离通用图像生成约束和具体内容提示，以及预设多种插画风格，该 Skill 在保证图片质量、风格一致性的同时，也提供了灵活性和可控性。

💬 文章金句

  • 把文章丢给它，它自己分析哪里需要图、应该画什么风格、然后一张张生成并插入对应位置。整个过程我只需要一句话："给这篇文章配图。"
  • Agent Skills 就是一份"入职培训手册"------你把这些知识写下来，Agent 需要的时候自己翻阅，不需要你反复交代。
  • Agent 启动时只记住它的名字和简介（大概 100 个 token），真正用到时才去读详细内容，用完就可以"忘掉"。
  • 图像生成的约束条件是通用的，而具体内容是变化的。把通用部分抽出来，既减少重复，也方便统一调整。
  • Agent Skills 是个被低估的功能。很多人还停留在"和 AI 聊天"的阶段，没意识到可以把自己的工作流程、领域知识"教"给它，让它变成真正懂你业务的助手。
