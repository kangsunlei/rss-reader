对话 xLean 薛轲翰：扫地机产品远没有到头，清洁机器人可以是 Family Agent 的起点

9/15/2026, 3:00:00 AM

📌 一句话摘要

xLean 创始人薛轲翰分享其双形态洗地机器人 TR1 的产品逻辑：以高频刚需的家庭清洁为切入点，通过手持模式采集高密度示范数据实现清洁闭环，并以此为底座构建模块化扩展的 Family Agent 生态。

📝 详细摘要

本文是 Founder Park 对 xLean 颗粒进化创始人薛轲翰的深度访谈。xLean 推出全球首款双形态洗地机器人 TR1，既能自主清洁，又能变身手持洗地机。薛轲翰指出，传统扫地机处于「开环」状态，而 TR1 通过用户手持操作收集高密度的「识别、策略、结果」示范数据，训练机器人实现「清洁闭环」。xLean 的终极愿景是通用家庭机器人，但他们选择不走纯人形路线，而是将清洁机器人作为可移动、可感知的智能底座，通过统一协议（PAI）和 Agent 编排系统（EvoMate™ OS）接入空气净化、巡检、机械臂等长尾模块，逐步构建 Family Agent 生态。文章还深入探讨了软硬件工程挑战、量产交付、出海众筹、团队建设以及与传统厂商和具身智能公司的竞争策略。

💡 主要观点

  1. 真正的通用家庭机器人不会从实验室直接诞生，必须从高频刚需的真实场景（家庭清洁）切入积累数据 薛轲翰认为，清洁机器人是目前唯一大规模进入家庭并每天自主工作的品类。xLean 选择清洁作为起点，旨在通过具体任务跑通数据、算法和硬件的 pipeline，而非直接研发技术尚未成熟、缺乏真实场景数据的通用人形机器人。
  2. 双形态设计不仅是消费卖点，更是高密度、高价值清洁示范数据的天然筛选器 传统扫地机自动运行时的有效脏污数据密度极低。TR1 的双形态设计允许用户在处理即时重污时手持使用，这自然地记录了人类的「识别、策略、结果」示范数据（类似特斯拉的 Shadow Mode），解决了机器人端到端学习中 Corner Case 数据匮乏的难题。
  3. 清洁机器人只是移动底座，其终局是承载模块化扩展的 Family Agent 生态 家庭场景中并非所有任务都需要双足人形，一个会移动、会清洁的底盘是刚需。xLean 将 TR1 设计为开放底座，通过统一的协议层和 EvoMate™ OS 编排系统，利用大模型（如 DeepSeek）的 Agent 能力，让用户能用自然语言调用和组合空气净化、巡检、甚至未来机械臂等长尾硬件模块。
  4. 传统扫地机厂商受限于组织固化和旧技术栈，给创新型初创公司留下了利用新算法范式破局的窗口期 传统厂商长期依赖 rule-based 技术栈，且陷入价格战和同质化竞争，甚至砍掉高端传感器限制了智能上限。xLean 引入强化学习和 learning-based pipeline 解决底层算法，并通过智驾人才搭建数据回流 infra，构建起算法与数据的动态壁垒。

💬 文章金句

  • 一个消费电子产品在场景里从开环变成闭环，就是质变。
  • 双形态对消费者是卖点，对技术来说是天然的数据筛选器。
  • 打败清洁机器人的，很难只是一个更好的清洁机器人。
  • 通用家庭机器人未必是人形，这条路不在市场共识里。
