效果全面超越 Claude Design！天工设计智能体一句话出整套 UI 设计图

6/17/2026, 10:00:00 AM

📌 一句话摘要

本文评测天工设计智能体，展示其通过一句话生成完整、可修改的 UI 设计项目的能力，并称其效果全面超越 Claude Design。

📝 详细摘要

文章以产品评测的形式，介绍昆仑万维旗下「天工设计智能体」的新功能。作者从设计师视角，通过两个具体案例（搭建插画师作品集官网、基于千里江山图风格生成旅游 APP UI）展示了该工具的核心能力：输入自然语言需求即可生成包含多页面、设计规范、交互逻辑的完整 UI 项目，支持在画布上通过指令进行迭代修改，并具备移动端适配、深度编辑、导出为.fig 文件或直接上线等功能。文章将天工设计智能体定位为「国内版 Claude Design」，并强调其与 AI 生图工具的本质区别在于生成的是可长期维护的项目而非单张图片。

💡 主要观点

  1. 天工设计智能体可一句话生成完整的 UI 设计项目。 用户输入自然语言需求，工具即可生成包含多页面、设计规范、交互逻辑的完整项目，而非单张效果图，并自动完成移动端适配。
  2. 支持基于参考图生成风格统一的 APP 界面。 用户上传一张风格参考图，智能体能自动延伸出完整的 APP 设计规范，并生成视觉风格高度统一的多个核心页面。
  3. 项目可在画布上通过指令进行迭代修改。 所有修改在原项目上同步进行，组件风格与页面逻辑全程统一，避免了每次修改都重新生成的割裂感。
  4. 支持导出为.fig 文件或直接上线为可分享的网站。 设计稿可导出为图片或 Figma 文件，也可一键生成原型，将设计转换为可直接使用的网站。

💬 文章金句

  • 生成的不是一张张独立的图片，而是一个完整的 UI 项目。所有修改都在原项目上迭代生长，而不是每次都从零开始重新生成。
  • 本质上，它不是又一个和传统设计工具抢存量的 AI 作图插件，而是打开了一个全新的增量市场：让所有有想法的人，都能低成本把创意落地成可用的 UI 项目！
