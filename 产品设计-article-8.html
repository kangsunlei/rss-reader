微信 AI 团队开源 WeKnora：给知识库装上“手脚”，AI 从能答到能做

9/18/2026, 10:02:43 AM

📌 一句话摘要

腾讯开源的 WeKnora 0.8.0 框架通过引入持久化运行时沙箱、多格式文档解析及 Wiki 模式，将知识库从单一问答工具升级为支持多步推理、工具调用与产物生成的知识工作台。

📝 详细摘要

WeKnora 是腾讯开源的一套基于大语言模型的知识管理框架，旨在解决传统 RAG 知识库在复杂文档理解、知识关联及任务执行上的局限。0.8.0 版本核心亮点在于引入了会话持久化的 Skill Sandbox Runtime，为 Agent 提供受控的工作区，支持文件读写、脚本执行与产物生成。在文档解析方面，内置 anydoc 引擎支持多种格式并保留文档结构与版本历史；在知识组织上，通过 Wiki 模式与图谱增强实现知识的可关联与可追溯；在交互上，支持跨会话长期记忆与上下文压缩。该框架采用模块化设计，兼容多种向量数据库与模型提供方，并提供 Docker 等多种部署方式，旨在让分散的文档资产转化为可推理、可执行的知识。

💡 主要观点

  1. 引入持久化运行时沙箱，实现 Agent 从「问答」到「做事」的跨越 0.8.0 版本为每个会话提供受控工作区，支持 Docker、E2B 等后端，使 Agent 能在同一环境中执行脚本、调用 Skill、读写文件并收集产物，解决了多步任务执行中的环境一致性与边界控制问题。
  2. 深度文档解析与版本化管理，确保知识资产的可追溯性 系统不仅支持多种文档格式解析，还保留了文档结构与元数据，允许用户直接编辑检索分块并自动重建索引，同时通过版本快照与差异对比功能，确保知识库内容可维护、可更新。
  3. Wiki 模式与知识图谱，提升知识的关联性与可浏览性 通过将原始文档整理为相互链接的 Markdown 页面并生成可视化图谱，改变了传统 RAG 仅返回片段的模式，让用户能沿着概念脉络探索知识，将知识库从资料夹转变为知识工作台。
  4. 模块化解耦设计，适应多样化部署与生态需求 框架将解析、向量化、检索与推理流程解耦，支持按需替换组件。同时提供多种入口（Web UI、API、Chrome 插件等）及 GitLab/IMA 等数据源同步，满足企业私有化部署与多场景集成需求。

💬 文章金句

  • 当知识库不再满足于"找答案"，腾讯开源的 WeKnora 把文档解析、知识图谱、Agent 沙箱与 Skill 生态串成一条完整链路。
  • 0.8.0 版本为每个会话提供持久化运行时，让文件读写、脚本执行与产物生成在受控工作区中完成。
  • 解析完成后，文档不会只变成一段无法回溯的文本。系统支持保留文件夹结构、管理文档元数据，并允许直接编辑检索分块。
  • Agent 不只是"会调用工具"的对话模型：它有一个可持续的工作区、一组明确来源的 Skill，以及围绕文件、环境变量和网络访问建立的运行边界。
