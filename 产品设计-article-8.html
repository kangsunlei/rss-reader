DeepSeek Harness 桌面端发布：一手体验

9/30/2026, 12:49:42 AM

📌 一句话摘要

DeepSeek 发布桌面端 Harness 工具，通过将本地文件夹作为工作区，提供资料整理、制作 PPT、代码编写及插件市场等 Agent 自动化功能。

📝 详细摘要

DeepSeek Harness 桌面端正式发布，支持 Windows 和 Mac 系统。该工具将本地文件夹定义为工作区，支持整理资料、制作 PPT、修改代码等日常办公与开发任务。核心特性包括插件市场、训练沙盒以及自动化任务。用户可以通过插件页面自定义配置环境，并支持标准、PTC、极简及创造四种模式。此外，还提供了智能体团队、自动授权审查等实验性功能。

💡 主要观点

  1. 本地文件夹工作区化设计 DeepSeek Harness 将用户指定的本地文件夹作为执行空间，能够直接读写文件、调用各种工具并完成从查资料到写代码的复杂任务。
  2. 多场景预设与功能分区 工具预置了办公（整理资料、做 PPT）和开发（改代码、排查问题）两大核心场景，并允许用户在引导阶段选择任务重点。
  3. 插件化架构与自定义扩展 提供专门的插件管理页面，用户可以通过安装 npm 包来扩展功能，并支持在“创造模式”下通过对话让模型自动编写和修改新插件。
  4. 实验性 Agent 协作能力 内置了智能体团队（多模型并行工作）和自动授权审查（在工具调用前进行模型审核）等前沿功能，探索更复杂的 AI 协作边界。
