📝 详细摘要

本文探讨了 Web 开发的演变，将过去由于浏览器不一致而过度依赖 JavaScript 的时代与当今强大且标准化的 Web 平台进行了对比。文章认为，现代开发人员可以通过利用原生 HTML、CSS 和 JavaScript 功能来显著减少第三方库的依赖。作者重点介绍了几个当前的平台功能，如 Popover API、`

` 手风琴组件、高级 CSS 语法（例如，级联层、嵌套、`:has()`）、现代 JS Array/Set 方法和容器查询，这些功能可以替代常见的 UI 组件和实用工具库。此外，它还预览了令人兴奋的即将推出的功能，如锚点定位、导航 API、视图过渡 API、滚动驱动动画、可定制的选择框，特别是 CSS Masonry。文章强调了这种方法的好处：减少代码大小、更快的执行速度、改进的可访问性和更好的性能，最终带来更具包容性的 Web 体验。详细介绍了 CSS Masonry 的功能、灵活性及其对现有 JS Masonry 库的替代潜力。

💡 主要观点

  1. 现代 Web 平台功能可以替代许多常见的 JavaScript 和 CSS 库。 浏览器现在原生支持弹出窗口、手风琴、高级 CSS 布局和实用方法等功能，从而减少外部依赖，简化开发流程。
  2. 利用原生功能可以显著提高 Web 性能和可访问性。 减少代码量并依赖优化的浏览器实现可以加快加载时间、更流畅的执行、更好的响应能力以及提升用户可访问性。
  3. 即将推出的 Web 平台功能（如 CSS Masonry）将进一步使开发人员能够原生构建复杂用户界面。 CSS Masonry、锚点定位和视图过渡 API 等功能有望简化传统上复杂的 UI 模式，从而无需广泛的自定义 JavaScript 解决方案。
  4. 了解 Web 平台为负责任的工程师提供了竞争优势。 及时了解原生浏览器功能，有助于开发者构建更高效、弹性且易于维护的应用，更好地适应不同设备和网络环境。

💬 文章金句

  • 学习理解和使用当今的 Web 平台使您比其他开发人员具有巨大的优势。
  • 不要立即抛弃所有你喜欢的库并重写代码。 还需要考虑浏览器兼容性以及项目本身的特殊性。
  • 主要的好处是你最终向客户的设备发送的代码要少得多。
  • Masonry 是一种布局，多年前因 Pinterest 而流行。它创建了独立的内容轨道，其中的项目尽可能靠近轨道起点地将自己堆叠起来。
  • CSS Masonry 能够实现 flex、grid 等传统 CSS 布局方案难以实现的复杂布局。
