Opus 5.5 生成视频的「预制菜」感分析

9/28/2026, 3:51:26 PM

📌 一句话摘要

作者通过用 GitHub 仓库让 Opus 5.5 生成宣传视频，认为其产出虽然质量高但缺乏灵魂，像是一种「AI 预制菜」。

📝 详细摘要

作者尝试使用当前流行的玩法，将 GitHub 仓库输入给 Opus 5.5 以生成产品宣传视频。评价认为结果虽然质量较高，不属于低质内容（slop），但风格高度同质化，缺乏独特性，将其比作给中产阶级消费的「AI 预制菜」。

💡 主要观点

  1. 生成内容高质量但同质化 Opus 5.5 在执行 GitHub 仓库转视频的任务时，能够产出视觉质量较高的内容，但不同案例之间的「味道」一致，缺乏创意差异。
  2. AI 内容的「预制菜」化 这种精致但标准化的产出被作者定义为「AI 预制菜」，暗示当前 AI 生成视频在满足基础美学的同时，难以突破模版化的限制。

💬 文章金句

  • 感觉味道都一样
  • 看似精致，给中产吃的 AI 预制菜
