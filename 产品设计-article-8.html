小屏幕，大作为：为功能手机开发 Web 应用的被遗忘的艺术 — Smashing Magazine

7/16/2025, 3:00:00 PM

📌 一句话摘要

功能手机市场潜力巨大，却常被忽视：本文探讨如何使用标准 Web 技术为功能手机构建 Web 应用。

📝 详细摘要

文章强调，功能手机，或称非智能手机，远未过时，每年销量超过 2 亿部，尤其是在南亚和非洲，是用户经济实惠的上网选择。文章认为，由于自然增长潜力、品牌推广机遇和竞争优势，为该市场开发 Web 应用是有意义的。从技术上讲，现代功能手机越来越多地支持 Web 技术（HTML、CSS、JavaScript），而不是原生运行时，类似于渐进式 Web 应用 (PWA)。文章深入探讨了硬件限制、性能考虑（特别是对于像 Opera Mini 和云手机这样的远程浏览器）和安全性。至关重要的是，它强调了小屏幕的独特设计原则，提倡简化而不是“缩放适配”，并优先考虑键盘导航。它还建议尽量减少用户输入，提倡数字输入、SSO 和语音搜索等无需过多输入的设计。最后，它讨论了基于 Web 的平台（如云手机、KaiOS 和 Opera Mini）的碎片化生态系统，每个平台都有其独特的特征。

💡 主要观点

  1. 功能手机代表着一个潜力巨大的蓝海市场。 尽管存在常见误解，功能手机年销量仍达数百万部，尤其是在新兴经济体，由于应用商店竞争低，为开发者提供了自然增长和品牌推广的优势。
  2. 现代功能手机应用开发利用了标准的 Web 技术。 像 KaiOS 和云手机这样的平台已经转向 HTML、CSS 和 JavaScript，降低了 Web 开发者的入门门槛，从而实现了类似 PWA 的体验。
  3. 为功能手机设计需要特定的 UI/UX 调整。 开发者必须优先考虑简化，避免为不同尺寸小屏幕采用简单“缩放适配”设计，并确保强大的键盘导航，同时通过数字输入或语音搜索来最大限度地减少用户输入。

💬 文章金句

  • 功能手机并没有消亡。相反，每年售出超过 2 亿部非智能手机。
  • 如今，功能手机平台已经放弃了原生运行时，转而支持标准的 Web 技术，以降低入门门槛并吸引更广泛的软件开发者。
  • 小屏幕的可用性需要独特的设计考虑——而不是简单缩放适配。
  • 无论你做什么，都不要让功能手机用户打字！
  • 为功能手机开发 Web 应用的另一个挑战是其碎片化的生态系统。
