开源一个 commands 帮你深度拆解顶尖 Skills

5/7/2026, 11:45:00 PM

📌 一句话摘要

本文开源了一个名为 /howSkills 的 Claude Code 命令，可自动从产品视角深度拆解任意 Agent Skill，并通过对 hatch-pet 宠物的拆解案例，提炼了多个可迁移的最佳设计模式。

📝 详细摘要

文章是作者继 /howPrompt 之后开源的第二个指令 /howSkills，旨在帮助产品经理和技术从业者深度拆解 Agent 生态中的 Skills。该命令能自动完成结构扫描、痛点挖掘、工作流可视化、脚本设计拆解等 8 个阶段的分析，输出详细的产品分析报告。作者通过拆解 Codex 中一个创建动画桌面宠物的复杂 Skill（hatch-pet），展示了该命令的实际效果。hatch-pet 通过 15 个脚本、3 个参考文档和 323 行指令，将充满不确定性的图像生成任务转化为确定性生产流水线。文章重点提炼了身份锚点模式、确定性-不确定性分离、渐进式验证、JSON 中间态和写边界隔离等 5 条可迁移的最佳实践。最后提供了 /howSkills 的配置方法和使用方式。

💡 主要观点

  1. 开源 /howSkills 命令，可自动深度拆解任意 Agent Skill。 该命令能自动完成 8 个阶段的深度分析，包括结构扫描、痛点挖掘、工作流可视化、脚本设计拆解等，输出几千字的产品分析报告，帮助从业者学习设计巧思。
  2. 通过拆解 hatch-pet 案例，展示了将不确定性任务转化为确定性流程的设计思路。 hatch-pet 使用 15 个脚本和 323 行指令，通过身份锚点、色度键自适应、镜像决策门控和渐进式验证等设计，解决了图像生成不确定性与精灵图精确性之间的矛盾。
  3. 提炼了 5 条可迁移的 Agent 设计最佳实践。 包括身份锚点模式（视觉锚点比文字描述更可靠）、确定性-不确定性分离（Agent 做决策，脚本做计算）、渐进式验证（关键节点设验证点）、JSON 中间态（文件持久化比上下文更可靠）和写边界隔离（子代理模式中明确写入权限）。

💬 文章金句

  • Skills 才是现在最值得学的东西。
  • 一个好的 Skill，背后是一整套产品设计思维。
  • Agent 不再'画宠物'，而是'组装宠物'。
  • 把'一致性'从文字层面提升到视觉层面。简单粗暴，极其有效。
  • 确定性-不确定性分离：Agent 做创意决策，脚本做精确计算，各司其职。
