贾维斯 Personal Agent 集成 Todo list，实现主动任务预研

11/17/2026, 1:33:44 AM

📌 一句话摘要

作者分享将内网自研 AI 助手贾维斯接入待办清单，实现自动查询、筛选高置信度任务并生成「开工侦查报告」，类比 Personal Agent 的 Pro-Active 功能。

📝 详细摘要

作者通过内网自研的贾维斯 AI 助手，成功接入滴答清单（Todo list），配置后贾维斯可在空闲时自动查询用户待办事项，筛选出具备上下文、置信度高且可完成的任务，进行初步的预研。每天清晨，作者会收到来自飞书的「开工侦查报告」，甚至包含半成品结果。这一实践被作者称得益于 Personal Agent 在媒体通稿中所强调的 Pro-Active 能力，作者认为这一功能提升了贾维斯的实用价值，甚至感叹其估值“涨了 2 块钱”。

💡 主要观点

  1. 贾维斯实现了对待办清单的主动检索与任务筛选 贾维斯可在空闲时自动查阅 Todo list，依据上下文和置信度选取高概率可完成的任务，执行初步的预研工作。
  2. 生成「开工侦查报告」提升日常工作效率 每天清晨通过飞书收到包含已完成或半完成的任务分析报告，能提前了解任务可行性，减少重复沟通。
  3. 将 Personal Agent 的 Pro-Active 能力落地到个人生产场景 作者通过自研系统验证了 AI Agent 从被动响应转向主动推进的商业想象，形成可复制的工作流程。

💬 文章金句

  • 我把内网自研的贾维斯接入了 Todo list（滴答清单），让它在空闲没事的时候，自己查一下我的待办事项，找出它有上下文的、能搞定的、置信度高的任务，自己先替我做一波预研。
  • 于是现在每天起床，我都能在飞书上收到一波「开工侦查报告」，甚至（半）成品。
  • 这是不是就是媒体通稿里 Personal Agent 在吹的 Pro-Active 呀。
