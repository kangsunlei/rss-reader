马化腾点赞的 Agent，正是“挂羊头卖狗肉”的 AI 泡沫本身

10/22/2025, 11:45:00 PM

📌 一句话摘要

文章深度剖析了 AI Agent 的“泡沫”现象，指出通用 Agent 的根本缺陷在于工程、资本和创业环境，并强调垂直 Agent 的务实价值。

📝 详细摘要

文章对当前 AI Agent 领域的“泡沫”进行了批判性分析，认为通用 Agent 普遍存在功能多但不精、幻觉严重、难以解决复杂场景问题等缺陷。作者指出，Agent 的根本缺陷并非纯技术问题，而是源于工程深度不足、资本的急功近利以及国内浮躁的创业环境。文章通过引用多位行业专家的观点，并以 Manus 等产品为例，揭示了通用 Agent 被资本炒作的本质。同时，文章以医疗领域的 OpenEvidence 为例，详细阐述了垂直 Agent 如何通过聚焦单一用户、强溯源、产品化证据链和工程确定性，有效克服通用 Agent 的弊端，实现真正的行业价值，并提出“Workflow + Agent”的混合模式是未来发展方向。

💡 主要观点

  1. 通用 Agent 因缺乏场景深度和工程化支撑，普遍存在“功能多但不精”的问题。 通用 Agent 由于没有专业数据、专属工具链和深度业务绑定，难以有效解决用户复杂问题，其高估的宣传能力与实际能力存在明显落差，易沦为资本炒作工具。
  2. Agent 的根本缺陷在于工程深度、资本驱动和国内创业环境的急躁。 国内创业者为追求融资，往往急于推出通用型产品，导致无法沉下心来做数据工程和领域知识沉淀，加剧了 Agent 的“泡沫”现象。
  3. 垂直 Agent 通过聚焦特定场景和工程化方法，能有效解决通用 Agent 的痛点。 以 OpenEvidence 为例，通过锁定单一用户、强溯源、产品化证据链和工程确定性，将大模型的不确定性约束在可控范围内，从而创造实际价值。

💬 文章金句

  • Agent 的根本缺陷在工程在资本在决心。
  • 当一个 Agent 宣称能做所有事情时，它往往在任何一个领域都做不到最好；...
  • AI 应用的竞争已经从技术能力的竞争，转向了产品定义、用户体验打磨、生态整合与垂直行业知识深度的竞争，早期的红利属于在垂直领域做得无比深入的团队。
  • 通用 Agent 作为既得利益者，他们是绝不会说自己不行的，资本参与者对于他们暂时行不行不大关注，反正他们是最为了解 AI 的一批人，相较而言，他们比其他人容易成功
  • “Workflow（工作流）+ Agent”的混合模式会是一种选择，用确定的流程框架，约束不确定的 AI 决策。
