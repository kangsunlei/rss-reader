阿里大会观察：大厂从抄 Cursor 转向抄 Codex，第三方 agent 创业空间收窄

9/24/2026, 12:00:35 AM

📌 一句话摘要

作者逛阿里大会后判断，行业从抄 Cursor 转向抄 Codex，垂直 agent 同质化严重，第三方小厂难与字节、阿里竞争。

📝 详细摘要

作者在阿里大会展区逛了两天，观察到去年大厂都在抄 Cursor、今年都在抄 Codex，连鼠标厂商都做了自己的 Codex，界面和产品逻辑高度同质化。硬件产品较火，软件展台除阿里自家外人气不足，因为多是各垂直领域的 agent。作者认为字节豆包工作与阿里千问办公已优化到第一梯队水平，第三方小厂晚半年入场很难有竞争力，头部已转向 personal agent 赛道；并提到 OpenAI 的 Codex Bot 即将推出，预判明年国内大会将涌现大量 personal agent 产品。

💡 主要观点

  1. 行业模仿对象从 Cursor 转向 Codex，产品界面与逻辑高度同质化。 作者以阿里大会展商为观察样本，指出连硬件厂商都在做自己的 Codex，说明模仿已扩散到非软件公司，但缺乏新意。
  2. 第三方小厂在通用办公 agent 方向已难与字节、阿里竞争。 作者判断豆包工作与千问办公已属第一梯队，小厂入场时间晚约半年，且头部已转向 personal agent 赛道。
  3. personal agent 可能成为下一轮展台热点。 依据是 OpenAI 的 Codex Bot 即将推出，作者据此预判明年国内大会将出现大量同类产品。

💬 文章金句

  • 去年所有大厂都在抄 Cursor，今年都在抄 Codex，逛了两天阿里大会上的展商深有体会。
  • 所有公司都在抄袭 Codex 的界面和产品逻辑，但已经没什么新意了。
  • 时间节点晚了半年，人家那边已经开始卷 personal agent 赛道了。
