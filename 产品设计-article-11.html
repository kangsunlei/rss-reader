智谱 GLM-5.4 悄然上线！新增视觉能力、百万 Token 上下文，调用额度提升 50% - UIED 学习社区

11/24/2026, 8:50:37 AM

📌 一句话摘要

本文报道了智谱 AI 推出的 GLM-5.4 模型，新增视觉理解能力和百万 Token 超长上下文，并同步提升 Coding Plan 套餐使用额度 50%。

📝 详细摘要

本文聚焦于智谱 AI 于 11 月 23 日推出的 GLM-5.4 模型，这一更新不仅引入了视觉理解能力，使 AI 编程能够直接处理截图、设计稿等视觉输入，大幅提升了前端开发、UI 设计和 Vibe Coding 的实用性。同时，模型支持百万 Token 级别的上下文，为大型代码库分析和长程 Agent 任务提供了更大的信息承载能力。文章还提到，GLM-5.4 背后可能采用了 Loop Transformer 技术以提升综合编程能力，但目前尚未公开完整技术报告。此外，智谱同步调整了 Coding Plan 的套餐权益，V2、V3 及团队版用户的使用额度提升 50%，为高频开发者提供了更多使用空间。

💡 主要观点

  1. GLM-5.4 新增视觉理解能力，支持直接处理截图、设计稿等视觉输入 开发者可以将页面截图、UI 设计稿和错误界面作为参考，让模型结合视觉信息理解开发需求，减少文字描述的重复工作，尤其适用于前端开发、UI 设计和 Vibe Coding 场景。
  2. 支持百万 Token 超长上下文，提升大型项目处理能力 百万 Token 的上下文窗口为模型保留更多项目背景、历史修改记录和任务要求，对于包含多组件、复杂依赖关系的前端项目分析和长程 Agent 任务尤为重要，但实际效果仍需通过使用验证。
  3. Loop Transformer 技术可能用于提升综合编程能力 智谱官方透露 GLM-5.4 背后可能采用了 Loop Transformer 技术，通过循环计算机制进行更充分的信息处理，但目前尚未公开完整模型架构和技术报告，具体参数规模和推理成本尚不明晰。
  4. Coding Plan 套餐使用额度提升 50% V2、V3 及团队版用户使用 GLM-5.4 时，每周使用额度相比 GLM-5.3 提升至 1.5 倍，为经常使用 AI 编程工具的开发者提供了更多使用空间，但仅限于指定套餐，其他套餐和 API 价格是否下调尚未公布。

💬 文章金句

  • GLM-5.4 新增视觉能力后，为这类任务提供了更加直接的输入方式。
  • 开发者可以尝试将页面截图、UI 设计稿和错误界面作为参考，让模型结合视觉信息理解开发需求。
  • 支持百万 Token 并不等于模型拥有永久记忆，也不代表一次读取整个代码仓库就一定能够准确理解所有内容。
  • V2、V3 及团队版用户使用 GLM-5.4 时，每周使用额度相比 GLM-5.3 提升 50%。
  • AI 编程模型接下来比拼的，已经不只是会写多少代码，而是能不能看懂需求、减少返工，并把整个开发任务真正完成。
