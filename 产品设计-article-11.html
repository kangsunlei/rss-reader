📝 详细摘要

本文是该系列的第二部分，深入探讨了环境动画在网页设计中的实际应用。它将环境动画定义为微妙的、缓慢移动的细节，这些细节可以增加氛围，而不会分散人们对主要内容的注意力。作者展示了三个不同的项目：一位作曲家的网站 (Reuven Herman) 、Mike Worth 的叙事驱动网站以及一家房地产投资公司的品牌形象设计 (EPD) 。对于 Reuven Herman，诸如变形乐谱和漂移音符之类的动画使用 GSAP 创建了一种音乐纹理。Mike Worth 的网站具有动画角色和交互式光束，展示了环境运动如何与故事讲述相结合，同时利用 CSS 和 GSAP 。对于 EPD，使用 CSS 和 GSAP 的微妙的闪烁城市灯光和旋转元素有助于在保守的行业中建立独特的品牌形象。在整个示例中，本文强调了核心原则，例如缓慢、无缝的循环、分层、避免分散注意力以及对可访问性和性能的关键考虑，最后比较了 CSS 和 GSAP 在不同动画复杂性方面的应用。

💡 主要观点

  1. 环境动画通过添加微妙的氛围来增强品牌形象、个性和叙事性，而不会分散人们对核心内容的注意力。 本文通过不同的案例研究（作曲家网站、房地产投资）表明，微妙的背景运动如何增强品牌的个性和叙事性，使设计更具活力，且不会让用户感到信息过载。
  2. 在动画中采用分层和不同的时间安排可以创造深度和复杂性，使微妙的运动更具吸引力。 像 Reuven Herman 的网站这样的例子表明，以不同的速度和旋转动画不同的元素（五线谱线、音符、钢琴键）如何构建丰富的伪视差效果，从而增强氛围。
  3. CSS 和 GSAP 之间的战略选择可以实现最佳的性能和控制，从而满足不同的动画需求。 CSS 非常适合简单的重复效果（ EPD 的轮子），而 GSAP 为复杂的任务（如 Reuven 的五线谱线）和序列时间线提供高级控制。
  4. 优先考虑可访问性和性能可确保环境动画增强而不是阻碍所有用户的用户体验。 关键实践包括尊重 `prefers-reduced-motion` 设置和对纯粹的装饰元素使用 `aria-hidden`，以及针对设备性能进行优化，以确保良好的用户体验和无障碍访问。

💬 文章金句

  • 环境动画是您可能一开始不会注意到的被动运动。但是，它们以微妙的方式使设计栩栩如生。
  • 保持动画缓慢而流畅。无缝循环并避免突然变化。使用分层来构建复杂性。避免分心。考虑可访问性和性能。
  • 另一个环境动画原则是使用分层来构建复杂性。可以将其理解为声音的组合，需要考虑节奏、音调和时序的变化。
  • 在开发任何环境动画时，考虑性能至关重要，因为即使 CSS 动画是轻量级的，模糊滤镜和阴影等功能仍然会给低功耗设备带来压力。
  • 保持运动缓慢、无缝且精心设计，以便它增强设计而不是分散设计的注意力。
