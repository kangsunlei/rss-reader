iPhone 系统最激进更新来了！iOS 26 变玻璃，iPad 迎「史诗级升级」，苹果 AI「明年再说」

6/10/2025, 5:53:40 AM

📌 一句话摘要

WWDC 2025 发布激进 UI 重构 Solarium、系统全面升级 iOS 26 等，AI 融入多项功能，强调端侧能力。

📝 详细摘要

文章深度分析了苹果 WWDC 2025 大会的关键发布内容。核心是全新的 Solarium UI 设计，采用液态玻璃质感，统一了 iOS、iPadOS、macOS、watchOS 等多个操作系统的界面语言，是自 iOS 7 以来最大的一次设计升级。各系统版本号统一命名为 26。iOS 26 在 UI 变化外，带来了相机、相册、Safari 等应用改进，以及独立的游戏应用 Games。iPadOS 26 大幅提升了多任务窗口管理能力，更接近桌面体验。watchOS 26 带来了健身搭子和实时翻译等功能。visionOS 26 增强了沉浸感和对游戏设备的支持。AI（Apple Intelligence）未高调单独发布，但已深度融入电话、信息、地图、翻译、视觉智能等多个原生应用，并开放 Foundation Models Framework 等 API 供开发者集成端侧 AI 能力。文章最后探讨了 Solarium UI 可能为未来一体成型玻璃 iPhone 硬件设计铺路。

💡 主要观点

  1. Solarium UI 是核心，统一苹果全家桶界面语言 全新的液态玻璃质感 UI 跨平台应用，是 iOS 7 以来最大设计变革，预示未来产品设计方向，提升视觉统一性。
  2. 各系统版本号统一为 26，强化品牌整体性 苹果通过命名统一，呼应多系统间的整合努力，传达一致性体验，构建更强软件品牌形象。
  3. AI 以功能形式深度融入系统，低调但实用 Apple Intelligence 未独立发布，但支持实时翻译、智能筛选、通话助理等功能，强调端侧隐私和实用性。
  4. iPadOS 迎来史诗级升级，多任务体验接近 macOS 全新窗口管理系统允许自由缩放、拖拽、平铺，显著提升 iPad 生产力，不再是大号 iPhone。
  5. 推出独立游戏 App，发力游戏生态 Games 应用整合游戏中心、成就、好友社交和推荐，对标 Steam，显示苹果对游戏市场的野心。

💬 文章金句

  • 一块玻璃，意外抢走了 WWDC 上苹果 AI 的风头。
  • 整场发布会的核心，是一次 UI 层面的深度重构，也是自 iOS 7 以来跨度最大的一次设计体系升级。
  • 只要与其交互，新的 UI 都会实时响应并渲染效果。
  • AI 没有高调登场，但在 iPhone 里已经无处不在
  • Solarium 是我们设计的一个令人兴奋和美丽的新篇章，为我们产品的下一个时代以及您每天如何与他们互动奠定了基础。
