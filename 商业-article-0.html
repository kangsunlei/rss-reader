Pruna AI releases P-H3-Image: converting video model MiniMax-H3 into image generation tool

11/4/2026, 4:42:04 AM

📌 一句话摘要

Pruna AI open-sourced P-H3-Image derived from MiniMax-H3， a video-to-image model offering 5× speed， 7× size reduction， and support for 2-16MP resolution with up to 8-image editing.

📝 详细摘要

Pruna AI open-sourced P-H3-Image， an image generation and editing model rebuilt from the video model MiniMax-H3. It reduces inference steps from 50 to 8 (2.6 sec for 4MP images)， shrinks model size 7× for easier GPU deployment， and supports resolutions up to 16MP with editing using up to 8 input images. It excels at photorealism， documentary photography， film stills， and graphic styles with text. Native support included for ComfyUI and Diffusers.

💡 主要观点

  1. 5× faster generation (8 steps vs 50， 2.6 seconds for 4MP) The model accelerates inference through rebuilt diffusion schedule and transformer components， enabling rapid high-resolution image synthesis.
  2. 7× smaller model size with native ComfyUI and Diffusers support Reworked decoder and text encoder reduce file size， allowing local deployment on smaller GPUs than the original H3 video model.
  3. Supports 2-16MP resolution and 8-image editing Ideal for cinematic stills， realistic photography， and text-integrated posters， enabling high-fidelity static outputs from dynamic training.

💬 文章金句

  • Generate or edit images 5× faster， in 8 steps instead of 50. A 4 MP image takes 2.6 s instead of 12.4 s.
  • The model is 7× smaller than H3， so high-resolution images are a light download and run on a much smaller GPU.
  • It renders 2 to 16 MP and edits with up to 8 input images.
