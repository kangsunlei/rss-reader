OpenAI“杀死了”Codex，一个超级应用诞生

7/10/2026, 2:11:00 AM

📌 一句话摘要

OpenAI 发布 GPT-5.6 系列并推出统一桌面应用 ChatGPT Work 与 Sites 功能，Codex 被整合进超级应用，强调成本效率与企业级自动化。

📝 详细摘要

文章报道 OpenAI 在 2026 年 7 月 10 日正式向全球用户开放 GPT-5.6 系列模型（旗舰版 Sol、均衡版 Terra、成本效益最高的 Luna），并公布了其 API 定价与在多项基准测试中的表现：在 Agent's Last Exam 中 Sol 得分 53.6，比 Claude Fable 5 高 13.1 分且成本仅为其四分之一；在 Coding Agent Index 上 Sol 得 80 分，超越 Fable 5 且 token、耗时、成本均大幅下降。文章重点介绍了随模型同步推出的 ChatGPT 桌面应用新版，整合了 Chat、Work、Codex 三大视图，支持本地计算机使用能力、浏览器操作以及定时任务，使其能够作为「AI 数字员工」自主执行长周期项目。同时推出 Sites（公开测试版）功能，让用户可将工作成果直接生成可共享的交互式网站。文中引用了 OpenAI 首席执行官山姆·奥特曼、沃顿商学院教授伊桑·莫里克、投资人马特·舒머、科技评论家马修·伯曼以及内部测试者等多方观点，强调效率提升和成本优势是此次发布的核心价值，并展示了在英伟达、Zapier、RingCentral 等企业及 OpenAI 内部的实际应用案例。

💡 主要观点

  1. GPT-5.6 系列将重点从提升智力天花板转向成本效率，Sol 在多项基准测试中以更低成本实现显著性能领先。 例如在 Agent's Last Exam 中 Sol 得分 53.6，比 Claude Fable 5 高 13.1 分，而成本仅为其四分之一；在 Coding Agent Index 上 Sol 得 80 分，超越 Fable 5，且 token、耗时、成本均减半甚至更多。
  2. 全新 ChatGPT 桌面应用整合 Chat、Work、Codex 三大视图，具备本地计算机使用能力和定时任务，可作为 AI 数字员工自主执行长周期项目。 用户可通过桌面应用直接调用浏览器、文件系统等本地资源，设置定时任务自动抓取 Slack、Teams 等平台信息并更新文档或 PPT，实现无人值守的工作流自动化。
  3. Sites 功能让用户能够一键将工作成果转化为可共享的交互式网站，适用于实时数据看板、项目进度跟踪等轻量级场景。 用户在聊天框中输入内容即可生成专属 URL，后台会随底层数据变化自动更新网站内容，极大降低了跨团队信息同步的成本。
  4. 多位行业专家和内部测试者指出，GPT-5.6 在速度和成本上的优势使其成为企业 AI 投资的高性价比选择。 埃森·莫里克认为 Sol 适合需求不明确的迭代任务；马特·舒머称其像经过极致强化学习的精干模型；马修·伯曼称日常使用速度比 Fable 快 2–3 倍；丹·希珀则推荐将 GPT-5.6 用作 Fable 的子智能体。
