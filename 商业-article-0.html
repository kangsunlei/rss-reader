SF 计算：将计算大众化，一举解决 GPU 泡沫

4/11/2025, 7:22:56 PM

📌 一句话摘要

SF 计算 CEO Evan Conrad 分析了 GPU 市场，强调了 CoreWeave 通过长期合同取得的成功，并提出了 GPU 市场大众化的愿景。

📝 详细摘要

本文深入探讨了 GPU 市场的经济学，分析了 CoreWeave 通过获得长期合同并专注于低风险客户的成功商业模式。与 CPU 市场不同，GPU 市场的特点是对价格敏感的客户，限制了高利润软件服务的潜力。讨论延伸到 GPU 市场中各公司的定位和风险，以及潜在的未来方向，包括金融化和大众化。SF 计算旨在 GPU 拥有者和消费者之间建立流动性，实现 GPU 的广泛交易和可编程性。这类似于亚马逊 Spot 实例。SF 计算设想了一个未来，GPU 像商品一样交易，降低价格波动并促进风险管理。

💡 主要观点

  1. 长期合同和低风险客户是 GPU 市场盈利的关键。 获得长期合同可以降低风险和资本成本，从而实现盈利。
  2. GPU 市场客户对价格高度敏感。 由于 GPU 的高成本，客户愿意更换供应商以节省成本，因此很难在增值软件服务上获得高利润。
  3. SF 计算旨在通过大众化在 GPU 市场中创造流动性。 通过建立 GPU 交易平台，SF 计算希望将 GPU 大众化，降低价格波动，并为客户提供风险管理。
  4. GPU 市场大众化能够实现风险管理和金融创新。 将 GPU 视为商品可以开发期货合约等金融工具，使企业能够对冲价格波动和管理风险。

💬 文章金句

  • GPU 赚钱的最佳方式就是像 CoreWeave 那样，签订长期合同，忽略低端市场，最大化长期合同价值。
  • 它是一家银行。它是一家房地产公司。而且很难不这样做。
  • 最佳的定位是尽可能长时间地向风险最低的客户销售给风险最低的客户。然后你永远不必担心折旧，而且你赚很多钱。
  • SFC 的全部意义在于在 GPU 拥有者和消费者之间创造流动性，并使其可以广泛交易，甚至可以编程。
