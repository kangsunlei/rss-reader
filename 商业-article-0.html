Google 也布局通用 Agent 了，创业者怎么办？

5/22/2026, 12:52:00 PM

📌 一句话摘要

文章是 Founder Park 在 Google I/O 2026 后举办的线下闭门交流活动预告，核心讨论了大厂布局通用 Agent 后创业者的机会空间。

📝 详细摘要

文章是 Founder Park 在 Google I/O 2026 结束后，于加州山景城举办的一场线下闭门交流活动的预告与回顾。活动邀请了 50 多位创业公司创始人及 AI 研究员，围绕 Google 的最新发布展开讨论。核心议题包括：Gemini Omni 多模态能力从输入端扩展到输出端后，哪些模态组合能率先跑出杀手级应用；Agent 在实际产品中跑通的「最后一公里」卡点在哪；以及当大厂纷纷下场 Agent 后，创业者在垂直 Agent、Harness 层、Agent Infra 等方向还有哪些真正的机会。文章还列出了活动合作伙伴，并邀请海外读者参与后续活动。

💡 主要观点

  1. Google I/O 2026 后，Agent 成为最大叙事，大厂纷纷布局通用 Agent。 活动核心议题之一，探讨当大厂如 Google 下场 Agent 后，创业公司是否还有生存空间，以及哪些细分方向仍有创业机会。
  2. Gemini Omni 将多模态从输入端扩展到输出端，引发对杀手级应用的讨论。 活动探讨了哪些模态组合可能率先跑出商业闭环，以及哪些方向可能被过度高估，短期内难以实现商业价值。
  3. Agent 在实际产品中跑通存在「最后一公里」难题。 现场有十多位正在产品中运行 Agent 的从业者，共同探讨了 Agent 落地的关键瓶颈，如可靠性、工具调用、用户信任等。

💬 文章金句

  • Agent 是这次 I/O 最大的叙事，同样现场也来了十几位真正在产品里跑 Agent 的人，Agent 跑不通的「最后一公里」，到底卡在哪一关？
  • 当大厂们都下场 Agent 了，创业者还有机会吗？垂直 Agent、Harness 层、Agent Infra，哪里还有真正的空间？
