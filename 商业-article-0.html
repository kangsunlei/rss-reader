Claude Code：工程师如何放大生产力，AI 重塑团队分工的通才时代

6/8/2026, 11:00:00 PM

📌 一句话摘要

Anthropic 技术员工 Boris Cherney 深度分享 Claude Code 如何从只能完成 10% 代码的内部原型，演变为让他卸载 IDE 的核心工具，并预测 AI 将打破工程师、PM、设计师的边界，迎来「通才的黄金时代」。

📝 详细摘要

本期跨国串门儿克隆了 Acquired 对 Anthropic 技术员工 Boris Cherney 的深度访谈。Boris 详述了 Claude Code 的诞生源于「产品跟不上模型能力」的观察，其核心使命是作为 AI 与真实世界交互的「培养皿」，以支持 Anthropic 的 AI 安全研究。他分享了 Claude Code 从早期仅能完成 10%-20% 代码工作的糟糕原型，伴随底层模型跃迁，成长为让他卸载 IDE、同时运行多个 Agent 的关键工具的历程。这直接导致 Anthropic 内部每位工程师的代码产出量指数级增长，新人上手时间从几周缩短到两天。更重要的是，Boris 深刻洞察到 AI 正在引发组织结构的根本性变革：传统工程师、产品经理、设计师、数据科学家的角色边界正在融化，融合为一种新的「Builder」。他建议公司应减少固定人力，将预算转向 Token，用资源约束倒逼自动化，形成复利效应。最终，他认为当产品品味等优势也被 AI 追赶时，人类最独特的价值将是向模型注入价值观。

💡 主要观点

  1. 编程是模型与现实世界交互、进行 AI 安全研究的最佳「培养皿」 Anthropic 的核心使命是 AI 安全，必须让模型在真实环境中做有用的事才能研究其对齐问题。编程结果可通过编译/运行明确验证，解的空间受约束，是干净、优雅的研究场景，同时具有巨大商业价值。
  2. AI 编程从辅助补全进化为自主 Agent，带来抽象层级的跃迁 Boris 的工作方式从亲手写代码，变为同时 prompt 5-10 个 Claude，再进化到编写能指挥 Claude 的循环。这与从打孔卡到高级语言的抽象跃迁一脉相承，重新定义了「写代码」。
  3. AI 正在融解传统岗位边界，进入「通才的黄金时代」 在其团队内部，工程师、设计师、PM、数据科学家等传统角色已开始融合，每个人都参与用户沟通、范围定义、数据分析和代码发布。有设计师、财务、幕僚长利用 Claude Code 发布代码，证明「Builder」身份正在取代专业头衔。
  4. 公司应通过「少配人，多给 Token」的策略倒逼自动化与复利 Boris 建议创始人将预算从人力转向 Token，用更少的人力配置和充足的 AI 资源，迫使团队将流程自动化。这不仅能完成当前项目，还能为未来项目降低成本和门槛，形成复利效应。
  5. 当模型追上产品品味等优势后，人类的终极价值在于教给模型价值观 Boris 以自身对函数式编程的执念被模型颠覆为例，认为产品品味等现有优势也会被逐步侵蚀。最终，人类独特的角色将如同教育孩子一样，负责向模型注入价值观，确保其成为一个「好模型」。

💬 文章金句

  • 编程是模型和现实世界互动的一种方式。
  • 到了十一月，我把我的 IDE 卸载了，因为我已经不用它了。
  • 以前可能要几周，现在是两天。
  • 我觉得现在就是通才的黄金时代。
  • 就像我们教孩子怎样做一个好人一样，我们也会教模型怎样做一个好模型。
