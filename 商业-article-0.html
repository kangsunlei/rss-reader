用 ChatGPT 新功能修了张图发朋友圈，结果私信全在问怎么做到的？

3/26/2025, 5:46:38 PM

📌 一句话摘要

ChatGPT 新文生图功能在指令遵循和一致性方面表现出色，通过自然语言即可轻松实现高精度图片微调，降低了用户对 prompt 工程的依赖。

📝 详细摘要

文章评测了 OpenAI 最新发布的 ChatGPT 文生图功能。该功能在指令遵循和一致性方面表现突出，用户仅通过简单的自然语言 prompt，即可实现对图片细部的精确调整，无需额外的按钮或笔刷操作，降低了用户对 prompt 工程的依赖，提升了用户体验。文章通过多组示例展示了该功能在食物、人像、城市街景等不同场景下的应用效果，并着重强调了其在理解用户意图、快速切换生图和生文能力方面的优势。文章还对比了 ChatGPT 与 Gemini 在生图方面的表现，认为二者都展示出通过自然语言指令实现精确控制的趋势，降低了用户学习 prompt 技巧的门槛。

💡 主要观点

  1. 通过自然语言指令实现精确控制是文生图的发展趋势 降低了用户学习 prompt 技巧的门槛，使模型能更好地理解用户意图，从而优化使用体验。
  2. ChatGPT 文生图功能在指令遵循和一致性方面有突破性进展 用户可以通过简单的文字 prompt 实现高精度的图片细部微调，无需额外的操作，降低了使用门槛。
  3. ChatGPT 具备在同一会话中快速切换生图和生文的能力 模型不仅能理解单一指令，还能领悟用户潜在意图，主动询问并明确任务细节，提供更智能化的服务。

💬 文章金句

  • 一切修改只需要在会话当中进行，无需任何按钮、笔刷等额外操作。
  • 细节微调是这次更新非常大的亮点，能够准确将指令与相对应的细部关联起来，从而完成精确的局部修改。
  • 模型不仅体现在理解单一指令上，也体现在领悟用户潜在意图上，比用户「多想一步」。
