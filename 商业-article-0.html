85.和蚂蚁、千问、吉利、OPPO、vivo 的五位总裁，聊 Agent 的商业元年、漏斗与放大器

8/31/2026, 12:00:00 AM

📌 一句话摘要

五位来自蚂蚁、千问、吉利、OPPO、vivo 的总裁在支付宝生态大会上讨论 Agent 商业化元年，提出从流量漏斗到意图放大器、终端从应用入口转为意图入口、开放生态关键是利益分享与信任等核心观点。

📝 详细摘要

本期节目是主持人在支付宝 AI 生态合作伙伴大会上主持的一场闭门圆桌，邀请蚂蚁集团 CEO 韩歆毅、阿里千问事业部总裁吴嘉、吉利汽车集团首席工程技术科学家任向飞、OPPO 副总裁唐凯、vivo 副总裁周围五位嘉宾，围绕 Agent 商业化的元年议题展开讨论。核心观点包括：移动互联网流量见顶，智能体时代 AI 成为放大器而非漏斗，提升信息转化效率；终端角色从应用入口变为意图入口、感知器和多设备执行器；开放生态的挑战在于利益分享机制与信任构建，而非技术本身。圆桌还讨论了汽车从流量经济走向交付经济、跨端调用的透明与用户选择权、千万智能体催生原子级服务与智能体互联网等话题。嘉宾对 Agent 短期内带来商业爆发持乐观态度，预计明年下半年出现爆发点。

💡 主要观点

  1. 2026 年是 Agent 商业化的关键元年，核心变化是服务提供方式与组织形式发生根本改变。 吴嘉指出，AI 时代服务将极大统一到大模型为核心来提供和组织，大幅提升服务能力上限、降低使用门槛并提升执行效率。这与移动互联网时代各 APP 各自为政的服务方式形成鲜明对比。
  2. Agent 时代 AI 是放大器而非流量漏斗，能补上信息转化效率的最后环节。 韩歆毅认为智能解决的是商业中信息转化效率问题，触达、生产、履约效率已极大提升，唯独缺少智能。AI 放大个性化需求与商业机会，改变现有移动互联网流量的构成形态。
  3. 终端角色从应用入口转变为意图入口、感知器和多设备执行器。 唐凯提出终端将变成更强大的感知器、意图入口和多设备执行器，推动聚生智能演化。吴嘉补充，终端离用户更近，能持续感知用户和环境变化，不同终端各有价值，用户记住的是跨端综合助理。
  4. 开放 Agent 生态最大的挑战是利益分享机制与信任构建，而非技术本身。 韩歆毅强调开放生态需要新的收益分享机制，支付宝向能力侧下沉，构建信任、支付、安全等底层能力。唐凯分享 AHA 协议案例，说明跨端合作通过信任和推倒技术墙带来 200 万新增日活，现阶段重点是做大蛋糕而不是分利润。
  5. 汽车将从流量经济走向交付经济，车企为端到端服务负责并接受价值贡献分配。 任向飞指出汽车将变为主动服务的智慧生命体，如自动驾驶、健康识别、挂号就医形成端到端服务链，车企对最终结果负责。价值分配应依据真实价值贡献，市场会给出定价。

💬 文章金句

  • 这个变化的本质还是整个服务提供的能力，提供的过程和组织的形式发生了本质的变化。
  • 在移动互联网时代，商业的核心是 APP，是流量，是注意力的争夺。但在 agent 时代，从意图识别到端的交互闭环，当 agent 可以为我们办事，智能正在绕过移动互联网时代筑成的流量墙，构建全新不同以往的 AI 原生交互体验。
  • 总结下来，我觉得挑战不在于能力，不在于技术本身，而是在于背后的整个利益分享的这个机制。
  • 因为整个生态所有的行为，包含调用支付、交易履约，能够被记录、被追诉是非常之重要的。
  • 我觉得现在可能永远赶不上，但好处是这样的，我觉得它发生的速度有可能比我们每个人想象的都快。
