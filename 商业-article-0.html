独家专访 AirPods 团队：一只小小的耳机，如何学会追踪 50 种运动？

10/15/2025, 11:32:04 PM

📌 一句话摘要

文章独家专访苹果团队，深入揭示 AirPods Pro 3 如何利用耳道生理优势、多模态传感器融合及借鉴 LLM 训练思路，实现高精度心率监测和 50 多种运动追踪。

📝 详细摘要

文章通过对苹果感知与连接副总裁 Ron Huang 和健康感知总监 Steve Waydo 的独家专访，详细阐述了 AirPods Pro 3 在健康监测和运动追踪方面的突破性进展。文章指出，耳道因其生理结构优势（靠近颞浅动脉、血流稳定、无光线干扰）成为比手腕更理想的生理信号采集点。AirPods Pro 3 采用红外光 PPG 方案，结合 IMU 数据，通过光学信号与动态数据融合算法，实现了可媲美专业胸带的高精度心率监测。苹果将 Apple Watch 十年积累的算法“小型化”并微调应用于 AirPods，同时强调良好的耳塞贴合度是确保生理数据准确性的关键。此外，苹果借鉴大语言模型训练思路，基于 Apple Heart and Movement Study 中约 5000 万小时的真实运动数据，训练了全新的动作基础模型，使 AirPods Pro 3 能实时识别超过 50 种运动类型。文章还强调了 Apple Watch 与 AirPods Pro 3 在不同场景下的互补作用，以及苹果从声学设备到身体感知界面的产品哲学转变。

💡 主要观点

  1. 耳道是理想的生理信号采集点，AirPods Pro 3 实现高精度心率监测。 通过耳道红外光 PPG 结合 IMU 数据，利用光学信号与动态数据融合算法，AirPods Pro 3 的心率监测精度可媲美专业胸带。
  2. 苹果利用十年算法积累，实现 AirPods 心率算法的“小型化”。 将 Apple Watch 的心率算法微调并应用于空间有限的 AirPods，确保在极端条件下也能准确追踪心率。
  3. 借鉴大语言模型训练思路，通过动作基础模型识别 50 多种运动。 基于海量运动数据训练的回归模型，使 AirPods Pro 3 能理解并识别普拉提、HIIT 等多种运动类型。
  4. Apple Watch 与 AirPods Pro 3 互补，共同构建更完整的身体数字镜像。 系统能自动选择更可靠的信号源，如在力量训练中优先选择耳道数据，提升整体健康监测的准确性。
  5. AirPods 从声学器件转变为双向感知界面，体现苹果技术回归人体的产品哲学。 耳机不再仅是声音输出设备，而是能感知身体信号的入口，实现从“听世界”到“听身体”的转变。

💬 文章金句

  • 耳道，也许比手腕更懂你。
  • 耳道 PPG（光电容积描记）信号在血管分布、抗运动干扰和环境光抑制方面，优于腕部与指端。
  • 这种光学信号与动态数据融合的算法，是 AirPods Pro 3 能在运动中保持心率精度的关键。它不是单一传感器的胜利，而是多模态数据协同的结果。
  • 当用户同时佩戴 Apple Watch 和 AirPods Pro 3 时，系统会在最近 5 分钟的信号里滚动比较，并自动选择更可靠的来源。
  • 从「听世界的声音」到「听身体的声音」，这条路径延续了苹果一贯的产品哲学------技术最终要回归人的感知。
