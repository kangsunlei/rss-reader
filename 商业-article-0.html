💡 主要观点

  1. Supabase MCP 漏洞揭示 LLM 与数据库集成安全挑战 文章详细分析了 Model Context Protocol（MCP）与大型语言模型（LLM）结合时，用户输入可能被误识别为指令，导致私有 SQL 数据库泄露的风险，强调了过度权限和对用户内容盲目信任带来的新安全威胁。
  2. Git CVE-2025-48384 漏洞允许远程代码执行 通过巧妙利用 Git 配置文件中回车符的处理缺陷，攻击者可在克隆子模块时实现任意文件写入，进而执行远程代码，对使用 Git 的用户（特别是 Unix-like 平台）构成严重安全威胁，需及时更新。
  3. 美国法院推翻 FTC“点击取消”规定，凸显监管程序的重要性 联邦上诉法院因程序缺陷推翻了 FTC 旨在简化订阅取消的规定，强调了政府机构在制定法规时必须严格遵循法律程序，这对未来的商业监管实践具有指导意义，也引发了对消费者权益保护方式的讨论。
  4. Ikea 全面转向 Matter 和 Thread 标准，推动智能家居互操作性与普惠性 宜家计划推出大量基于 Matter-over-Thread 协议的智能家居设备，放弃 Zigbee，旨在简化用户体验、降低成本，并提升跨品牌兼容性，预示着智能家居行业向更开放、更易用方向发展的重要趋势。
  5. 多数“RESTful”API 未完全遵循 REST 原则，尤其缺乏 HATEOAS 文章指出，许多 API 虽自称 RESTful，但未实现 Roy Fielding 论文中强调的超媒体驱动（HATEOAS）核心约束，导致客户端与服务器紧耦合，降低了系统的可演化性，提示开发者应重新审视 REST 的真正含义和最佳实践。

💬 文章金句

  • Supabase 的 Model Context Protocol（MCP）可能导致 SQL 数据库泄露。
  • 美国法院推翻了 FTC 的"点击取消"规定，认为其制定过程存在程序缺陷，规定要求公司提供与注册服务同样简便的取消服务方式。
  • Git 的 CVE-2025-48384 漏洞通过回车符注入，攻击者可在克隆子模块时执行远程代码，用户需更新 Git 至修复版本并谨慎使用 --recursive 选项。
  • Ikea 转向 Thread 和 Matter 标准，推出 20 多款智能家居设备，取代 Zigbee 设备，支持与其他品牌设备兼容，计划于 2025 年 1 月发布。
  • 许多所谓的"RESTful"API 并不完全遵循 REST 原则，尤其在超媒体驱动（HATEOAS）方面存在不足，Fielding 的论文定义了 REST 的核心约束。
