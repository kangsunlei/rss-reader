自进化时代，强化学习可能得有一套新算法了｜Hao 好聊趋势

📌 一句话摘要

本文深入剖析了强化学习在自进化与 Agent 场景下的锐化问题，并系统梳理了 2026 年出现的多种新算法，旨在平衡能力提升与探索多样性。

📝 详细摘要

本文首先指出自进化系统中模型搜索空间狭窄的问题，并分析了强化学习（RL）在训练中导致的分布锐化现象。通过引用多篇研究，如北大论文、斯坦福的《The Invisible Leash》以及混元团队的《Low-probability Tokens Sustain Exploration》，文章解释了 RL 如何通过提高高概率路径、压低低概率路径来提升 pass@1，但同时也牺牲了答案多样性。随后，文章介绍了 2026 年出现的多种新方法，包括 IPS-GRPO、LAD、Rewarding the Rare、Vector Policy Optimization（VPO）以及基于进化策略（ES）的《Beyond the Best Guess》，这些方法试图通过调整奖励权重、优化目标或改变参数更新方式，在保持正确性的同时保留探索多样性。最后，文章强调这些方法对 Agent 任务和自进化系统的重要性，指出未来的 RL 需要为选择而生，避免过早收敛。

💡 主要观点

  1. 强化学习主要是在锐化分布，而非创造新能力。 通过北大论文和斯坦福研究，RL 通过提高高概率路径、压低低概率路径来提升 pass@1，但基础模型在大量采样下也能达到相似效果，说明 RL 更多是重新分配已有输出的概率。
  2. 锐化与泛化可以在不同层级共存。 英伟达的 ProRL 和北大的《New Skills or Sharper Primitives?》表明，RL 在原子能力上的锐化，通过长推理链的乘法效应，可以在任务层面打开新的可解区域，实现组合性泛化。
  3. 2026 年的新方法通过调整奖励权重或优化目标来减少锐化。 IPS-GRPO 对高频结果降权，LAD 保持初始概率优势，Rewarding the Rare 奖励稀有正确解法，VPO 奖励一组互补的答案，这些方法旨在让模型在提高正确性的同时保留多样性。
  4. 进化策略（ES）通过比较参数邻域内的模型，而非单条轨迹，来避免锐化。 Cognition AI 的《Beyond the Best Guess》显示，ES 在参数空间内寻找稳健区域，相比 RL 能保留更多低概率但有效的路径，减少能力丢失。
  5. 防止锐化对 Agent 和自进化系统至关重要。 Agent 在长程任务中，过早收敛会导致后续步骤无法探索新方向；自进化系统则可能在多次迭代后才发现已删除的路径，因此未来的 RL 需要为选择而生。

💬 文章金句

  • 模型不是「简单地知道得更多了」，而是「更相信其中一部分了」。
  • RL 可以在原子能力上做锐化，压低错误操作，提高正确操作的概率。而这些局部变化沿着长推理链相乘，却会在任务层面打开此前无法到达的区域。
  • 一种失败已经把门关死了。另一种失败只是暂时还没有找到出口。
  • RL 没有放弃提高能力，只是不再急着替未来做完全部选择。
