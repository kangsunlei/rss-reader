E246｜何谓蒸馏？聊聊硅谷如何看中国开放模型逼近前沿

8/1/2026, 12:00:00 AM

📌 一句话摘要

深度解读 Kimi K3 发布引发的开源与闭源之争：从蒸馏技术争议到开放模型对 AI 商业模式的冲击，揭示中国开源模型崛起的真实驱动力。

📝 详细摘要

本期邀请前 Hugging Face 亚太开源生态负责人王铁震、TinyFish 联合创始人 Keith Zhai，围绕月之暗面 Kimi K3 模型发布后的硅谷反应展开。嘉宾梳理了从 DeepSeek 到 GLM 5.2 再到 K3，中国开放权重模型如何逐步追赶并挑战闭源前沿，解读背后模型架构优化、成本效率及算力受限下的创新倒逼。重点探讨了“蒸馏”争议：技术定义、商业指控与能力归因，强调中国模型成功是多因素结果，蒸馏仅为其中之一。商业层面，分析了 K3 的定制授权协议对云厂商和推理服务商的冲击，以及开放模型如何撼动 OpenAI、Anthropic 的估值体系与收入模式，甚至可能引发价格战。还讨论了英伟达等支持开源生态的利益逻辑、安全之争以及开放模型催生的 Agent 应用新生态。节目认为，开源模型的普及将推动智能成为基础服务，长期利好好实际业务企业。

💡 主要观点

  1. K3 的发布标志着开源模型首次在能力上反超最前沿闭源模型，硅谷重新评估 AI 生态格局。 从 DeepSeek 到 K3，中国开放权重模型通过架构演进、成本优化和效率提升，在受限算力下实现了对闭源前沿的逼近甚至超越，迫使硅谷反思依赖闭源生态的风险。
  2. 蒸馏争议更多是商业竞争而非技术指控，中国模型的能力提升不能简单归因于蒸馏。 蒸馏是中性训练技术，但闭源模型不公开思维链使其难以被有效蒸馏；中国模型的成功融合了强化学习、数据工程和架构创新，证据表明 K3 核心能力并非来自蒸馏前沿模型。
  3. 开放权重模型正在将高级智能变为流通商品，直接冲击闭源实验室的估值与定价权。 当开源模型能力接近闭源，企业转向成本更低且可掌控的模型，导致 OpenAI 等闭源 API 的稀缺性溢价消失，可能陷入价格战并影响其 IPO 估值。
  4. K3 的商业授权协议探索了让开源模型持续赚钱的路径，但全球执行面临挑战。 K3 License 要求大型推理服务商付费，既避免云厂商白嫖，又通过官方认证构建生态；然而跨境营收核查、灰色地带等问题依然是落地的关键难题。
  5. 开放模型的安全风险被夸大，闭源不透明同样存在滥用可能，技术平权更利于安全研究。 智能与攻击能力独立，安全应依赖社会监管而非少数公司垄断；开源模型的可控性甚至更高，因为能够被社群审计和本地化部署，无开源才是最大不安全。

💬 文章金句

  • 有了开源模型之后，非常聪明的模型变成了一个流通的商品，甚至是被平民化，变成一个社会的基础服务。
  • 蒸馏可以让你很快地去达到一个及格线，... 但是从本质上它无法实现超越或者达到一个上限的。
  • 随着开源模型的普及，随着整个 info 行业的极致的优化，其实最终受益的就是每一个有实际业务，然后能赚到钱的企业。
  • 攻击和智能，我觉得这两个是完全独立的两个话题。
