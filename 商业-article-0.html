雨森的创投观察第 2 集：Harness、下一个字节、2026 大机会和 Stanley Druckenmiller

5/27/2026, 12:00:00 AM

📌 一句话摘要

真格基金戴雨森复盘 2026 年 AI 投资判断，深入分析 Harness 架构、模型公司 vs 应用公司格局、字节系创业者机会以及 AI 时代组织变革与投资策略。

📝 详细摘要

本期播客是真格基金合伙人戴雨森的创投观察系列第二集。节目开场他直面第一集「Year of R（回调之年）」判断被认为「被打脸」的评论，以「Strong Opinions， Weakly Held」的理念解释了为何自己应持续进化而非固守观点。核心讨论围绕 Harness（套壳/马具）架构展开，戴雨森提出「Harness 本身更像 OS，模型更像处理器」的框架，认为模型外面包的 Context、Tool、Runtime、Sandbox 等层次的价值正在增加，且好的 Harness 能通过数据回流反哺模型训练，形成数据飞轮。他强调 2026 年 Agent 将真正落地——模型能力提升使 Agent 能在无人关注时自主完成任务。关于竞争格局，他认为短期头部模型公司（Anthropic/OpenAI）可能被低估，中期被高估，长期可能成长为 5-10 万亿公司。他提出两大「暴论」：「AGI 是在缩水的」以及「字节系创始人，要把在字节学的东西，自己颠覆自己」。最后他深入讨论了 AI 投资的结构性机会、中美投资差异以及投资人应具备的持续学习心态。

💡 主要观点

  1. Harness 架构正在成为 AI 应用的核心价值层 模型外面包的 Context、Tool、Runtime、Sandbox 等多层次结构决定了 Agent 的任务完成效果，Harness 本身更像 OS，模型更像处理器，这层价值正在超过纯模型 API。
  2. 好的 Harness 能通过数据回流形成飞轮效应 Chatbot 的数据对模型提升有限，但 Agent 在解决真实用户问题时产生的高质量数据（如 coding 数据）能反哺模型训练，形成持续进化的闭环。
  3. AI 投资中短期和长期估值逻辑截然不同 短期市场情绪下 Anthropic 和 OpenAI 可能被低估，中期 Return 问题未真正解决可能被高估，长期赢家可能成长为 5-10 万亿公司。
  4. 字节系创业者需要颠覆自己学到的字节方法论 字节系创始人是优质投资人群，但 AI 时代需要把字节打法「自己颠覆自己」，不能简单复制过去的成功模式。
  5. AI 的组织变革比技术变革更重要 从蒸汽机到电动机的历史证明，技术进步需伴随组织变革才能实现生产力跃迁，AI Native 公司的组织结构扁平化和全栈人才需求正在重塑企业形态。

💬 文章金句

  • 一个好的 Harness 是很有生命力的。Harness 本身更像 OS，模型更像处理器。
  • AGI 是在缩水的。模型能力提升不会向下吞并 Harness 的空间，反而可能出现 Agent 的网络效应。
  • 字节系创始人，要把在字节学的东西，自己颠覆自己。你原来的护城河可能会变成你的软肋。
  • 让人类拥有更多更好的 Agent，第二波是让 Agent 更好的适应人类的数字世界，第三步是构建 AI 专属的数字世界。
  • 思考需要刻意练习，创新需要刻意练习。在 AI 时代，学习有效利用 AI 工具并进行创新实践至关重要。
