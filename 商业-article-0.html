定制化软件的未来：按需重写代码的 AI Agent

3/11/2026, 11:33:02 PM

📌 一句话摘要

Garry Tan 挑战了“不要改动运行中的代码”这一传统教条，预见到一个 AI Agent 为个人用户动态重写并定制软件的未来。

📝 详细摘要

Y Combinator 首席执行官 Garry Tan 提出了软件开发领域的范式变革。他质疑了行业长期以来认为“运行中的软件不应被触碰”的观念。相反，他构想了一个由 AGI 级别 Agent 驱动的未来，这些 Agent 能够阅读现有代码库，并将其重写为专门为每个用户量身定制的高质量、经过充分测试的版本。这预示着软件将从静态、通用的形式转向由 Agent 生成的动态定制化解决方案。
