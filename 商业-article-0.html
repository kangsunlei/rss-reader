编程测试碾压人类！Claude Opus 4.5 深夜突袭，AI 编程进入「超人时代」

11/25/2025, 7:13:32 AM

📌 一句话摘要

Claude Opus 4.5 深夜发布，凭借在编程测试中超越人类的卓越表现和全面的工具链升级，将 AI 编程推向“超人时代”，并提升了模型理解和智能体能力。

📝 详细摘要

文章详细介绍了 Anthropic 最新发布的大语言模型 Claude Opus 4.5，强调其在编程能力上的显著突破，尤其在 SWE-Bench Verified 测试中首次突破 80%得分，并在多语言编程中表现优异，甚至在公司内部高难度性能工程师测试中超越所有人类候选人。Opus 4.5 不仅在编程方面达到业界领先，其对模糊需求的理解力、创造性解决问题的能力（如客服案例）也得到提升。此外，文章还介绍了 Opus 4.5 的全面工具链升级，包括 Claude Code 的计划模式、桌面应用，Chrome 插件和 Excel 集成，以及“无尽对话”功能。底层升级引入了“effort”参数、Tool Search Tool 和 Programmatic Tool Calling，显著提升了模型效率、成本效益和 Agent 能力，使其能更智能、更高效地处理复杂任务和工具协作。

💡 主要观点

  1. Claude Opus 4.5 在编程测试中表现卓越，尤其在 SWE-Bench Verified 上首次突破 80%，多语言编程能力领先。 模型在真实场景的软件工程测试中取得里程碑式成就，并在公司内部招聘测试中超越人类，预示 AI 编程能力进入新阶段。
  2. 模型对模糊需求理解力及创造性问题解决能力显著提升，甚至能超越现有评测标准的预期答案。 Opus 4.5 展现出强大的推理和变通能力，能够以非传统但有效的方式解决复杂问题，体现了更高层次的智能。
  3. Anthropic 全面升级工具链，如 Claude Code、Chrome 插件、Excel 集成等，并实现“无尽对话”功能。 这些功能显著提升了开发者和普通用户的使用体验，使 Claude 能更深入地融入日常工作流，并解决长对话上下文限制问题。
  4. 底层技术升级（如 effort 参数、Tool Search Tool、Programmatic Tool Calling）提升了模型效率、成本效益及 Agent 能力。 这些创新机制使得 Opus 4.5 能够更智能、更高效地管理资源和工具，大幅提升了模型在复杂智能体任务中的表现和准确度。

💬 文章金句

  • 在真实场景的软件工程测试 SWE-Bench Verified 里，它是头一个拿到 80% 以上分数的模型。
  • 在规定的两小时内，Claude Opus 4.5 的得分超过了所有人类候选人。
  • Opus 4.5 想出了一个巧妙方案：先把舱位从基础经济舱升级到普通经济舱，然后再改航班。
  • Claude 会在需要的时候自动总结早期上下文，让对话持续下去。
  • API 里新加了一个叫 effort 的参数，让你可以根据需求选：要么优先省时间和成本，要么最大化模型能力。
