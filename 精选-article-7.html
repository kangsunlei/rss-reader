Qwen-AgentWorld 开源: 面向通用智能体的语言世界模型

6/25/2026, 10:00:00 AM

📌 一句话摘要

Qwen 团队开源业内首个原生语言世界模型 Qwen-AgentWorld，能模拟七大 Agent 环境，在基准上超越 GPT-5.4，并提出 Sim RL 和 Agent 基础模型两种训练范式，显著提升智能体效果。

📝 详细摘要

本文详细介绍 Qwen-AgentWorld，一个原生语言世界模型（LWM），通过三阶段训练（CPT + SFT + RL）将环境模拟能力内化到模型自身。模型覆盖 MCP、Search、Terminal、SWE、Web、OS、Android 七大领域，能以语言形式生成高保真的环境反馈。旗舰版 397B 在自建 AgentWorldBench 上达到 58.71 分，超过 GPT-5.4（58.25）和 Claude Sonnet 4.6（56.04）；轻量版 35B-A3B 相对基模提升 +8.66。文章展示了两种应用范式：作为独立模拟器进行 Sim RL，在搜索任务上甚至超越真实环境训练效果；作为 Agent 基础模型提供世界模型先验，在多个下游任务（包括 OOD）上稳定提升。还披露了模型自发涌现的自我纠错、信息泄漏防护、多步因果推理等推理模式。最后给出 SGLang、vLLM、Transformers 部署示例。

💡 主要观点

  1. Qwen-AgentWorld 将环境模拟从工程问题转化为模型问题。 通过三阶段训练让语言模型直接预测环境反馈，替代传统 Sandbox，大幅降低 Agent 训练的成本与不稳定性。
  2. 覆盖七大 Agent 领域，在基准上超越 GPT-5.4 和 Claude Sonnet 4.6。 旗舰版 397B 在 AgentWorldBench 上取得 58.71 分，轻量版 35B-A3B 也以 56.39 分高于 Claude Sonnet 4.6（56.04）。
  3. Sim RL 范式可超越真实环境训练效果。 在 WideSearch 上，使用 Qwen-AgentWorld 作为模拟器训练得到的 Agent 拿到 50.3% F1 Item，高于真实环境 RL 的 45.6%。
  4. 作为 Agent 基础模型提供可迁移的世界模型先验。 在 LWM 权重上做下游 RL，在 SWE-Bench、WideSearch、Claw-Eval 等任务上获得两位数提升，包括 OOD 场景。
  5. 模型自发涌现自我纠错、信息泄漏防护、多步因果推理等推理行为。 这些行为使得生成的环境反馈更可靠，提升了世界模型的保真度。

💬 文章金句

  • Qwen-AgentWorld 把「环境模拟」从工程问题变成了模型问题。
  • 纯模拟训练不仅省掉了真实工具调用的延迟和成本，还反过来超越了在真实环境训练的效果。
  • 通过 LWM 预热依然拿到了两位数提升，说明世界模型把「对环境的理解」沉淀成了可迁移的通用 Agent 先验。
