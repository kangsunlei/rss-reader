OpenAI 视频 API 向所有开发者开放

3/12/2026, 7:30:57 PM

📌 一句话摘要

OpenAI 宣布其视频 API 全面开放，开发者现在可以将其高质量视频生成能力集成到自己的应用程序中。

📝 详细摘要

这条推文标志着 OpenAI 视频 API 功能正式向更广泛的开发者社区发布。该 API 旨在支持工作室、品牌和开发者创建高品质内容，适用于故事板制作、营销活动和用户生成内容平台等多种用例。通过取消此前有限的访问权限，OpenAI 正显著降低程序化 AI 视频创作的门槛，并提供了详细的实施文档。
