使用 Deep Agents 构建研究智能体

11/20/2025, 5:02:01 PM

📌 一句话摘要

LangChain 的 Deep Agents 框架简化了构建复杂 AI 智能体的过程，它集成了规划、文件系统和子智能体委派等工具。

📝 详细摘要

LangChain 的 Lance 介绍了 Deep Agents 框架，该框架旨在简化复杂 AI 智能体的开发。它集成了用于规划、与文件系统交互以及将任务委派给子智能体的基本原子工具，从而显著减少了样板代码，并避免了重复实现，其设计灵感来源于 Manis 和 Claude Code 等流行的智能体。该框架强调可扩展性，允许开发者轻松集成自定义提示词、工具和专用子智能体，以适应不同的使用场景。视频通过构建一个研究智能体进行了演示，重点介绍了配置任务专属工具（如搜索工具和用于内部反思的可选“思考”工具）、通过子智能体有效管理上下文隔离，以及通过设置明确的预算限制和停止条件来防止智能体进入“无限循环”等关键因素。此外，它还解释了中间件在编排智能体循环中的作用，从而实现自动摘要、提示缓存和人工干预等高级功能。部署选项包括交互式 Jupyter Notebook 和具有自定义 UI 的可扩展 LangGraph 服务器，所有智能体活动都可以通过 LangSmith 进行全面追踪。Deep Agents 框架旨在为常见的智能体功能提供一个强大且可复用的基础，使开发者能够专注于应用专属的逻辑。

💡 主要观点

  1. Deep Agents 框架通过内置的可扩展工具，简化了复杂 AI 智能体的创建。 该框架提供了规划、文件系统访问和子智能体委派等基础能力，这对于长时间运行的复杂智能体至关重要，从而减少了开发者的样板代码。
  2. 子智能体对于上下文隔离和高效的任务委派至关重要。 通过将特定的、大量 Token 的任务委派给子智能体，主智能体的上下文窗口保持可管理，从而提高效率和专注度，尤其是在研究场景中。
  3. 有效的提示词工程与中间件是实现智能体控制和高级功能的关键。 精心设计的指令可以防止智能体进入“无限循环”，而中间件可以实现自动摘要、提示缓存和人工干预等高级编排。

💬 文章金句

  • Deep Agents 是一个简单的开源智能体工具，它实现了我们在 Manis 和 Claude Code 等许多流行的智能体中看到的一些理念，特别是规划、计算机访问和子智能体委派。
  • 这组简单的原子工具功能强大，可以访问文件系统、调用 shell 命令、计划待办事项，并通过任务工具委派工作。
  • 这就是为什么这些子智能体如此出色，尤其是在研究任务中，可以将该研究任务中收集的所有上下文隔离到子智能体自己的上下文窗口中，然后只返回结果。
  • 我见过智能体只是不断循环搜索以改进结果，却不知道何时停止。因此，这些启发式方法对于防止我们所说的“无限循环”非常有帮助。
  • 中间件可以充当钩子，例如在智能体、模型或工具被调用之前停止。因此，在这个智能体循环的不同阶段，你可以注入中间件来暂停并执行某些操作。
