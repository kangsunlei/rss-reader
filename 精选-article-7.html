GPT-5-Codex 发布：为 Codex 自主编码优化

9/15/2025, 5:09:29 PM

📌 一句话摘要

OpenAI 发布了为自主编码设计的 GPT-5-Codex 优化版本，该版本可在 Codex 命令行界面（CLI）、IDE 扩展（IDE Extension）、Web 和 GitHub 等多个平台使用。

📝 详细摘要

OpenAI 宣布发布 GPT-5-Codex，这是其 GPT-5 旗舰模型的一个专门版本。此版本专为 Codex 框架内的“自主编码”而优化，意味着更强大的自主代码生成和问题解决能力。它在 Codex CLI、IDE Extension、Web、移动端和 GitHub 中进行代码审查的广泛应用，标志着将先进的 AI 编码辅助集成到各种开发工作流程中的重大举措。此次发布是 AI 驱动的软件工程领域的一个重大进展。
