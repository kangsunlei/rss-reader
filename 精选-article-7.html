Paperclip：像招聘员工一样雇佣 AI Agent（现场演示）

3/26/2026, 7:00:20 PM

📌 一句话摘要

Paperclip 创始人 Dota 演示了一个 AI Agent 编排平台，让用户能够构建「零人类公司」——由具备角色、记忆和技能的 AI Agent 团队在人类战略指导下自主运营。

📝 详细摘要

Greg Isenberg 采访了 Paperclip 的创始人 Dota。Paperclip 是一个开源 AI Agent 编排层，三周内在 GitHub 上获得了 3 万颗星。视频以产品实操演示为主线，展示如何从零开始构建并管理一家 AI 驱动的公司。 Paperclip 的核心理念是「零人类公司」：用户定义一个 CEO Agent，设定高层业务目标，由 AI 层级结构——CMO、CTO、工程师、QA——自主执行任务。关键差异化设计是「心跳」机制，通过结构化清单让 Agent 每次「醒来」时重建身份和上下文，解决了 LLM 固有的持久记忆问题。 演示内容涵盖：为金融应用 Moola 创建 CEO Agent、配置 Agent 人设、分配技能（包括通过 skills.sh 等平台引入第三方技能）、委派 QA 审核闭环，以及配置每日自动化例行程序（如 GitHub 更新日志摘要）。「自带机器人」（BYOB）功能支持接入任意模型，让运营者能将模型特性与任务需求精准匹配。 视频中的真实用例包括：带有创意总监和技术总监 Agent 的游戏工作室模板、用 Paperclip 管理基金会事务的牙科医生，以及利用卫星图像和 AI 识别冰雹受损区域进行精准销售拓客的屋顶承包商。 路线图中的「最大化模式」将让 CEO Agent 不计成本 24/7 运转，直到达成既定目标。Dota 将人类的角色定位为设定「品味与价值观」的董事会成员，而非任务管理者。

💡 主要观点

  1. Paperclip 将人类定位为董事会成员，而非任务管理者 用户设定高层目标并审批 Agent 产出，CEO Agent 制定计划并向下级 Agent 委派任务。这种从「执行者」到「决策者」的思维转变是其核心 UX 哲学。
  2. 「心跳」机制解决了 Agent 记忆持久化问题 每个 Agent 在激活时都会执行启动清单：重新确认身份、读取今日计划、检查分配的任务。这补偿了 LLM 跨会话缺乏持久记忆的天然缺陷。
  3. BYOB 功能实现了模型与任务的精准匹配 运营者可以将 Claude Code 等顶级模型分配给 CEO 角色，同时为常规子任务使用更廉价或免费的模型，在整个 Agent 层级中优化成本与能力配置。
  4. 可共享的公司模板实现了组织结构的复用 经过验证的组织架构——如包含创意、技术和 QA 角色的游戏工作室——可以打包为模板分发，让其他人无需从零构建即可「运行」一套经过验证的组织逻辑。
  5. 上下文和品牌价值观仍是人类的责任 Dota 认为 AI 几乎无所不能，但唯独不了解你的品味与价值观。人类领导者必须投入精力构建品牌指南、质量标准和反馈闭环，才能持续获得高质量产出。

💬 文章金句

  • 「你应该把自己看作董事会成员。你与 CEO 对话，告知高层目标和想要达到的营收，由 CEO 来制定计划并执行。」
  • 「我常把 AI Agent 比作电影《记忆碎片》里的男主角。他非常能干，但每天醒来都不记得自己是谁、在做什么。所以你需要给他留下照片或在手臂上纹身。」
  • 「AI 现阶段能做任何事，唯独不知道你的价值观和审美。作为领导者，你的任务是清晰地沟通你的品味。」
  • 「Paperclip 是一个为零人类公司设计的 Agent 编排器。你把创意投入其中，然后管理一个由 Agent 组成的公司。」
  • 「最好的结果是成名但无人识。」
