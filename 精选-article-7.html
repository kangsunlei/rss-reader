一文读懂 OpenAI DevDay：应用、Agent、代码三连击，勾勒 AI 商业帝国的统治蓝图

10/6/2025, 9:38:00 PM

📌 一句话摘要

文章深入解读 OpenAI DevDay，分析 Apps SDK、AgentKit 和 Codex 更新如何构建以 AI 为核心的软件生态，并探讨 OpenAI 日益清晰的商业帝国蓝图。

📝 详细摘要

本文深入剖析了 OpenAI DevDay 发布会的核心内容，将其归纳为 Apps SDK、AgentKit、Codex 正式版更新以及 API 开放四大板块。作者强调，OpenAI 正致力于构建一个以 AI 为绝对核心的全新软件生态系统。Apps SDK 旨在将大语言模型（LLM）打造成所有软件的统一入口，通过提供完整的开发堆栈，实现应用在 ChatGPT 内部的真实、可交互体验。AgentKit 通过可视化的 Agent Builder 和独特的强化学习微调（RFT）与端到端评估（Evals）能力，旨在超越现有 Dify 等工具，加速 Agent 时代的到来。Codex 从研究预览版转为正式版，通过企业级支持，预示着未来通过对话实时迭代代码的编程模式。文章最后分析了 OpenAI 日益清晰的商业帝国轮廓，指出其商业化战略的光芒日益强烈，甚至开始掩盖了早期对通用人工智能（AGI）的探索与“惊艳感”，引发对未来方向的思考。

💡 主要观点

  1. OpenAI 通过 Apps SDK 将 LLM 打造为统一软件入口，实现应用无缝融合与交互。 Apps SDK 提供完整开发堆栈，允许开发者在 ChatGPT 内构建可交互应用，利用 LLM 的上下文理解能力，让用户在单一对话框中协同调用工具完成复杂任务。
  2. AgentKit 以可视化开发和 RFT 定制能力，加速 Agent 时代的到来并提升开发效率。 AgentKit 通过可视化的 Agent Builder 简化 Agent 开发，尽管在设计逻辑上未完全超越 Dify 等现有工具，但其独特的强化学习微调（RFT）能力允许深入模型优化，结合 Evals 功能提供端到端评估，为开发者提供了超越传统 API 调用的定制和效率优势，旨在加速 Agent 时代的到来。
  3. Codex 正式版升级，结合未来编程愿景，预示通过对话实现软件实时迭代。 Codex 通过 Slack 集成、SDK 和管理工具支持企业级应用，并展示了通过语音助手实时修改代码的未来编程模式，降低开发门槛。
  4. OpenAI 战略重心转向构建以大模型为核心的商业生态，AGI 愿景渐被商业化轮廓覆盖。 文章深刻指出，OpenAI 此次 DevDay 的各项发布，均围绕搭建一个以其大模型为核心、封闭且极具掌控力的软件生态。这表明其战略重心已明确转向商业化，其商业嗅觉和产品构想的光芒日益强烈，甚至开始掩盖了早期对通用人工智能（AGI）的探索与曾经的“惊艳感”，引发了对 OpenAI 未来发展方向的深层思考。

💬 文章金句

  • OpenAI 此次首次将这一蓝图更系统化、平台化地呈现出来。
  • 用户无需在不同软件间切换，只需通过对话，就能在一个统一的入口中，让最合适的工具在最恰当的时机出现，并协同完成一项复杂的任务。
  • 目前的 AgentKit 并没有整体在设计逻辑上超越 Dify 类工具很多，但确实更精简，更易用。
  • 这个场景就是 OpenAI 预想的软件开发的未来——你甚至不需要看到代码，软件就可以在与你的对话中，实时地自我迭代和进化。
  • 如今的 OpenAI，商业帝国的轮廓愈发清晰，甚至已经隐隐盖住了通用人工智能（AGI）的远景图景。
