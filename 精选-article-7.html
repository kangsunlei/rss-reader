📝 详细摘要

本文作为首篇全面综述，深入探讨了大型语言模型（LLMs）的后训练技术（PoLMs），旨在解决 LLMs 预训练架构在特定情境下（如推理能力有限、伦理不确定性、领域性能不佳）的局限性。文章系统地将 PoLMs 分为微调、对齐、推理、效率、集成与适应五大核心范式，并追溯了它们从 2018 年 ChatGPT 到 2025 年 DeepSeek-R1 的发展历程。文中详细阐述了监督微调（SFT）、强化学习结合人类反馈（RLHF）、直接偏好优化（DPO）等关键技术，并介绍了如何通过思维链（CoT）和专家混合（MoE）等方法增强推理能力和提升模型效率。PoLMs 通过利用数据集减轻偏差、深化推理能力和增强领域适应性，极大地推动了 LLM 的发展。文章还概述了 PoLMs 所依赖的数据集类型和广泛应用场景，并指出了未来研究方向，强调了大型推理模型（LRMs）的战略议程，为 LLM 的精确、伦理稳健和多功能发展奠定了理论框架。

💡 主要观点

  1. PoLMs 系统分类框架：将后训练技术划分为微调、对齐、推理、效率、集成与适应五大范式。 这种结构化分类为理解和定位 LLM 后训练的各种方法提供了清晰的视角，揭示了它们之间的相互关系，从而指导技术选型和研究方向。
  2. PoLMs 的历史演变与前沿进展：系统追溯了从 2018 年 BERT/GPT 到 2025 年 DeepSeek-R1 等模型的后训练技术发展，特别是 DeepSeek-R1 在推理能力和效率优化上的创新突破。 文章不仅分类了现有技术，更提供了清晰的时间线和关键模型案例，展现了 PoLMs 如何持续演进以解决 LLM 的局限性，并指明了大型推理模型（LRMs）的战略方向。
  3. RLHF 及其变体的核心作用：详细阐述 RLHF、DPO 等对齐技术在使 LLM 符合人类偏好和伦理标准方面的重要性。 对齐是 LLM 从通用模型走向实用化的核心，这些技术确保模型输出安全、有效且符合用户预期，极大提升了模型在实际应用中的可用性。
  4. 推理能力增强与效率优化：探讨 CoT、ReFT 等推理增强技术，以及 MoE、PEFT 等效率提升方法。 这些技术是推动 LLM 从简单生成到复杂推理，并使其在有限计算资源下大规模部署的关键，预示着 LLM 未来发展的方向和挑战。

💬 文章金句

  • DeepSeek-R1 成为了 PoLM 创新的里程碑，它摆脱了传统监督微调（SFT）的依赖，转而采用链式思维（CoT）推理和探索性 RL 策略。
  • 大型语言模型（LLMs）的出现从根本上改变了自然语言处理，使其在从对话系统到科学探索等多个领域不可或缺。
  • 本文首次全面综述了 PoLMs，系统地追溯了它们在五个核心范式中的演变：微调、对齐、推理、效率以及集成与适应。
  • PoLMs 则专注于将这些模型适应特定任务和需求。
  • 此外，开源 LLMs（例如 LLaMA、Gemma 和 Nemotron）和领域特定的大规模数据集（例如 Prompt Source 和 Flan）的日益可用，正在推动学术研究人员和行业从业者开发 PoLMs 的趋势。
