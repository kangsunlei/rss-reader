AI 算法开源｜Logics-Parsing：攻克 PDF 复杂文档端到端结构化处理

10/17/2025, 12:31:00 AM

📌 一句话摘要

阿里开源 Logics-Parsing 模型，通过以布局为中心的强化学习，实现了对 PDF 复杂文档（含公式、手写体、表格）的端到端高精度结构化解析。

📝 详细摘要

文章详细介绍了阿里巴巴自主研发并开源的 Logics-Parsing 模型，旨在解决传统 OCR 和现有视觉语言模型在处理复杂 PDF 文档（如多栏排版、图文混排、专业公式、手写字）时存在的理解和阅读顺序不足的问题。Logics-Parsing 基于 Qwen2.5-VL 架构，采用“SFT-then-RL”两阶段训练策略，核心创新在于引入了以布局为中心的强化学习（LC-RL），通过精心挖掘标注的高质量难例数据集，并设计了文本准确性、定位精度和阅读逻辑多组件奖励函数，优化模型对复杂布局的分析和阅读顺序的推断。模型能够端到端地将 PDF 或图片内容转化为 Qwen HTML 或 Mathpix Markdown 格式，并支持数学公式复现、化学分子式还原（支持 SMILES 格式）、复杂表格解析和手写文字识别等功能。该模型在自建评测集上取得了业界最佳（SOTA）性能，并提供了 GitHub 代码、ModelScope 在线体验及技术报告。

💡 主要观点

  1. Logics-Parsing 有效攻克复杂 PDF 文档的端到端结构化解析难题 解决了现有工具和 LVLM 在处理多栏、图文混排、专业公式及手写体等复杂文档时，阅读顺序和内容识别的不足，实现从图像到结构化输出的一步到位处理。
  2. 引入以布局为中心的强化学习（LC-RL）优化模型性能 通过“SFT-then-RL”两阶段训练策略和包含文本准确性、定位精度、阅读逻辑的多组件奖励函数，强化模型对复杂布局的理解和阅读路径的规划。
  3. 模型具备先进的内容元素识别和丰富的结构化输出能力 能够精准识别并结构化数学公式、化学分子式（转 SMILES）、复杂表格及手写文字，输出为 Qwen HTML 或 Mathpix Markdown 格式，极大地提升了文档处理的实用性。

💬 文章金句

  • 哪怕是最近大火的视觉语言模型（LVLM）在理解复杂布局与阅读顺序也有明显不足。
  • 引入以布局为中心的强化学习（Layout-centric Reinforcement Learning，LC-RL），通过"SFT-then-RL"两阶段训练策略确保模型合理规划阅读路径，强化复杂内容的识别能力。
  • Logics-Parsing 可以轻松理解复杂排版，在保留自然的阅读顺序的同时，精准提取文字、表格、公式、手写字、化学分子式等内容，将 PDF 或图片转化为 qwen-html 或 mathpix-markdow 格式。
  • 端到端模型架构无需多阶段流水线处理，从文档图像一步到位生成结构化输出。
  • Logics-Parsing 在自建 PDF 解析综合评测集上取得了业界最佳（SOTA） 的结果，在纯文本解析、化学结构识别和手写内容处理方面全面优于所有其他方法。
