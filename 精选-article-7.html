一个 Personal Agent 创业者的思考｜对谈 Ambi 创始人子皓

10/12/2026, 10:00:00 PM

📌 一句话摘要

Ambi 创始人莫子皓谈 Personal Agent 创业：关键不是堆智能，而是降低获取智能的交互成本，靠软硬结合补线下情境与入口，让 AI 持续运行、人机同步在场。

📝 详细摘要

本期 42 章经 对谈 Ambi 创始人莫子皓，围绕 Personal Agent 的产品路线、软硬件结合、交互设计与创业认知展开。子皓认为，Personal Agent 的兴起是 OpenClaw、Minus 等主线延续，但 C 端尚未出现真正的 PMF 产品，核心不在智能不够，而在获取智能的交互成本太高。Ambi 选择做软硬结合，补下线下的 context 与交互入口，主张 AI 应像软件一样持续运行、人机同步在场，而非每次唤醒和重复输入。隐私上，Ambi 类比苹果的 ambient 方案，录音与敏感数据尽量在本地或可信端处理。他还判断 AI Coworker 落地受组织变革制约，新公司会以更高效率与人才密度逐步替代旧公司；国内大厂失去成为世界第一的雄心，做「中国的某某」难以跑出原创产品。商业认知上，他强调选择比努力重要，商业本质是效率、ROI 与需求，对外识别需求、对内招到人；并分享高三暑假做溜冰票代理的经历。最后，他认为应用公司自训模型是在成本、速度、智能的帕累托曲线上找平衡，而非追求更高智能。

💡 主要观点

  1. Personal Agent 的瓶颈在于获取智能的交互成本，而非智能本身。 OpenClaw 那波虽然技术能力令人兴奋，但安装成本高、场景描述不明确、传播链路长，普通用户难以获得同等能力；当智能像空气水电一样默认触手可及，需求会被显著激发；如果每次都要花 30 秒到几分钟准备 context，生活场景中的鸡毛蒜皮需求就很难被触发。
  2. Ambi 的差异化是软硬结合，补齐线下 context 与线下交互入口，让 AI 持续运行。 现有 Personal Agent 缺少线下情境和即时入口，AI 每次使用都需唤醒和重复输入；Ambi 希望人机同步在场，而非 human in the loop，像软件一样 continuous running，自然听到与看到正在发生的事情，减少重复操作。
  3. Agent 之间的网络效应来自每个 agent 背后的 memory、context 与权限沉淀，而不是先建协作再谈网络效应。 用户使用产品后沉淀 memory、flow system 和权限，才使 A2A 协作有价值；例如作者把自己的 Lark bot 放进群，让同事通过 bot 审稿或征求意见，同时通过权限控制保护隐私；这形成 agent 间协作的正向循环。
  4. AI Coworker 落地慢的根因是组织变革，而非模型能力；新公司会凭借更高效率与人才密度逐步替代旧公司。 组织像水管，会被最窄的一段限制；旧公司按新方式改造要花五倍以上时间；电发明后按用电方式建工厂花了约 30 年，AI 时代的公司替代也需要时间，但复利和知识积累会让新形态公司市场占有率越来越高。
  5. 商业认知：选择比努力重要，商业本质是效率、ROI 与需求，创始人核心能力是对外识别需求、对内招得到人。 嘉宾从六年公益创业、十年保险/创新支付/SaaS、模型厂到消费硬件的经历中总结，每个赛道的能力和时机比努力更重要；商业没有秘密，底层是效率、ROI 和需求；招人靠真诚与长期积累，不适合的人不应勉强加入。他还用高三暑假做溜冰场独家代理的案例说明用商业方法解决自己拉不下脸销售的问题。

💬 文章金句

  • 但我们创业的时候，刚开始的想法其实在于说是改变人跟 AI 的那个交互方式。
  • 但是核心是在比这个需求更底层的一个问题在于说是你对智能的获取的成本是多少。
  • 我们希望在于说是人跟 AI 是同步在场，没有 human 的路。
  • 对外能够识别需求，对内能够招得到人。
  • 这一波就是大厂跟上一个时代比，失去了去成为世界第一和领先全世界的这样的一个雄心。
