OpenMausBot 虚拟机支持，组合 Kiri 实现流畅体验

11/8/2026, 10:47:03 AM

📌 一句话摘要

OpenMausBot 支持虚拟机，可搭配 Kiri 在低配设备上流畅运行，平替 Grok Bot。

📝 详细摘要

OpenMausBot 是 Grok Bot 的平替方案，支持在虚拟机中运行，基于 Docker 容器。作者结合 Kiri 使用，让 Bot 可在低配 Mac mini 上流畅运行。推文同时提到 Kiri 是一个轻量级容器运行时，支持 Docker CLI、Compose 和 buildx。

💡 主要观点

  1. 虚拟机支持 OpenMausBot 可在虚拟机中运行，提升部署灵活性。
  2. Docker 生态兼容 基于 Docker 容器运行，兼容现有 docker CLI 和 Compose 工具。
  3. 资源友好 结合 Kiri 可在低配置设备上流畅运行，提升可用性。
