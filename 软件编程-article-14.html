Cisco Talos 发布安全预警，自主 AI Agent 可将渗透测试转为隐蔽红队攻击

10/11/2026, 10:00:00 AM

📌 一句话摘要

Cisco Talos 发布安全预警，指出攻击者正利用预置操作手册和工具集驱动自主 AI Agent，将高噪声的常规渗透测试转变为隐蔽、持久的红队攻击模式。

📝 详细摘要

Cisco Talos 研究人员 Jerzy "Yuri" Kramarz 发布安全预警，警告自主 AI Agent 正从常规的自动化漏洞扫描转向隐蔽、持久的红队攻击。攻击者通过为 Agent 提供工具映射、攻击性提示词、Markdown 操作指南以及特定任务的 skills 等预置资源，使其能够协同开展身份伪造、漏洞利用和横向移动。相较于以往特征明显的恶意软件活动，AI 驱动的隐蔽攻击旨在不触发 SOC 告警的前提下获取长期访问权限。对此，Talos 建议企业加强内部身份管控、开展失陷假设演练，并将可见性建设覆盖端点、内网流量与 AI 应用。

💡 主要观点

  1. 自主 AI Agent 正从高可见度的常规渗透转向隐蔽的红队攻击 Cisco Talos 警告称，通过植入规避检测的指令和协同策略，攻击者能够指挥多个 Agent 隐藏行踪并持续渗透，直到触及核心敏感系统，将原本需要数月的工作压缩至数小时。
  2. 攻击者通过预置资源和操作手册赋能 Agent 开展协同渗透 攻击者为 Agent 提供工具映射、攻击性提示词、Markdown 操作指南（如 agents.md）和 skills，使其能够自主选择工具、研判探测结果并实现多 Agent 间的信息共享与动态调整。
  3. 企业防御需要突破传统网络边界局限并强化身份与可见性管控 Talos 建议企业开展失陷假设演练，将身份管控范围延伸至内部应用与 Linux 设备（优先采用 FIDO2 密钥），并将可见性建设覆盖端点、内网流量、DNS 以及访问企业数据的 AI 应用。

💬 文章金句

  • 自主 AI Agent 攻击可从渗透活动转向隐蔽红队行动。
  • 真正的风险在于，多组 Agent 可学会隐藏行踪、共享探测结果，持续渗透直到触及核心敏感系统。
  • 如果攻击者训练 Agent 时将隐蔽性置于攻击速度之上，就会大幅减少防御方当前依赖的检测信号。
