本文报道了 OpenJDK 中已提升为候选状态的八个 JEP 以及 JDK 25 的发布时间表。

📝 详细摘要

本文重点介绍了 2025 年 4 月 14 日这一周 OpenJDK 生态系统中的活动，其中八个新的 JEP 已从草案提升为候选状态。其中四个将在各自的预览轮次后最终确定。这些 JEP 包括几个旨在改进 Java 语言和性能的 JEP，例如 JEP 512（紧凑源文件（Compact Source Files）），JEP 511（模块导入声明（Module Import Declarations）），JEP 510（密钥派生函数 API（Key Derivation Function API）），JEP 509（JFR CPU 时间分析（JFR CPU-Time Profiling）），JEP 508（向量 API（Vector API）），JEP 507（模式中的原始类型（Primitive Types in Patterns）），JEP 506（作用域值（Scoped Values））和 JEP 505（结构化并发（Structured Concurrency））。本文还提供了 JDK 25 的发布时间表，并列出了当前包含在其功能集中的两个 JEP。

💡 主要观点

  1. 多个 JEP 提升为候选状态表明 Java 语言的持续发展。 这些 JEP 涵盖了从简化初学者编程到增强性能和并发能力的各个方面，表明 Java 平台正在不断适应新的开发需求。
  2. JDK 25 引入了几项改进和实验性功能，包括向量 API（Vector API）（第十个试验版本）和结构化并发（Structured Concurrency）。 包含向量 API（Vector API）（第十个试验版本）、结构化并发（Structured Concurrency）（预览版本）以及模式匹配的增强功能为开发人员提供了更多的选择和可能性。
  3. 作用域值（Scoped Values）有助于在线程之间安全地共享数据。 与线程局部变量相比，使用大量虚拟线程时，作用域值（Scoped Values）更有效，有助于提高程序性能和可维护性。
