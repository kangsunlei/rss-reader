发现了 4 个好玩 SKills，已经在 GitHub 上开源了。

1/23/2026, 7:14:00 AM

📌 一句话摘要

本文介绍了四款基于 Claude Code 等 AI 助手的开源 Skill 工具，涵盖视频自动化剪辑、文本去 AI 化、小红书内容自动发布及 Skill 安装管理。

📝 详细摘要

文章重点推荐了四个在 GitHub 上开源的 AI 技能插件（Skills），旨在提升开发者的生产力与创作效率。具体包括：1. videocut-skills，利用 Whisper 和 FFmpeg 实现口播视频的自动去噪、去静音及字幕生成；2. Humanizer-zh，针对中文语境优化，通过模拟人类写作习惯消除 AI 生成文本的机械感；3. Auto-Redbook-Skills，结合 Playwright 自动化技术，实现小红书文案生成、图片渲染及一键发布；4. add-skill，由 Vercel Labs 开发，用于简化在 Claude Code 等工具中安装第三方技能的流程。文章提供了各项目的核心功能介绍、安装命令及开源地址。

💡 主要观点

  1. AI Skills 正在成为增强 AI 助手能力、实现复杂任务自动化的核心方式。 通过在 Claude Code 等工具中集成特定 Skill，AI 可以调用本地环境（如 FFmpeg、Playwright）完成从视频处理到网页自动化的闭环操作。
  2. 视频剪辑 Skill 通过集成 Whisper 和 FFmpeg 极大提高了口播类视频的后期效率。 它能自动识别并剔除口误、静音片段，并支持通过词典纠错生成字幕，将繁琐的剪辑过程简化为对话式指令。
  3. 文本“去 AI 化”工具通过模拟人类写作特征，提升了生成内容的自然度。 基于维基百科的 AI 写作特征指南，针对性地修改语言语法和交流模式，使 AI 生成的文案更具真实感和生动性。
