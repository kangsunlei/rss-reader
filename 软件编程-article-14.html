Agent 工程范式演变：从 Prompt Engineering 到 Context Engineering

5/28/2026, 8:39:57 AM

📌 一句话摘要

通过分析 Agent 六大基本模块（Prompt、Planning、Memory、Tools、Workflow、Environment）近年来的实现方式变化，揭示 Agent 工程正从依赖模型能力转向构建工程系统来承载模型不确定性。

📝 详细摘要

这是一篇高质量的原创技术 Thread，系统梳理了 Agent 六大核心模块的工程演变。作者指出，Agent 的变化不是单点技术升级，而是整个工程范式的转变：Prompt 从写长提示词转向按需加载上下文的 Context Engineering；Planning 从简单的逐步思考演进为能拆解长任务并动态调整；Memory 从纯向量检索转向文件系统与检索混合的务实方案；Tools 从 Function Call 转向直接使用 CLI 和 Script；Workflow 从固定流程转向 Skill 与 Workflow 混合的灵活兜底模式；Environment 从无状态问答转向需要 Workspace 和 Runtime 的安全运行环境。核心观点是，好的 Agent 不是靠模型硬扛一切，而是用工程系统承载模型的不确定性。
