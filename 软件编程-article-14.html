huashu-art-motion：让 Claude 画 35 种风格的艺术动画

10/10/2026, 2:07:21 AM

📌 一句话摘要

一个装进 Claude Code 的艺术动画 Skill，包含 35 种经典画风配方，能生成精确到帧的动画片段，并用独立 Agent 质检最终效果。

📝 详细摘要

huashu-art-motion 是一个专门为 Claude Code 设计的艺术动画 Skill。它提供了 35 种经典艺术风格的预设「配方」，包括岩洞壁画、梵高、包豪斯等，每种风格都配备了可以直接运算的场景代码和转场效果。该 Skill 还能生成用于解说视频的动画段落，涵盖 Kurzgesagt、Vox 等多种画面语法，并确保输出的时长精确到帧。最后，它通过一个独立的 Agent 对最终动画进行质量检查，确保成品无误。

💡 主要观点

  1. 丰富的风格库 包含 35 种经典艺术风格的配方，覆盖从原始壁画到现代像素画的广泛范围，为开发者提供了丰富的可视化选择。
  2. 精确的视频生产 支持生成精确到帧的动画片段，并提供横屏、竖屏两种画面比例，适合制作高品质的解说视频。
  3. 独立的质量控制 引入一个没有参与制作的独立 Agent，对成品进行挑错和质检，确保最终输出的动画质量可靠。
