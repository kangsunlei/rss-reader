OpenAI DevDay 2025：Sam Altman 开幕主题演讲

10/7/2025, 12:00:00 AM

📌 一句话摘要

OpenAI DevDay 2025 主题演讲概述了四大核心发布：Apps SDK、Agent Kit、Codex 增强及 GPT-5 Pro、Sora 2 等模型更新，旨在赋能开发者加速 AI 创新与应用。

📝 详细摘要

文章详细回顾了 Sam Altman 在 OpenAI DevDay 2025 的开幕主题演讲。他首先强调了 OpenAI 平台自上次大会以来的显著增长，包括开发者数量和 API 使用量的激增。随后，重点介绍了四项核心发布：Apps SDK，允许开发者在 ChatGPT 内部构建并分发应用，支持交互式 UI 和变现；Agent Kit，提供 Agent Builder、Chat Kit 和 Evals 等工具，旨在简化智能体的构建、部署和优化流程；Codex，作为 OpenAI 的软件工程智能体，运行于新的 GPT-5 Codex 模型，大幅提升了代码重构、审查效率，并新增团队协作功能；以及模型与 API 的重大更新，包括更智能的 GPT-5 Pro、实现自然语音对话的新的先进语音模型 Realtime Mini，以及面向创作者、具有高可控性和声画一致性的 Sora 2 API 预览版。通过现场演示，文章生动展现了这些技术如何彻底改变应用开发、智能体创建和软件工程的未来。

💡 主要观点

  1. Apps SDK 赋能开发者在 ChatGPT 内部构建并分发应用 提供完整技术栈，支持数据连接、动作触发、交互式 UI 渲染，并计划支持多种变现方式，极大扩展了 AI 应用的生态和用户触达能力。
  2. Agent Kit 简化智能体开发流程，加速其从原型到生产 通过 Agent Builder 可视化构建、Chat Kit 集成聊天体验、Evals 评估智能体性能，并提供连接器注册中心，降低了智能体开发的门槛和复杂性。
  3. Codex 运行于 GPT-5 Codex 模型，重塑软件编写方式 增强了代码重构和审查能力，能动态调整思考时间，并集成 Slack、提供 SDK 和管理工具，显著提升了个人和团队的开发效率。
  4. GPT-5 Pro、Sora 2 等新模型扩展 AI 能力边界 GPT-5 Pro 提供顶级智能推理，Realtime Mini 实现自然语音对话，Sora 2 API 预览版支持高可控性、声画一致性的视频生成，为多模态内容创作带来革命性突破。
