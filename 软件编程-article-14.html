“如果你不用更多 Token，就永远逃不出底层”：AI 竞赛开始变成资源战争

5/1/2026, 2:12:00 AM

📌 一句话摘要

本文编译自 SemiAnalysis 创始人 Dylan Patel 的播客访谈，核心观点是 AI 竞赛的瓶颈正从模型能力转向资源分配，Token 已成为稀缺资源，企业需通过获取顶级模型访问权并高效利用 Token 来构建竞争优势。

📝 详细摘要

本文编译整理了 SemiAnalysis 创始人 Dylan Patel 在一档播客中的深度访谈内容。文章指出，AI 领域的核心瓶颈正从模型能力转向资源分配，Token 已成为一种高度稀缺的战略资源。Dylan 以自身公司为例，其 AI 年支出已飙升至 700 万美元，超过薪资成本的 25%，并展示了多个通过大量使用 Token 实现效率飞跃的案例，如芯片逆向工程和能源数据分析。文章深入探讨了 Anthropic 顶级模型（如 Opus 4.7 和未公开的 Mythos）带来的能力跃迁，以及由此引发的 Token 供需失衡。Dylan 预测，未来竞争的关键在于获取最先进模型的访问权，并将 Token 用于创造最高价值的地方，否则将被市场淘汰。此外，文章还分析了半导体供应链（GPU、内存、CPU）的瓶颈，并大胆预测大规模反 AI 抗议即将到来。

💡 主要观点

  1. AI 竞赛的核心瓶颈正从模型能力转向 Token 的供需与分配。 顶级模型能力持续提升，但 Token 的供给受限于算力、内存等硬件供应链，导致需求远超供给，Token 成为稀缺资源，获取访问权成为关键竞争优势。
  2. 企业需将 AI 支出视为生存性投资，而非可选项。 SemiAnalysis 的 AI 年支出已达 700 万美元，超过薪资的 25%。作者认为，不积极使用 Token 提升效率的企业将被竞争对手淘汰，因为执行成本已极低，而好想法和资源获取能力才是核心。
  3. 顶级模型的能力跃迁正在加速，但访问权将越来越集中。 Anthropic 的 Mythos 模型被认为能力接近 L6 工程师，但仅向少数客户开放。未来，最先进的模型可能被少数资金雄厚的公司垄断，形成降维打击式的竞争优势。
  4. 半导体供应链瓶颈（内存、CPU、设备）将持续加剧 Token 的稀缺性。 GPU 之外，内存（DRAM）和 CPU 因强化学习及推理后执行需求而成为新瓶颈。整个供应链从光刻机到 PCB 材料均处于紧张状态，导致硬件成本上升、交付周期延长。
  5. AI 创造的真实经济价值（幻影 GDP）远超统计数据，但社会反弹可能加剧。 Token 带来的效率提升和产出增长难以被传统 GDP 衡量。同时，随着 AI 对就业和社会的冲击显现，大规模反 AI 抗议可能在未来几个月内爆发。

💬 文章金句

  • 如果你不用更多 Token，就永远逃不出底层。
  • Token 本身已经变成一种高度稀缺资源。谁能付得起钱，谁就能用到更多。
  • 从某种意义上讲，一两年之后，很多公司的本质，可能就是在'做 token 套利'。
  • 如果你不使用更多 token，你会被困在一个'永久底层'。
  • 少谈未来，多讲当下，如果一直强调'AI 将改变一切'，只会加剧恐惧感。
