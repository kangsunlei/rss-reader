大语言模型的训练后量化算法综述

4/14/2025, 9:49:02 AM

📌 一句话摘要

本文全面综述了大语言模型训练后量化（PTQ）算法，如 GPTQ、AWQ、HQQ、SmoothQuant、QuIP 和 QuaRot 等，并对比分析了其原理、性能和适用场景。

📝 详细摘要

文章深入探讨了大语言模型（LLM）的训练后量化（PTQ）算法，旨在降低模型部署成本并提升推理效率。首先介绍了量化的基本概念，包括量化分类、量化对象和细粒度量化。接着详细阐述了 GPTQ、AWQ、HQQ、SmoothQuant、QuIP 和 QuaRot 等主流 PTQ 算法的原理、优化过程和性能表现。这些算法各有特点，例如 GPTQ 量化速度快，AWQ 在多数量化方案和模型上量化损失更小，HQQ 通过半二次优化直接优化权重误差，SmoothQuant 通过平滑激活值来降低量化难度，QuIP 则通过正交矩阵变换处理异常值。文章还对比了这些算法在量化速度、精度损失和实际应用中的表现，其中 GPTQ 适用于早期 LLM 量化，AWQ 至今仍是一种非常实用的方案，SmoothQuant 已被 Nvidia 和 Intel 集成到各自的大模型量化工具中。文章为读者提供了全面的技术参考。

💡 主要观点

  1. PTQ 是 LLM 量化的主要选择，因其训练成本较低 相比 QAT，PTQ 无需重新训练模型，只需少量或无需校验数据，简单高效，适用于参数规模庞大的 LLM。
  2. SmoothQuant 通过平滑激活值降低 LLM 量化难度，并已被业界广泛采用 SmoothQuant 通过逐通道缩放变换，平滑激活矩阵的绝对值幅度，从而降低量化难度，提高量化精度，并被 Nvidia 和 Intel 集成到各自的大模型量化工具 TensorRT-LLM 和 Neural-Compressor 中。
  3. QuIP 通过正交矩阵变换优化 LLM 量化中的异常值 QuIP 通过对权重矩阵进行正交矩阵变换，使得矩阵中的异常值改善或消失，从而使矩阵变得更容易量化。

💬 文章金句

  • 从最初的 GPTQ、AWQ 等 weight-only 的量化算法开始，到现在 LLM 从训练、推理、轻量化、Agent 等所有赛道都卷到飞起的时代，基于大模型的特性，在两年多时间里业内已有很多新的量化算法。
  • 由于 LLM 通常训练成本巨大，所以 PTQ 在 LLM 中通常是主要的量化选择，本文后续主要介绍各种 PTQ 的方案。
  • SmoothQuant 是 LLM 量化领域首个对 weight 和 activation 做全量化，并能保障良好的量化损失，从而在实际中有广泛应用的量化算法，并以被 Nvidia 和 Intel 集成到各自的大模型量化工具 TensorRT-LLM 和 Neural-Compressor 中。
