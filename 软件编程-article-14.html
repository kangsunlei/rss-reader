HuggingFace Chat v2 (HuggingChat Omni) 上线，支持 115 种开源模型及 API 调用

10/18/2025, 12:58:59 AM

📌 一句话摘要

HuggingFace Chat v2（HuggingChat Omni）重新上线，提供 115 种开源模型，支持自动模型选择和 API 调用，旨在成为比 ChatGPT 更强大的开源替代方案。

📝 详细摘要

此推文宣布了 HuggingFace Chat v2（命名为 HuggingChat Omni）的重新上线，这是一个集成了 115 种开源模型的统一界面。该平台的一大亮点是其自动模型选择功能，能为用户查询智能匹配最佳模型，并支持 API 调用，极大方便了开发者和研究人员。HuggingChat Omni 汇集了来自 15 家提供商的模型，并通过 HF 推理服务提供支持，目标是超越 ChatGPT，成为更强大的开源 AI 聊天解决方案。后续还将支持 MCP、网页搜索、文件上传和更灵活的策略定制。
