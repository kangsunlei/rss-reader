One Network：云平台无关的服务和面向策略的网络架构

8/12/2025, 9:00:00 AM

📌 一句话摘要

Google 的 One Network 统一了跨各种云环境的服务网络，通过基于开源、云平台无关且可扩展的架构，简化了策略管理和执行。

📝 详细摘要

文章详细介绍了 Google 的“One Network”，这是一项为期七年的计划，旨在创建一个统一的服务网络覆盖，以便在包括公有云、私有云和多云设置在内的异构环境中实现简化且一致的策略管理。它解决了 Google 在不同基础设施上运行的 300 多种产品所面临的复杂性，随着服务数量的增加，策略管理的复杂性呈指数级增长，形成所谓的“n 平方问题”。核心思想是将每个服务视为一个可管理的服务接入点，从而实现单一、一致的网络级策略方法。该架构建立在五个核心原则之上：使用通用的开源基础（Envoy、流量调度器、xDS API、WebAssembly），将所有内容视为服务接入点（通过负载均衡器、私有服务连接、无头服务），统一所有网络路径和环境（例如，GKE、Istio、移动、多云），培养服务扩展的开放生态系统（用于授权 AuthZ、API 管理、Web 应用程序防火墙 WAFs），并实现统一的策略执行（分段、应用程序边界）。作者强调，成功需要长期的战略投入，多个团队之间的协同工作以及持续的迭代优化，这些经验对于面临相似挑战的组织具有重要的参考价值。

💡 主要观点

  1. One Network 集中化策略管理并统一不同的网络环境。 通过将每个服务视为一个可管理的服务接入点，并建立在通用基础上，它可以解决不同基础设施的“n 平方问题”，从而简化跨公有云、私有云和多云设置的策略执行。
  2. 该架构利用开源组件和可扩展性来实现广泛的适用性。 建立在 Envoy 和 xDS API 之上，它允许通过服务扩展（Wasm 过滤器）插入自定义策略，从而可以与第一方和第三方工具集成，以实现授权 AuthZ、API 管理和 Web 应用程序防火墙 WAFs。
  3. 通过统一所有网络路径和服务表示来实现一致的策略执行。 通过概括网络路径并统一处理各种服务类型（负载均衡、生产者 - 消费者、无头服务），可以在整个网络中一致地应用分段和应用程序边界等策略。

💬 文章金句

  • One Network 是一个统一的服务网络覆盖，可简化跨不同服务和环境的策略管理。
  • 策略是云基础设施最关键的部分，控制着从安全到流量策略和合规性的所有内容。
  • 通用数据平面 API 通过第一方和第三方服务扩展了生态系统，而可扩展性 API 用于插入第一方和第三方服务，从而在整个环境中实现统一的第一方和第三方策略。
  • 开放的生态系统意味着客户可以选择使用合适的 Web 应用程序防火墙，所有这些都在同一基础设施上完成。这无需构建额外的组件，也无需处理集成难题。
  • 成功依赖于长期的战略投入，多个团队之间的协同工作以及持续的迭代优化，而不是一次性的大规模推广。
