当设计经验开始自我进化：TaoDesign 的探索与实践

11/23/2026, 6:50:00 AM

📌 一句话摘要

本文介绍了淘天团队构建的原生 AI 设计工具 TaoDesign，通过自建画板、端云沙箱架构和确定性源码处理机制，显著降低跨表示层转换损耗，提升 AI 辅助设计的生成效率与准确性。

📝 详细摘要

文章聚焦淘天面向真实需求交付的原生 AI 设计工具 TaoDesign 的探索与实践。团队最初尝试在 MasterGo 插件中实现 AI 生稿，但跨表示层转换（HTML/CSS 到画布节点）导致损耗和效果瓶颈。为解决此问题，团队放弃插件路线，转向自建浏览器画板方案，直接以 HTML/JSX 为设计产物，消除中间转换损耗。系统采用客户端、服务端、云端沙箱三层架构，支持确定性源码处理优先、Design Agent 兜底的双流水线机制，并通过异步快照与安全回滚保障版本一致性。评测显示该方案在 B 端和 C 端均可获得较高还原度的设计稿，单次生成可用率约 85%。

💡 主要观点

  1. TaoDesign 采用自建画板方案，直接以 HTML/JSX 为设计产物，消除跨表示层转换损耗 传统插件路线需将模型生成的 HTML/CSS 转换为画布节点，导致布局错乱和功能受限。自建画板让生成代码原生可渲染，支持弹窗、Tab 切换等动态交互，显著提升生成效果。
  2. 系统采用客户端、服务端、云端沙箱三层架构，实现本地交互、状态持久化与隔离的 Agent Loop 执行环境分离 客户端基于 Electron 和 SwiftUI 实现画布编辑与本地模型接力；服务端负责身份认证、任务调度与文件存储；云端沙箱提供 7×24 小时稳定的生成、修改与编译验证环境，支持闲时回收与快速恢复。
  3. 设计编辑采用确定性源码处理优先、Design Agent 兜底的双流水线机制 设计师的操作先进入待应用修改队列，按规则生成确定性代码 Diff Patch；当遇到复杂结构调整或定位失败时，自动分流至 Design Agent 重新规划 UI 结构，保证修改准确性与效率。
  4. 通过异步快照与安全回滚机制保障版本一致性与操作安全 每次 Agent 会话结束后后台 Worker 异步触发 Checkpoint 记录，主链路零阻塞；回滚前自动建立安全 Checkpoint，防止误操作丢失，确保端云状态一致。
  5. 方案在 B 端和 C 端均可获得较高还原度的设计稿，单次生成可用率约 85% 实际业务生成效果显示，千牛 B 端后台商品管理页面、交易发货中心等页面均可快速生成高还原度设计稿，局部错位可通过画布编辑人工微调完成。

💬 文章金句

  • 我们开始换一个角度思考：既然模型已经生成了符合 Web 标准的前端代码，为什么不直接用浏览器引擎承载画板，让 HTML / JSX 直接成为可渲染的设计产物？
  • TaoDesign 端·云·沙箱架构
  • 确定性源码处理（优先）
  • Design Agent（模型兜底）
  • 为此，我们设计了一套异步快照与安全回滚的机制
