📝 详细摘要

本文详细报道了 X 平台（原 Twitter）正式开源其核心推荐算法的重大事件。该算法托管于 GitHub 的 x-algorithm 仓库，上线短时间内即获得大量关注。技术上，该系统采用 Rust 和 Python 编写，核心架构从传统的启发式规则转向基于 Grok Transformer 模型的端到端学习。文章深入解析了推荐系统的七个执行阶段，包括用户数据补全、站内外内容召回、信息补全、前置过滤、多维度打分排序及最终验证推送。马斯克强调此举是为了实现「自由广场」的透明化承诺，尽管开源可能带来被「刷榜」的风险，但其长远意义在于将神秘的注意力分配机制转化为可理解、可监督的公共系统。

💡 主要观点

  1. X 推荐算法核心已转向基于 Grok Transformer 的模型驱动架构。 系统剔除了绝大部分手工设计的特征和启发式规则，完全依赖模型从用户互动序列中自主学习内容相关性，降低了基础设施复杂度。
  2. 推荐流程通过七个标准化阶段实现从海量内容到精准推送的转化。 流程涵盖了从 Thunder（站内）和 Phoenix（站外）模块召回内容，到多维度打分器（如作者多样性、相关性加权）的精细化排序与过滤。
  3. 开源旨在通过透明度建立信任并借助全球开发者力量优化系统。 马斯克试图通过公开代码减少外界对流量操纵的质疑，并计划每四周更新一次代码，开启社交平台「持续开源」的先河。
