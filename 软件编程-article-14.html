谷歌发布 A2UI v0.9：可移植、框架无关的生成式 UI

7/23/2026, 8:29:00 AM

📌 一句话摘要

谷歌发布 A2UI v0.9 标准，旨在通过框架无关的协议让 AI Agent 声明 UI 意图并在多平台原生渲染，强调与现有设计系统的一致性。

📝 详细摘要

本文报道了谷歌发布的 A2UI v0.9 标准，这是一种允许 AI 智能体声明用户界面意图，并在 Web、移动与桌面平台进行原生渲染的框架无关协议。该标准的核心理念是让智能体接入应用已有的设计系统，而非生成任意可执行代码。v0.9 版本引入了双向协议、新的 JSON 结构、Python SDK 以及对多种传输方式（如 MCP、WebSockets）的支持。文章同时梳理了该领域的竞争格局，并引用了开发者对安全漏洞、UI 冒充及界面同质化等潜在风险的担忧。

💡 主要观点

  1. 核心理念是智能体应使用应用已有的设计系统，而非自行发明新组件。 这种做法旨在确保 UI 的一致性，并避免通过传输任意可执行代码带来的安全风险。
  2. v0.9 版本引入了双向协议、Python SDK 及多种传输方式支持。 通过支持 MCP、WebSockets 等协议，增强了 Agent 与客户端之间的交互能力，并提升了流式渲染的健壮性。
  3. 社区对 AI 生成 UI 的安全性与可用性存在争议。 开发者担心可能出现 UI 冒充攻击、安全漏洞以及由于目录模型限制导致的界面同质化问题。
