本文是 React 中文周刊第 276 期，由印记中文团队编辑。内容涵盖多个热点：Component Party 作为一个多框架代码对比库，近期扩展了对 Angular、Svelte 等框架的支持；TanStack 的 RSC 实现被作者认为优于 Next.js 的实现；Expo SDK 56 正式版发布，其 UI 组件被视为生产可用。此外还介绍了 Storybook 10.4 新增的 TanStack 支持和 AI 自动配置能力、Redux Toolkit v2.12.0 发布、Google 弃用 Gemini CLI 转向 Antigravity CLI、Mark Erikson 分享的 AI Agent 工作流、Julia Evans 关于远离 Tailwind 学习 CSS 组织的文章、GL-React v6 用于创建 WebGL 着色器、Hot Updater 用于 React Native 自托管 OTA 更新、Relay 21.0 新增 TypeScript 支持和实验性 RSC 支持、SVAR Calendar 日历组件、Google 现代 Web 指导、npq 安全工具、Node.js 官方 Axios 迁移 codemod 等。

💡 主要观点

  1. Component Party 提供了多框架代码对比，有助于跨框架学习。 该工具通过代码片段展示 React、Vue、Svelte 等框架实现相同任务的方式，近期扩展了对 Angular 和 Svelte 的覆盖，是学习和比较框架差异的实用资源。
  2. TanStack 的 RSC 实现被认为优于 Next.js，引发社区讨论。 文章引用 Adam Rackis 的观点，认为 TanStack 的 React Server Components 实现与 Next.js 截然不同且更好，同时 Reddit 上也有关于从 Next.js 迁移到 TanStack Start 的讨论。
  3. Expo SDK 56 正式版发布，UI 组件达到生产可用状态。 Expo 生态持续成熟，SDK 56 的发布标志着其 UI 组件库已可用于生产环境，对 React Native 开发者是重要更新。
  4. Julia Evans 分享了远离 Tailwind 学习 CSS 组织的经验。 文章推荐了一篇关于如何结构化 CSS 的实践分享，为那些希望摆脱 Tailwind 依赖、回归传统 CSS 组织方式的开发者提供了参考。
