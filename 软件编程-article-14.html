Cloudflare Access 大幅增强私有应用支持，推出可重用访问策略

3/20/2025, 1:00:08 PM

📌 一句话摘要

Cloudflare Access 通过增强对私有应用（支持私有 IP/主机名）和引入可重用策略，简化了零信任网络访问的部署和管理。

📝 详细摘要

Cloudflare Access 通过支持私有 IP 地址和主机名以及可重用访问策略，简化了零信任网络访问（ZTNA）的部署和策略管理。过去需经 Cloudflare Gateway 间接实现，存在配置复杂、日志分散等问题；现在可直接在 Access 中定义私有应用。重新设计的自托管私有应用程序管理体验与公共主机名上的 Web 应用程序体验相匹配。用户现在可以直接在 Access 中定义私有主机名和 IP 地址的应用程序，并使用可重用访问策略。文章还介绍了私有应用程序的定义、访问方式，以及之前使用 Cloudflare Zero Trust 保护私有应用程序的方式，并解释了为什么新功能是一个巨大的进步。此外，Cloudflare 还推出了可重用策略，允许管理员创建标准化策略并在多个应用程序中分配，简化了管理。新的用户界面也提供了更直观的工作流程，用于定义和管理应用程序。

💡 主要观点

  1. Cloudflare Access 现在支持私有 IP 地址和主机名，简化了私有应用程序的保护。 管理员可以直接在 Access 中定义私有 IP 地址和主机名的应用程序，无需通过公共 DNS 暴露应用程序。
  2. 可重用策略简化了跨多个应用程序的策略管理。 管理员可以创建标准化策略并在多个应用程序中分配，从而减少了管理大量访问策略的需求。
  3. 增强的应用感知防火墙，为私有应用提供更精细的安全控制。 Gateway 的防火墙现在可以检测用户的流量是否与定义的应用程序匹配，并将流量发送到 Access 进行身份验证和授权。

💬 文章金句

  • Cloudflare Access is designed to protect internal applications and resources without the need for a traditional VPN.
  • Access Applications now support private IP addresses and hostnames.
  • With Reusable Policies， administrators can now create standardized policies --- such as high， medium， or low risk --- and assign them across multiple applications.
