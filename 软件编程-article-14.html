React Server Components 曝严重漏洞，攻击者无需认证可远程执行代码

11/9/2026, 11:00:00 AM

📌 一句话摘要

React Server Components 暴露 CVSS9.5 分高危漏洞，攻击者无需认证即可远程执行代码，影响多个构建工具包。

📝 详细摘要

React 团队于 2026 年 10 月 14 日发布安全公告，披露了 React Server Components 存在 CVSS v4 评分 9.5 的高危漏洞，编号 GHSA-xqc2-xf4c-x3h3。该漏洞影响 react-server-dom-webpack、react-server-dom-parcel、react-server-dom-turbopack 三个包，允许攻击者无需认证、无需用户交互即可远程执行代码。触发条件为响应中包含多个类型化数组且存在攻击者可控数据。受影响版本为 19.0.0 至 19.0.8、19.1.0 至 19.1.9、19.2.0 至 19.2.8 及 19.3.0，官方已发布修复版本 19.0.9、19.1.10、19.2.9 和 19.3.1。

💡 主要观点

  1. React Server Components 存在 CVSS9.5 分高危漏洞 漏洞编号为 GHSA-xqc2-xf4c-x3h3，攻击者无需认证即可远程执行代码，影响数据隐私、完整性和服务可用性。
  2. 漏洞影响三个构建工具包的多个版本 受影响包包括 react-server-dom-webpack、react-server-dom-parcel、react-server-dom-turbopack，版本范围覆盖 19.0.0 至 19.3.0，官方已发布 19.0.9、19.1.10、19.2.9 和 19.3.1 修复版本。
  3. 利用条件涉及类型化数组和可控数据 触发漏洞需要响应中同时包含多个类型化数组且存在攻击者可控数据，虽然条件罕见但仍被评为严重级别。
  4. 官方建议立即升级受影响的包 未使用服务端 React 代码或支持 React Server Components 的框架的应用不受影响，用户应优先更新到修复版本。
