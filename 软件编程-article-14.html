DeepSeek 刚宣布涨价，小扎立马“拼命”：Meta 新模型打出更低骨折价，但要一点“数据税”

8/10/2026, 5:18:00 AM

📌 一句话摘要

Meta 发布编程智能体 Muse Code 及模型 Muse Spark 1.2，以低价和数据换取的方式挑战 Anthropic 与 OpenAI，同时暗示开源策略可能转向。

📝 详细摘要

Meta 近日推出首款编程智能体 Muse Code 及其配套的编程优化模型 Muse Spark 1.2。文章详细介绍了 Muse Code 的异步后台智能体架构、可审计性设计以及在终端基准（Terminal‑Bench 2.1、DeepSWE 1.1）上的表现，并对比了 GPT‑5.6 Terra、Grok 4.5、Opus 5 等竞品。定价方面，Meta 提供标准层（每百万输入 1.25 美元、输出 4.25 美元）和贡献者层（输入 0.10 美元、输出 0.20 美元），后者要求用户提供数据以换取低价。文中还指出，此次发布未提开源，与之前 Llama 系列的开源承诺形成对比，暗示公司策略可能正在转向专有模型。

💡 主要观点

  1. Muse Code 采用异步后台智能体架构，降低延迟并支持并行处理。 通过在会话期间保持专门智能体存活，避免为每个任务重新探索代码库，提升大型代码库中的开发效率。
  2. Muse Spark 1.2 在多项基准上表现接近领先模型，但在内部基准仍落后于 Anthropic Opus 5。 在 Terminal‑Bench 2.1 得分 82.9%，略高于 GPT‑5.6 Terra 和 Grok 4.5，但低于 Opus 5 的 86.7%；在 DeepSWE 1.1 得分 59.3%，排名第三。
  3. Meta 提供两层定价，贡献者层以极低价格换取用户数据用于模型训练。 标准层每百万输入 1.25 美元、输出 4.25 美元；贡献者层每百万输入 0.10 美元、输出 0.20 美元，但要求用户选择加入以帮助改进模型，速率限制更严。
  4. 本次发布未涉及开源，与之前 Llama 系列的开源承诺形成对比，暗示 Meta 可能正在转向专有模型策略。 过去三年 Meta 以 Llama 系列树立开源形象，而 Muse Spark 仅提供云端 API，无权重下载，扎克伯格仅称将来可能有开源计划，但当前未作承诺。

💬 文章金句

  • 在测试中，我们让它同时为一个游戏构建了六个功能，且没有发生冲突。
  • 它在初始探索阶段之后仍在持续发现实质性改进。
  • 该层级价格为每百万输入 token 0.10 美元，每百万输出 token 0.20 美元。
  • 开发者必须'选择加入以帮助改进模型'，这指的是 Meta 利用第三方数据来增强底层技术。
  • Meta 承诺，该层级的提示词和生成内容不会用于训练，速率限制为每分钟每团队 3000 次请求和 400 万 token。
