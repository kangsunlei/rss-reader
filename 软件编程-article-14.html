使用 Git filter-repo 彻底清除 Git 历史中的敏感文件

8/21/2025, 8:53:11 AM

📌 一句话摘要

一位开发者分享了如何利用 Git filter-repo 工具彻底清除 Git 私有仓库中已提交的敏感文件（如证书）的痕迹。

📝 详细摘要

推文作者分享了一个从 AI 那里学到的实用 Git 技巧。当不小心将敏感文件（例如证书）提交到私有 Git 仓库后，即使后续删除，其痕迹仍会保留在 Git 历史记录中，存在安全隐患。为彻底清除这些痕迹，作者推荐使用 `Git filter-repo` 工具。该工具能够重写 Git 历史，彻底移除特定文件的所有提交记录，从而有效解决敏感信息泄露的风险。作者也向社区征集是否有更好的解决方案，体现了对技术交流的开放态度。这是一个非常实用的开发运维技巧，尤其对需要处理敏感数据的开发者具有重要价值。
