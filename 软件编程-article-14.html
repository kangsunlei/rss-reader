Claude 接管了我的电脑……

3/26/2026, 6:11:51 PM

📌 一句话摘要

Fireship《代码报告》介绍 Anthropic 发布的 Claude Computer Use 功能——让 Claude 自主控制你的 Mac——并用一段搞笑演示展示了用它同时「虚构」五份工作的全流程。

📝 详细摘要

本期 Fireship《代码报告》介绍了 Anthropic 发布的「Computer Use」功能，该功能允许 Claude 通过一条自然语言指令自主控制整台电脑：打开应用、安排任务、参加会议、编写代码等，全程无需用户坐在键盘前。 视频将该产品定位为「把工作外包给更便宜开发者」这一老套路的 AI 升级版，指出该功能目前仅支持 macOS，且深度绑定 Claude 模型。Anthropic CEO Dario Amodei 被援引警告称，未来 1 到 5 年内，50%的初级律师、顾问和金融从业者可能被 AI 完全取代。 视频对 Computer Use（付费、闭源、仅限 macOS、Claude 独占）和 OpenClaw（OpenAI 收购的开源替代品）进行了对比，类比为 Android 与 iOS 2.0 的竞争。安全方面，帕洛阿尔托网络警告 OpenClaw 将私有数据访问、不可信内容和外部通信结合在一起存在风险。 最精彩的是演示环节：主持人模拟同时在职五家公司，展示 Claude 自动撰写并发送求职信、面试时实时解决 LeetCode 算法题、自动加入周一 Zoom 晨会、配合本地语音 AI 模型代替本人发言、故意将代码 PR 推迟到周五下午 4:30 以模拟一周人类工作产出，以及登录银行账户核查工资到账。 视频末尾有 SerpApi 的赞助广告段落。整体风格简洁风趣，对技术受众信息密度不低，但内容较短，缺乏深度技术或分析性内容。

💡 主要观点

  1. Claude Computer Use 支持通过单条指令实现完整的电脑自主控制 该功能允许 Claude 打开应用、撰写报告、安排任务、参加会议并与同事互动——全程用户无需在场。目前要求 macOS 系统，且绑定 Claude 模型。
  2. 开源替代品 OpenClaw 以开放性换取了更高的安全风险 OpenClaw 被 OpenAI 收购，支持本地运行任意模型，但需要掌握命令行工具，且因兼具私有数据访问与外部通信能力而被安全机构标注为风险。Computer Use vs OpenClaw 的竞争格局类似 Android vs iOS。
  3. Dario Amodei 警告 5 年内白领岗位将有 50%被取代 Anthropic CEO 公开表示，初级律师、顾问和金融从业者近期面临被 AI 自动化取代的生存威胁，这也是 Anthropic 和 OpenAI 都在争夺个人计算设备控制权的战略背景。
  4. Computer Use 采用「权限优先」的安全模型 与 OpenClaw 不同，Computer Use 在访问新应用前会征求用户同意，且只能接触用户明确授权的文件夹，对不擅长命令行的普通用户更友好。
  5. 「身兼五职」的讽刺演示揭示了真实能力与社会伦理隐忧 自动投递简历、实时破解面试算法题、代入会议、AI 发言、卡时间点提交 PR、管理银行账户——这段幽默演示在展现真实自主性的同时，也引发了关于职场诚信的严肃问题。
