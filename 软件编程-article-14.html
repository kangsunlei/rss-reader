被 Vibe Coding 坑惨了？TypeScript 大神开源 skill：技能描述 Token 成本狂降 63%，AI 自主判断技能调用？

6/18/2026, 7:39:00 AM

📌 一句话摘要

TypeScript 大神 Matt Pocock 开源项目 skills 发布 v1 更新，通过将技能调用权从模型交还给用户并精简描述，使技能描述的 Token 成本降低 63%，并新增 ask-matt 元技能等关键能力。

📝 详细摘要

文章报道了 TypeScript 社区知名开发者 Matt Pocock 的开源项目 skills 的 v1 版本更新。核心变化包括：将技能调用模式分为「用户主动调用」和「模型自主调用」两类，大幅减少模型自动调用的技能数量，并精简技能描述文字，从而使技能描述的 Token 成本降低 63%。新增的 ask-matt 元技能将 Matt 本人的工程思考框架打包，用户输入任务后，AI 会推荐并驱动执行一整套工程流程。此外还新增了 codebase-design（深模块架构方法论）、domain-modeling（领域建模）等技能，并重写了 writing-great-skills 指南。文章引用了 Matt 本人的观点，强调将认知负担放在用户身上，而非让模型掌控一切。

💡 主要观点

  1. 技能调用权从模型交还给用户，是降低 Token 成本的关键。 v1 将大量技能从「模型自动调用」改为「用户手动调用」，同时精简技能描述，使 Token 成本降低 63%。Matt 明确表示更希望认知负担放在用户身上，而非模型。
  2. 新增 ask-matt 元技能，将工程思考框架打包为可复用流程。 ask-matt 是一个用户触发的路由器，分析任务性质后推荐并驱动执行需求拷问、领域建模、架构设计、TDD 等一整套工程流程，相当于把 Matt 本人的经验封装成可调用的技能。
  3. 新增 codebase-design 和 domain-modeling 等硬核技能。 codebase-design 引入「深模块」架构方法论，domain-modeling 帮助建立和维护业务领域模型，这些技能进一步丰富了 AI 辅助工程的能力集。

💬 文章金句

  • 我更希望认知负担更多地放在用户身上。
  • GSD、BMAD 和 Spec-Kit 等方法试图通过掌控整个流程来提供帮助。但与此同时，它们也剥夺了你的控制权，使流程中的错误难以解决。
