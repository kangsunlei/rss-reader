蜂群 Agent 来了！openJiuwen 社区发布 JiuwenSwarm，引领 Coordination Engineering 新范式

5/18/2026, 7:37:00 AM

📌 一句话摘要

华为支持的开源社区 openJiuwen 发布并开源了多智能体协作框架 JiuwenSwarm，提出 Coordination Engineering（协同工程）新范式，旨在解决多 Agent 在复杂任务中的分工、协作、经验沉淀与持续演进问题。

📝 详细摘要

本文介绍了 openJiuwen 社区发布的开源多智能体协作框架 JiuwenSwarm，并提出了从 Harness Engineering 到 Coordination Engineering 的范式演进。文章指出，随着 AI Agent 从单点任务向长链路、多角色、可复用的复杂场景演进，多智能体协作成为下一个核心工程命题。JiuwenSwarm 围绕四个核心组件构建：Agent Swarm（多 Agent 成军与协同机制）、Swarm Skills（团队级协作经验的标准化封装）、Swarm Skills Hub（技能共享市场）以及 Swarm Skills 自演进（从执行轨迹中自动反推可复用技能）。此外，文章还介绍了 HOTS（Human on the Swarm）和 HITS（Human in the Swarm）两种人机协作模式，并通过医疗会诊、昇腾算子开发、短视频创作、狼人杀游戏等案例展示了其实际效果。在 PinchBench 评测中，JiuwenSwarm 以 94.2% 的综合得分取得 SOTA，同时 token 消耗降低 34.8%。

💡 主要观点

  1. AI Agent 工程范式正从 Harness Engineering 走向 Coordination Engineering。 Harness 强调单 Agent 的约束与纠错，而 Coordination 在此基础上关注多 Agent 的组织、协作与持续进化，以应对长链路、多角色的复杂真实场景。
  2. JiuwenSwarm 提供了一套完整的全栈多智能体协作技术体系。 该体系包括 Agent Swarm（协同机制）、Swarm Skills（经验沉淀）、Swarm Skills Hub（技能共享）和 Swarm Skills 自演进（自动优化），形成了从协作到沉淀再到进化的闭环。
  3. JiuwenSwarm 支持 HOTS 和 HITS 两种人机协作模式。 HOTS 让人作为指挥官全局调度 Agent 团队，HITS 则让人作为团队成员与 Agent 沉浸式协作，两种模式覆盖了人与智能体团队协作的核心姿态。
  4. JiuwenSwarm 在 PinchBench 评测中取得 SOTA，并显著降低 token 消耗。 以 94.2% 的综合得分超越 OpenClaw 的 91.6%，同时平均 token 消耗降低 34.8%，验证了其多 Agent 协同在准确率和成本上的双重优势。
