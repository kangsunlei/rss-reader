Anthropic 推出用于自定义 Claude 任务的技能

10/25/2025, 10:05:00 AM

📌 一句话摘要

Anthropic 为 Claude 引入了“技能 (Skills)”，使开发者能够使用模块化、可重用的任务组件来扩展人工智能，强调透明性、可审计性和精细控制，以实现专门化应用。

📝 详细摘要

Anthropic 推出了“技能 (Skills)”，一项允许开发者使用独立的、可重用的任务组件增强 Claude 能力的新功能。这些技能可以在对话期间被 Claude 调用，执行诸如总结文档、检索应用程序编程接口 (API) 数据或执行特定领域计算等操作。该功能可以通过 Claude 的 Web 应用程序、代码环境和 API 访问，并提供一个新的 `/v1/skills` 端点，用于创作和管理版本。技能在安全的代码运行环境 (Code Execution Tool) 中运行，并由模式 (Schema) 定义，从而实现动态调用和与外部系统的无缝集成。虽然类似于 OpenAI 的 GPT 模型中的函数调用和微软的 Copilot 生态系统，但 Anthropic 强调了一种更透明和可审计的方法，这与其对模型安全性和可解释性的关注相一致。这种架构提供了对数据访问和操作执行的精细控制，吸引了那些优先考虑灵活性和合规性的企业。早期采用者对专业化和代理潜力表示出极大的热情，Anthropic 计划提供进一步的文档和社区支持。

💡 主要观点

  1. Anthropic 的“技能 (Skills)”使开发者能够使用模块化、可重用的任务组件来扩展 Claude。 技能允许 Claude 动态地执行特定的功能，如数据检索、总结或外部操作，从而显著增强了其多功能性和适应性，以满足专业的业务和研究需求。
  2. 技能 (Skills) 功能优先考虑透明性、可审计性和精细的开发者控制。 与竞争对手的产品不同，技能由模式 (Schema) 定义，并在明确的边界内运行，确保 Claude 只访问允许的数据和操作，使其对专注于安全和合规性的企业极具吸引力。
  3. 技能 (Skills) 代表着人工智能应用朝着更加专业化和代理化的未来迈出了一步。 通过允许 Claude 动态地调用特定能力并与外部系统集成，技能促进了复杂人工智能代理的开发，这些代理能够执行复杂的自动化工作流程和适应性智能。

💬 文章金句

  • 每个技能 (Skill) 都是一个独立的能力，Claude 可以在对话期间调用它，例如总结长文档、从应用程序编程接口 (API) 检索数据或执行特定领域的计算。
  • 这种架构与 OpenAI 的 GPT 模型和微软的 Copilot 生态系统已经采用的函数调用范例相似，但 Anthropic 强调了一种更透明和可审计的方法，这与其对模型安全性和可解释性的关注相一致。
  • 每个技能 (Skill) 都在明确定义的边界内运行，确保 Claude 只访问开发者明确允许的数据和执行操作。这种精细的控制可以使该系统对寻求灵活性和合规性的企业更具吸引力。
  • Claude 不仅仅变得更聪明，它还变得专业化了。自动化的未来是个性化的、持久的和自由的。
