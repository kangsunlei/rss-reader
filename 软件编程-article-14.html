Framework 台式机：性能怪兽

8/7/2025, 3:53:01 PM

📌 一句话摘要

Framework 台式机，由 AMD Ryzen AI Max 395+ 驱动，在安静、紧凑且可修复的设计中提供卓越的多核性能，为开发者提供相较于预组装电脑更卓越的价值。

📝 详细摘要

本文对 Framework 台式机进行了深入评测，重点介绍了其卓越的性能、紧凑的尺寸 (4.5 升) 和静音运行，即使在高负载下也是如此。最初，作者对 Framework 进入台式机市场表示好奇，因为台式机通常是用户可修复的。然而，他通过详细介绍 Framework 集成强大的 AMD Ryzen AI Max 395+ 笔记本电脑 CPU 的独特方法来证明这一点，这使其具有微小的体积和静音性能。文章还赞扬了其可定制的美学设计，3D 打印的前面板相较于传统设计，令人耳目一新。基准测试表明其卓越的多核性能，尤其是在以开发者为中心的工作负载（如依赖 Docker 的重负载测试套件）中，它显著优于包括 Apple 的 M4 Max / M4 Pro 芯片在内的竞争对手，部分原因是 Linux 原生的 Docker 效率。虽然承认 Apple 在单核性能方面处于领先地位，但作者认为这种差异在日常使用中可以忽略不计。一个关键的结论是 Framework 台式机具有出色的性价比，成本几乎是配置相似的 Mac Studio 的一半。文章还提到了其令人惊讶的游戏能力，与 RTX 4060 相当，并且适合运行本地大型语言模型（具有足够的内存）。最终，它将 Framework 台式机定位为寻求强大、安静且用户友好的机器的开发者和 Linux 爱好者的理想选择。

💡 主要观点

  1. Framework 台式机在开发者工作负载的多核性能方面表现出色。 该机器利用 AMD 395+ CPU，在多核任务中表现出明显更快的性能，尤其是在 Linux 上的 Docker 中，使其在软件开发测试套件的运行和复杂计算中表现出极高的效率。
  2. 它将高性能与安静、紧凑且用户可修复的设计相结合。 尽管其内部结构强大，但 Framework 台式机保持静音运行和 4.5 升的微小体积，坚持 Framework 对用户可修复性和可定制性的承诺，这在高性能 PC 中是罕见的结合。
  3. 与高端替代品相比，Framework 台式机提供了卓越的价值。 凭借可比的规格，Framework 台式机比 Mac Studio 便宜得多。对于寻求高端功能但又注重性价比的开发者和高级用户来说，极具吸引力。

💬 文章金句

  • 它完全安静，即使在高负载、所有核心都承受压力的情况下也是如此。它也很小，只有 4.5 升的体积，特别是与我旧的漂亮但笨重的 North 机箱运行 7950X 相比，但性能更强！
  • Framework 台式机绝对碾压它。它几乎是 Beelink SER8 的两倍快，并且仍然比 Beelink SER9 快三分之一。
  • 它比 M4 Max 快 40%，比 M4 Pro 快 50%！现在有些人会说“这只是因为 Docker 在 Linux 上更快”，他们并没有完全错。
  • 配备 64 GB 内存 + 2 TB NVMe 的 Framework 台式机售价 1，876 美元。要获得具有类似规格的 Mac Studio --- M4 Max、64 GB 内存、2 TB NVMe --- 你实际上要花费近两倍的价格，为 3，299 美元！
  • 如果你只是想要最好的、开箱即用的、运行 Linux 非常出色的小型计算机，你应该购买 Framework 台式机。
