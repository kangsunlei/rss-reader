Apple 容器化：macOS 的原生 Linux 容器支持

6/12/2025, 12:00:00 AM

📌 一句话摘要

Apple 在 WWDC 2025 上宣布，为 macOS 26 引入原生 Linux 容器支持，采用开源的每容器独立轻量级虚拟机方案。

📝 详细摘要

在 WWDC 2025 上，Apple 发布了容器化 (Containerization) 和 Container CLI，这是一个开源框架和工具，使开发者能够将 Linux 容器作为轻量级虚拟机原生运行在 macOS 上。通过让每个容器运行在独立的虚拟机内，这一重大转变消除了对 Docker 等第三方工具的需求，从而增强了安全性、提供了专用资源并改进了隐私。该框架主要使用 Swift 构建，具有自定义的基于 Swift 的 init 系统（`vminitd`），并利用了 Swift 的 Static Linux SDK 和 `musl` 进行静态链接。Apple 声称由于优化内核和 Apple Silicon 特定增强，启动时间可达亚秒级。`container` CLI 提供了熟悉的命令行界面，用于管理镜像和运行容器。该解决方案已在 GitHub 上发布，它与 Podman 或 containerd 等使用的传统共享内核容器化技术不同，为 macOS 开发者提供了一种独特的原生选项。

💡 主要观点

  1. Apple 通过轻量级虚拟机在 macOS 上引入原生 Linux 容器执行。 新的容器化框架和 CLI 允许直接在 macOS 26 上运行 Linux 容器，无需依赖外部虚拟化解决方案，从而简化了开发工作流程。
  2. 每容器独立虚拟机架构增强了安全性、隐私和资源隔离。 将每个容器隔离在独立的轻量级虚拟机内，通过减少攻击面来提高安全性，并为每个容器提供专用的网络/CPU/内存资源。
  3. 该框架是开源的、基于 Swift 的，并针对 Apple Silicon 进行了优化。 已在 GitHub 上发布，基于 Swift 的实现针对 Apple Silicon 进行了优化，旨在提升性能并允许社区贡献，从而促进采用和透明度。

💬 文章金句

  • Apple 在 WWDC 2025 上宣布了容器化 (Containerization) 和 Container CLI，这是一个在 Mac 上创建和运行 Linux 容器作为轻量级虚拟机的工具。
  • 与在单个大型虚拟机中运行多个容器的传统容器化解决方案不同，Apple 的方法是在独立的轻量级虚拟机内运行每个 Linux 容器。
  • 每个容器都获得与完整虚拟机相同的隔离级别，显著减少了攻击面。
  • Apple 已将容器化框架和 container CLI 工具作为开源项目在 GitHub 上发布。
  • Apple 这种将每个容器运行在独立的轻量级虚拟机内的独特方法使其区别于这些现有解决方案，后者通常依赖于 cgroups 和 namespaces 等共享内核容器化技术。
