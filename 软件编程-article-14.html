开源个小插件：直接在浏览器中批注 UI 修改内容，本地 Claude Code 实时修改

6/14/2026, 4:14:21 AM

📌 一句话摘要

PinFix 是一个开源前端开发插件，允许开发者在浏览器中直接批注 UI 元素，并将批注与源码位置一起发送给 Claude Code 进行实时修改。

📝 详细摘要

本文作者介绍了自己开发的开源工具 PinFix，旨在解决使用 Claude Code 调整前端 UI 时，需要编写复杂 prompt 描述修改位置的问题。PinFix 通过注入源码位置信息，让开发者可以在浏览器中直接点击 UI 元素并添加批注，然后将批注和源码位置一起交给本地的 Claude Code 进行修改，修改后通过 HMR 实时查看效果。目前支持 Vite、Webpack、Rspack、Rsbuild 等主流构建工具。

💡 主要观点

  1. PinFix 解决了 AI 编程中描述 UI 修改位置困难的问题。 传统方式需要编写复杂的 prompt 描述 UI 修改位置，容易出错且效率低。PinFix 通过可视化批注，让开发者直接在页面上标记修改位置，避免了描述歧义。
  2. PinFix 通过注入源码位置信息实现精准定位。 在开发服务器运行时，PinFix 自动向页面元素注入源码位置信息，使得批注时能准确获取 UI 元素对应的源码文件和行号，从而让 Claude Code 精确修改。
  3. PinFix 支持主流前端构建工具。 目前支持 Vite、Webpack、Rspack、Rsbuild，覆盖了大多数前端开发场景，降低了使用门槛。

💬 文章金句

  • 直接在本地运行的前端页面上，点一下你想改的地方，留一句批注，然后把这条批注和对应的源码位置一起交给你本地的 Claude Code。
