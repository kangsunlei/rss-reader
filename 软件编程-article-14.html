GitHub 发布 Agentic Workflows：开启 AI 驱动的自动化新篇章

2/27/2026, 7:18:35 PM

📌 一句话摘要

GitHub 推出 Agentic Workflows，允许开发者使用 Copilot 和 Claude 等 AI 模型，将 Markdown 描述直接转换为可执行的工作流。

📝 详细摘要

GitHub 宣布推出 “Agentic Workflows”，这是一项通过 AI 将 Markdown 需求转化为功能完备的可执行工作流来简化自动化的新功能。该系统支持包括 GitHub Copilot、Anthropic 的 Claude 以及 OpenAI Codex 在内的多种 AI 后端，标志着 AI 驱动的 DevOps 和仓库管理迈出了重要一步。该功能旨在通过自然语言处理技术，降低创建复杂自动化的门槛。
