半价“背刺”Fable 5，Opus 5 登场！A 社高管：Kimi K3 更便宜，但复杂项目表现待观察

7/25/2026, 3:37:00 AM

📌 一句话摘要

Anthropic 发布 Opus 5 模型，定价仅为 Fable 5 一半，在编码和知识工作上表现相当，强调 token 效率而非能力飞跃。

📝 详细摘要

Anthropic 于 2026 年 7 月 25 日发布 Opus 5 模型，宣称其能力接近商用最强模型 Fable 5，而价格仅为后者的一半，且安全限制更宽松。文章详细列出了多项基准测试结果：在 Frontier‑Bench 中得分较前代翻倍有余并超越所有竞品；在 ARC‑AGI 3 上得分约为次优模型的 3 倍；在 CursorBench 3.2、Zapier AutomationBench 和 OSWorld 2.0 等测试中，以更低的 token 消耗达到相当或更佳的性能。文章还指出，Anthropic 在新模型中移除了约 80% 的 Claude Code 系统提示，同时保留特定网络安全和生物领域的防护，并推出“自动回退”功能以降低误触影响。高管 Dianne Penn 建议开发者在日常高性价比场景使用 Opus 5，而将持续数天的高度自主项目交给 Fable 5；她对开源模型 Kimi K3 在复杂实际项目中的表现持观望态度。

💡 主要观点

  1. Opus 5 在编码和知识工作上接近或略超 Fable 5，基准测试显著优于前代。 在 Frontier‑Bench 得分翻倍有余，ARC‑AGI 3 得分约为次优模型的 3 倍；多项编码基准中与 Fable 5 持平或略胜。
  2. 核心优势在于 token 效率，相同成本下性能更高，定价仅为 Fable 5 的一半。 API 价格为每百万输入 token 5 美元、输出 25 美元；在 OSWorld 2.0 中以约 Fable 5 三分之一价格超越其最佳成绩，且在多项任务中 token 消耗更少。
  3. 安全策略更为宽松，移除约 80% 的 Claude Code 系统提示，保留特定网络安全和生物领域防护，并提供自动回退机制。 Anthropic 表示安全分类器干预频率将比 Fable 5 降低约 85%；允许在源码中搜索漏洞而非二进制扫描，以支持良性使用。
  4. 尽管在复杂长期自主项目中的表现仍待观察，Anthropic 建议将 Opus 5 用于日常高性价比场景，保留 Fable 5 用于持续数天的自主任务。 高管 Dianne Penn 指出用户应根据项目复杂度选择模型，开源模型如 Kimi K3 在实际复杂项目中的表现还有待验证。

💬 文章金句

  • Opus 5 的能力接近其商用最强模型 Fable 5，而价格仅为后者的一半，且安全限制比 Fable 模型更宽松，很可能在大多数使用场景中成为更优选择。
  • 在 Frontier‑Bench（一项衡量模型能否根据工程图纸构建可用软件的编码评估）中，Opus 5 的得分较前代翻倍有余，并超越了所有竞品，包括 Fable 5。
  • 在宣布新模型的博文中，Anthropic 强调，Opus 5“在验证自身工作并反复推敲直至成功方面更加强大”。
  • Anthropic 表示，‘Claude Opus 5 的安全措施旨在允许模型在网络安全和生物学领域的良性使用’。‘根据我们的测试，我们预计分类器的干预频率将比 Fable 5 低约 85%。’
  • 用户应该选择 Opus 5 来获得更高的性价比，而选择 Fable5 来处理‘持续数天的、高度自主的项目’。
