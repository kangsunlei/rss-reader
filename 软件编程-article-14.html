Chrome 发布 WebMCP 预览版：开启 Agentic Web 高效模式

3/2/2026, 12:03:50 PM

📌 一句话摘要

Chrome 推出 WebMCP 预览版，通过声明式和命令式 API 让 AI 直接调用网站工具，显著提升 Agent 操作效率与准确率。

📝 详细摘要

本推文介绍了 Chrome 浏览器推出的 WebMCP（Web Model Context Protocol）预览版。该协议提供了声明式（HTML 标签）和命令式（JavaScript）两种 API，旨在为 Agentic Web 奠定基础。相比于传统的视觉识别和页面抓取，WebMCP 允许网站直接向 AI 提供函数接口，使 AI 能像调用 API 一样执行下单、搜索等复杂操作，极大地降低了视觉 Token 消耗，并将准确率提升至接近 100%。
