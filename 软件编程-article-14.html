Redis 之父为 DeepSeek 抱不平：美国 AI 圈又为“蒸馏”吵起来了

6/16/2026, 8:59:00 AM

📌 一句话摘要

Redis 之父 antirez 发推反驳美国 AI 圈关于 DeepSeek 等中国模型通过 API 蒸馏美国模型的指控，指出技术定义被混淆且预设不公，引发业界对蒸馏定义、技术能力与舆论偏见的讨论。

📝 详细摘要

本文报道了 Redis 之父 Salvatore Sanfilippo（antirez）在 X 上针对美国 AI 圈流行的「中国模型通过 API 蒸馏美国模型」说法进行的激烈反驳。antirez 从技术角度提出「不可能三角」：API 无法提供完整 logits 与思维链、数学上无法从少量输出点还原复杂模型、信息路径不明确。他引用 DeepSeek 公开的预训练、SFT 和 RL 管线细节及社区复现结果，认为其能力来自真实的工程创新而非蒸馏。文章进一步梳理了业界分歧：Redwood Research 首席科学家 Ryan Greenblatt 和 AI2 研究员 Nathan Lambert 指出 antirez 对「蒸馏」的定义过于狭义，但认同「蒸馏」一词已被武器化为道德指控。文章还引用 Linux Foundation AI & Data CTO Matt White 和 Nathan Lambert 的中国行观察，强调中国 AI 实验室的年轻化、开源文化与工程能力，认为这才是 DeepSeek 等快速进步的真实原因。

💡 主要观点

  1. antirez 认为通过 API 蒸馏模型在技术上不可行。 他提出三个核心论据：API 无法提供完整 logits 和思维链中间输出；从少量输出点无法还原复杂模型曲面；缺乏预训练所需的数万亿 token 和 RL 所需的奖励信号等明确信息路径。
  2. 业界对「蒸馏」定义存在根本分歧。 antirez 坚持经典知识蒸馏（白盒蒸馏）定义，需要完整 logits；而 Ryan Greenblatt 和 Nathan Lambert 指出，通过 API 收集 (指令， 输出) 对进行黑盒蒸馏已被 Alpaca、Vicuna 等项目证明可行，antirez 的定义过于狭窄。
  3. 「蒸馏」一词已被武器化为道德指控。 Nathan Lambert 指出，将「在其他模型输出上训练」称为「蒸馏攻击」是刻意选择带有负面色彩的术语，目的是将商业利益诉求包装成道德框架，以维护先发优势。
  4. 中国 AI 实验室的真实优势在于工程文化与开源生态。 Matt White 和 Nathan Lambert 的中国行观察显示，中国实验室普遍年轻（平均 25 岁）、精简、以开源为默认选项，DeepSeek 的 GRPO、Muon 优化器等创新被全球采纳，其能力来自密集的工程优化而非捷径。

💬 文章金句

  • 中国模型之所以强大，绝不是因为它们对美国模型进行'蒸馏'。通过 API 进行模型蒸馏是不可能的。如果有人告诉你相反的情况，那说明他们根本不懂机器学习。
  • 「蒸馏」这个词很好，因为它会让人联想到私酒和 20 世纪 20 年代禁酒令时期那种地下交易的氛围。'攻击'这个词也很好，因为只有坏人才会攻击。
  • 如果说有一个实验室在整个中国 AI 生态中获得普遍尊重，那就是 DeepSeek。
