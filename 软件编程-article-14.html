Bun 推出内置数据库客户端与零配置前端开发

1/9/2026, 5:31:00 AM

📌 一句话摘要

Bun 1.3 版本发布，实现全栈开发能力，内置数据库和 Redis 客户端，支持零配置前端开发，并显著提升了运行时性能与包管理功能。

📝 详细摘要

Bun 1.3 版本标志着其成为一个功能更全面的 JavaScript 运行时环境。此版本引入了零配置前端开发模式，支持 HTML 文件直接运行并自动处理 JS、CSS 和 React 的转译与打包，且内置模块热替换功能。核心更新包括 Bun.SQL，这是一个统一的数据库 API，支持 MySQL、PostgreSQL 等多种数据库且不依赖外部组件。此外，还新增了内置的 Redis 客户端，性能远超流行包 ioredis。在包管理方面，Bun 1.3 引入了单体库依赖项目录和隔离安装模式，并增强了漏洞检测功能。性能方面，Next.js 和 Elysia 等框架的内存占用减少 10%-30%，I/O 操作和网络协议处理速度也有明显提升。尽管社区对此反响褒贬不一，Bun 仍通过将常用功能集成到运行时中，继续与 Node.js 和 Deno 等竞争对手保持差异化优势。

💡 主要观点

  1. Bun 1.3 实现全栈开发能力，推出零配置前端开发模式。 开发者可直接运行 HTML 文件，Bun 自动处理 JS、CSS、React 转译打包及热重载，简化前端开发流程。
  2. 引入统一的 Bun.SQL API，内置支持多种数据库且无外部依赖。 它为 MySQL、PostgreSQL、SQLite 等数据库提供了高性能的原生统一语法，极大方便了后端数据操作。
  3. 新增内置高性能 Redis 客户端，增强了数据缓存和操作能力。 该客户端性能远超流行的 ioredis 包，并支持所有标准 Redis 操作，提升了数据层的性能和开发效率。
  4. 显著提升运行时整体性能，降低内存占用和 I/O 延迟。 Next.js 和 Elysia 等框架内存占用减少 10%-30%，并优化了文件 I/O 和网络协议处理速度，提升了开发和生产效率。
  5. 扩展包管理功能，引入单体库依赖项目录和隔离安装模式。 此举增强了包管理的灵活性和安全性，同时新增交互式更新和依赖链解析命令，优化了开发者体验。

💬 文章金句

  • Bun 1.3 引入了零配置前端开发模式，内置模块热替换功能并支持 React 快速刷新。开发人员现在可以直接通过 Bun 运行 HTML 文件，系统将自动处理 JavaScript、CSS 及 React 的转译与打包。
  • Bun 1.3 的核心功能之一是 Bun.SQL，这是一个支持 MySQL、MariaDB、PostgreSQL 和 SQLite 的统一 API，而且完全不依赖外部组件。
  • 本次发布还引入了一个内置的 Redis 客户端，其性能比流行的 ioredis 包高出 7.9 倍以上。它支持所有的标准 Redis 操作。
  • 此次更新堪称迄今为止最大的一个版本，不仅实现了全栈开发能力，还推出了统一的数据库 API，并显著提升了运行时的整体性能。
  • 相较于 Node.js 和 Deno 等竞争对手，Bun 通过将常用功能直接打包到运行时环境中继续保持差异化优势。
