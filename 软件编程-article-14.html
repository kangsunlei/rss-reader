提升后量子加密使用、加密消息及路由安全的透明度

2/27/2026, 2:00:08 PM

📌 一句话摘要

Cloudflare Radar 推出了全新的透明度工具和数据集，用于追踪后量子加密的采用情况、审计端到端加密消息密钥，以及监控基于 ASPA 的 BGP 路由安全。

📝 详细摘要

Cloudflare Radar 对其安全洞察平台进行了重大更新，重点关注现代互联网基础设施的三大支柱：后量子密码学 (PQC)、加密消息完整性和路由安全。此次更新将 PQC 监控从客户端扩展到了面向源站的连接，结果显示，虽然客户端支持率已超过 60%，但目前只有约 10% 的源站服务器支持混合后量子密钥交换 (X25519MLKEM768)。为了助力这一转型，Cloudflare 推出了一个由 Cloudflare Containers 驱动的公开测试工具，允许用户验证任何网站的 PQ 就绪情况。在消息领域，新增的“密钥透明度”板块提供了一个公共仪表板，用于审计 WhatsApp 和 Facebook Messenger 等服务的公钥日志，利用可审计密钥目录 (AKD) 技术防止未经授权的密钥替换。最后，该平台现在开始追踪 ASPA (自治系统提供商授权) 的采用情况，这是一种新兴的 BGP 安全标准，通过验证路由公告的路径来防止泄漏和劫持。文章强调了 OpenSSL 3.5.0 和 Go 1.24 等现代密码库在推动 PQC 采用方面的作用。这些指标可通过 Radar 仪表板及其 API 获取，为研究人员和网络运营商提供推动采用更安全互联网协议所需的数据。

💡 主要观点

  1. Cloudflare Radar 扩展了其后量子加密监控，将面向源站的连接纳入其中，提供了更完整的抗量子技术采用视图。 通过使用自动化 TLS 扫描器探测源站，Cloudflare 追踪了 X25519MLKEM768 混合算法的采用情况。这些数据帮助业界了解除“浏览器到边缘”环节之外的转型进展，并指出过去一年源站支持率增长了 10 倍。
  2. 全新的密钥透明度仪表板为端到端加密消息服务中使用的公钥日志提供实时验证状态。 该功能允许用户和研究人员监控 WhatsApp 等应用的公钥分发完整性。通过审计可审计密钥目录 (AKD) 并发布周期签名，Cloudflare 提供了一个独立的信任层，以防止涉及密钥替换的中间人攻击。
  3. 该平台现在开始追踪 ASPA 的全球部署情况，这是一种旨在通过路径验证防止路由泄漏的新兴 BGP 标准。 ASPA 通过验证 BGP 路径中客户与提供商之间的关系来扩展 RPKI。Radar 的新工具允许网络运营商检查 ASPA 记录，追踪不同注册机构的采用趋势，并实时验证特定自治系统的路由健康状况。
  4. Cloudflare 推出了一个公开的 Web 工具和 API，允许任何人测试特定主机名的后量子加密兼容性。 该工具基于 Cloudflare Containers 和 Go 的 crypto/tls 包构建，通过执行按需握手来确定服务器是否支持或首选后量子密钥交换。这降低了开发人员和管理员验证其自身基础设施就绪情况的门槛。

💬 文章金句

  • 用户到 Cloudflare 连接的后量子加密支持仅仅是故事的一部分。
  • 密钥透明度通过创建一个可审计、仅追加的公钥日志来解决这一挑战。
  • ASPA 通过允许自治系统 (AS) 对列出授权将其路由传播到上游的网络的记录进行加密签名，从而扩展了 RPKI 保护。
  • 可见性是广泛采用 ASPA 等新兴路由安全协议的重要第一步。
