编程 Agent 可能是软件开发史上最昂贵的错误之一

5/26/2026, 6:05:00 AM

📌 一句话摘要

George Hotz 等资深技术专家警告，AI 编程 Agent 正在大规模生成难以维护和理解的劣质代码，可能导致软件质量危机和成本失控。

📝 详细摘要

本文综合报道了以 George Hotz 为代表的技术专家对 AI 编程 Agent 的严厉批评。Hotz 在亲身实践六个月后得出结论：Agent 本质上是模仿编程分布的统计模型，其生成的代码质量低下且问题隐蔽，大规模采用将导致「垃圾代码的黄金时代」。文章还引用了 OpenClaw 核心工程师 Mario Zechner 和 Armin Ronacher 的警告，他们指出 AI 正在制造大量「vibe slop」代码，导致基础设施崩溃、技术债累积。此外，Uber 高管透露 AI token 消耗成本难以与业务产出挂钩，公司已开始放缓招聘。文章呈现了 AI 编程热潮背后关于代码质量、成本效益和长期可持续性的深刻争议。

💡 主要观点

  1. AI 编程 Agent 本质是统计模型，无法真正理解代码逻辑。 George Hotz 认为 Agent 只是模仿编程的分布，生成的代码在语法上看似正确，但缺乏人类程序员的心智模型，导致问题隐蔽且难以排查。
  2. 大规模使用 AI Agent 将导致代码质量全面下降和技术债累积。 OpenClaw 工程师指出，AI 生成的「vibe slop」代码缺乏严谨设计和测试，长期来看会破坏软件基础设施，增加安全漏洞和维护成本。
  3. AI 编程的成本效益尚未得到验证，投入产出比存疑。 Uber 高管表示，AI token 消耗与有用功能产出之间缺乏直接关联，公司难以证明其合理性，已开始放缓招聘以对冲成本。

💬 文章金句

  • Agent 不会编程，而且我们意识到它们不会编程这件事，正在变得越来越难。
  • Agent 最终会生产出比以往更多的代码、更多的应用、更多的功能。这会是一个垃圾代码成吨涌出的黄金时代，也会是高质量精品的黑暗时代。
  • 基础设施正在崩溃，软件比以前漏洞百出。我们还能再玩几个月甚至几年，但它最终会让我们付出代价。
  • 很难把其中某一个指标和'好，现在我们实际产出了 25% 更多有用的消费者功能'直接对应起来。
