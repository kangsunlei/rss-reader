JavaScript 中 __proto__、prototype 与继承机制详解

11/4/2025, 4:44:51 PM

📌 一句话摘要

本文深入解析 JavaScript 原型继承机制，阐明 `__proto__` 和 `prototype` 在实现对象、函数和类的继承中的关键作用。

📝 详细摘要

本文全面解释了 JavaScript 的 prototype 系统，解决了围绕 `__proto__`、`prototype` 和继承的常见困惑。首先，它通过隐式类型转换创建临时对象（wrapper objects）来说明字符串等原始类型如何访问对象方法。然后，它深入研究了对象的内部工作原理，详细说明了隐藏的 `__proto__` 属性如何将对象链接到它们的 prototype，形成一个“原型链”，从而实现属性查找和继承。明确区分了 `prototype`（函数/类的属性，充当实例的蓝图）和 `__proto__`（对象实例的属性，指向它们继承的 prototype）。本文进一步解释了这些概念如何应用于传统的 JavaScript 函数和现代 ES6 类，强调类是同一基于 prototype 机制的语法糖，减少了重复方法在内存中的占用。结论总结了关键要点，强化了 prototype 对于掌握 JavaScript 的基本性质。

💡 主要观点

  1. `__proto__` 是每个对象实例上的一个内部引用，指向其继承的 prototype。 JavaScript 引擎通过原型链查找对象属性或方法，实现继承机制。
  2. `prototype` 是函数和类的属性，用作使用 `new` 创建的实例的蓝图。 函数或类的 `prototype` 上的方法可被所有实例共享，提高内存利用率。
  3. JavaScript 使用自动装箱（auto-boxing）来允许原始类型访问对象方法。 JavaScript 通过自动装箱机制，将原始类型临时转换为对象，使其能够访问对象方法。
  4. ES6 类是 JavaScript 现有基于 prototype 的继承机制的语法糖（一种更简洁的语法形式）。 尽管语法更简洁，但类在内部使用构造函数和 prototype，这意味着底层继承机制保持不变。

💬 文章金句

  • 理解 JavaScript 如何处理原始类型和 prototype 是解开这个奥秘的关键。
  • 这被称为 **原型链**，这就是 JavaScript 中继承的工作方式。
  • 在 JavaScript 中，几乎所有东西的行为都像一个对象，即使原始类型（如字符串、数字和布尔值）在技术上不是对象。这通过一个称为 **自动装箱 (wrapper objects)** 的过程来实现。
  • `prototype` 是函数/类的属性，用作实例的蓝图
  • `__proto__` 是对象实例的属性，指向它们继承的 prototype
  • 类本质上是 JavaScript 基于 prototype 的继承之上的语法糖。
