📌 一句话摘要

2025 年 Python 开发者调查揭示了关键趋势，包括 Python 的主要应用、大量涌入的新开发者、数据科学的主导地位、向异步 / Rust 的转变以及升级的重要性。

📝 详细摘要

Michael Kennedy 基于第八次年度 Python 开发者调查，分析了超过 30，000 份回复，旨在为 Python 开发者揭示重要趋势和实用见解。 主要发现显示，86% 的受访者以 Python 作为主要语言，且令人惊讶的是，50% 的人专业编码经验不足两年，突显了 Python 对新手的友好性，并促使内容创作者和工具供应商调整策略。 数据科学目前占据 Python 应用的半壁江山，巩固了其作为 Python 技术重心的地位，这得益于人工智能和数据工具的蓬勃发展。 尽管新版 Python 在性能和内存方面有显著提升（例如，从 3. 10 到 3. 13 速度提升高达 42%），但 83% 的开发者仍使用旧版本，这导致企业在云成本上存在潜在的浪费，因此亟需立即升级。 文章还指出，Python Web 开发正在复苏（使用率达 46%），其中 FastAPI 成为领先框架，并且业界正在转向基于异步和 Rust 的 Web 服务器和二进制扩展以提升性能。 此外，文档被强调为开发者首选的学习资源，PostgreSQL 依然是主流数据库。 展望未来，自主智能体 (Agentic AI) 有望显著提高开发者生产力，即将推出的无 GIL 的 Python 3. 14 将使并发成为核心考虑因素。

💡 主要观点

  1. 大量涌入的新开发者（50% 的人经验不足 2 年）和数据科学的主导地位（使用率达 51%）正在重塑 Python 生态系统。 这种人口结构变化要求内容创作者和工具供应商为初学者量身定制资源，同时 Python 与数据和人工智能的紧密联系也巩固了其在这些快速发展领域的核心地位。
  2. 绝大多数 (83%) Python 开发者仍在使用旧版本，错失了大量的性能和内存优化机会。 升级到较新的 Python 运行时（例如，从 3. 10 升级到 3. 13）可以带来高达 42% 的速度提升和 20-30% 的内存缩减，从而为企业节省数百万美元的潜在云成本。
  3. Python Web 开发正经历复苏（使用率达 46%），这得益于 FastAPI 等框架以及向异步和基于 Rust 的 Web 服务器的转变。 这表明 Python 领域对高性能和并发 Web 应用的需求日益增长，而新兴的框架和服务器技术正引领潮流。
  4. Rust 正日益成为 Python 的性能助推器，尤其是在二进制扩展和新型工具方面。 33% 的二进制扩展使用 Rust，并且诸如 'ty' 和 'Pyrefly' 之类的新型类型检查器也由 Rust 构建，使其成为加速 Python 代码（无需修改 Python 源代码）的首选语言。
  5. 自主智能体 (Agentic AI) 有望显著提高开发者生产力，即将推出的无 GIL 的 Python 3. 14 将使并发成为核心考虑因素。 近一半的开发者计划尝试 AI 编码代理，并且 Python 3. 14 中 GIL 的移除将从根本上改变开发者处理并发编程的方式，从而释放多核性能优势。

💬 文章金句

  • 恰好 50% 的受访者专业编码经验不足两年！
  • Python 的重心确实进一步向数据 / AI 倾斜。
  • Python 3. 11、3. 12 和 3. 13 都包含主要的性能优势，即将推出的 3. 14 将包含更多。
  • 如果你的公司意识到，仅仅因为没有花一天时间进行升级，每年就额外损失 40 万到 500 万美元，这将面临严峻的质询。
  • 自主智能体 (Agentic AI) 工具与卓越的工程师或数据科学家协同工作时，能释放惊人的生产力。
