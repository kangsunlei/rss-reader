Variant 介绍：用于 Apache Parquet、Delta Lake 和 Apache Iceberg 中半结构化数据的新开放标准

10/10/2025, 10:37:57 AM

📌 一句话摘要

介绍了 Variant，这是一种用于 Apache Parquet、Delta Lake 和 Apache Iceberg 中半结构化数据的新开放标准，提供灵活且高性能的存储方案。

📝 详细摘要

本文介绍了 Variant，这是一种新的开放标准数据类型，用于有效处理数据湖仓生态系统中的半结构化数据。它旨在解决在 AI、应用程序日志和遥测等领域中，管理具有不断演变的模式的数据这一常见挑战。在这些场景下，传统的字符串存储方式虽然灵活但速度较慢，而结构体则速度快但不够灵活。Variant 通过以紧凑的二进制格式存储数据来克服这些问题，这种格式既灵活又具有出色的查询性能。文章详细介绍了两个核心机制：二进制编码，它利用偏移量在数据中实现高效导航，避免完全解析；以及切分（shredding），它将常用字段提取到单独的、类型化的列式块中，从而实现 I/O 裁剪、数据跳过和卓越的压缩。Databricks 主导了 Variant 在 Apache Parquet 中的批准过程，确保其作为开放标准被采用，并已在 Delta Lake、Apache Iceberg 和 Apache Spark 中获得支持，从而为半结构化数据提供了一个统一的生态系统标准。

💡 主要观点

  1. Variant 旨在解决半结构化数据的高效存储和查询问题。 它为具有不断演变的模式的数据提供了一种灵活且性能卓越的解决方案，常见于 AI、应用程序日志和遥测等领域，克服了传统字符串或结构体方法的局限性。
  2. Variant 通过高效的二进制编码格式，优化数据导航。 数据并非以纯文本形式存储，而是采用带有偏移量的紧凑二进制格式，从而可以直接访问特定字段，而无需解析整个值，显著提升查询性能。
  3. 切分（shredding）优化了 Variant 数据存储和查询效率。 此技术能够自动将常用字段提取到单独的、类型化的列式块中，从而实现 I/O 裁剪、数据跳过和更高的压缩率，进而加快数据处理速度。
  4. Variant 作为开放标准在数据湖仓生态系统中获得批准。 在 Apache Parquet 中获得批准，并受到 Delta Lake、Apache Iceberg 和 Apache Spark 的支持，确保了广泛的互操作性，并为半结构化数据处理提供统一的方法。

💬 文章金句

  • 半结构化数据在 AI、应用程序日志和遥测中无处不在。这些数据非常有用，但不断变化的模式使其难以存储和查询。
  • Variant 数据类型现在已在 Apache Parquet ™ 中获得批准，它采用了一种不同的方法：以紧凑的二进制格式存储数据，这种格式既灵活又具有出色的查询性能。
  • 既然 Variant 已在 Parquet 社区中获得批准，那么整个数据湖仓生态系统就拥有了一个用于半结构化数据的标准、开放数据类型。
  • 通过 Variant 二进制编码，数据的结构使用指向 Variant 值内其他位置的偏移量进行编码。借助这些偏移量，导航 Variant 结构无需读取或处理整个值。
  • 当切分（shredding）后的字段存储为单独的 Parquet 块时，引擎可以使用所有 Parquet 优化来实现高效的行组和列页跳过。
