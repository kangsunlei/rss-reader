Ling-2.6-flash 发布：更快响应、更强执行、更高 Token Efficiency

4/23/2026, 3:12:00 AM

📌 一句话摘要

蚂蚁百灵发布 Ling-2.6-flash 模型，通过混合线性架构和 Token 效率优化，在 104B 总参数量下实现 340 tokens/s 推理速度，并以 1/10 的 Token 消耗在 Agent 场景达到同尺寸 SOTA 水平。

📝 详细摘要

文章介绍了蚂蚁百灵最新发布的 Ling-2.6-flash 模型，这是一款总参数量 104B、激活参数 7.4B 的 Instruct 模型。其核心创新在于围绕推理效率、Token 效率与 Agent 场景表现进行系统性优化，而非单纯依赖更长输出换取更高分数。模型采用混合线性注意力机制与高度稀疏化 MoE 架构，在 4 卡 H20 条件下推理速度可达 340 tokens/s，Prefill 吞吐达到对比模型的 2.2 倍。在 Artificial Analysis 评测中，Ling-2.6-flash 仅消耗 15M tokens 即完成评测，约为同类模型的 1/10。在 Agent 相关基准如 BFCL-V4、TAU2-bench、SWE-bench Verified 等上达到同尺寸 SOTA 水平。文章还介绍了其匿名测试版 Elephant Alpha 在 OpenRouter 上的表现，以及免费 API 调用和开源计划。

💡 主要观点

  1. Ling-2.6-flash 采用混合线性架构，显著提升推理效率。 通过 1:7 的 MLA + Lightning Linear 混合注意力机制与高度稀疏化 MoE 架构，在 4 卡 H20 条件下实现 340 tokens/s 推理速度，Prefill 吞吐达对比模型 2.2 倍。
  2. Token 效率优化使模型以更低成本实现高智能水平。 在 Artificial Analysis 评测中仅消耗 15M tokens，约为同类模型的 1/10，同时 Intelligence Index 达到 26 分，实现了智能表现与输出成本的更优平衡。
  3. 面向 Agent 场景进行定向增强，多项基准达同尺寸 SOTA。 通过大规模高保真交互环境进行 RL 训练，在 BFCL-V4、TAU2-bench、SWE-bench Verified 等 Agent 相关基准上表现优异，并在 Claude Code、Kilo Code 等框架中展现良好使用体验。

💬 文章金句

  • Token 消耗快速增长正在成为大模型落地中的核心矛盾之一。
  • Ling-2.6-flash 所追求的，并不是单点极限能力，而是在控制 Token 消耗的前提下，依然保持对 Agent 任务的强竞争力。
  • Ling-2.6-flash 追求的并不是单纯'更强'，而是在'足够强'的基础上，进一步做到'更快、更省、更可落地'。
  • 对极致智效比的追求并非没有代价。在部分高复杂度场景中，受限于推理深度，模型仍可能出现一定的工具幻觉。
