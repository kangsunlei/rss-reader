Java 新闻综述：Groovy 5.0，Leyden 项目，Helidon MCP，JReleaser，LangChain4j，Open Liberty

9/1/2025, 9:20:00 AM

📌 一句话摘要

本次 Java 新闻综述简要概述了 Java 生态系统的最新更新，包括 OpenJDK、Leyden 项目、Groovy、Quarkus、Helidon、Hibernate、Open Liberty、JReleaser 等的最新发布和进展。

📝 详细摘要

本周的 Java 新闻综述，日期为 2025 年 8 月 25 日，全面概述了 Java 生态系统中的最新发展。值得注意的更新包括 OpenJDK 的 JEP 522，旨在通过减少同步来提高 G1 垃圾收集器的吞吐量，该提案已成为候选提案。Leyden 项目发布了一个新的早期访问版本 (26-leydenpremain+1)，继续其关键工作，以增强 Java 程序的启动时间、峰值性能和内存占用，这对于现代云原生和微服务应用程序至关重要。JDK 25 (Build 36) 和 JDK 26 (Build 13) 的早期访问版本也进行了更新。主要框架和库的发布包括 Apache Groovy 5.0.0 的正式发布。该版本提供与 JDK 11 到 JDK 25 的完全兼容性，引入了一个新的 `@OperatorRename` 注解，并且 `groovysh` 基于 JLine 3 进行了重新设计。Quarkus 3.26.0 引入了对 Hibernate Reactive 中命名持久化单元的支持和开发用户界面改进，同时发布了紧急版本 (3.26.1， 3.20.2.2， 3.15.6.2) 以修复 Eclipse Vert.x 中的一个关键缺陷。Helidon 发布了其 MCP 服务器的技术预览版，该服务器支持命令式和声明式 API。Hibernate Validator 9.1.0 发布了第一个 alpha 版本，改进了级联验证的性能。Open Liberty 25.0.0.9 beta 进一步提高了其 FIPS 140-3 合规性。JReleaser 1.20.0 增强了 JBang 支持，LangChain4j 1.4.0 引入了与 `watson.ai`、Azure OpenAI 和 Anthropic 的新集成，显著扩展了 Java 在构建 AI 驱动的应用程序方面的能力，并且在错误处理和虚拟线程方面也有重大突破性更改。最后，Apache Camel Quarkus 3.26.0 已发布，与 Quarkus 3.26.0 和 Camel 4.14.0 对齐，并更新了配置类和生命周期自定义。本次综述为 Java 开发人员提供了一个有价值的摘要，以便及时了解快速发展的平台及其相关工具。

💡 主要观点

  1. Leyden 项目继续推进 Java 的启动时间、峰值性能和内存占用。 新的早期访问版本和交付的 JEP（如 AOT 类加载）表明，Java 应用程序正在不断优化以适应现代云原生环境，从而解决关键的性能问题。
  2. 主要的 Java 框架和库收到了重大更新，增强了功能和兼容性。 Groovy 5.0、Quarkus 3.26.0、Helidon MCP、Hibernate Validator 9.1.0 和 Open Liberty 25.0.0.9 都引入了新功能、性能改进或更好的合规性，反映了 Java 生态系统的持续创新。
  3. Java 生态系统对 AI 集成等新兴技术的支持力度越来越大。 LangChain4j 1.4.0 与 `watson.ai`、Azure OpenAI 和 Anthropic 的新集成展示了 Java 在构建复杂的 AI 驱动的应用程序和服务方面日益增长的能力。
  4. 关键的错误修复和稳定性改进会定期在 Java 平台上得到解决。 Quarkus 解决 Eclipse Vert.x 缺陷的紧急版本突显了社区对及时解决问题的承诺，确保生产系统的可靠性和稳定性。
