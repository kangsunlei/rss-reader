马斯克 22 万张 GPU 救场后，Claude 勉强恢复“三个月前体验”，Gary Marcus 却警告：GPU 将严重过剩，很快不值钱

5/7/2026, 3:21:00 AM

📌 一句话摘要

Anthropic 与 SpaceX 达成算力合作，使用其 22 万张 GPU 集群缓解算力瓶颈，提升 Claude 速率限制，同时 xAI 解散并入 SpaceXAI，引发业界对 GPU 过剩的讨论。

📝 详细摘要

本文报道了 Anthropic 与 SpaceX 达成的重要算力合作。Anthropic 将使用 SpaceX 位于孟菲斯的 Colossus 1 设施的全部算力（超过 22 万块 Nvidia GPU），以缓解因需求爆发导致的算力紧缺问题。合作将直接提升 Claude Pro 和 Max 订阅用户的服务能力，包括将 Claude Code 的速率限制提高一倍、取消高峰时段额度削减等。与此同时，马斯克宣布 xAI 将解散并并入 SpaceXAI，这一系列动作被解读为马斯克对 Anthropic 的态度反转，以及为 SpaceX IPO 铺路。文章还报道了 Anthropic 开发者日发布的新功能「dreaming」和「routines」，以及其争夺企业客户的战略。纽约大学学者 Gary Marcus 则警告，xAI 将过剩算力出售给竞争对手，可能预示着 GPU 供给过剩、价格下跌的来临。

💡 主要观点

  1. Anthropic 与 SpaceX 达成算力合作，使用 Colossus 1 设施的 22 万张 GPU 缓解算力瓶颈。 该合作将直接提升 Claude 的速率限制和服务能力，解决因需求爆发导致的用户体验下降问题，标志着 Anthropic 算力紧缺的阶段性缓解。
  2. 马斯克态度反转，xAI 解散并入 SpaceXAI，为 SpaceX IPO 铺路。 从年初批评 Anthropic 到如今提供算力支持，马斯克的态度转变被解读为商业考量。xAI 的解散和并入 SpaceXAI，被视为将算力资产转化为 IPO 前收入来源的策略。
  3. Gary Marcus 警告 GPU 可能严重过剩，价格将急剧下跌。 xAI 将过剩算力出售给竞争对手，表明单纯扩大规模并不能通向 AGI。这可能预示着超大规模云厂商面临供给过剩风险，对 Amazon、Google 等造成冲击。
  4. Anthropic 发布「dreaming」和「routines」功能，发力争夺企业客户。 新功能旨在让 AI 系统跨会话学习和按计划执行操作，同时 Anthropic 强调企业需围绕 AI 重构业务流程才能释放生产力红利。
