.NET Aspire 9.3 集成 GitHub Copilot 并扩展 Azure 支持

6/6/2025, 12:00:00 AM

📌 一句话摘要

.NET Aspire 9.3 新增 GitHub Copilot 仪表板集成，并扩展了 Azure 部署支持。

📝 详细摘要

The .NET 团队发布了 .NET Aspire 9.3 版本，重点在于通过增强的诊断、集成和部署工作流来改进开发者体验。主要特性包括将 GitHub Copilot 集成到 Aspire 仪表板中，用于 AI 辅助的日志分析和错误调查；扩展基于 OpenTelemetry 的跟踪；以及对仪表板的可用性改进，例如上下文菜单。此版本还引入了针对自行管理 YARP 的新集成，以及针对 Postgres 和 SQL Server 等数据库的简化容器配置。Azure 支持得到显著扩展，支持创建 Blob Storage 容器并简化 Key Vault 访问。一个值得注意的新增功能是提供了将 .NET 项目直接部署到 Azure App Service 的预览支持，简化了云部署工作流。本次更新旨在为开发者提供更好的可见性，并简化构建和部署分布式应用的过程。

💡 主要观点

  1. 将 GitHub Copilot 集成到 Aspire 仪表板，用于 AI 驱动的诊断。 开发者可以在仪表板内利用 AI 分析日志和跟踪错误，简化分布式系统中根本原因的识别。
  2. 通过扩展跟踪和上下文菜单增强仪表板诊断功能。 通过包含对外调用的详细跟踪以及通过新的上下文菜单快速访问遥测数据，提高应用行为的可见性。
  3. 简化了常见服务的 Azure 和容器集成。 新的 API 和配置选项简化了添加 Blob Storage 等 Azure 服务以及轻松部署容器化数据库（Postgres、SQL Server）的过程。
  4. 引入了将项目部署到 Azure App Service 的预览支持。 提供将 .NET 项目直接发布到 Azure App Service 环境的直接途径，简化云部署工作流。

💬 文章金句

  • 此集成使开发者无需离开开发者仪表板环境，即可使用 AI 分析日志、调查分布式服务中的错误并识别性能问题。
  • Copilot 通过总结日志、解释错误代码并协助识别复杂跟踪场景中的根本原因，增强了基于 OpenTelemetry 的诊断能力。
  • 跟踪页面现在可以显示对外调用（例如对数据库和缓存的调用），即使这些服务不发出自己的遥测数据。
  • 关于 Azure App Service，9.3 版本引入了将 .NET 项目部署到其中的预览支持。
