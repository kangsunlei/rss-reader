Zod v4 发布，带来重大性能改进并引入 Zod Mini

8/23/2025, 11:00:00 AM

📌 一句话摘要

TypeScript 模式验证库 Zod v4 引入了显著的性能提升，通过 `Zod Mini` 减少了包大小，并改进了 API，从而增强了开发者体验和应用程序性能……

📝 详细摘要

Zod，一个著名的以 TypeScript 为先的模式验证库，已经发布了其稳定的版本 4，带来了性能、包大小和 API 设计方面的重大改进。主要亮点包括：与 Zod 3 相比，字符串解析速度提高了 14 倍，数组解析速度提高了 7 倍，对象解析速度提高了 6.5 倍，同时减少了 TypeScript 类型实例化过程，从而加快了编译速度。一个重要的新特性是 `@zod/mini`，这是一个轻量级的、可 Tree-shaking 的发行版（压缩后大约 1.9 KB），专为现代前端应用程序设计，它通过包装器函数而非方法实现 Tree-shaking。API 改进包括将 `z.email()` 等格式助手提升为顶层函数，以更好地进行 Tree-shaking 并统一错误处理。开发者现在还可以将强类型元数据附加到模式，从而实现高级工作流程，如模式驱动的表单生成，并受益于内置的 JSON Schema 转换。为 v3 用户提供了一个非官方的 codemod 和详细的迁移指南。来自 Reddit 等平台和 Matt Pocock 等专家的社区反馈称赞了性能提升、更小的包大小以及表单生成的潜力，将 Zod v4 定位为 TypeScript 生态系统的“重大升级”。

💡 主要观点

  1. Zod v4 提供了显著的性能增强，并减少了 TypeScript 类型实例化过程。 新版本实现了字符串、数组和对象高达 14 倍的解析速度提升，并加快了项目编译速度，从而提高了应用程序的效率。
  2. `@zod/mini` 的引入为现代前端应用程序提供了一个轻量级的、可 Tree-shaking 的解决方案。 Zod Mini 将包大小减少了大约 6 倍，通过函数式 API 实现了在客户端环境中更高效和优化的验证。
  3. Zod v4 使用顶层格式助手、统一的错误处理和强类型元数据来改进其 API。 这些 API 改进增强了 Tree-shaking，简化了错误管理，并解锁了新的功能，如模式驱动的表单生成和 JSON Schema 转换。

💬 文章金句
