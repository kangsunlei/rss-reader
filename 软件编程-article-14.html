OpenAI 的 gpt-realtime 通过端到端语音处理实现生产级语音代理

9/11/2025, 8:00:00 AM

📌 一句话摘要

OpenAI 的 gpt-realtime 和实时 API 提供端到端语音处理方案，显著降低延迟并提高语音质量，适用于生产级 AI 语音代理。

📝 详细摘要

OpenAI 发布了 gpt-realtime，这是其最先进的语音到语音模型，同时还发布了正式可用的实时 API。这个集成系统绕过了传统的语音转文本和文本转语音模型的串联/链式调用，从而在单个系统内实现了端到端的语音处理。主要优势包括降低延迟、更自然的语速和语调，以及可靠地遵守风格指令。Gpt-realtime 在理解能力方面表现出改进，可以跟踪非语言线索、无缝切换语言以及准确处理多种语言的字母数字序列，并在基准测试中表现出显著提升（例如，Big Bench 音频准确率达到 82.8%）。函数调用能力也得到了增强，包括更好地识别、定时和提供参数，包括异步函数调用以保持对话流程。实时 API 已准备好投入生产，提供诸如 MCP 服务器支持、用于视觉上下文的图像输入、SIP 电话呼叫集成、可重用提示和欧盟数据驻留（确保数据存储在欧盟境内）等功能。Zillow 和 T-Mobile 等早期企业合作伙伴已经在试用这些功能，突显了向更灵活、领域定制化 AI 代理的转变。OpenAI 还实施了强大的安全措施，包括用于有害对话的分类器和通过 Agents SDK 进行开发者可配置的防护栏，以及用于减轻身份冒用风险的预设声音。该模型和 API 都可供开发者立即使用。

💡 主要观点

  1. 端到端语音处理显著降低了实时 AI 代理的延迟。 通过在单个系统内集成语音到语音，gpt-realtime 和实时 API 消除了链接单独模型时固有的延迟，这对于自然的对话流程至关重要。
  2. Gpt-realtime 提供卓越的理解能力、指令遵循能力和自然语音生成能力。 该模型在理解非语言线索、切换语言、处理复杂序列以及遵守风格指令方面表现出显著的改进，从而提高了对话质量。
  3. 增强的异步函数调用功能提高了助手的功能性和用户体验。 改进的函数识别和参数提供，加上异步执行，使 AI 助手能够在保持活跃对话的同时执行任务，这对于交互式应用非常有价值。
  4. 实时 API 为企业部署提供强大、生产就绪的功能。 通过支持 MCP 服务器、图像输入、SIP 集成和欧盟数据驻留，该 API 使开发者能够大规模构建和部署复杂的、合规的 AI 语音助手。
  5. OpenAI 优先考虑安全性和合规性，并集成了安全措施。 内置的分类器、通过 Agents SDK 进行开发者可配置的防护栏以及预设声音解决了围绕有害内容和身份冒用的关键问题，从而确保了负责任的 AI 部署。

💬 文章金句

  • 实时 API 和 gpt-realtime 的组合旨在通过单个系统处理端到端的语音，避免了分别链接语音转文本和文本转语音模型的传统方式。
  • 在理解能力基准测试中，gpt-realtime 显示出可衡量的改进。它可以跟踪非语言线索、在单个句子中切换语言，以及更准确地处理字母数字序列……跨语言。
  • 该模型现在在识别相关函数、在正确的时间调用它们以及提供正确的参数方面表现更好。
  • 异步函数调用进行了更新，允许语音助手在等待结果时继续对话，这对于客户支持和事务性应用程序具有明显的价值。
  • 实时 API 已升级以符合生产要求。
