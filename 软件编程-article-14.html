Qodana 2025.1 版本发布 | Qodana 博客

5/2/2025, 12:47:29 PM

📌 一句话摘要

Qodana 2025.1 版本引入增强的 OWASP 十大安全风险（2021）检查功能（含预定义污点规则），优化了 Azure 和 GitLab CI/CD（持续集成/持续交付）的 PR（Pull Request）模式与快速修复功能，新增具备 MISRA 合规性和数据流分析能力的专业版 C++ 静态分析工具，并支持 Kotlin K2 模式。

📝 详细摘要

本文详述 Qodana 2025.1 版本更新，重点包括新增 OWASP 十大安全风险（2021）检查（覆盖 A01、A03、A07、A08、A10 漏洞）及 KTS 定制功能；优化 Azure 和 GitLab CI/CD（持续集成/持续交付）流程，新增 PR/MR（Pull Request/Merge Request）模式（仅分析变更文件）、快速修复和结果展示优化；推出专业版 C++ 静态分析工具，具备 MISRA 合规性和数据流分析能力（可检测内存泄漏和空指针解引用）；新增 Kotlin K2 模式支持（含回退选项），但需注意第三方插件兼容性。这些更新全方位提升了代码质量、安全性和开发效率。

💡 主要观点

  1. 新增 OWASP 十大安全风险检查，提供预定义污点规则覆盖 A01/A03/A07/A08/A10 漏洞类别 Qodana 现在包含 700 余项预配置规则和针对 OWASP 十大安全风险（2021）特定类别的污点规则，显著降低安全配置复杂度，同时支持通过 KTS 文件进行深度定制以适应项目特殊需求。
  2. 优化 Azure 和 GitLab CI/CD（持续集成/持续交付）流程，引入 PR/MR 模式和快速修复 通过仅分析修改文件的 PR（Pull Request）模式可减少 60%～70% 的分析时间，新的结果展示方式和快速修复功能（直接应用或创建 PR）显著提升开发工作流效率，特别适合频繁提交的大型项目。
  3. 推出专业版 C++ 静态分析工具，具备 MISRA 合规和数据流分析能力 相比 Clang-Tidy 和社区版，专业版 C++ 分析工具能检测更复杂的运行时错误如内存泄漏和空指针解引用，数据流分析可追踪变量状态变化路径，提供比传统语法检查更深层的代码质量保障。
  4. 支持 Kotlin K2 模式并保留回退选项 K2 模式带来 20%～30% 的性能提升和更好的稳定性，支持 Kotlin 2.1 新特性。虽然部分第三方插件可能不兼容，但用户可通过简单配置切换回旧版解析器保证项目连续性。

💬 文章金句

  • Qodana 现已包含针对 OWASP 十大安全风险（2021）最常见漏洞类别（A01、A03、A07、A08、A10）的预定义污点规则。
  • 在 Azure 中，通过 PR（Pull Request）模式仅分析变更文件可将 PR 分析时间缩短 60%～70%。
  • 新版 C++ 静态分析工具相比 Clang-Tidy 具备更强大的功能，通过高级数据流分析检测内存泄漏和空指针解引用等关键问题。
  • K2 模式相比旧编译器性能提升 20%～30%，但部分第三方插件可能需要更新以保持兼容性。
