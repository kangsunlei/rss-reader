从头构建多智能体系统学到的经验

5/14/2026, 12:35:02 AM

📌 一句话摘要

Shopify 高级工程师 Paulo Arruda 在 QCon 上分享构建多 Agent 系统的亲身经验，核心发现是专才 Agent 优于通才，赋能领域专家比组建 AI 特种部队更有效。

📝 详细摘要

这篇推文解读了 Shopify 高级工程师 Paulo Arruda 在 QCon 上的演讲。故事起点是测试生成，他尝试过文件依赖图、GPT 摘要、语义关系建图等方案，但成本极高。转折点是 Claude Code 的研究预览版上线，他发现 Agent 搜索（Grep/文件读取）效果与向量索引相当但无需维护索引。两个关键经验：专才 Agent 效果远好于通才 Agent；为领域专家提供更好的工具比组建 AI 全能小队更有效。他还创建了名为 Swarm 的多 Agent 编排工具，成功案例包括将主题审查时间从 22 小时缩短至 7-20 分钟。
