准确率提升至 90%，阿里商旅基于 AgentScope 构建多智能体差旅助手最佳实践

2/14/2026, 12:31:00 AM

📌 一句话摘要

本文详细介绍了阿里商旅如何利用 AgentScope 框架，通过多智能体协作、意图识别优化及上下文工程，将差旅助手的准确率从 50% 提升至 90% 的实战经验。

📝 详细摘要

文章深入探讨了阿里商旅差旅助手 AliGo 的架构演进过程。针对早期单智能体模式在处理复杂业务时出现的准确率低（仅 50%）、稳定性差及扩展性不足等痛点，团队转向了基于 AgentScope 的多智能体架构。核心方案包括：采用 Python 与 Java 混合开发模式；设计“快慢车道”意图识别机制以平衡效率与深度；引入 ReAct 智能体钩子实现流式思考链输出，缓解用户焦虑；以及通过动态 Prompt 组装构建“状态机”式上下文管理。此外，文章还介绍了配套的知识库（MaxKB）、观测（Langfuse）及评测体系，为企业级 AI Agent 的落地提供了全栈参考。

💡 主要观点

  1. 从单智能体向多智能体架构演进是解决复杂业务逻辑瓶颈的关键。 单智能体在面对高复杂度业务时，Prompt Token 的剧增会导致模型注意力衰减。通过多智能体协作，可以将复杂任务拆解，显著提升识别准确率和系统稳定性。
  2. 设计意图识别的“快慢车道”机制，有效平衡了系统响应速度与理解深度。 通过规则引擎处理固定套路的“快车道”和 LLM 处理复杂语义的“慢车道”，既避免了简单意图的推理延迟，又保证了复杂多意图场景的分析精度。
  3. 利用 ReAct 智能体钩子构建实时思考链，优化了 AI 交互的用户体验。 在多智能体协作导致耗时增加的情况下，通过 Hook 机制实时展示智能体的“思考-行动-观察”过程，能有效缓解用户等待焦虑，增强系统透明度。
  4. 上下文工程应从静态 Prompt 转向基于工程手段控制的动态状态机模式。 通过程序化状态控制精准识别对话阶段，将模型注意力聚焦于当前主链路，在工程确定性与 AI 灵活性之间取得平衡，提升了非线性对话的处理能力。
  5. 完善的周边生态（观测、评测、知识库）是 AI Agent 生产环境落地的保障。 引入 Langfuse 进行全链路追踪、构建自动化评测系统以及标准化的 RAG 知识库，形成了从开发到观测再到优化的闭环，确保了系统的持续进化。

💬 文章金句

  • 将明确的用户意图通过快速通道直接路由，复杂语义理解仍交由 AI 智能分析。整体就是个'快慢车道'的设计。
  • 在工程确定性与 AI 灵活性之间实现有效平衡。
  • 基于 ReAct 智能体在调用工具时暴露的 hook，可构建实时推理链（Chain-of-Thought），有效缓解用户在等待最终结果时的焦虑感。
  • 通过动态 Prompt 组装机制，本质上为 AI 构建了一个状态机。
  • 事项收集准确率从原来的 50% 提升到 90%+
