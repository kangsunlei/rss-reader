📌 一句话摘要

文章详细封装了一个 Vue3 自定义指令，通过结合 JS 文本测量与 CSS 动画，优雅地实现了 AI 对话的多行打字效果，并解决了传统方法的弊端。

📝 详细摘要

文章针对 AI 对话界面中常见的“打字效果”需求，深入探讨了多种实现方案。首先，作者尝试了纯 CSS 动画，发现其无法实现多行文本的打字效果；接着，转向 JavaScript 定时器方案，解决了多行问题但引入了潜在的性能卡顿；随后，通过`requestAnimationFrame`优化了 JS 方案的性能。最终，作者回到 CSS 动画的优势，并结合 JS 动态计算每行可显示的字符数，将长文本切片为多段，为每段创建独立的 DOM 元素并应用延迟的 CSS 动画，从而完美实现了多行文本的平滑打字效果。文章将此方案封装为 Vue3 自定义指令，提供了完整的代码示例和使用方法，对前端开发者解决类似 UI 需求具有很高的参考价值。

💡 主要观点

  1. 传统 CSS 动画无法实现多行文本的打字效果 单纯使用 CSS 的`steps()`动画配合`overflow: hidden`和`white-space: nowrap`，虽然能模拟打字，但文本超出单行时会被截断，无法展示完整内容。
  2. JS 结合`requestAnimationFrame`能实现多行打字效果且性能优于定时器 通过 JavaScript 逐字添加文本并利用`requestAnimationFrame`调度动画，可以有效解决多行问题和定时器可能导致的卡顿，提供更流畅的视觉体验。
  3. 结合 JS 文本测量与 CSS 分段动画是实现多行打字效果的优化方案 核心思想是利用 JS 计算每行可容纳的字符数，将长文本切片，为每段创建独立的 DOM 并应用带有延迟的 CSS 动画，兼顾了多行显示和性能。
  4. Vue3 自定义指令封装提升了打字效果的复用性和开发效率 将复杂的实现逻辑封装为可复用的 Vue3 指令，使得开发者能以声明式方式轻松应用于任何元素，极大简化了开发流程。
