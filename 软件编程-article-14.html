Java 新闻汇总：Jakarta EE 11 和 Spring AI 更新，WildFly 36 Beta，Infinispan，JNoSQL

3/31/2025, 12:00:00 AM

📌 一句话摘要

本次 Java 新闻汇总重点介绍了 Jakarta EE 11、Spring AI、WildFly 36 Beta、Infinispan、JNoSQL 和其他 Java 生态系统项目的更新。

📝 详细摘要

本周的 Java 汇总重点介绍了 Jakarta EE 11 和 Spring AI 的更新。此外，还包括 WildFly 36.0 的首次 Beta 版本发布、Hibernate Search 8.0 的第三个 Alpha 版本发布、Open Liberty 的 3 月份版本以及 Quarkus、Infinispan、JHipster 和 OpenXava 的 Point 版本。这些更新为开发人员提供了新功能、错误修复和依赖升级，从而增强了他们构建和部署现代 Java 应用程序的能力。本次汇总还涵盖了 OpenJDK、JDK 25、Eclipse JNoSQL 和 BellSoft 的更新。

💡 主要观点

  1. Jakarta EE 11 Web Profile 的发布审查进展顺利。 Jakarta EE 11 Web Profile 的发布审查已经开始，绝大多数成员投票赞成，表明审查过程顺利，即将发布。
  2. Spring AI 迎来关于 artifact ID、依赖管理和自动配置的重大更新。 Spring AI 团队宣布了使用 1.0.0-SNAPSHOT 版本的重要更改和更新，包括 artifact ID 重命名以及对依赖管理和自动配置的调整，要求开发人员相应地更新他们的项目。
  3. Quarkus 新版本发布，3.21.0 被指定为新的 LTS 版本。 Quarkus 发布了 3.21.0 和 3.20.0 版本，其中 3.21.0 作为新的 LTS 版本，包括错误修复、依赖升级和新功能，为开发人员提供了一个稳定且功能丰富的平台。
  4. WildFly 36.0.0 包含重大修复、依赖升级和增强功能。 WildFly 36.0.0 持久化单元现在默认启用，以提高性能，如果启用了多个指标系统，现在将记录警告。
  5. Eclipse JNoSQL 1.1.6 提供了错误修复、性能改进和新功能。 Eclipse JNoSQL 1.1.6 支持 NoSQL 图数据库，并增强了 CDI Lite，以提高性能和兼容性。

💬 文章金句

  • Spring AI 团队发布了使用 1.0.0-SNAPSHOT 版本的 [重要更改和更新](https://spring.io/blog/2025/03/25/spring-ai-update-to-snapshots) 。
  • Quarkus 3.21.0 和 3.20.0 版本，前者被指定为新的 LTS 版本
  • 与 JDK 24 和 GraalVM for JDK 24 的发布相结合，BellSoft 还 [发布](https://bell-sw.com/blog/liberica-native-image-kit-24-2-0-is-released/) 了 [Liberica Native Image Kit](https://bell-sw.com/liberica-native-image-kit/) 的 24.2.0 版本。
