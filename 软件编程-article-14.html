全球开发者三年暴增 50%！增速最快的不是 Python，而是 C++和 Rust

1/13/2026, 10:11:00 AM

📌 一句话摘要

报告显示，电力和芯片成为 2025 年计算产业两大瓶颈，C++ 和 Rust 因其极致性能和持续迭代，成为全球开发者增速最快的编程语言，且在安全性方面持续增强。

📝 详细摘要

本文结合 2025 年全球开发者数据和科技公司高管观点，深入分析了 C++ 和 Rust 编程语言在全球开发者数量高速增长的背景下，为何能够成为增速最快的语言。文章指出，这主要源于软件消耗增速始终快于硬件供给能力，特别是在 AI 时代，对极致算力效率的需求推动了对高性能编程语言的需求。文章进一步揭示了电力和芯片是当前计算产业的两大核心瓶颈，微软、亚马逊、英伟达等公司高管的表态印证了“每瓦算力”和“每晶体管算力”成为关键指标，从而解释了 C/C++/Rust 等语言的增长逻辑。此外，文章还驳斥了关于 C++ 安全性不足的论调，通过数据和 C++26 的安全增强特性，强调 C++ 在持续发展中强化安全能力，使其在快速演进的编程环境中依然保持竞争力。文章最终总结，C++ 在满足“计算需求持续超越硬件供给”这一长期趋势中扮演关键角色，具有广阔的前景。

💡 主要观点

  1. 软件需求持续超越硬件供给是高性能编程语言增长的根本动力。 计算机发展史表明，人类对解决大规模计算问题的需求总是领先于硬件算力，AI 时代的到来进一步加剧了对极致硬件性能的压榨，从而推高了对 C/C++/Rust 等高性能语言的需求。
  2. 电力和芯片是 2025 年全球计算领域的核心瓶颈。 各大科技公司高管的表态指出，尤其是在 AI 算力竞争中，数据中心的电力供给和芯片产能限制成为最突出的资源瓶颈，这使得“每瓦算力”和“每晶体管算力”最大化成为衡量编程语言价值的关键标准。
  3. C++ 和 Rust 是全球开发者增速最快的编程语言。 SlashData 和 IDC 等机构数据显示，在 2022-2025 年间，C++ 和 Rust 的开发者增长速度领先于其他主流语言，这与它们在高效利用硬件资源方面的优势直接相关。
  4. C++ 的安全问题被夸大，且通过持续迭代不断增强。 文章指出，对 C++ 安全性的负面报道存在偏颇，忽视了大部分安全漏洞并非与语言本身直接相关，且多将 C 与 C++ 混淆。C++26 标准及未来的发展方向，都在不断强化其类型/内存安全和功能安全特性，提升其实用性和可靠性。

💬 文章金句

  • 软件的消耗增速，始终跑在硬件供给能力的前面。
  • 电力才是 2025 年的头号瓶颈。
  • 单位功耗的算力表现，将直接决定企业的营收，这是不折不扣的硬道理。
  • 在 2022---2025 年增速最快的编程语言榜单上，Rust 与 C++ 稳居前两位。
  • 媒体对 C++ 安全漏洞问题的报道，其实存在严重夸大。
