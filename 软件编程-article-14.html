新型 KATARU IoT 恶意软件现身，集成 Linux 提权与 Mirai 式 DDoS 能力

9/14/2026, 10:00:00 AM

📌 一句话摘要

Nozomi Networks 披露新型 IoT 恶意软件 KATARU，它通过 Telnet 暴力破解入侵设备，集成 Linux 提权漏洞利用、加密 C2 通信与 Mirai 式多协议 DDoS 能力，并可跨 Linux、路由器、安卓等多平台持久化驻留。

📝 详细摘要

Nozomi Networks 研究人员于 2026 年 8 月捕获并命名了新型 IoT 恶意软件 KATARU。攻击者先对蜜罐反复进行 Telnet 密码暴力破解，随后下载 ARM 架构载荷，研究人员由此获得样本。KATARU 的入侵流程始于 Telnet 凭证爆破，得手后通过 BusyBox 下载执行载荷，检查 /etc/passwd 可写性并尝试移除 root 密码占位符，随后调用 CVE-2026-46300（Fragnesia）、CVE-2026-43284（DirtyFrag）、CVE-2026-31431（Copy Fail）等多个公开漏洞利用代码，并尝试利用 cgroup v1 的 release_agent 逃逸机制提权。其持久化方式覆盖 systemd 服务、cron 任务、rc 脚本、OpenWrt 钩子、包管理钩子与安卓启动路径，并将自身副本设为不可修改或仅追加属性。与早期 Mirai 变种不同，KATARU 的 C2 通信全程加密，每台设备生成 X25519 密钥对，使用 ChaCha20-Poly1305 加密下发命令，但其硬编码公钥与 RFC 测试值一致。它支持 TCP、UDP、ICMP、HTTP、QUIC、DNS 多协议洪泛，目标覆盖 Minecraft、FiveM、OpenVPN、WireGuard 等服务，并内置诱饵组件干扰分析。文章最后给出补丁、关闭 Telnet、替换弱密码、网络隔离、监控异常出站加密连接等防御建议，并附入侵指标。

💡 主要观点

  1. KATARU 通过 Telnet 暴力破解这一老旧入口完成初始入侵，说明基础安全配置缺失仍是 IoT 设备被大规模感染的主因。 攻击者先对蜜罐反复尝试 Telnet 密码爆破，得手后通过 BusyBox 下载并执行 ARM 架构载荷。设备若开启 Telnet、使用弱凭证或运行老旧固件，就会给攻击者留下可乘之机，Mirai 与代理滥用案例已多次证明这一点。
  2. 该恶意软件集成了 Linux 提权漏洞利用与多平台持久化机制，显著提高清除难度与攻击利用价值。 它尝试调用 CVE-2026-46300、CVE-2026-43284、CVE-2026-31431 等公开漏洞利用代码，并利用 cgroup v1 的 release_agent 逃逸机制提权；持久化覆盖 systemd、cron、rc 脚本、OpenWrt 钩子、包管理钩子与安卓启动路径，还会将自身副本设为不可修改或仅追加属性。
  3. KATARU 采用加密 C2 通信与诱饵组件，对传统流量检测和应急响应构成新挑战。 每台受感染设备生成 X25519 密钥对，通过共享密钥以 ChaCha20-Poly1305 加密下发命令，可阻碍常规流量检测并防止 C2 仿冒；同时发送虚假 Web 请求与类 IRC 聊天消息干扰分析，诱饵中含类似 Mirai 或 Katana 的标签字符串。
  4. 其 DDoS 能力覆盖多种协议与常见服务，攻击面比传统 Mirai 变种更广。 支持 TCP、UDP、ICMP、HTTP、QUIC、DNS 多协议洪泛，目标覆盖 Minecraft、FiveM、OpenVPN、WireGuard 等服务，还支持 SSH 暴力破解与通过 wget 下载额外二进制文件，但 SSH 爆破是 C2 下发的定向任务，不用于自主传播。
  5. 防御重点在于基础加固、网络隔离与持续监控，停止支持的设备应淘汰或置于严格访问边界之后。 建议及时修补固件与内核、关闭不必要的 Telnet 端口、替换默认或弱密码，对 IoT 与 OT 设备做网络隔离，仅放行必要流量，持续监控异常出站加密连接与流量突增，并留存足够周期日志以对比行为基线。

💬 文章金句

  • KATARU 是研究人员新发现的一类 IoT 恶意软件，可将防护薄弱的联网设备转化为 DDoS 攻击节点。
  • 该恶意软件的流量洪泛攻击能力与 Mirai 僵尸网络家族类似，但搭载的工具覆盖范围更广。
  • 和早期 Mirai 变种使用明文 C2 流量不同，KATARU 的控制流量全程加密。
  • 如果设备已经无法安装安全更新，即便部署了上述防护措施，也无法保证设备绝对安全。
