NVIDIA Dynamo 解决多节点 LLM 推理难题

12/4/2025, 1:00:00 PM

📌 一句话摘要

NVIDIA Dynamo 是一个开源框架，旨在通过分离预填充和解码阶段、动态管理 GPU 资源以及优化 KV 缓存来解决多节点 LLM 推理的难题。

📝 详细摘要

本文介绍了 NVIDIA Dynamo，它是一个开源框架，旨在解决大规模 LLM 推理的复杂性，特别是对于那些超出单 GPU 或多 GPU 节点容量的模型。Dynamo 通过将推理分解为预填充和解码阶段，并分别优化内存密集型和计算密集型任务，从而管理跨 GPU 和节点的分布式执行。它动态地管理 GPU 资源，以提高利用率并最大限度地减少延迟，使基础设施团队能够灵活地扩展推理容量，而无需过度供应。该框架与各种推理引擎（如 TensorRT-LLM 和 vLLM）兼容。与微软 Azure 的合作展示了 Dynamo 在 Kubernetes (AKS) 上使用 ND GB200-v6 实例的能力，在使用 GPT-OSS 120B 模型时实现了每秒 120 万 tokens。主要创新包括将预填充（计算密集型）和解码（内存密集型）阶段分离到不同的 GPU 上，基于服务等级协议 (SLA) 和流量预测的动态 GPU 调度，以及优化 KV 缓存重用的 LLM 感知型路由器。Dynamo 还具有一个 KV 块管理器，用于卸载不经常访问的缓存块，防止缓存驱逐并提高并发性。Dynamo 被定位为 NVIDIA Triton 推理服务器的继任者，它使用 Rust 和 Python 构建，并且完全开源。

💡 主要观点

  1. Dynamo 通过将 LLM 推理分解为预填充和解码阶段来优化资源利用率。 通过将计算密集型的预填充任务和内存密集型的解码任务分配到不同的 GPU 上，Dynamo 允许独立优化，从而防止资源浪费并提高各种 LLM 工作负载的效率。
  2. 动态 GPU 调度和资源分配实现了响应式扩展和成本效率。 Dynamo 的规划器组件预测流量并实时调整 GPU 分配，从而允许系统在需求高峰期间扩大规模，并在低负载期间缩小规模，最终优化硬件利用率并降低运营成本。
  3. LLM 感知型路由和 KV 缓存管理显著提高了推理性能。 该框架智能地路由请求，以最大限度地重用 KV 缓存并卸载较少使用的缓存块，从而减少冗余计算并以更低的延迟实现更高的并发会话。

💬 文章金句

  • Dynamo 是一个用于分布式推理的开源框架。它管理跨 GPU 和节点的执行。
  • Dynamo 的核心创新在于将 LLM 推理的预填充和解码阶段分离到不同的 GPU 上。
  • 这种设置实现了每秒 120 万 tokens，表明 Dynamo 可以在常规集群上处理企业级推理任务。
  • Dynamo 包括一个 LLM 感知型路由器，用于跟踪跨 GPU 集群的键值 (KV) 缓存的位置。
  • Dynamo 被定位为 NVIDIA Triton 推理服务器的继任者，并借鉴了早期推理服务框架的经验。
