微软 GitHub Copilot Chat 扩展正式开源

7/2/2025, 8:41:18 AM

📌 一句话摘要

微软开源 GitHub Copilot Chat 扩展，提升 AI 开发工具透明度并促进开发者社区协作

📝 详细摘要

微软宣布将 GitHub Copilot Chat 扩展开源，采用 MIT 许可证，旨在提高 AI 辅助开发工具的透明度。该扩展安装量已超过 3500 万次，开源内容包括代理模式逻辑、系统提示和遥测机制，但核心服务如模型基础设施仍保持闭源。此举为开发者社区提供了审核和贡献的机会，同时增强了数据收集和处理的透明度。微软计划进一步将 AI 功能集成到 VS Code 核心中，推动开放的 AI 增强开发环境。开源还提高了安全性和合规性，让组织能更好地了解 AI 会话期间的数据收集。

💡 主要观点

  1. 开源 GitHub Copilot Chat 扩展提升 AI 工具透明度 微软通过开源扩展程序，允许开发者查看数据收集和处理方式，增强了对 AI 工具的信任和理解。
  2. 社区协作推动 AI 开发工具进步 开源使得开发者可以贡献代码和改进，促进 AI 工具的共同开发和优化。
  3. 核心服务仍保持闭源，平衡开放与商业利益 微软在开源部分功能的同时，保留了核心服务的闭源，以保护商业利益和技术优势。
  4. 开源增强安全性和合规性 组织可以通过访问源代码深入了解 AI 会话期间的数据收集，满足合规性和治理要求。

💬 文章金句

  • 我们相信，通过利用充满活力的开源社区，人工智能体验可以蓬勃发展------就像 VS Code 在过去十年中成功做到的那样。
  • 开源 Copilot Chat 扩展程序可以让您查看我们收集的数据。
  • 微软的目标似乎是创建一个支持 AI 的开发环境，其中客户端逻辑可供社区审核、测试和调整，且不会牺牲用户体验或开发者生产力。
