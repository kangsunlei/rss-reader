不应强迫 Google 出售 Chrome

4/28/2025, 6:00:48 AM

📌 一句话摘要

DHH 认为出售 Chrome 将扼杀创新，扶持封闭平台，从而损害整个 Web 生态系统。

📝 详细摘要

David Heinemeier Hansson 反对强迫 Google 出售 Chrome，即使是作为对其广告市场垄断行为的惩罚。他认为 Chrome 通过投资和技术优势公平地赢得了浏览器之战，其持续发展对于 Web 作为一个开放的应用程序平台的活力至关重要。Google 在一个蓬勃发展的 Web 中的自身利益驱动了其在 Chrome 上的工作，推动了诸如 import maps、nested CSS 和 web push 等标准的进步。出售 Chrome 将削弱 Google 的投资，导致 Web 停滞不前，并使专有平台获得主导地位。

💡 主要观点

  1. Chrome 的持续发展对 Web 的活力至关重要 Chrome 团队在诸多方面推动了 Web 的发展（如 import maps、nested CSS、web push 等），这对于一个自由和开放的应用程序平台至关重要。
  2. Chrome 的成功归功于卓越的技术，而非垄断 Chrome 通过巨额投资和技术实力打造出色的产品，公平地赢得了浏览器之战，是对卓越产品的合理回报。
  3. Google 对 Chrome 的投资使整个 Web 生态系统受益 Google 数万亿美元的业务依赖于一个蓬勃发展的 Web，因此，推动 Web 发展是符合其经济利益的行为。

💬 文章金句

  • 我们需要 Web 领域一个有绝对影响力的重量级玩家！
  • 如果 Google 被迫出售 Chrome，Web 的发展将会更加糟糕。
  • Chrome 通过提供更卓越的互联网体验，公平公正地赢得了浏览器之战。
  • 资本主义的驱动力不是仁慈，而是激励。
  • Google 不应逃脱操纵在线广告市场的惩罚，但强迫其出售 Chrome 将会对 Web 造成巨大损害。
