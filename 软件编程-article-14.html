Cloudflare 高效推理引擎构建实践

8/27/2025, 2:00:00 PM

📌 一句话摘要

Cloudflare 开发了基于 Rust 的 LLM 推理引擎 Infire，以更低的 CPU 占用和更高的 GPU 利用率，在 Cloudflare 的全球分布式边缘网络上高效运行 AI (人工智能) 模型，性能优于 vLLM。

📝 详细摘要

本文详细介绍了 Cloudflare 开发定制的 LLM (大型语言模型) 推理引擎 Infire 的战略决策，旨在满足其全球分布式边缘网络上运行大型 AI (人工智能) 模型的独特需求。文章 критически 考察了传统集中式 GPU (图形处理器) 部署和现有开源解决方案 (如 vLLM) 的局限性，这些解决方案主要针对大型数据中心进行了优化。Cloudflare 需要一个高效、安全且动态可扩展的边缘推理引擎，能够在 95% 的全球互联网连接人口的 50 毫秒内运行，这需要一种新的方法。文章解释了 vLLM 基于 Python 的架构、缺乏动态多模型调度以及安全沙箱 (gvisor) 的开销如何导致边缘环境中 GPU (图形处理器) 利用率低下和 CPU (中央处理器) 占用率高。 为了解决这些问题，Cloudflare 使用 Rust 设计了 Infire，利用该语言的底层控制来实现最大效率。Infire 的架构包括一个与 OpenAI 兼容的 HTTP 服务器、一个复杂的批处理器和核心 Infire 引擎。主要创新包括并行模型加载和内核编译、采用分块预填充的连续批处理以最大化 GPU (图形处理器) 内存带宽和 Tensor Core 利用率，以及用于高效注意力机制管理的页面 KV 缓存。此外，Infire 采用专门为 Nvidia Hopper GPU 优化的即时编译的 CUDA 内核，并利用细粒度的 CUDA 图来降低内核启动成本。基准测试结果清楚地表明了 Infire 的卓越性能，与 vLLM 相比，完成推理任务的速度更快，CPU (中央处理器) 开销显著降低，尤其是在实际、受限的生产场景下。这种效率转化为更高的 GPU (图形处理器) 利用率（高达 80% 以上）和更低的运营成本，从而将 Cloudflare 的 Workers AI 定位为一个用于 AI (人工智能) 应用程序开发的高性能平台。文章最后概述了未来的增强功能，如多 GPU (图形处理器) 支持、量化和真正的多租户。

💡 主要观点

  1. 现有的推理解决方案（如 vLLM）对于 Cloudflare 的分布式边缘网络来说并非最佳。 集中式 GPU (图形处理器) 部署和基于 Python 的引擎难以处理动态边缘工作负载、安全沙箱 (gvisor) 和底层优化需求，从而导致 GPU (图形处理器) 利用率低下和 CPU (中央处理器) 占用率高。
  2. Infire 是一种定制的基于 Rust 的引擎，通过量身定制的架构和底层优化，实现了卓越的 LLM (大型语言模型) 推理效率。 通过利用 Rust 进行底层控制、连续批处理、页面 KV 缓存和针对特定硬件优化的即时编译的 CUDA 内核，Infire 显著提高了 GPU (图形处理器) 利用率并降低了 CPU (中央处理器) 开销。
  3. Infire 提供了切实的性能改进，使 Cloudflare 能够更快、更经济高效地运行 AI (人工智能) 推理。 基准测试表明，Infire 完成推理任务的速度更快，CPU (中央处理器) 占用率比 vLLM 低得多，从而可以使用更少的资源处理更多的请求，并降低 Cloudflare AI (人工智能) 服务的运营成本。

💬 文章金句

  • 该模型不适用于 Cloudflare --- Cloudflare 的全球分布式网络与使用大型多 GPU (图形处理器) 节点的典型集中式 AI (人工智能) 部署之间存在不匹配。
  • Infire 是一个用 Rust 编写的 LLM (大型语言模型) 推理引擎，它采用一系列技术来最大限度地提高内存、网络 I/O (输入/输出) 和 GPU (图形处理器) 利用率。它可以用更少的 GPU (图形处理器) 提供更多请求，并显著降低 CPU (中央处理器) 占用率，从而节省我们网络上的时间、资源和能源。
  • 我们很乐意为我们使用的开源项目做出贡献，但在这种情况下，我们的优先级可能不符合 vLLM 项目的目标，因此我们选择编写一个服务器来满足我们的需求。
  • 从我们获得的基准测试中可以看出，我们实现了匹配甚至略微超过 vLLM 性能的最初目标，但更重要的是，我们在 CPU (中央处理器) 使用率显著降低的情况下做到了这一点，这在很大程度上是因为我们可以将 Infire 作为受信任的裸金属进程运行。
  • 通过构建在连续批处理、页面 KV 缓存和针对我们硬件量身定制的底层优化等技术之上，Infire 最大限度地提高了 GPU (图形处理器) 利用率，同时最大限度地减少了开销。
