Kimi K2.7 Code 编程模型已上线 Kimi Code、API 开放平台

6/12/2026, 10:25:00 AM

📌 一句话摘要

月之暗面发布并开源 Kimi K2.7 Code 编程模型，在长上下文编程、指令遵循和 token 效率上显著提升，并预告下周推出 6 倍速高速版。

📝 详细摘要

月之暗面正式发布并开源 Kimi K2.7 Code 编程模型。该模型相比 K2.6 在长上下文编程场景的指令遵循能力、长程编程任务性能上显著提升，同时大幅改善过度思考倾向，平均 token 消耗减少 30%。内部基准测试显示，Kimi Code Bench v2 提升 21.8%，Program-Bench 提升 11%，MLS Bench Lite 提升 31.5%。Agent 自主化能力在 Kimi Claw 24/7 Bench、MCP Atlas 和 MCP Mark Verified 等基准测试中也有约 10% 的提升。模型即日起通过 Kimi API 开放平台提供，定价与 K2.6 一致（输入 6.5 元/百万 token，输出 27 元/百万 token，缓存输入 1.3 元/百万 token）。Kimi Code Plan 默认模型已同步升级。文章还预告了下周一（6 月 15 日）将推出输出速度约 5-6 倍的高速版，价格为普通版的 2 倍，并介绍了为期三周的充值赠送活动。文章明确指出，使用 K2.7 Code 须开启思考模式以发挥最佳性能，非编程任务仍推荐 K2.6。

💡 主要观点

  1. Kimi K2.7 Code 在编程任务上相比 K2.6 有显著性能提升。 内部基准测试显示，Kimi Code Bench v2 提升 21.8%，MLS Bench Lite 提升 31.5%，Agent 能力也有约 10% 的提升。
  2. 新模型大幅改善了过度思考倾向，token 效率更高。 平均 token 消耗减少 30%，以更少的计算资源达到更好的性能，对开发者更具成本效益。
  3. K2.7 Code 是专用编程模型，非编程任务仍推荐 K2.6。 文章明确建议，在非编程任务中使用能力更全面的 K2.6 模型，体现了产品定位的清晰性。
  4. 下周将推出 6 倍速高速版，价格为普通版 2 倍。 高速版输出速度约 180-260 Token/s，旨在提供更极致的编程体验，但消耗的套餐用量是普通版的 3 倍。

💬 文章金句

  • 在非编程任务中，我们仍然推荐能力更加全面的 K2.6 模型。
