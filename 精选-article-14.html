CSS 终于原生支持瀑布流布局了！

7/28/2025, 12:47:00 AM

📌 一句话摘要

文章详细介绍了 CSS 原生支持瀑布流布局的最新进展，包括其历史演进、语法特性、显著优势及浏览器支持情况，为前端开发者提供了高效实现复杂布局的新途径。

📝 详细摘要

本文深入剖析了 CSS 原生瀑布流布局（Masonry Layout）的到来，解决了传统上依赖 JavaScript 库或复杂 CSS 技巧实现瀑布流布局的痛点。文章首先回顾了过去实现瀑布流（如小红书、淘宝内容墙）的方案及其局限性，例如增加 JS 加载体积、响应式调整复杂、易出错等。接着，详细阐述了 CSS Masonry 从 2017 年社区呼声到 2025 年 Chrome/Edge 实验性支持的标准化演进过程，以及 Apple/WebKit 与 Google/Chromium 在语法上的争论与最终的折中方案。文章强调了原生 CSS Masonry 在性能、响应式、代码量和加载速度上的显著优势，并提供了`display: masonry`和在 Grid 中使用`masonry`值的两种核心语法及基础用法（如行方向布局、自动列数、跨列元素）。最后，总结了当前主流浏览器的支持现状，并展望了这一特性对前端开发带来的积极影响。

💡 主要观点

  1. CSS 原生 Masonry 布局解决了传统瀑布流实现复杂低效的问题 过去依赖 JS 库或复杂的 CSS Grid/Flexbox 方案存在性能开销、代码量大、响应式调整困难等问题，原生支持大大简化了开发流程。
  2. 原生 CSS Masonry 在性能和开发效率上具有显著优势 浏览器引擎直接计算布局，提升渲染性能，减少 JS 依赖和代码量，使页面加载更快，响应式调整更轻松，提升开发体验。
  3. 新特性拥有灵活的语法和实验性支持，预示未来广泛应用 支持`display: masonry`和 Grid 扩展语法，且已在 Chrome/Edge 等浏览器提供实验性支持，表明其即将成为前端布局的标配。

💬 文章金句

  • CSS 原生支持瀑布流布局了！只需要加上一行 display: masonry，浏览器就能自动帮你排好那些'不规整'的元素。
  • Chrome 团队测试发现，在包含 100 个元素的瀑布流中，原生 Masonry 比 JS 方案加载速度快了大约 40%。
  • 从 table 到 float，从 flex 到 grid，再到现在的 masonry，CSS 布局能力的每一次演进，都是在帮我们把'样式'这件事做得更优雅、更少依赖、更易维护。
