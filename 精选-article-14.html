基于推理模型+RAG+Agent，作业帮内部安全体系建设实践

4/23/2025, 9:50:09 AM

📌 一句话摘要

作业帮通过推理模型、RAG 和 Agent 构建智能安全体系，实现告警自动处置，提升安全运营效率和知识积累。

📝 详细摘要

文章介绍了作业帮如何利用推理模型、RAG（检索增强生成）和 AI Agent 构建智能安全体系，以解决传统安全运营面临的告警过载、响应迟滞和知识断层问题。该方案通过标准化报警数据、补充关键信息、向量化、多路召回、大模型推理和 Agent 自动执行等步骤，并采用多模型交叉验证来提升推理准确性，实现了告警的自动处置和知识库的构建。其中，RAG 通过从海量历史数据中检索相似案例辅助决策。实验结果表明，该系统能够显著提升告警处置效率和准确率，将专家经验转化为可复用的数字资产，并实现对新型威胁的预测性防御。

💡 主要观点

  1. 传统安全运营面临告警过载、响应迟滞和知识断层三重困境 传统安全运营模式难以应对日益增长的告警量，专家经验难以沉淀和复用，导致安全风险响应不及时，效率低下。
  2. 基于推理模型 + RAG + Agent 的安全大脑实现深度安全运营 通过整合推理模型、RAG 和 AI Agent，构建智能化的安全运营体系，实现告警的自动分析、分类、处置和知识库的自动更新。
  3. 最小指令策略提升大模型推理准确性 通过减少指令性描述，让大模型更依赖参考内容，而非自身的预训练知识，从而减少模型幻觉问题，提高告警分类的准确性和可解释性。
  4. 知识工程化 将专家经验转化为可复用的数字资产。
  5. 决策透明化 建立威胁处置的可解释性链条。
  6. 防御前瞻性 实现对新型威胁的预测性防御。

💬 文章金句

  • 在安全攻防进入 '秒级对抗' 的新时代，大模型与专业知识库的深度协同将成为构建下一代智能安全体系的核心范式。
  • 内部杀毒和威胁监测系统日均 15，000 条安全告警中有效信号不足 15%，4 万员工产生的日均 6000 多条行为预警中的有效信号不足 3%。
  • 通过推理模型与 RAG 技术以及各种 AI agent 的深度融合，我们构建了符合中大型互联网企业的自适应内网安全体系。
