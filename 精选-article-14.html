Claude Code 创始人首次公开：我的 13 个使用技巧！

1/3/2026, 2:06:00 PM

📌 一句话摘要

Claude Code 创始人 Boris Cherny 公开分享了他使用 AI 编程助手 Claude Code 的 13 个高效实践技巧，涵盖多实例并行、模型选择、团队协作与自动化等。

📝 详细摘要

本文首次公开了 Claude Code 创始人 Boris Cherny 使用其 AI 编程助手的 13 个个人技巧。文章揭示了 Boris 如何在日常开发中高效利用 Claude，包括并行运行多个 Claude 实例、结合终端和网页端会话协作、选用 Opus 4.5 模型处理复杂编程任务。核心实践包括维护团队共享的 CLAUDE.md 文件以记录 AI 行为规范、在代码审查中集成 AI 反馈、使用“计划模式”确保 AI 理解任务、通过斜杠命令和子智能体自动化重复工作流，以及利用 PostToolUse 钩子和权限管理保障代码质量和安全性。最重要的是，文章强调为 Claude 提供有效的验证机制，形成反馈闭环，以显著提升 AI 产出质量。

💡 主要观点

  1. 多实例与多模式并行操作提升开发效率。 通过在终端和网页端并行运行多个 Claude 实例，并结合手机应用进行协作，实现无缝切换和持续工作，打破了单任务阻塞的限制。
  2. 选择合适的 AI 模型对编程工作至关重要。 明确指出 Opus 4.5 模型虽然更大更慢，但在编程任务中因其更强的理解和工具使用能力，最终能提供更高的效率和更少的人工干预。
  3. 通过共享文档规范 AI 行为，实现团队协作中的 AI 最佳实践。 建立并维护团队共享的 CLAUDE.md 文件，用于记录 Claude 的错误和正确实践，确保团队成员对 AI 的使用方式达成共识，并持续优化其表现。
  4. 强调预先规划和自动化以提高 AI 生产力。 利用“计划模式”与 AI 共同制定详细方案，并结合斜杠命令、子智能体等自动化工具，将重复性工作和常见流程标准化，减少人工干预，提高开发效率。
  5. 建立 AI 输出的反馈和验证闭环是提升 AI 质量的关键。 通过 Chrome 扩展、bash 命令、测试集或模拟器等方式，让 Claude 能够自验证其生成代码和方案的正确性，形成有效反馈循环，从而将其输出质量提升 2-3 倍。

💬 文章金句

  • 我的配置可能会让你大吃一惊，因为它极其朴素。Claude Code 能够完美地开箱即用，所以我个人并没有做太多的定制化修改。
  • 我所有工作都用带有"思考过程（thinking）"的 Opus 4.5。这是我用过最好的编程模型。
  • 我们团队共用一个 CLAUDE.md 文件。每当我们发现 Claude 做错了什么，就会记录进 CLAUDE.md，这样它下次就知道该怎么做了。
  • 大多数会话从"计划模式（Plan mode）"开始…一份好的计划至关重要！
  • 最后一个秘诀（可能也是让 Claude Code 产出高质量结果最重要的事）：给 Claude 一个验证工作的方法。只要有反馈闭环，最终结果的质量会提升 2-3 倍。
