Kimi Work Beta 版邀你体验：你的工作，分我一半

6/3/2026, 12:41:00 PM

📌 一句话摘要

Kimi 推出面向知识工作者的通用型本地 Agent「Kimi Work」Beta 版，将 Coding Agent 能力迁移至桌面 GUI，支持自然语言驱动的复杂任务拆解、多 Agent 并行协作与工具调用。

📝 详细摘要

文章由月之暗面官方发布，正式推出 Kimi Work Beta 版。Kimi Work 是面向知识工作者的通用型本地 Agent，基于 Kimi Code 的底层能力，将 Coding Agent 从终端（TUI）迁移至桌面图形界面（GUI）。用户无需编写命令或配置环境，仅用自然语言描述目标，即可让 Agent 在本地电脑上拆解任务、并行执行、调用浏览器、操作文件，并交付文档、表格、PPT 等产物。文章列举了金融（调研巴菲特持仓并生成投资 Skill）、科研（清洗数据、绘制图表、辅助论文）、办公（读取本地文件、调研市场、生成 128 页报告并转化为 PPT）三个典型场景的工作流。此外，文章披露 Kimi Work 自身由 Kimi Code 深度参与开发，一周内完成客户端，累计 5 万行有效代码中 92% 由 AI 生成，背后依赖 Kimi K2.6 模型的长程任务执行能力（支持 13 小时连续编码、300 个子 Agent 并行协作、4000 余次工具调用）。

💡 主要观点

  1. Kimi Work 将 Coding Agent 能力迁移至桌面 GUI，面向非技术知识工作者。 基于 Kimi Code 的本地 Agent 能力，Kimi Work 让用户通过自然语言而非终端命令来驱动 Agent 完成复杂工作流，降低了使用门槛。
  2. 支持 Agent 集群，最高可创建 300 个子 Agent 并行协作。 根据任务复杂度，Kimi Work 可自主创建多 Agent 团队，处理更复杂、耗时更长的任务，体现了其在任务拆解与并行执行上的能力。
  3. Kimi Work 自身由 AI 深度参与开发，92% 代码由 AI 生成。 开发过程中，工程师使用 Kimi Code 等工具，一周内完成客户端，累计 5 万行有效代码中 92% 由 AI 自主生成，展示了 AI 辅助开发的效率。
  4. 内置 Kimi WebBridge，可像用户一样操作浏览器。 Agent 能调用浏览器登录数据看板、调研网站，实现本地文件与在线数据的联动处理，扩展了 Agent 的能力边界。
