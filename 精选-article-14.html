我们如何训练人工智能以识别恶意 JavaScript 意图，提升网页浏览安全性

3/19/2025, 1:00:00 PM

📌 一句话摘要

Cloudflare Page Shield 利用人工智能和图神经网络分析 JavaScript 语法树，精准检测恶意代码，增强 Web 安全性。

📝 详细摘要

Cloudflare 开发了一种人工智能模型，通过分析 JavaScript 代码的语法树结构来检测恶意代码。该模型利用图神经网络（GNNs）处理抽象语法树（ASTs），有效识别 Magecart、加密货币挖矿和恶意软件等威胁。为解决恶意脚本数据不平衡问题，Cloudflare 采用 LLM 代码嵌入过滤语义相似脚本，减少误报，提高模型精度。该模型已集成到 Page Shield 中，为客户提供增强的客户端威胁洞察，并提高检测准确性。

💡 主要观点

  1. 图神经网络能够有效识别恶意 JavaScript 代码 通过分析代码的语法树结构，图神经网络可以识别指示恶意代码的模式与行为，即使代码被混淆。
  2. LLM 嵌入技术降低恶意代码检测误报率 使用大语言模型对代码进行语义分析可以过滤掉类似的良性脚本，从而减少需要手动审查的样本数量并降低误报率。
  3. Cloudflare Page Shield 集成了基于图神经网络和大语言模型的人工智能模型，显著提升恶意 JavaScript 代码检测能力 通过 Page Shield，用户可以更深入地了解客户端威胁，并可以实施相应的安全措施，从而更好地保护用户免受网络攻击。

💬 文章金句

  • 我们最初的方法无法清晰揭示脚本的特定恶意目标或其旨在发起的攻击类型。
  • 我们构建了这款全新的 Page Shield 人工智能模型，旨在实现对 JavaScript 威胁意图的大规模检测。
  • 发现恶意脚本如同大海捞针，它们隐藏在海量良性 JavaScript 代码中，实属异类。
