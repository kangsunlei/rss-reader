LoRA 一作、OpenAI o1 核心成员的新工作：首次公开 397B 模型的 Agent RL 训练配方

9/17/2026, 4:00:00 PM

📌 一句话摘要

LoRA 一作、OpenAI o1 核心成员联合发布的首份 397B 知识工作 Agent RL 训练配方，系统公开了从 Harness 治理、Token 对齐到异步训练调优的完整流程，Pass@1 相对提升 70%，并论证了 Agent RL 本质是系统工程而非算法选型。

📝 详细摘要

本文详细解析了 Mercor 与 SkyRL 团队联合发布的面向复杂知识工作的 Agent 强化学习训练方案。该方案首次系统公开了从任务环境搭建、Harness 优化、Token-in-Token-out 对齐、分布式系统调优，到小规模过拟合验证、35B 算法消融再到 397B 正式训练的完整链路。实验表明，仅 Harness 优化即可使平均奖励提升 5.95 个百分点；Prompt Mean 聚合将奖励再提升 3.85 个百分点；最终 Qwen3.5-397B-A17B 在 APEX-Agents 基准上 Pass@1 从 16.11%提升至 27.29%（相对提升约 70%），且 35B 模型训练后超过了 Claude Opus 4.5。文章强调 Agent RL 并非选定算法即可开始训练，而是模型、数据、工具、环境、Verifier、分布式系统的综合工程，任何环节的偏差都可能让长轨迹变成错误信号。跨 Harness 迁移实验显示收益可部分泛化，但大模型的工具偏好会影响迁移效果。

💡 主要观点

  1. Harness 治理的优先级高于算法调优 团队在 RL 前花费大量精力解决环境稳定性问题：设置所有外部操作 Timeout、多 API Key 轮询避免 LLM Judge 限流、每条 Agent Loop 使用独立进程防止 MCP 断连、区分任务失败与系统错误。仅修复沙箱 Python 包缺失、PDF 工具布局破坏、PowerPoint 返回 None 等 Harness 问题，未训练模型的奖励就提升了 5.95 个百分点，相当于一个 Epoch 的训练收益。
  2. TITO 确保训练-推理 Token 完全一致 多轮 Agent 会反复经历「模型输出→解码→执行→拼接→重新 Tokenize」，若通过文本重建上下文，不同 Token 序列可能解码为相同文本，导致状态-动作-概率对应关系破坏，使算法变成隐蔽的 Off-policy。团队采用 TITO 方案：Agent 直接处理原始 Token ID，保存输入 Token、输出 Token、Logprob、Loss Mask 和 Reward，确保训练器使用的动作与推理引擎实际采样完全一致。
  3. Prompt Mean 是最有效的单项算法改动 传统 Token Mean 会使超长轨迹（如 128K）获得远高于短轨迹（如 2K）的梯度权重，导致训练目标偏向输出最长的任务。Prompt Mean 先在同 Prompt 的 Rollout Group 内聚合，再对不同 Prompt 求平均，使每个任务获得相同权重。该项改动将平均奖励提升 3.85 个百分点，是全文效果最好的单项改动。
  4. 过拟合验证和跨 Harness 泛化检查不可省略 团队用 32 个有奖励方差的任务进行端到端过拟合实验，发现文件 Diff 评分任务的失败源于文件提取不完整和 Diff 工具不准确，更换第三方工具后才出现清晰学习信号。这证明小规模过拟合可作为单元测试，提前暴露 Verifier、Reward、Token 对齐等问题。跨 Harness 实验（Archipelago→OpenCode→Terminus）显示收益可迁移，但 35B 因代码执行比例上升而迁移更好，397B 仍偏好 MCP 工具。
  5. Agent RL 收益本质来自系统工程而非单一算法 完整 Post-training 使两个模型提高约 10-12 个百分点，而 Harness 优化贡献了近一半。DPPO 相对于 GLM-5 Loss 奖励提升不显著（0.34 个百分点），但改变了 Agent 行为模式：从「一次输出很长」转向「短思考→调工具→看结果→再思考」。这印证了核心判断：知识工作 Agent 需要构造完整的交互世界（环境+任务+工具+轨迹+可验证结果+可靠 Reward），而不仅是算法选择。

💬 文章金句

  • 对复杂知识工作 Agent 而言，RL 算法只是整个训练系统的一部分。环境、Harness、Verifier、Token 对齐、KV Cache 和异步调度，同样可能决定一次训练能否成功。
  • 在 Agent RL 中，修好 Harness 本身，就可能比修改一次 RL 算法更有效。
  • Prompt Mean 是最有效的单项改动，提高了约 3.9 个百分点。
  • Agent RL 并不是选定 GRPO、PPO 或者 DPPO 以后就可以开始训练。真正的大规模 Agent RL，是模型、数据、工具、环境、Verifier、分布式推理和训练系统共同组成的工程。
  • 先修环境，再保证 Token 正确；先证明可以过拟合，再比较算法；最后，才值得把 397B 模型放进训练集群。
