OpenAI 正在悄然采纳 'Skills' 机制，并已集成至 ChatGPT 和 Codex CLI

12/12/2025, 11:29:51 PM

📌 一句话摘要

OpenAI 已采用类似于 Anthropic 的“技能”机制 (Skills mechanism)，并将其整合到 ChatGPT 的代码解释器和 Codex CLI 中，以增强其模型与外部工具和资源的能力。

📝 详细摘要

本文报道了 OpenAI 悄然在 ChatGPT 的代码解释器和 Codex CLI 中引入“技能”机制，与 Anthropic 早期的实现方式类似。“技能”允许大型语言模型 (LLM) 与外部工具和资源交互，从本质上为它们提供了新的功能。在 ChatGPT 中，用户可以访问一个包含用于处理电子表格、DOCX 和 PDF 文件的技能的 `/home/oai/skills` 文件夹。值得注意的是，PDF 技能将文档转换为 PNG 图像，供视觉增强型 GPT 模型进行视觉处理，从而保留布局信息。Codex CLI 也支持技能，可以从 Git 仓库本地安装。作者展示了两种实现方式，展示了 ChatGPT 生成详细的 PDF 报告，以及 Codex CLI 创建 Datasette 插件，突出了这些技能在扩展大型语言模型能力方面的灵活性和强大功能。OpenAI 这样的大型参与者采用这种轻量级技能规范，突显了其作为人工智能交互方面重大进步的潜力。

💡 主要观点

  1. OpenAI 已将“技能”机制集成到 ChatGPT 和 Codex CLI 中，与 Anthropic 的方法类似。 这使得 OpenAI 的大型语言模型能够利用外部工具和资源，显著扩展了它们超越核心语言任务的功能能力。
  2. ChatGPT 代码解释器中的技能能够处理 PDF 和 DOCX 等各种文档类型。 通过将文档转换为图像格式 (PNGs) 供视觉增强型 GPT 模型使用，该系统保留了在纯文本提取中常常丢失的布局和图形信息，从而实现更丰富的理解。
  3. “技能”机制轻量化且基于文件夹，易于适应和扩展。 这种简单的设计允许快速集成和创建新技能，为大型语言模型的工具增强培养了一个多功能生态系统。
  4. OpenAI 采用技能验证了其作为人工智能重大进步的潜力。 这一主要人工智能参与者的广泛采用证实了轻量级、外部工具集成对于增强人工智能能力和开发者工作流程的价值。

💬 文章金句

  • 技能只是一个包含 Markdown 文件和一些可选额外资源和脚本的文件夹，所以任何能够导航和读取文件系统的 LLM 工具都应该能够使用它们。
  • 结果是，ChatGPT 的代码解释器功能现在有一个新的 `/home/oai/skills` 文件夹，你只需通过提示即可访问。
  • 有趣的是，他们为 PDF 和文档选择的方法是将其转换为每页渲染的 PNG 图像，然后通过他们视觉增强型的 GPT 模型进行处理，大概是为了保留布局和图形中可能丢失的信息，如果他们只是运行文本提取的话。
  • 事实上，现在才十二月，OpenAI 已经大力拥抱这些机制，这让我更加确信我判断对了这一点。
