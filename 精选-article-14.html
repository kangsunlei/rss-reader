为什么 Anthropic 认为 AI 应该拥有自己的计算机——Claude Cowork 和 Claude Code Desktop 的 Felix Rieseberg

3/17/2026, 9:39:16 PM

📌 一句话摘要

Felix Rieseberg 探讨了为什么 Anthropic 相信 AI 的未来在于通过本地优先的代理工作流实现可信的任务执行，即 AI 拥有自己的计算机来工作，而不仅仅是聊天界面。

📝 详细摘要

这是一期与 Felix Rieseberg 的深度播客访谈，他在 Anthropic 构建了 Claude Cowork。对话探讨了 Claude Code 如何意外地揭示出用户希望将 AI 用于杂乱的知识工作，而不仅仅是编程。Felix 分享了他从构建 Slack 桌面应用和维护 Electron 到创建 AI 驱动工具的历程。核心论点是，执行成本已经变得足够低，团队可以构建多个候选方案并进行测试，而 AI 产品的真正前沿不再是如何做出更好的聊天界面，而是可信的任务执行。讨论涵盖了本地优先的代理工作流、技能在 AI 系统中的重要性，以及关于自主性、安全性、可移植性和知识工作本身转变的根本问题。

💡 主要观点

  1. Claude Cowork 的出现源于观察到用户将 Claude Code 用于杂乱的知识工作，而不仅仅是编程。 即使是技术用户也在利用 Claude Code 处理非技术任务，这揭示了对非结构化知识工作中的 AI 协助有更广泛的需求，超越了传统编程。
  2. AI 产品的真正前沿已经从更好的聊天界面转向了可信的任务执行。 随着 AI 能力的成熟，竞争优势从对话式界面转向了能够在最少人工监督下可靠完成复杂任务的系统。
  3. 执行成本已经变得足够低，团队可以快速构建多个候选方案并进行测试。 借助 AI 辅助开发，原型制作和构建的成本大幅下降，使团队能够采用探索性方法，构建和评估多个解决方案，而不是早期就承诺单一方向。
  4. Anthropic 正在押注本地优先的代理工作流，即 AI 拥有自己的计算机来工作。 这一架构决策优先考虑用户隐私、数据所有权和离线能力，同时使 AI 代理能够更自然地与本地系统和文件交互。
  5. 技能在 AI 系统的未来中可能比大多数人意识到的更重要。 随着 AI 代理变得更加强大，组合、定制和共享专业技能的能力成为用户和平台的关键差异化因素。

💬 文章金句

  • Felix 和 Anthropic 团队注意到 Claude Code 的一个有趣现象：许多用户主要将其用于各种杂乱的知识工作，而不是编程。
  • 这并非 Felix 第一次开发有影响力且有趣的桌面应用。他曾参与发布 Slack 桌面应用，并且是 Electron 的核心维护者。
  • 执行成本突然变得足够低，团队可以『直接构建所有候选方案』
  • AI 产品的真正前沿不再是如何做出更好的聊天界面，而是可信的任务执行。
