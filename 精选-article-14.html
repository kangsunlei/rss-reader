Spring Boot 4.0.0 正式发布

11/20/2025, 12:00:00 AM

📌 一句话摘要

Spring Boot 4.0.0 发布，引入模块化架构、JSpecify 空安全、Java 25 支持以及增强的 API 版本控制和 HTTP 客户端，构建于 Spring Framework 7 之上。

📝 详细摘要

本文宣布 Spring Boot 4.0.0 的正式发布，标志着该框架进入新的发展阶段。此主要版本构建于 Spring Framework 7 之上，引入了多项重要功能。主要改进包括代码库的完全模块化架构，从而产生更小、更集中的 JAR 包，以及通过 JSpecify 实现的整个 Spring 生态系统的空安全增强。它还为 Java 25 带来全面支持，同时保持与 Java 17 的兼容性。此外，该版本还为 API 版本控制和 HTTP 服务客户端提供强大的支持，以支持现代 REST 应用程序开发。本文将用户引导至详细的发行说明，以获取完整的功能列表。同时，提供了专门的迁移指南，以帮助升级现有应用程序。最后，欢迎社区积极贡献，并提供全方位的支持资源。

💡 主要观点

  1. Spring Boot 4.0.0 引入了重要的架构变更，包括完全模块化架构。 代码库的模块化架构产生了更小、更集中的 JAR 包，改善了依赖管理和应用程序启动时间，与现代云原生架构原则保持一致。
  2. JSpecify 增强空安全，提高代码质量并减少运行时错误。 在整个 Spring 产品组合中集成 JSpecify 有助于开发人员编写更健壮和可靠的应用程序，从而在编译时捕获潜在的空指针异常。
  3. 对 Java 25 的全面支持确保了面向未来的能力，同时保留了 Java 17 的兼容性。 这使开发人员可以利用最新的 Java 语言特性和性能改进，同时为现有应用程序提供平滑的升级路径。
  4. API 版本控制和 HTTP 服务客户端的新功能简化了 REST 应用程序开发。 这些新增功能简化了 RESTful API 的创建和使用，解决了分布式系统通信和可维护性方面的常见挑战。

💬 文章金句

  • 此版本是新一代 Spring Boot 的开始，为未来几年提供了坚实的基础。
  • Spring Boot 代码库的完全模块化架构，提供了更小、更集中的 JAR 包。
  • 通过 JSpecify 实现的整个产品组合的空安全改进。
  • 对 Java 25 的全面支持（同时保留 Java 17 的兼容性）。
  • 对基于 REST 的应用程序的 API 版本控制和 HTTP 服务客户端的支持。
