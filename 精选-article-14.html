Kimi K2.6 发布并开源，全面精进代码和 Agent 集群能力

4/20/2026, 3:34:00 PM

📌 一句话摘要

月之暗面发布并开源 Kimi K2.6 模型，在代码能力、长程任务执行和 Agent 集群协作方面实现显著提升，并宣布开启 Claw 群组内测。

📝 详细摘要

本文是月之暗面官方发布的 Kimi K2.6 模型公告。K2.6 在代码、长程任务执行和 Agent 集群能力上取得行业领先（state-of-the-art）表现，在多项基准测试中持平或优于 GPT-5.4、Claude Opus 4.6 等闭源模型。核心升级包括：长程编码能力突破，可连续工作 13 小时，迭代优化数千行代码；Agent 集群架构升级，支持 300 个子 Agent 并行完成 4000 个协作步骤；与 OpenClaw、Hermes Agent 等框架协同，支持长达 5 天的持续自主运行。文章还详细介绍了代码驱动设计、Office 办公能力精进等新特性，并预告了旨在实现人机协作的 Claw 群组内测。模型已全面上线 Kimi 各平台并开源。

💡 主要观点

  1. Kimi K2.6 在代码和 Agent 能力上达到行业领先水平。 在 SWE-Bench Pro、DeepSearchQA 等基准测试中，K2.6 的表现持平或优于 GPT-5.4、Claude Opus 4.6 等顶级闭源模型，是其迄今最强的代码模型。
  2. 模型的长程编码与推理能力取得突破，可处理超长时复杂任务。 K2.6 可连续运行 13 小时，进行超过 4000 次工具调用，成功完成对复杂开源项目的深度重构和性能优化，展现了强大的持续推理和工程能力。
  3. Agent 集群架构全面升级，支持大规模、高质量的并行化协作。 集群能力从 K2.5 进化，现支持 300 个子 Agent 并行处理 4000 个步骤，并能组合不同技能，端到端交付从文档到网页、PPT 的多产物成果。
  4. 开启 Claw 群组内测，探索人机异构协同的新范式。 Claw 群组允许用户接入来自不同设备、供应商的 Agent，与人类在同一个群组中协作，由 K2.6 担任协调者，动态分配任务和管理生命周期。

💬 文章金句

  • Kimi K2.6 是我们迄今最强的代码模型，其长程编码能力也得到显著提升，在测试中可以不间断编码 13 小时，编写或修改超过 4000 行代码，完成复杂系统的开发和优化。
  • 突破单体 Agent 性能的限制，才能实现 Agent 能力的规模化扩张。
  • 在 K2.5 的基础上，K2.6 的 Agent 集群的协同能力全面升级。Agent 集群现在可以调度不同技能特长的 Agent 互补协作。
  • 人类通过团队协作和组织分工，创造了互联网、做出了大模型、登上了月球，AI Agent 想要帮助人类处理现实世界的复杂难题，也必然会向团队协作和组织分工的方向进化。
  • 这就是我们已开启小范围内测的「Claw 群组」。「Claw 群组」的目标是拥抱开放、异构的生态：多个 Agent 与人类作为真正的协作者共同运行。
