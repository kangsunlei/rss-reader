“亲手做了 12 个 AI Agent，我并不看好 2025 年的智能体！”

7/22/2025, 9:30:00 AM

📌 一句话摘要

一位资深工程师基于实践经验，指出当前 AI Agent 发展面临数学可靠性、成本爆炸和工具设计三大挑战，不看好 2025 年完全自主智能体热潮，强调人机协作和传统软件工程的重要性。

📝 详细摘要

文章作者作为一名拥有 12 个以上生产级 AI Agent 系统构建经验的工程师，对当前业界普遍高估的“AI Agent 元年”论调提出质疑。他指出，全自动智能体在生产环境中面临三大核心挑战：首先，多步骤任务中错误率会呈指数级放大，导致可靠性远低于生产环境要求；其次，长对话上下文会导致 token 成本呈二次方增长，使得经济上不可持续；最后，最大的难题并非 AI 模型能力本身，而是如何为 Agent 设计能有效沟通的工具和反馈系统，以及与复杂现实世界系统的集成。作者强调，真正成功的 Agent 是边界清晰、有明确人工确认点和传统软件工程保障的“能力超强且边界清晰的助手”，而非完全自主的智能体。

💡 主要观点

  1. 多步骤任务中错误率会呈指数级放大，导致全自动智能体在数学上不可行。 即使每一步成功率高，多步流程整体成功率也远低于生产环境要求的 99.9%，使得全自动 Agent 的可靠性难以保障。
  2. 长对话上下文会导致 Token 成本呈二次方增长，经济上不可持续。 每次交互需处理所有历史上下文，Token 消耗随对话长度呈二次方增长，大规模应用时成本将无法承受。
  3. AI Agent 最大挑战在于工具设计与反馈系统，而非模型能力。 关键在于设计能与 AI 有效沟通的工具接口和结构化反馈机制，让 Agent 真正理解操作状态并进行决策。
  4. 与复杂现实世界系统集成是 AI Agent 落地的巨大障碍。 企业遗留系统、复杂故障模式、动态认证和合规要求等，使得 Agent 难以无缝集成并稳定运行。
  5. 真正可行的 Agent 是人机协作且边界清晰的，并由传统软件工程保障。 AI 负责处理复杂问题，人工掌控关键决策，结合传统软件工程的可靠性、容错和成本控制，才能实现稳定实用。

💬 文章金句

  • 多步骤流程中的错误率会呈指数级放大。即便每一步的成功率有 95%，到第 20 步时整体成功率也只剩 36%。而生产环境的要求是 99.9% 起步。
  • 我做过的每一个成功 Sgent 系统都有相同的规律：有边界清晰的上下文、可验证的操作步骤，以及关键节点上的人工决策点。
  • 我做的函数生成 Agent 之所以成功，是因为它完全无状态：输入描述-输出函数-过程结束。没有需要维护的上下文，也不用追踪对话，避免了成本的爆炸。
  • AI 可能只做了 30% 的工作，其余 70% 是工具工程------设计反馈接口、高效管理上下文、处理部分失败，以及构建 AI 能理解和利用的恢复机制。
  • AI 负责处理复杂问题，人工负责掌控关键决策，传统软件工程保障系统稳定可靠。
