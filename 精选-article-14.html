OpenAI 杀入通用 AI Agent 背后：四大技术流派与下一个万亿流量之战

8/3/2025, 4:24:00 AM

📌 一句话摘要

文章深入剖析了 OpenAI 进军通用 AI Agent 领域后的市场格局，详细介绍了四大主流技术流派，并展望了 AI Agent 如何重塑未来的互联网流量和广告生态。

📝 详细摘要

文章围绕 OpenAI 发布 ChatGPT Agent，正式入局通用 AI Agent 赛道展开，探讨了该领域可能成为下一代互联网万亿流量入口的潜力。文章通过采访 Pokee.ai 创始人朱哲清和硅谷 101 特约研究员 Nathan Wang，详细分析了当前通用 AI Agent 在通用性与速度及稳定性之间进行权衡的四大主要技术流派：包括以 OpenAI 为代表的“浏览器为主派”；以 Manus 为代表的“虚拟机+浏览器派”；以 GensPark 为代表的“大模型+虚拟机派”；以及以 Pokee/UiPath 为代表的“工作流+工具集成派”。文章指出，目前“通用性”与“速度及稳定性”难以兼得，且未来通用 Agent 的发展将加速交互速度、走向细分与通用并存。最后，文章大胆预测了“幽灵光标”时代下，Agent 将成为新的流量入口，并颠覆现有的广告模式，为内容创作者带来更直接的收益模式，同时提示了 AI Agent 带来的新风险与挑战。

💡 主要观点

  1. 通用 AI Agent 赛道正成为未来互联网的“万亿流量入口”核心战场 OpenAI 的入局预示着 AI Agent 将成为继搜索引擎、社交媒体之后的新一代流量枢纽，重塑互联网生态格局，引发巨头间的激烈竞争。
  2. 当前通用 AI Agent 存在四大核心技术流派，各有优劣 包括浏览器为主、虚拟机+浏览器、大模型+虚拟机、工作流+工具集成，这些流派在通用性、速度、稳定性与执行效率之间进行权衡取舍。
  3. “通用性”与“速度/稳定性”是 AI Agent 发展中的核心矛盾 文章指出，目前的技术路线难以同时实现极致的通用性和高效稳定的性能，厂商需根据产品定位进行取舍，或通过技术优化寻求平衡。
  4. 未来互联网流量将由“幽灵光标”主导，颠覆传统广告模式 随着 AI Agent 成为互联网访问主力，传统的人类点击流量将失去意义，未来的广告和信息获取模式将发生根本性变革，内容价值将更直接变现。

💬 文章金句

  • 未来的流量入口将变成各个 Agent
  • 通用 Agent 很可能成为下一代互联网的“万亿流量入口”，让市场格局再次洗牌。
  • 目前“通用性”和“速度及稳定性”是鱼与熊掌不可兼得，必须要牺牲一个。
  • 以后的互联网充斥的都将是所谓的“ghost clicks”（幽灵光标），都是 Agent 们在与网页交互，抓取信息。
  • 未来的流量入口将成为 Agent，而这个赛道也将是下一场巨头之战的中心。
