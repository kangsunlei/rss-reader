Manus 回来了！更新 2.0 并发布全天候智能体 Cue

9/29/2026, 3:56:00 AM

📌 一句话摘要

Manus 2.0 通过 Cascade 架构和 Cloud Computer 实现全天候智能体能力，支持视频编辑、游戏开发和远程电脑操作，标志着 AI Agent 从助手向数字员工的进化

📝 详细摘要

Manus 2.0 重构了底层 Agent 架构，推出 Cascade 自研 Agent Harness，实现 Token 消耗减少 23.2%、任务完成时间缩短 28.2%、运行成本降低 32%。Cloud Computer 提供独立云端运行环境，Automations 支持事件触发工作流。Manus Studio 升级为共享工作空间，支持视频编辑、游戏开发等专业环境。Cue 应用推出，支持个人 Agent 场景，可独立执行任务并连接日常服务。Manus 2.0 旨在将想法变成现实，延续了从生成到完善和交互的完整流程。

💡 主要观点

  1. Cascade 架构实现高效 Agent 运行 Cascade 通过轻量化设计和统一项目管理，减少 Token 消耗 23.2%、缩短任务完成时间 28.2%、降低运行成本 32%，为复杂任务提供更好的效果和更少的浪费。
  2. Cloud Computer 提供独立运行环境 Cloud Computer 为项目提供独立的云端运行环境，支持多人游戏、自动化任务等需求，使 Agent 的生命周期不再依赖用户打开电脑。
  3. Automations 支持事件触发工作流 Automations 允许任务由外部事件触发，如收到新邮件、广告效果变化等，用户只需告诉 Manus 关注什么和下一步应该做什么，即可自动建立并运行整个工作流。
  4. Manus Studio 提供专业工作空间 Manus Studio 根据项目需求引入必要能力，支持视频编辑、游戏开发等专业环境，如 Video Editor 和 Game Dev，提供时间线编辑方式和 Alchemy 模式，使用户能够更方便地修改和优化内容。
  5. Cue 应用支持个人 Agent 场景 Cue 是 Manus 推出的全新独立应用，支持个人 Agent 场景，可在手机和桌面端使用，每个 Agent 拥有独立的电子邮箱、电话号码、钱包和电脑，支持替用户接听电话、发送消息、完成支付等任务。

💬 文章金句

  • Cascade 能够做到：Token 消耗减少 23.2%，任务完成时间缩短 28.2%，运行成本降低 32%。
  • Manus 2.0 想让它变成一个真正在线的「数字员工」。
  • 只需要通过一句话告诉 Manus：「关注什么，以及下一步应该做什么。」它就会自动建立并运行整个工作流。
  • Manus 2.0 将重点放在了「生成之后」。
  • Manus 希望帮助人们把想法变成现实，Manus 2.0 延续了这一承诺。
