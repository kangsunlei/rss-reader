Kimi K3.1 Pro：智能前沿，更进一步

10/23/2026, 5:16:00 PM

📌 一句话摘要

月之暗面发布 Kimi K3.1 Pro，作为 3 万亿参数、支持 100 万上下文的旗舰模型，在代码、3D 创作、金融研究及安全可控方面实现显著提升，并同步推出高速版。

📝 详细摘要

本文是月之暗面关于 Kimi K3.1 Pro 模型的官方发布公告。Kimi K3.1 Pro 是 K3.1 系列的首个模型，拥有 3 万亿参数，支持 100 万上下文窗口。文章详细介绍了模型在代码、3D 创作和金融研究等领域的性能提升，并提供了丰富的基准测试结果和实际案例。在代码方面，模型在 Terminal-Bench 4.0 等测试中得分 65.7%，超过 GPT-6 Astra，接近 Claude Opus 5.5，并展示了从游戏开发到复杂仿真等端到端能力。3D 创作方面，BenchCAD 基准得分 92.7%，可完成参数化建模和 3D 打印设计。金融方面，在 OfficeQA Pro v2 基准上取得 SoTA 成绩，并展示了财务建模、投研报告和行业深度研究案例，事实准确性大幅提升。此外，文章还讨论了模型的安全措施，包括移除网络攻防数据以降低滥用风险，并阐述了开放权重的决策。最后，提供了多种使用途径，包括 kimi.com、Kimi Work、Kimi Code 和 API，以及企业版服务。

💡 主要观点

  1. Kimi K3.1 Pro 是月之暗面发布的 3 万亿参数旗舰模型，支持 100 万上下文，在多个领域实现全面提升。 作为 K3.1 系列的首个模型，它通过大幅增加后训练算力和优化技术栈，在代码、3D 创作、金融研究等长程 Agent 能力上显著超越前代 K3。
  2. 模型在代码和 3D 创作方面展现出强大的端到端执行能力，达到或接近国际顶尖水平。 在 Terminal-Bench 4.0 基准中得分 65.7%，超过 GPT-6 Astra；在 3D 建模基准 BenchCAD 上得分 92.7%，并能独立完成游戏开发、复杂装配和参数化设计等任务。
  3. 在金融领域，Kimi K3.1 Pro 取得多项基准测试的当前最优成绩，并能交付专业级工作流。 在 OfficeQA Pro v2 上得分 64.4% 创 SoTA，内部金融基准全面超越 K3，案例包括财务建模、投研报告和行业深度研究，事实准确性也大幅提升。
  4. 月之暗面在安全方面采取主动措施，移除网络攻防相关数据，并基于评估决定开放权重。 通过数据清理和针对性控制，在降低潜在滥用风险的同时保留通用实用性，模型漏洞研究能力明显低于未清理版本，且落后于前沿闭源模型，旨在渐进式提升安全能力。

💬 文章金句

  • 今天，我们正式推出 Kimi K3.1 Pro，这是 K3.1 系列的第一个模型，也是我们迄今能力最强的 3 万亿级参数模型，支持 100 万上下文。
  • 在代码、Agent 和知识类基准上，K3.1 Pro 达到或接近最强闭源模型的水平。
  • 首先，我们不希望发布推进网络攻防能力绝对前沿的开放权重。
  • 发现「可能」之极限的唯一方法，是向「不可能」的方向多走一小步。
