时隔 7 年，Notion 发布 3.0 版本，全面进入 Agent 时代

9/19/2025, 8:38:00 AM

📌 一句话摘要

Notion 发布 3.0 版本，全面引入 Agent 功能，旨在通过 AI 队友执行复杂工作流，显著提升知识工作效率。

📝 详细摘要

文章详细介绍了 Notion 3.0 版本的发布及其核心 Agent 功能，这是 Notion 自 2.0 版本以来的又一次重大更新。Notion Agent 被定位为世界上首个知识工作 Agent，具备在 Notion 环境中执行创建文档、搭建数据库、跨工具搜索、以及处理多步骤工作流等能力，并支持长达 20 分钟的自主运行。文章强调了 Agent 在解放用户免于繁琐重复工作、自主执行复杂工作流、以及通过高度个性化的“记忆库”提升协作效率方面的潜力。此外，文章还预告了即将推出的“自定义 Agent”功能，允许团队创建并共享具有特定专长的 AI 专家。Notion 3.0 的目标是打造一个“AI 工作空间”，让 AI 学会运用 Notion 的基础模块功能来完成实际工作，实现“上下文理解”、“协作”与“行动执行”三大能力的集成。

💡 主要观点

  1. Notion 3.0 引入 AI Agent 功能，旨在实现知识工作的全面自动化。 Agent 能够像人类一样在 Notion 中执行创建文档、管理数据库、跨工具搜索等复杂操作，大幅提升工作效率，将用户从重复性任务中解放出来。
  2. Agent 具备自主执行长达 20 分钟的多步骤复杂工作流的能力。 它能跨平台检索、整合信息，将会议纪要转化为提案，或自动更新知识库，提供完整的解决方案，而非仅仅是聊天机器人。
  3. 高度个性化的“记忆库”让 Agent 能理解并适应用户的工作方式。 用户可以通过“指令页面”自定义 Agent 的行为模式和回复格式，使其更高效地与个人和团队协作，并可下载专业技能模板。

💬 文章金句

  • Notion AI Agents 是世界上第一个知识工作 Agent，通过与数据库协同，可以执行多步骤的复杂指令，支持长达 20 多分钟的自主运行。
  • 这并不是一个只会给出通用建议的 AI 聊天机器人。你的 Notion Agent 能够处理实际工作——因为它理解你的工作内容，并且可以直接采取行动。
  • 过去，Notion AI 擅长快速解答问题或编辑单个页面；现在，你的 Agent 一次能自主工作长达 20 分钟，同时处理几百个页面。
  • 你可以为 Agent 分配一个「指令页面」，自定义它的行为模式。这个页面就像一个「记忆库」，帮助你和 Agent 更高效地协作。
  • 这就像拥有一整个 AI 专家团队：每个 Agent 都有自己的专长，能按照你设置的时间或触发条件工作，即使你在休息，工作也能持续推进。
