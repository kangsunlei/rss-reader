IntelliJ IDEA 2025.1 重磅发布！ | IntelliJ IDEA 博客

4/16/2025, 12:17:16 PM

📌 一句话摘要

IntelliJ IDEA 2025.1 发布，显著增强 Java 24、Kotlin 等语言及技术支持，优化 AI 功能和调试体验。

📝 详细摘要

IntelliJ IDEA 2025.1 版本发布，带来了多项改进。它完全支持 Java 24 的所有特性，默认启用 K2 模式以增强 Kotlin 开发的性能，引入 Kotlin Notebooks 以进行交互式开发。JetBrains AI 进行了重大升级，统一了 AI 助手（AI Assistant）和 Junie，并支持 GPT-4.5、Claude 3.7 Sonnet 和 Gemini 2.0 Flash。调试支持也得到了增强，增加了暂停和恢复观察表达式评估的选项。用户体验方面，采用了新的终端架构，并默认使用 Windows 原生文件对话框。同时，对 Scala 和构建工具的支持也得到了改进。

💡 主要观点

  1. 完全支持 Java 24，确保与最新语言更新的无缝体验。 IntelliJ IDEA 2025.1 提供了对 Java 24 中所有特性的完整支持，使开发人员能够轻松地使用最新的语言功能。
  2. 默认启用 K2 模式，显著提升 Kotlin 开发的性能。 K2 模式的启用标志着在增强 Kotlin 代码分析、内存效率和整体性能方面迈出了重要一步，为 Kotlin 开发人员带来更流畅的体验。
  3. Kotlin Notebooks 提供了用于实时原型设计和数据分析的交互式环境。 Kotlin Notebooks 是一个内置功能，适用于各种任务，包括原型设计、演示、日志解析、文档编写、深入数据分析和可视化。
  4. JetBrains AI 进行了重大升级，提供更智能的 completion 和上下文感知。 JetBrains AI 统一了 AI 助手（AI Assistant）和 Junie，并支持 GPT-4.5、Claude 3.7 Sonnet 和 Gemini 2.0 Flash，为开发者提供更强大的 AI 辅助能力。
