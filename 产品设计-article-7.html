交互设计必备基础知识扫盲

4/8/2026, 2:34:00 PM

📌 一句话摘要

本文系统梳理了交互设计的基本概念、与 UI/UX 的区别及核心术语，旨在帮助设计师建立清晰的交互设计认知框架。

📝 详细摘要

文章针对交互设计初学者，系统性地扫盲了交互设计的基础知识。作者首先厘清了 UI 设计、UX 体验设计与交互设计的定义及相互关系，指出交互设计是制定界面操作流程的核心过程。文中重点强调了交互设计在复杂功能中的独立价值，并纠正了将交互设计等同于制作可交互原型的误区。此外，文章对人机交互、交互流程、交互事件、交互反馈等关键术语进行了详细解析，并结合 Figma 的操作逻辑进行了具象化说明，为 UI 设计师提供了清晰的专业知识图谱。

💡 主要观点

  1. 明确交互设计、UI 设计与 UX 设计的边界与联系。 UI 侧重视觉呈现，UX 是包含交互与视觉的体验总和，而交互设计专注于制定功能操作逻辑与流程，三者互为支撑，交互通常是视觉设计的前置条件。
  2. 纠正交互设计等于制作可交互原型的误区。 交互设计的核心交付物是清晰的逻辑方案与明细文档，而非仅仅是高保真的动态原型，过度沉迷于原型制作往往是低效的。
  3. 交互设计在复杂项目中的独立价值。 对于功能逻辑复杂的系统，独立开展交互设计能有效减少后续视觉设计的改稿成本，提升整体项目的推进效率。
  4. 基于 Figma 逻辑解析交互核心术语。 通过拆解交互事件（Interaction）、触发方式（Trigger）、反馈（Action）和动效（Animation），将抽象理论与设计工具的操作逻辑紧密结合。

💬 文章金句

  • 如果仅仅是基于产品需求把界面视觉做出来，那就是 UI 设计。如果目标是为了追求更好的用户体验，且把界面视觉作为提升体验的手段之一去完成，那就是体验设计。如果是为了制定产品界面或功能的操作方法，那就是交互设计。
  • 交互设计要交付的是具体方案和明细内容，怎么做看起来直观且高效就怎么做，而可交互原型很难满足这些核心要求。
  • 交互是 UI 设计师最重要的产出内容之一，也是无法被 AI 取代的部分。
