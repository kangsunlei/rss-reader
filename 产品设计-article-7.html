针对不同显示模式优化 PWA——Smashing Magazine

8/26/2025, 8:00:00 AM

📌 一句话摘要

本文详细介绍了如何通过 CSS 媒体查询和 JavaScript 优化渐进式 Web 应用，以适应不同显示模式，解决可用性问题并提升用户体验。

📝 详细摘要

本文全面探讨了为各种显示模式优化渐进式 Web 应用 (PWA)，旨在缓解从传统浏览器环境过渡到类似原生应用体验时出现的可用性问题。文章首先概述了 PWA manifest 的关键显示模式——`fullscreen` （全屏）、`standalone` （独立）、`minimal-ui` （最小化 UI）和 `browser` （浏览器）——并强调了当浏览器界面隐藏时，用户将无法访问的关键浏览器功能（例如，导航按钮、URL 栏、刷新）。提出的核心解决方案包括利用 CSS `display-mode` 媒体查询和 JavaScript 的 `window.matchMedia` API 以编程方式检测当前显示模式。这种检测能力使开发人员能够动态调整 PWA 的用户界面和内容。讨论的实际应用包括专门为已安装的 PWA 用户定制内容（例如，减少营销内容，提供应用内设置），实施平台专属功能（例如底部导航栏），有效地隐藏冗余的 PWA 安装提示，并战略性地利用 manifest 的 `scope` （作用域）和 `start_url` （启动 URL）属性来控制 PWA 的入口点和可导航边界。文章强调了调整 PWA 体验以符合用户对原生应用的期望的重要性。同时，文章还讨论了浏览器支持差异带来的挑战，以及在不同设备和操作系统上进行全面测试的必要性。最终，它提倡创建真正自适应和精致的 PWA 体验。

💡 主要观点

  1. 在 PWA 显示模式下隐藏浏览器 UI 可能会导致显著的可用性问题。 用户无法访问后退/前进导航、页面刷新和 URL 分享等基本浏览器功能，因此开发人员需要提供应用内替代方案，以实现无缝体验。
  2. 开发人员可以使用 `display-mode` 媒体查询和 JavaScript 动态调整 PWA UI 和内容。 CSS 媒体查询和 `window.matchMedia` 允许以编程方式检测 PWA 的当前显示模式，从而能够针对元素和行为进行有针对性的调整，以获得最佳用户体验。
  3. 根据检测到的显示模式定制内容和功能可显著提升 PWA 用户体验。 这包括为已安装的用户减少营销内容，公开类似原生的设置和导航，隐藏冗余的安装提示，以及利用 manifest `scope` 和 `start_url` 来实现上下文内容传递。

💬 文章金句

  • 就像我们在为 Web 设计与为印刷设计时会做出不同的考虑一样，我们需要在为独立体验设计时做出不同的考虑，而不是为基于浏览器的体验设计。这需要通过定制内容和用户体验来适应媒介。
  • 很容易忘记浏览器为我们提供了多少功能。
  • 显示模式媒体查询提供了一种强大的方式来创建真正自适应的渐进式 Web 应用，使其能够智能地响应安装和显示上下文。
  • 关键是要记住，独立模式下的 PWA 用户与标准网站访问者有不同的需求和期望。
